The one pair of CXP optical cables connect to a system node by using one 2-ports PCIe optical cable adapter feature EJ24 placed in the CEC.

The CXP optical cable pair and the optical cable adapter features are concurrently maintainable. Therefore, careful balancing of I/O, assigning adapters through redundant EMX0 expansion drawers, and different system nodes can ensure high-availability for the I/O resources assigned to partitions.
