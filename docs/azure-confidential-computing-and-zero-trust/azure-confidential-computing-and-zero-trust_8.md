## 关于作者

**拉齐·赖斯**在设计和开发高度安全且可扩展的软件和服务方面拥有二十多年的经验。他目前在微软工作，在那里十多年来一直协助企业通过保护其身份免受最复杂的网络攻击和欺诈来增强其网络安全态势。他的感兴趣领域包括隐私增强技术以及利用人工智能防止网络攻击。在 LinkedIn 上找到他。

**杰夫·伯恩鲍姆**是 IT 行业的 40 多年资深人士，曾担任产品管理、工程管理、销售和产品营销等职务。他于 2022 年加入微软，担任 Azure 营销部门的高级产品营销经理，一直专注于 Azure 机密计算产品组合。杰夫分别拥有哥伦比亚大学和加州大学伯克利分校的计算机科学学士学位和硕士学位。

**格雷厄姆·伯里**在微软拥有超过 18 年的经验，涉及 MSN、Windows、Office、Windows Phone 服务、Surface Hub、HoloLens 和混合现实等多种产品，目前在 Azure 工作，他专注于使用 Azure 机密计算在公有云中保护使用中的数据。他领导一支产品经理和解决方案专家团队，将机密计算引入无服务器和 Kubernetes 容器服务，提供开发人员和部署工具，并与客户和合作伙伴（包括机密 AI 和数据清洁室）实现 E2E 解决方案。他毕业于滑铁卢大学，获得系统设计工程和管理科学学位。

**维卡斯·巴蒂亚**是 Azure 机密计算的产品负责人，负责设计全球各地组织用来确保其工作负载在 Azure 上机密运行的产品和服务，方法是在数据使用时对其进行保护。他领导一个团队，负责涵盖跨 CPU 和 GPU 的机密硬件上的机密虚拟机、容器和应用程序等产品和服务。他还负责 Azure 中利用机密平台自身变成机密的服务。担任此职务之前，Vikas 在 Windows 开发者平台团队中领导了 Project Rome 的产品团队。他还在云游戏流式传输、Xbox One 以及 DevDiv 中的 C++ 编译器方面任职过。Vikas 拥有华盛顿大学福斯特商学院的 MBA 学位和阿拉巴马大学的计算机科学硕士学位。
