The Managed HSM service leverages the capabilities of Azure confidential computing, operating within a TEE constructed on Intel Software Guard Extensions (SGX). Intel SGX provides heightened security measures against both internal and external threats by leveraging hardware-based isolation within application enclaves to safeguard data while it is actively in use. You can’t view data or code inside the application enclave, even with a debugger. If untrusted code tries to change content in the application enclave memory, Intel SGX disables the environment and denies the operation. These unique capabilities help you protect your cryptographic key material from being accessible or visible as clear text. Capabilities of Managed HSM include the following:

+   - Single tenant and fully managed.
+   - FIPS 140-2 level 3 validated.
+   - Highly available and zone resilient.
+   - Each HSM pool consists of multiple HSM partitions that span three servers on several racks in several data centers. In case of hardware failure, member partitions for the HSM will be automatically migrated to healthy hardware.
+   - Each HSM instance uses a separate customer-specific security domain that cryptographically isolates each customer’s HSM.
