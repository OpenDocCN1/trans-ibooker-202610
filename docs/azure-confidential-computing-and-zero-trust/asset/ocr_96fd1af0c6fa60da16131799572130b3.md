# Always Encrypted with Secure Enclaves

Always Encrypted with secure enclaves in Azure SQL Database enables in-place encryption and rich confidential queries, including pattern matching, range comparisons, and sorting. As shown in Figure 3-7, Always Encrypted works by encrypting query parameters and decrypting query results inside the client driver on the application side. Within the database engine, only the secure enclave has access to plaintext data, reinforcing the protection of data confidentiality from rogue DBAs in customer’s organization, cloud operators, and malware.
