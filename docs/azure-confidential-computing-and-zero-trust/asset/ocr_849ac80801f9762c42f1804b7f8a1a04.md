# # Azure Confidential Computing and Zero Trust

Azure already helps protect data at rest and in transit using encryption. Azure confidential computing solutions are designed to help prevent unauthorized access to data in use in memory, by processing that data in a hardware-based, attested Trusted Execution Environment (TEE). In the process, these solutions help organizations strengthen their security posture by supporting the three key principles of zero trust starting at the hardware level: always verify, apply least privilege access, and assume a breach.

Azure offers a full range of services that use confidential computing ranging from virtual machines and container services to confidential computing enabled SaaS and developer tools.
