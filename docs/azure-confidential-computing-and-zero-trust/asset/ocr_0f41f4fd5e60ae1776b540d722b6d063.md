Various vendor-specific technologies enable reduction of what is in the TEE by providing memory isolation at different levels such as virtual machine level, container group level, and code level (even reducing it to few lines of code). As a result, more software can be moved outside of the TEE and can be breached without affecting the data in the TEE.
