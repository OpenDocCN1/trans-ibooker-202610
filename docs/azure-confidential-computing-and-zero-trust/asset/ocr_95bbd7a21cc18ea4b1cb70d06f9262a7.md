# VMs with Application Enclaves

VMs with application enclaves (app enclaves) support code-level isolation using Intel Software Guard Extensions (SGX) technology. It is important, when creating application enclaves, to identify which part of the application operates within the enclave. The enclave isolates that portion of code from the remainder of the application. After the enclave has initialized the code and it has been loaded into memory, untrusted components are unable to read or modify the code, which is encrypted with a unique key generated by the underlying SGX firmware.
