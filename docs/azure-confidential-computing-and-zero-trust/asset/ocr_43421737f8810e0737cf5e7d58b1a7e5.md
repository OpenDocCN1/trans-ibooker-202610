# Guest Attestation

Azure guest attestation software is the attestation support tool for confidential VMs on Azure. It lets users design their VM-based applications to verify the state of the underlying hardware and guest OS before secrets are exchanged and sensitive data is processed. It can be loaded onto a VM’s OS disk to provide cryptographically based proof that the VM is running in a hardware-based TEE with the necessary level of isolation and integrity. Guest attestation software can also provide a relying party, such as key management service, with evidence that both the TEE hardware and the software within the TEE are as expected before allowing the exchange of secrets.
