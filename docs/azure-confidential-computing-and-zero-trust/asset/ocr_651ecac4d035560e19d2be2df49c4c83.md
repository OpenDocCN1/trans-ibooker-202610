# Secure Key Release

The goal of Secure Key Release (SKR) is to ensure that keys stay encrypted during their lifecycle and are released only to the authorized code/application. SKR enables the transfer of a key from a key management service to an attested TEE, such as a secure enclave, a VM-based TEE, or a confidential container group. SKR adds an additional layer of access protection to data decryption/encryption keys, allowing only the TEE to access the keys. Access to these keys is governed by the SKR policies defined prior to key issuance.
