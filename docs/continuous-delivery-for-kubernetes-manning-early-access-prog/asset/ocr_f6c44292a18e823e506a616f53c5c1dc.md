# CONNECTING OUR SERVICES TO THE NEWLY PROVISIONED INFRASTRUCTURE

Note: Both services, the Agenda Service and Call for Proposals (C4P) Service were specially prepared to support both in-memory storage and external persistence. In your projects, you shouldn’t rely on an in-memory approach unless you are building a Proof of Concept.

![](bbox=[0.1, 0.28, 0.64, 0.7])

#1 A Kubernetes Deployment is created to run one of your services, the Pod Template contains the environment variables to configure the Pods that this Deployment will create.
#2 The Pod is created using the template specified in the Deployment resource which points to a Secret that contains the details to connect to the db instance.
#3 The container which is running inside the Pod needs to be prepared to consume the environment variables to connect to the db instance.
