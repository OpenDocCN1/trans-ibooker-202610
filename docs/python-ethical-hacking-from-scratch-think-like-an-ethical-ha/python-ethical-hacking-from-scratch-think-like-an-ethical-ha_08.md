# 第三部分：
恶意软件
开发

在本节中，我们将转向一个新主题。我们将从恶意软件开发过程开始，以及如何使用 Python 创建自己的恶意软件。创建自己的恶意软件是道德黑客攻击中非常重要的一方面。在第 6 章《恶意软件开发》中，我们将使用套接字编程创建一个非常基础的恶意软件远程访问工具。这将使你能够开发可用于入侵受害者机器的恶意软件。在第 7 章《高级恶意软件》中，我们将在恶意软件中开发更高级的功能，例如从受害者机器窃取敏感文件的能力，等等。在第 8 章《后利用》中，我们将讨论后利用的方面，即一旦你获得对受害者机器的访问权限后可以做的事情。最后一章涉及系统保护——如何保护你的系统免受攻击，以及黑客利用哪些弱点来控制你的系统。我们还将讨论如何使你的恶意软件持久化并在你想要时控制受害者机器。

本书的这一部分包含以下章节：

- 第 6 章，恶意软件开发
- 第 7 章，高级恶意软件
- 第 8 章，后利用
- 第 9 章，系统保护与持久化
