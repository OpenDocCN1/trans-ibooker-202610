# Publishing Messages

Publishing messages through the Cloud Console is only useful for testing our workflow. In a production environment as well as within our framework you will want the application to do the publishing. When publishing a message you will need to define either a message body or message attributes. A message can have just a message body or vice versa a message can have only one or more message attributes. You can also have both. You also don’t need to worry about a unique identifier or timestamp as Pub/Sub will add those receptive fields.
