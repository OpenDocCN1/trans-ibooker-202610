# Watermark

A watermark is a value that you define that will let Dataflow know when to expect the data. If you set the value to 30 seconds, and an element arrives after the 30-second watermark and even though the timestamp is within the water it will be considered late.

For example, if you have a window storing items for events in 30 seconds and you receive the following 3 elements [element 1: 2020-19-09 0:00:01], [element 2: 2020-19-09 0:00:05] & [element 3: 2020-19-09 0:00:15] but element 3 has the event time included in this interval but it comes to the system after the window computation is considered to be on late.
