# NOTE

Our preferred method is to use message attributes as this gives me the ability to programmatically lookup values for the needed key without processing the entire message. Example: In our framework, Cloud Dataflow will pull messages from Cloud Pub/Sub. Programmatically we extract the key:values pairs as follows: pub_sub_data["fileid"]. This makes it simple to then assign the value to a variable in our code versus parsing the message body.
