As an alternative approach, if you have a single publisher and single subscriber, you can sequence the messages with a counter. In the following exercise, we will configure a for loop which will send 100 messages to Pub/Sub, and you will then configure a single subscriber which uses a persistent counter to order the messages. We need to use the counterid variable as a message attribute when you publish the message as well as match the counterid variable starting value in the subscriber.
