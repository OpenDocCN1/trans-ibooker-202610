Cloud Monitoring provides additional metrics for Cloud Pub/Sub as well it allows you to send notifications based on a determined value you configure. To enable notifications you must first create a Notification Channel. Here's a rundown of how to do that.

+   1. Open the Monitoring in the Google Cloud Console:
+      Monitoring
+   2. Click Alerting:
+      Alerting
+   3. In the top menu Click Edit Notification Channels:
+      EDIT NOTIFICATION CHANNELS
+   4. Configure the SMS Notification Channel
+   5. Back in the Altering Console click Create Policy:
+      CREATE POLICY
+   6. Enter a Name for your Policy
+   7. Click Add Policy
+   8. For the Resource Type and Metric select the following:
+      a. Cloud Pub/Sub Subscription
