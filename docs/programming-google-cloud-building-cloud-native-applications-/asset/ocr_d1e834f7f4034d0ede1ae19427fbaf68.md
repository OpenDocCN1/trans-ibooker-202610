As you can see from the list, we are somewhat limited with persistent disks. Even if we choose to use zonal standard persistent disks and create an instance to store the audio files, our costs would be quite high. At the same time we start to move away from our cloud native approach as now we would need to manage a compute instance, attached persistent disks and we would need a way to monitor the storage for events as file creation to trigger a cloud function. +     - Approximate Total per Month for 128 TB, USD $2,621.44 per 1 month

This cost analysis doesn't account for the storage operations per month on the cloud storage or the compute instance cost for mounting the standard persistent disks. These numbers for storage are set for one year, but you have to consider what happens at year two, three, etc. Our persistent disk solution becomes complicated and expensive hence it makes the most sense to go the route of cloud storage buckets.

You might be wondering about storage operations in Cloud Storage. An operation is an action that makes changes to or retrieves information about buckets and objects. Cloud Storage operations are divided into three categories: Class A, Class B, and free.
