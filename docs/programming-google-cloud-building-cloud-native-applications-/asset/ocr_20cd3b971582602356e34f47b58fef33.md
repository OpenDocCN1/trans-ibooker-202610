# Pub/Sub or Pub/Sub Lite

Google Cloud offers two versions of Cloud Pub/Sub: Cloud Pub/Sub, and Cloud Pub/Sub Lite. If you have predictable traffic patterns and you don’t require regional Pub/Sub then Cloud Pub/Sub Lite will be a more cost-effective solution.
