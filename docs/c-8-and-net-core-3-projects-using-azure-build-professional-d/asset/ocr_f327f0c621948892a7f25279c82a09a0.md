FileSystemEnumerable allows us to traverse a directory in various ways. As you can see, we can filter certain files and file types by using a combination of EnumerationOptions and ShouldIncludePredicate. Once we have our list, we can simply iterate it as we would any collection; in our case, we’re calling the method that we passed in and passing back the filename.
