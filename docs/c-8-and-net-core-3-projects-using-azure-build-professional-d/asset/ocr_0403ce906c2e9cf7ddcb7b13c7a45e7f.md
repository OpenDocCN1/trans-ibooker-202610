As usual, you can simply search for this as well. When selected, click **Add** to create a new database:

![](bbox=[0.105, 0.18, 0.895, 0.645])

This screen is probably looking quite familiar by now. All the parts are broadly the same: **Subscription** and **Resource group** determine where your resource lives. The **Database name** should be unique per server.

Unless you already have a server set up, select the link labeled **Create a new SQL server**. This will open a window on the right-hand side of the screen, allowing you to create a new server. Once you've done so, it will populate that value for you.
