18. Ah, yes! We are still pointing to our local DB and we don't have access to that from the publish environment. Let's update our `appsettings.json` so that it points to our Azure DB.

19. Navigate to the SQL Server from your Azure dashboard and then to **Properties**. On the right-hand pane, you should see an option to **Show database connection strings**:

![](bbox=[0.106, 0.244, 0.896, 0.746])

20. Copy the **ADO.NET connectionstring**, head back to your code, and update the `CONNECTION STRINGS` entry in the `appsettings.json` file.

21. Republish the app and you should be good to go!
