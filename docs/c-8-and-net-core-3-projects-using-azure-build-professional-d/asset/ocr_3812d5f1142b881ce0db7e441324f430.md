```
public IMongoCollection<WorkItem> WorkItems

    get

        return Database.GetCollection<WorkItem>("workitem");
    }
}

+   4. Since we are using C# 6 at least, we can further simplify the WorkItem property by changing it to an expression-bodied property. To do this, change the code to look as follows:

```
public IMongoCollection<WorkItem> WorkItems =>
Database.GetCollection<WorkItem>("workitem");
