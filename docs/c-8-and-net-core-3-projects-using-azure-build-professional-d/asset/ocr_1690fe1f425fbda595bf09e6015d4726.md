appsettings.json file and, should we create or drop a file into the c:\tmp folder, we
should see it uploaded into the cloud. When it is changed, the changed version is uploaded;
however, we are missing three key pieces of functionality.

The next thing we'll need to add is logging. The unfortunate reality about Windows
Services or, indeed, services of any kind, is that they are notoriously difficult to debug.

Secondly, if we run our application and the target destination is empty, all the files that
were dropped into that directory will be transferred over to the cloud; however, what if we
