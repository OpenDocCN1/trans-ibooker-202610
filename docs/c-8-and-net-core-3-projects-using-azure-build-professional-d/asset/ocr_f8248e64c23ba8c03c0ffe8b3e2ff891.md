Let's start by configuring our queue:

+   1. The first thing we need to do is create a new storage account. In the Azure portal, select **Storage accounts** from the menu, or simply search. Once the **Create storage account** blade appears, select the option to add a new storage account:

![](bbox=[0.102, 0.238, 0.895, 0.66])
