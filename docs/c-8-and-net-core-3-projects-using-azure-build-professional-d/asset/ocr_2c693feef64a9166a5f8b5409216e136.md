npm init will create a file called package.json in your project; this file determines which files are needed and will download any packages specified in this file to a node_modules folder within the root directory of the project. As you're initializing node modules, you'll be asked a series of questions, to which you can just press Enter in response.

+   6. You can confirm that the download was successful if the node_modules directory exists; this won't be included in your project, so you may have to select to show all files:

While npm is a widely used package manager, it does have a slight issue with .NET applications. The problem is that it downloads the files into the node_modules directory (as you can see in the preceding screenshot). This is not ideal as you won't be able to access anything outside wwwroot. Additionally, it's not actually included in your project by default.
