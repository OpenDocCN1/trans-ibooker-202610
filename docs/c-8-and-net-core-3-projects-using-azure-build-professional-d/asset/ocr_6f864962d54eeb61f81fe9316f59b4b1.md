If we had an iOS project, there would be a third project, called `EmotionDetector.iOS`. If you have a look at the references in `EmotionDetector.Android`, you'll see that it refers to `EmotionDetector`. The idea here is that `EmotionDetector` represents the shared codebase; however, this functionality can be overridden per platform.
