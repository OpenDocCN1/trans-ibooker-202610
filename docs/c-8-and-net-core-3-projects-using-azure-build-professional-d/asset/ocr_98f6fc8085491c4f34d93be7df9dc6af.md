The first step is to add a Thread Group:

![](bbox=[0.106, 0.233, 0.892, 0.594])

A thread group is a way to represent a set of users performing an action. Let's set up 10 users who will execute our generation app 10 times each.

> 10 users running the app 10 times and the app generating 10 orders for each invocation means that 1,000 orders will be generated.
