2. For `MongoClient` to work, we need to give it a connection string to the MongoDB instance we created. Open the `appsettings.json` file in the Solution 'Bug Tracker' pane, as shown in the following screenshot:

![](bbox=[0.315, 0.19, 0.685, 0.535])

3. When you open your `appsettings.json` file, it should look as follows:

```
{
  "Logging": {
    "IncludeScopes": false,
    "LogLevel": {
      "Default": "Warning"
    }
  }
}
```

4. This is when you'll need the connection string that you copied earlier. Modify the file and add the MongoDB connection details, as follows (replacing `[connectionstring]` with the value that you copied earlier):

```
{
  "MongoConnection": {
    "ConnectionString": "[connectionstring]",
    "Database": "TaskLogger"
  },
}
```
