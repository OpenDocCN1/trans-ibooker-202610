Selecting the **Import profile** option will prompt you to find a saved profile (*.publishsettings). Obviously, when you create one of the previous profiles, you can save it. Sometimes, it can make sense to store multiple publish profiles: this is typically something you would do locally because, in modern software development, it is unusual to find anybody manually deploying an application; instead, they will set up a CI/CD pipeline, which is triggered directly from a GitHub repository check-in.
