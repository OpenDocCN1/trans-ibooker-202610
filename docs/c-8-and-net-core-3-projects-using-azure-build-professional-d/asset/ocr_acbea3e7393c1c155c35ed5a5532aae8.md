# Publishing the bot

To start the publishing process, simply right-click the project file and select **Publish**. You'll be shown the following screen:

![](bbox=[0.15, 0.2, 0.85, 0.44])

Leave the default settings as they are and select **Publish**. You'll now be asked a series of questions regarding how and where to deploy your app:

![](bbox=[0.15, 0.51, 0.85, 0.86])
