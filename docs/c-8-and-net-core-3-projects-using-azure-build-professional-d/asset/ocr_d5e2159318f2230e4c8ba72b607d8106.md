As you can see, we just have a very basic gated check that returns whether we are dealing with an image. Of course, we’re going to need to write that method. Here, we’ve come to one of the new C# 8 features we haven’t mentioned yet. Prior to C# 8, the method may have looked like this:

```
public static bool IsImage(string fileName)
{
    string ext = Path.GetExtension(fileName);
    switch (ext)
    {
        case "png":
        case "jpg":
        case "jpeg":
        case "bmp":
        case "gif":
            return true;
        default: return false;
    }
}
```

However, with the new switch statement, we can write that method like this:

```
public static bool IsImage(string fileName)
{
    string ext = Path.GetExtension(fileName);
    return ext switch
    {
        "png" => true,
        "jpg" => true,
        "jpeg" => true,
        "bmp" => true,
        "gif" => true,
        _ => false
    };
}
```

We could make it even terser if we included a GetExtension call in the switch statement itself, but, generally, it reads easier.

The new switch statement is actually more powerful than this and, in fact, supports pattern matching.
