# # Publishing the logic app

We're on the home stretch now. All that remains is to publish the app to Azure. Right-click on the logic app, select Deploy, and then New...

![](bbox=[0.24, 0.205, 0.76, 0.38])

As you can see from this screenshot, once you've deployed the project, a shortcut will be created to deploy to the correct resource group.

In the dialog that appears, you're asked to select a resource group:
