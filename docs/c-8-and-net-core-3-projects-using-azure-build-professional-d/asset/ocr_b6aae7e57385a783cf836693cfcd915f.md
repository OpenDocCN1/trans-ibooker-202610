This time, we're going to select **Condition**. When you select **Condition**, you're presented with what, on the face of it, seems like a complex set of options; however, it's actually very simple.

Each condition must be a test that results in a *yes* or *no* answer; there cannot be any middle ground. For example, if the test were Is it 5pm GMT?, then the answer would either be Yes, it is exactly 5pm GMT, or it would be No, it is not exactly 5pm GMT.
