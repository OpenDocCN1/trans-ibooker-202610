At the time of writing, having an MSDN subscription entitles you to a number of Azure credits each month; the exact number depends on the subscription type.

The resource group is just that: a way to group resources together. There are no rules, but it makes sense to group resources that have a similar lifetime and purpose.

This diagram illustrates the relationship between the various hierarchical entities within Azure:

![](bbox=[0.101, 0.305, 0.893, 0.675])

A resource is, effectively, anything that you can consume and be billed for. In our case, our Cosmos DB instance is our resource; as you can see, this exists within a resource group, and this, in turn, exists inside a subscription.
