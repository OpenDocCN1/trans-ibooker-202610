If you're familiar with ASP.NET 2.x, you'll have expected to see UseMvc here. In fact, UseMvc is deprecated, in favor of manually building the MVC middleware that you require.

+   3. Lastly, make sure that your Main method looks as follows:

```
public static void Main(string[] args)
{
    var host = BuildWebHost(args);
    using (var scope = host.Services.CreateScope())
    {
        var services = scope.ServiceProvider;
        try
        {
            var context = services.GetRequiredService<ResearchContext>();
            DbInitializer.Initialize(context);
        }
        catch (Exception ex)
        {
            var logger =
            services.GetRequiredService<ILogger<Program>>();
            logger.LogError(ex, "An error occurred while seeding the database.");
        }
    }
    host.Run();
}
```
