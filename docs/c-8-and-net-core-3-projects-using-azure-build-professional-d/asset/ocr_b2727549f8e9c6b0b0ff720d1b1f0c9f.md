We also have a **Settings** tab, which is applicable to all four methods. Let's have a quick look at what our options are there:

![](bbox=[0.105, 0.165, 0.895, 0.58])

The **Configuration** option can be set to either **Debug** or **Release**.

With **Debug**, your generated files are debuggable, meaning that it is possible to hit specified breakpoints. But it also means that there is a performance decrease.

With **Release**, you won't be able to debug on the fly, but will have an increase in performance as your application is fully optimized.

In our case, the only available target framework is **netcoreapp2.0**, but in standard .NET applications, this is where you could set the target to .NET 3.5 or .NET 4.5, or whichever is available.

You can also specify the target runtime, choose to have Visual Studio clean up the destination folder, and specify a connection string specifically for runtime.

As we mentioned previously, these settings are applicable to all four publishing methods, which we will have a look at now.
