Once you've noted the App ID and secret, there are two options to activate them. The first (and perhaps easiest while you're debugging) is to simply paste them into the `appsettings.json` and publish the app again. However, you don't *need* to do this—you can simply navigate to the **Configuration** blade of the App Service and add an `AppSetting` there:
