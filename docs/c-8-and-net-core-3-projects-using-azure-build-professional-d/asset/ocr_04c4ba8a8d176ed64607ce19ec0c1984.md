This is the absolute minimum code that you need for a functioning UWP ViewModel.
The INotifyPropertyChanged interface is an interface that has one event:
PropertyChanged. Essentially, the purpose here is that when you change a property, you
need to tell the binding system that you've done so, and then the UI can be updated. The
first thing that we need in our ViewModel is a method called Initialise—if you
remember, we actually called this further up:

```
internal async Task Initialise()
{
    await _wrapper.StartConversation();
}
```

# Let's add the data that we're displaying in the app:

```
public ObservableCollection<ChatMessage> ChatHistory { get; set; } = new
ObservableCollection<ChatMessage>();

private string _messageText;
public string MessageText
{
    get { return _messageText; }
    set
    {
        _messageText = value;
        RaisePropertyChanged();
    }
}
}
```

The MessageText phrase is simply a string (as we guessed earlier it would be). As you can
see, we're calling the RaisePropertyChanged event that we created earlier when the
property was set.

You can choose to enhance this by only raising the event when the value changes.
