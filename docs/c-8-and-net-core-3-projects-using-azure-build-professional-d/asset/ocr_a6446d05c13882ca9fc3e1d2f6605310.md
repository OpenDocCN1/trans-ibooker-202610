Make a note of the `MicrosoftAppId`. Select **Manage** to display the **Certificates & Secrets** blade:

![](bbox=[0.105, 0.163, 0.895, 0.445])

Here, we can create a new secret:

![](bbox=[0.312, 0.505, 0.685, 0.755])

Simply provide a description and click **Add**. Once you create the secret, you will have only one chance to make a note of it; you will never see it ever again, so if you lose it, you'll need to remove and recreate it.
