If you wish, you can edit the JSON directly. This works well if you have a very small change to make, or if you wish to compare or merge changes, but trying to create your logic app like this would be challenging to say the least! Instead, right-click on the `LogicApp.json` file and select **Open With Logic Apps Designer**:

![](bbox=[0.378, 0.221, 0.621, 0.409])

You'll be asked to pick an Azure subscription and resource group to associate your app with. You will then be presented with the following:

![](bbox=[0.192, 0.484, 0.808, 0.83])

As you can see, there's a useful little video to get you started, some pre-built trigger templates, and some templates that are almost ready to go.
