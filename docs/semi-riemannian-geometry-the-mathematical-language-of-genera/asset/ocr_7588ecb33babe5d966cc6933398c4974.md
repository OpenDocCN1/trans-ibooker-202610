hence

```
Curl(X)^F = *d(X^F)
= (∂α³/∂y - ∂α²/∂z) * (d(y) ∧ d(z)) + (∂α¹/∂z - ∂α³/∂x) * (d(z) ∧ d(x))
+ (∂α²/∂x - ∂α¹/∂y) * (d(x) ∧ d(y))
= (∂α³/∂y - ∂α²/∂z) d(x) + (∂α¹/∂z - ∂α³/∂x) d(y)
+ (∂α²/∂x - ∂α¹/∂y) d(z)
= (∂α³/∂y - ∂α²/∂z, ∂α¹/∂z - ∂α³/∂x, ∂α²/∂x - ∂α¹/∂y)^F
= curl(X)^F,
```

where the third equality follows from Example 8.5.4, the fourth equality from the manifold version of Theorem 3.3.2, and the last equality from Table 10.6.1. Thus, Curl(X) = curl(X).

# 20.6 Hesse Operator

Let (M, 𝔤) be a semi-Riemannian manifold. The Hesse operator is the map

```
Hess : C^∞(M) ⟶ T₂⁰(M)
```

defined by

```
Hess(f) = ∇²(f)  (20.6.1)
```

for all functions f in C^∞(M), where we denote

```
∇ ∘ ∇    by    ∇².
```

We refer to Hess(f) as the Hessian of f.

# Theorem 20.6.1. Let (M, 𝔤) be a semi-Riemannian m-manifold, let f be a function in C^∞(M), and let X, Y be vector fields in 𝔛(M). Then:

+   (a)

```
Hess(f)(X, Y) = X(Y(f)) - ∇_X(Y)(f)
= ∇_X(∇_Y(f)) - ∇_{∇_X(Y)}(f)
= ⟨∇_X(Grad(f)), Y⟩.
```

+   (b) Hess(f) is symmetric.
