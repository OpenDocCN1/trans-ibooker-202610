by ζ(t) = q + t e_i, where ε > 0 is chosen small enough that (q − ε e_i, q + ε e_i) ⊂ U. Consider the smooth curve λ(t) : (−ε, ε) ⟶ M defined by λ = φ ∘ ζ, and observe that λ(0) = φ(q) = p. By Theorem 10.1.10,

```
dλ/dt (0) = d(φ ∘ ζ)/dt |₀ = Σ_j dζ^j/dt (0) H_j|_q = H_i|_q.
```

It also follows from Theorem 10.1.10 that

```
d(N ∘ λ)/dt |₀ = d(N ∘ φ ∘ ζ)/dt |₀ = Σ_j dζ^j/dt (0) ∂(N ∘ φ)/∂r^j |_q
= ∂(N ∘ φ)/∂r^i |_q,
```

and then from (12.8.2) and (12.8.9) that

```
𝒲_p(H_i|_q) = − d(N ∘ λ)/dt |₀ = − ∂(N ∘ φ)/∂r^i |_q.
```

Taking the partial derivative with respect to r^i of both sides of ⟨𝒩_p, H_j|_q⟩ = 0 yields

```
0 = ⟨ ∂(N ∘ φ)/∂r^i |_q , H_j|_q ⟩ + ⟨ 𝒩_p , ∂H_j/∂r^i |_q ⟩.
```

We have from Theorem 10.1.6 and (11.2.1) that

```
∂H_i/∂r^j = ∂H_j/∂r^i,
```

hence

```
⟨ − ∂(N ∘ φ)/∂r^i |_q , H_j|_q ⟩ = ⟨ 𝒩_p , ∂H_i/∂r^j |_q ⟩.
```

Then

```
𝔥_ij(q) = ⟨𝒲_p(H_i|_q), H_j|_q⟩   [(12.8.6), (12.8.8)]
= ⟨ − ∂(N ∘ φ)/∂r^i |_q , H_j|_q ⟩   [(12.8.10)]
= ⟨ ∂H_i/∂r^j |_q , 𝒩_p ⟩,   [(12.8.11)]
```

which proves the first equality. We also have

```
⟨ ∂H_i/∂r^j |_q , 𝒩_p ⟩ = ⟨ ∂H_i/∂r^j |_q , G_q ⟩   [Th 12.7.3(a)]
= ε_M θ_ij(q),   [Th 12.3.3(c)]
```

which proves the second equality.
