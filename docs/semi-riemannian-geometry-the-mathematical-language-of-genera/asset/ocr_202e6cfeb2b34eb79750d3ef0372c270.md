# Theorem 11.2.1. Let φ : U ⟶ ℝ³ be a parametrized surface, let q be a point in U, and let (e₁, e₂) be the standard basis for ℝ². Then:

+   (a) d_q(φ)(e_i) = H_i|q for i = 1, 2.
+   (b) d_q(φ)(ℝ²) = span{ H₁|q, H₂|q }.

Proof. For a vector v = (a¹, a²) in ℝ², we have

d_q(φ)(v) = (d_q(φ¹)(v), d_q(φ²)(v), d_q(φ³)(v)) [Th 10.1.8(b)]

= ( Σ_i a^i ∂φ¹/∂r^i (q), Σ_i a^i ∂φ²/∂r^i (q), Σ_i a^i ∂φ³/∂r^i (q) ) [Th 10.1.2]

= Σ_i a^i ( ∂φ¹/∂r^i (q), ∂φ²/∂r^i (q), ∂φ³/∂r^i (q) )

= Σ_i a^i H_i|q,

from which the result follows.
