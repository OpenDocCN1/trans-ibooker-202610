# Theorem 22.1.10.

Let P₁, …, P_{m−1} be matrices in Mat_{(m−1)×1}, and consider the matrices

𝕡 = (P₁, …, P_{m−1}),      P₁¹ = [P₁ ⋯ P_{m−1}],

and

P = [ P₁¹   O_{(m−1)×1} ; O_{1×(m−1)}   1 ].

Then:

+   (a) 𝕡 is an orthonormal basis for Mat_{(m−1)×1} if and only if P₁¹ is in O(m−1).
+   (b) 𝕡 is a positively oriented orthonormal basis for Mat_{(m−1)×1} if and only if P₁¹ is in SO(m−1).
+   (c) If 𝕡 is a positively oriented orthonormal basis for Mat_{(m−1)×1} and A is a map in Lin(V,V) such that [A] = P or [A] = Pᵀ, then A is in R_m.

Proof. For brevity, let 𝕄 = Mat_{(m−1)×1} and 𝔼 = 𝔼_{m−1}. We have from (2.2.7) that

P₁¹ = [[P₁]_𝔼 ⋯ [P_{m−1}]_𝔼] = [id_𝕄]_𝕡^𝔼,

hence

det(P₁¹) = det( [id_𝕄]_𝕡^𝔼 ).    (22.1.4)

It follows that if 𝕡 is a basis for 𝕄, then: 𝕡 is consistent with 𝔼 (hence positively oriented) if and only if det(P₁¹) > 0.

(a): By definition, P₁¹ is in O(m−1) if and only if (P₁¹)ᵀ P₁¹ = I_{m−1}, which is equivalent to (P_i)ᵀ P_j = δ^i_j for i, j = 1, …, m−1.
