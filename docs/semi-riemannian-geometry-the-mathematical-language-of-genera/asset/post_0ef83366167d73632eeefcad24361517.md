
**Proof.** (c): We have

$\eta$ is in $\ker(A^*)$
$\Leftrightarrow\quad A^*(\eta)=0$
$\Leftrightarrow\quad A^*(\eta)(v)=0$ for all $v$ in $V$
$\Leftrightarrow\quad \eta(A(v))=0$ for all $v$ in $V$ \quad [(1.3.1)]
$\Leftrightarrow\quad \eta$ is in $\operatorname{im}(A)^0$.

(d): It follows from Theorem 1.3.1(c) and part (c) that

$$\ker(A)=\ker(A^{**})=\operatorname{im}(A^*)^0,$$

and then from Theorem 1.4.2 that

$$\ker(A)^0=\operatorname{im}(A^*)^{00}=\operatorname{im}(A^*).$$

(a): We have

$$\begin{aligned}
\operatorname{rank}(A^*) &= \dim(\operatorname{im}(A^*)) \\
&= \dim(\ker(A)^0) && [\text{part (d)}]\\
&= \dim(V)-\dim(\ker(A)) && [\text{Th 1.4.1}]\\
&= \operatorname{rank}(A). && [\text{Th 1.1.11}]
\end{aligned}$$

(b): We have

$$\begin{aligned}
\operatorname{rank}(A^*)+\operatorname{null}(A^*) &= \dim(W^*) && [\text{Th 1.1.11}]\\
&= \dim(W) && [\text{Th 1.2.1(c)}]\\
&= \dim(V) && [\text{assumption}]\\
&= \operatorname{rank}(A)+\operatorname{null}(A). && [\text{Th 1.1.11}]
\end{aligned}$$

The result now follows from part (a).

## Matrices and Determinants

In this chapter, we review some of the basic results from the theory of matrices and determinants.

### 2.1 Matrices

Let us denote by Mat_{m×n} the set of m × n matrices (that is, m rows and n columns) with real entries. When m = n, we say that the matrices are square. It is easily shown that with the usual matrix addition and scalar multiplication, Mat_{m×n} is a vector space, and that with the usual matrix multiplication, Mat_{m×m} is a ring.

Let P be a matrix in Mat_{m×n}, with

```
P = [p_j^i] = [ p_1^1  ...  p_n^1 ; ... ; p_1^m  ...  p_n^m ]
```

The transpose of P is the matrix P^T in Mat_{n×m} defined by

```
P^T = [p_i^j] = [ p_1^1  ...  p_1^m ; ... ; p_n^1  ...  p_n^m ]
```

The row matrices of P are

```
[p_1^1 ... p_n^1]   [p_1^2 ... p_n^2]   ...   [p_1^m ... p_n^m]
```

and the column matrices of P are

[p1^1; :; p1^m]   [p2^1; :; p2^m]   ...   [p_n^1; :; p_n^m].

### Example 2.1.1. For

P = [1 2 3; 4 5 6; 7 8 9],

the transpose is

P^T = [1 4 7; 2 5 8; 3 6 9]

and the column matrices are

[1;4;7]   [2;5;8]   [3;6;9].

### Theorem 2.1.2. If P and Q are matrices in Mat_l×m and Mat_m×n, respectively, then:

- (a) (P^T)^T = P.
- (b) (PQ)^T = Q^T P^T.

Proof. Straightforward.

We say that a matrix Q = [q^i_j] in Mat_m×m is symmetric if Q = Q^T, and diagonal if q^i_j = 0 for all i ≠ j. Evidently, a diagonal matrix is symmetric. Given a vector (a^1, …, a^m) in R^m, the corresponding diagonal matrix is defined by

diag(a^1, …, a^m) = [a^1 … 0; : ⋱ :; 0 … a^m],

where all the entries not on the (upper-left to lower-right) diagonal are equal to 0. For example,

diag(1) = [1]      diag(1,2) = [1 0; 0 2]      diag(1,2,3) = [1 0 0; 0 2 0; 0 0 3].

The zero matrix in Mat_m×n, denoted by O_m×n, is the matrix that has all entries equal to 0. The identity matrix in Mat_m×m is defined by

I_m = diag(1, …, 1),

so that, for example,

```
I₁ = [1]      I₂ = [1 0; 0 1]      I₃ = [1 0 0; 0 1 0; 0 0 1].
```

We say that a matrix Q in Matₘ×ₘ is invertible if there is a matrix in Matₘ×ₘ, denoted by Q⁻¹ and called the inverse of Q, such that

```
QQ⁻¹ = Q⁻¹Q = Iₘ.
```

It is easily shown that if the inverse of a matrix exists, then it is unique.

### Theorem 2.1.3. If P and Q are invertible matrices in Matₘ×ₘ, then:

- (a) (P⁻¹)⁻¹ = P.
- (b) (PQ)⁻¹ = Q⁻¹P⁻¹.
- (c) (P⁻¹)ᵀ = (Pᵀ)⁻¹.

Proof. (a), (b): Straightforward.

(c): By Theorem 2.1.2(b),

```
Iₘ = (Iₘ)ᵀ = (PP⁻¹)ᵀ = (P⁻¹)ᵀPᵀ,
```

from which the result follows.

Multi-index notation, introduced in Appendix A, provides a convenient way to specify submatrices of matrices. Let 1 ≤ r ≤ m and 1 ≤ s ≤ n be integers, and let I = (i₁,…,iᵣ) and J = (j₁,…,jₛ) be multi-indices in ℐᵣ,ₘ and ℐₛ,ₙ, respectively. For a matrix P = [pⱼⁱ] in Matₘ×ₙ, we denote by

```
P₍ⱼ₁,…,ⱼₛ₎⁽ⁱ¹,…,ⁱʳ⁾,    P_J^I,    [pⱼⁱ]₍ⱼ₁,…,ⱼₛ₎⁽ⁱ¹,…,ⁱʳ⁾,    or    [pⱼⁱ]_J^I
```

the r × s submatrix of P consisting of the overlap of rows i₁,i₂,…,iᵣ and columns j₁,j₂,…,jₛ (in that order); that is,

```
P₍ⱼ₁,…,ⱼₛ₎⁽ⁱ¹,…,ⁱʳ⁾ = [pⱼ₁ⁱ¹ … pⱼₛⁱ¹; ⋮ ⋱ ⋮; pⱼ₁ⁱʳ … pⱼₛⁱʳ].
```

When r = m, in which case (i₁,…,iₘ) = (1,…,m), we denote

```
P₍ⱼ₁,…,ⱼₛ₎⁽¹,…,ᵐ⁾   by   P₍ⱼ₁,…,ⱼₛ₎,
```

and when s = n, in which case (j₁,…,jₙ) = (1,…,n), we denote

```
P₍₁,…,ₙ₎⁽ⁱ¹,…,ⁱʳ⁾   by   P⁽ⁱ¹,…,ⁱʳ⁾.
```

When r = 1, so that I = (i) for some 1 ≤ i ≤ m, we have

```
P⁽ⁱ⁾ = [p₁ⁱ … pₙⁱ],
```

For a matrix $P = [p^i_j]$ in $\mathrm{Mat}_{m\times m}$, the trace of $P$ is defined by

$\operatorname{tr}(P) = \sum_i p^i_i.$

### Theorem 2.1.7. If $P$ and $Q$ are matrices in $\mathrm{Mat}_{m\times m}$, then:

- (a) $\operatorname{tr}(P+Q)=\operatorname{tr}(P)+\operatorname{tr}(Q)$.
- (b) $\operatorname{tr}(PQ)=\operatorname{tr}(QP)$.
- (c) If $Q$ is invertible, then $\operatorname{tr}(Q^{-1}PQ)=\operatorname{tr}(P)$.

Proof. (a): Straightforward.

(b): Let $P = [p^i_j]$ and $Q = [q^i_j]$. By Theorem 2.1.5(a),

$\operatorname{tr}(PQ)=\sum_i P^{(i)}Q_{(i)}=\sum_i\left(\sum_j p^i_j q^j_i\right)=\sum_j\left(\sum_i q^i_j p^j_i\right)$
$=\sum_j Q^{(j)}P_{(j)}=\operatorname{tr}(QP)$.

(c): This follows from part (b).

### 2.2 Matrix Representations

Matrices have many desirable computational properties. For this reason, when computing in vector spaces, it is often convenient to reformulate arguments in terms of matrices. We employ this device often.

Let $V$ be a vector space, let $\mathcal{H}=(h_1,\dots,h_m)$ be a basis for $V$, and let $v$ be a vector in $V$, with

$v = \sum_i a^i h_i.$

The matrix representation of $v$ with respect to $\mathcal{H}$ is denoted by $[v]_{\mathcal{H}}$ and defined by

$[v]_{\mathcal{H}} = \begin{bmatrix} a^1 \\ \vdots \\ a^m \end{bmatrix}.$

We refer to $a^1,\dots,a^m$ as the components of $v$ with respect to $\mathcal{H}$. In particular,

$[h_i]_{\mathcal{H}} = \begin{bmatrix} 0 \\ \vdots \\ 1 \\ \vdots \\ 0 \end{bmatrix}, \qquad (2.2.1)$

where 1 is in the $i$th position and 0s are elsewhere for $i=1,\dots,m$.

### Theorem 2.2.1 (Representation of Vectors)

If $V$ is a vector space of dimension $m$ and $\mathcal{H}$ is a basis for $V$, then the map

$$\mathcal{L}_{\mathcal{H}}: V \longrightarrow \operatorname{Mat}_{m\times 1}$$

defined by

$$\mathcal{L}_{\mathcal{H}}(v)=[v]_{\mathcal{H}}$$

for all vectors $v$ in $V$ is a linear isomorphism:

$$V\cong\operatorname{Mat}_{m\times 1}.$$

*Proof.* Straightforward.

With $V$ and $\mathcal{H}$ as above, let $W$ be another vector space, and let $\mathcal{F}=(f_1,\ldots,f_n)$ be a basis for $W$. Let $A:V\longrightarrow W$ be a linear map, with

$$A(h_j)=\sum_i a_j^i f_i,$$

so that

$$[A(h_j)]_{\mathcal{F}}=\begin{bmatrix}a_j^1\\\vdots\\a_j^n\end{bmatrix}$$

for $j=1,\ldots,m$. The matrix representation of $A$ with respect to $\mathcal{H}$ and $\mathcal{F}$ is denoted by $[A]_{\mathcal{H}}^{\mathcal{F}}$ and defined to be the $n\times m$ matrix

$$[A]_{\mathcal{H}}^{\mathcal{F}}=\begin{bmatrix}a_1^1&\cdots&a_m^1\\\vdots&\ddots&\vdots\\a_1^n&\cdots&a_m^n\end{bmatrix}=\left[\,[A(h_1)]_{\mathcal{F}}\ \cdots\ [A(h_m)]_{\mathcal{F}}\,\right].$$

As an example, consider the linear map $A:\mathbb{R}^2\longrightarrow\mathbb{R}^3$ given by $A(x,y)=(y,2x,3x+4y)$, and let $\mathcal{E}$ and $\mathcal{F}$ be the standard bases for $\mathbb{R}^2$ and $\mathbb{R}^3$, respectively. Then

$$[A]_{\mathcal{E}}^{\mathcal{F}}=\begin{bmatrix}0&1\\2&0\\3&4\end{bmatrix}.$$

### Theorem 2.2.2.

Let $U$, $V$, and $W$ be vector spaces, let $\mathcal{H}$, $\mathcal{F}$, and $\mathcal{G}$ be respective bases, let $A,B:U\longrightarrow V$ and $C:V\longrightarrow W$ be linear maps, and let $c$ be a real number. Then:

- (a) $[A+B]_{\mathcal{H}}^{\mathcal{F}}=[A]_{\mathcal{H}}^{\mathcal{F}}+[B]_{\mathcal{H}}^{\mathcal{F}}$.
- (b) $[cA]_{\mathcal{H}}^{\mathcal{F}}=c[A]_{\mathcal{H}}^{\mathcal{F}}$.
- (c) $[C\circ A]_{\mathcal{H}}^{\mathcal{G}}=[C]_{\mathcal{F}}^{\mathcal{G}}[A]_{\mathcal{H}}^{\mathcal{F}}$.
