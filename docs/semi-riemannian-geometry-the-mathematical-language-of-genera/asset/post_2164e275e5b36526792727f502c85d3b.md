
Then [M3] gives

curl(E) = -curl(∂A/∂t)

hence

curl(E + ∂A/∂t) = 0.

By Theorem 10.6.2, there is a function φ in C^∞(ℝ₀³ × ℝ), called the electric potential, such that

E + ∂A/∂t = -grad(φ)

so

E = -(grad(φ) + ∂A/∂t)    (22.2.3)

Equations (22.2.2) and (22.2.3) express E and B in terms of A and φ. As it stands, this representation is not unique. For example, let ψ be an arbitrary function in C^∞(ℝ₀³ × ℝ), and let

Ã = A + grad(ψ)      and      φ̃ = φ - ∂ψ/∂t

which is referred to as a gauge transformation of A and φ. Then

grad(φ̃) + ∂Ã/∂t = grad(φ - ∂ψ/∂t) + ∂/∂t(A + grad(ψ))

= grad(φ) + ∂A/∂t

and by Theorem 10.6.1(c),

curl(Ã) = curl(A) + curl(grad(ψ)) = curl(A).

Thus, Ã and φ̃ also satisfy (22.2.2) and (22.2.3). The range of potentials is limited by the constraint

div(A) + ∂φ/∂t = 0,    (22.2.4)

called the Lorenz gauge.

## Theorem 22.2.1. In the Lorenz gauge, Maxwell's equations are equivalent to:

□(A) = -μ₀J

□(φ) = -1/ε₀ ρ

where □ is the d'Alembert operator, as defined in Example 20.7.3.

Proof. Suppose Maxwell’s equations are satisfied. We have from (22.2.4) that

div(∂A/∂t) + ∂²φ/∂t² = 0,  (22.2.5)

hence

1/ε₀ ρ = div(E)  [M1]
= −div(grad(φ)) − div(∂A/∂t)  [(22.2.3)]
= −lap(φ) − div(∂A/∂t)  [Table 10.6.1]
= −(lap(φ) − ∂²φ/∂t²)  [(22.2.5)]
= −□(φ).

We also have

μ₀ J = curl(B) − ∂E/∂t  [M4′]
= curl(curl(A)) + ∂/∂t(grad(φ) + ∂A/∂t)  [(22.2.2), (22.2.3)]
= grad(div(A)) − lap(A) + grad(∂φ/∂t + ∂²A/∂t²)  [Th 10.6.1(e)]
= −lap(A) + ∂²A/∂t²  [(22.2.4)]
= −□(A).

Conversely, suppose □(A) = −μ₀ J and □(φ) = −ρ/ε₀ are satisfied. The preceding computations “in reverse” show that Maxwell’s equations are satisfied.

We now switch our focus from ℝ₀³ × ℝ to ℝ₁⁴ and recast the preceding discussion in terms of differential forms. Let J = (J¹, J², J³), E = (E¹, E², E³), A = (A¹, A², A³), and B = (B¹, B², B³), and define corresponding covector fields 𝒥, ℰ, 𝒜 in 𝔛*(ℝ₁⁴), and forms ℬ, ℱ in Λ²(ℝ₁⁴) by

𝒥 = 1/ε₀ [J¹ d(x) + J² d(y) + J³ d(z) − ρ d(t)],
ℰ = E¹ d(x) + E² d(y) + E³ d(z),
𝒜 = A¹ d(x) + A² d(y) + A³ d(z) − φ d(t),  (22.2.6)
ℬ = B¹ d(y) ∧ d(z) + B² d(z) ∧ d(x) + B³ d(x) ∧ d(y),

and

ℱ = ℰ ∧ d(t) + ℬ
= E¹ d(x) ∧ d(t) + E² d(y) ∧ d(t) + E³ d(z) ∧ d(t)
+ B¹ d(y) ∧ d(z) + B² d(z) ∧ d(x) + B³ d(x) ∧ d(y).

which proves the identity for the continuity equation. We have from the manifold version of Theorem 4.5.4 and (22.2.6) that 𝒜^S=(A^1,A^2,A^3,φ), hence

-δ(𝒜)=Div(𝒜^S) [Th 20.4.3(b)]

=∂A^1/∂x+∂A^2/∂y+∂A^3/∂z+∂φ/∂t [Ex 20.4.6]

=div(A)+∂φ/∂t,

which proves the identity for the Lorenz gauge.

## Theorem 22.2.4. In the Lorenz gauge (22.2.4), Maxwell’s equations are equivalent to:

d(𝒜)=ℱ

Δ(𝒜)=𝒥,

where Δ is the Laplace–de Rham operator, as defined by (20.8.1).

Proof. We need a couple of preliminary observations. Setting ω=𝒜, hence (α₁,α₂,α₃,α₄)=(A¹,A²,A³,−φ), in Example 16.1.9 gives

d(𝒜)= (−∂φ/∂x−∂A¹/∂t)d(x)∧d(t)+(−∂φ/∂y−∂A²/∂t)d(y)∧d(t)
+(−∂φ/∂z−∂A³/∂t)d(z)∧d(t)
+(∂A³/∂y−∂A²/∂z)d(y)∧d(z)+(∂A¹/∂z−∂A³/∂x)d(z)∧d(x)
+(∂A²/∂x−∂A¹/∂y)d(x)∧d(y).

We also have

grad(φ)+∂A/∂t=(∂φ/∂x+∂A¹/∂t,∂φ/∂y+∂A²/∂t,∂φ/∂z+∂A³/∂t)

and

curl(A)=(∂A³/∂y−∂A²/∂z,∂A¹/∂z−∂A³/∂x,∂A²/∂x−∂A¹/∂y).

Thus, d(𝒜)=ℱ if and only if (22.2.2) and (22.2.3) are satisfied, which is our first preliminary observation. It follows from (20.8.1) and Theorem 22.2.3 that

Δ(𝒜)=dδ(𝒜)+δd(𝒜)=dδ(𝒜), (22.2.7)

which is our second preliminary observation.

Now for the main proof. Suppose Maxwell’s equations are satisfied. Then (22.2.2) and (22.2.3) are satisfied, hence d(𝒜)=ℱ, which proves the first identity. Since d(𝒜)=ℱ, we have from Theorem 22.2.2 and (22.2.7) that Δ(𝒜)=δd(𝒜)=δ(ℱ)=𝒥, which proves the second identity. Conversely, suppose d(𝒜)=ℱ and Δ(𝒜)=𝒥. We have from Theorem 16.1.1(c) that d(ℱ)=d²(𝒜)=0, and from (22.2.7) that 𝒥=Δ(𝒜)=δd(𝒜)=δ(ℱ). By Theorem 22.2.2, Maxwell’s equations are satisfied.

## 22.3 Einstein Tensor

Let $(M,\mathfrak{g})$ be a semi-Riemannian manifold, and let $\mathcal{R}$ be the Riemann curvature tensor. The Ricci curvature tensor (field) in $\mathcal{T}_2^0(M)$ is defined by

R = C_{14}(\mathcal{R})

(22.3.1)

the scalar curvature (function) in $C^{\infty}(M)$ is defined by

S = C_{12}(R)

(22.3.2)

and the Einstein tensor (field) in $\mathcal{T}_2^0(M)$ is defined by

G = R - \frac{1}{2} S\mathfrak{g}.

In physics, the terms “Ricci curvature tensor”, “scalar curvature”, and “Einstein tensor” are typically used only when $M$ is a Lorentz 4-manifold, but we will continue with the more general context.

## Theorem 22.3.1 (Local Coordinate Expression for Ricci Curvature).

If $(M,\mathfrak{g})$ is a semi-Riemannian manifold, then, in local coordinates:

(a)

R_{ij} = \sum_{k} R_{kij}^{k}

= \sum_{k} \left( \frac{\partial \Gamma_{ij}^{k}}{\partial x^{k}} - \frac{\partial \Gamma_{jk}^{k}}{\partial x^{i}} \right) + \sum_{kl} (\Gamma_{kl}^{k} \Gamma_{ij}^{l} - \Gamma_{il}^{k} \Gamma_{jk}^{l}).

(22.3.3)

(b) R is symmetric; that is, $R_{ij} = R_{ji}$ for $i,j = 1,\dots,m$.

Proof. A preliminary result is

R_{ij} = C_{14}(\mathcal{R})_{ij} [(22.3.1)]

= C_{1} \circ S_{4}^{1}(\mathcal{R})_{ij} [(19.6.2)]

= \sum_{kl} \mathfrak{g}^{kl} \mathcal{R}_{kijl}. [mv Th 6.3.5(a)]

(22.3.4)

(a): We have

R_{ij} = \sum_{kl} \mathfrak{g}^{kl} \mathcal{R}_{kijl} [(22.3.4)]

= \sum_{kl} \mathfrak{g}^{kl} \left( \sum_{n} \mathfrak{g}_{ln} R_{kij}^{n} \right) [Th 19.8.2(a)]

= \sum_{kn} \left( \sum_{l} \mathfrak{g}^{kl} \mathfrak{g}_{ln} \right) R_{kij}^{n} = \sum_{kn} \delta_{n}^{k} R_{kij}^{n} = \sum_{k} R_{kij}^{k},

which proves the first equality. The second equality follows from Theorem 18.7.2.

(b): Local coordinate versions of the Riemann curvature symmetries in Theorem 19.8.5 yield

\mathcal{R}_{kijl}=\mathcal{R}_{jlki}=\mathcal{R}_{ljik}.

Then

R_{ij}=\sum_{kl}g^{kl}R_{kijl}
=\sum_{kl}g^{lk}R_{ljik}
=R_{ji}.

## Theorem 22.3.2 (Orthonormal Frame Expression for Ricci Curvature).

Let $(M,g)$ be a semi-Riemannian $m$-manifold with signature $(\varepsilon_1,\ldots,\varepsilon_m)$, let $(E_1,\ldots,E_m)$ be an orthonormal frame on an open set $U$ in $M$, and let $X,Y$ be vector fields in $\mathfrak{X}(M)$. Then:

(a)

R(X,Y)=\sum_i \varepsilon_i\mathcal{R}(E_i,X,Y,E_i)

on $U$.

(b) $R$ is symmetric; that is, $R(X,Y)=R(Y,X)$ for all vector fields $X,Y$ in $\mathfrak{X}(M)$.

Proof. (a): This follows from Theorem 19.6.2(a) and (22.3.1).

(b): By Theorem 19.8.5,

\mathcal{R}(E_i,X,Y,E_i)=\mathcal{R}(Y,E_i,E_i,X)=\mathcal{R}(E_i,Y,X,E_i).

The result now follows from part (a).

## Theorem 22.3.3 (Local Coordinate Expression for Scalar Curvature).

If $(M,g)$ is a semi-Riemannian manifold, then, in local coordinates,

S=\sum_{ij}g^{ij}R_{ij}.

Proof. We have from (19.6.3) and (22.3.2) that

S=C_{12}(R)=C^1_\circ S^1_1(R).

The result now follows from the manifold version of Theorem 6.3.5(b).

## Theorem 22.3.4 (Orthonormal Frame Expression for Scalar Curvature).

If $(M,g)$ is a semi-Riemannian manifold with signature $(\varepsilon_1,\ldots,\varepsilon_m)$, and $(E_1,\ldots,E_m)$ is an orthonormal frame on an open set $U$ in $M$, then

S=\sum_i\varepsilon_i\mathcal{R}(E_i,E_i)

on $U$.
