By definition, $J_i(t) = \Pi_{\lambda(t_0)}^{\lambda(t)}(v_i)$ for all $t$ in $(a,b)$. Using Theorem 18.5.6 to apply $(\Pi_{\lambda(t_0)}^{\lambda(t)})^{-1}$ to both sides of (18.5.14) yields

```
$$\Pi_{\lambda(t)}^{\lambda(t_0)}(K(t)) = \sum_i \alpha^i(t) v_i.$$
```

Thus,

```
$$\lim_{t\to t_0}\frac{\Pi_{\lambda(t)}^{\lambda(t_0)}(K(t))-K(t_0)}{t}=\sum_i\left(\lim_{t\to t_0}\frac{\alpha^i(t)-\alpha^i(t_0)}{t}\right)v_i\tag{18.5.16}$$
```

```
$$=\sum_i \frac{d\alpha^i}{dt}(t_0)v_i.$$
```

The result now follows from (18.5.15) and (18.5.16).

# 18.6 Torsion Tensors

Let $(M,\nabla)$ be a smooth manifold with a connection. The torsion tensor (field) corresponding to $\nabla$ is the map

```
$$T : \mathfrak{X}(M) \times \mathfrak{X}(M) \longrightarrow \mathfrak{X}(M)$$
```

defined by

```
$$T(X,Y)=\nabla_X(Y)-\nabla_Y(X)-[X,Y]\tag{18.6.1}$$
```

for all vector fields $X,Y$ in $\mathfrak{X}(M)$. We say that $\nabla$ is symmetric (or torsion-free) if $T=0$; that is,

```
$$\nabla_X(Y)-\nabla_Y(X)=[X,Y]$$
```

for all vector fields $X,Y$ in $\mathfrak{X}(M)$.

Since $T$ takes values in $\mathfrak{X}(M)$, referring to $T$ as a “tensor field”, although usual in the literature, is not consistent with Theorem 15.7.2. We take up this matter in Section 19.5.
