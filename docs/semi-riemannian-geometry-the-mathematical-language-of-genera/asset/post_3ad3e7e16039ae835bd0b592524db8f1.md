
**Proof.** $(\Rightarrow)$: This follows from (3.1.1).  
$(\Leftarrow)$: Straightforward.

Theorem 3.2.2 shows that provided $\mathbf b$ is symmetric, $\mathbf b$ and $q$ determine each other completely.

## Theorem 3.2.3.
Let $V$ be a vector space, let $\mathbf b$ be a bilinear function on $V$, and let $q$ be the corresponding quadratic function. Then the following are equivalent:

- (a) $\mathbf b$ is alternating.  
- (b) $q=0$.  
- (c) $V$ does not have a unit vector.

**Proof.** (a) $\Rightarrow$ (b): Since $\langle v,w\rangle=-\langle w,v\rangle$ for all vectors $v,w$ in $V$, setting $w=v$ gives $q(v)=-q(v)$, hence $q(v)=0$, for all vectors $v$ in $V$.

(b) $\Rightarrow$ (a): This follows from (3.1.1).  
(b) $\Leftrightarrow$ (c): We prove the logical equivalent assertion: $q\ne0$ if and only if $V$ has a unit vector. If $q\ne0$, then there is a (nonzero) vector $v$ in $V$ such that $q(v)\ne0$, hence $v/\sqrt{|q(v)|}$ is a unit vector. The converse is equally straightforward.

We are especially interested in vector spaces on which there is a nonzero symmetric bilinear function. The reason is that such vector spaces have a unit vector, as we now show.

## Theorem 3.2.4.
Let $V$ be a vector space, let $\mathbf b$ be a symmetric bilinear function on $V$, and let $q$ be the corresponding quadratic function. Then:

- (a) $\mathbf b=0$ if and only if $q=0$.  
- (b) If $\mathbf b\ne0$, then $V$ has a unit vector.

**Proof.** (a) $(\Rightarrow)$: Straightforward.  
(a) $(\Leftarrow)$: This follows from Theorem 3.2.2.  
(b): By part (a), $q\ne0$. The result now follows from Theorem 3.2.3.

The light set of a vector space is a rather mysterious entity. The next result provides a characterization when the bilinear function satisfies certain properties.

## Theorem 3.2.5.
If $V$ is a vector space and $\mathbf b$ is a symmetric semidefinite bilinear function on $V$, then

$$\Lambda=V^\perp\setminus\{0\}.$$

**Remark.** The preceding identity is equivalent to saying that for every nonzero vector $v$ in $V$, $\langle v,v\rangle=0$ if and only if $\langle w,w\rangle=0$ for all vectors $w$ in $V$.

**Proof.** Clearly, $V^\perp\setminus\{0\}\subseteq\Lambda$. To prove the reverse inclusion, let $q$ be the quadratic function corresponding to $\mathbf b$, and let $v$ and $w$ be vectors in $\Lambda$ and $V$, respectively. Consider the polynomial $p(t):\mathbb R\to\mathbb R$ defined by

$$p(t)=q(tv+w)=2\langle v,w\rangle t+\langle w,w\rangle.$$

We have $\langle v, w\rangle = 0$; for if not, then $p(t)$ takes both positive and negative values, which contradicts the semidefiniteness of $\mathbf b$. Since $w$ was arbitrary, $v$ is in $V^\perp\setminus\{0\}$. Thus, $\Lambda \subseteq V^\perp\setminus\{0\}$.

The next result is just one of the many versions of the Cauchy–Schwarz inequality that arise in several areas of mathematics. We will see another, likely more familiar, variation in Section 4.6.

## Theorem 3.2.6 (Cauchy–Schwarz Inequality).
If $V$ is a vector space and $\mathbf b$ is a symmetric semidefinite bilinear function on $V$, then

$$\langle v, w\rangle^2 \le \langle v, v\rangle\langle w, w\rangle \tag{3.2.1}$$

for all vectors $v, w$ in $V$.

Proof. The result is trivial if either $v = 0$ or $w = 0$, so suppose $v, w \ne 0$. Let $q$ be the quadratic function corresponding to $\mathbf b$, and consider the polynomial $p(t) : \mathbb R \longrightarrow \mathbb R$ defined by

$p(t) = q(tv + w) = \langle v, v\rangle t^2 + 2\langle v, w\rangle t + \langle w, w\rangle$.

If either $\langle v, v\rangle$ or $\langle w, w\rangle = 0$, that is, if either $v$ or $w$ is in $\Lambda$, then, by Theorem 3.2.5, $\langle v, w\rangle = 0$, so (3.2.1) is satisfied. Now suppose $\langle v, v\rangle, \langle w, w\rangle \ne 0$. According to the quadratic formula, $p(t)$ has the two (not necessarily distinct) roots

$-2\langle v, w\rangle \pm \sqrt{\langle v, w\rangle^2 - \langle v, v\rangle\langle w, w\rangle} / \langle v, v\rangle$.

By assumption, $\mathbf b$ is semidefinite. Suppose $\mathbf b$ is positive semidefinite, in which case $p(t) \ge 0$. If $p(t) > 0$ for all $t$ in $\mathbb R$, then the graph of $p(t)$ versus $t$ does not intersect the $t$-axis. It follows that $p(t)$ has two nonreal complex roots, which is equivalent to $\langle v, w\rangle^2 - \langle v, v\rangle\langle w, w\rangle < 0$. Thus, (3.2.1) is satisfied. If $p(t_0) = 0$ for some $t_0$ in $\mathbb R$, then the graph of $p(t)$ versus $t$ intersects the $t$-axis at the single point $t_0$. It follows that $t_0$ is a repeated root, which is equivalent to $\langle v, w\rangle^2 - \langle v, v\rangle\langle w, w\rangle = 0$. Once again, (3.2.1) is satisfied. This proves the positive semidefinite case. If $\mathbf b$ is negative semidefinite, then $-\mathbf b$ is positive semidefinite, and we again arrive at (3.2.1).

## 3.3 Flat Maps and Sharp Maps

Readers acquainted with tensor analysis, especially in the context of theoretical physics, may have some familiarity with computations involving “lowering” and “raising” indices. This section and Section 4.5 develop these ideas using flat maps and sharp maps.

Let $V$ be a vector space, and let $\mathbf b$ be a bilinear function on $V$. The flat map corresponding to $\mathbf b$ is the linear map

$F : V \longrightarrow V^*$

**Proof.** For a vector $w$ in $V$, Theorem 1.2.1(d) gives $w=\sum_j\theta^j(w)b_j$. Then

$$v^F(w)=\langle v,w\rangle=\left\langle\sum_i a^i h_i,\sum_j\theta^j(w)h_j\right\rangle=\sum_{ij}a^i\theta^j(w)\langle h_i,h_j\rangle$$

$$=\sum_{ij}a^i\theta^j(w)b_{ij}=\left(\sum_{ij}b_{ji}a^i\theta^j\right)(w)$$

$$=\left(\sum_i\left[\sum_j b_{ji}a^j\right]\theta^i\right)(w)=\left(\sum_i a_i\theta^i\right)(w).$$

Since $w$ was arbitrary, $v^F=\sum_i a_i\theta^i$. To prove the succinct version directly:

$$[v^F]_\Theta=[F(v)]_\Theta$$
$$=[F]^\Theta_\mathcal{H}[v]_\mathcal{H}\qquad\text{[Th 2.2.4]}$$
$$=b^T_\mathcal{H}[v]_\mathcal{H}.\qquad\text{[Th 3.3.1(b)]}$$

We see from (3.3.2)–(3.3.4) why taking the flat of $v$ to obtain $v^F$ is classically referred to as **lowering an index** by $\flat$.

Let $V$ be a vector space, and let $\mathfrak b$ be a bilinear function on $V$. Recall from Section 3.1 that $\mathfrak b$ is said to be nondegenerate on $V$ if for all vectors $v$ in $V$, $\langle v,w\rangle=0$ for all vectors $w$ in $V$ implies $v=0$.

## Theorem 3.3.3.
*If $V$ is a vector space and $\mathfrak b$ is a bilinear function on $V$, then the following are equivalent:*

(a) $\mathfrak b$ *is nondegenerate on $V$.*

(b) $V^\perp=\{0\}$.

(c) $F$ *is a linear isomorphism.*

(d) *The rows (hence columns) of $b_\mathcal{H}$ are linearly independent for some (hence every) basis $\mathcal{H}$ for $V$.*

(e) $b_\mathcal{H}$ *is invertible for some (hence every) basis $\mathcal{H}$ for $V$.*

(f) $\det(b_{ij})\ne0$ *for some (hence every) basis $\mathcal{H}$ for $V$.*

**Proof.** (a) $\Leftrightarrow$ (b): Straightforward.

(b) $\Leftrightarrow$ (c): We have

$$V^\perp=\{v\in V:v^F(w)=0\text{ for all }w\in V\}$$
$$=\{v\in V:v^F=0\}=\ker(F).$$

The result now follows from Theorem 1.1.12, Theorem 1.1.14, and Theorem 1.2.1(c).

(c) $\Leftrightarrow$ (d): Let $\dim(V)=m$, and let $\Theta$ be the dual basis corresponding to $\mathcal{H}$. Then

$$\operatorname{rank}(F)=\operatorname{rank}\left([F]^\Theta_\mathcal{H}\right)\qquad\text{[Th 2.3.1, (2.3.1)]}$$
$$=\operatorname{rank}(b^T_\mathcal{H})\qquad\text{[Th 3.3.1(b)]}$$
$$=\operatorname{rank}(b_\mathcal{H}),\qquad\text{[Th 2.3.2]}$$

Proof. (a): For vectors $v$ and $w$ in $V$, we have

$$\mathrm{F}^*(v)(w) = v(\mathrm{F}(w)) \qquad [(1.3.1)]$$
$$= \mathrm{F}(w)(v) \qquad [(1.2.3)]$$
$$= \langle w, v\rangle = \langle v, w\rangle$$
$$= \mathrm{F}(v)(w). \qquad [(1.2.3)]$$

Since $v$ and $w$ were arbitrary, $\mathrm{F}^* = \mathrm{F}$.

(b): The proof is similar to that given for part (a).

## Scalar Product Spaces

## 4.1 Scalar Product Spaces

We now begin the study of a type of vector space that will occupy us, in one way or another, for the rest of the book.

Let $V$ be a vector space, and let $\mathfrak{g}: V \times V \longrightarrow \mathbb{R}$ be a bilinear function. We say that $\mathfrak{g}$ is a scalar product on $V$, and that the pair $(V,\mathfrak{g})$ is a scalar product space, if $\mathfrak{g}$ is symmetric and nondegenerate on $V$. Recall from Section 3.1 that $\mathfrak{g}$ is symmetric on $V$ if $\langle v,w\rangle = \langle w,v\rangle$ for all vectors $v,w$ in $V$; and that $\mathfrak{g}$ is nondegenerate on $V$ if for all vectors $v$ in $V$, $\langle v,w\rangle = 0$ for all vectors $w$ in $V$ implies $v=0$.

Suppose $(V,\mathfrak{g})$ is in fact a scalar product space. It follows from the symmetry of $\mathfrak{g}$ that for all bases $\mathcal{H}$ for $V$, $\mathfrak{g}_{\mathcal{H}}$ is a symmetric matrix. The norm corresponding to $\mathfrak{g}$ is the function

$$\|\cdot\|: V \longrightarrow \mathbb{R}$$

defined by

$$\|v\| = \sqrt{|\langle v,v\rangle|} = \sqrt{|\mathfrak{g}(v)|} \tag{4.1.1}$$

for all vectors $v$ in $V$, where $\mathfrak{g}$ is the quadratic function corresponding to $\mathfrak{g}$. Taking the absolute value in (4.1.1) is necessary because a scalar product can have negative values. We refer to $\|v\|$ as the norm of $v$. Observe that $\|v\|=0$ if and only if $v=0$ or $v$ is lightlike; and $\|v\|=1$ if and only if $v$ is a unit vector. Recall from Theorem 3.3.3 that since $\mathfrak{g}$ is nondegenerate on $V$, the flat map $F$ is a linear isomorphism, so its inverse, the sharp map $S$, exists and is also a linear isomorphism.

**Example 4.1.1 ($\mathbb{R}^m$).** For an integer $0\leq \nu \leq m$, let

$$\mathfrak{g}: \mathbb{R}^m \times \mathbb{R}^m \longrightarrow \mathbb{R}$$
