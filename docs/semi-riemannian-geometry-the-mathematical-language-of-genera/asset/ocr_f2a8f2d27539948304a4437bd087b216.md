The “construction” in the preceding example generalizes to an arbitrary smooth manifold with boundary, as we now show.

# Theorem 17.2.5 (Existence of Outward-Pointing Vector Field). If M is a smooth manifold with boundary, then there is an outward-pointing vector field in 𝔛_M(∂M).

Proof. Only a sketch of the proof is provided. Let 𝔄 = {(U_α, (x_α¹,…,x_α^m)) : α ∈ A} be a smooth atlas for M, and let (∂/∂x_α¹,…,∂/∂x_α^m) be the coordinate frame corresponding to (U_α,(x_α¹,…,x_α^m)). For brevity, let V_α = −(∂/∂x_α^m)|_{∂M∩U_α}. Then V_α is an outward-pointing vector field in 𝔛_M(∂M∩U_α). Let {π_α : α ∈ A} be a partition of unity subordinate to the open cover {∂M ∩ U_α : α ∈ A} of ∂M. It can be shown that there is a smooth extension of π_α V_α to all of ∂M such that the extension, also denoted by π_α V_α, has constant value 0 on ∂M\supp(π_α). It can also be shown that V = Σ_α π_α V_α is a vector field in 𝔛_M(∂M).

We claim that V is outward-pointing. Let p be a point in ∂M, let (U, (x¹,…,x^m)) be a (boundary) chart at p, and let ((∂/∂x¹)|_p,…,(∂/∂x^m)|_p) be the corresponding coordinate basis at p. For each α in A, V_α|_p = Σ_{i=1}^m β_α^i(p) ∂/∂x^i|_p for some real numbers β_α¹(p),…,β_α^m(p), hence V_p = Σ_α π_α(p)V_α|_p = Σ_{i=1}^m (Σ_α π_α(p)β_α^i(p)) ∂/∂x^i|_p.

From the properties of partitions of unity, π_α(p) ≥ 0 for all α, and π_α(p) > 0 for at least one α. Since V_α|_p is outward-pointing, we have β_α^m(p) < 0 for all α. It follows that Σ_α π_α(p)β_α^m(p) < 0, hence V_p is outward-pointing. Since p was arbitrary, V is outward-pointing.

# 17.3 Orientation of Boundaries

Let (M,𝔒) be an oriented smooth m-manifold with boundary, where m ≥ 2. By Theorem 17.2.5, there is an outward-pointing vector field V in 𝔛_M(∂M).
