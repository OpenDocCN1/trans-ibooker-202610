
Let $g(u):[c,d]\to[a,b]$ be a diffeomorphism, and let $c_i=g^{-1}(a_i)$ for $i=1,\ldots,k+1$. According to Theorem 10.2.4(c), $g$ is either strictly increasing or strictly decreasing, so we have either $c=c_1<c_2<\cdots<c_{k+1}=d$ or $c=c_{k+1}<c_k<\cdots<c_1=d$. From (16.8.1), the line integral of $\omega$ over $\lambda\circ g$ is

$$\int_{\lambda\circ g}\omega=\sum_{i=1}^{k}\int_{g^{-1}([a_i,a_{i+1}])}(\lambda\circ g)^*(\omega). \tag{16.8.5}$$

where

$$g^{-1}([a_i,a_{i+1}])=\begin{cases}[c_i,c_{i+1}]&\text{if }g\text{ is strictly increasing},\\[2pt][c_{k+2-i},c_{k+1-i}]&\text{if }g\text{ is strictly decreasing},\end{cases}$$

for $i=1,\ldots,k$. When $\lambda$ is smooth, (16.8.5) simplifies to

$$\int_{\lambda\circ g}\omega=\int_{[c,d]}(\lambda\circ g)^*(\omega). \tag{16.8.6}$$

The next result is the line integral counterpart of Theorem 16.7.1.

## Theorem 16.8.1 (Diffeomorphism Invariance of Line Integral).

Let $M$ be a smooth manifold, let $\omega$ be a covector field in $\mathfrak{X}^*(M)$, let $\lambda(t):[a,b]\to M$ be a piecewise smooth curve, and let $g(u):[c,d]\to[a,b]$ be a diffeomorphism. Then

$$\int_{\lambda\circ g}\omega=\pm\int_{\lambda}\omega,$$

where the positive (negative) sign is chosen if $g$ is strictly increasing (strictly decreasing).

*Proof.* We consider only the case where $\lambda$ is smooth. Then

$$\begin{aligned}\int_{\lambda}\omega&=\int_{[a,b]}\lambda^*(\omega) &&[(16.8.2)]\\ &=\pm\int_{[c,d]}g^*(\lambda^*(\omega)) &&[\text{Th 16.7.1}]\\ &=\pm\int_{[c,d]}(\lambda\circ g)^*(\omega) &&[\text{Th 15.9.2, (15.12.3)}]\\ &=\pm\int_{\lambda\circ g}\omega. &&[(16.8.6)]\end{aligned}$$

Theorem 16.8.1 says that, up to a sign determined by the “direction” of the reparametrizing diffeomorphism, the line integral of $\omega$ is independent of the way $\lambda$ is parametrized.

The next result can be viewed as a generalization of the fundamental theorem of calculus.

## Theorem 16.8.2 (Fundamental Theorem of Line Integrals). Let M be a smooth manifold, let f be a function in C^∞(M), and let λ(t) : [a, b] ⟶ M be a piecewise smooth curve. Then

$$\int_{\lambda} d(f) = f(\lambda(b)) - f(\lambda(a)).$$

Proof. We consider only the case where λ is smooth. Then

$$\int_{\lambda} d(f) = \int_{a}^{b} d(f)_{\lambda(t)} ( d\lambda/dt (t) ) dt \quad [(16.8.4)]$$
$$= \int_{a}^{b} d_{\lambda(t)}(f) ( d\lambda/dt (t) ) dt \quad [(15.4.4)]$$
$$= \int_{a}^{b} d(f \circ \lambda)/dt (t) dt \quad [\text{Th 14.7.4(b)}]$$
$$= f(\lambda(b)) - f(\lambda(a)),$$

where the last equality follows from the fundamental theorem of calculus.

## 16.9 Closed and Exact Covector Fields

Let M be a smooth manifold, and let ω be a covector field in 𝔛*(M). We say that ω is closed if d(ω) = 0, exact if there is a function f in C^∞(M) such that ω = d(f), conservative if ∫_λ ω = 0 for all piecewise smooth curves λ(t) : [a, b] ⟶ M such that λ(a) = λ(b), and path-independent if ∫_μ ω = ∫_ψ ω for all piecewise smooth curves μ(t) : [a, b] ⟶ M and ψ(u) : [c, d] ⟶ M such that μ(a) = ψ(c) and μ(b) = ψ(d). In this section, we explore the various ways in which these properties are related.

## Theorem 16.9.1. Let M be a smooth m-manifold, let ω be a covector field in 𝔛*(M), and, in local coordinates, let

$$\omega = \sum_i \alpha^i d(x^i).$$

Then ω is closed if and only if for every such local coordinate expression,

$$\partial\alpha^i / \partial x^j = \partial\alpha^j / \partial x^i$$

for i, j = 1, …, m.

Proof. Computing as in Example 16.1.6 gives

$$d(\omega) = \sum_{1 \le i < j \le m} ( \partial\alpha^j/\partial x^i - \partial\alpha^i/\partial x^j ) d(x^i) \wedge d(x^j),$$

from which the result follows.

## Theorem 16.9.2. If $M$ is a smooth manifold and $\omega$ is a covector field in $\mathfrak{X}^*(M)$, then the following are equivalent:

- (a) $\omega$ is exact.
- (b) $\omega$ is conservative.
- (c) $\omega$ is path-independent.

Proof. (a) $\Rightarrow$ (b): Let $f$ be a function in $C^\infty(M)$ such that $\omega = d(f)$, and let $\lambda(t): [a,b] \longrightarrow M$ be a piecewise smooth curve such that $\lambda(a)=\lambda(b)$. By Theorem 16.8.2,

$$\displaystyle \int_{\lambda} \omega = \int_{\lambda} d(f) = f(\lambda(b)) - f(\lambda(a)) = 0.$$

(b) $\Rightarrow$ (c): Let $\mu(t): [a,b] \longrightarrow M$ and $\psi(u): [c,d] \longrightarrow M$ be smooth curves such that $\mu(a)=\psi(c)$ and $\mu(b)=\psi(d)$. Without loss of generality, we assume that $[a,b]=[-1,0]$ and $[c,d]=[0,1]$, so that $\mu(-1)=\psi(0)$ and $\mu(0)=\psi(1)$. Define the smooth curve $g(s): [0,1] \longrightarrow [0,1]$ by $g(s)=1-s$, and the piecewise smooth curve $\lambda(s): [-1,1] \longrightarrow M$ by

$$\displaystyle \lambda(s)=\begin{cases}\mu(s) & \text{if } s\in[-1,0] \\ \psi\circ g(s) & \text{if } s\in[0,1].\end{cases}$$

The image of $\lambda$ is a path starting and ending at $\mu(-1)=\psi(0)$, and passing through $\mu(0)=\psi(1)$. We have

$$\displaystyle 0 = \int_{\lambda} \omega = \int_{\mu} \omega + \int_{\psi\circ g} \omega = \int_{\mu} \omega - \int_{\psi} \omega,$$

where the last equality comes from Theorem 16.8.1. The result follows.

(c) $\Rightarrow$ (a): Only a sketch of the proof is provided. The construction to follow can be carried out on each connected component of $M$, so we assume without loss of generality that $M$ is connected. Let $p_0$ be a given point in $M$. Since $M$ is connected, it can be shown that for an arbitrary point $p$ in $M$, there is a piecewise smooth curve $\mu(t): [a,b] \longrightarrow M$ such that $\mu(a)=p_0$ and $\mu(b)=p$. Let

$$\displaystyle f(p)=\int_{\mu} \omega.$$

By assumption, line integrals of $\omega$ are path-independent, so the real number $f(p)$ does not depend on the choice of curve joining $p_0$ and $p$. Thus, the assignment $p\longmapsto f(p)$ defines a function $f: M \longrightarrow \mathbb{R}$. It can be shown that $f$ is smooth.

We claim that $d(f)=\omega$. Let $\lambda_1(t): [a,b] \longrightarrow M$ and $\lambda_2(t): [b,c] \longrightarrow M$ be piecewise smooth curves such that $\lambda_1(a)=p_0$ and $\lambda_1(b)=\lambda_2(b)$. Define a piecewise smooth curve $\lambda(t): [a,c] \longrightarrow M$ by

$$\displaystyle \lambda(t)=\begin{cases}\lambda_1(t) & \text{if } t\in[a,b] \\ \lambda_2(t) & \text{if } t\in[b,c],\end{cases}$$

so that λ(a) = p₀ and λ(b) = λ₂(b). Then

f(λ₂(c)) = ∫_λ ω = ∫_{λ₁} ω + ∫_{λ₂} ω = f(λ₁(b)) + ∫_{λ₂} ω = f(λ₂(b)) + ∫_{λ₂} ω,

hence

∫_{λ₂} ω = f(λ₂(c)) − f(λ₂(b)) = ∫_{λ₂} d(f),

where the last equality follows from Theorem 16.8.2. Thus,

∫_{λ₂} [ω − d(f)] = 0.

It can be shown that since λ₂ was arbitrary, ω − d(f) must be the zero form; that is, ω = d(f).

## Theorem 16.9.3. Let M be a smooth manifold, and let ω be a covector field in 𝔛*(M). If ω is exact, then it is closed.

Proof. This follows from Theorem 16.1.1(c).

In light of Theorem 16.9.3, there are three possibilities for a covector field with respect to being exact or not, and closed or not: (i) exact (hence closed), (ii) closed and not exact, and (iii) not closed (hence not exact). The following examples illustrate each of these cases.

## Example 16.9.4. Let ω be the covector field in 𝔛*(ℝ²) given by

ω_{(r,s)} = s d(r) + r d(s).

Since ω = d(rs), it is exact.

## Example 16.9.5 (Punctured Plane). Let φ be the standard coordinate on [0,2π], and let (r,s) be standard coordinates on ℝ²\{(0,0)}, the punctured plane. Let λ(φ) : [0,2π] ⟶ ℝ²\{(0,0)} be the smooth curve given by λ(φ) = (cos(φ), sin(φ)), and consider the form

ω_{(r,s)} = − s/(r² + s²) d(r) + r/(r² + s²) d(s)

in Λ²(ℝ²\{(0,0)}). Using Theorem 16.9.1, it is easily shown that ω is closed. Setting (U, (xⁱ)) = ([0,2π], (φ)) and (V, (yʲ)) = (ℝ², (r,s)) in a generalization of Theorem 15.11.3 yields

λ*(ω)(φ) = [ (− s/(r² + s²) ∘ λ) ∂(r ∘ λ)/∂φ + ( r/(r² + s²) ∘ λ) ∂(s ∘ λ)/∂φ ] d(φ) = ( − sin(φ)/(cos²(φ)+sin²(φ)) ∂(cos(φ))/∂φ + cos(φ)/(cos²(φ)+sin²(φ)) ∂(sin(φ))/∂φ ) d(φ) = d(φ).

Then (16.8.2) gives

∫_λ ω = ∫_[0,2π] λ*(ω) = ∫_0^{2π} dφ = 2π.

Thus, ω is not conservative. By Theorem 16.9.2, it is not exact.

## Example 16.9.6. Let ω be the covector field in 𝔛*(ℝ²) given by

ω_(r,s) = rs d(r) + rs d(s).

It follows from Theorem 16.9.1 that ω is not closed.

## Theorem 16.9.7. Let M be a smooth manifold, and let ω be a form in Λ^s(U). If ω is exact, then it is closed.
