# **Theorem 2.5.1.** With the above setup, $\operatorname{tr}(A)$ and $\det(A)$ are independent of the choice of basis for $V$.

*Proof.* Let $\mathcal{F}$ be another basis for $V$. By Theorem 2.2.6,

$$[A]_{\mathcal{H}}^{\mathcal{H}}=\left([\operatorname{id}_V]_{\mathcal{H}}^{\mathcal{F}}\right)^{-1}[A]_{\mathcal{F}}^{\mathcal{F}}[\operatorname{id}_V]_{\mathcal{H}}^{\mathcal{F}}.$$

We have from Theorem 2.1.7(c) that

$$\operatorname{tr}\left([A]_{\mathcal{H}}^{\mathcal{H}}\right)=\operatorname{tr}\left([A]_{\mathcal{F}}^{\mathcal{F}}\right),$$

and from Theorem 2.4.5 that

$$\det\left([A]_{\mathcal{H}}^{\mathcal{H}}\right)=\det\left([A]_{\mathcal{F}}^{\mathcal{F}}\right).$$

# **Theorem 2.5.2.** If $V$ is a vector space and $A,B:V\longrightarrow V$ are linear maps, then:

+   (a) $\det(\operatorname{id}_V)=1$.  
+   (b) $\det(A\circ B)=\det(A)\det(B)$.  
+   (c) If $A$ is a linear isomorphism, then $\det(A^{-1})=\det(A)^{-1}$.  
+   (d) $\det(A^*)=\det(A)$.

*Proof.* (a): This follows from Theorem 2.2.3(b) and (2.4.2).

(b): This follows from Theorem 2.2.3(b) and Theorem 2.4.5(a).

(c): This follows from Theorem 2.2.3(b) and Theorem 2.4.5(b).

(d): This follows from Theorem 2.2.7 and Theorem 2.4.5(c).

# **Theorem 2.5.3.** Let $V$ be a vector space, and let $A:V\longrightarrow V$ be a linear map. Then $A$ is a linear isomorphism if and only if $\det(A)\ne 0$.

*Proof.* This follows from Theorem 2.2.3(b) and Theorem 2.4.8.
