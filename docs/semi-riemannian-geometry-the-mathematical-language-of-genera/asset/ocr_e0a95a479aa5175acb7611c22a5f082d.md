# Theorem 19.3.8. Let (M, 𝔤) be a semi-Riemannian manifold, let X be a vector field in 𝔛(M), and let 𝒜 be a tensor field in 𝒯ₛʳ(M). Then

∇ₓ(𝔤 ⊗ 𝒜) = 𝔤 ⊗ ∇ₓ(𝒜).

Proof. We have

∇ₓ(𝔤 ⊗ 𝒜) = ∇ₓ(𝔤) ⊗ 𝒜 + 𝔤 ⊗ ∇ₓ(𝒜) [Th 18.1.3(b)] = 𝔤 ⊗ ∇ₓ(𝒜). [Th 18.4.1, Th 19.3.1]

# 19.4 Flat Maps and Sharp Maps

In this section, we present manifold versions of the flat maps and sharp maps defined in Section 3.3, Section 6.2, and Section 6.3.

Let (M, 𝔤) be a semi-Riemannian manifold. For a given vector field X in 𝔛(M), we define a map

Xᶠ : 𝔛(M) ⟶ C^∞(M)

by

Xᶠ(Y) = ⟨X, Y⟩ (19.4.1)

for all vector fields Y in 𝔛(M).

# Theorem 19.4.1. With the above setup, Xᶠ is a covector field in 𝔛*(M).

Proof. Let Y, Z be vector fields in 𝔛(M), and let f be a function in C^∞(M). Then

Xᶠ(Y + Z) = ⟨X, Y + Z⟩ = ⟨X, Y⟩ + ⟨X, Z⟩ = Xᶠ(Y) + Xᶠ(Z)

and (fX)ᶠ(Y) = ⟨fX, Y⟩ = f⟨X, Y⟩ = f Xᶠ(Y), so Xᶠ is a map in Lin_{C^∞(M)}(𝔛(M), C^∞(M)). The result now follows from Theorem 15.5.3.

The flat map on M is the map

F : 𝔛(M) ⟶ 𝔛*(M)

defined by the assignment

X ↦ Xᶠ

for all vector fields X in 𝔛(M). Thus, as a matter of notation,

F(X) = Xᶠ.
