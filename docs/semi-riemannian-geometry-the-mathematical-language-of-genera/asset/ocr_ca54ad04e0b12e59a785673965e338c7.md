# Theorem 2.4.5. If P and Q are matrices in Matₘ×ₘ, then:

+   (a) det(PQ) = det(P) det(Q).
+   (b) If P is invertible, then det(P⁻¹) = det(P)⁻¹.
+   (c) det(Pᵀ) = det(P).

Proof. (a): Let us define a function Δ : (Matₘ×₁)ᵐ ⟶ ℝ by

Δ(R₁, ..., Rₘ) = det([PR₁ ⋯ PRₘ])

for all matrices R₁, ..., Rₘ in Matₘ×₁. It is easily shown that Δ is a determinant function. We have

det([PQ₍₁₎ ⋯ PQ₍ₘ₎]) = Δ(Q₍₁₎, ..., Q₍ₘ₎)
= Δ(E₁, ..., Eₘ) det([Q₍₁₎ ⋯ Q₍ₘ₎])      [(2.4.1), Th 2.4.3]
= det(P) det(Q).

(b): We have from (2.4.1) and part (a) that

1 = det(Iₘ) = det(PP⁻¹) = det(P) det(P⁻¹),

from which the result follows.

(c): Let Pᵀ = [pⱼⁱ]ᵀ = [qⱼⁱ]. Then

det(Pᵀ) = Σ_{σ∈Sₘ} sgn(σ) q_{σ(1)}¹ ⋯ q_{σ(m)}ᵐ = Σ_{σ∈Sₘ} sgn(σ) p₁^{σ(1)} ⋯ pₘ^{σ(m)}
= det(P),

where the first and last equalities follow from (2.4.1), and the second equality from the observation that q_{σ(i)}ⁱ = pᵢ^{σ(i)} for all permutations σ in Sₘ.

Let P be a matrix in Matₘ×ₘ. The ij-th cofactor of P is defined by

cⱼⁱ = (-1)ⁱ⁺ʲ det(P^{(1,...,î,...,m)}_{(1,...,ĵ,...,m)}),

where ^ indicates that an expression is omitted. Thus, P^{(1,...,î,...,m)}_{(1,...,ĵ,...,m)} is the matrix in Mat₍ₘ₋₁₎×₍ₘ₋₁₎ obtained by deleting the ith row and jth column of P. The adjugate of P is the matrix in Matₘ×ₘ defined by

adj(P) = [cⱼⁱ]ᵀ.

# Theorem 2.4.6 (Column Expansion of Determinant). If P = [pⱼⁱ] is a matrix in Matₘ×ₘ and 1 ≤ j ≤ m, then

det(P) = Σᵢ cⱼⁱ pⱼⁱ,

which is called the expansion of det(P) along the jth column of P.
