The general principle underlying this observation suggests another way of computing the inverse of a permutation. For example, corresponding to $\sigma$, consider the 5-tuple $(4,5,1,3,2)$ representing the second row of (B.2.5). We seek a series of transpositions that reorders $(4,5,1,3,2)$ to $(1,2,3,4,5)$. In light of preceding remarks, their product (in the correct order) gives a cycle decomposition of $\sigma^{-1}$. In an obvious notation, we have

```
$(1\ 5)(4,5,1,3,2)=(4,1,5,3,2)$, then  
$(3\ 5)(4,1,5,3,2)=(4,1,3,5,2)$, then  
$(2\ 5)(4,1,3,5,2)=(4,1,3,2,5)$, then  
$(4\ 1)(4,1,3,2,5)=(1,4,3,2,5)$, then  
$(3\ 4)(1,4,3,2,5)=(1,3,4,2,5)$, then  
$(2\ 4)(1,3,4,2,5)=(1,3,2,4,5)$, then  
$(2\ 3)(1,3,2,4,5)=(1,2,3,4,5)$.
```

Collecting the transpositions together gives

$(2\ 3)(2\ 4)(3\ 4)(4\ 1)(2\ 5)(3\ 5)(1\ 5)=(1\ 3\ 4)(2\ 5)=\sigma^{-1}$.

Let $x_1,\ldots,x_m$ be indeterminates, and consider the multinomial

```
$$\Delta=\prod_{1\le i<j\le m}(x_i-x_j).$$
```

For each $\sigma\in S_m$, let

```
$$\sigma(\Delta)=\prod_{1\le i<j\le m}(x_{\sigma(i)}-x_{\sigma(j)}).$$
```

The **sign** of $\sigma$ is defined by

```
$$\operatorname{sgn}(\sigma)=\frac{\sigma(\Delta)}{\Delta}=\prod_{1\le i<j\le m}\frac{x_{\sigma(i)}-x_{\sigma(j)}}{x_i-x_j}.$$
```

Evidently, $\operatorname{sgn}(\sigma)$ equals $1$ or $-1$.

# **Theorem B.2.2.** If $\sigma,\rho$ are permutations in $S_m$, then:

+   (a) $\operatorname{sgn}(\sigma\rho)=\operatorname{sgn}(\sigma)\operatorname{sgn}(\rho)$.  
+   (b) $\operatorname{sgn}(\sigma)=\operatorname{sgn}(\sigma^{-1})$.  
+   (c) $\operatorname{sgn}(\sigma\rho\sigma^{-1})=\operatorname{sgn}(\rho)$.

*Proof.* (a): Since $\rho(\Delta)=\pm\Delta$, we have

```
$$\frac{(\sigma\rho)(\Delta)}{\rho(\Delta)}=\frac{\sigma(\rho(\Delta))}{\rho(\Delta)}=\frac{\sigma(\pm\Delta)}{\pm\Delta}=\frac{\pm\sigma(\Delta)}{\pm\Delta}=\frac{\sigma(\Delta)}{\Delta}=\operatorname{sgn}(\sigma),$$
```

hence

```
$$\operatorname{sgn}(\sigma\rho)=\frac{(\sigma\rho)(\Delta)}{\Delta}=\frac{(\sigma\rho)(\Delta)}{\rho(\Delta)}\frac{\rho(\Delta)}{\Delta}=\operatorname{sgn}(\sigma)\operatorname{sgn}(\rho).$$
```
