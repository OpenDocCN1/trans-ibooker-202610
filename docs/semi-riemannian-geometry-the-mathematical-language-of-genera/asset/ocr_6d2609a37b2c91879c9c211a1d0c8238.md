Let G and H be groups. A map F : G ⟶ H is said to be a group homomorphism if F(gh) = F(g)F(h) for all g, h in G. We say that F is a group isomorphism, and that G and H are isomorphic, if F is bijective.

# B.2 Permutation Groups

Let m be a positive integer, and let Sₘ be the set of bijective functions on {1,2,…,m}. In the present context, each element of Sₘ is referred to as a permutation. We make Sₘ into a group, called the symmetric group on {1,2,…,m}, by defining group multiplication to be composition of functions. The identity element of Sₘ is denoted by id. Let σ and ρ be permutations in Sₘ. For brevity, we denote σ ∘ ρ by σρ, and σ⋯σ [k copies] by σᵏ. Each permutation in Sₘ can be displayed as follows:

```
σ = ( 1   2   …   m−1   m )
      (σ(1) σ(2) … σ(m−1) σ(m))
```

This makes it clear that card(Sₘ) = m!
