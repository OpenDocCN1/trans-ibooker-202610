# Theorem 17.2.2.

Let M be a smooth manifold with boundary, and let p be a boundary point in M. Then T_p(M) is the disjoint union of the set of inward-pointing tangent vectors at p, the set of outward-pointing tangent vectors at p, and T_p(∂M).

See Figure 17.2.1, where v₁ is inward-pointing, v₂ is outward pointing, and v₃ is in T_p(∂M).

# Figure 17.2.1. Inward-pointing and outward-pointing tangent vectors

Recall from Section 15.1 that 𝔛_M(∂M) is the set of smooth vector fields along ∂M. Let V be a vector field in 𝔛_M(∂M). By definition, V_p is in T_p(M) for all p in ∂M. We say that V is inward-pointing (outward-pointing) if V_p is inward-pointing (outward-pointing) for all p in ∂M. Suppose V is in fact either inward-pointing or outward-pointing. According to the definition given in Section 15.1, V is nowhere-tangent to ∂M; or equivalently, V_p is in T_p(M) \ T_p(∂M) for all p in ∂M.

# Example 17.2.3 (ℍ²).

Let (r, s) be standard coordinates on ℍ², and let (∂/∂r, ∂/∂s) be the corresponding standard coordinate frame. From Example 15.1.6, we have the identification (∂/∂r, ∂/∂s) = (e₁, e₂). It follows that ∂/∂s and −∂/∂s are inward-pointing and outward-pointing vector fields in 𝔛_ℍ²(∂ℍ²), respectively.

# Example 17.2.4 (Hemisphere).

Let (x, y, z) be standard coordinates on ℝ³, and let (∂/∂x, ∂/∂y, ∂/∂z) be the corresponding standard coordinate frame. According to Example 15.1.6, we have the identification (∂/∂x, ∂/∂y, ∂/∂z) = (e₁, e₂, e₃). Consider the hemisphere-shaped smooth 2-manifold with boundary

𝒮² ∩ ℍ³ = {(x, y, z) ∈ ℝ³ : x² + y² + z² = 1, z ≥ 0},

where the boundary

∂(𝒮² ∩ ℍ³) = {(x, y, z) ∈ ℝ³ : x² + y² = 1, z = 0}
