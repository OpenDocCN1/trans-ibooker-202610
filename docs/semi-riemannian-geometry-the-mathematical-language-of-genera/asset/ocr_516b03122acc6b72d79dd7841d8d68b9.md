Thus, $d \circ i_X + i_X \circ d$ is a form derivation on $M$. By Theorem 16.4.3, the same is true of $\mathcal{L}_X$.

Let $f$ be a function in $C^\infty(M)$. Then

```
(d \circ i_X + i_X \circ d)(f) = d(i_X(f)) + i_X(d(f)) = X(f) [(16.5.2), (16.5.3)] = \mathcal{L}_X(f) [(16.4.1)]
```

and

```
(d \circ i_X + i_X \circ d)(d(f)) = d(i_X(d(f))) + i_X(d^2(f)) = d(X(f)) [Th 16.1.1(c), (16.5.2)] = d(\mathcal{L}_X(f)) [(16.4.1)] = \mathcal{L}_X(d(f)). [Th 16.4.6]
```

Since $f$ was arbitrary, $d \circ i_X + i_X \circ d$ and $\mathcal{L}_X$ agree on $C^\infty(M)$ and $\{d(f) : f \in C^\infty(M)\}$. The result now follows from Theorem 16.3.2.

The next result is a generalization of Theorem 16.4.6.

# Theorem 16.5.4 (Commutativity of Lie Derivative and Exterior Derivative of Forms). If $M$ is a smooth manifold and $X$ is a vector field in $\mathfrak{X}(M)$, then

```
\mathcal{L}_X \circ d = d \circ \mathcal{L}_X;
```

that is,

```
\mathcal{L}_X(d(\omega)) = d(\mathcal{L}_X(\omega))
```

for all forms $\omega$ in $\Lambda^s(M)$.

Proof. It follows from Theorem 16.1.1(c) and Theorem 16.5.3 that

```
\mathcal{L}_X \circ d = (d \circ i_X + i_X \circ d) \circ d = d \circ i_X \circ d + i_X \circ d^2 = d \circ i_X \circ d
```

and

```
d \circ \mathcal{L}_X = d \circ (d \circ i_X + i_X \circ d) = d^2 \circ i_X + d \circ i_X \circ d = d \circ i_X \circ d.
```

The result follows.
