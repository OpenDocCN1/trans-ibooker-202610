# ## Theorem 19.5.2.

If $(M,\mathsf g)$ is a semi-Riemannian manifold, then $\mathfrak X_s$ is a $C^\infty(M)$-module isomorphism:

$$\operatorname{Mult}_{C^\infty(M)}(\mathfrak X(M)^s,\mathfrak X(M))\cong \operatorname{Mult}_{C^\infty(M)}(\mathfrak X^*(M)\times\mathfrak X(M)^s,C^\infty(M)).$$

**Proof.** Recall the characterization map $\mathcal C_s^r$ defined in Section 15.7. Let us define the “sharp” map

$$\mathfrak P_1^1:\operatorname{Mult}_{C^\infty(M)}(\mathfrak X(M)^{s+1},C^\infty(M))\longrightarrow \operatorname{Mult}_{C^\infty(M)}(\mathfrak X^*(M)\times\mathfrak X(M)^s,C^\infty(M))$$

by

$$\mathfrak P_1^1=\mathcal C_s^1\circ S_1^1\circ(\mathcal C_{s+1}^0)^{-1}.\tag{19.5.3}$$

By Theorem 15.7.2 and Theorem 19.4.3, we have that $\mathcal C_s^1$, $\mathcal C_{s+1}^0$, and $S_1^1$ are $C^\infty(M)$-module isomorphisms, and therefore, so is $\mathfrak P_1^1$.

We claim that

$$\mathfrak X_s=\mathfrak P_1^1\circ\mathcal C_s,\tag{19.5.4}$$

which is the manifold version of Theorem 6.4.1(d). Once this established, the result follows from Theorem 19.5.1. Let $\Upsilon$ be a map in $\operatorname{Mult}_{C^\infty(M)}(\mathfrak X(M)^{s+1},C^\infty(M))$. Making the identifications inherent in Theorem 15.7.2, it can be shown that

$$\mathfrak P_1^1(\Upsilon)(\omega,X_1,\ldots,X_s)=\Upsilon(\omega^\flat,X_1,\ldots,X_s)$$

for all covector fields $\omega$ in $\mathfrak X^*(M)$ and all vector fields $X_1,\ldots,X_s$ in $\mathfrak X(M)$. For a map $\Psi$ in $\operatorname{Mult}_{C^\infty(M)}(\mathfrak X(M)^s,\mathfrak X(M))$, we have

$$\begin{aligned}\mathfrak X_s(\Psi)(\omega,X_1,\ldots,X_s)&=\omega(\Psi(X_1,\ldots,X_s))=(\omega^\flat)\mathsf F(\Psi(X_1,\ldots,X_s))\\&=\langle\omega^\flat,\Psi(X_1,\ldots,X_s)\rangle=\mathcal S_s(\Psi)(\omega^\flat,X_1,\ldots,X_s)\\&=\mathfrak P_1^1\circ\mathcal S_s(\Psi)(\omega,X_1,\ldots,X_s).\end{aligned}$$

Since $\Psi,\omega$, and $X_1,\ldots,X_s$ were arbitrary, this proves the claim. ◻

With the above setup, Figure 19.5.1 is a commutative diagram of $C^\infty(M)$-module isomorphisms. That is, any two $C^\infty(M)$-modules are connected by the $C^\infty(M)$-module isomorphism formed by taking the composite of intervening $C^\infty(M)$-module isomorphisms.

**Proof.** It follows from (19.5.3) and (19.5.4) that $\mathfrak X_s=\mathcal C_s^1\circ S_1^1\circ(\mathcal C_{s+1}^0)^{-1}\circ\mathcal C_s$. ◻

# ## Theorem 19.5.4 (Representation of Covariant Tensor Fields).

If $(M,\mathsf g)$ is a semi-Riemannian manifold, then

$$\mathcal T^0_{s+1}(M)\cong\operatorname{Mult}_{C^\infty(M)}(\mathfrak X(M)^s,\mathfrak X(M))\cong\mathcal T^1_s(M).$$

**Proof.** This is the manifold version of Theorem 6.4.2 and follows from Theorem 19.5.3. ◻
