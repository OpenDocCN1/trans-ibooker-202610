Let us now turn our attention to a special class of regular surfaces in $\mathbb{R}^3_\nu$. Recall from Section 3.1 that the quadratic function $q$ corresponding to $\mathbb{R}^3_\nu$ is given by $q(\cdot)=\langle\cdot,\cdot\rangle$. We consider three level sets of $q$, the first of which we have seen previously. For $\nu=0$, the **unit sphere** is

$$S^2=\{p\in\mathbb{R}^3_0:q(p)=1\}=q^{-1}(1). \tag{12.2.6}$$

For $\nu=1$, we define the **pseudosphere** by

$$P^2=\{p\in\mathbb{R}^3_1:q(p)=1\}=q^{-1}(1), \tag{12.2.7}$$

and **hyperbolic space** by

$$H^2=\{p\in\mathbb{R}^3_1:q(p)=-1\}=q^{-1}(-1). \tag{12.2.8}$$

Thus, $S^2$ is the set of (spacelike) unit vectors in $\mathbb{R}^3_0$, $P^2$ is the set of spacelike unit vectors in $\mathbb{R}^3_1$, and $H^2$ is the set of timelike unit vectors in $\mathbb{R}^3_1$. Taken together, $S^2$, $P^2$, and $H^2$ are called the **hyperquadrics** in $\mathbb{R}^3_\nu$ and are denoted collectively by $Q^2$. We have the following table:

| $Q^2$ | $\nu$ | Type of vectors |
|---|---|---:|---|
| $S^2$ | 0 | spacelike |
| $P^2$ | 1 | spacelike |
| $H^2$ | 1 | timelike |

V_p = 2p, (12.2.10)

so

⟨V_p, V_p⟩ = 4⟨p, p⟩ = 4 q(p). (12.2.11)

## 12.3 Induced Euclidean Derivative in ℝ³ᵥ

Let M be a regular surface, and let X be a vector field in 𝔛(M). The induced Euclidean derivative with respect to X consists of two maps, both denoted by D_X. The first is

```
D_X : C^∞(M) ⟶ C^∞(M)
```

defined by

```
D_X(f)(p) = d_p(f)(X_p)   (12.3.1)
```

for all functions f in C^∞(M) and all p in M. The second is

```
D_X : 𝔛_ℝ³(M) ⟶ 𝔛_ℝ³(M)
```

defined by

```
D_X(V)_p = d_p(V)(X_p)   (12.3.2)
```

for all vector fields $V$ in $\mathfrak{X}_{\mathbb{R}^3_\nu}(M)$ and all $p$ in $M$. (It will be clear from the context when the notation $D_X$ denotes the induced Euclidean derivative with respect to $X$ as opposed to the Euclidean derivative with respect to $X$ discussed in Section 10.3.)

We have from (11.5.1) and (11.7.1) that $D_X(f)(p)$ and $D_X(V)_p$ can be expressed as

$$D_X(f)(p)=\frac{d(f\circ\lambda)}{dt}(t_0)$$  (12.3.3)

and

$$D_X(V)_p=\frac{d(V\circ\lambda)}{dt}(t_0),$$  (12.3.4)

where $\lambda(t):(a,b)\longrightarrow M$ is any smooth curve such that $\lambda(t_0)=p$ and $(d\lambda/dt)(t_0)=X_p$. Let $V=(\alpha^1,\alpha^2,\alpha^3)$. It follows from Theorem 11.7.2 and (12.3.2) that $D_X(V)_p$ can also be expressed as

$$D_X(V)_p=\bigl(d_p(\alpha^1)(X_p),d_p(\alpha^2)(X_p),d_p(\alpha^3)(X_p)\bigr).$$  (12.3.5)

Following (12.2.2), for vector fields $V,W$ in $\mathfrak{X}_{\mathbb{R}^3_\nu}(M)$, we define a function

$$\langle V,W\rangle:M\longrightarrow\mathbb{R}$$

in $C^\infty(M)$ by the assignment

$$p\longmapsto\langle V_p,W_p\rangle$$

for all $p$ in $M$.

The next result is a counterpart of Theorem 10.3.1.

## **Theorem 12.3.1.**

+   (a) $D_{X+Y}(V)=D_X(V)+D_Y(V)$.
+   
+   (b) $D_{fX}(V)=fD_X(V)$.
+   
+   (c) $D_X(V+W)=D_X(V)+D_X(W)$.

+   (d) $D_X(fV)=D_X(f)V+fD_X(V)$.
