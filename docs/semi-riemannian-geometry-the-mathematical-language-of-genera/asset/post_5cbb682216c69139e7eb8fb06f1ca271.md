## Example 11.2.13 (Stereographic Projection).

Consider the set Σ² = 𝒮²\{(0,0,1)}, which is the unit sphere with the “north pole” removed. We define a map σ : Σ² ⟶ ℝ², called stereographic projection, as follows. For

each $(x,y,z)$ in $\Sigma^2$, let $\sigma(x,y,z) = (r,s)$ be the point where the straight line through $(0,0,1)$ and $(x,y,z)$ intersects the $xy$-plane, where we identify the latter with $\mathbb{R}^2$. See Figure 11.2.5. Then

$(x,y,z) - (0,0,1) = c[(r,s,0) - (0,0,1)]$

for some real number $c$, hence $x = cr$, $y = cs$, and $z = 1 - c$. This gives

$1 = x^2 + y^2 + z^2 = c^2 r^2 + c^2 s^2 + (1 - c)^2$,

so

$c = 1 - z = \frac{2}{r^2 + s^2 + 1}.$

Thus,

$\sigma(x,y,z) = (r,s) = \frac{1}{1 - z}(x,y)$ \hfill (11.2.2)

for all $(x,y,z)$ in $\Sigma^2$. It is evident from Figure 11.2.5 that $\sigma$ is bijective. Let $\varphi = \sigma^{-1}$. Then $\varphi(\mathbb{R}^2) = \Sigma^2$ and

$\varphi(r,s) = (x,y,z) = \frac{1}{r^2 + s^2 + 1}(2r, 2s, r^2 + s^2 - 1)$ \hfill (11.2.3)

for all $(r,s)$ in $\mathbb{R}^2$.

We claim that $(\mathbb{R}^2, \varphi)$ is a chart on $\mathcal{S}^2$. It is easily shown that $\varphi : \mathbb{R}^2 \longrightarrow \mathbb{R}^3$ is a parametrized surface. We need to prove that:

- [C1] $\varphi : \mathbb{R}^2 \longrightarrow \mathbb{R}^3$ is an immersion.
- [C2] $\Sigma^2$ is an open set in $\mathcal{S}^2$.
- [C3] $\varphi : \mathbb{R}^2 \longrightarrow \Sigma^2$ is a homeomorphism.

The proofs are as follows:

[C1]: The Jacobian matrix is

$J_{\varphi}(r,s) = \frac{2}{(r^2 + s^2 + 1)^2} \begin{bmatrix} -r^2 + s^2 + 1 & -2rs \\ -2rs & r^2 - s^2 + 1 \\ 2r & 2s \end{bmatrix}$,

and the corresponding vector product is

$\frac{4}{(r^2 + s^2 + 1)^4}(-r^2 + s^2 + 1, -2rs, 2r) \times (-2rs, r^2 - s^2 + 1, 2s)$

$= \frac{4}{(r^2 + s^2 + 1)^4}(-2r(r^2 + s^2 + 1), -2s(r^2 + s^2 + 1), -(r^2 + s^2)^2 + 1)$,

which never equals $(0,0,0)$. By Theorem 11.2.2, $\varphi$ is an immersion.

[C2]: Since $\mathbb{R}^3 \setminus \{(0,0,1)\}$ is open in $\mathbb{R}^3$, it follows that $\Sigma^2 = \mathcal{S}^2 \cap [\mathbb{R}^3 \setminus \{(0,0,1)\}]$ is open in $\mathcal{S}^2$.

[C3]: We observed above that $\varphi$ is bijective, and it is clear from the form of (11.2.2) and (11.2.3) that $\varphi$ and $\varphi^{-1}$ are continuous.

This proves the claim.

## 11.3 Tangent Planes in ℝ³

Having defined a regular surface and established some of its basic properties, we are now in a position to present a rigorous definition of “tangent plane”.

Let M be a regular surface. A curve (on M) is a curve λ(t) : I ⟶ M as defined in Section 11.1, with the additional feature that it takes values in M. Let p be a point in M. We say that a vector v in ℝ³ is a tangent vector to M at p if there is a smooth curve λ(t) : (a, b) ⟶ M such that λ(t₀) = p and (dλ/dt)(t₀) = v for some t₀ in (a, b). The tangent plane of M at p is denoted by Tₚ(M) and defined to be the set of all such tangent vectors:

```
Tₚ(M) = { dλ/dt (t₀) : λ(t) : (a, b) ⟶ M is smooth, λ(t₀) = p, t₀ ∈ (a, b) }.
```
