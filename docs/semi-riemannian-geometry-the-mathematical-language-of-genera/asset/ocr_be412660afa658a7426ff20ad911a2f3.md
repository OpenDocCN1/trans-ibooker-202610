for i = 1, ..., m, where the α^{ij} are uniquely determined functions in C^∞(U). Then

```
⟨[X, E_i], E_i⟩ = Σ_j ⟨E_i, E_j⟩ α^{ij} = ε_i α^{ii},
```

where (ε_1, ..., ε_m) is the signature of M. It follows from Theorem 20.4.2 that

```
Div(X)|_U = - Σ_i α^{ii}.
```

Then

```
f = f Ω_M|_U (E_1, ..., E_m) [Th 19.10.1]
= L_X (Ω_M|_U)(E_1, ..., E_m)
= X (Ω_M|_U (E_1, ..., E_m))
- Σ_i Ω_M|_U (E_1, ..., E_{i-1}, [X, E_i], E_{i+1}, ..., E_m) [Th 16.4.4]
= - Σ_i Ω_M|_U (E_1, ..., E_{i-1}, [X, E_i], E_{i+1}, ..., E_m) [Th 19.10.1]
= - Σ_{ij} α^{ij} Ω_M|_U (E_1, ..., E_{i-1}, E_j, E_{i+1}, ..., E_m) [(20.4.3)]
= - Σ_i α^{ii} Ω_M|_U (E_1, ..., E_{i-1}, E_i, E_{i+1}, ..., E_m) [mv Th 7.1.2]
= - Σ_i α^{ii}. [Th 19.10.1]
```

Thus, Div(X)|_U = f. Since p was arbitrary, the first equality follows. For the second equality, we have

```
Div(X) Ω_M = L_X (Ω_M) [first equality]
= d ∘ i_X (Ω_M) + i_X ∘ d(Ω_M) [Th 16.5.3]
= d ∘ i_X (Ω_M). [mv Th 7.2.12(b)]
```

(b): Since X^♭ is a covector field in 𝔛^*(M) = Λ^1(M), we have from (20.2.1) that δ = (-1)^{ν+1} ⋆ d ⋆, where ν is the index of M. Then

```
Div(X) = Div(X) ⋆ (Ω_M) [Th 20.1.1(b)]
= ⋆ (Div(X) Ω_M)
= ⋆ d(i_X (Ω_M)) [part (a)]
= (-1)^ν ⋆ d ⋆ (X^♭) [Th 20.1.2]
= -δ(X^♭).
```

# Theorem 20.4.4. Let (M, 𝔤, 𝔒) be an oriented semi-Riemannian manifold, let f be a function in C^∞(M), and let X be a vector field in 𝔛(M). Then

```
Div(f X) = f Div(X) + ⟨Grad(f), X⟩.
```
