

## 13.8 环面在 ℝ₀³ 中

对于实数 R > 1，集合

Tor = { (x, y, z) ∈ ℝ³ : (√(x² + y²) − R)² + z² = 1, x² + y² ≥ 0 }

是通过绕 z 轴旋转 xz 平面中以 (R, 0, 0) 为中心、半径为 1 的圆得到的环面。见图 13.8.1。

![](img/d712710a8eb78c0959204afd5dde4c91_344_0.png)

图 13.8.1. Tor

在定理 11.4.3 的记号下，令

ρ(θ) = cos(θ) + R
h(θ) = sin(θ)
φ(θ, φ) = ([cos(θ) + R] cos(φ), [cos(θ) + R] sin(φ), sin(θ))
U = (−π/2, π/2) × (−π, π).

h 的定义域被选为 (−π/2, π/2) 而不是例如 (0, 2π)，以确保第 11.4 节中性质 [R2] 得到满足。这参数化了环面的“外”一半；环面的“内”一半由单独的参数化给出。根据定理 11.4.3 可知 Tor 是一个正则曲面且 (U, φ) 是一个图。将 Tor 视为 ℝ₀³ 中的正则曲面，定理 12.10.3 给出：

H₁ = (−sin(θ) cos(φ), −sin(θ) sin(φ), cos(θ))
H₂ = (−[cos(θ) + R] sin(φ), [cos(θ) + R] cos(φ), 0)

$\mathcal{N}\circ\varphi=-(\cos(\theta)\cos(\phi),\cos(\theta)\sin(\phi),\sin(\theta))$

$g_H=\begin{bmatrix}1&0\\0&[\cos(\theta)+R]^2\end{bmatrix}$

$h_H=\begin{bmatrix}1&0\\0&[\cos(\theta)+R]\cos(\theta)\end{bmatrix}$

$K\circ\varphi=\dfrac{\cos(\theta)}{\cos(\theta)+R}$

$\Gamma^1_{11}=0\qquad \Gamma^1_{12}=\Gamma^1_{21}=0\qquad \Gamma^1_{22}=[\cos(\theta)+R]\sin(\theta)$

$\Gamma^2_{11}=0\qquad \Gamma^2_{12}=\Gamma^2_{21}=-\dfrac{\sin(\theta)}{\cos(\theta)+R}\qquad \Gamma^2_{22}=0$

$\kappa_1\circ\varphi=1\qquad \kappa_2\circ\varphi=\dfrac{\cos(\theta)}{\cos(\theta)+R}$.

如图 13.8.1 所示，高斯曲率在 Tor 的不同点上取正值、负值和零值。

## 13.9 伪球面在 $\mathbb{R}^3_1$

集合

$\mathcal{P}^2=\{(x,y,z)\in\mathbb{R}^3:x^2+y^2-z^2=1,\ z>0\}$

是第 13.6 节中描述的单叶双曲面 的同一上半部分，和之前一样，它是一个正则曲面。由于

$\left(\dfrac{\partial f}{\partial x}(x,y)\right)^2+\left(\dfrac{\partial f}{\partial y}(x,y)\right)^2-1=\dfrac{1}{x^2+y^2+1},$

定理 12.2.8 的条件得到满足。因此，$\mathcal{P}^2$ 是 $\mathbb{R}^3_1$ 中的正则曲面。或者，这直接来自定理 12.2.12(a)。定理 12.10.2 给出：

$H_1=\left(1,0,\dfrac{x}{\sqrt{x^2+y^2-1}}\right)\qquad H_2=\left(0,1,\dfrac{y}{\sqrt{x^2+y^2-1}}\right)$

$\mathcal{N}\circ\varphi=(-x,-y,-\sqrt{x^2+y^2-1})=-\varphi$

$g_H=h_H=\dfrac{1}{x^2+y^2-1}\begin{bmatrix}y^2-1&-xy\\-xy&x^2-1\end{bmatrix}$

$K\circ\varphi=1$

$\epsilon_{\mathcal{P}^2}=1.$

我们注意到 $\epsilon_{\mathcal{P}^2}=1$ 与定理 12.2.12(d) 一致。在 $\mathbb{R}^3_1$ 的背景下，我们称 $\mathcal{P}^2$ 为伪球面。

## 13.10 双曲空间在 ℝ³₁ 中

集合

```
ℋ² = {(x, y, z) ∈ ℝ³ : x² + y² − z² = −1, z > 0}
```

是第 13.7 节中描述的双叶双曲面的同一上片，和之前一样，它是一个正则曲面。由于

```
⎛∂f/∂x(x,y)⎞² + ⎛∂f/∂y(x,y)⎞² − 1 = − 1/(x² + y² − 1)
```

并且根据定义，x² + y² > 1，定理 12.2.8 的条件得到满足。因此，ℋ² 是 ℝ³₁ 中的正则曲面。或者，这直接来自定理 12.2.12(a)。定理 12.10.2 给出：

```
H₁ = (1, 0, x/√(x² + y² + 1))    H₂ = (0, 1, y/√(x² + y² + 1))
```

```
𝒩 ∘ φ = (x, y, √(x² + y² + 1)) = φ
```

```
𝔤_ℋ = 1/(x² + y² + 1) [ y² + 1  −xy ; −xy  x² + 1 ]
```

```
𝔥_ℋ = −𝔤_ℋ
```

```
𝒦 ∘ φ = −1
```

```
ε_ℋ² = −1.
```

我们注意到 ε_ℋ² = −1 与定理 12.2.12(d) 一致。在 ℝ³₁ 的背景下，我们称 ℋ² 为双曲空间。

```

```


## 第三部分

## 光滑流形和
半黎曼流形

在第二部分中，我们涵盖了曲线和曲面的诸多主题。尽管数学有时具有抽象性，但由于我们处理的是位于三维空间中的一维和二维几何对象，使得这一工作相对具体。第二部分中对维度的限制反映了曲线和曲面研究的经典性质。只需付出相对较少的努力，就有可能将结果推广到 m 维空间中 m−1 维的“曲面”。然而，这并不能解决这种方法的一个重要固有局限——需要一个环境空间。也许半黎曼几何最重要的应用，也是历史上推动这一数学领域发展的动机之一，是爱因斯坦的广义相对论。根据这一宇宙学构造，我们所居住的宇宙恰好有四个维度；我们的宇宙并不存在于一个五维环境空间中。当然，数学上可以构造一个，但那不会反映物理现实。为了建模广义相对论，我们需要一种“曲面”的数学描述，它完全摆脱了环境空间。

让我们考虑 R³ 在我们对曲面的讨论中出现（以及未出现）的地方，以期看是否可以规避环境空间的作用。回想一下，最初曲面被定义为一个拓扑空间，这并不依赖于环境空间。然而，在此之后我们很快就会遇到障碍。任何依赖于切向量的概念，尤其是法向量，似乎都与环境空间不可分割。我们把 Christoffel 符号、协变导数甚至高斯曲率视为“内在”量，但它们的初始表述依赖于环境空间。看起来作为第一步，我们需要找到一种在不诉诸这种外部性的情况下定义“切向量”的方法。一旦完成，我们就可以继续讨论“切空间”、“微分映射”以及微分几何的其他基本概念。这就是第 14–17 章的目标。

R³ 的一个“问题”在于其数学结构的丰富性。如前所述，R³ 可以被视为内积空间、洛伦兹向量空间、拓扑空间、度量空间等等。在我们对曲线和曲面的研究中，这迫使我们在讨论的每个阶段澄清对 R³ 的假设。我们即将开始发展一种基于我们对曲线和曲面所知、但在许多方面是全新的数学理论。这给了我们一个机会，在每个环节只假设本质的东西，这种方法极具启发性。因此，我们推迟到第 18 章才引入“联络”的概念，而“度量”的概念则推迟到第 19 和 20 章。第 21 章使用我们可用的新语言呈现了向量分析的一些经典结果，第 22 章以与狭义相对论和广义相对论密切相关的物理学领域的应用作为结尾。

## 第 14 章

## 光滑流形

### 14.1 光滑流形

本章及后续章节中提出的许多定义都是我们在研究曲线和曲面时所遇到的定义的改编。

设 $M$ 为拓扑空间。$M$ 上的一个 **图** 是一个对 $(U,\varphi)$，其中 $U$ 是 $M$ 中的开集且 $\varphi: U \longrightarrow \mathbb{R}^m$ 是一个映射，使得：

- [C1] $\varphi(U)$ 是 $\mathbb{R}^m$ 中的开集。
- [C2] $\varphi: U \longrightarrow \varphi(U)$ 是一个同胚。

我们称 $U$ 为该图的 **坐标域**，称 $\varphi$ 为其 **坐标映射**，称 $m$ 为该图的 **维数**。对于 $U$ 中的每一点 $p$，我们说 $(U,\varphi)$ 是 $p$ 处的 **图**。（注意在正则曲面的定义中，坐标映射是从 $\mathbb{R}^2$ 中的开集到正则曲面中的开集，而现在方向相反。）当 $U=M$ 时，我们说 $(M,\varphi)$ 是 $M$ 上的一个 **覆盖图**，并且 $M$ 被 $(M,\varphi)$ 覆盖。在当前背景下，$\varphi$ 的分量函数记为 $\varphi=(x^1,\ldots,x^m)$ 而不是 $\varphi=(\varphi^1,\ldots,\varphi^m)$，并且被称为 $U$ 上的 **局部坐标**。这种记号的选择专门用于鼓励将点 $p$ 在 $M$ 中与它的局部坐标对应物 $\varphi(p)=(x^1(p),\ldots,x^m(p))$ 在 $\mathbb{R}^m$ 中进行非正式的识别。我们经常用

$(U,\varphi) \quad\text{by}\quad (U,(x^i)) \quad\text{or}\quad (U,\varphi=(x^i)),$

其中 $(x^i)=(x^1,\ldots,x^m)$。$M$ 上的图 $(U,\varphi)$ 和 $(\widetilde{U},\widetilde{\varphi})$ 被称为 **重叠** 如果 $U\cap\widetilde{U}$ 非空。在这种情况下，映射

$\widetilde{\varphi}\circ\varphi^{-1}\big|_{\varphi(U\cap\widetilde{U})}:\varphi(U\cap\widetilde{U})\longrightarrow\widetilde{\varphi}(U\cap\widetilde{U})$
