= C( ∑_{j=1}^s Y_1 ⊗ ⋯ ⊗ D_0^1(Y_j) ⊗ ⋯ ⊗ Y_s ⊗ A ⊗ ω^1 ⊗ ⋯ ⊗ ω^r + Y_1 ⊗ ⋯ ⊗ Y_s ⊗ D_s^r(A) ⊗ ω^1 ⊗ ⋯ ⊗ ω^r + ∑_{i=1}^r Y_1 ⊗ ⋯ ⊗ Y_s ⊗ A ⊗ ω^1 ⊗ ⋯ ⊗ D_1^0(ω^i) ⊗ ⋯⋯ ⊗ ω^r ) = ∑_{j=1}^s C(Y_1 ⊗ ⋯ ⊗ D_0^1(Y_j) ⊗ ⋯ ⊗ Y_s ⊗ A ⊗ ω^1 ⊗ ⋯ ⊗ ω^r) + C(Y_1 ⊗ ⋯ ⊗ Y_s ⊗ D_s^r(A) ⊗ ω^1 ⊗ ⋯ ⊗ ω^r) + ∑_{i=1}^r C(Y_1 ⊗ ⋯ ⊗ Y_s ⊗ A ⊗ ω^1 ⊗ ⋯ ⊗ D_1^0(ω^i) ⊗ ⋯⋯ ⊗ ω^r) = ∑_{j=1}^s A(ω^1, …, ω^r, Y_1, …, Y_{j-1}, D_0^1(Y_j), Y_{j+1}, …, Y_s) + D_s^r(A)(ω^1, …, ω^r, Y_1, …, Y_s) + ∑_{i=1}^r A(ω^1, …, ω^{i-1}, D_1^0(ω^i), ω^{i+1}, …, ω^r, Y_1, …, Y_s),

where the second and sixth equalities follow from Theorem 15.14.4, and the third equality from [D2]. The result follows.

# Example 16.2.5.

For a covector field ω in 𝔛*(M) = T_1^0(M) and a vector field Y in 𝔛(M), setting r = 0 and s = 1 in Theorem 16.2.4 gives

D_1^0(ω)(Y) = X(ω(Y)) − ω(D_0^1(Y)), (16.2.2)

where X = D_0^0.

# Theorem 16.2.6.

A tensor derivation D on a smooth manifold M is uniquely determined by its values on C^∞(M) and 𝔛(M).

Proof. We see from Theorem 16.2.4 that D is uniquely determined by its values on C^∞(M), 𝔛(M), and 𝔛*(M). However, (16.2.2) shows that the values of D on 𝔛*(M) are uniquely determined by its values on 𝔛(M).

# Theorem 16.2.7 (Existence of Tensor Derivation).

Let M be a smooth manifold, let X be a vector field in 𝔛(M), and let

𝒟_X : 𝔛(M) ⟶ 𝔛(M)

be a linear map such that

𝒟_X(fY) = X(f)Y + f𝒟_X(Y) (16.2.3)

for all functions f in C^∞(M) and all vector fields Y in 𝔛(M). Then there is a unique tensor derivation D on M such that

D_0^0 = X and D_0^1 = 𝒟_X. (16.2.4)
