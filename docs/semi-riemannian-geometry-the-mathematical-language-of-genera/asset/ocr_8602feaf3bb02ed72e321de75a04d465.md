so there is agreement on overlaps. Taken together, the X|U, one for each point in M, define a vector field X in 𝔛(M) such that X^F = ω. Thus, F is surjective.

# The sharp map

S : 𝔛*(M) ⟶ 𝔛(M)

on M is defined to be the inverse of F; that is,

S = F⁻¹.

Let 1 ≤ k ≤ r and 1 ≤ l ≤ s + 1 be integers (so that r ≥ 1 and s ≥ 0). The (k, l)-flat map is denoted by

Fₗᵏ : 𝒯ₛʳ(M) ⟶ 𝒯ₛ₊₁ʳ⁻¹(M)

and defined (using Theorem 15.7.2) for all tensor fields 𝒜 in 𝒯ₛʳ(M), all covector fields ω¹, …, ωʳ⁻¹ in 𝔛*(M), and all vector fields X₁, …, Xₛ₊₁ in 𝔛(M) as follows, where ^ indicates that an expression is omitted:

# [F1] For r = 1 (so that k = 1):

Fₗ¹(𝒜)(X₁, …, Xₛ₊₁) = 𝒜(Xₗ^F, X₁, …, X̂ₗ, …, Xₛ₊₁).

# [F2] For r ≥ 2 and 1 ≤ k ≤ r − 1:

Fₗᵏ(𝒜)(ω¹, …, ωʳ⁻¹, X₁, …, Xₛ₊₁) = 𝒜(ω¹, …, ωᵏ⁻¹, Xₗ^F, ωᵏ, …, ωʳ⁻¹, X₁, …, X̂ₗ, …, Xₛ₊₁).

# [F3] For r ≥ 2 and k = r:

Fₗʳ(𝒜)(ω¹, …, ωʳ⁻¹, X₁, …, Xₛ₊₁) = 𝒜(ω¹, …, ωʳ⁻¹, Xₗ^F, X₁, …, X̂ₗ, …, Xₛ₊₁).

Similarly, let 1 ≤ k ≤ r + 1 and 1 ≤ l ≤ s be integers (so that r ≥ 0 and s ≥ 1). The (k, l)-sharp map is denoted by

Sₗᵏ : 𝒯ₛʳ(M) ⟶ 𝒯ₛ₋₁ʳ⁺¹(M)

and defined (using Theorem 15.7.2) for all tensor fields 𝒜 in 𝒯ₛʳ(M), all covector fields ω¹, …, ωʳ⁺¹ in 𝔛*(M), and all vector fields X₁, …, Xₛ₋₁ in 𝔛(M) as follows:

# [S1] For s = 1 (so that l = 1):

S₁ᵏ(𝒜)(ω¹, …, ωʳ⁺¹) = 𝒜(ω¹, …, ω̂ᵏ, …, ωʳ⁺¹, ωᵏS).

# [S2] For s ≥ 2 and 1 ≤ l ≤ s − 1:

Sₗᵏ(𝒜)(ω¹, …, ωʳ⁺¹, X₁, …, Xₛ₋₁) = 𝒜(ω¹, …, ω̂ᵏ, …, ωʳ⁺¹, X₁, …, Xₗ₋₁, ωᵏS, Xₗ, …, Xₛ₋₁).
