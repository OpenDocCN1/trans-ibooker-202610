# Theorem 10.4.3. If U is an open set in ℝ^m and X, Y, Z are vector fields in 𝔛(U), then:

D_{D_X(Y)}(Z) - D_{D_Y(X)}(Z) = D_{[X,Y]}(Z) = D_X(D_Y(Z)) - D_Y(D_X(Z)).

Proof. Let

X = (α¹, ..., α^m),    Y = (β¹, ..., β^m),    and    Z = (γ¹, ..., γ^m).

(a): By Theorem 10.3.3(c),

D_{D_X(Y)}(Z) = Σ_k ( Σ_{ij} α^i ∂β^j/∂x^i ) ∂γ^k/∂x^j E_k

and

D_{D_Y(X)}(Z) = Σ_k ( Σ_{ij} β^i ∂α^j/∂x^i ) ∂γ^k/∂x^j E_k,

hence

D_{D_X(Y)}(Z) - D_{D_Y(X)}(Z) = Σ_{kj} { Σ_i ( α^i ∂β^j/∂x^i - β^i ∂α^j/∂x^i ) ∂γ^k/∂x^j } E_k = Σ_k ( Σ_j [X,Y]^j ∂γ^k/∂x^j ) E_k   [Th 10.4.1] = D_{[X,Y]}(Z),   [Th 10.3.3(a)]

which proves the first equality.

It follows from Theorem 10.3.3(b) that the k-th component of D_X(D_Y(Z)) is

(D_X(D_Y(Z)))^k = Σ_{ij} ( α^i ∂β^j/∂x^i ∂γ^k/∂x^j + α^i β^j ∂²γ^k/∂x^i∂x^j ).   (10.4.7)

Replacing (α, β, γ) with (β, α, γ) in the preceding identity gives

(D_Y(D_X(Z)))^k = Σ_{ij} ( β^i ∂α^j/∂x^i ∂γ^k/∂x^j + β^i α^j ∂²γ^k/∂x^i∂x^j ).   (10.4.8)
