Not all maps of interest have domains that are open sets. For this reason we need an “extended” definition of smoothness to handle maps defined on sets that are not necessarily open. Let $S$ be an arbitrary subset of $\mathbb{R}^m$, and let $F:S\to\mathbb{R}^n$ be a map. We say that $F$ is (extended) smooth (on $S$) if for every point $p$ in $S$, there is a neighborhood $\mathcal{U}$ of $p$ in $\mathbb{R}^m$ and a (Euclidean) smooth map $\widetilde F:\mathcal{U}\to\mathbb{R}^n$ such that $F$ and $\widetilde F$ agree on $S\cap\mathcal{U}$; that is, $F|_{S\cap\mathcal{U}}=\widetilde F|_{S\cap\mathcal{U}}$. Although in the preceding definition both $\mathcal{U}$ and $\widetilde F$ might very well depend on $p$, the next result shows that this dependence can be avoided.

**Theorem 10.1.15.** Let $S$ be a subset of $\mathbb{R}^m$, and let $F:S\to\mathbb{R}^n$ be a map. Then $F$ is (extended) smooth if and only if there is an open set $\mathcal{U}$ in $\mathbb{R}^m$ containing $S$ and a (Euclidean) smooth map $\widetilde F:\mathcal{U}\to\mathbb{R}^n$ such that $F$ and $\widetilde F$ agree on $S$; that is, $F=\widetilde F|_S$.

For example, a curve $\lambda(t):[a,b]\to\mathbb{R}^m$ is smooth if and only if there is an interval $(\widetilde a,\widetilde b)$ containing $[a,b]$ and a smooth curve $\widetilde\lambda(t):(\widetilde a,\widetilde b)\to\mathbb{R}^m$ such that $\lambda=\widetilde\lambda|_{[a,b]}$.

**Theorem 10.1.16.** Let $S$ be a subset of $\mathbb{R}^m$, and let $F:S\to\mathbb{R}^n$ be a map. If $F$ is (extended) smooth, then it is continuous.

**Theorem 10.1.17.** Let $S$ and $T$ be subsets of $\mathbb{R}^m$ and $\mathbb{R}^n$, respectively, and let $F:S\to\mathbb{R}^n$ and $G:T\to\mathbb{R}^k$ be maps such that $F(S)\subseteq T$. If $F$ and $G$ are (extended) smooth, then so is $G\circ F$.

# 10.2 Immersions and Diffeomorphisms

Let $U$ be an open set in $\mathbb{R}^m$, let $F:U\to\mathbb{R}^n$ be a smooth map, where $m\le n$, and let $p$ be a point in $U$. Since $F$ is smooth on $U$, hence differentiable at $p$, we have from remarks in Section 10.1 that $d_p(F)(\mathbb{R}^m)$ can be viewed as the “tangent space” to the graph of $F$ at $F(p)$. We say that $F$ is an immersion at $p$ if the differential map $d_p(F):\mathbb{R}^m\to\mathbb{R}^n$ is injective, and that $F$ is an immersion (on $U$) if it is an immersion at every $p$ in $U$.
