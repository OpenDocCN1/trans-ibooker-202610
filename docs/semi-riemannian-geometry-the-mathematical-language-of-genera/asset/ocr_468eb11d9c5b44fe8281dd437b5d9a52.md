**Proof.** $(\Rightarrow)$: This follows from (3.1.1).  
$(\Leftarrow)$: Straightforward.

Theorem 3.2.2 shows that provided $\mathbf b$ is symmetric, $\mathbf b$ and $q$ determine each other completely.

# **Theorem 3.2.3.** Let $V$ be a vector space, let $\mathbf b$ be a bilinear function on $V$, and let $q$ be the corresponding quadratic function. Then the following are equivalent:

+   (a) $\mathbf b$ is alternating.  
+   (b) $q=0$.  
+   (c) $V$ does not have a unit vector.

**Proof.** (a) $\Rightarrow$ (b): Since $\langle v,w\rangle=-\langle w,v\rangle$ for all vectors $v,w$ in $V$, setting $w=v$ gives $q(v)=-q(v)$, hence $q(v)=0$, for all vectors $v$ in $V$.

(b) $\Rightarrow$ (a): This follows from (3.1.1).  
(b) $\Leftrightarrow$ (c): We prove the logical equivalent assertion: $q\ne0$ if and only if $V$ has a unit vector. If $q\ne0$, then there is a (nonzero) vector $v$ in $V$ such that $q(v)\ne0$, hence $v/\sqrt{|q(v)|}$ is a unit vector. The converse is equally straightforward.

We are especially interested in vector spaces on which there is a nonzero symmetric bilinear function. The reason is that such vector spaces have a unit vector, as we now show.

# **Theorem 3.2.4.** Let $V$ be a vector space, let $\mathbf b$ be a symmetric bilinear function on $V$, and let $q$ be the corresponding quadratic function. Then:

+   (a) $\mathbf b=0$ if and only if $q=0$.  
+   (b) If $\mathbf b\ne0$, then $V$ has a unit vector.

**Proof.** (a) $(\Rightarrow)$: Straightforward.  
(a) $(\Leftarrow)$: This follows from Theorem 3.2.2.  
(b): By part (a), $q\ne0$. The result now follows from Theorem 3.2.3.

The light set of a vector space is a rather mysterious entity. The next result provides a characterization when the bilinear function satisfies certain properties.

# **Theorem 3.2.5.** If $V$ is a vector space and $\mathbf b$ is a symmetric semidefinite bilinear function on $V$, then

$$\Lambda=V^\perp\setminus\{0\}.$$

**Remark.** The preceding identity is equivalent to saying that for every nonzero vector $v$ in $V$, $\langle v,v\rangle=0$ if and only if $\langle w,w\rangle=0$ for all vectors $w$ in $V$.

**Proof.** Clearly, $V^\perp\setminus\{0\}\subseteq\Lambda$. To prove the reverse inclusion, let $q$ be the quadratic function corresponding to $\mathbf b$, and let $v$ and $w$ be vectors in $\Lambda$ and $V$, respectively. Consider the polynomial $p(t):\mathbb R\to\mathbb R$ defined by

$$p(t)=q(tv+w)=2\langle v,w\rangle t+\langle w,w\rangle.$$
