Proof. Let Ξ = (ξ¹, …, ξᵐ). Since 𝔤_ℰ = diag(ε₁, …, εₘ), we have from Theorem 4.5.3(b) that

𝔤_Ξ* = 𝔤_ℰ⁻¹ = 𝔤_ℰ = diag(ε₁, …, εₘ),

and then from (7.5.2) that

⟨ξ^I, ξ^J⟩^∧ = det(diag(ε₁, …, εₘ)^I_J).

If I = J, then diag(ε₁, …, εₘ)^I_J = diag(ε_{i₁}, …, ε_{i_s}). On the other hand, if I ≠ J, then diag(ε₁, …, εₘ)^I_J has at least one row (and at least one column) of 0s. The result follows.

We are now in a position to define the multicovector counterpart of the dual scalar product space described in Section 4.5.

# Theorem 7.5.3. Let (V, 𝔤) be a scalar product space, let ℰ be an orthonormal basis for V, and let (ξ¹, …, ξᵐ) be its dual basis. Then:

+   (a) (Λ^s(V), 𝔤^∧) is a scalar product space, called the multicovector scalar product space corresponding to (V, 𝔤)
+   (b) (ξ^I : I ∈ ℐ_{s,m}) is an orthonormal basis for Λ^s(V).
+   (c) If (V, 𝔤) is an inner product space, then so is (Λ^s(V), 𝔤^∧).

Proof. (a): We need to show that 𝔤^∧ is a scalar product. By construction, 𝔤^∧ is bilinear, and clearly it is symmetric. According to Theorem 7.2.12(a), (ξ^I : I ∈ ℐ_{s,m}) is a basis for Λ^s(V). Suppose η is a multicovector in Λ^s(V) such that ⟨η, ζ⟩^∧ = 0 for all multicovectors ζ in Λ^s(V), and let

η = Σ_{I ∈ ℐ_{s,m}} a_I ξ^I.   (7.5.11)

Then Theorem 7.5.2 gives

0 = ⟨η, ξ^I⟩^∧ = ⟨ Σ_{J ∈ ℐ_{s,m}} a_J ξ^J, ξ^I ⟩^∧ = Σ_{J ∈ ℐ_{s,m}} a_J ⟨ξ^J, ξ^I⟩^∧ = ± a_I,

hence a_I = 0 for all multi-indices I in ℐ_{s,m}, so η = 0. Thus, 𝔤^∧ is nondegenerate.

(b): It was just observed that (ξ^I : I ∈ ℐ_{s,m}) is a basis for Λ^s(V). By Theorem 7.5.2, it is orthonormal.

(c): Since 𝔤 is an inner product, we have from Theorem 7.5.2 that

⟨ξ^I, ξ^J⟩^∧ = { 1 if I = J
                  0 if I ≠ J. }

With η as in (7.5.11),

⟨η, η⟩^∧ = ⟨ Σ_{I ∈ ℐ_{s,m}} a_I ξ^I, Σ_{J ∈ ℐ_{s,m}} a_J ξ^J ⟩^∧ = Σ_{I,J ∈ ℐ_{s,m}} ⟨ξ^I, ξ^J⟩^∧ a_I a_J
          = Σ_{I ∈ ℐ_{s,m}} (a_I)² ≥ 0,

and there is equality if and only if each a_I = 0, in which case η = 0.
