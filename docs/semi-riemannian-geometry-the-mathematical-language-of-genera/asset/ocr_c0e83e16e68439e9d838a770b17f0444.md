# 19.1  Semi-Riemannian Manifolds

Let $(M,g)$ be a semi-Riemannian $m$-manifold, and let $X,Y$ be vector fields in $\mathfrak{X}(M)$. We say that $X$ is a **unit vector field** if $X_p$ is a unit vector for all $p$ in $M$, and that $X$ and $Y$ are **orthogonal vector fields** if $X_p$ and $Y_p$ are orthogonal for all $p$ in $M$.

Let us define a function

$$\langle X,Y\rangle:M\longrightarrow\mathbb{R}$$

in $C^\infty(M)$ by the assignment

$$p\longmapsto\langle X_p,Y_p\rangle$$

for all $p$ in $M$. Similarly, for a smooth curve $\lambda:(a,b)\longrightarrow M$ and vector fields $J,K$ in $\mathfrak{X}_M(\lambda)$, we define a function

$$\langle J,K\rangle:(a,b)\longrightarrow\mathbb{R}$$

in $C^\infty((a,b))$ by the assignment

$$t\longmapsto\langle J(t),K(t)\rangle$$

for all $t$ in $(a,b)$.

Let $(U,(x^i))$ be a chart on $M$, and let $\mathcal{X}=(\partial/\partial x^1,\ldots,\partial/\partial x^m)$ be the corresponding coordinate frame. We define functions $g_{ij}$ in $C^\infty(U)$ by

$$g_{ij}(p)=\left\langle\left.\frac{\partial}{\partial x^i}\right|_p,\left.\frac{\partial}{\partial x^j}\right|_p\right\rangle \tag{19.1.1}$$

for all $p$ in $U$ for $i,j=1,\ldots,m$. The **matrix** of $g$ with respect to $\mathcal{X}$ is denoted by $g_{\mathcal{X}}$ and defined by

$$g_{\mathcal{X}}(p)=\begin{bmatrix}g_{11}(p)&\cdots&g_{1m}(p)\\ \vdots&\ddots&\vdots\\ g_{m1}(p)&\cdots&g_{mm}(p)\end{bmatrix}$$

for all $p$ in $U$. Recall from Section 3.1 that the matrix of $g_p$ with respect to $\mathcal{X}_p$ is $(g_p)_{\mathcal{X}_p}=[g_{ij}(p)]$. Thus, as a matter of notation,

$$g_{\mathcal{X}}(p)=(g_p)_{\mathcal{X}_p}.$$

The **inverse matrix** of $g$ with respect to $\mathcal{X}$ is denoted by $g_{\mathcal{X}}^{-1}$ and defined by

$$g_{\mathcal{X}}^{-1}(p)=g_{\mathcal{X}}(p)^{-1}$$

for all $p$ in $U$. It is usual to express the entries of $g_{\mathcal{X}}^{-1}(p)$ with superscripts:

$$g_{\mathcal{X}}^{-1}(p)=\begin{bmatrix}g_{11}(p)&\cdots&g_{1m}(p)\\ \vdots&\ddots&\vdots\\ g_{m1}(p)&\cdots&g_{mm}(p)\end{bmatrix}^{-1}=\begin{bmatrix}g^{11}(p)&\cdots&g^{1m}(p)\\ \vdots&\ddots&\vdots\\ g^{m1}(p)&\cdots&g^{mm}(p)\end{bmatrix}.$$

The assignment $p\longmapsto g^{ij}(p)$ defines functions $g^{ij}$ in $C^\infty(U)$ for $i,j=1,\ldots,m$. Since $[g_{ij}]$ and $[g^{ij}]$ are symmetric matrices, the functions $g_{ij}$ and $g^{ij}$ are symmetric in $i,j$.
