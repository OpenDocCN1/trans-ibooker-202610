For a sufficiently small real number ε > 0, define a smooth function g_t(p) : (−ε,ε) × M ⟶ ℝ by

```
g_t(p) = (Φ_t)^•(f)(p) − f(p) = f ∘ Φ_t − f,    (16.10.5)
```

and observe that g_0(p) = 0. Consider the smooth function h_t(p) : (−ε,ε) × M ⟶ ℝ defined by

```
h_t(p) = ∫₀¹ ∂g_{st}/∂s (p) ds.
```

For t ≠ 0, make a change of variable, and use the fundamental theorem of calculus to obtain

```
h_t(p) = 1/t ∫₀^t dg_r/dr (p) dr = 1/t (g_r(p))|_{r=0}^{r=t} = g_t(p)/t.    (16.10.6)
```

Then

```
h_0(p) = lim_{t→0} h_t(p)
      = ℒ_X(f)(p)      [Th 16.10.4]
      = X(f)(p)        [(16.4.1)]
```

for all p in M, hence

```
h_0 = X(f).    (16.10.7)
```

We have

```
(Φ_t)_*(Y)_p(f) = (Φ_t)_*(Y)_{Φ_{-t}(p)}(f)                     [Th 16.10.3(d)]
                 = d_{Φ_{-t}(p)}(Φ_t(Y_{Φ_{-t}(p)}))(f)               [Th 15.10.1]
                 = Y_{Φ_{-t}(p)}(f ∘ Φ_t)                             [(14.4.1)]
                 = Y_{Φ_{-t}(p)}(f + t h_t)                           [(16.10.5), (16.10.6)]
                 = Y_{Φ_{-t}(p)}(f) + t Y_{Φ_{-t}(p)}(h_t)
                 = Y(f)(Φ_{-t}(p)) + t Y(h_t)(Φ_{-t}(p)),             [(15.1.2)]
```
