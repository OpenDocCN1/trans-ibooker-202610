

对于充分小的实数 ε > 0，定义一个光滑函数 g_t(p) : (−ε,ε) × M ⟶ ℝ 为

```
g_t(p) = (Φ_t)^•(f)(p) − f(p) = f ∘ Φ_t − f,    (16.10.5)
```

并注意到 g_0(p) = 0。考虑光滑函数 h_t(p) : (−ε,ε) × M ⟶ ℝ 定义为

```
h_t(p) = ∫₀¹ ∂g_{st}/∂s (p) ds.
```

对于 t ≠ 0，做变量替换，并利用微积分基本定理得到

```
h_t(p) = 1/t ∫₀^t dg_r/dr (p) dr = 1/t (g_r(p))|_{r=0}^{r=t} = g_t(p)/t.    (16.10.6)
```

于是

```
h_0(p) = lim_{t→0} h_t(p)
      = ℒ_X(f)(p)      [Th 16.10.4]
      = X(f)(p)        [(16.4.1)]
```

对所有 p ∈ M 成立，故

```
h_0 = X(f).    (16.10.7)
```

我们有

```
(Φ_t)_*(Y)_p(f) = (Φ_t)_*(Y)_{Φ_{-t}(p)}(f)                     [Th 16.10.3(d)]
                 = d_{Φ_{-t}(p)}(Φ_t(Y_{Φ_{-t}(p)}))(f)               [Th 15.10.1]
                 = Y_{Φ_{-t}(p)}(f ∘ Φ_t)                             [(14.4.1)]
                 = Y_{Φ_{-t}(p)}(f + t h_t)                           [(16.10.5), (16.10.6)]
                 = Y_{Φ_{-t}(p)}(f) + t Y_{Φ_{-t}(p)}(h_t)
                 = Y(f)(Φ_{-t}(p)) + t Y(h_t)(Φ_{-t}(p)),             [(15.1.2)]
```

式 (16.10.8) 右边两项为

$$\begin{aligned}
\lim_{t\to 0}\frac{Y(f)(p)-Y(f)(\Phi_{-t}(p))}{t}
&=\lim_{t\to 0}\frac{Y(f)(\Phi_{-t}(p))-Y(f)(p)}{-t}\\
&=\lim_{t\to 0}\frac{Y(f)(\Phi_t(p))-Y(f)(p)}{t}\\
&=\lim_{t\to 0}\frac{(\Phi_t)_*(Y(f))(p)-Y(f)(p)}{t}\\
&=\mathcal{L}_X(Y(f))(p)\\
&=X(Y(f))(p).
\end{aligned}$$

和

$$\begin{aligned}
\lim_{t\to 0}Y(h_t)(\Phi_{-t}(p))&=Y(h_0)(\Phi_0(p))\\
&=Y(X(f))(p).
\end{aligned}$$

将 (16.10.9) 和 (16.10.10) 代入 (16.10.8) 得

$$\begin{aligned}
\lim_{t\to 0}\frac{(\Phi_t)^*(Y)_p-(\Phi_t)_*(Y)_p(f)}{t}
&=X(Y(f))(p)-Y(X(f))(p)\\
&=[X,Y](f)(p)\\
&=[X,Y]_p(f)\\
&=\mathcal{L}_X(Y)_p(f).
\end{aligned}$$

由于 f 为任意的，

$$\lim_{t\to 0}\frac{(\Phi_t)_*(Y)_p-Y_p}{t}=\mathcal{L}_X(Y)_p.$\quad\square$$

式 (16.10.4) 的第二个右边项使我们能够把 $\mathcal{L}_X(Y)_p$ 视为 $Y$ 在“方向” $X_p$ 上的某种“方向导数”，意义如下。通常 $T_p(M)$ 中的向量与 $M$ 其他切空间中的向量之间没有联系。$X$ 的最大流在 $T_p(M)$ 与那些对应于位于以 $p$ 为起点最大积分曲线上的点的切空间之间建立了联系。为了求 $\mathcal{L}_X(Y)_p$，利用微分同胚 $\Phi_t$ 计算 $Y$ 在 $p$ 处的拉回，得到 $T_p(M)$ 中的向量 $(\Phi_t)_*(Y)_p$，然后通过取极限将其与 $Y_p$ 进行比较。这是有意义的，因为所有计算都在 $T_p(M)$ 中进行。

在第 16.4 节，Lie 导数被表述为张量导数。特别地，矢量场的 Lie 导数是用 Lie 括号定义的。在文献中，矢量场的 Lie 导数更通常是用式 (16.10.4) 中的第一个等式定义的。定理 16.10.5 表明这两种方法等价。

## 第 17 章

## 带边界的光滑流形

在实践中遇到原本是光滑流形但因某种“边界”的存在而有所不同的情况并不罕见。本章中，我们引入带边界的光滑流形并证明微分几何中最重要的结果之一——Stokes 定理。

### 17.1 带边界的光滑流形

ℝ^m 的闭上半空间，由

ℍ^m = {(x¹, …, x^m) ∈ ℝ^m : x^m ≥ 0}

定义，是我们后来所称的带边界光滑 m-流形的模型。容易证明

int_ℝ^m(ℍ^m) = {(x¹, …, x^m) ∈ ℝ^m : x^m > 0}
ext_ℝ^m(ℍ^m) = {(x¹, …, x^m) ∈ ℝ^m : x^m < 0}
bd_ℝ^m(ℍ^m) = {(x¹, …, x^m) ∈ ℝ^m : x^m = 0}.

例如，ℍ³ = {(x, y, z) ∈ ℝ³ : z ≥ 0} 是包含 xy-平面的 ℝ³ 的上半部分，int_ℝ³(ℍ³) 是不含 xy-平面的 ℝ³ 的上半部分，ext_ℝ³(ℍ³) 是不含 xy-平面的 ℝ³ 的下半部分，而 bd_ℝ³(ℍ³) 是 xy-平面。

在整个讨论中，ℍ^m 假定具有由 ℝ^m 诱导的子空间拓扑。

我们的第一个目标是利用 ℍ^m 来拓广我们先前对“图表”的概念。设 M 是一个拓扑空间，并考虑对第 14.1 节中图表定义的一种修改。M 上的图表是一个对 (U, φ)，其中 U 是 M 中的开集且 φ : U ⟶ ℍ^m 是一个映射，使得：

- [C1] φ(U) 是 ℍ^m 中的开集。
- [C2] φ : U ⟶ φ(U) 是一个同胚。

与先前表述的不同之处在于 [C1] 中出现了 ℍ^m 而不是 ℝ^m。我们把 m 称为图表的维数。对于 φ(U) 中的每个点 p，(U, φ) 称为在 p 处的图表。如前所述，M 的一个图册 𝔄 = {(Uα, φα) : α ∈ A} 是 M 上图表的集合，使得 Uα 构成 M 的一个开覆盖。

带边界的拓扑 m-流形是一个对 (M, 𝔄)，其中 M 是一个拓扑空间且 𝔄 是 M 的一个图册，使得：

- [T1] 𝔄 中每个图表的维数为 m。
- [T2] M 的拓扑具有可数基。
- [T3] 对于 M 中任意一对不同点 p1, p2，存在 M 中不相交的开集 U1 和 U2，使得 p1 在 U1 中且 p2 在 U2 中。

设 M 是一个带边界的拓扑 m-流形，设 (U, φ) 是 M 上的一个图表。我们说 (U, φ) 是内部图表，如果 φ(U) 包含于 intℝ^m(ℍ^m)，并且是边界图表，如果 φ(U) 与 bdℝ^m(ℍ^m) 相交。显然，M 上的任何图表要么是内部图表要么是边界图表。由于 intℝ^m(ℍ^m) 是 ℝ^m 中的开集，根据定理 9.1.5 可知，如果 (U, φ) 是内部图表，则它是第 14.1 节意义下的图表。另一方面，如果 φ(U) 与 bdℝ^m(ℍ^m) 相交，我们就有了全新的东西。

### 定理 17.1.1 （边界的拓扑不变性）。带边界的拓扑流形中的每个点要么是内部点要么是边界点，但不是两者兼有。

设 M 是一个带边界的拓扑流形，设 p 是 M 中的一点。定理 17.1.1 的一个推论是，判断 p 是内部点还是边界点与在 p 处选择的图表无关。M 的内部点的集合记为 M° 并称为 M 的（流形）内部，M 的边界点的集合记为 ∂M 并称为 M 的（流形）边界。因此，M 是 M° 与 ∂M 的不交并。

有了图表的概念，第 14.1 节中提出的其它核心定义——过渡映射、切空间、光滑图册等——几乎逐字逐句地转移到本设定中。然而，必须考虑 ℍ^m 的边界。为此，在考虑光滑性时，我们采用第 10.1 节中引入的“扩展”光滑性定义。

带边界的拓扑流形 (M,𝔄) 称为带边界的光滑 m-流形，如果 𝔄 是 M 的一个光滑图册。

(ℍ^m)° = int_ℝ^m(ℍ^m)      且      ∂ℍ^m = bd_ℝ^m(ℍ^m)，

分别。我们模仿 ℝ^m 的情况，称 (r¹,…,r^m) 为 ℍ^m 上的标准坐标，称 (∂/∂r¹,…,∂/∂r^m) 和 (d(r¹),…,d(r^m)) 分别为 ℍ^m 的相应标准坐标标架和标准对偶坐标标架，并称由 d(r¹)∧⋯∧d(r^m) 诱导的 ℍ^m 的定向为标准定向。
