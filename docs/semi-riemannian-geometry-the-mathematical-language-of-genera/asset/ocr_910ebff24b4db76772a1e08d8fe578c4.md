𝔰((x¹,...,xᵐ),(y¹,...,yᵐ)) = ⟨(x¹,...,xᵐ),(y¹,...,yᵐ)⟩ = { Σᵢ=1ᵐ xⁱ yⁱ if ν = 0; Σᵢ=1ᵐ⁻ν xⁱ yⁱ − Σᵢ=m−ν+1ᵐ xⁱ yⁱ if 1 ≤ ν ≤ m − 1; − Σᵢ=1ᵐ xⁱ yⁱ if ν = m. }

Clearly, 𝔰 is bilinear and symmetric. Let (e₁,...,eₘ) be the standard basis for ℝᵐ, and suppose v = (a¹,...,aᵐ) is a vector in ℝᵐ such that ⟨v,w⟩ = 0 for all vectors w in ℝᵐ. Then, in particular, 0 = ⟨v,eᵢ⟩ = ±aⁱ for each i, hence v = 0. Thus, 𝔰 is nondegenerate. This shows that 𝔰 is a scalar product on ℝᵐ. The scalar product space (ℝᵐ,𝔰) is called semi-Euclidean (m,ν)-space. We usually denote (ℝᵐ,𝔰) by ℝᵥᵐ, and write ℝᵥᵐ = (ℝᵐ,𝔰).

Let us observe that the presence or absence of a scalar product on ℝᵐ has nothing to do with the existence of a basis. Accordingly, the standard basis for ℝᵥᵐ is defined to be the standard basis for ℝᵐ.

# Theorem 4.1.2. If (V,g) is a scalar product space and U is a subspace of V, then:

+   (a) dim(U⊥) = dim(U⁰).
+   (b) dim(V) = dim(U) + dim(U⊥).
+   (c) U⊥⊥ = U.

Proof. (a): We have U⊥ = {v ∈ V : ⟨v,u⟩ = 0 for all u ∈ U} = {v ∈ V : F(v) ∈ U⁰} = F⁻¹(U⁰) = S(U⁰) = im(S|U⁰), hence dim(U⊥) = rank(S|U⁰).

Since S : V* ⟶ V is a linear isomorphism, so is S|U⁰ : U⁰ ⟶ S(U⁰). Then Theorem 1.1.14 gives rank(S|U⁰) = dim(U⁰). The result follows.

(b): This follows from Theorem 1.4.1 and part (a).

(c): If u is a vector in U, then ⟨u,v⟩ = 0 for all vectors v in U⊥, hence u is in U⊥⊥. Thus, U ⊆ U⊥⊥. Using part (b) twice yields dim(U) + dim(U⊥) = dim(V) = dim(U⊥) + dim(U⊥⊥), so dim(U) = dim(U⊥⊥). The result now follows from Theorem 1.1.7(b).
