In the notation of Theorem 18.2.1, we have as special cases

```

```

These formulas tell us that to take the covariant derivatives of Y and ω with respect to ∂/∂x^i, we simply add a subscript “;i” to each of the components in the local coordinate expressions.

# Theorem 18.2.2 (Local Coordinate Expression for Covariant Derivative).

Let (M,∇) be a smooth m-manifold with a connection, let 𝒜 be a tensor field in T^r_s(M), and, in local coordinates, let 𝒜^{i_1...i_r}_{j1...j_s} be the components of 𝒜. Then the components of ∇_{∂/∂x^k}(𝒜) are

```
∇_{∂/∂x^k}(𝒜)^{i_1...i_r}_{j1...j_s} = ∂𝒜^{i_1...i_r}_{j1...j_s}/∂x^k + Σ_{l=1}^r ( Σ_{p=1}^m Γ^{i_l}_{kp} 𝒜^{i_1...i_{l-1} p i_{l+1}...i_r}_{j1...j_s} ) - Σ_{l=1}^s ( Σ_{p=1}^m Γ^p_{k j_l} 𝒜^{i_1...i_r}_{j1...j_{l-1} p j_{l+1}...j_s} ).
```

Proof. By Theorem 18.1.4,

```
∇_{∂/∂x^k}(𝒜)^{i_1...i_r}_{j1...j_s} = ∇_{∂/∂x^k}(𝒜)( d(x^{i1}),...,d(x^{ir}), ∂/∂x^{j1},...,∂/∂x^{js} ) = ∂/∂x^k( 𝒜( d(x^{i1}),...,d(x^{ir}), ∂/∂x^{j1},...,∂/∂x^{js} ) ) - Σ_{l=1}^r 𝒜( d(x^{i1}),...,∇_{∂/∂x^k}(d(x^{i_l})),...,d(x^{ir}), ∂/∂x^{j1},...,∂/∂x^{js} ) - Σ_{l=1}^s 𝒜( d(x^{i1}),...,d(x^{ir}), ∂/∂x^{j1},...,∇_{∂/∂x^k}(∂/∂x^{j_l}),...,∂/∂x^{js} ).
```

We have

```
∂/∂x^k( 𝒜( d(x^{i1}),...,d(x^{ir}), ∂/∂x^{j1},...,∂/∂x^{js} ) ) = ∂𝒜^{i1...ir}_{j1...js}/∂x^k
```
