# Theorem 12.3.4. With the above setup, if X is in 𝔛(M), then α^i is a function in C^∞(U) for i = 1, 2.

Proof. We have

```
⟨X ∘ φ, H_k⟩ = ⟨Σ_j α^j H_j, H_k⟩ = Σ_j α^j ⟨H_j, H_k⟩ = Σ_j α^j 𝔤_{jk},
```

hence

```
Σ_k 𝔤^{ik}⟨X ∘ φ, H_k⟩ = Σ_k 𝔤^{ik}(Σ_j α^j 𝔤_{jk}) = Σ_j α^j(Σ_k 𝔤^{ik} 𝔤_{kj}) = Σ_j α^j δ^i_j = α^i.
```

By assumption, X is smooth. It follows from Theorem 11.7.1 that X ∘ φ is smooth, and therefore, so is α^i.
