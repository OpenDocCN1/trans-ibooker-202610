Combining (16.2.6) and (16.2.7) gives

```
D₁⁰(ω)(fY + Z) = f D₁⁰(ω)(Y) + D₁⁰(ω)(Z)
```

which proves the claim.

The next step is to define a map

```
D₁⁰ : 𝔛*(M) ⟶ Lin_{C^∞(M)} (𝔛(M), C^∞(M))    (16.2.8)
```

by the assignment

```
ω ⟶ D₁⁰(ω)
```

for all covector fields ω in 𝔛*(M). We have 𝔛*(M) = 𝒯₁⁰(M), and by Theorem 15.5.3, Lin_{C^∞(M)} (𝔛(M), C^∞(M)) can be identified with 𝔛*(M). Thus, (16.2.8) can be expressed as D₁⁰ : 𝒯₁⁰(M) ⟶ 𝒯₁⁰(M), which is what we need for a tensor derivation corresponding to (r, s) = (0, 1).

It remains to show that [D1] and [D2] are satisfied. Let f be a function in C^∞(M), let ω be a covector field in 𝔛*(M), and let Y be a vector field in 𝔛(M). Then

```
D₀₊₁⁰⁺⁰(f ⊗ ω)(Y)
= D₁⁰(fω)(Y)
= X(fω(Y)) − fω(𝒟_X(Y))    [(16.2.5)]
= X(f)ω(Y) + f X(ω(Y)) − fω(𝒟_X(Y))    [(15.1.3)]
= D₀⁰(f)ω(Y) + f D₁⁰(ω)(Y)    [(16.2.4), (16.2.5)]
= (D₀⁰(f) ⊗ ω + f ⊗ D₁⁰(ω))(Y).
```

Since Y was arbitrary,

```
D₀₊₁⁰⁺⁰(f ⊗ ω) = D₀⁰(f) ⊗ ω + f ⊗ D₁⁰(ω),
```

hence [D1] is satisfied. For (r, s) = (0, 1), no contractions are possible, so [D2] is trivially satisfied.

Uniqueness. It follows from (16.2.2) and (16.2.4) that (16.2.5) is the only option for defining D₁⁰.

# 16.3 Form Derivations

A form derivation on a smooth manifold M is a family 𝔇 of linear maps

```
𝔇_s : Λ^s(M) ⟶ Λ^s(M)
```

defined for s ≥ 0 such that

```
𝔇_{s+s'}(ω ∧ ξ) = 𝔇_s(ω) ∧ ξ + ω ∧ 𝔇_{s'}(ξ)    (16.3.1)
```

for all forms ω in Λ^s(M) and ξ in Λ^{s'}(M).
