# ## 20.9 Divergence of Symmetric 2-Covariant Tensor Fields

Let \((M,g)\) be a semi-Riemannian manifold, and let \(\Sigma(M)\) be the subspace of \(\mathcal{T}^0_2(M)\) consisting of symmetric (2-covariant) tensor fields. For example, \(g\) is in \(\Sigma(M)\). **Divergence of symmetric 2-covariant tensor fields** is the map

$$\operatorname{Div}:\Sigma(M)\longrightarrow \mathfrak{X}^*(M)$$

defined by

$$\operatorname{Div}(\mathcal{A})=C_{13}\circ\nabla(\mathcal{A})$$

for all tensor fields \(\mathcal{A}\) in \(\Sigma(M)\). Since \(\nabla(\mathcal{A})\) is in \(\mathcal{T}^0_3(M)\), \(C_{13}(\nabla(\mathcal{A}))\) is in \(\mathcal{T}^0_1(M)=\mathfrak{X}^*(M)\), so the definition makes sense. We note in passing that by Theorem 19.3.1, \(\nabla(g)=0\), hence \(\operatorname{Div}(g)=0\).

**Theorem 20.9.1 (Orthonormal Frame Expression for Divergence).** Let \((M,g)\) be a semi-Riemannian manifold with signature \((\epsilon_1,\ldots,\epsilon_m)\), let \((E_1,\ldots,E_m)\) be an orthonormal frame on an open set \(U\) in \(M\), let \(\mathcal{A}\) be a symmetric tensor field in \(\mathcal{T}^0_2(M)\), and let \(X\) be a vector field in \(\mathfrak{X}(M)\). Then

$$\operatorname{Div}(\mathcal{A})(X)=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(X,E_i)=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(E_i,X)$$

on \(U\).

*Proof.* We have

$$\begin{aligned}
\operatorname{Div}(\mathcal{A})(X)&=C_{13}(\nabla(\mathcal{A}))(X)\\
&=\sum_i\epsilon_i\nabla(\mathcal{A})(E_i,X,E_i)\qquad [\text{Th 19.6.2(a)}]\\
&=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(X,E_i),\qquad [(18.4.1)]
\end{aligned}$$

which proves the first equality. It is easily shown using (18.1.3) that since \(\mathcal{A}\) is symmetric, so is \(\nabla_{E_i}(\mathcal{A})\). The second equality now follows from the first. □

**Theorem 20.9.2.** If \((M,g)\) is a semi-Riemannian manifold and \(f\) is a function in \(C^\infty(M)\), then

$$\operatorname{Div}(fg)=d(f).$$

*Proof.* Let \((\epsilon_1,\ldots,\epsilon_m)\) be the signature of \(M\), and let \(p\) be a point in \(M\). By Theorem 19.3.7, there is an orthonormal frame \((E_1,\ldots,E_m)\) on a neighborhood \(U\) of \(p\). Let \(X\) be a vector field in \(\mathfrak{X}(M)\), and let \(X=\sum_i\alpha^iE_i\) on \(U\), where the \(\alpha^i\) are uniquely determined functions in \(C^\infty(U)\). From the manifold version of Theorem 4.2.7,

$$X=\sum_i\epsilon_i\langle X,E_i\rangle E_i.\tag{20.9.1}$$
