# 22.1 Linear Isometries on Lorentz Vector Spaces

Let $(V,\mathfrak{g},\mathfrak{O})$ be an oriented Lorentz vector space, and let $\mathcal{E} = (e_1,\dots,e_m)$ be an orthonormal basis for $V$ that is positively oriented with respect to $\mathfrak{O}$. We denote by $\mathsf{L}_m$ the set of linear isometries on $V$:

$\mathsf{L}_m = \{A \in \operatorname{Lin}(V,V) : A \text{ a linear isometry}\}$

where we recall that $\operatorname{Lin}(V,V)$ is the vector space of linear maps from $V$ to $V$.

**Theorem 22.1.1.** $\mathsf{L}_m$ is a group (under composition of linear maps), called the *Lorentz group on $V$*.

*Proof.* Let $A$ be a map in $\mathsf{L}_m$. It follows from Theorem 1.1.9 and Theorem 4.4.1(a) that the inverse $A^{-1}$ exists and is in $\operatorname{Lin}(V,V)$. Let $v,w$ be vectors in $V$. Then

$\langle v,w\rangle = \langle A(A^{-1}(v)),A(A^{-1}(w))\rangle = \langle A^{-1}(v),A^{-1}(w)\rangle$,

so $A^{-1}$ is in $\mathsf{L}_m$. The rest of the verification that $\mathsf{L}_m$ is a group is straightforward.
