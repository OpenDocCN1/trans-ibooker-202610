and a lightlike vector is orthogonal to itself. Unless **b** is symmetric, \(\langle w,v\rangle\) may not equal \(\langle v,w\rangle\). Thus, even when \(v\) is orthogonal to \(w\), it does not necessarily follow that \(w\) is orthogonal to \(v\).

Let \(U\) be a subspace of \(V\). The **perp of \(U\) (in \(V\) with respect to \(\mathbf b\))** is denoted by \(U^\perp\) and defined to be the set of vectors in \(V\) that are orthogonal (perpendicular) to every vector in \(U\):

\[U^\perp=\{v\in V:\langle v,u\rangle=0\text{ for all }u\in U\}.\]

It is easily shown that \(U^\perp\) is a subspace of \(V\). Let us denote

\[(U^\perp)^\perp\quad\text{by}\quad U^{\perp\perp}.\]

The **light set** of \(V\) is denoted by \(\Lambda\) and defined to be the set of lightlike vectors in \(V\):

\[\Lambda=\{v\in V:\langle v,v\rangle=0\}\setminus\{0\}.\]

# 3.2  Symmetric Bilinear Functions

Let \(V\) be a vector space, and let **b** be a bilinear function on \(V\). Recall from Section 3.1 that **b** is said to be symmetric on \(V\) if \(\langle v,w\rangle=\langle w,v\rangle\) for all vectors \(v,w\) in \(V\).

**Theorem 3.2.1.** If \(V\) is a vector space and **b** is a bilinear function on \(V\), then the following are equivalent:

(a) **b** is symmetric (as a bilinear function).

(b) \(\mathbf b_\mathcal H\) is symmetric (as a matrix) for some basis \(\mathcal H\) for \(V\).

(c) \(\mathbf b_\mathcal H\) is symmetric (as a matrix) for every basis \(\mathcal H\) for \(V\).

**Proof.** (a) ⇒ (c): Straightforward.

(c) ⇒ (b): Straightforward.

(b) ⇒ (a): We have

\[
\begin{aligned}
\langle v,w\rangle &= ([v]_\mathcal H)^\mathsf T\mathbf b_\mathcal H[w]_\mathcal H && [\text{Th 3.1.2(a)}]\\
&=([v]_\mathcal H)^\mathsf T\mathbf b_\mathcal H^\mathsf T[w]_\mathcal H &&\\
&=(([w]_\mathcal H)^\mathsf T\mathbf b_\mathcal H[v]_\mathcal H)^\mathsf T && [\text{Th 2.1.2(b)}]\\
&=\langle w,v\rangle^\mathsf T && [\text{Th 3.1.2(a)}]\\
&=\langle w,v\rangle.
\end{aligned}
\]

**Theorem 3.2.2.** Let \(V\) be a vector space, let **b** be a bilinear function on \(V\), and let \(q\) be the corresponding quadratic function. Then **b** is symmetric if and only if

\[
\mathbf b(v,w)=\frac{q(v+w)-q(v)-q(w)}{2}
\]

(polarization identity)

for all vectors \(v,w\) in \(V\).
