**Proof.** It is easily shown that \(\mathfrak{S}_s\) is a \(C^\infty(M)\)-module homomorphism. We need to show that \(\mathfrak{S}_s\) is bijective.

**Injectivity.** Suppose \(\Psi\) is a map in \(\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}(M)^s,\mathfrak{X}(M))\) such that \(\mathfrak{S}_s(\Psi)=0\). Then \(\langle X_1|_p,\Psi(X_2,\ldots,X_{s+1})|_p\rangle=0\) for all vector fields \(X_1,\ldots,X_{s+1}\) in \(\mathfrak{X}(M)\) and all \(p\) in \(M\). Since \(g\) is nondegenerate, we have \(\Psi(X_2,\ldots,X_{s+1})_p=0\) for all vector fields \(X_2,\ldots,X_{s+1}\) in \(\mathfrak{X}(M)\) and all \(p\) in \(M\). Hence \(\Psi(X_2,\ldots,X_{s+1})=0\) for all vector fields \(X_2,\ldots,X_{s+1}\) in \(\mathfrak{X}(M)\). Thus, \(\Psi=0\), so \(\ker(\mathfrak{S}_s)=\{0\}\). By Theorem B.5.3, \(\mathfrak{S}_s\) is injective.

**Surjectivity.** Let \(\Upsilon\) be a map in \(\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}(M)^{s+1},C^\infty(M))\). We need to find a map \(\widetilde{\Upsilon}\) in \(\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}(M)^s,\mathfrak{X}(M))\) such that \(\mathfrak{S}_s(\widetilde{\Upsilon})=\Upsilon\). According to Theorem 19.4.2, defining a covector field in \(\mathfrak{X}^*(M)\) is equivalent to defining a vector field in \(\mathfrak{X}(M)\). For given vector fields \(X_2,\ldots,X_{s+1}\) in \(\mathfrak{X}(M)\), define a covector field \(\widetilde{\Upsilon}(X_2,\ldots,X_{s+1})^\mathrm{F}\) in \(\mathfrak{X}^*(M)\) by

$$\widetilde{\Upsilon}(X_2,\ldots,X_{s+1})^\mathrm{F}(X_1)=\Upsilon(X_1,\ldots,X_{s+1})$$

for all vector fields \(X_1\) in \(\mathfrak{X}(M)\). Then

$$\mathfrak{S}_s(\widetilde{\Upsilon})(X_1,\ldots,X_{s+1})=\langle X_1,\widetilde{\Upsilon}(X_2,\ldots,X_{s+1})\rangle=\langle\widetilde{\Upsilon}(X_2,\ldots,X_{s+1}),X_1\rangle$$
$$=\widetilde{\Upsilon}(X_2,\ldots,X_{s+1})^\mathrm{F}(X_1)=\Upsilon(X_1,\ldots,X_{s+1}).$$

Since \(X_1,\ldots,X_{s+1}\) were arbitrary, \(\mathfrak{S}_s(\widetilde{\Upsilon})=\Upsilon\). Thus, \(\mathfrak{S}_s\) is surjective. □

Let us now define a map

$$\mathfrak{R}_s:\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}(M)^s,\mathfrak{X}(M))\longrightarrow\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}^*(M)\times\mathfrak{X}(M)^s,C^\infty(M)),$$

called the **representation map**, by

$$\mathfrak{R}_s(\Psi)(\omega,X_1,\ldots,X_s)=\omega(\Psi(X_1,\ldots,X_s)) \tag{19.5.1}$$

for all maps \(\Psi\) in \(\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}(M)^s,\mathfrak{X}(M))\), all covector fields \(\omega\) in \(\mathfrak{X}^*(M)\), and all vector fields \(X_1,\ldots,X_s\) in \(\mathfrak{X}(M)\). We observe that \(\mathfrak{R}_s\) is the smooth manifold counterpart of the map defined by (5.3.1). When \(s=1\), we denote

$$\mathfrak{R}_1\quad\text{by}\quad\mathfrak{R}$$

and obtain

$$\mathfrak{R}:\operatorname{Lin}_{C^\infty(M)}(\mathfrak{X}(M),\mathfrak{X}(M))\longrightarrow\operatorname{Mult}_{C^\infty(M)}(\mathfrak{X}^*(M)\times\mathfrak{X}(M),C^\infty(M)).$$

Then

$$\mathfrak{R}(\Psi)(\omega,X)=\omega(\Psi(X)) \tag{19.5.2}$$

for all maps \(\Psi\) in \(\operatorname{Lin}_{C^\infty(M)}(\mathfrak{X}(M),\mathfrak{X}(M))\), all covector fields \(\omega\) in \(\mathfrak{X}^*(M)\), and all vector fields \(X\) in \(\mathfrak{X}(M)\).
