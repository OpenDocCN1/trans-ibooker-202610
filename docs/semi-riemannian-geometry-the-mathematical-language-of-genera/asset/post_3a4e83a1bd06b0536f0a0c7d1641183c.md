
In ℝ₀³, with standard coordinates (x, y, z), this becomes

Lap(f) = ∂²f/∂x² + ∂²f/∂y² + ∂²f/∂z² = lap(f),

and in ℝ₁⁴, with standard coordinates (x, y, z, t), it is

Lap(f) = ∂²f/∂x² + ∂²f/∂y² + ∂²f/∂z² − ∂²f/∂t².

In the physics literature, Lap in the context of ℝ₁⁴ is usually denoted by □ (sometimes by □²) and called the d’Alembert operator.

## 20.8 Laplace–de Rham Operator

Let (M, 𝔤, 𝔒) be an oriented semi-Riemannian manifold. The Laplace–de Rham operator is the family of linear maps

Δ : Λˢ(M) ⟶ Λˢ(M)

defined for 1 ≤ s ≤ m by

Δ = dδ + δd;  (20.8.1)

that is,

Δ(ω) = dδ(ω) + δd(ω)

for all forms ω in Λˢ(M). Recall from Theorem 16.1.1(c) that d² = 0, and from Theorem 20.2.1(a) that δ² = 0. Thus,

(d + δ) ∘ (d + δ) = d² + dδ + δd + δ² = Δ,

which can be expressed as

Δ = (d + δ)².

The next result shows that, except for a sign, the Laplace–de Rham operator is a generalization of the Laplace operator.

## Theorem 20.8.1. If (M, 𝔤, 𝔒) is an oriented semi-Riemannian manifold and f is a function in C^∞(M), then

Lap(f) = −Δ(f).

Proof. We have

Lap(f) = Div(Grad(f))  [(20.7.1)]
= −δ(Grad(f)^♭)  [Th 20.4.3(b)]
= −δd(f)  [(20.3.2)]
= −(dδ + δd)(f)  [(20.2.2)]
= −Δ(f).  [(20.8.1)]

### 20.9 Divergence of Symmetric 2-Covariant Tensor Fields

Let (M,g) be a semi-Riemannian manifold, and let Σ(M) be the subspace of 𝒯⁰₂(M) consisting of symmetric (2-covariant) tensor fields. For example, g is in Σ(M). **Divergence of symmetric 2-covariant tensor fields** is the map

$$\operatorname{Div}:\Sigma(M)\longrightarrow \mathfrak{X}^*(M)$$

defined by

$$\operatorname{Div}(\mathcal{A})=C_{13}\circ\nabla(\mathcal{A})$$

for all tensor fields 𝒜 in Σ(M). Since ∇(𝒜) is in 𝒯⁰₃(M), C₁₃(∇(𝒜)) is in 𝒯⁰₁(M)=𝔛*(M), so the definition makes sense. We note in passing that by Theorem 19.3.1, ∇(g)=0, hence Div(g)=0.

**Theorem 20.9.1 (Orthonormal Frame Expression for Divergence).** Let (M,g) be a semi-Riemannian manifold with signature (ε₁,…,εₘ), let (E₁,…,Eₘ) be an orthonormal frame on an open set U in M, let 𝒜 be a symmetric tensor field in 𝒯⁰₂(M), and let X be a vector field in 𝔛(M). Then

$$\operatorname{Div}(\mathcal{A})(X)=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(X,E_i)=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(E_i,X)$$

on U.

*Proof.* We have

$$\begin{aligned}
\operatorname{Div}(\mathcal{A})(X)&=C_{13}(\nabla(\mathcal{A}))(X)\\
&=\sum_i\epsilon_i\nabla(\mathcal{A})(E_i,X,E_i)\qquad [\text{Th 19.6.2(a)}]\\
&=\sum_i\epsilon_i\nabla_{E_i}(\mathcal{A})(X,E_i),\qquad [(18.4.1)]
\end{aligned}$$

which proves the first equality. It is easily shown using (18.1.3) that since 𝒜 is symmetric, so is ∇_{E_i}(𝒜). The second equality now follows from the first. □

**Theorem 20.9.2.** If (M,g) is a semi-Riemannian manifold and f is a function in C^∞(M), then

$$\operatorname{Div}(fg)=d(f).$$

*Proof.* Let (ε₁,…,εₘ) be the signature of M, and let p be a point in M. By Theorem 19.3.7, there is an orthonormal frame (E₁,…,Eₘ) on a neighborhood U of p. Let X be a vector field in 𝔛(M), and let X=∑ᵢαⁱEᵢ on U, where the αⁱ are uniquely determined functions in C^∞(U). From the manifold version of Theorem 4.2.7,

$$X=\sum_i\epsilon_i\langle X,E_i\rangle E_i.\tag{20.9.1}$$

By Theorem 19.3.8,

$$\nabla_{E_i}(fg)=\nabla_{E_i}(g\otimes f)=g\otimes\nabla_{E_i}(f)=\nabla_{E_i}(f)g,$$

hence

$$\nabla_{E_i}(fg)(X,E_i)=\nabla_{E_i}(f)g(X,E_i)=\langle X,E_i\rangle\nabla_{E_i}(f). \tag{20.9.2}$$

Then

$$d(f)(X)=X(f) \qquad\text{[Th 15.4.5(b)]}$$

$$\qquad=\sum_i\varepsilon_i\langle X,E_i\rangle\nabla_{E_i}(f) \qquad\text{[(18.1.1), (20.9.1)]}$$

$$\qquad=\sum_i\varepsilon_i\nabla_{E_i}(fg)(X,E_i) \qquad\text{[(20.9.2)]}$$

$$\qquad=\operatorname{Div}(fg)(X). \qquad\text{[Th 20.9.1]}$$

Since X and p were arbitrary, the result follows.

For the second line, we have from parts (c) and (d) of Theorem 18.11.4 that
