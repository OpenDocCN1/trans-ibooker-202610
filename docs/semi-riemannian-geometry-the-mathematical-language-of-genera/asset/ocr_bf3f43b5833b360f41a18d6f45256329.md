We have ⟨v, w⟩ = 0; for if not, then p(t) takes both positive and negative values, which contradicts the semidefiniteness of b. Since w was arbitrary, v is in V⊥\{0}. Thus, Λ ⊆ V⊥\{0}.

The next result is just one of the many versions of the Cauchy–Schwarz inequality that arise in several areas of mathematics. We will see another, likely more familiar, variation in Section 4.6.

# Theorem 3.2.6 (Cauchy–Schwarz Inequality). If V is a vector space and b is a symmetric semidefinite bilinear function on V, then

⟨v, w⟩² ≤ ⟨v, v⟩⟨w, w⟩ (3.2.1)

for all vectors v, w in V.

Proof. The result is trivial if either v = 0 or w = 0, so suppose v, w ≠ 0. Let q be the quadratic function corresponding to b, and consider the polynomial p(t) : ℝ ⟶ ℝ defined by

p(t) = q(tv + w) = ⟨v, v⟩t² + 2⟨v, w⟩t + ⟨w, w⟩.

If either ⟨v, v⟩ or ⟨w, w⟩ = 0, that is, if either v or w is in Λ, then, by Theorem 3.2.5, ⟨v, w⟩ = 0, so (3.2.1) is satisfied. Now suppose ⟨v, v⟩, ⟨w, w⟩ ≠ 0. According to the quadratic formula, p(t) has the two (not necessarily distinct) roots

-2⟨v, w⟩ ± √[⟨v, w⟩² − ⟨v, v⟩⟨w, w⟩] / ⟨v, v⟩.

By assumption, b is semidefinite. Suppose b is positive semidefinite, in which case p(t) ≥ 0. If p(t) > 0 for all t in ℝ, then the graph of p(t) versus t does not intersect the t-axis. It follows that p(t) has two nonreal complex roots, which is equivalent to ⟨v, w⟩² − ⟨v, v⟩⟨w, w⟩ < 0. Thus, (3.2.1) is satisfied. If p(t₀) = 0 for some t₀ in ℝ, then the graph of p(t) versus t intersects the t-axis at the single point t₀. It follows that t₀ is a repeated root, which is equivalent to ⟨v, w⟩² − ⟨v, v⟩⟨w, w⟩ = 0. Once again, (3.2.1) is satisfied. This proves the positive semidefinite case. If b is negative semidefinite, then −b is positive semidefinite, and we again arrive at (3.2.1).
