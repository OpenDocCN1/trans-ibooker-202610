so that λ(a) = p₀ and λ(b) = λ₂(b). Then

f(λ₂(c)) = ∫_λ ω = ∫_{λ₁} ω + ∫_{λ₂} ω = f(λ₁(b)) + ∫_{λ₂} ω = f(λ₂(b)) + ∫_{λ₂} ω,

hence

∫_{λ₂} ω = f(λ₂(c)) − f(λ₂(b)) = ∫_{λ₂} d(f),

where the last equality follows from Theorem 16.8.2. Thus,

∫_{λ₂} [ω − d(f)] = 0.

It can be shown that since λ₂ was arbitrary, ω − d(f) must be the zero form; that is, ω = d(f).

# Theorem 16.9.3. Let M be a smooth manifold, and let ω be a covector field in 𝔛*(M). If ω is exact, then it is closed.

Proof. This follows from Theorem 16.1.1(c).

In light of Theorem 16.9.3, there are three possibilities for a covector field with respect to being exact or not, and closed or not: (i) exact (hence closed), (ii) closed and not exact, and (iii) not closed (hence not exact). The following examples illustrate each of these cases.

# Example 16.9.4. Let ω be the covector field in 𝔛*(ℝ²) given by

ω_{(r,s)} = s d(r) + r d(s).

Since ω = d(rs), it is exact.

# Example 16.9.5 (Punctured Plane). Let φ be the standard coordinate on [0,2π], and let (r,s) be standard coordinates on ℝ²\{(0,0)}, the punctured plane. Let λ(φ) : [0,2π] ⟶ ℝ²\{(0,0)} be the smooth curve given by λ(φ) = (cos(φ), sin(φ)), and consider the form

ω_{(r,s)} = − s/(r² + s²) d(r) + r/(r² + s²) d(s)

in Λ²(ℝ²\{(0,0)}). Using Theorem 16.9.1, it is easily shown that ω is closed. Setting (U, (xⁱ)) = ([0,2π], (φ)) and (V, (yʲ)) = (ℝ², (r,s)) in a generalization of Theorem 15.11.3 yields

λ*(ω)(φ) = [ (− s/(r² + s²) ∘ λ) ∂(r ∘ λ)/∂φ + ( r/(r² + s²) ∘ λ) ∂(s ∘ λ)/∂φ ] d(φ) = ( − sin(φ)/(cos²(φ)+sin²(φ)) ∂(cos(φ))/∂φ + cos(φ)/(cos²(φ)+sin²(φ)) ∂(sin(φ))/∂φ ) d(φ) = d(φ).
