# 8.5 Hodge Star

In this section, we define a map that assigns to a given multivector another multivector that “complements” the first. The methods that result add to our growing armamentarium of techniques for computing with multivectors.

**Theorem 8.5.1.** Let $(V,g,\mathcal{Q})$ be an oriented scalar product space of dimension $m$, let $\Omega_V$ be its volume multivector, and let $\eta$ be a multivector in $\Lambda^s(V)$, where $s\le m$. Then there is a unique multivector $\star(\eta)$ in $\Lambda^{m-s}(V)$ such that

$$\eta\wedge\zeta=\langle\star(\eta),\zeta\rangle^\Lambda\Omega_V$$

for all multivectors $\zeta$ in $\Lambda^{m-s}(V)$, where $\langle\cdot,\cdot\rangle^\Lambda$ is the scalar product defined in Section 7.5.

**Proof.** *Existence.* By Theorem 7.2.12(d), $(\Omega_V)$ is a basis for $\Lambda^m(V)$, so

$$\eta\wedge\zeta=f_\eta(\zeta)\,\Omega_V$$

for some real number $f_\eta(\zeta)$. The assignment $\zeta\mapsto f_\eta(\zeta)$ defines a function $f_\eta:\Lambda^{m-s}(V)\to\mathbb{R}$. Evidently, $f_\eta$ is linear, so $f_\eta$ is a multivector in $\Lambda^{m-s}(V)^*$. Recall the flat map and sharp map introduced at the end of Section 7.5:

$$F^\Lambda:\Lambda^{m-s}(V)\longrightarrow\Lambda^{m-s}(V)^*\qquad\text{and}\qquad S^\Lambda:\Lambda^{m-s}(V)^*\longrightarrow\Lambda^{m-s}(V).$$

Let us define $\star(\eta)=(f_\eta)^{S^\Lambda}$. Then $\star(\eta)$ is a multivector in $\Lambda^{m-s}(V)$ and $f_\eta=(\star(\eta))^{F^\Lambda}$. According to (7.5.12), $f_\eta(\zeta)=\langle\star(\eta),\zeta\rangle^\Lambda$, so

$$\eta\wedge\zeta=\langle\star(\eta),\zeta\rangle^\Lambda\Omega_V \tag{8.5.1}$$

for all multivectors $\zeta$ in $\Lambda^{m-s}(V)$. Thus, $\star(\eta)$ satisfies the desired property.

*Uniqueness.* Suppose $\zeta$ is a multivector in $\Lambda^{m-s}(V)$ satisfying the specified property; that is,

$$\eta\wedge\zeta=\langle\xi,\zeta\rangle^\Lambda\Omega_V \tag{8.5.2}$$

for all multivectors $\zeta$ in $\Lambda^{m-s}(V)$. Since $(\Omega_V)$ is a basis for $\Lambda^m(V)$, we have from (8.5.1) and (8.5.2) that $\langle\xi,\zeta\rangle^\Lambda=\langle\star(\eta),\zeta\rangle^\Lambda$, hence $\langle\xi-\star(\eta),\zeta\rangle^\Lambda=0$. Because $\zeta$ was arbitrary and, by Theorem 7.5.3(a), $\langle\cdot,\cdot\rangle^\Lambda$ is nondegenerate, $\xi-\star(\eta)=0$.

$$\star:\Lambda^s(V)\longrightarrow\Lambda^{m-s}(V)$$

$$\eta\longmapsto\star(\eta)$$
