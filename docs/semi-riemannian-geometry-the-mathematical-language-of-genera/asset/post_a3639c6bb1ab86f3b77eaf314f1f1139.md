
**Proof.** We prove the logically equivalent assertion: if $\gamma$ is not regular, then it is constant. Suppose $(d\gamma/dt)(t_0)=0$ for some point $t_0$ in $(a,b)$. Let $g(u):(a-t_0,b-t_0)\longrightarrow(a,b)$ be the diffeomorphism given by $g(u)=u+t_0$. Since $g$ is bijective, as $u$ varies over $(c,d)$, $g(u)$ varies over $(a,b)$. Because $\gamma$ is a geodesic, it follows from Theorem 18.3.3(b) that

$$\frac{\nabla}{du}\left(\frac{d(\gamma\circ g)}{du}\right)(u)=\frac{d^2g}{du^2}(u)\frac{d\gamma}{dt}(g(u))=0$$

for all $u$ in $(c,d)$. Thus, $\gamma\circ g$ is a geodesic. Let $p=\gamma(t_0)$, so that $\gamma\circ g(0)=p$. By Theorem 14.4.5,

$$\frac{d(\gamma\circ g)}{du}(0)=\frac{dg}{du}(0)\frac{d\gamma}{dt}(g(0))=\frac{d\gamma}{dt}(t_0)=0.$$

We have from Theorem 18.8.2(b) that $\gamma\circ g$ is the restriction of $\gamma_{p,0}$ to $(a-t_0,b-t_0)$. By Theorem 18.8.3, $\gamma_{p,0}$ has constant value $p$, and therefore, so does $\gamma$.

## **Theorem 18.8.5.**

Let $(M,\nabla)$ be a smooth manifold with a connection, let $\gamma(t):(a,b)\longrightarrow M$ be a nonconstant geodesic, and let $g(u):(c,d)\longrightarrow(a,b)$ be a diffeomorphism. Then $\gamma\circ g(u):(c,d)\longrightarrow(a,b)$ is a geodesic if and only if $g$ is linear.

**Proof.** Since $\gamma$ is a geodesic, by Theorem 18.3.3(b),

$$\frac{\nabla}{du}\left(\frac{d(\gamma\circ g)}{du}\right)(u)=\frac{d^2g}{du^2}(u)\frac{d\gamma}{dt}(g(u)),$$

and because $\gamma$ is nonconstant, by Theorem 18.8.4, $(d\gamma/dt)(g(u))\ne0$ for all $u$ in $(c,d)$. Since $g$ is bijective, as $u$ varies over $(c,d)$, $g(u)$ varies over $(a,b)$. Thus,

$$\begin{aligned}
\gamma\circ g\text{ is a geodesic}
&\iff \frac{\nabla}{du}\left(\frac{d(\gamma\circ g)}{du}\right)=0\\
&\iff \frac{d^2g}{du^2}=0\\
&\iff g\text{ is linear.}
\end{aligned}$$

## **Theorem 18.8.6.**

Let $(M,\nabla)$ be a smooth manifold with a connection, let $p$ be a point in $M$, and let $v$ be a vector in $T_p(M)$. Let $\gamma_{p,v}(t):(a,b)\longrightarrow M$ be the maximal geodesic with starting point $p$ and initial velocity $v$, and let $\epsilon>0$ be a real number. Then the maximal geodesic with starting point $p$ and initial velocity $\epsilon v$ is $\gamma_{p,\epsilon v}(t):(a/\epsilon,b/\epsilon)\longrightarrow M$, where

$$\gamma_{p,\epsilon v}(t)=\gamma_{p,v}(\epsilon t)$$

for all $t$ in $(a/\epsilon,b/\epsilon)$.

Proof. Consider the diffeomorphism g(u) : (a/ε, b/ε) ⟶ (a, b) given by g(u) = εu. By Theorem 18.8.5, γ_{p,v} ∘ g(u) : (a/ε, b/ε) ⟶ M is a geodesic. Since γ_{p,v} is maximal, so is γ_{p,v} ∘ g, otherwise γ_{p,v} could be extended. We have from Theorem 18.8.2(a) that γ_{p,v} ∘ g(0) = γ_{p,v}(0) = p, and from Theorem 14.4.5 and Theorem 18.8.2(a) that

```
d(γ_{p,v} ∘ g)/du (0) = dg/du (0) dγ_{p,v}/dt (g(0)) = ε dγ_{p,v}/dt (0) = εv.
```

It follows from Theorem 18.8.2 that γ_{p,εv} = γ_{p,v} ∘ g. Thus, γ_{p,εv}(u) = γ_{p,v}(εu) for all u in (a/ε, b/ε).

### Example 18.8.7 (Smooth 2-Manifold).

```
d²(x¹ ∘ λ)/dt² (t) + (d(x¹ ∘ λ)/dt (t))² Γ¹₁₁(λ(t)) + 2 d(x¹ ∘ λ)/dt (t) d(x² ∘ λ)/dt (t) Γ¹₁₂(λ(t)) + (d(x² ∘ λ)/dt (t))² Γ¹₂₂(λ(t)) = 0
```

and

```
d²(x² ∘ λ)/dt² (t) + (d(x¹ ∘ λ)/dt (t))² Γ²₁₁(λ(t)) + 2 d(x¹ ∘ λ)/dt (t) d(x² ∘ λ)/dt (t) Γ²₁₂(λ(t)) + (d(x² ∘ λ)/dt (t))² Γ²₂₂(λ(t)) = 0.
```

Viewing a regular surface as a smooth 2-manifold with the connection defined in Example 18.1.1, we have from Example 18.6.1 that the connection is symmetric. Thus, the above geodesic equations apply.

### Example 18.8.8 (Pln).

Let us view the regular surface Pln, discussed in Section 13.1, as a smooth 2-manifold with the connection defined in Example 18.1.1. Suppose γ(t) = (γ¹, γ²) : ℝ ⟶ ℝ² is a geodesic. Since the Christoffel symbols have constant value 0, by Theorem 18.8.1, the geodesic equations are (d²γᵏ/dt²)(t) = 0 for k = 1,2. These have the solutions γᵏ(t) = aᵏ + bᵏ t for any choice of real numbers a¹, b¹, a², b². Thus,

```
γ(t) = (a¹, a²) + t(b¹, b²).
```

Not surprisingly, the image of γ is a straight line. This demonstrates that the maximal geodesics in Pln with a given starting point are the straight lines through that point.

### Example 18.8.9 (Cyl).

Let us view the regular surface Cyl, discussed in Section 13.2, as a smooth 2-manifold with the connection defined in Example 18.1.1. Suppose γ(u) : ℝ ⟶ Cyl is a geodesic parametrized by

```
γ(u) = (cos(φ(u)), sin(φ(u)), t(u)).
```

We have from Example 18.8.7 that the geodesic equations are

```
d²t/du²(u) = 0      and      d²φ/du²(u) = 0,
```

These have the solutions t(u) = a¹ + b¹ u and φ(u) = a² + b² u for any choice of real numbers a¹, b¹, a², b². Thus,

```
γ(u) = (cos(a¹ + b¹ u), sin(a¹ + b¹ u), a² + b² u).
```

If b¹ = 0, then the image of γ is a straight line parallel to the z-axis; and if b² = 0, then the image of γ is a circle lying in a plane parallel to the xy-plane. Otherwise, the image of γ is a helix. This shows that the maximal geodesics in Cyl with a given starting point are the straight lines, circles, and helices through that point. Whether it is one or another is determined by the initial velocity of the maximal geodesic.

### Example 18.8.10 (S²).

Let us view the regular surface S², discussed in Section 13.4, as a smooth 2-manifold with the connection defined in Example 18.1.1. Continuing with Example 18.5.4, suppose γ(t) : (a, b) ⟶ S² is a geodesic. Setting α¹ = dθ/dt and α² = dφ/dt in (18.5.3) gives the geodesic equations

```
d²θ/dt²(t) − cos(θ(t)) sin(θ(t)) (dφ/dt(t))² = 0

d²φ/dt²(t) + 2 cot(θ(t)) dθ/dt(t) dφ/dt(t) = 0.   (18.8.1)
```

For ease of computation, we view S² as what we will later refer to as a Riemannian 2-manifold. In the present context, this means treating S² as a regular surface in ℝ₀³ and permitting computations that involve the Euclidean inner product.

Setting

```
μ = (μ¹, μ²) = (θ, φ)   (18.8.2)
```

in (12.5.2), we have from Theorem 12.5.2(d) that

```
⟨dγ/dt(t), dγ/dt(t)⟩ = (dθ/dt(t))² + sin²(θ(t)) (dφ/dt(t))².
```

By Theorem 19.9.1(a), γ has constant speed, say, c. The preceding identity then becomes

```
(dθ/dt(t))² + sin²(θ(t)) (dφ/dt(t))² = c².   (18.8.3)
```

Using (18.8.1) and (18.8.3), a lengthy but straightforward computation yields

```
\frac{d^2\gamma}{dt^2}(t) + c^2\gamma(t) = 0. \tag{18.8.4}
```

Alternatively, we have from Theorem 12.5.2(c), the Christoffel symbol results in Section 13.4, and (18.8.2) that

```
\frac{d^2\gamma}{dt^2}(t) = \left[\frac{d^2\theta}{dt}(t) - \cos(\theta(t))\sin(\theta(t))\left(\frac{d\phi}{dt}(t)\right)^2\right] H_{1\mid(\theta(t),\phi(t))} + \left[\frac{d^2\phi}{dt}(t) + 2\cot(\theta(t))\frac{d\theta}{dt}\frac{d\phi}{dt}\right] H_{2\mid(\theta(t),\phi(t))} - \left[\left(\frac{d\theta}{dt}(t)\right)^2 + \sin^2(\theta(t))\left(\frac{d\phi}{dt}(t)\right)^2\right] G_{(\theta(t),\phi(t))},
```

Substituting from (18.8.1)–(18.8.3) gives $(d^2\gamma/dt^2)(t) + c^2 G_{(\theta(t),\phi(t))} = 0$. It follows from Theorem 12.7.3(a) and a remark at the end of Section 13.4 that

```
G_{(\theta(t),\phi(t))} = \mathcal{N}_{\varphi(\theta(t),\phi(t))} = \varphi(\theta(t),\phi(t)) = \gamma(t),
```

so we again arrive at (18.8.4).

The solution of (18.8.4) is

```
\gamma(t) = \cos(ct)v + \sin(ct)w, \tag{18.8.5}
```

for some vectors $v, w$ in $\mathbb{R}^3$ as yet to be determined. If $c = 0$, then $\gamma$ has constant value $\gamma(0) = v$. We exclude this case and suppose $\pi/(2c)$ is in $(a,b)$. Then

```
\gamma(0) = v, \quad \gamma\left(\frac{\pi}{2c}\right) = w, \quad \text{and} \quad \frac{d\gamma}{dt}(0) = c w.
```

It follows from Theorem 18.8.2 that $\gamma$ is the restriction of $\gamma_{v,cw}$ to $(a,b)$, and from (18.8.5) that the image of $\gamma$ lies in the intersection of $\mathcal{S}^2$ and the subspace of $\mathbb{R}^3_0$ spanned by $v$ and $w$. Thus, the image of $\gamma$ is all or a portion of a great circle. More generally, the maximal geodesics in $\mathcal{S}^2$ with a given starting point are the great circles through that point.
