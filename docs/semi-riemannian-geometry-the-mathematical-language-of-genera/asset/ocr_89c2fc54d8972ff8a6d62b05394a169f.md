# 20.3 Gradient

Let $(M,\mathfrak{g})$ be a semi-Riemannian manifold. **Gradient** is the map

```
$$\operatorname{Grad}: C^\infty(M)\longrightarrow \mathfrak{X}(M)$$
```

defined by

```
$$\operatorname{Grad}(f)=d(f)^\sharp,$$
```

or equivalently, by

```
$$\operatorname{Grad}(f)^\flat=d(f)$$
```

for all functions $f$ in $C^\infty(M)$. We refer to $\operatorname{Grad}(f)$ as the **gradient of $f$**.

**Theorem 20.3.1.** Let $(M,\mathfrak{g})$ be a semi-Riemannian manifold, let $X$ be a vector field in $\mathfrak{X}(M)$, and let $f$ be a function in $C^\infty(M)$. Then:

```
$$\langle\operatorname{Grad}(f),X\rangle=d(f)(X)=X(f).$$
```

*Proof.* We have

```
$$\begin{aligned}
\langle\operatorname{Grad}(f),X\rangle&=\operatorname{Grad}(f)^\flat(X)\quad [(19.4.1)]\\
&=d(f)(X)\quad [(20.3.2)]\\
&=X(f).\quad [\mathrm{Th}\ 15.4.5(b)]
\end{aligned}$$
```

**Theorem 20.3.2 (Local Coordinate Expression for Gradient).** If $(M,\mathfrak{g})$ is a semi-Riemannian $m$-manifold and $f$ is a function in $C^\infty(M)$, then, in local coordinates, the components of $\operatorname{Grad}(f)$ are

```
$$\operatorname{Grad}(f)^i=\sum_j g^{ij}\frac{\partial f}{\partial x^j}$$
```

for $i=1,\ldots,m$.
