
Proof. Setting ω = d(f) and ξ = Ω_M in Theorem 16.5.1(e) gives

d(f) ∧ i_X(Ω_M) = i_X(d(f)) ∧ Ω_M − i_X(d(f) ∧ Ω_M) = X(f) Ω_M [(16.5.2), Th 7.2.12(b)] = ⟨Grad(f), X⟩ Ω_M, [Th 20.3.1]

hence

Div(f X) Ω_M = d(i_{f X}(Ω_M)) [Th 20.4.3(a)] = d(f i_X(Ω_M)) [Th 16.5.1(b)] = d(f) ∧ i_X(Ω_M) + f d(i_X(Ω_M)) [(16.1.1)] = [⟨Grad(f), X⟩ + f Div(X)]Ω_M. [Th 20.4.3(a)]

Since (Ω_M) is a basis for Λ^m(M), the result follows.

The preceding result has a clear resemblance to Theorem 10.6.1(b).

## Theorem 20.4.5 (Divergence Theorem for Semi-Riemannian Manifolds). Let (M, g, 𝔒) be a compact oriented semi-Riemannian manifold with boundary, let Ω_M be its volume form, and let X be a vector field in 𝔛(M). Then ∫_M Div(X) Ω_M = ∫_{∂M} i_X(Ω_M).

Proof. We have ∫_M Div(X) Ω_M = ∫_M d(i_X(Ω_M)) [Th 20.4.3(a)] = ∫_{∂M} i_X(Ω_M). [Th 17.4.1]

## Example 20.4.6 (ℝ_ν^m). Let (r^1, …, r^m), (∂/∂r^1, …, ∂/∂r^m), and (ε_1, …, ε_m) be the standard coordinates, corresponding standard coordinate frame, and signature of ℝ_ν^m, respectively. From Example 15.1.6, (∂/∂r^1, …, ∂/∂r^m) = (e_1, …, e_m), where (e_1, …, e_m) is the standard basis for ℝ_ν^m. Let X = (α^1, …, α^m) = Σ_i α^i e_i = Σ_i α^i ∂/∂r^i be a vector field in 𝔛(ℝ_ν^m). It follows from (18.2.2), Theorem 19.3.5, and Theorem 20.4.1 that Div(X) = Σ_i ∂α^i/∂r^i.

In ℝ_0^3, with standard coordinates (x, y, z), this becomes Div(X) = ∂α^1/∂x + ∂α^2/∂y + ∂α^3/∂z = div(X),

and in ℝ_1^4, with standard coordinates (x, y, z, t), it becomes Div(X) = ∂α^1/∂x + ∂α^2/∂y + ∂α^3/∂z + ∂α^4/∂t.

## 20.5 Curl

Let (M,g,𝒟) be an oriented semi-Riemannian 3-manifold of index ν, and let Ω_M be its volume form. Curl is the map

\[\operatorname{Curl}:\mathfrak{X}(M)\longrightarrow\mathfrak{X}(M)\]

defined by

\[\operatorname{Curl}(X)^\mathrm{F}=\star d(X^\mathrm{F}) \tag{20.5.1}\]

for all vector fields X in 𝔛(M). Since X^F is a covector field in 𝔛^*(M)=Λ^1(M), it follows that d(X^F) is a form in Λ^2(M), hence ⋆ d(X^F) is a vector field in Λ^1(M), so the definition makes sense. We refer to Curl(X) as the curl of X.

## Theorem 20.5.1. With the above setup,

\[i_{\operatorname{Curl}(X)}(\Omega_M)=d(X^\mathrm{F}).\]

Proof. We have

\[i_{\operatorname{Curl}(X)}(\Omega_M)=(-1)^\nu\star(\operatorname{Curl}(X)^\mathrm{F})\qquad [\mathrm{Th\ 20.1.2}]\]
\[\phantom{i_{\operatorname{Curl}(X)}(\Omega_M)}=(-1)^\nu\star^2d(X^\mathrm{F}).\qquad [(20.5.1)]\]

Since d(X^F) is a form in Λ^2(M), setting m=3 and s=2 in Theorem 20.1.1(c) yields

\[\star^2(d(X^\mathrm{F}))=(-1)^\nu d(X^\mathrm{F}).\]

The result follows.

Despite the unfamiliar appearance of definition (20.5.1), the following example shows that the Curl and classical curl operators are identical in ℝ^3_0.

## Example 20.5.2.

Let (x,y,z) and (d(x),d(y),d(z)) be the standard coordinates and corresponding standard dual coordinate frame on ℝ^3_0, respectively, and let X=(α^1,α^2,α^3) be a vector field in 𝔛(ℝ^3_0). From the manifold version of Theorem 3.3.2,

\[X^\mathrm{F}=\alpha^1d(x)+\alpha^2d(y)+\alpha^3d(z).\]

Then (16.1.2) gives

\[
d(X^\mathrm{F})=\left(\frac{\partial\alpha^3}{\partial y}-\frac{\partial\alpha^2}{\partial z}\right)d(y)\wedge d(z)+\left(\frac{\partial\alpha^1}{\partial z}-\frac{\partial\alpha^3}{\partial x}\right)d(z)\wedge d(x)
\]
\[
\qquad+\left(\frac{\partial\alpha^2}{\partial x}-\frac{\partial\alpha^1}{\partial y}\right)d(x)\wedge d(y).
\]

hence

Curl(X)^F = *d(X^F)
= (∂α³/∂y - ∂α²/∂z) * (d(y) ∧ d(z)) + (∂α¹/∂z - ∂α³/∂x) * (d(z) ∧ d(x))
+ (∂α²/∂x - ∂α¹/∂y) * (d(x) ∧ d(y))
= (∂α³/∂y - ∂α²/∂z) d(x) + (∂α¹/∂z - ∂α³/∂x) d(y)
+ (∂α²/∂x - ∂α¹/∂y) d(z)
= (∂α³/∂y - ∂α²/∂z, ∂α¹/∂z - ∂α³/∂x, ∂α²/∂x - ∂α¹/∂y)^F
= curl(X)^F,

where the third equality follows from Example 8.5.4, the fourth equality from the manifold version of Theorem 3.3.2, and the last equality from Table 10.6.1. Thus, Curl(X) = curl(X).

## 20.6 Hesse Operator

Let (M, 𝔤) be a semi-Riemannian manifold. The Hesse operator is the map

Hess : C^∞(M) ⟶ T₂⁰(M)

defined by

Hess(f) = ∇²(f)  (20.6.1)

for all functions f in C^∞(M), where we denote

∇ ∘ ∇    by    ∇².

We refer to Hess(f) as the Hessian of f.

## Theorem 20.6.1. Let (M, 𝔤) be a semi-Riemannian m-manifold, let f be a function in C^∞(M), and let X, Y be vector fields in 𝔛(M). Then:

- (a)

Hess(f)(X, Y) = X(Y(f)) - ∇_X(Y)(f)
= ∇_X(∇_Y(f)) - ∇_{∇_X(Y)}(f)
= ⟨∇_X(Grad(f)), Y⟩.

- (b) Hess(f) is symmetric.

Proof. (a): The first two equalities follow from (18.4.3). We have

X(Y(f)) = X(⟨Grad(f), Y⟩)  [Th 20.3.1]
= ⟨∇_X(Grad(f)), Y⟩ + ⟨Grad(f), ∇_X(Y)⟩  [(19.3.1)]
= ⟨∇_X(Grad(f)), Y⟩ + ∇_X(Y)(f).  [Th 20.3.1]

The third equality now follows from the first.

(b): Since the Levi-Civita connection ∇ is symmetric,

∇_X(Y)(f) − ∇_Y(X)(f) = [X,Y](f) = X(Y(f)) − Y(X(f)),

so

Hess(f)(X, Y) = X(Y(f)) − ∇_X(Y)(f)  [part(a)]
= Y(X(f)) − ∇_Y(X)(f)
= Hess(f)(Y, X).  [part(a)]

## Theorem 20.6.2 (Local Coordinate Expression for Hesse Operator). If (M, g) is a semi-Riemannian m-manifold and f is a function in C^∞(M), then, in local coordinates, the components of Hess(f) are

Hess(f)_{ij} = ∂²f/∂x^i∂x^j − Σ_k Γ^k_{ij} ∂f/∂x^k

for i, j = 1, …, m.

Proof. We have

Hess(f)_{ij} = Hess(f)(∂/∂x^i, ∂/∂x^j)
= ∂/∂x^i (∂f/∂x^j) − ∇_{∂/∂x^i}(∂/∂x^j)(f)  [Th 20.6.1(a)]
= ∂²f/∂x^i∂x^j − Σ_k Γ^k_{ij} ∂f/∂x^k.  [(18.2.1)]

## Example 20.6.3 (ℝ^m_ν). Let (r¹, …, r^m) and (∂/∂r¹, …, ∂/∂r^m) be the standard coordinates and corresponding standard coordinate frame on ℝ^m_ν, respectively. It follows from Theorem 19.3.5 and Theorem 20.6.2 that

Hess(f)_{ij} = ∂²f/∂r^i∂r^j

for i, j = 1, …, m.

## 20.7 Laplace Operator

Let $(M,\mathfrak{g})$ be a semi-Riemannian manifold. The Laplace operator is the map

Lap : $C^{\infty}(M) \longrightarrow C^{\infty}(M)$

defined by

Lap$(f) = \text{Div} \circ \text{Grad}(f)$ (20.7.1)

for all functions $f$ in $C^{\infty}(M)$. We refer to Lap$(f)$ as the Laplacian of $f$.

## Theorem 20.7.1. If $(M,\mathfrak{g})$ is a semi-Riemannian manifold and $f$ is a function in $C^{\infty}(M)$, then

Lap$(f) = C_{12} \circ \text{Hess}(f)$.

Proof. We have

Lap$(f) = \text{Div} \circ \text{Grad}(f)$
$= C_{1}^{1} \circ \nabla \circ S_{1}^{1}(d(f))$ [mv Ex 6.3.1, (20.3.1), (20.4.1)]
$= C_{1}^{1} \circ S_{1}^{1} \circ \nabla(\nabla(f))$ [Th 18.4.3, Th 19.6.3]
$= C_{1}^{1} \circ S_{1}^{1} \circ \nabla^{2}(f)$
$= C_{12} \circ \text{Hess}(f)$. [(19.6.3), (20.6.1)]

## Theorem 20.7.2 (Orthonormal Frame Expression for Laplace Operator). Let $(M,\mathfrak{g})$ be a semi-Riemannian manifold with signature $(\varepsilon_{1},...,\varepsilon_{m})$, let $f$ be a function in $C^{\infty}(M)$, and let $(E_{1},...,E_{m})$ be an orthonormal frame on an open set $U$ in $M$. Then

Lap$(f) = \sum_{i} \varepsilon_{i} \text{Hess}(f)(E_{i},E_{i})$

on $U$.

Proof. This follows from Theorem 19.6.2(b) and Theorem 20.7.1.

## Example 20.7.3 ($\mathbb{R}_{\nu}^{m}$). Let $(r^{1},...,r^{m})$, $(\partial/\partial r^{1},...,\partial/\partial r^{m})$, and $(\varepsilon_{1},...,\varepsilon_{m})$ be the standard coordinates, corresponding standard coordinate frame, and signature of $\mathbb{R}_{\nu}^{m}$, respectively. We have from Example 20.6.3 that

Hess$(f)\left(\frac{\partial}{\partial r^{i}},\frac{\partial}{\partial r^{j}}\right) = \text{Hess}(f)_{ij} = \frac{\partial^{2} f}{\partial r^{i}\partial r^{j}}$,

and from Example 15.1.6 that $(\partial/\partial r^{1},...,\partial/\partial r^{m}) = (e_{1},...,e_{m})$, where $(e_{1},...,e_{m})$ is the standard basis for $\mathbb{R}_{\nu}^{m}$. Thus, $(\partial/\partial r^{1},...,\partial/\partial r^{m})$ is an orthonormal frame on $\mathbb{R}_{\nu}^{m}$. Then Theorem 20.7.2 gives

Lap$(f) = \sum_{i} \varepsilon_{i} \frac{\partial^{2} f}{\partial (r^{i})^{2}}$.
