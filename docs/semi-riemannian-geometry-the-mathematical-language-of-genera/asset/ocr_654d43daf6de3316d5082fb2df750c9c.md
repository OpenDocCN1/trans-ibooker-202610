# 16.2  Tensor Derivations

A tensor derivation on a smooth manifold $M$ is a family $\mathbf{D}$ of linear maps

$$\mathbf{D}^{r}_{s}:\mathcal{T}^{r}_{s}(M)\longrightarrow \mathcal{T}^{r}_{s}(M)$$

defined for $r,s\geq 0$ such that for all tensor fields $\mathcal{A}$ in $\mathcal{T}^{r}_{s}(M)$ and $\mathcal{B}$ in $\mathcal{T}^{r'}_{s'}(M)$, and all $(k,l)$-contractions $C^k_l$:

**[D1]**
$$\mathbf{D}^{r+r'}_{s+s'}(\mathcal{A}\otimes\mathcal{B})=\mathbf{D}^{r}_{s}(\mathcal{A})\otimes\mathcal{B}+\mathcal{A}\otimes\mathbf{D}^{r'}_{s'}(\mathcal{B}).$$

**[D2]**
$$C^k_l\circ\mathbf{D}^{r}_{s}(\mathcal{A})=\mathbf{D}^{r-1}_{s-1}\circ C^k_l(\mathcal{A}).$$

[D1] is a type of product rule for tensor fields, and [D2] says that “contraction commutes with tensor derivation”.

**Theorem 16.2.1.** Let $M$ be a smooth manifold, let $\mathbf{D}$ be a tensor derivation on $M$, and let $\mathcal{A}_i$ be a tensor field in $\mathcal{T}^{r_i}_{s_i}(M)$ for $i=1,\ldots,k$. Then

$$\mathbf{D}^{r_1+\cdots+r_k}_{s_1+\cdots+s_k}(\mathcal{A}_1\otimes\cdots\otimes\mathcal{A}_k)=\sum_{i=1}^{k}\mathcal{A}_1\otimes\cdots\otimes\mathbf{D}^{r_i}_{s_i}(\mathcal{A}_i)\otimes\cdots\otimes\mathcal{A}_k.$$

*Proof.* This follows from [D1] using an inductive argument.

**Theorem 16.2.2.** Let $M$ be a smooth manifold, let $\mathbf{D}$ be a tensor derivation on $M$, let $f$ be a function in $C^\infty(M)$, and let $\mathcal{A}$ be a tensor field in $\mathcal{T}^{r}_{s}(M)$. Then:

(a) $\mathbf{D}^{0}_{0}$ is a vector field in $\mathfrak{X}(M)$.

(b) $\mathbf{D}^{r}_{s}(f\mathcal{A})=\mathbf{D}^{0}_{0}(f)\mathcal{A}+f\mathbf{D}^{r}_{s}(\mathcal{A})$.

*Proof.* (a): For functions $f,g$ in $C^\infty(M)=\mathcal{T}^{0}_{0}(M)$, we have from [D1] that

$$\mathbf{D}^{0}_{0}(fg)=f\mathbf{D}^{0}_{0}(g)+g\mathbf{D}^{0}_{0}(f).$$

Thus, $\mathbf{D}^{0}_{0}$ is a derivation on $C^\infty(M)$. The result now follows from the identification given by Theorem 15.2.1.

(b): Since $f$ is a function in $C^\infty(M)=\mathcal{T}^{0}_{0}(M)$, so is $\mathbf{D}^{0}_{0}(f)$. By definition, $f\otimes\mathcal{A}=f\mathcal{A}$ and $\mathbf{D}^{0}_{0}(f)\otimes\mathcal{A}=\mathbf{D}^{0}_{0}(f)\mathcal{A}$. Then [D1] gives

$$\mathbf{D}^{r}_{s}(f\mathcal{A})=\mathbf{D}^{0}_{0}(f)\otimes\mathcal{A}+f\otimes\mathbf{D}^{r}_{s}(\mathcal{A})=\mathbf{D}^{0}_{0}(f)\mathcal{A}+f\mathbf{D}^{r}_{s}(\mathcal{A}).$$
