Thus, $d_p(\mathcal{N})$ is a linear map from $T_p(M)$ to itself.

For each point $p$ in $M$, the **Weingarten map at $p$** is denoted by

$\mathcal{W}_p : T_p(M) \longrightarrow T_p(M)$

and defined by

$\mathcal{W}_p = -d_p(\mathcal{N}).$  (12.8.1)

For all vectors $v$ in $T_p(M)$, we have from (11.6.1) that

$\mathcal{W}_p(v) = -\frac{d(\mathcal{N}\circ\lambda)}{dt}(t_0),$  (12.8.2)

where $\lambda(t) : (a,b) \longrightarrow M$ is any smooth curve such that $\lambda(t_0)=p$ and $(d\lambda/dt)(t_0)=v$ for some $t_0$ in $(a,b)$. The **Weingarten map** is the linear map

$\mathcal{W} : \mathfrak{X}(M) \longrightarrow \mathfrak{X}(M)$

defined by

$\mathcal{W}(X)_p = \mathcal{W}_p(X_p)$  (12.8.3)

for all vector fields $X$ in $\mathfrak{X}(M)$ and all $p$ in $M$.

Let $(U,\varphi)$ be a chart in $\mathfrak{A}$, let $\mathcal{H}=(H_1,H_2)$ be the corresponding coordinate frame, and let $q$ be a point in $U$. The vector $\mathcal{W}_p(H_j|_q)$ can be expressed as

$\mathcal{W}_p(H_j|_q)=\sum_i \mathfrak{w}_j^i(q)H_i|_q,$  (12.8.4)

where the $\mathfrak{w}_j^i$ are uniquely determined functions in $C^\infty(U)$. We then have from (2.2.2) and (2.2.3) that

$[\mathcal{W}_p]_{\mathcal{H}_q}=\begin{bmatrix}\mathfrak{w}_1^1(q)&\mathfrak{w}_1^2(q)\\\mathfrak{w}_2^1(q)&\mathfrak{w}_2^2(q)\end{bmatrix}.$  (12.8.5)

# **Theorem 12.8.1.** *If $(M,\mathfrak{g},\mathfrak{A},\mathfrak{O})$ is an oriented regular surface in $\mathbb{R}_\nu^3$ and $X$ is a vector field in $\mathfrak{X}(M)$, then*

$\mathcal{W}(X) = -D_X(\mathcal{N}).$

*Proof.* Let $p$ be a point in $M$, and let $\lambda(t) : (a,b) \longrightarrow M$ be a smooth curve such that $\lambda(t_0)=p$ and $(d\lambda/dt)(t_0)=X_p$ for some $t_0$ in $(a,b)$. Then

$-D_X(\mathcal{N})_p = -\frac{d(\mathcal{N}\circ\lambda)}{dt}(t_0)\quad[(12.3.4)]$

$= \mathcal{W}_p(X_p)\quad[(12.8.2)]$

$= \mathcal{W}(X)_p.\quad[(12.8.3)]$

Since $p$ was arbitrary, the result follows.
