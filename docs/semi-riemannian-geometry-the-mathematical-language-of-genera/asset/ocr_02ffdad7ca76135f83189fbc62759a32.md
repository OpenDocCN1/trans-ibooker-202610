2-dimensional, by Theorem 14.6.2, $\mathcal{N}$ is a local diffeomorphism at $p$. Taking $\varepsilon$ to be smaller if necessary, it follows that $(B_\varepsilon,\mathcal{N}\circ\varphi|_{B_\varepsilon})$ is a chart on $S^2$. See Figure 12.8.2. We have from Example 19.10.3 that

$$\operatorname{area}(\varphi(B_\varepsilon))=\iint_{B_\varepsilon}\|H_1\times H_2\|\,dr^1dr^2.$$

and

$$\begin{aligned}
\operatorname{area}(\mathcal{N}\circ\varphi(B_\varepsilon))
&=\iint_{B_\varepsilon}\left\|\frac{\partial(\mathcal{N}\circ\varphi)}{\partial r^1}\times\frac{\partial(\mathcal{N}\circ\varphi)}{\partial r^2}\right\|\,dr^1dr^2\\
&=\iint_{B_\varepsilon}\|\mathcal{W}(H_1)\times\mathcal{W}(H_2)\|\,dr^1dr^2.\qquad [\text{(12.8.10)}]\\
&=\iint_{B_\varepsilon}|\det(\mathcal{W})|\|H_1\times H_2\|\,dr^1dr^2.\qquad [\text{Th 8.4.7}]
\end{aligned}$$

It can be shown using Theorem 10.5.6 that

$$\lim_{\varepsilon\to0}\frac{\operatorname{area}(\mathcal{N}\circ\varphi(B_\varepsilon))}{\operatorname{area}(\varphi(B_\varepsilon))}=\lim_{\varepsilon\to0}\frac{\iint_{B_\varepsilon}|\det(\mathcal{W})|\|H_1\times H_2\|\,dr^1dr^2}{\iint_{B_\varepsilon}\|H_1\times H_2\|\,dr^1dr^2}=|\det(\mathcal{W}_p)|=|\mathcal{K}(p)|.$$
