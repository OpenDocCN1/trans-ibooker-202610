# Theorem 15.9.1. If M, N, and P are smooth manifolds, and F : M ⟶ N and G : N ⟶ P are diffeomorphisms, then

(G ∘ F)_• = G_• ∘ F_•.

Proof. For a function f in C^∞(M), we have

(G ∘ F)_•(f) = f ∘ (G ∘ F)^{-1} = (f ∘ F^{-1}) ∘ G^{-1} = F_•(f) ∘ G^{-1}

= G_•(F_•(f)) = (G_• ∘ F_•)(f).

Since f was arbitrary, the result follows.

Let M and N be smooth manifolds, and let F : M ⟶ N be a smooth map (but not necessarily a diffeomorphism). Pullback by F (for functions) is the map

F^• : C^∞(N) ⟶ C^∞(M)

defined by

F^•(g) = g ∘ F

(15.9.2)

for all functions g in C^∞(N).

# Theorem 15.9.2. If M, N, and P are smooth manifolds, and F : M ⟶ N and G : N ⟶ P are smooth maps, then

(G ∘ F)^• = F^• ∘ G^•.

Proof. For a function g in C^∞(P), we have

(G ∘ F)^•(g) = (g ∘ G) ∘ F = G^•(g) ∘ F = F^•(G^•(g)) = (F^• ∘ G^•)(g).

Since g was arbitrary, the result follows.

# Theorem 15.9.3. If M is a smooth manifold and F : M ⟶ N is a diffeomorphism, then:

+   (a) F^• is bijective, with inverse (F^•)^{-1} = (F^{-1})^• = F_•.
+   (b) F_• is bijective, with inverse (F_•)^{-1} = (F^{-1})_• = F^•.

Proof. (a): By Theorem 15.9.2,

id_{C^∞(M)} = (id_M)^• = (F^{-1} ∘ F)^• = F^• ∘ (F^{-1})^•

and

id_{C^∞(N)} = (id_N)^• = (F ∘ F^{-1})^• = (F^{-1})^• ∘ F^•.

It follows from Theorem A.4 that F^• is bijective. The preceding identities give the first equality. For a function f in C^∞(M), we have

(F^{-1})^•(f) = f ∘ F^{-1} = F_•(f).

Since f was arbitrary, the second equality follows.

(b): This follows from part (a).
