# Theorem 19.8.7. If $R$ and $\mathcal{R}$ are the Riemann curvature tensors on $\mathbb{R}^m_\nu$, then $R$ has constant (vector) value 0, and $\mathcal{R}$ has constant (real number) value 0.

Proof. We have from Theorem 19.3.5 that in standard coordinates the Christoffel symbols in $\mathbb{R}^m_\nu$ have constant value 0, and then from Theorem 18.7.2 that $R$ has constant value 0. The corresponding result for $\mathcal{R}$ follows from Theorem 19.8.2(a).

# Theorem 19.8.8. $d_p(F)\left(\left.\frac{\partial}{\partial x^i}\right|_p\right)=\left.\frac{\partial}{\partial \widetilde{x}^i}\right|_{F(p)}$ ,

hence

$=\widetilde{\mathfrak{g}}_{F(p)}\left(d_p(F)\left(\left.\frac{\partial}{\partial x^i}\right|_p\right),d_p(F)\left(\left.\frac{\partial}{\partial x^j}\right|_p\right)\right)$
