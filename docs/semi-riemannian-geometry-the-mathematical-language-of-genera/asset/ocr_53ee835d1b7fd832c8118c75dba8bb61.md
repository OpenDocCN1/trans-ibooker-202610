# 16.10 Flows

We saw in Section 15.1 that the velocity of a smooth curve on a smooth manifold is a vector field on the curve. In this section, we turn this observation around and ask if a given smooth vector field on a smooth manifold can be realized as a family of velocities of smooth curves.

Let M be a smooth manifold, let X be a vector field in 𝔛(M), and let p be a point in M. An integral curve of X with starting point p is a smooth curve λ(t) : (a,b) ⟶ M such that

λ(0) = p and dλ/dt (t) = X_{λ(t)}

for all t in (a,b). We say that λ is maximal if it cannot be extended to a smooth curve satisfying these properties on a larger open interval.

Φ_p(t) : (a_p, b_p) ⟶ M

of X with starting point p.

Φ_p(0) = p and dΦ_p/dt (t) = X_{Φ_p(t)} (16.10.1)
