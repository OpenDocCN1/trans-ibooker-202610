We also have

```
d(α₁) ∧ d(y) ∧ d(z)
= (∂α₁/∂x d(x) + ∂α₁/∂y d(y) + ∂α₁/∂z d(z) + ∂α₁/∂t d(t)) ∧ d(y) ∧ d(z)
= ∂α₁/∂x d(x) ∧ d(y) ∧ d(z) + ∂α₁/∂y d(y) ∧ d(y) ∧ d(z)
  + ∂α₁/∂z d(z) ∧ d(y) ∧ d(z) + ∂α₁/∂t d(t) ∧ d(y) ∧ d(z)
= ∂α₁/∂x d(x) ∧ d(y) ∧ d(z) + ∂α₁/∂t d(y) ∧ d(z) ∧ d(t);
```

likewise,

```
d(α₂) ∧ d(z) ∧ d(x) = ∂α₂/∂y d(x) ∧ d(y) ∧ d(z) − ∂α₂/∂t d(x) ∧ d(z) ∧ d(t)
d(α₃) ∧ d(x) ∧ d(y) = ∂α₃/∂z d(x) ∧ d(y) ∧ d(z) + ∂α₃/∂t d(x) ∧ d(y) ∧ d(t)
d(β₁) ∧ d(x) ∧ d(t) = − ∂β₁/∂y d(x) ∧ d(y) ∧ d(t) − ∂β₁/∂z d(x) ∧ d(z) ∧ d(t)
d(β₂) ∧ d(y) ∧ d(t) = ∂β₂/∂x d(x) ∧ d(y) ∧ d(t) − ∂β₂/∂z d(y) ∧ d(z) ∧ d(t)
d(β₃) ∧ d(z) ∧ d(t) = ∂β₃/∂x d(x) ∧ d(z) ∧ d(t) + ∂β₃/∂y d(y) ∧ d(z) ∧ d(t).
```

Thus,

```
d⋆(φ) = (∂α₁/∂x + ∂α₂/∂y + ∂α₃/∂z) d(x) ∧ d(y) ∧ d(z)
      − (∂β₂/∂x − ∂β₁/∂y − ∂α₃/∂t) d(x) ∧ d(y) ∧ d(t)
      + (∂β₁/∂z − ∂β₃/∂x − ∂α₂/∂t) d(x) ∧ d(z) ∧ d(t)
      − (∂β₃/∂y − ∂β₂/∂z − ∂α₁/∂t) d(y) ∧ d(z) ∧ d(t).
```
