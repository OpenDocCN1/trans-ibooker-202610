# 16.4 Lie Derivative

Let M be a smooth manifold, let X be a vector field in 𝔛(M), and consider the map ℒ_X : 𝔛(M) ⟶ 𝔛(M) defined by ℒ_X(Y) = [X,Y] for all vector fields Y in 𝔛(M). By parts (c) and (d) of Theorem 15.3.2, ℒ_X is linear and satisfies ℒ_X(fY) = X(f)Y + fℒ_X(Y) for all functions f in C^∞(M) and all vector fields Y in 𝔛(M). It follows from Theorem 16.2.7 that there is a unique tensor derivation

ℒ_X : 𝒯_s^r(M) ⟶ 𝒯_s^r(M)

on M, called the Lie derivative with respect to X, such that

ℒ_X(f) = X(f)      and      ℒ_X(Y) = [X,Y]      (16.4.1)

for all functions f in C^∞(M) and all vector fields Y in 𝔛(M), where (ℒ_X)_s^r has been abbreviated to ℒ_X.

The Lie derivative enjoys a wealth of algebraic properties.

# Theorem 16.4.1 (Vector Field Properties of Lie Derivative). Let M be a smooth manifold, let X,Y,Z be vector fields in 𝔛(M), and let f,g be functions in C^∞(M). Then:

+   (a) ℒ_X(Y) = -ℒ_Y(X).
+   (b) ℒ_X+Y(Z) = ℒ_X(Z) + ℒ_Y(Z).
+   (c) ℒ_X(Y + Z) = ℒ_X(Y) + ℒ_X(Z).
+   (d) ℒ_fX(gY) = fgℒ_X(Y) + fX(g)Y - gY(f)X.
+   (e) ℒ_X([Y,Z]) = [ℒ_X(Y),Z] + [Y,ℒ_X(Z)].

Proof. This follows from Theorem 15.3.2.

We note that Jacobi’s identity in part (e) of Theorem 15.3.2 gives rise to a product rule for Lie brackets in part (e) of the above theorem. The next result contains a product rule for tensor products, and the one after that a product rule for wedge products.

# Theorem 16.4.2 (Tensor Field Properties of Lie Derivative). Let M be a smooth manifold, let X be a vector field in 𝔛(M), let 𝒜,ℬ and 𝒞 be tensor fields in 𝒯_s^r(M) and 𝒯_s'^r'(M), respectively, and let f be a function in C^∞(M). Then:

+   (a) ℒ_X(𝒜 + ℬ) = ℒ_X(𝒜) + ℒ_X(ℬ).
+   (b) ℒ_X(f𝒜) = X(f)𝒜 + fℒ_X(𝒜).
+   (c) ℒ_X(𝒜 ⊗ 𝒞) = ℒ_X(𝒜) ⊗ 𝒞 + 𝒜 ⊗ ℒ_X(𝒞).

Proof. This follows from the properties of ℒ_X as a tensor derivation on M.

# Theorem 16.4.3 (Form Derivation Property of Lie Derivative). If M is a smooth manifold and X is a vector field in 𝔛(M), then ℒ_X is a form derivation; that is,

ℒ_X(ω ∧ ξ) = ℒ_X(ω) ∧ ξ + ω ∧ ℒ_X(ξ)

for all forms ω in Λ^s(M) and ξ in Λ^s'(M).
