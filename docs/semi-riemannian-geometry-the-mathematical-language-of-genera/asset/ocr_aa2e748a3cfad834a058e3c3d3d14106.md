# Example 7.2.1.

Let η, ζ be covectors in Λ¹(V) = V*, and let v₁, v₂ be vectors in V. With 𝒮₂ = {id, (1 2)}, we have

(η ∧ ζ)(v₁, v₂) = 1/(1!1!) Σ_{σ∈𝒮₂} sgn(σ) η(v_{σ(1)}) ζ(v_{σ(2)}) = η(v₁)ζ(v₂) − η(v₂)ζ(v₁).

Now let η be a multicovector in Λ²(V), let ζ be a covector in Λ¹(V) = V*, and let v₁, v₂ be vectors in V. With

𝒮₃ = {id, (1 2), (1 3), (2 3), (1 2 3), (1 3 2)},

we have

(η ∧ ζ)(v₁, v₂, v₃) = 1/(2!1!) Σ_{σ∈𝒮₃} sgn(σ) η(v_{σ(1)}, v_{σ(2)}) ζ(v_{σ(3)}) = [η(v₁, v₂)ζ(v₃) − η(v₂, v₁)ζ(v₃) − η(v₃, v₂)ζ(v₁) − η(v₁, v₃)ζ(v₂) + η(v₂, v₃)ζ(v₁) + η(v₃, v₁)ζ(v₂)]/2 = [η(v₁, v₂)ζ(v₃) + η(v₁, v₂)ζ(v₃) + η(v₂, v₃)ζ(v₁) + η(v₃, v₁)ζ(v₂) + η(v₂, v₃)ζ(v₁) + η(v₃, v₁)ζ(v₂)]/2 = η(v₁, v₂)ζ(v₃) + η(v₂, v₃)ζ(v₁) + η(v₃, v₁)ζ(v₂).

Wedge products behave well with respect to basic algebraic structure.

# Theorem 7.2.2.

Let V be a vector space, let η, η¹, η² and ζ, ζ¹, ζ² be multicovectors in Λˢ(V) and Λˢ'(V), respectively, and let c be a real number. Then:

+   (a) (η¹ + η²) ∧ ζ = η¹ ∧ ζ + η² ∧ ζ.
+   (b) η ∧ (ζ¹ + ζ²) = η ∧ ζ¹ + η ∧ ζ².
+   (c) (cη) ∧ ζ = η ∧ (cζ) = c(η ∧ ζ).

Proof. Straightforward.

# Theorem 7.2.3.

If V is a vector space, and η and ζ are multicovectors in Λˢ(V) and Λˢ'(V), respectively, then:

+   (a) η ∧ ζ = (−1)^{ss'} ζ ∧ η.
+   (b) If s = s' = 1, then η ∧ ζ = −ζ ∧ η.
+   (c) If s = 1, then η ∧ η = 0.

Proof. (a): Let v₁, …, v_{s+s'} be vectors in V, and define a permutation σ in 𝒮_{s+s'} by

σ = ( 1 … s s+1 … s+s' ; s'+1 … s'+s 1 … s' ).

We have

σ(η ⊗ ζ)(v₁, …, v_{s+s'}) = η ⊗ ζ(v_{σ(1)}, …, v_{σ(s)}, v_{σ(s+1)}, …, v_{σ(s+s')}) = η ⊗ ζ(v_{s'+1}, …, v_{s'+s}, v₁, …, v_{s'}) = η(v_{s'+1}, …, v_{s'+s}) ζ(v₁, …, v_{s'}) = ζ(v₁, …, v_{s'}) η(v_{s'+1}, …, v_{s'+s}) = ζ ⊗ η(v₁, …, v_{s'}, v_{s'+1}, …, v_{s'+s}).
