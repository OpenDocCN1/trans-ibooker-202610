called the induced connection on M. Using the notation ∇̅ in both (19.12.1) and (19.12.3) is intentional and meant to emphasize the relatedness of the two maps. For a given vector field X in 𝔛(M), the induced covariant derivative with respect to X is the map

∇̅_X : 𝔛_{M̅}(M) ⟶ 𝔛_{M̅}(M)

defined by

∇̅_X(V) = ∇̅(X, V)

for all V in 𝔛_{M̅}(M). Corresponding to Theorem 12.3.1, we have the following result.

# Theorem 19.12.1. With the above setup, let X, Y and V, W be vector fields in 𝔛(M) and 𝔛_{M̅}(M), respectively, and let f be a function in C^∞(M). Then:

+   (a) ∇̅_{X+Y}(V) = ∇̅_X(V) + ∇̅_Y(V).
+   (b) ∇̅_{fX}(V) = f ∇̅_X(V).
+   (c) ∇̅_X(V + W) = ∇̅_X(V) + ∇̅_X(W).
+   (d) ∇̅_X(fV) = X(f)V + f ∇̅_X(V).
+   (e) ∇̅_X(⟨V, W⟩) = ⟨∇̅_X(V), W⟩ + ⟨V, ∇̅_X(W)⟩.

# Theorem 19.12.2. With the above setup, if X, Y are vector fields in 𝔛(M), then

∇_X(Y) = tan(∇̅_X(Y)).

# Theorem 19.12.3. With the above setup, define a function

𝔥 : 𝔛(M) × 𝔛(M) ⟶ 𝔛(M)^⊥,

called the shape tensor, by

𝔥(X, Y) = nor(∇̅_X(Y))

for all vector fields X, Y in 𝔛(M). Then 𝔥 is C^∞(M)-bilinear and symmetric.

We have from (19.12.2) and the preceding two theorems that

∇̅_X(Y) = ∇_X(Y) + 𝔥(X, Y),

which is the counterpart of (12.9.4).
