# Theorem 1.1.15. If V is a vector space, and U₁ and U₂ are subspaces of V, then

dim(U₁ + U₂) = dim(U₁) + dim(U₂) − dim(U₁ ∩ U₂).

Proof. Let ℋ = (h₁, …, hₖ) be a basis for U₁ ∩ U₂. By Theorem 1.1.7(c), ℋ can be extended to a basis (h₁, …, hₖ, f₁, …, fₘ) for U₁, and also to a basis (h₁, …, hₖ, g₁, …, gₙ) for U₂. Let

𝒱 = {h₁, …, hₖ, f₁, …, fₘ, g₁, …, gₙ}.

We claim that 𝒱 is basis for U₁ + U₂. Clearly, 𝒱 spans U₁ + U₂. To show that 𝒱 is linearly independent, suppose

(a¹ h₁ + ⋯ + aᵏ hₖ) + (b¹ f₁ + ⋯ + bᵐ fₘ) + (c¹ g₁ + ⋯ + cⁿ gₙ) = 0

for some real numbers a¹, …, aᵏ, b¹, …, bᵐ, c¹, …, cⁿ. Then

c¹ g₁ + ⋯ + cⁿ gₙ = −(a¹ h₁ + ⋯ + aᵏ hₖ) − (b¹ f₁ + ⋯ + bᵐ fₘ). (1.1.3)

Since h₁, …, hₖ, f₁, …, fₘ are in U₁, so is c¹ g₁ + ⋯ + cⁿ gₙ, and because g₁, …, gₙ are in U₂, so is c¹ g₁ + ⋯ + cⁿ gₙ. Thus, c¹ g₁ + ⋯ + cⁿ gₙ is in U₁ ∩ U₂, hence

c¹ g₁ + ⋯ + cⁿ gₙ = d¹ h₁ + ⋯ + dᵏ hₖ

for some real numbers d¹, …, dᵏ, so

(−d¹) h₁ + ⋯ + (−dᵏ) hₖ + c¹ g₁ + ⋯ + cⁿ gₙ = 0.
