Proof. Let $\omega$ be the covector field in $\mathfrak{X}^*(\mathbb{R}^2)$ given by $\omega=\alpha^1d(r)+\alpha^2d(s)$. By Stokes’s theorem,

```
$$\int_D d(\omega)=\int_{\partial D}\omega.$$
```

A computation similar to that leading to (16.1.2) gives

```
$$d(\omega)=\left(\frac{\partial\alpha^2}{\partial r}-\frac{\partial\alpha^1}{\partial s}\right)d(r)\wedge d(s),$$
```

and then (16.7.2) yields

```
$$\int_D d(\omega)=\int\!\!\int_D\left(\frac{\partial\alpha^2}{\partial r}-\frac{\partial\alpha^1}{\partial s}\right)dr\,ds.$$
```

The result follows.

The setup for the next result is the same as that for Theorem 19.11.4, except that $(M,\epsilon|_M)$ is assumed to be compact, something needed to ensure certain integrals exist.

# **Theorem 21.2.4 (Classical Stokes’s Theorem).**

Let $(M,\epsilon|_M)$ be a compact orientable Riemannian hypersurface with boundary of $\mathbb{R}^3_0=(\mathbb{R}^3,\epsilon)$, let $V$ be a unit normal vector field in $\mathfrak{X}_\epsilon(M)$ (as given by Theorem 19.11.1), and let $\mathcal{D}_M$ be the orientation of $M$ induced by $V$, so that $(M,\epsilon|_M,\mathcal{D}_M)$ is a compact oriented Riemannian hypersurface with boundary of $\mathbb{R}^3_0$. Let $\Omega_M$ be its volume form. Let $W$ be the unique outward-pointing unit normal vector field in $\mathfrak{X}_M(\partial M)$ (as given by Theorem 19.11.3), and let $\partial_M$ be the (Stokes) orientation induced by $W$, so that $(\partial M,\epsilon|_{\partial M},\mathcal{D}_{\partial M})$ is an oriented Riemannian hypersurface of $(M,\epsilon|_M,\mathcal{D}_M)$. Let $\Omega_{\partial M}$ be its volume form, and let $U=V\times W$. If $X$ is a vector field in $\mathfrak{X}(\mathbb{R}^3_0)$, then

```
$$\int_M\langle\operatorname{Curl}(X),V\rangle\,\Omega_M=\int_{\partial M}\langle X,U\rangle\,\Omega_{\partial M}.$$
```

Proof. By Stokes’s theorem,

```
$$\int_M d(X^\flat)=\int_{\partial M}X^\flat.$$  (21.2.1)
```

We seek alternative expressions for the integrands in (21.2.1). For the left-hand side, Theorem 19.11.2(b) and Theorem 20.5.1 give

```
$$d(X^\flat)=i_{\operatorname{Curl}(X)}(\Omega_{\mathbb{R}^3_0})|_M=\langle\operatorname{Curl}(X),V\rangle\Omega_M,$$  (21.2.2)
```

where $\Omega_{\mathbb{R}^3_0}$ is the volume form on $\mathbb{R}^3_0$. For the right-hand side, by Theorem 19.11.4(e),

```
$$\Omega_{\partial M}(U)=\mathord{\pm}1\,\partial_M.$$  (21.2.3)
```
