# Theorem 22.1.10.

Let P₁, …, P_{m−1} be matrices in Mat_{(m−1)×1}, and consider the matrices

𝕡 = (P₁, …, P_{m−1}),      P₁¹ = [P₁ ⋯ P_{m−1}],

and

P = [ P₁¹   O_{(m−1)×1} ; O_{1×(m−1)}   1 ].

Then:

+   (a) 𝕡 is an orthonormal basis for Mat_{(m−1)×1} if and only if P₁¹ is in O(m−1).
+   (b) 𝕡 is a positively oriented orthonormal basis for Mat_{(m−1)×1} if and only if P₁¹ is in SO(m−1).
+   (c) If 𝕡 is a positively oriented orthonormal basis for Mat_{(m−1)×1} and A is a map in Lin(V,V) such that [A] = P or [A] = Pᵀ, then A is in R_m.

Proof. For brevity, let 𝕄 = Mat_{(m−1)×1} and 𝔼 = 𝔼_{m−1}. We have from (2.2.7) that

P₁¹ = [[P₁]_𝔼 ⋯ [P_{m−1}]_𝔼] = [id_𝕄]_𝕡^𝔼,

hence

det(P₁¹) = det( [id_𝕄]_𝕡^𝔼 ).    (22.1.4)

It follows that if 𝕡 is a basis for 𝕄, then: 𝕡 is consistent with 𝔼 (hence positively oriented) if and only if det(P₁¹) > 0.

(a): By definition, P₁¹ is in O(m−1) if and only if (P₁¹)ᵀ P₁¹ = I_{m−1}, which is equivalent to (P_i)ᵀ P_j = δ^i_j for i, j = 1, …, m−1.

(b)(⇒): Since 𝕡 is an orthonormal basis, we have from part (a) that P₁¹ is in O(m−1). Then

1 = det(I_{m−1}) = det((P₁¹)ᵀ P₁¹) = det(P₁¹)²,

so det(P₁¹) = ±1. Since 𝕡 is positively oriented, hence consistent with 𝔼, it follows from (22.1.4) that det(P₁¹) = 1. Thus, P₁¹ is in SO(m − 1).

(b)(⇐): Since P₁¹ is in SO(m − 1), which is a subgroup of O(m − 1), we have from part (a) that 𝕡 is an orthonormal basis for 𝕄. Also, because P₁¹ is in SO(m − 1), we have det(P₁¹) = 1. It follows from (22.1.4) that 𝕡 is consistent with 𝔼, hence positively oriented.

(c): If [A] = P, the result follows from part (b). Suppose [A] = Pᵀ, in which case [A] = [(P₁¹)ᵀ  O_{(m−1)×1}; O_{1×(m−1)} 1].

Let (P₁¹)ᵀ = [Q₁ … Q_{m−1}], where Q₁,…,Q_{m−1} are matrices in 𝕄, and let ℚ = (Q₁,…,Q_{m−1}). Since 𝕡 is a basis for 𝕄, we have from Theorem 2.3.2 that so is ℚ. Furthermore, because 𝕡 is orthonormal, ℚ is too. Arguing as above gives (P₁¹)ᵀ = [[Q₁]_𝔼 … [Q_{m−1}]_𝔼] = [id_𝕄]_𝔼^ℚ,

hence det(P₁¹) = det([id_𝕄]_ℚ^𝔼). Since 𝕡 is positively oriented, it follows from (22.1.4) that so is ℚ. We have shown that ℚ is a positively oriented orthonormal basis for 𝕄. The result now follows from part (b).

We close this section by showing that any map in a proper orthochronous Lorentz group can be expressed as the composition of a rotation, followed by a boost, followed by another rotation.

# Theorem 22.1.11. Any map A in L_m^{↑+} can be expressed as A = R₁ ∘ B ∘ R₂, where R₁, R₂ are maps in R_m and B is a map in B_m.

Proof. If ([A]₂¹)ᵀ[A]₂¹ = 0, then [A]₂¹ = O_{(m−1)×1}. By Theorem 22.1.7, A is in R_m, so in this case we set R₁ = A and B = R₂ = id_V.

Now suppose ([A]₂¹)ᵀ[A]₂¹ ≠ 0, and let P_{m−1} = − 1/βγ [A]₂¹, (22.1.5)

Then (22.1.5) gives

$$P_1^1[A]_2^1=-\beta\gamma\begin{bmatrix}(P_1)^\mathrm{T}P_{m-1}\\ \vdots\\ (P_{m-1})^\mathrm{T}P_{m-1}\end{bmatrix}=[0\ \cdots\ 0\ -\beta\gamma]^\mathrm{T}.$$

Let

$$P_1^1[A]_1^1=[Q_1\ \cdots\ Q_{m-1}]^\mathrm{T},$$

where $Q_1,\ldots,Q_{m-1}$ are matrices in $\operatorname{Mat}_{(m-1)\times 1}$. We have

$$\begin{bmatrix}(Q_1)^\mathrm{T}\\ \vdots\\ (Q_{m-1})^\mathrm{T}\end{bmatrix}[Q_1\ \cdots\ Q_{m-1}]$$

$$=(P_1^1[A]_1^1)(P_1^1[A]_1^1)^\mathrm{T}$$
$$=P_1^1\big([A]_1^1([A]_1^1)^\mathrm{T}\big)(P_1^1)^\mathrm{T}$$
$$=P_1^1\big(I_{m-1}+[A]_2^1([A]_2^1)^\mathrm{T}\big)(P_1^1)^\mathrm{T}\quad[\text{Th 22.1.2(a)}]$$
$$=I_{m-1}+(P_1^1[A]_2^1)(P_1^1[A]_2^1)^\mathrm{T}\quad[\text{Th 22.1.10(a)}]$$
$$=I_{m-1}+\operatorname{diag}(0,\ldots,0,\beta^2\gamma^2)\quad[(22.1.8)]$$
$$=\begin{bmatrix}I_{m-2}&O_{(m-2)\times1}\\O_{1\times(m-2)}&\gamma^2\end{bmatrix}\quad[(22.1.3)].$$

which shows that $(Q_1,\ldots,Q_{m-1})$ is “close” to being an orthonormal basis for $\operatorname{Mat}_{(m-1)\times1}$. Since $A$ is in $L_m^+$, we have, by definition, that $\gamma\geq1$. Let $\varepsilon=\pm1$, and let

$$R_{m-1}=\frac{\varepsilon}{\gamma}Q_{m-1}.$$

We see from (22.1.10) that $R_{m-1}$ is a unit vector and

$$(Q_{m-1})^\mathrm{T}R_{m-1}=\varepsilon\gamma.$$

For an appropriate choice of $\varepsilon$, $(Q_1,\ldots,Q_{m-2},R_{m-1})$ is a positively oriented orthonormal basis for $\operatorname{Mat}_{(m-1)\times1}$. (We will see shortly that, in fact, $\varepsilon=1$.) Let

$$R_1^1=[Q_1\ \cdots\ Q_{m-2}\ R_{m-1}]^\mathrm{T}$$

and

$$R=\begin{bmatrix}R_1^1&O_{(m-1)\times1}\\O_{1\times(m-1)}&1\end{bmatrix}.$$

By Theorem 2.2.3(a), there are maps $F$ and $G$ in $\operatorname{Lin}(V,V)$ such that

$$[F]=P\quad\text{and}\quad[G]=R^\mathrm{T}.$$

hence
[F ○ A ○ G] = [F][A][G]      [Th 2.2.2(c)]
= P[A]Rᵀ      [(22.1.14)]
= ⎡ P₁¹[A]₁¹(R₁¹)ᵀ   P₁¹[A]₁² ⎤ .      [(22.1.7), (22.1.13)]
  ⎣ [A]₁²(R₁¹)ᵀ      γ      ⎦
(22.1.15)

We seek alternative expressions for P₁¹[A]₁¹(R₁¹)ᵀ and [A]₁²(R₁¹)ᵀ. For the former,

P₁¹[A]₁¹(R₁¹)ᵀ
= ⎡ (Q₁)ᵀ ⎤ ⎡ Q₁ ⋯ Qₘ₋₂  Rₘ₋₁ ⎤  [(22.1.9), (22.1.12)]
  ⎢  ⋮  ⎥
  ⎢(Qₘ₋₂)ᵀ⎥
  ⎣(Qₘ₋₁)ᵀ⎦
(22.1.16)
= ⎡ Iₘ₋₂   O₍ₘ₋₂₎×₁ ⎤ .      [(22.1.10), (22.1.11)]
  ⎣ O₁×₍ₘ₋₂₎  εγ   ⎦

For the latter,

[Q₁ ⋯ Qₘ₋₁] = ([A]₁¹)ᵀ (P₁¹)ᵀ      [(22.1.9)]
= [ ([A]₁¹)ᵀ P₁ ⋯ ([A]₁¹)ᵀ Pₘ₋₁ ],      [(22.1.6)]

hence
Qₘ₋₁ = ([A]₁¹)ᵀ Pₘ₋₁
= -1/βγ ([A]₁¹)ᵀ [A]₁²      [(22.1.5)]
= -1/β ([A]₁²)ᵀ,      [Th 22.1.2(c)]

so
[A]₁² = -β (Qₘ₋₁)ᵀ.      (22.1.17)

It follows from (22.1.10) and (22.1.17) that
[A]₁² Qᵢ = -β (Qₘ₋₁)ᵀ Qᵢ = 0
for i = 1, …, m − 2, and from (22.1.11) and (22.1.17) that
[A]₁² Rₘ₋₁ = -β (Qₘ₋₁)ᵀ Rₘ₋₁ = -εβγ,
hence

$$[A]^2_1(R^1_1)^T = [ [A]^2_1Q_1 \ \cdots \ [A]^2_1Q_{m-2} \ [A]^2_1R_{m-1} ]\ [(22.1.12)] = [0 \ \cdots \ 0 \ -\varepsilon\beta\gamma].$$

Substituting (22.1.8), (22.1.16), and (22.1.18) into (22.1.15) yields

$$[F\circ A\circ G]=\begin{bmatrix} I_{m-2} & O_{(m-2)\times1}\\ O_{1\times(m-2)} & \varepsilon\gamma\\ 0&\cdots&0&-\varepsilon\beta\gamma\end{bmatrix}\begin{bmatrix}0\\ \vdots\\ 0\\ -\beta\gamma\\ \gamma\end{bmatrix} = \begin{bmatrix} I_{m-2} & O_{(m-2)\times2}\\ O_{2\times(m-2)} & \begin{bmatrix}\varepsilon\gamma&-\beta\gamma\\ -\varepsilon\beta\gamma&\gamma\end{bmatrix}\end{bmatrix}.$$

By construction, $(P_1,\ldots,P_{m-1})$ and $(Q_1,\ldots,Q_{m-2},R_{m-1})$ are positively oriented orthonormal bases for $\operatorname{Mat}_{(m-1)\times1}$. It follows from (22.1.7), Theorem 22.1.10(b), and (22.1.13) that

$$\det(P)=\det(R)=1.$$

Since $A$ is in $L_m^{+\dagger}$,

$$\begin{aligned}1&=\det([A])\\ &=\det(P[A]R^T) &&[(22.1.20)]\\ &=\det([F][A][G]) &&[(22.1.14)]\\ &=\det([F\circ A\circ G]) &&[\text{Th 2.2.2(c)}]\\ &=\varepsilon(\gamma^2-\beta^2\gamma^2) &&[(22.1.19)]\\ &=\varepsilon, &&[(22.1.3)]\end{aligned}$$

so (22.1.19) becomes

$$[F\circ A\circ G]=\begin{bmatrix} I_{m-2} & O_{(m-2)\times2}\\ O_{2\times(m-2)} & \begin{bmatrix}\gamma&-\beta\gamma\\ -\beta\gamma&\gamma\end{bmatrix}\end{bmatrix}.$$

By definition, $\beta$ and $\gamma$ satisfy (22.1.2). Thus, $F\circ A\circ G$ is in $B_m$. We have from (22.1.6), (22.1.7), Theorem 22.1.10(c), and (22.1.14) that $F$ is in $R_m$. Similarly, we have from (22.1.12), (22.1.13), Theorem 22.1.10(c), and (22.1.14) that $G$ is in $R_m$. It follows from Theorem 22.1.6 that $F^{-1}$ and $G^{-1}$ are in $R_m$. Setting $B=F\circ A\circ G$, $R_1=F^{-1}$, and $R_2=G^{-1}$ gives $A=R_1\circ B\circ R_2$, which is the desired expression for $A$ in terms of two rotations and a boost.

# 22.2 Maxwell’s Equations

Let $(x, y, z, t)$ be standard coordinates on $\mathbb{R}_0^3 \times \mathbb{R}$. In what follows, we think of $x, y, z$ as “space” variables and $t$ as a “time” variable. Using the differential operators in Section 10.6, an **electromagnetic field** in $\mathbb{R}_0^3 \times \mathbb{R}$ is characterized by **Maxwell’s equations**:

[M1] $\operatorname{div}(E) = \frac{1}{\epsilon_0} \rho$
[M2] $\operatorname{div}(B) = 0$
[M3] $\operatorname{curl}(E) = -\frac{\partial B}{\partial t}$
[M4] $\operatorname{curl}(B) = \mu_0 J + \mu_0 \epsilon_0 \frac{\partial E}{\partial t}$,

where the vector fields $E, B, J$ in $\mathfrak{X}(\mathbb{R}_0^3 \times \mathbb{R})$ are the **electrical field**, **magnetic field**, and **current density**, respectively; the function $\rho$ in $C^\infty(\mathbb{R}_0^3 \times \mathbb{R})$ is the **charge density**; and the real numbers $\epsilon_0$ and $\mu_0$ are the **permittivity of free space** and the **permeability of free space**, respectively. We interpret the operators div and curl in the above identities as applying only to the space variables, and likewise for other vector calculus operators to follow. Let us assume units have been chosen so that $c = 1$, where $c = \mu_0 \epsilon_0$ is the speed of light. Thus, [M4] becomes

[M4'] $\operatorname{curl}(B) = \mu_0 J + \frac{\partial E}{\partial t} = \frac{1}{\epsilon_0} J + \frac{\partial E}{\partial t}$.

We observe that $J$ and $\rho$ are not independent of each other:

$0 = \operatorname{div}(\operatorname{curl}(B))$ [Th 10.6.1(d)]
$= \operatorname{div}\left(\frac{\partial E}{\partial t} + \mu_0 J\right)$ [M4']
$= \frac{\partial(\operatorname{div}(E))}{\partial t} + \mu_0 \operatorname{div}(J)$
$= \frac{1}{\epsilon_0} \frac{\partial \rho}{\partial t} + \mu_0 \operatorname{div}(J)$. [M1]

Then $\mu_0 \epsilon_0 = 1$ gives

$\operatorname{div}(J) + \frac{\partial \rho}{\partial t} = 0,$ (22.2.1)

which is called the **continuity equation**.

The rest of this section is devoted to finding alternative expressions for Maxwell’s equations, especially in terms of differential forms. This is an opportunity to showcase some of the computational tools developed earlier.

Let us reformulate Maxwell’s equations using what are referred to as potentials. It follows from Theorem 10.6.3 and [M2] that there is a vector field $A$ in $\mathfrak{X}(\mathbb{R}_0^3 \times \mathbb{R})$, called the **magnetic potential**, such that

$B = \operatorname{curl}(A).$ (22.2.2)
