
## Theorem 2.5.1. With the above setup, $\operatorname{tr}(A)$ and $\det(A)$ are independent of the choice of basis for $V$.

*Proof.* Let $\mathcal{F}$ be another basis for $V$. By Theorem 2.2.6,

$$[A]_{\mathcal{H}}^{\mathcal{H}}=\left([\operatorname{id}_V]_{\mathcal{H}}^{\mathcal{F}}\right)^{-1}[A]_{\mathcal{F}}^{\mathcal{F}}[\operatorname{id}_V]_{\mathcal{H}}^{\mathcal{F}}.$$

We have from Theorem 2.1.7(c) that

$$\operatorname{tr}\left([A]_{\mathcal{H}}^{\mathcal{H}}\right)=\operatorname{tr}\left([A]_{\mathcal{F}}^{\mathcal{F}}\right),$$

and from Theorem 2.4.5 that

$$\det\left([A]_{\mathcal{H}}^{\mathcal{H}}\right)=\det\left([A]_{\mathcal{F}}^{\mathcal{F}}\right).$$

## Theorem 2.5.2. If $V$ is a vector space and $A,B:V\longrightarrow V$ are linear maps, then:

## Bilinear Functions

The inner product is an example of a bilinear function that likely is familiar to the reader. In this book, we are more interested in a less restrictive type of bilinear function called a scalar product, but we will not ignore the inner product altogether. In order to decide whether a bilinear function is a scalar product, we need to determine whether it is symmetric and nondegenerate. These properties of bilinear functions will be the focus of the present chapter.

### 3.1 Bilinear Functions

Let $V$ be a vector space. A function

$$\mathfrak{b}: V \times V \longrightarrow \mathbb{R}$$

is said to be **bilinear (on $V$)** if it is linear in both arguments; that is,

$$\mathfrak{b}(cu+v,w)=c\mathfrak{b}(u,w)+\mathfrak{b}(v,w)$$

and

$$\mathfrak{b}(u,cv+w)=c\mathfrak{b}(u,v)+\mathfrak{b}(u,w)$$

for all vectors $u,v,w$ in $V$ and all real numbers $c$. In the literature, a bilinear function is sometimes called a **quadratic form**. We often denote

$$\mathfrak{b}(\cdot,\cdot)\quad\text{by}\quad\langle\cdot,\cdot\rangle,$$

writing $\langle v,w\rangle$ in place of $\mathfrak{b}(v,w)$.

We say that b is:

- **symmetric** if $\langle v, w\rangle = \langle w, v\rangle$ for all $v, w$ in $V$.
- **alternating** if $\langle v, w\rangle = -\langle w, v\rangle$ for all $v, w$ in $V$.
- **nondegenerate** if for all $v$ in $V$, $\langle v, w\rangle = 0$ for all $w$ in $V$ implies $v = 0$.
- **degenerate** if b is not nondegenerate.
- **positive definite** if $\langle v, v\rangle > 0$ for all nonzero $v$ in $V$.
- **negative definite** if $\langle v, v\rangle < 0$ for all nonzero $v$ in $V$.
- **definite** if b is either positive definite or negative definite.
- **indefinite** if b is not definite.
- **positive semidefinite** if $\langle v, v\rangle \ge 0$ for all $v$ in $V$.
- **negative semidefinite** if $\langle v, v\rangle \le 0$ for all $v$ in $V$.
- **semidefinite** if b is either positive semidefinite or negative semidefinite.

Let $U$ be a subspace of $V$. For brevity, we denote the restriction

$b|_{U\times U}$ by $b|_U$.

In fact, we often drop “$|_U$” from the notation altogether and say, for example, that b is symmetric on $U$ if $b|_U$ is symmetric. Evidently, b is bilinear on $U$, and if b is symmetric (resp., alternating, definite, semidefinite) on $V$, then b is symmetric (resp., alternating, definite, semidefinite) on $U$. The situation is more complicated with nondegeneracy. If b is nondegenerate on $V$, it does not necessarily follow that b is nondegenerate on $U$. We will explore this phenomenon later on.

### Example 3.1.1. The following table gives examples of bilinear functions on $\mathbb{R}^3$. Observe that a bilinear function can be either symmetric or not, and independent of that, nondegenerate or not.

| $\langle(x^1, x^2, x^3), (y^1, y^2, y^3)\rangle$ | Symmetric | Definite | Semidef. | Nondegen. |
|---|---|---|---|---|
| $x^1y^1 + x^2y^2 + x^3y^3$ | yes | yes | yes | yes |
| $x^1y^1 + x^2y^2$ | yes | no | yes | no |
| $x^1y^1 + x^2y^2 - x^3y^3$ | yes | no | no | yes |
| $x^1y^1 - x^3y^3$ | yes | no | no | no |
| $x^1y^1 + x^2y^3 - x^3y^2$ | no | no | yes | yes |
| $x^1y^1 + x^2y^3$ | no | no | no | no |

Borrowing terminology from the special theory of relativity, we say that (with respect to b) a vector $v$ in $V$ is:

- **spacelike** if $v = 0$ or $\langle v, v\rangle > 0$.
- **timelike** if $\langle v, v\rangle < 0$.
- **lightlike** if $v \neq 0$ and $\langle v, v\rangle = 0$.

The zero vector is usually considered to be spacelike (as is the case here), but in some of the literature it is taken to be lightlike. Evidently, each vector is either spacelike, timelike, or lightlike, and this results in a corresponding partition of $V$. (There are several standard but differing uses of the term “partition” found at various places in this book. The present instance refers to the definition of partition given in Appendix A.)

Let b be a bilinear function on a vector space $V$, and let $H = (h_1, \dots, h_m)$ be a basis for $V$. The matrix of b with respect to $H$ is denoted by $b_H$ and defined by

```
b_H = [ b_{11} … b_{1m} ; ⋮ ⋱ ⋮ ; b_{m1} … b_{mm} ]
```

where

```
b_{ij} = ⟨h_i, h_j⟩
```

for $i, j = 1, …, m$.

The next two results illustrate how matrix representations can be used to facilitate computations involving bilinear functions.

## Theorem 3.1.2. Let $V$ be a vector space of dimension $m$, let b be a bilinear function on $V$, and let $H$ be a basis for $V$. Then:

- (a) For all vectors $v, w$ in $V$,
  $\langle v, w\rangle = ([v]_H)^T b_H [w]_H$.
- (b) For all integers $1 \le k \le m$ and all vectors $v_1, …, v_k, w_1, …, w_k$ in $V$,
  $\begin{bmatrix} \langle v_1,w_1\rangle & \dots & \langle v_1,w_k\rangle \\ \vdots & \ddots & \vdots \\ \langle v_k,w_1\rangle & \dots & \langle v_k,w_k\rangle \end{bmatrix} = [ [v_1]_H \dots [v_k]_H ]^T b_H [ [w_1]_H \dots [w_k]_H ]$.

Proof. (a): Let $H = (h_1, …, h_m)$, and let $v = \sum_i a^i h_i$ and $w = \sum_j b^j h_j$. Then

```
([v]_H)^T = [a^1 … a^m] and [w]_H = [b^1 … b^m]^T,
```

hence

```
⟨v, w⟩ = ⟨ Σ_i a^i h_i, Σ_j b^j h_j ⟩ = Σ_{ij} a^i b^j ⟨h_i, h_j⟩ = Σ_{ij} a^i b^j b_{ij} = ([v]_H)^T b_H [w]_H.
```

(b): It follows from Theorem 2.1.5(b) and part (a) that

$[[v_1]_H ... [v_k]_H]^T b_H [[w_1]_H ... [w_k]_H] = [([v_i]_H)^T b_H [w_j]_H] = [\langle v_i, w_j\rangle]$

## Theorem 3.1.3 (Change of Basis). Let $V$ be a vector space, let b be a bilinear function on $V$, and let $H$ and $F$ be bases for $V$. Then

$b_F = ([id_V]_F^H)^T b_H [id_V]_F^H$.

Proof. We have

$([id_V]_F^H)^T b_H [id_V]_F^H = [[f_1]_H ... [f_m]_H]^T b_H [[f_1]_H ... [f_m]_H]$ [(2.2.7)] $= [\langle f_i, f_j\rangle]$ [Th 3.1.2(b)] $= b_F$.

We close this section with a few definitions that will be useful later on. Let $V$ be a vector space, and let b be a bilinear function on $V$. The quadratic function corresponding to b is the function

$q : V \longrightarrow \mathbb{R}$

defined by

$q(v) = \langle v, v\rangle$

for all vectors $v$ in $V$. It is easily shown that

$q(v + w) - q(v) - q(w) = b(v, w) + b(w, v)$ (3.1.1)

for all vectors $v, w$ in $V$.

Several of the earlier definitions can be expressed in terms of $q$. Specifically, b is:

- positive definite if $q(v) > 0$ for all nonzero $v$ in $V$.
- negative definite if $q(v) < 0$ for all nonzero $v$ in $V$.
- positive semidefinite if $q(v) \ge 0$ for all $v$ in $V$.
- negative semidefinite if $q(v) \le 0$ for all $v$ in $V$.
- spacelike if $v = 0$ or $q(v) > 0$.
- timelike if $q(v) < 0$.
- lightlike if $v \neq 0$ and $q(v) = 0$.

We say that $v$ is a unit vector if $\langle v, v\rangle = \pm 1$, and that $v$ is orthogonal to $w$ if $\langle v, w\rangle = 0$. In particular, the zero vector is orthogonal to every vector in $V$,

and a lightlike vector is orthogonal to itself. Unless **b** is symmetric, $\langle w,v\rangle$ may not equal $\langle v,w\rangle$. Thus, even when $v$ is orthogonal to $w$, it does not necessarily follow that $w$ is orthogonal to $v$.

Let $U$ be a subspace of $V$. The **perp of $U$ (in $V$ with respect to $\mathbf b$)** is denoted by $U^\perp$ and defined to be the set of vectors in $V$ that are orthogonal (perpendicular) to every vector in $U$:

$U^\perp = \{v \in V : \langle v, u\rangle = 0 \text{ for all } u \in U\}.$

It is easily shown that $U^\perp$ is a subspace of $V$. Let us denote

$(U^\perp)^\perp$ by $U^{\perp\perp}$.

The **light set** of $V$ is denoted by $\Lambda$ and defined to be the set of lightlike vectors in $V$:

$\Lambda = \{v \in V : \langle v, v\rangle = 0\} \setminus \{0\}.$

### 3.2 Symmetric Bilinear Functions

Let $V$ be a vector space, and let **b** be a bilinear function on $V$. Recall from Section 3.1 that **b** is said to be symmetric on $V$ if $\langle v,w\rangle = \langle w,v\rangle$ for all vectors $v,w$ in $V$.

## Theorem 3.2.1. If $V$ is a vector space and **b** is a bilinear function on $V$, then the following are equivalent:

(a) **b** is symmetric (as a bilinear function).

(b) $\mathbf b_{\mathcal H}$ is symmetric (as a matrix) for some basis $\mathcal H$ for $V$.

(c) $\mathbf b_{\mathcal H}$ is symmetric (as a matrix) for every basis $\mathcal H$ for $V$.

**Proof.** (a) ⇒ (c): Straightforward.

(c) ⇒ (b): Straightforward.

(b) ⇒ (a): We have

\[
\begin{aligned}
\langle v,w\rangle &= ([v]_{\mathcal H})^{\mathsf T}\mathbf b_{\mathcal H}[w]_{\mathcal H} && [\text{Th 3.1.2(a)}]\\
&=([v]_{\mathcal H})^{\mathsf T}\mathbf b_{\mathcal H}^{\mathsf T}[w]_{\mathcal H} &&\\
&=(([w]_{\mathcal H})^{\mathsf T}\mathbf b_{\mathcal H}[v]_{\mathcal H})^{\mathsf T} && [\text{Th 2.1.2(b)}]\\
&=\langle w,v\rangle^{\mathsf T} && [\text{Th 3.1.2(a)}]\\
&=\langle w,v\rangle.
\end{aligned}
\]

## Theorem 3.2.2. Let $V$ be a vector space, let **b** be a bilinear function on $V$, and let $q$ be the corresponding quadratic function. Then **b** is symmetric if and only if

\[
\mathbf b(v,w)=\frac{q(v+w)-q(v)-q(w)}{2}
\]

(polarization identity)

for all vectors $v,w$ in $V$.
