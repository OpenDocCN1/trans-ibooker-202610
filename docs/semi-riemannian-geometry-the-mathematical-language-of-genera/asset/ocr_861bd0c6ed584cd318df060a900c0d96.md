(b): Using Theorem 15.3.2 and Theorem 18.1.2, it is easily shown that $T$ is additive in both arguments. For functions $f,g$ in $C^\infty(M)$, we have from the same two theorems that

```
$$\begin{aligned}
T(fX,gY)&=\nabla_{fX}(gY)-\nabla_{gY}(fX)-[fX,gY]\\
&=(fX(g)Y+fg\,\nabla_X(Y))-(gY(f)X+fg\,\nabla_Y(X))\\
&\quad -(fg[X,Y]+fX(g)Y-gY(f)X)\\
&=fg(\nabla_X(Y)-\nabla_Y(X)-[X,Y])\\
&=fgT(X,Y),
\end{aligned}$$
```

so $T$ is $C^\infty(M)$-bilinear.

Let $(M,\nabla)$ be a smooth $m$-manifold with a connection, and let $(U,(x^i))$ be a chart on $M$. In local coordinates, $T(\partial/\partial x^i,\partial/\partial x^j)$ can be expressed as

```
$$T\left(\frac{\partial}{\partial x^i},\frac{\partial}{\partial x^j}\right)=\sum_k T^k_{ij}\frac{\partial}{\partial x^k}.$$
```

where the $T^k_{ij}$ are uniquely determined functions in $C^\infty(U)$.

# **Theorem 18.6.3.** *With the above setup:*

+   (a) $T^k_{ij}=\Gamma^k_{ij}-\Gamma^k_{ji}$ for $i,j,k=1,\ldots,m$.
+   
+   (b) $\nabla$ is symmetric if and only if for all such local coordinate expressions, $\Gamma^k_{ij}=\Gamma^k_{ji}$ for $i,j,k=1,\ldots,m$.

*Proof.* (a): We have from Theorem 15.3.3(b) and (18.2.1) that

```
$$\begin{aligned}
T\left(\frac{\partial}{\partial x^i},\frac{\partial}{\partial x^j}\right)
&=\nabla_{\partial/\partial x^i}\left(\frac{\partial}{\partial x^j}\right)-\nabla_{\partial/\partial x^j}\left(\frac{\partial}{\partial x^i}\right)-\left[\frac{\partial}{\partial x^i},\frac{\partial}{\partial x^j}\right]\\
&=\sum_k(\Gamma^k_{ij}-\Gamma^k_{ji})\frac{\partial}{\partial x^k}.
\end{aligned}$$
```

(b): From Theorem 18.6.2(b), $T$ is R-bilinear, so symmetry is determined by the behavior of $T$ on coordinates frames. By part (a), $T^k_{ij}=0$ if and only if $\Gamma^k_{ij}=\Gamma^k_{ji}$. The result follows.

# **Theorem 18.6.4.** If $(M,\nabla)$ is a smooth manifold with a symmetric connection and $\sigma(r,s):(a,b)\times(-\epsilon,\epsilon)\longrightarrow M$ is a parametrized surface, then

```
$$\frac{\nabla}{\partial r}\left(\frac{\partial\sigma}{\partial s}\right)=\frac{\nabla}{\partial s}\left(\frac{\partial\sigma}{\partial r}\right).$$
```

where $\partial\sigma/\partial r$ and $\partial\sigma/\partial s$ are given by (14.9.1) and Theorem 15.1.5, and $\nabla/\partial r$ and $\nabla/\partial s$ are given by (18.3.3).
