# 19.9  Geodesics

In Section 18.8, a geodesic was defined to be a curve with zero acceleration. We now add to our knowledge of geodesics using the metric properties of semi-Riemannian manifolds. In particular, we find a relationship between geodesics and length.

**Theorem 19.9.1.** If $(M,g)$ is a semi-Riemannian manifold and $\gamma(t):(a,b)\longrightarrow M$ is a geodesic, then:

(a) $\langle d\gamma/dt,d\gamma/dt\rangle:(a,b)\longrightarrow\mathbb{R}$ is a constant function, hence $\gamma$ has constant speed.

(b) $\gamma$ is either spacelike, timelike, or lightlike.

(c) $\gamma$ has constant speed $0$ if and only if it is lightlike.

*Proof.* (a): Since $\gamma$ is a geodesic, $d\gamma/dt$ is a parallel vector field in $\widetilde X(M)$. The result now follows from Theorem 19.3.1.

(b): This follows from part (a).

(c): Straightforward.

**Theorem 19.9.2.** If $p$ and $q$ are distinct points in $\mathbb{R}^m_v$ and $a<b$ are real numbers, then:

(a) The smooth curve $\gamma(t):[a,b]\longrightarrow\mathbb{R}^m_v$ defined by

$$\gamma(t)=p+\frac{t-a}{b-a}(q-p)$$

is the unique geodesic such that $\gamma(a)=p$ and $\gamma(b)=q$.
