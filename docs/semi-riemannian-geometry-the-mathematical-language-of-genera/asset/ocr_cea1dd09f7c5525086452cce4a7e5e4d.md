# 12.6  Lie Bracket in $\mathbb{R}^3_\nu$

Let $(M,g)$ be a regular surface in $\mathbb{R}^3_\nu$. **Lie bracket** is the map

$$[\cdot,\cdot]:\mathfrak{X}(M)\times\mathfrak{X}(M)\longrightarrow\mathfrak{X}(M)$$

defined by

$$[X,Y]=\nabla_X(Y)-\nabla_Y(X)$$ \tag{12.6.1}

for all vector fields $X,Y$ in $\mathfrak{X}(M)$.
