# Theorem 15.11.8. Let M be a smooth manifold, let λ(t) : (a, b) ⟶ M be a smooth curve, let ω be a covector field in 𝔛*(M), and view (a, b) as a smooth 1-manifold. Then

```
λ*(ω)_t = ω_{λ(t)} ( dλ/dt (t) ) d(t)
```

for all t in (a, b).

Proof. Let p be a point in M, let (U, (x^i)) be a chart at p, and, in local coordinates, let

```
ω = Σ_i α_i d(x^i).
```

By Theorem 15.11.3,

```
λ*(ω)_t = ( Σ_i α_i(λ(t)) d(x^i ∘ λ)/dt (t) ) d(t). (15.11.5)
```

On the other hand, (15.4.4) gives

```
ω_{λ(t)} = Σ_j α_j(λ(t)) d(x^j)_{λ(t)} = Σ_j α_j(λ(t)) d_{λ(t)}(x^j),
```

hence

```
ω_{λ(t)} ( ∂/∂x^i |_{λ(t)} ) = Σ_j [ α_j(λ(t)) d_{λ(t)}(x^j) ( ∂/∂x^i |_{λ(t)} ) ] = α_i(λ(t))
```

for i = 1, …, m. By Theorem 14.7.1(b),

```
dλ/dt (t) = Σ_i d(x^i ∘ λ)/dt (t) ∂/∂x^i |_{λ(t)} ,
```

so

```
ω_{λ(t)} ( dλ/dt (t) ) = Σ_{ij} d(x^i ∘ λ)/dt (t) ω_{λ(t)} ( ∂/∂x^i |_{λ(t)} ) = Σ_{ij} α_i(λ(t)) d(x^i ∘ λ)/dt (t). (15.11.6)
```

Substituting (15.11.6) into (15.11.5) gives the result.
