```
d(f)(X)(p) = d(f)_p(X_p)    [(15.4.1)]
= X_p(f)                [(15.4.4)]
= X(f)(p).              [(15.1.2)]
```

Since p was arbitrary, the result follows.

# Theorem 15.4.6. Let M be a smooth manifold, let f, g be functions in C^∞(M), and let c be a real number. Then:

+   (a) d(cf + g) = c d(f) + d(g).
+   (b) d(fg) = f d(g) + g d(f).

Proof. This follows from Theorem 14.5.6 and (15.4.4).

# Theorem 15.4.7. If M is a smooth manifold and f is a function in C^∞(M), then, in local coordinates,

```
d(f) = Σ_i ∂f/∂x^i d(x^i).
```

Proof. For a point p in M and a vector v in T_p(M), we have

```
d(f)_p(v) = d_p(f)(v)                     [(15.4.4)]
= Σ_i ∂f/∂x^i (p) d_p(x^i)(v)            [Th 14.5.3]
= Σ_i ∂f/∂x^i (p) d(x^i)_p(v)            [(15.4.4)]
= ( Σ_i ∂f/∂x^i d(x^i) |_p )(v).
```

Since p and v were arbitrary, the result follows.
