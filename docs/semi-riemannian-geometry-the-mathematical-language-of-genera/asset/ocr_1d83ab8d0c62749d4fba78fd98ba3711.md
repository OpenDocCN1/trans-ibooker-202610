Proof. By definition,

Grad(f) = \sum_{i} Grad(f)^{i} \frac{\partial}{\partial x^{i}}.

It follows from Theorem 20.3.1 that

\frac{\partial f}{\partial x^{j}} = \left\langle \frac{\partial}{\partial x^{j}}, Grad(f) \right\rangle = \left\langle \frac{\partial}{\partial x^{j}}, \sum_{k} Grad(f)^{k} \frac{\partial}{\partial x^{k}} \right\rangle = \sum_{k} \mathfrak{g}_{jk} Grad(f)^{k},

hence

\sum_{j} \mathfrak{g}^{ij} \frac{\partial f}{\partial x^{j}} = \sum_{j} \mathfrak{g}^{ij} \left( \sum_{k} \mathfrak{g}_{jk} Grad(f)^{k} \right) = \sum_{k} \left( \sum_{j} \mathfrak{g}^{ij} \mathfrak{g}_{jk} \right) Grad(f)^{k}

= \sum_{k} \delta^{i}_{k} Grad(f)^{k} = Grad(f)^{i}.

# Theorem 20.3.3. If (M, \mathfrak{g}) is a semi-Riemannian m-manifold and f, g are functions in C^{\infty}(M), then

Grad(fg) = f Grad(g) + g Grad(f).

Proof. By Theorem 19.4.3, S is C*(M)-linear. The result now follows from Theorem 15.4.6(b) and (20.3.1).

The preceding result has an obvious resemblance to Theorem 10.6.1(a).

# Example 20.3.4 (\mathbb{R}_{\nu}^{m}). Let (r^{1},...,r^{m}), (\partial/\partial r^{1},...,\partial/\partial r^{m}), and (\varepsilon_{1},...,\varepsilon_{m}) be the standard coordinates, corresponding standard coordinate frame, and signature of \mathbb{R}_{\nu}^{m} = (\mathbb{R}^{m}, \mathfrak{g}), respectively. Since \mathfrak{g}^{ij} = \mathfrak{g}_{ij} = \varepsilon_{i}\delta_{ij}, we have from Theorem 20.3.2 that Grad(f)^{i} = \varepsilon_{i}(\partial f/\partial r^{i}), hence

Grad(f) = \left( \varepsilon_{1} \frac{\partial f}{\partial r^{1}}, ..., \varepsilon_{m} \frac{\partial f}{\partial r^{m}} \right).

In \mathbb{R}_{0}^{3}, with standard coordinates (x, y, z), this becomes

Grad(f) = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right) = grad(f),

and in \mathbb{R}_{1}^{4}, with standard coordinates (x, y, z, t), it becomes

Grad(f) = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}, -\frac{\partial f}{\partial t} \right).
