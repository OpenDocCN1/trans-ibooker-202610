# Theorem 7.4.3. Let V be a vector space, let v be a vector in V, and let η and ζ be multicovectors in Λ^s(V) and Λ^{s'}(V), respectively. Then

i_v(η ∧ ζ) = i_v(η) ∧ ζ + (-1)^s η ∧ i_v(ζ).

# Proof.

For reasons exhibited by the proof of Theorem 7.3.1(b), it suffices to consider multicovectors of the form η = ξ^1 ∧ ⋯ ∧ ξ^s and ζ = ξ^{s+1} ∧ ⋯ ∧ ξ^{s+s'}, where ξ^j is a covector in V* for j = 1,2,…,s + s'. By Theorem 7.4.2,

i_v(η ∧ ζ) = i_v(ξ^1 ∧ ⋯ ∧ ξ^s ∧ ξ^{s+1} ∧ ⋯ ∧ ξ^{s+s'}) = Σ_{j=1}^s (-1)^{j-1} ξ^j(v) (ξ^1 ∧ ⋯ ∧ \widehat{ξ^j} ∧ ⋯ ∧ ξ^s) ∧ (ξ^{s+1} ∧ ⋯ ∧ ξ^{s+s'}) + Σ_{j=s+1}^{s+s'} (-1)^{j-1} ξ^j(v) (ξ^1 ∧ ⋯ ∧ ξ^s) ∧ (ξ^{s+1} ∧ ⋯ ∧ \widehat{ξ^j} ∧ ⋯ ∧ ξ^{s+s'}) = ( Σ_{j=1}^s (-1)^{j-1} ξ^j(v) ξ^1 ∧ ⋯ ∧ \widehat{ξ^j} ∧ ⋯ ∧ ξ^s ) ∧ ξ^{s+1} ∧ ⋯ ∧ ξ^{s+s'} + (-1)^s ξ^1 ∧ ⋯ ∧ ξ^s ∧ ( Σ_{j=s+1}^{s+s'} (-1)^{j-(s+1)} ξ^j(v) ξ^{s+1} ∧ ⋯ ∧ \widehat{ξ^j} ∧ ⋯ ∧ ξ^{s+s'} ) = i_v(η) ∧ ζ + (-1)^s η ∧ i_v(ζ).
