# Smooth Manifolds with a
Connection

In the introduction to Part III, we set out the task of developing a theory of differential geometry built upon our earlier study of curves and surfaces, but without having to involve an ambient space. Implicit in this undertaking was the aim of recovering, to the extent possible, the results presented for curves and surfaces. Chapters 14–17 have met significant parts of this agenda. Noticeably absent, however, is a discussion of “covariant derivative” and “metric”. We remedy the first of these deficits in this chapter by adding “connection” to our discussion of smooth manifolds.

## 18.1  Covariant Derivatives

Let $M$ be a smooth manifold. A **connection** on $M$ is a map

$$\nabla : \mathfrak{X}(M) \times \mathfrak{X}(M) \longrightarrow \mathfrak{X}(M)$$

+   such that for all vector fields $X,Y,Z$ in $\mathfrak{X}(M)$ and all functions $f$ in $C^\infty(M)$:
+   
+   [V1] $\nabla(X+Y,Z)=\nabla(X,Z)+\nabla(Y,Z)$.
+   
+   [V2] $\nabla(fX,Y)=f\nabla(X,Y)$.
+   
+   [V3] $\nabla(X,Y+Z)=\nabla(X,Y)+\nabla(X,Z)$.
+   
+   [V4] $\nabla(X,fY)=X(f)Y+f\nabla(X,Y)$.

We refer to the pair $(M,\nabla)$ as a **smooth manifold with a connection**. It is possible for a given smooth manifold to have more than one connection. Thus, a connection is not a fundamental constituent of the manifold in the same way that, for example, the boundary forms part of a smooth manifold with boundary.

### Example 18.1.1.

There are two obvious examples of connections. Let U be an open set in ℝ^m. Viewing U as a smooth m-manifold, let

D : 𝔛(U) × 𝔛(U) ⟶ 𝔛(U)

be the map defined by

D(X, Y) = D_X(Y)

for all vector fields X, Y in 𝔛(U), where D_X is the Euclidean derivative with respect to X. It follows from Theorem 10.3.1 that D is a connection on U.

Similarly, let (M, 𝔤) be a regular surface in ℝ³. According to Example 14.1.5, M is a smooth 2-manifold. Let

∇ : 𝔛(M) × 𝔛(M) ⟶ 𝔛(M)

be the map defined by

∇(X, Y) = ∇_X(Y)

for all vector fields X, Y in 𝔛(M), where ∇_X is the covariant derivative with respect to X. We have from Theorem 12.4.1 that ∇ is a connection on M. ◇

In each of the preceding examples, we started with a “derivative” and used it to define a connection. Given a smooth manifold with a connection, we can reverse that process.

Let (M, ∇) be a smooth manifold with a connection, and let X be a vector field in 𝔛(M). We define a map

∇_X : 𝔛(M) ⟶ 𝔛(M)

by

∇_X(Y) = ∇(X, Y)

for all vector fields Y in 𝔛(M). It follows from [∇3] and [∇4] that ∇_X is ℝ^m-linear, and from [∇4] that

∇_X(fY) = X(f)Y + f∇_X(Y)

for all functions f in C^∞(M) and all vector fields Y in 𝔛(M). By Theorem 16.2.7, there corresponds a unique tensor derivation

∇_X : 𝒯_s^r(M) ⟶ 𝒯_s^r(M)

on M, called the covariant derivative with respect to X, where (∇_X)_s^r has been abbreviated to ∇_X. In particular, we have

∇_X(f) = X(f) (18.1.1)

for all functions f in C^∞(M).

### Theorem 18.1.2 (Vector Field Properties of Covariant Derivative).

Let (M, ∇) be a smooth manifold with a connection, let X, Y, Z be vector fields in 𝔛(M), and let f be a function in C^∞(M). Then:

+   (a) ∇_{X+Y}(Z) = ∇_X(Z) + ∇_Y(Z).
+   (b) ∇_{fX}(Y) = f∇_X(Y).
+   (c) ∇_X(Y + Z) = ∇_X(Y) + ∇_X(Z).
+   (d) ∇_X(fY) = X(f)Y + f∇_X(Y).

Proof. This follows immediately from properties [∇1]–[∇4].

### Theorem 18.1.3 (Tensor Field Properties of Covariant Derivative).

Let (M,∇) be a smooth manifold with a connection, let X be a vector field in 𝔛(M), and let 𝒜,ℬ and 𝒞 be tensor fields in 𝒯_s^r(M) and 𝒯_{s'}^r'(M), respectively. Then:

+   (a) ∇_X(𝒜 + ℬ) = ∇_X(𝒜) + ∇_X(ℬ).
+   (b) ∇_X(𝒜 ⊗ 𝒞) = ∇_X(𝒜) ⊗ 𝒞 + 𝒜 ⊗ ∇_X(𝒞).

Proof. This follows from the defining properties of tensor derivations given in Section 16.2.

### Theorem 18.1.4 (Global Expression for Covariant Derivative).

Let (M,∇) be a smooth manifold with a connection, let 𝒜 be a tensor field in 𝒯_s^r(M), let X, Y₁,...,Y_s be vector fields in 𝔛(M), and let ω¹,...,ω^r be covector fields in 𝔛*(M). Then

∇_X(𝒜)(ω¹,...,ω^r, Y₁,...,Y_s)
= X(𝒜(ω¹,...,ω^r, Y₁,...,Y_s))
− ∑_{i=1}^r 𝒜(ω¹,...,ω^{i−1}, ∇_X(ω^i), ω^{i+1},...,ω^r, Y₁,...,Y_s)
− ∑_{j=1}^s 𝒜(ω¹,...,ω^r, Y₁,...,Y_{j−1}, ∇_X(Y_j), Y_{j+1},...,Y_s).

Proof. This follows from Theorem 16.2.4.

### Example 18.1.5.

Let (M,∇) be a smooth manifold with a connection, let 𝒜 be a tensor field in 𝒯₂⁰(M), let X,Y,Z be vector fields in 𝔛(M), and let ω be a covector field in 𝔛*(M)=𝒯₁⁰(M). We have from (18.1.1) and Theorem 18.1.4 that

∇_X(ω)(Y) = X(ω(Y)) − ω(∇_X(Y)) = ∇_X(ω(Y)) − ω(∇_X(Y))    (18.1.2)

and

∇_X(𝒜)(Y,Z) = X(𝒜(Y,Z)) − 𝒜(∇_X(Y),Z) − 𝒜(Y,∇_X(Z))
= ∇_X(𝒜(Y,Z)) − 𝒜(∇_X(Y),Z) − 𝒜(Y,∇_X(Z)).    (18.1.3)

It is easily shown that if 𝒜 is symmetric in its two arguments, then so is ∇_X(𝒜).

Let $(M,\nabla)$ be a smooth manifold with a connection, and let $X$ be a vector field in $\mathfrak{X}(M)$. It can be shown that $\nabla_X$ is determined pointwise in the following sense: for all points $p$ in $M$ and all vector fields $Y$ in $\mathfrak{X}(M)$,

$$\nabla_X(Y)_p = \nabla_{\tilde{X}}(Y)_p$$

for all vector fields $X,\tilde{X}$ in $\mathfrak{X}(M)$ such that $X_p = \tilde{X}_p$. For each point $p$ in $M$ and vector $v$ in $T_p(M)$, we define a vector $\nabla_v(Y)$ in $T_p(M)$ by

$$\nabla_v(Y) = \nabla_X(Y)_p \tag{18.1.4}$$

where $X$ is any vector field in $\mathfrak{X}(M)$ such that $X_p = v$. By Theorem 15.1.2, such an $X$ always exists. Since $\nabla_X$ is determined pointwise, $\nabla_v(Y)$ is independent of the choice of vector field and is therefore well-defined. It follows from (18.1.4) that for all vector fields $X,Y$ in $\mathfrak{X}(M)$,

$$\nabla_{X_p}(Y) = \nabla_X(Y)_p \tag{18.1.5}$$

By definition, $\operatorname{Lin}(\mathfrak{X}(M),\mathfrak{X}(M))$ is the vector space of $\mathbb{R}$-linear maps from the vector space $\mathfrak{X}(M)$ to itself. We make $\operatorname{Lin}(\mathfrak{X}(M),\mathfrak{X}(M))$ into a ring over $\mathbb{R}$ by defining multiplication to be composition of maps. Let $\Theta,\Upsilon,\Psi$ be three such maps, and define the bracket of $\Theta$ and $\Upsilon$ by

$$[\Theta,\Upsilon] = \Theta \circ \Upsilon - \Upsilon \circ \Theta.$$

It is easily shown that with this definition, $\operatorname{Lin}(\mathfrak{X}(M),\mathfrak{X}(M))$ is a Lie algebra over $\mathbb{R}$. In particular, Jacobi's identity is satisfied:

$$[[\Theta,\Upsilon],\Psi] + [[\Upsilon,\Psi],\Theta] + [[\Psi,\Theta],\Upsilon] = 0.$$

For vector fields $X,Y,Z$ in $\mathfrak{X}(M)$, we have from parts (c) and (d) of Theorem 18.1.2 that $\nabla_X,\nabla_Y,\nabla_Z$ are maps in $\operatorname{Lin}(\mathfrak{X}(M),\mathfrak{X}(M))$, hence

$$[[\nabla_X,\nabla_Y],\nabla_Z] + [[\nabla_Y,\nabla_Z],\nabla_X] + [[\nabla_Z,\nabla_X],\nabla_Y] = 0. \tag{18.1.6}$$

## 18.2 Christoffel Symbols

In our study of regular surfaces in $\mathbb{R}_p^3$, we defined Christoffel symbols and used them to construct the covariant derivative, which we now think of as equivalent to a connection (see Example 18.1.1).
