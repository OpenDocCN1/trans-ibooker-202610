
## 19.3 Fundamental Theorem of Semi-Riemannian Manifolds

**Theorem 19.3.6 (Normal Coordinates).**

If $(M,g)$ is a semi-Riemannian $m$-manifold with signature $(\epsilon_1,\ldots,\epsilon_m)$ and $p$ is a point in $M$, then, in normal coordinates at $p$,

$$g_{ij}(p)=\epsilon_i\delta_{ij}\qquad\text{and}\qquad \Gamma^k_{ij}(p)=0$$

for $i,j,k=1,\ldots,m$.

**Proof.** Continuing with the setup at the beginning of Section 18.10, suppose $(\tilde e_1,\ldots,\tilde e_m)$ is an orthonormal basis for $T_p(M)$. From Theorem 18.10.1(a) and (19.1.1),

$$g_{ij}(p)=\left\langle\left.\frac{\partial}{\partial x^i}\right|_p,\left.\frac{\partial}{\partial x^j}\right|_p\right\rangle=\langle\tilde e_i,\tilde e_j\rangle.$$

By definition, $T_p(M)$ and $M$ have the same signature, hence $\langle\tilde e_i,\tilde e_j\rangle=\epsilon_i\delta_{ij}$. This proves the first identity. The second identity is a repeat of Theorem 18.10.2.

Let $(M,g)$ be a semi-Riemannian manifold, let $U$ be an open set in $M$, and let $\mathcal X=(X_1,\ldots,X_m)$ be a frame on $U$. We say that $\mathcal X$ is **orthonormal** if $\mathcal X_p=(X_{1|p},\ldots,X_{m|p})$ is an orthonormal basis for $T_p(M)$ for all $p$ in $U$. When $M$ is oriented, $\mathcal X$ is said to be **positively oriented** if $\mathcal X_p$ is positively oriented for all $p$ in $U$.

**Theorem 19.3.7 (Existence of Orthonormal Frame).**

Every point in a semi-Riemannian manifold has a neighborhood on which there is an orthonormal frame. If the semi-Riemannian manifold is oriented, then the orthonormal frame can be chosen to be positively oriented.

**Proof.** Let $(M,g)$ be a semi-Riemannian manifold, let $p$ be a point in $M$, and let $(e_1,\ldots,e_m)$ be an orthonormal basis for $T_p(M)$. Let $V$ be a normal neighborhood of $p$ in $M$, let $\exp_p:\widetilde V\longrightarrow V$ be the corresponding diffeomorphism, and let $\gamma(t):[0,1]\longrightarrow M$ be a radial geodesic with starting point $p$. By Theorem 18.5.7, there is a unique frame $(E_{1\gamma},\ldots,E_{m\gamma})$ on $\gamma$ consisting of parallel vector fields in $\mathcal X_m(\gamma)$ such that $(E_{1\gamma}(0),\ldots,E_{m\gamma}(0))=(e_1,\ldots,e_m)$ and $(E_{1\gamma}(t),\ldots,E_{m\gamma}(t))$ is a basis for $T_{\gamma(t)}(M)$ for all $t$ in $[0,1]$. It follows from Theorem 19.3.1 that $\langle E_{i\gamma}(t),E_{j\gamma}(t)\rangle=\langle e_i,e_j\rangle$ for all $t$ in $[0,1]$ for $i,j=1,\ldots,m$. Thus, each $(E_{1\gamma}(t),\ldots,E_{m\gamma}(t))$ is an orthonormal basis. It can be shown that combining these vector fields across all radial geodesics with starting point $p$ yields an orthonormal frame $(E_1,\ldots,E_m)$ on $V$.

Now suppose $M$ is oriented. Replacing $e_1$ with $-e_1$ if necessary, we assume without loss of generality that $(E_{1|p},\ldots,E_{m|p})=(e_1,\ldots,e_m)$ is a positively oriented orthonormal basis for $T_p(M)$ and that the above construction has been revised accordingly. By Theorem 16.6.5, there is an orientation form $\varpi$ that induces the orientation of $M$. Then $\varpi_p(E_{1|p},\ldots,E_{m|p})>0$, hence $f=\varpi|_V(E_1,\ldots,E_m)$ is a function in $C^\infty(V)$ such that $f(p)>0$. Since $f$ is smooth, by Theorem 14.2.2, it is continuous. Let $\epsilon>0$ be a real number such that the open interval I = (f(p)−ε, f(p)+ε) consists of positive real numbers. By Theorem 9.1.5 and Theorem 9.1.7, W = f⁻¹(I) is a neighborhood of p in M on which f is positive-valued. It follows that (E₁, …, Eₘ) is positively oriented on W.

We call upon Theorem 19.3.7 often, but usually without attribution.

**Theorem 19.3.8.** Let $(M, \mathfrak g)$ be a semi-Riemannian manifold, let $X$ be a vector field in $\mathfrak X(M)$, and let $\mathcal A$ be a tensor field in $\mathcal T_s^r(M)$. Then

$\nabla_X(\mathfrak g \otimes \mathcal A) = \mathfrak g \otimes \nabla_X(\mathcal A)$.

Proof. We have

$\nabla_X(\mathfrak g \otimes \mathcal A) = \nabla_X(\mathfrak g) \otimes \mathcal A + \mathfrak g \otimes \nabla_X(\mathcal A)$ [Th 18.1.3(b)] = $\mathfrak g \otimes \nabla_X(\mathcal A)$. [Th 18.4.1, Th 19.3.1]

## 19.4 Flat Maps and Sharp Maps

In this section, we present manifold versions of the flat maps and sharp maps defined in Section 3.3, Section 6.2, and Section 6.3.

Let $(M, \mathfrak g)$ be a semi-Riemannian manifold. For a given vector field $X$ in $\mathfrak X(M)$, we define a map

$X^f : \mathfrak X(M) \longrightarrow C^\infty(M)$

by

$X^f(Y) = \langle X, Y \rangle$ (19.4.1)

for all vector fields $Y$ in $\mathfrak X(M)$.

**Theorem 19.4.1.** With the above setup, $X^f$ is a covector field in $\mathfrak X^*(M)$.

Proof. Let $Y, Z$ be vector fields in $\mathfrak X(M)$, and let $f$ be a function in $C^\infty(M)$. Then

$X^f(Y + Z) = \langle X, Y + Z \rangle = \langle X, Y \rangle + \langle X, Z \rangle = X^f(Y) + X^f(Z)$

and $(fX)^f(Y) = \langle fX, Y \rangle = f\langle X, Y \rangle = f X^f(Y)$, so $X^f$ is a map in $\operatorname{Lin}_{C^\infty(M)}(\mathfrak X(M), C^\infty(M))$. The result now follows from Theorem 15.5.3.

The flat map on $M$ is the map

$F : \mathfrak X(M) \longrightarrow \mathfrak X^*(M)$

defined by the assignment

$X \mapsto X^f$

for all vector fields $X$ in $\mathfrak X(M)$. Thus, as a matter of notation,

$F(X) = X^f$.

## Theorem 19.4.2.

With the above setup, $F$ is a $C^\infty(M)$-module isomorphism:

$$\mathfrak{X}(M) \cong \mathfrak{X}^*(M).$$

**Proof.** It is easily shown that $F$ is a $C^\infty(M)$-module homomorphism. We need to show that $F$ is bijective.

**Injectivity.** Since $\mathbf g$ is nondegenerate, $\ker(F)=0$. It follows from Theorem B.5.3 that $F$ is injective.

**Surjectivity.** Let $\omega$ be a covector field in $\mathfrak{X}^*(M)$, let $(U,(x^i))$ be a chart on $M$, and, in local coordinates, let $\omega|_U=\sum_i\alpha_i d(x^i)$. Define a vector field $X|_U$ in $\mathfrak{X}(U)$ by

$$X|_U=\sum_{ij}g^{ij}\alpha_i\frac{\partial}{\partial x^j}.$$

Then

$(X|_U)^F\left(\frac{\partial}{\partial x^i}\right)=\left\langle X|_U,\frac{\partial}{\partial x^i}\right\rangle=\left\langle\sum_{jk}g^{jk}\alpha_j\frac{\partial}{\partial x^k},\frac{\partial}{\partial x^i}\right\rangle=\sum_{jk}\alpha_jg^{jk}g_{ki}$

$=\sum_j\alpha_j\left(\sum_kg^{jk}g_{ki}\right)=\sum_j\delta_i^j\alpha_j=\alpha_i$

for $i=1,\ldots,m$, hence

$$\omega|_U=\sum_i(X|_U)^F\left(\frac{\partial}{\partial x^i}\right)d(x^i)$$

It follows from the manifold version of Theorem 1.2.1(e) that $(X|_U)^F=\omega|_U$.

Let $(\widetilde U,\widetilde\varphi)$ be a chart on $M$ that overlaps with $(U,\varphi)$, and, in local coordinates, let $\omega|_{\widetilde U}=\sum_i\widetilde\alpha_i d(\widetilde x^i)$. We have

$$\frac{\partial}{\partial\widetilde x^i}=\sum_q\frac{\partial x^q}{\partial\widetilde x^i}\frac{\partial}{\partial x^q},\qquad \widetilde\alpha_j=\sum_p\frac{\partial x^p}{\partial\widetilde x^j}\alpha_p,\qquad \widetilde g^{ij}=\sum_{kl}\frac{\partial\widetilde x^i}{\partial x^k}g^{kl}\frac{\partial\widetilde x^j}{\partial x^l},$$

where the first identity follows from Theorem 15.1.8, the second identity from Theorem 15.6.3, and the third identity from the manifold version of Theorem 2.2.5(b), Theorem 14.3.5(b), and Theorem 19.1.3. Then

$X|_{\widetilde U}=\sum_{ij}\widetilde g^{ij}\widetilde\alpha_i\frac{\partial}{\partial\widetilde x^j}=\sum_{ijkl p q}\left(\frac{\partial\widetilde x^i}{\partial x^k}g^{kl}\frac{\partial\widetilde x^j}{\partial x^l}\right)\left(\frac{\partial\widetilde x^j}{\partial x^p}\alpha_p\right)\left(\frac{\partial x^q}{\partial\widetilde x^i}\frac{\partial}{\partial x^q}\right)$

$=\sum_{klp q}\left[g^{kl}\alpha_p\left(\sum_i\frac{\partial\widetilde x^i}{\partial x^k}\frac{\partial x^q}{\partial\widetilde x^i}\right)\left(\sum_j\frac{\partial\widetilde x^j}{\partial x^l}\frac{\partial x^p}{\partial\widetilde x^j}\right)\frac{\partial}{\partial x^q}\right]$

$=\sum_{klpq}\delta_k^q\delta_l^p g^{kl}\alpha_p\frac{\partial}{\partial x^q}$

$=\sum_{kl}g^{kl}\alpha_k\frac{\partial}{\partial x^l}=X|_U,$

so there is agreement on overlaps. Taken together, the $X|_U$, one for each point in $M$, define a vector field $X$ in $\mathfrak X(M)$ such that $X^F = \omega$. Thus, $F$ is surjective.

The sharp map

$S : \mathfrak X^*(M) \longrightarrow \mathfrak X(M)$

on $M$ is defined to be the inverse of $F$; that is,

$S = F^{-1}$.

Let $1 \le k \le r$ and $1 \le l \le s + 1$ be integers (so that $r \ge 1$ and $s \ge 0$). The $(k, l)$-flat map is denoted by

$F_l^k : \mathcal T_s^r(M) \longrightarrow \mathcal T_{s+1}^{r-1}(M)$

and defined (using Theorem 15.7.2) for all tensor fields $\mathcal A$ in $\mathcal T_s^r(M)$, all covector fields $\omega^1, \dots, \omega^{r-1}$ in $\mathfrak X^*(M)$, and all vector fields $X_1, \dots, X_{s+1}$ in $\mathfrak X(M)$ as follows, where $^\wedge$ indicates that an expression is omitted:

- For $r = 1$ (so that $k = 1$):

$F_l^1(\mathcal A)(X_1, \dots, X_{s+1}) = \mathcal A(X_l^F, X_1, \dots, \hat X_l, \dots, X_{s+1})$.

- For $r \ge 2$ and $1 \le k \le r - 1$:

$F_l^k(\mathcal A)(\omega^1, \dots, \omega^{r-1}, X_1, \dots, X_{s+1}) = \mathcal A(\omega^1, \dots, \omega^{k-1}, X_l^F, \omega^k, \dots, \omega^{r-1}, X_1, \dots, \hat X_l, \dots, X_{s+1})$.

- For $r \ge 2$ and $k = r$:

$F_l^r(\mathcal A)(\omega^1, \dots, \omega^{r-1}, X_1, \dots, X_{s+1}) = \mathcal A(\omega^1, \dots, \omega^{r-1}, X_l^F, X_1, \dots, \hat X_l, \dots, X_{s+1})$.

Similarly, let $1 \le k \le r + 1$ and $1 \le l \le s$ be integers (so that $r \ge 0$ and $s \ge 1$). The $(k, l)$-sharp map is denoted by

$S_l^k : \mathcal T_s^r(M) \longrightarrow \mathcal T_{s-1}^{r+1}(M)$

and defined (using Theorem 15.7.2) for all tensor fields $\mathcal A$ in $\mathcal T_s^r(M)$, all covector fields $\omega^1, \dots, \omega^{r+1}$ in $\mathfrak X^*(M)$, and all vector fields $X_1, \dots, X_{s-1}$ in $\mathfrak X(M)$ as follows:

- For $s = 1$ (so that $l = 1$):

$S_1^k(\mathcal A)(\omega^1, \dots, \omega^{r+1}) = \mathcal A(\omega^1, \dots, \hat\omega^k, \dots, \omega^{r+1}, \omega^k S)$.

- For $s \ge 2$ and $1 \le l \le s - 1$:

$S_l^k(\mathcal A)(\omega^1, \dots, \omega^{r+1}, X_1, \dots, X_{s-1}) = \mathcal A(\omega^1, \dots, \hat\omega^k, \dots, \omega^{r+1}, X_1, \dots, X_{l-1}, \omega^k S, X_l, \dots, X_{s-1})$.
