for i, j = 1, ..., m. Observe that the Γ^k_ij(p) are independent of the choice of (r^1, ..., r^m). Setting

```
(r^1, ..., r^i, ..., r^m) = (0, ..., 1, ..., 0)
```

yields

```
Γ^k_ii(p) = 0    (18.10.4)
```

for i = 1, ..., m; and setting

```
(r^1, ..., r^i, ..., r^j, ..., r^m) = (0, ..., 1, ..., 1, ..., 0)
```

gives

```
0 = Γ^k_ii(p) + Γ^k_ij(p) + Γ^k_ji(p) + Γ^k_jj(p) = 2Γ^k_ij(p)
```

for i ≠ j = 1, ..., m, where the last equality follows from Theorem 18.6.3(b) and (18.10.4).

# 18.11 Jacobi Fields

On intuitive grounds, it seems that the way geodesics radiate from a given point on a smooth manifold, and the rapidity with which they spread out, should be related to the “curvature” of the smooth manifold at that point. This line of reasoning leads to a consideration of Jacobi fields.

Let (M, ∇) be a smooth manifold with a connection, and let γ(r) : (a, b) ⟶ M be a geodesic. We say that the vector field J in 𝔛_M(γ) is a Jacobi field if it satisfies Jacobi’s equation:

```
R(J, dγ/dr) dγ/dr + ∇²J/dr² = 0,    (18.11.1)
```

where we denote

```
∇/dr ∘ ∇/dr  by  ∇²/dr².
```

By Theorem 18.7.1(a), Jacobi’s equation is equivalent to

```
R(dγ/dr, J) dγ/dr = ∇²J/dr².
```

# Theorem 18.11.1 (Existence of Jacobi Field). Let (M, ∇) be a smooth manifold with a connection, and let p be a point in M. Let γ(r) : (a, b) ⟶ M be a geodesic, with γ(0) = p, and let v, w be vectors in T_p(M). Then there is a unique Jacobi field J in 𝔛_M(γ) such that J(0) = v and (∇J/∂r)(0) = w.

Proof. It can be shown that Jacobi’s equation is equivalent to a system of ordinary differential equations. The result now follows from the theory of differential equations.
