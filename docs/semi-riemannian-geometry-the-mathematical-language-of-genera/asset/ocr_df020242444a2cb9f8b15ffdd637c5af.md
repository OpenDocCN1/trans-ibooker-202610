so that, for example,

```
I₁ = [1]      I₂ = [1 0; 0 1]      I₃ = [1 0 0; 0 1 0; 0 0 1].
```

We say that a matrix Q in Matₘ×ₘ is invertible if there is a matrix in Matₘ×ₘ, denoted by Q⁻¹ and called the inverse of Q, such that

```
QQ⁻¹ = Q⁻¹Q = Iₘ.
```

It is easily shown that if the inverse of a matrix exists, then it is unique.

# Theorem 2.1.3. If P and Q are invertible matrices in Matₘ×ₘ, then:

+   (a) (P⁻¹)⁻¹ = P.
+   (b) (PQ)⁻¹ = Q⁻¹P⁻¹.
+   (c) (P⁻¹)ᵀ = (Pᵀ)⁻¹.

Proof. (a), (b): Straightforward.

```
Iₘ = (Iₘ)ᵀ = (PP⁻¹)ᵀ = (P⁻¹)ᵀPᵀ,
```
