# 2.4 Determinant of Matrices

The next result is not usually included in an overview of determinants, but it will prove invaluable later on.

# Theorem 2.4.10 (Cauchy–Binet Identity). Let $1\le k\le m$ be integers.

+   (a) If $P$ and $Q$ are matrices in $\operatorname{Mat}_{m\times k}$, then
+   
+   $$\det(P^{\mathsf T}Q)=\sum_{I\in\mathcal I_{k,m}}\det(P^I)\det(Q^I).$$

+   (b) If $R$ and $S$ are matrices in $\operatorname{Mat}_{k\times m}$, then
+   
+   $$\det(RS^{\mathsf T})=\sum_{J\in\mathcal I_{k,m}}\det(R_J)\det(S_J).$$

*Proof.* (a): Let $Q=[q_j^i]$, so that

$$Q=[Q_{(1)}\ \cdots\ Q_{(k)}],\qquad Q_{(j)}=[q_j^1\ \cdots\ q_j^m]^{\mathsf T},$$

and

$$P^{\mathsf T}Q_{(j)}=\sum_i q_j^i(P^{\mathsf T})_{(i)}$$

for $j=1,\ldots,k$. We have

$$\begin{aligned}
\det(P^{\mathsf T}Q)
&=\det\big([P^{\mathsf T}Q_{(1)}\ \cdots\ P^{\mathsf T}Q_{(k)}]\big)\\
&=\det\big([\sum_{i_1}q_1^{i_1}(P^{\mathsf T})_{(i_1)}\ \cdots\ \sum_{i_k}q_k^{i_k}(P^{\mathsf T})_{(i_k)}]\big)\\
&=\sum_{1\le i_1,\ldots,i_k\le m}q_1^{i_1}\cdots q_k^{i_k}\det\big([(P^{\mathsf T})_{(i_1)}\ \cdots\ (P^{\mathsf T})_{(i_k)}]\big)\\
&=\sum_{\substack{1\le i_1,\ldots,i_k\le m\\i_1,\ldots,i_k\text{ distinct}}}q_1^{i_1}\cdots q_k^{i_k}\det\big([(P^{\mathsf T})_{(i_1)}\ \cdots\ (P^{\mathsf T})_{(i_k)}]\big)\\
&=\sum_{1\le i_1<\cdots<i_k\le m}\left(\sum_{\sigma\in S_k}q_1^{i_{\sigma(1)}}\cdots q_k^{i_{\sigma(k)}}\det\big([(P^{\mathsf T})_{(i_{\sigma(1)})}\ \cdots\ (P^{\mathsf T})_{(i_{\sigma(k)})}]\big)\right).
\end{aligned}$$

where the third equality follows from Theorem 2.4.2. The term in large parentheses in the last row of the preceding display can be expressed as

$$\begin{aligned}
&\sum_{\sigma\in S_k}q_1^{i_{\sigma(1)}}\cdots q_k^{i_{\sigma(k)}}\det\big([(P^{\mathsf T})_{(i_{\sigma(1)})}\ \cdots\ (P^{\mathsf T})_{(i_{\sigma(k)})}]\big)\\
&=\sum_{\sigma\in S_k}q_1^{i_{\sigma(1)}}\cdots q_k^{i_{\sigma(k)}}\operatorname{sgn}(\sigma)\det\big([(P^{\mathsf T})_{(i_1)}\ \cdots\ (P^{\mathsf T})_{(i_k)}]\big)\\
&=\det\big([(P^{\mathsf T})_{(i_1)}\ \cdots\ (P^{\mathsf T})_{(i_k)}]\big)\left(\sum_{\sigma\in S_k}\operatorname{sgn}(\sigma)q_1^{i_{\sigma(1)}}\cdots q_k^{i_{\sigma(k)}}\right)\\
&=\det(P^{\mathsf T}_{(i_1,\ldots,i_k)})\det(Q^{(i_1,\ldots,i_k)}).
\end{aligned}$$
