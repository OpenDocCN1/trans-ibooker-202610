# Theorem 16.3.1. If M is a smooth manifold and 𝔇 is form derivation on M, then, in local coordinates,

𝔇ₛ(d(x¹) ∧ ⋯ ∧ d(xˢ)) = ∑ᵢ d(x¹) ∧ ⋯ ∧ 𝔇₁(d(xⁱ)) ∧ ⋯ ∧ d(xˢ).

Proof. The proof is by induction. For s = 1, the result is trivial. Let s > 1, and suppose the assertion is true for all indices < s. We have from (16.3.1) that

𝔇ₛ(d(x¹) ∧ ⋯ ∧ d(xˢ)) = 𝔇₁(d(x¹)) ∧ d(x²) ∧ ⋯ ∧ d(xˢ) + d(x¹) ∧ 𝔇ₛ₋₁(d(x²) ∧ ⋯ ∧ d(xˢ)). (16.3.2)

By the induction hypothesis,

𝔇ₛ₋₁(d(x²) ∧ ⋯ ∧ d(xˢ)) = ∑ᵢ₌₂ˢ d(x²) ∧ ⋯ ∧ 𝔇₁(d(xⁱ)) ∧ ⋯ ∧ d(xˢ),

hence

d(x¹) ∧ 𝔇ₛ₋₁(d(x²) ∧ ⋯ ∧ d(xˢ)) = ∑ᵢ₌₂ˢ d(x¹) ∧ d(x²) ∧ ⋯ ∧ 𝔇₁(d(xⁱ)) ∧ ⋯ ∧ d(xˢ). (16.3.3)

Combining (16.3.2) and (16.3.3) gives the result for s.

# Theorem 16.3.2. A form derivation 𝔇 on a smooth manifold M is uniquely determined by its values on C^∞(M) and {d(f) : f ∈ C^∞(M)}.

Proof. Let dim(M) = m, let ω be a form in Λˢ(M), and, in local coordinates, let

ω = ∑_{1 ≤ i₁ < ⋯ < iₛ ≤ m} α_{i₁...iₛ} d(x^{i₁}) ∧ ⋯ ∧ d(x^{iₛ}).

Then

𝔇ₛ(ω) = ∑_{1 ≤ i₁ < ⋯ < iₛ ≤ m} 𝔇_{0+s}(α_{i₁...iₛ} d(x^{i₁}) ∧ ⋯ ∧ d(x^{iₛ})) = ∑_{1 ≤ i₁ < ⋯ < iₛ ≤ m} [𝔇₀(α_{i₁...iₛ}) ∧ d(x^{i₁}) ∧ ⋯ ∧ d(x^{iₛ}) + α_{i₁...iₛ} ∧ 𝔇ₛ(d(x^{i₁}) ∧ ⋯ ∧ d(x^{iₛ}))] = ∑_{1 ≤ i₁ < ⋯ < iₛ ≤ m} [𝔇₀(α_{i₁...iₛ}) d(x^{i₁}) ∧ ⋯ ∧ d(x^{iₛ}) + α_{i₁...iₛ} ∑_{j=1}^s d(x^{i₁}) ∧ ⋯ ∧ 𝔇₁(d(x^{i_j})) ∧ ⋯ ∧ d(x^{iₛ})],

where the second equality follows from (16.3.1), and the third equality from Theorem 16.3.1. The result follows.
