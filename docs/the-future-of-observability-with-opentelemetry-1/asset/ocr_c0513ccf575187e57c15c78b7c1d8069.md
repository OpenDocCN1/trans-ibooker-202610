+   - HTTP servers (application frameworks) must use a propagator to extract the context from the HTTP headers. The extracted context is used to create a *server span*, which is set as the currently active span, which wraps all of the application code.
+   - Likewise, senders in a messaging/queuing system must use propagators to inject the context into the messages, so that tracing can continue by extracting the context on the receiver.
+   - Database clients must create a *database span* to record the database transaction. Once database servers are also instrumented with OpenTelemetry, database clients must also inject the context into the database request.

This requirement is one of the main reasons we would like to see OSS libraries ship with native instrumentation. In the meantime, instrumentation plug-ins are provided as *contrib packages* maintained by the OpenTelemetry project or by third parties.
