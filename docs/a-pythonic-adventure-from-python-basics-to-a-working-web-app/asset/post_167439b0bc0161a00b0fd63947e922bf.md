## New things you have learned today

- **Folders and directories**
  In different operating systems people use different terms for the same thing: a collection of files that belong to a certain project or files of a certain type or purpose.
- **Jinja templates**
  Jinja templates are used by Flask to create HTML pages. You can pass variables, lists, and dictionaries into templates and use them as you would in Python. You can use `for` loops in templates, similar to Python.
- **Database**
  Database is a program that can store data and perform various operations with data. Database can search records using specific criteria, summarize data (like the number of vanilla flavor orders for this month).
- **SQL**
  SQL stands for Structured Query Language and is used to work with databases.
- **Front-end and back-end**
  The front-end part of the application works with users: displays pages, gets input from keyboard and menus. The back-end part works with data: stores and retrieves data from files and databases. Front-end and back-end parts are used for separation of concerns when working on big applications.

Styles specify the ways your HTML elements look on the page. For example, you can say that your <H2> headers should have a size of 36 pixels and should be red. Or they should use a specific font."

He continued, "One of the ideas in web design is separating content from styles. Of course I can set the style in the HTML file. But that is not very convenient. If you want to change the font size or color, you have to go through all your HTML files and change all <H2> headers. Instead of that, we define styles in a separate file where we say: all <H2> headers should use this color and size. If we want to change it—we change it only in one place. Very convenient, huh?"

"I see," Erik said. "It’s like functions in Python. You write it once and then you use it in other places." "Yes, right!" Simon said. "I like you analogy! So we figured out why they are called Style Sheets, but why Cascading? For your web site or application you can have several style sheets and combine them together, one after another. Very often people use a style sheet created by somebody else and add or change only the elements that they want to look differently. It’s another similarity to functions."
