

这种对类型的严格性还有其他影响。由于 Go 中的所有类型转换都是显式的，你不能将另一种 Go 类型当作布尔值处理。在许多语言中，非零数字或非空字符串都可以被解释为布尔值 `true`。就像自动类型提升一样，“真值”的规则因语言而异，可能会令人困惑。毫不奇怪，Go 不允许真值。事实上，*没有任何其他类型可以隐式或显式地转换为 bool*。如果你想将其他数据类型转换为布尔值，必须使用其中一个比较运算符（`==`、`!=`、`>`、`<`、`<=` 或 `>=`）。例如，要检查变量 `x` 是否等于 0，代码应为 `x == 0`。如果你想检查字符串 `s` 是否为空，请使用 `s == ""`。

### Note

类型转换是 Go 选择在简洁性上增加一点冗长，以换取大量简洁性和清晰度的地方之一。你会多次看到这种权衡。惯用的 Go 更看重可理解性而非简洁性。

## min and max

Go 提供了两个用于比较数字和字符串的内置函数，`min` 和 `max`。两者都接受一个或多个值，所有值必须为同一类型。`min` 返回最小值，`max` 返回最大值。

除了内置函数外，Go 在标准库中还提供了几个查找数字最小值或最大值的函数。不幸的是，它们在处理 `NaN`、`Inf` 和 `-Inf` 时的行为不同。对于内置的 `min` 和 `max` 函数，如果传递给函数的值中任一值为 `NaN`，函数将返回 `NaN`，即使其他值包含 `Inf` 或 `-Inf`。`slices.Min` 和 `slices.Max` 函数的行为相同。然而，`math.Min` 和 `math.Max` 函数则相反。它们将负无穷视为最小值，正无穷视为最大值。你可以在 [The Go Playground](https://go.dev/play/p/YdKF8pk3rde) 上看到此演示。

应使用哪个函数取决于具体情况。如果需要与 `math.Min` 和 `math.Max` 的行为兼容，请使用它们。如果比较的值数量可能变化，请使用 `slices.Min` 和 `Max`。在任何其他情况下，首选内置函数。

### Note

为什么 `min` 和 `max` 是内置函数？你可以阅读它们实现前的 [长讨论](https://github.com/golang/go/issues/59488) 来了解历史。其中有两个原因突出，一个是实际的，一个是哲学的。首先，将 `min` 和 `max` 实现为内置的可变参数函数可以避免每次调用时分配内存（内存分配在第 6 章中介绍）。也许更重要的是，人们认为这些是基本操作，如加法或减法，而基本操作应该是内置的。正如 Russ Cox 所说，“这最终是设计直觉和判断的问题。”

## Literals Are Untyped

虽然你不能将两个整数变量相加，如果它们被声明为不同类型的整数，但 Go 允许你在浮点表达式中使用整数字面量，甚至将整数字面量赋给浮点变量：

```
var x float64 = 10
var y float64 = 200.3 * 5
```

这是因为，正如我之前提到的，Go 中的字面量是无类型的。Go 是一种实用的语言，让类型在开发者指定之前保持未指定是有意义的。这意味着它们可以与任何与字面量兼容类型的变量一起使用。当你在第 7 章查看用户定义类型时，你会看到你甚至可以将字面量与基于预定义类型的用户定义类型一起使用。无类型是有一定限制的。你不能将字符串字面量赋给数值类型的变量，也不能将数字字面量赋给字符串变量，也不能将浮点字面量赋给 `int`。这些都会被编译器标记为错误。还存在大小限制。虽然你可以编写大于任何整数可容纳的数字字面量，但尝试将值溢出的字面量赋给指定变量是编译时错误，例如尝试将字面量 1000 赋给类型为 `byte` 的变量。

# var Versus :=

对于一种小型语言来说，Go 有很多种声明变量的方式。这是有原因的：每种声明方式都传达了变量使用方式的信息。让我们回顾一下在 Go 中声明变量的方式，并看看何时使用每种方式。

在 Go 中声明变量最冗长的方式使用 `var` 关键字、显式类型和赋值。它看起来像这样：

```
var x int = 10
```

如果 `=` 右侧的类型是变量预期的类型，你可以省略 `=` 左侧的类型。由于整数字面量的默认类型是 `int`，以下代码将 `x` 声明为类型为 `int` 的变量：

```
var x = 10
```

反之，如果你想声明一个变量并将其赋值为零值，你可以保留类型并去掉右侧的 `=`：

```
var x int
```

你可以使用 `var` 一次声明多个变量，它们可以是同一类型：

```
var x, y int = 10, 20
```

你可以声明同一类型的全部零值：

```
var x, y int
```

或不同类型：

```
var x, y = 10, "hello"
```

使用 `var` 还有一种方式。如果一次声明多个变量，你可以将它们包装在 *声明列表* 中：

```
var (
    x    int
    y        = 20
    z    int = 30
    d, e     = 40, "hello"
    f, g string
)
```

Go 还支持一种简短的声明和赋值格式。当你在函数内部时，可以使用 `:=` 运算符替换使用类型推断的 `var` 声明。以下两个语句完全相同——它们都将 `x` 声明为值为 10 的 `int`：

```
var x = 10
x := 10
```

与 `var` 一样，你可以使用 `:=` 一次声明多个变量。这两行都将 10 赋给 `x`，将 “hello” 赋给 `y`：

```
var x, y = 10, "hello"
x, y := 10, "hello"
```

`:=` 运算符可以做 `var` 做不到的一件事：它允许你同时为现有变量赋值。只要 `:=` 左侧至少有一个新变量，其他变量就可以已经存在：

```
x := 10
x, y := 30, "hello"
```

使用 `:=` 有一个限制。如果你在包级别声明变量，必须使用 `var`，因为 `:=` 在函数外部是非法的。

你如何知道使用哪种风格？一如既往，选择最能表达你意图的。函数内部最常见的声明风格是 `:=`。在函数外部，在极少数需要声明多个包级变量的情况下，使用声明列表。

在函数内的某些情况下，应避免使用 `:=`：

*   当将变量初始化为其零值时，使用 `var x int`。这表明零值是故意为之。

*   当将无类型常量或字面量赋给变量，而常量或字面量的默认类型不是你想要的变量类型时，使用带指定类型的长 `var` 形式。虽然使用类型转换指定值的类型并使用 `:=` 编写 `x := byte(20)` 是合法的，但惯用写法是 `var x byte = 20`。

*   因为 `:=` 允许你同时为新变量和现有变量赋值，所以它有时会在你以为是在重用现有变量时创建新变量（详见 [Link to Come]）。在这些情况下，请使用 `var` 显式声明所有新变量以明确哪些变量是新的，然后使用赋值运算符（`=`）为新旧变量赋值。

虽然 `var` 和 `:=` 允许你在同一行声明多个变量，但仅在为函数返回的多个值赋值或使用逗号 ok 惯用法（见第 5 章）时使用这种风格。
