

还有一种数值类型，它相当不寻常。Go 对复数提供了第一类支持。如果你不知道复数是什么，你就不是这个特性的目标用户；请随意跳过。

Go 中复数支持的内容并不多。Go 定义了两种复数类型。`complex64` 使用 `float32` 值来表示实部和虚部，而 `complex128` 使用 `float64` 值。两者都使用 `complex` 内置函数声明：

```
var complexNum = complex(20.3, 10.2)
```

`complex` 返回的类型取决于其参数。如果两个参数都是 `float32`，或一个参数是 `float32` 而另一个是无类型常量或字面量且能容纳在 `float32` 中，则返回 `complex64`。否则，函数返回 `complex128`。

所有标准浮点算术运算符都适用于复数。与浮点数一样，你可以使用 `==` 或 `!=` 来比较它们，但它们具有相同的精度限制，因此最好使用 epsilon 技术。你可以使用 `real` 和 `imag` 内置函数分别提取复数的实部和虚部。`math/cmplx` 包提供了用于操作 `complex128` 值的其他函数。

两种复数类型的零值都将实部和虚部都赋值为 0。

[示例 1-1](#ch01.html#EX2_4) 显示了一个简单的程序，演示了复数的工作方式。你可以在 [The Go Playground](https://go.dev/play/p/rRofeSJAazA) 上自行运行它，或在 [Chapter 2 repository](https://oreil.ly/zXZqI) 中的 `sample_code/complex_numbers` 目录中运行。

### 示例 1-1. 复数

```
func main() {
	x := complex(2.5, 3.1)
	y := complex(10.2, 2)
	fmt.Println(x - y)
	fmt.Println(real(x))
	fmt.Println(imag(x))
	fmt.Println(cmplx.Abs(x))
}
```

运行此代码会得到以下结果：

```
(-7.699999999999999+1.1i)
2.5
3.1
3.982461550347975
```

你可以在结果中看到浮点数不精度的表现。

如果你在想第五种原始字面量是什么，Go 支持虚数字面量来表示复数的虚部。它们看起来就像浮点数字面量，但后缀为 `i`。

尽管复数是预声明的类型，但 Go 并不是数值计算的流行语言。采用率有限，因为其他特性（如矩阵支持）不是语言的一部分，库必须使用低效的替代方案，如切片的切片。 （你将在第 3 章了解切片，以及在第 6 章了解它们的实现。）但如果你需要在较大程序中计算曼德布罗集，或实现二次方程求解器，复数支持就在那里为你提供。

你可能想知道为什么 Go 包含复数。答案很简单：Go（和 Unix）的创建者之一 Ken Thompson 认为它们会很有趣 [interesting](https://oreil.ly/eBmkq)。曾有关于 [removing complex numbers](https://oreil.ly/Q76EV) 从 Go 的讨论，但兼容性承诺意味着它们将继续存在。

#### Note

如果你确实想在 Go 中编写数值计算应用程序，请使用第三方 [Gonum](https://www.gonum.org) 包。它利用了复数，并为线性代数、矩阵、积分、图和统计等提供了有用的库。其他语言具有更好的数值计算支持，但 Go 对软件工程的关注可能对大型项目来说是一个优势。

# A Taste of Strings and Runes

这就引出了字符串。与大多数现代语言一样，Go 将字符串作为内置类型包含在内。字符串的零值为空字符串。Go 支持 Unicode；正如我在 [“Literals”](#ch01.html#goliterals) 中展示的那样，你可以将任何 Unicode 字符放入字符串中。与整数和浮点数一样，字符串使用 `==` 比较相等，使用 `!=` 比较不等，或使用 `>`、`>=`、`<` 或 `<=` 比较顺序。它们使用 `+` 运算符连接。

Go 中的字符串是不可变的；你可以重新分配字符串变量的值，但不能更改分配给它的字符串的值。

Go 还具有表示单个代码点的类型。*rune* 类型是 `int32` 类型的别名，正如 `byte` 是 `uint8` 的别名一样。你可能可以猜到，rune 字面量的默认类型是 rune，而字符串字面量的默认类型是 string。

如果你指的是一个字符，请使用 rune 类型，而不是 `int32` 类型。它们对编译器来说可能相同，但你希望使用能阐明代码意图的类型：

```
var myFirstInitial rune = 'J' // good - the type name matches the usage
var myLastInitial int32 = 'B' // bad - legal but confusing
```

我将在下一章中更多地谈论字符串，涵盖一些实现细节、与字节和 rune 的关系，以及高级特性和陷阱。

## Explicit Type Conversion

大多数具有多种数值类型的语言在需要时会自动从一种类型转换为另一种类型。这称为 *automatic type promotion*，虽然看起来很方便，但事实证明，正确转换一种类型到另一种类型的规则可能很复杂并产生意外结果。作为一种重视意图清晰和可读性的语言，Go 不允许变量之间进行自动类型提升。你必须在变量类型不匹配时使用 *type conversion*。即使不同大小的整数和浮点数也必须转换为相同类型才能交互。这使得你想要的类型非常明确，而无需记住任何类型转换规则（参见 [示例 1-2](#ch01.html#EX2_1)）。

### 示例 1-2. 类型转换

```
var x int = 10
var y float64 = 30.2
var sum1 float64 = float64(x) + y
var sum2 int = x + int(y)
fmt.Println(sum1, sum2)
```

在此示例代码中，你定义了四个变量。`x` 是一个值为 10 的 `int`，`y` 是一个值为 30.2 的 `float64`。由于这些不是相同类型，因此你需要将它们转换后才能相加。对于 `sum1`，你使用 `float64` 类型转换将 `x` 转换为 `float64`，对于 `sum2`，你使用 `int` 类型转换将 `y` 转换为 `int`。运行此代码时，它会打印出 40.2 40。

对于不同大小的整数类型也适用相同的行为（参见 [示例 1-3](#ch01.html#EX2_1a)）。

### 示例 1-3. 整数类型转换

```
var x int = 10
var b byte = 100
var sum3 int = x + int(b)
var sum4 byte = byte(x) + b
fmt.Println(sum3, sum4)
```
