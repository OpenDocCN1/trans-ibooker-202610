显示用户应逐字输入的命令或其他文本。

# Chapter 1. Predeclared Types and Declarations

现在你已经设置好了开发环境，是时候开始了解 Go 的语言特性和如何最好地使用它们了。试图弄清楚“最好”意味着什么时，有一个 overriding 原则：以使你的意图清晰的方式编写程序。在我介绍特性并讨论选项时，我会解释为什么我认为某种方法能产生更清晰的代码。

我将首先查看 Go 内置的类型以及如何声明这些类型的变量。虽然每个程序员都对这些概念有经验，但 Go 在某些方面做得不同，并且 Go 与其他语言之间存在细微差异。
