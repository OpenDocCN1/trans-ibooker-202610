+   3 We open a web page protected with basic authentication.

+   4 We verify that the page is correctly displayed.

# Block URLs

CDP provides the ability to block given URLs in a session. Example 5-30 provides a test blocking the practice web site logo URL. If you run this test and inspect the browser during the execution, you will discover that this logo is not displayed on the page.

# Example 5-30. Test blocking an URL

```
@Test
void testBlockUrl() {
    devTools.send(Network.enable(Optional.empty(),
Optional.empty(),
        Optional.empty()));

    String urlToBlock =
        "https://bonigarcia.dev/selenium-webdriver-java/img/hands-on-icon.png";

devTools.send(Network.setBlockedURLs(ImmutableList.of(urlToBlock)))
; ①

    devTools.addListener(Network.loadingFailed(), loadingFailed ->
{
        BlockedReason reason =
loadingFailed.getBlockedReason().get();
        log.debug("Blocking reason: {}", reason);
        assertThat(reason).isEqualTo(BlockedReason.INSPECTOR);
    }); ②

    driver.get("https://bonigarcia.dev/selenium-webdriver-java/");
    assertThat(driver.getTitle()).contains("Selenium WebDriver");
}
```

+   ① We block a given URL.

+   ② We create a listener to trace the failed events.
