Another solution we can use to support the browser infrastructure for Selenium is Docker. Docker is an open-source software technology that allows to pack and run applications as lightweight, portable containers. The Docker platform has two main components: the Docker Engine, a tool for creating and running containers, and the Docker Hub, a cloud service for distributing Docker images.
