# Compound Locators

The Selenium WebDriver API has several support classes that enable the composition of the different locator types we have seen. These classes are the following:

+   - ByIdOrName (String idOrName): It seeks by id, and if it is not available, it seeks by name.

+   - ByChained (By... bys): It seeks elements in a sequence (i.e., the second one should appear inside the first one, and so on).

+   - ByAll (By... bys): It seeks elements that match a number of location strategies (following an and logic condition for these locators).
