# Table 4-7. Select methods

| Method | Return | Description |
|---|---|---|
| `Select(WebElement element)` | `Select` | Constructor using a WebElement as parameter (it must be a `<select>` element), otherwise it throws an `UnexpectedTagNameException` |
| `getWrappedElement()` | `WebElement` | Get wrapped WebElement (i.e., the one used in the constructor) |
| `isMultiple()` | `boolean` | Whether the select element supports selecting multiple options |
