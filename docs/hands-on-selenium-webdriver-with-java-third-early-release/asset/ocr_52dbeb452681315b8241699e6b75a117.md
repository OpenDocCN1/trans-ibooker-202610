# Emulate Network Conditions

The CDP allows the emulation of different networks (such as mobile 2G/3G/4G, Wi-Fi, or Bluetooth, among others) and conditions (e.g., latency or throughput). This feature can be helpful to test the behavior of web applications under specific connectivity parameters. Example 5-26 shows a test using the feature.
