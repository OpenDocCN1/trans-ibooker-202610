# XPath and CSS selector

| XPath | CSS selector |
|---|---|
| XPath allows bidirectional location, i.e., the traversal can be from parent to child and vice-versa | CSS allows one-directional locations, i.e., the traversal is from parent to child only |
| XPath is slower in terms of performance | CSS has better performance than XPath |
| XPath allows the identification of visible text on the screen using the `text()` function | CSS does not allow locating elements by its text content |
