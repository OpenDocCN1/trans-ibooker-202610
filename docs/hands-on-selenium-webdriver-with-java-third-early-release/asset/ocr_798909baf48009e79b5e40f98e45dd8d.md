provided by the application under test. These classes are instantiated as page objects in different test cases. We can implement end-to-end tests using the method exposed in these objects while avoiding code repetition.

Let’s see a basic example using page objects. In the following example, we refactor the test explained in the previous section (i.e., using the login form) using a page object instead of vanilla Selenium WebDriver. To that aim, the first step is to create a Java class that models the login page. Example 7-3 shows a very basic implementation of this page class.

# Example 7-3. Basic page class to model the practice login form

```
public class BasicLoginPage {

    WebDriver driver; ①

    By usernameInput = By.id("username"); ②
    By passwordInput = By.id("password");
    By submitButton = By.cssSelector("button");
    By successBox = By.id("success");

    public BasicLoginPage(WebDriver driver) { ③
        this.driver = driver;

        driver.get(
            "https://bonigarcia.dev/selenium-webdriver-java/login-form.html");
    }

    public void with(String username, String password) { ④
        driver.findElement(usernameInput).sendKeys(username);
        driver.findElement(passwordInput).sendKeys(password);
        driver.findElement(submitButton).click();
    }

    public boolean successBoxPresent() { ⑤
        return driver.findElement(successBox).isDisplayed();
    }
}
```

① We declare a WebDriver class attribute. This variable is used in the page object to implement the interaction with the web page.
