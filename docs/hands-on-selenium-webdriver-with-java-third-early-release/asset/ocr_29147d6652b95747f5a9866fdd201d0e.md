# Get User Media

WebRTC is a set of standard technologies that allows exchanging real-time media using web browsers. This technology allows the creation of audio and video conferencing web applications using JavaScript APIs on the client-side. The practice site contains a web page that gets the user media (microphone and webcam) using the *getUserMedia* JavaScript API.
