# The Chrome DevTools Protocol

Chrome DevTools is a set of web developer tools for Chromium-based web browsers, such as Chrome and Edge. These tools allow inspecting, debugging, or profiling these browsers, among other functions. The Chrome DevTools Protocol (CDP) is a communication protocol that allows the manipulation of the Chrome DevTools by external clients. As of version 4, Selenium WebDriver provides an interface for the CDP. This way, we can leverage the features provided by the Chrome DevTools in WebDriver tests.

Chrome DevTools in Selenium WebDriver is restricted to browsers that inherit from ChromiumDriver in the WebDriver hierarchy (see Figure 2-2 in Chapter 2), i.e., Chrome and Edge. We first need to open a CDP session (i.e., a WebSocket connection between the client and the browser) using the method createSession() of a DevTools instance to use it. Example 5-25 shows the structure I recommend to use Chrome DevTools for testing. As you can see, the CDP session is created in the test setup and closed in the teardown. Each test will make use of the class attribute devTools to interact with the Chrome DevTools.
