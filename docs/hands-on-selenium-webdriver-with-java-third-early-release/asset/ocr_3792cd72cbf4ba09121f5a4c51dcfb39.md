We decorate test classes using the JUnit 4 annotation @RunWith and our custom runner.

# TestNG

TestNG provides the interface ITestListener for implementing test listeners. The classes implementing this interface can override methods for the different stages of the TestNG lifecycle, such as onTestSuccess, onTestFailure, or onTestSkipped, among others. Example 8-38 shows a sample class implementing this interface. In this example, the listener methods log a message in the standard output. Then, Example 8-38 shows a test using this listener.

# Example 8-38. Test listener using TestNG

```
public class MyTestListener implements ITestListener {

    static final Logger log = getLogger(lookup().lookupClass());

    @Override
    public void onTestStart(ITestResult result) {
        ITestListener.super.onTestStart(result);
        log.debug("onTestStart {}", result.getName());
    }

    @Override
    public void onTestFailure(ITestResult result) {
        ITestListener.super.onTestFailure(result);
        log.debug("onTestFailure {}", result.getThrowable());
    }

    // Other listeners

}
```
