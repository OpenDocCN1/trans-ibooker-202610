@Test
void testDragAndDrop() {
    driver.get(

## Click and Hold

The following example shows how to use complex user gestures, including click and hold. To that aim, we practice with the webpage you can see in

**Figure 3-11.** This page uses an open-source JavaScript library called **Signature Pad** to draw signatures in HTML canvas using the mouse. **Example 3-25** shows a test using it.

![](img/b67ec8e49249e340add6ed66ab413d78_162_0.png)

*Figure 3-11. Practice web page with a drawable canvas*

### Example 3-25. Test drawing a circumference on a canvas

```java
@Test
void testClickAndHold() {
    driver.get(
        "https://bonigarcia.dev/selenium-webdriver-java/draw-in-canvas.html");
    Actions actions = new Actions(driver);

    WebElement canvas = driver.findElement(By.tagName("canvas"));
    actions.moveToElement(canvas).clickAndHold();

    int numPoints = 10;
    int radius = 30;
    for (int i = 0; i <= numPoints; i++) {
        double angle = Math.toRadians(360 - i / numPoints);
        double x = Math.sin(angle) * radius;
        double y = Math.cos(angle) * radius;
        actions.moveByOffset((int) x, (int) y);
    }

    actions.release(canvas).build().perform();
}
```

- 1. We locate the canvas by tag name.
- 2. We move mouse to this element with `moveToElement()` and then add the action `clickAndHold()` (for drawing into the canvas) to the actions pipeline.
- 3. We iterate using a fixed number of points, using the equation to find the points in a circumference.
- 4. We use the circumference points (x and y) to move the mouse by offset (`moveByOffset()`). Since the click is held from the previous step, the resulting compound action will move the mouse while the click button is pressed.
- 5. We release the click, build the action, and carry out the whole chain. As a result, a circumference should appear on the canvas.
