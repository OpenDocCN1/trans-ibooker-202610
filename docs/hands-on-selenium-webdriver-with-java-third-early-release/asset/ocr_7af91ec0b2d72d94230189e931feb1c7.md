This early version of Selenium IDE was a Firefox plugin that embedded Selenium Core to record, edit, and playback Selenium scripts. These early versions were XPI modules (i.e., a technology used to create Mozilla extensions). As of version 55 (released in 2017), Firefox migrated the addons support to the W3C Browser Extension specification. As a result, Selenium IDE was discontinued, and for some time, it has not been possible to use it. To solve this problem, the Selenium team rewrote Selenium IDE following the Browser Extensions recommendation. Thanks to this, we can now use Selenium IDE in multiple browsers, such as Chrome, Edge, and Firefox.

Figure 1-3 shows the new Selenium IDE GUI (Graphical User Interface). Using this GUI, users can record interactions with a browser and edit and execute the generated script. Selenium IDE encodes each interaction in different parts: a command (i.e., the action executed in the browser), a target (i.e., the locator o the web element), and a value (i.e., the data handled). Optionally, we can include a description of the command. In particular, Figure 1-3 shows a recording example that:

+   1. Open website (https://bonigarcia.dev/selenium-webdriver-java/). We will use this website as the practice site in the rest of the book.
+   2. Click on the link with the text “GitHub.” As a result, the navigation moves to the examples repository source code.
+   3. Assert that the book title (“Hands-On Selenium WebDriver with Java”) is present on the web page.
+   4. Close the browser.
