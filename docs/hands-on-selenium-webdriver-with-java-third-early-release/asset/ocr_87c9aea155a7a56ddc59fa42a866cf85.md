# Retrying Tests

As explained in Chapter 7, test flakiness (i.e., lack of reliability) is a well-known issue in end-to-end tests. As a tester, we sometimes need to identify a flaky test (i.e., a test that passes or fails under the same conditions), and for that, we retry a given test to check if its result is consistent or not. This way, we might want some mechanism to retry tests in case of failure. This section explains how to carry out this process using the different unit testing frameworks.
