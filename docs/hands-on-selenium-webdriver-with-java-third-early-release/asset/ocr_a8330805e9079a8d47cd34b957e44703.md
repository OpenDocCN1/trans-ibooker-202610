# Device Emulation

Major web browsers allow simulating mobile devices using the development tools. This feature is available using the development tools, i.e., DevTools in Chromium-based browsers and Developer Tools in Firefox, and typically include:

+   - Simulating a mobile viewport: to reduce user visible area of a web page using the width and height of a given mobile device.
+   - Throttling the network: to slow down the connectivity speed to simulate mobile networks (e.g., 3G).
+   - Throttling the CPU: to slow down the processing performance.
+   - Simulating geolocation: to set custom Global Positioning System (GPS) coordinates.
+   - Setting orientation: to rotate the screen.
