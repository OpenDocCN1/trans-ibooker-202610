# built-in functions

| Category | Syntax | Description | Example | Example explanation |
|---|---|---|---|---|
| Attributes | contains(@attr, 'string') | Check if an attribute contains a string | //a[contains(@href, 'github')] | Match links with href containing github |
| Attributes | starts-with(@attr, 'string') | Check if an attribute starts with a string | //a[starts-with(@href, 'https')] | Match all links using HTTPS |
| Attributes | ends-with(@atr, 'string') | Check if an attribute end with a string | //a[ends-with(@href, https)] | Match all links to PDF documents |
| Text | text()='string' | Locate elements based on text content | //*[text()=click] | Match all elements with the text click |
| Child nodes | [index] | Locate children elements | //div/*[0] | First child of a <div> |
| Boolean | or | Logic operator or | //@type='subm | Match buttons to |
