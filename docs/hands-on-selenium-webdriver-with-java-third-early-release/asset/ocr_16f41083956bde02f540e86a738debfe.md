So far, the examples explained in this book use web browsers locally installed on the machine that executes the tests. This chapter covers another relevant feature of the Selenium WebDriver API, i.e., the ability to use remote browsers (i.e., installed in other hosts). To this aim, first, we review the architecture that allows using remote browsers in Selenium WebDriver. Second, we study Selenium Grid, a networked infrastructure that provides remote browsers for Selenium WebDriver tests. Third, we analyze some of the most relevant cloud providers, i.e., companies that provide managed services for automated testing. Finally, we explore how to use Docker to support the browser infrastructure for Selenium.
