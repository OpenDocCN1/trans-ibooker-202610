```
@Then("I should see the message {string}") ⑤
public void iShouldSee(String result) {
    try {
        String bodyText =
        driver.findElement(By.tagName("body")).getText();
        assertThat(bodyText).contains(result);
    } finally {
        driver.quit();
    }
}
```

+   ① We use the first step to create a WebDriver instance.
+   ② We open the URL.
+   ③ We type the credentials.
+   ④ We click on the submit button.
+   ⑤ We verify that the expected message is on the page.

Finally, we need to run our step definition as a test case. This final action is unit testing framework-dependant. In other words, the required development is different in JUnit 4 (see Example 9-15), JUnit 5 (see Example 9-16), and TestNG (see Example 9-17).
