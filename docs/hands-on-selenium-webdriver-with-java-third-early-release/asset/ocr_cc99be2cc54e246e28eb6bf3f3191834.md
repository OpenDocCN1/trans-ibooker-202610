# ## Security

A relevant organization in the software security domain is **OWASP** (Open Web Application Security Project), a nonprofit foundation that promotes open solutions to improve software security. One of the most popular OWASP projects is the Zed Attack Proxy (ZAP). **OWASP ZAP** is an open-source web application security scanner used to implement *vulnerability assessment* (i.e., seek for security issues) or *penetration testing* (i.e., a simulated cyber attack) to find exploitable web application vulnerabilities.
