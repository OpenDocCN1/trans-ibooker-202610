# A/B testing

A/B testing is a form of usability evaluation that compares variations of the same application to discover which one is more effective to its end-users. Different commercial products facilitate advanced features for A/B tests in Selenium WebDriver tests. For example, Applitools Eyes provides an automated visual comparison of the multiple webpage variations. Another option is Optimizely, which is a company that provides tools for customizing and experimenting with A/B testing.

An alternative way to carry out A/B testing is to use the vanilla Selenium WebDriver API and custom conditions for the different variations of a webpage. Example 9-9 shows a basic test following a manual approach for a multi-variant webpage.
