In JUnit 5, the Jupiter extension model replaced and improved the former test lifecycle management of JUnit 4 based on rules. As introduced in Chapter 2, the extension model provided by Jupiter allows adding new features on the top of the Jupiter programming model. This way, a Jupiter extension is a Java class that implements one or several *extension points*, which are interfaces that allow different types of operations in the Jupiter programming model.
