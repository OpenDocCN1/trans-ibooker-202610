+   1. We need to implement a TestNG listener called `IRetryAnalyzer` to implement a retry analyzer.
+   
+   2. We cannot parameterize this class, and therefore, we declare the maximum retries number within the class (as a constant, in this case).
+   
+   3. We need to override the method `retry`. This method returns a boolean value which determines if the test is retried or not in case of failure.
+   
+   4. The logic to determine this value is an accumulator that checks if the retries threshold is reached or not.
