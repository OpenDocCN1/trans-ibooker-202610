# Browser Binary

Selenium WebDriver detects the path of the controlled web browsers (Chrome, Firefox, etc.) out of the box. Nevertheless, we can specify a custom path for the browser executable file using capabilities. This feature can be helpful when the installation path of the browser is not standard (for instance, in the case of beta/development/canary browsers).

We use the same capabilities syntax to specify the binary path for Chrome, Edge, and Firefox. Example 5-16 shows a test setup using Chrome beta.

Example 5-16. Test setup setting a custom binary path for Chrome

```
@BeforeEach
void setup() {
    Path browserBinary = Paths.get("/usr/bin/google-chrome-beta");
    assumeThat(browserBinary).exists();
    ChromeOptions options = new ChromeOptions();
    options.setBinary(browserBinary.toFile());
    driver =
WebDriverManager.chromedriver().capabilities(options).create();
}
```
