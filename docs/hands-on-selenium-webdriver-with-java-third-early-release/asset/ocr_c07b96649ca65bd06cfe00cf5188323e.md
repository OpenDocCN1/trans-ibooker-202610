# Table 3-3. WebElement methods

| Method | Return | Description |
|---|---|---|
| `click()` | `void` | Perform a mouse click (i.e., a left-click) in the current element |
| `submit()` | `void` | Send a web form (when the element is a form) |
| `sendKeys(CharSequence...)` | `void` | Simulate typing with the keyboard (e.g., in input
