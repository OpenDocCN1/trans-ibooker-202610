# # Web Proxies

In computer networking, a *proxy* is a server that acts as an intermediary between a client a server. A web proxy is a proxy in between a browser and a web server, and it can serve multiple purposes, such as:

+   - Access region-specific information. The proxy is typically located in a different region than the client, and the server replies consequently to that region.
+   - Avoiding restrictions. A proxy can help to access blocked websites, for example, by an intermediate firewall.
+   - Capture network traffic. A proxy can gather HTTP requests and responses.
+   - Caching (for faster website retrieval).

We can also use a web proxy in Selenium WebDriver tests for these purposes. To that aim, the WebDriver API provides a class called `Proxy`, which is configured into a `WebDriver` object using capabilities. **Example 5-46** illustrates how.

# *Example 5-46. Test setup to configure a web proxy*

```
```java
@BeforeEach
void setup() {
    Proxy proxy = new Proxy();
    String proxyStr = "proxy:port";
    proxy.setHttpProxy(proxyStr);
    proxy.setSslProxy(proxyStr);

    ChromeOptions options = new ChromeOptions();
    options.setAcceptInsecureCerts(true);
}
