The second alternative to set up mobile emulation is to specify the individual attributes of the emulated device. These attributes are the following:

+   - `width`: device screen width (in pixels).
+   - `height`: device screen height (in pixels).
+   - `pixelRatio`: ratio between physical pixels and logical pixels.
+   - `touch`: whether to emulate touch events. The default value is `true`.

In addition to these attributes, we can specify the *user agent* of the emulated device. In HTTP, the user agent is a string specified in request headers that univocally identify the type of web browser. It contains the development code name, version, platform, and other information. **Example 5-7** shows a test setup illustrating the use of this feature.
