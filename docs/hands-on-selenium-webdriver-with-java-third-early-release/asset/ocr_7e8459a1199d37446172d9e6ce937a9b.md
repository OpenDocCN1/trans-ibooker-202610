+   1. We locate the link whose text is `Return to index`.
+   2. We specify the relative locator type, which will be by tag name the `input`.
+   3. We use a relative locator to find a web element (which should be an `input` filed) above the original web element (i.e., a link).
+   4. We verify the element above the reference link is a read-only field (see Figure 3-2 to double-check it).

WARNING

Relative locators can be helpful to find elements based on the relative position of other elements. On the other hand, this strategy can be very sensitive to the page layout. For example, you need to be careful when using relative locators in responsive pages since the layout can vary depending on the viewport.

As its name suggests, this element provides a handy way to select dates using a web GUI.
