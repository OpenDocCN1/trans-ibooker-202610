# Extra Headers

CDP allows adding additional headers at HTTP level. To that aim, we need to send the command Network.setExtraHTTPHeaders() in a CDP session. Example 5-29 shows a test that uses this command to add the HTTP header Authorization, for sending credentials (user name and password) in a web page that requires basic authentication to log in.

Example 5-29. Test adding extra HTTP headers

```
@Test
void testExtraHeaders() {
    devTools.send(Network.enable(Optional.empty(),
Optional.empty(),
        Optional.empty()));

    String userName = "guest";
    String password = "guest";
    Map<String, Object> headers = new HashMap<>();
    String basicAuth = "Basic " + new String(Base64.getEncoder()
        .encode(String.format("%s:%s", userName,
password).getBytes()));
    headers.put("Authorization", basicAuth); ①
    devTools.send(Network.setExtraHTTPHeaders(new
Headers(headers))); ②

    driver.get("https://jigsaw.w3.org/HTTP/Basic/"); ③
    String bodyText =
driver.findElement(By.tagName("body")).getText();
    assertThat(bodyText).contains("Your browser made it!"); ④
}
```

+   ① We encode the user name and password in Base64.
+   ② We create the authorization header.
