The Enter Data button (going back to Figure 2-3) will give you an interface that should feel familiar if you use Excel, as it opens a table-like structure where you can add columns, name them, and put data into cells, as shown in Figure 2-8. It’s important to note there is no formula function in this interface. It’s only for simple data entry. You can copy and paste information into this window, as well, but be careful before going copy-paste crazy in this window. This can be useful for testing or if you have a lookup table that you want to generate for your model, but I recommend that you do not put large amounts of information into this type of table structure because it has to be manually managed.
