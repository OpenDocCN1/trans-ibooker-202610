

这种增强的抽象对数据工程师意味着什么？正如我们在本章中已经论述的，数据工程师的角色不会消失，但将发生重大演变。打个比方，更复杂的移动操作系统和框架并没有淘汰移动应用开发人员。相反，移动应用开发人员现在可以专注于构建质量更高、更复杂的应用程序。随着云规模数据操作系统范式提高了各种应用程序和系统之间的互操作性和简易性，我们预期数据工程领域也将出现类似的发展。

# “企业级”数据工程

数据工具日益简化，最佳实践不断涌现并被记录下来，这意味着数据工程将变得更加“企业级”。^([2](#ch11.html#ch01fn84)) 这会让许多读者感到极度不适。对某些人来说，*企业* 一词唤起的是卡夫卡式的噩梦：面目模糊的委员会成员穿着过度挺括的蓝衬衫和卡其裤，无休止的繁文缛节，以及瀑布式管理的开发项目，进度不断拖延，预算不断膨胀。简而言之，你们中的一些人一看到“企业”，就会联想到一个创新扼杀殆尽的无灵魂之地。

幸运的是，这并非我们所指；我们指的是大公司利用数据做好的一些事情——管理、运维、治理，以及其他那些“枯燥”的工作。我们正处于“企业级”数据管理工具的黄金时代。曾经为大型组织保留的技术和实践正在向下游流淌。大数据和流数据曾经困难的部分现在已在很大程度上被抽象掉了，重点转移到了易用性、互操作性和其他改进上。

这使得从事新工具开发的数据工程师能够在数据管理、DataOps 以及数据工程所有其他暗流的抽象中找到机会。数据工程师将变得“企业级”。顺便说一句……

# 职称与职责将发生变形……

虽然数据工程生命周期在可预见的未来不会消失，但软件工程、数据工程、数据科学和 ML 工程之间的界限正变得越来越模糊。事实上，像作者一样，许多数据科学家通过一个自然的过程转型为数据工程师；他们被赋予“数据科学”的任务，却缺乏完成工作的工具，于是承担起设计和构建系统的工作，以服务于数据工程生命周期。

随着简化性上移到技术栈的上层，数据科学家花在收集和清洗数据上的时间比例将变小。但这一趋势将超越数据科学家。简化也意味着数据工程师将在数据工程生命周期中花费更少的时间在低级任务上（管理服务器、配置等），而“企业级”数据工程将变得更加普遍。

随着数据更紧密地嵌入到每个企业的流程中，数据和算法领域将涌现新角色。一种可能性是介于 ML 工程和数据工程之间的角色。随着 ML 工具集变得更易用，托管云 ML 服务能力增强，ML 正从临时探索和模型开发转变为一门运维学科。

这种横跨鸿沟的新型 ML 导向工程师将了解算法、ML 技术、模型优化、模型监控和数据监控。然而，他们的主要角色将是创建或利用系统，自动训练模型、监控性能，并为已被充分理解的模型类型将完整的 ML 流程运维化。他们还将监控数据管道和质量，与当前数据工程的领域产生重叠。ML 工程师将变得更加专业化，专注于更接近研究、理解程度较低的模型类型。

职称可能发生变形的另一个领域是软件工程与数据工程的交集。融合了传统软件应用与分析的数据应用将推动这一趋势。软件工程师将需要对数据工程有深得多的理解。他们将在流处理、数据管道、数据建模和数据质量等方面建立专长。我们将超越当前普遍存在的“甩过墙头”式做法。数据工程师将融入应用开发团队，软件开发人员将获得数据工程技能。应用后端系统与数据工程工具之间的界限也将降低，通过流处理和事件驱动架构实现深度集成。

# 超越现代数据栈，迈向实时数据栈

我们直说吧：现代数据栈（MDS）并不那么现代。我们为 MDS 向大众提供一系列强大的数据工具、降低价格、赋能数据分析师掌控其数据栈而喝彩。ELT 的兴起、云数据仓库的出现，以及 SaaS 数据管道的抽象，确实改变了许多公司的游戏规则，为 BI、分析和数据科学开启了新的能力。

话虽如此，MDS 本质上是利用现代云和 SaaS 技术对旧数据仓库实践的重新包装；因为 MDS 构建在云数据仓库范式之上，与下一代实时数据应用的潜力相比，它存在一些严重局限。从我们的角度来看，世界正在超越基于数据仓库的面向内部分析和数据科学，转向利用下一代实时数据库实时驱动整个业务和应用。

是什么在推动这种演变？在许多情况下，分析（BI 和运营分析）将被自动化取代。目前，大多数仪表盘和报表回答的是 *是什么* 和 *何时* 的问题。问问自己，“如果我在问一个 *是什么* 或 *何时* 的问题，我接下来采取什么行动？”如果该行动是重复性的，它就是自动化的候选者。为什么要看报表来决定是否采取行动，而不是根据事件发生时自动执行行动呢？

这远不止于此。为什么使用 TikTok、Uber、Google 或 DoorDash 等产品会让人感觉像魔法一样？虽然在你看来只是点击一下按钮观看短视频、叫车或订餐、或找到搜索结果，但引擎盖下发生了很多事情。这些产品是真正的实时数据应用的例子，它们在点击按钮的瞬间为你提供所需的操作，同时在幕后以微小的延迟执行极其复杂的数据处理和 ML。目前，这种复杂性被锁在大型科技公司的定制技术背后，但这种复杂性和力量正变得民主化，就像 MDS 将云规模数据仓库和管道带给大众一样。数据世界即将变得“实时”。

## 实时数据栈

实时技术的民主化将引领我们走向 MDS 的继任者：*实时数据栈* 很快将变得触手可及且无处不在。实时数据栈（如 [图 11-1](#ch11.html#in_the_live_data_stackcomma_data_and_in) 所示）将通过使用流技术，将实时分析和 ML 融入应用程序，覆盖从应用源系统到数据处理再到 ML，再返回的完整数据生命周期。
