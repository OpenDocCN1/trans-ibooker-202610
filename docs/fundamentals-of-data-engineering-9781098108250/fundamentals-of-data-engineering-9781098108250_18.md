# 作者简介

**Joe Reis** 是一位具有商业思维的数据极客，在数据行业深耕 20 年，职责涵盖统计建模、预测、机器学习、数据工程、数据架构以及几乎介于两者之间的所有其他领域。Joe 是 Ternary Data 的 CEO 兼联合创始人，这是一家总部位于犹他州盐湖城的数据工程与架构咨询公司。此外，他还在多个技术社区担任志愿者，并在犹他大学任教。业余时间，Joe 喜欢攀岩、制作电子音乐，并带着孩子们进行疯狂的探险。

**Matt Housley** 是一位数据工程顾问和云专家。在早期接触过 Logo、Basic 和 6502 汇编编程后，他在犹他大学获得了数学博士学位。随后 Matt 投身数据科学，最终专注于基于云的数据工程。他与 Joe Reis 共同创立了 Ternary Data，在那里他利用自己的教学经验培养未来的数据工程师，并为团队提供稳健数据架构方面的建议。Matt 和 Joe 还在 *The Monday Morning Data Chat* 节目中对数据相关的一切话题发表高见。

# 版本记录

*Fundamentals of Data Engineering*（《数据工程基础》）封面上的动物是白耳鵎鵼（*Nystalus chacuru*）。

因其耳部显眼的白色斑块以及蓬松的羽毛而得名，这些体型小巧、圆润的鸟类分布在中南美洲广阔的地带，栖息于森林边缘和稀树草原。

白耳鵎鵼是伏击猎手，长时间栖息在开阔地带，伺机捕食靠近的昆虫、蜥蜴甚至小型哺乳动物。它们通常单独或成对出现，属于相对安静的鸟类，极少鸣叫。

国际自然保护联盟 (IUCN) 将白耳鵎鵼列为*无危*物种，部分原因在于其分布范围广泛且种群数量稳定。O'Reilly 封面上的许多动物都濒临灭绝；但它们对世界都至关重要。
