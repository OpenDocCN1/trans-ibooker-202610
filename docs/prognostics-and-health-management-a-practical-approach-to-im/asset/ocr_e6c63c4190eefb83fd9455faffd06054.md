# Lognormal Failure

The failure rate of a lognormal variable X is shown in Figure 1.11. It is a mound-shaped curve with a maximum at t*, which can be determined as follows. There is a unique value t̄ such that ρₙ(t̄) = t̄ + σ, and then t* = exp(μ + σ t̄). Clearly

limₜ→0+ ρ(t) = limₜ→∞ ρ(t) = 0

# Logistic Failure

The failure rate of the logistic variable is

ρ(t) = 1 / [σ(1 + e^{-z})] with z = (t - μ)/σ   (1.40)

# Gumbel Failure

In the case of the Gumbel distribution,

ρ(t) = (1/σ) e^{z} with z = (t - μ)/σ   (1.41)

which is a simple exponential function.

# Log-Logistic Failure

Similarly, in the case of a log-logistic variable:

ρ(t) = e^{x} / [σ t (1 + e^{x})] with x = [ln(t) - μ]/σ   (1.42)

# Log-Gumbel Failure

For the log-Gumbel distribution,

ρ(t) = e^{x} / (σ t) = (1/σ) e^{x(1-σ)-μ} with x = [ln(t) - μ]/σ   (1.43)

as before.
