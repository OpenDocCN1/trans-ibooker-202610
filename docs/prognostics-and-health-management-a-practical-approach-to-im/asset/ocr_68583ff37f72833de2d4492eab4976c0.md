# Log-Gamma Failure

The failure rate of the log-gamma variable is

```
ρ(t) = y^{α-1} e^{-(λ+1) y} / ∫_{y}^{∞} u^{α-1} e^{-λ u} du  with y = ln(t)  (1.44)
```

Figures 1.12–1.14 show the graphs of some of these failure rates.

# Example 1.5  Assume that the failure rate of a variable is ρ(t) = t². Then, from Eq. (1.35),

```
F(t) = 1 - e^{-∫₀ᵗ τ² dτ} = 1 - e^{-t³/3}
```

showing that this is a Weibull variable with β = 3 and η = 3^{1/3}.
