which must be maximized. Notice first that as μ → −∞ or μ → +∞, since l(μ) tends to −∞, the maximum is interior. By differentiation:

∂l(μ)/∂μ = 1/σ² ∑_{k=1}^N (t_k − μ) = 1/σ² (∑_{k=1}^N t_k − N μ) = 0

implying that the maximum likelihood estimate is μ* = 1/N ∑_{k=1}^N t_k = t̄, which is the sample mean.

It gives the expectation of parameter μ. In order to obtain the variance of μ, we compute the Fisher information first:

I = − ∂²l(μ)/∂μ² = N/σ²

showing that the variance of μ is σ²/N, so μ can be approximated with large N values with a normal distribution with mean μ* and standard deviation σ/√N.

# Example 1.10 Assume next that X is exponential with an unknown parameter λ. If t₁, t₂, …, t_N are the sample elements, then

L(λ) = ∏_{k=1}^N λ e^{−λ t_k} = λ^N e^{−λ ∑_{k=1}^N t_k}

with logarithm

l(λ) = N ln(λ) − λ ∑_{k=1}^N t_k

As λ → 0 or λ → ∞, the value of l(λ) tends to negative infinity, so the optimum is local. Since

∂l(λ)/∂λ = N/λ − ∑_{k=1}^N t_k

the likelihood estimate is

λ* = N / ∑_{k=1}^N t_k = 1/t̄

The Fisher information is clearly

I = − ∂²l(λ)/∂λ² = N/λ²

and the variance of λ becomes λ*² / N.

If the distribution depends on more than one parameter – say, its PDF is f(t|θ₁, …, θ_n) – then the likelihood function is

L(θ₁, …, θ_n) = ∏_{k=1}^N f(t_k|θ₁, …, θ_n)
