# FFP Signature Data: Benefits Compared to CBD Signature Data

FFP signatures require less modeling compared to CBD signatures: one model for each failure level compared to 20 models (refer back to 3.4). In addition, prediction-algorithm processing of FFP signature data compared to that for CBD signature is greatly simplified:

+   - An FFP point less than or equal to 0 represents a state of zero degradation: RUL = maximum (specified or system-determined value) and SoH = 100%.
+   - An FFP point between 0 and less than a specified failure threshold represents a degraded state: 0 < RUL < maximum and 0% < SoH < 100%.
+   - An FFP point at or above a failure threshold represents a functionally failed state: RUL = 0 and SoH = 0%.
