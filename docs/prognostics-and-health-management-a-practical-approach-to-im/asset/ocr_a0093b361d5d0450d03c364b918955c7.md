# 1.5.3 Decreased Number of Failures Due to Partial Repairs

Assume next that partial repairs are performed, resulting in the number of failures decreasing by a factor of α < 1. Then, similar to the previous cases,

E(X_t|S_1) = { 0 if t < S_1; 1 if S_1 < t < S_1 + T; 1 + α(M(t - T) - M(S_1)) if t > S_1 + T } (1.93)

So

M(t) = ∫_{t-T}^{t} f(s)ds + ∫_{0}^{t-T} [1 + α(M(t - T) - M(s))]f(s)ds = F(t) - F(t - T) + F(t - T) + αM(t - T)F(t - T) - α ∫_{0}^{t-T} M(s)f(s)ds = { F(t) if t ≤ T; F(t) + αM(t - T)F(t - T) - α ∫_{0}^{t-T} M(s)f(s)ds if t > T } (1.94)

Assume again instantaneous repairs with T = 0. Then (1.94) is modified as

M(t) = F(t) + αM(t)F(t) - α ∫_{0}^{t} M(s)f(s)ds (1.95)

# 1.5.4 Decreased Age Due to Partial Repairs

Consider finally the case where partial repairs decrease the effective age of the object by a factor α < 1. Then we have

E(X_t|S_1) = { 0 if t < S_1; 1 if S_1 < t < S_1 + T; 1 + M((t - S_1 - T + αS_1)) - M(αS_1) if t > S_1 + T } (1.96)

since at time t the effective age is (t - S_1 - T) + αS_1, where the first term is the length of interval [S_1 + T, t] and the second term is the effective age at time S_1 + T after repair. Therefore

M(t) = ∫_{t-T}^{t} f(s)ds + ∫_{0}^{t-T} [1 + M((t - s - T + αs)) - M(αs)]f(s)ds = { F(t) if t ≤ T; F(t) + ∫_{0}^{t-T} [M(t - s - T + αs) - M(αs)]f(s)ds if t > T } (1.97)

If T = 0 then

M(t) = F(t) + ∫_{0}^{t} [M(t - s + αs) - M(αs)]f(s)ds (1.98)

Notice that the case α = 1 corresponds to minimal repair, and Eqs. (1.95) and (1.98) reduce to Eq. (1.81) as they should. Equations (1.81), (1.90), and (1.95) are usually called the renewal equations (Mitov and Omey 2014).
