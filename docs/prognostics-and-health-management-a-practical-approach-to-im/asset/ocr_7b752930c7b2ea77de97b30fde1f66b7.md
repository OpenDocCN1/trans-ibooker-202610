# Example 1.3 Assume now that random variable X is exponential with λ = 1. Then

```
$$f(t) = 1 \cdot e^{-1 \cdot t} = e^{-t}$$
```

so

```
$$P(X > 2) = \int_{2}^{\infty} e^{-t} dt = [-e^{-t}]_{2}^{\infty} = 0 + e^{-2} = 0.1353$$
```

and

```
$$P(1 < X < 2) = \int_{1}^{2} e^{-t} dt = [-e^{-t}]_{1}^{2} = -e^{-2} + e^{-1} = 0.2326$$
```

as in Example 1.1.

# Example 1.4 Assume next that X is Weibull with parameter values β = 1.5 and η = 5. Then

```
$$f(t) = \frac{1.5}{5^{1.5}} t^{0.5} e^{-(\frac{t}{5})^{1.5}}$$
```

therefore

```
$$P(X > 2) = \int_{2}^{\infty} \frac{1.5}{5^{1.5}} t^{0.5} e^{-(\frac{t}{5})^{1.5}} dt = \left[-e^{-(\frac{t}{5})^{1.5}}\right]_{2}^{\infty} = 0 + e^{-0.4^{1.5}} = 0.7765$$
```
