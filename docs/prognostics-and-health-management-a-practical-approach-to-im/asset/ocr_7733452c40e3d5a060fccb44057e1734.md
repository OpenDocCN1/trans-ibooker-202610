# Table 5.1 FFS nonlinearity procedure.

| Procedure name | Procedure expression |
|---|---|
| Calculate time to failure (TTF) | $TTF = t_{FAILURE} - t_{ONSET}$ |
| Create set of ideal data {$IDEAL\_FFS_i$} | $IDEAL\_FFS_i = 100\,(t_i - t_{ONSET})/TFF$ |
| Calculate point-by-point nonlinearity {$FNL_i$} | $FNL_i = FFS_i - IDEAL\_FFS_i$ |
| Calculate positive nonlinearity ($FNL_P$) | $FNL_P = max({FNL_i})$ |
| Calculate negative nonlinearity ($FNL_N$) | $FNL_N = min({FNL_i})$ |
| Calculate total nonlinearity error ($FNL_E$) | $FNL_E = FNL_P - FNL_N$ |
