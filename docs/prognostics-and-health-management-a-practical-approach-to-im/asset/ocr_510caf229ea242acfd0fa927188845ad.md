independent, then X_t is a Poisson variable with λ = M(t) expectation, so

$$P(X_t = n) = \frac{M(t)^n}{n!} e^{-M(t)}\tag{1.83}$$

Assume that the repairable failures occur at times 0 < t_1 < t_2 < ... and repairs are done instantly. Let F_k(t) denote the CDF of t_k. Then

$$F_k(t) = P(t_k \le t) = P(X_t \ge k) = \sum_{n=k}^{\infty} \frac{M(t)^n}{n!} e^{-M(t)}\tag{1.84}$$

and the corresponding PDF is its derivative,

$$f_k(t) = F_k'(t) = \sum_{n=k}^{\infty} \left( \frac{n M(t)^{n-1}}{n!} \rho(t) e^{-M(t)} + \frac{M(t)^n}{n!} e^{-M(t)} (-\rho(t)) \right)$$

$$= \sum_{n=k}^{\infty} \left( \frac{M(t)^{n-1}}{(n-1)!} - \frac{M(t)^n}{n!} \right) e^{-M(t)} \rho(t) = \frac{M(t)^{k-1}}{(k-1)!} e^{-M(t)} \rho(t)\tag{1.85}$$

# Example 1.12 In the special case when X is exponential, ρ(t) = λ and M(t) = λt, so

$$f_k(t) = \frac{(\lambda t)^{k-1}}{(k-1)!} \lambda e^{-\lambda t} = \frac{\lambda^k t^{k-1} e^{-\lambda t}}{(k-1)!}\tag{1.86}$$

which is a gamma PDF with parameters k and θ = 1/λ.

# Example 1.13 If X is Weibull, then ρ(t) = β/η^β t^{β-1} and M(t) = (t/η)^β, so

$$f_k(t) = \frac{\left(\frac{t}{η}\right)^{β(k-1)}}{(k-1)!} \frac{β}{η^β} t^{β-1} e^{-\left(\frac{t}{η}\right)^β} = \frac{β t^{βk-1} e^{-\left(\frac{t}{η}\right)^β}}{(k-1)! η^{βk}}\tag{1.87}$$

# 1.5.2 Failure Replacement

Assume next that upon failures, failure replacement is performed, which requires T time to complete. Then, similar to the previous case,

$$E(X_t|S_1) = \begin{cases} 0 & \text{if } t < S_1 \\ 1 & \text{if } S_1 < t < S_1 + T \\ 1 + E(X_{t-S_1-T}) & \text{if } t > S_1 + T \end{cases}\tag{1.88}$$

Therefore, Eq. (1.78) implies that

$$M(t) = \int_{t-T}^{t} f(s) ds + \int_{0}^{t-T} (1 + M(t - s - T)) f(s) ds$$

$$= F(t) - F(t - T) + F(t - T) + \int_{0}^{t-T} M(t - s - T) f(s) ds$$

$$= F(t) + \int_{0}^{t-T} M(t - s - T) f(s) ds$$
