# Prognostic Distance

PD is the period of time between when degradation begins and when functional failure occurs. You can define a performance metric called PD figure of merit ($PD_{FOM}$), as follows:

```
$PD_{FOM} = (PD/PD_{MAX}) = (EOL - BD_{DETECTED})/(EOL - BD)$
```

From the definition of $BD_{OFFSET}$, $BD_{DETECTED} = BD_{OFFSET} + BD$, so that

```
$PD_{FOM} = (EOL - BD - BD_{OFFSET})/(EOL - BD) = (1 - BD_{OFFSET}/(EOL - BD))$
```
