# Table 1.1 Expectations and variances.

| Type of distributions | Parameters | Domain | E(X) | Var(X) |
|---|---|---|---|---|
| Exponential | λ | [0, ∞) | 1/λ | 1/λ² |
| Weibull | β, η | [0, ∞) | ηΓ(1 + 1/β) | η²[Γ(1 + 2/β) − Γ²(1 + 1/β)] |
| Gamma | k, θ | [0, ∞) | kθ | kθ² |
| Normal | μ, σ² | (−∞, ∞) | μ | σ² |
| Lognormal | μ, σ² | [0, ∞) | exp(μ + σ²/2) | (e^{σ²} − 1) exp(2μ + σ²) |
| Logistic | μ, σ | (−∞, ∞) | μ | σ²π²/3 |
| Gumbel | μ, σ | (−∞, ∞) | μ − σγ | π²σ² |
| Log-logistic | μ, σ | (0, ∞) | e^{μ}Γ(1 + σ)Γ(1 − σ) | e^{2μ}[Γ(1 + 2σ)Γ(1 − 2σ) − (Γ(1 + σ)Γ(1 − σ))²] |

The expected value is given by the integral

```
E(X) = ∫₀^∞ 2t e^{-2t} dt = [2t e^{-2t}/-2]₀^∞ − ∫₀^∞ 2 e^{-2t}/-2 dt
```

where integration by parts is used with u = 2t, v' = e^{-2t}.

Therefore,

```
E(X) = ∫₀^∞ e^{-2t} dt = [e^{-2t}/-2]₀^∞ = 0 + 1/2 = 1/2
```

The second moment of X is the following:

```
E(X²) = ∫₀^∞ 2t² e^{-2t} dt = [2t² e^{-2t}/-2]₀^∞ − ∫₀^∞ 4t e^{-2t}/-2 dt
```

where integration by parts is used again with u = 2t² and v = e^{-2t}. From E(X),

```
E(X²) = ∫₀^∞ 2t e^{-2t} dt = 1/2
```

and therefore

```
Var(X) = 1/2 − (1/2)² = 1/4
```

Notice that X is exponential with λ = 2, and the results we obtained by integration match the formulas of the first line in Table 1.1.
