# Normal Failure

If X is a normal variable with parameters μ and σ, then ρ(t) = (1/σ) ρₙ((t−μ)/σ), limₜ→−∞ ρ(t) = 0, and limₜ→∞ ρ(t) = ∞. Furthermore, its asymptote is (t−μ)/σ² as t → ∞.
