| Architecture | Benefits | Weaknesses |
| :--- | :--- | :--- |
| Business intelligence applications | • Rich palette of visualizations.<br>• Good range of connectivity.<br>• High performance from in-memory engines. | • User experience can be very different from the host application.<br>• Highly interactive environment can confuse or distract users.<br>• Security is unlikely to be integrated with the host application. |
| Embedded analytics platforms | • Highly customizable, even enabling some self-service.<br>• Optimized for embedding.<br>• Integrates with application security and administration. | • Higher cost than component libraries.<br>• Requires more training than component libraries. |
