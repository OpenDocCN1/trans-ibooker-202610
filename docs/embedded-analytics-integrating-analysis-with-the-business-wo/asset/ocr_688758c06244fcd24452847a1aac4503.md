In any of these cases, tables perform a valuable role in your embedded solution: previewing data for exporting and giving the user the ability to refine and otherwise control what eventually makes it into the downloaded file.

In this case, the user is shown a table representing the data they’re going to download, with the ability to preview a selected number of rows and show or hide columns that may not be used in the chart itself. This is a good user experience, and a perfect example of how tables can be used to add value to an embedded experience.
