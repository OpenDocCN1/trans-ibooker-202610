Within the dashboard itself, we’re making use of several techniques we’ve already touched on. # Interaction as a Value-Add

It’s also useful to think about interactivity from a product experience perspective, putting yourself in the position of an end user and thinking critically about the actual use case. Will users want to interact with visualizations? Will they need to interact to get actionable insights, or is a simpler method more appropriate?
