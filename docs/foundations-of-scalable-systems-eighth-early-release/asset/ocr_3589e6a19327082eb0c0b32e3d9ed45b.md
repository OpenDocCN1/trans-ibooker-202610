# Code base

Following the ‘two pizza rule’, an individual service should not be more complex than a small team size can build, evolve and manage. As a microservice is a black box, the team has full autonomy to choose their own development stack and data management platform.³ Given the narrower, highly cohesive scope of functionality that a well designed microservice supports, this should result in lower code complexity and higher development cadence for new features.
