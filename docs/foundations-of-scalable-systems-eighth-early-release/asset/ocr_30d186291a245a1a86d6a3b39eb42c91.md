# Distribution and Replication

In its original version, Redis was a single server data store, which somewhat limited its scalability. In 2015, Redis Cluster² was released to facilitate partitioning and replication of a Redis data store across multiple nodes. Redis Cluster defines 16384 hash slots for a cluster. Every key is hashed modulo 16384 to a specific slot, which is configured to reside on a host in the cluster.
