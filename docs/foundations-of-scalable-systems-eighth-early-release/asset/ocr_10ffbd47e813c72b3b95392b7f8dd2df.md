Got that? As is hopefully apparent, these three settings interact with each other, making configuration somewhat complex. By default, an instance will handle 10 x 0.6 = 6 concurrent requests before a new instance is created. And if these 6 (or less) requests cause the CPU utilization for an instance to go over 60%, the scheduler will also try to create a new instance.
