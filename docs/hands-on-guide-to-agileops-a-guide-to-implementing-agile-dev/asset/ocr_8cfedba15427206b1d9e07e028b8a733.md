Each stream offers a list of key performance indicators (KPIs) that help in defining organizations’ success toward its adoption, as shown in Table 6-1.

# Table 6-1. Value Stream and Its KPIs

| Value Stream | Key KPIs |
|---|---|
| S2P | • CapEx versus OpEx<br>• Percent of software license consumption<br>• Frequency of security assessments<br>• Average cost/service or application |
| R2D | • Percent of actual versus planned executed tests<br>• Percent of automated tests<br>• Planned cost versus actual cost<br>• Percent reduction in rework |
| R2F | • Number of completed service requests<br>• Percent of WIP within SLAs<br>• Percent of completed work within SLAs<br>• Number of incidents for request fulfillment |
| D2C | • OLA versus SLA<br>• Reduction in outages<br>• Number of problems identified and removed<br>• Percent of time invested on business-critical services |
