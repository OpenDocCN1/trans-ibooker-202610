# Figure 5-22. Viewing WIP limits in JIRA

The Selected for Development swim lane has a maximum limit of five issues, and the moment you drag a new issue from backlog it turns red. This alerts the user that more work items cannot be placed. This is an excellent method to review team capacity that brings in transparency and helps to track and prioritize work. See Figure 5-23.
