# Agile ITSM

As ITSM has evolved, there arose a need to complement rapid digitization and emerging needs. Organizations identified gaps that needed attention such as fragmented ITSM tools, limited standardization, etc., and looked at alternates to ITSM. While classic ITSM was well accepted by many organizations, there was a growing need for agility. Organizations looked for guidance to run their Service Delivery phase effectively in an agile way.
