The code is shown in the following snippet:


12. If the authorization callback denies the action, the statement object is NULL, so it's best to use an if () statement to test its presence. If so, we then proceed to bind the value and execute the statement, as illustrated in the following code snippet:

```
if ($stmt) {
    $stmt->bindValue(':id', $id);
    $stmt->bindValue(':name', $user_name);
    $stmt->bindValue(':email', $user_email);
    $stmt->bindValue(':pwd', 'password');
    $result = $stmt->execute();
```
