# Examining the createFromInterface() method

In PHP 8, it's much easier to convert between DateTime and DateTimeImmutable, and back again. A new method called createFromInterface() has been added to both classes. The method signature simply calls for a DateTimeInterface instance, which means that instances of either DateTime or DateTimeImmutable are acceptable arguments for this method.

The following brief code example demonstrates how easy it is to convert from one type into another in PHP 8:
