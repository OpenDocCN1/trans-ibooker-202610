## 前言

我认识道格·比埃尔很多年了。与他一起培训新 PHP 开发人员并帮助现有人员提升技能是我的荣幸。我也多次把他名字的发音弄错。多年来，我敬佩他能把技术概念用任何人都能懂的语言表达出来。所以当他请我为本书写前言时，我很乐意答应。

技术培训不容易。培训师既要透彻理解主题，又要能清晰传达。我长期苦恼如何结合这两项技能。道格让它看起来很简单，本书就是证明。从语言到示例，一切都清晰呈现。

PHP 8 是巨大飞跃。写 PHP 8.0 时，PHP 8.1 已在 Alpha 测试，PHP 的工具和概念已与任何 Web 开发语言一样优秀。加上近年各版本的速度提升，更能看出 PHP 仍是 Web 开发主力。

购买本书是利用 PHP 8 能力的第一步。结合本书知识和道格让概念易懂且可立即应用的技巧，你将点燃推动技能和职业发展的火箭。

系好安全带，坐稳——这将是一次有趣的旅程！

Cal Evans (cal@calevans.com)

**道格·比埃尔** 自 1971 年在 DEC PDP-8 上写第一个程序起就迷上计算机。职业生涯中自 1978 年起担任专业合同程序员，曾使用 BASIC、PL/I、Assembler、FORTH、C、C++、dBase/FoxBase/Clipper、Pascal、Perl、Java 和 PHP。1993 年在旧金山部署了第一个网站。他会四种语言，旅居广泛，现居泰国。也从事过系统管理和 TCP/IP 网络。技术著作包括 *PHP 7 Programming Cookbook* 和 *Learning MongoDB 4.x*（Packt），以及 *Learning PHP and MySQL*、*Learning PHP Security* 和 *Learning Doctrine*（O'Reilly Media）。
