The first important thing to note from the output is that the indices are all integers. Because the array is of type char, we can use FFI::string() to display one of the rows. Here is a command that produces an ABC response:


Any attempt to supply the FFI\CData instance to a PHP function that takes an array as an argument is doomed to failure, even if it is defined as an array type. In the following code snippet, note the output if we add this command to the preceding code block:

```

```
