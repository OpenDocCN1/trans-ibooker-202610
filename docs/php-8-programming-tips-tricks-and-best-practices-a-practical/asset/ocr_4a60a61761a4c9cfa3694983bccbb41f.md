# Conventional ::class constant usage

The special `::class` constant is frequently used in situations where you have a lengthy namespace and wish to not only save yourself a lot of unneeded typing, but also preserve the readability of your source code.

In this simple example, using the `Php7\Image\Strategy` namespace, we wish to create a list of strategy classes:

+   1. First, let's identify the namespace and set up the autoloader:
+   2. Before the special `::class` constant was introduced, to produce a list of full namespace class names, you had to write it all out as a string, as shown here:
+   3. Using the special `::class` constant, you can reduce the amount of typing required, and you can also make the code more readable, as shown here:

```
// /repo/ch09/php7_class_normal.php
namespace Php7\Image\Strategy;
require_once __DIR__
  './../../src/Server/Autoload/Loader.php';
$autoload = new \Server\Autoload\Loader();
```

```
$listOld = [
  'Php7\Image\Strategy\DotFill',
  'Php7\Image\Strategy\LineFill',
  'Php7\Image\Strategy\PlainFill',
  'Php7\Image\Strategy\RotateText',
  'Php7\Image\Strategy\Shadow'
];
print_r($listOld);
```

```
$listNew = [
  DotFill::class,
  LineFill::class,
  PlainFill::class,
  RotateText::class,
  Shadow::class
];
print_r($listNew);
```
