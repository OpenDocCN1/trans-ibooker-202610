## 前言

PHP 8 代表了 PHP 核心开发团队为最大化核心语言效率而做的工作的集大成。仅通过迁移到 PHP 8，您的应用程序代码就会立即看到速度提升，并且内存占用更小。此外，在 PHP 8 中，开发者注意到在语法和语言使用规范化方面投入了巨大的努力。简而言之，对于欣赏良好编码实践的开发者来说，在 PHP 8 中编程是一种乐趣。

然而，这不可避免地引出一个问题：PHP 语言接下来会走向何方？PHP 8 也提供了这个问题的答案，以即时编译器和对纤程的支持形式出现。后者构成了异步编程的基础，并已宣布用于 PHP 8.1。PHP 8 让您一窥语言的未来，而那个未来看起来极其光明！

如果把这些结合起来，就很清楚，理解和掌握 PHP 8 中实现的新特性和更严格的编码实践，对于那些希望作为 PHP 开发者追求严肃职业的人来说至关重要。本书正是您快速上手 PHP 8 所需的工具。不仅我们涵盖了新特性，而且我们还向您展示如何避免可能导致 PHP 8 迁移后代码失败的陷阱。此外，我们还通过对 JIT 编译器和 PHP 异步编程的全面介绍，让您一窥 PHP 的未来。

## 本书涵盖内容

第 1 章《介绍 PHP 8 的新 OOP 特性》向您介绍面向对象编程（OOP）特定的 PHP 8 新特性。本章包含大量简短的代码示例，清晰地说明了新特性和概念。本章对于帮助您快速利用 PHP 8 的强大功能并将代码示例适配到自己的实践中至关重要。

第 2 章《了解 PHP 8 的函数式新增功能》涵盖了在过程层面引入 PHP 8 的重要新增和增强功能。它包含大量代码示例，展示了新的 PHP 8 特性和技术以促进过程式编程。本章教您如何编写更快、更干净的应用程序代码。

第 3 章《利用错误处理增强功能》探讨了 PHP 8 的关键改进之一，即其高级错误处理能力。在本章中，您将了解哪些 Notices 已被升级为 Warnings，以及哪些 Warnings 现在已被提升为 Errors。本章将为您提供关于安全增强背景和意图的出色理解，使您能够更好地控制代码的使用。此外，了解那些过去仅生成 Warnings、现在生成 Errors 的错误条件至关重要，以便您采取措施防止应用程序在升级到 PHP 8 后失败。

第 4 章《进行直接的 C 语言调用》帮助您了解外部函数接口（FFI）是什么、它有什么用以及如何使用它。本章中的信息对于希望使用直接 C 语言调用进行快速自定义原型设计的开发者非常重要。本章向您展示如何将 C 语言结构和函数直接合并到您的代码中，从而打开了迄今为止对 PHP 来说不可用的整个功能世界的大门。

第 5 章《发现潜在的 OOP 向后兼容性破坏》向您介绍面向 OOP 的 PHP 8 新特性。本章包含大量简短的代码示例，清晰地说明了新特性和概念。本章对于帮助您通过将代码示例适配到自己的实践中，快速利用 PHP 8 的强大功能至关重要。此外，本章还强调了在 PHP 8 迁移后面向对象的代码可能中断的情况。

第 6 章《理解 PHP 8 的功能差异》涵盖了 PHP 8 命令或功能层面的潜在向后兼容性破坏。本章提供了重要信息，突出了将现有代码迁移到 PHP 8 时可能遇到的陷阱。本章中提供的信息使您能够生成可靠的 PHP 代码。完成本章概念的学习后，您将处于更好的位置来编写产生精确结果并避免不一致的代码。

- 第 7 章《在使用 PHP 8 扩展时避免陷阱》带您了解对扩展所做的重大更改以及在将现有应用程序更新到 PHP 8 时如何避免陷阱。一旦您完成对示例代码和所呈现主题的审阅，您将能够为迁移到 PHP 8 准备任何现有的 PHP 代码。除了了解对各种扩展的更改外，您还将深入了解其运行方式。这将使您在使用 PHP 8 中的扩展时做出明智的决策。

- 第 8 章《了解 PHP 8 中已弃用或移除的功能》引导您了解在 PHP 8 中已弃用或移除的功能。在您阅读完本章内容并遵循示例应用程序代码后，您将能够检测和重写已弃用的代码。您还将学习如何为已移除的功能开发变通方法，以及如何重构使用涉及扩展的已移除功能代码。您在本章中将学习到的另一个重要技能是通过重写依赖于在 PHP 8 中完全移除的函数的代码来提高应用程序安全性。

- 第 9 章《掌握 PHP 8 最佳实践》向您介绍现在在 PHP 8 中强制执行的最佳实践。它涵盖了许多重要的方法签名更改以及其新用法如何延续 PHP 的总体趋势，帮助您生成更好的代码。您还将了解私有方法、接口、trait 和匿名类的使用变化，以及命名空间现在如何被解析。掌握本章涵盖的最佳实践不仅会使您朝着编写更好代码的方向发展，还将帮助您避免如果未能掌握这些新实践而可能出现的代码中断。

- 第 10 章《提升性能》向您介绍许多对性能产生积极影响的新 PHP 8 特性，特别关注新的即时编译器。本章还包括对弱引用的全面介绍，其正确使用可使应用程序使用更少的内存。通过仔细审阅本章涵盖的材料并研究代码示例，您将能够编写更快、更高效的代码。

- 第 11 章《将现有 PHP 应用迁移到 PHP 8》介绍了一组构成 PHP 8 向后兼容性破坏扫描器基础的类。在整本书中，您将看到 PHP 8 更新后可能出现的潜在代码破坏。此外，您还将了解将现有客户 PHP 应用程序迁移到 PHP 8 的推荐流程。本章将使您更好地配备处理 PHP 8 迁移的能力，使您能够以更大的信心和最少的问题执行 PHP 8 迁移。

- 第 12 章《使用异步编程创建 PHP 8 应用》解释了传统同步和异步编程模型之间的区别。近年来，一项令人兴奋的新技术席卷了 PHP 社区：异步编程，也称为 PHP async。此外，还涵盖了流行的 PHP async 扩展和框架，包括 Swoole 扩展和 ReactPHP，并附有大量示例供您入门。到您完成本章学习时，您将能够提高应用程序的性能，使其速度提升 5 倍到惊人的 40 倍！
