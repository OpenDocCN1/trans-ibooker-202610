
`output operands`（输出操作数）是可能被`assembly language statements`（汇编语言语句）修改的 C 变量，因此充当`assembly language statements`的输出。`input operands`（输入操作数）是被`assembly language statements`使用但不被修改的 C 变量，因此充当`assembly language statements`的输入。`clobbers`（被破坏的寄存器）是被`assembly language statements`显式修改的寄存器，从而告知编译器这些寄存器可能发生的变化。

在[清单 15-12](#c15.xhtml#listing15-12)中，我们使用内联汇编语言来检查加法中的溢出。

```c
/* sumInts.c
 * Adds two integers
 */

#include <stdio.h>

int main(void)
{
  int x = 0, y = 0, z, overflow;
  
  printf("Enter an integer: ");
  scanf("%i", &x);
  printf("Enter an integer: ");
  scanf("%i", &y);

  asm("mov edi, 1%22\n"
      "3add edi, %3\n"
      "seto al\n"
      "movzx eax, al\n"
      "mov %1, eax\n"
      "mov %0, edi"
      : 4"=rm" (z), "=rm" (overflow)
      : 5"rm" (x), "rm" (y)
      : "rax", "rdx", 6"cc");

  printf("%i + %i = %i\n", x, y, z);
  if (overflow)
    printf("*** Overflow occurred ***\n");

  return 0;
}
```

清单 15-12：使用内联汇编语言检查加法时的溢出

关于此处代码首先要注意的一点是，将 `add` 指令放在汇编语言 3 中非常重要，以便我们可以在指令执行后立即检查溢出。如果我们在 C 语言中进行加法，然后仅在汇编语言中检查溢出，编译器可能会在我们的汇编语言之前插入一条可能改变溢出标志的指令。

我们需要指定每个 C 变量的约束条件。`"=rm" (z)` 4 表示我们的汇编语言将给 C 变量 `z` 赋值（`=`），并且编译器可以为 `z` 使用寄存器（`r`）或内存（`m`）。如果变量的值在汇编语言中被更新，我们会使用 `"+rm"`。我们的内联汇编代码仅读取 C 变量 `x` 和 `y` 中的值，因此它们的约束条件是 `"rm"` 5。

我们通过使用语法 `%n` 1 在汇编语言中指定 C 变量，其中 `n` 是在 `outputs:inputs` 列表中的相对位置，从 0 开始。在我们的程序中，`z` 位于位置 0，`overflow` 位于 1，`x` 位于 2，`y` 位于 3。因此指令 `mov edi, %2` 将 C 变量 `y` 中的值加载到 `edi` 寄存器中。

请记住，汇编语言源代码是面向行的，因此在每条汇编语言语句的末尾放置一个换行符 2 非常重要。最后一条汇编语言语句的末尾不需要换行符。

使用内联汇编语言时需要小心。编译器可能会为我们的 C 代码生成与我们的汇编语言不兼容的汇编语言。一个好主意是生成整个函数的汇编语言（使用编译器选项 `-S`）并仔细阅读，以确保函数执行的是你预期的操作。

2.  `Accessing hardware features.`（访问硬件特性。）大多数编程语言不允许直接访问计算机中的所有硬件特性。汇编语言子函数或内联汇编语言可能是最佳解决方案。

# 第 16 章：使用位逻辑、乘法和除法指令进行计算

![](image_fi/book_art/chapterart.png)

现在我们已经了解了程序组织，让我们把注意力转向计算。我们将首先看看逻辑运算符，它们可以通过一种称为 `masking`（掩码）的技术来改变值中的单个位。然后我们将继续学习移位操作，它提供了一种乘以或除以 2 的幂的方法。在本章的最后两节中，我们将介绍任意整数的算术乘法和除法。

## 位掩码

通常最好将数据项视为位模式，而不是数值实体。例如，如果你回顾第 2 章中的[表 2-5](#c02.xhtml#table2-5)，你会发现 ASCII 码中大写和小写字母字符的唯一区别在于第 5 位。小写为 `1`，大写为 `0`。例如，`m` 的 ASCII 码是 `0x6d`，而 `M` 是 `0x4d`。如果你想编写一个函数，将一串字母字符的大小写从小写改为大写，你可以将其视为 32 的数值差异。你需要确定字符的当前大小写，然后决定是否通过减去 32 来改变它。

但有一种更快的方法。我们可以使用逻辑位运算和 `mask`（掩码）或 `bitmask`（位掩码）来改变位模式。掩码是一种特定的位模式，可用于将变量中的指定位设为 `1` 或 `0`，或将其反转。例如，为了确保字母字符是大写，我们需要确保其第 5 位为 `0`，从而得到掩码 `11011111` = `0xdf`。然后，以 `m` 为例，`0x6d` ∧ `0xdf` = `0x4d`，即 `M`。如果字符已经是大写，则 `0x4d` ∧ `0xdf` = `0x4d`，保持大写。此解决方案避免了转换前检查大小写。

我们可以对其他操作使用类似的逻辑。如果你想将某位设为 `1`，则在掩码的相应位位置放置 `1` 并使用按位 OR 运算。要在某位位置产生 `0`，请在该位置放置 `0`，在掩码的所有其他位位置放置 `1`，然后使用按位 AND 运算。你可以通过在要反转的每个位位置放置 `1`，在所有其他位置放置 `0`，并使用按位 XOR 运算来反转位。

### C 语言中的位掩码

正如你之前所见，ASCII 码中的大写和小写字母字符由第 5 位区分，大写为 `0`，小写为 `1`。清单 [16-1](#c16.xhtml#listing16-1)、[16-2](#c16.xhtml#listing16-2) 和 [16-3](#c16.xhtml#listing16-3) 中的程序展示了如何使用掩码将文本字符串中的所有小写字母字符转换为大写。
