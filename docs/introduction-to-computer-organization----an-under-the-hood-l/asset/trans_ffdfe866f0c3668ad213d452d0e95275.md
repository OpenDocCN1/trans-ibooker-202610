
## 可编程阵列逻辑 (PAL) 器件

在 `programmable array logic` (`PAL`) 器件中，每个 OR 门永久连接到一组 AND 门。只有 AND 门平面可编程。[图 6-18](#c06.xhtml#figure6-18) 中所示的 PAL 有四个输入。它提供两个输出，每个输出最多可为四个乘积之和。OR 门平面中的“×”连接表明：顶部四个 AND 门经 OR 运算产生 `F1(w, x, y, z)`，底部四个经 OR 运算产生 `F2(w, x, y, z)`。该图中的 AND 门平面已编程以产生这两个函数：

![c06m0007](image_fi/500099c06/c06m0007.png)

```
F1(w, x, y, z) = (w ∧ ¬x ∧ z) ∨ (¬w ∧ x) ∨ (w ∧ x ∧ ¬y) ∨ (¬w ∧ ¬x ∧ ¬y ∧ ¬z)
F2(w, x, y, z) = (¬w ∧ y ∧ z) ∨ (x ∧ y ∧ ¬z) ∨ (w ∧ x ∧ y ∧ z) ∨ (w ∧ x ∧ ¬y ∧ ¬z)
```

## PLD 类型比较

在本文介绍的三种 PLD 中，`PLA` 最灵活，因为我们可以同时编程 OR 平面和 AND 平面，但它也是三种器件中最昂贵的。`ROM` 灵活性较低。它可被编程以产生任意最小项组合，这些最小项再经 OR 运算组合。我们知道任何函数都可实现为最小项的 OR，因此用 ROM 可产生任意函数。然而，ROM 不允许我们最小化函数，因为所有乘积项必须是最小项。

![图 6-18：双功能可编程阵列逻辑](image_fi/500099c06/f06018.png)

图 6-18：双功能可编程阵列逻辑

`PAL` 最不灵活，因为在 AND 平面编程的所有乘积项将被 OR 在一起。所以，我们不能通过编程 OR 平面来选择函数中的最小项。然而，PAL 允许我们进行一些布尔函数最小化。如果所需函数可在 PAL 中实现，它比 ROM 或 PLA 更便宜。

## 学习总结

1. `Combinational logic circuits` 这些电路仅依赖于任意时刻的输入。它们没有对输入先前效果的记忆。示例包括加法器、解码器、多路复用器和可编程逻辑器件。

2. `Half adder` 该电路有两个一位输入。它产生两个一位输出：输入之和及该和的进位。

3. `Full adder` 该电路有三个一位输入。它产生两个一位输出：输入之和及该和的进位。

4. `Ripple-carry adder` 使用 `n` 个全加器来加 `n` 位数字。每个全加器的进位输出是下一高位全加器的三个输入之一。

5. `Decoder` 一种基于 2^(`n`) 个输入选择 `n` 个输出之一的器件。

6. `Multiplexer (MUX)` 一种基于 `n` 位选择信号从 2^(`n`) 个输入中选择一个的器件。

7. `Programmable logic array (PLA)` 一种用于生成最小项的 OR 组合以在硬件中实现布尔函数的器件。

8. `Read-only memory (ROM)` 提供非易失性存储器，输入为数据或指令的地址。

9. `Programmable array logic (PAL)` 一种用于在硬件中实现布尔函数的器件。它比 PLA 或 ROM 灵活性低，但更便宜。

# 第 7 章：时序逻辑电路

![](image_fi/book_art/chapterart.png)

在上一章中，你学习了 `combinational logic circuits`，即仅依赖于当前输入的电路。另一种思考方式是：组合逻辑电路是瞬时的（除去电子器件稳定所需时间）：其输出仅取决于观察输出时刻的输入。而 `Sequential logic circuits` 则依赖于当前和过去的输入。它们有时间历史，可用电路的当前状态来概括。

形式上，`system state` 是系统的一种描述，使得在时间 `t[0]` 知道状态以及从时间 `t[0]` 到 `t[1]` 的输入，就能唯一确定时间 `t[1]` 的状态以及从 `t[0]` 到 `t[1]` 的输出。换句话说，系统状态提供了影响系统的一切的摘要。在任意给定时间 `t` 知道系统的状态，就能告诉你从那时起指定系统行为所需的一切。它是如何进入该状态的无关紧要。

系统状态的概念体现在 `finite state machine` 中，这是一种计算数学模型，可存在于有限数量的状态中的任意一个。有限状态机的外部输入导致其从一个状态转移到另一个状态或同一状态，同时可能产生输出。顺序逻辑电路用于实现有限状态机。如果顺序逻辑电路的设计使其输出仅依赖于其所处的状态，则称为 `Moore state machine`。如果输出还依赖于导致状态转移的输入，则称为 `Mealy state machine`。

在本章中，我们将探讨如何在逻辑电路中使用 `feedback` 使门电路随时间保持特定状态，从而实现存储器。我们将使用 `state diagrams` 来展示输入如何导致顺序逻辑电路在状态间转移以及相应的输出。你还将学习如何用时钟同步顺序逻辑电路以提供可靠结果。
