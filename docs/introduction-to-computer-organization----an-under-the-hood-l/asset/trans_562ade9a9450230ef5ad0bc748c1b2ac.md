

# 布尔代数简化与卡诺图

## 使用布尔代数进行电路简化

对比图 4-5 和图 4-4 中的电路，布尔代数帮助你简化了硬件实现。你可以从用英语陈述导致进位为 `1` 的条件中看到这种简化：该方程的原始标准形式指出，进位 `C[out](c[in], x, y)` 将在以下四种情况中的任意一种中为 `1`：

1.  若 `c[in]` = `0`，`x` = `1`，且 `y` = `1`
2.  若 `c[in]` = `1`，`x` = `0`，且 `y` = `1`
3.  若 `c[in]` = `1`，`x` = `1`，且 `y` = `0`
4.  若 `c[in]` = `1`，`x` = `1`，且 `y` = `1`

最小化表达可以陈述得更简单：当 `c[in]`、`x` 和 `y` 中**至少有两个**为 `1` 时，进位为 `1`。

我们通过从最小项之和开始，得出了[图 4-5](#c04.xhtml#figure4-5) 中的解；换句话说，我们使用的是产生进位为 `1` 的 `c[in]`、`x` 和 `y` 的值。正如你在 69 页的“标准乘积或最大项乘积”中所见，由于进位必须是 `1` 或 `0`，从产生进位补码为 `0` 的 `c[in]`、`x` 和 `y` 的值开始，并将方程写为最大项乘积的形式，同样是有效的：

```
¬C[out](c[in], x, y) = (c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ y) ∧ (¬c[in] ∨ ¬x ∨ ¬y)
```

为了简化这个方程，我们将采用与最小项之和相同的方法，首先复制最后一项两次：

```
¬C[out](c[in], x, y) = (c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ y) ∧ (¬c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ ¬y)
```

添加一些括号有助于阐明简化过程：

```
¬C[out](c[in], x, y) = ((c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ ¬y)) ∧ ((¬c[in] ∨ x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ ¬y)) ∧ ((¬c[in] ∨ ¬x ∨ y) ∧ (¬c[in] ∨ ¬x ∨ ¬y))
```

接下来，使用或对与的分配律。因为这比较棘手，我将讲解简化该方程中第一组乘积项的步骤——其他两组的步骤与此类似。或对与的分配律具有以下通用形式：

```
(X ∨ Y) ∧ (X ∨ Z) = X ∨ (Y ∧ Z)
```

观察我们第一组中的和项，你可以看到它们都共享一个 `(¬x ∨ ¬y)`。因此，我们将这些代入通用形式中：

![c04m0011](image_fi/500099c04/c04m0011.png)

进行代入并使用与的补码规则，我们得到

```
(c[in] ∨ ¬x ∨ ¬y) ∧ (¬c[in] ∨ ¬x ∨ ¬y) = (¬x ∨ ¬y) ∨ (c[in] ∧ ¬c[in])
 = (¬x ∨ ¬y)
```

对另外两组应用相同的操作，我们得到

```
¬C[out](c[in], x, y) = (¬x ∨ ¬y) ∧ (¬c[in] ∨ ¬x) ∧ (¬c[in] ∨ ¬y)
```

[图 4-6](#c04.xhtml#figure4-6) 展示了该函数的电路实现。该电路产生进位的补码。我们需要对输出 `¬C[out](c[in], x, y)` 取补，才能得到进位的值。

![Figure 4-6: Simplified hardware implementation generating the complement of carry when adding two numbers](image_fi/500099c04/f04006.png)

图 4-6：两数相加时产生进位补码的简化硬件实现

对比[图 4-6](#c04.xhtml#figure4-6)与[图 4-5](#c04.xhtml#figure4-5)，你可以直观地看到德摩根定律：或门变成了输入端取反的与门。

[图 4-5](#c04.xhtml#figure4-5) 中的电路对你来说可能看起来更简单，因为[图 4-6](#c04.xhtml#figure4-6) 中的电路要求在或门的六个输入端加上非门。但正如你在下一章将看到的，由于构建逻辑门所用器件固有的电子特性，情况可能并非如此。这里要理解的重要一点是，解决问题的方法不止一种。硬件工程师的工作之一就是根据成本、元件可用性等因素决定哪种方案最好。

### 使用卡诺图进行最小化

用于最小化布尔函数的代数操作并不总是显而易见的。你可能会发现使用逻辑陈述的图形表示更容易处理。

处理布尔函数常用的图形工具是卡诺图，也称为 K 图。1953 年，贝尔实验室的电信工程师莫里斯·卡诺发明了卡诺图，它提供了一种直观的方法来寻找代数上可发现的相同简化。它们既可以用于最小项的乘积之和，也可以用于最大项的和之积。为了说明其工作原理，我们将从最小项开始。

#### 使用卡诺图简化乘积之和

卡诺图是一个矩形网格，每个最小项对应一个单元格。对于 `n` 个变量，有 2`n` 个单元格。[图 4-7](#c04.xhtml#figure4-7) 是一个卡诺图，显示了两个变量 `x` 和 `y` 的所有四种可能的最小项。垂直轴用于绘制 `x`，水平轴用于绘制 `y`。每行的 `x` 值由紧邻该行左侧的数字（`0` 或 `1`）表示，每列的 `y` 值出现在列顶部。

![Figure 4-7: Mapping of two-variable minterms on a Karnaugh map](image_fi/500099c04/f04007.png)

图 4-7：两变量最小项在卡诺图上的映射

为了说明如何使用卡诺图，让我们看一个两个变量的任意函数：

```
F(x, y) = (x ∧ ¬y) ∨ (¬x ∧ y) ∨ (x ∧ y)
```

首先在方程中出现的每个最小项对应的单元格中放置一个 `1`，如[图 4-8](#c04.xhtml#figure4-8)所示。

![Figure 4-8: Karnaugh map of the arbitrary function, F(x, y)](image_fi/500099c04/f04008.png)

图 4-8：任意函数 `F(x, y)` 的卡诺图

通过在每个求值为 `1` 的最小项对应的单元格中放置 `1`，我们可以直观地看到方程何时求值为 `1`。右侧的两个单元格对应最小项 `m[1]` 和 `m[3]`，即 `(¬x ∧ y)` 和 `(x ∧ y)`。由于这些项通过或运算连接，如果这两个最小项中任意一个求值为 `1`，`F(x, y)` 就求值为 `1`。利用分配律和补码规则，我们可以看到

![c04m0007](image_fi/500099c04/c04m0007.png

这从代数上表明，无论何时 `y` 为 `1`，`F(x, y)` 都求值为 `1`，接下来你将通过简化这个卡诺图看到这一点。

这两个最小项 `(¬x ∧ y)` 和 `(x ∧ y)` 的唯一区别在于 `x` 变为 `¬x`。卡诺图的排列使得共享一条边的两个单元格之间只有一个变量发生变化，这一要求称为邻接规则。

要使用卡诺图进行简化，你需要在乘积之和卡诺图中将两个包含 `1` 的相邻单元格分组。然后消除它们之间不同的变量，并将两个乘积项合并。重复此过程即可简化方程。每次分组都会消除最终乘积之和中的一个乘积项。这可以扩展到两个以上变量的方程，但分组在一起的单元格数量必须是 2 的倍数，且只能分组相邻单元格。邻接性从左到右、从上到下环绕。几页后你将看到一个相关示例。

要了解这一切如何运作，请考虑[图 4-9](#c04.xhtml#figure4-9) 中卡诺图的分组。

![Figure 4-9: Two of the minterms in F(x, y) grouped](image_fi/500099c04/f04009.png)

图 4-9：`F(x, y)` 中的两个最小项分组

该分组是我们之前进行的代数操作的图形表示。你可以看到，无论 `x` 的值如何，`F(x, y)` 在 `y` = `1` 时总是求值为 `1`。因此，该分组通过消除 `x` 将两个最小项合并为一个乘积项。

从最后的分组中，我们知道我们最终简化的函数将包含一个 `y` 项。让我们进行另一次分组以找到下一项。首先，我们将从代数上简化方程。回到 `F(x, y)` 的原始方程，我们可以利用幂等律复制其中一个最小项：

```
F(x, y) = (x ∧ ¬y) ∨ (¬x ∧ y) ∨ (x ∧ y) ∨ (x ∧ y)
```
