
# 清单 18-15：`fraction` 类的 `fraction_add` 函数

```asm
# fraction_add.s
# 将整数加到分数上
# 调用序列：
#   rdi <- 对象指针
#   esi <- 要加的整数
        .intel_syntax noprefix
        .include    "fraction"
# 代码
        .text
        .globl  fraction_add
        .type   fraction_add, @function
fraction_add:
        push    rbp             # 保存帧指针
        mov     rbp, rsp        # 设置新帧指针
        mov     eax, den[rdi]   # 加载分母
        imul    eax, esi        # 分母 X 要加的整数
        add     num[rdi], eax   # 加到分子上
        mov     rsp, rbp        # 恢复栈指针
        pop     rbp             # 并恢复调用者的帧指针
        ret
```

`fraction_get` 或 `fraction_add` 没有什么特别之处。`fraction_get` 函数调用其他函数，因此我们需要将 `this` 指针放在栈帧中。`rdi` 寄存器在 `fraction_add` 中可安全用作 `this` 指针，因为它不调用任何其他函数。

2.  **C++ 中的对象** — 一个命名的内存区域，包含类中声明的数据成员。

6.  **析构函数** — 用于清理不再需要的资源的成员函数。

# 第 19 章：小数值

![](image_fi/book_art/chapterart.png)

在程序中，我们一直只使用整数值——整数和字符。在本章中，我们将探讨计算机如何表示小数值。我们将介绍两种表示小数值的方式：*定点数* 和 *浮点数*。

我们将首先看看定点数，这将展示小数值如何用二进制表示。正如你将看到的，用于数值整数部分的位数限制了我们能表示的数值范围。为小数部分使用一些位只是允许我们将该范围划分为更小的部分。

这种范围限制将引导我们讨论浮点数，它允许更大的范围，但也引入了其他限制。我们将讨论浮点表示的格式和属性，然后讨论最常见的浮点二进制标准 IEEE 754。我们将以简要探讨浮点数在 x86-64 架构中如何处理来结束本章。

## 二进制中的小数值

让我们从小数值的数学原理开始看起。回顾第 2 章，十进制整数 *N* 可用二进制表示如下：

$$
N = d_{n-1} \times 2^{n-1} + d_{n-2} \times 2^{n-2} + \dots + d_1 \times 2^1 + d_0 \times 2^0
$$

其中每个 $d_i \in \{0, 1\}$。

我们可以扩展它以包含小数部分 *F*：

$$
N.F = d_{n-1} \times 2^{n-1} + d_{n-2} \times 2^{n-2} + \dots + d_0 \times 2^0 + d_{-1} \times 2^{-1} + d_{-2} \times 2^{-2} + \cdots
$$

$$
= d_{n-1}d_{n-2}\dots d_0.d_{-1}d_{-2}\dots
$$

其中每个 $d_i \in \{0, 1\}$。请仔细注意等式右侧 $d_0$ 和 $d_{-1}$ 之间的 *二进制点*。二进制点右侧的所有项都是 2 的负幂，因此这部分数值之和为一个小数值。就像左侧的十进制点一样，二进制点将数值的小数部分与整数部分分开。这里有个例子：

$$
1.6875_{10} = 1.0_{10} + 0.5_{10} + 0.125_{10} + 0.0625_{10}
$$

$$
= 1 \times 2^0 + 1 \times 2^{-1} + 0 \times 2^{-2} + 1 \times 2^{-3} + 1 \times 2^{-4}
$$

$$
= 1.1011_2
$$
