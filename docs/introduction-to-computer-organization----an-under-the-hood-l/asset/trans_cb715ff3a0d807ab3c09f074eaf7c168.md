## AT&T 语法

本书中汇编语言使用的是 Intel 语法，但对于可能偏好 AT&T 语法的读者，我将在此简要介绍。AT&T 语法是大多数 Linux 发行版中的默认语法。

[清单 10-7](#c10.xhtml#listing10-7) 重复了[清单 10-5](#c10.xhtml#listing10-5)中的程序，但使用 AT&T 语法编写。

```
# doNothingProg_att.s
# C 程序的最小组件，用汇编语言编写。
        .text
        .globl  main
        .type   main, @function
main:
      1 pushq 2 %rbp        # 保存调用者的帧指针
        movq  3 %rsp, %rbp  # 建立我们的帧指针

        movq  4 $0, %rax    # 返回 0；

        movq    %rbp, %rsp  # 恢复栈指针
        popq    %rbp        # 恢复调用者的帧指针
        ret                 # 返回调用者
```

**清单 10-7：** 使用 AT&T 语法编写的最小 C 程序汇编语言版本

你可能注意到的第一个区别是，一个指定操作数大小的字符作为后缀被添加到了大多数指令助记符后面 1。[表 10-2](#c10.xhtml#table10-2) 列出了这些大小字母。（是的，在操作数之一为寄存器的情况下这是冗余的，但这是语法的一部分。）你可能看到的下一个区别是每个寄存器都以前缀 `%` 字符开头 2。

最显著的区别是操作数的顺序被颠倒了 3。目的操作数不再放在第一位，而是最后一位。如果你在 Intel 和 AT&T 两种语法之间切换，很容易搞错操作数的顺序，尤其是使用两个寄存器的指令。在 AT&T 语法中，你还需要在立即数值前加上 `$` 字符 4。

**表 10-2：** AT&T 语法的数据大小后缀

| **后缀字母** | **数据类型** | **位数** |
| --- | --- | --- |
| `b` | 字节 | 8 |
| `w` | 字 | 16 |
| `l` | 双字 | 32 |
| `q` | 四字 | 64 |

如前言所述，我选择在本书中使用 Intel 语法，以与 Intel 和 AMD 手册保持一致。据我所知，GNU 汇编器 `as` 是唯一默认使用 AT&T 语法的汇编器。所有其他汇编器都使用 Intel 语法，而 `as` 将其作为一个选项提供。

## 你所学到的内容

1.  **编辑器** — 用于用选定的编程语言编写程序源代码的程序。
2.  **预处理器** — 编译的第一阶段。它将其他文件引入源代码，定义宏等，为实际编译做准备。
3.  **编译** — 将选定的编程语言翻译成汇编语言。
4.  **汇编** — 将汇编语言翻译成机器语言。
5.  **链接** — 将单独的目标代码模块和库链接在一起，生成最终的可执行程序。
6.  **汇编器指令** — 在汇编过程中指导汇编程序。
7.  `mov` **指令** — 在内存与 CPU 之间以及 CPU 内部移动值。
8.  `push` **指令** — 将值压入调用栈。
9.  `pop` **指令** — 从调用栈中弹出值。
10. `ret` **指令** — 将程序流程返回给调用函数。
11. `gdb` **TUI 模式** — 在你单步执行程序时实时显示寄存器的变化。它是一个极好的学习工具。
12. **序言** — 为被调用函数设置调用栈。
13. **尾声** — 为调用函数恢复调用栈。

# 第 11 章：深入 main 函数

![](image_fi/book_art/chapterart.png)

正如你所知，每个 C 程序都从执行一个名为 `main` 的函数开始，该函数由 C 运行时环境中的启动函数调用。`main` 函数将调用其他函数（*子函数*）来完成大部分处理。即使是一个简单的“Hello, World!”程序，也需要调用另一个函数将消息写在屏幕上。

大多数子函数需要从调用函数传递参数作为数据，并且它们经常将结果传回调用函数。函数的参数可以是数据或内存地址。当函数被调用时，它执行其操作，然后返回调用函数。调用函数需要将返回地址发送给被调用函数。在 x86-64 架构中，返回地址通过调用栈传递。

增加一点复杂性，大多数函数需要自己的局部变量来存储数据和地址。寄存器可用于变量，但它们是全局的，我们会很快用完可用的寄存器。栈为在内存中分配局部变量空间提供了良好的场所。
