

## 可编程逻辑阵列

与门平面产生的乘积项均通过熔丝连接到或门的输入端。因此，取决于保留了哪些或门熔丝，每个或门的输出都是乘积之和。可能会有额外的逻辑电路用于在不同输出之间进行选择。我们已经看到，任何布尔函数都可以表示为乘积之和，因此，通过烧断熔丝，该逻辑器件可以被编程以实现任意布尔函数。

典型的 PLA 比 [图 6-15](#c06.xhtml#figure6-15) 所示的要大，而后者绘制起来已经很复杂了。为了简化绘图，通常使用类似 [图 6-16](#c06.xhtml#figure6-16) 的图来指定设计。

![图 6-16：可编程逻辑阵列示意图。圆点表示连接。](`image_fi/500099c06/f06016.png`)

图 6-16：可编程逻辑阵列示意图。圆点表示连接。

该图理解起来可能有点棘手。在[图 6-15](#c06.xhtml#figure6-15)中，每个与门有多个输入——每个变量一个，每个变量的补码一个。在[图 6-16](#c06.xhtml#figure6-16)中，我们用一条通向每个与门输入的水平线来表示多根导线（变量及其补码）。因此，[图 6-16](#c06.xhtml#figure6-16)中的每个与门有八个输入，尽管我们只画了一条线。

垂直线和水平线交叉处的圆点表示熔丝保持完好、从而形成连接的位置。例如，最顶端水平线上的三个圆点表明有三个输入保持连接到该与门。最顶端与门的输出如下：

`¬w ∧ y ∧ z`

再次参考[图 6-15](#c06.xhtml#figure6-15)，我们看到每个与门的输出都（通过熔丝）连接到每个或门。因此，或门也有多个输入——每个与门一个——通向或门输入的垂直线代表多根导线。[图 6-16](#c06.xhtml#figure6-16)中的 PLA 已被编程以提供以下三个函数：

![`c06m0006`](`image_fi/500099c06/c06m0006.png`)

```
F1(w, x, y, z) = (¬w ∧ y ∧ z) ∨ (w ∧ x ∧ ¬z)
F2(w, x, y, z) = ¬w ∧ ¬x ∧ ¬y ∧ ¬z
F3(w, x, y, z) = (¬w ∧ y ∧ z) ∨ (w ∧ x ∧ ¬z)
```

由于与门平面可以产生所有可能的最小项，而或门平面可以提供这些最小项的任意和，因此 PLA 可用于实现任意可能的逻辑函数。如果我们想改变该函数，只需编程另一个 PLA 并替换旧的即可。

### 只读存储器

虽然 PLD 没有记忆功能（意味着当前状态不受输入先前状态的影响），但它们可用于制造*非易失性*存储器——即断电后内容保持完好的存储器。*只读存储器* (*ROM*) 用于存储可代表数据或程序指令的位模式。程序只能读取存储在 ROM 中的数据或程序，但不能通过写入新数据或程序指令来改变 ROM 的内容。ROM 通常用于具有固定功能集的设备中，如手表、汽车发动机控制单元和家用电器。事实上，我们的生活被由存储在 ROM 中的程序控制的设备所包围。

ROM 可以作为一种可编程逻辑器件来实现，其中只有或门平面可编程。与门平面保持固定连线以提供所有最小项。我们可以将 ROM 的输入视为地址。然后对或门平面进行编程，以提供每个地址处的位模式。例如，[图 6-17](#c06.xhtml#figure6-17) 中所示的 ROM 有两个输入 `a[1]` 和 `a[0]`，它们提供一个两位地址。

![图 6-17：四字节 ROM](`image_fi/500099c06/f06017.png`)

图 6-17：四字节 ROM

[图 6-17](#c06.xhtml#figure6-17) 中的“×”连接代表永久连接，表明与门平面是固定的。该 ROM 中的每个与门在每个地址处产生一个最小项。或门平面最多可产生 `2^n` 个八位字节，其中 `n` 是输入与门平面的地址位宽（以位为单位）。连接到或门的连线（圆点）代表存储在相应地址处的位模式。[表 6-7](#c06.xhtml#table6-7) 显示了一个 ROM，其或门平面已被编程以存储四个字符 A、B、C 和 D（采用 ASCII 码）。

**表 6-7：存储四个 ASCII 字符的 ROM**

| **最小项** | **地址** | **内容** | **ASCII 字符** |
| --- | --- | --- | --- |
| `¬a[1]¬a[0]` | `00` | `01000001` | A |
| `¬a[1]a[0]` | `01` | `01000010` | B |
| `a[1]¬a[0]` | `10` | `01000011` | C |
| `a[1]a[0]` | `11` | `01000100` | D |

虽然本例中仅存储了数据，但计算机指令也是位模式，因此我们同样可以轻松地在 ROM 中存储整个程序。与可编程逻辑阵列一样，如果需要更改程序，只需编程另一个 ROM 并替换旧的即可。

ROM 有几种类型。虽然 ROM 的位模式在制造过程中就已设定，但*可编程只读存储器* (*PROM*) 器件是由使用者编程的。还有*可擦除可编程只读存储器* (*EPROM*) 器件，可用紫外线擦除后重新编程。
