
# 简单 `if` 语句的汇编语言

`if` 语句通过简单的条件跳转 1 来实现。如果条件为真（在本例中为大于），程序流程将跳过由 `if` 语句控制的代码块 2。

我们经常需要在两个不同的代码块之间进行选择，接下来我们将讨论这一点。

## if-then-else 条件语句

C 语言中 `if-then-else` *条件语句* 的一般形式如下（C 语言不使用 `then` 关键字）：

```
if (expression)
{
  then-block
}
else
{
  else-block
}
next_statement
```

`expression` 在布尔上下文中求值。如果 `expression` 求值为真（在 C 语言中为非零），则执行 `then-block`，控制流跳转到 `next_statement`。如果求值为假（在 C 语言中为 `0`），控制流跳转到 `else-block`，然后继续执行 `next_statement`。[图 13-2](#c13.xhtml#figure13-2) 展示了 `if-then-else` 条件语句的控制流程。

[清单 13-7](#c13.xhtml#listing13-7) 中抛硬币程序的一个问题是用户不知道硬币总共被抛了多少次。我们可以通过使用 `if-then-else` 条件语句来打印一条消息，指明硬币何时朝上为反面，从而改进该程序，如 [清单 13-9](#c13.xhtml#listing13-9) 所示。

### 清单 13-9：抛硬币，正面或反面

```
/* coinFlips2.c
 * Flips a coin, heads or tails.
 */

#include <stdio.h>
#include <stdlib.h>

int main()
{
  register int randomNumber;
  register int i;

  for (i = 0; i < 10; i++)
  {
    randomNumber = random();
    if (randomNumber < RAND_MAX/2)
    {
      puts("heads");
    }
    else
    {
      puts("tails");
    }
  }

  return 0;
}
```

[清单 13-10](#c13.xhtml#listing13-10) 展示了编译器生成的汇编语言。

### 清单 13-10：实现 `if-else` 结构的汇编语言

```
        .file   "coinFlips2.c"
        .intel_syntax noprefix
        .text
        .section        .rodata
.LC0:
        .string "heads"
.LC1:
        .string "tails"
        .text
        .globl  main
        .type   main, @function
main:
        push    rbp
        mov     rbp, rsp
        push    r12
        push    rbx
        mov     ebx, 0
        jmp     .L2
.L5:
        call    random@PLT        ## get random number
        mov     r12d, eax         ## save random number
        cmp     r12d, 1073741822  ## less than half max?
        jg      .L3               ## no, else block
        lea     rdi, .LC0[rip]    ## yes, then block
        lea     rdi, .LC0[rip]
        call    puts@PLT
      1 jmp     .L4
 .L3:
        lea     rdi, .LC1[rip]    ## else block
        call    puts@PLT
 2 .L4:
        add     ebx, 1
.L2:
        cmp     ebx, 9
        jle     .L5
        mov     eax, 0
        pop     rbx
        pop     r12
        pop     rbp
        ret
        .size   main, .-main
        .ident  "GCC: (Ubuntu 9.3.0-17ubuntu1~20.04) 9.3.0"
        .section        .note.GNU-stack,"",@progbits
```

编写汇编语言时，需要在 `then-block` 末尾 1 处放置一个无条件跳转，以跳过 `else-block` 2。

我的抛硬币程序汇编语言设计略有不同，如 [清单 13-11](#c13.xhtml#listing13-11) 所示。

### 清单 13-11：抛硬币程序的汇编语言设计

```
# coinFlips2.s
# flips a coin, heads/tails
        .intel_syntax noprefix

# Useful constants
        .equ    MIDDLE, 1073741823  # half of RAND_MAX
        .equ    STACK_ALIGN, 8

# Constant data
        .section .rodata
headsMsg:
        .string "heads"
tailsMsg:
        .string "tails"

# The code
        .text
        .globl  main
        .type   main, @function
main:
        push    rbp                 # save frame pointer
        mov     rbp, rsp            # set new frame pointer
      1 push    r12                 # save, use for i
      2 sub     rsp, STACK_ALIGN
        
        mov     r12, 0              # i = 0;
for:
        cmp     r12, 10             # any more?
        jae     done                # no, all done
        
        call    random@plt          # get a random number
        cmp     eax, MIDDLE         # which half?
        jg      tails
        lea     rdi, headsMsg[rip]  # it was heads
        call    puts@plt
        jmp     next                # jump over else block
tails:
        lea     rdi, tailsMsg[rip]  # it was tails
        call    puts@plt
next:   inc     r12                 # i++;
        jmp     for
done:
      3 add     rsp, STACK_ALIGN    # realign stack ptr
      4 pop     r12                 # restore for caller
        mov     rsp, rbp            # restore stack pointer
        pop     rbp                 # and caller frame pointer
        ret
```

我的设计与编译器生成的代码之间的主要区别在于，我仅使用 `r12` 寄存器存放变量 `i`，而编译器同时使用了 `rbx` 和 `r12`。在决定函数中使用哪些寄存器存放变量时，检查第 11 章中的 [表 11-1](#c11.xhtml#table11-1) 的规则非常重要。该表规定函数必须为调用函数保留 `r12` 中的值。一个好的做法是在建立栈帧后 1 将其压入栈中，然后在拆除栈帧前 4 将其弹出。你大概能明白此处约定规则的重要性。不仅我们的函数返回调用函数时必须保持 `r12` 中的值不变，而且我们也可以假设我们的函数所调用的函数也会保留我们在 `r12` 中的值。因此，可以安全地假设该值在函数调用过程中保持不变。

在将寄存器保存到栈上时，容易违反的一条栈处理规则是：在函数调用之间保持栈指针位于 16 字节地址边界上。寄存器宽 8 字节，因此我在将 `r12` 压入栈中保存后，通过从栈指针减去 8 来遵守此规则 2。重要的是要记住，在将 `r12` 的值从栈中弹出 3 之前，要加回相同的值，从而为调用函数恢复寄存器的值。

我不会在此深入细节，但如果你需要从多个代码块中选择一个执行，可以使用 `if-else` 语句构成 *阶梯结构*。一般形式如下：

```
if (expression1)
{
  block1
}
else if (expression2)
{
  block2
}
⋮
else (expression_n)
{
  block_n
}
next_statement
```

`if-then-else` 选择基于控制表达式的布尔求值，但正如你在下一节将看到的，有些算法的选择基于离散值，该值用于从多种情况中选择一种。
