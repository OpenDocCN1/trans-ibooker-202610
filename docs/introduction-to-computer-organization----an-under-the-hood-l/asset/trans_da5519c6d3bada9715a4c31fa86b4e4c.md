
# 多路选择器和三态缓冲器

在上一节中，你学习了如何使用一个 *n* 位数来选择 2^(*n*) 条输出线中的哪一条应被设置为 `1`。相反的情况也会发生，即我们需要选择哪个输入应该被传递下去。例如，在执行加法等算术运算时，数字可能来自 CPU 内部的不同位置。（你将在接下来的几章中了解更多相关内容。）运算本身将由一个算术单元执行，CPU 需要从所有可能的位置中选择运算的输入。

能够进行这种选择的设备称为 *多路选择器* (*MUX*)。它可以通过使用 *n* 条选择线在 2^(*n*) 条输入线之间进行切换。[图 6-11](#c06.xhtml#figure6-11) 展示了一个四路多路选择器的电路。

输出由下式给出：

```
Output = (¬s[0] ∧ ¬s[1] ∧ w) ∨ (¬s[0] ∧ s[1] ∧ x) ∨ (s[0] ∧ ¬s[1] ∧ y) ∨ (s[0] ∧ s[1] ∧ z)
```

![图 6-11：四路多路选择器](image_fi/500099c06/f06011.png)

**图 6-11：四路多路选择器**

当使用与门和或门时，实现多路选择器所需的晶体管数量会随着输入数量的增加而变大。多路选择器的每个输入都需要一个三输入与门，而或门的输入数量等于多路选择器的输入数量。与门被用来将多路选择器的仅一个输入传送给或门。接下来我们将看到一种器件，它可以通过简单地将输入信号与输出断开，来实现与门和或门组合的相同功能。

## 三态缓冲器

称为 *三态缓冲器* 的逻辑器件有三种可能的输出：`0`、`1` 和"无连接"。"无连接"输出实际上是一种高阻抗连接，也称为 *高阻* 或 *开路*。"无连接"输出允许我们将许多三态缓冲器的输出在物理上连接在一起，但只选择一个将其输入传递给公共输出线。

三态缓冲器既有数据输入也有使能端，其行为如 [表 6-5](#c06.xhtml#table6-5) 所示。

**表 6-5：三态缓冲器真值表**

| **使能** | **输入** | **输出** |
| --- | --- | --- |
| `0` | `0` | 高阻 |
| `0` | `1` | 高阻 |
| `1` | `0` | `0` |
| `1` | `1` | `1` |

[图 6-12](#c06.xhtml#figure6-12) 展示了三态缓冲器的电路符号。

![图 6-12：三态缓冲器](image_fi/500099c06/f06012.png)

**图 6-12：三态缓冲器**

当 `Enable = 1` 时，输出（等于输入）连接到三态缓冲器后面的任何电路元件。但当 `Enable = 0` 时，输出基本上是断开的。这不同于 `0`；断开意味着它对所连接的电路元件没有影响。

为了说明三态缓冲器如何使用，请回顾第 124 页 "多路选择器" 一节中的四路多路选择器。它需要四个与门、两个非门和一个四输入或门。如果我们尝试扩大规模，对于大的 *n*，*n* 输入或门将带来一些技术上的电子问题。通过使用 *n* 个三态缓冲器，可以避免使用 *n* 输入或门，如 [图 6-13](#c06.xhtml#figure6-13) 所示的四路多路选择器。

![图 6-13：由解码器和三态缓冲器构建的四路多路选择器](image_fi/500099c06/f06013.png)

**图 6-13：由解码器和三态缓冲器构建的四路多路选择器**

[图 6-13](#c06.xhtml#figure6-13) 中的多路选择器使用了一个 2 × 4 解码器和四个三态缓冲器。2 × 4 解码器选择哪个三态缓冲器将输入 `w`、`x`、`y` 或 `z` 中的一个连接到输出。

[图 6-14](#c06.xhtml#figure6-14) 展示了用于多路选择器的电路符号，[表 6-6](#c06.xhtml#table6-6) 展示了它的行为。

![图 6-14：四路多路选择器的电路符号](image_fi/500099c06/f06014.png)

**图 6-14：四路多路选择器的电路符号**

**表 6-6：四路多路选择器真值表**

| **s[1]** | **s[0]** | **输出** |
| --- | --- | --- |
| `0` | `0` | `w` |
| `0` | `1` | `x` |
| `1` | `0` | `y` |
| `1` | `1` | `z` |

作为一个示例，说明我们可能在哪里使用 [图 6-14](#c06.xhtml#figure6-14) 中的四路多路选择器，请考虑一台有四个寄存器和一个加法器的计算机。我们将寄存器命名为 `w`、`x`、`y` 和 `z`。如果我们将每个寄存器中对应位位置的位连接到一个多路选择器，那么我们就可以使用两位选择器 `s[0]s[1]` 来选择哪个寄存器将为加法器提供输入。例如，位置 5 的每一位，`w[5]`、`x[5]`、`y[5]` 和 `z[5]`，将被连接到多路选择器 5 的输入之一。如果 `s[0]s[1] = 10`，加法器的输入将是 `y[5]`。

# 可编程逻辑器件

到目前为止，我们一直在讨论使用单个逻辑门的硬件设计。如果设计发生变化，逻辑门配置也会随之改变。这几乎总意味着承载并连接逻辑门的电路板将需要重新设计。设计变更通常还意味着要订购不同种类的逻辑门，这可能既昂贵又耗时。通过使用 *可编程逻辑器件* (*PLD*) 来实现所需的逻辑功能，可以减少这些问题。

PLD 包含许多与门和或门，它们可以被编程以实现布尔函数。输入及其补码连接到与门。与门组合在一起被称为 *与平面* 或 *与阵列*。与门的输出连接到或门，或门组合在一起被称为 *或平面* 或 *或阵列*。根据类型，可以对一个或两个平面进行编程以实现组合逻辑。使用 PLD 时，设计变更仅意味着改变器件的编程方式，而不需要购买不同的器件，这意味着电路板不需要重新设计。

PLD 有几种类型。大多数可以由用户编程。有些在制造时预编程，有些甚至可以由用户擦除并重新编程。编程技术范围从指定制造掩膜（用于预编程器件）到廉价的电子编程系统。

PLD 有三大类别。

## 可编程逻辑阵列

在 *可编程逻辑阵列* (*PLA*) 中，与平面和或平面都是可编程的。PLA 用于实现逻辑功能。[图 6-15](#c06.xhtml#figure6-15) 给出了一个具有两个输入变量和两个可能的输出函数的 PLA 的大致概念。

![图 6-15：可编程逻辑阵列的简化电路](image_fi/500099c06/f06015.png)

**图 6-15：可编程逻辑阵列的简化电路**

每个输入变量，无论是其非补形式还是补形式，都通过熔丝作为输入连接到与门。*熔丝* 是一根用于保护电路的细导体。如果流过它的电流足够大，导体就会熔化，从而断开电路并停止电流流动。PLD 可以通过断开（或 *熔断*）适当的熔丝来编程，从而移除通往逻辑门的输入。有些器件使用 *反熔丝* 代替熔丝。这些通常是断开的，编程它们的过程是建立连接而不是移除连接。可重新编程的器件具有可以熔断然后重新制造的熔丝。

在 [图 6-15](#c06.xhtml#figure6-15) 中，电路图中的 *S* 形线代表熔丝。熔丝可以被熔断或保留，以便将每个与门编程为输出输入 `x`、`¬x`、`y` 和 `¬y` 的乘积。由于每个输入及其补码都被输入到每个与门，因此任何与门都可以被编程为输出一个最小项。
