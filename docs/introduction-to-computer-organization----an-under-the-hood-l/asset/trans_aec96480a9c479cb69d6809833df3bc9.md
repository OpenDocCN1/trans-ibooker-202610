
## 由半加器构建全加器

```
Carry_{i+1} = (x_i ∧ y_i) ∨ (Carry_i ∧ ¬x_i ∧ y_i) ∨ (Carry_i ∧ x_i ∧ ¬y_i)
            = (x_i ∧ y_i) ∨ Carry_i ∧ ((¬x_i ∧ y_i) ∨ (x_i ∧ ¬y_i))
            = (x_i ∧ y_i) ∨ (Carry_i ∧ (x_i ⊻ y_i))
```

请注意，该方程中的两项，`x_i ∧ y_i` 和 `x_i ⊻ y_i`，已由半加器生成（参见[图 6-1](#c06.xhtml#figure6-1)）。因此，利用第二个半加器和一个或门，我们可以实现一个全加器，如[图 6-5](#c06.xhtml#figure6-5)所示。

![图 6-5：使用两个半加器的全加器](image_fi/500099c06/f06005.png)

现在你可以明白*半加器*和*全加器*这两个术语的由来了。

简单的电路并不总是更好。事实上，仅从逻辑电路图来看，我们无法判断[图 6-3](#c06.xhtml#figure6-3)和[图 6-5](#c06.xhtml#figure6-5)这两个全加器电路哪个更好。良好的工程设计取决于许多因素，例如每个逻辑门的实现方式、逻辑门的成本及其可获得性等。此处给出这两种设计是为了表明不同的方法可以得出不同但功能等效的设计。

### 行波进位加法和减法电路

现在我们知道如何将给定位位置上的两个位相加，再加上来自次低位位置的进位。但程序处理的大多数值都有许多位，因此我们需要一种方法将两个 *n* 位数中每个位位置上对应的位相加。这可以通过一个 *n* 位加法器来完成，它可以用 *n* 个全加器实现。[图 6-6](#c06.xhtml#figure6-6)展示了一个四位加法器。

![图 6-6：四位加法器](image_fi/500099c06/f06006.png)

加法从最右侧的全加器开始，它接收两个最低位 `x[0]` 和 `y[0]`。由于这是最低位，没有进位，所以 `c[0] = 0`。位和为 `s[0]`，该次加法产生的进位 `c[1]` 连接到左侧下一个全加器的进位输入端，在那里与 `x[1]` 和 `y[1]` 相加。

因此，第 *i* 个全加器将两个操作数的第 *i* 位相加，再加上来自第 (*i – 1*) 个全加器的进位（即 `0` 或 `1`）。每个全加器处理待加数值总宽度中的一位（通常称为*切片*）。每个位位置的进位被加到下一个高位位置的位上。加法过程从最低位流向最高位，呈现一种行波效应，因此这种加法方法称为*行波进位加法*。

请注意，在[图 6-6](#c06.xhtml#figure6-6)中，我们有 `CF` 和 `OF`，即*进位标志*和*溢出标志*。你在第三章学习了进位和溢出。每当 CPU 执行算术运算（本例中为加法）时，它会在 `rflags` 寄存器中记录是否发生了进位和溢出。你将在第九章了解该寄存器。

现在让我们看看如何利用类似的思路实现减法。回顾一下，在补码表示中，一个数取反是通过求其补码、翻转所有位并加 1 来完成的。因此，我们可以通过以下方式计算 *x* 减 *y*：

```
x – y = x + (two's complement of y)
      = x + ((y's bits flipped) + 1)
```

如果我们将每个 `y[i]` 取反，并将初始进位设为 `1` 而不是 `0`，就可以用[图 6-5](#c06.xhtml#figure6-5)中的加法器执行减法。每个 `y[i]` 可以通过与 `1` 进行异或运算来取反。这得出了[图 6-7](#c06.xhtml#figure6-7)中的四位电路，当 `func = 0` 时它将两个四位数相加，当 `func = 1` 时将它们相减。

![图 6-7：四位加法器/减法器](image_fi/500099c06/f06007.png)
