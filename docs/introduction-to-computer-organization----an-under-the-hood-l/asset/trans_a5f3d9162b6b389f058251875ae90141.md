
## 步骤 6：绘制电路

以下方程定义了两个 JK 触发器的 J 和 K 输入（其中 `s₁` 和 `s₀` 为状态位）：

```
J₀(Actual, s₁, s₀) = Actual
K₀(Actual, s₁, s₀) = ¬Actual
J₁(Actual, s₁, s₀) = Actual ∧ s₀
K₁(Actual, s₁, s₀) = ¬Actual ∧ ¬s₀
```

因此，该电路需要两个 JK 触发器、两个与门和一个非门。

在该电路中，若上一次未发生分支，则输入 `Actual = 0`；若发生了分支，则 `Actual = 1`。我们需要在 JK 触发器的输入端添加两个与门和一个非门，如[图 7-22](#c07.xhtml#figure7-22)所示。

此例展示了最简单的分支预测方法。也存在更复杂的方法。关于分支预测的有效性，研究仍在进行中。虽然它能加速某些算法，但分支预测所需的额外硬件会消耗更多电能，这在电池供电设备中令人担忧。

## 你学到的内容

1.  **SR 锁存器** — SR 锁存器的状态取决于其输入，即置位或复位。它可以包含一个使能输入。
2.  **D 触发器** — D 触发器存储一位数据。通过将两个锁存器以主从配置连接，输出与输入隔离，使触发器能与时钟信号同步。D 触发器的输出每个时钟周期只能改变一次。
3.  **T 触发器** — 当 T 触发器被使能时，其状态会在每个时钟周期在 0 和 1 之间翻转。
4.  **JK 触发器** — JK 触发器被称为*通用触发器*，因为它提供四种基本功能——保持当前状态、置位、复位、翻转。

# 第 8 章：存储器

![](image_fi/book_art/chapterart.png)

在前三章中，我们了解了一些用于实现逻辑功能的硬件。现在我们将探讨如何利用这些功能来实现构成计算机的子系统，首先从存储器开始。

每位计算机用户都想要大容量存储器和快速计算。然而，更快的存储器成本更高，因此存在一些权衡。本章将首先讨论如何利用不同类型的存储器在速度和成本之间提供合理的折中方案。然后我们将讨论几种在硬件中实现存储器的不同方法。

## 存储器层级结构

一般来说，存储器离 CPU 越近，速度越快、价格越高。最慢的存储器是云端。它也是最便宜的。我的电子邮件账户在云端提供 15 GB 存储空间，且无需花费金钱（如果忽略看到几条广告的“成本”）。但其速度受限于我的网络连接。在另一极端，CPU 内部的存储器以与 CPU 相同的速度运行，但价格相对昂贵。在 `x86-64` 架构中，CPU 中可供程序员使用的存储器只有约 1 KB。

[图 8-1](#c08.xhtml#figure8-1) 展示了这一大致层级。随着离 CPU 越近（图的顶部），存储器速度越快、成本越高，因此容量越小。

![Figure 8-1: Computer memory hierarchy](image_fi/500099c08/f08001.png)

**图 8-1：** 计算机存储器层级结构

[图 8-1](#c08.xhtml#figure8-1) 中的顶层三层通常集成在现代计算机的 CPU 芯片中。在到达主存之前，可能还有一到两级缓存。主存和磁盘通常与 CPU 在同一机箱内，其中可能包含多个磁盘。

离 CPU 更远的下一层代表离线数据存储设备。DVD 和内存棒只是两个例子。你可能还有一个外置 USB 磁盘、磁带驱动器等。这些设备通常需要你采取一些物理操作，如将 DVD 放入驱动器或将内存棒插入 USB 端口，计算机才能访问它们。

该层级的最后一层是云存储。虽然我们大多数人设置计算机自动登录，但它并不总是可用。

在本章中，我们将从云层之上的两层——离线存储和磁盘——开始，逐步深入到 CPU 寄存器。然后我们将描述用于构建寄存器的硬件，并逐步回溯到主存。我们将把最外层三层的实现讨论留给其他书籍。

### 大容量存储

*大容量存储* 用于以机器可读格式保存程序和大量数据。这包括硬盘、固态硬盘、内存棒、光盘等。其内容是*非易失性*的，即断电后内容保留。与 CPU 相比，它们也很慢。访问其内容需要显式编程。
