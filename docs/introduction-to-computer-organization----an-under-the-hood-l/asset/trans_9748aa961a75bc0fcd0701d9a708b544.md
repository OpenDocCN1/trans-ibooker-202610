
## 使用 JK 触发器的两位计数器

我们需要两个触发器，每个位一个。状态转换表中新增的列显示了每个 JK 触发器所需的输入——`Enable`、`n[1]`、`n[0]`——以引起正确的状态转换。根据本章前面对 JK 触发器的描述，我们知道 JK = `00` 保持当前状态，JK = `01` 将其复位（变为 `0`），JK = `10` 将其置位（变为 `1`），而 JK = `11` 则翻转状态。当输入可以是 `0` 或 `1` 时，即“不关心”条件下，我们使用 `X`。[表 7-12](#c07.xhtml#table7-12) 显示了所需的 JK 输入。

### 步骤 5：化简所需输入

我们将使用卡诺图来寻找更简单的解决方案，用 `E` 表示 Enable（使能），如[图 7-17](#c07.xhtml#figure7-17)所示。

![J0/K0 的卡诺图](image_fi/500099c07/f07017a.png)
![J1/K1 的卡诺图](image_fi/500099c07/f07017b.png)

**图 7-17：使用 JK 触发器实现的两位计数器的卡诺图**

我们可以轻松地从卡诺图写出方程来解决这个问题，如下所示：

![方程](image_fi/500099c07/c07m0002.png)

```
J₀(E, n₁, n₀) = E
K₀(E, n₁, n₀) = E
J₁(E, n₁, n₀) = E ∧ n₀
K₁(E, n₁, n₀) = E ∧ n₀
```

J = K = `1` 会导致 JK 触发器在状态间翻转。这些方程表明，低位 JK 触发器在每个时钟周期翻转。当它被使能时，其输出 `n[0]` 在每个时钟周期在 `0` 和 `1` 之间变化。该输出与高位 JK 触发器的使能输入进行与运算，导致高位触发器每两个时钟周期在 `0` 和 `1` 之间翻转一次。（你将在下一步的[图 7-19](#c07.xhtml#figure7-19)中看到这一时序。）

## 设计分支预测器

让我们在这里做另一个指导性的“动手试一试”。这个例子比前一个稍微复杂一些。

除了非常廉价的微控制器外，大多数现代 CPU 都分阶段执行指令。每个阶段由专门用于执行该阶段操作的硬件组成。指令以流水线的方式通过每个阶段。例如，如果你要创建一条制造木椅的装配线，可以分三个阶段：锯木头制作椅子零件、组装零件、给椅子刷漆。每个阶段所需的硬件分别是锯子、锤子和螺丝刀、以及刷子。

CPU 中专用硬件的这种排列称为*流水线*（*pipeline*）。第一阶段的硬件设计用于从内存取指令，正如你将在第 9 章看到的那样。指令从内存取出后，进入流水线的下一阶段进行译码。同时，流水线的第一阶段从内存取取下一条指令。结果是 CPU 同时处理多条指令。这提供了一定的并行性，从而提高了执行速度。
