
# 编译器生成的 `factorial` 函数汇编语言

## 清单 15-4：`factorial` 函数的编译器生成汇编代码

`factorial` 函数使用的算法是一个简单的 `if`-`then` 结构，这是我们在第 13 章学习的内容。递归函数的重要部分在于：我们需要将传递给它的参数保存在寄存器中，以便寄存器可以被重用来在递归调用中传递参数。

例如，`factorial` 函数接受一个参数 `n`，它通过 `rdi` 寄存器传递。（只使用寄存器的 `edi` 部分，因为在我们的环境中 `int` 是 32 位的。）根据第 11 章的 [表 11-2](#c11.xhtml#table11-2)，我们不需要在函数中保存 `rdi` 的内容，但我们需要使用 `rdi` 进行带有新值 `(n - 1)` 的递归调用。当递归调用返回时，我们需要 `n` 的原始值。编译器在栈帧中分配了空间用于保存 `n`。

我们还没有讨论 `imul` 指令。顾名思义，这里的指令将 `eax` 中的整数与 `edx` 中的整数相乘，将乘积留在 `eax` 中。乘法指令的细节有些复杂，我们将在第 16 章讨论它们。

我们可以通过直接用汇编语言编写 `factorial` 函数来简化它，如 [清单 15-5](#c15.xhtml#listing15-5) 所示。

## 清单 15-5：`factorial` 函数的汇编语言版本

```assembly
# factorial.s
# Computes n! recursively.        
# Calling sequence:
#       edi <- n
#       call    readLn
# returns n!
        .intel_syntax noprefix
# Stack frame
        .equ    n,-4
        .equ    localSize,-16

        .text
        .globl  factorial
        .type   factorial, @function
factorial:
        push    rbp                 # save frame pointer
        mov     rbp, rsp            # set new frame pointer
        add     rsp, localSize      # for local var.

      1 mov     n[rbp], edi         # save n
      2 mov     eax, 1              # assume at base case
        cmp     dword ptr n[rbp], 0 # at base case?
      3 je      done                # yes, done
        mov     edi, n[rbp]         # no,
      4 sub     edi, 1              # compute (n - 1)!
        call    factorial
      5 mul     dword ptr n[rbp]    # n! = n * (n - 1)!
done:
        mov     rsp, rbp            # restore stack pointer
        pop     rbp                 # and caller frame pointer
        ret
```

在我们的 `factorial` 汇编语言版本中的一个简化是使用 `eax` 作为存储当前结果的局部变量。我们首先假设处于基本情况。如果这是真的，结果就在 `eax` 中，这正是返回值应该在的位置。如果不是，则递归调用 `factorial`，传递 `(n – 1)` 作为参数。由于在从递归调用返回后，输入参数对于 `n * (n – 1)!` 计算仍然需要，我们需要将输入参数保存在栈上。

编译器使用的是有符号乘法指令 `imul`，但由于该函数中的所有数字都是无符号的，我选择使用无符号乘法指令 `mul`。`mul` 指令假设被乘数已经在 `eax` 中，从 `factorial` 的递归调用返回时确实如此。乘法操作后，`mul` 指令用乘积替换 `eax` 中的被乘数，这正是返回所需的位置。同样，`mul` 和 `imul` 指令的使用细节将在第 16 章解释。

递归算法可以简单优雅，但它们大量使用栈。我将 [清单 15-5](#c15.xhtml#listing15-5) 中的 `factorial` 汇编语言版本（以及 [清单 15-2](#c15.xhtml#listing15-2) 中的 C 头文件）与 [清单 15-1](#c15.xhtml#listing15-1) 中的 `main` 函数一起使用，并在 `gdb` 下运行程序，以便我们可以查看栈的使用情况。

我们看到第一次对 `factorial` 的递归调用传递 `2` 作为参数，这在该程序中是 `(n – 1)`。`factorial` 的栈帧是 32 字节，这里以 8 字节组显示。当 `factorial` 从 `main` 被调用时，压入栈的第一个值是返回 `main` 的返回地址。

请记住，我们环境中的内存存储是小端序，所以在读取存储在栈帧中 `n` 的值时需要小心。[清单 15-5](#c15.xhtml#listing15-5) 中的代码显示变量 `n` 存储在 `rbp` 向下 4 字节处，即在我这里的程序运行中内存位置 `0x7fffffffde3c`。由于我们的环境是小端序且我们显示 8 字节值，包含内存位置 `0x7fffffffde3c` 的 8 字节将以 `0x7fffffffde38` 处的字节在最右侧位置、`0x7fffffffde3f` 处的字节在最左侧位置显示。因此变量 `n` 是该 8 字节显示中从右数第五个字节，即 `0x03`。
