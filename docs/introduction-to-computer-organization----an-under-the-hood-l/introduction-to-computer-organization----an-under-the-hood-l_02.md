## 本书适合谁阅读

你是否曾好奇，当你用高级语言编写程序时，“引擎盖下”究竟发生了什么？你知道计算机可以被编程来做决策，但它们是如何做到的？你可能知道数据是以位存储的，但存储十进制数时这意味着什么？我写这本书的目标是回答这些以及其他许多关于计算机如何工作的问题。我们将同时查看硬件组件和用于控制硬件的机器级指令。

我假设你了解高级语言编程的基础知识，但不需要你是专家程序员。在讨论完硬件组件后，我们将查看并编写大量*汇编语言*程序，这是一种直接转换为机器指令的语言。

与大多数汇编语言书籍不同，我们不会强调用汇编语言编写应用程序。高级语言——如 C++、Java 和 Python——创建应用程序的效率要高得多。用汇编语言编写是一个繁琐、易出错、耗时的过程，因此应尽可能避免。我们的目标是学习编程概念，而不是创建应用程序。

## 关于本书

我在编写本书时遵循的准则如下：

1. 如果学习建立在你已知的概念之上，会更容易。
2. 真实世界的硬件和软件为学习理论概念提供了更有趣的平台。
3. 用于学习的工具应当廉价且易于获取。

### 本书中的编程

本书基于 *x86-64* 指令集架构，这是 *x86*（32 位）指令集架构的 64 位版本。它也被称为 *AMD64*、*x86_64*、*x64* 和 *Intel 64*。书中所有编程均在运行 Ubuntu Linux 操作系统的 GNU 编程环境中完成。这些程序只需极少修改（甚至无需修改）即可在大多数常见的 Linux 发行版上运行。

我们使用 C 作为高级语言，后面的章节会用到一些 C++。如果你不懂 C/C++ 也没关系。我们所有的 C/C++ 编程都非常简单，我会在过程中解释你需要知道的内容。

学习汇编语言时会出现一个重要问题，即在应用程序中使用键盘和终端屏幕。从键盘编程输入和向屏幕输出非常复杂，远超初学者的能力范围。GNU 编程环境包含 *C 标准库*。遵循本书的“真实世界”标准，我们将使用该库中的函数，这些函数可轻松从汇编语言调用，用于在应用程序中使用键盘和屏幕。

x86-64 指令集架构包含约 1,500 条指令。确切数量取决于你认为什么算作不同的指令，但数量太多，无法全部记忆。一些汇编语言书籍通过发明一套“理想化”的指令集架构来说明概念来处理这个问题。同样，秉承本书的“真实世界”性质，我们将使用标准的 x86-64 指令集，但仅使用一小部分足以说明基本概念的指令。

### 为什么要读这本书？

考虑到有许多优秀的高级语言允许你编写程序而无需关心机器指令如何控制硬件，你可能会想知道为什么要学习本书中的内容。所有高级语言最终都会被翻译成控制硬件的机器指令。了解硬件的作用以及指令如何控制它，有助于你理解计算机的能力和局限性。我相信这种理解能让你成为一名更好的程序员，即使你在使用高级语言工作。

如果你的主要兴趣在于硬件，我认为了解程序将如何使用硬件很重要。

你可能会喜欢汇编语言编程并想继续钻研。例如，如果你的兴趣带你进入*系统编程*领域——编写操作系统的部分模块、编写编译器，甚至设计另一种高级语言——这些工作通常都需要汇编语言级别的理解。

在*嵌入式系统*编程领域也存在许多极具挑战性的机会，嵌入式系统是指计算机具有专用任务的系统。例子是我们日常生活中不可或缺的一部分：手机；家用电器；汽车；供暖、通风和空调（HVAC）系统；医疗设备；等等。嵌入式系统是启用物联网技术的关键组成部分。编程它们通常需要了解计算机如何在汇编语言级别与各种硬件设备交互。

如果你已经了解另一种处理器的汇编语言，本书可以作为阅读手册的入门指南。

# 书籍前言

## 结构安排

本书大致分为三部分：数学与逻辑、硬件和软件。数学部分旨在为你提供讨论概念所需的语言。硬件部分介绍构建计算机所用的组件。

这两部分为讨论软件如何控制硬件提供了背景。我们将探讨 C 编程语言中的每一种基本编程结构，并在本书末尾涉及一些 C++。然后我们将研究编译器如何将 C/C++ 代码翻译成汇编语言——一种直接访问指令集架构的语言。我还将向你展示程序员如何直接用汇编语言编程实现相同的结构。

## 目录

### 第 1 章：搭建舞台
描述计算机的三大整体子系统及其连接方式。还讨论了本书中使用的编程工具的设置。

### 第 2 章：数据存储格式
展示如何使用二进制和十六进制数制存储无符号整数，以及如何使用 ASCII 码存储字符。我们将编写第一个 C 程序，并使用 `gdb` 调试器来探索这些概念。

### 第 3 章：计算机算术
描述无符号和有符号整数的加法与减法，并解释使用固定位数表示整数的局限性。

### 第 4 章：布尔代数
描述布尔代数运算符和函数，以及使用代数工具和卡诺图进行函数最小化。

### 第 5 章：逻辑门
从电子学简介开始。随后讨论逻辑门及其如何使用 CMOS 晶体管构建。

### 第 6 章：组合逻辑电路
讨论没有存储功能的逻辑电路，包括加法器、解码器、多路选择器和可编程逻辑器件。

### 第 7 章：时序逻辑电路
讨论保持存储状态的有锁和无锁逻辑电路，以及使用状态转移表和状态图进行电路设计。

### 第 8 章：存储器
描述存储层级：云存储、大容量存储、主存、缓存和 CPU 寄存器。还讨论了寄存器、SRAM 和 DRAM 的存储硬件设计。

### 第 9 章：中央处理器
概述 CPU 子系统。本章还解释指令执行周期和主要的 x86-64 寄存器，并展示如何在 `gdb` 调试器中查看寄存器内容。

### 第 10 章：汇编语言编程
着眼于最小的 C 函数，包括编译器生成的汇编语言和直接用汇编语言编写的版本。本章涵盖汇编器指令和初步指令。我给出了一个使用 `gdb` 文本用户界面作为学习工具的示例。其中包括对 AT&T 语法的简要说明。

### 第 11 章：main 函数内部
描述通过寄存器传递参数、位置无关代码，以及使用调用栈传递返回地址和创建自动变量。

### 第 12 章：指令细节
着眼于指令在比特层面是如何编码的。还涵盖寻址模式和条件跳转，以及汇编器和链接器程序的算法。

### 第 13 章：控制流结构
涵盖使用 `while`、`do-while`、`for`、`if-else` 和 `switch` 结构控制程序流程的汇编语言实现。

### 第 14 章：子函数内部
描述函数如何访问外部变量：全局变量、按值传递、按指针传递和按引用传递。本章总结了栈帧的结构。

### 第 15 章：子函数的特殊用法
展示递归的工作原理。本章还讨论如何使用汇编语言访问高级语言中无法直接访问的 CPU 硬件特性，方法是使用单独的函数或内联汇编。

### 第 16 章：位逻辑运算、乘法和除法指令计算
描述位掩码、位移位，以及乘法和除法指令。

### 第 17 章：数据结构
解释数组和记录在程序中是如何在汇编语言层面实现和访问的。

### 第 18 章：面向对象编程
展示结构体在 C++ 中如何作为对象使用。

### 第 19 章：小数
描述定点数和浮点数、IEEE 754 标准，以及一些 SSE2 浮点指令。

### 第 20 章：输入/输出
将 I/O 与内存和总线时序进行比较。描述孤立 I/O 和内存映射 I/O。本章大致勾勒了轮询 I/O 编程，并讨论了中断驱动和直接内存访问 (DMA) I/O。

### 第 21 章：中断与异常
简要描述 x86-64 如何处理中断和异常。本章包含使用 `int 0x80` 和 `syscall` 进行系统调用而不使用 C 运行时环境的示例。

### 附录 A：使用 GNU `make` 构建程序
简要介绍如何使用 GNU `make` 程序。

## 高效使用本书

鉴于本书的编排方式，如果你遵循以下几条简单的指导原则，将能更高效地学习材料。

许多章节末尾都有练习，给你机会练习正文中呈现的材料。这些是练习，而非测试。事实上，我已在 <https://rgplantz.github.io.> 在线提供了大多数练习的答案和我的解答。

如果你是使用本书的教师，抱歉，你得自己出考题。许多练习都有相当明显的扩展，教师可利用这些扩展创建课堂作业。

### 推荐的迭代过程

为了高效利用这些练习，我推荐一个迭代过程：

1.  尝试自行解决问题。花些时间思考，但不要让自己卡太久。
2.  如果想不出答案，看一眼我的解答。在某些情况下，我会在给出完整解答前先提供提示。
3.  回到第 1 步，利用一些有经验的汇编语言程序员可能采用的解题思路知识。

### 实践方法

我强烈建议你做的一件事是**亲自敲入代码**。我相信这种身体力行的活动将帮助你更快地掌握材料。如果没有别的好处，它至少迫使你阅读代码中的每一个字符。我看不出从我的在线解答中复制粘贴代码有任何优势。坦白说，本书中的程序没有任何实际用途。代码是为你练习而提供的，所以请以这种精神使用它。

### 数学练习

这种实践方法也适用于前几章的数学内容，包括在多个数制之间转换数字。任何好的计算器都能轻松完成转换，但实际转换并非重点。重点是了解数据值如何用位模式表示。我相信用纸笔演算算术将帮助你领会这些模式。
