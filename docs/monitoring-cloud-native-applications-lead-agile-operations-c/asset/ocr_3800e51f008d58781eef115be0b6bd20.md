A check consists of a defining a query and then configuring the check (see Figures 5-52 and 5-53). The query definition includes selecting the dataset which needs to be queried. The dataset would include measurement, field, and tags (optional). Using an aggregating function is mandatory for a valid check definition. Tags when included will help to narrow down the points to be queried.
