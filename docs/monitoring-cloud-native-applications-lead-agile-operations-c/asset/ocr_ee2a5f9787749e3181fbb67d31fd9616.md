InfluxDB has constructs which are similar to SQL, and a comparison between the two will show that their data elements resemble this. Let’s look at a few of the important concepts in InfluxDB in detail:

| SQL Database | InfluxDB |
|---|---|
| Table | Measurement |
| Rows | Points |
| Indexed Columns | Tags |
| Unindexed Column | Fields |
| Stored Procedures | Continuous queries |
