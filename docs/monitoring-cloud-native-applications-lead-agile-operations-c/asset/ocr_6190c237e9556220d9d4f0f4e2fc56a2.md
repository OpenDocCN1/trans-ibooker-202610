# Figure 6-47. Sharing dashboard through a direct link

You can share this dashboard using the direct link or embed the link in a website. The template variables slider allows us to include the variables while sharing the dashboard with another user. You can also choose to modify the theme of the dashboard from dark to light.

You also have an option of taking a snapshot of the dashboard and then sharing it as an attachment. See Figures 6-48 and 6-49.
