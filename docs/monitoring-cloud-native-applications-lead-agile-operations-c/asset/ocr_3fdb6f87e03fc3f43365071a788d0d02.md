# Buckets

A bucket is associated with an organization and stores all the time-series data. Buckets have a retention policy to store data points only for a particular time period as dictated by the retention policy.

You can use the UI to *Create Bucket* from two different places: one from the **Load Data - Buckets** page as shown in Figure 5-32 and the second from the **Data Explorer - From** page.
