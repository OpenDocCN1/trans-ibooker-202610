The interval is the time after which each of the dashboards will be refreshed with another dashboard from the playlist. Once started, a playlist can be controlled using the navigation bar at the top of the screen. A playlist can be run in five different modes, which determine the position of the menu and the navigation bar on the dashboard. The various modes are normal mode, kiosk mode, kiosk mode with auto-fit panels, TV mode, and TV mode with auto-fit panels. See Figures 6-61 and 6-62.
