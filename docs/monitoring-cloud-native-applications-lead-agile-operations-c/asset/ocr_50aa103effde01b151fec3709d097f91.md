Since we don’t have access to the resources that we created in the deployment, we will create a NodePort service that will provide us with the access to Prometheus. See Figure 4-14:

```
1 apiVersion: v1
2 kind: Service
3 metadata:
4   name: prometheus
5   namespace: monitoring
6 spec:
7   selector:
8     app: prometheus
9   type: NodePort
10  ports:
11    - name: prometheus
12      protocol: TCP
13      port: 9090
14      nodePort: 30900
```

Figure 4-14. prometheus-nodeservice.yaml
