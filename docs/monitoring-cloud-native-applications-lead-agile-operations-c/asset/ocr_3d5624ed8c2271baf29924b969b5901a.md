NodePort exposes the service on each node’s IP at a static port (NodePort) with default value, which is usually between 30000 and 32767. We can now look at Prometheus on port 30900 of the single node and use the following command to open Prometheus in a web browser.

```
$ minikube service -namespace=monitoring prometheus
```
