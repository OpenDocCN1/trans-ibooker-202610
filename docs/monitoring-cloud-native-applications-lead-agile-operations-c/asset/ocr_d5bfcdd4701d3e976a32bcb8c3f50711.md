A row is used to logically segregate your dashboard into specific areas so that a set of panels can be grouped together. If you save a dashboard with a row collapsed, then it saves in that state and does not load those graphs until you expand the row. Use the repeating rows functionality to dynamically create or remove entire rows, which can be filled with panels, based on the template variables selected.
