## 跨境数据流动

跨境数据流动的概念与之前讨论的进出口管制主题密切相关。更具体地说，这一概念侧重于限制某些数据进入或来自特定地理位置或司法管辖区的相关要求。上一节讨论的ITAR就是限制数据流动的立法的绝佳例子。根据ITAR，数据必须留在美国境内；否则，就被视为出口（可能被允许，也可能不被允许）。此外，ITAR特别禁止将受监管的数据发送到伊朗、叙利亚、朝鲜和其他指定国家。ITAR要求对于具有全球足迹的公共云基础设施尤其值得注意。许多云服务提供商已开发出“GovCloud”或类似的区域化云服务，以支持ITAR和其他限制跨境数据流动的进出口要求。

许多司法管辖区要求某些类型的数据必须在其境内处理。近年来，这一趋势有所增加，其假设是信息默认情况下会更安全，会在合法请求时提供给政府，并具有经济效益，即促使数据处理中心运营商在其国家内设立设施。超过34个国家有某种形式的数据本地化要求。

数据本地化法律在斯诺登披露国家安全局进行的各种收集活动后变得更加重要。数据本地化法律被视为对外国势力的情报活动提供某种保护。

数据本地化的经济论据不一定令人信服。大量研究表明，数据流动壁垒造成的贸易和投资机会丧失、IT成本上升、竞争力下降以及经济生产率和GDP增长降低的成本是显著的。估计显示，本地化使巴西、中国、欧盟、印度、印度尼西亚、韩国和越南的GDP降低了0.7%至1.7%。

尽管如此，许多国家（除了前面提到的美国）已通过此类法律。

### 俄罗斯

2015年，俄罗斯成为首批要求所有在俄罗斯境内收集的关于俄罗斯公民的数据必须存储在俄罗斯境内的政权之一。实施该法律的法规可能不要求本地化，如果信息服务并非针对俄罗斯（即使用俄语、使用俄罗斯顶级域名等）；这仍然对信息提供商产生了重大影响。一些提供商，包括Google、Apple和Twitter，已在俄罗斯收购计算能力以遵守该法律。其他人，尤其是领英，则抵制该法律，其服务在俄罗斯境内被封锁或受限。

### 中国

在中国，《网络安全法》的执行将对信息流动施加新的限制。中国声称对在其边界内运营的互联网拥有主权，并安装了网络保护措施，包括限制接入点和严格的防火墙规则，以审查在中国境内提供的数据。《网络安全法》第37条要求关键行业网络运营商将其网络运营商收集或产生的所有数据存储在国内系统上。特别是，该法律要求在国内收集的中国公民数据必须保留在中国境内，未经中国政府许可不得转移到国外。

## 隐私

隐私和信息安全密不可分。如本章前面所述，隐私有效地是应用于个人数据的保密安全原则。全球有几项重要法规建立了隐私和数据保护要求。作为一名安全专业人员，了解管辖您所在司法管辖区的每项隐私法规非常重要。作为一名CISSP，您可能熟悉以下法规，具体取决于您的司法管辖区：
* 美国1974年联邦隐私法
* 美国1996年健康保险可携性和责任法案（HIPAA）
* 美国1998年儿童在线隐私保护法（COPPA）
* 美国1999年格雷姆-里奇-比利雷法案（GLBA）
* 美国2009年经济和临床健康法案中的健康信息技术法案（HITECH）
* 数据保护指令（欧盟）
* 1998年数据保护法（英国）
* 安全港
* 欧盟-美国隐私盾
* 通用数据保护条例（GDPR）（欧盟）

### 美国1974年联邦隐私法，5 U.S.C. § 552a

《联邦隐私法》是1974年颁布的美国法律。《隐私法》建立并规范了美国政府机构收集、维护、使用和传播个人身份信息的做法。《隐私法》的目的是在政府维护公民和永久居民信息的需要与这些个人保持其个人信息私密的权利之间取得平衡。在其条款中，《隐私法》规定，“任何机构不得通过任何通信方式向任何人或另一机构披露记录系统中的任何记录，除非根据该记录所涉及的个人的书面请求，或经该个人事先书面同意。”尽管《1974年隐私法》大大早于互联网，但该法中的条款仍然相关，并在在线隐私同意书和其他用作“个人书面同意”的机制的形式中体现出来。

### 美国1996年健康保险可携性和责任法案

HIPAA于1996年签署成为法律，而HIPAA隐私规则和安全规则分别于2003年生效。必须遵守HIPAA要求的组织被称为受监管实体，分为三类：
* 健康计划：这包括健康保险公司、政府项目如医疗保险，以及支付医疗保健的军事和退伍军人健康项目。
* 医疗保健提供者：这包括医院、医生、养老院、药房和其他传输健康信息的医疗提供者。
* 医疗保健清算所：这包括公共和私人组织，如计费服务，它们处理或促进非标准健康信息的处理并将其转换为标准数据类型。医疗保健清算所通常是医疗保健提供者与健康计划或医疗服务付款人之间的中介。

HIPAA隐私规则为保护患者隐私建立了最低标准，并规范了个人健康信息的使用和披露，被称为受保护健康信息。根据HIPAA，个人的PHI仅允许用于执行和计费医疗服务的目的，并且必须受到不当披露或使用的保护。
