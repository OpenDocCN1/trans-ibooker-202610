# 主编作者

![](images/ffirsuf001.png)

**ARTHUR DEANE, CISSP, CCSP**，是 Capital One Financial 的高级总监，负责信用卡部门的信息安全活动。在加入 Capital One 之前，Arthur 在 Google、Amazon 和 PwC 担任过安全领导职务，并在美国联邦政府担任过多个安全工程和咨询职务。

Arthur 是美国大学的兼职教授，也是 Howard University 计算机科学顾问委员会的成员。他拥有罗切斯特理工学院（RIT）的电气工程学士学位和马里兰大学的信息安全硕士学位。Arthur 也是 *CCSP for Dummies* 的作者。

![](images/ffirsuf002.png)

**AARON KRAUS, CISSP, CCSP**，是一名信息安全专业人士，在安全风险管理、审计和网络安全教学方面拥有超过 15 年的经验。他曾在美国联邦政府民用机构、金融服务、保险和科技初创公司等行业担任安全和合规领导职务。

Aaron 是 Learning Tree International 的课程作者、讲师和网络安全课程主任，最近教授了官方 (ISC)² CISSP CBK 复习研讨会。他是 *The Official (ISC)*^(*2*) *Guide to the CCSP CBK, 3rd Edition* 的合著者，并担任多本 Wiley 出版物的技术编辑，包括 *(ISC)*^(*2*) *CCSP Certified Cloud Security Professional Official Study Guide, 2nd Edition*；*CCSP Official (ISC)*^(*2*) *Practice Tests*；*The Official (ISC)*^(*2*) *Guide to the CISSP CBK Reference, 5th Edition*；和 *(ISC)*^(*2*) *CISSP Certified Information Systems Security Professional Official Practice Tests, 2nd Edition*。
