今天，企业面临的安全挑战比以往任何时候都更加复杂。无论您的公司相对较小，仅限于某个城市或地区，还是拥有重要国际足迹的大型跨国公司，您都必须时刻关注组织和员工面临的潜在安全问题以及它们如何变化。

## 引言

任何严肃的安全讨论都适用一个基础原则，那就是：除非您致力于培养安全思维模式，否则您将无法利用本书中提供的大部分信息。安全思维模式比我们能部署的任何技术或安全程序或协议都更有价值；就解决安全和生命安全问题而言，人为因素是最关键的元素。

在阅读本书时，每一章都强调了安全的一个不同方面，旨在极大提高整体安全，无论您是在工作、在家还是在海外旅行。提供的每项建议多年来已被证明在提高整体安全态势方面有效。然而，除非您学会关注周围环境并在威胁形成之前识别威胁，否则本书中的大部分信息对您来说将毫无用处。以下是我们将在本书中涵盖内容的简要概述。

第 1 章：培养安全思维模式。您的大脑是个人安全和整体生命安全方面最有价值的工具，因此我们首先讨论如何培养训练有素的安全专业人员所具备的相同心理技能。本章论证了培养适当的观察技能并学会从观察中得出正确结论是任何人减少受伤害脆弱性的最重要的事情。我们详细解释了在关键事件期间经历的压力和恐惧对您的认知和感知能力可能产生的影响。理想情况下，目标是教您在危险情况发生之前识别危险情况；避免危险情况总是比危险开始后试图摆脱危险更好。

第 2 章：办公室应急规划。您如何在办公室处理紧急情况或突发事件？如果员工、客户、供应商或客人发生医疗紧急情况怎么办？如果您的建筑物或楼层发生火灾怎么办？还有许多与火灾无关的紧急情况，范围从



从恶劣天气，到事故，再到涉及大规模杀伤性武器的恐怖袭击，这些都可能威胁到你的安全。你目前是否已制定处理此类事件的程序，还是在关键事件发生时被迫在没有计划且承受极端压力的情况下尝试做出适当应对？那你的业务保护呢？如果需要疏散或在建筑物内转移，是否需要采取与业务连续性相关的行动？你的办公室或设施长时间关闭会对你的业务产生什么影响？

在本章中，我们教你如何在紧急情况下制定应对计划，以确保员工的安全、保护资产以及业务的连续性。

# 第3章：收到可疑邮件和包裹以及炸弹威胁

如果办公室收到炸弹威胁，你会如何处理？你会立即疏散大楼，还是等待警察到来并告诉你该怎么做？你的营业场所收到信件或包裹炸弹的几率极其微小，但许多企业在某个时候都必须处理此类威胁，因此事先准备是必要的。大多数威胁是真实的吗？不，大多数此类威胁旨在扰乱你的日常业务活动。这会改变你的应对方式吗？

你会如何处理收到可疑信件或包裹的情况？如果办公室里遗留了一件无人能识别的物品怎么办？如果你的员工报告收到一封泄漏某种粉末或液体的信件，且有强烈或恶臭味，你会怎么做？

本章涵盖所有这些问题，并深入探讨导致办公室威胁的动机。这类事件总是会引发执法部门的响应，但在第一响应者到达之前你采取的步骤至关重要，本章对此进行了详细讨论。

# 第4章：工作场所暴力

根据劳工统计局的数据，凶杀案是工作场所死亡的第三大原因。有时威胁来自外部；例如，零售企业存在被抢劫的风险。然而，在许多其他情况下，对员工造成伤害的威胁来自其他员工。工作场所员工引发的暴力对任何公司来说都是令人恐惧的前景，特别是因为，如果没有建立适当的报告系统，在暴力行为发生之前很难检测和处理。公司必须建立对工作场所暴力的零容忍政策，并保持警惕，以应对具有攻击性、好斗的以及可能暴力的员工。本章分析了工作场所暴力个体带来的风险，并提出了适当的预防措施以维护办公室的安全环境。本章还讨论了如何处理影响员工的家庭暴力行为，因为此类暴力往往会蔓延到工作场所。

# 第5章：在活跃枪手事件中幸存

FBI 的统计数据显示，活跃枪手事件的数量正在增加。这些事件不可预测、混乱且发生得非常快。组织永远无法完全消除此类袭击发生的风险，但它们可以在袭击发生前采取许多行动以尝试预防袭击，在袭击发生期间减轻潜在损害和生命损失，并在袭击发生后尽快恢复正常运营。本章回顾了活跃枪手事件，特别是在工作场所发生的此类事件，并提供了在事件发生时幸存所需的信息。

# 第6章：个人和商务旅行安全

公司从事的业务类型以及工作的世界各地也可能造成安全问题。国际公司可能需要处理对其海外商务旅客和外籍员工的潜在威胁。位于政治动荡地区的公司及其员工可能卷入当地或地区冲突甚至恐怖袭击。本章提供了有关如何为旅行做准备以及在海外期间如何表现的宝贵信息。本章还涉及在国外居住的问题。

# 第7章：前往高风险地区旅行

大多数刑事或恐怖行动并非随机进行。几乎所有恐怖或刑事袭击都先于一个预作战阶段，在此阶段会收集有关目标的信息。为了了解目标的日常规律而跟踪目标是此阶段最关键的元素之一，其目的是确定目标最脆弱的地点和/或时间。本章讨论了如何进行监视，以便帮助你了解如何利用反监视技术来检测自己是否被监视或跟踪。你将学习路线选择的原则，以在驾驶时降低脆弱性，并认识到了解最近安全避难所位置的重要性。如果你需要前往潜在危险地区，或是公众人物或负责保护某人的安全专业人员，本章将对你极具兴趣。

# 第8章：劫持和人质生存

如何应对劫持以及如何在人质情况下生存的主题极其复杂。关于如果卷入其中一种或两种情况该怎么做，有几种不同的观点。由于目前对最佳应对方式几乎没有共识，本章分享了不同的做法。我们讨论了各种做法的利弊，以便让你熟悉该主题上流行的专家意见。

# 第9章：间谍活动和欺诈保护：高管视角

知识产权被盗和欺诈构成了企业收入和库存损失的主要来源。根据两党知识产权委员会 2017 年研究报告《美国知识产权被盗：挑战的重新评估和美国政策》的调查结果，假冒商品、盗版软件和商业机密被盗每年给美国经济造成的“经济损失”在 2,250 亿至 6,000 亿美元之间。尽管知道这一点，企业仍在犯同样的错误。我们能否保护公司最关键的信息不落入坏人之手？

高管通常是诈骗的目标，既有简单也有复杂的。能否做些什么来降低这种风险？本章涵盖基本的欺诈预防和知识产权保护。

# 第10章：高管保护

保护个人与保护设施是完全不同的学科。高级高管无法被限制活动。他们必然具有流动性，而这种流动性会使高管面临各种风险。在过去十六年里，我们有机会为企业高管、A 级名人、大使、政治人物和要人提供安全和近身保护。我们还培训了保护世界上一些最知名和最具影响力的企业家的人员。我们学到的经验是，在私营企业中，没有比高管保护专业人员的角色更被广泛误解的安全角色了。对于一些高管来说，安全团队仅仅意味着他们有一名曾是警察且携带武器的司机。对于娱乐业的许多人来说，安全团队似乎按体重估价；特工都是体型极大、体格强壮的类型，其工作只是充当客户的移动保镖。本章描述了高管保护计划可以是什么以及应该是什么。

# 第11章：成功运营安全业务职能

在过去十年中，越来越多的公司将安全职能集中化，并设立了一个新的角色，即首席安全官或安全主管。该个人负责整体企业安全，包括员工、设施、资产的物理安全和安全，以及信息的保护。近年来，该角色已扩展到包括业务连续性规划、损失和欺诈预防等相关领域。该职位极具挑战性，成功需要远不止技术知识。该角色要求领导力、强大的商业头脑和管理技能。许多担任此角色的人来自执法或军事背景，但缺乏商业经验和对企业文化的理解。这一问题可能



存在问题，因为他们面临着争夺预算资金的竞争，必须在其他部门的老练商业老将面前为安全预算的增加资金提出理由，而这些老将也在寻求同样的资金。在企业环境中学会游刃有余是一项新技能，本章为您提供了开发、管理和运营成功的企业安全运营所需知识。
