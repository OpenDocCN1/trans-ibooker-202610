## 前言

自我们撰写本书第一版以来，已过去十六多年。当时，距离 9/11 袭击事件不到两年，我们两人已分别脱离各自国家的服役，转入私营部门。国家仍处于高度警戒状态。私营部门的平民工人曾被蓄意针对，企业和个人被迫重新考虑他们对安全的看法。我们撰写本书第一版的最初目标是应对 9/11 袭击事件后一段时间内私营公司不断变化的安全需求。因此，第一版的大部分内容提供了应对美国本土和海外恐怖主义行为或潜在恐怖主义行为所带来的担忧的措施。

在本书出版后的几年里，我们为数百家公司、政府机构、执法人员、私人安保人员和高管提供了咨询和培训。伊兰获得芝加哥大学布斯商学院工商管理硕士学位。他曾担任管理顾问，目前是某大型国际公司的 senior executive。大卫创立了 Global Security Group, Inc.，该公司提供多项服务，包括人身保护、消防和生命安全咨询、规划和演练、私人调查以及高度专业化的培训。正是这种私营部门的经验让我们两人对美国企业当前的安全状况以及为实现工作场所更大程度的安全和保障目标而需要做的事情有了更清晰的认识。尽管恐怖主义的威胁将继续成为可能影响私营部门的问题，但本书更侧重于公司每天面临的更常见的安全问题。

今天，企业面临的安全挑战比以往任何时候都更加复杂。无论您的公司相对较小，仅限于某个城市或地区，还是拥有重要国际足迹的大型跨国公司，您都必须时刻关注组织和员工面临的潜在安全问题以及它们如何变化。

对工作场所暴力、主动枪手事件（通常是未解决的工作场所暴力问题的结果）、知识产权和资产保护以及其他问题如健康紧急情况、与天气相关的危险、自然灾害、旅行安全和海外政治动荡或局部暴力等问题的担忧更为紧迫。未能在工作场所解决这些问题可能导致对您的业务和员工造成重大甚至灾难性的后果。

在本第二版中，我们利用我们在政府服务和私营部门职业生涯中的综合经验，教导安保人员、企业高管和员工如何识别和为当今世界普通个人和公司面临的真实威胁做好准备。本书提供了使您能够获得保护您的业务、您自己和他人的知识所需的信息。这种知识以前仅提供给政府安全专业人员，现在以适合企业环境的形式在本书中向您提供。您将了解危险事件期间经历的恐惧和压力如何导致认知能力、感知能力和做出关键决策能力发生变化，以及如何减轻这些影响。您将学习如何发现潜在暴力员工的警告信号以及如何防止暴力发生。您将学习如果被困在主动枪手事件中应采取的生存策略。如果您是负责员工和公司资产安全的执行官，您将学习如何保护员工和设施，如何制定应急协议，以及如何管理火灾或非火灾紧急情况的响应。如果您计划出国旅行或作为外派人员在另一个国家为公司工作，本书将为您提供必要的知识，以便采取措施增强您自身的身体安全以及您家人和同事的安全。最后，如果您是负责企业安全和生命安全问题的执行官，本书将为您提供成功运营安全行动并在企业商业环境中确立自己为宝贵资产所需的知识。

## 引言

任何严肃的安全讨论都适用一个基础原则，那就是：除非您致力于培养安全思维模式，否则您将无法利用本书中提供的大部分信息。安全思维模式比我们能部署的任何技术或安全程序或协议都更有价值；就解决安全和生命安全问题而言，人为因素是最关键的元素。

在阅读本书时，每一章都强调了安全的一个不同方面，旨在极大提高整体安全，无论您是在工作、在家还是在海外旅行。提供的每项建议多年来已被证明在提高整体安全态势方面有效。然而，除非您学会关注周围环境并在威胁形成之前识别威胁，否则本书中的大部分信息对您来说将毫无用处。以下是我们将在本书中涵盖内容的简要概述。
