
服从。刀具掉落在地上，袭击者远离受害者。此时你命令肇事者不要移动。对你或受害者都没有立即的威胁，肇事者保持不动。突然你看到肇事者的眼睛朝巷子的尽头瞟去，你意识到他正在考虑逃跑的选项。你叫他别动，但他冲破阻拦并跑了。根据纽约法律，你可以开枪阻止他逃跑吗？如果你回答是否定的，你就错了。纽约州法律授权你采取一切必要手段，包括使用致命武力，以实施逮捕并防止逃跑，只要满足两个标准：肇事者必须是在实施上述严重罪行之一时被抓获，并且肇事者必须正从中立即逃离。换句话说，你必须当场抓住坏人，并且罪行实施与试图逃跑之间不能有实质性的时间间隔。根据这些事实，肇事者在你抓住他实施强奸后试图逃跑的那一刻，你就可以命令他停止。如果他拒绝服从并试图逃跑，你就可以开枪阻止逃跑。

然而，如果逃跑企图并非“立即逃离”，你就不能使用致命武力。一个例子是你在强奸正在进行时赶到，肇事者在你采取任何行动之前就跑了。第二天，你在同一街区行走时，看到了强奸犯。你确信那就是他，并且命令那个人停下。他无视你的命令再次跑开。你可以开枪阻止逃跑吗？显然答案是否定的，因为罪行实施与逃跑之间存在间隔时间。

如果你刚刚目睹有人犯下谋杀、抢劫、一级过失杀人或强奸或鸡奸，现在定义为强奸性行为，使用致命武力的完全相同的正当理由也适用。如果使用致命武力与自卫有关，那么在这些特定情况下使用武力有何意义，鉴于致命武力的自卫正当理由？答案是这些特定罪行被视为如此严重、如此残忍，并且对整个社区构成如此大的危险，因此允许使用致命武力来保护整个社区。

从前面的讨论中应该显而易见的是，关于使用致命武力的法律是复杂的。即使规则在阅读时似乎清晰易懂，但在实际致命武力遭遇的背景下，它们变得远不那么清晰。例如，法律规定，如果你合理地认为致命武力即将对你或无辜第三方使用，或者你即将遭受严重伤害，你被允许使用致命武力。但现在尝试分析法律在多种不同可能情况下的适用。我们

很可能会一致认为，如果一个体格强壮的袭击者拿起棒球棒并举着棒子冲向你，在这种情况下，合理地认为你面临严重伤害的风险，并且可能受伤严重甚至被杀是合理的。在那种情况下，使用致命武力是正当的。如果你被这样的攻击者对峙时开枪，你的行为在法律上是可以正当化的。但如果你的攻击者不是强壮魁梧的人，而是一个体弱的人呢？在开枪前这会是需要考虑的因素吗？如果使用的武器不是棒球棒，而是儿童的曲棍球杆呢？当然这是一种威慑力远不如的武器，但它仍然可能在某种程度上伤害你。如果你认为你的攻击者可以用曲棍球杆杀死或致残你，这合理吗？如果有人赤手空拳表明要暴力攻击你呢？假设你身高5英尺8英寸，体重160磅。你的攻击者身高6英尺4英寸，体重280磅。在这种情况下，一个更大更强的人严重伤害你甚至杀死你不是也很可能吗？在那种情况下你被允许使用武器自卫吗？如果体型和力量上的差异没有那么大呢？那又如何？

我们可以讨论一个又一个场景，但我们的观点应该很明显。这些问题并不像看起来那么简单；也许你在舒适的环境中阅读时，脱离了暴力对峙引发的压力，甚至对每个问题的回答都感到困难。现在想象一下，你深夜走去取车时，突然被一名持械者袭击并试图攻击你。你被打了个措手不及，已是深夜，光线非常微弱，你只有不到一秒钟的时间行动。你认为在那种情况下做出正确决定会更困难还是更简单？

如果你要携带枪支进行个人保护，你需要在极度恐惧时仍然能够准确、快速地射击。做到这一点需要大量的训练和定期练习的承诺。射击就像其他任何事情一样；如果不通过练习强化，你的技能会随着时间推移而退化。除了保持射击能力敏锐之外，你还需要练习并培养在最恶劣条件下快速判断的能力。你必须在逼真的情况下训练，这种训练需要让你处于压力之下并强迫自己快速做出决定。这可以通过多种方式实现，包括使用电子模拟器，在进行体力活动后耗尽体力后通过需要快速决策的战斗课程，或进行一系列其他旨在强迫你做出开枪或不开枪决定的练习。这种类型的训练很难找到。事实上，甚至全国领先的执法机构也常常缺乏这种训练。然而，你不能忽视在压力下训练。你是一个成功的人，有很多东西要失去。不要因为你从未训练过如何在压力下行使判断力而冒着自由或财产的风险做出错误决定。

考虑隐蔽携带的责任保险。一些公司提供保单，涵盖因自卫使用枪支而被逮捕或被起诉时的刑事和民事责任。各种网站甚至提供比较这些公司提供的此类保险的保障范围。保单费率，在我们撰写本章时，每年介于130美元至599美元之间。这是一笔相对较小的费用，可以换来很大的安心。检查这些保单是否在你所在州的法律下可用。

最后一点思考：如果你 ever 被迫在自卫情况下开枪，一旦安全就立即将武器放回枪套。记住，警察会赶到，他们对你是谁或发生了什么一无所知。他们所知道的只是他们正在响应“枪击”的呼叫，并且在行动上会极其积极。你认为如果他们到达时发现你手持枪支站在刚被射击的人上方会发生什么？顺便说一下，如果警察到达并给你命令（即，放下武器，双手举起等），立即毫不犹豫地服从。不要向到场的警官发表任何声明。每一场枪击事件都会被调查。即使你做了一切正确的事情，你的行为在法律上是正当的，你也会承受巨大的压力，而我们已经知道压力对我们思考能力的影响。你会感到慌乱，并可能说出让你陷入法律危险的话。你还应该去医院检查。告诉到场的警官你想去医院，并且在做出任何声明之前想先与律师谈谈。

我们以讨论为捍卫你的生命或他人生命而采取行动结束本书是有原因的。我们的安全在很大程度上取决于我们的行动能力；因此，我们固有的偏向始终应该是行动。有句来源不明的说法：“行动或接受。”这句话是那些决心拥有更安全生活的人的优秀信条。保持警惕，保持安全，如果必要，采取一切必要行动来生存威胁到你生命的危险。
