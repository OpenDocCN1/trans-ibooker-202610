额外的电子邮件诈骗已经存在很长时间了。联邦贸易委员会有一个最常见的 12 种列表（http://www.ftc.gov）。该列表包括虚假商业机会、连锁信、工作在家计划、健康和饮食诈骗、轻松赚钱、“免费”商品、投资机会、批量电子邮件计划、有线电视解码器套件、“保证”贷款或信用。

您如何保护自己免受这些诈骗？答案很简单：意识、培训和适当程序到位。

- 1. 验证所有电汇请求。任何电汇请求，尤其是必须紧急进行的请求，都应被视为可疑。在许多情况下，快速打电话确认转账给错误认为已指示转账的人就可以防止这种诈骗得逞。
- 2. 就像您不会为不认识的人开门一样，不要打开您不认识的人发送的电子邮件。打开电子邮件就像邀请侵犯您自己的隐私。同样，切勿打开未经请求的电子邮件的附件。最重要的是，除非您确定它是合法的，否则不要点击电子邮件中发送给您的链接。
- 3. 每当供应商更改账户或您收到意外发票时，验证更改。
- 4. 与您的工作安全部门讨论在收到的每封外部电子邮件上标记 [EXTERNAL] 的必要性。当您在电子邮件地址旁边看到 [EXTERNAL] 一词时，请格外小心。不要打开来自外部来源的电子邮件或链接，除非您知道发件人。
- 5. 仔细检查任何声称来自银行和其他金融机构的电子邮件。大多数金融机构已制定政策禁止在电子邮件中索取个人或账户信息，因此您应将提出此类请求的任何电子邮件视为非法。
- 6. 防止垃圾邮件进入您的邮箱。
- 7. 安装防病毒软件和个人防火墙，并保持两者最新。
- 8. 最后，参与所有层级员工的持续安全意识培训，以了解最新的安全诈骗。
