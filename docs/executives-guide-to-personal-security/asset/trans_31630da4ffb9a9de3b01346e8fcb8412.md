让我们谈谈一种非技术性的信息收集技术：诱导技术。根据联邦调查局的说法，诱导是用来收集并非 readily 可从某人那里获得的信息，而该人是经过刻意挑选和针对的，且不会引起人们怀疑正在寻求特定事实。训练有素的诱导者利用人类本性的几个基本特征，包括大多数人希望有礼貌和乐于助人，即使是对陌生人也诚实地回答问题。人们还有一种共同的愿望，即在自己的职业上显得知识渊博、受到赞赏，以及需要证明自己正在从事重要的工作。因此，当得到提示时，我们往往会就特定主题大谈特谈。最后，人们喜欢谈论自己或分享自己的观点。由于这些自然的人类倾向，许多高管都会落入分享超出所需关于自己、公司、项目甚至家人的信息的陷阱。

你可以在任何地方遇到诱导者。他们可能会通过电话或互联网联系你，但面对面的交谈是最有效的。因此，你可能在工作以外的商务会议和旅行期间暴露于诱导技术。以下是一个很好的例子。你在商务会议上遇见某人。他或她很快就接近你，自然的关于天气或你前往会议的细节的交谈很快就转向工作讨论。你从未提及你的名字、头衔或你工作的公司，所以你觉得在匿名中相对安全。然而，“陌生人”确切地知道你是谁，并说了一些旨在引发揭示性回应的话，例如“在上次演讲中讨论的解决方案永远不会奏效”，希望你会就此陈述大谈特谈，并根据你的知识和经验确认或反驳所说的内容。因为你仍然认为这个人不知道你在哪里工作或做什么，你可能认为提供意见没有害处。然而，你大错特错了。“陌生人”确切地知道你做什么，并且已经构建了这个问题以挖掘可能只有你和公司少数几个人才知道的知识。他或她依靠你诚实和显得有知识的愿望来提供这种高度敏感的竞争信息。诱导者故意做出虚假陈述，以便你能“纠正”他们；通过这样做，你刚刚把诱导者需要的信息交给了他。

有许多类型的诱导技术，并且在一次诱导尝试中可能会使用多种技术。以下是诱导者使用的最常见技术的一些描述。

**假设知识：** 假装与某人有共同的知识或关联。“根据我以前合作过的计算机网络人员所说……”

**框定：** 提供高低估计以诱使更具体的数字。“我认为费率很快就会上涨。我猜在五美元到十五美元之间。”

**回应：** 讲述极端的故事，希望对方想要超过它。“我听说 X 公司正在开发一种令人惊叹的新产品，能够……”

**机密诱饵：** 假装透露机密信息以期换取机密信息。“就我们俩之间说……” “不记名……”

**批评：** 批评个人或组织，而该人对其有兴趣，希望该人在为其辩护时披露信息。“你们公司怎么拿到那份合同的？大家都知道 X 公司在那种工作上拥有更好的工程师。”

**故意虚假陈述 / 否定显而易见：** 说错话以期让对方用真实信息纠正你的陈述。“大家都知道那个流程行不通——它只是一个 DARPA 的梦想项目，永远也无法起步。”

**恭维：** 使用赞美来引诱某人提供信息。“我敢打赌你就是设计这个新产品的关键人物。”

**善于倾听：** 通过耐心倾听并验证个人的感受（无论积极还是消极）来利用抱怨或炫耀的本能。如果一个人觉得自己有可以倾诉的对象，他/她可能会分享更多信息。

**引导性问题：** 问一个答案为“是”或“否”的问题，但其中包含至少一个预设。“你在离开那家公司之前是否做过集成系统测试？”（与：“你在前一份工作中的职责是什么？”相反）……

**共同兴趣：** 建议你与某人基于共同的兴趣、爱好或经历相似，以此获取信息或在索取信息前建立融洽关系。“你哥哥在伊拉克战争服役？我哥哥也是。你的哥哥在哪个部队？”²

还有许多其他威胁。你能采取什么措施来减少下一次旅行的风险并避免成为企业间谍或欺诈行为的目标？

- 1. **尽可能保持你的旅行信息私密。** 不要在家人和你信任的人之外透露旅行计划和细节。
- 2. **记住，旅客在酒店房间中很脆弱。** 人们可以进入房间。切勿在酒店房间里留下敏感的业务材料和你的笔记本电脑无人看管；确保你的笔记本电脑和手机始终随身携带，并注意你丢弃的东西。垃圾始终是信息的良好来源。
- 3. **你的电脑是一个有价值的目标。** 它包含数万份文件。始终将你的电脑放在随身行李中。不要使用公共 Wi-Fi 服务。始终使用受信任的虚拟专用网络，并在你的电脑上使用加密程序来保护你的电子邮件。
- 4. **不要主动提供信息。** 酒店酒吧是诱导的完美场所。在忙碌的一天和几杯酒之后，大多数人都会放松警惕。这正是竞争对手或外国特工针对你的时间和地点。怀疑那些开始交谈并迅速进入与你工作相关的讨论的人。
- 5. **注意性勒索。** 许多企业高管都会落入这个陷阱。他们发现自己在交换敏感信息，以换取性遭遇不会出现在报纸头版或被告知给他们的家人。

## 现代欺诈：邮箱正不断受到攻击

电子邮件是一种方便且强大的通信工具。不幸的是，它也是骗子针对高管进行欺诈攻击的方便且容易的工具。在电子邮件发明之前，骗子必须通过邮件、电话或直接与受害者沟通。这些类型的沟通方式要求骗子投入大量时间和承担被曝光的潜在风险。电子邮件带来了用一次简单的“发送”按钮点击就能针对数百名受害者的便利。此外，骗子保持匿名，这降低了他们被抓的风险。为了保护自己免受此类攻击，你必须了解它们是什么、它们如何运作，以及你应该做什么来避免成为受害者。

一个好的起点是问为什么高管经常成为欺诈攻击的目标。高管经常向员工和承包商下令支付资金以执行大型项目。他们还接收和发送机密信息。当收到高级高管的命令时，初级员工往往会毫不问理由就完成转账或涉及金额。犯罪分子了解这一点并知道如何利用它。

一种常见的诈骗是付款转移。这通常发生在目标高管正在旅行且不在办公室时发生。骗子发送一封伪造的来自高管的电子邮件给目标员工（例如，簿记员、会计师或行政助理）。骗子通常假装是拥有指示付款给另一方的权威的高管。请求通常是电汇，以便立即转移资金。目标员工相信他或她正在向熟悉的账户汇款，就像过去所做的那样。但账户号码略有不同，数万或数十万美元的转账最终进入了不同的账户。

罪犯总是试图通过使用社会工程技术或网络钓鱼来从个人那里索取个人信息。为此，他们制作电子邮件，看起来像是来自合法组织或已知个人发送的。这些电子邮件通常试图引导用户点击一个链接，该链接将用户带到一个虚假网站。那个看似合法的网站会下载病毒或软件，从而损害计算机。或者受害者被诱骗输入个人信息，这些信息可用于获取计算机或个人银行账户的访问权限。

例如，一封电子邮件可以伪装成来自美国国税局，主题行令人兴奋，例如“联系我们领取退款”。电子邮件正文将解释在你的纳税申报表中发现了一个错误，因此你有一笔待发送的退款。为了收到退款，你需要使用提供的链接。链接将带你到一个看起来和感觉像 IRS 网站但实际上是假的网站。一旦到达该网站，你将被要求输入个人信息，包括银行账号和密码，以便将直接存款汇入你的账户。有了这些信息，骗子通往你账户的路线就很短而且很快。这种技术非常常见，骗子用它来假装电子邮件是从银行、信用卡公司和其他金融机构发送的。而尽管“每个人”都知道 IRS 从不发送电子邮件，仍有许多人落入这个陷阱。
