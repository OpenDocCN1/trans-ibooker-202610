**恋爱诈骗：**“乔”正在约会网站上寻找匹配对象。他收到“米歇尔”发来的友好请求，希望建立联系。他们一直在交换短信，一切似乎都在朝着正确的方向发展。米歇尔自称是一名在加拿大工作生活的美国人。他们计划很快见面，并在米歇尔夏季回到美国时安排一次度假。为了准备他们的旅行，米歇尔给乔寄了一张 3,000 美元的支票，但突然要求他把 2,000 美元退还给她，因为她被解雇了，需要钱付房租。乔非常期待见到米歇尔，立即汇出了钱。几天后，他接到银行的电话，银行告诉他，他存入的那张 3,000 美元的支票没有资金。支票是假的，“米歇尔”根本不存在。她消失了，乔再也没有收到她的消息。

**病毒式视频：**病毒式视频在社交媒体上非常流行，尤其是政治、搞笑或承诺揭示有趣信息的视频。然而，正因为它们对我们大多数人来说难以抗拒，它们也是骗子欺骗受害者的完美方式。当你点击其中一个视频时，会被要求更新你的视频播放器。当你这样做时，它会下载并在你的系统上安装病毒。

**假慈善：**强有力、令人感动的需要帮助的人和灾难受害者的图像让我们都想做点什么来帮助他们。不幸的是，罪犯学会利用人们天生的善良欲望，创建假网站为善举筹款。仅仅因为一个慈善机构在社交媒体上出现，或者你的朋友转发或发布了它，并不意味着它是合法的。

**谁在查看我的资料：**这种 Facebook 诈骗表现为广告或发布在你墙上的消息，由你的朋友邀请你查看谁在查看他们的资料。点击此类消息会让垃圾邮件发送者直接访问你的 Facebook 帐户和网络，以及可能访问你朋友名单上的人。

**不要点击：**骗子试图通过将链接隐藏在你想点击的另一个超链接下，来诱骗你点击链接。这可能导致用户在不知情的情况下下载恶意软件或泄露敏感信息。例如，骗子可能声称来自合法金融机构，提供特别信用，只要你完成调查就可以登录某个程序。你完成调查，却没有意识到你正在与骗子分享敏感信息，这可能使你面临欺诈或身份盗窃的风险。

**入室盗窃：**罪犯还使用社交媒体页面，例如 Facebook，来判断潜在受害者是否在家。公开分享有关度假和其他离家时间的信息正是窃贼所寻找的。

社交媒体上还有许多其他类型的诈骗。记住，社交网络意味着在网上与他人开放和分享信息。有一些信息你永远不应该在网上分享，并且有一些做法可以确保你不会成为下一个受害者。

你能做些什么来保护自己？以下是关于社交媒体的 dos 和 don’ts。

- 1. **限制访问。**对陌生人发来的非请求连接或好友请求保持怀疑。不要接受陌生人的“好友”或“关注”请求。人们并不总是他们自称的那样，而保持骗子远离你的生活的最好方法是永远不要让他们进来。同样，不要回复你不认识的人或号码发来的手机短信。

- 2. **不要在公共电脑上登录社交网络网站。**使用自己的电脑或智能手机，而不是图书馆和其他公共场所的电脑。你的登录信息可能在公共电脑上被拦截。

- 3. **保持你的信息私密。**要小心你在网上分享和发布的信息以及与谁分享。明显不应该分享的信息是你的社会安全号码、地址和出生日期。关于发布“度假中”呢？你不会在前门贴上你正在度假，大约一周后会回来的纸条，对吧？避免发布正面全脸照片。骗子可以复制图像并用它创建可以用来盗用你身份的照片 ID。关于在网上发布你的完整简历供所有人查看呢？可能不是好主意。身份窃贼很容易利用这些信息填写贷款申请。在像 LinkedIn 这样的网站上限制你的工作历史细节。如果你觉得为了求职需要发布信息，在你获得职位后删除这些信息。

- 4. **实践良好的密码安全。**使用强密码（至少八个字符，混合大小写字母和至少一个通配符字符）。定期更改密码，并且为每个社交网络网站使用不同的密码，这样如果一个密码被盗，你的所有帐户都不会面临风险。

- 5. **谨慎点击链接。**始终对可疑的链接、消息和广告保持警惕，无论它们有多诱人。即使它们是由你的朋友发送的，也要确保与他们核实，以确保链接是合法的。对任何金钱请求要格外谨慎。如果你收到朋友的此类请求，请在回复前打电话给他或她，确认请求是否真实。

- 6. **自定义安全选项。**利用隐私选项限制你的信息，使其只能被选定的人查看。网站越来越多地让用户对自己的隐私设置有更多控制权。不要假设默认设置是最适合保护你的。检查设置、配置和隐私部分，看看你可以将哪些选项限制给谁以及你的个人信息类型可见。Facebook 例如，有隐私选项让用户控制谁可以看到你的基本信息、个人信息、照片、朋友和帖子：无人、朋友、朋友和网络，或所有人。如果你刚刚加入社交网络网站，或者即使你已经使用一段时间，登录你的帐户并查看和调整隐私设置。

- 7. **搜索自己。**搜索你在互联网上的名字是个好主意。了解关于你的哪些信息可用以及你在何处出现。如果你看到你的名字出现在你不认识的地方，这可能提醒你有人在网上使用你的身份。

- 8. **教育你的家人和孩子了解社交网络诈骗的危险。**年轻的社交媒体用户可能比你更懂电脑，但他们不知道其中的危险。

## Executive Protection

在执行保护方面存在一个很大的（而且常见的）误解。大多数人认为提高个人安全最好的方法是雇佣一个极其庞大和令人生畏的个人或多个人陪同他们去任何地方。这种对保护专家实际角色的基本理解错误导致了客户群失望、众多过度使用武力的诉讼、公关灾难，甚至名人和高管的死亡。有效的高管保护专业人员（EPP）的价值在于他们的知识，而不在于他们携带的肌肉量。EPP 需要知道如何进行风险评估，制定计划，并为多种不同场景准备应急计划。EPP 必须能够融入高管的环境中，以确保他的安全并最大限度地减少安保团队对高管日常生活的影响。我们亲自培训了数百名保护首席执行官、名人、政治人物的专业人员，在这里我们分享我们教授给寻求填补这一角色的个人的第一课：我们不是保安，也不是保镖。我们是专业保护专家。
