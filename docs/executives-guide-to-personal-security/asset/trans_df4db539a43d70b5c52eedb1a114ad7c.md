
他说，他最近和那个每天清晨送报纸的男孩有些麻烦，那男孩总是把报纸随手一扔，没法每次都落在同一个地方。他说，因此每天早上他都得出门去找报纸。这故事挺有趣。但仔细想想。这个人每天早上在门外张望，这一简单的举动，尽管与反恐毫无关系，却足以吓退潜在的袭击者。他们认为这个人很有安全意识，警觉性高，于是决定转而寻找下一个不注重安全的人。不幸的是，他们这样做的结果很悲惨；另一个人就没那么幸运了。一个绝不能忽视的基本教训是：哪怕仅仅是做出采取安全防范措施的样子，往往也足以阻止一次袭击。人性真是奇妙。人，包括坏人和恐怖分子，常常只看到他们预期想看的东西。策划袭击或绑架的恐怖分子看到的不是一个在找报纸的人。相反，他们看到的是一个显然经过反恐技术训练的士兵。人类通常会选择与自己焦虑程度相符的解释。

人们经常听到一种说法：大家不愿意生活在恐惧中，时刻等着坏事发生。我们完全同意。关注周围环境并不等于生活在恐惧中。恰恰相反。你不会生活在恐惧中。你会带着“世界可能是危险的”这种认知，也带着“如果危险发生在你或家人身上，你有足够的警觉去发现它”的自信生活。这并不难。环顾四周，保持注意。就这么简单。

## 对恐惧的生理和心理反应

阅读本章的每个人大概都会同意，面对重大突发事件的人很可能会感到恐惧以及由此产生的压力。这种恐惧和压力几乎肯定会对他们的认知能力和感知环境的方式产生负面影响。恐惧通常是一件好事。它是你的身体在告诉你，你正处于危险之中。除非恐惧变成瘫痪状态，否则它会促使肾上腺素释放到血液中，帮助你更奋力搏斗或跑得更快。然而，肾上腺素激增也会让人类经历某些反应，这些反应对毫无准备的人来说可能相当令人不安。这些反应包括时间知觉加速、听觉封闭、隧道视野和认知失调。

“时间知觉加速”一词描述的是人们在压力下对时间流逝的感知发生变化，一切都在以慢动作进行。例如，在遭遇袭击时，受害者常常觉得袭击者是在慢动作移动。全球安全集团的高级管理人员之一马克·诺瓦克是一名退休的纽约警察局警监，他讲述了在9月11日世界贸易中心双子塔倒塌时自己拼命逃生的可怕经历。马克是一个体格极其健壮的人，还是马拉松运动员，他觉得自己和周围的人在从倒塌的大楼中逃出时是慢动作奔跑。实际上他肯定不是；他是在全速奔跑，最终毫发无损地逃了出来。但在事件过程中，他的感知是时间急剧变慢了。人们进行了大量研究试图理解这一现象，据信时间过得较慢的感知实际上是一种防御机制，很可能有助于在危险事件中生存。人们认为，这一现象是由于大脑更快地处理信息，以便做出更快的防御反应。不幸的是，大多数经历这种现象的人会因此感到迷失方向，并受到负面影响。认识到了时间知觉加速的影响，你就能利用它为自己服务。

听觉封闭是人在极端压力下发生的另一种常见现象。这个术语指的是大脑在专注于威胁时屏蔽听觉的能力。例如，许多卷入枪击事件的警察报告说，他们从未听到枪声，无论是袭击者的枪还是自己的枪发出的。对于那些有一定枪支使用经验的人来说，这有点令人惊讶；枪声是相当响亮的。发生听觉封闭的原因是大脑干脆屏蔽了听觉输入，让你完全专注于威胁。例如，在枪战中，你的大脑会在五种感官中做取舍。在对峙的那一刻，你最需要的是看到威胁并做出回应。你当然不需要尝、触摸、闻，甚至不需要听到对手。这种效应既有积极的方面，也有消极的后果。增强专注能力是积极的。然而，听觉封闭可能让你听不到需要听到的东西，比如另一个袭击者从你背后悄悄靠近的声音。我们不知道有什么方法可以减轻这种效应，除了意识到它会发生，并认识到通过专注于听觉，听觉会恢复。在恢复之前，你需要扫视一下周围区域，并“check six”，意思是每次有机会就向后看一眼。在平民环境中，听力丧失也同样麻烦。你可能听不到紧急情况下广播系统发出的指示，也可能听不到枪声或其他危险逼近的声音。要意识到听力丧失的可能性，并专注于让耳朵重新恢复功能。

“隧道视野”一词指的是当你专注于某件事时，视野变窄的现象。作者多次体验过这种效应，发现它相当危险。出现隧道视野时，你会失去周边视觉，从而无法发现从侧面接近的其他袭击者或危险。训练自己保持眼球移动可以减轻隧道视野的影响。例如，缉毒局特工被教导在与某个威胁交火后要扫视周围区域。他们这样做是为了避免“钻入”一个威胁而对其他威胁视而不见。

最后一个必须考察的效应叫做认知失调或否认。这指的是在事件实际发生时与之脱离。有时，在危机或袭击中，受害者觉得自己像是在看事件发生，仿佛发生在别人身上。这种反应也许是最危险的。分离的思维拒绝接受如此可怕的事情会发生在自己身上。这种分离是大脑应对突然出现的、令人不快现实的一种方式。危险在于，通过否认正在发生的事件，处于这种状态的人也在否定自己有效反击或逃跑的能力。另一个相关现象是，人们在许多情况下倾向于接受一个“不那么吓人”的解释，这个解释可能符合他们正在经历的事实和环境。例如，在2012年科罗拉多州奥罗拉电影院发生的枪击事件中，观众看到詹姆斯·霍姆斯携带多支枪支、穿着战术背心进入影院。事件发生后接受采访的许多人说，他们以为看到的是一种与《蝙蝠侠》电影首映相关的某种宣传噱头或角色扮演。他们搁置了更可怕的解释——霍姆斯即将向人群开枪——转而选择了不那么令人恐惧的想法。在面临极端危险时，我们的思维倾向于编造不那么可怕的替代解释，这是有问题的。老话说“安全总比后悔好”是良言。你总可以抱最好的希望——前提是你做好最坏的打算。
