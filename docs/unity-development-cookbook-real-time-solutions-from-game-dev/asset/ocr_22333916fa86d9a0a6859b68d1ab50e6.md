```
[SerializeField] float speed = 1f;

// Use this for initialization
void Start () {
    animator = GetComponent<Animator>();
}

void Update () {
    animator.SetFloat("Speed",
    Input.GetAxis("Vertical") * speed);
}
}
```

This creates a new Animator, exposes a speed field to the Inspector,
and uses the Update function to set the speed based on whether the
“Vertical” input axis (see Chapter 3 for details on using the Unity Input
System) is being used. In simple terms: this sets it up so that if the
character is asked to go forward, the right animation is played.
