# ## 6.1 Creating a Simple Material

# ### Problem

You want to customize the appearance of the surface of a 3D object by creating a material.

# ### Solution

In this recipe, we’ll customize a simple shape, though the steps apply to most other meshes you’ll end up using in your game:

+   1. Create a new sphere by opening the GameObject menu and choosing 3D Object → Sphere.
+   
+   2. Open the Assets menu, and choose Create → Material. Name it whatever you like.
+   
+   3. Select the new material, and configure its colors (Figure 6-1).
+   
+   4. Drag and drop the material onto the sphere.
