
## 印务信息

*Unity 开发秘籍* 封面上的动物是普通椋鸟（*Sturnus vulgaris*）。这些中等体型的鸣禽分布于欧洲、中东、北美、澳大利亚，以及非洲北部和南部。它们在19世纪被引入澳大利亚和北美，此后通过成为这些新家园地区最常见的鸟类之一，展示了其适应性，以至于被视为害鸟。

尽管其作为害鸟的名声有待商榷，但普通椋鸟是相当美丽的生物。成年普通椋鸟的羽毛具有显著的虹彩，这种现象发生在羽毛内部微小结构与光线相互作用，反射和折射光线时。通常呈光泽感，带有紫色和绿色色调，椋鸟的羽毛还可能带有白色斑点，尤其是在冬季，当新羽毛生长时。然而，不久之后，这些新羽毛的白色羽尖会磨损，鸟类恢复日常的光泽外观（科学家将这一不寻常现象称为“磨损融化”）。

尽管它们又吵又美，但普通椋鸟或许最为人熟知的，是许多 *在线视频* 的主题，这些视频展示了它们冬季壮观的“群飞”。一年中的大部分时间，椋鸟以小型松散的鸟群活动，但冬季它们会形成由数千只鸟组成的大型鸟群。起飞时，鸟儿有时会以协调的方式飞行，表演不断变化的机动动作，这些动作可以类似于单一生物的运动。为实现这一目标，所有鸟类都通过观察附近的鸟来协调它们的努力；一项2013年的研究发现，椋鸟通过视觉上将其飞行与最近的六七只鸟同步，从而如此紧密地集群成群。有时，鸟儿似乎进行群飞既为了骚扰也为了躲避猎鹰或鹰等空中掠食者，一只快速移动的猛禽常常可以出现在这些佯动、扭曲的鸟群的外围。
