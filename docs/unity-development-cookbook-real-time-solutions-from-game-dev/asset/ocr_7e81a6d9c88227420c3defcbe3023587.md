public static float ClampAngle(float angle, float min, float max)
{
    // Wrap the angle at -360 and 360
    if (angle < -360F)

    return Mathf.Clamp(angle, min, max);

# ## Discussion

This kind of camera is sometimes referred to as a “chase camera.” We do most of the work in the LateUpdate function here, because we want to make sure that the camera is in the correct position if the object it’s tracking has its position change in the Update function.
