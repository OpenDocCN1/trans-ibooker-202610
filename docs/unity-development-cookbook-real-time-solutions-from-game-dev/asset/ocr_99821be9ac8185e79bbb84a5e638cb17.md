# Discussion

If you don't have your own textures to use, there are a number of good, free sites that offer textures with usable licenses. For example, ambientCG offers high-resolution textures available under a Creative Commons Zero (CC0) license, which allows you to use its textures for commercial and noncommercial purposes.
