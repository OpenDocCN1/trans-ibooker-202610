**Jon Manning 博士** 是 Secret Lab 的联合创始人，Secret Lab 是一家独立游戏开发工作室。他为 O’Reilly Media 撰写了大量关于 iOS 开发和游戏开发的书籍，并拥有关于“互联网上的混蛋”的博士学位。他参与开发了顶视解谜游戏 *Button Squid* 以及广受好评的冒险游戏 *Night in the Woods*，其中包含他开发的交互式对话系统 Yarn Spinner。可以在 Twitter 上找到他 @desplesda，或访问 http://desplesda.net。

**Tim Nugent 博士** 自称是移动应用开发者、游戏设计师、博士生，甚至自称是作者。当他不忙于避免被发现是骗子时，他大部分时间都在设计和创建不让任何人看到的小型应用和游戏。Tim 撰写这段简短的简历花了不成比例的长时间，大部分时间都在试图加入一个机智的科幻引用，后来他放弃了。可以在 Twitter 上找到他 @The_McJones。
