# Discussion

Enabling Unity to understand your custom file types opens a world of possibilities. If you, for example, built an external level editor that exported a level file, this system would allow you to equip the Unity editor with the ability to read your file.

> **TIP**
> 
> The Unity community has built importers for lots of common file formats that Unity doesn’t necessarily support out of the box. If you’re missing a file format feature, search the internet before trying to implement it yourself!
