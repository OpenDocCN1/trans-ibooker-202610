# # 6.10 Creating a Shader Using the Shader Graph

# ## Problem

You want to use Unity's Shader Graph tool to create new shaders, with which you can create your own custom materials.

# ## Solution

Create a new shader by opening the Assets menu and choosing Create → Shader → URP → Lit Shader Graph. Name the new shader.

You'll see a new shader graph with a single node (Figure 6-13). Click Save Asset, and your shader is ready for use in a material.
