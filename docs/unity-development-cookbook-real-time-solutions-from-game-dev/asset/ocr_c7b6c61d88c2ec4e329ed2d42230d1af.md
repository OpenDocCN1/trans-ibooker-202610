# Discussion

When a game object that has a `CharacterCollider` component attached touches a `Collider`, scripts on that game object that implement the `OnControllerColliderHit` method are notified. This method receives a `ControllerColliderHit` parameter, which contains information about the “collision.” It’s not a real collision, because there might not be a rigidbody involved, but similar information can be accessed about the event.
