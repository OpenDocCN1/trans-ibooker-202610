# Discussion

One of the most important components of the animation system is the animator controller. The animator controller lets you control which animation clip(s) are currently playing, structured into a flowchart-style diagram of when and how each animation clip should play.

> TIP
> 
> The animator controller is a state machine. Learn more about state machines and animation in the Unity manual.
