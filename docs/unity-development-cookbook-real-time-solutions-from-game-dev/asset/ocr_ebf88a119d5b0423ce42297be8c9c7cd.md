# 5.7 Using the Sprite Packer

# Problem

You want to pack multiple sprites into a single texture to save on wasted space.

# Solution

To use the sprite packer:

+   1. Create a new Sprite Atlas by opening the Assets menu and choosing Create → Sprite Atlas.
+   
+   2. Drag the sprites you want to be grouped together into the Objects for Packing list. You can drag folders as well.
