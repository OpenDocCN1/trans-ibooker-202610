The cost of rendering a scene multiple times is also why games designed for virtual reality need to be more careful with their performance. # 6.22 Faking a Dynamic Emissive Object

# Problem

You have a real-time object that has an emissive color, and you want it to illuminate other objects.

# Solution

Fake it. Create a real-time light, and add it as a child. Make it the same color as your emissive light, and, if you place it right, the player won’t realize that the emissive light isn’t what’s lighting up other objects.
