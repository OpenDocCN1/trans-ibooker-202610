The Path drop-down lets you configure which specific physical control
should be bound to the action. You can have as many bindings as you
like; if you open the Move action, for example, you’ll see a large
number of bindings, each for different kinds of input devices.

The By Location of Key path allows you to specify a *location* on the
keyboard. In this example, we’ll set it to whatever key is at the
position the C key has on a US-layout keyboard.
