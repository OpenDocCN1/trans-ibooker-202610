# ## Problem

You want to use a state machine, which is a programming pattern that lets you manage the various possible object states.

# ## Solution

Create a new C# script called `StateMachine.cs`, and add the following code to it:

```
```csharp
// Manages a collection of states, which can be transitioned from and to.
public class StateMachine {
    // A single state.
    public class State
    {
        // The state's visible name. Also used to identify the state to
        // the state machine.
        public string name;

        // Called every frame while the state is active.
        public System.Action onFrame;
    }
}
```
```
