## 前言

欢迎使用《Unity 开发指南》第二版！过去二十年里，实时 3D 和游戏开发工具不断进步，越来越多的人正在从事各种项目，从大型“3A”游戏到由个人利用业余时间开发的业余项目。

我们非常兴奋能够更新此书，也为我们的工作感到无比自豪。希望本书能成为你使用 Unity 引擎进行软件开发时的得力助手。自 2007 年我们开始使用 Unity 以来，它已经走得很远，而且你使用得越多，就会想出越多关于如何使用它、为什么使用它等等的新点子！这一切都非常令人兴奋。相信我们，我们也经历过这些。

在 Secret Lab，我们使用 Unity 构建大部分视频游戏。我们最知名的是在澳大利亚开发儿童游戏，以及荣获 BAFTA 和 IGF 大奖的 *夜林奇境*（Finji）和大受欢迎的 *纱线旋转器* 工具。自从发现 Unity 以来，我们就从未停止使用它。

在本书中，我们收集了一系列配方，用于解决我们在使用 Unity 构建项目时反复遇到的常见问题。本书不会涵盖你想了解的关于 Unity 的每一个微小细节，但希望能覆盖你在视频游戏开发日常工作中要做的大部分事情。本书第二版增加了大量新内容，基于自上一版以来 Unity 采用的变化，并更新了所有已更改的内容。Unity 发展并不十分迅速，但保持与时俱进很重要。

这些配方涉及我们当初首次使用 Unity 时希望有人可以咨询的问题。我们真心希望它们能帮助你！

使用 Unity 是一段非常令人兴奋的时光。实时和游戏开发世界每天都在变得更大、更有趣，我们使用的工具和技术也比以往更好。去创造伟大的东西吧！

## 本书结构

本书分为 13 章：

- 第 1 章，“在 Unity 中工作”，介绍你使用 Unity 所需了解的基本概念：游戏对象、组件、场景，以及如何使用 Unity 编辑器本身。

- 第 2 章，“脚本编写”，介绍 Unity 的脚本接口，这是你编写定义项目运行方式的实际代码的方法。在建立基础后，我们将深入一些实际示例，包括如何编写保存和加载系统、如何高效地处理对象，以及如何以你的代码和 Unity 都能轻松使用的方式存储数据。

- 在第 3 章，“输入”中，你将学习如何以键盘输入、鼠标和游戏手柄的形式从用户那里获取输入。我们还将讨论如何设置对输入事件做出反应的游戏对象，例如用户单击它们。

- 第 4 章，“数学”，介绍在游戏开发中有用的一些数学概念的基础知识，例如向量、矩阵和四元数。我们还将探讨这些概念的一些实际用途，例如检测对象是否在玩家面前。

- 第 5 章，“2D 图形”，讨论 Unity 内置的 2D 图形和物理系统。你将学习如何显示精灵、对它们进行排序，并使它们相互反弹。

- 第 6 章，“3D 图形”，介绍 Unity 的材质和着色系统：材质和着色器的工作原理，如何在 Unity 中构建着色器，以及如何在场景中获得最佳效果。

- 在第 7 章，“3D 物理和角色控制”中，你将学习如何让 Unity 的 3D 物理系统按你需要的方式运行，以支持常见的游戏玩法任务，例如捡起和投掷对象，以及创建玩家可以乘坐的移动平台。

- 第 8 章，“动画和运动”，介绍 Unity 中使用的动画系统，并涵盖如何设置角色在不同动画状态之间混合，以及如何将玩家移动与角色动画集成等主题。我们还将介绍 Unity 中的摄像机系统，并讨论如何设置可以跟随目标移动的摄像机。

- 第 9 章，“逻辑和游戏玩法”，全关于创建玩家交互的游戏玩法。这里包含了广泛的常见游戏玩法任务，例如管理你给予玩家的任务的状态、跟踪赛车是否走捷径太多，以及管理游戏中对象之间伤害的处理方式。

- 在第 10 章，“行为、模拟和 AI”中，你将学习如何为角色增加“大脑”，包括检测玩家何时可见的能力、在空间中导航并避开障碍物的能力，以及找到他们无法被看到的位置的能力。本章还简要探讨了使用 Unity 进行模拟，以及使用机器学习技术实现真正的 AI。
- 第 11 章，“声音和音乐”，介绍 Unity 中的音频系统。我们将介绍播放声音的基础知识，然后继续介绍更高级的功能，例如将音频路由到多个组，以及在角色说话时自动降低音乐音量。
- 第 12 章，“用户界面”，介绍构建玩家可以查看和交互的界面的工具。本章还有一节关于如何通过扩展编辑器在 Unity 中构建自己的工具。
- 第 13 章，“文件、网络和截图”，我们的最后一章，探讨网络、从网络获取数据以及从代码保存截图。
