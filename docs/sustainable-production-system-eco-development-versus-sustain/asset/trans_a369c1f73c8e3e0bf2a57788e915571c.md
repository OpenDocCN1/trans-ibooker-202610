这种在两个功能生态系统之间的分析耦合方法还意味着克服某些障碍，这些障碍与当前的地域邻近性（空间、组织、制度）相关。产生并受益于功能优势的活动不属于同一部门这一事实，可能导致在绩效的认可、支持和提升方面出现社会学、技术或监管方面的限制。

进而有必要解锁用于表征生产性现象的时间性和空间的框架：建筑回收或再利用的盈利性在微观层面有时并不立即显现，而这些活动的绩效对于部门层面的盈利性却是必要的。
