## Preface





在过去几年里，世界各地的更多组织在构建云端可扩展且可靠的应用时开始采用无服务器计算范式。用于在各种云平台上管理无服务器应用的工具和支持也得到了显著改善。为了支持无服务器计算服务和架构的增加采用，亚马逊网络服务（AWS）、微软 Azure 和 Google Cloud 等云平台通过在产品中增加服务和功能，不断推动无服务器计算的极限。尽管如此，无服务器和云计算采用率的增加也提高了数据泄露的风险，因为越来越多的公司将数据存储在云中，却没有对无服务器和云安全有充分的理解。

尽管存在这些趋势，无服务器安全知识和专业技能仍存在很大差距。安全专业人员仍在追赶针对云中无服务器应用进行攻击和保护的不断演进的技术组合。本书旨在弥合这一差距，通过深入探讨在处理现代无服务器架构时所涉及的进攻性和防御性安全策略。

## 谁应该阅读本书

本书面向负责管理、审计和保护其云基础设施的安全工程师、云工程师、开发人员、安全架构师和渗透测试人员。本书面向具有使用云服务经验的专业人士，他们计划深入研究云和无服务器安全。

预计你对云计算和安全概念有良好的理解。具备无服务器计算的基础知识以及 AWS、Google Cloud 和 Azure 的基本服务知识会有所帮助。了解或使用安全工具的知识或经验是可选的。

## 我为何撰写本书

尽管无服务器计算的采用率不断提高，但相对较少的书籍和资源关注无服务器应用和系统的安全。凭借影响技术未来的机会，我决定撰写本书，帮助下一代技术专业人员在云中构建更安全的应用程序。我希望本书能成为那些有兴趣了解更多无服务器安全策略和最佳实践的人的有用资源。

## 如何阅读本书

以下是本书涵盖内容的概要：

第 1 章，“无服务器计算简介”，和 第 2 章，“理解无服务器架构和实现模式”

：
我将阐明无服务器计算是什么，涵盖常见的神话和误解，并为你概述无服务器应用如何在 AWS、Azure 和 Google Cloud 上实现。为了帮助你了解无服务器计算的核心原则在实践中如何应用，你将探索无服务器架构中使用的最常见构建块、模式和解决方案，并在过程中审视相关的安全考虑。

第 3 章，“深入探讨无服务器安全威胁和风险”

：
你将在此基础上构建你在前两章中学到的知识，并探索与无服务器应用相关的安全考虑。为了拓宽你对无服务器安全的理解，你将深入研究与无服务器计算相关的各种安全威胁和风险。

第 4 章，“利用和保护暴露的 AWS IAM 凭证”，第 5 章，“利用和保护配置错误的 AWS IAM 角色”，第 6 章，“入侵公开可访问的 AWS Lambda 函数”，和 第 7 章，“在 VPC 中运行和保护无服务器函数”

：
你将专注于 AWS 无服务器安全，并亲身体验攻击者如何利用无服务器应用中的配置错误和漏洞。你还将学习保护在 AWS 上运行的无服务器应用的各种组件和构建块的最佳实践。

第 8 章，“入侵和保护 Google Cloud Storage 存储桶”，第 9 章，“通过恶意文件上传滥用 Google Cloud Storage 事件触发器”，和 第 10 章，“在 Google Cloud 中设置后门和提升权限”

：
你将专注于 Google Cloud 中无服务器环境的安全。你将检查常见的云存储桶配置错误、事件触发器如何通过恶意文件上传被利用，以及攻击者如何设置后门并提升权限。此外，你将学习如何识别你在 Google Cloud 上运行的无服务器应用中的漏洞和配置错误，以便领先攻击者一步。

第 11 章，“入侵和保护 Azure Functions”，第 12 章，“在 Microsoft Azure 中提升权限”，和 第 13 章，“分析、审计和保护无服务器应用代码”

：
你将专注于 Azure 无服务器安全，并深入探讨攻击者如何利用无服务器函数中的配置错误和漏洞。你将探索特定于 Azure 的权限提升技术，并使用各种工具和方法分析你的无服务器应用代码及其依赖项。这些章节将共同完成你对无服务器安全的探索，涵盖前几章未充分涉及的领域，帮助你保护无服务器应用和系统免受更广泛的攻击。
