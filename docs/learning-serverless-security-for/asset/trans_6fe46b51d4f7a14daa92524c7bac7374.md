# 对 *Learning Serverless Security* 的赞誉

> 一本面向有志于从事无服务器安全实践者的卓越入门指南。从高层次介绍到动手实验和深入剖析，本书加速了非 IT 初学者和高级从业者的学习——让以下内容人人可及：复杂的网络安全概念、缓解措施，以及坦白说，甚至黑客技术！
>
> Jasper Riane D. Mendoza，亚马逊网络服务全球公共部门高级解决方案架构师

> 这本书是 DevSecOps 专业人士、应用安全工程师和 AppSec 渗透测试人员的必备之作。Joshua 在深入探讨如何利用它们进行实际攻击，例如权限提升和创建后门之前，先介绍了无服务器应用中的当前威胁和漏洞。他真的很了解攻击者如何思考以及如何保护你的资产。
>
> Jay Turla，首席安全研究员（汽车）

> 本书提供了无服务器安全的深入实践演练，从身份访问配置错误和暴露的函数到模式和事件驱动攻击。对于在主要云平台上保护真实工作负载的工程师来说，这是一份宝贵的资源。
>
> Rafi Quisumbing，获奖 AWS Hero、兼职 CTO 和云顾问

> 作为曾在学术界、政府和行业工作的人，我认为这本书是理论与实践之间罕见的桥梁，并珍视它在阐明无服务器风险方面提供的清晰度。通过实践见解，复杂威胁变得易于理解。
>
> Mars Cacacho，网络安全高级经理、创始人，Hackthenorth.ph

> 一本关于无服务器安全的优秀入门读物。本书教会你，保护无服务器应用不仅仅是保护你的函数、云存储资源和访问密钥。它展示了攻击者如何以不同方式入侵在 AWS、Google Cloud 和 Azure 上运行的云应用。
>
> Raphael Jambalos，应用现代化与安全负责人，eCloudValley Philippines

> 这本书不仅仅解释无服务器安全——它以实践方式演示它。通过引导读者了解逼真的攻击路径和具体的缓解措施，*Learning Serverless Security* 使工程师能够像构建者一样思考，也像攻击者一样思考。
>
> Adelen Festin，软件工程师

> 随着 AI 编程工具加速无服务器开发，安全已成为关键差异化因素。本书为 vibe 编码者、开发人员、安全工程师和架构师配备了在 AI 辅助开发时代防御应用所需的跨多云专业知识。
>
> Jason Torres，创始人，BetterGov.ph

> Joshua 提供了在所有主要云平台上进行无服务器安全的基本实践培训。精心设计的易受攻击实验室出色地演示了攻击和防御技术。这种实践方法将安全理论转化为可操作的技能，是云架构师和安全专业人员的必读之作。
>
> Diwa “Wawi” del Mundo，Apper Digital, Inc. 创始人（AWS 高级服务合作伙伴、Google Cloud 合作伙伴）

> 一本结构良好且及时的无服务器安全指南。风险评估和控制措施切实可行、相关且易于应用。这是一本既能让经验丰富的网络安全专业人士受益，也能让新手受益的书。
>
> Felix Marasigan，安全运营中心负责人，G-Xchange Inc.（GCash）

> 终于有一本出色的实践指南，解决了 AWS、Azure 和 Google Cloud 上无服务器应用的各种安全挑战！书中包含大量真实案例，包括保护 AI 驱动的无服务器应用的步骤，在当今 AI 驱动的行业中尤其相关。
>
> Jon Bonso，CEO，Tutorials Dojo

> 在 AWS 上使用无服务器技术五年后，我印象深刻的是这本书总结了你需要了解的关于无服务器的一切：架构模式、访问控制、最佳实践，甚至黑客技术。
>
> Seaver Choy，工程总监，First Mate Technologies

> 这本书对无服务器安全进行了耳目一新的解读。它超越了通常的“保护你的函数”叙事，而是审视了身份、存储、网络、CI/CD 和应用代码如何在真实的无服务器系统中协同工作的全貌。它在服务和软件层之间建立联系，表明安全不是你附加到无服务器函数上的东西，而是你在整个架构中设计的东西。它切合实际、富有洞察力，并以无服务器在生产环境中的实际运作方式为基础，而不仅仅是其营销方式。
>
> Michael Angelo C. Rayco，全球云解决方案架构师，国际水稻研究所
