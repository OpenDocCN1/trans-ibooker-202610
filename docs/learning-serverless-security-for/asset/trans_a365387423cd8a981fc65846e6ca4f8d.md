

在过去几年里，世界各地的更多组织在构建云端可扩展且可靠的应用时开始采用无服务器计算范式。用于在各种云平台上管理无服务器应用的工具和支持也得到了显著改善。为了支持无服务器计算服务和架构的增加采用，亚马逊网络服务（AWS）、微软 Azure 和 Google Cloud 等云平台通过在产品中增加服务和功能，不断推动无服务器计算的极限。尽管如此，无服务器和云计算采用率的增加也提高了数据泄露的风险，因为越来越多的公司将数据存储在云中，却没有对无服务器和云安全有充分的理解。

尽管存在这些趋势，无服务器安全知识和专业技能仍存在很大差距。安全专业人员仍在追赶针对云中无服务器应用进行攻击和保护的不断演进的技术组合。本书旨在弥合这一差距，通过深入探讨在处理现代无服务器架构时所涉及的进攻性和防御性安全策略。

# 谁应该阅读本书

本书面向负责管理、审计和保护其云基础设施的安全工程师、云工程师、开发人员、安全架构师和渗透测试人员。本书面向具有使用云服务经验的专业人士，他们计划深入研究云和无服务器安全。

预计你对云计算和安全概念有良好的理解。具备无服务器计算的基础知识以及 AWS、Google Cloud 和 Azure 的基本服务知识会有所帮助。了解或使用安全工具的知识或经验是可选的。

# 我为何撰写本书

尽管无服务器计算的采用率不断提高，但相对较少的书籍和资源关注无服务器应用和系统的安全。凭借影响技术未来的机会，我决定撰写本书，帮助下一代技术专业人员在云中构建更安全的应用程序。我希望本书能成为那些有兴趣了解更多无服务器安全策略和最佳实践的人的有用资源。
