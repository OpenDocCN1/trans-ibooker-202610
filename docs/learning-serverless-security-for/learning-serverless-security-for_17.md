## 关于作者

**Joshua Arvin Lat** 是 NuWorks Interactive Labs, Inc. 的首席技术官（CTO）。他曾担任三家澳大利亚公司的 CTO，并担任多家电子商务初创公司的软件开发和工程总监。多年以前，他和他的团队凭借发表的研究论文在全球网络安全竞赛中获得第一名。他是 AWS AI Hero，并撰写了多本技术书籍，包括 *Machine Learning with Amazon SageMaker Cookbook*、*Machine Learning Engineering on AWS* 和 *Building and Automating Penetration Testing Labs in the Cloud*。由于他在组织数字化转型方面的卓越记录，他被评为享有盛誉的 Orange Boomerang：2023 年度数字领袖奖获得者之一。
