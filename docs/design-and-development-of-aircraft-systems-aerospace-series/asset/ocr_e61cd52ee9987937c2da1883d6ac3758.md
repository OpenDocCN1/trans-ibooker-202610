# Table 12.60 Electronic warfare system characteristics.

| System title | Electronic warfare |
|---|---|

| Description | Antennas to detect a wide spectrum of signals for COMINT and identification of radars for SIGINT. |

| Key integration aspects | Antenna integration, mission computing, on-board intelligence database. |
