# 5.4 Architecture Modelling and Trade-off

An example of a fuel system is given to show how architectures can be used to define a system that can be used to seek the optimal solution using modelling and trade-off techniques. The fuel system performs a number of functions specific to the carriage and use of fuel. It is generally considered safety critical in that total loss of fuel to the aircraft engines may be catastrophic. Fuel is used by the auxiliary power unit (APU) and the main engines, and it has some subsidiary roles. It is used by the flight control system to control the aircraft centre of gravity within certain limits and it is used in the aircraft cooling system as a cooling medium, for example fuel-cooled oil coolers and heat exchangers.
