Quadrax - airbus

Airbus and boeing adopt different installation strategies for ethernet/AFDX - type wiring:

+   - Airbus adopt the quadrax approach using 24 AWG wires — fewer connectors and wires

Twinax - boeing

+   - Boeing adopt the twinax approach using 22 AWG wires — more connectors and wires; heavier; more robust ?
