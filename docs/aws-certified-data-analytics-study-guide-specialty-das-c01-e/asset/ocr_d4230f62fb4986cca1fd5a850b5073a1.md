Security is essential from an IoT perspective when your devices have to connect to the AWS IoT service; authentication and authorization becomes critical. AWS IoT Core provides identity service for authentication and end-to-end encryption throughout all points of connection so that data is never exchanged between devices and AWS IoT without proven identity. You can secure access to your devices and applications by applying policies with granular permissions.
While AWS IoT was a critical part of the AWS Big Data Specialty exam, it is not a core service that you will be tested on in the new AWS Data Analytics Specialty certification exam, and hence we are not going to spend more time on it during this book.
