# Apache HBase on Amazon EMR

*HBase* is a distributed column-oriented store, which is built on top of HDFS and used when you need real-time read/write random access to extremely large datasets, which is typically not possible with MapReduce and Apache Spark.

HBase is built with the intent of linear scalability and is one of the most popular NoSQL databases. It does not support SQL out of the box; however, you can run SQL on HBase with projects like Apache Phoenix.
