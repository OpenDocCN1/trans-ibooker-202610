# Accelerated Log and Data Feed Intake and Processing

Quite often web servers, application servers and IoT devices produce logs that need to be captured as soon as they are created. Kinesis Data Streams allows you to capture this data in low latency and process it in real-time fashion, thus protecting you from server, disk failures, and data loss.
