# Data Replication in Amazon S3

Amazon S3 can automatically replicate your data inside an S3 bucket to a bucket in the same account or a different account. You can also copy objects within the same AWS Region using same-region replication (SRR) or between different AWS Regions using cross regional replication (CRR). See Table 3.1 for more information. You can use replication to do the following:

+   - Replicate objects including metadata like creation time, version IDs, etc.
+   - Replicate objects to a different storage class.
+   - Change ownership of the replicated objects.
+   - Replicate objects using Replication Time Control (RTC) in a predictable time frame (99.99 percent of the objects can be replicated within a 15-minute interval).

# TABLE 3.1 Same-region replication (SRR) vs. cross-region replication (CRR)

| Same-Region Replication | Cross-Region Replication |
|---|---|
| Aggregate logs into a single bucket for simpler processing. | Meet compliance requirements. |
| Replicate data between production and test accounts. | Minimize latency for customers in different geographical locations. |
| Honor data sovereignty laws and compliance requirements. | Optimize performance for computation needed in multiple AWS Regions. |
