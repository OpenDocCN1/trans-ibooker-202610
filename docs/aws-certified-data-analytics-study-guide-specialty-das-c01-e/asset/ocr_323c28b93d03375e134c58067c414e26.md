Amazon Aurora with cutting-edge features, or you may even want to upgrade underlying infrastructure while keeping the same database engine. It supports a number of different databases as source databases:

+   - Oracle
+   - Microsoft SQL Server
+   - MySQL
+   - MariaDB
+   - PostgreSQL
+   - Db2 LUW
+   - SAP
+   - MongoDB
+   - Amazon Aurora

And a number of databases as targets:

+   - Oracle
+   - Microsoft SQL Server
+   - PostgreSQL
+   - MySQL
+   - Amazon Redshift
+   - SAP ASE
+   - Amazon S3
+   - DynamoDB

AWS DMS supports secure migrations using the following:

+   - KMS for encryption of data at rest
+   - SSL for data in motion

To learn more about AWS DMS, please visit amzn.to/2Vvfj6i.
