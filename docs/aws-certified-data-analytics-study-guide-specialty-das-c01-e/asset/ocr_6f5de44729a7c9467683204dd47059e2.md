# # Amazon FSx for Lustre

While Amazon provides a number of options for compute-intensive workloads, there are cases where the current file systems like EFS are unable to handle the needs to quickly scale out to millions of cores reading in excess of 100 Gb/s per core. This is typical with grid-computing architectures and some analytics applications working on big data looking to process the results instantaneously.
