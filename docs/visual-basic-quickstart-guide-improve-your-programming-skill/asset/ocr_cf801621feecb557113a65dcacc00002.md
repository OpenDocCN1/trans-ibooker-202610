```
Dim curDate
curDate = Date()
Dim fDate
fDate = FormatDateTime(curDate, vbShortDate)
WScript.Echo fDate
```

The FormatDateTime function formats the date and time according to the custom format provided.

You can use various predefined constants and custom format strings with the FormatDateTime function to achieve the desired formatting for dates and times. The predefined constants are vbGeneralDate, vbLongDate, vbShortDate, vbLongTime, and vbShortTime. Custom format strings can include multiple placeholders such as yyyy for the year, MM for the month, dd for the day, hh for the hour, mm for the minute, ss for the second, and AM/PM for the time indicator.
