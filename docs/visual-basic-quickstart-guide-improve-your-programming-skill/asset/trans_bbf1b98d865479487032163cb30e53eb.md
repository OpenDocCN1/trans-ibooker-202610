## 关于作者

**Aspen Olmsted** 是温特沃斯理工学院计算机科学系的副教授和项目主任。他获得了南卡罗来纳大学的计算机科学与工程博士学位。在学术生涯之前，他曾担任 Alliance Software Corporation 的首席执行官。Alliance Software 为表演艺术和人文学科市场开发了 N 层企业应用程序。Olmsted 博士的研究重点是开发分布式企业解决方案的算法和架构，在保证安全性和正确性的同时保持高可用性。Aspen 每年在他的安全数据工程实验室指导十多名研究生和本科生。
