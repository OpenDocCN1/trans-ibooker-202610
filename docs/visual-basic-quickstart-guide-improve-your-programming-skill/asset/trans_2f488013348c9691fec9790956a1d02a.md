## 前言

在本书中，你将学习 Visual Basic 语言及其所有不同的用例。这一旅程将使你能够运用这些知识来维护、增强、管理和保护 Visual Basic 控制台或 Windows 应用程序、Visual Basic 网站或 Visual Basic 脚本。本书基于这样一个认识：许多程序员将需要因各种不同目的而使用 Visual Basic。在每一章中，我们都会突出介绍 Visual Basic 所用于的各种不同用例的主题。

在学习一门新语言的编程时，你总是需要给自己时间来消化这些概念。对一个主题的多次重复有助于在脑海中巩固它。为了充分利用本书，建议你在阅读时打开电脑。另一种极好的方法是先读一章，然后到电脑前，亲自输入这些示例来重新回顾。

我也鼓励你深入挖掘自己的创造力，思考如何将我们讲解的技能应用于一个创造性项目中。我在本书的最后一章中提出了几个项目建议，但你应该尝试找到对自己有意义的内容。祝你好运！

## 本书面向的读者

如果你从事软件工程、信息技术或网络安全工作，并且需要维护、增强、管理或保护 Visual Basic 控制台或 Windows 应用程序、Visual Basic 网站或 Visual Basic 脚本，那么本书适合你。

在撰写本书时，微软正在减少对 Visual Basic 的投入。尽管如此，仍有许多软件开发工作涉及维护、增强、管理和防御 Visual Basic 程序、网站和脚本。这些工作在未来几十年内仍将持续存在。本书面向那些正在从事或希望获得这类工作的软件开发和 Web 开发人员。本书以简洁的方式介绍了 Visual Basic 的所有不同用例。

## 本书涵盖内容

第1章，Visual Basic 编程语言家族，概述了 VB 及其多年来的用例。

第2章，控制台输入与输出，教你如何获取键盘输入并将计算结果发送到计算机屏幕。

第3章，数据类型与变量，讨论程序执行期间在计算机内存中存储数据的不同方式。

第4章，决策分支，讲解如何根据外部环境（例如用户输入）在代码内部构建不同的路径。

第5章，迭代，展示了如何重复执行代码段，要么固定次数，要么直到环境处于特定状态。

第6章，函数与过程，重点讨论将代码段模块化以供复用。这使得只需要维护执行特定功能的一份代码副本，从而更容易减少 bug。

第7章，项目第一部分，让你能够运用到目前为止所学的编程技能。

第8章，格式化与修改数据，探讨重新排列数据以用于显示或外部保存的概念。

第9章，文件输入与输出，演示如何从磁盘驱动器上的文件读取数据以及向文件写入数据。

第10章，集合，讨论在一个变量中存储多个值，然后在代码中访问这些变量。

第11章，项目第二部分，提供了一个应用我们目前所学编程技能的机会。

第12章，面向对象编程，讲解如何将代码组织为对象。每个对象可以拥有状态和可执行的操作。

第13章，继承，教我们如何通过创建分类体系来复用代码，在树中较高层指定通用功能。

第14章，多态，向我们展示了如何让 VB 在运行时根据正在运行的程序的上下文执行正确版本的某个方法。

第15章，接口，通过为后续开发但由我们的代码执行的实现定义契约，来探索代码复用。

*第16章*，*项目第三部分*，让我们能够应用到目前为止所学的编程技能。

*第17章*，*请求与响应模型*，讨论了 Web 应用程序的通信模型，以及我们如何在应用程序的各分区之间发送消息。

*第18章*，*变量作用域与并发*，探讨了如何处理 Web 应用程序中的多用户。

*第19章*，*项目第四部分*，提供了尝试我们所学的最后机会。

*第20章*，*结论*，回顾了所涵盖的主题，并提出了进一步学习和项目的建议。
