# Small Buffer Optimization (SBO)

Let us start our quest to speed up the performance of our Type Erasure implementation. One of the first things, that usually comes to mind when talking about performance, is to optimize memory allocations. This is because acquiring and freeing dynamic memory can be very sloooww and nondeterministic. And for real: optimizing memory allocations can make all the difference between slow and lightning fast.

However, there is a second reason to look into memory. In “Guideline 32: Consider Replacing Inheritance Hierarchies with Type Erasure” I might have accidentally given you the impression that we need dynamic memory to pull off Type Erasure.
