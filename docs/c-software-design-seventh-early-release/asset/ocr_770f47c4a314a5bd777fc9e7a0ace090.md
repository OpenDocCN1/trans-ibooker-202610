This chapter is devoted to two of the most commonly used design patterns: the *Strategy* design pattern and the *Command* design pattern. Most commonly used indeed: the C++ standard library itself uses both of them dozens of times and it is very likely that you have used them many times yourself before. For that reason, both of these can be considered fundamental tools for every developer.
