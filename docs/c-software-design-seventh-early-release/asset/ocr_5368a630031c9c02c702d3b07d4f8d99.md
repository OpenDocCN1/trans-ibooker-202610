the original price of the book needs to be adapted by means of a given tax rate. In this example, I assume an imaginary tax rate of 15%.

The ConferenceTicket class is the second example for an Item:

```
//---- <ConferenceTicket.h> ----------------

#include <Item.h>
#include <string>

class ConferenceTicket : public Item
{
public:
    explicit ConferenceTicket( std::string name, Money price )
        : name_( std::move(name) )
        , priceWithTax_( price * 1.15 )  // 15% tax rate
    {}

    std::string const& name() const { return name_; }

    Money price() const override { return priceWithTax_; }

private:
    std::string name_;
    Money priceWithTax_;
};
```

ConferenceTicket is very similar to the CppBook class, but only expects the name of the conference and the price in the constructor (7). Of course you can access the name and the price by means of the name() and price() functions, respectively. Most importantly, however, the price for a C++ conferences is also subject to taxes. Therefore, we again adapt the original price by the imaginary tax rate of 15%.
