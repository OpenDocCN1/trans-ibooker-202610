However, the physical dependency of `Document` on the selected JSON library, and the direct dependency on the `ByteStream` class, cause an indirect, transitive dependency of `User` to the JSON library and `ByteStream`, which reside on the highest level of our architecture.²⁶ In the worst case, this means that changes to the JSON library or the `ByteStream` class have an effect on `User`. It is hopefully easy to see that this is not an intentional, but an artificial dependency: a `User` should not have to depend on JSON or serialization.
