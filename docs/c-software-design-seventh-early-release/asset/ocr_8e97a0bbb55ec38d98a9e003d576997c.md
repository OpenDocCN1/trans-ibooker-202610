```
class Square : public Shape
{
  public:
    explicit Square( double side, std::unique_ptr<DrawStrategy>
    drawer ) ⑦
      : side_( side )
      , drawer_( std::move(drawer) ) ⑧
    {
      /* Checking that the given side length is valid and that
         the given std::unique_ptr instance is not nullptr */
    }

    void draw( /*some arguments*/ ) const override
    {
      drawer_->draw( *this, /*some arguments*/ );  ⑩
    }

    double side() const { return side_; }

  private:
    double side_;
    std::unique_ptr<DrawStrategy> drawer_;  ⑨
};
```

Both Circle and Square are now expecting a unique_ptr to a DrawStrategy in their constructors ⑦. This allows us to configure the drawing behavior from the outside, and this is what is commonly called dependency injection. The unique_ptr is moved ⑧ into a new data member of the same type ⑨. Additionally, it is also possible to provide according setter functions, which would allow you to change the drawing behavior at a later point. The draw() member function now does not have to implement the drawing itself, but simply has to call the draw() function for the given DrawStrategy ⑩.⁶
