```
#include <Widget.h>
#include <assert>
#include <cstdlib>
#include <string>

int main()
{
    Widget<std::string> w1{ "Hello" };
    Widget<std::string> w2{ "World" };

    swap( w1, w2 );

    assert( w1.value == "World" );
    assert( w2.value == "Hello" );

    return EXIT_SUCCESS;
}
```

In consequence, the Widget swap() function itself follows the expectations and thus adds to the overload set, similar to what a derived class would do. The dependency structure for the swap() overload set is shown in Figure 2-9: since the requirements, i.e. the expectations, for the overload set, are part of the high-level of the architecture, and, since any implementation of swap() depends on these expectations, the dependency runs from the low-level towards the high-level. The dependency is therefore properly inverted.
