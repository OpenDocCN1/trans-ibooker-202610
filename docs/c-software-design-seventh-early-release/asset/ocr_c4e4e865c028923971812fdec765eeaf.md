This combination of design patterns is particularly interesting if you already have a Strategy implementation in place: while Strategy is intrusive and requires the modification of a class, it is always possible to non-intrusively add a Decorator such as the DecoratedPriceStrategy class. But of course it depends: whether or not this is the right solution is something you will have to decide on a case-by-base basis.
