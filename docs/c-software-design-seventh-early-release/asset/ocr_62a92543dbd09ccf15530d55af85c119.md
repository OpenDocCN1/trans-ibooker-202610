Dolly is great, right? And so cute! In fact, she is so much fun, that we want another Dolly. However, all we have, is a pointer-to-base, i.e. an Animal*. We cannot copy via the Sheep copy constructor or the copy assignment operator, because we (technically) do not even know that we are dealing with a Sheep.
