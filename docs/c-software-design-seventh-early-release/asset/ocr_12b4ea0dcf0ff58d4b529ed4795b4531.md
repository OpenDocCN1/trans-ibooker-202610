This choice of implementation breaks the cyclic dependency. As Figure 4-6 demonstrates, the high level of the architecture does not depend on the concrete shape types anymore. Both the shapes (Circle and Square) and the operations are now on the low-level of the architectural boundary. That means that we can now add both types and operations.
