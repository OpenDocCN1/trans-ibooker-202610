The std::pmr::get_default_resource() function also returns a pointer to a std::pmr::memory_resource, which represents an abstraction for the system-wide default allocator. By default, the returned allocator is the one returned by the std::new_delete_resource() function. However, amazingly, this default can be customized by means of the std::pmr::set_default_resource() function:

```
namespace std::pmr {

memory_resource* set_default_resource(memory_resource* r)
noexcept;

} // namespace std::pmr
```
