在“准则 31：对非侵入式运行时多态使用外部多态”中，我们继续通过从类中提取函数的实现细节来分离关注点。然而，为了进一步减少依赖，我们将把这种关注点分离提升到全新水平：我们不仅会提取虚函数的实现细节，还会通过外部多态设计模式提取完整的函数本身。
