    SystemConfiguration config{ &clock, /*...*/ };

}

# Applying the Strategy Design Pattern

Based on this previous example you should now have an idea how to fix our Database example. As a reminder, the goal is to keep the Database class as the default database implementation, but to make it an implementation detail, i.e. to remove all dependencies on the concrete implementation. All you need to do is to apply the Strategy design pattern to introduce an abstraction, alongside a global point of access and a global point for dependency injection, on the high-level of our architecture.
