# An Example for Violating Expectations

Let us start with a Rectangle base class:

```
class Rectangle
{
public:
    // ...
    virtual ~Rectangle() = default;  ①

    int getWidth() const;  ③
    int getHeight() const;

    virtual void setWidth(int);  ④
    virtual void setHeight(int);

    virtual int getArea() const;  ⑤
    // ...

private:
    int width;  ②
    int height;
};
```

First of all, this class is designed as a base class, since it provides a virtual destructor ①. Semantically that means that a Rectangle represents an abstraction for different kinds of rectangle. And technically that means that you can properly destroy an object of derived type via a pointer to Rectangle.

Second, the Rectangle class comes with two data members: width and height ②. That is to be expected, since a rectangle has two side lengths, which are represented by width and height. The getWidth() and getHeight() member functions can be used to query the two side lengths ③, and via the setWidth() and setHeight() member functions we can set the width and height ④.
