The only way to build a proper plugin architecture is to assign the abstraction to the high-level. That means that the abstraction *must* belong to *you*, not to your fan community. Figure 2-7 demonstrates that this resolves the architectural dependency and frees your Editor class from the dependencies on plugins. This resolves both the *DIP* because the dependency is properly inverted, but also the *SRP* because the abstraction belongs to the high-level.
