## 12.1 模板

### ⚠️ 复制和粘贴

在入门章节中，我们说过不要复制粘贴——但这是一个例外。然而，如果你直接剪切和粘贴，最终会带入你不想要的额外文本。为了快速开始，请访问我们的 GitHub 页面，获取下面显示的[基础模板](http://bit.ly/twd2-bootstrap-base-template)。

如果你不明白特定的 Bootstrap 类有什么作用，请查阅 [Bootstrap 文档](https://getbootstrap.com/docs/4.3/getting-started/introduction/) 以加深理解。

```html
<!DOCTYPE html>

{% load staticfiles %}
{% load tango_template_tags %}

<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1, shrink-to-fit=no">
    <meta name="description" content="">
    <meta name="author"
          content="Mark Otto, Jacob Thornton, and Bootstrap contributors">
    <meta name="generator"
          content="Jekyll v3.8.5">
    <link rel="icon" href="{% static 'images/favicon.ico' %}">
    <title>
        Rango - {% block title_block %}How to Tango with Django!{% endblock %}
    </title>
    <!-- Bootstrap core CSS -->
    <link href="https://getbootstrap.com/docs/4.2/dist/css/bootstrap.min.css"
          rel="stylesheet">
    <!-- Custom styles for this template -->
    <link href="https://getbootstrap.com/docs/4.2/examples/dashboard/dashboard.css"
          rel="stylesheet">
```

如果你仔细查看修改后的 Bootstrap dashboard HTML 源代码，你会注意到其中包含大量由一系列 `<div>` 标签创建的结构。本质上，页面分为两部分：由 `<header>` 标签包含的顶部导航栏，以及由 `<main ...>` 标签表示的主内容窗格。在主内容窗格中，有一个 `<div>` 容纳另外两个 `<div>`，分别用于 `sidebar_block` 和 `body_block`。

上面的代码假定你已经完成了有关用户身份验证的章节，并按照前一章的说明使用了 `django-registration-redux`。如果你还没有完成这两项操作，则需要更新模板，并删除/修改页头导航栏中这些链接的引用。

另外需要注意的是，HTML 模板引用了外部网站来请求所需的 css 和 js 文件。为了使其全部正常工作，你需要连接到互联网，这样在运行 Rango 时样式和 JavaScript 文件才能被加载。

### 离线工作？

与其在 css 和 js 文件中包含外部引用，你可以下载所有相关文件并将它们存储在项目的静态目录中。我们建议将 CSS 文件存储在 `static/css/` 中，将 JavaScript 文件存储在 `static/js/` 中。如果这样做，你需要更新 `bootstrap-base.html`，使用 `{% static '...' %}` 模板函数在本地指向正确的文件。

## 12.2 快速更改样式

为了让 Rango 进行一次急需的改头换面，我们需要更新基础模板，以使用新的 `bootstrap-base.html` 模板。它现在已经可以开始使用了！实现这一目标的方法有很多，其中一种选择是在所有其他模板中将 `base.html` 重命名为 `bootstrap-base.html`。不过，更快捷的解决方案是执行以下操作。

1. 将 `templates/rango/` 中的 `base.html` 模板重命名为 `base-old.html`。
2. 将 `templates/rango/` 中的 `bootstrap-base.html` 模板重命名为 `base.html`。

## 第二章 线性表

线性表是最基本、最常用的一种线性结构。线性表由n（n≥0）个数据元素组成的有穷序列，该序列中所有元素具有相同的数据类型。其中数据元素可以由若干个数据项组成。

线性表的特点是：在数据元素的非空有限集合中，除第一个元素外，其它数据元素有且仅有一个直接前驱；除最后一个元素外，其它数据元素有且仅有一个直接后继。

- 顺序表
- 链表

下面分别介绍线性表的顺序存储和链式存储。

头部消息标记（包括现有的 `<h1>` 标签及其正下方的相应 `<div>`）。

```html
<div class="jumbotron p-4">
    <div class="container">
        <h1 class="jumbotron-heading">Rango says...</h1>
        <div>
            <h2 class="h2">
                {% if user.is_authenticated %}
                    howdy {{ user.username }}!
                {% else %}
                    hey there partner!
                {% endif %}
            </h2>
            <strong>{{ boldmessage }}</strong>
        </div>
    </div>
</div>
```

对于 `<div>` 容器，我们应用了 jumbotron 和 p-4 类。p-4 类控制 [间距](https://getbootstrap.com/docs/4.2/utilities/spacing/)，即 jumbotron 周围的内边距。尝试将内边距改为 p-6 或 p-1，看看会发生什么！你还可以通过专门设置 pt、pb、pr 和 pl 来控制上、下、左、右的空间，而不仅仅是设置 p。

更新所有其他模板，使页面标题封装在 jumbotron 中。这将使整个应用具有一致的外观，这对于专业设计的网站至关重要。

不要忘记更新注册包使用的模板！

成功添加 jumbotron 之后，我们可以继续到两栏布局。这里我们借鉴了 [相册](https://getbootstrap.com/docs/4.2/examples/album/) 布局。虽然它有三列（称为卡片），但我们只需要两列。大多数（即便不是全部）CSS 框架都使用由总共 12 列组成的 [网格布局](https://getbootstrap.com/docs/4.2/layout/grid/)。如果你检查相册布局的 HTML 源代码，会发现在一行中有一个 `<div>` 用于设置卡片的大小。这个 `<div>` 是 `<div class="col-md-4">`，后面跟着 `<div class="card mb-4 shadow-sm">`。这将每张卡片的长度设置为相对于宽度的 4 个单位（共 12 个单位）（4 乘以 3 等于 12）。由于我们需要两张卡片（一张用于最受欢迎的页面，一张用于最受欢迎的类别），所以我们可以将 4 改为 6（即 50%，2 乘以 6 等于 12）。要实现这一点，请再次更新 `index.html` 模板。这一次，我们要替换现有的用于容纳最受欢迎类别和最受欢迎页面的 `<div>` 元素。

```html
<div class="container">
    <div class="row">
        <div class="col-md-6">
            <div class="card mb-6">
                <div class="card-body">
                    <h2>Most Liked Categories</h2>
                    <p class="card-text">
                    {% if categories %}
                    <ul>
                    {% for category in categories %}
                        <li>
```
