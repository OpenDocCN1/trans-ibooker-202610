# There’s More!

There are other more advanced features of Git that we have not covered in this chapter. Examples include **branching** and **merging**, which are useful for projects with different release versions, for example. There are many fantastic tutorials available online if you are interested in taking you super-awesome version control skills a step further. For more details about such features take a look at this [tutorial on getting started with Git](https://veer asundar.com/blog/2011/06/git-tutorial-getting-started/), the [Git Guide](https://rogerdudler.github.io/git-guide/) or [Learning about Git Branching](https://pcottle.github.io/learnGitBranching/).

However, if you’re only using this chapter as a simple guide to getting to grips with Git, everything that we’ve covered should be enough. Good luck!
