def read_bing_key():
    """
    reads the BING API key from a file called 'bing.key'
    returns: a string which is either None, i.e. no key found, or with a key
    remember to put bing.key in your .gitignore file to avoid committing it.

    See Python Anti-Patterns - it is an awesome resource to improve your python code
    Here we using "with" when opening documents
    http://bit.ly/twd-antipattern-open-files
    """
    bing_api_key = None
    try:
        with open('bing.key','r') as f:
            bing_api_key = f.readline().strip()
    except:
        try:
            with open('../bing.key') as f:
                bing_api_key = f.readline().strip()
        except:
            raise IOError('bing.key file not found')

    if not bing_api_key:
        raise KeyError('Bing key not found')

    return bing_api_key

def run_query(search_terms):
    """
    See the Microsoft's documentation on other parameters that you can set.
    http://bit.ly/twd-bing-api
    """
    bing_key = read_bing_key()
    search_url = 'https://api.cognitive.microsoft.com/bing/v7.0/search'
    headers = {'Ocp-Apim-Subscription-Key': bing_key}
    params = {'q': search_terms, 'textDecorations': True, 'textFormat': 'HTML'}

    # Issue the request, given the details above.
    response = requests.get(search_url, headers=headers, params=params)

## 14. 使 Rango 更具 Tango 风格的练习

到目前为止，我们已向 Rango 添加了多个关键功能。我们以一种希望能让你熟悉使用 Django 框架并学习如何构建现代 Web 应用的各种部分的方式构建应用。

然而，目前 Rango 并不是非常连贯或互动的。在本章中，我们挑战你通过整合我们已实现的一些功能以及一些新功能，进一步改进应用及其用户体验。为了使 Rango 更连贯、集成和互动，让我们来看一下实现以下功能的实现。

在 Rango 的 Category 和 Page 模型中，我们包含了 views 字段。然而，我们尚未使用它们，所以为什么不实现跟踪对这两种内容类型的浏览量的功能呢？具体来说，我们将关注：

- 统计某个分类被查看的次数；以及
- 统计从 Rango 分类视图中点击某个页面的次数。

我们还希望为不同的分类收集点赞数，这是我们尚未实现的功能。我们将使用 AJAX 来实现这一点（参见 [Django 中的 AJAX](#)）。我们还将使用 AJAX 允许用户过滤他们在左侧分类栏中看到的分类。

除了这些新功能外，我们还将努力为 Rango 的注册用户提供更多服务。具体来说，我们将努力：

- 允许注册网站的用户再次指定个人资料图片和网站（如果你完成了 [django-registration-redux 章节](#)，此功能将会丢失）；
- 让用户查看和编辑他们的个人资料；以及
- 让已登录的用户查看其他用户及其个人资料的列表。

### 14.1 跟踪页面点击

目前，Rango 为外部页面提供直接链接。虽然简单，但这种方法不允许我们记录每个页面收到的点击次数——点击会将你带离 Rango，无法记录刚刚发生的事情的信息。为了解决这个问题，我们可以实现一个简单的视图来记录一次点击——*然后* 将用户重定向到请求的页面。

这就是许多当代社交媒体平台发生的情况，例如——如果有人在 Facebook Messenger 中向你发送链接，Facebook 会插入一个简单的重定向设备，以便能够跟踪你点击了该链接。

要实现跟踪页面链接的功能，请尝试以下步骤。

1. 首先，创建一个名为 `goto_url()` 的新视图。它应映射到 URL `/rango/goto/`，URL 映射名称为 `goto`。

¹ [https://github.com/maxwelld90/tango_with_django_2_code](https://github.com/maxwelld90/tango_with_django_2_code)

2. 将 `search.html` 中的搜索表单和结果模板标记取出，并将其放置在 `category.html` *页面列表下方*。你只希望在分类存在于数据库中时显示搜索功能。

3. 更新搜索表单定义，使其 action 指向分类 URL，而不是搜索 URL。

4. 更新 `show_category()` 视图以处理 HTTP POST 请求。视图必须在上下文字典中包含任何搜索结果，以便模板渲染。记住搜索查询将作为 POST 请求的一部分在字段 `query` 中提供。

5. 最后，更新 Rango，使只有已登录的用户才能查看和使用更新后的搜索功能。为了在 `category.html` 模板中限制访问，我们可以使用类似以下代码片段的代码。

```django
{% if user.is_authenticated %}
    <!-- Your search code goes here -->
{% endif %}
```

第三步的标记和模板代码如下所示。

```html
<form class="form-inline"
      id="user-form"
      method="post"
      action="{% url 'rango:show_category' category.slug %}">
```

### 注释掉代码

注释掉代码会阻止解释器或编译器使用所选代码。虽然它看不到并执行它，但你仍然可以阅读和使用它。在 Python 中，注释掉一行代码的最简单方法是在其前面加上 `#`——放在任何文本之前。

其他语言会有不同的注释语法。例如，HTML 使用 `<!--` 来表示注释块标记的开始，使用 `-->` 来表示结束。
