### 2.6 测试你的实现

在你按照 Rango 应用的要求进行实现的过程中，我们希望你有信心知道自己*编写的代码*是否正确。我们无法亲自坐在你身边，因此我们做了次优选择——**我们实现了一系列不同的测试，你可以针对自己的代码库运行这些测试，看看哪些是正确的，哪些可以改进。**我们为核心章节（到第 10 章）准备了测试。

这些测试可以从我们的示例代码仓库中获取，[可在 GitHub 上找到](https://github.com/maxwelld90/tango_with_django_2_code/tree/master/progress_tests)。该仓库中的 `progress_tests` 目录包含多个不同的 Python 模块，每个模块都包含一系列不同的测试模块，你可以针对你的 Rango 实现运行这些测试。请注意，它们是针对各个章节的——例如，你应该*在*完成第 3 章后、开始第 4 章前，针对你的实现运行 `tests_chapter3.py` 模块。请注意，并不是每章末尾都有测试——书中有些部分很难在不下载大型支持库的情况下编写自动化测试。

### 完成所有练习！

这些测试假设你完成了某一章的所有练习！如果你没有完成，很有可能一些测试无法通过。

我们会检查到你所测试的节点为止应该已经正常工作的基本功能。我们还会检查当访问特定 URL 时服务器返回的内容——如果响应与你书中要求的内容*完全*不匹配，*测试就会失败*。这看起来可能过于严苛，但我们希望在你的脑海中刻下一个观念：*你必须完全按照规定的要求来满足需求*——任何偏差都是不可接受的。这也能让你逐步树立*测试驱动开发*的意识，我们在[测试章节开始时](#)对此进行了概述。

### 运行单元测试

那么，如何运行这些测试呢？下面的分步流程演示了基本操作过程。我们假设你想运行[第 3 章 Django 基础](#)的测试。

1. 首先，确定你要运行哪一章的测试。
2. 在计算机上克隆我们的[示例代码仓库](https://github.com/maxwelld90/tango_with_django_2_code)，或者从 [GitHub 网页界面](https://github.com/maxwelld90/tango_with_django_2_code/tree/master/progress_tests)访问你想要的具体测试模块。
   - 如果选择后者，请点击你需要的模块（例如 `tests_chapter3.py`）。在 GitHub 网站上看到代码后，点击 **Raw** 按钮并保存随后加载的页面。
3. 将 `tests_chapter3.py` 模块移动到你的项目的 `rango` 目录中。现在你可能觉得这一步没什么意义；随着你逐步阅读本书，之后回到这里复习操作时，就会明白它的意义。
4. 运行命令 `$ python manage.py test rango.tests_chapter3`。这将启动测试。

你还需要确保在运行这些测试时，你的 `rangoenv` 虚拟环境处于激活状态。

当所有测试完成后，你应该会看到 **OK**。这意味着全部测试都通过了！如果你没有看到 **OK**，说明有测试失败了——请查看测试输出，找出哪个测试失败以及失败原因。有时，你可能遗漏了某些内容，导致测试尚未执行就抛出了异常。在这种情况下，你需要查看预期结果，然后回头补充缺失的内容。你可以调整代码并重新运行测试，看看它们是否能够通过。

当你完成某一章的测试后，我们**强烈建议**你删除移动到 `rango` 目录中的那个模块。在上面的例子中，我们会删除 `tests_chapter3.py`。一旦你确认自己的解决方案通过了我们提供的测试，就不再需要这个模块了。直接删除即可——不要用这些模块弄乱你的仓库！

## 3. Django 基础

让我们开始 Django 吧！在本章中，我们将为你概述创建过程。你将建立一个新项目和一个新的 Web 应用程序。到本章结束时，你将拥有一个由 Django 驱动的简单网站！

### 3.1 测试你的环境设置

首先，让我们检查你的 Python 和 Django 安装是否适合本教程。为此，请打开一个新的终端/命令提示符窗口，并激活你的 `rangoenv` 虚拟环境。

激活后，执行以下命令。输出将告诉你当前的 Python 版本。

```
$ python --version
```

响应应该类似于 3.7.2，但 Python 3.5+ 的任意版本都可以正常工作。如果你需要升级或安装 Python，请参阅[设置系统](#)章节。

如果你使用虚拟环境，请确保已激活它——如果你忘记了如何激活，请参阅我们关于[虚拟环境](#)的章节。

验证完 Python 安装后，再检查你的 Django 安装。在终端窗口中，通过执行以下命令运行 Python 解释器。

```
$ python
Python 3.7.2 (default, Mar 30 2019, 05:40:15)
[Clang 9.0.0 (clang-900.0.39.2)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

在提示符下，输入以下命令：

```
>>> import django
>>> django.get_version()
'2.1.5'
>>> exit()
```

一切顺利的话，你应该会看到正确版本的 Django，然后可以使用 `exit()` 退出 Python 解释器。如果 `import django` 导入失败，请检查你是否处于虚拟环境中，并在终端窗口中使用 `pip list` 查看已安装的包。

如果你在安装包时遇到问题，或者安装了不同版本，请参阅“系统设置”章节，或查阅 Django 官方文档中关于安装 Django 的内容¹。

> ¹ https://docs.djangoproject.com/en/2.1/topics/install/
