
尽管取得了令人印象深刻的结果，但仍有很大的改进空间。首先，这是一个仿真。如果能有一些真实场景的结果那将是很棒的，尽管我从经验中知道，针对此类潜在危险环境进行开发极其困难。我还希望看到更真实的观测。例如，车辆位置和局部信息可以从视频摄像头推断得出。没有必要假设车辆或预言机拥有周围车辆的完美知识。最后，我担心对于一个相当简单的状态空间，策略模型过于复杂。我不认为需要这么多复杂性，状态表示应该被委托处理。我有信心，策略本身——用于选择合适的速度以插入间隙——实际上非常容易学习。

# 最大熵方法的扩展

SAC 开箱即用地为你提供了一个简单且高性能的离策略算法，但与其他算法一样，研究人员仍在不断提出改进，以追求最大性能。和往常一样，这些改进并不能保证对你的特定问题有更好的表现；你必须亲自测试它们。

## 其他熵度量（及集成）

香农熵只是衡量熵的一种方式。还有其他形式会改变 SAC 惩罚策略以偏好或忽略无前途动作的方式。Chen 和 Peng 尝试了 Tsallis 熵和 Rényi 熵，发现这些能提升基线算法的性能。^([9](#ch07.html#idm46428620266792)) 他们还演示了策略集成的用法，即同时训练多个策略。在每个新回合开始时，智能体从该集成中随机选择一个策略来选取动作。这种方法源自引导式 DQN，旨在改进探索（参见[“改进探索”](#ch04.html#sec_dqn_improving_exploration)）。

## 利用双Q学习上界进行乐观探索

类似于双 Q 学习对动作价值估计建立下界（参见[“双 Q 学习”](#ch03.html#sec_double_q_learning)），Ciosek 等人提出将悲观界用作目标策略（带有一个使其看起来类似标准 SAC 的熵项），但将*上界*（即高估奖励的动作价值）用于行为策略。^([10](#ch07.html#idm46428620257128)) 他们建议这有助于防止因依赖下界而导致的*悲观探索不足*。实证上，在标准 MuJoCo 环境上的结果有所提升，但幅度不大。如果你在智能体难以充分探索的环境中工作，可能需要考虑这种方法。

## 调整经验回放

正如[“优先经验回放”](#ch04.html#sec_prioritized_replay)所述，你选择用于学习的经验会影响学习性能。Wang 和 Ross 证明，添加优先经验回放可以在某些环境中改进 SAC，但过采样更新的经验能在所有环境中持续改进结果。^([11](#ch07.html#idm46428620248376)) 这是一个简单的添加，值得一试，但要警惕*灾难性遗忘*（参见[“经验回放”](#ch04.html#sec_experience_replay)），即智能体忘记之前的经验。大容量的回放缓冲区可以缓解这种影响。

## 软策略梯度

与其通过熵度量进行惩罚，为什么不推导一个受熵启发的软策略梯度呢？Shi、Song 和 Wu 引入了软策略梯度方法，据报道该方法比 SAC 更具原则性且更稳定。^([12](#ch07.html#idm46428620240424))

Shi 等人从最大熵强化学习的定义出发，对策略求导，得出了一个令人惊讶的简单梯度计算，如[公式 7-8](#ch07.html#eq_dspg_objective)所示。这比使用自动微分框架更有效，因为你可以直接观察和操作梯度，所以他们选择直接裁剪梯度，而不是应用信任域优化，以防止灾难性更新。这导致了更简单的实现和更好的稳定性。如果这在未来成为“默认”的最大熵解释，我不会感到惊讶。

## 软Q学习（及其衍生算法）

你也可以将最大熵强化学习应用于 Q 学习。Haarnoja 等人首次展示了可以推导基于熵的价值和动作估计。^([13](#ch07.html#idm46428620230728)) 其他人将相同的想法应用于计算优势函数，发现它在具有离散动作空间的复杂、潜在连续环境中效果很好。^([14](#ch07.html#idm46428620229016)) 我可以想象，将这些估计集成到其他算法（如 PPO）中可能会带来积极结果。

## 路径一致性学习

Nachum 等人提出的*路径一致性学习*（PCL）与 SAC 相关，因为它认识到熵鼓励探索，并推导出与软 Q 学习相同的软状态和动作价值函数。然而，PCL 探索使用了回溯，采用 `n` 步算法的风格，从而得出一个不需要任何修正（例如重要性采样）的 `n` 步离策略算法。^([15](#ch07.html#idm46428620221800)) 后续的一篇论文实现了一个基于 KL 散度的信任方法（Trust-PCL），其性能超过了 TRPO。^([16](#ch07.html#idm46428620219288)) 这凸显了即使结合深度学习和离策略采样技术，你仍然可以融入对底层时序差分算法的改进。尽管如此，SAC 往往能大幅超越 PCL 方法。

# 性能对比：SAC 与 PPO

房间里有一头大象，它在整个强化学习领域横行霸道：对于连续控制任务，PPO 还是 SAC 更好？普遍认为 SAC 及其衍生算法优于 PPO。但事实并没有那么清晰。正如我之前提到的，研究人员用不同的方式衡量性能，实现细节会严重改变性能。^([17](#ch07.html#idm46428620210024)) 本节的主要问题是研究人员大多不发布学习曲线的原始数值。而且他们经常甚至不在表格中报告数值，只在图表中展示。这使得在论文之间比较结果变得极其困难。
