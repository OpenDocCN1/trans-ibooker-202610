

## 缩略语和常用术语

**Offline（离线）**  
: 在机器学习意义上，指不进行推理的训练

**On-policy（同策略）**  
: 改进用于做决策的策略的算法

**Online（在线）**  
: 在机器学习意义上，指与推理同时进行的训练

**PAAC**  
: 并行优势 Actor-Critic（Parallel advantage actor-critic）

**PAC**  
: 近似正确（Probably approximately correct）

**Partially observable（部分可观测）**  
: 智能体只能观测到环境的有限视图

**PCL**  
: 路径一致性学习

**PG**  
: 策略梯度

**Policy（策略）**  
: 定义如何行动的规则

**POMDP**  
: 部分可观测马尔可夫决策过程

**PPO**  
: 近端策略优化

**QMIX**  
: 用于深度多智能体强化学习的单调价值函数分解

**RAM**  
: 随机存取存储器

**RBM**  
: 受限玻尔兹曼机

**REINFORCE**  
: 一种受蒙特卡洛启发的策略梯度算法

**Reward（奖励）**  
: 给予智能体以表示成功或失败的数值

**RL**  
: 强化学习

**RNN**  
: 循环神经网络

**ROBEL**  
: 面向学习的机器人基准测试

**RTB**  
: 实时竞价

**SAC**  
: 软 Actor-Critic

**SARSA**  
: Q-learning 的详尽版本

**SAS**  
: 随机动作集

**SEED**  
: 可扩展且高效的深度 RL

**State（状态）**  
: 环境的完全可观测内部状态，常被误用为观测值

**Stationary（平稳）**  
: 在统计意义上稳定；意味着可预测性

**Stochastic policy（随机策略）**  
: 将状态映射为动作上的概率分布

**Strategy（策略/战略）**  
: 长期序列决策制定；参见 policy

**SQIL**  
: 软 Q 模仿学习

**SQL**  
: 软 Q-learning

**TD**  
: 时序差分

**TRPO**  
: 信任域策略优化

**UAV**  
: 无人机

**UCB**  
: 置信上界

**VAE**  
: 变分自编码器

**VIME**  
: 变分信息最大化探索

**XAI**  
: 可解释人工智能

## 符号与记号

`∥`  
: 两个分布之间的差异，通常指 KL 散度

`*α*`  
: 通常指学习率参数

`*β*`  
: 行为策略，也是某些算法中的第二个学习率参数

`*γ*`  
: 折扣因子

`∇`  
: 梯度算子

`*π*`  
: 一个策略，或目标策略，常用作下标以表示遵循某策略

`*θ*`  
: 模型或策略的参数

`*ϕ*`  
: 一个将一种维度映射到另一种维度的函数

`𝒜`  
: 所有可能的动作，一个集合

`*a*`  
: 一个特定的动作，`𝒜` 的成员

`𝔼`  
: 期望算子

`*G*`  
: 回报（轨迹上两点之间所有奖励的总和）

`ℋ`  
: 熵算子

`*J*`  
: 策略梯度算法的目标函数

`*Q*`  
: 动作价值函数，也称为 Q 函数，给定状态和动作的期望回报

`ℛ`  
: 所有可能的奖励，一个集合

`*r*`  
: 一个特定的奖励，`ℛ` 的成员

`𝒮`  
: 所有可能的状态，一个集合

`*s*`  
: 一个特定的状态，`𝒮` 的成员

`*V*`  
: 状态价值函数，给定状态的期望回报

`*Z*`  
: 分布式动作价值函数
