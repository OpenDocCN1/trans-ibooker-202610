
# 非洲企鹅保护

## 种群数量下降

19世纪初，非洲企鹅的数量约为400万只。如今，种群数量已下降了95%。有人预测，到本世纪末，企鹅将面临灭绝。企鹅面临着诸多威胁，包括食物来源减少，因为它们捕食的鱼类对水温上升很敏感。

## 保护现状与书籍封面

非洲企鹅的保护现状为濒危。奥莱利（O'Reilly）书籍封面上的许多动物都是濒危物种；它们对世界都至关重要。
