
在 RL 中使用 DL 比在 ML 中使用它更难。在监督机器学习中，你通过针对真实标签优化性能度量来改进模型。在 RL 中，智能体往往需要等待很长时间才能收到任何反馈。DL 已经因需要大量数据来训练一个好的模型而臭名昭著，但将这一点与智能体必须随机碰巧遇到奖励这一事实结合起来，这可能需要永远的时间。出于这一原因以及其他更多原因，研究人员开发了一袋子技巧来帮助 DL 在合理的时间内学习。

# 深度 Q 学习

2013 年之前，研究人员意识到他们需要函数近似来解决具有大型或复杂状态空间的问题。他们已经证明，使用线性近似保留了与表格方法相同的收敛保证。但他们警告说，使用非线性函数近似器实际上可能会发散，而不是收敛。^([1](#ch04.html#idm46428615774280)) 因此，大部分研究都集中在改进线性近似方法上。

最终，作为禁果的 DL 对研究人员的诱惑太大了，他们设计了 `deep Q-network` (`DQN`)。^([2](#ch04.html#idm46428615771240)) 他们意识到主要问题是移动的目标。想象一下试图拍打一只苍蝇。苍蝇的运动如此随机，反应如此之快，以至于只有《龙威小子》才指望能在半空中抓住它。如果你等到苍蝇静止不动，你就有更大的机会预测苍蝇在 500 毫秒后会在哪里，因此也有更大的机会打中它。智能体面临同样的问题。除非数据是平稳的，否则它会发现很难收敛。在某些情况下，它实际上会发散，因为就像在一个破坏性的反馈回路中，下一个动作可能会让事情变得更糟。

一般来说，像随机梯度下降这样的模型优化器假设你的数据是独立同分布（IID）的随机变量。当你在时间上紧密采样时，数据很可能是相关的。例如，MDP 的定义表明下一个观测值依赖于先前的状态和采取的动作。这违反了 IID 假设，并可能导致模型无法收敛。

## 经验回放

解决这个问题的最初方案是使用 `experience replay`。这是一个包含观测值、动作、奖励和后续观测值的缓冲区，可用于训练 DL 模型。这允许你使用旧数据来训练模型，使训练更加样本高效，很像 [“资格迹”](#ch03.html#sec_eligibility_traces)。通过在训练时采取随机子集，你打破了连续观测值之间的相关性。

`experience replay` 缓冲区的大小很重要。Zhang 和 Sutton 观察到，调整不当的缓冲区大小会对性能产生巨大影响。^([3](#ch04.html#idm46428615761928)) 在最坏的情况下，当观测值从 `first in, first out` (`FIFO`) 缓冲区的末尾移出时，智能体可能会“灾难性地遗忘”经验，这可能导致策略发生巨大变化。理想情况下，训练数据的分布应与智能体观察到的分布相匹配。^([4](#ch04.html#idm46428615759736))

## Q 网络克隆

在对原始 `DQN` 算法的更新中，同一批研究人员提出了克隆 `Q-network`。这导致了两个 `NN`：一个产生动作的 `online network` 和一个继续学习的 `target network`。经过一定数量的迭代后，预测网络从目标网络复制当前权重。研究人员发现这使得算法更稳定，不太可能振荡或发散。原因与之前相同。智能体获得的数据在有限时间内变得平稳。诀窍是将这个周期设置得足够小，以便你能快速改进模型，但又要足够长以保持数据平稳。^([5](#ch04.html#idm46428615752136)) 你也会注意到这与 [“Double Q-Learning”](#ch03.html#sec_double_q_learning) 中提出的想法相同；两个估计比一个更稳定。

## 神经网络架构

使用随机采样的 `experience replay` 和 `target Q-network`，`DQN` 足够稳定，可以在复杂任务中表现良好。主要驱动因素是对建模并将观测值映射为动作的 `NN` 的选择。原始 `DQN` 论文从视频帧玩 Atari 游戏，所以使用 `CNN` 是显而易见的选择。但这并不妨碍你使用其他 `NN` 架构。选择在你的领域表现良好的架构。

`DQN` 的另一个有趣特性是选择预测状态价值函数。回想标准 `Q-learning`（或 `SARSA`）使用动作价值函数；`Q-values` 将状态和动作都作为参数。结果是对某个状态和单个动作的期望值估计。你可以为每个动作训练一个单独的 `NN`。相反，`NNs` 可以有多个 `heads` 同时预测所有动作的值。训练时，你可以将期望动作设为 1，非期望动作设为 0，这是动作的 `one-hot encoding`。

## 实现 DQN

表示 `DQN` 更新规则的方程类似于 [“Q-Learning”](#ch03.html#sec_q_learning)。主要区别在于 `Q-value` 由一个函数近似，而该函数有一组参数。例如，要选择最优动作，选择具有最高期望值的动作，如 [Equation 4-1](#ch04.html#eq_dqn_choosing_action) 所示。

### Equation 4-1. 使用 DQN 选择动作

```
$$\\left. a\\leftarrow\\operatorname{argmax}\\limits\_{a\_{s} \\in \\mathcal{A}{(s)}}Q\\left( {s,a\_{s};\\theta} \\right) \\right.$$  
```

在 [Equation 4-1](#ch04.html#eq_dqn_choosing_action) 中，`Q` 表示用于从 `NN` 预测动作值的函数，`θ` 表示该函数的参数。所有其他符号与 [Equation 3-5](#ch03.html#eq_q_learning_update_function) 中的相同。

要训练 `NN`，你需要提供一个损失函数。请记住，目标是预测动作价值函数。因此，损失函数的一个自然选择是实际动作价值函数与预测值之间的平方差，如 [Equation 4-2](#ch04.html#eq_dqn_loss_function) 所示。这通常实现为 `mean squared error` (MSE)，但任何损失函数都是可能的。

### Equation 4-2. DQN 损失函数

```
L(θ) ≐ 𝔼[π][(y − Q(s, a; θ))²]
```

`NN` 优化器使用梯度下降来更新 `NN` 参数的估计。它们利用损失函数梯度的知识，将参数朝着最小化损失函数的方向轻推。底层 `DL` 框架会为你处理梯度的计算。但你也可以通过对 [Equation 4-2](#ch04.html#eq_dqn_loss_function) 关于 `θ` 求导来写出它。

`DQN` 的实现很像 [Algorithm 3-1](#ch03.html#alg_q_learning) 中的 `Q-learning`。不同之处在于动作直接从 `NN` 传递，经验需要缓冲，并且偶尔你需要传输或训练 `target NN` 的参数。魔鬼在于细节。你如何精确实现 `experience replay`，选择什么 `NN` 架构和超参数，以及何时进行训练，可能会决定是超人类性能还是算法爆炸。
