# 第 8 章 改进智能体的学习方式

复杂的工业问题通常可以分解为**有向无环图**（DAG）。这有助于提高开发效率，因为它将一个漫长的项目拆分为许多更容易解决的小项目。这也有助于强化学习（RL），因为较小的组件通常更容易、更快地训练，且可能更加稳健。[“分层强化学习”](#ch08.html#sec_hrl)展示了一种常见的形式化方法，即推导出一个策略层级，其中低层策略负责细粒度的“技能”，而高层策略进行长期规划。

到目前为止，本书中我仅考虑了单智能体问题。某些问题需要智能体团队，或者至少可能有多个智能体在同一环境中运行。[“多智能体强化学习”](#ch08.html#sec_marl)将向你展示智能体如何通过全局或局部奖励进行合作或竞争，以解决多智能体问题。

强化学习另一个快速发展的领域是重新定义你应如何思考奖励。传统上，利用奖励信号学习策略是智能体的唯一责任。但你可以通过以专家指导的形式提供额外的、潜在的外部信息来增强这一过程。[“专家指导”](#ch08.html#sec_expert_guidance)讨论了如何将专业知识融入策略，最终通过改进探索来加速学习。甚至可以*学习*最优奖励，旨在消除对奖励工程的需求。

但首先，强化学习通过贝尔曼方程与马尔可夫决策过程（MDP）密不可分，所有强化学习算法在进行序列决策时都依赖 MDP 的最优性理论保证（你可能需要复习[“马尔可夫决策过程”](#ch02.html#markov-decision-processes)）。但各种现实场景会打破 MDP 的底层假设，这往往导致贝尔曼方程所作假设的静默失效，表现为无论怎么调整超参数，策略都无法收敛。下一节将探讨基本 MDP 的变体，以适应这些场景。

## 注记

本章总结了最新技术进展。我认为最重要的四个主题是：如何定义 MDP、分层 RL、多智能体 RL 以及提供专家指导。但所有这些都可被视为“进阶”内容，若要全面讨论足以写成另一本书。不过，我认为提供一个概览很有用，这样你就知道这些内容的存在，若有需要可深入研究。一如既往，[“延伸阅读”](#ch08.html#ch08_further_reading)中的引用和推荐能提供大量额外信息。

## 重新思考 MDP

利用 MDP 框架及贝尔曼方程所得保证的 RL 算法，假设底层环境是马尔可夫的。尽管对智能体动作的效果可能存在大量不确定性，但对环境状态的感知必须是完美的。智能体随后利用这种全知的知识，根据当前策略 *π*(*a*∣*s*) 选择下一个动作。

但如果状态表示不完美怎么办？如果你指示舵机移动到某个位置，它却移动到了围绕该位置随机分布的某个位置怎么办？又或者存在潜在的隐藏特征，代表用户点击推荐的可能性有多大？在这些情况下，状态无法被完全观测，马尔可夫假设被打破。

### 部分可观马尔可夫决策过程

解决这种**部分可观性**的一个方法是拆分状态的表示。部分可观马尔可夫决策过程（POMDP）在 MDP 基础上增加了额外参数，以包含智能体可经历的有限观测集合 *Ω*，以及一个将状态和动作映射到动作概率分布的**观测函数** *O*。随后，你可以通过近似观测函数的逆函数，并用它将观测转换回状态，将问题转换回 MDP。

[图 8-1](#ch08.html#fig_pomdp) 显示 POMDP 是 MDP 的扩展，其中智能体无法直接观测环境的当前状态。取而代之的是，它利用观测以及关于先前动作和状态的信息来生成当前状态的预测 *ŝ*。状态的预测通常称为**信念状态** *b*，你可以将其描述为“这是我认为环境所处的状态”。

#### 预测信念状态

那么什么是信念状态，以及如何预测它？考虑一个试图指导机器人穿越简单迷宫的例子。智能体不知道迷宫的布局，但它可能足够聪明，能够检测到前方有一个“T 型路口”，并需要决定朝哪个方向走。一个朴素的策略会过拟合训练环境，并收敛到每次都建议单一决策的地步。

如[图 8-1](#ch08.html#fig_pomdp)中的循环所示，解决此问题的一个简单方法是根据过去的经验来确定最佳动作。我指的不是训练意义上的过去经验，不是经验回放缓冲区，而是当前回合和环境的过去经验。例如，如果你知道机器人已经尝试过向左但走进了死胡同，那么迷宫的隐藏状态（最佳路线）很可能是向右的选项。

许多复杂的示例利用这一简单想法，将过去的动作和观测包含在状态表示中。例如，Atari 基准测试总是堆叠四帧像素观测，以保留环境的一些“历史”。这使智能体能够预测乒乓球的轨迹或敌人的移动。许多机器人示例也包含先前的动作和状态，以帮助解决定位不准的问题并使移动更平滑。

尽管这一想法在许多情况下有帮助，但总体上并不充分。为了最优地行动，智能体需要主动考虑它对当前情况的不确定程度。一个更复杂的解决方案是使用能够学习时序依赖特征的近似器来建模状态估计器。
