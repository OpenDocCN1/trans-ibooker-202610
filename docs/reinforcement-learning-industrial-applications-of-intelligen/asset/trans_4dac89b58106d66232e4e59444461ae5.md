
# 基于熵的算法和正则化马尔可夫决策过程

[第6章](#ch06.html#ch_beyond_policy_gradients)通过约束更新来解决这个问题，使其不会显著改变策略。但这仍可能导致脆弱、过度稀疏的策略，即除最优轨迹外，大多数动作的价值为零。本章介绍了基于熵的算法，它们修改了马尔可夫决策过程（MDP）回报的原始定义，以重新缩放或*正则化*回报。这引出了其他熵的定义可能表现更好的提议，因为香农熵不够稀疏。我认为可以通过调整温度参数来产生适合你自己问题的策略。但另一种熵度量很有可能在你的特定问题上表现更好。

这一论点的合乎逻辑的结论是使用任意函数。这由Li、Yang和Zhang在*正则化马尔可夫决策过程*中提出，并规定了该函数必须遵循的几条理论规则，例如它应该严格为正、可微、凹函数，并在0到1范围之外降为零。他们建议其他基于指数的函数和三角函数是有趣的提议。^([20](#ch07.html#idm46428619965016))

无论实现如何，用探索奖励增强价值函数对生产环境实现都是有益的。你希望你的智能体对变化具有鲁棒性。小心不要过拟合到你的环境。

## 策略梯度与软Q学习的等价性

为了结束本章，我想回到价值方法与策略方法的比较。简单来说，`Q-learning`和策略梯度方法都试图强化导致更好奖励的行为。`Q-learning`增加动作的价值，而策略梯度增加选择动作的概率。

当你加入基于熵的策略梯度（或等价形式）时，你会按动作价值的某个函数比例提高动作的概率（参考[公式 7-2](#ch07.html#eq_maximum_entropy_objective_function)）。更简洁地说，策略与`Q值`的某个函数成正比。因此，策略梯度方法解决的问题与`Q-learning`相同。^([21](#ch07.html#idm46428619956808))

即使从经验上看，`Q-learning`和策略梯度方法的比较也得出性能相似的结论（看ACER论文中的图4，策略梯度和`Q-learning`方法几乎相同）。^([22](#ch07.html#idm46428619954776)) 考虑到样本效率或并行性等外部改进时，许多差异可以被解释。Schulman和Abbeel甚至将`Q-learning`和基于策略梯度的算法归一化为等价，并证明它们产生相同的结果。^([23](#ch07.html#idm46428619952872))

## 这对未来意味着什么？

从中可以得出的结论是，随着时间的推移，价值方法和策略梯度方法之间的差别将很小。这两个学科将会融合（它们已经在一定程度上通过`actor-critic`范式融合了），因为策略改进和价值估计是密不可分的。

## 这对现在意味着什么？

但目前很明显，没有单一的实现适用于所有问题，这是*没有免费午餐*定理的经典解释。你必须考虑多种实现以确保优化了性能。但要确保选择解决你问题的最简单方案，特别是如果你在生产环境中运行。这些算法积累的工业知识和经验也有帮助。例如，你不会默认选择一些晦涩的算法而不是`SAC`，因为人们、平台和公司对`SAC`有更多经验。
