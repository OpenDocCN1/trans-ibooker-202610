
# 利用强化学习提高建筑能效

欧盟约 40% 的能源用于建筑供电和供暖，这占温室气体排放量的约 25%。^([6](#ch04.html#idm46428615664872)) 有一系列技术有助于降低建筑能耗，但其中许多具有侵入性且昂贵。然而，微调建筑供暖、通风和空调（HVAC）的控制适用于任何年代的建筑。Marantos 等人提出在智能恒温器中使用 RL 来提高建筑供暖系统的舒适度和效率。^([7](#ch04.html#idm46428615663096))

## 马尔可夫决策过程定义

他们首先定义马尔可夫决策过程。状态由室外气象传感器（如温度和日照量）、室内传感器（如湿度和温度）、用于量化用量的能源传感器以及热舒适度指示拼接而成。

## 智能体动作

智能体可从三个动作中选择：维持温度、升高一度、降低一度。

## 奖励函数

奖励通过热舒适度和能源用量的组合来量化，该组合使用滚动均值和标准差进行缩放，从而无需使用任意缩放参数。由于这主要是一个连续问题，Marantos 等人引入了终止状态以防止智能体超出边界：如果智能体试图超出预定义的运行窗口，则会受到惩罚。

## 算法选择：NFQ

Marantos 等人选择使用神经网络拟合 Q 迭代（NFQ）算法，它是 DQN 的前身。DQN 与 NFQ 思路相同，只是额外包含了经验回放和目标网络。他们使用前馈多层感知机作为状态表示函数来预测二元动作。

## 评估结果

他们使用多项类似工作中采用的仿真来评估其实现。该仿真对应位于希腊克里特岛的一座实际建筑，使用公开的天气信息。与标准基于阈值的恒温器相比，智能体能将平均能耗降低高达 59%，具体取决于所选的舒适度水平。

## 嵌入式设备上的实现

一个不常见的有趣想法是，Marantos 等人在 `Raspberry Pi Zero` 上实现了该算法，并证明即使有神经网络，他们也拥有足够的计算资源来训练模型。

## 未来改进

如果我要帮助改进这个项目，首先考虑的是切换到 DQN 或其衍生算法之一，以提高算法性能。由于经验回放和目标网络，NFQ 明显弱于 DQN。这一变化将带来更好的样本效率，并受益于使用行业标准技术。我喜欢使用嵌入式设备进行计算，并会通过考虑整栋建筑中的多个智能体来扩展这一点。在这种多智能体设置中，智能体可以协作以优化不同区域的温度舒适度，例如卧室更凉爽，或客厅过夜时完全关闭。

最后，这不仅适用于供暖。智能体可以轻松提高照明效率、热水使用效率和用电效率，所有这些都有文档案例研究。您可以在[配套网站](https://rl-book.com/applications/?utm_source=oreilly&utm_medium=book&utm_campaign=rl)上找到更多信息。

# Rainbow DQN

作为 Q-learning 的衍生算法，您可以使用[“Q-Learning 的扩展”](#ch03.html#sec_extentions_q_learning)中看到的扩展来改进 DQN。2017 年，研究人员利用六种扩展创建了 Rainbow DQN，每种扩展都解决了 Q-learning 和 DQN 的根本问题。研究人员还进行了实验，以查看哪种扩展对性能提升最大。^([8](#ch04.html#idm46428615648664))

您已经看到了前两种改进：双 Q-learning（见[“双 Q-Learning”](#ch03.html#sec_double_q_learning)），用于缓解最大化偏差；以及 `n` 步回报（见[“n 步算法”](#ch03.html#n_step_algorithms)），用于累积多个未来步骤的奖励。

## 分布式 RL

与标准 DQN 最根本的区别在于将概率重新引入智能体。所有 Q-learning 智能体都源自贝尔曼方程（[公式 2-10](#ch02.html#eq_optimal_value_function)），该方程将最优轨迹定义为使期望奖励最大化的动作。这里的关键词是*期望*。Q-learning 将其实现为指数衰减平均值。每当您使用汇总统计量时，都意味着对底层分布做出假设。通常，如果您选择均值作为汇总统计量，就会隐含假设数据服从正态分布。这正确吗？

例如，想象您在 `Cliffworld` 环境中站在悬崖边平衡。如果您掉下悬崖，会获得巨大的负奖励。但沿着悬崖边行走也有更大（但接近零）的奖励。[“Q-Learning 与 SARSA”](#ch03.html#sec_q-learning-vs-sarsa) 表明 SARSA 遵循远离悬崖的平均“安全”路径。Q-learning 选择了靠近悬崖的冒险路径，因为到达目标的步骤较少，导致期望回报略高。`Cliffworld` 环境中的所有状态都导致两种结果。两种结果都有自己的分布，表示探索可能导致智能体达到替代结果的小概率。期望回报不服从正态分布。一般来说，奖励是*多模态*的。

现在想象一个类似 `Cliffworld` 的环境，其中成功与失败的差异没有那么大。假设成功奖励为 +1，失败奖励为 -1。那么，对于至少某些状态，期望回报将接近零。在这些状态下，平均期望值产生的动作没有任何差别。这可能导致智能体在无意义的状态中随机游荡（可将其与损失函数变得过于平坦时陷入平台期的梯度下降算法相比较）。这在[图 4-5](#ch04.html#fig_reward_distribution)中显示。一般来说，奖励分布要复杂得多。

![](assets/rele_0402.png)

实际上，这会导致收敛问题。最坏的情况是智能体永远不收敛。当它收敛时，研究人员常将智能体描述为“抖动”。即智能体收敛但从未稳定。它可能像[图 4-6](#ch04.html#fig_chattering)那样振荡，也可能更复杂。注意，这不是抖动的唯一原因。

![](assets/rele_0403.png)

学习*奖励分布*可以带来更稳定的学习。^([9](#ch04.html#idm46428615622728)) Bellemare 等人重新表述了贝尔曼方程，以考虑您在[公式 4-3](#ch04.html#eq_distributional_bellman_equation)中看到的随机奖励，其中 `γ` 是折扣因子，`R` 是取决于状态和动作的随机奖励。

### 公式 4-3. 分布式贝尔曼方程

```
Z(s,a) ∼ R(s,a) + γZ(S′,A′)
```

这里我暂时打破本书惯例，使用大写字母表示随机变量。`Z` 表示奖励分布。`Z` 的期望是 Q 值。与 Q 值一样，`Z` 应根据接收到的奖励递归更新。关键区别在于强调期望回报 `Z` 是一个分布在所有未来状态 `S` 和未来动作 `A` 上的随机变量。换句话说，策略 `Z^π` 是从状态-动作对到期望回报分布的映射。这种表示保留了多模态性，Bellemare 等人认为这能带来更稳定的学习。我建议您观看[此视频](https://oreil.ly/vTVHj)，以查看 `Space Invaders` 游戏中学习到的奖励分布示例。
