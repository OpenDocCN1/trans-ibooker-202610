
此外，因为你可以将 `K-FAC` 用于卷积神经网络（如 `PPO`），这意味着 `ACKTR` 可以处理离散的、视觉的状态空间，例如 `Atari 基准测试`。

自 2017 年以来，独立评测表明 `ACKTR` 与 `TRPO` 的性能高度依赖于环境。例如，在高度不稳定的 `Swimmer-v1` `MuJoCo` 环境中，`TRPO` 优于大多数算法。但在 `HalfCheetah-v1` 环境中，`TRPO` 的表现明显更差。^([28](#ch06.html#idm46428616378696)) 在原始论文中，Henderson 等人展示了 `Swimmer-v1` 的结果，显示 `A2C`、`TRPO` 和 `ACKTR` 表现相似（参见[“我应该使用哪种算法？”](#ch06.html#sec_which_pg_algorithm)）。据传闻，从业者更倾向于 `ACKTR` 而非 `TRPO`，因为两者的思路和最终性能相似，但 `ACKTR` 的计算效率得到了显著提升。

## 强调法

梯度时序差分方法（参见[“梯度时序差分学习”](#ch06.html#sec_gtd)）引入了使用函数逼近状态价值函数，并直接计算投影贝尔曼误差的梯度以避免逼近发散的想法。然而，它们需要两组参数和两个学习率，这使得它们在实践中难以使用。为了解决这个问题，Sutton 等人提出了强调时序差分方法。^([29](#ch06.html#idm46428616370040),[30](#ch06.html#idm46428616368344))

在其最一般的形式中，强调时序差分学习使用一个函数来根据当前策略量化对特定状态的兴趣。这与重要性采样一起呈现，以补偿离策略智能体。然而，确定一个函数已被证明很困难，且与投影相关的性能问题阻碍了其取得突破性成功。^([31](#ch06.html#idm46428616366168))

一个特别有趣的强调提议称为广义离策略行动者-评论家（`Geoff-PAC`），建议使用反事实目标的梯度。^([32](#ch06.html#idm46428616362648)) `反事实` `推理` 是质询未观测到的数据的过程；例如，基于过去收集的数据，询问新策略的奖励会是多少。虽然细节超出了本书范围，但其思路是你可以通过预测 `密度比` 来学习强调函数的逼近（当然是使用神经网络），这类似于重要性采样的连续版本。结果很有希望，但尚未获得广泛普及。

# 策略梯度算法的扩展

贯穿全书，你已经看到了一系列算法增强，原则上你可以将它们应用于任何算法。每隔几年，研究人员就会发布一篇论文，将这些增强结合起来，在基准环境中产生最先进的结果并引起媒体关注。但从从业者的角度来看，随附的消融研究往往更有趣，因为它能向你展示哪些调整可能最适合你的问题。为了演示这种方法，这里有一个如何将分布式 RL 添加到 PG 算法的示例。

## 策略梯度算法中的分位数回归

Richter 等人演示了如何以大致相同的方式将分布式 RL 纳入策略梯度算法，就像[“改进奖励”](#ch04.html#sec_quantile_regression)为价值方法所做的那样。^([33](#ch06.html#idm46428620414856)) 他们使用神经网络来预测每个动作的分位数。和以前一样，这很有用，因为从动作到奖励的映射通常是随机的，并且许多环境具有多峰分布。本文的关键区别在于对策略梯度算法的适配。他们从标准的 `A2C` 损失函数（`公式 6-8`）开始，不再学习优势函数，而是用分位数估计来替代它。接下来，他们做了一系列近似来分解出分位数估计，从而得到一个版本，该版本根据温度超参数迭代地更新分位数估计。他们实现了该算法的 `on-policy` 版本，在某些基准测试中击败了 `TRPO`（他们没有将其与 `PPO` 进行比较），并建议以类似的方式将其用于 `off-policy`。

# 总结

在本篇相当广泛的章节中，你看到了各种最先进的策略梯度算法，重点关注 `off-policy` 行动者-评论家方法。[第 5 章](#ch05.html#ch_policy_gradient_methods)介绍了将策略评估和策略改进抽象为行动者-评论家架构的想法。本章的目的是解释和演示 `off-policy` 学习的威力。

`Off-policy` 学习前景广阔，智能体可以学习多种不同于行为策略的策略。`Off-policy` 学习使智能体从探索-利用权衡的暴政中解脱出来，允许行为策略自由探索。由于最优策略是分离的，你可以使用离线数据日志或从人类演示中学习。但主要优势是你可以随意重新训练你的逼近函数，因为没有环境成本。这导致算法具有更高的样本效率，尽管以计算复杂度为代价，特别是如果你涉及神经网络的话。

## 我应该使用哪种算法？

研究人员也清楚你对哪种算法最好感到困惑。已经有许多研究试图给出答案，但转述一个总结的话，研究人员很容易展示可能并不完全稳健的投机结果。^([34](#ch06.html#idm46428620403608)) 举个具体例子，原始 `ACKTR` 论文展示了许多其他人难以复现的环境结果。当然，这可能是由于实现细节或一组幸运的超参数。但这确实凸显了这个问题。不过，我可以提出一些通用建议：

*   优先选择 `TD3` 而非 `DDPG`
*   在动态不稳定的环境中优先选择信任域方法，这种情况下策略的微小变动可能导致灾难性后果
*   在动态稳定的环境中优先选择确定性方法
*   如果性能或鲁棒性是考量因素，请考虑更简单的算法和更小的神经网络，如 `PPO` 或 `TD3`

## 关于异步方法的说明

`Off-policy` 算法的另一个重要特性是它让你不必使用单个评论家。我还没提到这一点（参见[“`扩展 RL`”](#ch10.html#sec_scaling_rl)），但因为评论家是从经验回放缓冲区学习的，所以没有理由不让许多重复的评论家都学习单独的策略。在这些 `异步方法` 中，你需要在某个时刻将这些知识重新组合回行为策略，但这可以显著提高算法的实际运行时性能。我还没有讨论它，因为我认为这是一个实现细节，且取决于是否有一个需要更快学习以证明额外开销合理的问题。对于工业问题，我首先建议你考虑简化问题或领域以消除对这种方法的需求，因为它增加了大量的操作复杂性和成本。
