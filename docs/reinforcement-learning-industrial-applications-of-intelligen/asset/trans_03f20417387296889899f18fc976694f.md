# 其他 DQN 改进

**“Rainbow DQN”** 为 DQN 引入了六项改进。每个算法解决单一障碍，并概括了三个研究主题。(1) 神经网络应学习得更快并产生更有信息量的结果。(2) Q 学习不应不稳定或有偏差。(3) RL 应高效找到最优策略。你可以看到这些指的是三个不同的抽象层级。例如在 **Rainbow DQN** 中，优先经验回放试图改进神经网络的学习，双重 Q 学习有助于防止 Q 学习中的最大化偏差，分布式 RL 有助于在 RL 中学习更真实的奖励。在本节中，我将介绍其他专注于 DQN 的最新改进。

## 改进探索

`ϵ-greedy` 探索策略无处不在，旨在随机采样小型有限状态空间。但在复杂环境中，抖动方法（即随机扰动智能体）并不实用；它们需要呈指数增长的数据量。描述此问题的一种方式是想象由 Q 值表示的曲面。如果 Q 学习智能体反复选择次优状态-动作对，后续回合也会选择该对，就像智能体陷入局部最大值一样。一种替代方案是考虑其他采样方法。

“[改进 `ϵ-greedy` 算法](#ch04.html#idm46428617404008)”引入了置信上界（`UCB`）采样，它使动作倾向于欠采样状态。这防止了对初始最优轨迹的过度采样。[汤普森采样](#ch04.html#idm46428617404008)常用于 A/B 测试（见“[多臂老虎机测试](#ch04.html#idm46428617404008)”），它维护表示期望值的分布。对 Q 学习而言，这意味着每个 Q 值是一个分布，而非期望。这与[分布式 RL](#ch04.html#idm46428617404008)背后的想法相同（见“[分布式 RL](#ch04.html#idm46428617404008)”）。自举 DQN（`BDQN`）利用这一想法，训练一个具有多个头的神经网络来模拟 Q 值分布，即动作价值估计的*集成*。^([13](#ch04.html#idm46428617404008)) 这被分布式 `RL` 取代，后者能高效预测实际分布，而非粗略近似。但 Osband 等人巧妙地继续复用随机选择的策略以在未来也驱动探索。这引出了“深度探索”的想法。在复杂环境中，`ϵ-greedy` 像苍蝇一样移动，经常返回之前观察过的状态。深入寻找新的、未观察过的状态是合理的。在这里你也能看到与噪声网络的相似之处。
