

## 使用状态价值函数预测奖励

[公式 2-6](#ch02.html#eq_expected_return) 将所有未来奖励求和，直到最后一个时间步 `T`。这个最终状态被称为*终止状态*，仅出现在*情节式*任务中。一个情节代表从开始到自然终止点的一次完整运行过程。这可能是你的机器人掉下悬崖，或者游戏中的角色死亡。但当然，也可能存在永远持续下去的任务，比如库存示例——如果你允许我对零售市场的状态持乐观态度的话。在这种情况下，终止状态为 `T = ∞`，预期回报也可能是无限的。

### 公式 2-6. 回报

```
G ≐ r + r' + ⋯ + r[T]
```

为了缓解无限大的爆炸性威力，[公式 2-7](#ch02.html#eq_discounted_expected_return) 引入了一个折扣因子，使未来奖励呈指数级衰减。

### 公式 2-7. 折扣回报

```
G ≐ r + γ r' + γ² r'' + ⋯ = ∑_{k=0}^{T} γ^k r_k
```

在[公式 2-7](#ch02.html#eq_discounted_expected_return)中，`T` 代表终止状态，可以是无穷大。`γ` 称为*折扣率*或*因子*。它控制未来奖励被忽略的速度，取值应在 0 到 1 之间（含边界）。换句话说，如果 `γ = 0`，则仅考虑当前奖励。如果 `γ = 1`，则这与[公式 2-6](#ch02.html#eq_expected_return)相同。通常你希望考虑未来奖励，以便解决奖励远在未来的问题。但具体数值取决于手头的问题。在大多数非平凡示例中，折扣率设置在 0.9 到 0.99 之间。

因此，你想构建一个能够产生最大*预期回报*的智能体。你可能会问，既然预期回报取决于未来奖励，该如何计算它？答案是通过迭代和学习，找出哪些状态和动作映射到最佳奖励。换句话说，你应该通过迭代来寻找最佳策略。

在[“库存控制模拟”](#ch02.html#inventory-control-simulation)的库存示例中，我任意选择了三种补货策略。但我想自动优化动作选择以最大化预期回报。这就是*策略*的目的；它将状态映射到动作。形式上，它是在给定状态下选择某个动作的概率 `p(a|s)`，用 `π` 表示。

#### 提示

可以通过根据预期回报调整策略的梯度来改进策略。我将在[第 5 章](#ch05.html#ch_policy_gradient_methods)中回到这个话题。

你可以根据当前策略 `π` 从当前状态 `s` 开始获得的回报 `G` 来计算预期回报。这被称为策略的*状态价值函数*，如[公式 2-8](#ch02.html#eq_state_value_function)所示。

### 公式 2-8. 状态价值函数

```
V_π(s) ≐ 𝔼_π[G | s] = 𝔼_π[∑_{k=0}^{T} γ^k r_k | s]
```

乍一看，我理解这个公式显得很复杂，所以让我带你逐步拆解。等式由等号分隔为三个部分。左边的 `V` 是表示价值函数的符号。

#### 提示

对于那些非数学专业出身的人，我发现将数学函数想象成软件中的函数会有所帮助。

第二部分，即函数的定义，是说价值函数是在遵循策略 `π` 的情况下，给定当前状态时回报的期望值。符号 `𝔼` 是期望算子（稍后详述）。它指示你计算括号内项的期望值。而下标 `π` 告诉你智能体应遵循该策略来计算该期望。

等式右边的第三部分是括号内项的展开。你已从[公式 2-7](#ch02.html#eq_discounted_expected_return)了解 `G` 的定义。并且你知道需要从当前状态开始。此时括号内的数学含义基本上是在说“从这一点向前求和所有奖励”。

[公式 2-8](#ch02.html#eq_state_value_function) 有两个重要点。第一是期望算子。大多数 RL 算法假设奖励服从正态分布，期望可以按样本均值计算。换句话说，期望算子的结果是从该给定状态获得的平均折扣奖励。某些应用中的奖励可能不服从正态分布。例如，你会选择：一个巨大的单次奖励，还是许多小奖励？在这两种情况下均值相同，但奖励的分布不同。奖励的细微差别可能被期望算子掩盖。事实上，最近许多研究都集中在尝试评估和使用奖励的分布（参见[“分布式 RL”](#ch04.html#sec_distributional_rl)）。

第二个重要部分是策略。只有当你已有一个策略时，才能计算预期回报。但这个公式旨在帮助你量化策略的表现。这是一个经典的“鸡生蛋，蛋生鸡”问题，RL 通过从随机开始并迭代寻找改进来解决它。

### 使用状态价值函数进行模拟

我发现通过简单的模拟能增强我对公式的直觉。我开发了一个程序，模拟五个方格上的位置（即状态）。智能体从最左侧开始。在每个时间步，智能体可以向左或向右移动。如果智能体到达最右侧的方格 5（目标状态），或者智能体在方格 0 向左移动（掉下假想的悬崖），模拟结束。为了尽可能保持简单，策略是随机的，即在每个时间步随机选择向左或向右。

#### 提示

你应该持续考虑不同的环境。*过拟合*是指意外构建出仅适用于非常特定数据或情境的模型或算法的过程。例如，很容易将算法改进到过拟合你的模拟，却发现它在现实生活中行不通。工业级 RL 算法应当健壮，考虑不同环境是帮助算法*泛化*的一种方式。此外，使用不同环境是积累经验的重要途径。因此，我特意在整个示例中不断切换环境。

[公式 2-8](#ch02.html#eq_state_value_function) 的目标是计算每个状态的预期奖励。你可以通过记录智能体在每个*纪元*中的位置来做到这一点，纪元是指环境持续循环直到智能体到达终止状态。最终，你将获得一个奖励，然后你可以回溯查看沿途访问的所有状态。接着将奖励加到累积和中，并保持一个计数器，以计算访问所有那些状态后观察到的平均回报。

#### 提示

每当你进行实验时，设想一些理论期望或先验是明智的——定义假设是科学方法的核心。
