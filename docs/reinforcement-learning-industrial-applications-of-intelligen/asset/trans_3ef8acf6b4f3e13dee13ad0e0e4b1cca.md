
## RL 实施的最佳实践

*   拙劣或有缺陷的神经网络实现会让 RL 名声受损。从简单的东西开始，比如线性近似器或等效的单层神经网络。在尝试更复杂的网络之前，确保一切按预期工作。参考一本好的深度学习实战书籍以获取帮助（请参阅[“延伸阅读”](#ch11.html#sec_ch11_further_reading)）。
*   在扩展到多种子或多线程/多节点运行之前，确保一切在固定种子和单线程下都能正常工作。
*   从您过往其他实现经验中已知效果良好的超参数开始。

# 强化学习的未来

目前对 RL 的看法如何？这让我想起了 Andrew Ng 关于实用深度学习的那场近乎开创性的演讲，他在演讲中完美地平衡了健康的短期悲观主义与长期乐观主义。^([5](#ch11.html#idm46428618104472)) 这让我领会到了该主题的复杂性，尤其是在工业界实施方面，但同时乐观情绪让这些问题感觉只是过程的一部分。挑战客观存在，所以接受它们，以最好的方式应对它们，然后继续前进。有时深度学习讲不通，这也没关系。但当它奏效时，模型与数据的融合美不胜收。

我认为 RL 目前正处于这个位置。我们正处于工业化产品化和运营化成为可能但棘手的临界点。在许多情况下，更简单的算法仍然优于 RL；例如，如果您能够离线运行环境，那么您可以直接使用蒙特卡洛树搜索 (MCTS) 算法（如 AlphaGo）来评估可能的走法。例如，2014 年的一个实验使用 MCTS 碾压了 DQN 的性能，RL 方法花了一段时间才追上来。^([6](#ch11.html#idm46428618101608)) 但这没关系。RL 不是银弹，就像机器学习还没有诞生出人工智能一样。它只是一个工具。就像木匠一样，您应该为您的工作使用最好的工具。

## RL 市场机遇

深度学习已成为主流，因此即使是我的企业客户也在投资运营化。我相信 RL 将在未来几年内跟进。这开辟了新的市场和机遇。不幸的是，与机器学习一样，RL 是一种跨行业技术，而非解决方案。您将需要领域专业知识、特定行业的市场洞察力，以及一点灵感来利用 RL。

然而，已经有迹象表明 RL 特别适合特定领域。机器人技术是一个显而易见的例子。但自动竞价和推荐是其他可能在全球收入方面超越机器人技术的领域。目前还没有针对 RL 的全行业研究，但如果 RL 成功，这将会到来。

市场研究公司 Gartner 认为 RL 仍处于炒作曲线的上升期，三分之一的企业希望到 2023 年实现战略决策自动化（他们称之为决策智能）。^([7](#ch11.html#idm46428618093912),[8](#ch11.html#idm46428618092424)) 他们对市场价值含糊其辞，尤其是在量化特定技术影响方面，但据报道，其对全球商业的价值每年达数万亿美元。^([9](#ch11.html#idm46428618090888)) 有趣的是，在 Gartner 的一些可视化图表中，他们开始将“智能体”和“决策自动化”与其他更传统的机器学习形式（他们称之为“决策支持/增强”）分开，以便清晰地看到优化序贯决策的新兴价值。

这一前景意味着运营领域存在价值和机遇。公司将无法使用当前这一批机器学习即服务产品，因为大多数不太适合持续学习和序贯决策。当然，一些会适应调整，但这也为公司填补这一空白提供了机会。

开源项目也不会落后太远，甚至在许多情况下可能处于领先地位。有一种观点认为，只有开源项目才能真正成功，因为像机器学习一样，全球采用需要开放协作。否则，您的需求和挑战可能会与专有流程和观点发生冲突。如果您正在考虑这一点，请确保将您的产品定位在大型供应商可能感兴趣的领域之外。并确保思考您和全球社区如何从开源开发中互利共赢。

这也意味着公司在未来很长一段时间内都将需要 RL 支持和专业知识。RL 成为大宗商品可能需要长达 10 年的时间。因此，拥有可证明的 RL 专业知识的顾问和工程师（如我公司的那些）将备受追捧。如果您正考虑将 RL 作为职业专长，我认为这不会是一个坏决定，因为刚才讨论的明显机遇和预测。但不要因此而麻痹大意，产生虚假的安全感。RL、ML 和软件工程都很难，尤其是当您尝试将这些东西投入生产时。而且像任何知识型行业一样，目标桩不断移动。您必须接受这一点并随之变动，以确保在这个竞争激烈的领域中拥有长期的立足之地。要投入这么多精力，您真的必须热爱它。您必须享受这门技艺和逆境的挑战，享受面对前所未有的特定工业情境的挑战。

## 未来的 RL 与研究方向

RL 面临许多挑战，正如我全书所讨论的。不要让这些阻碍您探索 RL 的潜力，因为我真诚地相信，下一级人工智能将由这些思想驱动；它们只是在等待突破性的应用。但希望我已清楚地标明了 RL 的哪些部分会在解决工业问题时拖慢您的进度或导致您跌倒。这些问题大多转化为未来的研究机会。

研究方向大致可分为两类：工业研究和学术研究。工业研究由改进开发和运营效率的方法组成，由业务需求驱动。学术研究更侧重于改进或重新定义基础理解，由同行定义的理论上的新颖性或进步概念驱动。这意味着学术研究人员不会投入时间来提高代码的可读性，例如。同样，工业研究人员不太可能偶然发现真正开创性的东西。但当然，也有人处于两者之间。

### 警告

我认为目前学术机器学习界存在一个问题。学术成功的主要场所是会议和期刊。最受欢迎的场所可以挑三拣四，因此审稿人拥有很大权力来主导当前和未来的内容。不幸的是，应用被认为不如（例如）新颖的算法改进有价值。例如，Hannah Kerner 最近谈到了她试图将以应用为中心的论文推向会议的经历，结果却发现“其对机器学习社区的意义似乎有限”。^([10](#ch11.html#idm46428618078520)) 当然，基础改进是学术界和科学发现的总体主要目标，但我感觉天平倾斜得太厉害了。
