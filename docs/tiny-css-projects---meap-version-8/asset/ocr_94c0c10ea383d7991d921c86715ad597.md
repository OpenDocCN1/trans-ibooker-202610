Now let’s add a border radius of 50% which will make our image a circle. At this point though, the text does not follow the curve yet, we still need to add the shape-outside property.

We have margin around our image, that ideally we want the shape to respect, we are therefore going to use the margin-box value. Listing 7.9 shows this concept applied in code.

# Listing 7.9 Starting point

```
img.compass {
  aspect-ratio: 1;
  float: right;
  margin-left: 1rem;
  border-radius: 50%;
  shape-outside: margin-box;
}
```
