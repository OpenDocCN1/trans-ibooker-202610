# Listing 11.10 Transitioning the link size change

```
.share__link:link,
.share__link:visited {
  text-decoration: none;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  height: 48px;
  width: 48px;
  border-radius: 50%;
  border: solid 1px transparent;
  transition: transform ease-in-out 250ms;
}

.share__link:hover,
.share__link:focus-visible {
  border-color: black;
  outline: none;
  transform: scale(1.25);
  background:rgb(255, 228, 106);
}
```

In our transition we specifically tell the browser to animate the changes that occur on the `transform` property but we do not have a `transform` property in our `.share__link:link`, `.share__link:visited` rule. When we run the code, however, we notice that our size change is animated, and that the code does work. This is because when not defined, by default scale will equal `scale(1)`. We are therefore animating going from `scale(1)` to `scale(1.25)` when we hover or focus the link and then animating the scale back to `scale(1)` when moving away from the link.
