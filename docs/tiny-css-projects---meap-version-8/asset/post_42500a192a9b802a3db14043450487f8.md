## 11.7 Summary

- There are a number of ways to organize CSS, and three common patterns are OOCSS, SMACSS, and BEM
- Icons are subject to copyright
- Follow brand guidelines when using social media icons
- We can make a flexed element behave as an inline-level element by using `inline-flex`
- `inline-flex` uses the same properties as `flex`
- The position of an outline can be controlled via `outline-offset`
- The `scale()` function allows us to proportionally grow or shrink an element
- The `inherit` property value allows us to inherit values from the parent element that generally would not be inherited
- Transitions do not require keyframes
- Transitions allow us to animate CSS changes from one state to another
- The `overflow` property allows us to control whether elements that extend beyond their container should be seen or hidden
- When using JavaScript to extend our transitions’ functionality we can use the `ontransitionstart` and `ontransitionend` event listeners to trigger JavaScript change in response to the transition’s lifecycle
