# Listing 5.6 Layout for the cards

```
@media (min-width: 700px) { #A
  main {
    grid-template-columns: repeat(2, 1fr);
  }
  main > section {
    height: 350px;
  }
}
@media (min-width: 950px) { #B
  main {
    grid-template-columns: repeat(4, 1fr);
  }
}
```

#A Media query to determine if the browser window is at least 700px wide. If it is then use the styles within the query.

#B Second media query determines if the browser window is at least 950px wide. If it is then this overrides the previous query and sets grid to 4 columns wide

Figures 5.8 and 5.9 show the output in 800 and 1000 pixel wide browser windows.
