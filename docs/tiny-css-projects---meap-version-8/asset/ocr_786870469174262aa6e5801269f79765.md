To add the outline color for both the radio and checkmark when they are checked, we are going to use the :checked pseudo class again, to specifically select the control only when it is checked and change the border color to our accent color. In code this translates to what is shown in Listing 10.16. We use :is instead of :where because of specificity.

# Listing 10.16 Accent color outline for checked inputs

```
input[type="radio"],
input[type="checkbox"] {
  ...
  border: 0.1875em solid currentColor;
}

:is(input[type="radio"], input[type="checkbox"]):checked {
  border-color: var(--accent);
}
```

# 10.3.9 Calculating specificity with :is() and :where()

We mentioned earlier that :where has a specificity of 0, meaning it is the least specific selector available to us. We set our default border color in the following selector input[type="radio"], input[type="checkbox"] { ... } which has a specificity of 11, calculated using table 10.2 below. In each column we count the number of each type of selector, with columns A, B, and C forming the specificity value¹⁶.

# Table 10.2 Calculating Specificity

| :where(input[type="radio"], input[type="checkbox"]) | Ignores specificity rules and always equals 0 |  | 000 |
