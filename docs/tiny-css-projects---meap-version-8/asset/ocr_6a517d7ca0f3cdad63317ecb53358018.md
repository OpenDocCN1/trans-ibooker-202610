# 7.3.1 Shape-Outside: Circle

In order to make the text follow the curve of the compass we need to add a curve to the image for the text to wrap around.

The property we will use is shape-outside (https://developer.mozilla.org/en-US/docs/Web/CSS/shape-outside). Shape-outside allows us to define a shape around which the adjacent text will flow. This shape does not have to be rectangular either. It can be a

+   - Circle or ellipse
+   - Polygon
+   - Derived from an image - uses the alpha channel (transparency) of the image to determine what the shape should be
+   - Path - in the specification but not implemented on any browser as of this book being written (https://developer.mozilla.org/en-US/docs/Web/CSS/basic-shape#path())
+   - Box model value
