# 8.2 Theming

Although our layout has 2 clearly defined sections (the cart and the summary), and needs to work across screen sizes, there are styles that are not going to change regardless of where they are or the size of the screen. These include

+   - Fonts used
+   - Buttons and link styles
+   - Input and error message styles
+   - Header size and color

These types of styles can be referred to as our theme, and to keep them consistent across our page, we generally want to write them once and apply them everywhere. Let’s start with our fonts.

# 8.2.1 Typography

Currently our `font-family` is our browser’s default. In my case it is Times New Roman, but this may be different for you depending on your operating system, browser, and system settings. Figure 8.3 shows the default typeface and developer tools indicating that Times New Roman is being used. In most browsers, right clicking on the page and selecting inspect will open the developer tools. Since the font-family is not being explicitly set some browsers will obscure it and you may need to excitedly tell the browser to show all properties via a checkbox at the top of the computed list of properties or via the browser tools settings.
