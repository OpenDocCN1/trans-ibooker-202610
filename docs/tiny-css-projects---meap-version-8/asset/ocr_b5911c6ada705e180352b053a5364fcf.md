# 7.3.3 Shape-box

We can make a shape from an element’s shape which has been altered from its rectangular shape using border radius. We still use shape-outside but instead of passing in a shape we specify at which level of the box model we want the shape to form. Our options are

+   - margin-box: shape follows the margins
+   - border-box: shape follows the borders
+   - padding-box: shape follows the padding
+   - content-box: shape follows the content

Let’s start with a clean slate with our image being floated to the right and some margin to keep the text from crowding the image. Listing 7.8 includes our starting CSS while Figure 7.10 shows the current display.
