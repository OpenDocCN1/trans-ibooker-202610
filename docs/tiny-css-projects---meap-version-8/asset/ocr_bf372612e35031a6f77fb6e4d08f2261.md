We will not try to reinstate our colors in this mode, we want to respect the user’s settings but we do need to make sure that checked inputs are distinguishable from those that are not and that our select has an arrow to visibly denote it as a dropdown.

To create rules that are only applied to users that have forced-color set to active, we will use a media query of @media (forced-colors: active) { ... }. Rules created inside of the media query will only take effect when users have forced-colors enabled.

The reason our checkmark and radio are no longer visible is because the system defined background color (in this case white) is being applied to them. We will therefore change our background color to use a system color rather than our accent color. The CSS Color Module Level 4 specification¹⁹ defines the colors available for us. We are going to use CanvasText, meaning that the color we will apply will be the same as the color being used for the text.
