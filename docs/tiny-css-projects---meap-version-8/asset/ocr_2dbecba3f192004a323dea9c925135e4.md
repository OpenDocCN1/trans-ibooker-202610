Figure 10.38 Focus-visible on field elements

Our outline is visible and works well for all of our fields except our checkboxes, radios, and buttons, especially the submit button. To fix this we will change the outline offset so that instead of the outline being inside of the element, we will place it on the outside, 2 pixels away from the element. To accomplish this we add the following rule to our styles file (Listing 10.29).

# Listing 10.29 Focus-visible on radios and checkboxes

```
:where(input[type="radio"], input[type="checkbox"], button):focus-visible {
  outline-offset: 2px;
}
```

With the edits applied, our checkboxes, inputs, and buttons now look as shown in Figure 10.37 when navigated to or interacted with via keyboard.
