To place the header information before each piece of content, we aren’t going to be using the header. Instead in our HTML, we have added some data attributes to the cells: <td data-name="Item">Red Grapes, 1lb</td>. We move the table header offscreen using absolute positioning. We do not want to use a display none, as the information available in the header is still needed by assistive technologies. By absolute positioning it offscreen (using a very large negative value), we hide it visually but not programmatically.

Next we use the data-name attribute information, which we display in each cell. To display the attribute value we use the attr() function, which takes an attribute name and returns a value. For our use case, our content property will look as follows: td[data-name]:before { content: attr(data-name) ":"; }. Figure 8.19 breaks it down in detail.
