
# Accessibility and Justification

A word of caution: The Web Content Accessibility Guideline (WCAG) includes three levels of conformance which build upon each other A, AA, and AAA. A is the least restrictive, building up to AAA which is the most stringent. Most often, websites will aim for AA level of conformance, but if we are required to conform to AAA, it is worth mentioning that justifying text goes against accessibility guideline 1.4.5 which is a requirement for AAA⁴.

To justify our text we are going to use the text-align property which can take a value of left, right, center, or justify. We add `text-align: justify;` to our previously created paragraph rule.

Our paragraph rule now has 2 properties, text-align and line-height, which takes care of styling the paragraph. Listing 7.3 shows the completed paragraph rule.

## Listing 7.3 Completed Paragraph Rule

```
p {
  line-height: 1.5;
  text-align: justify;
}
```

## 7.1.3 First Letter

We do not need to add any tags to the HTML to select the first letter of our first paragraph, we can use the pseudo-class `:first-of-type` (https://developer.mozilla.org/en-US/docs/Web/CSS/:first-of-type) to select the first paragraph and then the pseudo-element `::first-letter` (https://developer.mozilla.org/en-US/docs/Web/CSS/::first-letter) to get to the letter, in this case a B, both of which can be chained. In code, this translates to `p:first-of-type::first-letter {}`.

## Pseudo-Class vs Pseudo-Element

A pseudo-class is added to a selector to target a specific state while a pseudo-element allows us to select a part of the element.

With the letter selected, we can now start styling it in order to make it look like a drop cap. To really make it stand out from the rest of the text, we are going to pick a more ornate typeface. In this particular case, we are going to use Passions Conflict (https://fonts.google.com/specimen/Passions+Conflict) seen in Figure 7.4, which we will import from google fonts.

![](img/b56145aa9b751926a7aedbd7172bc818_195_0.png)

Figure 7.4 Passions Conflict Glyphs

Because this typeface has particularly ornate capital letters, it will be well suited to use for our drop cap. We will also use it a little bit later on in this chapter to style the quote at the beginning of the chapter. Beautiful typefaces such as this one are a wonderful way of embellishing a page but only for very short bits of content. Handwriting and display fonts can be quite difficult to read and are therefore not well suited for large bodies of text. For a drop cap, large headers, or short quotes, however, they can be a great way to differentiate the element from the rest of the content and give the page some personality.

This particular font has glyphs that are quite a bit smaller than those of Times New Roman (the font we use for the rest of our content), and we are creating a drop cap which by definition is larger than the rest of the text, so we are going to have to adjust its size. We are also going to adjust the line height of the letter to make it fit nicely with the text. Finally we are going to float it to the left so that the text flows around the letter, accomplishing our desired effect.

The float property places an element to the right or left of its container based upon the value it is passed. Inline elements around it (our text) will use the leftover space to wrap around the floated element. The float property can take one of three properties:

- Left
- Right
- None (element is not floated)

Since our text is in english which flows from left to right, we want to keep the letter B to the left. We are therefore going to float the first letter of the first paragraph (B) to the left by adding `float: left;` to our rule. Listing 7.4 shows the completed CSS rule we created to style our drop cap as well as the import of the Passions Conflict typeface. Figure 7.5 shows the output generated.

## Listing 7.4 Drop Cap

```
@import url(
  'https://fonts.googleapis.com/css2?family=Passions+Conflict&display=swap'
);
p:first-of-type::first-letter {
  font-size: 6em;
  float: left;
  line-height: .5;
  font-family: 'Passions Conflict', cursive;
}
```

We use ems and a unitless line-height so that if we were ever to change the font size of the paragraph, the drop cap would scale accordingly since the value of 1 em is set based on the font-size of the parent element which in this case is our paragraph tag.

To reposition our B to fit well with the text, we edited the line height of the letter. Another technique we could have used would have been to set the position of the B to relative, and then use top, bottom, left, and right, to alter its position relative to the rest of the text.

## 7.3.1 Shape-Outside: Circle

In order to make the text follow the curve of the compass we need to add a curve to the image for the text to wrap around.

The property we will use is shape-outside (https://developer.mozilla.org/en-US/docs/Web/CSS/shape-outside). Shape-outside allows us to define a shape around which the adjacent text will flow. This shape does not have to be rectangular either. It can be a

- Circle or ellipse
- Polygon
- Derived from an image - uses the alpha channel (transparency) of the image to determine what the shape should be
- Path - in the specification but not implemented on any browser as of this book being written (https://developer.mozilla.org/en-US/docs/Web/CSS/basic-shape#path())
- Box model value
