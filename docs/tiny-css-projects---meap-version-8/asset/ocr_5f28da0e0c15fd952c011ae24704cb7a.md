We will apply an outline that is solid, 2 pixels in width, and uses our accent color. This will not only style our outline but also replace the browser’s default hover state outline with one we styled specifically to match our theme. This does look a bit off on fields that have our invalid styles hover. We can see from Figure 10.36 that not only do the border and outline clash but the border also encroaches on the error message.

To prevent the clash between the outline and the border, we make the outline use our error color when the field is dirty and invalid. Since we have plenty of padding, for all fields, we will inset the border so that it does not end up so close to the error message. To inset the outline, we will give the outline-offset property a negative value. We end up with the 2 rules shown in Listing 20.28.

# Listing 10.28 Focus-visible on form fields and button

```
:focus-visible {
  outline: solid 2px var(--accent);  #A
  outline-offset: -2px;              #A
}

.dirty:invalid:focus-visible {      #B
  outline-color: var(--error);       #B
}
```

#A all elements get an outline when they are focused
#B when the element is dirty and invalid we change the outline color to red
