# 7.2 Styling the quote

The quote at the top of the page is rather drab at the moment, and gets a little lost in the rest of the text. To make it stand out we are going to use the same font we used for our drop cap. Because of the previously mentioned differences in size and line height, we are going to adjust them so that the paragraphs and the quote look uniformly sized and spaced. Listing 7.6 shows the CSS we will add to accomplish this task, and Listing 7.6 shows the output.

```
Listing 7.5 Blockquote
```css
blockquote {
  font-family: 'Passions Conflict', cursive;
  font-size: 2em;
  line-height: 1;
}
```
```

![](bbox=[0.18, 0.36, 0.88, 0.66])

Figure 7.6 Blockquote

Again we use relative units so that should the rest of the content’s font size change, so will the quote. You may have noticed that we used a line-height of 1 even though we stated above that for optimal legibility a line height of 1.5 to 2 would be ideal. We make an exception here because observing the output, we see that by default the font already has a very large line height, we do not need to increase the size. This can occur on occasion especially when dealing with cursive or display fonts.

With our text taken care of, we can now focus on the images.
