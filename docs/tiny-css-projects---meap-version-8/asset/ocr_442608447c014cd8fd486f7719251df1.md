Our starting CSS (Listing 5.2) includes some base styles to set up our page. For the body we are just increasing the margin by 40px and adding a padding of 20px to all 4 sides. We are also using Google Fonts again, but this time we are using the font family Cardo with a regular weight but the italicized version, which will be used for the description of each card.

For the headers we will use Rubik with both regular and bold weights. This font is a good choice because it combines good readability with rounded edges, which provide a sense of informality that works well with the Cardo font.
