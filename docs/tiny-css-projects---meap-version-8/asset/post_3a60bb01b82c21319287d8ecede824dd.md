## 5.2 Laying out the page using grid

A good starting point is to look at the layout of our cards and the web page as a whole. We need to consider 3 aspects of our layout:

- The header and main content
- The container for the cards
- The content within the cards

We will use the grid layout module for all 3 use cases.

> **Grid**
> Grid allows us to place and align elements across both the vertical and horizontal axis on a system of columns and rows.
> 
> Check out chapter 2 if you need a refresher on how grid works.

To lay out the elements on our page we will start with creating the styles for narrow screens and then edit the layout as we build up to larger screen sizes via media queries.

Our layout consists of 2 landmarks, <header> and <main>, which are immediate children of <body> (Listing 5.3). By giving the body a display property a value of grid we will be affecting the position of the header and main elements.

```
Listing 5.3 Starting HTML
<body>
  <header>  #A
  ...       #A
  </header> #A
  <main>    #B
  ...       #B
  </main>   #B
</body>
```

#A Contains the page header
#B Contains the cards

We then use the place-items property to center the elements on the page. This property is the short-hand for combining declaring values for the align-items and justify-items properties. We will set its value to center, aligning all the items in the middle of their respective rows and columns. Our updated body rule is shown in Listing 5.4.

### Listing 5.4 Positioning the header and main elements

```
body {
  display: grid;
  place-items: center;
  margin-top: 40px;
  padding: 20px;
}
```

Notice that we have not defined any grid-template-rows, grid-template-columns, or grid-template-areas. By default, when none are declared, the browser will still create a 1 column grid with as many rows as there are elements to position. In our case, we have 2 therefore our grid has 1 column and 2 rows (Figure 5.5).

![](img/b56145aa9b751926a7aedbd7172bc818_134_0.png)

Figure 5.5 1 by 2 grid

The header and main’s widths are altered by being within the grid to only take as much horizontal space as their content requires. Since the header has narrow content (the h1 containing the word Hotels) the page title centers itself to the page. The main element takes the full width available to it because the description of Flamingo beach (in the second card) needs the full width, and even wraps. If we extend the width of the screen further, we will see that the main element also centers itself (Figure 5.6).

![](img/b56145aa9b751926a7aedbd7172bc818_135_0.png)

Figure 5.6 Centered Main on a very wide screen

We will also rely on the default functionality of the grid and omit defining rows and columns because we want to keep the cards stacked on narrow screens. To add space between cards, we include a gap of 1rem. We also restrict the width of the main element to a maximum of 1024 pixels to prevent our cards being too spaced out on wide screens once we align them horizontally for on wide screens in the next section.

Our updated CSS (Listing 5.5) keeps the cards stacked but adds a 1rem gap between each card as seen in Figure 5.7.

### Listing 5.5 Positioning the cards on narrow screens

```

  display: grid;
  max-width: 1024px;
  grid-gap: 1rem;
}
```

### 5.2.1 Media queries

At the moment our cards are vertically stacked. This is the default behavior in most cases with HTML elements and makes sense on mobile devices where device width is rather narrow. However, for desktop screens, where the browser window can be much wider, we can take advantage of the horizontal space by using media queries. We can define some media queries to adjust the layout.

- 1. If the window width is greater than or equal to 700px, we adjust the grid to have 2 equally sized columns, and set the height of each section to exactly 350pixels.
- 2. At 950 pixels, we adjust the layout again to have 4 equally sized columns overriding the grid-template-columns value set in the previous media query. The height property value still remains 350 pixels since the condition for the previous media query (min-width: 700px) is still being met.

```
min-width: 700px
```

If neither of the requirements for these media queries are met (when the browser window is less than 700px wide) then the cards will be stacked vertically in a single column. Listing 5.6 shows the 2 media queries being created.
