In Chrome, we can use dev tools to emulate having forced colors mode enabled on our machine without having to actually edit our computer settings. In our dev tools, in the console area, we choose the rendering tab. If it is not already showing, we can select the ellipsis button to show the list of possible tabs and select it from the dropdown. In the tab we then look for the forced-color memulation drop down and set it to forced-colors: active. This will update the page’s styles to act as if we had forced-colors set to active on our machine. Figure 10.39 shows the Chrome dev tools settings to enable the emulation. (Note: different browsers may or may not have this functionality and how to enable it may be different.)
