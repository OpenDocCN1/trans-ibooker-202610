We can choose to right justify the text inside of the input field just in this table view or all the time regardless of screen size. Since we had right aligned our numbers and totals in the mobile view as well it seems logical to include as part of our theme that text inputs that are of type number should have their text right aligned as well. To specifically select inputs of type number, we can use an attribute selector: input[type="number"] { ... }. With our other theme styles, we will therefore add input[type="number"] { text-align: right; }

With the text inside of the input fields aligned, the last piece we need to consider for the table is the footer which contains a header and a cell. Because we earlier only selected cells after the first 2 of a row, the cells in the footer were not affected as it only has 2 cells total. We want both the header and data cell's content to be right justified, which we can select by specifically targeting the th and td in the tfoot itself as seen in Listing 8.20.
