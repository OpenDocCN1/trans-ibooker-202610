Next we will add some default borders. Like padding, styles related to the border property can be set individually or by using the shorthand border property which takes a style, width, and color. We are going to set ours to solid 1px #ddd which will produce a 1 pixel wide solid gray line around our elements. We will also curve our corners using the border-radius property.

Finally, because we are applying this rule to links, and links are underlined by default, we are going to remove the underline from the links by setting the text-decoration property to none.

Our base rule for our buttons, and links with a class of button, is shown in listing 8.3.

With the default state of the buttons taken care off we will now add style changes for when a user hovers over the button with their mouse or focuses on it via their keyboard. To achieve this goal we will use the :hover and :focus pseudo classes.

> NOTE Pseudo-Classes :hover and :focus' impact on accessibility A pseudo-class is added to a selector to target a specific state. Adding style changes on hover and focus is important for accessibility as it provides visual feedback. It lets the user know that the item can be interacted with. When using keyboard navigation, style changes on focus let the user know which element they are about to interact with. Without these visual cues it is very difficult to know what is clickable and where you are currently focused.

On hover we are going to add a dotted teal outline around our buttons and to give it some breathing room we are going to offset the outline by 2 pixels. We will use 2 properties, outline and outline-offset. Outline works very similarly to border taking the same three properties: style, width, and color. Outline-offset takes a length value (which can be negative) that dictates the amount of space we want between the outline and the edge of the element.
