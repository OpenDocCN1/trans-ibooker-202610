little differently. We want to right align all columns after the first 2. Inside of :nth-of-type() we can pass numbers, but also patterns. Earlier we used this trick when we set our background colors on our rows by passing it a parameter of even. In this case we are going to pass it a custom pattern. We are going to pass it a parameter of n + 3, indicating that we want to select all matching elements starting with the third instance where n is the iterator and 3 is the starting point. Listing 8.19 shows how this is applied to the table.

  }
