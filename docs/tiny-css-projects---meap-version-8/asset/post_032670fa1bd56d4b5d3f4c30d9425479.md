## 10.3.8 Using CSS shapes to create the checkmark

Shaping our radio inputs was pretty simple, we used border-radius and achieved a disk shape. A checkmark is not quite as simple of a shape. To create it we will use clip-path.

> NOTE Clip-path Clip path allows us to create shapes by creating a clipping region that defines which part of the element should be shown versus hidden. We've used clip-path before in chapters 5 and 7 if you want a refresher

To create our checkmark, the shape we will apply to the clip-path is a polygon which will create our checkmark. Polygons are created by setting a series of X and Y percentage based coordinates between which a line is created. The (0, 0) coordinate is the top left corner of the shape. If the shape is not explicitly closed, it will automatically join the first and last points. Our polygon function will be: polygon(14% 44%, 0% 65%, 50% 100%, 100% 16%, 80% 0%, 43% 62%). Figure 10.21 explains the point by point construction of the shape.

## 10.3.9 Calculating specificity with :is() and :where()

We mentioned earlier that :where has a specificity of 0, meaning it is the least specific selector available to us. We set our default border color in the following selector input[type="radio"], input[type="checkbox"] { ... } which has a specificity of 11, calculated using table 10.2 below. In each column we count the number of each type of selector, with columns A, B, and C forming the specificity value¹⁶.

### Table 10.2 Calculating Specificity

| Selector | A ID selectors (x100) | B Class selectors, Attribute Selectors, & Pseudo Classes (x10) | C Type Selectors, pseudo elements (x1) | Specificity |
|---|---|---|---|---|
| :where(input[type="radio"], input[type="checkbox"]) | Ignores specificity rules and always equals 0 |  | 000 |
| :where(input[type="radio"], input[type="checkbox"]):checked | Ignores specificity rules and always equals 0 |  | 000 |
| input[type="radio"] | 0 | 1 | 1 | 011 |

| input[type="radio"]:checked | 0 | 2 | 1 | 021 |
|:is(input[type="radio"], input[type="checkbox"]):checked | 0 | 2 | 1 | 021 |

Since :is will base its specificity value to be the value of the most specific selector within it, in our particular case, its specificity will be 11 plus another 10 for the :checked, giving us a specificity of 21. Since 21 is greater than 0 we override the styles and our border becomes our accent color.

### 10.4.2 Using linear-gradients to create an arrow

Our next order of business will be to create a new arrow whose positioning we can control. Remember at the beginning of the chapter, we used a gradient to create a circle? We are going to use this trick again to create our arrow which we will add to our dropdown using the background-image property.. Instead of a radial-gradient however, we will use a linear-gradient.

Much like radial-gradient, linear-gradient will take a series of colors and percentages for when they should start and stop, but instead of the colors being displayed in a circular fashion around a center point, they will be placed in a linear fashion towards a side or corner. It can also take an angle to dictate the direction of the lines of color. Table 10.3 shows the angle and their keyword equivalents when dictating the direction of the lines of color.

Table 10.3 Keyword and Angle Equivalent

| Keyword | Angle in degrees |
|---|---|
| to top | 0 |
| to bottom | 180 |
| to left | 270 |
| to right | 90 |

Same as with the radial-gradient, if we stop and stop a color at the same percentage, we will get a sharp line rather than a fade from one color to another.

The background-image property allows us to add multiple images to our background. We are going to exploit this functionality. We will need three overlapping gradients to create our arrow which will all be assigned to our background-image property.

We first give our background a height and width of 1rem, creating a square. We then set the background image to our three gradients. The first value will be on top, the last on the bottom. Working from the bottom to the top, we start with a gradient that goes from accent color to accent color. In other words, we create a blue box. We then create a second gradient that is placed on top of the square. Our second gradient splits the box from bottom left to top right, where the top is transparent and bottom is our background color. This creates a triangle obfuscating the bottom right of the box. Our third will be the opposing diagonal, from top left to bottom right with again, the top transparent, and the bottom our background color. This creates another triangle which obfuscates the bottom bottom left of the box. This leaves an inverted blue triangle 1rem wide and half a rem tall exposed. Figure 10.26 illustrates the process.

![](img/b56145aa9b751926a7aedbd7172bc818_279_0.png)

Figure 10.26 Creating an arrow from superimposed gradients

All that is left is to position our background and prevent it from repeating. We want the background to be 1rem from the right side of our control and centered. We can use the calc() function to do the math for us. To calculate the horizontal position we take the full width (100%) and subtract 1rem. For the vertical positioning, we know that we have 1rem of padding top and bottom plus our text which also has a size of 1rem making our control 3rem in height. We can therefore position our arrow at 50% below the top. Since the height of the arrow is only half a rem, we then add ⅓rem to the top position.

All put together we get the following rule for our select (Listing 10.18):

### Listing 10.18 Styled Select

```
select {
  appearance: none;
  width: 100%;

  background-image:
    linear-gradient(225deg, transparent 50%, var(--background) 50%),
    linear-gradient(135deg, transparent 50%, var(--background) 50%),
    linear-gradient(var(--accent), var(--accent))
  ;

  background-size: 1rem 1rem;
  background-position: calc(100% - 1rem) calc(50% + .33rem);
  background-repeat: no-repeat;
}
```
