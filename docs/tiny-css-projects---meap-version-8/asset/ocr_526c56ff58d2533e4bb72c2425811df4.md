Next we add margin to the right of the element so that the label text does not butt right up against it.

Finally we need to handle border-radius. This is where the checkbox and the input fields diverge since the chexbox is a square and the radio is circular. Since our fields have very rounded edges, we are going to add a small border-radius (4px) to the checkbox. To make the radio circular, we will add a border-radius of 50%, which will make the box appear circular.

The rules for our checkbox and radio inputs therefore look as follows (Listing 10.10):

# Listing 10.10 Radio and Checkbox Styled

```
input[type="radio"],
input[type="checkbox"] {
...
  display: inline-grid;
  place-content: center; #A
  width: 1.25em;
  height: 1.25em;
  border: 0.1875em solid currentColor; #B
  margin: 0 .5rem 0 0;
}

input[type="radio"] { border-radius: 50%; }

input[type="checkbox"] { border-radius: 4px; }
```

#A will automatically center the inner disk and checkbox inside the element once we create them
#B We also set the border width in em so that the thickness of the border will scale with the font size
