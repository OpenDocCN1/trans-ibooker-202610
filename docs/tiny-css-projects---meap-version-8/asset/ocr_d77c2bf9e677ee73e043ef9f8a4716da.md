Let’s go ahead and add the fill color to our rectangles. Because they aren’t all the same color (they have varying colors of blue green to give the loader a bit of a gradient effect), rather than giving each element a class, we are going to use the pseudo-class nth-of-child(n) which matches elements based on their position within the parent item. We will look for the nth rectangle, to which we will apply the fill. Therefore, section rect:nth-of-type(3), would find the third rectangle of the section container.

**REMEMBER:** A pseudo-class targets the state of an element. In this case its position relative to its siblings.

Listing 3.5 shows the fill color applied to each of our rectangles.
