# 8.2.6 Cards

To give the layout some depth and separation between the sections we are going to style each of our sections' containers as cards. Cards are a commonly used pattern in UI design to visually separate content by encapsulating it inside of a visual box or container reminiscent of a playing card. This is the same concept to the card we created for our profile information in Chapter 6.

To pull off our card design we are going to add a very pale teal background to the body, and outline the sections using a shadow which will make it look like they are hovering slightly above the body. To create the shadow we will use the box-shadow property which allows us to control the amount of shadow we want to add in the x and y axis, as well as the amount of blur (how fuzzy), the distance it should spread, and the color the shadow should be. Figure 8.14 details how the property values are applied.

```
box-shadow: 2px 2px 7px 0 #aeb7b7;
```
