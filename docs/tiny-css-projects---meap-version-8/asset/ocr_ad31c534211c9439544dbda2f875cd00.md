# 10.4.1 Select styling limitations

Before we go about fixing the select to match our other styles, let’s first address some of the limitations we are going to encounter. select, like the radio and checkbox inputs, gets a lot of its styles and functionality from the operating system itself. We are therefore going to be limited in what we can style with CSS alone, especially the options list. We can use JavaScript and ARIA to replace the entire control but since this is a book about CSS, we are going to style as much as we can with CSS alone and stop there.

Like we did with the radios and checkboxes, we will first start by removing as much of the native styles as we can by using the appearance property and give it a value of none. We will then set its width to 100% to make it take the full width of the container. With our drop down devoid of its native appearance and correctly sized as seen in Figure 10.25, we can focus on reinstating the arrow. Notice that the arrow is gone but that our options were not affected by adding appearance: none.
