use the `font-variant-numeric` (https://developer.mozilla.org/en-US/docs/Web/CSS/font-variant-numeric) property which lets us set how we want our numbers to display.

This lesser known property is very handy when handling numbers as it allows us to control multiple facets of how they are displayed including:

+   - Whether zeros are displayed with a slash in them
+   - How the numbers are aligned
+   - How fractions get displayed

We are going to use a `font-variant-numeric: lining-nums` which will change our number from old style to modern figures. Figure 8.5 shows the summary section before and after having the `font-variant-numeric` property to our body rule. In the before version we can see that the numerals have different sizes while the after version they are aligned and regularly sized.

Lastly we are going to change the color of our headers to teal.

We have now set the base typography for our page. We applied it directly on the body tag so that other child elements within our page will inherit the values. Listing 8.2 shows the rule we have constructed up to this point.

# Listing 8.2 Typography related styles applied to the body element

```
body {
  font-family: 'Raleway', sans-serif;
  color: #171717;
  font-variant-numeric: lining-nums;
}

h1, h2 {
  color: #2c6c69;
}
```
