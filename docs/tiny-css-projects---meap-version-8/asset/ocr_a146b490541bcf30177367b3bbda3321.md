With the space between the article and the date handled, let’s turn our attention to the space between the columns. To add a gap between our vertical lines and our text we use column-gap property. The column-gap property defines the amount of white space we want to have between our columns; we will set ours to 42px;

We continue to add these styles inside of the media query as seen in listing 4.12 because we only want them to apply when our layout is columned. We do not want these style changes to apply to narrower screens.

# Listing 4.12 Updated media query and article rule

```
@media (min-width: 955px) {
  article {
    column-count: 3;
    column-rule: 2px solid #333333;
    column-gap: 42px;
    margin-top: 36px;
  }
}
```
