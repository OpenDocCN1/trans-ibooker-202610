## 8.2.2 Links and Buttons

We have several links and buttons on this page but stylistically, they all look like buttons. They can be generally categorized by their purpose.

- Primary Call To Action: the proceed to checkout link
- Secondary Call To Action: Continue Shopping
- Destructive: Button with an X to remove items from the cart

We are going to use this categorization to name our classes in order for our rules to be easily reusable. In this chapter, we are only dealing with a single page, but this is an anomaly. In a full application we have multiple pages or components which will reuse the same styles, so instead of naming our class something like "proceed-to-checkout" we are going to use "primary" so that the class can easily be reused in a different context.

Before we address the differences between each of them, let’s first consider their similarities and write a baseline for all of our links that look like buttons (which were given a class of button) and buttons. Once we have written a baseline, we will make rules for each of the button types above.

To create our baseline, the first thing we will do is remove the default gray background set by the browser using background: none. Next we add padding.

We have 2 options on how we set our padding.

1. We can set each side individually using padding-top, padding-right, padding-bottom, and padding-right.
2. We can use the shorthand padding property which allows us to pass 1 to 4 values.

Figure 8.6 shows the breakdown of how the values are applied when using the shorthand property.

![](img/b56145aa9b751926a7aedbd7172bc818_219_0.png)

Figure 8.6 Padding property shorthand

We will use the shorthand property. We will pass 2 values (1ex and 1ch) to the padding property, the first will handle the top and bottom padding, while the second will handle left to right.

Next we will add some default borders. Like padding, styles related to the border property can be set individually or by using the shorthand border property which takes a style, width, and color. We are going to set ours to solid 1px #ddd which will produce a 1 pixel wide solid gray line around our elements. We will also curve our corners using the border-radius property.

Finally, because we are applying this rule to links, and links are underlined by default, we are going to remove the underline from the links by setting the text-decoration property to none.

Our base rule for our buttons, and links with a class of button, is shown in listing 8.3.

## Listing 8.3 Base styles for buttons

```
button, .button { #A
  background: none;
  border-radius: 4px;
  padding: 1ex 1ch;
  border: solid 1px #ddd;
  text-decoration: none;
}
```

#A this rule will be applied to all button elements and to all elements with a class of button

With the default state of the buttons taken care off we will now add style changes for when a user hovers over the button with their mouse or focuses on it via their keyboard. To achieve this goal we will use the :hover and :focus pseudo classes.

> NOTE Pseudo-Classes :hover and :focus' impact on accessibility A pseudo-class is added to a selector to target a specific state. Adding style changes on hover and focus is important for accessibility as it provides visual feedback. It lets the user know that the item can be interacted with. When using keyboard navigation, style changes on focus let the user know which element they are about to interact with. Without these visual cues it is very difficult to know what is clickable and where you are currently focused.

On hover we are going to add a dotted teal outline around our buttons and to give it some breathing room we are going to offset the outline by 2 pixels. We will use 2 properties, outline and outline-offset. Outline works very similarly to border taking the same three properties: style, width, and color. Outline-offset takes a length value (which can be negative) that dictates the amount of space we want between the outline and the edge of the element.

Focus will have the same styles as hover, but instead of the outline being a dotted line, we will make it a solid line. Listing 8.4 shows our final CSS for both the hover and focus states.

## Listing 8.4 Button hover and focus states

```
button:hover,
.button:hover {
```

```
outline: dotted 1px #2c6c69;
outline-offset: 2px;
}

button:focus,
.button:focus {
  outline: solid 1px #2c6c69;
  outline-offset: 2px;
}
```
