# 10.6 Styling the buttons

We have two buttons at the bottom of our form. The first performs our primary action, "Send". The second, "Reset" performs a secondary action. We will therefore make the "Send" button much more prominent than our reset as it is the most likely to be used and the behavior we desire the user to perform. The reset is there as a tool or utility to help the user but should not be our primary focus.

# 10.6.1 Resetting the button styles

We will first reset the button styles to match our theme and then differentiate where needed for our two use cases. We create a rule with a button selector, which applies to all buttons removing the border and background, setting our typography preferences, adding padding and marring, adding a border-radius, and changing the cursor to a pointer. Our base styles are shown in Listing 10.21.

# Listing 10.21 Reset button styles

```
button {
  border: none;
  background: none;
  border-radius: 36px;
  padding: 1rem 3rem;
  font-family: var(--font-family);
  font-size: 1rem;
  cursor: pointer;
}
```
