To really make the pictures pop, we will add a very dark gray almost black background to the entire page completing the project.

To apply the background color we will add the background property with a value of #010101 to our existing body rule (Listing 5.17).

# Listing 5.17 Adding the background

```
body {
  display: grid;
  place-items: center;
  margin-top: 40px;
  padding: 20px;
  background: #010101;
}
```
