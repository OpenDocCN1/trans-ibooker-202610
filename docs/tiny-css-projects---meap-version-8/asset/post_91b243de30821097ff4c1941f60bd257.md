Let’s first take a look at using shapes.

To define our circle, we are going to use the circle function. Circle takes a radius property and an optional position property which defines where the center of the circle should start. If the position property is omitted, the origin of the circle will default to the center of the image.

```
circle( [<shape-radius>]? [at <position>]? )
```

In our case we do want the center of the circle to be the middle of the image so we will not pass a position. However, we will have to define a radius. We are going to set it to 50% (we want the radius to equal half of the width of our image) which under the covers will resolve to the square root of our width squared plus our height squared divided by the square root of 2.

radius = % × √(height² + width²) / √2 = .5 × √(175² + 175²) / √2 = 87.5

Since our image is square and has a width of 175, when passing a radius of 50% it’s very logical that our radius would be 87.5, however, if the image were to be rectangular, understanding how a percentage based radius is calculated is quite important to understand what the resulting output will look like.

If we had a landscape image of height 100px and width 300px, the radius of the circle, we choose a percentage based value, is much less obvious. We can use the formula above to calculate what the radius would be.

radius = % × √(height² + width²) / √2 = .5 × √(100² + 300²) / √2 ≈ 111.8

Back to our image, it is square, so we use a shape-outside property with a value of circle(50%) to our image. Listing 7.6 shows our CSS rule.

Our image is square, so it has an aspect ratio of 1 (width / height = 175 ÷ 175 = 1).

ASPECT RATIO: The aspect ratio of an image is the proportional relationship of the image's height and width calculated by dividing the width by the height.

Adding the aspect ratio is not strictly necessary to create our shape but will help reduce layout shifts on load.

LAYOUT SHIFTS: When an element is added to the page, or its size is changed, everything after the element moves to make room for the element or fill in the void left behind. The movement of elements on the page is referred to as a layout shift.

When the image has a set height and width or has a defined aspect ratio, the browser can save room for the image while it is being loaded and therefore reduce this movement. It is therefore good practice to define aspect ratios and or a height and width for our images.

## Listing 7.6 shape-outside

```
img.compass {
  aspect-ratio: 1; #A
  float: right;  #B
  shape-outside: circle(50%); #C
}
```

#A Aspect ratio
#B Float the image to the right
#C Add our circle with a value of 50%

## 7.3.2 Clip-Path

This works because our image has a transparent background. We’ve curved the text, but the image is still quite square. If we add a background to the image, this becomes obvious. To make the image appear truly circular we need to add a clip-path (https://developer.mozilla.org/en-US/docs/Web/CSS/clip-path). Clip-path also takes a shape so we are going to pass it the same value we passed to shape-outside. We are also going to add some margin to our image to add a little bit of breathing room between it and the text. Listing 7.7 shows the complete css for our image.

## Listing 7.7 clip-path

```
img.compass {
  aspect-ratio: 1;
  float: right;
  shape-outside: circle(50%);
  clip-path: circle(50%);
  margin-left: 1rem;
}
```

We added a clip-path that matches our shape outside and a some margin to the left of the image to prevent the text from getting too close to the image especially since the compass has arrows protruding from the circular outline not accounted for by our circle. ## 7.3.3 Shape-box

We can make a shape from an element’s shape which has been altered from its rectangular shape using border radius. We still use shape-outside but instead of passing in a shape we specify at which level of the box model we want the shape to form. Our options are

-   - margin-box: shape follows the margins
-   - border-box: shape follows the borders
-   - padding-box: shape follows the padding
-   - content-box: shape follows the content

Let’s start with a clean slate with our image being floated to the right and some margin to keep the text from crowding the image. Listing 7.8 includes our starting CSS while Figure 7.10 shows the current display.

We notice that unlike when we used shape-outside with the circle function, our image is already cropped into a circular shape eliminating the need to use clip-path. This is a direct result of using border-radius, which is doing the clipping for us.

We have seen two different ways to accomplish the same outcome. Like many things in CSS, there is more than one way to approach any singular problem. This is one of these situations. Neither option is particularly superior to the other, in this case it is a matter of preference.
