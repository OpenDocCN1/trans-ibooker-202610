# 8.5 Wide screens

As we continue to increase the width of the screen, however, the summary section becomes harder to read because of the increasing distance between the definition titles and descriptions. Since, as we get wider, we have more horizontal real estate to play with, we will bring the summary section up beside the cart section once the viewport reaches 995 pixels wide or larger. Same as before we will create a media query: @media (min-width: 995px) { }.

In our HTML we have a container div around our 2 sections with a class of section-container. We will give it a display of flex for the 2 items to come side by side and align themselves on the x-axis. We will then add a gap of 1 rem between the 2 sections.

NOTE Flexbox Flexbox allows us to place and align elements on a single axis. Check out chapter 6 if you need a refresher on how flexbox works.

Flexbox will auto-calculate the amount of space to give each section based upon its content unless we use grow and shrink to instruct it otherwise. Rather than use grow and shrink which are ratio based, we are going to give the summary section a minimum width, preventing the chances of the text wrapping (unless the text is being scaled by the user) and leaving the rest of the available space to the table.

If we take the screen even wider, such as with the extra wide curved displays, we eventually get to a point where the content becomes unreadable once more. To prevent this from happening we will add a final condition limiting the width of our layout. By applying a maximum width to the body, we ensure that no matter how wide of a display the user has, and chooses to extend the window to, the content remains usable. We can then center the body by giving it a left and right margin of auto.

Listing 8.21 shows our media query and its contents as well as the edit to the body layout rule to cap the width the body will take.

# Listing 8.21 Wide screen media query and maximum width

```
body {
  padding: 1rem;
  max-width: 1280px;  #A
  margin: 0 auto;    #A
}

@media (min-width: 995px) {
  .section-container {  #B
    display: flex;      #B
    gap: 1rem;          #B
  }

  .summary {
    min-width: 250px;
  }
}
```

#A Preventing the content from getting any wider than 1280 pixels wide and centering the body.
