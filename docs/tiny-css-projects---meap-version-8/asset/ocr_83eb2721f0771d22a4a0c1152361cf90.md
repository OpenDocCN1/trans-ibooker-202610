Figure 10.11 Textarea Resize Issue

The textarea extends outside of the container in an unsightly fashion. When we resize vertically, the container resizes appropriately but this is not the case horizontally. By changing the texarea’s resize property’s value from its default of both to vertical, we can limit the user’s ability to resize the textarea. They will continue to be able to change its height but no longer the width. Visually the textbox still looks the same, and still has the control on the bottom right to resize it as demonstrated by Figure 10.12. When the user interacts with the resize control however, they will be constrained to only resizing vertically.
