In order to eliminate the gaps and make the border set on the row appear, we need to apply the border-collapse property to our table with a value of collapse. This property allows us to control whether we want each cell to have its own border, or whether they share a border. To eliminate the gap we want them to share a border.

Listing 8.12 shows the properties applied to the table in order to fix the borders and make the table take the full width of the page.

# Listing 8.12 Table borders and width

```
table {
  width: 100%;
  border-collapse: collapse;
}
```
