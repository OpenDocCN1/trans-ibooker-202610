When adding vertical padding to an inline element, the height of the element does not actually increase inside of the flow of the page, it will only take up as much room as its content (the text) which is why it is not increasing the height of the card. To fix this issue, will change their display value from inline to inline-block. Listing 8.14 shows the code necessary to style the cards and fix the links.
