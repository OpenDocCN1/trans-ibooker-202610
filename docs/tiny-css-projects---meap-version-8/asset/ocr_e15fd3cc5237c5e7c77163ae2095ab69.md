Figure 5.17 Moving the content down

Since we are going to animate showing the content when the user hovers off the section, we do not want the trailing content at the bottom to remain because if the user hovers on the content bleeding out of the picture, the content will move upward into the picture, lose the hover and then move back down again. This behavior will repeat creating a flicker. We will therefore set a height of 5rem for our inner container and hide the overflow when the paragraph and link are hidden.

Notice that in the second card, a little bit of the paragraph content will still be visible when the content should be hidden. We will therefore also hide the non header content using opacity, when it should not be seen. Additionally, we move that content down 1rem using translateY which will allow us to give it a little bit of motion when we animate it back in on hover.
