Although redundant, because of specificity, and being able to override our previously set border styles, we can't just add input inside of our :is pseudo class. Notice that we need to include both input, which will change the border color on the radio and checkboxes, and input:not(...), for the border color to change on the inputs of type text and type email.

# Listing 10.30 Hover rule

```
:is(
  input,
  input:not([type="radio"], [type="checkbox"]),
  textarea, select, button
):hover {
  border-color: var(--accent);
}
```
