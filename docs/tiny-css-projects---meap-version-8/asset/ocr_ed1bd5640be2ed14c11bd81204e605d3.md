# Listing 10.25 Error Styles

```
.error {
  color: var(--error);  #A
  Font-weight: bold;
  margin-left: 2rem;   #B
}

.error span::before { #C
  content: 'Error: '; #C
}                  #C
```

#A Make the text red
#B Align it with our input content and labels
#C Add "Error: " before each error

Notice how when we added the "Error: " verbiage before the text, we added it to the span and not the error div itself. That is because we are going to be showing and hiding the span inside of the error and the entire error div. Let’s take a closer look at the HTML to understand why. Listing 10.26 shows the complete control for the Name field including its label and error message. Notice how the error div has an id of nameError which is being referenced by the aria-describedby attribute on the input field. The aria-describedby attribute tells screen readers and assistive technologies that the element whose id it references contains extra information pertaining to the input field. If we hide the error div in its entirety using display:none, the element the aria-describedby is pointing to will not exist. We therefore only hide the contents (the span) in order not to break the programmatic connection between the element and its error. Since we will only be hiding the span, we need to apply the "Error: " verbiage to the span so that it can be hidden when we hide the error message.

# Listing 10.26 Name Field HTML

```
<label for="name">Your Name</label>
<input type="text" id="name" name="name" maxlength="250" required aria-describedby="nameError">
<div class="error" id="nameError">
  <span role="alert">
    Please let us know who you are
  </span>
</div>
```
