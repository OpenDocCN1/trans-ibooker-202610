# 8.2.5 Definition List

Still needing themed is the definition list (<dl>) in the summary section. Commonly used for glossaries, or to display metadata, it’s perfect for our summary which contains items and their values. We are going to style the definition term (<dt>) the same way as we did our table headers. We want to de-emphasize them from the definition description (<dd>) which contains the dollar value for each element. Because we want them styled the same as the table headers we are going to add dt as a selector to the already existing rule, similar to when we added input to the button rule earlier in the chapter.

We are then going to add a colon after each definition term by using the pseudo element :after with a property of content to insert the character. The CSS and output are shown in Listing 8.13 and Figure 8.13.

# Listing 8.13 Styling the Definition List

```
th, dt {  #A
  color: #3a3a3a;
  ...
}

dt:after {      #B
  content: ": "; #B
}               #B
```
