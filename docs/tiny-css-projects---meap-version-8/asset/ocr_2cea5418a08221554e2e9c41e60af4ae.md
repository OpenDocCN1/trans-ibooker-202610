# 10.3.7 Shaping the checked radio input’s inner disk

To turn our box into a circle for the insides of our checked radio input, we are going to use border-radius. We will specifically target the inputs of type radio’s before pseudo-class, and then add a border-radius of 50% to make our box look like a circle as seen in Listing 10.14. We do not differentiate between hover or checked because we want the shape to be a disk no matter the state of the element.

# Listing 10.14 Radio Button Inner Disk

input[type="radio"]::before {

}
