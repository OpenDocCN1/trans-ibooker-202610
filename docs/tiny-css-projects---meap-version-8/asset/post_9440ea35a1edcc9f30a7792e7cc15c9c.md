We have defs, which includes the styles for the image. This part defines what the individual elements in the svg will look like. Then we have a path. The path is the element displaying the dog, however it is 1988 characters long, quite complex, and when pasted into the path function as follows shape-outside: path('M21.913...'); does not seem to do anything. This is because as of this book being written, no browser has path() fully implemented⁶.

Once this feature is implemented, creating our paths using a graphics editor and copying them over to create our shapes will be a very valuable technique, but one that is not available to us yet. This method also comes with the drawback that these paths can get quite long, which makes maintainability dubious. However, we have a couple of alternatives:

- 1. Creating a polygon shape that roughly matches our image, similarly to the technique we used above with the circle.
- 2. Using the url() function which pulls in the image and bases the shape on the alpha channel.

We are going to go with option 2 and use the url() function.

## 7.4.2 Using the image

Same as when we handled the compass image, we are going to start by floating the image, but to the left this time to break up the visual monotony in our page. Then, to create the shape we use the url() function to which we pass the path to the image. Listing 7.11 shows the css applied to the dog image.

## Serving the image file

When using URLs with shape-outside, we need to make sure we are running our code through a server so that the image is getting fetched by the browser and not just read directly from the file system. This is specifically related to Cross-Origin Resource Sharing (CORS) and security policies set by the browser. A detailed explanation can be found in the CSS specification at https://drafts.csswg.org/css-shapes/#shape-outside-property. To mitigate this issue, the sample code in the git repository uses http-server, serving the files on localhost:8080 to accomplish this task. An alternative option would be to reference the hosted file in github using shape-outside:
url('https://raw.githubusercontent.com/michaelgearon/Tiny-CSS-Projects/main/chapter-07/before/img/dog.svg').

## Listing 7.11 Dog floated left

```
img.dog {
  aspect-ratio: 126 / 161;
  float: left;
  shape-outside: url('img/dog.svg');
}
```

We float the image left and then add our shape-outside passing in a reference to the image itself. The browser will look at the transparency of the image and determine where to create the shape based on where the transparency ends. Figure 7.12 shows our output.

![](img/b56145aa9b751926a7aedbd7172bc818_206_0.png)

Figure 7.12 Floated dog

Since our image has an opaque line with a transparent background, the cutoff is pretty straightforward. If our image had a gradient that went from opaque to transparent, we could tailor where the cutoff is using the shape-image-threshold property which takes a value between 0 and 1, zero being fully transparent and 1 being fully opaque.

## 7.4.3 Shape Margin

The next step is to add some margin to move the text away from the image because right now, it looks rather crowded. We can't simply add margin to the image like we did when we floated to the right, if we try we will notice that the margin is ignored and does not actually move the text. We need to use shape-margin instead. Shape-margin allows us to adjust the amount of space there is between our shape and the rest of the content. We are going to add 1 em's worth of space as seen in listing 7.12 and Figure 7.13.

## Listing 7.12 Shape Margin

```
img.dog {
  aspect-ratio: 126 / 161;
  float: left;
  shape-outside: url('img/dog.svg');
  shape-margin: 1em;
}
```

![](img/b56145aa9b751926a7aedbd7172bc818_207_0.png)

## Figure 7.13 Shape Margin

The text at the bottom of the image is still quite close. At this point we can add some margin to increase the space as long as the margin added is less than or equal to the shape-margin amount. If the value is greater than the shape-margin, it will still take effect, but only as much as the shape-margin amount. Keeping this caveat in mind, we will add 1em of margin to the right of the image. Listing 7.13 shows the completed CSS for the dog image.

## Listing 7.13 Complete dog image

```
img.dog {
  aspect-ratio: 126 / 161;
  float: left;
  shape-outside: url('img/dog.svg');
  shape-margin: 1em;
  margin-right: 1em;
}
```

The combination of shape-margin and margin-right, pushes the text away from our image for the polished end result we see in Figure 7.14.

![](img/b56145aa9b751926a7aedbd7172bc818_208_0.png)

## 7.5 Summary

- Leading, the amount of space between lines, is important for legibility
- Float can be used in conjunction with first-letter to create drop-caps
- Not all typefaces have the same size and line heights when given the same size value
- Shape-outside uses CSS shapes to alter the shape of an element
- CSS shapes can be created from border-radius
- Inline content adjacent to a floated CSS shape will follow the shape
- When using url() with shape-outside, the image file must be fetched by the browser (either hosted or via http-server or equivalent
- Shape-margin sets the margin of a shape
- There are layouts that cannot be accomplished without the use of float
