# #B Placing the card and the summary side by side

Figure 8.28 shows our layout with a 1800 pixel wide viewport. Notice however, that now that we have flexed the container, we have extra space between the h1 (Checkout) and the sections.

![](bbox=[0.18, 0.208, 0.9, 0.5])

Figure 8.28 Layout on a really wide screen

Because the container now has a display flex, the margin on the sections and the margin from the h1 (which exists as part of the browser’s default styles) no longer collapse. We have 3 ways we can fix this:

+   1. Change section margin to only have a margin bottom
+   2. Remove margins on the sections once we are flexed
+   3. Remove the margin-bottom which exists on the h1 from the browser’s default styles

We are going to choose option 2 and remove the top and bottom margins from the sections since once we are flexed and the sections are side by side, they are no longer necessary. Inside of our media query, we therefore need to add section { margin: 0; }.

With this final change we have a checkout cart that looks good on screens from mobile to extra wide. Figure 8.29 shows the final output for each screen size.
