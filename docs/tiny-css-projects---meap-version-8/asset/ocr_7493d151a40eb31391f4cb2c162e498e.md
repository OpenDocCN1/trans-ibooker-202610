# 11.3 Sourcing Icons

Anytime we are using iconography from someone else’s brand, we need to consider

+   1. Are we authorized to use the icon?
+   2. Are there any restrictions to how the icon can be used?

In the case of social media icons, their brand is being represented in our work and we therefore must follow their guidelines as to when, how, and in what context we can use their brand.

With icons that do not represent a brand (like the icon we used for the mailto link or share button), unless we created the icon ourselves, we are subject to the copyright laws same as any other image, sound, video, etc we might use in our projects.
