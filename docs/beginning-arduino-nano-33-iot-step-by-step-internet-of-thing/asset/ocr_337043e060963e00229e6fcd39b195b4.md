How does it work?

First, we include the Arduino LSM6DS3 library in the Arduino program.

```
#include <Arduino_LSM6DS3.h>
```

We initialize the IMU sensor and the Serial object on the setup() function.

```
void setup() {
  Serial.begin(115200);
  while (!Serial);

  if (!IMU.begin()) {
    Serial.println("Failed to initialize IMU!");

    while (1);
  }
}
```

We also can print the current accelerator sample rate by calling the IMU.accelerationSampleRate() function on the serial terminal.
