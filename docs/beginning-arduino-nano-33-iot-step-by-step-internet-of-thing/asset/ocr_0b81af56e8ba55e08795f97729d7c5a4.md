```
int led = 13;

void setup() {
    Serial.begin(115200);
    pinMode(led, OUTPUT);
}

void loop() {
    Serial.println("LED: HIGH");
    digitalWrite(led, HIGH);
    delay(1000);
    Serial.println("LED: LOW");
    digitalWrite(led, LOW);
    delay(1000);
}
```

Save this program as SerialDemo. Now you can compile and upload this program into Arduino Nano 33 IoT. Open the Serial Monitor tool to see the program output. Figure 2-16 shows my program output for the SerialDemo program.
