# Registering an Arduino Account

To use and build the Arduino program with Arduino web editor, we must register an Arduino account. This account is a similar account to that used to buy the Arduino board in the Arduino store.

You can register a new Arduino account on the right-top menu icon. You can fill personal information through this portal. After completed account registration, we can build the Arduino program with Arduino web editor.

# Installing Arduino Plug-in

To enable our Arduino Nano 33 IoT to connect to Arduino web editor, we need to install the Arduino plug-in. This is a required task for Windows. The Arduino plug-in will act as a bridge between local Arduino Nano 33 IoT and the Arduino web editor.
