On the setup() function, we initialize Serial object with baudrate 115200 and set digital mode for LED pins. We set OUTPUT for digital mode.

```
void setup() {
  Serial.begin(115200);
  delay(10);

  // prepare GPIO5
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  digitalWrite(led1, 0);
  digitalWrite(led2, 0);
  digitalWrite(led3, 0);
```
