How does this work?

This program starts by initializing values for LED and push button pins.

```
int led = 13;
int pushButton = 7;
int state = 0;

void setup() {
    pinMode(led, OUTPUT);
    pinMode(pushButton, INPUT);
}
```

Then, on the loop() function, we read a push button state using the digitalRead() function. The state value will be passed to the digitalWrite() function to turn on/off LED.

```
void loop() {
    state = digitalRead(pushButton);
    digitalWrite(led,state);
    delay(300);
}
```
