On the loop() function, we perform some tasks such as waiting for incoming HTTP requests. Then, we parse incoming packets. If the packet is valid, we can turn on/off LED. First, we wait for incoming client connections. We can call server.available().

```
```cpp
void loop() {
    // Check if a client has connected
    WiFiClient client = server.available();
    if (!client) {
        return;
    }

    // Wait until the client sends some data
    Serial.println("new client");
    while(!client.available()){
        delay(1);
    }
