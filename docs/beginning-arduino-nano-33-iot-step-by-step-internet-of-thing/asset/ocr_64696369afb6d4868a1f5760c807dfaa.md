Once we have a connected client, we wait for incoming HTTP request packets. We parse the packet to identify the type of command. We can use a string manipulation process. We call indexOf() if we have “/gpioX/Y” requests. X is an LED number, and Y is a command for turning on/off LED.

```
String req = client.readStringUntil('\r');
Serial.println(req);
client.flush();

// Match the request
int val1 = 0;
int val2 = 0;
int val3 = 0;
int ledreq = 0;
if (req.indexOf("/gpio1/0") != -1) {
  val1 = 0;
  ledreq = 1;
}
else if (req.indexOf("/gpio1/1") != -1) {
  val1 = 1;
  ledreq = 1;
}
else if (req.indexOf("/gpio2/0") != -1) {
  val2 = 0;
  ledreq = 2;
}
else if (req.indexOf("/gpio2/1") != -1) {
  val2 = 1;
  req = 2;
}
else if (req.indexOf("/gpio3/0") != -1) {
  val3 = 0;
  ledreq = 3;
}
```
