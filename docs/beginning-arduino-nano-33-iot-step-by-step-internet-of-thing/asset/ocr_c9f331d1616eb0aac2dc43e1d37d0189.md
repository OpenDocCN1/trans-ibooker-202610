# Operators

The Sketch program adopts C++ operators. We can declare arithmetic operators to perform mathematic operations. We can use the following arithmetic operators:

+   - % (remainder)
+   - * (multiplication)
+   - + (addition)
+   - - (subtraction)
+   - / (division)
+   - = (assignment operator)

For Boolean operators, we implement && for logical, || for logical or, and ! for logical not.
