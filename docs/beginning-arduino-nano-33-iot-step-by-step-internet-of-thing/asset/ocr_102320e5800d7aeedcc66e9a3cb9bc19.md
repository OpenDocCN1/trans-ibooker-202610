# Building an Arduino Program

The Arduino web editor has the same functionalities as the desktop version of Arduino software. The Arduino web editor has project samples. We also can add Arduino libraries into the project.

In this section, we build a blink Arduino application like in the previous project. We start by opening a browser and navigating to https://create.arduino.cc/editor. Click the Examples menu on the left menus. Then, click the BUILTIN tab and select 01.BASICS(6) -> Blink. You can see Figure 1-14 for our Arduino project.

After we select the Blink project sample, we have a blink program. You can see this program in Figure 1-15. Now we can compile and upload the program into Arduino Nano 33 IoT.

Select your Arduino Nano 33 IoT board from the dropdown of the device list. Click the Verify and Upload icon on the left of dropdown. This tool will compile and upload the Arduino program into the targeted board.
