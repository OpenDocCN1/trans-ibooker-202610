```
Wire.requestFrom(PCF8591, 2);
delay(100);
ADC1=Wire.read();
ADC1=Wire.read();
```

We set delay(100) to wait the module to complete our request. We read a data per byte using the Wire.read() function. Next, we print thermistor data on the serial terminal.

```
Serial.print("Thermistor=");
Serial.println(ADC1);
```

With the same method, we can read photo-voltaic cell by changing channel the value PCF8591_ADC_CH1. After that, we read sensor data and print the result to the serial terminal.

```
// read photo-voltaic cell
Wire.beginTransmission(PCF8591);
Wire.write(PCF8591_ADC_CH1);
Wire.endTransmission();
delay(100);
Wire.requestFrom(PCF8591, 2);
delay(100);
ADC2=Wire.read();
ADC2=Wire.read();
```

```
Serial.print("Photo-voltaic cell=");
Serial.println(ADC2);
```
