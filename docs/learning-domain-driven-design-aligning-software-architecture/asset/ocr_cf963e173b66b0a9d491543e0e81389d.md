+   a. A process manager requires explicit instantiation, while a saga is executed when a relevant domain event is published.
+   
+   b. Contrary to a process manager, a saga never requires persistence of its execution state.
+   
+   c. A saga requires the components it manipulates to implement the event sourcing pattern, while a process manager doesn’t.
+   
+   d. The process manager pattern is suitable for complex business workflows.
+   
+   e. A and D are correct.
