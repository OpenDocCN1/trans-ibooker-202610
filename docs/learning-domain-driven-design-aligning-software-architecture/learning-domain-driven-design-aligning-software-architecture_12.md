# Part III. Applying Domain-Driven Design in Practice

在第一部分和第二部分中，我们讨论了用于做出战略和战术设计决策的领域驱动设计工具。在本书的这一部分，我们将从理论转向实践。你将学习如何在真实项目中应用领域驱动设计。

- 第 10 章将我们关于战略和战术设计的讨论合并为简化的经验法则，以简化设计决策过程。你将学习快速识别与业务域复杂性和需求相匹配的模式。
- 在第 11 章中，我们将从不同角度审视领域驱动设计。设计出色的解决方案很重要，但还不够。我们必须随着项目随时间的演进保持其良好状态。在本章中，你将学习如何应用领域驱动设计工具来维护和随时间演进软件设计决策。
- 第 12 章介绍了 EventStorming：一种动手活动，可简化发现领域知识和构建通用语言的过程。
- 第 13 章以一系列提示和技巧作为第三部分的结尾，用于“温和地”在棕地项目中引入和融入领域驱动设计模式和实践——也就是我们最常处理的那类项目。
