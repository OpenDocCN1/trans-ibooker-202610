# Part II. 战术设计

在第一部分，我们讨论了软件的“是什么”和“为什么”：你学习了分析业务域、识别子域及其战略价值，并将业务域知识转化为有界上下文的设计——软件组件实现业务域的不同模型。

在本书记中，我们将从战略转向战术：软件设计的“如何”：

- 在第 5 章至第 7 章中，你将学习业务逻辑实现模式，使代码能够使用其有界上下文的通用语言说话。第 5 章介绍了两种适应相对简单业务逻辑的模式：事务脚本和活动记录。第 6 章转向更具挑战性的案例并介绍领域模型模式：DDD 实现复杂业务逻辑的方式。在第 7 章中，你将学习通过对时间维度的建模来扩展领域模型模式。
- 在第 8 章中，我们将探讨组织有界上下文架构的不同方式：分层架构、端口与适配器以及 CQRS 模式。你将学习每种架构模式的精髓以及在何种情况下应使用每种模式。
- 第 9 章将讨论编排系统组件之间交互的技术问题和实现策略。你将学习支持有界上下文实现



集成模式，如何实现可靠的消息发布，以及定义复杂、跨组件工作流的模式。
