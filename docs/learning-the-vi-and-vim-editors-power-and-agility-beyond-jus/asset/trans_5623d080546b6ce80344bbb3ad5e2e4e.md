
# 有用的菜单

如果你的鼠标带有滚轮，`gvim` 默认就能很好地处理它，无论如何设置 `mouse` 选项，都能可预测地上下滚动屏幕或窗口。

一个不错的特点是 `gvim` 为 GUI 环境带来的菜单操作，它简化了一些 Vim 更晦涩的命令。值得一提的有两个。

## `gvim`’s 窗口菜单

`gvim`’s *窗口* 菜单包含许多最有用和最常见的 Vim 窗口管理命令：命令将单个 GUI 窗口分割成多个显示区域。你可能会觉得值得“撕下”这个菜单，如 [图 9-1](#ch09.html#vi8-ch-9-fig-1) 所示，以便方便地在窗口之间打开和切换。结果如 [图 9-2](#ch09.html#vi8-ch-9-fig-2) 所示。（我们稍后会讨论可撕下菜单。）

![](assets/lvv8_0901.png)

注意 [图 9-2](#ch09.html#vi8-ch-9-fig-2) 中的菜单如何被移动并浮动在完全无关的应用程序之上。这是一种让常用菜单方便可用但又不妨碍编辑的好方法。这两者对于常见的选择、剪切、复制、删除和粘贴操作都很方便。其他 GUI 编辑器的用户经常使用这种功能，但即使对于长期使用 Vim 的用户也很有用。特别有用的是它以可预测的方式与 Windows 剪贴板交互。

# 自定义滚动条、菜单和工具栏

`gvim` 提供了通常的 GUI 小部件，如滚动条、菜单和工具栏。与大多数现代 GUI 应用程序一样，这些小部件是可以定制的。

默认情况下，`gvim` 窗口在顶部显示多个菜单和工具栏，如 [图 9-5](#ch09.html#vi8-ch-9-fig-5) 所示。

## 滚动条

滚动条可让你快速在文件中上下或左右导航，在 `gvim` 中是可选的。你可以使用本章末尾 [“GUI 选项和命令概要”](#ch09.html#vi8-ch-9-sect-6) 部分描述的 `guioptions` 选项来显示或隐藏它们。

由于 Vim 的标准行为是显示文件中的所有文本（必要时在窗口中换行），因此值得注意的是，在通常配置的 `gvim` 会话中，水平滚动条没有任何作用。

通过在 `guioptions` 选项中包含或排除 `r` 或 `l` 来打开或关闭左右滚动条。`l` 确保屏幕始终具有左侧滚动条，而 `r` 使其始终具有右侧滚动条。大写变体 `L` 和 `R` 告诉 `gvim` 仅在有垂直分割窗口时显示左侧或右侧滚动条。

水平滚动条通过在 `guioptions` 选项中包含或排除 `b` 来控制。

而且，是的，你 *可以* 同时滚动左右滚动条！更准确地说，滚动其中一个会导致另一个向相应方向移动。在两侧配置滚动条可能非常方便。根据鼠标的位置，你只需单击并拖动最近的滚动条即可。

###### 注意

许多选项，包括 `guioptions`，控制多种行为，因此默认情况下可以包含许多标志。甚至在 `gvim` 的未来版本中也可能添加新标志。因此，在 `:set guioptions` 命令中使用 `+=` 和 `-=` 语法非常重要，以避免删除期望的行为。例如，`:set guioptions+=l` 添加“滚动条始终在左侧”选项到 `gvim`，同时保持 `guioptions` 字符串中的其他组件不变。

值得注意的是，这些菜单选项只是 Vim 命令的包装。事实上，这正是你可以创建和自定义自己的菜单条目的方法，我们稍后会讨论。

###### 提示

如果你注意菜单，包括右侧显示的按键或命令，你可以随着时间的推移学习 Vim 命令。例如，在 [图 9-6](#ch09.html#vi8-ch-9-fig-6) 中，虽然对于初学者来说，在编辑菜单中找到熟悉的撤销命令很方便，该命令在其他流行应用程序中也出现，但使用 Vim `u` 按键要 *非常* 快且更容易，该按键在菜单中显示。

如 [图 9-6](#ch09.html#vi8-ch-9-fig-6) 所示，每个菜单都以一条包含剪刀图片的虚线开始。单击此行会“撕下”菜单以创建一个独立窗口，在该窗口中该子菜单的选项可在不进入菜单栏的情况下使用。如果你单击 [图 9-6](#ch09.html#vi8-ch-9-fig-6) 中 `Toggle Pattern Highlight` 菜单选项上方的虚线，你会看到类似 [图 9-7](#ch09.html#vi8-ch-9-fig-7) 的内容。你可以将自由浮动的菜单放置在桌面的任何位置。

![](assets/lvv8_0907.png)

现在此子菜单上的所有命令都只需在子菜单窗口中单击一下即可立即使用。每个菜单选择都映射到一个按钮。如果菜单选择本身是子菜单，则它由一个按钮表示，该按钮的右侧带有大于号（看起来像右指向箭头）。单击这些箭头会展开子菜单。

### 基本菜单自定义

`gvim` 将菜单定义存储在名为 `$VIMRUNTIME/menu.vim` 的文件中。

定义菜单项类似于映射。如你在 [“使用 map 命令”](#ch07.html#vi8-ch-7-sect-3.2) 部分所见，你可以像这样映射一个键：

```
:map <F12> :set syntax=html<CR>
```

菜单的处理方式非常相似。

假设我们不想将 F12 映射为设置语法为 `html`，而是希望在文件菜单上有一个特殊的“HTML”条目来执行此任务。使用 `:amenu` 命令：

```
:amenu File.HTML :set filetype=html<CR>
```

四个字符 `<CR>` 应按所示输入，是命令的一部分。

现在查看你的文件菜单。你应该看到一个新的 HTML 条目，如 [图 9-8](#ch09.html#vi8-ch-9-fig-8) 所示。通过使用 `amenu` 而不是 `menu`，我们确保该条目在所有模式（命令、插入和普通）中都可用。

![](assets/lvv8_0908.png)

###### 注意

`menu` 命令仅在命令模式下将条目添加到菜单中；该条目在插入和普通模式下不会出现。

菜单条目的位置由一系列用句点（`.`）分隔的级联菜单名称指定。在我们的示例中，`File.HTML` 将菜单条目“HTML”添加到文件菜单中。系列中的最后一个条目是你想要添加的条目。这里我们将其添加到现有菜单中，但我们很快就会看到，我们可以同样轻松地创建一系列全新的级联菜单。

务必测试你的新菜单选择。例如，我们开始编辑 Vim 将其视为 XML 文件的文件，如 [图 9-9](#ch09.html#vi8-ch-9-fig-9) 中的状态行所示（请参阅 [“一个不错的 Vim Piggybacking 技巧”](#ch12.html#vi8-ch-12-sect-1.5) 部分，了解如何设置状态行）。我们已自定义状态行，以便 Vim 和 `gvim` 在最右侧显示当前活动的文件类型。

![](assets/lvv8_0909.png)
