
Vim 的一个较为冷门的特性是其支持从右到左输入，这对于希伯来语和波斯语等语言很有用，也体现了 Vim 的多功能性。

作为专业软件开发者可以信赖的坚如磐石的编辑器是 Vim 的另一个设计目标。Vim 崩溃的情况很少见，而一旦发生，你也可以恢复你的修改。

Vim 的开发仍在继续。帮助添加功能并将 Vim 移植到更多平台的人群正在增长，不同计算机系统上移植的质量也在提高。Microsoft Windows 版本具有对话框和文件选择器，这使得难以学习的 `vi` 命令对大量用户开放。

## 为什么选择 Vim？

Vim 如此大幅度地扩展了传统的 `vi` 功能，以至于人们更可能问：“为什么 *不* 用 Vim？” `vi` 引入了其他克隆版本借鉴的标准，而 Vim 接过了接力棒并将其发扬光大。Vim 敢于激进地扩展功能，有时甚至将处理器推向其以足够响应时间完成 Vim 工作能力的极限。我们不知道 Bram 是否坚信处理器和内存速度会提高到足以跟上 Vim 的需求，但幸运的是，现代处理器和计算机即使处理最艰难的 Vim 任务也能游刃有余。

## 与 vi 的比较与对比

Vim 比 `vi` 更具通用性。几乎所有操作系统上都有某个版本的 Vim，而 `vi` 仅在 Unix 或类 Unix 系统上可用。

`vi` 是原版，多年来变化不大。它是 POSIX 标准的主力，履行其角色良好。Vim 在 `vi` 结束的地方开始，提供所有 `vi` 的功能，然后扩展以添加图形界面和诸如复杂选项和脚本等功能，这些功能远远超出了 `vi` 的原始能力。

Vim 附带了自己的内置文档，以专门的文本文件目录的形式提供。对该目录进行粗略检查（使用标准的 Unix 字数统计工具 `wc -l *.txt`）显示有 140 个文件，包含近 200,000 行文档！^([4](#ch08.html#idm46601079768032)) 这是 Vim 功能范围的第一个提示。Vim 通过其内部的 `help` 命令访问这些文件，这是 `vi` 中没有的另一项功能。我们稍后会更详细地研究 Vim 的帮助系统，并提供技巧以最大化你的学习体验。

在当前版本中，Vim 的 `vi_diff` 帮助文件概述了 Vim 与原始 `vi` 的不同之处。细节变得如此众多，以至于帮助文件对“不在 `vi` 中”的注释造成了太多混乱而被删除！

本章和以下章节涵盖了一些更有趣的 Vim 功能。从对历史 `vi` 的扩展到新功能，我们描述了最佳和最受欢迎的生产力功能。我们涵盖了普遍公认为有用增强的主题，例如语法颜色高亮。我们还研究了一些较为冷门的、用于提高生产力的功能。例如，在章节 [“自动命令”](#ch12.html#vi8-ch-12-sect-2.1) 中，我们展示了如何自定义 Vim 状态行，以便在你移动光标时实时更新日期和时间。

## 功能分类

Vim 的功能涵盖了几乎任何文本编辑任务中常见的活动范围。一些功能只是扩展了用户希望原始 `vi` 完成的功能；其他功能则完全是新的，不在 `vi` 中。而且，如果你需要一些 *不存在* 的功能，Vim 提供了内置脚本以实现无限的扩展性和定制性。Vim 功能的一些类别包括：

### 初始化

Vim 与 `vi` 一样，使用配置文件在启动时定义会话，但 Vim 具有大大扩展的可定义行为范围。你可以像在 `vi` 中一样简单地设置几个选项，也可以编写一套完整的自定义设置，根据你定义的任何上下文定义你的会话。例如，你可以编写初始化文件以根据你正在编辑文件的目录预编译代码，或者你可以从某个实时源检索信息并在启动时将其合并到你的文本中。参见本章中 [“启动和初始化选项”](#ch08.html#vi8-ch-8-sect-5) 部分。

### 无限撤销

Unix `vi` 只允许你撤销最后一次更改，或将当前行恢复到你在开始进行任何更改之前的状态。Vim 提供了“无限撤销”，能够不断撤销你的更改，一直到你在开始 *任何* 编辑之前文件的状态。参见本章稍后的 [“扩展撤销”](#ch08.html#vi8-ch-8-sect-8) 部分了解更多信息。

### 图形用户界面（GUI）功能

Vim 通过允许像许多现代易用编辑器一样的点按编辑，将可用性扩展到更广泛的人群。所有强大的用户功能都获得了简单 GUI 可访问性的提升，用于更轻量和更简单的编辑任务。参见 [第9章，“图形化 Vim（`gvim`）”](#ch09.html#vi8-ch-9) 了解更多信息。

### 多窗口

如前所述，Vim 提供了同时打开多个窗口的能力，针对同一文件和不同文件。这在 [第10章，“Vim 中的多个窗口”](#ch10.html#vi8-ch-10) 中进行了充分讨论。

### 程序员辅助

尽管 Vim 并没有试图提供所有编程需求，但它提供了集成开发环境（IDEs）中通常找到的许多功能。从快速的编辑-编译-调试循环到关键字自动补全，Vim 具有专门的功能，让你做的不只是快速编辑——它帮助你编程。参见 [第11章，“Vim 为程序员提供的增强功能”](#ch11.html#vi8-ch-11) 了解更多信息。

当然，如果你愿意，你 *可以* 将 Vim 变成一个 IDE；参见 [第15章，“Vim 作为 IDE：需要一些组装”](#ch15.html#vi8-ch-15) 了解更多信息。

### 关键字补全

Vim 允许你使用上下文相关的补全规则补全部分输入的单词。例如，Vim 可以在字典中查找单词或在包含特定于语言的关键字的文件中查找。这在 [“关键字和字典单词补全”](#ch11.html#vi8-ch-11-sect-3) 部分中进行了讨论。

### 语法扩展

Vim 让你控制文本的缩进和基于语法的颜色编码。你有许多选项来定义这种自动格式化。如果你不喜欢颜色高亮，你可以更改它。如果你需要某种缩进样式，Vim 提供了它，或者如果你有特殊需求，它允许你自定义环境。参见 [“语法高亮”](#ch11.html#vi8-ch-11-sect-5) 部分了解更多信息。

### 脚本和插件

你可以编写自己的 Vim 扩展或从互联网下载插件。你甚至可以通过发布你的扩展供他人使用，为 Vim 社区做出贡献。参见 [第12章，“Vim 脚本”](#ch12.html#vi8-ch-12) 了解更多信息。

### 后处理

除了执行初始化功能外，Vim 还允许你定义在编辑文件 *之后* 要做什么。你可以编写清理例程以删除编译产生的临时文件，或在文件写回存储之前对文件进行实时编辑。例如，你可以检查 Python 代码布局是否一致遵守本地格式规则。你可以完全控制以自定义任何编辑后活动。

### 任意长度的行和二进制数据

历史版本的 `vi` 通常每行限制约为一千个字符；更长的行会被截断。Vim 处理任意长度的行。^([5](#ch08.html#idm46601079723408))
