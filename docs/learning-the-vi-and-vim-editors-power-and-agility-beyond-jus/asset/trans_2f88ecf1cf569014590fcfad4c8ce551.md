
Start `Vim` in restricted mode. Do not allow shell commands or suspension of the editor. {Vim}

尽管大多数人仅通过在 `vi` 中的使用才知道 `ex` 命令，但该编辑器也作为独立程序存在，可以从 shell 中调用（例如，作为脚本的一部分来编辑文件）。在 `ex` 中，你可以输入 `vi` 或 `visual` 命令来启动 `vi`。同样，在 `vi` 中，你可以输入 `Q` 退出 `vi` 编辑器并进入 `ex`。

你可以通过以下几种方式退出 `ex`：

| `:x` || 退出（保存更改并退出）。 |
| --- | --- |
| `:q!` || 不保存更改而退出。 |
| `:vi` || 进入 `vi` 编辑器。 |

# vi 操作回顾

本节提供以下内容的回顾：

* `vi` 模式
* `vi` 命令语法
* 状态行命令

## 命令模式

打开文件后，你处于命令模式。从命令模式，你可以：

* 调用插入模式
* 发出编辑命令
* 将光标移动到文件中的不同位置
* 调用 `ex` 命令
* 调用 shell
* 保存文件的当前版本
* 退出编辑器

## 插入模式

在插入模式下，你向文件中输入新文本。通常使用 `i` 命令进入插入模式。按下 `ESC` 键可退出插入模式并返回命令模式。进入插入模式的命令完整列表将在后面，在小节 [“插入命令”](#app01.html#vi8-app-a-sect-3.2) 中提供。

## vi 命令语法

在 `vi` 中，编辑命令的一般形式如下：

```
[n] operator [m] motion
```

基本编辑 `operators` 为：

| `c` || 开始更改。 |
| --- | --- |
| `d` || 开始删除。 |
| `y` || 开始 yank（或复制）。 |

如果当前行是操作的对象，则 `motion` 与操作符相同：`cc`、`dd`、`yy`。否则，编辑操作符作用于由光标移动命令或模式匹配命令指定的对象。例如，`cf.` 更改到下一个句点。`n` 和 `m` 是操作执行的次数，或操作执行的对象数。如果同时指定 `n` 和 `m`，效果为 `n` × `m`。

操作对象可以是以下任何文本块：

`word`

包括字符直到空白字符（空格或制表符）或标点符号。首字母大写的对象是仅识别空白的变体形式。

`sentence`

直到 `.`、`!` 或 `?`，后跟两个空格。Vim 只查找单个后续空格。

`paragraph`

直到下一空白行或由 `para=` 选项定义的 `nroff`/`troff` 段落宏。

`section`

直到由 `sect=` 选项定义的下一个 `nroff`/`troff` 节标题。

`motion`

直到由 motion 指定符指定的字符或其他文本对象，包括模式搜索。

### 示例

| `2cw` || 更改接下来的两个词。 |
| --- | --- |
| `d}` || 删除到下一个段落。 |
| `d^` || 删除回行首。 |
| `5yy` || 复制接下来的五行。 |
| `y]]` || 复制到下一个节。 |
| `cG` || 更改到编辑缓冲区末尾。 |

更多命令和示例可在本附录后面，在小节 [“更改和删除文本”](#app01.html#vi8-app-a-sect-3.3.1) 中找到。

### 视觉模式（仅 Vim）

Vim 提供了一个额外的功能，`visual mode`。这允许你突出显示文本块，然后这些文本块成为删除或保存（yanking）等编辑命令的对象。Vim 的图形版本允许你使用鼠标以类似方式突出显示文本。有关更多信息，请参阅前面小节 [“视觉模式移动”](#ch08.html#vi8-ch-8-sect-6.1)。

| `v` || 在视觉模式下逐字符选择文本。 |
| --- | --- |
| `V` || 在视觉模式下逐行选择文本。 |
| `CTRL-V` || 在视觉模式下以块形式选择文本。 |

## 状态行命令

大多数命令在输入时不会在屏幕上回显。但是，屏幕底部的状态行用于编辑这些命令：

| `/` || 向前搜索模式。 |
| --- | --- |
| `?` || 向后搜索模式。 |
| `:` || 调用 `ex` 命令。 |
| `!` || 调用一个 Unix 命令，该命令以缓冲区中的对象作为输入并用命令的输出替换它。你在 `!` 之后输入一个 motion 命令来描述应传递给 Unix 命令的内容。命令本身显示在状态行上。 |

输入到状态行的命令必须通过按下 `ENTER` 键来完成。^([3](#app01.html#idm46601069862752)) 此外，错误消息和 `CTRL-G` 命令的输出会显示在状态行上。

# vi 命令

`vi` 在命令模式下提供大量单键命令。Vim 提供额外的多键命令。

## 移动命令

某些版本的 `vi` 不识别扩展键盘键（例如，箭头键、向上翻页、向下翻页、home、insert 和 delete）；有些版本识别。所有版本都识别本节中的键。许多 `vi` 用户更喜欢使用这些键，因为它有助于将手指保持在键盘的基准行上。命令前面的数字重复移动。移动命令也用于操作符之后。操作符作用于移动的文本。

### 字符

| `h`, `j`, `k`, `l` || 左、下、上、右（ ← , ↓ , ↑ , → ） |
| --- | --- |
| `Space bar` || 右 |
| `BACKSPACE` || 左 |
| `CTRL-H` || 左 |
| `CTRL-N` || 下 |
| `CTRL-P` || 上 |

### 文本

| `w`, `b` || 按“word”向前、向后移动（字母、数字和下划线构成单词）。 |
| --- | --- |
| `W`, `B` || 按“Word”向前、向后移动（仅空白分隔项目）。 |
| `e` || 单词末尾。 |
| `E` || Word 末尾。 |
| `ge` || 前一个单词末尾。 {Vim} |
| `gE` || 前一个 Word 末尾。 {Vim} |
| `)`, `(` || 下一句、当前句的开头。 |
| `}`, `{` || 下一段、当前段的开头。 |
| `]]`, `[[` || 下一节、当前节的开头。 |
| `][`, `[]` || 下一节、当前节的末尾。 {Vim} |

### 行

文件中长行可能在屏幕上显示为多行。它们从一个屏幕行换行到下一个屏幕行。虽然大多数命令按文件中定义的行工作，但少数命令按它们在屏幕上显示的行工作。Vim 选项 `wrap` 允许你控制长行的显示方式。

| `0`, `$` || 当前行的第一个、最后一个位置。 |
| --- | --- |
| `^`, `_` || 当前行第一个非空白字符。 |
| `+`, `-` || 下一行、上一行的第一个非空白字符。 |
| `ENTER` || 下一行的第一个非空白字符。 |
| `num` `|` || 当前行的第 `num` 列。 |
| `g0`, `g$` || 屏幕行第一个、最后一个位置。 {Vim} |
| `g^` || 屏幕行第一个非空白字符。 {Vim} |
| `gm` || 屏幕行中间。 {Vim} |
| `gk`, `gj` || 向上、向下移动一行屏幕。^([a](#app01.html#idm46601069790096)) {Vim} |
| `H` || 屏幕顶行（Home 位置）。 |
| `M` || 屏幕中间行。 |
| `L` || 屏幕最后一行。 |
| `num` `H` || 顶行之后第 `num` 行。 |
| `num` `L` || 最后一行之前第 `num` 行。 |
| ^([a](#app01.html#idm46601069790096-marker)) 这些是冗余的，因为去掉 `g` 后结果相同。 |
| --- |

### 屏幕

| `CTRL-F`, `CTRL-B` || 向前、向后滚动一屏。 |
| --- | --- |
| `CTRL-D`, `CTRL-U` || 向下、向上滚动半屏。 |
