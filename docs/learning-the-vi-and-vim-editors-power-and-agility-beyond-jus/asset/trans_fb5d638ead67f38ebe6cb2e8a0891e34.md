
同样的命令也可以作为上下文敏感的替换输入。如果所有行都以 `Name` 开头，你可以这样写：

```
:g/^Name/s/: \([^,]*\), \([^;]*\);/: \2 \1;/
```

你还可以在第一个空格后添加一个星号，以便匹配冒号后面有额外空格（或没有空格）的情况：

```
:g/^Name/s/: *\([^,]*\), \([^;]*\);/: \2 \1;/
```

## 使用 `:g` 重复命令

在我们通常看到的 `:g` 命令用法中，它会选择行，然后通常由同一条 `ex` 命令行上的后续命令进行编辑——例如，我们使用 `:g` 选择行然后对其进行替换，或者选择它们并删除它们：

```
:g/mg[ira]box/s/box/square/g
:g/^$/d
```

然而，在 *UnixWorld* 的两部分教程中^([10](#ch06.html#idm46601102679136))，Walter Zintz 对 `:g` 命令提出了一个有趣的观点。该命令选择行，但相关的编辑命令并不一定需要实际影响所选的行。

相反，他演示了一种技术，可以让你重复执行 `ex` 命令任意次数。例如，假设你想将文件第 12 行到第 17 行的内容复制 10 份放到当前文件的末尾。你可以输入：

```
:1,10g/^/ 12,17t$
```

这是 `:g` 的一种非常出乎意料的用法，但它有效！`:g` 命令选择第 1 行，执行指定的 `t` 命令，然后继续到第 2 行执行下一个复制命令。当到达第 10 行时，`ex` 将已完成 10 次复制。

## 收集行

这是另一个高级 `:g` 示例，同样基于 Zintz 教程中提供的建议。假设你正在编辑一个由多个部分组成的文档。此文件的第 2 部分如下所示，使用省略号表示省略的文本并显示行号以供参考：

```
301  Part 2
302  Capability Reference
303  .LP
304  Chapter 7
305  Introduction to the Capabilities
306  This and the next three chapters ...

400  ... and a complete index at the end.
401  .LP
402  Chapter 8
403  Screen Dimensions
404  Before you can do anything useful
405  on the screen, you need to know ...

555  .LP
556  Chapter 9
557  Editing the Screen
558  This chapter discusses ...

821  .LP
822  Part 3
823  Advanced Features
824  .LP
825  Chapter 10
826  ....
```

每章编号出现在单独一行，章节标题出现在下一行，而章节正文（以 **粗体** 强调）则从其下一行开始。你想做的第一件事是复制每个章节的开头行，并将其发送到一个已存在的名为 `begin` 的文件。

执行此操作的命令如下：

```
:g /^Chapter/ .+2w >> begin
```

在发出此命令之前，你必须位于文件的顶部。首先，你在行首搜索 `Chapter`，但随后你希望在每个章节的开头行上运行命令——`Chapter` 下面的第二行。因为以 `Chapter` 开头的行现在被选为当前行，所以行地址 `.+2` 表示其下面的第二行。等效的行地址 `+2` 或 `++` 也适用。你希望将这些行写入名为 `begin` 的现有文件，因此使用追加操作符 `>>` 发出 `w` 命令。

假设你只想发送第 2 部分内的章节开头。你需要限制 `:g` 选择的行，因此将命令改为如下：

```
:/^Part 2/,/^Part 3/g /^Chapter/ .+2w >> begin
```

这里，`:g` 命令选择以 `Chapter` 开头的行，但它只在从以 `Part 2` 开始的行到以 `Part 3` 开始的行这一文件部分中搜索。如果你执行刚才显示的命令，文件 `begin` 的最后几行将如下所示：

```
This and the next three chapters ...
Before you can do anything useful
This chapter discusses ...
```

这些是第 7、8 和 9 章的开头行。

除了你刚刚发送的行之外，你还想将章节标题复制到文档末尾，以便制作目录表。你可以使用竖线在第一个命令后附加第二个命令，如下所示：

```
:/^Part 2/,/^Part 3/g /^Chapter/ .+2w >> begin | +t$
```

请记住，对于任何后续命令，行地址都相对于前一个命令。第一个命令已标记（在第 2 部分内）以 `Chapter` 开头的行，而章节标题出现在这些行的下一行。因此，要在第二个命令中访问章节标题，行地址为 `+`（或等效的 `+1` 或 `.+1`）。然后使用 `t$` 将章节标题复制到文件末尾。

# 第 7 章 高级编辑

本章向你介绍 `vi` 和 `Vim` 以及其底层 `ex` 编辑器的一些更高级功能。在开始学习本章介绍的概念之前，你应合理熟悉本书前面章节所介绍的内容。

正如我们在前面章节中所做的那样，本章介绍适用于所有 `vi` 版本的通用功能，但以 `Vim` 为背景。当你在此处单独看到“`vi`”时，通常可以将其理解为“`vi` 和 `Vim`”。

我们将本章分为五个部分。第一部分讨论了多种设置选项的方法，以允许你自定义编辑环境。你将学习如何使用 `set` 命令以及如何使用 `*.exrc` 文件创建多种不同的编辑环境。
