# 关于前几版

本书第五版（当时名为 *学习 vi 编辑器*）首次更全面地讨论了 `ex` 编辑器命令。在第 5、6 和 7 章中，通过增加更多示例阐明了 `ex` 和 `vi` 的复杂功能，涵盖了诸如正则表达式语法、全局替换、`.exrc` 文件、单词缩写、键盘映射和编辑脚本等主题。其中一些示例取自 *UnixWorld* 杂志的文章。Walter Zintz 写了一篇关于 `vi` 的两部分教程^([2](#preface01.html#idm46601109527024))，让我们学到了一些以前不知道的东西，并且还提供了许多巧妙的示例来说明书中已涵盖的功能。Ray Swartz 在他的专栏之一中也提供了一个有用的提示。^([3](#preface01.html#idm46601109523008)) 我们感谢这些文章中的创意。

第六版 *学习 vi 编辑器* 介绍了四种可自由获得的“克隆”或类似编辑器的内容。许多编辑器在原始 `vi` 的基础上有所改进。因此可以说存在一个 `vi` 编辑器“家族”，本书的目标是教您使用它们所需了解的知识。该版本对 `nvi`、`Vim`、`elvis` 和 `vile` 给予同等对待。新的附录描述了 `vi` 在更大的 Unix 和互联网文化中的地位。

第七版 *学习 vi 和 Vim 编辑器* 保留了第六版的所有优点。随着时间的推移，`Vim` 已被证明是最受欢迎的 `vi` 克隆，因此第七版大幅扩展了对该编辑器的介绍（并在书名中为 `Vim` 提供了位置）。然而，为了尽可能适用于更多用户，它保留并更新了有关 `nvi`、`elvis` 和 `vile` 的内容。

# 关于第八版

本书第八版 *学习 vi 和 Vim 编辑器* 保留了第七版的所有优点。`Vim` 现在“独占鳌头”，因此本版更新了对 `Vim` 的介绍，并删除了有关 `nvi`、`elvis` 和 `vile` 的内容。[第一部分](#part01.html#vi8-part-1) 现在以 `Vim` 为教学和示例的背景。此外，已删除了有关原始 `vi` 旧版本问题的引用，这些问题已不再相关。我们已尝试精简本书，使其尽可能保持相关性和实用性。
