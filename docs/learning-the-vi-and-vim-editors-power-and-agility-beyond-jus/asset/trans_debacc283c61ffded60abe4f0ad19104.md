
如果 Vim 的默认设置找不到合适的编译程序，它提供了一些选项供你使用，以定义实用程序的位置，从而让你完成工作。有关编程环境和编译器的细节超出了本次讨论的范围，但我们在此介绍这些 Vim 选项作为起点，以防你需要调整环境：

`:cnext`, `:cprevious`

将光标移动到 *下一个* 和 *上一个* 错误位置的命令，分别如 `Quickfix List` 窗口中所定义。

`:colder`, `:cnewer`

Vim 会记住最近的 10 个错误列表。这些命令在 `QuickFix List` 窗口中加载下一个 *较旧* 或下一个 *较新* 的错误列表。每个命令都接受一个可选的整数 `n`，以加载第 `n` 个较旧或较新的错误列表。

`errorformat`

一个定义 Vim 用于匹配编译返回错误时的格式的选项。Vim 的内置文档对此定义提供了更详细的信息，但默认设置几乎总是有效。如果需要调整该选项，请使用以下命令查看其详情：

```
:help errorformat
```

`makeprg`

包含开发环境 `make` 或 `compile` 程序名称的选项。

## 快捷修复列表窗口的更多用途

Vim 还允许你构建文件内位置的自定义列表，通过类似 `grep` 的语法指定位置。`QuickFix List` 窗口以与前面描述的编译过程返回的行非常相似的格式返回你请求的结果。这是通过 `:vimgrep` 命令完成的，其语法为：

```
:vimgrep[!] /pattern/[g][j] file(s)
```

这本质上是标准 `grep`(1) 工具的内置版本。它在 `files` 中搜索匹配 `pattern` 的行，并将结果放入 QuickFix 窗口。（请参阅 Vim 文档以了解标志的详细信息及其含义。）

此功能对于重构等任务很有用。例如，我们使用 AsciiDoc 编写了本文稿。在撰写过程中，我们在某一点将所有出现的“++vim++”的标记从 `++vim++` 改为 `__vim__`。^([11](#ch11.html#idm46601075161456)) 因此，像这样的每个出现：

```
++vim++
```

需要更改为：

```
__vim__
```

执行此命令后：

```
:vimgrep /++vim++/ *.asciidoc
```

`Quickfix List` 窗口包含了信息，如 [图 11-30](#ch11.html#vi8-ch-11-fig-30) 所示。

![](assets/lvv8_1130.png)

#### 注意

请记住使用 Vim `ex` 命令打开 QuickFix 窗口：

```
:copen
```

否则你将看不到结果。

请注意在 [图 11-30](#ch11.html#vi8-ch-11-fig-30) 中 Vim 如何显示 `:vimgrep` 输出。左侧是 QuickFix 缓冲区的行号，仅表示输出中有多少行；它们可以使用 Vim `ex` 命令关闭：

```
:set nonumber
```

`:vimgrep` 输出包含三个由管道字符 (`|`) 分隔的字段。第一个字段是 `vimgrep` 匹配 `pattern` 的文件名称。第二个字段描述了匹配 `pattern` 找到的行和列。第三个字段是匹配行的实际文本。

你可以通过将光标移动到感兴趣的行来导航到任何匹配项，或者双击感兴趣的行。Vim 在另一个（拆分）窗口中打开该文件，并将光标定位在第一个匹配模式字符上。

在 [图 11-30](#ch11.html#vi8-ch-11-fig-30) 中，高亮的行（阅读起来有点困难，尽管我们尝试选择尽可能易读的配色方案）是指向文件 `ch04.asciidoc` 中第 98 行、第 32 列的指针。有关双击该行后的结果，请参阅 [图 11-31](#ch11.html#vi8-ch-11-fig-31)；你可以看到 Vim 如何在对应的窗口中将光标放置在 `ch04.asciidoc` 的正确行和列中。

![](assets/lvv8_1131.png)

因此，浏览所有出现的位置并快速更改为新值变得非常简单。

#### 注意

这个例子似乎可以用这个简单的命令更轻松地解决这个问题：

```
:%s/++vim++/__vim__/g
```

但请记住，`vimgrep` 更通用，并且可在多个文件上操作。这是一个 `vimgrep` 的示例，而不是执行此任务的确定性方法。在 Vim 中，通常有许多方法可以完成某项任务。

# 第 12 章 Vim 脚本

有时仅靠自定义不足以满足你的编辑环境。Vim 允许你在 `*.vimrc` 文件中定义你最喜欢的所有设置，但也许你想要更动态或“即时”的配置。Vim 脚本可以做到这一点。

从检查缓冲区内容到处理不可预见的外部因素，Vim 的脚本语言让你能够完成复杂任务并基于 *你的* 需求做出决策。

如果你有一个 Vim 配置文件（`*.vimrc`、`*.gvimrc` 或两者），你已经在 Vim 中进行脚本编写了；你只是不知道而已。所有 Vim 命令和选项都是脚本的有效输入。而且，正如你所期望的，Vim 提供了任何语言中典型的所有标准流程控制语句（`if…then…else`、`while` 等）、变量和函数。
