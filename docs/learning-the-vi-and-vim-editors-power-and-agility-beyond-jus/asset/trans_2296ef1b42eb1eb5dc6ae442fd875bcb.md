## 第1章. 介绍 `vi` 和 `Vim`

计算机日常最重要的用途之一就是处理文本：撰写新文本、编辑和重新排列现有文本、删除或重写错误和过时的文本。如果你使用 Microsoft Word 等文字处理程序，那就是你在做的事情！如果你是程序员，你也在处理文本：程序的源代码文件以及开发所需的辅助文件。文本编辑器处理任何文本文件的内容，无论这些文件包含数据、源代码还是句子。

本书关于使用两个相关的文本编辑器进行文本编辑：`vi` 和 `Vim`。`vi` 作为标准 Unix^([1](#ch01.html#idm46601096365968)) 文本编辑器有着悠久的传统。`Vim` 在 `vi` 的命令模式和命令语言的基础上构建，提供比原版多出至少一个数量级的强大功能和能力。

## 文本编辑器和文本编辑

开始吧。

### 文本编辑器

Unix 文本编辑器随着时间的推移而演进。最初，有 *行编辑器*，例如 `ed` 和 `ex`，用于在连续进纸打印机上使用的串行终端。（是的，人们真的在这种东西上编程！包括你们的作者之一。）行编辑器之所以被称为行编辑器，是因为你一次只处理程序的一行或几行。

随着具有光标寻址的阴极射线管（CRT）终端的引入，行编辑器演变为 *屏幕编辑器*，例如 `vi` 和 `Emacs`。屏幕编辑器让你一次处理一个全屏的文件，并让你可以轻松地在屏幕上的行之间移动。

随着图形用户界面（GUI）环境的引入，屏幕编辑器进一步演变为图形文本编辑器，在其中你使用鼠标滚动文件的可见部分、移动到文件中的特定位置并选择要执行操作的文本。基于 X Window 系统的此类文本编辑器的例子有基于 Gnome 系统的 `gedit` 和 MS-Windows 上的 `Notepad++`。还有其他。

对我们特别感兴趣的是，流行的屏幕编辑器已经演变为图形编辑器：^([2](#ch01.html#idm46601105274240)) GNU `Emacs` 提供多个 X 窗口，`Vim` 通过其 `gvim` 版本也提供。图形编辑器继续与原始的基于屏幕的版本完全相同地工作，使得过渡到 GUI 版本几乎是微不足道的。

在 Unix 系统上的所有 *标准* 编辑器中，`vi` 是你最应该掌握的。^([3](#ch01.html#idm46601105267968)) 与 `Emacs` 不同，它几乎以相同的形式存在于每个现代 Unix 系统上，从而提供了一种文本编辑的通用语言。^([4](#ch01.html#idm46601105264304)) 同样的话也可以说 `ed` 和 `ex`，但屏幕编辑器及其基于 GUI 的后代要容易得多使用。（事实上如此，以至于行编辑器通常已不再使用。）

`vi` 存在多种实现。有原始的 Unix 版本，还有多个“克隆”：从头编写的程序，其行为像 `vi` 一样，但不基于原始 `vi` 源代码。其中，[`Vim`](https://www.vim.org) 已成为最受欢迎的。

在 [第一部分](#part01.html#vi8-part-1) 的章节中，我们教你如何以一般意义上使用 `vi`。这些章节中的所有内容都适用于所有版本的 `vi`。然而，我们在 `Vim` 的上下文中进行讲解，因为这很可能是你系统上拥有的版本。阅读时，请随意将“`vi`”理解为代表“`vi` 和 `Vim`”。
