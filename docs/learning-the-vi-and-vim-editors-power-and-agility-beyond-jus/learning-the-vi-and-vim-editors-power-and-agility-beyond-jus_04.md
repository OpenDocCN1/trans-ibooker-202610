## 第 3 章. 快速移动

当然，你不会只创建新文件。你将花费大量时间编辑现有文件。你很少想简单地打开到文件中的第一行并逐行移动；有时你想直接到达文件中的特定位置并开始工作。

所有编辑都始于你将光标移动到想要开始编辑的位置（或者，使用 `ex` 行编辑器命令，通过标识要编辑的行号）。本章向你展示如何以多种方式思考移动（按屏幕、按文本、按模式或按行号）。在 `vi` 和 `Vim` 中有许多移动方式，因为编辑速度取决于仅用几个击键到达目的地。

本章涵盖：
* 按屏幕移动
* 按文本块移动
* 按模式搜索移动
* 按行号移动

## 按屏幕移动

当你阅读一本书时，你会以页面的形式思考书中的“位置”：你停止阅读的那一页，或索引中的页码。当你在编辑文件时，你没有这种便利。有些文件只有几行，你可以一次看到整个文件。但许多文件有数百（或数千！）行。

你可以将文件视为长卷纸上的文本。屏幕是该长卷上（通常）24 行文本的窗口。^(1)

在插入模式下，随着你在屏幕上填满文本，你最终会在屏幕的底行上输入。当你到达末尾并按下 `ENTER` 时，顶行会滚出视野，并在屏幕底部出现一个空白行用于新文本。这称为 *scrolling*。

在命令模式下，你可以通过向前或向后滚动屏幕来浏览文件中的任何文本。而且由于光标移动可以通过数字前缀相乘，你可以快速移动到文件中的任何位置。

## 滚动屏幕

有 `vi` 命令可通过整屏和半屏向前和向后滚动文件：

`^F`:
向前滚动一屏。

`^B`:
向后滚动一屏。

`^D`:
向前滚动半屏（向下）。

`^U`:
向后滚动半屏（向上）。

### 注意
在此命令列表中，`^` 符号代表 CTRL 键。因此 `^F` 表示按住 CTRL 键同时按下 SHIFT-F 键。

还有将屏幕向上滚动一行（`^E`）和向下滚动一行（`^Y`）的命令。然而，这两个命令不会将光标移动到行的开头。光标保持在发出命令时所在的行内的相同位置。

## 使用 z 重新定位屏幕

如果你想向上或向下滚动屏幕，但希望光标保持在离开的那一行，使用 `z` 命令：

`z` `ENTER` and `z+` `ENTER`:
将当前行移动到屏幕顶部并滚动。

`z.`:
将当前行移动到屏幕中央并滚动。

`z-`:
将当前行移动到屏幕底部并滚动。

使用 `z` 命令时，将数字前缀用作乘数是没有意义的。（毕竟，你只需要将光标重新定位到屏幕顶部一次。重复相同的 `z` 命令不会移动任何东西。）相反，`z` 将数字前缀理解为行号，用它代替当前行。例如，`z` `ENTER` 将当前行移动到屏幕顶部，但 `200z` `ENTER` 将第 200 行移动到屏幕顶部。

### 注意
一些 GNU/Linux 发行版带有 `/etc/vimrc` 文件，该文件将 `Vim` 选项 `scrolloff`（“滚动偏移”）设置为非零值（通常为五）。^(2) 其他发行版使用文件 `/usr/share/vim/vimXX/defaults.vim`，其中 `XX` 为 `Vim` 版本。将 `scrolloff` 设置为非零值会导致 `Vim` 总是在光标上方和下方提供相应数量的上下文行。因此，如果你输入 `z` `ENTER` 将当前行移动到屏幕顶部，但当前行仅移动到屏幕顶部下方几行，你就会明白原因。

此选项也会影响 `H` 和 `L` 命令（参见 “屏幕内移动”），也许还有其他命令。

你可以通过在个人 `*.vimrc` 文件中显式将 `scrolloff` 设置为零来取消此类默认设置的影响。（有关此文件的更多信息，请参阅章节 “自定义 vi 和 Vim”，以及章节 “系统和用户配置文件”。）

## 重绘屏幕

如果你在终端窗口中使用 `vi` 或 `Vim`，在编辑时计算机系统消息可能会显示在你的屏幕上。（这在你登录到远程服务器系统时尤其可能发生。）这些消息不会成为编辑缓冲区的一部分，但会干扰你的工作。当系统消息出现在屏幕上时，你需要重新显示或重绘屏幕。

每当你滚动时，你都会重绘屏幕的一部分（或全部），因此你始终可以通过将不需要的消息滚动出屏幕然后返回到之前的位置来摆脱它们。但你也可以通过输入 `CTRL-L` 在不滚动的情况下重绘屏幕。

## 按行移动

在当前屏幕内还有按行移动的命令。你已经见过 `j` 和 `k`。你还可以使用：

`ENTER`:
移动到下一行的第一个非空白字符。

`+`:
移动到下一行的第一个非空白字符。（与 `ENTER` 相同。）

`-`:
移动到上一行的第一个非空白字符。

这三个命令向下或向上移动到行的第一个 *字符*，忽略任何空格或制表符。相比之下，`j` 和 `k` 将光标向下或向上移动到行的第一个位置，即使该位置为空（并且假设光标从第一个位置开始）。

### 当前行上的移动

不要忘记 `h` 和 `l` 将光标向左和向右移动，并且 `0`（零）和 `$` 将光标移动到行的开头或结尾。你还可以使用以下命令：

`^`:
移动到当前行的第一个非空白字符。

`n` `|`:
移动到当前行第 `n` 列的字符，如果 `n` 大于该行字符数则移动到行尾。^(3)

与前面显示的行移动命令一样，`^` 移动到行的第一个 *字符*，忽略任何空格或制表符。相比之下，`0` 移动到行的第一个位置，即使该位置为空。

## 按文本块移动

另一种思考在 `vi` 文件中移动的方式是通过文本块——单词、句子、段落或章节。

你已经学会了通过单词向前和向后移动（`w`、`W`、`b` 或 `B`）。此外，你还可以使用以下命令：

`e`:
移动到当前单词的末尾（标点和空白分隔单词）。

`E`:
移动到当前单词的末尾（空白分隔单词）。

`(`:
移动到当前句子的开头。

`)`:
移动到下一句子的开头。

`{`:
移动到当前段落的开头。

`}`:
移动到下一段落的开头。

`[[`:
移动到当前章节的开头。

`]]`:
移动到下一章节的开头。

为了找到句子的结尾，`vi` 和 `Vim` 会查找以下标点符号之一：`?`、`.` 或 `!`。当标点后面至少有两个空格或出现在行的最后一个非空白字符时，`vi` 会定位句子的结尾。如果你只在句号后留下一个空格，或者句子以引号结束，`vi` 就不会识别该句子。然而，`Vim` 并没有那么老式，只要求终止标点后有一个空格。

段落定义为直到下一空白行或 `troff` MS 宏包中的默认段落宏（`.IP`、`.PP`、`.LP` 或 `.QP`）的文本。^(4) 同样，章节定义为直到下一个默认章节宏（`.NH`、`.SH`、`.H 1` 或 `.HU`）的文本。被识别为段落或章节分隔符的宏可以通过 `:set` 命令自定义，描述见 第 7 章，“高级编辑”。



请记住你可以将数字与移动命令结合使用。例如，`3)` 向前移动三句话。还请记住你可以使用移动命令进行编辑：`d)` 删除到当前句子的末尾；`2y}` 复制（抓取）前两个段落。

还请记住你可以使用诸如 `cw` 和 `ce` 之类的编辑命令配合运动命令。Robert P. J. Day 指出，有趣的是，“虽然 `w` 和 `e` 是略有不同的移动命令，但更改命令 `cw` 和 `ce` 完全做同样的事情。”

# 通过搜索移动

在大型文件中快速移动的最有用方法之一是通过搜索文本，或者更准确地说，搜索 `pattern` 的字符。有时可以执行搜索来查找拼写错误的单词或查找程序中变量的每个出现位置。

搜索命令是特殊字符 `/`（斜杠）。当你输入斜杠时，它会出现在屏幕底行；然后你输入想要查找的 `pattern`：`/` `pattern`。

一个 pattern 可以是一个完整的单词或任何其他字符序列（称为“字符字符串”）。例如，如果你搜索字符 `red`，你将匹配 `red` 作为一个完整单词，但也会匹配 `occurred`。如果在 `pattern` 之前或之后包含空格，则空格会被视为待匹配文本的一部分。与所有底行命令一样，按 `ENTER` 完成。

`vi` 和 `Vim`，像所有其他 Unix 编辑器一样，都有一种特殊的模式匹配语言，允许你查找可变文本模式——例如，以大写字母开头的任何单词，或行首的单词 `The`。我们将在 第 6 章，“全局替换” 中讨论这种更强大的模式匹配语法。现在，只需将 pattern 视为一个单词或短语即可。

编辑器从光标处开始搜索并向前搜索，如果必要则环绕到文件开头。光标移动到 `pattern` 的第一次出现位置。如果没有匹配，则在状态行显示消息“Pattern not found”。^(5)

使用文件 `practice`，以下是通过搜索移动光标的方法：

Keystrokes: `/edits` `ENTER`

Results:
```
With a screen editor you can scroll the
page, move the cursor, delete lines, insert
characters, and more, while seeing the
results of your edits as you make them.
```
搜索 pattern `edits`。光标直接移动到匹配文本。注意在按 `ENTER` 之前不要在 `edits` 后输入空格。

Keystrokes: `/scr` `ENTER`

Results:
```
With a screen editor you can scroll the
page, move the cursor, delete lines, insert
characters, and more, while seeing the
results of your edits as you make them.
```
搜索 pattern `scr`。搜索会环绕到文件前端。

请注意你可以输入任意字符组合；搜索不一定针对完整单词。

要向后搜索，请输入 `?` 而不是 `/`：

```
?pattern
```

在这两种情况下，如果必要，搜索会环绕到文件开头或结尾。

## 重复搜索

你最后搜索的 `pattern` 在整个编辑会话中保持可用。搜索后，而不是重复原始按键，你可以使用 `vi` 命令再次搜索上一个 `pattern`：

`n`:
重复以相同方向搜索。

`N`:
重复以相反方向搜索。

`/` `ENTER`:
向前重复搜索。

`?` `ENTER`:
向后重复搜索。

由于上一个 `pattern` 保持可用，你可以搜索一个 `pattern`，做一些工作，然后使用 `n`、`N`、 `/` 或 `?` 再次搜索同一个 `pattern` 而无需重新输入。你的搜索方向（`/` 为向前，`?` 为向后）显示在屏幕左下角。`Vim` 超越了 `vi`，它将搜索文本放入命令行并允许你使用上下箭头键滚动已保存的搜索命令历史。章节 “介绍历史窗口” 讨论了如何充分利用已保存的搜索文本历史。

为了继续前面的示例，由于 pattern `scr` 仍可用于搜索，你可以执行以下操作：

Keystrokes: `n`

Results:
```
With a screen editor you can scroll the
page, move the cursor, delete lines, insert
characters, and more, while seeing the
results of your edits as you make them.
```
使用 `n`（next）命令移动到 pattern `scr` 的下一个实例（从 `scr`een 到 `scr`oll）。

Keystrokes: `?you` `ENTER`

Results:
```
With a screen editor you can scroll the
page, move the cursor, delete lines, insert
characters, and more, while seeing the
results of your edits as you make them.
```
使用 `?` 从光标向后搜索到 `you` 的第一次出现。你需要在输入 pattern 后按 `ENTER`。

Keystrokes: `N`

Results:
```
With a screen editor you can scroll the
page, move the cursor, delete lines, insert
characters, and more, while seeing the
results of your edits as you make them.
```
重复上一次对 `you` 的搜索，但方向相反（向前）。

有时你只想在更前面找到一个词；你不希望搜索环绕到文件 earlier 部分。有个选项 `wrapscan` 控制搜索是否环绕。你可以这样禁用环绕：

```
:set nowrapscan
```

当设置 `nowrapscan` 且向前搜索失败时，`vi` 的状态行显示以下消息：

```
Address search hit BOTTOM without matching pattern
```

`Vim` 显示此消息：

```
E385: search hit BOTTOM without match for: foo
```

当设置 `nowrapscan` 且向后搜索失败时，消息中显示 “TOP” 而不是 “BOTTOM”。

你可以将 `/` 和 `?` 搜索运算符与更改文本的命令（如 `c` 和 `d`）结合使用。继续前面的示例：

Results:
```

# 按行号移动

文件中的行按顺序编号，你可以通过指定行号在文件中移动。

行号对于识别要编辑的大块文本的开头和结尾很有用。对程序员来说行号也很实用，因为编译器错误信息会引用行号。最后，行号被 `ex` 命令使用，你将在后面的章节学习这些命令。

如果你要按行号移动，必须有一种方法来识别它们。行号可以使用 `:set` `nu` 选项在屏幕上显示，该选项在 第 5 章 中有描述。你也可以在屏幕底部显示当前行号。

`CTRL-G` 命令会使 `vi` 在屏幕底部显示以下信息：当前行号、文件中的总行数以及当前行号占总数的百分比。例如，对于文件 `practice`，`CTRL-G` 可能显示：

```
"practice" line 3 of 6 --50%--
```

Vim 提供更多信息：

```
"practice" 4 lines --75%--                          3,23          All
```

倒数第二个字段是光标位置（第 3 行，第 23 个字符）。在更大的文件中，最后一个字段会变成一个百分比，表示你在文件中的位置。

`CTRL-G` 要么用于显示命令中要使用的行号，要么在你从编辑会话中分心时帮助你重新定位。

如果你已修改文件但尚未写入，`[Modified]` 会出现在文件名后的状态行中。

## G（Go To，去到）命令

你可以使用行号在文件中移动光标。`G`（go to）命令使用行号作为数字参数并直接移动到该行。例如，`44G` 将光标移动到第 44 行的开头。没有行号的 `G` 将光标移动到文件的最后一行。

输入两个反引号（`` `` ``）会将你返回到原始位置（即上次发出 `G` 命令的位置），除非在此期间你进行了一些编辑。如果你在进行编辑后使用除 `G` 之外的命令移动光标，`` `` `` 会将光标返回到上次编辑的位置。如果你发出过搜索命令（`/` 或 `?`），`` `` `` 会将光标返回到开始搜索时的位置。一对单引号（`''`）的工作方式与两个反引号类似，只是它将光标返回到该行的开头，而不是光标之前所在的精确位置。

`CTRL-G` 显示的总行数可以让你大致了解需要移动多少行。如果你在 1,000 行的文件的第 10 行：

```
"practice" 1000 lines --1%--                   10,1          1%
```

而你知道想要在该文件接近末尾处开始编辑，你可以用 `800G` 给出目的地的近似值。

按行号移动是一种工具，可以让你在大型文件中快速从一个位置移动到另一个位置。
