8. In NorthwindContext.cs, in the OnConfiguring method, remove the compiler #warning about the connection string.

Good Practice: We will override the default database connection string in any projects such as websites that need to work with the Northwind database, so the class derived from DbContext must have a constructor with a DbContextOptions parameter for this to work, as shown in the following code:

```
public NorthwindContext(DbContextOptions<NorthwindContext> options)
    : base(options)
{
}
```
