## 了解 HTTP

为了与 Web 服务器通信，客户端（也称为用户代理）使用 HTTP 通过网络进行调用。因此，HTTP 是 Web 的技术基础。因此，当我们谈论网站和 Web 服务时，我们指的是它们使用 HTTP 在客户端（通常是 Web 浏览器）和服务器之间进行通信。
