Such operations should either be converted to asynchronous operations where possible or executed on dedicated threads that then communicate using a primitive that does support asynchrony, like a channel. Some executors also provide mechanisms for indicating that a particular segment of asynchronous code might block, or for yielding voluntarily in the context of loops that might otherwise not yield, which can comprise part of the solution. A good rule of thumb is that no future should be able to run for more than 1 ms without returning Poll::Pending.
