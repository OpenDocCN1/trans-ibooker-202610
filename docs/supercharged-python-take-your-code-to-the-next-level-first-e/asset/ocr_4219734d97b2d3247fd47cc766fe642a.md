```
[ 8  9 10 11]
[12 13 14 15]]
```

This is a familiar pattern. Is there a way to produce such an array without having to enter all the data directly? Yes, there are at least two! The simplest technique is to generate the numbers from 1 to 15 to form a simple array, and then use the **numpy reshape** function to rearrange it into a 4 × 4 array with the same elements.

Click here to view code image

```
A = np.arange(16).reshape((4, 4))
```

The other way (which is slightly more verbose) is to use **fromfunction** to do the job. In either case, you can apply this pattern to much, much larger arrays, with a shape such as 200 × 100 or even 1,000 × 3,000.

In the case of creating a 4 × 4 array, the function call would be

Click here to view code image

```
A = np.fromfunction(lambda r, c: r*4 + c, (4, 4))
```
