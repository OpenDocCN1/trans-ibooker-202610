```
import numpy as np
import matplotlib.pyplot as plt

A = np.random.standard_normal(2000000)
A = A * 10 + 100
B = np.histogram(A, 50)[0]
plt.plot(B)
plt.show()
```

This code specifies no argument for the “X-axis” array;
instead, it’s handled by default. The plotting software uses 0, 1,
2 ... N–1 for the X coordinates, where N is the length of the B
array, which contains the result of the `.histogram` function.
