# # 11.9 OVERVIEW OF THE MATH PACKAGE

The `math` package provides a series of functions useful in many scientific and mathematical applications.

Although most of the services of the `math` package are provided as functions, the package also includes two useful constants: `pi` and `e`. Depending on how you import the package, these constants are referred to as `math.pi` and `math.e`.

The `math` package is another package provided in any standard Python download. You never have to search for it or download it. Importing it is sufficient.

```
```
import math
```
```

You can also import symbols selectively, of course.
