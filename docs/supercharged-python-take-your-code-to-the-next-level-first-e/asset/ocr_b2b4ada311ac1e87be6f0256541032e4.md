Remember that units is the extra attribute that the Money

But this approach fails with immutable classes such as
Decimal. Instead, it’s necessary to write a __new__ method
for the Money class. The allocation of the Decimal portion of
the Money class is handled by __new__.

```
from decimal import Decimal

class Money(Decimal):
    def __new__(cls, v, units='USD'):
        return super(Money, cls).__new__(cls, v)

    def __init__(self, v, units='USD'):
        self.units = units

m = Money('0.11', 'USD')
print(m, m.units)
```

This small program prints the following:

```
0.11 USD
```
