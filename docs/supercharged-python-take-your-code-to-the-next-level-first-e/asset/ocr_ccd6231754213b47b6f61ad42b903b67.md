can produce a more complete spreadsheet, in which the bottom row contains sums of the columns.

To do this, we get the sums of all the columns of B1. The setting `axis=0` moves along the X axis, getting totals as it moves; therefore, it creates a row containing column totals.

```
B_cols = np.sum(B1, axis = 0)
```

The following statement then glues on the row, along the bottom of B1.

```
B2 = np.r_[B1, [B_cols]]
```

Printing B2 prints the following results:

```
[[ 0  1  2  3  4 10]
 [ 0  1  2  3  4 10]
 [ 0  1  2  3  4 10]
 [ 0  1  2  3  4 10]
 [ 0  4  8 12 16 40]]
```

So there we have it: transformation of an ordinary array into a spreadsheet display that includes totals of all rows and columns along the bottom and the right.

The whole procedure can be placed in a function that will operate on any two-dimensional array.

```
def spreadsheet(A):
    AC = np.sum(A, axis = 1)
    A2 = np.c_[A, AC]
    AR = np.sum(A2, axis = 0)
    return np.r_[A2, [AR] ]
```
