This last set of changes, you should be able to see, reduces the amount of code by several lines.

Let’s review. By using this approach, adopting a Scanner object, what has been gained?

We could have just used the regular expression function, **re.findall**, to split up a line of input into tokens and then processed the tokens as part of a list, one at a time, examining the token and deciding what function to call.

By creating a Scanner object, we’re doing something similar, but it gives us more control. This RPN Interpreter application is controlled by functions that the Scanner object calls directly in response to finding specific kinds of tokens.
