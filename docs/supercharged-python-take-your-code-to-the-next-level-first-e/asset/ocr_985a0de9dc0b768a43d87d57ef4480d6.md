```
>>> 'Here is a number: %d.' % 100
'Here is a number: 100.'
```

These elements can be broken up programmatically, of course. Here’s an example:

```
n = 25 + 75
fmt_str = 'The sum is %d.'
print(fmt_str % n)
```

This example prints the following:

```
The sum is 100.
```

The string formatting operator, %, can appear in either of these two versions.
