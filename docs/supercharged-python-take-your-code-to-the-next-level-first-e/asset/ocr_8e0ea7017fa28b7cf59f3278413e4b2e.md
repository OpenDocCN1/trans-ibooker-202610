character is not part of the number itself and is therefore not
affected by the comma, described in the next section.
There’s also interaction with the plus/minus sign. If you try
the following, you’ll see a difference in the location where the
plus sign (+) gets printed.

Click here to view code image

```
print('{:0>+10} {:+010}'.format(25, 25))
```

This example prints

```
0000000+25 +000000025
```
