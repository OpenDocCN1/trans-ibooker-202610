```
(r'\d+',
 sc_int),
(r'\s+',
 None)
])
```

With these definitions in place, we can now call the function `scanner.scan`. That function returns a tuple with two outputs: the first is a list of all the tokens returned by the functions; the second is a string containing text not successfully scanned. Here are some examples:

```
print(scanner.scan('3 3+'))
```

This prints

```
([3, 3, '+'], '')
```
