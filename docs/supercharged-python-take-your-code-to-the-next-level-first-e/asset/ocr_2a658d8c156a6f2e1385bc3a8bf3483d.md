```
# File mod_b.py ----
import mod_a

def funcB(n):
    print(n)
    mod_a.funcA(n)
```

This program works, or at least it does until it gets more complex. All the main module does is import the two modules (mod_a and mod_b) and then run one of the functions. Although the functions are mutually dependent— each calls the other— there is an appropriate exit condition, and so the program runs fine, producing the following result:

```
4
3
2
1
0
```

Wonderful! Except that this code is easy to break. Suppose you add an innocent-looking statement to mod_a.py, producing the following (with a new statement shown in bold):
