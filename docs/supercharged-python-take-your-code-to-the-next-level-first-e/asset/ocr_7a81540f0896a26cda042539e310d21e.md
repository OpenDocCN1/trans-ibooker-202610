In general, `__init__` methods tend to have the pattern
shown here, although they can do other initialization work if
you want.

![](bbox=[0.1445, 0.5062, 0.2539, 0.5859])

```
class class_name:
    def __init__(self, val1, val2, ...):
        self.instance_var1 = val1
        self.instant_var2 = val2
        ...
```

Python actually uses the `__new__` method to create
objects, but most of the time, you’ll want to stick to writing and
implementing the `__init__` method to perform
