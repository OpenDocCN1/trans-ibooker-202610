```
st.push(20)
st.push(30)
st.push(40)
print('Size of stack is:', len(st))
print('First elem is:', st[0])
print('The top of the stack is:', st.peek())
print(st.pop())
print(st.pop())
print(st.pop())
print('Size of stack is:', len(st))
```

These statements result in the following output:

```
Size of stack is: 4
First elem is: 10
The top of the stack is: 40
40
30
20
Size of stack is: 1
```

If you’re familiar with object oriented programming, you may note that the same results could have been achieved more easily in this case just by using inheritance. We could implement this dedicated Stack class by using the following:

```
class Stack(list):
    def push(self, v):
        self.append(v)

    def peek(self):
        return self[-1]
```

Given these few lines of code, this Stack class can carry out all the operations of the more elaborate class definition shown
