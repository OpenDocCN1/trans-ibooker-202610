Suppose you have an expression adding two objects together,
each of a different class:

```
fido = Dog()
precious = Cat()
print(fido + precious)
```

Python evaluates the expression `fido + precious` by first
checking to see whether the Dog class implements an `__add__`
method. There are several possibilities for what happens next.

+   • The left operand implements an `__add__` method and returns a
+   value other than `NotImplemented`. Then no method of the right
+   operand needs to be called.

+   • The left operand (or rather its class) does not implement an `__
+   __add__` method at all. In that case, Python checks to see whether
+   the right operand implements an `__radd__` method.
