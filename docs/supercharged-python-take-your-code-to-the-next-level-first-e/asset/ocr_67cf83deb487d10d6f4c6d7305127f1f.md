# 2.8 BINARY, HEX, AND OCTAL CONVERSION FUNCTIONS

In addition to the **str** conversion function, Python supports three functions that take numeric input and produce a string result. Each of these functions produces a digit string in the appropriate base (2, 16, and 8, corresponding to binary, hexadecimal, and octal).

![](bbox=[0.148, 0.491, 0.254, 0.573])

Click here to view code image

```
bin(n) # Returns a string containing n in binary:
# For example, bin(15) -> '0b1111'
hex(n) # Returns a string containing n in hex:
# For example, hex(15) -> '0xf'
oct(n) # Returns a string containing n in octal:
# For example, oct(15) -> '0o17'
```
