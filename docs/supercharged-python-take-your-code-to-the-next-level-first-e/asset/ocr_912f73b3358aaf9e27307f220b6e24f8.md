# # SET_OBJ.UNION(OTHER_SET)

Returns the union of _set_obj_ and _other_set_, which is the set containing all objects that are in either set or both. For example:

Click here to view code image

```
```python
a_set = {1, 2, 3, 4}
b_set = {3, 4, 5, 6}
print(a_set.union(b_set))  # Prints {1, 2, 3, 4, 5,
                           #         6}
```
```

The union operator (`|`) performs the same action.

Click here to view code image

```
```python
print(a_set | b_set)  # Prints {1, 2, 3, 4, 5,
                      #         6}
```
