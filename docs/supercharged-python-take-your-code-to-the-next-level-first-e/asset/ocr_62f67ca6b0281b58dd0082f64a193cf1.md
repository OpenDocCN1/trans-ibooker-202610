An alternative to writing a literal is to use an explicit
**complex** conversion:

```
z = complex(5.7, 10)
```

If we then print the real and imaginary portions of z
explicitly, as in the previous example, z is now described this
way:

The ability to write complex numbers directly is a
convenience. You can even exclude the “real” part, and if you
do, the number still has type **complex**.
So you can do things like this:

```
print(2j * 3j)
```

This statement produces the result of multiplying two
complex numbers together (each of which has an imaginary
portion in this case; the real portion exists but in each case is
assumed to be 0). If you’re familiar with the basic math of
complex numbers, the result should not surprise you.

```
(-6+0j)
```
