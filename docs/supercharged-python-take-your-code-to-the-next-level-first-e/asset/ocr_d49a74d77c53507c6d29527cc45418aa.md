_Make “b_list” an alias for whatever “a_list” refers to._

The variable b_list therefore becomes an alias for whatever a_list refers to. Consequently, if changes are made to either variable, both reflect that change.

If instead you want to create a separate copy of all the elements of a list, you need to perform a member-by-member copy. The simplest way to do that is to use slicing.

```
my_list = [1, 10, 5]
yr_list = my_list[:] # Perform member-by-member
copy.
```

Now, because my_list and yr_list refer to separate copies of [1, 10, 5], you can change one of the lists without changing the other.
