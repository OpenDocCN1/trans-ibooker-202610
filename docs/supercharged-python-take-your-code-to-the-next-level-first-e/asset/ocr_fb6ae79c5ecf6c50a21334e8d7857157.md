# ## 2.4 INDEXING AND SLICING

Two of the ways to extract data from strings include indexing
and slicing:

+   - *Indexing* uses a number to refer to an individual character,
+   according to its place within the string.

+   - *Slicing* is an ability more unique to Python. It enables you to refer
+   to an entire substring of characters by using a compact syntax.

Lists support similar abilities, so “Chapter 3, Advanced List
Capabilities,” should look similar. However, there are some
