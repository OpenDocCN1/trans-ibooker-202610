A print-field size of 12 (or any other multiple of 4), creates a conflict with the comma, because an initial comma cannot be part of a valid number. Therefore, Python adds an additional leading zero in that special case.

# Click here to view code image

```
n = 13000
print('The amount is {:012,}'.format(n))
```

# This prints

```
The amount is 0,000,013,000
```

But if o is specified as a fill character instead of as a leading zero, the zeros are not considered part of the number and are not grouped with commas. Note the placement of the o here relative to the right justify (>) sign. This time it’s just to the left of this sign.

# Click here to view code image

```
print('The amount is {:o>11,}'.format(n))
```

# This prints

```
The amount is 0000013,000
```
