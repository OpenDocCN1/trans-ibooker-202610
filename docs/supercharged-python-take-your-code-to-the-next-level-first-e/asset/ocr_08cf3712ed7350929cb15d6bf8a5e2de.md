# # 14.10.3 Greater-Than (>) and Get-Random-Number (!)

Before leaving the topic of the RPN interpreter altogether, let’s add two more features, which will aid in the creation of game programs. By adding a greater-than operator (>) and a get- random-number operator (!), we’ll enable the writing of the number guessing game as an RPN script.

The greater-than operator will be like most RPN operations. It will pop two operands off the stack and then push a result on top of the stack.

![](bbox=[0.1484, 0.3969, 0.2559, 0.4742])

```
`op1 op2 >`
```

The two operands are compared. If `op1` is greater than `op2`, then the value 1 is pushed onto the stack; otherwise, the value o is pushed.
