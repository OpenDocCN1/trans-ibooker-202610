The process of reading from a binary file using the **struct** package is similar.

+   - Open the file in binary read mode (`'wb'`).

+   - Read in a string of bytes. You must specify the exact number of bytes to read, so you need to know the size of the record ahead of time; you can determine that by running the **struct.calcsize** function on the data-format string based on characters from Table 8.2.
