

That’s a mouthful, but an example should help clarify. The following example demonstrates how **zip** can be used to create one list from the sum of two other lists: each element in _a_ is added to the corresponding element in _b_.

Click here to view code image

```
a = [1, 2, 3]
b = [10, 20, 30]
c = [i[0] + i[1] for i in zip(a, b)]
```

Printing the results gives us

```
[11, 22, 33]
```

The expression `zip(a, b)`, were you to convert it to a list and print it, produces a list of tuples, as shown:

```
>>> a_list = list(zip(a, b))
>>> a_list
[(1, 10), (2, 20), (3, 30)]
```

Compare the first three lines of the previous example with the following lines, which are more complicated and harder to maintain. This is a longer way of producing the same result.

Click here to view code image

```
a = [1, 2, 3]
b = [10, 20, 30]
c = []
for i in range(min(len(a), len(b)) ):
    c.append(a[i] + b[i])
```

## C. Set 方法

本附录列出了 `set` 类型的方法。它不涵盖也可用于此类型的函数，例如 `len`。有关这些内容，请参见附录 B。

### 表 C.1. 最常用的 Set 方法。

| 要执行的任务： | 调用的方法： |
| --- | --- |
| 将元素添加到集合 | `add` |
| 清除集合的所有内容 | `clear` |
| 复制另一个集合的所有内容 | `copy` |
| 从集合中删除项目 | `discard`, `pop`, `remove` |
| 确定集合是否是另一个集合的子集或超集 | `issubset`, `issuperset` |
| 执行集合差集（集合减法） | `difference`, `symmetric_difference` |
| 执行交集 | `intersection` |
| 执行并集 | `union` |

**注意**：要确定元素是否是特定集合的成员，请使用 `in` 关键字。

## SET_OBJ.ADD(OBJ)

将对象 _obj_ 添加到现有集合中。如果 _obj_ 已经是集合的成员，则该语句无效。两种情况均返回 **None**。例如：

Click here to view code image

```
a_set = {1, 2, 3}
a_set.add(4)        # Adds 4 to the set.
```

集合 `a_set` 现在等于 `{1, 2, 3, 4}`。

## SET_OBJ.CLEAR()

清除现有集合中的所有元素。不接受参数，并返回值 **None**。

```
a_set.clear()
```

## SET_OBJ.COPY()

返回集合的浅拷贝，逐个成员复制。例如：

```
a_set = {1, 2, 3}
b_set = a_set.copy()
```

执行这些语句后，`b_set` 具有与 `a_set` 相同的内容，但它们是两个独立的集合，因此对其中一个的更改不会影响另一个。

## SET_OBJ.DIFFERENCE(OTHER_SET)

返回一个集合，包含 `set_obj` 中存在但不在 `other_set` 中的所有元素。例如：

Click here to view code image

```
a_set = {1, 2, 3, 4}
b_set = {3, 4, 5, 6}
c = a_set.difference(b_set)
print(c)            # Prints {1, 2}
print(b_set.difference(a_set))  # Prints {5, 6}
```

`difference` 运算符（对集合使用减号 `-`）产生相同的结果且更紧凑。

Click here to view code image

```
print(a_set - b_set)        # Prints {1, 2}
```

## SET_OBJ.DIFFERENCE_UPDATE(OTHER_SET)

执行与 `difference` 方法相同的操作，但结果存储在 `set_obj` 中，返回值为 `None`。

差值赋值运算符 (`-=`) 执行相同的操作。

Click here to view code image

```
a_set -= b_set    # Put results of diff. in a_set
```

## SET_OBJ.DISCARD(OBJ)

从 _set_obj_ 中删除元素 _obj_。返回值 **None**。执行与 **remove** 方法相同的操作，但如果 _obj* 当前不是集合的成员，则不会引发异常。

Click here to view code image

```
a_set = {'Moe', 'Larry', 'Curly'}
a_set.discard('Curly')
print(a_set)        # Prints {'Moe', 'Larry'}
```

## SET_OBJ.INTERSECTION(OTHER_SET)

返回 _set_obj_ 和 _other_set_ 的交集，即同时是两个集合元素的所有对象。如果两个集合没有共同元素，则返回空集合。例如：

Click here to view code image

```
a_set = {1, 2, 3, 4}
b_set = {3, 4, 5, 6}
print(a_set.intersection(b_set))  # Prints {3, 4}
```

交集运算符 (&) 执行相同的操作。

Click here to view code image

```
print(a_set & b_set)      # Prints {3, 4}
```

## SET_OBJ.INTERSECTION_UPDATE(OTHER_SET)

执行与 intersection 方法相同的操作，但结果存储在 set_obj 中，返回值为 None。

交集赋值运算符 (&=) 执行相同的操作。

Click here to view code image

```
a_set &= b_set   # Put the intersection in a_set
```

## SET_OBJ.ISDISJOINT(OTHER_SET)

根据 set_obj 和 other_set 是否不相交（即没有共同元素）返回 True 或 False。

## SET_OBJ.ISSUBSET(OTHER_SET)

如果 _set_obj_ 是 _other_set_ 的子集，则返回 **True**；这包括两个集合相等的情况。例如：

Click here to view code image

```
{1, 2}.issubset({1, 2, 3})  # Produces the value True.
{1, 2}.issubset({1, 2})     # Also produces True.
```

## SET_OBJ.ISSUPERSET(OTHER_SET)

如果 _set_obj_ 是 _other_set_ 的超集，则返回 True；这包括两个集合相等的情况。例如：

Click here to view code image

```
{1, 2}.issuperset({1})     # Produces the value True.
{1, 2}.issuperset({1, 2})   # Also produces True.
```

## SET_OBJ.POP()

从集合中返回一个随机元素，然后删除该元素。例如：

Click here to view code image

```
a_set = {'Moe', 'Larry', 'Curly'}
stooge = a_set.pop()
print(stooge, a_set)
```

此示例打印（或者可能打印）以下内容：

```
Moe { 'Larry', 'Curly' }
```

## SET_OBJ.REMOVE(OBJ)

从 _set_obj_ 中删除指定元素 _obj_。这与 **discard** 方法执行相同的操作，但如果 _obj* 当前不是元素，则 **remove** 会引发 **KeyError** 异常。

## SET_OBJ.SYMMETRIC_DIFFERENCE(OTHER_SET)

返回一个集合，包含属于 _set_obj_ 但不属于 _other_set_ 的所有对象，反之亦然。例如：

Click here to view code image

```
a_set = {1, 2, 3, 4}
b_set = {3, 4, 5, 6}
print(a_set.symmetric_difference(b_set))
```

此代码打印集合 {1, 2, 5, 6}。

对称差集运算符 (**^**) 执行相同的操作。

Click here to view code image

```
print(a_set ^ b_set)   # Prints {1, 2, 5, 6}
```

## SET_OBJ.SYMMETRIC_DIFFERENCE_UPDATE(OTHER_SET)

执行与 `symmetric_difference` 方法相同的操作，但结果存储在 _set_obj_ 中，返回值为 **None**。

对称差集赋值运算符 (`^=`) 执行相同的操作。

Click here to view code image

```
a_set ^= b_set     # Put the sym. difference in a_set
```

## SET_OBJ.UNION(OTHER_SET)

返回 _set_obj_ 和 _other_set_ 的并集，即包含属于任一集合或两个集合的所有对象的集合。例如：

Click here to view code image

```
a_set = {1, 2, 3, 4}
b_set = {3, 4, 5, 6}
print(a_set.union(b_set))  # Prints {1, 2, 3, 4, 5, 6}
```

并集运算符 (`|`) 执行相同的操作。

Click here to view code image

```
print(a_set | b_set)  # Prints {1, 2, 3, 4, 5, 6}
```

## SET_OBJ.UNION_UPDATE(OTHER_SET)

执行与 **union** 方法相同的操作，但结果存储在 _set_obj_ 中，返回值为 **None**。

并集赋值运算符 (`|=`) 执行相同的操作。

Click here to view code image

```
a_set |= b_set    # Put the union in a_set
```

此运算符提供了一种扩展集合内容的简便方法。例如：

Click here to view code image

```
a_set = {1, 2, 3}
a_set |= {200, 300}
print(a_set)    # Prints {1, 2, 3, 200, 300}
```
