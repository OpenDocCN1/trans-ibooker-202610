# 3.4 GETTING DATA FROM SLICES

Whereas indexing refers to one element at a time, the technique of slicing produces a sublist from a specified range. The sublist can range in size from an empty list to a new list having all the contents of the original list.

Table 3.1 shows the various ways you can use slicing.

# Table 3.1 Slicing Lists in Python

| Syntax | Produces this new list |
|---|---|
| `list[beg :end]` | All list elements starting with `beg`, up to but not including `end`. |
| `list[:e nd]` | All elements from the beginning of the list, up to but not including `end`. |
| `list[beg : ]` | All elements from `beg` forward to the end of the list. |
| `list[:]` | All elements in the list; this operation copies the entire list, element by element. |
