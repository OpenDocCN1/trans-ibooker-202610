# # del Statement

This statement removes one or more symbols from the current context. It has the following syntax:

```
del sym1 [, sym2]...
```

The effect is to remove the specified symbol or symbols but not necessarily to destroy any other object, as long as there are references to it. For example:

Click here to view code image

```
a_list = [1, 2, 3]
b_list = a_list  # Create alias for the list
del a_list      # Remove a_list from symbol table
print(b_list)   # List referred to still exists.
```
