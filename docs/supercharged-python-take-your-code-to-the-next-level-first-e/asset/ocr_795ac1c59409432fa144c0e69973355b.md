```
def get_avg(a_list):
    return sum(a_list)/len(a_list)
```

Here’s an example that executes this function:

```
>>> get_avg([1, 2, 3, 4, 10])
4.0
```

The **sum** function can be used on other kinds of iterables,
such as generators, as long as they produce a finite sequence.
For example:

```
>>> def gen_count(n):
    i = 1
    while i <= n:
        yield i
        i += 1
>>> sum(gen_count(100))
5050
```

The effect of `sum(gen_count(n))`, in this case, is to add up
all the numbers from 1 to n.
