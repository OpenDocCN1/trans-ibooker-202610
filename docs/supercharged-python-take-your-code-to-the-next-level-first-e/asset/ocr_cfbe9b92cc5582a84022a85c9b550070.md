# ## 12.5.5 The “eye” Function

The **eye** function is similar to the **identity** function in **numpy**.
Both create the same kind of array—specifically, an “identity”
array, which places 1’s in the positions [0,0], [1,1], [2,2], [3,3]
and so on, while placing 0’s everywhere else.
This function produces a two-dimensional array only.
