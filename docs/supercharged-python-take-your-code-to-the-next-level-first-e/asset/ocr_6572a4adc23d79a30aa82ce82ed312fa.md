```
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

def __add__(self, other):
    """ Return a point containing self+other."""
    newx = self.x + other.x
    newy = self.y + other.y
    return Point(newx, newy)

def __sub__(self, other):
    """ Return the distance between points."""
    dx = self.x - other.x
    dy = self.y - other.y
    return (dx * dx + dy * dy) ** 0.5

def __mul__(self, n):
    """ Return point * a scalar number, n."""
    newx = self.x * n
    newy = self.y * n
    return Point(newx, newy)
```

This sample class, which supports four magic methods (__init__, __add__, __sub__, and __mul__),
illustrates some important points.
First, each of the arithmetic operator methods returns a
value; that value, of course, can be assigned to a variable or
used in any other kind of expression. Consider this example:

```
pt1 = Point(10, 15)
pt2 = Point(0, 5)
x = pt1 + pt2
```
