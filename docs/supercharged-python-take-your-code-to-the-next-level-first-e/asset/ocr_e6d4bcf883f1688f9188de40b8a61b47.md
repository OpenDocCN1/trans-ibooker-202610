
As in other languages, putting a decimal point after a number gives it floating-point type, even the digit following the decimal point is 0:

```
x = 5.0
```

Python integers are “infinite integers,” in that Python supports arbitrarily large integers, subject only to the physical limitations of the system. For example, you can store 10 to the 100th power, so Python can handle this:

```

100.
```

Integers store quantities precisely. Unlike floating-point values, they don’t have rounding errors.
