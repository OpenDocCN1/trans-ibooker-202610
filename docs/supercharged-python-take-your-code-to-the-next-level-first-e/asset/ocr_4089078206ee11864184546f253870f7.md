```
[[fill]align]
```

**Placement**: these items, if they appear within a print-field specification, precede all other parts of the syntax, including _width_. Here’s an example containing _fill_, _align_, and _width_:

```
{:->24}
```

The next example uses this specification in context:

Click here to view code image

```
print('{:->24}'.format('Hey Bill G, pick me!'))
```

This prints

```
----Hey Bill G, pick me!
```

Let’s examine each part of this print field, `{:->24}`. Here’s the breakdown.

+   - The colon (:) is the first item to appear inside the print-field spec when you’re working with the **format** method (but not the global **format** function).

+   - After the colon, a _fill_ and an _align_ character appear. The minus sign (-) is the fill character here, and the alignment is right justification (>).

+   - After _fill_ and _align_ are specified, the print-field _width_ of 24 is given.
