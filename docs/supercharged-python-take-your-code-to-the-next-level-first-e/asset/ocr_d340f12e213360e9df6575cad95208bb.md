Meanwhile, position indexes 1 and 3 (corresponding to second and fourth arguments) refer to the integer expressions 3 and 7, which become the print-field widths of the respective fields.

Similarly, the following example shows the use of position indexes to display the number 3.141592, using a print-field width of 8 and a fixed-point display of 3 digits to the right of the decimal point. Note that numbers are right justified by default.

```
>>> 'Pi is approx. {0:{1}.{2}f}'.format(3.141592, 8,
3)
'Pi is approx.     3.142'
```
