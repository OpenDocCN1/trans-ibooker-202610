elements are accessed. So a step value of –1 produces values in
the slice by going backward through the list one item at a time.
A step value of –2 produces values in the slice by going
backward through the list two items at a time.

The following example starts with the last element and works
backwards; it therefore produces an exact copy of the list—with
all elements reversed!

```
rev_list = a_list[::-1]
```

# Here’s an example:

Click here to view code image

```
a_list = [100, 200, 300]
rev_list = a_list[::-1]
print(rev_list)    # Prints [300, 200, 100]
```

The _step_ argument can be positive or negative but cannot be
o. If _step_ is negative, then the defaults for the other values
change as follows:

+   • The default value of _beg_ becomes the last element in the list
+   (indexed as –1).

+   • The default value of _end_ becomes the beginning of the list.
+   Therefore, the slice expression [::-1] produces a reversal of the
+   original list.
