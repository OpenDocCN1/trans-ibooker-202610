```
n = int(input('Enter a positive integer: '))
prod = 1
for i in range(1, n + 1):
    prod *= i
print(prod)
```

This loop works because `range(1, n + 1)` produces integers beginning with 1 _up to but not including_ `n + 1`. This loop therefore has the effect of doing the following calculation:

```
1 * 2 * 3 * ... n
```
