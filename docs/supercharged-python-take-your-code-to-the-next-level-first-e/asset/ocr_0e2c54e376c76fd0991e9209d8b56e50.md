# # 1.15 PYTHON LISTS (AND A COOL SORTING APP)

Python’s most frequently used collection class is called the _list_ collection, and it’s incredibly flexible and powerful.

![](bbox=[0.149, 0.322, 0.254, 0.401])

```
`[ items ]`
```

Here the square brackets are intended literally, and _items_ is a list of zero or more items, separated by commas if there are more than one. Here’s an example, representing a series of high temperatures, in Fahrenheit, over a summer weekend:

```
`[78, 81, 81]`
```

Lists can contain any kind of object (including other lists!) and, unlike C or C++, Python lets you mix the types. For example, you can have lists of strings:

```
`[ 'John', 'Paul', 'George', 'Ringo' ]`
```
