These are easy qualities to test. By running tests with a
different number of trials, you should be able to see the ratio of
predicted hits to actual hits gets closer to 1.0. Here’s a function
designed to test these qualities.

import random
def do_trials(n):
    hits = [0] * 10
    for i in range(n):
        a = random.randint(0, 9)
        hits[a] += 1
    for i in range(10):
        fss = '{{: {}t{{:.3}}'.format(i, hits[i],
        print(fss.format(i, hits[i],
        hits[i]/(n/10)))
