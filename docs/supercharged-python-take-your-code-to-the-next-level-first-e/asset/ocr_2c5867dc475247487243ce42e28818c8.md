# # SET_OBJ.ADD(OBJ)

Adds an object, _obj_, to an existing set. The statement has no effect if _obj_ is aslready a member of the set. Returns **None** in either case. For example:

Click here to view code image

```
```
a_set = {1, 2, 3}
a_set.add(4)        # Adds 4 to the set.
```
```

The set `a_set` is now equal to `{1, 2, 3, 4}`.

# # SET_OBJ.CLEAR()

Clears all the elements from an existing set. Takes no arguments and returns the value **None**.

```
```
a_set.clear()
