| __eq__ __ (self , other) | Test for equality. Called in response to the == operator, which tests to see whether contents are equal. The method should return either True or False. If this method is not implemented, Python tests “equality” by using the is operator. |
| __ne__ __ (self , other) | Not equal. Called in response to the != operator, which tests contents for being unequal. As with all the other methods listed here, the correct response is to return either True or False. If this method is not implemented, Python calls the test for equality and then reverses the logical meaning. Therefore, implementing the __ __eq__ __ method is usually sufficient. |
| __gt__ __ (self | Greater-than test. This method is called in response to the > operator. Through the rules of symmetry, you can get a greater- than operation for free, as explained later, if you only need to compare to other objects of the same class. |
