> > When strings are compared, Python uses a form of alphabetical order; more specifically, it uses _code point_ order, which looks at ASCII or Unicode values of the characters. In this order, all uppercase letters precede all lowercase letters, but otherwise letters involve alphabetical comparisons, as you'd expect. Digit comparisons also work as you'd expect, so that `'1'` is less than `'2'`.
