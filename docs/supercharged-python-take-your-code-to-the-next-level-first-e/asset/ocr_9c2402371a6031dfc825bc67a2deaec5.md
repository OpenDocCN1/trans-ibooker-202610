argument: a tuple giving the shape of the array.
Another thing to note is that with `ran.randint`, the _begin_
and _end_ arguments include numbers starting with the _begin_
argument, up to but not including the _end_ argument. So this
example produces numbers up to 19.
Finally, the _shape_ argument—which comes after the _begin_
and _end_ arguments—is (3, 3), which causes the random
integers to be placed throughout a 3 × 3 array.
Here it is again. Your mileage will vary.

```
[[ 4 13 11  8]
 [ 7 14 16  1]
 [ 4  1  5  9]]
```

gets the mean of all 20 elements.

```
>>> np.mean(A)
7.75
```
