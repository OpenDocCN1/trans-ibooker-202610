The `write_var_str` function has to do some tricks. First, it creates a string format specifier of the form **hnums**. In the next example, that format specifier is `h24s`, meaning, “Write (and later read) an integer followed by a string with 24 characters.”

The `read_var_str` function then reads in an integer—in this case, 24—and uses that integer to determine exactly how many bytes to read in. Finally, these bytes are decoded back into a standard Python text string.

write_var_str('silly.dat', "I'm Henry the VIII I am!")
print(read_var_str('silly.dat'))
