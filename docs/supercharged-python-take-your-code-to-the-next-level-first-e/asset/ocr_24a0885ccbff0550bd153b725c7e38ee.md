This statement has a fairly complicated syntax, so we break it down into two major parts: first, the overall syntax. Square brackets indicate optional items.

```
try:
    statements
[except exception_specifier:
    statements]...
[else:
    statements]
[finally:
    statements]
```

The first block of `statements` is executed directly. However, if an exception is raised during the execution of that block— even during a function called directly or indirectly by one of these statements—Python checks exception handlers, as described later in this section. There may be any number of exception handlers.

The statements in the optional `else` clause are executed if the first statement block finishes without being interrupted by an exception. The statements in the optional `finally` clause execute unconditionally, after other statements in this syntax.

Each `except` clause has the following syntax:

```
except [exception [as e]]:
    statements
```
