| Operator or syntax | Description |
|---|---|
| `name = str` | Assigns the string data to the specified variable name. |
| `str1 == str2` | Returns **True** if `str1` and `str2` have the same contents. (As with all comparison ops, this is case-sensitive.) |
| `str1 != str2` | Returns **True** if `str1` and `str2` have different contents. |
| `str1 < str2` | Returns **True** if `str1` is earlier in alphabetical ordering than `str2`. For example, `'abc' < 'def'` returns **True**, but `'abc' < 'aaa'` returns **False**. (See the note about ordering.) |
| `str1 > str2` | Returns **True** if `str1` is later in alphabetical ordering than `str2`. For example, `'def' > 'abc'` returns **True**, but `'def' > 'xyz'` returns **False**. |
| `str1 <= str2` | Returns **True** if `str1` is earlier than `str2` in alphabetical ordering or if the strings have the same content. |
