```
op1 = sym_tab[op1]
if type(op2) == str:
    op2 = sym_tab[op2]
if op1:
    pc = int(op2) - 1
```

Note the importance of the **global** statement. To prevent `pc` from being interpreted as local, the **global** statement is necessary.

```
global pc
```

The core of the function is the following two lines, which alter the program counter if `op1` is nonzero (true).

```
if op1:
    pc = int(op2) - 1
```
