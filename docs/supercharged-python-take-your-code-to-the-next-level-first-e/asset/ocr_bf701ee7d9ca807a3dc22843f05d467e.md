```
print('n is %d' % n)
print('n is %d and m is %d' % (n, m))
```

The next example also works, because it organizes three numbers into a tuple.

```
tup = 10, 20, 30
print('Answers are %d, %d, and %d.' % tup)
```

These statements print the following:

```
Answers are 10, 20, and 30.
```
