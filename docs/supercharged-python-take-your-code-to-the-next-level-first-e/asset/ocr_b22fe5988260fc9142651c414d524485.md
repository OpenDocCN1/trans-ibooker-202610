# ## 4.2.8 Return Multiple Values

You can’t pass a simple variable to a Python function, change
the value inside the function, and expect the original variable to
reflect the change. Here’s an example:

Click here to view code image

```
```
def double_me(n):
    n *= 2

a = 10
double_me(a)
print(a)  # Value of a did not get doubled!!
```
```

When n is assigned a new value, the association is broken
between that variable and the value that was passed. In effect, n
is a local variable that is now associated with a different place in
memory. The variable passed to the function is unaffected.
But you can always use a return value this way:

```
```
def double_me(n):
    return n * 2

a = 10
a = double_me(a)
print(a)
```
```
