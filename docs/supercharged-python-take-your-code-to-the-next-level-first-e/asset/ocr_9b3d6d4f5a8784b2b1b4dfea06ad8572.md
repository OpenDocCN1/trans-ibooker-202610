Having run this code, we can then print the two parts of the name. Note that the group name must be in string format—and therefore be delimited by single quotation marks—before being passed to the **print** function.

Click here to view code image

```
print('first name = ', m.group('first'))
print('last name = ', m.group('last'))
```

This prints

```
first name = Jane
last name = Austen
```

Given this division, it’s easy to print or store the name in last- name-first order:

Click here to view code image

```
print(m.group('last') + ', ' + m.group('first'))
```

This prints

```
Austen, Jane
```
