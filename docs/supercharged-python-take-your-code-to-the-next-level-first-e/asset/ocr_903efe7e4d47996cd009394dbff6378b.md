```
my_lst = [100, 102, 50, 25, 72]
for i in range(len(my_lst)):
    my_lst[i] *= 2
```

After this loop is executed, my\_lst contains [200, 204,
100, 50, 144].

The **range** function produces a sequence of integers as
shown in Table 1.3, depending on whether you specify one, two,
or three arguments.

# Table 1.3. Effects of the Range Function

| Syntax | Effect |
|--------|--------|
| `range(`
`end)` | Produces a sequence beginning with 0, up to but not including
`end`. |
| `range(`
`beg,`
`end)` | Produces a sequence beginning with `beg`, up to but not
including `end`. |
| `range(`
`beg,`
`end,`
`step)` | Produces a sequence beginning with `beg`, up to but not
including `end`; however, the elements are increased by the
value of `step` each time. If `step` is negative, then the range
counts backward. |
