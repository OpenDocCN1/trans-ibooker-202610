This gives us a nice cross-section of all the cells neighboring G[2, 2], not including the cell itself. To get the neighbor count, therefore, it’s only necessary to sum this cross-section and then subtract the value of the cell itself.

```
neighbor_count = np.sum(G[1:4, 1:4]) - G[2, 2]
```

The result is 2. In the Game of Life, that would indicate that the cell in the middle is “stable”: In the next generation, it will experience neither a birth nor a death event.
