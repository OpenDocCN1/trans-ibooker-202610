Although lists can grow without limit, an index number must be in range at the time it’s used. Otherwise, Python raises an **IndexError** exception.

Performance Tip
Here, as elsewhere, we’ve used separate calls to the print function because it’s convenient for illustration purposes. But remember that repeated calls to print slow down your program, at least within IDLE. A faster way to print these values is to use only one call to print.
