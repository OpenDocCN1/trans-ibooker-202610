The basic properties of a tuple and a list are almost the same: Each is an ordered collection, in which any number of repeated values are allowed.

However, unlike a list, a tuple is immutable; tuple values cannot be changed in place. Tuples do not support all the methods or functions supported by lists; in particular, tuples do not support any methods that modify the contents of the tuple.
