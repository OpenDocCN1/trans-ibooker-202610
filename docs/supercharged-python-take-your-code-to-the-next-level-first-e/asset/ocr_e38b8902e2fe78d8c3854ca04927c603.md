```
def write_num(fname, n):
    with open(fname, 'wb') as f:
        bss = pack('h', n)
        f.write(bss)

def read_num(fname):
    with open(fname, 'rb') as f:
        bss = f.read(calcsize('h'))
        t = struct.unpack('h', bss)
        return t[0]
```

With these definitions in place, you can read and write individual integers to files, assuming these integers fit into the short-integer (16-bit) format. Larger values may need a bigger data format.

Here’s an example:

```
write_num('silly.dat', 125)
print(read_num('silly.dat')) # Write the number
125.
```
