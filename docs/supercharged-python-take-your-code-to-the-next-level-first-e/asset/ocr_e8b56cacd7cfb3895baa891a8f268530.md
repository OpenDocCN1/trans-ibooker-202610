# # Description

Regular-expression package. This package lets you create text patterns that can match many different words, phrases, or sentences. This pattern-specification language can do sophisticated searches with high efficiency.

This package is so important that it’s explored in both Chapters 6 and 7.

Math package. Contains helpful and standard math functions so that you don’t have to write them yourself. These include trigonometric, hyperbolic, exponential, and logarithmic functions, as well as the constants e and pi.

This package is explored in Chapter 11.

A set of functions for producing pseudo-random values. Pseudo-random numbers behave as if random—meaning, among other things, it’s a practical impossibility for a user to predict them.
