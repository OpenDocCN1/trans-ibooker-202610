## 前言

数据网格是我们思考、创建、共享和使用数据方式的根本转变。我们通过精心策划和制作数据产品，将数据提升为一等公民，并以与任何其他业务产品相同的关怀和承诺来支持它。消费者可以发现并选择其自身用例所需的数据产品，依赖数据产品生产者维护和支持它的承诺。从本质上讲，数据网格既关乎技术重组，也关乎社会契约、责任和期望的重新谈判。

当我编写《构建事件驱动微服务》（O'Reilly）时，我提到过（并且有些模糊地定义了）一个数据通信层，它与数据网格非常相似，但远不如数据网格经过深思熟虑。数据通信层的原则很简单：将数据视为一等公民，使其可靠且值得信赖，并通过事件流生产它，以便您可以为运营和分析应用程序提供动力。

数据网格的美妙之处在于，它并非对我们所了解的关于数据的一切进行大爆炸式的彻底修订。事实上，它真正是对基于无数人的集体辛勤工作和经验的社会和技术最佳实践的肯定。它提供了讨论如何创建、通信和使用数据所需的框架，充当数据世界的通用语言。

扎马姆·德格汉尼在将数据网格带给世界方面做出了非凡的工作。我记得 2019 年她在马丁·福勒博客上的初次文章让我震惊不已。她非常出色地描述了我团队当时面临的问题，并确定了我们为走向解决方案而需要采用的原则。她的工作深刻影响了我的思考：我们需要一个明确定义的数据通信层，以使共享和使用数据变得可靠且容易。德格汉尼的数据网格正是我们构建更美好数据世界所需要的社会技术框架。




事件和事件流在数据网格中起着至关重要的作用，因为你的业务机遇只能以最慢的数据源的速度来解决。经典的分析用例，例如计算月度销售报告，可能可以通过每天仅更新一次的数据产品来满足。但你许多最重要的业务用例，例如完成销售、计算库存和确保及时发货，需要实时数据。事件驱动的数据网格提供了支持运营和分析用例的功能，无论是实时还是批处理。

采用数据网格具有真正的价值。它简化了整个组织中数据的发现、消费、处理和应用。但数据网格最好的功能之一是，你可以从当前所处的任何位置开始应用它。这并非非此即彼的命题。你可以选取对改善你的情况有效的碎片、原则和概念，其余的则留到你准备好采纳它们的时候再处理。

我对数据网格非常兴奋。它为我们提供了一套有原则的社会和技术框架，用于构建自己的数据网格，但同样重要的是，它提供了一种与所有同事讨论和解决数据问题的语言。我希望你阅读本书的乐趣能和我写作时一样多。
