## 构建事件驱动的数据网格

数据的指数级增长与获取实时业务价值的需求相结合，是一个关键问题。事件驱动的数据网格可以从单一数据产品流中，为实时运营和分析工作负载提供动力。本书结合实践中的真实案例，提供了一系列模式，指导软件架构师和开发人员如何成功设计和构建事件驱动的数据网格。

作者Adam Bellemare演示了事件和流是什么、它们来自哪里，以及如何使用它们。你还将探讨设计模式、其影响及其使用中固有的权衡。

本书提供：

- 关于事件和事件流如何与数据网格四大支柱相关的基础
- 构建事件驱动数据网格的实用技巧，包括与现有系统的渐进式集成
- 清晰理解事件如何与系统及其他事件相关，无论是在同一流中还是跨流
- 对事件设计选项的现实审视，例如事实、增量和命令事件类型，包括这些选择将如何影响您的数据产品
- 隐私、大规模事件处理和监管合规方面的最佳实践
- 关于异步通信和处理最终一致性的建议
