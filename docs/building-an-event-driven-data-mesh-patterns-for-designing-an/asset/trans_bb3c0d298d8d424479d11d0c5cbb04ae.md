## 版权页

*构建事件驱动的数据网格* 封面上的动物是红天堂鸟 (*Paradisaea rubra*)。这些鸟仅分布于印度尼西亚的两个岛屿：Waigeo 和 Batanta。

该物种的雄鸟以其鲜艳的羽毛而闻名。它们胸部两侧有长长的红色羽毛，脸部呈绿色，每只眼睛上方有羽毛绒球，尾羽呈长长的螺旋形。雌鸟大多呈棕色，没有装饰。这些鸟具有 lek 求偶系统，雄鸟聚集进行竞争性求偶仪式，而雌鸟则观察并选择配偶。

这些鸟的饮食主要由水果、浆果和昆虫组成。*天堂鸟科* 在新几内亚的森林中起着传播种子的重要作用。

由于栖息地丧失，红天堂鸟的保护状态为近危。O'Reilly 封面上的许多动物处于濒危状态；它们都对世界至关重要。
