### Solutions

1. Answer: b

Concept: EAP-TLS is a secure wireless authentication protocol, as it uses certificates. An X509 certificate is installed on the endpoint.

Wrong Answers:

+   a. With WPA2-PSK, you use the wireless router password. If someone came to your house and asked for the wireless password, this is what you would give them.
+   c. WPS allows you to connect to the wireless network by pushing a button.
+   d. PAP is the least secure authentication protocol as it is in clear text.

2. Answer: c

Concept: The first stage in any attack is to capture the volatile evidence. In this incident, you would capture the network traffic to identify the source of the attack.

Wrong Answers:

+   a. If you remove the web server from the network, you will not be able to establish who the attacker is.
+   b. If you disconnect the connection, you will not be able to track the attacker.
+   d. A screenshot might not show the evidence you require. In this case, it will not identify the attacker.

3. Answer: b

Concept: A wildcard certificate can be used on multiple servers, normally those that are internet-facing.

Wrong Answers:

+   a. A PEM is a Base 64 certificate that can only be installed on a single device.
+   c. A SAN certificate can contain multiple domain names and cannot be installed on multiple servers
+   d. A root certificate is the certificate belonging to the CA.

4. Answer: c

Concept: The hot site is up and running with data that has been replicated. It is the most expensive site to run.

Wrong Answers:

+   a. A cold site has no equipment or data. It is the cheapest and takes the longest amount of time to become operational.
+   b. A warm site is up and running, but the data might be 2-3 hours out of date.
+   d. Off-site is a remote location where copies of back up tapes are held. It is not a disaster recovery site.

5. Answer: a

Concept: The first step is to create a system image or, if it is a hard drive, create a forensic copy. This will allow you to keep the original data pristine and deploy it on another computer for investigation.

Wrong Answers:

+   b. The evidence will already be bagged and tagged when the forensic analyst receives it.
+   c. Once the forensic analyst has deployed the system image on a computer, the second step will be to hash the data before and after his investigation to prove its integrity.
+   d. The forensic analyst will be told who the owner of the laptop is when he receives it.
