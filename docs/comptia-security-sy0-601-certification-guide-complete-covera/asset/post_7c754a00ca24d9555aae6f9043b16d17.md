- **File Manipulation**: In a Linux environment you may want to look deeper into different files, including the log files that are produced. Let's look at some manual tools that an administrator could use, starting with Cat:

  - a. **Concatenate (cat):** The `cat` command in Linux can be used to create files, view files, and also concatenate several files into another file. To create a new file called `rugbyfile`, we use the following syntax:

    ```text
    cat > rugbyfile
    ```

    You can also concatenate the contents of three files and combine them in an output file using the following syntax:

    ```text
    cat file1.txt file2.txt file3.txt | sort > samplefile.txt
    ```

  - b. **Head:** The most important file in Linux is the `/var/log/messages` file, which shows system events such as shutdown and reboot. We can use the head command to check the top 10 messages from that log using the following syntax:

    ```text
    head /var/log/messages -n 10
    ```
