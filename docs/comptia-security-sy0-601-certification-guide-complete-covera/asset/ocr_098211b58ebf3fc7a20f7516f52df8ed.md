# Restoration Order

Once a disaster has happened, it is important that we look at the services necessary for getting a company back up and running. We would rank them as critical, essential, or non-essential, and we would work on getting the most crucial service up and running first. We would start with power, then our network infrastructure and critical servers, and then restore data before going back online.

# Diversity

Companies need to use diversity within their organization so that they can be prepared for any disasters. Let’s look at diversity starting with technologies.

# Technology Diversity

This is where a company might use more than one type of operating system for their servers. Some might run Windows Server whilst other might run Linux. This ensures that they can still function should one of the operating systems become vulnerable to attack. You might have some web servers using Internet Information Servers (IIS) in a Windows environment, while others might be using Apache that runs on the Linux operating system. Once again, if one web server is exploited the other can keep a company’s web presence running.

# Vendor Diversity

We need to purchase the same technologies from different vendors just in case one of the businesses either goes out of business or faces failure. An example of this would be purchasing broadband from two different companies. This is because it is a critical area of a business and should one provider suffer a disaster, then the other would provide the service.

# Crypto Diversity

This is where a company can use different algorithms to protect their data. We know that symmetric encryption such as AES is designed to encrypt large amounts of data as it uses a block cipher, but we also know it is weak as the key size is small. AES is only 256-bit and vulnerable to attack. We may decide to diversify by using RSA to protect data where the key sizes are larger. Another example is that we might encrypt financial transactions using RSA 4096-bit keys. As an alternative, we could use blockchain to protect financial transactions as it uses the public ledger, making it harder to commit financial fraud.
