# Certificate Management Concepts

We are now going to look at the different ways in which certificates are managed in a PKI environment, starting with the request for a new certificate and ending with different certificate formats. You must learn all this information thoroughly as these aspects are heavily tested:

+   - **Certificate Signing Request (CSR)**: This is the process of requesting a new certificate.

+   - **Key Escrow**: The key escrow holds the private keys for third parties and stores them in a **Hardware Security Module (HSM)**, a device that can store digital keys. It could be as simple as an external hard drive:

+   - **Hardware Security Module (HSM)**: The HSM can be a piece of hardware attached to the server or a portable device that is attached to store the keys. See the preceding diagram for more on this.

+   - **Data Recovery Agent (DRA)**: If a user cannot access their data because their private key is corrupted, the DRA will recover the data. The DRA needs to get a copy of the private key from the key escrow.
