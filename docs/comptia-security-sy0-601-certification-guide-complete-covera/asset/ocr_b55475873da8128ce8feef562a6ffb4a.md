+   - **Server-Side Request Forgery(SSRF)**: Server-side request forgeries will use a web application as their attack vector to create a packet from a backend server to look as if it has come from the localhost (127.0.0.1). The request looks if it has come from the server itself and will try and access the contents of the /etc/passwd file. The best way to prevent this is to create a whitelist of any domain or IP Addresses that is legitimate. That way it will then block all other domains and IP Addresses.
+   - **Cross-Site Scripting (XSS)**: XSS is when a user injects malicious code into another user's browser. It uses both HTML tags and JavaScript. The following is a very simple server-side script to display the latest comments:

```
print "<html>"
print "Latest comment:" print database.latestComment
print "</html>"
```

The attacker could alter the comment to insert HTML tags for a script, as follows:

```
<html>
Latest comment:
<script>    (Javascript code is placed here)    </script>
</html>
```

When the user loads the page into the browser, it will now launch the JavaScript and then the attack will be successful. Here are some examples using JavaScript.
