+   - **Discovering the Disabled SSID**: A Wi-Fi analyzer, sometimes called a wireless sniffer or a wireless scanner, can extract the SSID from a packet going to the WAP. An SSID decloak device can magically capture the SSID from a WAP. To protect the WAP, we must use encryption.
+   - **MAC Filtering**: To control access to a WAP, we insert the **Media Access Control (MAC)** address into MAC filtering, and then only those devices with a MAC address inserted will be allowed access. A MAC address is a unique address that every device has embedded into it. If you think of it, why did they not call it MAC addition, because that is basically what you are doing?
