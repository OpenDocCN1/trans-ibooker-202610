## 第6章 – 理解安全和不安全协议

- 1. 使用Kerberos认证时，会建立TGT会话，用户在其中获取加密的服务票据。Kerberos使用UDP和时间戳来防止重放攻击。
- 2. IPSec隧道模式用于L2TP/IPSec VPN会话，其中AH和ESP均被加密。
- 3. IPSec传输模式用于LAN上的服务器到服务器通信，其中仅ESP被加密。
- 4. SSH是一种取代Telnet的安全协议。
- 5. 路由器连接外部网络并路由IP数据包。
- 6. 交换机是一种用于连接同一地点内计算机的内部设备。
- 7. Spotify是一种订阅服务，用户按月付费。这是一种按使用付费的模式。
- 8. 端口安全是指禁用交换机上的某个端口，以防止有人使用特定的墙壁插座。
- 9. 802.1x可对连接到交换机的用户和设备进行认证。通常，用户或设备拥有证书即可进行认证，而无需禁用交换机上的端口。未授权用户因没有证书而无法使用该端口。





- 10. 一个可分辨名称的三个部分（从左到右）是 CN、OU，然后是 DC。
- 11. DNSSEC 会生成 RRSIG 记录并防止 DNS 污染。
- 12. 计算机可能由于资源耗尽或网络连接问题而无法从 DHCP 服务器获取 IP 地址。
- 13. SIEM 服务器和使用 Kerberos 身份验证的 Microsoft 域控制器都依赖于 NTP 服务器来保持主机时钟时间同步。否则，SIEM 服务器无法将事件按时间顺序排列，而 Kerberos 客户端无法登录。
- 14. 建筑管理员通常会将位于同一物理位置的公司连接到同一交换机。他们可以通过使用 VLAN 来提供部门隔离。
- 15. 生成树协议可防止交换机形成环路，这会降低交换机速度。
- 16. 网络管理员可以使用 SMTP v3 来安全地收集网络设备的状态和报告。
- 17. 网络管理员可以使用 AES 作为 L2TP/IPsec VPN 的最强协议，因为它可以使用 256 位。
- 18. 哈希传递攻击是对 NTLM 身份验证的哈希碰撞攻击。Kerberos 可防止此攻击并使用 Active Directory，后者将密码存储在加密数据库中。
- 19. **传输层安全（TLS）** 或 **安全套接字层（SSL）** 可保护传输中的数据。
- 20. S/MIME 可用于在两个人之间数字签名电子邮件。
- 21. SRTP 用于保护视频会议流量。
- 22. SIP 用于管理基于互联网的通话，并且可以与 Skype 配合使用以保持通话挂起并进行转移。
- 23. LDAP 使用 TCP 端口 389 并用于管理目录服务。它可以用 LDAPS TCP 端口 636 替换，后者更安全。
- 24. 格式为 NETBIOS，其中名称最长为 15 个字符，并带有一个服务标识符。在此示例中，主机的名称为 Ian；<00> 表示工作站服务，<20> 表示服务器服务。
- 25. FTPS 用于传输大文件，因为它使用两个端口：989/990。
