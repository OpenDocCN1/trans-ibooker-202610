## 第 2 章 – 实施公钥基础设施

- 24. 美国发布了 CLOUD Act，以便他们为 FBI 调查从其他国家获取证据。英国政府发布了 COPOA 法案以寻求存储在海外的數據并为其执法部门提供更快获取由提供商持有的证据的途径。
- 25. 在云取证流程 26 的 C 阶段，你确定云背后的技术类型。

- 1. CA 拥有根证书，用于签署密钥。
- 2. 你会仅用于内部使用的私有 CA；这些证书在组织外部不会被接受。
- 3. 你会为 B2B 活动使用公共 CA。
- 4. 如果你是军事、安全或银行组织，你会在不使用时将 CA 离线以防止其被入侵。
- 5. PKI 使用非对称加密。
- 6. CA 签署 X.509 证书。
- 7. 证书钉扎可用于防止 CA 被入侵并防止签发欺诈性证书。
- 8. 如果两个独立的 PKI 实体想要建立交叉认证，根 CA 将在它们之间建立信任模型，被称为桥接信任模型。
- 9. PGP 使用的信任模型称为信任网络。
- 10. 证书吊销列表 Certificate Revocation List (CRL) 用于确定证书是否有效。
- 11. 如果 CRL 运行缓慢，你应使用 OCSP，因为它提供更快的验证。
- 12. 证书钉扎/OCSP 钉扎是指 Web 服务器使用 OCSP 以实现更快的证书身份验证，从而绕过 CRL。
- 13. 你会提交证书签名请求 Certificate Signing Request (CSR) 以请求新证书。
- 14. 密钥托管存储和管理第三方私钥。
- 15. 硬件安全模块 Hardware Security Module (HSM) 由密钥托管用于安全存储和管理证书。
- 16. DRA 的目的是在用户的私钥损坏时恢复数据。为此，它必须首先从密钥托管获取私钥的副本。
- 17. 每个证书都可以通过其 OID 识别，其类似于序列号。
- 18. 私有证书为 P12 格式，扩展名为 .pfx。
- 19. 公共证书为 P7B 格式，扩展名为 .cer。
- 20. PEM 证书为 Base64 格式。
- 21. 通配符证书可在同一域的多个服务器上使用。
- 22. 主体备用名称 Subject Alternative Name (SAN) 证书可在多个域上使用。
- 23. 你会对软件进行代码签名以验证其为原件，而非副本。这类似于数字签名，因为它确保了软件的完整性。
- 24. 扩展验证通常由金融机构使用，以为 X.509 提供更高级别的信任。
- 25. 凯撒密码是一种替换密码；例如 ROT 4，其中每个字母将被字母表中沿后四个字符的字母替换。
- 26. 加密是将明文 输入 转换为密文 输出 的过程。
- 27. 对称加密用于加密大量数据，因为它使用一个密钥。
- 28. Diffie-Hellman (DH) 是一种非对称技术，可创建安全隧道。在 VPN 连接期间，它在 IKE 阶段使用，并使用 UDP 端口 500 来创建 VPN 隧道。
- 29. 加密的第一阶段是密钥交换。在非对称加密期间，每个实体都会向另一个实体提供其公钥。私钥是安全的，永远不会被泄露。
- 30. Carol 使用 Bob 的公钥加密数据，然后 Bob 将使用他的私钥解密数据。加密和解密始终由同一密钥对完成。
- 31. 否。George 必须获取旧的私钥来解密数据，因为加密是使用不同的密钥对完成的。
- 32. Janet 将使用她的私钥对电子邮件进行数字签名，John 将使用 Janet 的公钥检查其有效性，他会提前收到该公钥。





- 54. 完美前向保密确保服务器私钥与会话密钥之间没有关联。即使VPN服务器的密钥被泄露，也无法解密会话。它非常适合用于投票机。
- 55. 碰撞攻击指的是两个哈希值相同的情况。
- 56. 彩虹表是一份预计算单词及其哈希值的列表，用于破解密码的哈希值。MD5有对应的彩虹表，SHA-1也有不同的彩虹表。
- 57. 隐写术用于将数据隐藏在其他形式的数据中。你可以将文件、图像、视频或音频隐藏到另一张图像、视频或音频文件中。
- 58. DLP可防止敏感信息或个人身份信息（PII）通过电子邮件发送出公司，或使用USB设备从文件服务器中被窃取。
- 59. 对密码加盐可以确保不会存储重复的密码，并通过增加密钥长度（密钥拉伸）来提高暴力破解的难度。它会将盐附加到密码之后，使其在哈希处理前变得更长。
