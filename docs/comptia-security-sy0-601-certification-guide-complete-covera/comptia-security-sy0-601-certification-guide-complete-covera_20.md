## Chapter 7 – Delving into Network and Security Concepts
- 1. Web 应用防火墙通常安装在 Web 服务器上或之前，其工作是保护 Web 应用免受攻击。
- 2. 隐式拒绝同时被防火墙和路由器使用。如果没有允许规则，它们会得到最后一条规则，即拒绝所有。这被称为隐式拒绝。
- 3. **统一威胁管理（UTM）** 是一种防火墙，因其可提供 URL 过滤、内容过滤和恶意软件检查以及防火墙功能而物有所值。
- 4. 路由器连接不同的网络，并在 OSI 参考模型的第 3 层工作。
- 5. 交换机连接内部网络上的用户，通常采用星型拓扑。它在数据链路层工作。
- 6. **网络地址转换（NAT）** 将内部网络隐藏在外部网络之外。
- 7. 内联 NIPS 在流量流经时对其进行筛选。
- 8. **基于主机的 IPS（HIPS）** 安装在访客虚拟机或计算机内部，以保护其免受攻击。
- 9. **基于网络的 IPS（NIPS）** 放置在防火墙后面作为额外的安全层。防火墙可防止未经授权访问网络。
- 10. NIPS 可以被动监控网络，因为如果网络上没有 NIDS，它可以实现 NIDS 的功能。
- 11. 基于签名的 NIDS 依赖于已知的变种数据库，而基于异常的 NIDS 则从数据库开始，可以学习新的模式或威胁。基于异常的 NIDS 可能被称为启发式。
- 12. 放置在网络内部的被动设备是 NIDS。它可以使用传感器和收集器检测网络的变化。
- 13. 如果其中一个监控系统报告病毒，而你手动检查后发现没有病毒，这被称为误报。
- 14. 你应该启用端口安全，即在交换机上关闭该端口。这将防止进一步使用墙上插座。
