11. Now, we'll create a stream to read the lines of a file. First, create a BufferedReader object to read the file you want to read. Then, use the lines() method of the BufferedReader class to get a stream of String objects. Each element of this stream will be a line from the file. Finally, use the parallel() method to get a parallel version of the stream and the count() method to get the number of elements of the Stream. We also have to close the BufferedReader object:

```
System.out.printf("From a File:\n");
try (BufferedReader br = new BufferedReader(new FileReader("data\\nursery.data"))) {
    Stream<String> fileLines = br.lines();
    System.out.printf("Number of lines in the file: %d\n\n", fileLines.parallel().count());
    System.out.printf("***********************************\n***********************************\n");
    System.out.printf("\n");
    br.close();
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}
```
