8. Then, we'll use the first version of the reduce() method. This method receives as parameter an associative BinaryOperator that receives two objects of the same type and returns an object of that type. When the operation has processed all the elements of the Stream, it returns an Optional object parameterized with the same type. For example, we'll use this version to calculate the sum of both the coordinates of a random list of Point objects:

```
List<Point> points=PointGenerator.generatePointList(10000);
Optional<Point> point=points.parallelStream().reduce((p1,p2) -> {
    Point p=new Point();
    p.setX(p1.getX()+p2.getX());
    p.setY(p1.getY()+p2.getY());
    return p;
});
System.out.println(point.get().getX()+":"+point.get().getY());
```
