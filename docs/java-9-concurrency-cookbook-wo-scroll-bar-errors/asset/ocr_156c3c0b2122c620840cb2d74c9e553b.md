4. Create 1,000 threads to execute 1,000 task objects and wait for their finalization, controlling the total execution time:

```
Thread threads[]=new Thread[1000];
Date start,end;

start=new Date();
for (int i=0; i<threads.length; i++) {
    Task task=new Task();
    threads[i]=new Thread(task);
    threads[i].start();
}

for (int i=0; i<threads.length; i++) {
    try {
        threads[i].join();
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
}
end=new Date();
System.out.printf("Main: Threads: %d\n", (end.getTime()-start.getTime()));
```
