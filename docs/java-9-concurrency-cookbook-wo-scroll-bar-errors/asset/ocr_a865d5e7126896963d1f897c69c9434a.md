4. Implement the run() method. Get control of the lock, put the thread to sleep for 2 seconds, and free the lock:

```
@Override
public void run() {
    lock.lock();
    try {
        TimeUnit.SECONDS.sleep(1);
        lock.unlock();
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
}
```
