第 4 章，线程执行器，探讨将线程管理委托给执行器的情况。它们允许运行、管理以及获取并发任务的结果。

第 5 章，Fork/Join 框架，涵盖 Fork/Join 框架的使用。它是一种特殊的执行器，面向使用分而治之技术将任务划分为更小任务的执行。

第 6 章，并行和响应式流，教你如何创建流并使用其所有中间和终端操作，以并行和函数式的方式处理大数据集合。流是在 Java 8 中引入的。Java 9 已包含一些新接口以实现响应式流。

第 7 章，并发集合，解释如何使用 Java 语言提供的一些并发数据结构。在并发程序中使用这些数据结构可以避免在其实现中使用同步代码块。

第 8 章，自定义并发类，教你如何将 Java 并发 API 中最有用的一些类适配到你的需求。

第 9 章，测试并发应用程序，涵盖如何获取有关 Java 7 并发 API 中最有用的一些结构的状态的信息。你还将学习如何使用一些免费工具来调试并发应用程序，例如 Eclipse、NetBeans IDE 或 FindBugs 应用程序，以检测应用程序中的可能错误。

第 10 章，附加信息，探讨同步、执行器、Fork/Join 框架、并发数据结构以及并发对象的监控等概念，这些概念未包含在各自的章节中。

第 11 章，并发编程设计，为每个在开发并发应用程序时应考虑的程序员提供一些提示。

## 本书所需条件

要阅读本书，你需要具备 Java 编程语言的一些基础知识。你应该知道如何使用 IDE，例如 Eclipse 或 NetBeans，但这不是必要的先决条件。
