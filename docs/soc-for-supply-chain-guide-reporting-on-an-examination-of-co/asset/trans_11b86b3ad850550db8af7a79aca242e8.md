## 使用适用的受托服务标准评估供应链 SOC 检查中的控制有效性

1.56 如前所述，补充 B 中列出的受托服务标准用于评估供应链 SOC 检查中控制的有效性（设计的适当性和运行有效性）。这些标准基于 COSO 框架，该框架指出“组织采用使命和愿景，制定战略，建立其希望实现的目标，并制定实现目标的计划。”内部控制支持组织实现其目标。因此，为了评估内部控制，实务人员需要了解实体的目标。出于这个原因，许多受托服务标准都提及实现“实体的目标”。

1.57 在本指南讨论的检查中，受托服务标准用于评估实体的控制是否有效以实现实体的系统目标。实体的系统目标通常是指实体管理为其个别生产、制造或分销系统所设定的目标。在评估控制是否已设计、实施和运行以满足 CC3.2，*实体识别实体范围内实现其目标的风险，并分析风险以确定风险应如何管理* 时，实体管理识别实现其主要系统目标的风险，并评估此类风险实现的可能性，以作为管理风险的基础。

**1.58** 第 3 章更详细地讨论了实务人员在评估描述中所述的控制是否有效以提供合理保证基于适用的受托服务标准实现实体的主要系统目标时，如何使用受托服务标准。

## 评估实体的主要系统目标

**1.59** 如 1.28 段所述，实体的主要系统目标是指合理预期会影响预期使用者所做相关决策的目标。实体管理负责识别主要系统目标，包括对客户和业务合作伙伴做出的主要承诺、实体所受的法律法规以及实体需要遵守的行业标准。实体的承诺通常与满足产品的规格以及满足其他生产、制造和分销规格有关。承诺还可能与其它事项有关，例如符合各种其他标准和准则，如美国国家标准与技术研究院（NIST）发布的风险管理框架、国际标准化组织（ISO）发布的网络安全标准，或美国食品药品监督管理局在《联邦法规汇编》（CFR）《电子记录；电子签名》第 21 篇第 11 部分中的法规。实体还可能就产品的不同方面或其分销做出承诺，包括与产品性能规格和可用性相关的承诺。

**1.60** 表 1-2 说明了实体管理可能根据检查所涉及的每个受托服务类别识别的主要系统目标。

### 表 1-2：按受托服务类别组织的由主要系统目标解决的事项类型

| 受托服务类别 | 可能由实体主要系统目标解决的事项 |
|---|---|
| **安全** | 关于保护系统免受物理和逻辑（包括网络安全）风险的承诺 |
| **可用性** | 产品按与客户约定的数量和时间可用 |
|  | 对客户做出的交付承诺的实现，包括交付时间、存储和运输承诺，以及实现这些承诺所必需的*系统要求*（例如，对制药公司做出的在分销过程中保持产品在特定温度下的承诺） |
|  | 根据关于时间、存储和运输的适用法律法规分销产品 |
| **处理完整性（关于服务提供或商品的生产、制造或分销）** | 系统生产实现产品性能规格（与产品的物理特性或功能相关）的产品的能力 |
|  | 系统实现对客户做出的其他承诺的能力 |
|  | 系统符合实体为满足或遵守法律法规、行业标准或客户要求而建立的生产要求的能力（例如，制造商可能在合同上要求在生产过程中执行某些行业标准的质量控制测试） |
| **保密性** | 对客户或业务合作伙伴做出的具体承诺的实现（例如，对业务合作伙伴关于实体在生产过程中使用其知识产权的承诺） |
| **隐私** | 实体*隐私声明*或隐私政策中确定的承诺和系统要求实现 |

1.61 实体对客户或业务合作伙伴做出的某些承诺可能与安全、可用性、处理完整性、保密性或隐私无关，但仍与使用者相关。例如，原材料成本的剧烈上涨可能阻止实体以合同价格交付货物。本指南所述的检查不预期涉及此类财务风险。

**1.62** 实体管理负责设计、实施和运行系统及相关控制，以基于适用的受托服务标准获得实现其主要系统目标的合理保证。它还负责在描述中披露实体的主要系统目标，其清晰度足以使预期使用者了解系统如何运作以及管理层和实务人员如何评估控制的有效性。第 2 章“接受和计划供应链 SOC 检查”更详细地讨论了主要系统目标。它还讨论了实务人员评估描述中披露的主要系统目标是否适当的责任。

## 供应链 SOC 检查中的实务人员意见

**1.63** 在检查结束时，实务人员对以下事项发表意见：（a）描述是否在所有重大方面按照描述标准如实地呈现了已设计和实施的系统，以及（b）描述中所述的、为提供合理保证实体实现其主要系统目标所必需的控制是否在整个期间有效，基于适用的受托服务标准。

**1.64** 只有在获得的证据支持得出描述不存在重大错报的结论时，实务人员才能对描述发表无保留意见。在考虑已识别的描述错报的重大性时，如果有，实务人员会考虑基于整体主体的决策的预期使用者的共同信息需求。因此，在形成意见时，实务人员合理地考虑描述整体是否按照描述标准呈现。虽然导致未能满足一个或多个描述标准的已识别描述错报可能表明存在重大错报，但最终实务人员的意见集中于该错报对系统描述的影响（即该错报是否可能影响预期使用者基于整体主体所做出的决策）。

**1.65** 只有在获得的证据支持得出控制有效以提供合理保证实体实现其主要系统目标的结论时，实务人员才能对控制有效性发表无保留意见。虽然在控制测试中可能识别出一个或多个控制缺陷，但最终，实务人员对控制有效性的意见集中于控制缺陷对系统基于适用的受托服务标准提供合理保证实现主要系统目标的能力的影响。
