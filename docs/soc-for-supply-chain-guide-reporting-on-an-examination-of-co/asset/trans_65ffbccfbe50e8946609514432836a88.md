## 沟通与信息

| TSP 参考编号 | 信任服务标准与关注点 |
|---|---|
| **CC2.1** | **COSO 原则13：实体获取或生成并使用相关、高质量的信息来支持内部控制的运行。** |
|  | **COSO 框架中规定的以下关注点强调了与该标准相关的重要特征：** |
|  | • **识别信息需求** — 已建立流程来识别支持内部控制其他组成部分运行及实现实体目标所需和预期的信息。 |
|  | • **捕获内部和外部数据源** — 信息系统捕获内部和外部来源的数据。 |
|  | • **将相关数据处理为信息** — 信息系统处理和转换相关数据为信息。 |
|  | • **通过处理保持质量** — 信息系统生成的信息及时、最新、准确、完整、可访问、受保护、可验证并得以保留。信息经审查以评估其在支持内部控制组成部分方面的相关性。 |
| **CC2.2** | **COSO 原则14：实体在内部沟通信息，包括与内部控制相关的目标与职责，以支持内部控制的运行。** |
|  | **以下关注点强调了与该标准相关的重要特征：** |
|  | **COSO 框架中规定的关注点：** |
|  | • **沟通内部控制信息** — 已建立流程来沟通所需信息，使所有人员能够理解并履行其内部控制职责。 |
|  | • **与董事会沟通** — 管理层与董事会之间存在沟通，从而双方都能获得在实现实体目标方面履行职责所需的信息。 |
|  | • 提供独立的沟通渠道 — 建立独立的沟通渠道，如举报热线，作为故障安全机制，以便在正常渠道失效或无效时进行匿名或保密沟通。 |
|  | • 选择相关的沟通方式 — 沟通方式考虑信息的时机、受众和性质。 |

使用信任服务标准的所有业务中特别适用的其他关注点：

• 沟通职责 — 负责设计、开发、实施、操作、维护或监控系统控制的人员会收到有关其职责（包括职责变更）的沟通，并拥有履行这些职责所需的信息。

• 沟通关于报告失败、事件、关切和其他事项的信息 — 向实体人员提供有关如何向相关人员报告系统故障、事件、关切和其他投诉的信息。

• 沟通目标及目标变更 — 实体及时向人员传达其目标及目标的变更。

• 沟通信息以提升安全知识和意识 — 实体通过安全意识培训项目，沟通信息以提升安全知识和意识，并为人员示范适当的安全行为。

仅当使用信任服务标准在系统层面执行业务时适用的其他关注点：

• 沟通关于系统运行和边界的信息 — 实体向授权人员准备并沟通有关系统设计、运行及其边界的信息，使他们能够理解自己在系统中的角色及系统运行的结果。

• *沟通系统目标* — 实体向人员传达其目标，使他们能够履行职责。

• *沟通系统变更* — 影响职责或实体目标实现的系统变更应及时沟通。
