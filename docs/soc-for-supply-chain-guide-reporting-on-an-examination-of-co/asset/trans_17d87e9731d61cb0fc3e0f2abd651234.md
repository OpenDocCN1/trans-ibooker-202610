## 控制环境

公司 X 的控制环境存在于组织的治理结构和机构之下，由董事会领导。董事会监督并监控公司 X 的控制环境，其下属委员会提供协助，包括审计委员会，该委员会对财务报表编制、外部审计以及内部控制评估和报告相关事项提供总体指导和监督，以及技术委员会，该委员会监督实体的信息技术和运营，特别是与制造、工程和生产相关的方面。这些治理机构在促进公司 X 控制环境完整性方面的角色已在本文各小标题下根据需要进行了引用。

## 行为准则

健全的控制环境是通过对组织各层级诚信和道德行为的承诺而建立的。公司 X 通过组织文化和理念来促进诚信文化，该文化将标准和道德行为置于优先地位。为此，公司 X 已制定了行为准则政策，该政策已由董事会强制执行并批准。行为准则提供了关于适当行为的详细指导，并概述了违反行为的制裁措施，直至包括解雇。人力资源负责监督对行为准则的遵守情况，并对具有监督职责的人员进行培训和指示，要求其报告违规行为。此外，还设立了匿名道德热线，以促进对可疑行为的报告，并提供一种旨在保护举报人免受报复的报告方式。所有报告的事件都将被分配案件编号并进行调查。这些报告和调查的记录会被汇总并向董事会报告，以提供适当的可见性和监督。行为准则适用于符合某些预定义特征和条件的供应商和关键第三方。公司 X 管理下的所有员工和合同工均需在入职时阅读行为准则并通过签名证明其承诺，并在此后每年确认其认可。

公司 X 为内部和外部用户提供了由第三方管理的匿名举报人热线。首席风险官监控通过热线报告的客户和员工投诉。

## 控制评估、监督和报告

董事会成员被任命代表股东行事。董事会成员的角色和职责如《董事会章程》所述，与管理层的角色和职责相分离。根据章程，董事会由至少 50% 的独立董事组成，并对公司 X 的控制环境和内部控制体系负有最终责任。董事会根据议程事项，还会评估是否需要补充董事会成员，例如具备供应链和第三方风险管理相关专业知识的人员。具体而言，在每次董事会会议前，都会根据会议议程评估对特殊专业知识的需求。如果有必要，董事会将根据需要聘请所需专家或顾问。

每季度和每年，高级管理层和董事会都会收到履行其职责所需的信息和培训，以实现公司 X 的服务承诺和系统要求。

内部控制监督责任委托给审计委员会，其至少 50% 的成员由董事会独立成员组成。审计委员会至少每季度召开一次会议。审计委员会由具备财务报告、内部控制、运营和物流以及网络安全相关必要专业知识的人员组成。此外，其他专业学科的人员将以当然成员身份被召集，以根据需要解决特定主题。内部审计部门直接向审计委员会主席报告，负责评估公司 X 的控制环境，并负责计划、执行并向负责管理层（针对所审查的主题）和审计委员会发布审计报告。

技术委员会由董事会指定代表、首席技术官、首席风险官、首席信息安全官以及公司 X 业务单元总经理组成。各种内部和外部业务分析师和系统分析师也会根据需要参加委员会会议，以提供专业知识。技术委员会的目的是确保公司的技术方向和能力，包括信息技术、工程和生产，能够支持公司 X 当前的运营、其战略和未来增长。技术委员会的一项重要授权是为实体提供设计治理，确保拟收购和实施的重要技术组件和应用系统将支持公司 X 的业务战略，将很好地集成到现有的应用和技术基础设施中，并在整个企业中很好地扩展并支持所需的目标用户群体。

## 组织设计、权限范围和汇报关系
