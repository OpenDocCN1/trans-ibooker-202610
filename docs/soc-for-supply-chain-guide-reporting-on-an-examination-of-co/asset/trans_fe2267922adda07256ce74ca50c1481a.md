

# 附录 B

# 2017 年信任服务标准：安全性、可用性、处理完整性、机密性和隐私

*本补充文件包含美国注册会计师协会（AICPA）鉴证服务执行委员会的权威性材料。*

本补充文件中的安全性、可用性、处理完整性、机密性和隐私信任服务标准及相关关注要点，摘录自美国注册会计师协会鉴证服务执行委员会于 2017 年 4 月发布的 TSP 第 100 节《2017 年安全性、可用性、处理完整性、机密性和隐私信任服务标准》。¹

完整文本可在 https://www.aicpa.org/interestareas/frc/assuranceadvisoryservices/socforserviceorganizations.html 查阅。

下表列示了针对安全性、可用性、处理完整性、机密性和隐私的信任服务标准及相关关注要点。其中任何类别都可能适用于供应链 SOC 鉴证业务。在表中，直接源自 Treadway 委员会发起组织委员会《2013 年内部控制——整合框架》（COSO 框架）² 的标准及相关关注要点以常规字体显示；相反，适用于使用信任服务标准的鉴证业务的标准和关注要点以斜体显示。

| TSP 参考编号 | 信任服务标准与关注要点 |
|---|---|
| | 控制环境 |
| CC1.1 | COSO 原则 1：实体展现出其对诚信和道德价值观的承诺。 |
| | |
| | 以下关注要点强调了与该标准相关的重要特征： |
| | |
| | COSO 框架中规定的关注要点： |
| | |
| | • 高层定调 —— 董事会和各层级管理层通过其指令、行动和行为，展示诚信和道德价值观对支持内部控制体系运行的重要性。 |
| | • **制定行为准则** —— 董事会和高级管理层对诚信和道德价值观的期望，在实体的行为准则中予以界定，并在实体各层级以及外包服务提供商和业务合作伙伴中得到理解。 |
| | • **评估对行为准则的遵守情况** —— 已建立相关流程，依据实体预期的行为准则评估个人和团队的表现。 |
| | • **及时处理偏差** —— 偏离实体预期行为准则的情况会被及时、一致地识别和纠正。 |
| | |
| | **与所有使用信任服务标准的鉴证业务特别相关的补充关注要点：** |
| | |
| | • *在表明其承诺时考虑承包商和供应商员工* —— 管理层和董事会在制定行为准则、评估对这些准则的遵守情况以及及时处理偏差的流程中，考虑使用承包商和供应商员工的情况。 |
| | |
| **CC1.2** | **COSO 原则 2：董事会证明其独立于管理层，并对内部控制的建立与运行进行监督。** |
| | |
| | **以下关注要点强调了与该标准相关的重要特征：** |
| | |
| | **COSO 框架中规定的关注要点：** |
| | |
| | • **确定监督职责** —— 董事会确定并接受其相对于既定要求和期望的监督职责。 |
| | • **运用相关专业知识** —— 董事会界定、维护并定期评估其成员所需的技能和专业知识，以便他们能够向高级管理层提出探询性问题并采取相应行动。 |
| | • **独立运作** —— 董事会拥有足够数量的独立于管理层且在评估和决策中保持客观的成员。 |
| | |
| | **与所有使用信任服务标准的鉴证业务特别相关的补充关注要点：** |
| | |
| | • *补充董事会专业知识* —— 董事会视需要通过使用专门委员会或顾问，补充其在安全性、可用性、处理完整性、机密性和隐私方面的专业知识。 |
| | |
| CC1.3 | **COSO 原则 3：管理层在董事会的监督下，为实现目标建立结构、报告线以及适当的权限和职责。** |
| | |
| | **以下关注要点强调了与该标准相关的重要特征：** |
| | |
| | **COSO 框架中规定的关注要点：** |
| | |
| | • *考虑实体的所有结构* —— 管理层和董事会考虑为支持目标实现而使用的多种结构（包括运营单位、法律实体、地域分布和外包服务提供商）。 |
| | • *建立报告线* —— 管理层为每个实体结构设计和评估报告线，以便执行权限和职责并实现信息流动，从而管理实体的活动。 |
| | • *界定、分配和限制权限与职责* —— 管理层和董事会授权、界定职责，并使用适当的流程和技术在各组织层级分配责任，并视需要进行职责分离。 |
| | |
| | **与所有使用信任服务标准的鉴证业务特别相关的补充关注要点：** |
| | |
| | • *在界定权限与职责时考虑具体要求* —— 管理层和董事会在界定权限与职责时，考虑与安全性、可用性、处理完整性、机密性和隐私相关的要求。 |
| | • *在建立结构、报告线、权限和职责时考虑与外部方的互动* —— 管理层和董事会在建立结构、报告线、权限和职责时，考虑实体与外部方互动并监控其活动的需要。 |
| CC1.4 | **COSO 原则 4：实体展现出对吸引、培养和留用有胜任能力的人员以配合目标实现的承诺。** |
| | |
| | **以下关注要点强调了与该标准相关的重要特征：** |
| | |
| | **COSO 框架中规定的关注要点：** |
| | |
| | • *制定政策和实务* —— 政策和实务反映了支持目标实现所需的能力期望。 |
| | • *评估能力并处理不足* —— 董事会和管理层根据既定政策和实务，评估整个实体及外包服务提供商的能力，并采取必要行动处理不足。 |
| | • *吸引、培养和留用人员* —— 实体提供所需的指导和培训，以吸引、培养和留用足够且有胜任能力的人员和外包服务提供商，从而支持目标的实现。 |
| | • *规划并准备继任* —— 高级管理层和董事会为对内部控制至关重要的职责分配制定应急计划。 |
| | |
| | **与所有使用信任服务标准的鉴证业务特别相关的补充关注要点：** |
| | |
| | • *考虑个人背景* —— 实体在决定是否雇用和留用个人时，考虑潜在及现有员工、承包商和供应商员工的背景。 |
| | • *考虑个人技术能力* —— 实体在决定是否雇用和留用个人时，考虑潜在及现有员工、承包商和供应商员工的技术能力。 |
