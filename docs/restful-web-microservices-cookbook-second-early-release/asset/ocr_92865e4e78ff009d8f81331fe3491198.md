Creating client applications that know the media type and understand the nine H-Factors will greatly improve the flexibility and resilience of the client application.

There are nine H-Factors that can appear within a RESTful service response. They are:

**Table 3-1. Five Link Factors**

| Title | Description | Example |
|---|---|---|
| L Link<br>E Embedded | Brings content into the current view | `HTML <img />` tag |
| L Link<br>O Outbound | Navigates the client to a new view | `HTML <a />` tag |
| L Link<br>T Template | Supports additional parameters before executing | URI templates<br>`http://example.org/users/{id}` |
| L Link Non-<br>N Idempotent | Describes a non-idempotent action | `<FORM method=POST ...>` |
| L Link<br>I Idempotent | Describes an idempotent action | `SIREN "actions":[{"name":"update-item","method":"put" ...}]` |

**Table 3-2. Four Control Factors**

| Title | Description | Example |
|---|---|---|
| C Control for Read<br>R Requests | Describes read details | `Accept:application/vnd.hal+json` |
| C Control for<br>U Update Requests | Describes write details | `enctype="application/x-www-form-urlencoded"` |
| C Control for HTTP<br>M Methods | Describes the HTTP method to use | `<FORM method="GET" ... >` |
| C Control for Link<br>L Relations | Describes the link relation for an action | `<link rel="create-form" ... />` |
