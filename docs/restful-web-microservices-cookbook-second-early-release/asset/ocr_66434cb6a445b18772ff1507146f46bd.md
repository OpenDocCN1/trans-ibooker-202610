```
```java
return (c == '=' ? 'x' : (r & 0x3 | 0x8)).toString(16);
});
}
```
```

The output of UUID functions is much less likely to result in a collision but the resulting output (e.g. "e6db8698-7128-478d-8658-12c2cb9dd126") longer that the simple example shown earlier.
