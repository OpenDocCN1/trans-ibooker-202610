## 关于作者

迈克·阿蒙森（Mike Amundsen）是一位国际知名的作家和演讲者，为世界各地的组织提供网络架构、Web 开发以及技术与社会的交汇方面的咨询。他与大小公司合作，帮助他们利用 API、微服务和数字化转型为消费者和企业带来的机遇。
