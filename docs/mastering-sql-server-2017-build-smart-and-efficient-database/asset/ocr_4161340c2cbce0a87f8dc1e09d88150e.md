The Azure Feature Pack is not an SSIS 2016 specific feature. It's also available for SSIS version 2012 and 2014. It's worth mentioning that it appeared in July 2015, a few months before the SSIS 2016 release.

# Getting ready

This section assumes that you have installed SQL Server Data Tools 2015.

# How to do it...

We'll start SQL Server Data Tools, and open the `CustomLogging` project if not already done:

+   1. In the SSIS Toolbox, scroll to the **Azure** group. Since the Azure tools are not installed with SSDT, the **Azure** group is disabled in the toolbox. The tools must be downloaded using a separate installer. Click on the **Azure** group to expand it and click on **Download Azure Feature Pack** as shown in the following screenshot:
