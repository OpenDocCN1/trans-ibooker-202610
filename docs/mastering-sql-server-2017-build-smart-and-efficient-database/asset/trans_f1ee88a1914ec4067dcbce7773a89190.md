## Azure 任务和转换

本节将指导您如何安装 Azure 功能包，该功能包将随之安装 Azure 控制流任务和数据流组件。Azure 生态系统在微软生态系统中正日益占据主导地位，而过去几年中 SSIS 也未曾掉队。

Azure 功能包并非 SSIS 2016 的专属功能。它也适用于 SSIS 2012 和 2014 版本。值得一提的是，它于 2015 年 7 月推出，比 SSIS 2016 发布早了几个月。
