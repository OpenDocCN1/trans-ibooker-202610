## 工作原理...

在执行 SSIS 包时使用日志记录，会在 `internal` 架构中名为 `execution_data_statistics` 的 SSIS 目录表中创建条目。该表用于记录 SSIS 包中的数据移动统计信息。

我们从不使用 internal 架构中的表，因为它们被视为系统表。这就是我们改用视图 `[catalog].[execution_data_statistics]` 的原因。
