![](img/07d1225e179d5df9f2b2d26b026386c6_670_1.png)

18. Click on **Machine Selection** in the upper-left pane. You can see that the worker we registered in the previous recipe is there. ![](img/07d1225e179d5df9f2b2d26b026386c6_671_1.png)

![](img/07d1225e179d5df9f2b2d26b026386c6_672_0.png)

21. The report opens and you can see that the execution has succeeded, as shown in the following screenshot. Click on the **All Messages** link under the **Report** column.

![](img/07d1225e179d5df9f2b2d26b026386c6_672_1.png)

![](img/07d1225e179d5df9f2b2d26b026386c6_673_0.png)
