+   2. The **CustomLogging Property Pages** dialog box opens. Select **Configuration Properties** and you'll notice a drop-down list near the property **TargetServerVersion**. In our case, the selected version is **SQL Server 2016**. You'll notice that you can select prior versions as shown in the following screenshot. Click on **OK** to close this window.
