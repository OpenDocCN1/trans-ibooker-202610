# 关于作者

**Miloš Radivojević** 是奥地利维也纳的一名数据库顾问。他是数据平台 MVP，专注于为应用程序开发人员和性能/查询调优提供 SQL Server 支持。目前，他在 Bwin（GVC Holdings）担任首席数据库顾问，该公司是全球最大的受监管在线博彩公司。Miloš 是 PASS Austria 的联合创始人。他也是国际会议的演讲者，并定期在 SQL Saturday 活动和 PASS Austria 会议上发言。

**Dejan Sarka**，MCT 和微软数据平台 MVP，是一位独立培训师和顾问，专注于数据库和商业智能应用程序的开发。除了项目之外，他大约一半的时间用于培训和指导。他是斯洛文尼亚 SQL Server 和 .NET 用户组的创始人。他是许多关于数据库和 SQL Server 的书籍的主要作者或合著者。在此之前的三本书由 Packt 出版，书名分别是《SQL Server 2016 Developer's Guide》《SQL Server 2017 Integration Services Cookbook》和《SQL Server 2016 Developer's Guide》。Dejan Sarka 还为 Microsoft、SolidQ 和 Pluralsight 开发了许多课程和研讨会。

**William Durkin** 是 Data Masterminds 的数据平台架构师。他利用十多年的 SQL Server 经验帮助跨国企业实现其数据管理目标。William 出生于英国，现居德国，是全球各地会议的常客演讲者、数据平台 MVP，并且是广受欢迎的 SQLGrillen 活动的创始人。

**Christian Coté** 从事 IT 行业超过 12 年。他是微软认证的商业智能技术专家（MCTS-BI）。大约 10 年来，他一直担任 ETL/BI 项目的顾问。他的 ETL 项目使用了各种 ETL 工具以及针对各种关系数据库管理系统（如 Oracle 和 SQL Server）的纯代码。目前，他正在开展 4 年内的第六个 SSIS 实施项目。

**Matija Lah** 拥有超过 15 年的 Microsoft SQL Server 工作经验，主要从事法律领域的数据中心解决方案架构设计。他对 SQL Server 社区的贡献使他在 2007 年获得了微软最有价值专家（数据平台）奖。他大部分时间都花在涉及高级信息管理和自然语言处理的项目上，但也经常抽出时间在 Microsoft SQL Server 相关的活动中演讲，他喜欢在那里分享他在 SQL Server 平台方面的经验。
