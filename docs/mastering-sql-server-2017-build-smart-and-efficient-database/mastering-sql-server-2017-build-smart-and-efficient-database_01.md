## 本书涵盖内容

第 1 章 *SQL Server 2017 简介*，非常简要地介绍了最重要的功能和增强，不仅仅是面向开发人员的部分。本章展示了整体情况，并为读者指明了发展方向。

第 2 章 *SQL Server 工具*，帮助您了解 SQL Server 工具发布管理中的变化，并探讨 **SQL Server Management Studio (SSMS)** 中细小而实用的增强功能。本章还介绍了 RStudio IDE（一种非常流行的 R 代码开发工具），并简要介绍了 **SQL Server Data Tools (SSDT)**，包括新的 **R Tools for Visual Studio (RTVS)**，这是一个 Visual Studio 插件，使您能够在深受使用 Microsoft 产品和语言的开发人员欢迎的 IDE 中开发 R 代码。本章还介绍了 Visual Studio 2017，并展示了如何将其用于 Python 数据科学应用程序。

第 3 章 *SQL Server 中的 JSON 支持*，探讨了 SQL Server 内置的 JSON 支持。这种支持应该使应用程序更容易与 SQL Server 交换 JSON 数据。

第 4 章 *Stretch Database*，帮助您了解如何使用 **Stretch Database (Stretch DB)** 功能，将历史数据或访问频率较低/不频繁访问的数据透明且安全地迁移到 Microsoft Azure。

第 5 章 *时态表*，介绍了基于 SQL:2011 标准的系统版本化时态表的支持。我们解释了这在 SQL Server 中是如何实现的，并演示了一些用例（例如，时间旅行应用程序）。

第 6 章 *列存储索引*，回顾了列式存储，然后探讨了 SQL Server 2016 中与列存储索引相关的巨大改进：可更新的非聚集列存储索引、内存表上的列存储索引，以及用于运营分析的其他许多新功能。

第 7 章 *SSIS 安装*，包含一步步设置 SQL Server 2016 以获取本书中使用的功能的操作指南。

第 8 章 *SSIS 2016 新特性*，包含讨论 SSIS 随时间演变以及 SSIS 2016 新增功能的操作指南。本章详细概述了 Integration Services 2016 的新功能。

## 前言

第 9 章 *现代 ETL 解决方案的关键组件*，解释了 ETL 在过去几年中的演变，并说明了构建适合现代数据仓库的可扩展现代 ETL 解决方案所需的组件。本章还将描述每个目录视图提供的功能，并帮助您学习如何使用其中一些视图来归档 SSIS 执行统计信息。

第 10 章 *处理数据质量*，重点介绍如何利用 SSIS 来验证和加载数据。您将学习如何识别无效数据、清理数据以及将有效数据加载到数据仓库中。

第 11 章 *释放 SSIS 脚本任务和组件的威力*，涵盖如何将脚本与 SSIS 结合使用。您将学习脚本任务和脚本组件在许多情况下如何非常有价值，以克服标准工具箱任务和转换的局限性。

第 12 章 *本地和 Azure 大数据集成*，描述了允许 SSIS 集成来自 Blob 存储和 HDInsight 集群的 Azure 数据的 Azure 功能包。您将学习如何使用 Azure 功能包组件来增加 SSIS 解决方案架构的灵活性，并了解如何通过 SSIS 操作本地大数据。

第 13 章 *扩展 SSIS 任务和转换*，讨论使用自定义开发的任务和转换以及安全功能来扩展和自定义工具箱。您将了解创建自定义任务以扩展 SSIS 工具箱和保护部署的利弊。

第 14 章 *使用 SSIS 2017 横向扩展*，讨论在多台服务器上横向扩展 SSIS 包执行。您将了解 SSIS 2017 如何横向扩展到多个工作进程以增强执行可扩展性。
