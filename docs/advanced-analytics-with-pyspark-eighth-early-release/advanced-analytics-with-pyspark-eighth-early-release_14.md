# 关于作者

Akash Tandon 是一名独立顾问和经验丰富的全栈数据工程师。此前，他曾在 Atlan 担任高级数据工程师，为企业数据科学团队构建软件。在另一段人生中，他曾为政府参与数据科学项目，并在一家金融科技初创公司构建风险评估工具。作为学生，他曾与 R 统计计算项目和 Google 一起编写开源软件。在空闲时间，他无缘无故地研究各种事物。

Sandy Ryza 是 Elementl 的软件工程师。此前，他在 Remix 开发公共交通算法，并曾在 Cloudera 和 Clover Health 担任高级数据科学家。他是 Apache Spark 提交者、Apache Hadoop PMC 成员，以及 Time Series for Spark 项目的创始人。

Uri Laserson 是 Patch Biosciences 的创始人兼 CTO。此前，他在 Cloudera 从事大数据和基因组学工作。

Sean Owen 是 Databricks 的首席解决方案架构师，专注于机器学习和数据科学。他是 Apache Spark 提交者和 PMC 成员。此前，他曾任 Cloudera 数据科学部门总监和 Google 工程师。

Josh Wills 是一名独立的数据科学与工程顾问，曾任 Slack 数据工程部门负责人和 Cloudera 数据科学部门负责人，还曾发过一条关于数据科学家的推文。
