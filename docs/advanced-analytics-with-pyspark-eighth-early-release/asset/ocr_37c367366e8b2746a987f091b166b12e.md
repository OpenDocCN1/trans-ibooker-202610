Before we start, we load some data that will be used throughout the
computation, including transcription start sites, and the CTCF PWM as
derived from HT-SELEX. We also define a utility function and a broadcast
variable that will be used to generate the features:

```
local_prefix = "data/genomics"
import pyspark.sql.functions as fun

## UDF for finding closest transcription start site
## naive; exercise for reader: make this faster
def distance_to_closest(loci, query):
    return min([abs(x - query) for x in loci])
distance_to_closest_udf = fun.udf(distance_to_closest)
```
