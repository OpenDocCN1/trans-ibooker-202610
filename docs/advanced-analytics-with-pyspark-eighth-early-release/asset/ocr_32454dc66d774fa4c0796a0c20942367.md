```
outputCol="hashes", numHashTables=200, bucketLength=2.0)
model = brp.fit(output)
```

In the BucketedRandomProjection LSH implementation, the bucket length can be used to control the average size of hash buckets (and thus the number of buckets). A larger bucket length (i.e., fewer buckets) increases the probability of features being hashed to the same bucket (increasing the numbers of true and false positives).

We now transform the input DataFrame using the newly created LSH model object. The resulting DataFrame will contain a *hashes* column containing hashed representation of the image embeddings.
