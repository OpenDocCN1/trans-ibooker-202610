# Why Did We Write This Book Now?

Apache Spark experienced a major version upgrade in 2020—version 3.0. One of the biggest improvements is the introduction of Spark Adaptive Execution. This feature takes away a big portion of the complexity around tuning and optimization. We do not refer it in the book since its turned on by default in Spark 3.2 and later versions so you automatically get the benfits.

The ecosystem changes, combined with Spark’s latest major release, make this edition a timely one. Unlike previous editions of Advanced Analytics with Spark, which chose Scala, we will use Python. We will cover best practices and integrate with wider Python data science ecosystem when appropriate. All chapters have been updated to use the latest PySpark API. Two new chapters have been added and multiple chapters have undergone major rewrites. We will not cover Spark’s streaming and graph libraries. With Spark in a new era of maturity and stability, we hope that these changes will preserve the book as an useful resource on analytics for years to come.
