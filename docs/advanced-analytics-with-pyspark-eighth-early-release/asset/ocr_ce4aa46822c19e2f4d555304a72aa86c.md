The resulting data set is the concatenation of all the files in the
_data/genomics/reads/HG00103/_ directory, where each _part-*.parquet_ file is
the output from one of the PySpark tasks. You’ll also notice that the data
has been compressed more efficiently than the initial _.bam_ file (which is
gzipped underneath) thanks to the columnar storage (see “Parquet Format
and Columnar Storage”).
