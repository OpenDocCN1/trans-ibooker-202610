We will use the following annotators as part of our preprocessing pipeline: - Tokenizer - Normalizer - StopWordsCleaner - Stemmer

Let's start with the `Tokenizer`.

```
```scala
# Split sentence to tokens (array)
tokenizer = Tokenizer() \\
    .setInputCols(["document"]) \\
    .setOutputCol("token")
```
```

A Tokenizer is a fundamental Annotator. Almost all text-based data processing begins with some form of tokenization. It is the process of breaking raw text into small chunks. Tokens can be words, characters or subwords (n-grams). Most classical NLP algorithms expect tokens as the basic input. Many deep learning algorithms are being developed that take characters as basic input. Most NLP applications still use tokenization.

Next up is the `Normalizer`.`.

```
```scala
# clean unwanted characters and garbage
normalizer = Normalizer() \\
    .setInputCols(["token"]) \\
    .setOutputCol("normalized") \\
    .setLowercase(True)
```
```

The Normalizer cleans out tokens from previous step and removes all unwanted characters from text.

# remove stopwords
