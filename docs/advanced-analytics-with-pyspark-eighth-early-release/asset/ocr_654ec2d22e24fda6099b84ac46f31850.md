We import the data using the wholeTextFiles method accessible through sparkContext. This method reads the data in as an RDD. We convert it into a DataFrame since that's what we want.

```
raw_data = spark.sparkContext.wholeTextFiles(data_source).toDF()
raw_data.show(1, vertical=True)
...
-RECORD 0-------------------------------
_1 | file:/home/analyt...
_2 | <doc id="18831" u...
```

The resulting DataFrame will consist of two columns. The number of records will correspond to the number of files that were read. The first column consists of the filepath and second contains the corresponding text content. The text contains multiple entries but we want each row to correspond to a single entry. Based on the entry structure that we had seen earlier, we can separate entries using couple of PySpark utilities - split and explode.

```
df = df.withColumn('content',
fun.explode(fun.split(fun.col("_2"), "</doc>")))
df = df.drop(fun.col('_2')).drop(fun.col('_1'))

df.show(4, vertical=True)
```
