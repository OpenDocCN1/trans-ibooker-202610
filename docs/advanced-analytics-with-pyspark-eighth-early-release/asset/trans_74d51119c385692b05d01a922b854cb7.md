## 前言

Apache Spark 从 MPI 到 MapReduce 拥有悠久的前身谱系，使得编写能够利用大量资源的程序成为可能，同时抽象掉分布式系统的琐碎细节。尽管数据处理需求推动了这些框架的发展，但从某种意义上说，大数据领域与这些框架关系如此密切，以至于其范围由这些框架所能处理的内容所定义。Spark 的最初承诺是将这一点进一步推进——使编写分布式程序感觉就像编写常规程序一样。

Spark 的流行度上升与 Python 数据（PyData）生态系统的兴起同步。因此，Spark 的 Python API——PySpark——在过去几年中流行度显著增长。尽管 PyData 生态系统最近涌现出一些分布式编程选项，Apache Spark 仍然是跨行业和领域处理大数据集的最流行选择之一。结合最近将 PySpark 与其他 PyData 工具集成的努力，作为数据科学从业者，学习该框架可以显著提高您的工作效率。

我们认为，教授数据科学的最佳方式是通过示例。为此，我和我的同事编写了一本应用书籍，试图涉及大规模分析中最常见的算法、数据集和设计模式之间的交互。本书不打算从头到尾阅读。翻到看起来像您正在尝试完成的事情，或者仅仅引起您兴趣的章节。

## 我们为什么现在编写此书？

Apache Spark 在 2020 年经历了一个主要版本升级——3.0 版。最大的改进之一是引入了 Spark 自适应执行。此功能消除了调优和优化中很大一部分的复杂性。我们在书中没有提及它，因为它在 Spark 3.2 及更高版本中默认启用，因此您会自动获得其优势。

生态系统的变化，加上 Spark 的最新主要版本，使这一版本及时。与之前选择 Scala 的 *使用 Spark 进行高级分析* 不同，我们将使用 Python。我们将在适当的时候介绍最佳实践并与更广泛的 Python 数据科学生态系统集成。所有章节都已更新为使用最新的 PySpark API。增加了两个新章节，多个章节经过了重大重写。我们不会涵盖 Spark 的流和图形库。随着 Spark 进入成熟和稳定的新时代，我们希望这些变化能够使本书在未来多年内保持为分析领域有用的资源。

## 本书的组织方式

第一章将把 Spark 和 PySpark 放在数据科学和大数据分析的更广泛背景下介绍。此后，每一章都将包含使用 PySpark 进行的自包含分析。第二章将通过数据清洗的用例介绍 PySpark 和 Python 中数据处理的基础知识。接下来的几章将深入探讨使用 Spark 进行机器学习的核心内容，在规范应用中应用一些最常见的算法。其余章节则更像是一箱杂项，将 Spark 应用于一些略显奇特的应用中——例如，通过文本中的隐语义关系查询维基百科、分析基因组数据或识别相似图像。

本书不会讨论 PySpark 的优缺点。还有几件事它也不会涉及。它将介绍 Spark 编程模型和 Spark Python API（即 PySpark）的基础知识。然而，它不会试图成为 Spark 参考指南或提供所有细节的全面指南。它不会试图成为机器学习、统计学或线性代数参考，尽管许多章节在使用这些内容之前会提供一些背景知识。

相反，它将帮助读者了解使用 PySpark 在大型数据集上进行复杂分析是什么感觉。它将涵盖整个流程：不仅仅是构建和评估模型，还包括数据清洗、预处理和探索，并注重将结果转化为生产应用程序。我们认为，教授这一点的最佳方式是通过示例。

以下是本书将处理的一些任务示例：

- *预测森林覆盖类型*

我们使用决策树，利用位置和土壤类型等相关特征来预测森林覆盖类型。（参见第 4 章）

- *查询相似的维基百科条目*

我们使用自然语言处理（NLP）技术识别条目之间的关系并查询维基百科语料库。（参见第 6 章）

- *了解纽约出租车的使用情况*

我们通过执行时空分析，将平均出租车等待时间作为位置的函数进行计算。（参见第 7 章）

- *降低投资组合风险*

我们使用蒙特卡罗模拟来估算投资组合的金融风险。（参见第 9 章）

尽可能，我们将尝试不仅仅提供“解决方案”，而是展示完整的数据科学工作流程，包括所有迭代、死胡同和重启。本书将有助于让您更熟悉 Python、Spark、机器学习和数据分析。然而，这些是为更大的目标服务的，我们希望最重要的是，本书能教会您如何处理本章开头描述的这类任务。每一章大约 20 页，会尽可能接近演示如何构建其中一个数据应用程序。
