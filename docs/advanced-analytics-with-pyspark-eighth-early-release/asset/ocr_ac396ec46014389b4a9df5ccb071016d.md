# # FUNCTIONALITY AND ANNOTATION NLP LIBRARIES

NLP libraries can be broadly divided into two types: functionality libraries and annotation libraries.

# ## Functionality Libraries

These are built for specific NLP tasks and techniques. The methods provided by these libraries are often self-contained. That means, it is assumed that basic tasks like tokenization will have to be performed even when methods for entity recognition or part-of-speech (POS) tagging are invoked. This makes them easier to work with at the cost of performance since there is a lack of coherent design.

# ## Annotation Libraries

Annotation libraries are libraries in which all the functionality is built around a document-annotation model. There are three main concepts that they are designed around: document, annotation, and annotator.

# ### Document

It is a representation of the text we want to analyse or work with.

# ### Annotation

It is the representation of the output of our NLP functions.

# ### Annotator

It is the object that contains the logic for using the NLP functions.

As we use Spark NLP in upcoming sections, the concepts above will become clearer.
