# # Preparing the data using Spark NLP

We had earlier mentioned that a library based on the document-annotator model such as Spark NLP has the concept of Documents. There does not exist such a concept natively in PySpark. Hence, one of Spark NLP's core design tenets is strong interoperability with MLLib. This is done by providing DataFrame-comptabile transformers that convert text columns into documents and converting annotations into PySpark data types.
