# Listing 5-10. Adding dependencies and npm Script in Package.json

```
...
"scripts": {
    "start": "serve",
    ...
},
"devDependencies": {
    "serve": "^11.3.2"
}
...
```

This instruction will install the 'serve' package in our project and, with 'npm run start', run a local server.

Then, to run our example, you must go inside our math-operations-component folder and run

```
$npm install
```

Later, run

```
$npm run start
```
