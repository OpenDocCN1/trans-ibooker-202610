以下是 Shadow DOM 的一些好处：

- Shadow DOM 创建了一个隔离的 DOM，使我们能够在 Web 组件中操作 DOM 而无需担心外部节点。
- Shadow DOM 创建了作用域 CSS，这意味着我们可以创建更通用的规则而无需担心命名冲突。

使用 Shadow DOM 的基本方法在清单 4-2 中展示。你可能还记得我们在第 3 章中使用过这种方法，当时在清单 3-7 中，我们为 Web 组件添加了 Shadow DOM，以激活/停用示例中的模板。

### 清单 4-2. 附加 Shadow DOM

```
let shadowElement = element.attachShadow({mode: 'open'});
```

前述代码片段中的 attachShadow() 接收一个 mode，可以是 'open' 或 'closed'。'open' 表示你可以从主上下文访问 Shadow DOM，而 'closed' 表示你不能。
