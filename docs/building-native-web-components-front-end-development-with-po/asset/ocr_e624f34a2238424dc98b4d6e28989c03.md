# Creating a New Vue Project

First, we are going to create a new project in Vue 3, using the Vue CLI. Be sure that you are using the latest version of the Vue CLI and run the following:

```
$npm update -g @vue/cli
```

To create the project, run the following in your terminal:

```
$vue create note-app
```
