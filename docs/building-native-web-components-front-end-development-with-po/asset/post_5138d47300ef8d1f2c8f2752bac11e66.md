### Publishing to npm

In Chapter 6, we created three components: `<simple-form-modal-component>`, `<note-list-component>`, and `<note-list-item-component>`. Now we are going to make these components available through www.npmjs.com. npm is a repository of packages that we can add in our projects easily with the command `$npm install <package>`.

First, we require an account to publish packages (see Figure 7-1).
