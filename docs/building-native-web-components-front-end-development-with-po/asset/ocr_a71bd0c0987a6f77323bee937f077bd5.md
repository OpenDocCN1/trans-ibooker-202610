In this package.json file, we are defining the name that our component has in npmjs.com and how the files are structured. npm package names should be unique. Therefore, you must be sure that the name you choose for the name property in package.json is not taken in npmjs.com.

Now we are going to create a directory called src, in which we are going to locate our code source. Then, we are going to move our simple-form-modal-component.js there and create a new file index.js, as in Listing 7-2.

# Listing 7-2. index.js for simple-form-modal-component

```
export * from './simple-form-modal-component';
```

This is just one line with which we are importing everything in simple-form-modal-componet.js. Therefore, in our file simple-form-modal-component.js, we must add the word export, to make our component available as a module, as in Listing 7-3.

# Listing 7-3. Converting simple-form-modal-component in a Module

```
export class SimpleFormModalComponent extends HTMLElement {
...
}
customElements.define('simple-form-modal-component', SimpleFormModalComponent);
```

OK, we have our component ready for now. The next step is run

```
$npm publish
```
