# Adding Guards

Now, in App.vue, we must add a mechanism to prevent users not logged in from accessing Dashboard.vue directly from the URL. To achieve this, we are going to use a feature from Vue Router called Guards. Guards are primarily used to guard navigations, either by redirecting or canceling them. You can learn more about Guards at https://router.vuejs.org/guide/advanced/navigation-guards.html#global-before-guards. We are going to add this mechanism in our router/index.js file (Listing 10-4).
