Here, we are using fireApp.currentUser() to check if the user is logged in when Login.vue is mounted(), if we can jump directly to Dashboard.vue, or if we require that the user enter credentials. Also, we create handleLogout(), a method that uses auth.signOut to close the session and redirect the user to Login.vue. When the user is logged in, we show the logout link, using the v-if directive, Then, only when the user has already logged in, we show this link to the user (Figure 10-5).
