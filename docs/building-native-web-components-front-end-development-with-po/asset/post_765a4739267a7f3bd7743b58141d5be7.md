First, we must authenticate our Firebase CLI with our Firebase account. To do this run the following:

```

```

After successful authentication, you can start to use the Firebase tool to connect your apps with Firebase. The next step is to create our production bundle. To do this run

```
$ npm run build
```

Now we must run the Firebase CLI wizard to connect VueNoteApp with Firebase (Figure 10-8). Run
