用户在插入新笔记时可能会犯错。因此我们必须允许他们删除笔记。为此，我们必须修改我们的数组并移除元素。JavaScript 有一个方法可以帮助我们做到这一点：Splice。Splice 方法允许我们更改数组中的内容。

我们将创建 handleDelete(id) 方法并将其添加到 Delete 按钮中，我们将向其传递要删除的项目索引。使用 Splice，我们可以从数组中移除内容，如列表 9-30 所示。
