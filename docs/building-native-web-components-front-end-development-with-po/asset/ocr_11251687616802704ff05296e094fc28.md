# Node.js

Node.js is a JavaScript runtime environment. Most projects that use JavaScript use Node to install dependencies and create scripts to automate the development workflow.

You must install Node in your machine. You can download it from https://nodejs.org/en/.

Once you download the installer, run it and follow the instructions.
