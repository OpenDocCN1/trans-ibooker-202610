
## 第 5 章
## ES 模块

在本章中，我将讨论 ES 模块，这是 Web Components 规范集中的另一项规范。你将学习 ES 模块是什么以及如何在 Web 组件中使用 ES 模块。然后我们将为我们的集合构建一个新的 Web 组件。

### ES 模块是什么？

ES 模块规范定义了一种机制，可通过不同的文件在项目中共享变量和函数。ES 模块现在可通过 ES6 使用。在此之前，如果你想共享某些内容，你会将其添加到全局上下文中，无论是否使用都使其可用。请参阅清单 5-1 中的代码。

### 清单 5-1. 在 main.js 中使用常量

```js
var pi = 3.1415;
var euler = 2.7182;

function getCircumference(radius) {
    return 2 * pi * radius;
}

function getCalcOneYear(interestRate, currentVal) {
    return currentVal * (euler ** interestRate);
}

console.log(getCircumference(2)); // 12.566
console.log(getCalcOneYear(0.3, 100)); // 134.98466170045035
```

在 main.js 中，我们有两个值 pi 和 euler，它们在 getCircumference 和 getCalcOneYear 函数中是必需的。但如果我们在应用程序的不同位置的不同函数中需要 pi 和 euler 怎么办？

为了更轻松地共享这些值，我们可以创建一个新文件 math-constants.js，并使用 'export' 告诉 JavaScript 我们可以导入该值。这在清单 5-2 中显示。

### 清单 5-2. 在文件 math-constants.js 中导出值

```
export const pi = 3.1415;
export const euler = 2.7182;
```

现在我们可以在其他文件中使用这些值，在 HTML 文件中使用 type="module"，如清单 5-3 所示，或在 JS 文件中导入，如清单 5-4 所示。

### 清单 5-3. 在 HTML 中使用 ES 模块

```
<script type="module" src="./math-constants.js"></script>
```

### 清单 5-4. 在 JS 脚本中使用 ES 模块

```
import {pi, euler} from "./math-constants.js";
```

### 构建 MathOperationsComponent

为了练习 Shadow DOM，我们将构建一个名为 <math-operations-component> 的简单组件，用于在我们的应用中添加社交网络链接。该组件接收两个参数 'operation' 和 'initialValue'，其中 'getCircumference' 接收半径的圆周；getCalcOneYear 使用两个参数（利率和当前值）获取一年的复利；'getLog2' 返回 2 的自然对数值。

```

    constructor() {
    }
}

MathOperationsComponent);
```

在与 index.html 同级的层级创建一个新的 math-constants.js 文件并创建常量 pi、euler 和 ln2，使用 'export' 以允许将这些值作为模块使用，如清单 5-6 所示。

### 清单 5-6. 定义 MathOperationsComponent

```

export const euler = 2.7182;
```

现在，在文件 index.html 中，我们必须添加几件事，以便在组件中使用模块，如清单 5-7 所示。

### 清单 5-7. 在 MathOperationsComponent 中使用模块

```
<script type="module">
import {pi, euler, ln2} from './math-constants.js';

    constructor() {
    }
}

MathOperationsComponent);

```

前述代码片段中首先是 script 标签中的 type="module"，用于代码中的模块。其次是 'import'，用于我们在 math-constants.js 中声明的常量。

现在，在我们的组件中，我们将创建 getCircumference、getCalcOneYear 和 getLN2，以返回我们在调用中发送的参数所需的 value。这在清单 5-8 中显示。

### 清单 5-8. 在 MathOperationsComponent 中使用模块

```
getCircumference(radius) {
    return 2 * pi * radius;
}

getCalcOneYear(interestRate, currentVal) {
    return currentVal * (euler ** interestRate);
}

getLN2() {
    return ln2;
}
```

请注意，这里我们使用的是从模块导入的常量。

最后，我们在 constructor() 中添加逻辑，以处理我们在组件中发送的 'operation' 和 'initialValue' 属性中的参数，并创建模板和方法以及样式，以便在文档中显示我们的信息，如清单 5-9 所示。

### 清单 5-9. 在 MathOperationsComponent 中使用模块

```
<script type="module">
import {pi, euler, ln2} from './math-constants.js';

class MathOperationsComponent extends HTMLElement {
    constructor() {
        super();
        this.root = this.attachShadow({mode: 'open'});
        this.container = document.createElement('div');
        this.root.appendChild(this.container);

        switch(this.getAttribute('operation')) {
            case 'getCircumference':
                const radius = this.getAttribute('initialValue');
                this.container.innerHTML = MathOperationsComponent.getTemplate(this.getCircumference(radius));
                break;
            case 'getCalcOneYear':
                const [interestRate, currentVal] = this.getAttribute('initialValue').split(',');
                this.container.innerHTML = MathOperationsComponent.getTemplate(this.getCalcOneYear(interestRate, currentVal));
                break;
            case 'getLog2':
                this.container.innerHTML = MathOperationsComponent.getTemplate(this.getLN2());
                break;
        }
    }

    getCircumference(radius) {
        return 2 * pi * radius;
    }
}
```

