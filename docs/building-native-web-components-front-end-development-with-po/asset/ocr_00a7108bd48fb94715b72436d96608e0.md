If we want to bind a clickHandler to a click event, we can pass it with the $click notation from the template literal, as in Listing 8-7.

# Listing 8-7. Binding a clickHandler in a Click Event

```
import { LitElement, html } from 'lit-element';
class MyComponent extends LitElement {
  render(){
    return html`
      <button @click="${this.clickHandler}">click</button>
    `;
  }
  clickHandler(e) {
    console.log(e.target);
  }
}
```

You can find all the mechanisms for templates at https://lit-element.polymer-project.org/guide/templates or https://lit-html.polymer-project.org/guide.

# Styles

Adding styles in your web components with Polymer is straightforward. Simply add your selectors and properties in the static method styles(), as in Listing 8-8.

# Listing 8-8. Adding Styles in Web Components

```
import { LitElement, html } from 'lit-element';

class MyComponent extends LitElement {
  static get styles() {
    return css`
      div { color: blue; }
    `;
  }
}
```
