# Getting Started

To start to build apps with Web Components, you must understand and install several technologies and tools.

# cmder (Windows Only)

cmder is a terminal emulator for Windows. By default, Windows operating systems come with a terminal (command prompt) that is not useful for development. That is why we need cmder, which is an emulator we can use to run commands smoothly in our terminal.

+   - To access this emulator, go to cmder.net and download the latest version.
+   - Extract the file in your C:/ location.
+   - Go to System Properties ► Environment Variables and edit Path Variable, as in Figure 1-2.
