# Distributing Web Components

In this chapter, you will learn how to make our web components available in npm. You are also going to learn about the browser support offered by Web Components APIS, how to add polyfills to support more web browsers, and how to add Webpack and Babel to process and prepare our web components for publication.

# Publishing to npm

In Chapter 6, we created three components: `<simple-form-modal-component>`, `<note-list-component>`, and `<note-list-item-component>`. Now we are going to make these components available through www.npmjs.com. npm is a repository of packages that we can add in our projects easily with the command `$npm install <package>`.
