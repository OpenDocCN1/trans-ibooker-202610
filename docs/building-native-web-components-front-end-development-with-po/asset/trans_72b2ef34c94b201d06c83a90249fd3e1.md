## Listing 8-26. 在 NoteListComponent 中使用 LitElement 添加 attributeChangedCallback

```
import {LitElement, html, css} from 'lit-element';

  static get properties() {

        type: Array,
        attribute: true,
        reflect: true,

    };

    super();

  }
}
```
