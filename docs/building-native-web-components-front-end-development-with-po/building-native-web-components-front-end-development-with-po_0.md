## 引言
Web Components 无处不在于当前的前端环境中。三大最流行的框架 Angular、React 和 Vue.js 都将 Web Components 作为架构元素使用。在本书中，你将学习如何增强 Web 应用，构建可集成到任何现代 JavaScript 项目中的小组件，并在公司决定将当前 Web 应用迁移到更新颖更有前景的框架时进行修改以供未来使用。

在第 1 章中，你将创建你的第一个原生 Web 组件。我将指导你完成使用 Web 平台规范创建占位组件所需的所有步骤。

第 2 章涵盖 CustomElement 规范。你将学习如何使用它在 Web 上创建自定义标签以及其生命周期的工作方式。

第 3 章涵盖 HTML 模板。我将讨论 <template> 和 <slot> 元素以及如何使用它们构建组件。

在第 4 章中，你将学习 Shadow DOM 规范，如何将其添加到原生 Web 组件中，以及它的好处。

第 5 章讨论 ES 模块规范，如何创建模块，以及如何在我们的 Web 应用中使用模块。

在第 6 章中，你将学习如何设计组件并使它们在 Web 应用中协同工作。我们将把 Web 应用连接到 API 并为组件定义数据流。

在第 7 章中，你将学习如何使我们的 Web Components 在 npm 中可用。你还将了解浏览器对 Web Components API 的支持，如何添加 polyfill 以支持更多 Web 浏览器，以及如何添加 Webpack 和 Babel 来处理和准备我们的 Web Components 以便发布。

第 8 章涵盖如何使用 Polymer 构建 Web Components，为什么使用 Polymer 而不是 VanillaJS，如何在我们的 Web Components 中使用 LitElement，以及如何使用 lit-html。

在第 9 章中，我们将开发一个应用。你将学习一些关键概念并了解如何集成 Web Components 和 Vue.js。

在第 10 章中，你将看到 Firebase Hosting 和 Firebase 身份验证如何用于将我们的最终 Web 应用发布到世界。
