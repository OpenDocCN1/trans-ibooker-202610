# 入门

在本节中，你将学习如何在开始编写主要元素之前设置此服务。设置此服务比之前的服务 UMS 容易得多。我们要发送电子邮件，但不发布 JWT。我们基本上将执行以下操作：

* **接收用户的订单：** 服务需要接收来自用户的订单，通常通过你的应用程序或前端。订单请求包含用户想要购买的商品以及发货和账单信息。

* **验证订单中的价格：** 在微服务中，数据库不共享。因此 OMS 不知道产品的价格，因为它们在 PMS 中。为了验证订单，我们必须在收到订单后连接到 PMS 并获取价格列表。

* **等待付款到账：** 订单下单后，我们需要等待付款。某些付款可能几乎是即时的，如信用卡。其他付款，如寄送支票或电汇，可能需要几天时间。

* **付款完成后处理订单：** 订单完成后，我们需要开始发货。在我们的例子中，我们只是将订单标记为已发货，但将来扩展此服务时可能涉及更多内容。

* **让用户查看订单历史：** 用户通常想查看过去订购的内容，因此应该提供该功能。

## 设置 JWT 验证

为了让此服务将正确的用户与订单关联，我们需要能够识别发送请求的用户。正如我们在[第 7 章](#de77c71a-d8d1-4d47-9dbe-b621d7690103.xhtml)《编写用户服务》中讨论的，我们使用 JWT 进行识别。在此服务中，我们只需使用提供的包将负载与其签名进行验证。

得益于随模板安装的 JWT 包，我们在这里不需要做太多工作。为了方便，让我们像在[第 7 章](#de77c71a-d8d1-4d47-9dbe-b621d7690103.xhtml)《编写用户服务》中那样创建一个设置文件。请遵循以下步骤：

1. 编辑文件夹中的 `.env` 文件：

```
$ open .env
```

2. 打开你的 `jwks.json` 文件，它应该保存在项目文件夹上方的文件夹中。它看起来像这样：

![](assets/464a7938-a47e-4ec7-9786-6df729a896f6.png)

3. 将 `jwks.json` 复制为一行。

4. 将其粘贴到设置文件中，如下所示：

```
JWKS='<从 jwks 复制值>'
```

就这样。我们不需要私钥，因为我们只是验证 JWT。每当有请求进来并需要验证时，JWT 中间件将自动使用公钥检查 JWT 负载是否正确签名。如果你需要熟悉这一点，可能需要回到[第 3 章](#9b085c0a-3b19-4c38-94b9-05739781ff96.xhtml)《Vapor 框架入门》。

现在我们已经设置好 JWT，让我们配置数据库。

## 设置数据库

继续在本地数据库设置中创建一个新用户和数据库。如果需要提醒，请查看[第 3 章](#9b085c0a-3b19-4c38-94b9-05739781ff96.xhtml)《Vapor 框架入门》。将用户命名为 `service_orders`，数据库也命名为 `service_orders`。

要设置数据库，我们只需执行以下操作：


确保你输入了正确的密码。
