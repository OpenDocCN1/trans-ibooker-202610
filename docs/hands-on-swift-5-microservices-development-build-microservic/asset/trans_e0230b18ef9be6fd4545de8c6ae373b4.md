## 前言

2018 年，我在柏林举办的首届服务端 Swift 大会上有幸亲自结识了 Ralph。我们在哥本哈根的下一届大会上再次相遇。Ralph 为人友善，我们花了很多时间相互了解并分享想法。

Ralph 拥有长达十余年的商业学习与实践经验，这让他对当今 Web 开发者面临的问题拥有独到的见解。除了商业敏锐度，他还对编程有深刻的理解。他是个合我心意的人，总是渴望尝试新事物并与他人分享知识。

在我们亲自见面前几个月，Ralph 的公司 Skelpo 成为了 Vapor 的第二大主要赞助商。这种早期对框架的支持已被证明极其宝贵。除了单纯的赞助，Ralph 还积极参与框架的开发。他迅速采纳变更并提供反馈。这种反馈对 Vapor 的成功至关重要，也展示了他对框架的精通。

更重要的是，Ralph 现在在整个 Vapor 社区广为人知。他为贡献者创造了许多参与相关项目并回馈框架的机会。他的工作壮大了社区，帮助生态系统蓬勃发展。像 Ralph 这样的人让开源变得特别，并推动软件工程向前发展。

希望您喜欢他在这本书中辛勤编纂并分享给您的知识。愿它激励您尝试新事物，并与他人分享您的知识。

## 作者简介

**Ralph Kuepper** 在 Web 和软件行业拥有超过 15 年的经验。他在 17 岁时仍在上高中和大学期间就创办了自己的公司。多年来，他曾为阿迪达斯、起亚和本田等公司从事项目工作。从使用 PHP 和单体架构开发后端和网站的传统背景出发，他在过去 4 年中拥抱并精细调整了基于 Swift 的微服务方法。他的公司 Skelpo Inc. 积极参与 Vapor 框架的开发，并贡献了各种开源微服务及相关包。

首先，我要感谢我了不起的挚友兼妻子 Elizabeth，感谢她在我写作这本书过程中给予的所有耐心。写书是一项漫长而紧张的工作，我感激她在过程中给我的所有支持。我也要感谢 Packt Publishing 的优秀员工和编辑团队。特别要感谢 Aamir Ahmed 在写作过程中持续的鼓励、指导和支持。我还要感谢技术审阅者 Caleb Kleveter，他提供了宝贵的见解和反馈，且对 Swift 非常熟悉。最后，我要感谢 Vapor 创始人 Tanner Nelson 的全力支持，以及最终为本书撰写前言！

## 审阅者简介

**Caleb Kleveter** 是 Skelpo Inc. 的合同软件开发人员。自 2014 年 WWDC 发布 Swift 以来，他已使用 Swift 5 年，并使用 Vapor 构建微服务应用 3 年。Caleb 还是多个核心 Vapor 仓库的维护者，在 Medium 上发表过多篇关于如何使用 Vapor 和 Fluent ORM 构建后端应用的文章，并在 ServerSide.swift 大会上就如何在 Vapor 中构建弹性微服务应用发表过演讲。除了服务端 Swift，Caleb 还喜欢钻研其他技术，如 Vue.js、正则表达式和 X86 汇编，并在业余时间编写流式文本解析器。
