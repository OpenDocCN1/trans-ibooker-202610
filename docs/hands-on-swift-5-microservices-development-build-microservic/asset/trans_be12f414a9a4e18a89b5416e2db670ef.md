## 设置模板

让我们开始设置在[第 5 章](#045da3f4-89ae-4871-bde0-08285e687f02.xhtml)《创建您的第一个微服务》中创建的模板。我们不需要重写之前创建的内容，只需将其作为该服务的基础。请遵循以下步骤：

1. 进入产品管理器的文件夹，如下所示：

```
$ cd ~/Shop\ Backend/ProductService
```

2. 现在，将模板从原始文件夹复制到我们的新文件夹：

```
$ cp -r ../template/. . && rm -rf .build
```

3. 现在，打开 `Package.swift` 文件，如下所示：

```
$ open Package.swift
```

4. 将名称更改为 `ProductService`。

5. 现在，安装所有依赖并构建项目，如下所示：

```
$ swift package update
```

6. 在 Xcode 中打开项目，如下所示：

```
$ xed .
```

现在我们已经设置好模板，可以开始使用它了。PMS 不需要任何额外的包。我们确实想要验证某些请求，以允许管理员用户管理产品，所以让我们继续设置 JWT 验证。

## 设置 JWT 验证

得益于我们随模板安装的 JWT 包，我们在这里不需要做太多工作。为了方便，让我们创建一个设置文件，就像我们在[第 7 章](#de77c71a-d8d1-4d47-9dbe-b621d7690103.xhtml)《编写用户服务》中所做的那样。为此，请遵循以下步骤：

1. 在文件夹中创建一个设置文件，如下所示：

```
$ open .env
```

2. 打开您的 **JSON Web Key Set (JWKS)** 文件，该文件应保存在项目文件夹上方的文件夹中。

3. 将整个 JWKS 内容复制到一行并粘贴到 `.env` 文件中，如下所示：

```
JWKS='<copy the value from the jwks>'
```

就这样。我们不需要私钥，因为我们只是验证 JWT。每当有请求进来并需要验证时，`JWTMiddleware` 将自动使用公钥检查 JWT 负载是否正确签名。如果您需要熟悉这一点，可以回顾[第 3 章](#9b085c0a-3b19-4c38-94b9-05739781ff96.xhtml)《Vapor 框架入门》。

现在我们已经设置好 JWT，让我们配置数据库。

## 设置数据库

继续在您的本地数据库设置中创建一个新用户和一个数据库。如果您需要提醒如何操作，请查看[第 3 章](#9b085c0a-3b19-4c38-94b9-05739781ff96.xhtml)《Vapor 框架入门》。将用户命名为 `service_products`，数据库也应命名为 `service_products`。

要设置数据库，我们只需执行以下操作：

将以下行添加到 `.env` 文件中：

```
MYSQL_CRED='mysql://service_products:password@localhost:3306/service_products?ssl=false'
```

请确保您输入了正确的密码。

我们现在已经完成了所有设置：模板、JWT 和数据库。这完成了我们的准备工作，以便我们现在可以着手处理路由。
