# # Scoring

Questions 1–4 reflect self-awareness. Questions 5–8 reflect social awareness, questions 9–12 reflect self-management, and questions 13–16 reflect relationship management. Add up the number of “T” responses that you had for each dimension. If that score is 3 or 4 on a given dimension, this means that you are especially strong on it.
