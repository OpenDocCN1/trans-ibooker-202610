# Scoring

Add up your scores on items as follows:

| Economic values | Stakeholder values |
|---|---|
| 2 | 1 |
| 3 | 4 |
| 6 | 5 |
| 7 | 8 |

Note that the possible score for each column can range from 4–8, and both columns should add up to 12 in total. For example, if items 2, 3, 6, and 7 each has a score of 1, then your economics values score would equal 4. For each column:

+   - Score of 4–5 = Strong priority
+   - Score of 6 = Moderate priority
+   - Score of 7–8 = Weak priority
