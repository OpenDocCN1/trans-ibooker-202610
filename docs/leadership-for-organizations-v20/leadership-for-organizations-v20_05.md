## 领导-成员交换与关系建设

> "即使是表现最差的员工也能产生影响。领导力的考验不在于好管理的员工，而在于难管理的员工。与那个人一起工作，设定新目标，并辅导和鼓励他或她取得成功。” —Bob Nelson，作者兼管理顾问

### 学习目标

- 1. 识别领导-成员交换（LMX）是如何形成的。
- 2. 定义内群体与外群体关系。
- 3. 从外群体形成的角度描述 LMX 两难困境。
- 4. 阐述可以采取哪些措施来预防或纠正 LMX 两难困境。
- 5. 识别领导者政治敏锐度的重要性，作为与同事、客户、供应商和上级建立关系并影响他们的一种手段。

领导在很大程度上是指与领导者试图影响的个人随时间建立和维护关系。事实上，关系是领导者有效性所必需的影响过程的关键。换句话说，领导者施加影响，而关系建设是能够影响他人的关键。关系可以与各种个人建立，包括同事、上级、客户，以及也许最重要的是，追随者。在本章中，我们将讨论所有这些类型的目标个人，特别是关注追随者。我们首先描述与追随者建立关系的性质及其重要性。

### 3.1 领导-成员交换

担任领导职务的人最初有两种方式与追随者接触。首先，领导者可以参与将追随者选入其团队，也许会与在选拔过程中可能有发言权的其他人（例如，人力资源官员）一起参与。其次，领导者可能会被安置（例如，通过晋升、调动等）在追随者已经存在的环境中。无论哪种情况，领导者都会与追随者形成随时间演变的关系。老话“一见钟情（或一见钟怨）”有一定道理，这表明领导者与追随者之间的关系会很早就定下来。尽管如此，关系确实存在随时间改变或演变的趋势——有时会变得更有利，但不幸的是，有时也会变得不利。

### 领导-成员交换（LMX）

领导者与追随者之间关系形成或演变的方式；追随者如何承担角色；领导者如何对待或回应追随者，以及由此产生的“化学反应”。

这些关系究竟如何形成或演变？这个问题的答案在很大程度上取决于追随者如何承担角色，领导者如何对待或回应追随者，以及由此产生的“化学反应”。换句话说，当涉及到领导-成员关系或所谓的领导-成员交换（LMX）时，绝对是“一手拍不响”。正如一句老话所说。对一些人来说，这可能反直觉，因为他们可能认为领导力完全关乎领导者本人，以及他或她与追随者之间所做的事。然而，本章乃至下一章的前提是，追随者在 LMX 中也发挥着关键作用。

LMX 的核心观点是领导-追随者关系基于交换。但领导者和追随者究竟交换什么？换句话说，交换的“货币”是什么？[1] 基本上，有两种类型的交换：（1）有形交换，和（2）无形交换。有形交换与我们传统认为的“货币”所指的内容一致。它们是基于经济或生产力的。最基本的交换是用工资换取满意的绩效。然而，有形交换也可以稍微被动一些，即如果一个人表现令人满意，只需被放任不管。例如，如果追随者表现尚可，他或她可能更喜欢被老板放任不管或回避，而不是不断受到质疑、成为辱骂或嘲笑的对象等等。换句话说，这种回避可能被一些追随者视为一种积极的交换——或至少是没有消极的交换。

有形交换构成了领导者与追随者之间关系的基础，如果缺失或被认为不公平，当然可能引起问题。然而，这种性质的交换并不能涵盖领导-追随者关系的所有可能性，也不能完全解释关系的长期性质。确实，并非所有交换都涉及货币货币，或容易转化为货币价值的东西。无形交换也同样值得考虑。无形交换涉及友谊（或友好）、接受共同责任、忠诚和信任等事物。例如，信任是任何关系中的强大因素，包括领导者与追随者之间的关系。如果没有信任，领导者会觉得需要密切监控追随者的行为和举止，这花费大量时间，并倾向于在领导者和追随者双方产生焦虑。同样，追随者只会付出足够的努力来满足其关系的“合同性”性质。[2] 此外，追随者不会有动力去发挥创造力或寻找棘手问题的解决方案，因为害怕失败或受到责备。但是，如果存在信任，关系会更加轻松，追随者可能会有动力付出额外的努力和创造力，并接受更大的责任。

就 LMX 的表征而言，可能会出现两个基本方向之一。这些不同的方向通常被称为内群体 vs. 外群体，如图 3.1 所示。[3] 首先，追随者可能会成为领导者内群体的一部分，这主要基于上述类型的无形交换。领导者出于不同原因将追随者纳入其内群体，但一个关键原因是，追随者会在早期证明他或她能够表现良好并承担越来越多的责任。这显然减轻了领导者密切监控追随者的压力，考虑到领导者的时间要求，这始终是受欢迎的解脱。或者，领导者可能会因为追随者拥有相似的价值观、兴趣或背景而接纳他或她。例如，一位喜欢打高尔夫球作为消遣的领导者，自然会对同样打高尔夫球的追随者持好感。这两个人可能会花更多时间在一起，与领导者与其他追随者相处的时间相比，然后强化内群体成员身份。请记住，这种“成员身份”是非正式的，双方可能不会讨论，甚至可能没有意识到。身处领导者内群体的好处是，追随者将享有更好的工作分配或条件（例如，工作时间），获得积极的辅导和反馈，并能够在决策和问题解决方面提供大量投入。

### 图 3.1 内群体与外群体

| | 内群体领导者 | 内群体追随者 | 外群体领导者 | 外群体追随者 |
|---|---|---|---|---|
| | 授予自主权、责任和有趣的任务 | 表现强劲；承担责任 | 分配例行任务并密切监控 | 表现弱势；不承担责任 |
| | 提供支持和鼓励 | 拥有与领导者相似的价值观、背景等 | 迅速指出追随者犯下的错误 | 拥有与领导者不同的价值观或背景 |
| | 允许犯错 | 对领导者表现出忠诚 | 不允许追随者参与决策 | 缺乏忠诚，甚至可能破坏领导者 |
| | 允许追随者参与决策 | 以建设性方式主动提供投入，而非破坏领导者 | 对追随者很少信任 | 表现出缺乏可信度 |
| | 对追随者表示信任 | 展现可信度 | | |

归根结底，领导者与追随者之间的内群体关系基于信任。领导者信任追随者会承担越来越多的责任，且很少需要密切监督。追随者信任领导者会支持他/她，并关注该人士的最大利益。虽然信任感可能在关系早期就开始形成，但为了巩固信任，领导者和追随者会随着时间的推移不断从对方那里寻找线索，并观察对方的行为。

另一方面，外群体关系可能会形成，并主要基于有形交换。外群体可以被描述为内群体的镜像对立面。外群体成员可能是表现不佳的人，或者是根本无法或不愿承担更高责任的人。他或她通常只做足够多的工作来令人满意地满足期望。外群体成员的背景（例如，基于性别、年龄或种族）可能与领导者大不相同，且不与领导者共享价值观或兴趣。有一件事能迅速且不可逆转地将个人置于外群体，那就是该个人公开不尊重或破坏领导者。这可以以多种不同的方式发生。例如，追随者可能在团队会议上或与组织中其他领导者（例如，领导者的上级）交谈时表现出对领导者的不尊重。另一个例子是，追随者可能会不断试图忽略或破坏领导者试图推动的组织变革或新方向。如果追随者一方发生此类行为，领导者对追随者就会缺乏信任。

应当澄清的一件事是，关于领导-成员关系的内群体 vs. 外群体区分是一种纯粹的，也许有时是人为的区分。作为替代方案，还有三种其他可能性。首先，一些追随者可能介于两者之间，即既不在内群体也不在外群体。这些追随者可能被领导者适度重视和信任，但不如内群体成员那样程度深。其次，有可能所有追随者都在外群体。这显然代表了一个有毒的局面，如果发生，可能是领导者行为不良的结果。第三，有可能所有追随者都在内群体。如下文所述，这种情况代表了理想状态，很可能需要领导者和所有追随者双方采取积极行动才能实现。再说一遍，“一手拍不响”。

### LMX 的“两难困境”

虽然某种程度的外群体成员身份对领导者来说是一种自然发生的现象，但在理想情况下，这并不可取。外群体成员身份有可能导致许多负面后果。例如，根据定义，外群体成员往往是边缘绩效者，他们的存在可能会对组织的绩效产生负面影响。但也许同样重要的是，有一句谚语说“一个坏苹果会坏掉整筐苹果。”这意味着



在于，如果允许外群成员身份滋生并持续存在，则很可能会损害整个团队或组织中人际关系的动态。简而言之，外群形成对领导者而言是一个两难困境。

让我们考虑一个例子。外群成员可能会树立一个危险的先例，即不良行为（例如，边际绩效）是可以接受的。因此，其他人可能会质疑，自己必须以更高水平表现或行为，或者说“补齐缺口”，是否公平。此外，尽管LMX完全关乎领导者与追随者之间的关系，但外群成员很可能与其他追随者关系不好，尤其是与内群成员。再次，我们回到了那句谚语，“一个坏苹果会坏掉一整筐。”一个团队中拥有与领导者外群关系的个人越多，发生这种“变质”的可能性就越大。

此外，在这一点上，在使用“内群”和“外群”这些术语时，我们专门考虑了领导者与每个追随者之间独立关系的性质。然而，如果一个人与其领导者关系不好，那么此人也很可能与其他团队成员关系不好。一个例外可能是当所有或大多数团队成员与领导者关系不好时。尽管如此，一般而言，当外群关系超越领导者并影响追随者与追随者之间的关系时，势必会对团队凝聚力和士气产生负面影响。随后，团队绩效将受到影响。

因此，归根结底，虽然外群形成在领导者与个别追随者关系中往往是一种自然现象，但这并不是应该长期容忍或忽视的事情。但如果情况如此，那么解决办法是什么？如何补救外群形成，或者干脆从一开始就加以预防？

这些问题不容易回答。而且，很容易产生将责任简单推给领导者、让其采取行动以尽量减少外群成员身份的诱惑。诚然，领导者采取行动来预防或补救外群形成确实是合适且得体的。然而，请回顾第1章，不可避免地，领导效能涉及三个因素的结合：领导者、追随者以及他们的环境。

也就是说，显然，领导者发挥着重要作用。为了从一开始就预防外群形成，领导者需要维持在第2章中讨论的“以爱领导”理念。有了这一总体理念，领导者就有最大机会与最多比例的追随者建立内群关系。此外，领导者需要意识到某些追随者可能如何滑入外群，以及领导者本人如何可能触发这种过程。例如，我们知道一位教职人员似乎属于系主任（即该教职人员的第一级主管）的外群。一个迹象是，该教职人员从未被要求参与正式、重要的委员会工作，例如负责新教职人员搜索活动。相反，只有同一小群相对较小的教职人员或“宠儿”（即内群成员）被指定进行重要的委员会工作。在这种情况下，这种指定与被安排在委员会中的人的表现几乎毫无关系。简而言之，领导者不偏袒、监测外群形成是否可能发生、努力了解每位追随者的个人需求或风格，并在发现外群形成似乎正在发生时采取补救措施，这是至关重要的。

另一方面，追随者在与领导者建立关系的过程中发挥着重要作用，因此也在理解实现有效领导需要什么方面发挥作用。换句话说，领导者可以以平等或统一的方式展示第2章中讨论的有效特征和行为。但如果特定的追随者没有以同样的方式回报，就会出现问题，导致这些追随者陷入领导者的外群。在下一章，我们将深入探讨良好追随ership的性质以及如何向上管理。但目前，只需说，良好的追随者，特别是那些能够避免外群成员身份的人，应注意以下几点：

- 尽力履行职责，不逃避额外责任，
- 准时且认真负责，以及
- 对领导者表示忠诚，绝不做任何破坏领导者试图完成的事情的行为。

上述最后一点的一个明显例外是，如果领导者正在从事某种不道德、不安全或明显无效率的行为，那么就会涉及举报问题。我们将在本书后续章节中更深入地探讨此类问题。

最后，还有更大的组织环境会发挥作用，并可能影响领导者-追随者关系或LMX的性质。正如在第1章中提到的，领导不仅仅关乎领导者，甚至不仅仅关乎领导者和追随者。如果我们要真正理解有效的领导过程，就必须始终考虑他们所处的环境。环境既可以帮助促进领导者-追随者关系，甚至可能会损害这些关系。

让我们考虑几个关键示例。首先，许多担任领导职位的人根本不知道上面描述的LMX两难困境可能发生。他们也不知道自己可以做些什么来可能防止此类情况发生，或者至少在事后补救。因此，领导者应该接受自身主管的指导，或者接受培训以帮助处理此类问题。例如，可以对领导者进行培训，让他们认识到自己的偏见和风格偏好可能导致他们倾向于某些追随者（即内群成员），而基本上回避或不完全接受其他人（即外群成员）。此类培训还可以包括如何理解不同个人及其风格的想法，以及如何更加包容所有追随者的方法。

其次，组织的人员配备流程可以帮助防止LMX两难困境。通常，人员配备侧重于技术技能和经验，而不是考虑个人在多大程度上可能适应更大的组织，更具体地说，是团队。但是，当正确考虑人与组织匹配度时，我们预计会看到更少的外群成员实例。[4] 这究竟意味着什么？首先，这意味着任何可能被插入团队的个人都将由正式领导者通过面试并获取甄选信息（例如，推荐信检查、简历等）进行彻底审查。此外，团队的其他成员也应该参与人员配备流程，以确保新成员能与整个团队相处融洽。虽然LMX特指领导者与追随者之间的关系，但如果团队成员之间存在关系困难，最终可能会影响领导者与个别追随者之间的关系。因此，归根结底，虽然在技术技能或经验方面正确筛选个别追随者可能很重要，但也应该选择与领导者和团队相匹配（或“契合”）的人员。

西南航空和西捷航空代表了那些始终强调人与组织/团队匹配度以及工作环境中关系重要性的组织。[5] 例如，在选入组织时，西捷航空考察个人素质（例如，幽默感、喜欢玩乐的倾向、乐于助人的愿望等）至少与考虑候选人技术资格一样多。这样做，他们有助于确保组织内以及团队中的每个人在关键个人特征或价值观方面都处于共同基础上。因此，最终外群形成的可能性被最小化。

话虽如此，我们应该注意，过分强调人与组织或人与团队的匹配度存在潜在危险。如果过分强调匹配度，领导者和团队可能会倾向于选择只长得像他们、思维像他们、行为像他们的新成员。当这种情况发生时，我们可能最终会看到缺乏多样性，这可能导致自满、缺乏变革以及通常所说的群体思维。群体思维发生在团队成员过于团结一致，以至于他们甚至拒绝倾听不同观点，或拒绝引入可能与决策过程相悖的外部信息时。这在同质化或非多样化团队中更容易发生。我们将在第8章和第9章中更详细地讨论团队和多元化领导的主题。目前，我们只是提醒，虽然为了尽量减少LMX两难困境，人与组织或人与团队的匹配度很重要，但也可能过犹不及。




### 3.2 政治敏锐度

领导者通过建立和维护良好关系来影响追随者。但影响的对象往往并非正式下属或直属汇报人。相反，领导者可以通过建立和维护良好关系，影响同事、客户/客户、供应商，甚至自己的上级。[6] 以下是他们需要影响这些类型个人的示例：

- **同事**—为了获取与团队和领导者绩效相关的信息或合作。
- **客户/客户**—为了确保客户或客户感到满意，从而继续与领导者及其组织开展业务。
- **供应商**—为了确保领导者负责的生产或服务流程所需的适当物资或投入品质量高且按时交付。
- **上级**—为了确保领导者拥有必要的信息和资源，并成为老板内圈的一部分。

**政治敏锐度**

有效理解工作中他人的能力，并利用此类知识影响他人采取有利于个人和/或组织目标的行动。

实现这些影响结果的关键是政治敏锐度，它涉及与上述每类个人建立和维护关系。领导者通过运用其政治敏锐度来做到这一点。[7] Gerald Ferris 及其同事将**政治敏锐度**定义为“有效理解工作中他人的能力，并利用此类知识影响他人采取有利于个人和/或组织目标的行动”。[8] 因此，影响是通过建立和维护关系来实现的。Ferris 及其同事确定了构成政治敏锐度的四个组成部分：(1) 社交敏锐度，(2) 人际影响力，(3) 社交网络能力，(4) 表面真诚。

首先，社交敏锐度涉及仔细观察他人的能力，尤其是在社交场合。具有这种敏锐度的个人可以准确理解和解释涉及自身及他人的社交互动。此外，他们对自己以及自己在他人眼中的形象有着高度的自我意识。例如，一位具有社交敏锐度的领导者在社交聚会上会非常敏锐地观察谁在与谁交谈（例如，拥有最大正式权力的人正在与谁交谈），谁看起来在享受，谁感到无聊，等等。该领导者还会敏锐地察觉社交聚会上其他人对他/她的反应。

其次，政治娴熟的个人拥有实现人际影响的有说服力的方式。其中一些影响相对清晰且不那么微妙，例如试图澄清*以利交换*安排。但有时候，说服更加微妙，例如故作谦逊地奉承。此外，政治敏锐的领导者会针对不同的影响对象或情境条件表现出适应性或灵活性。例如，此类领导者可能意识到，某些影响对象需要非常明确和公开的*以利交换*理解，而另一些人则会认为此类影响尝试是操纵性的和令人反感的。

再次，社交网络与政治敏锐度密不可分。具有政治敏锐度的领导者理解网络的本质，并知道如何通过社交网络更好地为自身和组织定位以取得成功。换言之，他们认识到网络中的人掌握着完成事情所需的宝贵资源和联系。特别是，领导者可能在网络中担当或认识担当“经纪人”的人。[9] 经纪人是连接网络中其他个人的个人。例如，领导者可能认识到某位特定客户可以将领导者及其团队与另一位潜在客户连接起来。

此外，政治敏锐的领导者认识到*强*和*弱*关系之间的区别。[10] 强关系意味着更深层的关系或友谊，而弱关系更多是熟人关系。政治敏锐的领导者认识到，其网络中的并非所有联系都可以是强关系，因为与所有个人建立深层关系根本不可行，甚至并非可取。然而，认识并培养大量弱关系，尤其是与有影响力的人，对领导者来说很有用，因为它们有助于提供重要的联系或信息。换言之，强关系和弱关系对政治敏锐的领导者都很重要。

第四，政治敏锐的领导者擅长展现表面真诚。这里的“表面”一词至关重要。真正重要的是，领导者在他/她的人际关系和交易中表现得真诚。但随着时间的推移，如果领导者并非真正诚实和直率，其他人会看穿他/她，领导者将损害关系和影响力。也就是说，领导者可能会被视为操纵性。例如，一家全球银行正苦苦挣扎，任命了一位新领导者。起初，其他人认为他很有魅力。他是一位优秀的演说家，并热情地谈论员工和客户等人的重要性。起初，人们对该机构的大胆愿景感到兴奋和振奋。他声称时显得真诚。但随着时间的推移，很明显他只关心推进自己的事业。一年之内，员工反对他，感到被欺骗。最终，他完全没能扭转银行的局面，被取代了。

第 2 章中考虑的若干特质或特征与政治敏锐度之间存在联系。例如，诚实和正直（或至少表面上的诚实和正直）是领导者既具政治敏锐度又有效的重要特征。但随着时间的推移，如果领导者的“表面”真诚显得虚假或不一致，领导者会显得虚伪，从而失去影响力。以类似的方式，领导者可能显得在寻求个人权力，而非社会化权力。不可避免地，领导者试图影响的人不会对他/她的政治敏锐度尝试做出积极反应。另一个例子是，情商和政治敏锐度似乎密不可分。很难想象缺乏情商的领导者如何能够展现政治敏锐度。总之，第 2 章中考虑的特质与政治敏锐度的有效或无效运用密不可分。在第 4 节中，有一份调查可以帮助你评估自己的政治敏锐度。

## 结论

在本章中，我们考虑了关系建设和维护对领导者的重要性。有效的领导者需要通过领导-成员交换过程，持续展现与追随者的牢固关系。此外，他们还需要展现与非直属汇报人员的良好关系。他们通过政治敏锐度来做到这一点。

本章应当清楚的一点是，如前所述，“单手无法拍响。”追随者在领导过程中的作用常常被忽视或低估。然而，在第 4 章中，追随者的作用将受到重视。

### 3.3 讨论问题

- 1. 为什么有些追随者随时间推移倾向于加入领导者的内群体，而其他人则倾向于加入领导者的外群体？
- 2. 领导者可能会如何不同地对待内群体成员和外群体成员（基于第 2 章中描述的领导者行为类型）？

- 4. 还有一句古老的谚语“一个烂苹果会烂掉整筐苹果”。这句谚语与外群体的形成及其对整体团队的影响有何关联？
- 5. 可以采取什么措施来预防或纠正外群体的形成？请考虑领导者、追随者以及领导者和追随者所处的更广泛的组织环境（例如人力资源政策和程序）。
- 6. 请解释政治敏锐度为何对您作为领导者或仅仅是组织中的一名有效员工可能很重要。政治敏锐度仅仅是指“拍马屁”吗，还是还有更多内涵？
