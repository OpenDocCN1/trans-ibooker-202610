
# Appendix C. XPath Navigation and Selection

## Sample XML Document

```xml
<AddressBook>
  <Person contactType="Personal">
    <Name>Lee</Name>
    <Phone type="home">555-1212</Phone>
    <Phone type="work">555-1213</Phone>
  </Person>
  <Person contactType="Business">
    <Name>Ariel</Name>
    <Phone>555-1234</Phone>
  </Person>
</AddressBook>
```

## Table C-1. Navigation and Selection

| Syntax | Meaning |
|--------|---------|
| `/` | Represents the root of the XML tree. |
| `/Node` | Navigates to the node named `Node` from the root of the XML tree. |
| `/Node/*/Node2` | Navigates to the node named `Node2` via `Node`, allowing any single node in between. |
| `//Node` | Finds all nodes named `Node`, anywhere in the XML tree. |
| `..` | Retrieves the parent node of the given node. |
| `@Attribute` | Accesses the value of the attribute named `Attribute`. |

### Examples for Table C-1

**Root (`/`)**
```powershell
PS > $xml | Select-Xml "/" | Select -Expand Node

AddressBook
-----------
AddressBook
```

**Child node (`/AddressBook`)**
```powershell
PS > $xml | Select-Xml "/AddressBook" | Select -Expand Node

Person
------
{Lee, Ariel}
```

**Grandchild via wildcard (`/AddressBook/*/Name`)**
```powershell
PS > $xml | Select-Xml "/AddressBook/*/Name" | Select -Expand Node

#text
-----
Lee
Ariel
```

**Descendant (`//Phone`)**
```powershell
PS > $xml | Select-Xml "//Phone" | Select -Expand Node

type                                   #text
----                                   -----
home                                   555-1212
work                                   555-1213
                                       555-1234
```

**Parent (`..`)**
```powershell
PS > $xml | Select-Xml "//Phone" | Select -Expand Node

type                                  #text
----                                  -----
home                                  555-1212
work                                  555-1213
                                      555-1234

PS > $xml | Select-Xml "//Phone/.." | Select -Expand Node

contactType              Name             Phone
-----------              ----             -----
Personal                 Lee              {Phone, Phone}
Business                 Ariel            555-1234
```

**Attribute (`@type`)**
```powershell
PS > $xml | Select-Xml "//Phone/@type" | Select -Expand Node

#text
-----
home
work
```

## Table C-2. Comparisons

| Syntax | Meaning |
|--------|---------|
| `[ ]` | Filtering, similar to the `Where-Object` cmdlet. |
| `and` | Logical *and*. |
| `or` | Logical *or*. |
| `not()` | Logical *negation*. |
| `=` | *Equality*. |
| `!=` | *Inequality*. |

### Examples for Table C-2

**Filter by attribute (`//Person[@contactType = 'Personal']`)**
```powershell
PS > $xml | Select-Xml "//Person[@contactType = 'Personal']" |
    Select -Expand Node

contactType               Name              Phone
-----------               ----              -----
Personal                  Lee               {Phone, Phone}
```

**Filter by element value (`//Person[Name = 'Lee']`)**
```powershell
PS > $xml | Select-Xml "//Person[Name = 'Lee']" |
    Select -Expand Node

contactType               Name              Phone
-----------               ----              -----
Personal                  Lee               {Phone, Phone}
```

# Appendix D. .NET String Formatting

## String Formatting Syntax

The format string supported by the format (`-f`) operator is a string that contains format items. Each format item takes the form of:

```
{index[,alignment][:formatString]}
```

- `index` represents the zero-based index of the item in the object array following the format operator.
- `alignment` is optional and represents the alignment of the item. A positive number aligns the item to the right of a field of the specified width. A negative number aligns the item to the left of a field of the specified width.

```powershell
PS > ("{0,6}" -f 4.99), ("{0,6:##.00}" -f 15.9)
  4.99
 15.90
```

- `formatString` is optional and formats the item using that type's specific format string syntax (as laid out in [Table D-1](#table-d-1-standard-numeric-format-strings) and [Table D-2](#table-d-2-custom-numeric-format-strings)).

## Standard Numeric Format Strings

<a id="table-d-1-standard-numeric-format-strings"></a>
**Table D-1. Standard numeric format strings**

| Format specifier | Name | Description |
|------------------|------|-------------|
| `C` or `c` | Currency | A currency amount: |
| `D` or `d` | Decimal | A decimal amount (for integral types). The precision specifier controls the minimum number of digits in the result: |
| `E` or `e` | Scientific | Scientific (exponential) notation. The precision specifier controls the number of digits past the decimal point: |
| `F` or `f` | Fixed-point | Fixed-point notation. The precision specifier controls the number of digits past the decimal point: |
| `G` or `g` | General | The most compact representation (between fixed-point and scientific) of the number. The precision specifier controls the number of significant digits: |
| `N` or `n` | Number | The human-readable form of the number, which includes separators between number groups. The precision specifier controls the number of digits past the decimal point: |
| `P` or `p` | Percent | The number (generally between 0 and 1) represented as a percentage. The precision specifier controls the number of digits past the decimal point: |
| `R` or `r` | Roundtrip | The Single or Double number formatted with a precision that guarantees the string (when parsed) will result in the original number again: |
| `X` or `x` | Hexadecimal | The number converted to a string of hexadecimal digits. The case of the specifier controls the case of the resulting hexadecimal digits. The precision specifier controls the minimum number of digits in the resulting string: |

### Examples for Table D-1

**Currency (`C`)**
```powershell
PS > "{0:C}" -f 1.23
$1.23
```

**Decimal (`D`)**
```powershell
PS > "{0:D4}" -f 2
0002
```

**Scientific (`E`)**
```powershell
PS > "{0:E3}" -f [Math]::Pi
3.142E+000
```

**Fixed-point (`F`)**
```powershell
PS > "{0:F3}" -f [Math]::Pi
3.142
```

**General (`G`)**
```powershell
PS > "{0:G3}" -f [Math]::Pi
3.14

PS > "{0:G3}" -f 1mb
1.05E+06
```

**Number (`N`)**
```powershell
PS > "{0:N4}" -f 1mb
1,048,576.0000
```

**Percent (`P`)**
```powershell
PS > "{0:P4}" -f 0.67
67.0000 %
```

**Roundtrip (`R`)**
```powershell
PS > "{0:R}" -f (1mb/2.0)
524288

PS > "{0:R}" -f (1mb/9.0)
116508.44444444444
```

**Hexadecimal (`X`)**
```powershell
PS > "{0:X4}" -f 1324
052C
```

## Custom Numeric Format Strings

You can use custom numeric strings, listed in [Table D-2](#table-d-2-custom-numeric-format-strings), to format numbers in ways not supported by the standard format strings.

<a id="table-d-2-custom-numeric-format-strings"></a>
**Table D-2. Custom numeric format strings**

| Format specifier | Name | Description |
|------------------|------|-------------|
| `0` | Zero placeholder | Specifies the precision and width of a number string. Zeros not matched by digits in the original number are output as zeros: |
| `#` | Digit placeholder | Specifies the precision and width of a number string. `#` symbols not matched by digits in the input number are not output: |
| `.` | Decimal point | Determines the location of the decimal: |
| `,` | Thousands separator | When placed between a zero or digit placeholder before the decimal point in a formatting string, adds the separator character between number groups: |
| `,` | Number scaling | When placed before the literal (or implicit) decimal point in a formatting string, divides the input by 1,000. You can apply this format specifier more than once: |
| `%` | Percentage placeholder | Multiplies the input by 100, and inserts the percent sign where shown in the format specifier: |
| `E0`<br>`E+0`<br>`E-0`<br>`e0`<br>`e+0`<br>`e-0` | Scientific notation | |

### Examples for Table D-2

**Zero placeholder (`0`)**
```powershell
PS > "{0:00.0}" -f 4.12341234
04.1
```

**Digit placeholder (`#`)**
```powershell
PS > "{0:##.#}" -f 4.12341234
4.1
```

**Decimal point (`.`)**
```powershell
PS > "{0:##.#}" -f 4.12341234
4.1
```

**Thousands separator (`,`) **
```powershell
PS > "{0:#,#.#}" -f 1234.121234
1,234.1
```

**Number scaling (`,`) **
```powershell
PS > "{0:##,,.000}" -f 1048576
1.049
```

**Percentage placeholder (`%`)**
```powershell
PS > "{0:%##.000}" -f .68
%68.000
```
