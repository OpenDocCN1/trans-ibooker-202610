## 4.6 添加暂停或延迟

### 问题

你想暂停或延迟你的脚本或命令。

### 解决方案

要暂停直到用户按下 Enter 键，请使用 `pause` 命令：

```
PS > pause
Press Enter to continue...:
```

要暂停直到用户按下任意键，请对 `$host` 对象使用 `ReadKey()` 方法：

```
PS > $host.UI.RawUI.ReadKey()
```

要暂停脚本指定的时间量，请使用 `Start-Sleep` cmdlet：

```
PS > Start-Sleep 5
PS > Start-Sleep -Milliseconds 300
```

### 讨论

当你想暂停脚本直到用户按下键或设定的时间量时，`pause` 和 `Start-Sleep` 是你最可能使用的两个 cmdlet。

#### 注意

如果你想获取用户输入而不仅仅是暂停，`Read-Host` cmdlet 允许你从用户读取输入。更多信息，请参阅 [食谱 13.1](#ch13.xhtml#read_a_line_of_user_input)。

在其他情况下，你有时可能想在脚本中编写一个以恒定速度运行的循环——例如每分钟一次或每秒 30 次。这通常是一项困难的任务，因为循环中的命令可能会占用大量时间，甚至是不一致的时间量。

过去，许多电脑游戏因错误解决此问题而受影响。为控制游戏速度，游戏开发者添加命令以减慢游戏。例如，经过大量调整和摆弄，开发者可能会发现，如果让计算机每次更新屏幕时数到 100 万，游戏在典型机器上运行正常。不幸的是，这些命令（如计数）的速度高度依赖计算机速度。因为快速计算机数到 100 万比慢速计算机快得多，游戏最终在更快的计算机上运行得快得多（往往快到难以理解）！

要使循环以固定速度运行，你可以测量循环中命令完成所需的时间，然后延迟剩余的时间，如 [示例 4-1](#ch04.xhtml#running_a_loop_at_a_constant_speed) 所示。

#### 示例 4-1. 以恒定速度运行循环

```
$loopDelayMilliseconds = 650
while($true)
{
   $startTime = Get-Date

   ## Do commands here
   "Executing"

   $endTime = Get-Date
   $loopLength = ($endTime - $startTime).TotalMilliseconds
   $timeRemaining = $loopDelayMilliseconds - $loopLength

   if($timeRemaining -gt 0)
   {
      Start-Sleep -Milliseconds $timeRemaining
   }
}
```

有关 `Start-Sleep` cmdlet 的更多信息，请输入 `Get-Help Start-Sleep`。

# 第 5 章 字符串和非结构化文本

## 5.0 简介

创建和操作文本长期以来一直是脚本语言和传统 Shell 的主要任务之一。事实上，Perl（该语言）最初是作为一个简单（但有用）的文本处理工具而设计的。它已远远超越了这些卑微的起源，但其流行度有力地证明了它满足的需求。

在基于文本的 Shell 中，这种强烈的关注持续存在。当你与系统的大多数交互通过操作程序的基于文本的输出发生时，强大的文本处理实用程序变得至关重要。这些文本解析工具，如 `awk`、`sed` 和 `grep`，构成了基于文本的系统管理的基石。

在 PowerShell 的基于对象的环境中，这种传统工具链的作用不那么关键。你可以通过其他 PowerShell 命令更有效地完成以前需要这些工具的大多数任务。然而，作为基于对象的 Shell 并不意味着 PowerShell 放弃了对文本处理的所有支持。处理字符串和非结构化文本在系统管理员的生活中仍然扮演重要角色。由于 PowerShell 让你能以全保真度（使用 cmdlet 和对象）管理系统的大部分，文本处理工具可以再次专注于实际的文本处理任务。

## 5.1 创建字符串

### 问题

你想创建一个保存文本的变量。

### 解决方案

使用 PowerShell 字符串变量作为存储和处理文本的方式。

要定义支持变量扩展和转义字符的字符串，请用双引号将其括起来：

```
$myString = "Hello World"
```

要定义字面量字符串（即不解释变量扩展或转义字符的字符串），请用单引号将其括起来：

```
$myString = 'Hello World'
```

### 讨论

字符串字面量有两种类型：*字面量*（*非扩展*）和*扩展*字符串。要创建字面量字符串，请在文本周围放置单引号（`$myString = 'Hello World'`）。要创建扩展字符串，请在文本周围放置双引号（`$myString = "Hello World"`）。

在字面量字符串中，单引号之间的所有文本都成为字符串的一部分。在扩展字符串中，PowerShell 会将变量名（如 `$replacementString`）和转义序列（如 `` `n ``）扩展为其值（分别为 `$replacementString` 的内容和换行符）。

有关 PowerShell 字符串中转义序列和替换规则的详细解释，请参阅 [“字符串”](#app01.xhtml#strings)。

“字面量字符串中的所有文本都是字面量”这一规则的一个例外来自引号字符本身。在任一类型的字符串中，PowerShell 都允许你将该字符串的两个引号字符放在一起以添加引号字符本身：

```
$myString = "This string includes ""double quotes"" because it combined quote characters."
$myString = 'This string includes ''single quotes'' because it combined quote characters.'
```

这有助于防止当你尝试在单引号字符串中包含单引号时出现的转义惨剧。例如：

```
$myString = 'This string includes ' + "'" + 'single quotes' + "'"
```

#### 注意

此示例展示了 PowerShell 通过将其他字符串相加来创建新字符串是多么容易。这是在脚本中构建格式化报表的一种吸引人的方式，但应谨慎使用。由于 .NET Framework（因此 PowerShell）管理字符串的方式，以这种方式向大字符串末尾添加信息会导致明显的性能问题。如果你打算创建大型报表，请参阅 [食谱 5.16](#ch05.xhtml#generate_large_reports_and_text_streams)。

## 5.2 创建多行或格式化字符串

### 问题

你想创建一个包含换行符或其他显式格式的文本变量。

### 解决方案

使用 PowerShell *here string* 来存储和处理包含换行符和其他格式信息的文本。

```
$myString = @"
This is the first line
of a very long string. A "here string"
lets you create blocks of text
that span several lines.
"@
```

### 讨论

当 PowerShell 看到字符 `@"` 后跟换行符时，开始一个 here string。当它看到单独一行上的字符 `"@` 时，结束该字符串。这些看似奇怪的限制让你能够创建包含引号字符、换行符和其他符号的字符串，这些符号在创建大块预格式化文本时常用。

#### 注意
