# 6.5 使用管理常量简化数学运算

## 问题

你想要处理常见的管理数字（即千字节、兆字节、吉字节、太字节和拍字节），而不必记住或计算这些数字。

## 解决方案

使用 PowerShell 的管理常量 `KB`、`MB`、`GB`、`TB` 和 `PB` 来帮助处理这些常见数字。

例如，我们可以计算以每秒 215 千字节的速度下载 10.18 兆字节文件所需的时间（以秒为单位）：

```
PS > 10.18mb / 215kb
48.4852093023256
```

## 讨论

PowerShell 的管理常量基于 2 的幂，因为这是处理计算机时最常用的类型。每个常量比前一个大 1,024 倍：

```
1kb = 1024
1mb = 1024 * 1 kb
1gb = 1024 * 1 mb
1tb = 1024 * 1 gb
1pb = 1024 * 1 tb
```

有些人（如硬盘制造商）倾向于将基于 2 的幂的数字称为“千字节”、“兆字节”和“吉字节”。他们用“千字节”、“兆字节”和“吉字节”表示基于 10 的幂的数字——即每个比前一个大 1,000 倍的数字。

虽然管理常量不表示这些数字，但 PowerShell 仍然可以轻松处理基于 10 的幂的数字——例如，计算 Windows 报告的“300 GB”硬盘实际有多大。为此，请使用科学（指数）表示法：

```
PS > $kilobyte = 1e3
PS > $kilobyte
1000

PS > $megabyte = 1e6
PS > $megabyte
1000000

PS > $gigabyte = 1e9
PS > $gigabyte
1000000000

PS > (300 * $gigabyte) / 1GB
279.396772384644
```

# 6.6 在不同进制间转换数字

## 问题

你想要将数字转换为不同的进制。

## 解决方案

PowerShell 脚本语言允许你直接输入十进制和十六进制数字。它不原生支持其他进制，但其对 .NET Framework 交互的支持可实现二进制、八进制、十进制和十六进制之间的双向转换。

要将十六进制数字转换为十进制表示，请在数字前加上 `0x` 前缀：

```
PS > $myErrorCode = 0xFE4A
PS > $myErrorCode
65098
```

要将二进制数字转换为十进制表示，请在前面加上 `0b` 前缀：

```
PS > 0b10011010010
1234
```

如果你有字符串形式的值，可以向 `[Convert]::ToInt32()` 方法提供 `2` 作为基数：

```
PS > [Convert]::ToInt32("10011010010", 2)
1234
```

要将八进制数字转换为十进制表示，请向 `[Convert]::ToInt32()` 方法提供 `8` 作为基数：

```
PS > [Convert]::ToInt32("1234", 8)
668
```

要将数字转换为十六进制表示，请使用 `[Convert]` 类或 PowerShell 的格式运算符：

```
PS > ## 使用 [Convert] 类
PS > [Convert]::ToString(1234, 16)
4d2

PS > ## 使用格式运算符
PS > "{0:X4}" -f 1234
04D2
```

如果你有一个想要转换为十六进制表示的大字节数组，可以使用 `BitConverter` 类：

```
PS > $bytes = Get-Content hello_world.txt -AsByteStream
PS > [System.BitConverter]::ToString($bytes).Replace("-","")
FFFE480065006C006C006F00200057006F0072006C006400200031000D000A00
```

要将数字转换为二进制表示，请向 `[Convert]::ToString()` 方法提供 `2` 作为基数：

```
PS > [Convert]::ToString(1234, 2)
10011010010
```

要将数字转换为八进制表示，请向 `[Convert]::ToString()` 方法提供 `8` 作为基数：

```
PS > [Convert]::ToString(1234, 8)
2322
```

## 讨论

当你处理表示数据二进制组合的数字（如文件属性）时，最常需要在不同进制间转换数字。有关如何处理此类二进制数据的更多信息，请参阅[食谱 6.4](#ch06.xhtml#work_with_numbers_as_binary)。

# 第 7 章 列表、数组和哈希表

# 7.0 简介

大多数脚本处理的不止一件事——服务器列表、文件列表、查找代码等。为了实现这一点，PowerShell 通过其语言特性和实用 cmdlet 提供了许多功能来帮助你完成这些任务。

PowerShell 让处理数组和列表就像处理其他数据类型一样：你可以轻松创建数组或列表，然后添加或删除元素。你也可以同样轻松地对其进行排序、搜索或与另一个数组合并。当你想要存储一条数据到另一条数据的映射时，哈希表完美满足该需求。

# 7.1 创建项目数组或列表

## 问题

你想要创建一个项目数组或列表。

## 解决方案

要创建一个包含给定项目集的数组，请用逗号分隔这些项目：

```
PS > $myArray = 1,2,"Hello World"
PS > $myArray
1
2
Hello World
```

要创建特定大小的数组，请使用 `New-Object` cmdlet：

```
PS > $myArray = New-Object string[] 10
PS > $myArray[5] = "Hello"
PS > $myArray[5]
Hello
```

要创建特定类型的数组，请使用强类型集合：

```
PS > $list = New-Object Collections.Generic.List[Int]
PS > $list.Add(10)
PS > $list.Add("Hello")
无法转换参数 "0"，其值为: "Hello"，用于 "Add" 类型 "System.Int32": "无法将值 "Hello" 转换为类型 "System.Int32"。错误: "输入字符串的格式不正确。""
```

要存储生成列表的命令的输出，请使用变量赋值：
