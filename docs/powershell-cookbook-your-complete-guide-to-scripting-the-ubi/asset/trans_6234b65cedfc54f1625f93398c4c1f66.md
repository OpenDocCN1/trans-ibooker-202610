
## 2.5 PipelineVariable 参数

为了解决这个问题，PowerShell 支持 `-PipelineVariable` 参数。当你向命令添加此参数时，PowerShell 会将命令的当前管道输出保存到你指定的变量名中，除了 `$_` 变量之外。此时你可以在其他嵌套脚本块中自由使用它，而不必担心它被覆盖：

```powershell
## Get all processes
Get-Process -PipelineVariable currentProcess | ForEach-Object {
    ## Get all of their modules (loaded DLLs)
    $_.Modules | ForEach-Object {
        ## If the DLL is loaded from AppData
        if ($_.FileName -match 'AppData') {
            ## Output the process name
            $currentProcess
        }
    } | Select-Object -First 1
}
```

`ForEach-Object` Cmdlet 并非对列表中的项目执行操作的唯一方式。PowerShell 脚本语言还支持其他几个关键字，例如 `for`、（另一种）`foreach`、`do` 和 `while`。有关如何使用这些关键字的信息，请参阅 [Recipe 4.4](#ch04.xhtml#repeat_operations_with_loops)。

有关 `ForEach-Object` Cmdlet 的更多信息，请输入 `Get-Help ForEach-Object`。

有关在自己的脚本、函数和脚本块中处理管道输入的更多信息，请参阅 [Recipe 11.18](#ch11.xhtml#access_pipeline_input)。

# 2.6 自动化数据密集型任务

## 问题

你想要在大量数据上调用一个简单任务。

## 解决方案

如果只有一项数据发生变化（例如服务器名称或用户名），请将数据存储在文本文件中。使用 `Get-Content` Cmdlet 检索项目，然后使用 `ForEach-Object` Cmdlet（具有标准别名 `foreach` 和 `%`）来处理列表中的每个项目。[示例 2-3](#ch02.xhtml#using_information_from_a_text_file_to_au) 演示了此技术。

### 示例 2-3. 使用文本文件中的信息自动化数据密集型任务

```powershell
PS > Get-Content servers.txt
SERVER1
SERVER2
PS > $computers = Get-Content servers.txt
PS > $computers | ForEach-Object {
     Get-CimInstance Win32_OperatingSystem -Computer $_ }

SystemDirectory : C:\WINDOWS\system32
Organization    :
BuildNumber     : 19041
Version         : 10.0.19041

SystemDirectory : C:\WINDOWS\system32
Organization    :
BuildNumber     : 19041
Version         : 10.0.19041
```

如果在 `ForEach-Object` Cmdlet 中包含操作变得繁琐（或不清晰），你也可以使用 `foreach` 脚本关键字，如 [示例 2-4](#ch02.xhtml#using_the_foreach_scripting_keyword_to_m) 所示。

### 示例 2-4. 使用 foreach 脚本关键字使循环语句更易读

```powershell
$computers = Get-Content servers.txt

foreach ($computer in $computers)
{
    ## Get the information about the operating system from WMI
    $system = Get-CimInstance Win32_OperatingSystem -Computer $computer

    ## Determine if it is running Windows XP
    if ($system.Version -match "^10.")
    {
        "$computer is running Windows 10"
    }
}
```

如果每个任务有多个数据方面发生变化（例如，大型报告中计算机的 CIM 类和计算机名称均发生变化），请创建一个 CSV 文件，每个任务占一行。使用 `Import-Csv` Cmdlet 将该数据导入 PowerShell，然后使用生成对象的属性作为多个相关数据源。[示例 2-5](#ch02.xhtml#using_information_from_a_csv_to_automate) 演示了此技术。

### 示例 2-5. 使用 CSV 中的信息自动化数据密集型任务

```powershell
PS > Get-Content WmiReport.csv
ComputerName,Class
LEE-DESK,Win32_OperatingSystem
LEE-DESK,Win32_Bios

PS > $data = Import-Csv WmiReport.csv
PS > $data

ComputerName                          Class
------------                          -----
LEE-DESK                              Win32_OperatingSystem
LEE-DESK                              Win32_Bios

PS > $data |
    ForEach-Object { Get-CimInstance $_.Class -Computer $_.ComputerName }

Organization    :

```

## 讨论

PowerShell 的主要优势之一是其自动化重复任务的能力。有时这些重复任务是操作密集型的（例如通过注册表和文件清理进行系统维护），并由始终一起调用的复杂命令序列组成。在这种情况下，你可以编写脚本来组合这些操作，以节省时间并减少错误。

其他时候，你只需要完成单个任务（例如检索 WMI 查询结果），但需要为大量数据重复调用该任务。在这种情况下，PowerShell 的脚本语句、管道支持和数据管理 Cmdlet 有助于自动化这些任务。

解决方案中给出的选项之一是 `Import-Csv` Cmdlet。`Import-Csv` Cmdlet 读取 CSV 文件，并为每一行自动创建一个对象，其属性对应于列名。[示例 2-6](#ch02.xhtml#the_import-csv_cmdlet_creating_objects_w) 显示了包含 `ComputerName` 和 `Class` 标题的 CSV 的结果。

### 示例 2-6. Import-Csv Cmdlet 创建具有 ComputerName 和 Class 属性的对象

```powershell
PS > $data = Import-Csv WmiReport.csv
PS > $data

ComputerName                         Class
------------                         -----
LEE-DESK                             Win32_OperatingSystem
LEE-DESK                             Win32_Bios

PS > $data[0].ComputerName
LEE-DESK
```

正如解决方案所示，你可以使用 `ForEach-Object` Cmdlet 将这些对象中的数据提供给重复的 Cmdlet 调用。它通过指定每个参数名称，后跟适用于该参数的数据（取自当前 CSV 对象的属性）来实现这一点。

> **注意**
>
> 如果你已经在变量中拥有逗号分隔的值（而不是文件），可以使用 `ConvertFrom-Csv` Cmdlet 将这些值转换为对象。

虽然这是最通用的解决方案，但许多 Cmdlet 参数可以自动从传入对象中检索其值，前提是该对象的任何属性具有相同的名称。这使你可以完全省略 `ForEach-Object` 和属性映射步骤。支持此功能的参数被称为支持 *按属性名从管道获取值*。`Move-Item` Cmdlet 就是一个支持此功能的参数示例，正如 [示例 2-7](#ch02.xhtml#help_content_of_the_move-item_showing_a_) 中的 `Accept pipeline input?` 行所示。

### 示例 2-7. Move-Item Cmdlet 的帮助内容，显示接受按属性名从管道获取值的参数
