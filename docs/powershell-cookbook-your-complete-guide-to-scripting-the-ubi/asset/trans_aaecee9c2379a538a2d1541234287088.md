
```
PS > $errorActionPreference = "Continue"
PS > trap { "Caught an error"; continue }; Get-WarningsAndErrors
WARNING: Warning: About to generate an error
Get-WarningsAndErrors: Error: You are running this script
Caught an error
```

在 `catch` 块或 `trap` 语句中，`$_`（或 `$PSItem`）变量代表正在处理的当前异常或错误。

与 `try` 语句不同，`trap` 语句处理定义它的作用域中发生的任何终止错误。有关作用域的更多信息，请参阅 [食谱 3.6](#ch03.xhtml#control_access_and_scope_of_variables_an)。

### 注意

处理错误后，您还可以通过输入 `$error.RemoveAt(0)` 将其从系统的错误集合中移除。

有关 PowerShell 自动变量的更多信息，请输入 `Get-Help about_automatic_variables`。有关 PowerShell 中错误管理的更多信息，请参阅 [“管理错误”](#app01.xhtml#managing_errors)。有关这些首选项变量有效设置的更详细信息，请参阅 [附录 A](#app01.xhtml#powershell_language_and_environment)。

# 15.7 输出警告、错误和终止错误

## 问题

您希望脚本通知其调用者有关警告、错误或终止错误的信息。

## 解决方案

要输出警告和错误，请分别使用 `Write-Warning` 和 `Write-Error` cmdlet。使用 `throw` 语句生成终止错误。

## 讨论

当您需要通知脚本调用者有关异常情况时，`Write-Warning`、`Write-Error` 和 `throw` 语句是实现此目的的方法。如果您的用户应将该消息视为警告，请使用 `Write-Warning` cmdlet。如果您的脚本遇到错误（但可以合理地继续执行），请使用 `Write-Error` cmdlet。如果错误是致命的，且您的脚本根本无法继续，请使用 `throw` 语句。

有关生成这些错误以及处理其他脚本抛出的错误的更多信息，请参阅 [食谱 15.6](#ch15.xhtml#handle_warnings_errors_and_terminating_e)。有关 PowerShell 中错误管理的更多信息，请参阅 [“管理错误”](#app01.xhtml#managing_errors)。有关运行脚本的更多信息，请参阅 [食谱 1.2](#ch01.xhtml#run_programs_scripts_and_existing_tools)。

## 问题

您有一个交互式或耗时的脚本，想要查看哪些部分拖慢了它的速度。

## 解决方案

从 PowerShell 库安装 `PSProfiler` 模块，并使用 `Measure-Script` 命令查看脚本中消耗时间最多的行。在本示例中，我们正在调查 `burn-console-original.ps1`，这是一个有趣的小脚本，可在 PowerShell 控制台中显示类似演示场景的火焰效果：

PS > $profileData = Measure-Script (Get-Command burn-console-original.ps1).Path

    26    61    00:01.4885363 updateScreen

## 讨论

当您编写的脚本导致用户或其他系统等待结果时，您有时会觉得脚本的性能可以得到改进。

解决性能问题的第一条规则是测量问题。除非您能用硬性的性能数据指导优化工作，否则您几乎肯定是在错误的地方浪费精力。随意的微小性能改进会迅速将您的代码变成难以阅读的混乱局面，通常却没有明显的性能提升！低级优化有其用武之地，但应始终由支持它的硬性数据指导。

# 第 16 章 环境感知

## 16.0 简介

虽然您的许多脚本设计为独立工作，但您经常会发现，为脚本提供其执行环境的信息很有帮助：其名称、当前工作目录、环境变量、常见系统路径等。

PowerShell 提供了多种获取此信息的方式——从其 cmdlet 和内置变量到它从 .NET Framework 提供的功能。

## 16.1 查看和修改环境变量

### 问题

您想要与系统的环境变量进行交互。

### 解决方案

要与环境变量交互，请以几乎与访问常规 PowerShell 变量相同的方式访问它们。唯一的区别是您在美元符号 ($) 和变量名之间放置 `env:`：

```
PS > $env:Username
Lee
```

您也可以通过这种方式修改环境变量。例如，要临时将当前目录添加到路径中：

```
PS > Invoke-DemonstrationScript
Invoke-DemonstrationScript.ps1: The term 'Invoke-DemonstrationScript.ps1' is not
recognized as a name of a cmdlet, function, script file, or executable program.
Check the spelling of the name, or if a path was included, verify that the path
is correct and try again.

Suggestion [3,General]: The command Invoke-DemonstrationScript.ps1 was not found,
but does exist in the current location. PowerShell does not load commands from
the current location by default. If you trust this command, instead type:
".\Invoke-DemonstrationScript.ps1". See "get-help about_Command_Precedence"
for more details.

PS > $env:PATH = $env:PATH + ".;"
PS > Invoke-DemonstrationScript
The script ran!
```

### 讨论
