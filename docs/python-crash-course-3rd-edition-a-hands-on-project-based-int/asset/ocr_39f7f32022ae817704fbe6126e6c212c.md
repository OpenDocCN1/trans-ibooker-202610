# Using Fixtures

In *test_survey.py*, we created a new instance of `AnonymousSurvey` in each test function. This is fine in the short example we’re working with, but in a real-world project with tens or hundreds of tests, this would be problematic.

In testing, a *fixture* helps set up a test environment. Often, this means creating a resource that’s used by more than one test. We create a *fixture* in pytest by writing a function with the decorator `@pytest.fixture`.
