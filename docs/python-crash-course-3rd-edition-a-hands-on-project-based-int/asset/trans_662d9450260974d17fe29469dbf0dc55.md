## 第三版前言

《Python 编程：从入门到实践》第一版和第二版获得了极为热烈的反响。目前印量已超过一百万册，包括 10 多种语言的译本。我收到了来自年仅 10 岁的读者以及希望在空闲时间学习编程的退休人员的信件和电子邮件。《Python 编程：从入门到实践》正在中学和高中以及大学课堂中使用。被指定使用更高级教科书的学生，也将本书作为课堂辅助教材，并认为它是值得的补充。人们用它来提升工作技能、转换职业，并开始自己的副业项目。简而言之，人们使用这本书的目的涵盖了我当初希望的全部范围，甚至更多。

有机会撰写《Python 编程：从入门到实践》第三版，我感到非常愉快。尽管 Python 是一种成熟的语言，但它仍在像所有语言一样不断演进。我修订本书的主要目标是使其继续保持一门精心策划的 Python 入门课程。通过阅读这本书，你将学到开始自己项目所需的一切，并为你未来的所有学习打下坚实基础。我更新了一些章节，以反映 Python 中更新、更简单的做法。我还澄清了一些部分，这些部分中对语言某些细节的表述本可以更准确。所有项目都已完全更新，使用了广受欢迎且维护良好的库，你可以放心地用它们来构建自己的项目。

以下是第三版所做具体更改的摘要：

第 1 章现在以文本编辑器 VS Code 为特色，它在初学者和专业程序员中都很受欢迎，并且在所有操作系统上都能良好运行。

第 2 章包含新方法 `removeprefix()` 和 `removesuffix()`，在处理文件和 URL 时非常有用。本章还介绍了 Python 新改进的错误消息，这些消息提供了更具体的信息，帮助你在出现问题时排查代码。

第 10 章使用 `pathlib` 模块来处理文件。这是一种更简单的读写文件的方法。

第 11 章使用 `pytest` 为你编写的代码编写自动化测试。pytest 库已成为 Python 中编写测试的行业标准工具。它足够友好，可用于你的第一次测试，如果你以 Python 程序员为职业，你也将在专业环境中使用它。

第 12–14 章的《外星人入侵》项目包含一个控制帧率的设置，这使得游戏在不同操作系统上运行更一致。构建外星人舰队采用了更简单的方法，项目的整体组织结构也得到了清理。

第 15–17 章的数据可视化项目使用了 Matplotlib 和 Plotly 的最新功能。Matplotlib 可视化具有更新的样式设置。随机漫步项目有一项小改进，提高了绘图的准确性，这意味着每次生成新的漫步时，你都会看到更多样的模式出现。所有使用 Plotly 的项目现在都使用 Plotly Express 模块，只需几行代码即可生成初始可视化。你可以轻松地尝试各种可视化方式，然后再确定一种图表类型，并专注于完善该图表的各个细节。

第 18–20 章的“学习日志”项目使用最新版本的 Django 构建，并使用最新版本的 Bootstrap 进行样式设置。项目的部分内容已重新命名，以便更容易理解项目的整体组织。该项目现已部署到 Platform.sh，这是一个面向 Django 项目的现代托管服务。部署过程由 YAML 配置文件控制，这让你对项目的部署方式拥有很大的控制权。这种方法与专业程序员部署现代 Django 项目的方式一致。

附录 A 已全面更新，推荐了在所有主要操作系统上安装 Python 的当前最佳实践。附录 B 包含设置 VS Code 的详细说明，以及当前使用的大多数主要文本编辑器和 IDE 的简要描述。附录 C 指导读者访问几个最受欢迎的在线帮助资源。附录 D 继续提供使用 Git 进行版本控制的迷你速成课程。附录 E 是第三版全新增加的。即使有部署所创建应用的详细说明，仍有许多可能出错的地方。本附录提供了一份详细的故障排除指南，供你在部署过程第一次不成功时使用。

索引已全面更新，以便你可以将《Python 编程：从入门到实践》用作未来所有 Python 项目的参考。
