
例如，如果你在 *python_work* 文件夹中有一个配置文件，这些设置只会影响该文件夹（及其子文件夹）中的文件。这是一个很好的功能，因为这意味着你可以拥有覆盖全局设置的项目特定设置。

## 使用制表符和空格

如果你在代码中混用制表符和空格，可能会导致程序中难以诊断的问题。在安装了 Python 扩展的情况下处理 *.py* 文件时，VS Code 被配置为每当你按下 TAB 键时插入四个空格。如果你只编写自己的代码，并且安装了 Python 扩展，你很可能永远不会遇到制表符和空格的问题。

然而，你的 VS Code 安装可能没有正确配置。此外，在某个时候，你可能会处理一个只有制表符或混用制表符和空格的文件。如果你怀疑制表符和空格有任何问题，请查看 VS Code 窗口底部的状态栏，并点击 **空格** 或 **制表符大小**。将出现一个下拉菜单，让你可以在使用制表符和使用空格之间切换。你还可以更改默认缩进级别，并将文件中的所有缩进转换为制表符或空格。

如果你正在查看某些代码，不确定缩进是由制表符还是空格组成，请选中几行代码。这将使不可见的空白字符变得可见。每个空格将显示为一个点，每个制表符将显示为一个箭头。

> **注意**
>
> *在编程中，空格优于制表符，因为空格可以被处理代码文件的所有工具无歧义地解释。制表符的宽度可能被不同工具以不同方式解释，这会导致极其难以诊断的错误。*

## 更改颜色主题

VS Code 默认使用深色主题。如果你想更改这一点，请点击 **文件**（macOS 菜单栏中的 **代码**），然后点击 **首选项**，并选择 **颜色主题**。将出现一个下拉列表，让你选择一个适合你的主题。

## 设置行长度指示器

大多数编辑器允许你设置一个视觉提示，通常是一条垂直线，以显示你的行应该在哪里结束。在 Python 社区中，惯例是将行限制在 79 个字符或更少。

要设置此功能，请点击 **代码**，然后点击 **首选项**，然后选择 **设置**。在出现的对话框中，输入 **标尺**。你会看到一个用于编辑器：标尺的设置；点击标有 *在 settings.json 中编辑* 的链接。在出现的文件中，将以下内容添加到 `editor.rulers` 设置中：

**settings.json**

```json
"editor.rulers": [
  80,
]
```

这将在编辑窗口的 80 字符位置添加一条垂直线。你可以有多条垂直线；例如，如果你想要在 120 字符处再添加一条线，你的设置值将是 `[80, 120]`。如果你看不到垂直线，请确保你保存了设置文件；在某些系统上，你可能还需要退出并重新打开 VS Code 才能使更改生效。

## 简化输出

默认情况下，VS Code 在嵌入式终端窗口中显示程序的输出。此输出包括用于运行文件的命令。在许多情况下，这是理想的，但当你刚开始学习 Python 时，它可能比你想要的更分散注意力。

为了简化输出，请关闭 VS Code 中打开的所有标签页，然后退出 VS Code。再次启动 VS Code，并打开包含你正在处理的 Python 文件的文件夹；这可以只是保存了 *hello_world.py* 的 *python_work* 文件夹。

点击运行/调试图标（看起来像一个带小虫子的三角形），然后点击 **创建 *launch.json* 文件**。在出现的提示中选择 Python 选项。在打开的 *launch.json* 文件中，进行以下更改：

**launch.json**

```json
{
    --snip--
    "configurations": [
        {
            --snip--
            "console": "internalConsole",
            "justMyCode": true
        }
    ]
}
```

保存设置文件后，打开一个 .py 文件，例如 *hello_world.py*，然后按 CTRL-F5 运行它。在 VS Code 的输出面板中，点击 **调试控制台**（如果尚未选中）。你应该只看到程序的输出，并且每次运行程序时输出都会刷新。

> **注意**
>
> *调试控制台是只读的。它不适用于使用 `input()` 函数的文件，你将在第 7 章开始使用该函数。当你需要运行这些程序时，你可以将 `console` 设置改回默认的 `integratedTerminal`，或者像第 11 页“从终端运行 Python 程序”中描述的那样，在单独的终端窗口中运行这些程序。*

## 探索更多自定义选项

你可以通过多种方式自定义 VS Code，以帮助你更高效地工作。要开始探索可用的自定义选项，请点击 **代码**，然后点击 **首选项**，然后选择 **设置**。你会看到一个标题为“常用”的列表；点击任何子标题，即可看到一些修改 VS Code 安装的常见方法。花一些时间看看是否有任何让你更好地使用 VS Code 的功能，但不要沉迷于配置编辑器，以至于推迟学习如何使用 Python！

## *VS Code 快捷键*

所有编辑器和 IDE 都提供了高效的方法来完成编写和维护代码时每个人都需要做的常见任务。例如，你可以轻松缩进单行代码或整个代码块；你也可以轻松地将一个代码块在文件中上下移动。

这里无法完整描述所有快捷键。本节将分享一些在你编写第一批 Python 文件时可能会觉得有用的快捷键。如果你最终使用的编辑器不是 VS Code，请确保你学会如何在你选择的编辑器中高效地完成这些相同的任务。

### 缩进和取消缩进代码块

要缩进整个代码块，请选中它并按 CTRL-]，在 macOS 上按 ⌘-]。要取消缩进一个代码块，请选中它并按 CTRL-[，在 macOS 上按 ⌘-[。

### 注释掉代码块

要临时禁用一段代码，你可以选中该代码块并注释它，这样 Python 就会忽略它。选中你想忽略的代码部分，然后按 CTRL-/，在 macOS 上按 ⌘-/。选中的行将被注释掉，并使用与代码行相同缩进级别的井号标记（#），以表明这些不是常规注释。当你想要取消注释该代码块时，选中该代码块并重新发出相同的命令。

### 向上或向下移动行

随着你的程序变得越来越复杂，你可能会发现你想在文件内向上或向下移动一个代码块。要做到这一点，请选中你想移动的代码，然后按 ALT-上箭头，在 macOS 上按 Option-上箭头。使用相同的按键组合配合下箭头会将代码块在文件中向下移动。

如果你要移动单行，你可以点击该行的任意位置；你不需要选中整行来移动它。

### 隐藏文件资源管理器

VS Code 中的集成文件资源管理器非常方便。然而，在你编写代码时，它可能会分散注意力，并在较小的屏幕上占用宝贵的空间。CTRL-B 命令（在 macOS 上为 ⌘-B）可以切换文件资源管理器面板的可见性。

### 查找其他快捷键

在编辑环境中高效工作需要练习，但也需要用心。当你学习使用代码时，试着注意你反复做的事情。你在编辑器中执行的任何操作都可能有快捷键；如果你通过点击菜单项来执行编辑任务，请查找这些操作的快捷键。如果你经常在键盘和鼠标之间切换，请查找那些能让你不必频繁伸手去拿鼠标的导航快捷键。

你可以通过点击 **代码**，然后点击 **首选项**，然后选择 **键盘快捷键** 来查看 VS Code 中的所有键盘快捷键。你可以使用搜索栏查找特定快捷键，或者滚动列表以找到可能帮助你更高效工作的快捷键。

请记住，最好专注于你正在处理的代码，避免在使用的工具上花费太多时间。
