
*IDLE* 是 Python 自带的一款文本编辑器。与其他更现代的编辑器相比，它的操作不太直观。不过，你会在其他面向初学者的教程中看到关于它的介绍，因此不妨试一试。

### Geany

*Geany* 是一款简单的文本编辑器，它会将所有输出显示在独立的终端窗口中，这有助于你熟悉终端的使用。Geany 的界面非常简洁，但其功能足以让相当多经验丰富的程序员仍在使用它。

如果你觉得 VS Code 太过分散注意力、功能过多，可以考虑改用 Geany。

### Sublime Text

*Sublime Text* 是另一款极简风格的编辑器。如果你觉得 VS Code 过于繁杂，可以考虑使用它。Sublime Text 拥有非常简洁的界面，并且以即使在处理超大文件时也能流畅运行而闻名。它是一款不会妨碍你、让你专注于所写代码的编辑器。

Sublime Text 提供无限期的免费试用，但它并非免费或开源软件。如果你决定喜欢它并且有能力购买完整许可证，就应该购买。购买是一次性付费，而不是软件订阅。

### Emacs 和 Vim

*Emacs* 和 *Vim* 是许多经验丰富的程序员青睐的两款流行编辑器，因为它们的设计让你无需将双手离开键盘即可使用。一旦你学会了这些编辑器的操作方式，编写、阅读和修改代码会变得非常高效。这也意味着这两款编辑器都有相当陡峭的学习曲线。Vim 预装在大多数 Linux 和 macOS 系统中，而且 Emacs 和 Vim 都可以完全在终端内运行。因此，它们常被用于通过远程终端会话在服务器上编写代码。

程序员们常常会推荐你尝试它们，但许多熟练的程序员忘记了新手程序员已经有太多东西要学了。了解这些编辑器是好事，但你应该暂缓使用它们，直到你能熟练地在更友好的编辑器中处理代码，让你专注于学习编程，而不是学习使用编辑器。

### PyCharm

*PyCharm* 是 Python 程序员中流行的 IDE，因为它是专门为 Python 而构建的。完整版需要付费订阅，但也有一个名为 PyCharm 社区版的免费版本，许多开发者觉得它很有用。

如果你尝试使用 PyCharm，请注意，默认情况下它会为你的每个项目设置一个隔离环境。这通常是好事，但如果你不了解它为你做了什么，可能会导致意想不到的行为。

### Jupyter Notebooks

*Jupyter Notebook* 是一种与传统文本编辑器或 IDE 不同的工具，它是一个主要由块组成的 Web 应用；每个块要么是代码块，要么是文本块。文本块以 Markdown 渲染，因此你可以在文本块中包含简单的格式。

Jupyter Notebooks 最初是为了支持 Python 在科学应用中的使用而开发的，但此后其应用范围已扩展到各种场景。你不仅可以在 `.py` 文件中编写注释，还可以在代码段之间编写带有简单格式的清晰文本，例如标题、项目符号列表和超链接。每个代码块都可以独立运行，让你能够测试程序的小片段，也可以一次性运行所有代码块。每个代码块都有独立的输出区域，你可以根据需要打开或关闭这些输出区域。

由于不同单元格之间的交互，Jupyter Notebooks 有时会让人感到困惑。如果你在一个单元格中定义了一个函数，该函数在其他单元格中也可用。这在大多数情况下是有益的，但在较长的笔记本中，或者当你没有完全理解 Notebook 环境的工作方式时，可能会造成混淆。

如果你使用 Python 进行任何科学或数据处理相关的工作，你几乎一定会遇到 Jupyter Notebooks。

## C 获取帮助

![](img/8f15563c16d2a98c4d3115150679b092_760_0.png)

每个人在学习编程时都会在某一点遇到困难。因此，作为程序员，最重要的技能之一就是如何高效地摆脱困境。本附录概述了几种方法，帮助你在编程遇到困惑时重新上路。

### 第一步

当你遇到困难时，第一步应该是评估自己的情况。在向其他人求助之前，请清晰地回答以下三个问题：

- 你试图做什么？
- 到目前为止你尝试了什么？
- 你得到了什么结果？

请尽量让你的回答具体明确。对于第一个问题，像“我正在尝试在我的新 Windows 笔记本电脑上安装最新版本的 Python”这样的明确陈述，其详细程度足以让 Python 社区的其他人帮助你。像“我正在尝试安装 Python”这样的陈述则无法提供足够的信息让他人提供多少帮助。

你对第二个问题的回答应提供足够的细节，这样你才不会被告知去重复你已经尝试过的事情：“我访问了 https://python.org/downloads，点击了适用于我系统的下载按钮，然后运行了安装程序”比“我访问了 Python 网站，下载了一些东西”更有帮助。

对于第三个问题，知道你收到的确切错误消息会很有帮助，这样你可以用它们在网上搜索解决方案，或者在求助时提供这些信息。

有时，在你向他人求助之前，仅仅回答这三个问题就能让你看到自己遗漏的东西，并帮助你摆脱困境，而无需进行下去。程序员甚至为此取了个名字：橡皮鸭调试法。这个想法是，如果你向一只橡胶鸭（或任何无生命物体）清晰地说明你的情况，并提出一个具体问题，你往往能自己回答自己的问题。一些编程团队甚至会放一只真正的橡胶鸭，以鼓励人们“和鸭子说话”。

### 再试一次

仅仅回到起点再试一次，就足以解决许多问题。假设你正尝试根据本书中的示例编写一个 for 循环。你可能只是遗漏了一些简单的东西，比如 for 行末尾的冒号。再次逐步操作可能会帮助你避免重蹈覆辙。

搜索确切的错误消息也非常有用。例如，假设你在新的 Windows 系统上从终端运行一个 Python 程序时收到以下错误：

```
> python hello_world.py
Python was not found; run without arguments to install from the Microsoft Store...
```

搜索完整短语“Python was not found; run without arguments to install from the Microsoft Store”可能会得到一些好建议。

当你开始搜索编程相关主题时，有几个网站会反复出现。我将简要介绍其中一些网站，以便你了解它们可能有多大帮助。

### Stack Overflow

*Stack Overflow* ([https://stackoverflow.com](https://stackoverflow.com)) 是程序员中最受欢迎的问答网站之一，它经常出现在 Python 相关搜索结果的首页上。成员们在遇到困难时发布问题，其他成员则尽力提供有用的回答。用户可以为他们觉得最有帮助的回答投票，因此最好的答案通常是你最先找到的那些。

许多基础的 Python 问题在 Stack Overflow 上都有非常清晰的答案，因为社区一直在不断完善它们。用户也被鼓励发布更新，因此回答往往能保持相对时新。在撰写本文时，Stack Overflow 上已经回答了近两百万个与 Python 相关的问题。
