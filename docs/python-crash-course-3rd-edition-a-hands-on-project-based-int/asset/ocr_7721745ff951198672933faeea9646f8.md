The *c* argument is similar to *color*, but it’s used to associate a sequence of values with a color mapping. We pass the list of *y*-values to *c*, and then tell *pyplot* which colormap to use with the *cmap* argument. This code colors the points with lower *y*-values light blue and the points with higher *y*-values dark blue. [Figure 15-8](Figure 15-8) shows the resulting plot.
