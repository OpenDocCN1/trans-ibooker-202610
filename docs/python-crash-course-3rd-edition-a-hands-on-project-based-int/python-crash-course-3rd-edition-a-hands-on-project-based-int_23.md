## 文本编辑器和 IDE

![](img/8f15563c16d2a98c4d3115150679b092_748_0.png)

程序员会花费大量时间编写、阅读和编辑代码，因此使用文本编辑器或 IDE（集成开发环境）来尽可能高效地完成这项工作至关重要。一个好的编辑器会处理一些简单任务，比如高亮代码结构，让你在工作中发现常见错误。但它不会做太多事情，以免分散你的思考。编辑器还具有一些有用的功能，如自动缩进、显示合适行长的标记，以及常见操作的键盘快捷键。

*IDE* 是一种文本编辑器，但包含了大量其他工具，如交互式调试器和代码自省功能。IDE 会在你输入代码时检查代码，并尝试了解你正在构建的项目。例如，当你开始键入函数名时，IDE 可能会显示该函数接受的所有参数。当一切正常并且你理解所看到的内容时，这种行为会非常有用。但作为初学者，它也可能令人不知所措，并且在你不确定为什么代码在 IDE 中无法运行时，会难以排查问题。

如今，文本编辑器和 IDE 之间的界限已经模糊。大多数流行的编辑器都拥有一些曾经专属于 IDE 的功能。同样，大多数 IDE 也可以配置为以更轻量的模式运行，从而减少工作时的干扰，但在需要时仍可使用更高级的功能。

如果你已经安装了自己喜欢的编辑器或 IDE，并且它已经配置好，可以配合系统中安装的最新 Python 版本使用，那么我建议你继续使用你熟悉的工具。探索不同的编辑器可能很有趣，但这也是一种逃避学习新语言工作的方式。

如果你还没有安装编辑器或 IDE，我推荐 VS Code，原因如下：

- 它是免费的，并根据开源许可证发布。
- 它可以安装在所有主要操作系统上。
- 它对初学者友好，但也足够强大，许多专业程序员将其作为主要编辑器。
- 它能找到你已安装的 Python 版本，并且通常不需要任何配置即可运行你的第一个程序。

它有一个集成终端，因此你的输出会显示在与代码相同的窗口中。

有一个 Python 扩展可用，它能让编辑器在编写和维护 Python 代码时非常高效。

它的可定制性很强，因此你可以调整它以适应自己的代码工作方式。

在本附录中，你将学习如何开始配置 VS Code，使其适合你。你还将学到一些能让你更高效工作的快捷键。打字速度快并不像许多人想象的那么重要，但了解你的编辑器并懂得如何高效地使用它则非常有帮助。

话虽如此，VS Code 并不适合所有人。如果它由于某种原因在你的系统上运行不佳，或者在工作时让你分心，那么还有其他许多编辑器可能会更吸引你。本附录包含一些你应该考虑的其他编辑器和 IDE 的简要介绍。

## 高效使用 VS Code

在第 1 章中，你安装了 VS Code 并添加了 Python 扩展。本节将向你展示一些可以进行的进一步配置，以及高效处理代码的快捷键。

## 配置 VS Code

更改 VS Code 默认配置设置的方法有几种。有些更改可以通过界面完成，有些则需要修改配置文件。这些更改有时会影响到你在 VS Code 中执行的所有操作，而其他更改只会影响包含配置文件的文件夹内的文件。




例如，如果你在 *python_work* 文件夹中有一个配置文件，这些设置只会影响该文件夹（及其子文件夹）中的文件。这是一个很好的功能，因为这意味着你可以拥有覆盖全局设置的项目特定设置。

## 使用制表符和空格

如果你在代码中混用制表符和空格，可能会导致程序中难以诊断的问题。在安装了 Python 扩展的情况下处理 *.py* 文件时，VS Code 被配置为每当你按下 TAB 键时插入四个空格。如果你只编写自己的代码，并且安装了 Python 扩展，你很可能永远不会遇到制表符和空格的问题。

然而，你的 VS Code 安装可能没有正确配置。此外，在某个时候，你可能会处理一个只有制表符或混用制表符和空格的文件。如果你怀疑制表符和空格有任何问题，请查看 VS Code 窗口底部的状态栏，并点击 **空格** 或 **制表符大小**。将出现一个下拉菜单，让你可以在使用制表符和使用空格之间切换。你还可以更改默认缩进级别，并将文件中的所有缩进转换为制表符或空格。

如果你正在查看某些代码，不确定缩进是由制表符还是空格组成，请选中几行代码。这将使不可见的空白字符变得可见。每个空格将显示为一个点，每个制表符将显示为一个箭头。

> **注意**
>
> *在编程中，空格优于制表符，因为空格可以被处理代码文件的所有工具无歧义地解释。制表符的宽度可能被不同工具以不同方式解释，这会导致极其难以诊断的错误。*

## 更改颜色主题

VS Code 默认使用深色主题。如果你想更改这一点，请点击 **文件**（macOS 菜单栏中的 **代码**），然后点击 **首选项**，并选择 **颜色主题**。将出现一个下拉列表，让你选择一个适合你的主题。

## 设置行长度指示器

大多数编辑器允许你设置一个视觉提示，通常是一条垂直线，以显示你的行应该在哪里结束。在 Python 社区中，惯例是将行限制在 79 个字符或更少。

要设置此功能，请点击 **代码**，然后点击 **首选项**，然后选择 **设置**。在出现的对话框中，输入 **标尺**。你会看到一个用于编辑器：标尺的设置；点击标有 *在 settings.json 中编辑* 的链接。在出现的文件中，将以下内容添加到 `editor.rulers` 设置中：

**settings.json**

```json
"editor.rulers": [
  80,
]
```

这将在编辑窗口的 80 字符位置添加一条垂直线。你可以有多条垂直线；例如，如果你想要在 120 字符处再添加一条线，你的设置值将是 `[80, 120]`。如果你看不到垂直线，请确保你保存了设置文件；在某些系统上，你可能还需要退出并重新打开 VS Code 才能使更改生效。

## 简化输出

默认情况下，VS Code 在嵌入式终端窗口中显示程序的输出。此输出包括用于运行文件的命令。在许多情况下，这是理想的，但当你刚开始学习 Python 时，它可能比你想要的更分散注意力。

为了简化输出，请关闭 VS Code 中打开的所有标签页，然后退出 VS Code。再次启动 VS Code，并打开包含你正在处理的 Python 文件的文件夹；这可以只是保存了 *hello_world.py* 的 *python_work* 文件夹。

点击运行/调试图标（看起来像一个带小虫子的三角形），然后点击 **创建 *launch.json* 文件**。在出现的提示中选择 Python 选项。在打开的 *launch.json* 文件中，进行以下更改：

**launch.json**

```json
{
    --snip--
    "configurations": [
        {
            --snip--
            "console": "internalConsole",
            "justMyCode": true
        }
    ]
}
```

保存设置文件后，打开一个 .py 文件，例如 *hello_world.py*，然后按 CTRL-F5 运行它。在 VS Code 的输出面板中，点击 **调试控制台**（如果尚未选中）。你应该只看到程序的输出，并且每次运行程序时输出都会刷新。

> **注意**
>
> *调试控制台是只读的。它不适用于使用 `input()` 函数的文件，你将在第 7 章开始使用该函数。当你需要运行这些程序时，你可以将 `console` 设置改回默认的 `integratedTerminal`，或者像第 11 页“从终端运行 Python 程序”中描述的那样，在单独的终端窗口中运行这些程序。*

## 探索更多自定义选项

你可以通过多种方式自定义 VS Code，以帮助你更高效地工作。要开始探索可用的自定义选项，请点击 **代码**，然后点击 **首选项**，然后选择 **设置**。你会看到一个标题为“常用”的列表；点击任何子标题，即可看到一些修改 VS Code 安装的常见方法。花一些时间看看是否有任何让你更好地使用 VS Code 的功能，但不要沉迷于配置编辑器，以至于推迟学习如何使用 Python！

## *VS Code 快捷键*

所有编辑器和 IDE 都提供了高效的方法来完成编写和维护代码时每个人都需要做的常见任务。例如，你可以轻松缩进单行代码或整个代码块；你也可以轻松地将一个代码块在文件中上下移动。

这里无法完整描述所有快捷键。本节将分享一些在你编写第一批 Python 文件时可能会觉得有用的快捷键。如果你最终使用的编辑器不是 VS Code，请确保你学会如何在你选择的编辑器中高效地完成这些相同的任务。

### 缩进和取消缩进代码块

要缩进整个代码块，请选中它并按 CTRL-]，在 macOS 上按 ⌘-]。要取消缩进一个代码块，请选中它并按 CTRL-[，在 macOS 上按 ⌘-[。

### 注释掉代码块

要临时禁用一段代码，你可以选中该代码块并注释它，这样 Python 就会忽略它。选中你想忽略的代码部分，然后按 CTRL-/，在 macOS 上按 ⌘-/。选中的行将被注释掉，并使用与代码行相同缩进级别的井号标记（#），以表明这些不是常规注释。当你想要取消注释该代码块时，选中该代码块并重新发出相同的命令。

### 向上或向下移动行

随着你的程序变得越来越复杂，你可能会发现你想在文件内向上或向下移动一个代码块。要做到这一点，请选中你想移动的代码，然后按 ALT-上箭头，在 macOS 上按 Option-上箭头。使用相同的按键组合配合下箭头会将代码块在文件中向下移动。

如果你要移动单行，你可以点击该行的任意位置；你不需要选中整行来移动它。

### 隐藏文件资源管理器

VS Code 中的集成文件资源管理器非常方便。然而，在你编写代码时，它可能会分散注意力，并在较小的屏幕上占用宝贵的空间。CTRL-B 命令（在 macOS 上为 ⌘-B）可以切换文件资源管理器面板的可见性。

### 查找其他快捷键

在编辑环境中高效工作需要练习，但也需要用心。当你学习使用代码时，试着注意你反复做的事情。你在编辑器中执行的任何操作都可能有快捷键；如果你通过点击菜单项来执行编辑任务，请查找这些操作的快捷键。如果你经常在键盘和鼠标之间切换，请查找那些能让你不必频繁伸手去拿鼠标的导航快捷键。

你可以通过点击 **代码**，然后点击 **首选项**，然后选择 **键盘快捷键** 来查看 VS Code 中的所有键盘快捷键。你可以使用搜索栏查找特定快捷键，或者滚动列表以找到可能帮助你更高效工作的快捷键。

请记住，最好专注于你正在处理的代码，避免在使用的工具上花费太多时间。

## 其他文本编辑器和 IDE

你会听说并看到人们使用许多其他文本编辑器。它们中的大多数都可以配置成与自定义 VS Code 相同的方式来帮助你。以下是一些你可能会听说的文本编辑器。

### *IDLE*



*IDLE* 是 Python 自带的一款文本编辑器。与其他更现代的编辑器相比，它的操作不太直观。不过，你会在其他面向初学者的教程中看到关于它的介绍，因此不妨试一试。

### Geany

*Geany* 是一款简单的文本编辑器，它会将所有输出显示在独立的终端窗口中，这有助于你熟悉终端的使用。Geany 的界面非常简洁，但其功能足以让相当多经验丰富的程序员仍在使用它。

如果你觉得 VS Code 太过分散注意力、功能过多，可以考虑改用 Geany。

### Sublime Text

*Sublime Text* 是另一款极简风格的编辑器。如果你觉得 VS Code 过于繁杂，可以考虑使用它。Sublime Text 拥有非常简洁的界面，并且以即使在处理超大文件时也能流畅运行而闻名。它是一款不会妨碍你、让你专注于所写代码的编辑器。

Sublime Text 提供无限期的免费试用，但它并非免费或开源软件。如果你决定喜欢它并且有能力购买完整许可证，就应该购买。购买是一次性付费，而不是软件订阅。

### Emacs 和 Vim

*Emacs* 和 *Vim* 是许多经验丰富的程序员青睐的两款流行编辑器，因为它们的设计让你无需将双手离开键盘即可使用。一旦你学会了这些编辑器的操作方式，编写、阅读和修改代码会变得非常高效。这也意味着这两款编辑器都有相当陡峭的学习曲线。Vim 预装在大多数 Linux 和 macOS 系统中，而且 Emacs 和 Vim 都可以完全在终端内运行。因此，它们常被用于通过远程终端会话在服务器上编写代码。

程序员们常常会推荐你尝试它们，但许多熟练的程序员忘记了新手程序员已经有太多东西要学了。了解这些编辑器是好事，但你应该暂缓使用它们，直到你能熟练地在更友好的编辑器中处理代码，让你专注于学习编程，而不是学习使用编辑器。

### PyCharm

*PyCharm* 是 Python 程序员中流行的 IDE，因为它是专门为 Python 而构建的。完整版需要付费订阅，但也有一个名为 PyCharm 社区版的免费版本，许多开发者觉得它很有用。

如果你尝试使用 PyCharm，请注意，默认情况下它会为你的每个项目设置一个隔离环境。这通常是好事，但如果你不了解它为你做了什么，可能会导致意想不到的行为。

### Jupyter Notebooks

*Jupyter Notebook* 是一种与传统文本编辑器或 IDE 不同的工具，它是一个主要由块组成的 Web 应用；每个块要么是代码块，要么是文本块。文本块以 Markdown 渲染，因此你可以在文本块中包含简单的格式。

Jupyter Notebooks 最初是为了支持 Python 在科学应用中的使用而开发的，但此后其应用范围已扩展到各种场景。你不仅可以在 `.py` 文件中编写注释，还可以在代码段之间编写带有简单格式的清晰文本，例如标题、项目符号列表和超链接。每个代码块都可以独立运行，让你能够测试程序的小片段，也可以一次性运行所有代码块。每个代码块都有独立的输出区域，你可以根据需要打开或关闭这些输出区域。

由于不同单元格之间的交互，Jupyter Notebooks 有时会让人感到困惑。如果你在一个单元格中定义了一个函数，该函数在其他单元格中也可用。这在大多数情况下是有益的，但在较长的笔记本中，或者当你没有完全理解 Notebook 环境的工作方式时，可能会造成混淆。

如果你使用 Python 进行任何科学或数据处理相关的工作，你几乎一定会遇到 Jupyter Notebooks。
