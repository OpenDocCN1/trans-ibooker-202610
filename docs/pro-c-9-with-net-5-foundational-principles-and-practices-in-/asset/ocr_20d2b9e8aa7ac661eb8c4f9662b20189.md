# Splitting Queries on Related Data

The more joins added into a LINQ query, the more complex the resulting query becomes. New in EF Core 5 is the ability to run complicated joins as split queries. Refer to the previous chapter for the full discussion, but to sum it up, adding the AsSplitQuery() method into the LINQ query instructs EF Core to split the call to the database into multiple calls. This can gain efficiency at the risk of data inconsistency. Add the following test to your test fixture:

```
[Fact]

{

        .Include(c => c.MakeNavigation)
        .Include(c => c.Orders).ThenInclude(o => o.CustomerNavigation)
        .AsSplitQuery();
    var cars = query.ToList();
    Assert.Equal(4, cars.Count);
    cars.ForEach(c =>
    {
        Assert.NotNull(c.MakeNavigation);
        Assert.NotNull(c.Orders.ToList()[0].CustomerNavigation);
    });
}
```
