# Create and Configure the Solution

Now that you have a background in some of the major concepts in ASP.NET Core, it’s time to start building the ASP.NET Core applications. The ASP.NET Core projects can be created using either Visual Studio or the command line. Both options will be covered in the next two sections.

# Using Visual Studio

Visual Studio has the advantage of a GUI to step you through the process of creating a solution and projects, adding NuGet packages, and creating references between projects.

# Create the Solution and Projects

Start by creating a new project in Visual Studio. Select the C# template ASP.NET Core Web Application from the “Create a new project” dialog. In the “Configure your new project” dialog, enter AutoLot.Api for the project name and AutoLot for the solution name, as shown in Figure 29-1.
