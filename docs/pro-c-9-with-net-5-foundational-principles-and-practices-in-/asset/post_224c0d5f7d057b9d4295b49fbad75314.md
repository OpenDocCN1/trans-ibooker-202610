## HTML Helpers

The HTML helpers from ASP.NET MVC are still supported, and there are some that are still used extensively. Table 31-5 lists those helpers still commonly used.

Table 31-5. Commonly Used HTML Helpers

| HTML Helper | Use |
|---|---|
| Html.DisplayFor() | Displays an object defined by the expression |
| Html.DisplayForModel() | Displays the model using the default template or a custom template |
| Html.DisplayNameFor() | Gets the Display name if it exists or the property name in the absence of a Display name |
| Html.EditorFor() | Displays an editor for an object defined by the expression |
| Html.EditorForModel() | Displays an editor for the model using the default template or a custom template |

## The DisplayFor HTML Helper

The DisplayFor() helper displays an object defined by an expression. If there is a display template for the type being displayed, then it will be used to create the HTML for the item. For example, if a view’s model is the Car entity, the Make information for that Car can be displayed using this:

```
@Html.DisplayFor(x=>x.MakeNavigation);
```

If a view named Make.cshtml exists in the DisplayTemplates folder, then that view will be used to render the values (remember that the template name lookup is based on the type of an object, and not its property name). If there is a view named ShowMake.cshtml (for example), it can be used to render the object with the following call:

```
@Html.DisplayFor(x=>x.MakeNavigation, "ShowMake");
```

If a template isn’t specified and there isn’t a template for the class name, reflection is used to create the HTML for display.

## The DisplayForModel HTML Helper

The DisplayForModel() helper displays the model for the view. If there is a display template for the type being displayed, then it will be used to create the HTML for the item. Continuing with the previous example of a view with the Car entity as its model, the entire Car information can be displayed using this:

```
@Html.DisplayForModel();
```

Just like the DisplayFor() helper, if a display template named for the type exists, it will be used. Named templates can also be used. For example, to display the Car with the CarWithColors.html display template, use the following call:

```
@Html.DisplayForModel("CarWithColors");
```

If a template isn’t specified and there isn’t a template for the class name, reflection is used to create the HTML for display.

## The EditorFor and EditorForModel HTML Helpers

The EditorFor() and EditorForModel() helpers function the same as their corresponding display helpers. The difference is that templates are searched in the EditorTemplates directory and HTML editors are displayed instead of a read-only representation of the object.

## Managing Client-Side Libraries

Before finishing the views, it’s time to update the client-side libraries (CSS and JavaScript). The LibraryManager project (originally built by Mads Kristensen) is now part of Visual Studio (VS2019) and also available as a .NET Core global tool. LibraryManager uses a simple JSON file to pull CSS and JavaScript tools from CDNJS.com, UNPKG.com, JSDeliver, or the file system.

## Install Library Manager As a .NET Core Global Tool

Library Manager is now built into Visual Studio. To install it as a .NET Core global tool, enter the following command:

```
dotnet tool install --global Microsoft.Web.LibraryManager.Cli --version 2.1.113
```

The current version can be found at https://www.nuget.org/packages/Microsoft.Web.LibraryManager.Cli/.

## Add Client-Side Libraries to AutoLot.Mvc

When the AutoLot.Mvc project was created (using either Visual Studio or the .NET Core CLI), several JavaScript and CSS files were installed into the wwwroot\lib folder. Delete the entire lib folder and all of the files contained, as Library Manager will replace all of them.
