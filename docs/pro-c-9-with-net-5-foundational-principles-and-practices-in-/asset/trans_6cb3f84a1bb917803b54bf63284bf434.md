## 第 IV 部分：高级 C# 编程

本书的这一部分将通过引导您了解许多更高级（但重要）的概念来加深您对 C# 语言的理解。在这里，您将通过研究集合和泛型来完成对 .NET Core 类型系统的考察。您还将考察 C# 的许多更高级功能（例如，扩展方法、运算符重载、匿名类型和指针操作）。然后您将考察委托和 lambda 表达式，对语言集成查询进行首次了解，并以两章内容结束本节，这两章重点关注进程和多线程/异步编程。

### 第 10 章：集合和泛型

本章探讨 *泛型* 主题。正如您将看到的，泛型编程为您提供了一种创建包含各种 *占位符* 的类型和类型成员的方法，这些占位符可以由调用方指定。简而言之，泛型大大增强了应用程序性能和类型安全。您不仅将探索 `System.Collections.Generic` 命名空间中的各种泛型类型，而且还将学习如何构建自己的泛型方法和类型（有约束和无约束）。

### 第 11 章：高级 C# 语言功能

本章通过向您介绍许多高级编程技术来加深您对 C# 编程语言的理解。在这里，您将学习如何重载运算符并为您的类型创建自定义转换例程（隐式和显式）。您还将学习如何构建和交互类型索引器，以及如何使用扩展方法、匿名类型、局部方法以及在不安全代码上下文中使用 C# 指针。

### 第 12 章：委托、事件和 Lambda 表达式

本章的目的是揭开委托类型的神秘面纱。简单来说，.NET Core 委托是一个指向应用程序中其他方法的对象。使用此类型，您可以构建允许多个对象进行双向对话的系统。在您考察了 .NET Core 委托的使用之后，您将被介绍到 C# `event` 关键字，您可以使用它来简化原始委托编程的操作。您将通过研究 C# lambda 运算符（`=>`）的作用以及委托、匿名方法和 lambda 表达式之间的联系来结束本章。

### 第 13 章：LINQ to Objects

本章开始您对语言集成查询（LINQ）的考察。LINQ 允许您构建可应用于多种 LINQ 目标以以最广泛意义上的“数据”进行操作的数据的强类型查询表达式。在这里，您将了解 LINQ to Objects，它允许您将 LINQ 表达式应用于数据容器（例如，数组、集合和自定义类型）。这些信息将在您在本书其余部分遇到许多其他 LINQ API 时为您提供很大帮助。

### 第 14 章：进程、AppDomains 和加载上下文

现在您对程序集有了扎实的理解，本章深入探讨加载的 .NET Core 可执行文件的组成。本章的目标是说明进程、应用程序域和上下文边界之间的关系。这些主题为第 15 章提供了适当的基础，在第 15 章中，您将考察多线程应用程序的构建。

### 第 15 章：多线程、并行和异步编程

本章考察如何构建多线程应用程序，并说明您可用于编写线程安全代码的许多技术。本章首先重新审视 .NET 委托类型，以确保解释委托对异步方法调用的固有支持。接下来，您将研究 `System.Threading` 命名空间中的类型。下一节涵盖任务并行库（TPL）。使用 TPL，.NET 开发人员可以以极其简单的方式构建跨所有可用 CPU 分布其工作负载的应用程序。此时，您还将了解并行 LINQ 的作用，它提供了一种创建跨多台机器核心扩展的 LINQ 查询的方法。本章其余部分涵盖使用 C# 5 中引入的 `async`/`await` 关键字创建非阻塞调用；使用 C# 7 中新增的局部函数和广义异步返回类型；以及使用 C# 8 中引入的异步流。

## 第 V 部分：使用 .NET Core 程序集编程

第 V 部分深入探讨 .NET Core 程序集格式的细节。您不仅将学习如何部署和配置 .NET Core 代码库，而且还将了解 .NET Core 二进制映像的内部组成。本节解释 .NET Core 属性的作用、运行时解析类型信息的作用以及动态语言运行时（DLR）和 C# `dynamic` 关键字的作用。最后一章涵盖通用中间语言（CIL）的语法和动态程序集的作用。

### 第 16 章：构建和配置类库

从高层次来看，程序集是指使用 .NET Core 编译器创建的二进制文件的术语。然而，.NET Core 程序集的真实故事远比这丰富。在这里，您将学习如何构建和部署程序集，并了解类库与控制台应用程序之间的区别，以及 .NET Core 类库与 .NET Standard 类库之间的区别。最后一节涵盖 .NET 5 中可用的新选项，例如单文件可执行文件和即时运行发布。

### 第 17 章：类型反射、后期绑定和基于属性的编程

本章通过检查使用 `System.Reflection` 命名空间进行运行时类型发现的过程，继续您对 .NET Core 程序集的考察。使用该命名空间的类型，您可以构建能够即时读取程序集元数据的应用程序。您还将学习如何使用后期绑定在运行时动态加载和创建类型。本章的最后一个主题将探讨 .NET Core 属性（标准和自定义）的作用。为了说明这些主题的实用性，本章向您展示如何构建一个可扩展的应用程序，其中包含即插组件。

### 第 18 章：动态类型和动态语言运行时

.NET 4.0 引入了 .NET 运行时环境的一个新方面，称为动态语言运行时。使用 DLR 和 C# `dynamic` 关键字，您可以定义直到运行时才真正解析的数据。使用这些功能可将一些复杂的 .NET Core 编程任务大大简化。在本章中，您将学习动态数据的一些实际用途，包括如何以精简的方式利用 .NET Core 反射 API，以及如何以最少的麻烦与旧版 COM 库进行通信。
