Now that all of the pieces are in place, the GiveBonus() method can be updated based on the pay type of the employee. Commissioned employees get 10% of the bonus, hourly get the equivalent of 40 hours of the prorated bonus, and salaried get the entered amount. The updated GiveBonus() method is listed here:

```
public void GiveBonus(float amount)
{
    Pay = this switch
    {
        {PayType: EmployeePayTypeEnum.Commission } => Pay += .10F * amount,
        {PayType: EmployeePayTypeEnum.Hourly } => Pay += 40F * amount/2080F,
        {PayType: EmployeePayTypeEnum.Salaried } => Pay += amount,
        _ => Pay+=0
    };
}
```

As with other switch statements that use pattern matching, either there must be a catchall case statement or the switch statement must throw an exception if none of the case statements is met.
