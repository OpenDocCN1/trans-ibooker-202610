There are additional options to explore with owned entities, including collections, table splitting, and nesting. These are all beyond the scope of this book. To find out more information, consult the EF Core documentation on owned entities here: https://docs.microsoft.com/en-us/ef/core/modeling/owned-entities.

# Database Function Mapping

SQL Server functions can be mapped to C# methods and be included in LINQ statements. The C# method is merely a placeholder as the server function gets folded into the generated SQL for the query. Support for table-valued function mapping has been added in EF Core to the already existing support for scalar function mapping. For more information on database function mapping, consult the documentation: https://docs.microsoft.com/en-us/ef/core/querying/user-defined-function-mapping.

# The EF Core Global Tool CLI Commands

The dotnet-ef global CLI tool EF Core tooling contains the commands needed to scaffold existing databases into code, to create/remove database migrations, and to operate on a database (update, drop, etc.). Before you can use the dotnet-ef global tooling, it must be installed with the following command (if you were following along earlier in this chapter, you’ve already done this):

```
dotnet tool install --global dotnet-ef --version 5.0.1
```

> Note Because EF Core 5 is not a Long Term Supported release, to use the EF Core 5 global tools, you must specify a version.

To test the install, open a command prompt and enter the following command:

dotnet ef
