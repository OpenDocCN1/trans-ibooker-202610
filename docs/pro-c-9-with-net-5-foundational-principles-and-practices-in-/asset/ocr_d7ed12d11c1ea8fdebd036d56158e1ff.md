# Add the XML Documentation File

.NET Core can generate an XML documentation file from your project by examining methods for triple-slash (///) comments. To enable this functionality using Visual Studio, right-click the AutoLot.Api project and open the Properties window. Select the Build page, check the XML documentation file check box, and enter AutoLot.Api.xml for the filename. Also, enter 1591 in the “Suppress warnings” text box, as shown in Figure 30-3.
