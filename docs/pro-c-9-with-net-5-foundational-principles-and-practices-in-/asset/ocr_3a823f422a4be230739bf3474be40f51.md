# Connecting to SQL Server in a Docker Container

To connect to your SQL Server instance running in a Docker container, first make sure it is up and running. Next, click “Create a connection” in Azure Data Studio, as shown in Figure 21-3.

![](bbox=[0.07, 0.192, 0.895, 0.508])

Figure 21-3. Creating a connection in Azure Data Studio

In the Connection Details dialog, enter „5433" for the Server value. The dot indicates the current host, and the ,5433 is the port that you indicated when creating the SQL Server instance in the Docker container. Enter sa for the username; and the password is the same one that you entered when creating the SQL Server instance. The name is optional but allows you to quickly select this connection in subsequent Azure Data Studio sessions. Figure 21-4 shows these connection options.
