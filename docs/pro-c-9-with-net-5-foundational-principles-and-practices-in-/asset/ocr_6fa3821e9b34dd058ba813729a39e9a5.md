# The Create Action Methods

The create process uses two action methods: one (HTTP Get) to return a blank view for input of the new record and one (HTTP Put) to submit the values of the new record.

# The GetMakes Helper Method

The GetMakes() helper method returns the list of Make records into a SelectList. It takes an instance of the IMakeRepo as a parameter.

```
internal SelectList GetMakes(IMakeRepo makeRepo)
    => new SelectList(makeRepo.GetAll(), nameof(Make.Id), nameof(Make.Name));
```

# The Create Get Method

The Create() HTTP Get action method adds a SelectList of Make records to the ViewData dictionary and then gets a single car by Id and sends it to the Create view.

```
[HttpGet]
public IActionResult Create([FromServices] IMakeRepo makeRepo)
{
    ViewData["MakeId"] = GetMakes(makeRepo);
    return View();
}
```
