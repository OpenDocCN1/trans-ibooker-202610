## 引言

### 我们是一个包括你的团队

技术作者为一群要求很高的人写作（出于最好的可能原因）。你知道，使用任何平台或语言构建软件解决方案都极其复杂，并且特定于你的部门、公司、客户群和主题领域。也许你从事电子出版行业，为州或地方政府开发系统，或在 NASA 或军方分支机构工作。

我们集体在各种行业工作过，包括开发儿童教育软件（Oregon Trail/Amazon Trail）、各种企业系统，以及医疗和金融行业项目。你在工作场所编写的代码几乎 100% 的可能性与我们多年来编写的代码无关。

因此，在本书中，我们刻意避免创建将示例代码与特定行业或编程分支绑定的演示。鉴于此，我们使用行业无关的示例来解释 C#、OOP、.NET 运行时和 .NET Core 基础类库。与其让每个示例都填充网格数据、计算工资单或某些其他特定领域的任务，我们坚持使用我们都能理解的主题：汽车（再加上一些几何结构和员工工资系统以锦上添花）。而这就是你发挥作用的地方。

我们的工作是尽可能最好地解释 C# 编程语言和 .NET 5 平台的核心方面。此外，我们将尽一切努力为你在本书结尾继续学习提供所需的工具和策略。

你的工作是获取这些信息并将其应用于你的特定编程任务。我们显然理解你的项目很可能不围绕带有友好宠物名称的汽车（例如 Zippy the BMW 或一辆名为 Clunker 的 Yugo 等），但这就是应用知识的全部！

请放心，一旦你理解了本文本中介绍的主题和概念，你将处于完美的位置来构建映射到你自己独特编程环境的 .NET 5 解决方案。

### 本书概述

*Pro C# 9 with .NET 5* 在逻辑上分为八个不同的部分，每个部分包含若干相关章节。以下是逐部分和逐章节的文本分解。

### 第一部分：介绍 C# 和 .NET 5

第一部分的目的在于让你熟悉 .NET 5 平台的性质以及在构建 .NET 5 应用程序时使用的各种开发工具。

#### 第 1 章：介绍 C# 和 .NET（Core）5

本第一章是整本书的骨干。本章的主要目标是让你熟悉许多以 .NET Core 为中心的构建块，例如通用语言运行时（CLR）、通用类型系统（CTS）、通用语言规范（CLS）和基础类库（BCL）。在这里，你将初步了解 C# 编程语言、命名空间和 .NET 5 程序集格式。

#### 第 2 章：构建 C# 应用程序

本章的目标是向你介绍编译 C# 源代码文件的过程。在安装 .NET 5 SDK 和运行时后，你将了解完全免费（且功能齐全）的 Visual Studio Community 版本以及极受欢迎（同样免费）的 Visual Studio Code。你将学习如何使用 Visual Studio 和 Visual Studio Code 创建、运行和调试 .NET 5 C# 应用程序。

### 第二部分：核心 C# 编程

本书这一部分介绍的主题非常重要，因为无论你打算开发哪种类型的 .NET 5 软件（例如 Web 应用程序、桌面 GUI 应用程序、代码库、服务等），你都将使用它们。在这里，你将学习 .NET 5 的基本数据类型，处理文本操作，并学习各种 C# 参数修饰符的作用（包括可选和命名参数）。

#### 第 3 章：核心 C# 编程结构，第 1 部分

本章开始你对 C# 编程语言的正式研究。在这里，你将学习 Main() 方法的作用、顶层语句（C# 9.0 中的新功能），以及有关 .NET 5 平台固有数据类型的众多细节和变量声明。你将使用 System.String 和 System.Text.StringBuilder 处理和操作文本数据。你还将检查迭代和决策结构、模式匹配、窄化与扩展操作以及 unchecked 关键字。

#### 第 4 章：核心 C# 编程结构，第 2 部分

本章完成你对 C# 核心方面的检查，首先是创建和操作数据数组。接下来，你将检查如何构造重载类型方法和使用 out、ref 和 params 关键字定义参数。你还将学习 enum 类型、结构和可空数据类型，并理解值类型与引用类型之间的区别。最后，你将学习元组，这是 C# 7 中的新功能，并在 C# 8 中更新。

### 第三部分：使用 C# 进行面向对象编程

在本部分中，你将理解 C# 语言的核心结构，包括面向对象编程的细节。本部分还将检查如何处理运行时异常，并深入探讨使用强类型接口的细节。最后，你将学习对象生命周期和垃圾回收。
