

## 第19章：理解 CIL 和动态程序集的作用

本节最后一章的目标有两个。第一部分将比前几章更详细地检查 CIL 的语法和语义。本章的其余部分将介绍 System.Reflection.Emit 命名空间的作用。你可以使用这些类型构建在运行时在内存中生成 .NET Core 程序集的软件。严格来说，在内存中定义和执行的程序集被称为动态程序集。

## 第六部分：文件处理、对象序列化和数据访问

到目前为止，你已经牢牢掌握了 C# 语言和 .NET Core 程序集格式的细节。第六部分利用你新获得的知识，探索基类库中一些常用的服务，包括文件 I/O、对象序列化和使用 ADO.NET 进行数据库访问。

### 第20章：文件 I/O 和对象序列化

System.IO 命名空间允许你与机器的文件和目录结构进行交互。在本章中，你将学习如何以编程方式创建（和销毁）目录系统。你还将学习如何将数据移入和移出各种流（例如基于文件、基于字符串和基于内存的流）。本章后半部分将检查 .NET Core 平台的 XML 和 JSON 对象序列化服务。简单来说，序列化允许你将对象的公共状态（或一组相关对象）持久化到流中以供以后使用。反序列化（不出所料）是从流中取出对象到内存中供你的应用程序使用的过程。

### 第21章：使用 ADO.NET 进行数据访问

本章介绍使用 ADO.NET 进行数据库访问，ADO.NET 是 .NET Core 应用程序的数据库 API。具体来说，本章将介绍 .NET 数据提供程序的作用以及如何使用 ADO.NET 与关系数据库通信，ADO.NET 由连接对象、命令对象、事务对象和数据读取器对象表示。本章还开始创建 AutoLot 数据库，该数据库将在第22章和第23章中得到增强。

## 第七部分：Entity Framework Core

到目前为止，你已经牢牢掌握了 C# 语言和 .NET Core 程序集格式的细节。第六部分利用你新获得的知识，探索基类库中一些常用的服务，包括文件 I/O、使用 ADO.NET 进行数据库访问，以及使用 Entity Framework Core 进行数据库访问。

### 第22章：介绍 Entity Framework Core

本章介绍 Entity Framework (EF) Core。EF Core 是构建在 ADO.NET 之上的对象关系映射 (ORM) 框架。EF Core 提供了一种使用直接映射到业务模型的类型化类编写数据访问代码的方法。在这里，你将了解 EF Core 的构建块，包括 DbContext、实体、专用集合类 DbSet<T> 和 DbChangeTracker。接下来，你将学习查询执行、跟踪与非跟踪查询，以及 EF Core 的一些更值得注意的功能。本章理论的最后一部分是用于 .NET Core 命令行界面 (CLI) 的 EF Core 全局工具。

### 第23章：使用 Entity Framework Core 构建数据访问层

本章构建 AutoLot 数据访问层。它首先从第21章的 AutoLot 数据库脚手架生成派生的 DbContext 和实体类。然后项目和数据库更新为采用代码优先方法。实体更新到最终版本，并创建并执行迁移以使数据库与实体匹配。数据库的最终更改是为第21章的存储过程创建迁移以及新的数据库视图。为代码封装添加了存储库，并创建了数据初始化过程。本章的最后一部分使用 xUnit 对数据访问层进行测试驱动的自动化集成测试。

## 第八部分：Windows Presentation Foundation

.NET 平台支持的初始桌面 GUI API 被称为 Windows Forms。虽然该 API 仍然完全受支持，但 .NET 3.0 向程序员引入了一个名为 Windows Presentation Foundation (WPF) 的 API。与 Windows Forms 不同，该框架将许多关键服务，包括数据绑定、2D 和 3D 绘图、动画和富文档，集成到单一统一对象模型中。这都是通过一种名为可扩展应用程序标记语言 (XAML) 的声明性标记语法实现的。此外，WPF 控件架构提供了一种使用很少的格式良好的 XAML 就能从根本上重新设计典型控件的外观和感觉的简单方法。

### 第24章：介绍 Windows Presentation Foundation 和 XAML

在本章中，你将首先检查 WPF 创建的动机（当 .NET 中已经存在桌面开发框架时）。然后，你将学习 XAML 的语法，最后，查看 Visual Studio 对构建 WPF 应用程序的支持。

### 第25章：WPF 控件、布局、事件和数据绑定

本章将让你接触使用内置 WPF 控件和布局管理器的过程。例如，你将学习构建菜单系统、拆分窗口、工具栏和状态栏。本章还将介绍一些 WPF API（及其相关控件），包括 Ink API、命令、路由事件、数据绑定模型和依赖属性。

### 第26章：WPF 图形渲染服务

WPF 是一个图形密集型 API；鉴于此事实，WPF 提供了三种渲染图形的方式：形状、绘图和几何图形，以及可视对象。在本章中，你将评估每个选项，并在途中学习一些重要的图形原语（例如画刷、画笔和变换）。本章还将检查将矢量图像合并到 WPF 绘图中的方法，以及如何对图形数据执行命中测试操作。

### 第27章：WPF 资源、动画、样式和模板

本章将介绍三个重要（且相互关联）的主题，这些主题将加深你对 Windows Presentation Foundation API 的理解。首先要做的是学习逻辑资源的作用。正如你将看到的，逻辑资源（也称为对象资源）系统提供了一种在 WPF 应用程序中命名和引用常用对象的方法。接下来，你将学习如何定义、执行和控制动画序列。尽管你可能在想什么，WPF 动画并不局限于电子游戏或多媒体应用程序的范围。你将通过学习 WPF 样式的作用来结束本章。与使用 CSS 的网页或 ASP.NET 主题引擎类似，WPF 应用程序可以为一组控件定义统一的外观和感觉。

### 第28章：WPF 通知、验证、命令和 MVVM

本章首先检查三个核心 WPF 框架功能：通知、验证和命令。在通知部分，你将学习可观察模型和集合以及它们如何使你的应用程序数据和 UI 保持同步。接下来，你将深入研究命令，构建自定义命令以封装你的代码。在验证部分，你将学习如何在 WPF 应用程序中使用多种验证机制。本章以对 Model-View-ViewModel (MVVM) 模式的检查结束，并通过创建一个演示 MVVM 模式实际应用的应用程序结束。

## 第九部分：ASP.NET Core

第八部分专门用于使用 ASP.NET Core 构建 Web 应用程序的检查。ASP.NET Core 可用于构建 Web 应用程序和 RESTful 服务。

### 第29章：介绍 ASP.NET Core

本章介绍 ASP.NET Core 和 Model-View-Controller (MVC) 模式。下一节列出（并解释）从经典 ASP.NET MVC/WebAPI 引入到 ASP.NET Core 的功能。这些包括控制器和操作、模型绑定、路由和过滤器。下一节介绍 ASP.NET Core 中引入的新功能，包括内置依赖注入、面向云的、环境感知的配置系统、部署模式和 HTTP 请求管道。本章其余部分创建了将在接下来的两章中完成的两个 ASP.NET Core 项目，展示了运行 ASP.NET Core 应用程序的选项，并开始了这两个 ASP.NET Core 项目的配置过程。

### 第30章：使用 ASP.NET Core 的 RESTful 服务

本章完成 ASP.NET Core RESTful 服务应用程序。本章首先演示了向客户端返回 JSON 结果的不同机制以及 ApiController 属性提供的服务应用程序内置支持。接下来添加 Swagger/OpenAPI 以提供测试和记录服务的平台。本章其余部分构建应用程序的控制器，并创建异常过滤器。

### 第31章：使用 ASP.NET Core 的 MVC 应用程序

这是涵盖 ASP.NET Core 的最后一章，完成基于 MVC 的 Web 应用程序。本章首先深入研究视图和 Razor 视图引擎，包括布局和局部视图。接下来探索标签助手（ASP.NET Core 中的另一个新功能），然后管理客户端库以及这些库的捆绑/压缩。接下来，构建 CarsController 及其视图，以及自定义标签助手。为数据驱动的菜单添加视图组件，并探索选项模式。最后，创建一个 HTTP 客户端服务包装器，并更新 CarsController 以使用 ASP.NET Core 服务而不是 AutoLot 数据访问层。
