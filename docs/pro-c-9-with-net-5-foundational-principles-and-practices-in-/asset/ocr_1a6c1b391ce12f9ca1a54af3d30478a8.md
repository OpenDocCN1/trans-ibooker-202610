# Mapping Properties to Columns

When using a relational data store, the EF Core conventions map all read-write public properties to columns in the table the entity is mapped to. If the property is an automatic property, EF Core reads and writes through the getter and setter. If the property has a backing field, EF Core will read and write to the backing field instead of the public property, even though the backing field is private. While EF Core can read and write to private fields, there still must be a public read-write property that encapsulates the backing field.

Two scenarios where the backing field support is advantageous are when using the INotifyPropertyChanged pattern in Windows Presentation Foundation (WPF) applications and when database default values clash with .NET Core default values. Using EF Core with WPF is covered in Chapter 28, and database default values are covered later in this chapter.

The names, data types, and nullability of the columns are configured through conventions, data annotations, and/or the Fluent API. Each of these topics is covered in depth later in this chapter.

# Mapping Classes to Tables

There are two available class to table mapping schemes available in EF Core: table-per-hierarchy (TPH) and table-per-type (TPT). TPH mapping is the default and maps an inheritance hierarchy to a single table. New in EF Core 5, TPT maps each class in the hierarchy to its own table.

> Note Classes can also be mapped to views and raw SQL queries. These are referred to as query types and are covered later in this chapter.

# Table-per-Hierarchy Mapping (TPH)

Consider the following example, which shows the Car class from Chapter 21 split into two classes: a base class for the Id and TimeStamp properties and the remaining properties left in the Car class. Both of these classes should be created in the Models directory of the AutoLot.Samples project.

```
using System.Collections.Generic;

namespace AutoLot.Samples.Models
{
    public abstract class BaseEntity
    {
        public int Id { get; set; }
        public byte[] TimeStamp { get; set; }
    }
}
```

```
using System.Collections.Generic;
namespace AutoLot.Samples.Models
{
    public class Car : BaseEntity
    {
        public string Color { get; set; }
        public string PetName { get; set; }
        public int MakeId { get; set; }
    }
}
```
