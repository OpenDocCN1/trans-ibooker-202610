# Understanding Database Transactions

Let’s wrap up this examination of ADO.NET by taking a look at the concept of a database transaction. Simply put, a transaction is a set of database operations that succeed or fail as a collective unit. If one of the operations fails, all other operations are rolled back, as if nothing ever happened. As you might imagine, transactions are quite important to ensure that table data is safe, valid, and consistent.

Transactions are important when a database operation involves interacting with multiple tables or multiple stored procedures (or a combination of database atoms).
