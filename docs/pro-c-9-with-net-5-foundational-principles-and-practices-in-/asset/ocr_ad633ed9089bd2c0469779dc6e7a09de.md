# Add XML Comments to SwaggerGen

The generated XML comments must be added into the swagger.json generation process. Start by adding the following using statements to the Startup class:

```
using System.IO;
using System.Reflection;
```

The XML documentation file is added into Swagger by calling the IncludeXmlComments() method in the AddSwaggerGen() method. Navigate to the ConfigureServices() method of the Startup class and update the AddSwaggerGen() method to the following to add the XML documentation file:

```
services.AddSwaggerGen(c =>
{
    c.SwaggerDoc("v1",
        new OpenApiInfo
        {
            Title = "AutoLot Service",
            Version = "v1",
            Description = "Service to support the AutoLot dealer site",
            License = new OpenApiLicense
            {
                Name = "Skimedic Inc",
                Url = new Uri("http://www.skimedic.com")
            }
        });
    var xmlFile = $"{Assembly.GetExecutingAssembly().GetName().Name}.xml";
    var xmlPath = Path.Combine(AppContext.BaseDirectory, xmlFile);
    c.IncludeXmlComments(xmlPath);
});
```
