The final section loops through the records and displays the table records using the DisplayFor Razor HTML helper. This helper will look for a DisplayTemplate template name that matches the type of the property and, if not found, will create the markup in the default manner. Each property on the object will also check for a display template and use that if found. For example, if the Car had a DateTime property, the DisplayTemplate shown earlier in the chapter would be invoked for the property.

This block also uses the item-edit, item-details, and item-delete custom tag helpers that were added in the previous section. Note that when passing in values to a custom tag helper's public property, the property name is lower-kebab-cased and added to the tag as an attribute.
