## Configure the Services

Create a new class named ServiceConfiguration.cs in the ApiWrapper directory of the AutoLot.Service project. Update the using statements to the following:

```csharp

```

Make the class public and static and add a public static extension method for the IServiceCollection.

```csharp
namespace AutoLot.Services.ApiWrapper
{
    public static class ServiceConfiguration
    {
        public static IServiceCollection ConfigureApiServiceWrapper(this IServiceCollection services, IConfiguration config)
        {
            return services;
        }
    }
}
```

The first line of the extension methods adds ApiServiceSettings into the DI container. The second line adds IApiServiceWrapper into the DI container and registers the class with the HTTPClient factory. This enables IApiServiceWrapper to be injected into other classes, and the HTTPClient factory will manage the injection and lifetime of the HTTPClient.

```csharp
public static IServiceCollection ConfigureApiServiceWrapper(this IServiceCollection services, IConfiguration config)
{
    services.Configure<ApiServiceSettings>(config.GetSection(nameof(ApiServiceSettings)));
    services.AddHttpClient<IApiServiceWrapper,ApiServiceWrapper>();
    return services;
}
```

Open the Startup.cs class and add the following using statement:

```csharp
using AutoLot.Services.ApiWrapper;
```

Finally, navigate to the ConfigureServices() method and add the following line:

```csharp
services.ConfigureApiServiceWrapper(Configuration);
```
