# Any() and All()

The Any() and All() methods check a set of records to see whether any records match the criteria (Any()) or whether all records match the criteria (All()). Just like the aggregation methods, they can be added to the end of a LINQ query with Where() methods or the filter expression can be contained in the method itself. Any() and All() methods execute on the server side, and a Boolean is returned from the query. Global query filters affect Any() and All() methods functions as well and can be disabled with IgnoreQueryFilters().
