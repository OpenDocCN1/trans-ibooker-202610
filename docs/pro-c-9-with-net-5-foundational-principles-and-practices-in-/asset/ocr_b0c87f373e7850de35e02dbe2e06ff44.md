# Update the Fluent API Code

The OnModelCreating override is where the Fluent API code belongs and uses an instance of the ModelBuilder class to update the model.

# The SeriLog Entity

The first change to this method is to add Fluent API code for the configuration of the SeriLogEntry entity. The Properties property is a SQL Server XML column, and the TimeStamp property maps to a datetime2 column in SQL Server with the default value set to the getdate() SQL Server function. In the OnModelCreating method, add the following code:

```
modelBuilder.Entity<SeriLogEntry>(entity =>
{
    entity.Property(e => e.Properties).HasColumnType("Xml");
    entity.Property(e => e.TimeStamp).HasDefaultValueSql("GetDate()");
});
```
