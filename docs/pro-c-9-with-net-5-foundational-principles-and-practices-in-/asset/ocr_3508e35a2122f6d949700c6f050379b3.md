# SQL Queries with LINQ

If the LINQ statement for a particular query is over-complicated or testing reveals the performance is less than desired, data can be retrieved using a raw SQL statement using DbSet<T>’s FromSqlRaw() or FromSqlInterpolated() method. The SQL statement can be an inline T-SQL select statement, stored procedure, or table-valued function. If the query is an open query (e.g., T-SQL statement without a termination semicolon), then LINQ statements can be added to the FromSqlRaw()/FromSqlInterpolated() method to further define the generated query. The entire query is executed on the server side, combining the SQL statement with the generated SQL from the LINQ statements.

If the statement is terminated or contains SQL that cannot be built upon (e.g., uses common table expressions), that query is still executed on the server side, but any additional filtering and processing must be done on the client side as LINQ to Objects.

FromSqlRaw() executes the query exactly as it is typed. FromSqlInterpolated() uses C# string interpolation and then turns the interpolated values into parameters. The following tests (in the CarTests.cs class) show examples from using both of these methods, with and without the global query filters:

```
[Fact]
public void ShouldNotGetTheLemonsUsingFromSql()
{
    var entity = Context.Model.FindEntityType($"{typeof(Car).FullName}");
    var tableName = entity.GetTableName();
    var schemaName = entity.GetSchema();
    var cars = Context.Cars.FromSqlRaw($"Select * from {schemaName}.{tableName}").ToList();
    Assert.Equal(9, cars.Count);
}
```

```
[Fact]
public void ShouldGetTheCarsUsingFromSqlWithIgnoreQueryFilters()
{
    var entity = Context.Model.FindEntityType($"{typeof(Car).FullName}");
    var tableName = entity.GetTableName();
    var schemaName = entity.GetSchema();
    var cars = Context.Cars.FromSqlRaw($"Select * from {schemaName}.{tableName}")
        .IgnoreQueryFilters().ToList();
    Assert.Equal(10, cars.Count);
}
```

```
[Fact]
public void ShouldGetOneCarUsingInterpolation()
{
    var carId = 1;
    var car = Context.Cars
        .FromSqlInterpolated($"Select * from dbo.Inventory where Id = {carId}")
        .Include(x => x.MakeNavigation)
        .First();
    Assert.Equal("Black", car.Color);
    Assert.Equal("VW", car.MakeNavigation.Name);
}
```
