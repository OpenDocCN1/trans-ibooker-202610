# Figure 18-2. Embedding the interop type

To change the property through the project file, add <EmbedInteropTypes>True</EmbedInteropTypes>, as shown here:

```
<ItemGroup>
    <COMReference Include="Microsoft.Office.Excel.dll">
        <Guid>00020813-0000-0000-c000-000000000046</Guid>
        <VersionMajor>1</VersionMajor>
        <VersionMinor>9</VersionMinor>
        <WrapperTool>tlbimp</WrapperTool>
        <Lcid>0</Lcid>
        <Isolated>false</Isolated>
        <EmbedInteropTypes>true</EmbedInteropTypes>
    </COMReference>
</ItemGroup>
```

The C# compiler will include only the parts of the interop library you are using. Thus, if the real interop library has .NET Core descriptions of hundreds of COM objects, you will bring in only the definitions of the subset you are really using in your C# code. Beyond reducing the file size that must be deployed, you also have an easier installation path, as you do not need to install any missing PIAs on the target machine.
