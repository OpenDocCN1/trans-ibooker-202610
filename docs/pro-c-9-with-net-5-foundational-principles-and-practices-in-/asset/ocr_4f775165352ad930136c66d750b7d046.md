# Leverage Data Annotations with WPF

WPF can leverage data annotations as well for UI validation. Let’s add some data annotations to the Car model.

# Add Data Annotations to the Model

Open Car.cs and add a using statement for System.ComponentModel.DataAnnotations. Add the [Required] and [StringLength(50)] attributes to Make, Color, and PetName. The Required attribute adds a validation rule that the property must not be null (admittedly, this is redundant for the Id property since it is not a nullable int). The StringLength(50) attribute adds a validation rule that the value of the property cannot be longer than 50 characters.
