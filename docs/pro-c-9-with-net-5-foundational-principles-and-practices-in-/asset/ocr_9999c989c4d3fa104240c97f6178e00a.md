The Orders navigation property needs the JsonIgnore attribute to prevent circular JSON references when serializing the object model. The scaffolded code does use the nameof() method in the inverse property but needs an update since all reference navigation properties will have the suffix Navigation added to their names. The final change is to have the type of the property typed as IEnumerable<Order> instead of ICollection<Order> and initialized with a new List<Order>. This is not a required change, as ICollection<Order> will also work. I prefer to use the lower-level IEnumerable<T> on collection navigation properties (since IQueryable<T> and ICollection<T> both derive from IEnumerable<T>). Update the code to match the following:

```
[JsonIgnore]
[InverseProperty(nameof(Order.CarNavigation))]
public IEnumerable<Order> Orders { get; set; } = new List<Order>();
```
