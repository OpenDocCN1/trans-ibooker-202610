# The GetMakes Helper Method

The GetMakes() helper method builds a SelectList of all the Makes in the database. It uses the Id as the value and the Name as the display text.

```
internal async Task<SelectList> GetMakesAsync()=>
    new SelectList(
        await _serviceWrapper.GetMakesAsync(),
        nameof(Make.Id),
        nameof(Make.Name));
```

# The GetOne Car Method

The GetOne() helper method gets a single Car record:

```
internal async Task<Car> GetOneCarAsync(int? id)
    => !id.HasValue ? null : await _serviceWrapper.GetCarAsync(id.Value);
```

# The Public Action Methods

The only difference between the public action methods in this controller versus CarsController is the data access, and all of the action methods are async. Since you already understand what each action is used for, here are the rest of the methods with changes highlighted in bold and/or with comments:

```
[Route("/[controller]")]
[Route("/[controller]/[action]")]
public async Task<IActionResult> Index()
    => View(await _serviceWrapper.GetCarsAsync());

[HttpGet("{makeId}/{makeName}")]
public async Task<IActionResult> ByMake(int makeId, string makeName)
{
    ViewBag.MakeName = makeName;
    return View(await _serviceWrapper.GetCarsByMakeAsync(makeId));
}

[HttpGet("{id?}")]
public async Task<IActionResult> Details(int? id)
{
    if (!id.HasValue)
    {
        return BadRequest();
    }
    var car = await GetOneCarAsync(id);
    if (car == null)
    {
        return NotFound();
    }
    return View(car);
}
```
