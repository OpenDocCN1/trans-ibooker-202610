# The Razor View Engine and Razor Syntax

The Razor View Engine was designed as an improvement over the Web Forms View Engine and uses Razor as the core language. Razor is server-side code that is embedded into a view, is based on C#, and has corrected many annoyances with the Web Forms View Engine. The incorporation of Razor into HTML and CSS results in code that is much cleaner and easier to read than using the Web Forms View Engine syntax.

To get started, add a new view by right-clicking the Views\Home folder in the AutoLot.Mvc project and selecting Add ► New Item. Select Razor View - Empty from the Add New Item - AutoLot.Mvc dialog and name the view RazorSyntax.cshtml.

Note When you right-click the Views\Home folder, there is also a menu option: Add ► View. However, that dialog brings you right back to the Add New Item dialog.
