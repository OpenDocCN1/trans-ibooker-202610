# Discussion

Note the following:

+   - The loop’s *initializer* is possibly the simplest. You just start at ten.
+   - The *iterator* is not difficult either; the numbers go down, which is why you just subtract one at the end of each turn.
+   - The most difficult is the *loop condition*. You must formulate it in such a way that it holds as long as you want the loop to go on and that it ceases holding at the moment you want to quit. The correct test is whether the number variable is greater than or equal to one.
