### 解决方案

以下是代码：

```csharp
static void Main(string[] args)
{
    // Input
    Console.Write("Enter a number: ");
    string input = Console.ReadLine();
    int number = Convert.ToInt32(input);

    // Increasing by 1 using INCREMENT OPERATOR
    number++; // same as number = number + 1;
    Console.WriteLine("Increased by 1: " + number);

    // Decreasing by 1 using DECREMENT OPERATOR
    number--; // same as number = number - 1;
    Console.WriteLine("Back again: " + number);

    // Waiting for Enter
    Console.ReadLine();
}
```

## 复合赋值与文本

由于 + 运算符可以用于文本，因此你也可以将复合赋值运算符 (+=) 与文本一起使用。你可能会经常使用它。

### 任务

此任务将使你熟悉使用复合赋值进行文本连接（见图 13-4）。

![](img/32b055c352c70d22a656320349173d95_192_0.png)

*Figure 13-4. Text concatenations using compound assignment*

### 解决方案

以下是代码：

```csharp
static void Main(string[] args)
{
    // Initial value (empty text)
    string books = "";

    // Appending
    books += "Homage to Catalonia" + Environment.NewLine;
    books += "Silent Spring" + Environment.NewLine;
    books += "The beat of a different drum" + Environment.NewLine;

    // Output
    Console.WriteLine("Valuable books");
    Console.WriteLine("-------------");
    Console.WriteLine(books);

    // Waiting for Enter
    Console.ReadLine();
}
```

## 渐进求和

渐进求和是求和大量值的重要原则。它意味着不是一次性在单个语句中全部求和，而是逐个求和，逐步将中间结果累积到一个特殊变量中。

### 任务

你将编写一个程序，逐步求和三个输入的数字。当然，求和三个数字更方便地可以在一行中一次性完成。然而，我想在简单示例上说明渐进求和的重要原则，并在介绍更复杂主题——循环之前让你熟悉这一思想（见图 13-5）。

![](img/32b055c352c70d22a656320349173d95_193_0.png)

*Figure 13-5. Progressively summing three entered numbers*

### 解决方案

以下是代码：

```csharp
static void Main(string[] args)
{
    // Preparation - variable to accumulate intermediate result
    int sum = 0;

    // Input - 1. number
    Console.Write("Enter first number: ");
    string input = Console.ReadLine();
    int number = Convert.ToInt32(input);

    // Adding first number to intermediate result
    sum += number;

    // Input - 2. number
    Console.Write("Enter second number: ");
    input = Console.ReadLine();
    number = Convert.ToInt32(input);

    // Adding second number to intermediate result
    sum += number;

    // Input - 3. number
    Console.Write("Enter third number: ");
    input = Console.ReadLine();
    number = Convert.ToInt32(input);

    // Adding third number to intermediate result
    sum += number;

    // Output
    Console.WriteLine();
    Console.WriteLine("Sum of entered numbers: " + sum);

    // Waiting for Enter
    Console.ReadLine();
}
```

## 多重文本连接

同样，由于 + 运算符也可以用于文本，因此你可以将渐进求和的原则扩展到文本。在这种情况下，它可能更被称为 *渐进累积*。

### 任务

你将编写一个程序，逐步累积用户输入的名称。将进行两次累积会很有趣；第一次按原始顺序，第二次按相反顺序。

为简单起见，你将只处理三个值（见图 13-6）。

![](img/32b055c352c70d22a656320349173d95_195_0.png)

*Figure 13-6. Progressively accumulating names*

### 解决方案

以下是代码：

```csharp
static void Main(string[] args)
{
    // Preparation - variables to accumulate intermediate results
    string inOriginalOrder = "";
    string inReversedOrder = "";

    // Input of the first person
    Console.Write("Enter first person: ");
    string person = Console.ReadLine();

    // Appending the first person to intermediate result
    inOriginalOrder += person + Environment.NewLine;
    inReversedOrder = person + Environment.NewLine + inReversedOrder;

    // Input of the second person
    Console.Write("Enter second person: ");
    person = Console.ReadLine();

    // Appending the second person to intermediate result
    inOriginalOrder += person + Environment.NewLine;
    inReversedOrder = person + Environment.NewLine + inReversedOrder;

    // Input of the third person
    Console.Write("Enter third person: ");
    person = Console.ReadLine();

    // Appending the third person to intermediate result
    inOriginalOrder += person + Environment.NewLine;
    inReversedOrder = person + Environment.NewLine + inReversedOrder;

    // Output
    Console.WriteLine();
    Console.WriteLine("Entered persons");
    Console.WriteLine("---------------");
    Console.WriteLine(inOriginalOrder);
    Console.WriteLine("In reversed order");
    Console.WriteLine("----------------");
    Console.WriteLine(inReversedOrder);

    // Waiting for Enter
    Console.ReadLine();
}
```

### 注意

值得注意的是，当以相反顺序连接人名时，复合赋值是无济于事的。

## 总结

本章的核心主题是向同一变量中累积值。与迄今为止的程序相反，此处的程序会反复更改变量的值，通常使用其原始值并以某种方式修改它。具体来说，你研究了以下内容：

- 诸如 `variable = variable + change;` 这样的语句，它取变量的当前值，将 change 加到它上面，并将结果存储为变量的新值
- 复合赋值，如 `variable += change;`，它是前述语句的简写形式
- 使用其他算术运算的复合赋值： `-=`、 `*=`、 `/=`
- 与文本的复合赋值（仅 `+=`）
- 使用超简洁的记法 `variable++;` 和 `variable--;` 对变量进行递增（加一）和递减（减一）

在本章结束时，你熟悉了渐进求和（和渐进累积）的原则，这意味着逐个求和数字，同时将中间结果存储在特殊变量中。该原则主要用于求和大量值，当你在本书后面学习循环时，你会体会到其极端重要性。

### IntelliSense

你知道我将介绍的第一个工具：Visual Studio IntelliSense。每当你开始输入任何内容时，Visual Studio 会立即为你提供完成文本的选项。当你选择其中一个选项时，开发环境会在工具提示中向你显示有关该选项的进一步详细信息——该选项的作用、它需要什么参数等等。

我在本章介绍 IntelliSense 是因为它经常被初学者程序员低估。我建议你习惯于使用 IntelliSense 完成你输入的几乎每个单词。你将节省自己大量拼写错误。

在过去，你必须在手册或书籍中研究可能性。其中一些足够全面，可以涵盖程序员几乎所有的问题。然而，今天的可能性如此之多，即使是 1000 页的书也无法全部展示。
