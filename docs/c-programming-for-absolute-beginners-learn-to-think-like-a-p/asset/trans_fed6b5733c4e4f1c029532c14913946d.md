

## 第 3 章 处理输出

## 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Output of a calculation
    Console.WriteLine(1 + 1);

    // Waiting for Enter
    Console.ReadLine();
}
```

输入并运行程序！

## 注意

在编程中，这种计算（通常指值的组合）称为*表达式*。

## 进行更复杂的计算

当然，你不需要计算机来计算 1 加 1。但如果是 1 加 2 乘以 3 呢？你是否又觉得这简单得可笑？稍等一下，因为即使在这种简单的情况下也很容易出错！

## 任务

你将创建一个程序来计算 1 加 2 乘以 3。

## 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Multiplication has greater priority
    Console.WriteLine(1 + 2*3);

    // Forcing priority using parentheses
    Console.WriteLine((1 + 2)*3);

    // Waiting for Enter
    Console.ReadLine();
}
```

***图 3-3.*** *进行更复杂的计算*

## 讨论

关于这个程序，请注意以下几点：

- 本任务旨在向你展示，你必须始终清楚到底需要计算什么。在这个示例中，你需要决定先进行加法还是先进行乘法。
- 在基础数学规则中，乘法和除法的优先级高于加法和减法。编程中的规则与数学中相同。如果你想先计算 1 加 2，再乘以 3，就需要用括号将 1 和 2 括起来。
- 我没有在乘号（星号）周围添加空格，但这与计算顺序无关。我只是认为这样看起来更好。在 C# 中，空格和换行无关紧要。（当然，你不应该把一个单词从中间断开。）
- 最后，这个示例表明计算机按照语句编写的顺序执行程序语句。也就是说，从上到下执行。

## 拼接文本

你现在将了解加号运算符（+）不仅可以用于数字，也可以用于文本。换句话说，它可以将文本拼接在一起。

## 任务

任务是探索如何将文本拼接在一起（见图 3-4）。

![图 3-4](img/32b055c352c70d22a656320349173d95_64_0.png)

*图 3-4.* 拼接文本

## 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Normal text
    Console.WriteLine("I have started to program");
    // Also normal text
    Console.WriteLine(" in C#.");

    // Joining two texts using plus sign
    Console.WriteLine("I have started to program" + " in C#.");

    // Waiting for Enter
    Console.ReadLine();
}
```

注意介词 *in* 前面的空格！

## 输出特殊字符

有时，你需要向屏幕输出特殊字符。以下是一些示例：

- 输出回车来结束一行。
- 输出引号。（在 C# 中，引号用作文本分隔符，因此必须特殊处理。）
- 输出 Unicode 字符（当然，前提是你的字体能够显示它）。

## 任务

现在你将编写一个程序，演示如何处理特殊字符。

## 解决方案

要处理特殊字符，你需要使用*转义序列*。在 C# 中，转义序列以反斜杠开头。

```csharp
static void Main(string[] args)
{
    // Multiline output
    Console.WriteLine("First line\r\nSecond line");

    // I prefer specifying "Enter" in more human form
    Console.WriteLine("First line" + Environment.NewLine + "Second line");

    // Text containing a quote
    Console.WriteLine("The letter started so sweet: \"My Darling\"");

    // Unicode characters, in this case Greek beta
    Console.WriteLine("If the font knows, here is Greek beta: \u03B2");

    // Backslashes themselves need to be doubled
    Console.WriteLine("Path to desktop on my computer: " + "C:\\Users\\vystavel\\Desktop");

    // Waiting for Enter
    Console.ReadLine();
}
```

结果应如图 3-5 所示。

![图 3-5](img/32b055c352c70d22a656320349173d95_66_0.png)

*图 3-5. 处理特殊字符*

## 讨论

关于这个程序，请注意以下几点：

- 在 C# 中，文本中的反斜杠会引入所谓的转义序列。但如果想要输出反斜杠该怎么办？那就需要将其写两次。在处理 Windows 操作系统中的文件路径时，经常会出现这种情况。
- 控制台应用程序甚至会将简单的 \n 识别为行终止符（表示回车）。然而，在许多其他 C# 程序中，你需要“完整的回车”，即 \r\n。这就是为什么你在本程序中使用了它。你还使用了 Environment.NewLine，这绝对是最佳选择，因为它具有良好的可读性。

## 使用预格式化文本

有时，你可能希望一次性显示多行文本（见图 3-6）。

![图 3-6](img/32b055c352c70d22a656320349173d95_67_0.png)

**图 3-6.** 多行文本

## 任务

你将创建一个程序来显示多行文本。

## 解决方案

在文本的开头引号前加上 at（@）符号，如下所示：

```csharp
static void Main(string[] args)
{
    // Bob Dylan...
    Console.WriteLine(@" Yes, and how many times can a man turn his head
    and pretend that he just doesn’t see?");

    // Waiting for Enter
    Console.ReadLine();
}
```

## 注意

at（@）符号也会关闭转义序列。这就是为什么在处理 Windows 中的文件路径（前面提到过）时，它可能很有用；在这种情况下，你不需要将每个反斜杠都写成双份。

## 计算 1 加 1

在下一个任务中，你将回到 1 加 1 的问题。你是否奇怪为什么我要回到这么简单的任务？嗯，即使像 1 加 1 这样简单的事情也可能出错。让我们来看看。

## 任务

任务是探索将两个数字组合在一起的不同方式（见图 3-7）。

![图 3-7](img/32b055c352c70d22a656320349173d95_69_0.png)

*图 3-7. 将数字组合在一起*

## 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Pay special attention when mixing texts with numbers!
    Console.WriteLine(
@"Senior math test
=================

One and one is:");
    Console.WriteLine("a) " + 1 + 1);
    Console.WriteLine("b) " + (1 + 1));
    Console.WriteLine("c) " + "mostly fun");

    // Waiting for Enter
    Console.ReadLine();
}
```

## 讨论

当你将数字与文本混合时，结果可能与你的预期不同！

让我们考虑第一个答案 (a)。计算机从左到右计算整个表达式。首先，它取文本 a) 和一个数字（第一个 1），将它们拼接成 a) 1。然后，它再取这个新文本和最后一个数字（第二个 1），再次拼接，得到文本 a) 11。

第二个答案 (b) 则不同。括号让计算机先执行数字相加，之后才拼接左侧的文本。

有时，预先计算中间结果并将其存储在变量中可能更清晰。这正是你将在下一章学习的内容。当然，变量远不止这些用途，你接下来会看到。

## 小结

在本章中，你探索了 Console.WriteLine 语句为你提供的几种不同输出可能性。具体来说，你学习了以下内容：

- 除了文本之外，你还可以在程序中使用数字。与文本不同，数字不需要用引号括起来。
- 你可以将多个值组合成表达式。为此，可以使用 +、- 和 * 等运算符。对于数字，它们执行普通算术运算。加号运算符也可以用于文本，在这种情况下，它会将两段文本拼接成一段。
- 在计算中，你始终要注意结果的求值顺序。乘法和除法的优先级高于加法和减法。要强制使用不同的求值顺序，请使用括号。
- 特殊字符（如引号或换行符）可以用以反斜杠开头的转义序列输出。
- 通过在文本前加上 at（@）符号，你可以方便地输出预格式化的多行文本。
