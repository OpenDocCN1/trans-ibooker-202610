### 两个数字中的较大值

程序员的一项常见任务是找出两个数字中哪一个更大（同样地，也可找出哪一个更小）。

### 任务

你现在的任务是编写一个程序，询问用户两个数字，然后说明这两个数字中哪个更大（见图15-14）。

![](img/32b055c352c70d22a656320349173d95_233_0.png)

**图15-14.** *判断哪个数字更大*

### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Inputs
    Console.Write("Enter first number: ");
    string input1 = Console.ReadLine();
    int number1 = Convert.ToInt32(input1);

    Console.Write("Enter second number: ");
    string input2 = Console.ReadLine();
    int number2 = Convert.ToInt32(input2);

    // Evaluating
    int greater = number1;
    if (number2 > greater)
    {
        greater = number2;
    }

    // Output
    Console.WriteLine("Greater of entered numbers is: " + greater);

    // Waiting for Enter
    Console.ReadLine();
}
```

### 使用内置函数

在本书中，我经常从不同角度向你展示内容。我坚信这能加深你的理解。对于当前“找出两个数中较大值”的问题，我将向你展示第三种解决方法。事实上，这项任务非常常见，因此 C# 提供了一个方便的内置函数。

### 任务

你将使用内置函数`Math.Max`来解决之前的练习。

### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Inputs
    Console.Write("Enter first number: ");

    Console.Write("Enter second number: ");
```

### 小结

在本章中，你开始学习程序语句的条件执行，这意味着一条或多条语句是否执行可以由某个测试来决定。你看到了以下测试示例：

- 使用`==`运算符测试两段文本或两个数字是否相等
- 使用`!=`运算符测试两段文本或两个数字是否不相等
- 使用`>`（或`<`）运算符测试一个数字是否大于（或小于）另一个数字

最后一个测试还可以使用`>=`（或`<=`）运算符扩展为“大于或等于”（或“小于或等于”）。

为了在代码中使用条件执行，你学习了if-else结构。它由一个条件和两个分支组成。如果条件被判定为真（满足），则执行if分支中的语句；如果条件被判定为假（不满足），则执行else分支中的语句。

你了解到，如果某个分支只包含一条语句，C#语法允许你省略包围该分支的大括号，但我不建议你这样做，因为人们在之后将分支扩展为多条语句时，常常会忘记补上大括号。

更重要的是，你了解到else分支可以根据需要省略。这意味着没有备选操作——当条件不满足时，什么都不做。

作为额外收获，你了解了实用的内置函数Math.Max。（你大概能猜到还有一个类似的函数叫Math.Min。）

### 追加扩展名

有时，你想向用户询问文件名，但你不知道用户输入时是否带扩展名。

### 任务

你将编写一个程序，为输入的文件名追加.png扩展名，除非该扩展名已经是输入的一部分（见图16-1和图16-2）。

![](img/32b055c352c70d22a656320349173d95_238_0.png)

**图16-1.** *追加.png扩展名*

![](img/32b055c352c70d22a656320349173d95_239_0.png)

**图16-2.** *不追加.png扩展名*

### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Input
    Console.Write("Enter image name: ");
    string fileName = Console.ReadLine();

    // Appending extension (ONLY IN CASE OF NEED)
    if (!fileName.ToLower().EndsWith(".png"))
    {
        fileName += ".png";
    }

    // Output
    Console.WriteLine("We are going to use name: " + fileName);

    // Waiting for Enter
    Console.ReadLine();
}
```

### 讨论

让我们稍微讨论一下这个程序。

### 链式调用

请注意ToLower和EndsWith方法的*链式调用*。小写转换的输出并没有存储到任何变量中，而是作为链中下一个方法（即EndsWith）的输入。

### 正面与反面

我们再做一些与条件相关的练习。

### 任务

你将编写一个程序，抛一次硬币（见图16-3）。

![](img/32b055c352c70d22a656320349173d95_241_0.png)

**图16-3.** *抛硬币*

### 解决方案

解决方案的核心是生成一个随机数——0或1——然后将其转换为正面或反面。

代码如下：

```csharp
static void Main(string[] args)
{
    // Random number generator
    Random randomNumbers = new Random();

    // Random number 0/1 and its transformation
    int randomNumber = randomNumbers.Next(0, 1 + 1);

    if (randomNumber == 0)
    {
        Console.WriteLine("Head tossed");
    }
    else
    {
        Console.WriteLine("Tail tossed");
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

### 讨论

我只想提醒你，Next方法要求随机数范围的上限在指定时已经加1。这就是为什么你在前面的程序中写了1+1。当然，你也可以直接写2，但1+1在我看来更符合逻辑：将1作为上限，再加上（有点奇怪的）必需的1。
