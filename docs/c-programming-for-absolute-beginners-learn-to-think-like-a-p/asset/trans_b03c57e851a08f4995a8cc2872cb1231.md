## 使用循环的解决方案

循环可以高效地解决这类问题。实际上，你会发现更多时候需要使用循环来重复类似的活动，而不是完全相同的活动。

```csharp
static void Main(string[] args)
{
    // Output
    Console.WriteLine("My main to-do list:");

    for (int taskNumber = 1; taskNumber <= 10; taskNumber++)
    {
        Console.WriteLine(taskNumber.ToString() + ". To learn");
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

## 讨论

以下各节讨论该程序。

## 控制变量

解决方案的核心是在循环体内使用循环控制变量的值。在该程序中，你将变量命名为 taskNumber，并使用其值进行输出。这样，你就能在第一次循环时显示1，第二次循环时显示2，以此类推。你可以使用调试工具自行检查这种情况。

## 循环从1开始

上一个练习（反复掷骰子）中，循环控制变量从0运行到19。与此相反，这次从1开始比从0开始更方便。这种改变也导致了循环条件的变化。你使用了“小于或等于”测试，而不是“小于”测试。

## 小结

本章向你介绍了循环的主题，循环是一种强大的编程工具，允许你指定重复相同或更常见的类似活动。

对于循环，C# 提供了几种编程结构；你在本章中学习了最基本的 for 循环。在代码中，for 循环由一个控制循环的头部和一个由花括号括起来的、包含要重复语句的循环体组成。头部本身由三个用分号分隔的部分组成：

-   *初始化器*是在循环开始“转动”之前执行一次的语句。
-   *循环条件*是在每次循环之前评估的条件。如果条件满足（即计算结果为 true），则执行循环体的另一轮语句。如果条件不满足（即计算结果为 false），则循环终止，程序执行继续到循环之后的语句。
-   *迭代器*是在每次循环之后执行的语句。

为了更深入地理解 for 循环的工作原理，一定要使用调试工具，如单步执行和内存检查。

for 循环通常由一个变量控制，该变量多少类似于循环轮次的计数器。这个变量称为*控制变量*。在最后一个任务中，你学习了如何在循环体内使用控制变量的值。

代码如下：

```csharp
static void Main(string[] args)
{
    // Inputs
    Console.Write("Enter text to repeat: ");
    string textToRepeat = Console.ReadLine();

    Console.Write("Enter number of repetitions: ");
    string input = Console.ReadLine();
    int howManyTimes = Convert.ToInt32(input);

    // Output
    for (int count = 0; count < howManyTimes; count++)
    {
        Console.WriteLine(textToRepeat);
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

### 备注

请注意以下几点：

-   条件不必写成 `learning == true`。learning 变量已经是 bool 类型，这意味着你可以直接将其用作条件。当它为 true 时，条件成立。
-   你需要在进入循环之前设置变量的初始值。初始值在循环的第一次迭代中使用。在本例中，你将其设置为 true。
-   使用取反运算符（`!`）在 true 和 false 之间切换。

### 第三种解决方案

第三种解决方法是循环五次而不是十次，并在循环的每一次迭代中同时执行“奇数活动”和“偶数活动”。

代码如下：

```csharp
static void Main(string[] args)
{
    // Preparations
    Console.WriteLine("My main to-do list:");
    int taskNumber = 1;

    for (int coupleCount = 0; coupleCount < 5; coupleCount++)
    {
        // Couple output and adjusting task number
        Console.WriteLine(taskNumber.ToString() + ". Learning");
        taskNumber++;
        Console.WriteLine(taskNumber.ToString() + ". Dating");
        taskNumber++;
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

### 讨论
