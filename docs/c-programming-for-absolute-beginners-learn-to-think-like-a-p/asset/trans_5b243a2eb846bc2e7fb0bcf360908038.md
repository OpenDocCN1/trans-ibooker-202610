
## 结构

在 C# 中，你同样可能会遇到术语*结构*或*结构体*。什么是结构？

嗯，你可以将它们视为某种轻量级的类。在初学者水平上，它们与普通类几乎无法区分，因此在很长一段时间内，你可以在任何看到*结构*或*结构体*的地方简单地用*类*一词替代。

例如，DateTime 就是结构的一个典型例子。然而，为了简便起见，在本书中所有地方我都将 DateTime 与 Random 或 CultureInfo 等普通类同等对待。在本书的层面上，你可能会感觉到的唯一细微差别是，DateTime 对象不一定非要通过构造函数调用等方式显式创建。只需声明一个该类型的变量即可，尽管这可能不太实际。

你首次初步了解了对象编程的术语。具体请注意以下几点：

- *类*一词是“对象数据类型”的同义词。你经常会读到特定类的对象，这意味着“特定类型的对象”。

### 解决方案

Console.ReadLine 始终读取文本，即使其含义是数字。如果你想保存一个真正的数字（即 int 类型的值），你必须使用 Convert.ToInt32 调用来生成它。

```csharp
static void Main(string[] args)
{
    // Prompting the user
    Console.Write("How old are you? ");

    // Reading line of text
    string input = Console.ReadLine();

    // CONVERTING TO NUMBER (of entered text)
    int enteredNumber = Convert.ToInt32(input);

    // Output of entered number
    Console.WriteLine("Your age: " + enteredNumber);

    // Waiting for Enter
    Console.ReadLine();
}
```

### 讨论

严格来说，你实际上还不需要一个真正的数字，因为你还没有对这些数字进行任何计算。不过，这将在下一个练习中改变。在这里，你是在以最简单的形式探索数字输入。

### 使用输入的数字进行计算

你现在将对用户输入的值进行第一次计算。

### 任务

你将编写一个程序，接受用户输入的出生年份，然后计算他们的年龄（见图 8-4）。

![](img/32b055c352c70d22a656320349173d95_123_0.png)

图 8-4. 计算年龄

### 解决方案

解决方案如下：

```csharp
static void Main(string[] args)
{
    // Prompting the user
    Console.Write("Enter year of your birth: ");

    // Reading line of text
    string input = Console.ReadLine();

    // CONVERTING TO NUMBER (of entered text)
    int yearOfBirth = Convert.ToInt32(input);

    // Finding this year
    DateTime today = DateTime.Today;
    int thisYear = today.Year;

    // Calculating age
    int age = thisYear - yearOfBirth;

    // Outputting the result
    Console.WriteLine("This year you are/will be: " + age);

    // Waiting for Enter
    Console.ReadLine();
}
```
