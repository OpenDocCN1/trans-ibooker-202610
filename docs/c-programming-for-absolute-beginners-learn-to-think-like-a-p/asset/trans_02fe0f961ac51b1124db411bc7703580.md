## 第 22 章 数列

许多编程任务都可以归结为生成有规律的数列。这就是本章将要学习的内容。通过这种方式，你还将更好地理解循环。

### 每隔一个

你已经能够生成一个简单的数列，比如从 1 到 10。现在你将着手生成更复杂一些的数列。

#### 任务

在此任务中，你将显示“每隔一个”的数，直到 20（见图22-1）。

![](img/32b055c352c70d22a656320349173d95_318_0.png)

*图 22-2. 数字递减*

#### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Output
    for (int number = 10; number >= 1; number--)
    {
        Console.WriteLine(number);
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

#### 讨论

请注意以下几点：

- 循环的*初始化器*可能是最简单的。你只需从 10 开始。
- *迭代器*也不难；数字是递减的，所以你只需在每一轮结束时减 1。
- 最困难的是*循环条件*。你必须以这样的方式来构造它：只要你想让循环继续，它就成立；当你想退出时，它就不再成立。正确的判断标准是 number 变量是否大于或等于 1。

### 二次幂

那么，如果在一行中显示两个相关联的数字呢？

#### 任务

除了显示 1 到 10 数列中的数字之外，你还可以在每一行输出中显示对应的二次幂（见图22-6）。

![](img/32b055c352c70d22a656320349173d95_323_0.png)

*图 22-6. 显示二次幂*

#### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Output
    for (int number = 1; number <= 10; number++)
    {
        int secondPower = number * number;
        Console.WriteLine(number.ToString() + " + " + secondPower.ToString());
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

### 两个独立数列

将来某天你可能会遇到另一个有趣的情况：两个独立的数列。

#### 任务

你将有两个略显随意、成员数量不同的数列。第一个数列每次递减 2（111, 109, ..., 97），第二个数列每次递增 3（237, 240, ..., 270）。

程序将在每一行同时显示第一个数列中的一个数和第二个数列中的一个数（见图22-8）。

![](img/32b055c352c70d22a656320349173d95_327_0.png)

*图 22-8. 更复杂的交替*

#### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Preparation
    int first = 111;

    // Output
    for (int second = 237; second <= 270; second += 3)
    {
        // Preparing first text
        string firstText = first >= 97 ?
            first.ToString().PadLeft(3) : "   ";

        // Actual output
        Console.WriteLine(firstText + " " + second.ToString());

        // Changing x
        first -= 2;
    }

    // Waiting for Enter
    Console.ReadLine();
}
```

#### 讨论

请注意以下几点：

- 其中一个数列（较长的那个）使用循环的控制变量来显示，另一个数列则使用一个独立的变量。
- 在每一步中，你都要检查较短的数列是否仍在继续。
- 为了实现良好的格式，你使用了 PadLeft 方法调用，它会在其参数的左侧添加空格，以达到指定的总字符数。

### 小结

在本章中，你在生成各种数列的任务中练习了循环。具体来说，你学习了以下内容：

- 当数列以 2 为步长时，如何编写循环的迭代器。
- 如何在循环体中不直接显示控制变量，而是显示由它推导（计算）出的值。
- 如何在循环的迭代器中使用 -- 运算符来生成递减数列，并使用 >= 运算符指定循环条件，使它在你想继续循环的期间一直成立。
- 小数数列需要格外小心，因为小数在内存中的表示并不精确。这意味着，例如，你需要在循环条件中留出额外的余量。

你还解决了单个输出行中有两个数字的情况，以及最后更有难度的两个独立数列的任务。

## 第 23 章 未知的重复次数

到目前为止，你所解决的所有循环中，你都知道迭代次数。但有时在编写程序时你并不知道这个次数，因为次数要由用户输入。不过，在所有情况下，当循环开始运行时，它将要迭代多少次就已经确定了。

有时，循环开始执行时，重复次数仍是未知的。你经常会遇到这样一个问题：循环应该继续还是终止。

### 输入密码

第一个任务与登录有关。你无法预先知道用户需要尝试多少次。

#### 任务

你将反复要求用户输入密码，直到用户输入正确的密码为止（见图23-1）。正确的密码是 *friend*。

![](img/32b055c352c70d22a656320349173d95_331_0.png)

*图 23-1. 反复询问*

#### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    string correctPassword = "friend";

    bool ok; // the variable must be declared outside of the loop!
    do
    {
        // Input
        Console.Write("Enter password: ");
        string enteredPassword = Console.ReadLine();

        // Evaluating
        ok = enteredPassword == correctPassword;
    } while (!ok); // loop repeats when the condition holds

    Console.WriteLine("Come inside, please...");

    // Waiting for Enter
    Console.ReadLine();
}
```
