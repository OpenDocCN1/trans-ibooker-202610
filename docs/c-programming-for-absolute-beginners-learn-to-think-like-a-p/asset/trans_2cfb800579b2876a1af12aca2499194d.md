## 第6章 使用对象操作

你已经从前一章了解到，对象是一种由几个“数据块”组成的数据集合体。你还知道，输入对象名、点和组件名即可访问对象的各个组件。在本章中，你将发现编程中的对象更为复杂。你将学习到，除了数据组件之外，对象还能封装你可以对该对象执行的操作。通过几个任务，你将练习使用对象操作。

### 以文本形式显示月份

第一个任务将向你介绍可以对 DateTime 对象执行的操作。

**任务**

你将编写一个程序，以文本形式（而非数字形式，或一般称为长格式）显示当前日期中的月份，如图 6-1 所示。

![](img/32b055c352c70d22a656320349173d95_96_0.png)

图 6-1 以文本形式显示当前日期中的月份

你可以使用 DateTime 对象的 ToLongDateString 操作来完成此任务。

**解决方案**

代码如下：

```csharp
static void Main(string[] args)
{
    // Today's date
    DateTime today = DateTime.Today;

    // Output
    Console.WriteLine("Today is " + today.ToLongDateString());

    // Waiting for Enter
    Console.ReadLine();
}
```

**讨论**

请注意以下几点：

- 在 C# 中调用某个对象操作时，操作名称后面总是带有括号（圆括号），即使括号内没有任何内容。
- 括号内通常不是空的，而是包含一个*参数*（或多个参数），这些参数是操作特有的信息。例如，在 `Console.WriteLine` 操作中，你在括号内指定要显示的内容。
- 可以对对象执行的操作也称作*方法*。
- `ToLongDateString` 方法显示的月份名称取决于操作系统的语言设置。

### 显示明天

DateTime 对象除了能将日期转换为文本外，还有更多可用的操作。日期算术尤其重要。

**任务**

你将编写一个显示明天日期的程序（见图 6-2）。

![](img/32b055c352c70d22a656320349173d95_98_0.png)

图 6-2 显示明天的日期

**解决方案**

DateTime 对象可以执行更多有趣的操作（方法），例如：

- 使用 `AddDays` 进行日期算术
- 使用 `ToShortDateString` 以短格式显示日期

代码如下：

```csharp
static void Main(string[] args)
{
    // Today's date
    DateTime today = DateTime.Today;

    // Tomorrow's date
    DateTime tomorrow = today.AddDays(1);

    // Output
    Console.WriteLine("Today is " + today.ToShortDateString() + ".");
    Console.WriteLine("I will start learning on " + tomorrow.ToShortDateString() + ".");

    // Waiting for Enter
    Console.ReadLine();
}
```

### 显示指定日期

让我们继续处理日期，并了解什么是构造函数。

**任务**

处理日期时，你不必总是从今天的日期开始。你也可以选择某个特定的日期（见图 6-3）。

![](img/32b055c352c70d22a656320349173d95_99_0.png)

图 6-3 从指定日期开始

**解决方案**

你可以通过调用对象的构造函数来创建一个以特定日期初始化的 DateTime 对象。输入 `new` 关键字，输入类型名称（即 DateTime），并在括号内传入可能的参数。在这种情况下，参数是年、月、日。

```csharp
static void Main(string[] args)
{
    // A specific date
    DateTime overlordDday = new DateTime(1944, 6, 6);

    // Output
    Console.WriteLine("D-Day (Overlord operation): " +
                      overlordDday.ToLongDateString() + ".");

    // Waiting for Enter
    Console.ReadLine();
}
```

### 掷一个骰子

关于日期的内容到此为止。现在你将学习如何处理随机性。

**任务**

你将编写一个“掷”三次骰子的程序（见图 6-4）。

![](img/32b055c352c70d22a656320349173d95_100_0.png)

图 6-4 掷骰子

**解决方案**

要处理随机性，你需要一个*随机数生成器*。在 C# 中，你可以使用 Random 对象来实现此目的。

首先，在程序运行开始时，通过调用其构造函数**一次**来创建 Random 对象，然后**重复**调用名为 Next 的方法。

```csharp
static void Main(string[] args)
{
    // Creating random number generator object
    Random randomNumbers = new Random();

    // Repeatedly throwing a die
    int number1 = randomNumbers.Next(1, 6 + 1);
    int number2 = randomNumbers.Next(1, 6 + 1);
    int number3 = randomNumbers.Next(1, 6 + 1);

    // Output
    Console.WriteLine("Thrown numbers: " +
        number1 + ", " +
        number2 + ", " +
        number3);

    // Waiting for Enter
    Console.ReadLine();
}
```

**注意**

Next 方法（操作）在括号内需要两个参数：

- 生成数字区间的下界
- 上界**加上1**（抱歉，这个怪癖并不是我发明的）

### 掷两个骰子

继续随机数的话题，你将看到如何使用多个随机数序列。

**任务**

你将编写一个程序，投掷一对骰子三次（见图 6-5）。我会向你展示正确的方法和错误的方法。

![](img/32b055c352c70d22a656320349173d95_102_0.png)

图 6-5 三次掷骰子

**解决方案**

解决方案的关键信息是使用单一的随机数生成器。如果你几乎同时创建两个生成器，它们通常会生成相同的数字！代码如下：

```csharp
static void Main(string[] args)
{
    // 1. CORRECT SOLUTION
    // Creating random number generator object
    Random randomNumbers = new Random();

    // Repeatedly throwing two dice
    int correctNumber11 = randomNumbers.Next(1, 6 + 1);
    int correctNumber12 = randomNumbers.Next(1, 6 + 1);

    int correctNumber21 = randomNumbers.Next(1, 6 + 1);
    int correctNumber22 = randomNumbers.Next(1, 6 + 1);

    int correctNumber31 = randomNumbers.Next(1, 6 + 1);
    int correctNumber32 = randomNumbers.Next(1, 6 + 1);

    // Output
    Console.WriteLine("CORRECTLY");
    Console.WriteLine("Thrown couples: " +
        correctNumber11 + "-" + correctNumber12 + ", " +
        correctNumber21 + "-" + correctNumber22 + ", " +
        correctNumber31 + "-" + correctNumber32);

    // 2. INCORRECT SOLUTION
    // Two random number generators
    Random randomNumbers1 = new Random();
    Random randomNumbers2 = new Random();

    // Repeatedly throwing two dice
    int incorrectNumber11 = randomNumbers1.Next(1, 6 + 1);
    int incorrectNumber12 = randomNumbers2.Next(1, 6 + 1);

    int incorrectNumber21 = randomNumbers1.Next(1, 6 + 1);
    int incorrectNumber22 = randomNumbers2.Next(1, 6 + 1);

    int incorrectNumber31 = randomNumbers1.Next(1, 6 + 1);
    int incorrectNumber32 = randomNumbers2.Next(1, 6 + 1);

    // Output
    Console.WriteLine(); // empty line
    Console.WriteLine("INCORRECTLY");
    Console.WriteLine("Thrown couples: " +
        incorrectNumber11 + "-" + incorrectNumber12 + ", " +
        incorrectNumber21 + "-" + incorrectNumber22 + ", " +
        incorrectNumber31 + "-" + incorrectNumber32);

    // Waiting for Enter
    Console.ReadLine();
}
```

### 获取桌面路径

作为本章的结尾，你将了解另一个对象的操作。

**任务**

处理文件时，你可能想在用户的桌面上创建文件。但是，每个人访问桌面的文件系统路径都不同。我将向你展示如何找到该路径（见图 6-6）。

![](img/32b055c352c70d22a656320349173d95_104_0.png)

图 6-6 查找路径

**解决方案**

你可以使用老朋友 Environment 对象。代码如下：

```csharp
static void Main(string[] args)
{
    // Finding path to the desktop
    string pathToDesktop = Environment.GetFolderPath(Environment.
        SpecialFolder.Desktop);

    // Output
    Console.WriteLine("Path to your desktop: " + pathToDesktop);

    // Waiting for Enter
    Console.ReadLine();
}
```
