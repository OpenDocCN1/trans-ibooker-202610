# Documentation

IntelliSense can give you many tips. It can also show you the basic usage of the feature you search for. However, the place where you can find all the detailed information is the online documentation.

# docs.microsoft.com

The Web at http://docs.microsoft.com is the best place to start looking for anything concerning C# and other Microsoft technologies (see Figure 14-6). On the page, click “Documentation” and then go directly to “C#”.
