## 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Some text to try things on
    string text = "This is the last day of our acquaintance";

    // What e.g. can be done with texts
    Console.WriteLine("Original text: " + text);
    Console.WriteLine("Number of characters: " + text.Length);
    Console.WriteLine("In uppercase: " + text.ToUpper());
    Console.WriteLine("Does it contain word \"last\"? " + text.Contains("last"));

    // Waiting for Enter
    Console.ReadLine();
}
```

## 讨论

数据成员（例如 `Length`）不带括号，而方法（如 `ToUpper`、`Contains`）则始终需要括号，即使括号之间没有任何内容。

## 解决方案

要将数字转换为其文本表示形式，请使用 `ToString` 方法。实际上，要将**任何**内容转换为文本，在 C# 中你始终可以使用 `ToString` 方法（操作）。

```csharp
static void Main(string[] args)
{
    // Some number
    int number = 1234;

    // Conversion to text
    //string numberAsText = number; // DOES NOT WORK!
    string numberAsText = number.ToString();

    // Output
    Console.WriteLine("Output of number: " + number);
    Console.WriteLine("Output of text: " + numberAsText);

    // Waiting for Enter
    Console.ReadLine();
}
```

## 讨论

你可以看到，`int` 类型的值不能直接赋值给 `string` 类型的变量。你必须先将其转换为文本形式。

当然，在输出中你不会看到任何差异（参见图 7-3）。

![](img/32b055c352c70d22a656320349173d95_111_0.png)

**图 7-3.** *输出*

然而，很多时候你需要将数字转换为文本，但并不立即显示它。这时你会将值的文本形式存储在 string 类型的变量中，这正是你刚才看到的。

为了结束讨论，我将告诉你为什么在图 7-3 中显示的两行看不出任何区别：

-   `Console.WriteLine` 方法会将其获得的所有内容都转换为文本。它会在幕后静默地使用 `ToString` 转换来实现这一点。

-   如果你使用加号将某些文本与数字连接起来，则该数字会在 C# 中自动转换为文本。如果你希望获得更多控制权，请在处理数字时始终写下 `.ToString()`。

## 数字格式化

在之前的练习中，你一直在忙于将数字转换为其文本表示形式。然而，一个数字可以以多种文本形式表达。你现在将了解小数位、四舍五入、千位分隔等。

### 任务

在本练习中，你将看到使用 `ToString` 方法获取格式良好数字输出的几个示例（参见图 7-4）。

![](img/32b055c352c70d22a656320349173d95_112_0.png)

**图 7-4.** *格式良好的输出*

### 解决方案

代码如下：

```csharp
static void Main(string[] args)
{
    // Some money amounts and a number
    double amount = 1234.56;
    double anotherAmount = 789;
    int wholeNumber = 1234567;

    // Formatted outputs
    Console.WriteLine("Separating thousands and millions + money to cents");
    Console.WriteLine(amount.ToString("N2"));
    Console.WriteLine(anotherAmount.ToString("N2"));
    Console.WriteLine(wholeNumber.ToString("N0"));

    // Waiting for Enter
    Console.ReadLine();
}
```

与之前的练习相反，`ToString` 方法调用现在在括号之间有一个参数。*格式字符串*指定了输出的样式。

在此处使用的格式字符串中，`N` 表示需要千位分隔，而 2 和 0 表示输出中的小数位数。

## 类

任何涉及对象的文档或教科书都充满了*类*一词的用法。那么，这是什么意思呢？简单来说，*类*是对象数据类型的同义词。你可以说“Random 类的对象”，而不是“Random 类型的对象”。这意味着类也可以视为某种对象类型的名称。

### 类与对象的关系

从另一个角度来看，类也是定义特定种类对象包含什么以及如何行为的 C# 源代码。你也可以说，类充当对象的模板。例如，Random 类的源代码（由 Microsoft 拥有，而不是你）定义了*所有* Random 对象将具有哪些属性和方法。

因此，所有 Random 对象的行为方式相同，因为它们都是从同一个模板或同一个类创建的。对于所有 DateTime、所有 CultureInfo 等也是如此。

换句话说，正如面向对象编程的一句著名格言所说，*对象*是类的一个实例。*实例*一词表示单个实现或单个出现。

### 特殊类

在本章中，你看到了文本、数字等也具有对象般的行为。以下是它们对应的类：

| 数据类型 | 对应的类 |
| --- | --- |
| `string` | `String` |
| `int` | `Int32` |
| `double` | `Double` |
| `bool` | `Boolean` |
| `...` | `...` |

在 C# 中，你可以互换使用 `string` 和 `String`、`int` 和 `Int32`，以此类推。当然，你需要在源代码顶部添加 `using System;` 行，因为所有对应的类都属于该特定命名空间。
