

## 应用可持续发展目标 16

Taylor Smith

Free to Run 在世界上一些最具挑战性的地区运营，数十年的冲突和不稳定导致妇女和女孩极度孤立，并遭受骚扰、行动受限以及受教育机会不平等。通过体育项目、生活技能发展和社区外展相结合的方式，Free to Run 帮助妇女和女孩重新夺回公共空间，并改变人们对她们在社会中可以和应该扮演的角色的看法。通过此举，Free to Run 支持妇女和女孩将成功转化为日常生活，使她们能够成为并将成为建设持久平等公正社会的积极力量。

自 2014 年以来，Free to Run 已在冲突地区与超过 3,500 名妇女和女孩合作，包括在香港、南苏丹和刚果民主共和国的过往项目，以及在阿富汗和伊拉克的当前项目。2020 年，Free to Run 因其大胆使用体育而获得 Beyond Sports & Social Justice Award，因其最具颠覆性的由女孩领导的组织而获得 With & for Girls 中东和北非奖，创始人兼主席 Stephanie Case 代表加拿大政府秘书办公室获得 Meritorious Service Medal。

## 49.1 与可持续发展目标的关系

Free to Run 将跨文化的妇女和女孩团结起来，提供分享经验和挑战先入为主观念的支持，以支持以下可持续发展目标：

- SDG 4: 优质教育：通过 Free to Run 的体育生活技能（LSS）课程，妇女和女孩被教授成为自力更生并掌控自己生活的技能，包括积极沟通、冲突预防和领导力技能。
- SDG 3: 良好健康与福祉：通过 LSS 获得的技能转化为年轻女孩和妇女生活的各个方面，监测与评估（M&E）显示出对持续的心理、身体和社会福祉的积极影响。
- SDG 5: 性别平等：Free to Run 利用创新的体育活动支持妇女和女孩重新夺回公共空间，通过提高可见度构建对其未来的另类愿景。
- SDG 10: 减少不平等：通过当地社区参与，妇女和女孩将 LSS 中学到的技能应用于其社区，使她们在公共空间中接触到积极的认知并挑战不平等。
- SDG 16: 和平、正义与强大机构：Free to Run 对跨区域活动的重视鼓励社会包容和女性参与公共空间、决策过程以及社区领导角色，支持她们积极参与和平建设运动。

## 49.2 FTR 的方法

作为一个由妇女和青年领导的组织，Free to Run 利用冒险体育和生活技能支持冲突地区的妇女和女孩建立身体、情感和社会福祉，加强她们参与当地社区并积极参与其中，以团结不同文化、种族和宗教背景的人。为实现这一目标，Free to Run 采取以下方法：

- 社区认可：Free to Run 与学校、家长、社区成员和其他关键利益相关者保持开放对话，讨论项目结构和提供的活动，回答问题并分享女性参与体育的好处。
- 创造安全空间：Free to Run 为妇女和女孩创造安全空间，让她们以她们从未认为可能的方式和地点保持活跃。通过定期的社区志愿服务和积极的社区互动，Free to Run 挑战社区对女性角色的先入为主观念，增加社区接受度并扩大公共安全空间。
- 提高可见度：Free to Run 将妇女和女孩带出其通常的环境，并通过体育教育创造新的体验机会，使她们跨文化团结，为她们提供空间、时间和支持以开始分享经验和挑战先入为主观念。这使她们能够彼此以及周边社区的人们所看见。
- 通过冒险体育学习：Free to Run 的 LSS 课程与冒险体育一起教授，例如跑步、徒步和皮划艇，教授领导力、冲突解决、韧性和有效沟通所需的技能。

## 49.3 执行

### 49.3.1 挑战

由于 Free to Run 专注于冲突地区的妇女和女孩，安全始终是一个挑战。作为回应，项目设计为能够灵活应对关键事件，即使在与安全相关的障碍下也能相对顺畅地运行。Free to Run 还依靠一小群个人关系和协议以及多变的、可识别的行动模式来确保项目和参与者的安全。

2020 年，Free to Run 面临前所未有的挑战：COVID-19。幸运的是，Free to Run 专注于社交距离活动（在户外重新夺回公共空间和使用非接触式体育）以及出于安全原因对灵活的虚拟、混合或面对面编程的适应性，使得能够迅速反应，将项目中断降至最低。Free to Run 目前采用三步方法，使用双周评估、项目/行动关键性矩阵和重新开放指南来确定项目交付形式。初步的 2020 年 M&E 数据表明，尽管由于 COVID-19，受益人数和活动总数较低，但项目的成效同样显著。

### 49.3.2 成功

尽管伊拉克和阿富汗持续存在安全问题，Free to Run 已交付了几项开创性举措。成功包括：

- 2019 年，我们通过体育和教育课程在两个国家（伊拉克和阿富汗）和七个省份（阿富汗的喀布尔、马扎尔、坎大哈、赫尔曼德和巴米扬，以及伊拉克的埃尔比勒和摩苏尔）接触了超过 870 名参与者，其中包括超过 30 名残疾参与者。¹
- 迄今为止，我们正在进行超过 1,800 次体育课程，包括跑步、力量训练、瑜伽和冥想、排球、冰上滑冰、骑自行车和滑雪。
- 迄今为止，我们通过 FTR 的 LSS 和营养课程进行超过 1,050 次教育课程。
- 迄今为止，我们正在进行超过 40 次社区外展活动、六次跨区域体育和领导力周、四次残奥会比赛和 13 次混合性别比赛。
- 支持了阿富汗第一位完成马拉松的女性和首支参加国际超级马拉松的阿富汗女子队。

额外的成功可以通过我们参与者的故事来讲述。首先，2020 年，Free to Run 参与者 Shaymaa 获得了 Courageous Use of Sport Award Winner。她原籍 Sinjar，因逃离 ISIS 而流离失所至埃尔比勒的国内流离失所者（IDP）营地。Shaymaa 于 2018 年加入 Free to Run，并坚持克服极其困难的处境，成为 Free to Run 的教练、妇女权利倡导者和社区活动家。谈及体育在赋权女性方面的重要性，Shaymaa 说：“体育是生存的秘密，是实现我无法做到的事的动力。它是在流离失所和男性主导的黑暗中，我被迫挑战的黑暗中的一束光。”其次，Sediqa 17 岁时加入 Free to Run。起初，由于传统信仰，她的家人不允许她加入。然而，在 Free to Run 的支持下，Sediqa 的家人允许她加入。Sediqa 前往中部高地参加冬季跨区域体育与领导力周——这是她第一次独立旅行。谈及 Free to Run 的影响，Sediqa 说：

> （冬季体育周）已经过去一年多，但我仍然记得能够做曾经对我来说不可能的事情的那种强大的感觉。它在每当我面临困难情况时都成为积极能量的来源。现在，我正在准备大学入学考试。每天清晨，我都告诉自己我能做到。正如我找到了加入 Free to Run 并独自前往另一个省份与他们同行的方法一样，我也会通过考试并克服生活中的任何其他挑战。
