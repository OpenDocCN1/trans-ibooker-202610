### 可持续发展目标 16 概述

Jon Welty Peachey 和 NaRi Shin

在 20 世纪后期到 21 世纪，联合国对体育在实现各种可持续发展目标方面的潜力产生了日益增长和不断演变兴趣，例如建设和平、冲突解决以及创建公正的机构和社会。联合国前秘书长科菲·安南在 2005 年一次奥运援助圆桌会议上表达了他对体育在促进社会变革方面的可能性看法：

> 体育可以改善个人的生活，不仅是个人，我要补充的是，整个社区的生活。我坚信现在是时候在此基础上建设，鼓励政府、发展机构和社区思考如何更系统地将体育纳入帮助儿童的计划中，特别是那些生活在贫困、疾病和冲突中的儿童。 (United Nations, 2005, p. 1)

安南的愿景在 2001 年得以实现，当时联合国创建了体育促进发展与和平办公室，该办公室负责激活和支持联合国利用体育的力量发展个人、社区、组织和社会 (Cohen & Welty Peachey, 2019)。该办公室于 2017 年解散，其职责转交给国际奥委会和其他国际体育组织，以继续支持体育在发展中发挥积极作用 (Shin et al., 2020)。

然而，联合国对体育作为发展工具的兴趣并未减弱。随着联合国 2015 年可持续发展目标的出台，体育再次被视为协助实现这些崇高目标的可行机制。在本章中，我们重点关注 SDG 16，其重点是“促进可持续发展的和平包容社会，为所有人提供司法获取渠道，并在所有层面建立有效、负责和包容的机构” (General Assembly, 2015, p. 14)。这可以说是一个非常宽泛的可持续发展目标范围，因为它同时关注更广泛社会中的和平、包容和正义问题以及机构层面的问题。在本章中，我们将审视体育与该可持续发展目标的交集。

就联合国在本可持续发展目标中促进可持续发展的和平、包容和公正社会这一重点而言，体育促进发展与和平 (SDP) 领域在许多层面与该目标相交。SDP 被定义为“利用体育对公共卫生、儿童、青年和成人的社会化、弱势群体的社会包容、地区和国家的经济发展，以及促进跨文化交流和冲突解决产生积极影响” (Lyras & Welty Peachey, 2011, p. 311)。SDP 领域近年来发展迅速，全球有超过一千个组织提供利用体育解决个人、社区和社会发展问题的项目 (Svensson & Woods, 2017)。例如，以色列的 Football 4 Peace International (F4P) 项目始于 2001 年，利用足球运动在中东地区弥合以色列和巴勒斯坦青年之间的文化鸿沟 (Sugden, 2006; Sugden & Spacey, 2020)。该项目强调社会正义、人权和平等，致力于缓解紧张局势并在历史上冲突的社区之间建立桥梁。因此，F4P 的工作与本可持续发展目标直接相关，因为它致力于促进可持续发展的和平包容社会，并努力为所有人提供司法获取渠道。

SDG 16 的第二个方面侧重于在所有层面建立有效、负责和包容的机构。不幸的是，体育充斥着世界各地机构和组织为追求商业或社会目标而从事不当甚至不道德行为的例子。在体育领域，只需看看奥运会的许多贿赂丑闻，以及 FIFA 主席约瑟夫·布拉特从 1998 年到 2015 年任职期间的财务管理不善和资金挪用，他目前因该运动被禁赛六年 (Conn, 2017)，就是损害体育在社会中的价值和作用的行为的例子。或者，在美国的大学体育中，可以指出与宾夕法尼亚州立大学杰里·桑达斯基丑闻有关的掩盖行为，他在担任助理足球教练期间多年性虐待男孩和年轻男子，或教练参与的众多招募违规和不道德行为，很容易看出体育行业在不断努力创造公正、包容、负责和道德的机构和实体 (Burton & Welty Peachey, 2013)。为与 SDG 16 相一致，已采取措施解决体育领域正义、包容和平等问题，包括探索体育领导力的新模式，但仍有很长的路要走。

下面，我们首先定义并讨论与 SDG 16 相关的目标。然后我们讨论与体育和 SDG 16 交集相关的一些理论基础，然后更详细地讨论 SDG 16 在体育背景下的激活情况。讨论将集中于体育组织如何参与社区以促进可持续发展目标，以及体育组织如何在日常运营中遵守可持续发展目标。

### 47.2 理论基础

学者们采用了多种理论基础和框架来支撑其与 SDG 16 相关的工作。虽然其中一些框架源自体育情境，但大多数都是以衍生方式从其他学科中借鉴而来，这是由于其社会和制度相关性（Chalip, 2006）。以下部分阐述了体育学者借鉴的许多流行且重要的基础和框架，但该列表当然并非详尽无遗。下面的理论基础和框架展示了体育学者参与 SDG 16 的深度和广度，但可以肯定的是，随着更多以体育为重点的理论概念化得到推进，其他框架将继续出现（Chalip, 2006）。

#### 47.2.1 体育促进发展理论

体育促进发展理论（SFDT；Lyras, 2007, Lyras & Welty Peachey, 2011, 2015）是在 SDP 情境中发展起来的，旨在帮助解释体育类项目应如何最好地设计和管理以实现积极成果，例如在微观、中观和宏观层面的和平建设、冲突解决、包容和公正社会，因此与 SDG 16 高度相关。SFDT 借鉴了跨学科的理论和概念基础

包括组织理论、群体间接触理论、人本心理学、教育心理学以及研究理论和方法（Lyras & Welty Peachey, 2011, 2015）。SFDT 有五个关键组成部分：（a）影响评估，（b）组织，（c）体育和身体活动，（d）教育，和（e）文化丰富。

SFDT 认为影响评估应衡量随时间推移的多层次变化，并且需要自上而下和自下而上的组织结构，这些结构具有文化敏感性并让所有利益相关者发声（Lyras & Welty Peachey, 2011）。关于体育和身体活动，SFDT 认为非传统体育项目和包容性游戏至关重要，竞争水平应与所服务的群体性质相匹配，并且应伴随高质量的教育课程，以促进学习成果向现实世界的迁移。最后，文化活动如音乐、舞蹈和艺术应与体育和教育项目打包在一起。综合起来，这些组成部分可以为旨在促进和平、包容和公正社会——正如 SDG 16 所规定的 SDP 干预提供一个整体的、理论上扎实的项目和设计策略（Lyras & Welty Peachey, 2015）。

#### 47.2.2 涟漪效应模型

涟漪效应模型（Sugden, 2010）借鉴了批判性左派现实主义和自下而上的行动主义，以通过体育影响积极的社会变革并促进和平建设，成为 SDG 16 的有力理论基础。该模型源于 Sugden 的 F4P 项目，即以色列北部的一个体育促进冲突解决项目（Sugden, 2006, 2010）。该模型认为，通过社会和文化参与，基层的和平活动家可以与来自体育内部和外部的关键合作伙伴携手，在任何特定情境中激活积极和包容性的变革。重要的是，特定 SDP 项目的影响在干预的中心最清晰地感受到且最容易衡量。随着涟漪远离中心并到达项目的下一层级（即参与者的家庭、其当地社区、相关利益相关者和更广泛的政治领域），它们会消散并减弱。

#### 47.2.3 体育促进发展框架

同样源自 SDP 情境，Schulenkorf（2012）的体育促进发展（S4D）框架提出了一个概念性的、过程导向的管理工具，旨在为体育和赛事规划、管理以及利用提供信息。虽然该框架旨在解决针对一系列成果的 SDP 干预的管理和利用问题，但它主要被用来帮助理解体育项目如何设计以促进和平建设和包容，直接与 SDG 16 相连。凭借其可塑性框架，S4D 优势在于文化异质性和项目多样性，同时塑造实施、指导评估并鼓励发展举措的未来规划。S4D 框架可以整合通过参与式体育活动产生的社会过程，作为指导框架，它提倡对个别项目进行量身定制的应用，以解决指定的目标和成果。

#### 47.2.4 社会资本

理解个人在社会和体育中的包容与排斥的一个重要理论基础与 SDG 16 相关的是社会资本概念。社会资本是一个有争议的术语，具有多种理论视角，最著名的是归因于 Bourdieu（1986）、Coleman（1988）和 Putnam（2000）。Bourdieu（1986）将社会资本视为“与更或少制度化的关系网络以及相互认识和认可联系在一起的实际或潜在资源的集合”（第 248 页）。因此，社会资本分布不均，取决于个人在其网络中可获得的资源。与 Bourdieu 不同，Coleman（1988, 1994）对社会资本的概念化将其视为一种资源，或“存在于家庭关系和社区社会组织中的资源集合，对儿童或年轻人的认知或社会发展有用”（Coleman, 1994，第 300 页）。在这里，社会资本侧重于人们如何通过自由选择产生的社会过程进行合作以促进自身利益（Coalter, 2007）。

虽然 Bourdieu 和 Coleman 都被体育学者用来为其社会包容和排斥的工作奠定基础，但可以说在学者中最流行的社会资本理论家是 Robert Putnam。对 Putnam（1995）而言，社会资本是“诸如网络、规范和社会信任等社会组织特征，可以促进为互利而进行的协调与合作”（第 66 页）。信任、网络和互惠是 Putnam 概念化中的关键要素。一旦建立信任，网络就可以发展，从而实现包容和社会流动，然后可以发生交换过程（互惠）。促进社会凝聚力和包容性的机制是联结和桥梁。联结社会资本将同质群体之间的社会网络带到前台，例如家庭、邻居或密友。另一方面，桥梁社会资本是在与自己不同的人发展关系时形成的，其中社会联系和纽带可能更松散、更多样化。这些桥梁关系使个人能够利用更广泛的资源，这对于社会凝聚力、包容性和流动性至关重要（Putnam, 1995, 2000）。许多体育和其他学科的学者在其社会包容工作中使用了 Putnam 对社会资本的概念化，为激活 SDG 16 提供了理论锚点。

#### 47.2.5 群体间接触理论

SDG 16 涵盖了全球和平建设、冲突解决和暴力减少的目标和指标。学者们借鉴的一个理论基础来为其和平建设和冲突解决的调查和干预提供依据，无论是在体育内部还是外部，都是 Allport（1954）的群体间接触理论。接触假说源自社会分类框架（Tajfel & Turner, 1979），其中人们将自己和他人归类为社会群体。内群体成员是与自己相似的个体，通常被正面看待并被信任。然而，外群体成员是与自己不同的人，不会被同样正面看待或信任。因此，群体间偏见可能存在，即人们对内群体成员的态度比对外群体成员更积极。例如，在前面描述的 F4P 项目中，一名犹太运动员可能会将其他犹太运动员视为内群体成员，而将阿拉伯运动员视为外群体成员，从而存在群体间偏见的可能性。

因此，在群体间接触理论中（Allport, 1954；Pettigrew, 1998），据建议，内群体和外群体成员之间的个人互动应导致群体间偏见减少。偏见减少是因为接触（a）使人们能够更多地了解外群体，（b）减少他们在外群体成员周围的焦虑，以及（c）增强他们对外群体的同理心和观点采择（Pettigrew & Tropp, 2008）。为


支持接触假说，Pettigrew 和 Tropp（2006）的荟萃分析表明，接触与对群体外成员的偏见存在可靠的负相关。Lederach（1997）也指出，为了促进和解与和平建设，关系必须始于一次相遇，并且这些关系应具有前瞻性，建立信任，并增强群体之间可持续、一致的相互联系。因此，群体间接触可以提供这种相遇，并为彼此差异很大的人之间建立可持续关系的基石，从而为可持续发展目标 16 的和平建设和冲突解决目标做出贡献。

### 47.2.6 组织能力

可持续发展目标 16 的第二个方面侧重于在各层面建设有效、负责任和包容的机构。组织能力是学者在体育内外用来理解组织有效性和问责制的理论基础之一（Hall et al., 2003; Svensson et al., 2018）。总体而言，组织能力是指组织利用一套结构和资源来履行其授权和使命的能力，并且能够有效地、高效地和可持续地做到这一点（Svensson et al., 2018）。Hall 等人（2003）的组织能力模型已成为体育内外众多研究的基石。其框架围绕五种能力展开：（a）人力资源能力，（b）财务能力，（c）外部合作伙伴能力，（d）内部基础设施能力，以及（e）规划与发展能力。组织越能高效有效地发展和利用这些能力，其长期可持续性就越强。

### 47.2.7 领导理论与框架

领导力在组织理论和发展中发挥着关键作用，在建设和维持有效、公正和包容的组织方面也至关重要，同时也是体育为各种个人和社会结果提供干预有效性的重要因素。传统的领导理论和风格，如专制、民主、变革型和交易型，正在让位于更新的、当代的领导模式，如仆人式、共享式、真实性和伦理领导，这些模式对于在各层面创建透明、公正和包容的机构是必要的。事实上，最近的概念性工作已提出，仆人式和共享式领导尤其可能是能够实现更好结果的必要领导范式，例如冲突解决、和平和包容，这些结果适用于利用体育为社会变革和正义问题提供干预的组织（Welty Peachey et al., 2020）。下面将讨论其中几种有影响力的当代领导范式。

#### 47.2.7.1 仆人领导

商业和体育管理领域的近期工作已采纳了仆人领导的范式，该范式源于 Robert Greenleaf（1977）的思想，此后在学术界获得了更多关注。仆人领导以追随者发展为前提，而非关注实现组织成果；通过发展追随者并关注追随者的需求，更好的组织成果将自然实现。正如 Greenleaf（1977）所说，成为仆人领导者是“一种自然的感觉，即一个人想要服务，想要首先服务”（第 7 页）。van Dierendonck（2011）将仆人领导概念化为以下六个维度：赋能与培养人才、谦逊、真实性、人际接纳、提供方向和管家精神。这种领导范式在体育行业中获得了进一步的认可，学者们将其视为解决困扰该行业的许多伦理问题的一种方式，例如在大学体育中（Burton & Welty Peachey, 2013）。学者们也主张其在体育发展计划领域的适用性，其固有的对追随者发展的关注对于实现各种个人和社会结果很重要（Welty Peachey et al., 2020; Welty Peachey & Burton, 2017）。因此，仆人领导是一种可直接适用于可持续发展目标 16 的领导范式，因为它可以帮助组织实现和平与和解、包容和社会正义的发展目标，并有助于建立更透明、负责任、包容和公正的组织。

#### 47.2.7.2 共享领导

与仆人领导类似，最近的工作表明，共享领导模式可能非常有效，能够使体育发展计划组织和干预措施赋权当地利益相关者并实现可持续发展项目（Jones et al., 2018; Welty Peachey et al., 2020）。共享领导也被定位为体育治理和董事会运作中的重要因素（Ferkins et al., 2018）。共享领导被定义为“群体中个人之间的一种动态互动过程，其目标是相互领导以实现群体或组织目标”（Pearce & Conger, 2003, 第 1 页）。其核心是关注组织内部及周边个人和群体之间的动态互动，而非将组织和领导视为静态（Drescher & Garbers, 2016）。与传统的层级领导形式不同，共享领导模式将领导力分配给组织成员和利益相关者，并通过这样做利用成员的技能和知识（Pearce & Conger, 2003）。有人认为，共享领导在体育发展计划背景下可能特别有效，因为领导力可以与当地社区成员共享，从而将权力和责任从体育发展计划组织转移出去，这最终将实现更可持续的结果，例如增强冲突解决和包容举措（Jones et al., 2018; Welty Peachey et al., 2020）。如前所述，共享领导对于董事会运作也很重要，以实现更有效和包容的组织（Ferkins et al., 2018）。

#### 47.2.7.3 真实领导

真实领导是另一种在商业和体育学者中日益受到关注的领导模式，特别是在审视与伦理领导相关的治理和董事会运作问题时（Takos et al., 2018）。Avolio 等人（2004）将真实领导者定义为“那些对自己的思维和行为有深刻认识的人，并且被他人视为对其自身和他人的价值观、知识和优势以及其所处情境有认识的人”（第 4 页）。这里的重点在于领导者带到谈判桌上的积极优势，而非缺点，并且以价值观驱动的行为为领导行为的基础，这种真诚可以赢得众多利益相关者对领导者的更大信任（Takos et al., 2018）。真实领导有四个组成部分：自我意识、人际取向、平衡处理和内化的道德视角（Avolio et al., 2009）。因此，将真实领导与可持续发展目标 16 结合起来，该领导模式可以增强人们对治理和组织如何变得更有效、更公正、更包容和更透明的理解。

#### 47.2.7.4 伦理领导

相关地，伦理领导的概念（Brown & Treviño, 2006）为激活可持续发展目标 16 及其在各层面发展负责任、公正和包容机构的重点提供了一个重要范式。事实上，许多体育学者呼吁在有时存在伦理挑战的体育行业中加强对伦理领导的关注（Staurowsky, 2014; Sagas & Wigley, 2014）。伦理领导是“通过个人行动和人际关系展示规范上适当的品行，并通过双向沟通、强化和决策制定来促进追随者的这种品行”（Mayer et al., 2009, 第 120 页）。伦理领导的一个基本组成部分是榜样作用——如果领导者践行伦理行为和决策，那么下属也会践行伦理行为和决策（Brown et al., 2005）。为了强化下属的伦理行为，伦理领导者对伦理行为提供奖励并惩罚不道德行为（Brown et al., 2005）。学者们主张，关注伦理领导对于遏制社会和体育行业中不道德行为以及不公正的制度和结构是必要的（Burton & Welty Peachey, 2013; Sagas & Wigley, 2014），因此，这一领导范式可直接适用于可持续发展目标 16 建设负责任、公正和包容机构的重点。

### 47.2.8 组织公正

我们以组织公正的简要考察结束本节关于理论基础的讨论，其与可持续发展目标 16 相关，特别关注分配、程序和互动公正。这些框架对体育内外学者和组织理解和改善工作环境中的公平和公正问题很有帮助（Mahony et al., 2010）。本质上，组织公正围绕着工作场所中的公平作用和公平感知（Greenberg, 1990）。它大约在 25 年前随着 Hums 和 Chelladurai（1994）的研究开始在体育学科中获得关注。分配公正关注工作场所中公平、平等和需求感知的公平，其中该领域在体育学科中的大部分工作最初是在大学体育中进行的。程序公正是指决策过程的感知公平，而互动公正则集中于这些决策的沟通（Mahony et al., 2010）。组织公正的学术工作综合表明，员工对公正的感知与工作绩效、工作满意度、组织承诺、组织公民行为和信任相关（Mahony et al., 2010）。因此，组织公正框架有助于理解可持续发展目标 16 在各层面建设负责任、公正、有效和包容机构的重点。

### 47.3 与体育的联系

我们接下来将关注可持续发展目标 16 如何在体育行业的各个层面和背景中得到激活。首先，我们讨论体育组织和实体如何参与社区和社会以促进和激活可持续发展目标 16，然后简要讨论体育组织和实体如何在日常运营中遵守可持续发展目标 16。

#### 47.3.1 体育参与可持续发展目标 16

众多体育组织和实体在过去 25 年里一直参与社区和社会的可持续发展目标 16。关于可持续发展目标 16 促进和平和


为了实现可持续发展的包容性社会，并为所有人提供司法获取，我们可以从奥林匹克运动和奥运会所宣扬的目标以及其历史先例说起。奥运会，当皮埃尔·德·顾拜旦于1896年将其重新振兴时，部分建立在这样一个前提之上：奥运会将通过体育促进世界青年之间的和平与理解（Cohen & Welty Peachey, 2019）。人们设想在奥运会期间冲突将被暂时中止，并且它们最终将通过体育竞赛的催化作用促进国家间的和平建设。奥运会确实已成为变革的催化剂和平台——我们可以回顾1968年墨西哥城奥运会，美国短跑运动员汤米·史密斯和约翰·卡洛斯在领奖台上戴着黑色手套举起拳头，做出与黑人权力运动保持一致的政治声明；或悉尼2000年奥运会上凯西·弗里曼为澳大利亚原住民的权利发声，澳大利亚原住民长期以来在该国遭受种族主义（Cohen & Welty Peachey, 2019）。当然，我们可以质疑这一值得称赞的目标的激活情况，因为奥林匹克运动的商业化日益加剧，奖牌榜在国家之间变得比不分裂更具分裂性，但值得注意的是，在其 arguably 最大的舞台上，体育被设想为和平与正义的基础。

在国际或国家层面，体育被用于和平、正义和包容的其他例子比比皆是。例如，1995年男子橄榄球世界杯对南非的种族融合产生了重大影响，这是种族隔离结束后在该国举行的首个体育赛事。南非首位黑人总统纳尔逊·曼德拉身穿斯普林博克斯队球衣走上球场并颁发冠军奖杯，这是一个重大的政治声明，鉴于斯普林博克斯是南非的国家队。该赛事为白人与黑人南非人之间的和解与统一提供了跳板（Cohen & Welty Peachey, 2019）。

在较小规模上，可以说在和平、正义和包容领域，体育学科和体育实体与可持续发展目标16建立了最紧密的联系。全球众多从事体育发展领域的体育非营利组织和其他实体已启动项目和干预措施，针对历史上处于冲突状态的群体开展和平建设工作，并在促进边缘化和被剥夺权利个人的正义与包容方面发挥作用。F4P项目在以色列已被提及为一项长期存在的体育干预的例子，该项目致力于和平建设和冲突解决，对象是历史上处于冲突状态的群体，在本例中为中东的阿拉伯人和犹太人。更早的例子也存在，例如北爱尔兰贝尔法斯特于20世纪80年代末启动的贝尔法斯特联合项目（Sugden, 1991）。这一社区为基础的干预措施操纵了体育进行的条件，以改善新教徒和天主教青年之间的和平与理解。作为同类首批体育为本干预措施之一，贝尔法斯特联合在短期内成功帮助青年对来自不同宗教传统的人形成更积极的印象。

许多其他以体育为基础的干预措施旨在促进和平与和解，随后纷纷效仿。例如，鸽子奥林匹克运动项目在2000年代于塞浦路斯进行，该干预措施采用体育、文化艺术和教育举措，帮助希腊塞浦路斯人和土耳其塞浦路斯青年弥合文化鸿沟，并在文化理解和冲突解决方面开展工作（Lyras, 2007）。该项目在促进这些青年之间更好理解方面取得了成功，是体育发展领域最重要的理论基础之一——体育发展理论的起源（上文已回顾；Lyras & Welty Peachey, 2011, 2015）。斯里兰卡的另一个类似项目（亚洲-德国体育交流项目，成立于2002年）利用体育试图治愈该国在僧伽罗人、泰米尔人和穆斯林之间因种族分裂而产生的分歧（Schulenkorf, 2010）。

重要的是，战略性设计和管理良好的体育干预有助于建立跨越族群社区界限的人际友谊和包容性社会认同。然而，至关重要的是，该倡议强调此类体育干预活动必须融入持续的政治和社会议程，并获得可持续的社会政治支持，才能在长期内有效促进和解、包容和和平建设工作（Schulenkorf, 2010）。

在国际层面，美国在20世纪90年代和2000年代的一项重要体育为本项目——世界学者-运动员运动会——在每次活动中汇聚了来自200个国家的2000多名青年领袖，旨在促进这些未来领导者之间的和平、理解和包容（Welty Peachey et al., 2015）。通过利用混编国家队、影响深远的文化和教育活动以及冲突解决工作坊，该活动成功减少了偏见，并培养了这些青年的变革推动者自我效能感（Welty Peachey et al., 2015）。该活动还强调了以健全理论为基础设计项目的重要性（在本例中为SFDT），并战略性地设计项目以实现特定成果。

以体育为基础的干预措施也在世界各地的地方层面开展，旨在促进和平建设、冲突解决和包容。例如，Beyond the Ball 是芝加哥市的一个以体育为基础的非营利组织，主要利用篮球帮助收复该市充斥帮派暴力的地区中的游乐空间，并致力于在来自不同背景和社区的青年之间建立关系和机会（Beyond the Ball, 2020）。成立于1998年，Beyond the Ball 是一个建立在坚实课程和理论基础之上的可持续体育发展组织，因其外展工作而获得众多国家和国际奖项，每年为超过1,500名青年提供服务。虽然舞台不如奥运会那样宏大，但Beyond the Ball 以及世界各地数百个利用体育促进和平与包容的地方体育项目，对于激活和维持可持续发展目标16至关重要。

除了和平建设和冲突解决工作外，世界各地还有许多其他组织将体育作为促进边缘化和被剥夺权利个人社会包容、正义和建设社会资本的途径。例如，全球有相当多的项目利用足球，特别是改良形式的街头足球，来解决无家可归者面临的包容和正义问题。澳大利亚的《大问题》项目就是一个例子，参与该项目的青年发展了更强的纽带和桥梁社会资本，他们在组织的帮助下利用这些资本改善了自己的生活状况（Sherry, 2010; Sherry & Strybosch, 2012）。美国的一个类似项目Street Soccer USA在全国13个城市开展，利用足球帮助遭受无家可归和贫困的个人在生活中做出积极改变（Street Soccer USA, 2020）。与《大问题》一样，该倡议自2009年以来成功帮助超过15,000名青年和成年人改善了生活状况，从而获得更安全的住房和可持续的工作（Street Soccer USA, 2020; Welty Peachey et al., 2013）。

其他组织针对不同的边缘化群体，例如难民。体育可以对难民青年的生活产生影响，因为这种休闲实践允许表达身体实践、构建和表演社会身份，以及与他人发展情感亲近或疏离（Spaaij, 2015）。例如，美国的难民体育俱乐部是一个以体育为基础的青年发展项目，旨在帮助主要来自非洲国家的难民青年融入新国家。项目参与者认为该项目有助于他们在新国家感受到归属感和包容感，因为他们学习了尊重、团队合作和领导力等价值观

通过体育项目以及如何将这些价值观转移到他们的日常生活当中（Whitley et al., 2016）。世界各地还有许多其他例子可以展示，组织如何利用各种形式的体育来帮助青年尤其是难民的文化适应和重新安置。然而，体育并不是难民的万灵药。包容与排斥的界限可能难以跨越，尤其是与性别、种族、民族和宗教相关的界限，而参与社区体育或有针对性的干预措施并不会立竿见影，必须在一段时间内进行战略性规划，以帮助边缘化个人融入社区生活（Spaaij, 2015）。

体育中女孩和女性的包容是体育和体育组织与可持续发展目标 16 保持一致的另一个领域。旨在通过体育赋权女性和女孩以帮助预防性暴力问题和排斥问题的项目不计其数。例如，加拿大温哥华的温哥华原住民友谊中心协会，以及澳大利亚珀斯的 Role Models and Leaders Australia 项目，就是两个通过体育针对原住民年轻女性的项目。虽然这些项目在一定程度上再现了新自由主义和竞争性资本主义的霸权，但两项计划的参与者都认为，他们的参与将有助于改变社区中的种族主义和性别歧视刻板印象，并在正义和包容问题上努力工作（Hayhurst et al., 2016）。尽管如此，虽然这种性质的许多体育发展项目可能会让参与者发声并激励他们成为变革推动者，但这种行动主义在多大程度上能够创造根本包容的社会环境仍有疑问（Collison et al., 2017）。

尽管存在关于有效性的争论，以上组织和例子确实已积极努力推动可持续发展目标 16，只有时间才能证明这些举措在真正实现和平、正义和包容的社区和社会方面是否可持续。

### 47.3.2 可持续发展目标 16 与体育组织的日常运营

正如上文所述，体育、体育组织与可持续发展目标 16 之间存在许多重要的联系，并且在这方面已取得许多积极进展，但在日常运营中坚持可持续发展目标 16 则呈现出完全不同的挑战。从奥运会的贿赂丑闻到与国际足联相关的腐败，不道德行为以及缺乏透明度和问责制仍然渗透在体育产业中。这种腐败不仅发生在体育的最高层级，也可能在更具社区性和草根性的体育组织中显现，甚至在具有社会使命的体育发展项目组织中也会出现。以 Dan Doyle 为例，他曾是罗德岛国际体育研究所的执行主任，该研究所是一家体育发展非营利组织，负责管理备受赞誉的世界学者运动员运动会，并在全球范围内大力推动体育与发展工作。Doyle 于 2016 年因 18 项挪用公款罪名被定罪，并被判处七年监禁（ABC6, 2020）。因此，在所有层面上成为有问责、正义、公平和包容的体育组织以坚持可持续发展目标 16，一直是一项巨大的挑战。

幸运的是，已取得进展。一些最具知名度的体育组织变得更加透明，并建立了更强的制衡机制以防止腐败和其他不道德行为。正如下一章将讨论的那样，国际奥委会、国际足联以及各种国际体育联合会正在实施越来越多的规章和程序，以解决历史上与这些组织相关的贿赂和腐败问题。重点放在良好治理和领导力上，以及董事会和治理机构必须采取的步骤，以便在活动中更具问责、透明和公正（Takos et al., 2018）。真实的、共享的和服务型领导模式正被推进为领导力范式，以帮助保持体育组织与其使命的一致，并在工作中做到公正和透明（Ferkins et al., 2018; Takos et al., 2018; Welty Peachey et al., 2015）。这一学术研究群体本质上倡导在董事会领导和体育治理中建立关系的重要性，同时结合信任建设和领导力的社会建构，即领导力在利益相关者之间共同分享和发展。令人鼓舞的是，体育组织和治理机构正在改变其领导和治理方法，让更多利益相关者发声，并积极努力解决腐败问题。仍有很长的路要走，但已迈出令人鼓舞的步伐。

即使具有社会使命的体育发展项目组织在坚持可持续发展目标 16 时也面临挑战，正如上面 Doyle 和国际体育研究所的案例所说明的那样。在更广泛的层面上，许多体育发展项目组织面临使命漂移的挑战，这通常是由于资助机构和合作伙伴的压力，迫使组织偏离其目标和[content]
通过体育项目以及如何将这些价值观转移到他们的日常生活当中（Whitley et al., 2016）。世界各地还有许多其他例子可以展示，组织如何利用各种形式的体育来帮助青年尤其是难民的文化适应和重新安置。然而，体育并不是难民的万灵药。包容与排斥的界限可能难以跨越，尤其是与性别、种族、民族和宗教相关的界限，而参与社区体育或有针对性的干预措施并不会立竿见影，必须在一段时间内进行战略性规划，以帮助边缘化个人融入社区生活（Spaaij, 2015）。

体育中女孩和女性的包容是体育和体育组织与可持续发展目标 16 保持一致的另一个领域。旨在通过体育赋权女性和女孩以帮助预防性暴力问题和排斥问题的项目不计其数。例如，加拿大温哥华的温哥华原住民友谊中心协会，以及澳大利亚珀斯的 Role Models and Leaders Australia 项目，就是两个通过体育针对原住民年轻女性的项目。虽然这些项目在一定程度上再现了新自由主义和竞争性资本主义的霸权，但两项计划的参与者都认为，他们的参与将有助于改变社区中的种族主义和性别歧视刻板印象，并在正义和包容问题上努力工作（Hayhurst et al., 2016）。尽管如此，虽然这种性质的许多体育发展项目可能会让参与者发声并激励他们成为变革推动者，但这种行动主义在多大程度上能够创造根本包容的社会环境仍有疑问（Collison et al., 2017）。

尽管存在关于有效性的争论，以上组织和例子确实已积极努力推动可持续发展目标 16，只有时间才能证明这些举措在真正实现和平、正义和包容的社区和社会方面是否可持续。

### 47.3.2 可持续发展目标 16 与体育组织的日常运营

正如上文所述，体育、体育组织与可持续发展目标 16 之间存在许多重要的联系，并且在这方面已取得许多积极进展，但在日常运营中坚持可持续发展目标 16 则呈现出完全不同的挑战。从奥运会的贿赂丑闻到与国际足联相关的腐败，不道德行为以及缺乏透明度和问责制仍然渗透在体育产业中。这种腐败不仅发生在体育的最高层级，也可能在更具社区性和草根性的体育组织中显现，甚至在具有社会使命的体育发展项目组织中也会出现。以 Dan Doyle 为例，他曾是罗德岛国际体育研究所的执行主任，该研究所是一家体育发展非营利组织，负责管理备受赞誉的世界学者运动员运动会，并在全球范围内大力推动体育与发展工作。Doyle 于 2016 年因 18 项挪用公款罪名被定罪，并被判处七年监禁（ABC6, 2020）。因此，在所有层面上成为有问责、正义、公平和包容的体育组织以坚持可持续发展目标 16，一直是一项巨大的挑战。

幸运的是，已取得进展。一些最具知名度的体育组织变得更加透明，并建立了更强的制衡机制以防止腐败和其他不道德行为。正如下一章将讨论的那样，国际奥委会、国际足联以及各种国际体育联合会正在实施越来越多的规章和程序，以解决历史上与这些组织相关的贿赂和腐败问题。重点放在良好治理和领导力上，以及董事会和治理机构必须采取的步骤，以便在活动中更具问责、透明和公正（Takos et al., 2018）。真实的、共享的和服务型领导模式正被推进为领导力范式，以帮助保持体育组织与其使命的一致，并在工作中做到公正和透明（Ferkins et al., 2018; Takos et al., 2018; Welty Peachey et al., 2015）。这一学术研究群体本质上倡导在董事会领导和体育治理中建立关系的重要性，同时结合信任建设和领导力的社会建构，即领导力在利益相关者之间共同分享和发展。令人鼓舞的是，体育组织和治理机构正在改变其领导和治理方法，让更多利益相关者发声，并积极努力解决腐败问题。仍有很长的路要走，但已迈出令人鼓舞的步伐。

即使具有社会使命的体育发展项目组织在坚持可持续发展目标 16 时也面临挑战，正如上面 Doyle 和国际体育研究所的案例所说明的那样。在更广泛的层面上，许多体育发展项目组织面临使命漂移的挑战，这通常是由于资助机构和合作伙伴的压力，迫使组织偏离其目标和目标以满足资助方或合作伙伴的优先事项（Coalter, 2010）。当这种情况发生时，体育发展项目组织可能会“漂移”远离其最初目的，导致与可持续发展目标 16 的目标和指标不一致。而且正如下一章将进一步讨论的那样，体育发展项目领域固有的权力动态对使命履行和可持续发展提出了挑战（Darnell, 2010）。通常，位于全球北方和高收入国家（HIC）的组织会设计项目并将其带到全球南方和低收入至中等收入国家（LMIC）以“发展”它们。这种模式中嵌入了权力动态，当地利益相关者在如何或发展什么方面几乎没有发言权。正在取得进展的是让当地利益相关者参与体育发展项目的所有方面并向他们转移领导权和能力（Welty Peachey et al., 2020），这只会有助于在当地社区制定和平、正义和包容的可持续战略。

这结束了我们对可持续发展目标 16 及其目标、理论基础以及与体育产业的多样化联系的讨论。提供了许多体育组织在社区中激活可持续发展目标 16 的例子，以及与在体育组织的日常运营中坚持可持续发展目标 16 的意图相关的挑战。在下一章中，我们将把注意力转向可持续发展目标 16 的衡量，无论是在体育之外还是在体育之内。

正如 SDG 16 所指出的，促进和平包容的社会、提供司法获取以及建设有效包容的机构，一直是非政府组织、管治机构、体育组织、联赛和联合会所追求的目标。本章将详细讨论这些机构如何努力改善 SDG 16 的衡量和评估。为此，首先提供了在 SDG 16 方面的进展概述，特别关注 SDG 指标。随后提供了体育组织如何衡量 SDG 16 进展的实例。最后，讨论了在体育背景下实施和衡量 SDG 16 的潜在问题和障碍。

### 48.1 体育、和平与公正机构的交集：为实现 SDG 16 而进行的进展、紧张关系和挑战

自 2015 年世界领导人在联合国齐聚并通过《2030 年可持续发展议程》以来，在 SDG 16 以及其他可持续发展目标方面取得了进展。成就包括例如通过了《第三届发展筹资问题国际会议亚的斯亚贝巴行动议程》、《2015-2020 年仙台减少灾害风险框架》以及《联合国气候变化框架公约巴黎协定》等重大全球协议。然而，正如秘书长《可持续发展目标进展报告》中所建议的那样（联合国经济及社会理事会，2019 年），由于缺乏定期收集的数据和衡量 SDG 16 的既定方法，在许多国家衡量工作仍存在困难。由于这种缺乏对充分理解 SDG 16 的进展和挑战产生负面影响，因此需要各方利益相关者进一步关注。

根据秘书长报告（联合国经济及社会理事会，2019 年；以下简称“该报告”），在结束暴力、促进法治、加强机构和增加司法获取方面的进展不均衡，继续剥夺人们的安全、权利和机会。因此，必须重新努力推动实现 SDG 16。随后将讨论 SDG 16 及其目标和指标的更具体状况。

目标 16.1 关注减少暴力和死亡率。每 10 万人中的国际凶杀案数量从 2015 年的 6.0 增加到 2017 年的 6.1（指标 16.1.1）。报告解释说，这一轻微增长在很大程度上是由于拉丁美洲、加勒比地区以及撒哈拉以南非洲一些国家的凶杀率上升。关于暴力，15 至 49 岁之间约有 20% 的人过去 12 个月内遭受过身体或性伴侣暴力。关于针对儿童的暴力（目标 16.2），来自 83 个国家、主要来自发展中地区的数据显示，近 8/10 的 1 至 14 岁儿童在家中遭受某种形式的体罚或心理虐待。在这 83 个国家中的 76 个国家，至少有一半的儿童经历了暴力管教方法（指标 16.2.1）。用于评估指标 2.3 的数据非常有限，即年轻人遭受性暴力的比例。然而，在 46 个具有可比数据的国家中，至少有 5% 的 18 至 29 岁女性在 18 岁之前首次经历了被迫的性交或其他性行为。指标 16.2.2，即人口贩运受害者人数的数据更多。该报告表明，受害者被发现的数量总体上有所增加，这可能是由于积极发展（当局为识别受害者而加强努力）或消极发展（人口贩运问题更大）所致。据最近数据，在每个国家国内被发现的人口贩运受害者人数均有所增加：2014 年为 43%，2016 年为 58%。令人担忧的是，被发现的人口贩运受害者中绝大多数，约 70%，是妇女和女孩，其中大多数被贩运用于性剥削。

目标 16.3 关注人人平等获取司法。根据指标 16.3.2，未决拘留者在监狱总人口中的比例近年来基本保持在 30%。报告指出监狱总人口的绝对数量有所增加，尽管监狱人口占总人口的比例保持不变。关于指标 16.3.1，即当局或其他正式认可的冲突解决机制的暴力受害者，报告称人权维护者、记者和工会主义者的杀害事件正在上升。联合国在 2017 年至 2018 年间在 41 个国家记录并核实了 431 起杀害事件。此外，至少每周有八人死于建设更包容、平等社会努力的前线。这表明从 2015 年至 2017 年每周平均七名受害者有所增加。受害者包括 99 名记者和博主。

发展有效、负责和透明的机构（目标 16.6）是 SDG 16 的重要组成部分。指标 16.6.1 指的是中央政府支出占最初批准预算的比例，因为批准预算与实施预算之间的差异反映了政府实现发展目标、例如向公众提供服务的能力。在 2006 年至 2017 年间的 108 个国家中，约有一半国家的实际支出在批准预算的正负 5% 以内，而近一半的低收入国家显示偏差超过 10%。十分之一的国家表现出 15% 的范围。

为所有人提供法律身份，主要是出生登记，是另一个重要目标领域（目标 16.9），因为出生登记在确保个人人权和获取司法、社会和医疗服务方面发挥主要作用。尽管许多地区出生登记已实现普遍或接近普遍，但全球平均水平仍为 73%。特别是在撒哈拉以南非洲，超过一半的儿童（约 54%）在 5 岁以下未登记出生。关于改善公众获取信息以及相关国家立法和国际协定（目标 16.10），125 个国家已通过具有约束力的法律和政策，允许个人获取公共当局持有的信息。其中至少有 31 个国家是在 2013 年之后这样做的。截至 2019 年，关于法律框架的数据可在 123 个国家获得，其中 40 个国家未包括上诉至独立行政机构的权利，这是妥善实施公众获取信息权利的关键。

目标 16.a 侧重于加强国家机构以防止暴力。根据报告，机构普遍不够强大或有效，无法充分应对极端贫困和饥饿、儿童肥胖以及生物多样性恶化等大规模跨国挑战等。必须改善多边合作，包括目标 16.a 所指的国际合作，以成功实施可持续发展目标。此外，为实现该目标，必须加快建立符合《巴黎原则》的国家人权机构的进展（指标 16.a.1）。2018 年，只有 39% 的国家建立了完全符合国际商定标准的机构——比 2015 年多出七个国家。尽管符合标准的国家数量在增加，但增长速度仍然很低。报告预计，如果增长保持在同一速度，全球约 54% 的国家将拥有符合标准的国家人权机构。

### 48.2 体育中的衡量

体育组织、管治机构、联赛、非政府组织和非营利慈善倡议一直在（重新）开发衡量和评估与可持续发展目标相关实践的方法。由于体育对实现发展与和平的贡献不断增长，体育被视为可持续发展最重要的推动因素之一（大会，2015 年）。由于 SDG 16 涉及促进和平，体育的力量最为明显，并且具有最大的潜力影响全球变革（可持续发展目标基金，2018 年）。基于证据的评估使用高质量、及时和可靠的数据得到了显著增强，因为 SDG 17 的两个目标也对其进行了推广（目标 17.18：提高可靠数据的可用性，17.19：进一步发展进展衡量）。下面提供了体育组织如何衡量 SDG 16 进展的实例以及改进衡量实践的建议。

国际体育儿童保护创始人小组是一个与来自多样化国家和背景的 50 多个组织合作的组织，旨在提高认识，即针对儿童和青少年的体育虐待需要在整个体育领域得到解决（国际体育儿童保护工作组，2014 年）。关于目标 16.1，即减少所有形式的暴力，以及 16.2，即结束所有形式的针对儿童的暴力及其各自指标，该组织为地方和国家组织提供实用的指导和资源，以便监测和评估为实现儿童在体育中的权利而实施的实践。在八项保障措施中，即政策；应对关切；建议和支持；最小化风险；指南；招募、培训和沟通；合作伙伴；以及监测和评估，监测和评估表示“通过让所有相关群体参与，包括儿童，对其他七项保障措施的每项有效性进行持续监测”（国际体育儿童保护工作组，2014 年，第 118 页）。该组织的工具包《国际体育儿童保护保障措施》提供了使用八项保障措施和支柱进行衡量的标准和资源（见表 48.1）。这套标准和问题旨在确保所有在体育中工作的组织都应制定标准，以确保儿童免受伤害。

鉴于围绕足球中未成年人交易所产生的担忧，国际足联于 2001 年根据第 19 条《球员身份和转会条例》（RSTP）禁止 18 岁以下球员的国际签约或转会。这些法规在全球范围内适用，因此，所有注册于任何国家足球（足球）协会的球员和俱乐部都须遵守这些法规（Drywood，2016）。自法规出台以来，国际足联逐步增加了一系列进一步的检查，以识别俱乐部和经纪人的剥削行为，目标是确保遵守第 19 条。通过努力，自 2009 年起，所有未成年人的国际转会和首次注册均由国际足联下属委员会球员身份委员会监督（国际足球联合会，2014）。

值得注意的是，该委员会的监督由计算机化的转会匹配系统促进，该系统要求俱乐部输入所有非本国球员的信息，这些球员是转会或首次注册的对象或可能成为对象（Drywood，2016）。未经球员身份委员会批准，任何转会都不能进行。虽然国际足联和该委员会既不公布监督结果，也不公布转会匹配系统中注册球员的状态，但这是一个全球体育管理机构对与指标 16.2.2 相关的议题进行监测和监管的重要贡献。国际足联和该委员会调查了多起案件，导致与国际足联纪律委员会行政合作，对欧洲多家俱乐部进行制裁。其中一起重大案件发生在 2014 年 4 月，巴塞罗那足球俱乐部和西班牙足球联合会因与 18 岁以下球员的国际转会和注册相关的违规行为而被点名（van Maren & Marino，2014）。国际足联及其下属委员会通过转会匹配系统联合调查，并查明了 2009 年至 2013 年间发生的违规行为。国际足联对巴塞罗那足球俱乐部实施转会禁令和罚款，对西班牙足球联合会处以罚款，展示了该组织作为管理机构对未成年人保护的承诺。

目标 16.5 及其指标（16.5.1 和 16.5.2）涉及腐败和贿赂。国际奥委会、国际足联和透明国际等全球组织一直在努力打击组织和成员的腐败行为。减少腐败和贿赂也是实现目标 16.6 的重要一步，因为良好的治理可以建立在有效、负责任和透明的制度实践之上。透明国际，一个全球反腐败联盟，发布了《全球腐败报告：体育》（2016），以权威地审视体育领域的腐败状况，并实施必要的行动来打击体育组织的腐败。该报告详细说明了体育组织如何揭露腐败以及他们为减少相关活动所采取的措施。章节涵盖的主题包括体育组织良好治理的现状（Chappelet，2016）、与亚洲足球相关的治理和腐败（Dorsey，2016）、非洲体育的腐败（Tsuma，2016）和南美足球（Kfouri，2016）、基层体育的良好治理（Kirkeby，2016）、以及匈牙利（Ligeti & Musci，2016）和意大利米兰市的犯罪和腐败（Bonoli & Gozzoli，2016）。报告中讨论的腐败的更具体领域是：体育大型赛事的竞标过程（Horne，2016；Szymanski，2016；Zimbalist，2016）、体育大型赛事的规划和管理（Burrow，2016；Carpenter，2016；Koval & Jvirblis，2016；Maening，2016；Mishra，2016）、体育组织参与操纵比赛（Trumpyte，2016；Zaman et al.，2016），以及美国的大学体育（Lopiano，2016；Smith，2016）。该报告本身展示了监测体育多层面（从全球到地方和基层）腐败状况和相关行为的努力——这是由非体育组织（透明国际）和来自国际体育文化协会、国际中心足球观察站、FIFPro、国际奥委会、联合国教科文组织和 UNI 世界运动员等体育组织的集体努力。

促进全球体育良好治理的另一个重要行为者是国际奥委会。简要提及上述内容，它是最大的全球体育组织之一，一直在努力减少腐败并发展良好治理。在盐湖城丑闻之后，国际奥委会调查了约 30 名被指控接受盐湖城 2002 年冬季奥运会申办委员会贿赂的成员，国际奥委会引入了行为准则以制裁不可接受的行为（Chappelet，2016）。作为持续促进透明治理的努力，国际奥委会引入了《奥林匹克和体育运动良好治理基本普遍原则》（BUPs），分为七章。BUPs 于 2009 年在奥林匹克大会上通过（国际奥委会，2009），并于 2010 年纳入国际奥委会《道德守则》：“奥林匹克和体育运动良好治理的基本普遍原则，特别是透明度、责任和问责，必须得到所有奥林匹克运动组成部分的尊重”（国际奥委会《道德守则》第 C1 点，国际奥委会，2010）。逐渐地，良好治理被纳入国际奥委会的使命（第 2.1 条），“鼓励和支持在体育中促进道德和良好治理”（国际奥委会，2011，第 14 页），以及《奥林匹克宪章》（基本原则 5）：“奥林匹克运动中的体育组织应享有自治的权利和义务，其中包括……确保良好治理原则得到应用的责任”（国际奥委会，2011，第 10 页）。结果，国际单项体育联合会（IFs）和国家奥委会（NOCs）随后有义务实行良好治理。BUPs 于 2012 年由国际奥委会实施，以评估 28 个希望继续成为一部分的 IF 和七个



IFs that applied to join, the Summer Olympic Games programming (International Olympic Committee, 2012). Examples of criteria used included: the existence of a code of ethics, alignment of IF’s Code of Ethics with the principles and rules of the IOC Code of Ethics, the existence of transparent and enhanced internal dispute resolution mechanisms, comparison between the number of women and number of men on the executive board (or equivalent), and rules and procedures to fight against competition fixing. Among the 35 IFs evaluated, one IF (United World Wrestling) underwent a provisional exclusion because it failed to follow the practices of good governance (e.g., it had no women on its executive board).

While the IOC was working to introduce its good governance standard, IFs and NOCs joined the work as well. As discussed in the previous section, the SDP field has flourished particularly after the UN recognized sport as an important apparatus for sustainable development. For example, F4P, one of the most significant peace-building interventions using sport, and its involved academics have conducted a number of studies on its outcomes since the beginning of the project (Schulenkorf & Sugden, 2011; Schulenkorf et al., 2014; Sugden, 2006a, 2006b, 2008, 2010). This approach, positioned as “circular and inclusive” (p. 266) to research and evaluation, enabled the project to (re)develop organically “from the bottom up, as the knowledge and viewpoints gleaned from all key actors and stakeholders are used to refine and reform interventions year on year” (p. 266).

### 48.3 Implementation challenges

Despite the progress made over the past years concerning SDG 16 and its targets, stakeholders have encountered challenges and barriers when implementing relevant strategies. Understanding these challenges is crucial for developing political leadership and multi-stakeholder actions to accelerate progress, to ultimately achieve SDG 16 by 2030. First and foremost, progress toward SDG 16 has not been equal across different regions. Gaps among regions make it difficult to develop a holistic and universal strategy that can be adopted by multiple areas and countries at the same time. For example, according to the Asia and the Pacific SDG progress report (United Nations Economic and Social Commission for Asia and the Pacific, 2020), SDG 16 was among the three goals with the most diverse patterns of progress observed across Asia-Pacific subregions. Another challenge comes from the lack of effective communication of statistics, that is, low data availability regarding SDG 16. Although data available on the SDG 16 indicators has substantially increased over the past few years, still data are lacking on many SDG 16 indicators. The Asia and the Pacific SDG progress report indicates that only four among 12 targets of SDG 16 were measured, leaving eight targets non-measurable due to the lack of, or skewed data. Therefore, there is a continuous need to collect robust, consistent, and comprehensive data to measure the progress across regions and to develop more effective communication and engagement with data users at the local and national levels.

The power imbalance between Global North and Global South, HIC and LMIC, or "the West and the Rest" (Hall, 1996, p. 184), has posed challenges in implementing contextualized and culturally sensitive practices toward SDG 16. Take the case of the IOC, for example, the proportion of IOC members from European countries was 48% while 15% for Asia, 17% for Africa, 5% for the Middle East, and 11% for Latin America as of 2006 (Brownell, 2008). Scholars like MacAloon (2008), Edwards and Skinner (2006), and Zakus (2005) also pointed out that the IOC's operation and management are deeply rooted in the European cultural and political tradition. When a global sport organization is operated with a region-focused perspective, it poses challenges to achieving good governance (target 16.6). Similar are the cases of SDP organizations operated at the global level. Programs are designed and funding is situated in HIC (usually located in the West) with little involvement of local communities and grassroots practitioners in LMIC (Coalter, 2013; Lindsey & Banda, 2011). As Nicholls et al. (2011) argued:

> Academics and development agencies in the Global North have consistently had the privilege of shaping what sport for development is and what constitutes relevant and valid evidence of its success. Grassroots practitioners' knowledge... is rarely considered as part of the evidence base of sport for development and is often dismissed in favor of knowledges emanating from the Global North. (p. 250)

This power imbalance in SDP is a difficult challenge for organizations and practitioners to achieve progress toward SDG 16 as it can negatively impact the quality of governance of global SDP organizations. As indicated in target 16.8, broadening and strengthening the participation of developing countries (usually located outside the West) in the institutions of global governance is the key to achieve SDG 16. However, statistical and situational evidence indicates that global sport organizations need to take more actions to seek a balance in their governance system. Nevertheless, we have seen more recently that an increasing number of Olympic Games and other major events are held in non-power countries located outside the West (e.g., Brazil, China, South Africa). Global sport organizations’ efforts to increase inclusivity in their governance systems and practices is and will be consistently needed to achieve SDG 16 in the near future.

Lastly, challenges exist in building effective and accountable institutions in the sport field. As Chappelet and Mrkonjic (2013) delineated in his report, global sport organizations are not governed by national laws, nor is there universal legal structure to regulate the organizations’ operation and management activities. Both sport governing organizations (e.g., the IOC or FIFA) and SDP organizations operating globally (e.g., Right to Play or Beyond Sport) have a relatively higher level of autonomy for organizational governance (Chappelet, 2010). What is critical is that autonomy can hide corruption in sport organizations at all levels (see the case of Dan Doyle in Chapter 47). There are, however, very few ways to address and penalize organizations or individuals involved in corruptive and unethical behavior. For example, there are numerous international sport organizations located in the territory of Switzerland but rarely do Swiss judges prosecute such organizations due to restrictions related to international legal practices (Chappelet & Mrkonjic, 2013). As a strategy to prevent corruption in organizational governance, the United Nations Office on Drugs and Crime (UNODC) hosted the Convention against Corruption, followed by the publication of relevant strategies (United Nations Office on Drugs and Crime, 2013). Continuous efforts to develop appropriate regulations that can address and amend corruption and unethical activities will be necessary to achieve good governance in effective and accountable sport organizations.

### 应用可持续发展目标 16

Taylor Smith

Free to Run 在世界上一些最具挑战性的地区运营，数十年的冲突和不稳定导致妇女和女孩极度孤立，并遭受骚扰、行动受限以及受教育机会不平等。通过体育项目、生活技能发展和社区外展相结合的方式，Free to Run 帮助妇女和女孩重新夺回公共空间，并改变人们对她们在社会中可以和应该扮演的角色的看法。通过此举，Free to Run 支持妇女和女孩将成功转化为日常生活，使她们能够成为并将成为建设持久平等公正社会的积极力量。

自 2014 年以来，Free to Run 已在冲突地区与超过 3,500 名妇女和女孩合作，包括在香港、南苏丹和刚果民主共和国的过往项目，以及在阿富汗和伊拉克的当前项目。2020 年，Free to Run 因其大胆使用体育而获得 Beyond Sports & Social Justice Award，因其最具颠覆性的由女孩领导的组织而获得 With & for Girls 中东和北非奖，创始人兼主席 Stephanie Case 代表加拿大政府秘书办公室获得 Meritorious Service Medal。

### 49.1 与可持续发展目标的关系

Free to Run 将跨文化的妇女和女孩团结起来，提供分享经验和挑战先入为主观念的支持，以支持以下可持续发展目标：

- SDG 4: 优质教育：通过 Free to Run 的体育生活技能（LSS）课程，妇女和女孩被教授成为自力更生并掌控自己生活的技能，包括积极沟通、冲突预防和领导力技能。
- SDG 3: 良好健康与福祉：通过 LSS 获得的技能转化为年轻女孩和妇女生活的各个方面，监测与评估（M&E）显示出对持续的心理、身体和社会福祉的积极影响。
- SDG 5: 性别平等：Free to Run 利用创新的体育活动支持妇女和女孩重新夺回公共空间，通过提高可见度构建对其未来的另类愿景。
- SDG 10: 减少不平等：通过当地社区参与，妇女和女孩将 LSS 中学到的技能应用于其社区，使她们在公共空间中接触到积极的认知并挑战不平等。
- SDG 16: 和平、正义与强大机构：Free to Run 对跨区域活动的重视鼓励社会包容和女性参与公共空间、决策过程以及社区领导角色，支持她们积极参与和平建设运动。

### 49.2 FTR 的方法

作为一个由妇女和青年领导的组织，Free to Run 利用冒险体育和生活技能支持冲突地区的妇女和女孩建立身体、情感和社会福祉，加强她们参与当地社区并积极参与其中，以团结不同文化、种族和宗教背景的人。为实现这一目标，Free to Run 采取以下方法：

- 社区认可：Free to Run 与学校、家长、社区成员和其他关键利益相关者保持开放对话，讨论项目结构和提供的活动，回答问题并分享女性参与体育的好处。
- 创造安全空间：Free to Run 为妇女和女孩创造安全空间，让她们以她们从未认为可能的方式和地点保持活跃。通过定期的社区志愿服务和积极的社区互动，Free to Run 挑战社区对女性角色的先入为主观念，增加社区接受度并扩大公共安全空间。
- 提高可见度：Free to Run 将妇女和女孩带出其通常的环境，并通过体育教育创造新的体验机会，使她们跨文化团结，为她们提供空间、时间和支持以开始分享经验和挑战先入为主观念。这使她们能够彼此以及周边社区的人们所看见。
- 通过冒险体育学习：Free to Run 的 LSS 课程与冒险体育一起教授，例如跑步、徒步和皮划艇，教授领导力、冲突解决、韧性和有效沟通所需的技能。

### 49.3 执行

#### 49.3.1 挑战

由于 Free to Run 专注于冲突地区的妇女和女孩，安全始终是一个挑战。作为回应，项目设计为能够灵活应对关键事件，即使在与安全相关的障碍下也能相对顺畅地运行。Free to Run 还依靠一小群个人关系和协议以及多变的、可识别的行动模式来确保项目和参与者的安全。

2020 年，Free to Run 面临前所未有的挑战：COVID-19。幸运的是，Free to Run 专注于社交距离活动（在户外重新夺回公共空间和使用非接触式体育）以及出于安全原因对灵活的虚拟、混合或面对面编程的适应性，使得能够迅速反应，将项目中断降至最低。Free to Run 目前采用三步方法，使用双周评估、项目/行动关键性矩阵和重新开放指南来确定项目交付形式。初步的 2020 年 M&E 数据表明，尽管由于 COVID-19，受益人数和活动总数较低，但项目的成效同样显著。

#### 49.3.2 成功

尽管伊拉克和阿富汗持续存在安全问题，Free to Run 已交付了几项开创性举措。成功包括：

- 2019 年，我们通过体育和教育课程在两个国家（伊拉克和阿富汗）和七个省份（阿富汗的喀布尔、马扎尔、坎大哈、赫尔曼德和巴米扬，以及伊拉克的埃尔比勒和摩苏尔）接触了超过 870 名参与者，其中包括超过 30 名残疾参与者。¹
- 迄今为止，我们正在进行超过 1,800 次体育课程，包括跑步、力量训练、瑜伽和冥想、排球、冰上滑冰、骑自行车和滑雪。
- 迄今为止，我们通过 FTR 的 LSS 和营养课程进行超过 1,050 次教育课程。
- 迄今为止，我们正在进行超过 40 次社区外展活动、六次跨区域体育和领导力周、四次残奥会比赛和 13 次混合性别比赛。
- 支持了阿富汗第一位完成马拉松的女性和首支参加国际超级马拉松的阿富汗女子队。

额外的成功可以通过我们参与者的故事来讲述。首先，2020 年，Free to Run 参与者 Shaymaa 获得了 Courageous Use of Sport Award Winner。她原籍 Sinjar，因逃离 ISIS 而流离失所至埃尔比勒的国内流离失所者（IDP）营地。Shaymaa 于 2018 年加入 Free to Run，并坚持克服极其困难的处境，成为 Free to Run 的教练、妇女权利倡导者和社区活动家。谈及体育在赋权女性方面的重要性，Shaymaa 说：“体育是生存的秘密，是实现我无法做到的事的动力。它是在流离失所和男性主导的黑暗中，我被迫挑战的黑暗中的一束光。”其次，Sediqa 17 岁时加入 Free to Run。起初，由于传统信仰，她的家人不允许她加入。然而，在 Free to Run 的支持下，Sediqa 的家人允许她加入。Sediqa 前往中部高地参加冬季跨区域体育与领导力周——这是她第一次独立旅行。谈及 Free to Run 的影响，Sediqa 说：
