## 前言

软件架构是一个广泛的主题，且没有单一的定义。在本书中，我将分享我在不同行业的多类客户中积累的领域经验。我将采取务实的方法来实现本书的标语：一个周末学会像软件架构师一样思考和行动。掌握大多数概念并入门只需这么短的时间。当然，你需要自己深入研究某些主题，这可能会花费比一个周末更长的时间。本书将带你踏上一段现实世界中软件架构的实践之旅：内容不掺水分，且具有可操作性。

## 本书面向的读者

本书面向希望晋升为软件架构师的开发人员。它将帮助他们理解更广阔的应用格局，以及大型企业如何实施软件架构实践。要充分利用本书，需要具备软件开发方面的先验知识。

## 本书涵盖的内容

第 1 章《软件架构简介》介绍软件架构及其在现实世界中的体现。

第 2 章《探索架构框架与方法论》通过可操作的示例，进一步分析上一章中简要介绍的框架。

第 3 章《理解 ATAM 与软件质量属性》介绍 ATAM，一种可用于为软件寻找最合适架构的方法论。

第 4 章《回顾历史架构风格》重新审视单体架构、面向服务架构和微服务的历史。了解过去十年间发生的事情很重要，因为架构师经常需要重构/迁移现有解决方案。

第 5 章《设计模式与整洁架构》探讨软件开发模式以及应用程序结构与设计的最新趋势。
