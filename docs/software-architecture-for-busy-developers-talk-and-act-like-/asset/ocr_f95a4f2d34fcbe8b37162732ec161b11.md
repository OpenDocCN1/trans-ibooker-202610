# Mediator pattern wrap-up

The mediator has some advantages and drawbacks, outlined as follows:

+   - It ensures one-to-one and one-to-many communication processes.
+   - It decouples the objects that communicate with each other.
+   - It isolates the communication logic in the concrete mediator.
+   - As a disadvantage, the SRP might be compromised should the concrete mediator implementation become complex over time.
