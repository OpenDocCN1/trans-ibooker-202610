
## 安装故障转移群集

在向导的功能页上，我们需要选择 `Failover Clustering`，如图 [3-5](#394392_3_En_3_Chapter.xhtml#Fig5) 所示。这满足了构建 Windows 群集的先决条件。 ![图 3-5 ¶ 功能页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig5_HTML.jpg)
图 3-5 ¶ 功能页

当您选择 `Failover Clustering` 时，向导会显示一个屏幕（图 [3-6](#394392_3_En_3_Chapter.xhtml#Fig6)），询问您是否以复选框的形式安装管理工具。如果您计划直接从节点管理群集，请选中此选项。 ![图 3-6 ¶ 选择管理工具](images/394392_3_En_3_Chapter/394392_3_En_3_Fig6_HTML.jpg)
图 3-6 ¶ 选择管理工具

在向导的最后一页，您会看到将要安装的功能摘要，如图 [3-7](#394392_3_En_3_Chapter.xhtml#Fig7) 所示。在这里，如果需要，您可以指定 Windows 介质的位置。您还可以选择服务器是否应自动重启（如果需要）。如果您正在构建新服务器，选中此框是有意义的。但是，如果在添加功能时服务器已在生产环境中运行，请确保考虑当前在该服务器上运行的内容，以及是否应等待维护窗口来执行重启（如果需要）。 ![图 3-7 ¶ 确认页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig7_HTML.jpg)
图 3-7 ¶ 确认页

除了通过 `Server Manager` 安装之外，群集服务也可以从 `PowerShell` 安装。列表 [3-1](#394392_3_En_3_Chapter.xhtml#PC1) 中的 PowerShell 命令可实现与前面步骤相同的结果。
```
Install-WindowsFeature -Name Failover-Clustering –IncludeManagementTools -Verbose
```

安装群集服务

### 创建群集

一旦在两个节点上安装了群集，您就可以开始构建群集。为此，连接到您打算作为活动节点的服务器，并从 `Administrative Tools` 运行 `Failover Cluster Manager`。

`Create Cluster Wizard` 的“开始之前”页警告说，Microsoft 仅支持通过所有验证测试的群集，如图 [3-8](#394392_3_En_3_Chapter.xhtml#Fig8) 所示。该消息还警告您必须是群集中每个节点的本地管理员。在以前版本的 Windows Server 中，这意味着您必须使用在将参与群集的每台服务器上具有本地管理员权限的域帐户。然而，从 Windows Server 2016 开始，对域身份验证的依赖已被移除，唯一的要求是在每个节点上存在具有一致名称和密码的本地管理员权限帐户。这允许在工作组上或跨多个域创建群集。在以前版本的 Windows Server 中，这两种选项都不可用。 ![图 3-8 ¶ 开始之前页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig8_HTML.jpg)
图 3-8 ¶ 开始之前页

在向导的“选择服务器”屏幕上，您需要输入群集节点名称。如图 [3-9](#394392_3_En_3_Chapter.xhtml#Fig9) 所示。在我们的例子中，我们的群集节点分别命名为 `ClusterNode1` 和 `ClusterNode2`。如果它们是域的一部分，则域名称和后缀将附加到服务器名称。 ![图 3-9 ¶ 选择服务器页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig9_HTML.jpg)
图 3-9 ¶ 选择服务器页

在“验证警告”页上，会询问您是否希望对群集运行验证测试。对于生产服务器，您应始终选择运行此验证，因为除非群集经过验证，否则 Microsoft 不会提供支持。选择运行验证测试会调用 `Validate a Configuration Wizard`。您也可以从 `Failover Cluster Manager` 的“管理”窗格独立运行此向导。“验证警告”页如图 [3-10](#394392_3_En_3_Chapter.xhtml#Fig10) 所示。 ![图 3-10 ¶ 验证警告页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig10_HTML.jpg)
图 3-10 ¶ 验证警告页

### 提示

在某些情况下无法进行验证，在这些情况下，您需要选择“否，我不需要支持…”选项。例如，一些 DBA 选择安装单节点群集而不是独立实例，以便在将来需要时可以扩展为完整群集。然而，这种方法可能会给 Windows 管理员带来操作挑战，因此请务必极其谨慎使用。

在通过 `Validate a Configuration Wizard` 的“开始之前”页后，您会看到“测试选项”页。在这里，您可以选择运行所有验证测试或选择要运行的测试子集，如图 [3-11](#394392_3_En_3_Chapter.xhtml#Fig11) 所示。通常在安装新群集时，您希望运行所有验证测试，但在对群集进行配置更改后，如果您独立调用 `Validate a Configuration Wizard`，能够选择测试子集会很有用。 ![图 3-11 ¶ 测试选项页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig11_HTML.jpg)
图 3-11 ¶ 测试选项页

在向导的“确认”页上，如图 [3-12](#394392_3_En_3_Chapter.xhtml#Fig12) 所示，您会看到将要运行的测试摘要以及它们将针对的群集节点。测试列表非常全面，包括以下类别：
* 清单（例如识别任何未签名的驱动程序）
* 网络（例如检查有效的 IP 配置）
* 存储（例如验证在节点之间故障转移磁盘的能力）
* 系统配置（例如验证 Active Directory 的配置）
![图 3-12 ¶ 确认页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig12_HTML.jpg)
图 3-12 ¶ 确认页

“摘要”页，如图 [3-13](#394392_3_En_3_Chapter.xhtml#Fig13) 所示，提供测试结果以及指向报告 HTML 版本的链接。请务必检查结果中的任何错误或警告。您应始终在继续之前解决错误，但某些警告可能是可以接受的。例如，如果您正在构建群集以托管 `AlwaysOn Availability Groups`，您可能没有任何共享存储。这会生成警告，但在这种情况下不是问题。在 Windows 上配置 `AlwaysOn Availability Groups` 将在第 [5](#394392_3_En_5_Chapter.xhtml) 章中进一步详细讨论。 ![图 3-13 ¶ 摘要页](images/394392_3_En_3_Chapter/394392_3_En_3_Fig13_HTML.jpg)
图 3-13 ¶ 摘要页

“查看报告”按钮显示验证报告的完整版本，如图 [3-14](#394392_3_En_3_Chapter.xhtml#Fig14) 所示。超链接会带您进入报告中的特定类别，其中每个测试都有进一步的超链接。这些允许您深入到特定测试生成的消息，使识别错误变得容易。 ![图 3-14 ¶ 故障转移群集验证报告](images/394392_3_En_3_Chapter/394392_3_En_3_Fig14_HTML.jpg)
图 3-14 ¶ 故障转移群集验证报告
