We execute the action as a method and pass its result to the dispatch method of the store variable.

+   7. Create a component property that invokes the PoiSelectors.getAllPoi selector to list POI data from the store:

```
pois$ = this.store.select(PoiSelectors.getAllPoi);
```

We use the select method of the store variable to execute the selector.

> **Important note**
> We did not create the PoiSelectors.getAllPoi selector. NgRx did it for us when we generated the feature state in the poi library.
