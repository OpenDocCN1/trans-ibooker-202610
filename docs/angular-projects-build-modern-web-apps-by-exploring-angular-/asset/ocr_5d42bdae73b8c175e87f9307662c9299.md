2. Open the angular.json configuration file and add the following entry in the assets array of the build architect option:

```
"assets": [
  {
    "glob": "**/*",
    "input": "src/assets",
    "output": "assets"
  },
  {
    "glob": "**/*.svg",
    "input": "node_modules/ionicons/dist/ionicons/svg",
    "output": "./svg"
  },
  {
    "glob": "**/*",
    "input": "node_modules/cesium/Build/Cesium",
    "output": "/assets/cesium"
  }
]
```

The preceding entry will copy runtime all CesiumJS source files into a cesium folder inside the assets folder of our application.

3. Also add the CesiumJS widgets style sheet file into the styles array of the build section:

```
"styles": [
  "node_modules/cesium/Build/Cesium/Widgets/widgets.css",
  "src/theme/variables.scss",
  "src/global.scss"
]
```

The viewer of CesiumJS contains a toolbar with widgets, including a search bar and a dropdown for selecting a specific type of map, such as Bing Maps or Mapbox.
