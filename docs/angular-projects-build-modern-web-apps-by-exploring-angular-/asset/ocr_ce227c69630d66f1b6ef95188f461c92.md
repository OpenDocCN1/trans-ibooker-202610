The preceding command will create the module in the `src\app\core` folder of our application. To create the header component, we will use the same command, passing a different set of options:

```
```
ng generate component header --path=src/app/core --module=core
--export
```
```

The previous command will create all necessary component files inside the `src\app\

# **core.module.ts**

```
```typescript
import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common';
import { HeaderComponent } from './header/header.component';

@NgModule({
    declarations: [
        HeaderComponent
    ],
    imports: [
        CommonModule
    ],
    exports: [
        HeaderComponent
    ]
})
export class CoreModule { }
