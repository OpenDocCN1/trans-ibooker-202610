In the preceding code, we subscribe to the `getAllPoi` selector manually using a subscription property instead of using an async pipe. In this case, we must also unsubscribe manually in the `ngOnDestroy` life cycle hook of the component, using the unsubscribe method. If we fail to do so, we may introduce a memory leak in our application.
