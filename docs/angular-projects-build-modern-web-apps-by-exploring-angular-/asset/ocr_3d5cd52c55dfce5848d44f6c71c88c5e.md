This is the same command that we execute when using the Angular CLI from a Terminal window.

The Nx Console uses tasks internally to run Angular CLI commands. Tasks are a built-in mechanism of VSCode that allow us to run scripts or start external processes without interacting directly with the command line.

The Nx Console extension does a fantastic job of removing the burden of remembering Angular CLI commands off by heart. The VSCode Marketplace contains many more extensions for Angular developers that supplement the job of the Nx Console.
