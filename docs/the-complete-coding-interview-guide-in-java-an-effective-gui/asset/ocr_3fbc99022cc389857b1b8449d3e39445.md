Almost always, a question such as this requires an example as part of the answer, so let's consider the `Rectangle` class that implements the `Cloneable` interface. The `clone()` method can return `Rectangle` instead of `Object` as follows:

```
```java
public class Rectangle implements Cloneable {

    ...

    @Override
    protected Rectangle clone()
            throws CloneNotSupportedException {

        Rectangle clone = (Rectangle) super.clone();

        return clone;
    }
}
```
```

Calling the `clone()` method doesn't require an explicit cast:

```
```java
Rectangle r = new Rectangle(4, 3);
Rectangle clone = r.clone();
```
```
