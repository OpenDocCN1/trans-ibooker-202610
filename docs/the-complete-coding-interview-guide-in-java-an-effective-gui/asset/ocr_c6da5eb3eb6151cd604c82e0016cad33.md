# Clock 1, 10:10:

+   - Hour hand: 10*30° + 10*0.5° = 300° + 5° = 305°
+   - Minute hand: 10 * 6° = 60°
+   - Result: abs(305° - 60°) = abs(245°) = 245° > 180°, so return 360° - 245° = 115°

# Clock 2, 9:40:

+   - Hour hand: 9*30° + 40*0.5° = 270° + 20° = 290°
+   - Minute hand: 40 * 6° = 240°
+   - Result: abs(290° - 240°) = abs(50°) = 50°

# Clock 3, 4:40:

+   - Hour hand: 4*30° + 40*0.5° = 120° + 20° = 140°
+   - Minute hand: 40 * 6° = 240°
+   - Result: abs(140° - 240°) = abs(-100°) = 100°

Based on these statements, we can write the following code:

```
public static float findAngle(int hour, int min) {
    float angle = (float) Math.abs(((30f * hour) + (0.5f * min)) - (6f * min));
    return angle > 180f ? (360f - angle) : angle;
}
```
