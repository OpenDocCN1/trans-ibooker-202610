# How can the superclass overridden method be called from the subclass overriding method?

We can call the superclass overridden method from the subclass overriding method via the Java `super` keyword. For example, consider a superclass, A, that contains a method, `foo()`, and a subclass of A named B. If we override the `foo()` method in subclass B, and we call `super.foo()` from the overriding method, B#foo(), then we call the overridden method, A#foo().

# Can we override or overload the main() method?

We must keep in mind that the `main()` method is static. This means that we can overload it. However, we cannot override it because the static methods are resolved at compile time, while the methods that we can override are resolved at runtime depending upon the type of object.

# Can we override a non-static method as static in Java?

No. *We cannot override a non-static method as static.* Moreover, the reverse is not possible either. Both lead to compilation errors.
