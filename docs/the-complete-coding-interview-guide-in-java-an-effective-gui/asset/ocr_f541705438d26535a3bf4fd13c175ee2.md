We can provide an implementation via three queues as well. The steps of this algorithm are as follows:

+   1. Initialize an integer, minElem=1.
+   2. Initialize three queues; that is, queue3, queue5, and queue7.
+   3. Loop from 1 to the given k-1:
+      a. Insert minElem*3, minElem*5, and minElem*7 into queue3, queue5, and queue7, respectively.
+      b. Update minElem as min(queue3.peek, queue5.peek, queue7.peek).
+      c. If minElem is queue3.peek, then do queue3.poll.
+      d. If minElem is queue5.peek, then do queue5.poll.
+      e. If minElem is queue7.peek, then do queue7.poll.
+   4. Return minElem.
