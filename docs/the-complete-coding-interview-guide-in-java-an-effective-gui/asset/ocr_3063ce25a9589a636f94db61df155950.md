Getting a value is done using the key. If the given key is not found, then we return `null`. Getting a value doesn't remove the entry from the map. Let's take a look at the code:

```
```java
public V get(K key) {

    for (int i = 0; i < size; i++) {
        if (entries[i] != null) {
            if (entries[i].getKey().equals(key)) {
                return entries[i].getValue();
            }
        }
    }

    return null;
}
