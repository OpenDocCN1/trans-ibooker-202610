So, when FR has reached the end of the linked list and SR has reached the fourth node (the middle of the linked list), the stack contains the values of 2, 1, and 4. Next, we can continue to move SR at a rate of 1 node until the end of the linked list. At each move, we pop a value from the stack, and we compare it with the current node value. If we find a mismatch, then the linked list is not a palindrome. In the code, we have the following:

public boolean isPalindrome() {

    Node fastRunner = head;
    Node slowRunner = head;

    Stack<Integer> firstHalf = new Stack<>();

    // the first half of the linked list is added into the stack
    while (fastRunner != null && fastRunner.next != null) {

        firstHalf.push(slowRunner.data);

        slowRunner = slowRunner.next;
        fastRunner = fastRunner.next.next;
    }

    // for odd number of elements we to skip the middle node
    if (fastRunner != null) {
        slowRunner = slowRunner.next;
    }

    // pop from the stack and compare with the node by node of
    // the second half of the linked list
    while (slowRunner != null) {
        int top = firstHalf.pop();

        // a mismatch means that the list is not a palindrome
        if (top != slowRunner.data) {
            return false;
        }
    }
