**Problem:** Given n nuts and n bolts, consider a one-to-one mapping between them. Write a snippet of code that finds all matches between the nuts and bolts with the minimum number of iterations.

```
char[] nuts = {'$', '%', '&', 'x', '@!'};
```

The most intuitive solution relies on a brute-force approach. We can choose a nut and iterate the bolts to find its mate. For example, if we choose nuts[0], we can find its mate with bolts[3]. Additionally, we can take nuts[1] and find its mate with bolts[0]. This algorithm is very simple to implement via two for statements and has a complexity time of O(n²).
