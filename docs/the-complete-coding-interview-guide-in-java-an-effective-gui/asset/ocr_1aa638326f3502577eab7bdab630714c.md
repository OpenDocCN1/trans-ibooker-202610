If we put this algorithm into code, then we get the following:

```
public static boolean search(int[][] matrix, int element) {

    int row = 0;
    int col = matrix[0].length - 1;

    while (row < matrix.length && col >= 0) {

        if (matrix[row][col] == element) {
            return true;
        } else if (matrix[row][col] > element) {
            col--;
        } else {
            row++;
        }
    }

    return false;
}
```

The time complexity of this algorithm is O(m+n), where m is the number of rows and n is the number of columns. The complete application is called SearchInSortedMatrix. It also contains a recursive implementation of this algorithm.
