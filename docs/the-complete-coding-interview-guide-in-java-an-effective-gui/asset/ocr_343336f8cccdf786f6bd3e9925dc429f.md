Finding a solution to this problem requires us to identify the number of ways in which the current node can be a part of the maximum path. By inspecting the preceding examples, we can isolate four cases, as shown in the following diagram (take your time and look at more examples until you reach the same conclusion):

Figure 13.32 – Number of ways the current node can be a part of the maximum path

So, a node that is part of the max path is put into one of the following four cases:

+   1. The node is the only node in the max path
+   2. The node is part of the max path next to its left child
+   3. The node is part of the max path next to its right child
+   4. The node is part of the max path next to its left and right children
