
3. **你是否对测试、调试和/或代码审查特别感兴趣？** 编写有价值的测试、发现 bug 和审查代码的能力是保证最终产品高质量最重要的技能。在这三个方面中，我们应该重点关注测试，因为几乎任何 Java 开发者职位描述都要求候选人具备编写单元测试和集成测试的扎实技能（最常用的工具是 JUnit、TestNG、Mockito 和 Cucumber-JVM）。然而，寻找专门的 Java 测试员或 Java 代码审查员职位相当困难，这类职位通常出现在大公司（尤其是在提供远程工作的公司，如 Upstack 或 Crossover）。大多数公司更喜欢*同行代码审查*，每个 Java 开发者都应该编写有意义的测试，为他们的代码提供高覆盖率。所以你必须两者兼备：写出令人赞叹的代码，并为这些代码编写测试。

4. **你对与数据库交互的应用程序感兴趣，还是尽量避免这类应用程序？** 大多数 Java 应用程序都使用数据库（关系型数据库或 NoSQL 数据库）。很多 Java 开发者职位都要求你具备以下扎实知识：通过对象关系映射框架（如 Hibernate）、JPA 实现（如 Hibernate JPA 或 Eclipse Link）或以 SQL 为中心的库（如 jOOQ）进行数据库编码。大多数 Java 应用程序都与关系型数据库（如 MySQL、PostgreSQL、Oracle 或 SQL Server）交互。但 MongoDB、Redis 或 Cassandra 等 NoSQL 数据库也在大量应用程序中出现。尽量避免开发与数据库交互的应用程序可能会严重限制你能获得的工作范围。如果你是这种情况，那么从今天起就应该重新考虑这一方面。

5. **你是否偏爱代码优化和性能？** 关注代码性能是一项备受赞赏的技能。这样的做法会让你被视为注重细节的完美主义者。拥有优化代码和提升性能的解决方案，会很快让你参与到功能需求解决方案的设计和架构中。但在面试（代码挑战阶段）时，不要专注于代码优化和性能！只需专注于交付一个可工作的解决方案，并尽可能保持代码整洁。

这是招聘者的另一个重要衡量标准。

## 学习，编码，学习，编码...

一旦你成为开发者，就必须遵循“学习->编码”的实践，才能登上顶峰并保持领先。永远不要停止学习，永远不要停止编码！通常来说，“学习->编码”实践可以通过示例学习或教学相长的方式，或者任何其他最适合你的方式来应用。

## 那么认证呢？

一旦你访问 education.oracle.com/certification，你可以看到 Oracle 提供了一整套 Java 认证。虽然获得认证（来自 Oracle 或其他机构）并没有错，但职位描述并不要求这些。参加这些认证需要大量的金钱和时间，而且大多数时候并不值得付出这些努力。你可以更明智地利用这些时间，参与项目（副业项目、学校项目、开源项目等）。这是给雇主留下深刻印象的更好方式。因此，证书的价值有限，而且获得证书需要耗费大量资源。此外，证书是会过时的。想想看，在 2020 年，获得 Java 6 认证还有多大用处；或者到 2030 年，获得 Java 12 认证又如何！

但如果你真的想考虑认证，那么以下是一些顶尖的认证（更多信息请在 Google 上搜索，因为链接可能会随时间失效）：

- OCAJP（Oracle 认证助理，Java 程序员 1）和 OCPJP（Oracle 认证专家，Java 程序员 2）
- Spring 专业认证
- OCEWCD（Oracle 认证专家，Java EE 6 Web 组件开发人员）
- Apache Spark 认证 HDPCD（HDP 认证开发人员）
- Professional Scrum Master
- 项目管理（PMP）
- AWS 解决方案架构师
- Oracle 认证大师

在互联网上拥有经验和可见度（粉丝）对你的职业生涯是一个巨大的加分项。但你仍然需要一份有用的简历来申请 Java 工作。所以，是时候写你的简历了。

- **不要只列出一种编程语言：** 理想情况下，你应该列出两到三种编程语言（例如，*Java（专家），C++（中等），Python（有经验）*），但不要说你是所有这些语言的专家。没有人会相信你！另一方面，只列一种编程语言可能被解读为你对学习新技术不开放。
- **将技术分类：** 不要把技术列成一个长长的逗号分隔列表。例如，避免像 *Java, Ruby, C++, Java EE, Spring Boot, Hibernate, JMeter, JUnit, MySQL, PostgreSQL, AWS, Ocean, 和 Vue.js* 这样的写法。将它们分类，并按经验排序，如下例所示：
  - **编程语言：** Java（专家），Ruby（中级），C++（初级）
  - **框架：** Java EE（专家），Spring Boot（高级）
  - **对象关系映射（ORM）：** Hibernate（专家）
  - **测试：** JMeter（专家），JUnit（高级）
  - **数据库：** MySQL（专家），PostgreSQL（中级）
  - **云：** AWS（专家），Ocean（初级）
  - **JavaScript 框架：** Vue.js（中级）

## LinkedIn 简历

很可能，你的 LinkedIn 个人资料会是招聘者的第一站。此外，大量在线招聘平台在你申请工作时都会要求提供你的 LinkedIn 账号。甚至在某些情况下，这个账号是强制性的。

LinkedIn 是一个致力于追踪职业关系的社交网络。从本质上讲，LinkedIn 是一份强化版的在线简历。在 LinkedIn 上，你可以创建职位提醒，同事、客户和朋友可以为你或你的工作背书，这可能非常有价值。

> **重要提示**
>
> 注意保持你的 LinkedIn 简历与纸质简历同步。另外，如果你正在通过 LinkedIn 寻找工作，要特别注意，因为你所有的联系人都会收到关于你更新的通知。这些联系人包括你当前公司的同事，而你很可能不想让他们知道你在找新工作。解决办法是在你进行更新之前禁用这些通知。

现在，我们可以讨论求职申请流程了。

- **认为形象无关紧要：** 不要忽视你的形象！穿着专业，去理发店，让自己气味怡人！所有这些方面都是第一印象的一部分。**如果你看起来邋遢，也许你的代码看起来也一样。如果你穿着专业，面试官就会把你视为出类拔萃的人。** 然而，穿着专业并不意味着你应该奢华。
- **不善于推销自己：** 面试官必须看到你的价值。没有人能比你更好地向他们传达你的价值。告诉他们你曾经遇到的问题（在之前的公司、某个项目中等等），并解释你是如何与团队或独立解决的。雇主想要的人既要能出色地团队合作，也要能独立工作。遵循*情境|行动|结果（SAR）*的方法。从描述情境开始，接着解释你采取的行动，最后描述结果。
- **不练习编码挑战：** 在某个时候，你至少会被安排一次编码挑战。大多数时候，一般的编码技能是不够的！这些挑战是面试特有的，你必须在面试前进行练习。通常来说，解决编码挑战（问题）遵循*方法->分解->构建*的解决模式。显然，你无法记住解决方案，因此你需要尽可能多地练习。在本书后面，我们将讨论解决编码挑战的最佳方法。

面试一结束，就是等待回复的时候了。大多数公司会告诉你他们需要多少时间来提供最终答复，并且通常会提供一个答复，表示录用、拒绝、下一轮面试或仅仅是你的申请状态。祝你好运！

## 总结

本章总结了在 Java 生态系统中获得工作应遵循的最佳实践。我们讨论了选择合适的工作和我们的资格、积累经验、撰写简历等等。这些建议大多是针对学生或刚毕业的人的。当然，不要把这些建议视为一份详尽的清单，或一份应该全盘照搬的清单。这些实践将帮助你摘取你认为有吸引力的果实，并允许你在这个过程中加入自己的特色。
