```

Enqueuing an element into a queue means adding this element to the end of the underlying array. Before enqueuing an element, we have to ensure that the queue is not full. If it is full, then we can signal this via a message/exception, or we can increase its capacity, as follows:

```
```java
// add an element 'e' in the queue
public void enqueue(E e) {
    // if the queue is full, we double its capacity
    if (isFull()) {
        ensureCapacity();
    }
}
