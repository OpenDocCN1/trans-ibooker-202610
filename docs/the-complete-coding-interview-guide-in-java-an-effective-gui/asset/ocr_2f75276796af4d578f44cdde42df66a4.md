Initially, this problem may sound complicated, but after a few minutes of reflection, you may come to the conclusion that the problem can be reduced to building a Max Binary Heap from an unsorted array. So, the fact that the given array is, or isn't, a Min Binary Heap is not important. We can build the required Max Binary Heap from any array (sorted or unsorted) by following two steps:

+   1. Start from the rightmost, bottommost node (last internal node) of the given array.
+   2. *Heapify* all the nodes via the bottom-up technique.

public static void convertToMinHeap(int[] maxHeap) {

    // build heap from last node to all
    // the way up to the root node
    int p = (maxHeap.length - 2) / 2;
    while (p >= 0) {
        heapifyMin(maxHeap, p--, maxHeap.length);
    }
}
