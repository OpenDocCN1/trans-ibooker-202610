# 590 Sorting and Searching

Conforming to the Merge Sort algorithm, we have to continually split the linked list in half until we obtain empty sub-lists or sub-lists that contain a single element (this is the divide and conquer approach). If a sub-list is empty or contains one element, it is sorted by definition – this is known as base case recursion.
