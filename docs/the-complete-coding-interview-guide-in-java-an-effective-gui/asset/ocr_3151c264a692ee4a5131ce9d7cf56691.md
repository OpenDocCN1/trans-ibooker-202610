Notice that after swapping these two pairs, n2.next points to n4, which is wrong. Hence, we must fix this link as well. For this, we can store n2, and, after swapping n3-n4, we can repair the link by setting n2.next=n3. Now, everything looks good and we can put it into code:

```
public void swap() {
    if (head == null || head.next == null) {
        return;
    }

    Node currentNode = head;
    Node prevPair = null;

    // consider two nodes at a time and swap their links
    while (currentNode != null && currentNode.next != null) {
        Node node1 = currentNode;          // first node
        Node node2 = currentNode.next;     // second node
        Node node3 = currentNode.next.next; // third node

        // swap node1 node2
        Node auxNode = node1;
        node1 = node2;
        node2 = auxNode;

        // repair the links broken by swapping
        node1.next = node2;
        node2.next = node3;
    }
```
