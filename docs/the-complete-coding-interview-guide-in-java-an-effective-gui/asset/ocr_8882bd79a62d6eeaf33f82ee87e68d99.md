The time complexity of this code is O(n) with O(h) extra space, where h is the height of the tree. How about an iterative implementation? We can provide an iterative implementation via a queue. The following code is the best explanation for this approach:

```
public boolean isSymmetricIterative() {

    boolean result = false;
    Queue<Node> queue = new LinkedList<>();

    queue.offer(root.left);
    queue.offer(root.right);

    while (!queue.isEmpty()) {
        Node left = queue.poll();
        Node right = queue.poll();

        if (left == null && right == null) {

            result = true;
        } else if (left == null || right == null
                   || left.element != right.element) {

            result = false;
            break;
        } else {
            queue.offer(left.left);
            queue.offer(right.right);

            queue.offer(left.right);
            queue.offer(right.left);
        }
    }

    return result;
}
```
