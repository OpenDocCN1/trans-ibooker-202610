# Recursive approach

Let's try to implement the spiral order traversal from the left-hand side of the preceding diagram. Notice that the odd levels should be printed from left to right, while the even levels should be printed in reverse order. Basically, we need to adjust the well-known Level-Order traversal by flipping the direction of the even levels. This means that we can use a boolean variable to alternate the printing order. So, if the boolean variable is true (or 1), then we print the current level from left to right; otherwise, we print it from right to left. At each iteration (level), we flip the boolean value.
