```
int count = entry.getValue();
while (count-- > 0) {
firstArr[index++] = entry.getKey();
}
}
}
```

The runtime of this code is O(m log m + n), where m is the number of elements in the first array and n is the number of elements in the second array. The complete application is called SortArrayBasedOnAnotherArray.
