+   3. If any of them are non-zero, return false.

+   4. If, for all the digits the given number % digit is 0, return true.

In terms of code, we have the following:

```
public static boolean isDivisible(int n) {
    int t = n;
    while (n > 0) {
        int k = n % 10;
        if (k != 0 && t % k != 0) {
            return false;
        }
        n /= 10;
    }
    return true;
}
```
