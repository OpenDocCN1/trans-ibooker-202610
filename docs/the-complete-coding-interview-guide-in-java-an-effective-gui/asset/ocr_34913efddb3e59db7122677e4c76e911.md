Based on this example, we can intuit that a simple solution consists of a recursive algorithm. We can traverse each node and compute the height of the left and right sub-trees. If the difference between these heights is greater than one, then we return false. In terms of code, this is quite straightforward:

```
public boolean isBalanced() {
    return isBalanced(root);
}

private boolean isBalanced(Node root) {
    if (root == null) {
        return true;
    }

    if (Math.abs(height(root.left) - height(root.right)) > 1) {
        return false;
    } else {
        return isBalanced(root.left) && isBalanced(root.right);
    }
}

private int height(Node root) {
    if (root == null) {
        return 0;
    }

    return Math.max(height(root.left), height(root.right)) + 1;
}
```
