```
minRight = Integer.min(q[qPointer], p[pPointer]);
}

return (maxLeft + minRight) / 2.0f;
}
}

return -1;
}
```

Our solution performs in O(log(max(q.length, p.length))) time. The complete application is called MedianOfSortedArrays.
