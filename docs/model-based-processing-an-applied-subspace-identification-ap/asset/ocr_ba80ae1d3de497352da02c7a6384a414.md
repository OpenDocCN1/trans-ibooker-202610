Substituting component-wise into Eq. (5.74) for each of the definitions (𝒲_{θ_i}, 𝒵_{θ_i}, 𝒱_{θ_i}), we obtain

```
𝒲_{θ_i}(t + 1) = [A(θ) − K(θ)C(θ)]𝒲_{θ_i}(t) + 𝒱_{θ_i}(\hat{x}_θ, u, e_θ) − K(θ)𝒵_{θ_i}(\hat{x}_θ(t|t − 1))  (5.76)
```

Now expanding over i = 1, …, N_θ, we obtain the recursion for the state predictor gradient weighting matrix as

```
𝒲_θ(t + 1) = [A(Θ) − K(Θ)C(Θ)]𝒲_θ(t) + 𝒱_θ(\hat{x}_θ(t|t − 1), u, e_θ) − K(Θ)𝒵_θ(\hat{x}_θ(t|t − 1))  (5.77)
```
