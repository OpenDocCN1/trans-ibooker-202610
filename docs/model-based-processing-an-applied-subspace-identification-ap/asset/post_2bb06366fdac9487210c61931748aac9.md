
# A.2 Gaussian Random Vectors

In this section, we consider the multivariable Gaussian distribution used heavily in this text to characterize Gaussian random vectors, that is, z ~ N(m_z, R_zz) where z ∈ R^{N_z×1} and defined by

Pr(z) = (2π)^{-N_z/2} |R_zz|^{-1/2} exp( -1/2 (z - m_z)^T R_zz^{-1} (z - m_z) )    (A.18)

where the vector mean and covariance are defined by
m_z := E{z}   and   R_zz = Cov(z) := E{(z - m_z)(z - m_z)^T}

Certain properties of the Gaussian vectors are useful such as the following:

- Linear transformation: Linear transformations of Gaussian variables are Gaussian; that is, if z ~ N(m_z, R_zz) and y = A z + b, then
  Y ~ N(A m_z + b, A R_zz A^T)    (A.19)

- Uncorrelated Gaussian vectors: Uncorrelated Gaussian vectors are independent.

- Sums of Gaussian variables: Sums of independent Gaussian vectors yield Gaussian distributed vectors with mean and variance equal to the sums of the respective means and variances.

- Conditional Gaussian vectors: Conditional Gaussian vectors are Gaussian distributed; that is, if x and y are jointly Gaussian, with
  m_z = E{ x \ y } = [ m_x \ m_y ] ; and R_zz = Cov(z) = [ R_xx R_xy \ R_yx R_yy ]
  then the conditional distribution for x and y is also Gaussian with conditional mean and covariance given by
  m_{x|y} = m_x + R_{xy} R_{yy}^{-1} (y - m_y)
  R_{x|y} = R_{xx} - R_{xy} R_{yy}^{-1} R_{yx}
  and the vectors x - E{x|y} and y are independent.

- Gaussian conditional means: Let x, y, and z be jointly distributed Gaussian random vectors and let y and z be independent, then
  E{x|y,z} = E{x|y} + E{y|z} - m_x

# A.3 Uncorrelated Transformation: Gaussian Random Vectors

Suppose we have a Gaussian random vector, x ~ N(m_x, R_xx) and we would like to transform it to a normalized Gaussian random vector with the mean,

m_x, removed so that, z ~ N(0, I). Assume that the mean has been removed (z → z − m_x), then there exists a nonsingular transformation, T, such that z = Tx and therefore

R_zz = Cov(z) = Cov((Tx)(Tx)') = T R_xx T' = I  (A.20)

Thus, we must find a transformation that satisfies the relation

R_zz = I = T R_xx T'  (A.21)

Since R_xx is a positive semidefinite, symmetric matrix, it can always be factored into matrix square roots (R = U U' = R_xx^{1/2} R_xx^{T/2}) using a Cholesky decomposition [4]; therefore, Eq. (A.21) implies

R_zz = I = (T U) U' T'  (A.22)

or simply that

T = U^{-1} = R_xx^{-1/2}    (Inverse Matrix Square Root)  (A.23)

and therefore

R_zz = (R_xx^{-1/2} U) U' R_xx^{-T/2} = R_xx^{-1/2} R_xx R_xx^{-T/2} = I  (A.24)

the desired result.

# A.4 Toeplitz Correlation Matrices

An N × N correlation matrix, R, is a Hermitian Toeplitz matrix (R^H = (R*)'), which has the following general properties [4]:

1) The set of distinct eigenvalues, {λ_i} of a Hermitian matrix are real.

2) The set of eigenvectors, {e_i} of a Hermitian matrix corresponding to the distinct eigenvalues, {λ_i}, are orthogonal → e_i^H e_i = 0 if λ_i ≠ λ_j.

3) Any Hermitian matrix admits an eigen-decomposition such that R = E Λ E^H with E unitary (E^{-1} = E^H).

R = E Λ E^H with E unitary (E^{-1} = E^H).

4) The inverse of a Hermitian matrix can be obtained for the eigen-decomposition as

R^{-1} = (E Λ E^H)^{-1} = E^{-H} Λ^{-1} E^{-1} = E Λ^{-1} E^H = Σ_{i=1}^N (1/λ_i) e_i e_i^H.

# B.1 Projections: Deterministic Spaces

Projection theory plays an important role in subspace identification primarily because subspaces are created by transforming or “projecting” a vector into a lower dimensional space – the subspace [1–3]. We are primarily interested in two projection operators: (i) orthogonal and (ii) oblique or parallel. The orthogonal projection operator “projects” • onto 𝒴 as 𝒫_{•|𝒴} or its complement 𝒫_{•|𝒴}^⊥, while the oblique projection operator “projects” • onto 𝒴 “along” 𝒵 as 𝒫_{•|𝒴∥𝒵}^∥. For instance, orthogonally projecting the vector x, we have 𝒫_{x|𝒴} or 𝒫_{x|𝒴}^⊥, while obliquely projecting x along 𝒵 is 𝒫_{x|𝒴∥𝒵}.

Mathematically, the n-dimensional vector space ℛ can be decomposed into a direct sum of subspaces such that

ℛ = ℛ₁ + ℛ₂

(B.1)

then for the vector r ∈ ℛⁿ, we have

r = r₁ + r₂ for r₁ ∈ ℛ₁ and r₂ ∈ ℛ₂

(B.2)

with r₁ defined as the projection of r onto ℛ₁, while r₂ defined as the projection of r onto ℛ₂.

When a particular projection is termed parallel (∥) or “oblique,” the corresponding projection operator that transforms r onto ℛ₁ along ℛ₂ is defined as 𝒫_{r|ℛ₁∥ℛ₂}^∥, then

r₁ = 𝒫_{r|ℛ₁∥ℛ₂}^∥ or r₂ = 𝒫_{r|ℛ₂∥ℛ₁}^∥

(B.3)

with r₁ defined as the oblique projection of r onto ℛ₁ along ℛ₂, while r₂ defined as the projection of r onto ℛ₂ along ℛ₁.

When the intersection ℛ₁ ∩ ℛ₂ = 0, then the direct sum follows as

𝒫_{r|ℛ₁∪ℛ₁} = 𝒫_{r|ℛ₁∥ℛ₂}^∥ + 𝒫_{r|ℛ₂∥ℛ₁}^∥

(B.4)

along with the corresponding projection given by

P_{A|B} = A × P_B = A × B(B'B)^{-1}B' (Orthogonal Projection) (B.12)

Numerically, these matrix operations are facilitated by the LQ-decomposition (see Appendix C) as

[ B ]   [ L11 | O ] [ Q1' ]
[ -- ] = [ -- | -- ] [ -- ]
[ A ]   [ L21 | L22 ] [ Q2' ] (B.13)

where the projections are given by

P_{A|B} = A × P_B = L21 × Q1'
P_{A|B}^⊥ = A × P_B^⊥ = L22 × Q2' (B.14)

# B.3.2 Oblique (Parallel) Projections

The oblique projection (|) of the Row(A) onto Row(C) along (°) the Row(B) is defined by P_A | c° B. This projection operation can be expressed as the rows of two nonorthogonal matrices (B and C) and their corresponding orthogonal complement. Symbolically, the projection of the rows of A onto the joint row space of B and C (B ∨ C) can be expressed in terms of two oblique projections and one orthogonal complement. This projection is illustrated in Figure B.1b, where we see that the Row(A) is first orthogonally projected onto the joint row space of B and C (orthogonal complement) and then decomposed along B and C individually enabling the extraction of the oblique projection of the Row(A) onto Row(C) along (°) the Row(B).

P_A | B∨C = P_A || B° C + P_A || C° B + P_A^⊥ | B∨C (B.15)

Pragmatically, this relation can be expressed into a more “operational” form that is applied in Section 6.5 to derive the N4SID algorithm [1, 4], that is,

P_A || C° B = [A × P_B^⊥][C × P_B^⊥]^# × C (Oblique Projection) (B.16)

for # the pseudo-inverse operation (see Appendix C). Oblique projections also have the following properties that are useful in derivations:

P_B || C° B = 0
P_C || C° B = C (B.17)
