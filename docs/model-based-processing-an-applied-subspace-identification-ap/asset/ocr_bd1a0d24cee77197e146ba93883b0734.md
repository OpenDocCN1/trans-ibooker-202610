First we begin by defining the power spectrum of a discrete random signal. Recall that the discrete-time Fourier transform (DtFT) pair is given by [4]

```
X(e^{jΩ}) := DtFT[x(t)] = Σ_{t=-∞}^{∞} x(t) e^{-jΩt}

x(t) = IDtFT[X(e^{jΩ})] = (1/(2π)) ∫_{2π} X(e^{jΩ}) e^{jΩt} dΩ  (2.15)
```

If x(t) is random, then X(e^{jΩ}) is also random because
x(t, ξ_i) ⟷ X(e^{jΩ}, ξ_i)  ∀ i

both are simply realizations of a random signal over the ensemble generated by i. Also, and more important, X(e^{jΩ}) for stationary processes almost never exists because any nonzero realization x(t, ξ_i) is not absolutely summable in the ordinary sense (these integrals can be modified [see [2] for details]).

Now let us develop the relationship between the PSD and its corresponding covariance. We have

```
S_{xx}(e^{jΩ}) = lim_{N→∞} (1/(2N+1)) E{ X_N(e^{jΩ}) X_N^*(e^{jΩ}) }  (2.16)
```

Substituting for the DtFT, moving the expectation operation inside the summation and introducing a change of variable gives the relation

```
S_{xx}(e^{jΩ}) = Σ_{k=-∞}^{∞} E_T{ R_{xx}(m+k, m) } e^{-jΩk}  (2.17)
```

If we further assume that the process is wide-sense stationary, then R_{xx}(m+k, m) → R_{xx}(k) is no longer a function of time, but lag k and, therefore,

```
S_{xx}(e^{jΩ}) = Σ_{k=-∞}^{∞} R_{xx}(k) e^{-jΩk}  (2.18)
```

evolves as the well-known Wiener–Khintchine relation with the corresponding covariance given by inverse discrete-time Fourier transform (IDtFT)

```
R_{xx}(k) = (1/(2π)) ∫_{2π} S_{xx}(e^{jΩ}) e^{jΩk} dΩ  (2.19)
```

Recall that the DtFT is just the Z-transform of x(t) evaluated on the unit circle, that is,

```
S_{xx}(Ω) = S_{xx}(z)|_{z=e^{jΩ}}
```
