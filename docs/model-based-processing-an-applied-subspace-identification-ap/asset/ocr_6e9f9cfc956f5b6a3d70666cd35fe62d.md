𝒫_{𝒴_{k+1|2k-1}|D_p}^{||} ∘ u_{k+1|2k-1} = 𝒪_{k-1} × \hat{𝒳}_{k+1} = [ℒ_{u|k} | 0 | ℒ_{y|k}] × L_{1:5,1:5} × Q'_{1:5} (Shifted Projection) (7.119)

where 𝒪_{k-1} ∈ 𝒪_k is the extended observability matrix with the last block row eliminated.

From these projections, we can now estimate both estimated state sequences, \hat{𝒳}_{k+1} and \hat{𝒳}_k in order to solve the least-squares problem, and extract Σ_{INV}. It is clear from the oblique projection that this can easily be accomplished from the SVD, since \hat{𝒳}_k = 𝒪_k^# × 𝒫_{𝒴_{k|2k-1}|D_p}^{||} ∘ u_f = (Σ_{S_k}^{-1/2} U_{S_k}) × 𝒫_{𝒴_{k|2k-1}|D_p}^{||} ∘ u_f \hat{𝒳}_{k+1} = 𝒪_{k-1}^# × 𝒫_{𝒴_{k+1|2k-1}|D_p}^{||} ∘ u_f = (Σ_{S_{k-1}}^{-1/2} U'_{S_{k-1}}) × 𝒫_{𝒴_{k+1|2k-1}|D_p}^{||} ∘ u_f (7.120)

where Σ_{S_{k-1}}^{-1/2} ∈ Σ_{S_k}^{-1/2} and U_{S_{k-1}} ∈ U_{S_k} are the singular values and orthogonal matrices respectively with the last block row eliminated (as above for the observability matrix).

Therefore, in terms of the LQ-matrices, we have that the estimated states are given by \hat{𝒳}_k = Σ_{S_k}^{-1/2} U'_S_k × [ℒ_{u|k-1} | 0 | ℒ_{y|k-1}] × L_{1:4,1:4} × Q'_{1:4} \hat{𝒳}_{k+1} = Σ_{S_{k-1}}^{-1/2} U'_{S_{k-1}} × [ℒ_{u|k} | 0 | ℒ_{y|k}] × L_{1:5,1:5} × Q'_{1:5} (7.121)

and \hat{𝒰}_{k|k} = L_{2:2,1:4} × Q'_{1:4} \hat{𝒴}_{k|k} = L_{5:5,1:5} × Q'_{1:5} (7.122)

With these states of the numerical Kalman filter now available from the SVD and pseudo-inversions, we can define the underlying “batch” state-space (INV) model as \hat{𝒳}_{k+1} = A \hat{𝒳}_k + B 𝒰_{k|k} + ξ_{ω_k} \hat{𝒴}_{k|k} = C \hat{𝒳}_k + D 𝒰_{k|k} + ξ_{v_k} (7.123)

where \hat{𝒳}_{k+1} := [\hat{x}(k+1) ⋯ \hat{x}(k+K-1)] \hat{𝒳}_k := [\hat{x}(k) ⋯ \hat{x}(k+K-2)] \hat{𝒴}_{k|k} := [\hat{y}(k) ⋯ \hat{y}(k+K-2)] 𝒰_{k|k} := [u(k) ⋯ u(k+K-2)] ξ_{ω_k} := [ε_ω(k) ⋯ ε_ω(k+K-2)] ξ_{v_k} := [ε_v(k) ⋯ ε_v(k+K-2)]
