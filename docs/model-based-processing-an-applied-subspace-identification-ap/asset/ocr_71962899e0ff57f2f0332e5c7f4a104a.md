If we have a state transition model available, then for a fixed parameter estimate, the state estimation problem is easily solved as in Chapter 4. Therefore, we will confine our discussion to the parameter posterior distribution estimation problem, that is, marginalizing the joint distribution with respect to the states (that have already been estimated) gives

Pr(Θₜ|Yₜ) = ∫ Pr(Xₜ, Θₜ|Yₜ) dXₜ (5.47)

and it follows that

𝒲(Θₜ) ∝ Pr(Θₜ|Yₜ) / I(Θₜ|Yₜ) (5.48)

Assuming that a set of particles can be generated from the importance distribution as Θₜ ∼ I(Θₜ|Yₜ), then we have the set of normalized weights

𝒲ₜ(Θ(i)) = W(Θₜ(i)) / Σₖ₌₁^{Nₚ} W(Θₜ(k)) for i = 1, ..., Nₚ (5.49)

which is the joint “batch” importance sampling solution when coupled with the dynamic state vectors.
