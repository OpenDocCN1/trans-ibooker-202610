
Applying the projection operator to the stochastic data equation of Eq. (7.69) nullifies the input term, that is,

𝒫_{𝒰_{k|2k-1}^⊥}^{⊥} 𝒴_{k|2k-1} 𝒰_{k|2k-1}^† := 𝒴_{k|2k-1} × 𝒫_{𝒰_{k|2k-1}^⊥} = 𝒪_k \hat{𝒳}_k 𝒫_{𝒰_{k|2k-1}^⊥} + \underbrace{Γ_k 𝒰_{k|2k-1} 𝒫_{𝒰_{k|2k-1}^⊥}}_{0} + Ξ_k ℰ_{k|2k-1} 𝒫_{𝒰_{k|2k-1}^⊥} (7.74)

The INV sequence is unaffected by the projection operator 𝒫_{𝒰_{k|2k-1}^⊥} because it is orthogonal to the inputs, past and future, therefore ℰ_{k|2k-1} 𝒫_{𝒰_{k|2k-1}^⊥} = ℰ_{k|2k-1} × (I - 𝒰_{k|2k-1} (𝒰_{k|2k-1} 𝒰_{k|2k-1}^†)^{-1} 𝒰_{k|2k-1}) = ℰ_{k|2k-1}

That is, from the well-known properties of the INV, we have that the future INV sequence is uncorrelated with the past inputs [32] ℰ_{k|2k-1} 𝒰_{0|k-1} = 0

Therefore, postmultiplying Eq. (7.74) by 𝒰_{0|k-1} and using this property, we can extract the observability matrix 𝒴_{k|2k-1} 𝒫_{𝒰_{k|2k-1}^⊥} 𝒰_{0|k-1} = 𝒪_k \hat{𝒳}_k 𝒫_{𝒰_{k|2k-1}^⊥} 𝒰_{0|k-1} + \underbrace{Ξ_k ℰ_{k|2k-1} 𝒰_{0|k-1}}_{0} = 𝒪_k \hat{𝒳}_k 𝒫_{𝒰_{k|2k-1}^⊥} 𝒰_{0|k-1} (7.75)

It has been shown that the corresponding rank condition for the stochastic realization problem is satisfied as (see [19] for details) ρ(𝒳_k 𝒫_{𝒰_{k|2k-1}^⊥} 𝒰_{k|2k-1}) = N_x (7.76)

If the underlying stochastic representation incorporates process noise such as the INV and Gauss–Markov models, then the SID technique must include both “past” inputs and outputs leading to either the PO-MOESP or the N4SID approach [17, 19, 27]. These methods provide robust solutions to the stochastic realization problem in this case.

The “past” input PI-MOESP method of the previous chapter has been developed from an instrumental variable (IV) perspective in which the IV is defined as ℐ_p := 𝒰_{0|k-1}; however, in contrast, both PO-MOESP and N4SID techniques are based on an augmented IV that incorporates the past outputs as well, that is, ℐ_{0|k-1} := [ 𝒰_{0|k-1} ; ; 𝒴_{0|k-1} ] ∈ ℛ^{k(N_u+N_y)×K} (7.77)

Recall that instrumental variables are selected to remove the effects of the noise term, leaving the critical information intact. IVs must satisfy the following conditions:

- $E\{\mathcal{E}_{0|k-1} \mathcal{I}'_{0|k-1}\}=0$  (Uncorrelated with Noise)
- $\rho\left(E\{\mathcal{X}'_{0} \mathcal{I}_{0|k-1}\}\right)=N_x$  (Rank Condition)

that is, the IV is to be selected such that it is uncorrelated with the noise (INV) and preserves the rank in order to extract the extended observability matrix $\mathcal{O}_k$ or the extended states $\mathcal{X}_f$.

It also follows from the orthogonality property of the INV that it is orthogonal to past outputs as well.

$E\{\mathcal{E}_{k|2k-1} \mathcal{Y}'_{0|k-1}\}=0$

After applying the projection operator $\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}$ to the future measurements removing the effect of the past inputs as in Eq. (7.74), we replace the “instrument” with the augmented instrumental variable $\mathcal{I}_{0|k-1}$ such that [19]

$\left(\mathcal{Y}_{k|2k-1}\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\right)\mathcal{I}'_{0|k-1}=\left(\mathcal{O}_k\hat{\mathcal{X}}_k\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\right)\mathcal{I}'_{0|k-1}+\underbrace{\left(\Xi_k\mathcal{E}_{k|2k-1}\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\right)\mathcal{I}'_{0|k-1}}_{0}$
(7.78)

It has been shown that the rank condition is preserved under these operations [19], that is,

$\rho\left(E\left\{\mathcal{Y}_{k|2k-1}\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\mathcal{I}'_{0|k-1}\right\}\right)=N_x$

Therefore, with this choice of IV, we have that the observability matrix can be recovered from

$\mathcal{Y}_{k|2k-1}\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\mathcal{I}'_{0|k-1}=\mathcal{O}_k\hat{\mathcal{X}}_k\mathcal{P}_{\mathcal{U}_{k|2k-1}^\perp}\mathcal{I}'_{0|k-1}$
(7.79)
leading to a robust implementation of the PO-MOESP algorithm to follow.

## 7.5.1 Multivariable Output Error State-Space (MOESP) Algorithm

The MOESP⁴ or more appropriately the PO-MOESP technique is based on performing an orthogonal LQ-decomposition on the data matrix (see Appendix C) [17–23, 25]. That is, $\mathcal{D}=L\times Q$ with $L$ a lower block triangular matrix, $L\in\mathcal{R}^{2k(N_u+N_y)\times2k(N_u+N_y)}$ and $Q$ an orthogonal matrix, $Q\in\mathcal{R}^{2k(N_u+N_y)\times K}$ such that

$\mathcal{D}:=
\begin{bmatrix}
\mathcal{U}_{k|2k-1}\\
---\\
\mathcal{I}_{0|k-1}\\
---\\
\mathcal{Y}_{k|2k-1}
\end{bmatrix}$

and from the upper block rows of the LQ-decomposition (see Section 6.4), we have

$$\begin{bmatrix}\mathcal{U}_{0|k-1}\\\mathcal{I}_{0|k-1}\end{bmatrix}=\begin{bmatrix}L_{11}&0\\L_{21}&L_{22}\end{bmatrix}\begin{bmatrix}Q'_1\\Q'_2\end{bmatrix}$$

it follows that

$$E\{\varepsilon_{k|2k-1}[Q_1\mid Q_2]\}=0$$

implying that the orthogonal matrices $Q'_i$, $i=1,2$ are *uncorrelated* with the future noise $\varepsilon_{k|2k-1}$ [19].

Therefore, nullifying the innovation terms, we have that Eq. (7.85) can be simplified as

$$\mathcal{Y}_{k|2k-1}\times Q_1=\mathcal{O}_k\mathcal{V}_kQ_1+\mathcal{T}_kL_{11}+\underbrace{\mathcal{E}_k\varepsilon_{k|2k-1}Q_1}_{0}$$

$$\mathcal{Y}_{k|2k-1}\times Q_2=\mathcal{O}_k\mathcal{V}_kQ_2+\underbrace{\mathcal{E}_k\varepsilon_{k|2k-1}Q_2}_{0}$$

resulting in the final set of relations enabling the extraction of the observability matrix and the KSP model, that is,

$$\mathcal{Y}_{k|2k-1}Q_1=L_{31}=\mathcal{O}_k\mathcal{V}_kQ_1+\mathcal{T}_kL_{11}$$

$$\mathcal{Y}_{k|2k-1}Q_2=L_{32}=\mathcal{O}_k\mathcal{V}_kQ_2$$

Performing the SVD of $L_{32}$, that is,

$$L_{32}=[U_S\mid U_N]\begin{bmatrix}\Sigma_S&0\\0&\Sigma_N\end{bmatrix}\begin{bmatrix}V'_S\\V'_N\end{bmatrix}=U_S\Sigma_SV'_S+U_N\Sigma_NV'_N$$

*Signal Subspace*  *Noise Subspace*

assuming the noise component is negligible compared to the signal component (as before) yields

$$L_{32}=\mathcal{O}_k\hat{\mathcal{V}}_kQ_2\approx U_S\times\Sigma_S\times V'_S\approx (U_S\Sigma_S^{1/2})\times((\Sigma'_S)^{1/2}V'_S)$$

extracting the observability matrix with a balanced stochastic realization.

The system matrices of the KSP model, $\Sigma_{KSP}=\{A,B,C,D\}$, can now be determined as before in the deterministic case using the shift-invariant approach to give

$$A=\mathcal{O}^{\#}_{N_x-1}\times\mathcal{O}^{\uparrow}_{N_x}=\left(\Sigma_S^{-1/2}U'_S\right)\times\mathcal{O}^{\uparrow}_{N_x};\quad C=\mathcal{O}(1:N_y,1:N_x)$$

with B and D obtained by solving a least-squares problem directly, since pre-multiplying Eq. (7.89) by U′N gives

U′N−31 = U′N O_k X_k Q1 + U′N T_k L11 = U′N T_k L11
        0

after applying the orthogonality conditions U′N O_k = 0, we have

U′N L31 = U′N T_k L11
Z := U′N T_k = U′N L31 × L11−1 (7.94)

Stacking and reordering the vectors leads to an overdetermined set of linear equations and a least-squares solution with

[ D̂ ] = U# × Z̃
[ -- ]       (7.95)
[ B̂ ]

where U is the block coefficient matrix (see Section 6.5 for details).

Using ΣKSP = {A, B, C, D}, the corresponding INV-based (Kalman) Riccati equation can be solved, yielding a positive definite solution Π̃ > 0 such that

Π̃ = A Π̃ A′ + (B − A Π̃ C′)(D + D′ − C Π̃ C′)⁻¹(B − A Π̃ C′)′ (7.96)

The INV covariance Ree and Kalman gain are then given by enabling the solution of the stochastic realization problem as follows:

Ree = (D + D′ − C Π̃ C′)
Kp = (B − A Π̃ C′) × Ree⁻¹ (7.97)

and therefore, the corresponding covariances are

Ruw^e = Kp Ree Kp′
Rvv^e = Ree
Rwv^e = Kp Ree (7.98)

completing the stochastic realization.

Therefore, we have the PO-Multivariable Output Error State-Space (PO-MOESP) [17] algorithm given by the following steps:

- Compute the LQ-decomposition of D of Eq. (7.80).
- Perform the SVD of L32 in Eq. (7.91) to extract O_k.
- Obtain A and C from Eq. (7.93).
- Solve the least-squares problem to obtain B and D from Eq. (7.95).
- With ΣKSP available, solve the INV-based (Kalman) Riccati equation of Eq. (7.96) for the positive definite state error covariance Π̃.
- Compute the INV covariance Ree and Kalman gain Kp from Eq. (7.97).
- Compute the corresponding set of noise covariances {Ruw^e, Rvv^e, Rwv^e} from Eq. (7.98).
