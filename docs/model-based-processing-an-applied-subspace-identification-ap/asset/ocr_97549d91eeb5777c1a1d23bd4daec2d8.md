Such techniques are residual analysis check for whiteness (resid) as well as comparing the identified model to the data (compare) or to a reference signal (goodnessoffit) and using the prediction error analysis (pe). Validation commands available to analyze/compare fits are fpe, aic, selstruc (MDL), and predict. Parameter estimates as well as their uncertainties (error bounds) are also available using the (present) command. Other implementations of subspace algorithms exist and can be extracted from the texts of [25, 27] (disk).
