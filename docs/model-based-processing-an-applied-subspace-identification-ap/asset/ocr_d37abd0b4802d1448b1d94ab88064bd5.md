Therefore, the state transition matrix is a critical component in the solution of the state equations of an LTI system given by

```
Φ_c(t, t₀) = e^{A_c(t−t₀)}    t ≥ t₀    (3.9)
```

and we can rewrite the transfer function matrix as

```
H(s) = C_c Φ_c(s) B_c + D_c    (3.10)
```

with the corresponding state-input transfer matrix given by

```
X(s) = Φ_c(s) x_{t₀} + Φ_c(s) B_c U(s)    (3.11)
```

Taking the inverse Laplace transformation gives the time-domain solution

```
x_t = ℒ⁻¹[X(s)] = Φ_c(t, t₀) x_{t₀} + Φ_c(t, t₀) B_c * u_t
```

or

```
x_t = Φ_c(t, t₀) x_{t₀} + ∫_{t₀}^{t} Φ_c(t, α) B_c u_α dα    (3.12)
      underbrace{zero−input}   underbrace{zero−state}
```

with the corresponding output solution

```
y_t = C_c Φ_c(t, t₀) x_{t₀} + ∫_{t₀}^{t} C_c Φ_c(t, α) B_c u_α dα + D_c δ(t)    (3.13)
```

Revisiting the continuous-time system of Eq. (3.12) and substituting the matrix exponential for the state transition matrix gives the LTI solution as

```
x_t = e^{A_c(t−t₀)} x_{t₀} + ∫_{t₀}^{t} e^{A_c(t−α)} B_c u_α dα    (3.14)
```

and the corresponding measurement system

```
y_t = C_c x_t + D_c u_t    (3.15)
```

In general, the continuous state transition matrix satisfies the following properties: [1, 2]

+   1) Φ_c(t, t₀) is uniquely defined for t, t₀ ∈ [0, ∞)  (Unique)
+   2) Φ_c(t, t) = I  (Identity)
+   3) Φ_c(t) satisfies the matrix differential equation:
+      Φ̇_c(t, t₀) = A_t Φ_c(t, t₀),    Φ_c(t₀, t₀) = I, t ≥ t₀    (3.16)
+   4) Φ_c(t, t₀) = Φ_c(t, τ) × Φ_c(τ, α) × ⋯ × Φ_c(β, t₀) (Semi-Group)
+   5) Φ_c(t, τ)⁻¹ = Φ_c(τ, t)  (Inverse)

Thus, the transition matrix plays a pivotal role in LTI systems theory for the analysis and prediction of the response of LTI and time-varying systems [2].
