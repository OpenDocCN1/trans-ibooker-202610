or

```
y(t) = [C_d - C_a M^{-1} K | C_v - C_a M^{-1} C_d] [ d(t) ; ḋ(t) ] + C_a M^{-1} B_p p(t) (6.35)
```

to yield the vibrational measurement as

```
y(t) = C x(t) + D u(t) (6.36)
```

where the output or measurement vector is y ∈ R^{N_y×1} completing the MIMO-mechanical system model.
