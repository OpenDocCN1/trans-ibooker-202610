Different from the EKF, the UKF does not approximate the nonlinear process and measurement models, it employs the true nonlinear models and approximates the underlying *Gaussian* distribution function of the state variable using the UT of the $\sigma$-points. In the UKF, the state is still represented as Gaussian, but it is specified using the minimal set of deterministically selected samples or $\sigma$-points. These points completely capture the true mean and covariance of the Gaussian distribution. When they are propagated through the true nonlinear process, the *posterior* mean and covariance are accurately captured to the second order for *any* nonlinearity with errors only introduced in the third-order and higher order moments as above.

Suppose we are given an $N_x$-dimensional *Gaussian distribution* having covariance, $P_{xx}$, then we can generate a set of $\sigma$-points having the same sample covariance from the columns (or rows) of the matrices $\pm\sqrt{(N_x+\kappa)P_{xx}}$. Here $\kappa$ is a scaling factor. This set is zero-mean, but if the original distribution has mean $\mu_x$, then simply adding $\mu_x$ to each of the $\sigma$-points yields a symmetric set of $2N_x$ samples having the desired mean and covariance. Since the set is symmetric, its odd central moments are null, so its first three moments are identical to those of the original Gaussian distribution. This is the *minimal* number of $\sigma$-points capable of capturing the essential statistical information. The basic UT technique for a multivariate Gaussian distribution [24] is

+   1. Compute the set of $2N_x$ $\sigma$-points from the rows or columns of $\pm\sqrt{(N_x+\kappa)P_{xx}}$. Compute $\mathcal{X}_i=\sigma+\mu_x$.

```
$$\mathcal{X}_0=\mu_x,\qquad W_0=\frac{\kappa}{N_x+\kappa}$$

$$\mathcal{X}_i=\mu_x+\left(\sqrt{(N_x+\kappa)P_{xx}}\right)_i,\qquad W_i=\frac{1-W_0}{2(N_x+\kappa)}$$

$$\mathcal{X}_{i+N_x}=\mu_x-\left(\sqrt{(N_x+\kappa)P_{xx}}\right)_i,\qquad W_{i+N_x}=\frac{1-W_0}{2(N_x+\kappa)}$$
```

where $\kappa$ is a scalar, $\left(\sqrt{(N_x+\kappa)P_{xx}}\right)_i$ is the ith row or column of the matrix square root of $(N_x+\kappa)P_{xx}$ and $W_i$ is the weight associated with the ith $\sigma$-point.

+   2. Nonlinearly transform each point to obtain the set of $\sigma$-points: $\mathcal{Z}_i=\mathbf{a}[\mathcal{X}_i]$.

+   3. Estimate the posterior *mean* of the new samples by its weighted average

```
$$\mu_z=\sum_{i=0}^{N_x}W_i\mathcal{Z}_i$$
```
