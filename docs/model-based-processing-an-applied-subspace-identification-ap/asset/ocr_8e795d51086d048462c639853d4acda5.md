The maximum Hankel singular value defines the so-called Hankel norm of the system, a metric of system input/output energy as [13, 15]

```
‖ℋ_{K,K}‖₂ = max{σ_i}    for    i = 1,⋯, K    (6.18)
```

The resulting realization is said to be a balanced realization and is scale invariant, that is, the balanced system is robust to amplitude scaling [12–14]. It is also interesting that the balancing (similarity) transformation for any system is given by

```
T_bal = Σ_{AB}^{1/2} × V_p × Σ_p^{-1/2}   and   T_bal^{-1} = Σ_p^{-1/2} × U'_p × Σ_{AC}^{1/2}    (6.19)
```

where we define the product matrix in terms of its Cholesky square-root decomposition as well as its corresponding SVD as

```
𝒫 = Σ_{AC}^{1/2} × Σ_{AB}^{1/2} = U_p × Σ_p × V'_p    (6.20)
```

with Σ_{•}^{1/2} the respective square-root matrices of the observability and controllability Gramians.

# 6.2.3 Systems Theory Summary

We summarize these important system theoretic properties of Hankel matrices as follows:

+   - The system defined by Σ_{ABCD} is minimal, if and only if, it is completely controllable and completely observable
+     (Minimal Order)

+   - For a minimal realization Σ_{ABCD}, the rank of the Hankel matrix satisfies:
+     ρ(ℋ_{K,K}) = min[ρ(𝒪_K), ρ(𝒞_K)] = N_x    (Rank Property)

+   - The constant rank under shifted Hankel matrix is
+     ρ[ℋ_{K,K}] = ρ[ℋ_{K+1,K}] = ρ[ℋ_{K,K+1}] = N_x    (Shift Property)

+   - The Hankel matrix is shift invariant such that
+     ℋ_{K,K}^↑ := 𝒪_K^↑ C_K   ⇔   ℋ_{K,K}^← := 𝒪_K C_K^←    (Shift Invariant)

+   - The eigenvalues of the system matrix A lie within the unit circle:
+     λ[A] ≤ 1    (Stability)
+     or if and only if the Lyapunov equation
+     P = A' P A + C' C    (Lyapunov Stability)
+     has a unique positive definite solution, P > 0.
