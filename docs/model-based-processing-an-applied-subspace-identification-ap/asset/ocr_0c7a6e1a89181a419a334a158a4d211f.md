# Table 4.7 Iterated–extended Kalman filter (IEKF) algorithm.

Prediction
\hat{x}(t|t-1) = a[\hat{x}(t-1|t-1)] + b[u(t-1)]  (State Prediction)
\tilde{P}(t|t-1) = A[\hat{x}(t|t-1)]\tilde{P}(t-1|t-1)A'[\hat{x}(t|t-1)] + R_{ww}(t-1)  (Covariance Prediction)
LOOP: i = 1, ..., N_{iterations}

Innovation
e_i(t) = y(t) - c[\hat{x}_i(t|t)] - d[u(t)]  (Innovations)
R_{e_i e_i}(t) = C[\hat{x}_i(t|t)]\tilde{P}(t|t-1)C'[\hat{x}_i(t|t)] + R_{vv}(t)  (Innovations Covariance)

Gain
K_i(t) = \tilde{P}(t|t-1)C'[\hat{x}_i(t|t)]R_{e_i e_i}^{-1}(t)  (Gain or Weight)

Update
\hat{x}_{i+1}(t|t) = \hat{x}(t|t-1) + K_i(t)e_i(t) - C[\hat{x}_i(t|t)](\hat{x}(t|t-1) - \hat{x}_i(t|t))  (State Update)
\tilde{P}_i(t|t) = [I - K_i(t)C[\hat{x}_i(t|t)]]\tilde{P}(t|t-1)  (Covariance Update)

Initial conditions
\hat{x}_0(t|0), \tilde{P}(0|0), \hat{x}_0(t|t) = \hat{x}(t|t-1)

Jacobians
A[\hat{x}(t|t-1)] \equiv \left.\frac{d a[x(t-1)]}{d x(t-1)}\right|_{x=\hat{x}(t|t-1)} \qquad C[\hat{x}_i(t|t)] \equiv \left.\frac{d c[x(t)]}{d x(t)}\right|_{x=\hat{x}_i(t|t)}

Stopping rule
||\hat{x}_{i+1}(t|t) - \hat{x}_i(t|t)|| < \epsilon \text{ and } \hat{x}_i(t|t) \rightarrow \hat{x}(t|t)

A typical stopping rule is
||\hat{x}_{i+1}(t|t) - \hat{x}_i(t|t)|| < \epsilon \quad \text{and} \quad \hat{x}_i(t|t) \rightarrow \hat{x}(t|t) \quad (4.89)

The IEKF algorithm is summarized in Table 4.7. It is useful in reducing the measurement function nonlinearity approximation errors, improving processor performance. It is designed for measurement nonlinearities and does not improve the previous reference trajectory, but it will improve the subsequent one.
