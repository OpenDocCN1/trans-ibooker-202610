where ∇_θ J(Θ) is the N_θ × 1 gradient vector and ∇_{θθ} J(Θ) is the N_θ × N_θ Hessian matrix. As part of the RPE algorithm, we must perform these operations on the predictor; therefore, we define the gradient matrix by

Ψ_θ(t) := [ψ_{θ_1}(t) ⋯ ψ_{θ_{N_θ}}(t)]′ for Ψ ∈ R^{N_θ×N_y}; ψ ∈ R^{N_y×1} (5.61)

Differentiating Eq. (5.59) using the chain rule,¹ we obtain the gradient

∇_θ J(Θ) = ∇_θ e'_θ(t) Λ^{-1}(t) e_θ(t) = -Ψ_θ(t) Λ^{-1}(t) e_θ(t) (5.62)

using the gradient matrix from the definition above.

Defining the Hessian matrix as R(t) := ∇_{θθ} J(Θ) and substituting for the gradient in Eq. (5.60), we obtain the parameter vector recursion

\hat{Θ}(t + 1) = \hat{Θ}(t) + γ(t)[R(t)]^{-1} Ψ_θ(t) Λ^{-1}(t) e_θ(t) (5.63)

where γ(t) is an N_θ-weighting vector sequence. However, this does give us a recursive form, but it can be transformed to yield the desired result, that is, under the Gauss–Newton approximation, it has been shown [2] that the Hessian can be approximated by a weighted sample variance estimator of the form

R(t) = (1/t) Σ_{k=1}^{t} γ(k) ψ(k) Λ^{-1}(k) ψ′(k) (5.64)

which is easily placed in recursive form to give

R(t) = R(t - 1) + γ(t)[ψ(t) Λ^{-1}(t) ψ′(t) - R(t - 1)] (5.65)

Following the same arguments, the prediction error covariance can be placed in recursive form as well to give

Λ(t) = Λ(t - 1) + γ(t)[e_θ(t) e'_θ(t) - Λ(t - 1)] (5.66)

The N_θ × N_y-gradient matrix in terms of our innovations model is given by

Ψ_θ(t) = ∇_θ e_θ(t) = ∇_θ \hat{y}′(t|t - 1)
= ∇_θ [C(Θ) \hat{x}_θ(t|t - 1)]′ and Ψ_θ ∈ R^{N_θ×N_y} (5.67)

A matrix expansion of the gradient matrix with operations developed component-wise is

Ψ_θ(t) = ∇_θ [C(Θ) \hat{x}_θ(t|t - 1)]′
= [ ∂/∂θ_1 ; ⋮ ; ∂/∂θ_{N_θ} ] [ c'_1(Θ) \hat{x}_θ(t|t - 1) ⋯ c'_{N_y}(Θ) x_θ(t|t - 1) ]

> 1 The chain rule from vector calculus is defined by ∇_Θ(a′b) := (∇_Θ a′)b + (∇_Θ b′)a a, b ∈ R^{N_θ×1} with a, b functions of Θ.
