and the *measurement mean vector* $m_y$ as

$$m_y(t)=C(t)m_x(t)+D(t)u(t)$$  \tag{3.61}

The *state variance*³ $P(t):=\operatorname{var}\{x(t)\}$ is given by the discrete Lyapunov equation:

$$P(t)=A(t-1)P(t-1)A'(t-1)+W(t-1)R_{ww}(t-1)W'(t-1)$$  \tag{3.62}

and the measurement variance, $R_{yy}(t):=\operatorname{var}\{y(t)\}$ is

$$R_{yy}(t)=C(t)P(t)C'(t)+R_{vv}(t)$$  \tag{3.63}

Similarly, it can be shown that the *state covariance* propagates according to the following equations:

$$P(t,k)=\begin{cases}\Phi(t,k)P(k),&\text{for }t\ge k\\P(t)\Phi'(t,k),&\text{for }t\le k\end{cases}$$  \tag{3.64}

We summarize the Gauss–Markov and corresponding statistical models in Table 3.1.

If we restrict the Gauss–Markov model to the stationary case, then

$$A(t)\to A,\quad B(t)\to B,\quad C(t)\to C,\quad W(t)\to W,\quad R_{ww}(t)\to R_{ww},$$
$$\text{and }R_{vv}(t)\to R_{vv}$$

**Table 3.1  Gauss–Markov representation.**
