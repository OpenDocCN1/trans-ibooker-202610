To develop the actual internal structure of the processor, we start with the EKF equations, augment them with the unknown parameters, and then investigate the resulting algorithm. We first define the composite state vector (as before) consisting of the original states, $x(t)$, and the unknown “augmented” parameters represented by $\theta(t)$, that is,

$$X(t):=\begin{bmatrix}x(t)\\---\\\theta(t)\end{bmatrix}$$

where $t$ is the time index, $X\in R^{(N_x+N_{\theta})\times1}$, and $x\in R^{N_x\times1},\theta\in R^{N_\theta\times1}$.

Substituting this augmented state vector into the EKF relations of Table 4.6, the following matrix partitions evolve as

$$\widetilde{P}(t|t-1):=\begin{bmatrix}
\widetilde{P}_{xx}(t|t-1) & \widetilde{P}_{x\theta}(t|t-1)\\
- & -\\
\widetilde{P}_{\theta x}(t|t-1) & \widetilde{P}_{\theta\theta}(t|t-1)
\end{bmatrix},\quad \widetilde{P}_{\theta x}(t|t-1)=\widetilde{P}'_{x\theta}(t|t-1)$$

where $\widetilde{P}\in R^{(N_x+N_{\theta})\times(N_x+N_{\theta})}$, $\widetilde{P}_{xx}\in R^{N_x\times N_x}$, $\widetilde{P}_{\theta\theta}\in R^{N_\theta\times N_\theta}$, and $\widetilde{P}_{x\theta}\in R^{N_x\times N_\theta}$.

This also leads to the partitioning of the corresponding gain

$$\mathcal{K}(t):=\begin{bmatrix}K_x(t)\\---\\K_\theta(t)\end{bmatrix}$$

for $\mathcal{K}\in R^{(N_x+N_{\theta})\times N_y}$, $K_x\in R^{N_x\times N_y}$, and $K_\theta\in R^{N_\theta\times N_y}$.
