where

A(z) = 1 + a_1 z^{-1} + ... + a_{N_a} z^{-N_a}

If we substitute H_AR for H_1, we obtain the AR power spectrum as

S_yy(z) = H_AR(z) H_AR^*(z) S_ee(z) = |H_AR(z)|^2 S_ee(z) (2.41)

or

S_yy(z) = (1/A(z))(1/A(z^{-1})) R_ee ΔT = R_ee ΔT / |A(z)|^2

which is the desired representation of the all-pole spectral density. Here recall that ΔT is the associated sampling interval. Note also that the spectral estimation procedure requires that we first estimate the AR model parameters, ({â_i}, R̂_ee) from the data and then form the estimate

min_a J(t) = E{e^2(t)} (2.43)

where the estimation error is defined by

e(t) := y(t) - ŷ(t)

and ŷ is the minimum variance estimate obtained from the AR model

y(t) = - Σ_{i=1}^{N_a} a_i y(t - i) + e(t) (2.44)
