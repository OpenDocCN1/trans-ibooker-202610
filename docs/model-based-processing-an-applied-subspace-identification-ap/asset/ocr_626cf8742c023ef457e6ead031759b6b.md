Further assuming that the system is LTI then over a finite time interval for t = 0, …, K − 1 for K > Nₓ leads to the K N_y × N_x observability matrix [4] given by

```
𝒪_K := [ C ; --- ; ⋮ ; --- ; C A^{K-1} ]  (3.47)
```

Therefore, a necessary and sufficient condition for a system to be completely observable is that the rank of 𝒪 or ρ(𝒪_K) must be N_x. Thus, for the LTI case, checking that all of the measurements contain the essential information to reconstruct the states reduces to checking the rank of the observability matrix. Although this is a useful mathematical concept, it is primarily used as a rule of thumb in the analysis of complicated measurement systems.

Analogous to the system theoretic property of observability is that of controllability, which is concerned with the effect of the input on the states of the dynamic system. A discrete system is said to be completely controllable if for any x(t), x(0) ∈ ℝ^{N_x×1}, there exists an input sequence, {u(t)} such that the solution to the state equations with initial condition x(0) is x(t) for some finite t > 0. Following the same approach as for observability, we obtain that the controllability Gramian defined by

```
C(0, t) := Σ_{k=0}^{t-1} Φ(0, k) B(k) B'(k) Φ'(0, k)  (3.48)
```

is nonsingular or ρ[C(0, t)] = N_x

Again for the LTI system, then over a finite time interval for t = 0, …, K − 1 for K > N_x the N_x × K N_u controllability matrix defined by

```
C_K := [ B | A B | … | A^{K-1} B ]  (3.49)
```

must satisfy the rank condition, ρ(C_K) = N_x to be completely controllable [4].

If we continue with the LTI system description, we know from ℤ-transform theory that the discrete transfer function can be represented by an infinite power series [4], that is,

```
H(z) = C(zI − A)^{-1} B = Σ_{t=1}^{∞} H_t z^{-t}  for  H_t = C A^{t-1} B  (3.50)
```

where H_t is the N_y × N_u unit impulse response matrix with H_0 = D. Here {H_t}_0^∞ is defined as the Markov sequence with the corresponding set of Markov parameters given by the embedded system Σ_{ABCD} = {A, B, C, D}.

If the MIMO transfer function matrix is available, then the impulse response (matrix) sequence {H_t} can be determined simply by long division of each matrix component (i, j) transfer function, that is, H_{ij}(z) = N_{ij}(z)/D_{ij}(z).
