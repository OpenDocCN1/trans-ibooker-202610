Therefore, we have the PO-Multivariable Output Error State-Space (PO-MOESP) [17] algorithm given by the following steps:

+   - Compute the LQ-decomposition of D of Eq. (7.80).
+   - Perform the SVD of L32 in Eq. (7.91) to extract O_k.
+   - Obtain A and C from Eq. (7.93).
+   - Solve the least-squares problem to obtain B and D from Eq. (7.95).
+   - With ΣKSP available, solve the INV-based (Kalman) Riccati equation of Eq. (7.96) for the positive definite state error covariance Π̃.
+   - Compute the INV covariance Ree and Kalman gain Kp from Eq. (7.97).
+   - Compute the corresponding set of noise covariances {Ruw^e, Rvv^e, Rwv^e} from Eq. (7.98).
