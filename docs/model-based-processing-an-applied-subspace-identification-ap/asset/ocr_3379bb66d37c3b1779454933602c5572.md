where Σ_{N_x}^{1/2} is the matrix square root, that is, R = S^{1/2} × (S')^{1/2} obtained by a Cholesky decomposition [22].

Now from shift-invariant property (see Eq. (6.10)) of the observability or controllability matrices, we can obtain the system matrices from either

𝒪_{N_x} × A = 𝒪_{N_x}^†
 or
 A × 𝒞_{N_x} = 𝒞_{N_x}^-
which yields the unique system matrices by applying the pseudo-inverse² (Z^# := (Z'Z)^{-1}Z'), since minimality guarantees full-rank observability and controllability matrices

A = 𝒪_{N_x}^# × 𝒪_{N_x}^†  or  A = 𝒞_{N_x}^- × 𝒞_{N_x}^#  (6.28)

with the input and output matrices extracted directly from the controllability and observability matrices as

B = 𝒞(1 : N_x, 1 : N_u)  and  C = 𝒪(1 : N_y, 1 : N_x)  (6.29)

However, from the SVD of Eq. (6.27), we have

A = 𝒪_{N_x}^# 𝒪_{N_x}^† = (Σ_{N_x}^{-1/2} U_{N_x}') × 𝒪_{N_x}^† or A = 𝒞_{N_x}^- 𝒞_{N_x}^# = 𝒞_{N_x}^- × (V_{N_x} (Σ_{N_x}^{-1/2})')  (6.30)

which is a very efficient method of calculating the pseudo-inverse and extracting the model.

It is also interesting to note that with the SVD extraction of Σ_{ABCD}, both for the A and C-matrices all lower-order models are “nested” within these structures and can easily be extracted as submatrices (see [23] and Problem 6.6 for more details).
