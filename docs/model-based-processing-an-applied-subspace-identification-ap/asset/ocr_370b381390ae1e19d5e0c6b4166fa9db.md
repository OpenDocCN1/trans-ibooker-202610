P_{Z|U}^{\perp} = U_2 \times U_2' = I - Z \times Z^{\#}
P_{Z|V} = V_1 \times V_1' = Z^{\#} \times Z
P_{Z|V}^{\perp} = V_2 \times V_2' = I - Z^{\#} \times Z
(C.9)

Finally, the SVD simultaneously diagonalizes the projection, Gramian matrix, and pseudo-inverse [2]

P_{Z|U} = U \times \begin{bmatrix} I & 0 \\ 0 & 0 \end{bmatrix} \times U' \quad (Projection)
G_Z := Z' \times Z = V \times \Sigma^2 \times V' \quad (Gramian)
Z^{\#} = V \times \Sigma^{-1} \times U' \quad (Pseudo-Inverse)
(C.10)

# C.2 QR-Decomposition

The QR-decomposition of a matrix is the matrix implementation of the well-known Gram–Schmidt vector orthogonalization procedure [4]. It is defined by the product of an orthogonal matrix Q \in R^{n\times m} with m \ge n and an upper triangular matrix R_q \in R^{m\times m}, that is,

R = Q \times R_q
(C.11)

where Q' \times Q = I_n such that Q' R = R_q with Q' is the orthogonal matrix transforming R \to R_q. It is numerically implemented using the Householder transform, T = I - 2 u u' with the vector u defined by

u = \pm \frac{v_1 - v_2}{\| v_1 - v_2 \|} \quad \| u \| = 1
(C.12)

# C.3 LQ-Decomposition

The LQ-decomposition is the (dual of the QR-decomposition: L = R', Q = Q' where

Z = L \times Q with L lower block triangular; and Q orthogonal
(C.13)
