therefore considered a “data adaptive” method. The idea behind the MVDR spectral estimator is that for a given discrete frequency, Ωₘ the signal to be extracted is characterized by a complex exponential (narrowband), that is,

```
x(t) = A e^{jΩₘ t}  (2.58)
```

and

```
X(Ω) = A δ(Ω − Ωₘ)
```

The measured output signal is assumed contaminated with additive white noise

```
y(t) = x(t) + n(t)  (2.59)
```

An estimator is to be designed so that the output variance is minimized, and the frequency under consideration, Ωₘ is passed undistorted. We assume that the estimator is of the form

```
ŷ(t) = h(t) * y(t) = Σ_{k=0}^{N} h(k) y(t − k)  (2.60)
```

Since the estimator is designed to pass the narrowband signal x(t), we would like to pass A e^{jΩₘ t} with unity gain or

```
H(Ω)|_{Ω=Ωₘ} = 1
```

In order to achieve this, we also require the estimate to be unbiased

```
E{ŷ(t)} = x(t) = A e^{jΩₘ t} = Σ_{k=0}^{N} h(k) E{ y(t − k) }
```

but from this relation, we have that

```
A e^{jΩₘ t} = Σ_{k=0}^{N} h(k) E{ x(t − k) + n(t − k) }
```

or

```
A e^{jΩₘ t} = Σ_{k=0}^{N} h(k) (A e^{jΩₘ (t−k)})  (2.61)
```

Dividing, we obtain the desired result

```
1 = Σ_{k=0}^{N} h(k) e^{−j k Ωₘ} = H(Ω)|_{Ω=Ωₘ}  (2.62)
```
