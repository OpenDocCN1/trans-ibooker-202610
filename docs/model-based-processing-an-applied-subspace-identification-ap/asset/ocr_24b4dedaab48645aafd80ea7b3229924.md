Under the Gauss–Markov assumptions, there exists an optimal model-based solution – the Kalman filter of Chapter 4 and Table 4.1 [9].

The performance of the processor is optimum, when the innovations sequence is deemed statistically white. The results of this run are white, indicating the desired performance.
