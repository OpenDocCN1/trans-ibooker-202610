Discretizing this equation using first differences with sampling interval $\Delta T$ and including white Gaussian noise sources for the parameter and measurement uncertainties, we develop the following discrete Gauss–Markov model:

```
$$e(t)=\left(1-\frac{\Delta T}{RC}\right)e(t-1)+\frac{\Delta T}{C}I_{in}(t-1)+w(t-1)$$
$$e_{out}(t)=K_e\,e(t)+v(t)$$
```

The resulting model-based processor (Kalman filter) is given by

```
$$\hat e(t|t)=\left(1-\frac{\Delta T}{RC}\right)\hat e(t-1|t-1)+K(t)e(t)$$
```

For $R=3.3\ \mathrm{k}\Omega$ and $C=1000\ \mu\mathrm{F}$, $\Delta T=100\ \mathrm{ms}$, $K_e=2.0$, $e_0=2.5\ \mathrm{V}$, $I_{in}=100\ \mu\mathrm{A}$ (negative step) with $w\sim\mathcal{N}(0,0.0001)$ and $v\sim\mathcal{N}(0,4.0)$ or

```
$$e(t)=0.97e(t-1)+I_{in}(t-1)+w(t-1)$$
$$e_{out}(t)=2e(t)+v(t)$$
```
