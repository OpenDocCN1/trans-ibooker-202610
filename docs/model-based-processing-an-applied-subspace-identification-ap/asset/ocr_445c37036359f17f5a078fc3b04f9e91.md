Time-invariant state-space discrete systems can also be represented in *input/output or transfer function* form using the Z-transform to give

H(z) = C(zI - A)^{-1}B + D = C\left(\frac{adj(zI - A)}{det(zI - A)}\right)B + D \quad (3.29)

where recall “adj” is the matrix adjoint (transpose of the cofactor matrix) and “det” is the matrix determinant.

We define the *characteristic equation* or *characteristic polynomial* of the N-dimensional system matrix A as

α(z) := det(zI - A) = z^N + α_1 z^{N-1} + α_2 z^{N-2} + ⋯ + α_{N-1} z + α_N \quad (3.30)

with *roots* corresponding to the *poles* of the underlying system that are also obtained from the *eigenvalues* of A defined by

λ(A) := eig(A) = ∏_{n=1}^N (z - λ_n) \quad (3.31)

for λ_n is the nth system pole.

Taking inverse Z-transforms of Eq. (3.29), we obtain the discrete impulse (or pulse) response matrix as

H_t = C A^{t-1} B + D δ(t) \quad (3.32)

for δ the Kronecker delta function.

The solution to the state-difference equations can easily be derived by induction [3] and is given by

x(t) = Φ(t, k)x(k) + Σ_{i=k+1}^t Φ(t, i)B(i)u(i) \quad for \quad t > k \quad (3.33)

where Φ(t, k) is the *discrete-time state-transition* matrix. For time-varying systems, it can be shown (by induction) that the state-transition matrix satisfies

Φ(t, k) = A(t - 1)·A(t - 2)⋯A(k)

while for time-invariant systems the state-transition matrix is given by

Φ(t, k) = A^{t-k} \quad for \quad t > k

The *discrete state-transition matrix* possesses properties analogous to its continuous-time counterpart, that is,

+   1) Φ(t, k) is uniquely defined \hfill (Unique)
+   2) Φ(t, t) = I \hfill (Identity)
+   3) Φ(t, k) satisfies the matrix difference equation:
+      Φ(t, k) = A(t - 1)Φ(t - 1, k), \quad Φ(k, k) = I, t ≥ k + 1 \quad (3.34)
+   4) Φ(t, k) = Φ(t, t - 1) × Φ(t - 1, t - 2) × ⋯ × Φ(k + 1, k) \hfill (Semi-Group)
+   5) Φ^{-1}(t, k) = Φ(k, t) \hfill (Inverse)
