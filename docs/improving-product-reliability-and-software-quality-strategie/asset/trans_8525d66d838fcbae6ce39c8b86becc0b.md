
| Term | Definition |
|------|------------|
| ELT | 早期寿命测试是在产品开发过程中识别非预期早期寿命损耗机制的过程。 |
| EOS | 电气过应力是在施加到电路或器件的电信号超过规格限制时可能发生的损坏。 |
| ESD | 静电放电是由两个带电物体之间突然的电流流动造成的潜在损坏，该流动会产生电气短路或介电击穿。 |
| ESS | 环境应力筛选是将组件、器件或产品暴露于热循环和振动等应力下，以使潜在缺陷在应力筛选过程中通过永久性或灾难性失效而显现的过程。 |
| FA | 失效分析是收集和分析数据以确定失效根本原因的过程。 |
| FBD | 功能框图是对系统或过程的功能及其相互关系进行描述的图形视图。 |
| FIFO | 先进先出是一种管理商品、原材料、零件和组件库存的方法，按最旧的库存优先使用。 |
| FIT | 每十亿小时失效次数是描述系统、器件或组件失效速率或频率的一种方式。 |
| FMEA | 失效模式和影响分析是一种工具，用于识别可能发生的潜在失效，并确定其严重性、发生概率和被检测的可能性，从而识别出最重要和最紧急的风险问题进行调查。 |
| FMMEA | 失效模式、机制和影响分析是一种工具，用于识别可能发生的潜在失效及其相关机制，并确定其严重性、发生概率和被检测的可能性，从而识别出最重要和最紧急的风险问题进行调查。 |
| FRACAS | 失效报告、分析和纠正措施系统是一种持续改进的过程，涉及收集失效数据、根据风险对失效进行优先级排序和调查，其目标是确定根本原因并实施纠正措施以消除未来再次发生失效。 |
| FRU | 现场更换单元是可以由用户或服务技术人员快速、轻松地维修或更换的任何组件、部件或印刷电路板，无需将其送至维修设施。 |
| FTA | 故障树分析是一种图形逻辑图，用于识别器件或系统失效的潜在原因。 |
| GOBI | 停止老化试验是在达到可接受的良率水平时停止老化试验的程序。 |
| HAL | 硬件抽象层（HAL）是一层薄软件，暴露出硬件的功能接口，以隐藏硬件细节不被调用软件所知。 |
| HALT | 高加速寿命试验是一种阶跃应力技术，旨在发现产品中的薄弱环节。 |
| HASA | 高加速应力审核是一种方法，用于从对所有生产材料进行应力测试转变为抽样测试，以确保产品质量。 |
| HASS | 高加速应力筛选是一种加速可靠性筛选，可揭示与工艺或制造相关的潜在产品缺陷。 |
| HAST | 高加速应力试验是一种涉及温度和湿度的高加速应力试验。 |
| HTOL | 高温工作寿命是对集成电路施加的加速可靠性应力试验，用于确定其可靠性。 |
| ICM | 识别、沟通和缓解是一种管理并缓解技术风险的过程。 |
| IDE | 集成开发环境是一种软件开发工具，结合了编辑、编译和调试功能。示例 IDE 有 Microsoft Visual Studio 和 Eclipse。 |
| IOT | 物联网是一个通用术语，用来指代连接到网络并可通过该网络远程控制或监控的众多设备。 |
| JIT | 准时制是一种管理库存的方式，其中材料、工艺和劳动力按需在生产过程中到达。 |
| LOC | 代码行代表一条可编译代码的单一编程语言语句。 |
| MRB | 物料评审委员会是一组人员，会议目的是确定不合格物料的处理方式。 |
| MTBF | 平均故障间隔时间是可修复系统在所有故障之间的算术平均时间计算得出的估计故障间隔时间。 |
| MTBI | 平均事件间隔时间是一个较少使用的术语，用来描述可能需要用户干预来修复的事件的频率。 |
| MTBM | 平均维护间隔时间用于描述可修复系统的可靠性。它是现场所有系统在两次维护（预防性维护和维修）之间的平均时间的度量。 |
| MTTF | 平均失效时间是描述不可修复系统可靠性的常用术语。 |
| MTTR | 平均修复时间是修复机队中所有故障所需时间的总和除以机队中的总故障数。 |
| MTTRS | 平均系统恢复时间与 MTTR 类似，但还包括获取修复问题所需零件的额外时间。 |
| Next-generation product | 包含改进技术或功能的产品的更新版本。 |
| NIST | 国家标准与技术研究院是一个计量标准实验室。 |
| NRE | 非经常性工程是为新产品或衍生产品的研究、设计和开发所关联的一次性费用。 |
| Pareto chart | 一种图表，显示按发生次数排序的排名，最频繁的在 x 轴左侧，最不频繁的向右递减。 |
| PDCA | 计划-执行-检查-行动是一种用于持续改进流程和产品的四步方法。 |
| PHM | 预测与健康管理提供了一种流程和方法，将实时数据与预期良好的数据集进行比较，以便对其健康状况做出判断。 |
| POS | 筛选证明是对 HASS 配置文件的重复，以确定沉淀应力是否过于严重或无效。 |
| PPM | 百万分之一。 |
| QFD | 质量功能展开是识别可能影响产品满足客户需求和要求的所有因素的过程。 |
| Quality | 质量是符合规格。 |
| RAC | 可靠性分析中心由美国国防部资助，为可靠性、可维护性、支持性和质量等工程学科提供技术专业知识。 |
| RCA | 根本原因分析是一个过程，通过该过程可以识别整体开发过程中的弱点，目的是随着时间的推移加以改进。 |
| RDT | 可靠性验证试验是一个过程，可在统计上确保项目早期设定的可靠性目标得以实现。 |
| Reliability | 可靠性是产品在预期时间内并在规定的运行条件下满足其要求的概率，即随时间推移的质量。 |
| RPN | 风险优先数是通过将发生、严重性和检测排名的乘积得出的风险数值评估。 |
| SDK | 软件开发工具包是库和/或示例代码，可促进使用特定软件平台或产品开发应用程序。 |
| SDLC | 软件开发生命周期是一组用于开发、测试和发布软件的流程和程序。 |
| SFTA | 软件故障树分析与 FMEA 类似，是一种预测失效及其潜在原因的工具。 |
| Sprint | Sprint 是在敏捷 SDLC 中使用的短开发迭代。 |
| SQA | 软件质量保证是验证软件按预期无错误运行的过程。SQA 也可指执行软件质量实践的人员。 |
| SPC | 统计过程控制是一种质量控制方法，采用统计方法来监控和控制过程。 |
| TQM | 全面质量管理是一种质量控制系统，其中组织的每个部门都设定目标和流程以实现这些目标。 |
| UML | 统一建模语言是一种通用建模语言，用于描述软件系统的各个方面 |
| Validation | 确保产品规格满足客户需求的过程，即造对的东西。 |
| Verification | 确保产品符合规格的过程，即把东西造对。 |
| VOC | 客户之声是捕获客户关于期望、体验、偏好和未来要求的输入的过程。 |
| Wearout | 磨损是指产品因化学、电、机械、物理、辐射或热降解而劣化到不可接受的状态后无法再使用。 |
