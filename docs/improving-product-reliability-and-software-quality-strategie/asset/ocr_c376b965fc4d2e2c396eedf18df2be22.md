# 20.8 HALT Test Development

In the HALT planning phase, the assemblies were identified for HALT testing along with the number of assemblies to be tested. Teams were then formed for each assembly to support the HALT activities. The HALT test development can begin after the planning is in place. The goal of test development is to have everything ready to support the HALT effort before testing begins (Figure 20.8).
