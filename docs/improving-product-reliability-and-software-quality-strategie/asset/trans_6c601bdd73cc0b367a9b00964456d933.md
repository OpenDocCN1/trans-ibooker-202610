# 关于作者

**Mark A. Levin** 是 Teradyne, Inc. 的可靠性经理，驻加州阿古拉山。他于1982年获得亚利桑那大学电气工程理学学士学位，1999年获得佩珀代因大学技术管理理学硕士学位，2009年获得马里兰大学可靠性工程理学硕士学位，并完成了马里兰大学可靠性工程博士论文的全部课程。他拥有超过36年的电子行业经验，涵盖航空航天、国防、消费和医疗电子行业。他曾在休斯飞机导弹系统集团、休斯飞机微波产品部、通用医疗公司和医疗数据电子公司担任多个管理和研究职位。他的经验多样，曾从事制造、设计和研发工作。他已制定制造和可靠性设计指南、可靠性培训课程、工艺标准、质量计划、准时制制造和ESD安全工作环境，并建立了表面贴装生产线。

(Mark.levin@Teradyne.com)

**Ted T. Kalal** 是一名可靠性工程师（现已退休），他通过实践经验和众多优秀导师获得了大部分可靠性理解。他于1981年毕业于威斯康星大学，主修工商管理，在此之前完成了数学、物理和电子学的预科学习。他曾担任多家公司的合同工程师和顾问，能够专注于设计、质量和可靠性任务。他已发表多篇电子电路论文，并在电力电子领域拥有专利。与两位合伙人一起，他创办了一家小型制造公司，生产面向生物研究社区的高科技电源和其他科学仪器。

**Jonathan Rodin** 是 Teradyne, Inc. 的软件工程经理。乔恩于1981年毕业于哥伦比亚大学，拥有39年软件开发经验，既担任程序员也管理软件开发项目。他的经验涵盖各种规模的公司，从初创企业到员工超过10万人的公司。在加入Teradyne之前，乔恩曾在FTP Software、NaviSite和Percussion Software担任高级工程管理职位。他多次领导软件流程再造项目，最近一次推动Teradyne半导体测试部门达到CMMI 3级。
