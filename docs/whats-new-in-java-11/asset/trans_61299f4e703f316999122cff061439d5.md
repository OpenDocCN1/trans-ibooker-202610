## What’s New in Java 11

## Introduction

几十年来，Java 一直是企业软件中最常用的编程语言之一，其发布节奏比以往任何时候都快。从 2017 年发布的 Java 9 开始，发布节奏已改为每六个月一次。Java 10 为平台添加了新功能。然而，对于许多用户来说，这些变化不足以证明迁移到 Java 10 的努力是合理的。但 Java 11 超出了典型的全新功能和错误修复。

作为一名 Java 开发者，很难跟上每个版本中包含的最新发展。本报告解释了升级到 Java 11 的好处，并为您提供了对其引人注目的特性的快速但凝练而富有洞察力的概述。

从早期版本的 Java 迁移可能并不像您预期的那样简单。Java 11 从平台中移除了多种技术和 API。在本报告中，您将了解有助于您尽快跟上进度的迁移策略。但是，尽管存在潜在障碍，Java 11 的新功能使升级是值得的。

## Convergence of Oracle JDK and OpenJDK

OpenJDK，即 Oracle JDK 的开源对应版本，自 Java 7 以来就已存在。在很大程度上，两种发行版的语言特性、核心 Java 库和工具非常相似，甚至完全相同。除了这些方面之外，Java 11 之前的 Oracle JDK 版本还包括商业功能，如 Flight Recorder、Java Mission Control 和 Z Garbage Collector，可通过在启动新 JVM 时传递 `-XX:+UnlockCommercialFeatures` 选项来激活。Java 11 之后，商业功能免费，并已添加到 OpenJDK。我们将在后面的章节中讨论其中一些功能。

Oracle 的长期目标是通过将商业工具完全开源来使两个发行版趋同。Java 11 实现了这一里程碑，同时还存在一些小的打包和外观差异。那么，您可能会问，对于您的项目应该选择哪个发行版？让我们来看看每个选项的许可影响。

## Licensing of the Oracle JDK and OpenJDK

Oracle JDK 和 OpenJDK 之间唯一的区分因素是许可协议。OpenJDK 继续以 GNU 通用公共许可证第 2 版（GPL 2）附带类路径例外的方式许可。该许可证允许您在开发和生产用途中将 Java 用于开源项目以及商业产品而无需任何限制或归属。类路径例外将 OpenJDK 的许可条款与随可执行程序捆绑的外部库适用的许可条款解耦。关于 Oracle JDK，其许可已从 Oracle Java SE 技术的二进制代码许可（BCL）更改为商业许可。因此，您不能再在不购买 Java SE 订阅模式的情况下将 Oracle JDK 用于生产。

> **NOTE**
> 
> 订阅模式也适用于 2019 年 1 月之后发布的任何 Java 8 修补程序版本，如果用于商业产品。

了解许可影响非常重要，以便为您的组织做出正确的选择。如果您正在从事关键任务软件，并且希望依靠 Oracle 对长期补丁的支持，商业 Oracle JDK 许可可能是最佳选择。对于开源软件和仅在未来六个月内需要短期补丁发布的产品，OpenJDK 应该完全足够。无论哪种方式，在升级到 Java 11 时，您都需要决定使用哪个 Java 发行版。请注意，还有其他供应商提供的免费 OpenJDK 发行版。有关更多信息，请参阅 Java Champions 的博客文章“Java Is Still Free”。

## Six-Month Release Cadence: What It Means to You

在 Java 的早期，新版本是一件大事。它们每两到三年才发布一次，包含大量重大、有时是破坏性的更改，例如 Java 5 中的泛型，或 Java 8 中的语法更改，或 Java 9 的模块系统。将软件项目迁移到新 Java 版本通常需要大量的计划和工作。一些项目甚至不得不推迟软件生产过程，直到迁移完全完成。

许多行业领导者转向持续交付模型以推动创新并降低风险：更改更少，发布更频繁。Oracle 致力于遵循这一做法，每六个月发布一个主要版本，每两个月发布一个次要版本。因此，升级到新版本的 Java 对您的项目影响会更小。图 1-1 显示了即将到来的主要和次要 Java 版本的预期日期。

发布频率更高意味着确保平台稳定性的责任。正是出于这个原因，Oracle 每三年提供一个长期支持版本。接下来，我们来看看“长期支持”在实践中意味着什么。

## Long-Term Support

Oracle 为所有被指定为长期支持（LTS）版本的主要 Java 版本提供终身 Premier 支持。LTS 版本的好处是，付费客户即使在下一个主要版本发布后仍会收到定期补丁更新。例如，Java 11 之后的下一个 LTS 版本将是计划于 2021 年 9 月发布的 Java 17。在此期间，您将继续收到上一节中解释的新版本。对于任何主要 Java 版本，OpenJDK 用户将仅收到另外两次补丁发布。此后，假设您需要升级到下一个主要版本。
