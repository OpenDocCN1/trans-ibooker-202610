But for now let’s learn the chain rule with a simple algebraic example. Let’s say you are given two functions:

$y = x^2 + 1$

$z = y^3 - 2$

Notice above the two functions are linked, because the y is the output variable in the first function but is the input variable in the second. This means we can substitute the first function y into the second function z like this:

$z = (x^2 + 1)^3 - 2$

So what is the derivative for z with respect to x? We already have the substitution expressing z in terms of x. Let’s use SymPy to calculate that in Example 1-27.

# *Example 1-27. Finding the derivative of z with respect to x*

```
```python
from sympy import *

z = (x**2 + 1)**3 - 2
dz_dx = diff(z, x)
print(dz_dx)

# 6*x*(x**2 + 1)**2
```
