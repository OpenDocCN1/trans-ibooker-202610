# USING R-SQUARE FOR TESTING

Note the \( r^2 \) is calculated a little bit different here as we have a predefined linear regression from training. We are comparing the testing data to a regression line built from training data. The objective is still the same: being closer to 1.0 is desirable to show the regression correlation is strong even with the training data, while being closer to 0.0 indicates the test dataset performs poorly. Here is how it is calculated, where \( y_i \) is each actual y-value, \( \widehat{y_i} \) is each predicted y-value, and \( \overline{y} \) is the average y-value for all data points.

\( r^2 = 1 - \frac{\sum \left( y_i - \widehat{y_i} \right)^2}{\sum \left( y_i - \overline{y} \right)^2} \)
