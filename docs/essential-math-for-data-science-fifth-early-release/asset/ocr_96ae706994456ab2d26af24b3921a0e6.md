+   4. The Python code below calculates an answer of .822, adding up the probabilities of 50 or more passengers who do not show up.

# Example B-5.

```
from scipy.stats import binom

n = 137
p = .40

p_50_or_more_noshows = 0.0

for x in range(50, 138):
    p_50_or_more_noshows += binom.pmf(x, n, p)

print(p_50_or_more_noshows) # 0.822095588147425
```

+   5. Using the beta distribution as shown in the SciPy code below, get the area up to .5 and subtract it from 1.0. Result is about .98 so this coin is highly unlikely to be fair.

# Example B-6.

```
from scipy.stats import beta

heads = 8
tails = 2

p = 1.0 - beta.cdf(.5, heads, tails)

print(p) # 0.98046875
```
