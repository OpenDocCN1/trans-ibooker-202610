
## 第 8 章 职业建议与前进之路

当本书即将结束时，回顾一下接下来的方向是个好主意。你学习并整合了广泛的应用数学主题：微积分、概率论、统计学和线性代数。然后你将这些技术应用于线性回归、逻辑回归和神经网络等实际应用。在本章中，我们将探讨如何在前进的过程中运用这些知识，同时穿梭于数据科学职业生涯那奇特、激动人心且异常多样的领域。我将强调拥有方向和切实目标的重要性，而不是在没有实际问题的情况下死记硬背工具和技术。

由于我们正在脱离基础概念和应用方法，本章的语气与书中其余部分不同。你可能期望学习如何将这些数学建模技能以专注且切实的方式应用于你的职业生涯。然而，如果你想在数据科学职业生涯中取得成功，你还需要掌握 SQL 和编程等一些硬技能，以及培养专业意识所需的软技能。后者尤其重要，以免你在不断变幻的数据科学职业中迷失方向，被看不见的市场力量打个措手不及。

我不会假设你的职业目标或你希望通过这些信息实现什么。不过，既然你在读这本书，我可以做几个合理的猜测。我想你可能对数据科学职业感兴趣，或者你已经在数据分析领域工作，希望将你的分析知识正式化。也许你来自软件工程背景，渴望掌握“AI”和机器学习。或者你是某种项目经理，发现你需要了解数据科学或 AI 团队的能力，以便相应地制定范围。

也许你只是一个好奇的专业人士，想知道数学在实际层面而不仅仅是学术层面如何有用。

我会尽力回应所有这些群体的关切，并希望概括一些对大多数读者有用的职业建议。让我们从重新定义数据科学开始。我们已经客观地研究了它，现在将从职业发展和该领域未来的角度来审视它。

### 重新定义数据科学

数据科学是分析数据以获得可操作洞察的过程。在实践中，它是将不同的数据相关学科融合为一体的综合体：统计学、数据分析、数据可视化、机器学习、运筹学、软件工程……仅举几例。几乎任何涉及数据的学科都可以被贴上“数据科学”的标签。这种缺乏明确定义的现象给该领域带来了问题。毕竟，任何缺乏定义的东西都广泛开放供人解读，就像一件抽象艺术品。
这就是为什么 HR 部门在“数据科学家”招聘启事方面苦恼不已，因为这些启事往往五花八门。图 8-1 展示了一个涵盖可能属于数据科学的不同学科和工具的伞形图。

我们是如何走到这一步的？以及像*数据科学*这样缺乏定义的东西如何能在商业世界中成为如此强大的力量？最重要的是，它的定义（或缺乏定义）如何影响你的职业生涯？这些都是本章讨论的重要问题。

这就是为什么我告诉我的客户，**数据科学更好的定义是精通统计学、机器学习和优化的软件工程。** 如果你去掉这四个学科中的任何一个（软件工程、统计学、机器学习和优化），数据科学家就有无法有效工作的风险。大多数组织在明确区分什么样的技能组合能让数据科学家有效方面一直存在困难，但所提供的定义应该能带来清晰度。虽然有些人可能认为软件工程是一个有争议的要求，但我认为考虑到行业的发展方向，这是非常必要的。我们稍后将讨论这一点。

但在此之前，理解*数据科学*的最好方式是追溯这个术语的历史。

### 数据科学简史

我们可以将*数据科学*追溯到统计学的起源，早在 17 世纪甚至 8 世纪。为了简洁起见，让我们从 20 世纪 90 年代开始。分析师、统计学家、研究人员、“量化分析师”和数据工程师通常保持着各自不同的角色。工具栈通常由电子表格、R、MATLAB、SAS 和 SQL 组成。

当然，2000 年后事情开始迅速变化。互联网和联网设备开始产生海量数据。伴随 Hadoop 的兴起，Google 将分析和数据收集推向了难以想象的高度。随着 2010 年的临近，Google 的高管坚称统计学家将在下一个十年拥有“性感”的工作。接下来发生的事情具有预见性。

2012 年，《哈佛商业评论》将称为*数据科学*的这个概念主流化，并宣称它是“21 世纪最性感的工作”。在 HBR 文章发表后，许多公司和企业工人争相填补*数据科学*的空白。管理咨询公司准备就绪，并着手向财富 500 强领导者介绍如何将*数据科学*引入他们的组织。SQL 开发者、分析师、研究人员、量化分析师、统计学家、工程师、物理学家以及众多其他专业人士都将自己重新包装为“数据科学家”。科技公司觉得“分析师”、“统计学家”或“研究人员”等传统职位名称听起来过时了，便将这些职位重命名为“数据科学家”。

自然而然地，财富 500 强公司的高管层在 C 级高管的压力下不得不加入*数据科学*的行列。最初的推理是大量数据正在被收集，因此*大数据*成为一种趋势，需要*数据科学家*从中获取洞察。大约在这个时候，“数据驱动”一词成为各行各业的座右铭。企业世界认为，与人不同，数据是客观且无偏见的。

> **提醒 - 数据并非客观且无偏见！**
>
> 直到今天，许多专业人士和管理人员仍陷入数据客观且无偏见的谬误。希望读完本书后，你明白这并非事实，如果需要回顾原因，请参阅*第 3 章*。
