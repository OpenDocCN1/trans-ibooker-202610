We are missing another piece to this neural network, the activation functions, but we will get to that shortly. Let's first understand what's going on here. The first layer on the left is simply an input of the three variables, which in this case are the red, green, and blue values. In the hidden (middle) layer, notice that we produce three **nodes**, or functions of weights and biases, between the inputs and outputs. Each node essentially is a linear function with slopes _w<sub>i</sub>_ and intercepts _b<sub>i</sub>_, being multiplied and summed with input variables _x<sub>i</sub>_. There is a weight _w<sub>i</sub>_ between each input node and hidden node, and another set of weights between each hidden node and output node. Each hidden and output node gets an additional bias _b<sub>i</sub>_ added.

Notice the output node repeats the same operation, taking the resulting weighted and summed outputs from the hidden layer and making them inputs into the final layer, where another set of weights and biases will be applied. I put “repeat weighting and summing” instead of the mathematical expressions because the expressions nested from the hidden layer is too long to display in the graphic. But here is the expression for the final node, and note how the outputs from the hidden layer become inputs to the final layer.

```
output = w<sub>10</sub> (x<sub>1</sub>w<sub>1</sub> + x<sub>2</sub>w<sub>2</sub> + x<sub>3</sub>w<sub>3</sub> + b<sub>1</sub>)
+w<sub>11</sub> (x<sub>1</sub>w<sub>4</sub> + x<sub>2</sub>w<sub>5</sub> + x<sub>3</sub>w<sub>6</sub> + b<sub>2</sub>)
+w<sub>12</sub> (x<sub>1</sub>w<sub>7</sub> + x<sub>2</sub>w<sub>8</sub> + x<sub>3</sub>w<sub>9</sub> + b<sub>3</sub>) + b<sub>4</sub>
```

In a nutshell, this is a regression just like linear or logistic regression, but with many more parameters to solve for. The weight and bias values are analagous to the m and b, or β<sub>1</sub> and β<sub>0</sub>, parameters in a linear regression. We do use stochastic gradient descent and minimize loss just like linear regression, but we need an additional tool called backpropogation to untangle the weight _w<sub>i</sub>_ and bias _b<sub>i</sub>_ values and calculate their partial derivatives using the chain rule. We will get to that later in this chapter, but for now let's assume we have the weight and bias values optimized. We need to talk about activation functions first.
