# Linear Transformations

This concept of adding two vectors with fixed direction, but scaling them to
get different combined vectors, is hugely important. This combined vector,
except in cases of linear dependence, can point in any direction and have
any length we choose. This sets up an intuition for linear transformations
where we use a vector to transform another vector in a functional-like
manner.
