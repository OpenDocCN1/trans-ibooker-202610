

必须雇人为图片中的物体打标签。而这仅仅是数据收集！

数据科学家头18个月常常花在向管理层解释为什么还没有交付成果，这是因为他们仍在努力收集和清洗数据，而这占据了机器学习工作量的95%。
管理层可能因此对这种情况感到失望，因为他们受到了一个流行叙事的误导，认为“机器学习”和“AI”将消除手动流程，结果却发现他们只是用一套手动流程换取了另一套：即获取标注数据。

所以要警惕那些设定不合理目标的环境，并寻找外交方式来管理与管理层的期望，尤其是在他人向他们承诺了“轻松按钮”时。很多声称来自声誉良好的商业期刊和高价管理咨询公司，声称超级智能AI近在咫尺。缺乏技术专长的管理人员可能会陷入这种被炒作的叙事中。

## CUI BONO?

拉丁语表达 cui bono 意为“谁受益？”当你试图理解“杰伯沃基效应”（Jabberwocky Effect）全盛期的行为时，这是一个值得提出的好问题。当媒体宣传关于人工智能的故事时，谁从中受益？无论你的答案是什么，媒体也从点击量和广告收入中受益。高价管理咨询公司围绕“AI战略”创造更多可计费工时。芯片制造商可以推广深度学习来销售更多显卡，云平台可以为机器学习项目销售更多数据存储和CPU时间。

所有这些各方有什么共同点？他们不仅仅是把“AI”作为销售产品的手段，而且他们与客户的成功没有长期利益关系。他们在销售单位，而不是项目成果，就像在淘金热期间出售铲子一样。

不过，我并不是说这些媒体和供应商的动机是不道德的。他们的工作就是为公司赚钱、养家糊口。推广其产品的声明甚至可能是合法且可实现的。但是，不能否认的是，一旦声明被推广出来，就很难收回，即使后来意识到它无法实现。许多企业可能会转变方向并重新分配精力，而不是承认他们的声明未能实现。所以只需意识到这种动态，并始终问一句 cui bono？

## 与现有系统竞争

这种警告可能属于“合理目标”的范畴，但我认为这种情况足够常见，值得单列一类。一种微妙但有问题的角色是与实际上并未损坏的现有系统竞争。这些情况可能出现在缺乏事情可做、需要显得忙碌的工作环境中。

你的雇主几年前聘请供应商安装了一个销售预测系统。你的经理现在要求你通过提高准确率1%来改进预测系统。

你看到这里的统计学问题了吗？如果你读过第3章，1%不应该具有统计显著性，而随机性很容易在你不费吹灰之力的情况下就给你带来1%。相反，随机性可能朝相反方向波动，而你无法控制的市场力量可能会抵消你实施的任何努力。糟糕的销售季度和你无法控制的因素（例如竞争对手进入你公司的市场）会使收入减少-3%，而不是你不可避免地 p-hack 出来的 1%。

这里的总体问题在于，除了工作冗余之外，结果不在你的影响范围内。这可能会变成一种不太理想的情况。如果你竞争的现有系统已经损坏且粗陋，或者完全是手动操作且没有自动化，那倒还好。但与一个并未损坏的系统竞争，就是给自己找麻烦。如果可能，一看到这种项目，就赶紧跑路。

## “你在这里...做什么？”

数据科学家可能被雇佣到一个不产生价值的角色中，尽管工作出色且努力工作？是的。个人无法控制的因素可能会抵消即使是最好的工作，因此保持敏锐观察很重要。

1999年由迈克·贾奇执导的喜剧电影 *办公室空间* 成为美国许多公司职员的邪典经典。在电影中，IT员工兼主角彼得·吉本斯在精神上脱离了向8位不同经理汇报的编程工作。当裁员顾问问他一天在做什么时，他诚实地回答说他“大约只有15分钟是真正的实际工作”。我不会为未读者剧透电影的其余部分，但就像任何伟大的喜剧一样，结果可能与你预期的不一样。

为了阐述前一个例子，替换一个并未损坏的系统，正是已故人类学家大卫·格雷伯所描述的 *垃圾工作*（恕我直言）。根据格雷伯的说法，*垃圾工作*是指薪酬工作，其完全毫无意义、不必要或有害，以至于连员工本人都无法证明其存在的合理性，却不得不假装否则。在他的著作和2013年的病毒式文章中，格雷伯理论认为这些工作变得如此普遍，以至于对劳动力和经济造成了心理打击。

尽管格雷伯的研究充斥着自我选择偏见和轶事发现，缺乏经验证据是一个可被批评的论点，但要声称这些 *垃圾工作* 不存在却很困难。为格雷伯辩护的是，这在经验上很难衡量，且很少有员工会在调查中诚实回答，因为担心危及自己的职业生涯。

数据科学职业能免受这些问题的影响吗？谷歌首席决策科学家卡西·科齐尔科夫（Cassie Kozyrkov）分享了一个奇怪的轶事，有助于回答这个问题：

> 几年前，一位在科技公司担任工程总监的朋友抱怨他那群没用的数据科学家。“我认为你雇佣数据科学家的方式就像毒枭为自家后院买老虎一样，”我告诉他。“你不知道自己想要老虎干什么，但所有其他毒枭都有一只。”
> >
> > ——卡西·科齐尔科夫

哎呀。管理层是否可能雇佣数据科学家来提升组织的感知可信度和企业地位？如果你发现自己处于一个不旨在创造价值的工作中，请从战略上思考如何推动积极变革。你能否创造机会，而不是等待他人提供？你能否有意义地对你识别出的项目承担责任，从而发展你的职业生涯？如果这不可能，请赋予自己权力去追求更好的机会。

## 角色并非你所期望的

当你开始一份工作并发现它不是你所期望的那样时，你会怎么做？例如，你被告知你的角色将是统计学和机器学习，但你发现自己反而在做类似IT的工作，因为组织的数据基础根本不足以进行机器学习。

你或许能“将柠檬变成柠檬水”。你当然可以接受你的“数据科学家”角色转变为IT角色，并在过程中获得一些数据库和编程技能。你甚至可能成为不可或缺的“SQL专家”或“技术大师”，并且在职业上感到自在。当你简化企业的数据运营和工作流程时，你正在为企业未来更好地应对更复杂的应用做好准备。当你的运营顺利运行时，你可以分配时间在感兴趣的领域学习并专业成长。

另一方面，如果你期望做统计分析和机器学习，却发现自己在调试损坏的电子表格、Microsoft Access 和 VBA 宏，你可能会感到失望。在这种情况下，至少要成为变革的倡导者。推动工具现代化，倡导使用 Python 和现代数据库平台，如 MySQL 或甚至 SQLite。如果你能做到这一点，那么至少你将处于一个允许更多创新的平台上，并且离应用本书中的概念更近一步。这也将惠及组织，因为工具支持和灵活性将提高，而 Python 人才比 Microsoft Access 和 VBA 等过时技术更容易获得。
