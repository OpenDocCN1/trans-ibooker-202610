# トレーニング・フレームワークの選択

KerasはTensorFlowでモデルを作成する際に推奨されるインタフェースだが、人物検出モデルを作成する際には、まだ必要な機能をすべてサポートしていなかった。そのため、旧インタフェースである`tf.slim`を使ってモデルをトレーニングする方法を紹介する。`tf.slim`はまだ広く使われているが、非推奨であるため、将来のTensorFlowのバージョンはこの方法をサポートしないかもしれない。将来的には、Kerasのインストラクションをオンラインで公開したいと考えている。最新情報は[tinymlbook.com/persondetectorを](https://oreil.ly/sxP6q)チェックしてほしい。

Slimのモデル定義は[TensorFlowのモデルリポジトリに](https://oreil.ly/iamdB)含まれているので、始めるにはGitHubからダウンロードする必要がある：

```
! cd ~
! git clone https://github.com/tensorflow/models.git
```

#### 注

以下のガイドでは、ホームディレクトリから行うことを前提としているため、モデルリポジトリのコードは`~/models`にあり、特に断りのない限り、すべてのコマンドはホームディレクトリから実行される。リポジトリは他の場所に置くこともできるが、リポジトリへの参照をすべて更新する必要がある。

Slimを使うには、Pythonがモジュールを発見し、1つの依存関係をインストールできるようにする必要がある。iPythonノートブックでこれを行う方法を紹介しよう：

```
! pip install contextlib2
import os
new_python_path = (os.environ.get("PYTHONPATH") or '') + ":models/research/slim"
%env PYTHONPATH=$new_python_path
```

このような`EXPORT` 。`PYTHONPATH` を更新するのは、現在のJupyterセッションに対してのみ機能するため、bashを直接使用している場合は、持続的な起動スクリプトに追加して、次のように実行する必要がある：

```
echo 'export PYTHONPATH=$PYTHONPATH:models/research/slim' >> ~/.bashrc
source ~/.bashrc
```

Slim スクリプトの実行でインポートエラーが発生する場合は、`PYTHONPATH` が正しくセットアップされ、`contextlib2` がインストールされていることを確認すること。`tf.slim`に関する一般化情報は[リポジトリのREADMEで](https://oreil.ly/azuvk)発見できる。

# データセットを構築する

人物検出モデルを訓練するには、人物が写っているかどうかによってラベル付けされた画像の大規模なコレクションが必要だ。画像分類器の学習に広く使われているImageNetの1,000クラスデータセットには人物のラベルは含まれていないが、幸運なことに[COCOデータセットには](http://cocodataset.org/#home)含まれている。

このデータセットは、ローカライゼーションのモデルを学習するために設計されているため、画像には「人」「人ではない」といった学習対象のカテゴリーがラベル付けされていない。その代わり、各画像には、その画像に含まれるすべてのオブジェクトのバウンディングボックスのリストが添付されている。「人物」はこれらのオブジェクト・カテゴリの1つなので、欲しい分類ラベルを得るためには、人物のバウンディング・ボックスがある画像を探す必要がある。認識できないほど小さなバウンディングボックスでないことを確認するために、非常に小さなバウンディングボックスを除外する必要もある。Slimには、データをダウンロードし、バウンディングボックスをラベルに変換する便利なスクリプトが含まれている：

```
! python download_and_convert_data.py \
  --dataset_name=visualwakewords \
  --dataset_dir=data/visualwakewords
```

このダウンロードは約40GBと大容量なので、しばらく時間がかかり、解凍とさらなる処理のスペースを確保するために、ドライブに少なくとも100GBの空きがあることを確認する必要がある。プロセスが完了するまでに20分程度かかっても驚かないでほしい。処理が終わると、`data/visualwakewords`にラベル付き画像情報を保持するTFRecordsのセットができる。このデータセットはAakanksha Chowdheryによって作成され、[Visual Wake Wordsデータセットとして](https://oreil.ly/EC6nd)知られている。このデータセットは、組み込みコンピューター構想のベンチマークやテストに役立つように設計されており、厳しいリソース制約の中で達成しなければならない非常に一般的なタスクを表しているからだ。我々は、このデータセットによって、このタスクや同様のタスクに対して、より優れたモデルが開発されることを期待している。

# モデルをトレーニングする

学習処理に`tf.slim`を使用する良い点の1つは、一般的に変更する必要があるパラメータがコマンドライン引数として利用可能であることで、モデルを学習するために標準の`train_image_classifier.py`スクリプトを呼び出すことができる。このコマンドを使用して、例で使用するモデルを構築することができる：

```
! python models/research/slim/train_image_classifier.py \
    --train_dir=vww_96_grayscale \
    --dataset_name=visualwakewords \
    --dataset_split_name=train \
    --dataset_dir=data/visualwakewords \
    --model_name=mobilenet_v1_025 \
    --preprocessing_name=mobilenet_v1 \
    --train_image_size=96 \
    --use_grayscale=True \
    --save_summaries_secs=300 \
    --learning_rate=0.045 \
    --label_smoothing=0.1 \
    --learning_rate_decay_factor=0.98 \
    --num_epochs_per_decay=2.5 \
    --moving_average_decay=0.9999 \
    --batch_size=96 \
    --max_number_of_steps=1000000
```

シングルGPUのV100インスタンスでは、100万ステップをすべて完了するのに2、3日かかるが、早く実験したいのであれば、数時間後にはかなり正確なモデルを得ることができるはずだ。以下は追加の考慮事項である：
