
* `RespondToCommand()`の引数`score`、予想スコアを表示する。LCDディスプレイにスコアを視覚的に表示するインジケータを作成する。
* 秘密のコードフレーズのように、「はい」と「いいえ」の特定のシーケンスにアプリケーションが反応するようにする。
* `yes` と `no` コマンドを使って、追加のLEDやサーボなど、他のコンポーネントを制御する。

# まとめ
これまで説明してきたアプリケーション・コードは、ハードウェアからデータを取り込み、推論に適した特徴を抽出することに主眼を置いている。実際にデータをモデルに送り込み、推論を実行する部分は比較的小さく、第6章で取り上げた例と非常によく似ている。

これは機械学習プロジェクトの典型的な例だ。モデルはすでに学習済みであるため、我々の仕事は適切な種類のデータを与え続けることだけだ。TensorFlow Liteを使っている組み込み開発者であれば、プログラミング時間のほとんどをセンサーデータの取得、特徴量への処理、モデルの出力への対応に費やすことになるだろう。推論自体は素早く簡単だ。

しかし、組み込みアプリケーションはパッケージの一部に過ぎない。[第8章](#ch08.html#chapter_training_micro_speech)では、さまざまな単語を聞き取るために、独自の音声モデルをトレーニングする方法を学ぶ。また、それがどのように機能するかについても詳しく説明する。

# 第8章. ウェイクワードの検出モデルをトレーニングする
この作品はAIを使って翻訳されている。ご意見、ご感想をお待ちしている：[translation-feedback@oreilly.com](mailto:translation-feedback@oreilly.com)

[第7章](#ch07.html#chapter_speech_wake_word_example)では、"はい "と "いいえ "を認識するように訓練されたモデルを中心にアプリケーションを構築した。この章では、異なる単語を認識できる*新しい*モデルを訓練する。

我々のアプリケーション・コードはかなり一般化されている。音声をキャプチャして処理し、それをTensorFlow Liteモデルに送り込み、出力に基づいて何かを行うだけだ。ほとんどの場合、モデルがどの単語を探しているかは気にしない。つまり、新しいモデルをトレーニングすれば、それをアプリケーションにドロップするだけで、すぐに動作するようになる。

新しいモデルをトレーニングする際に考慮しなければならないことは以下の通りだ：

インプット

:
新しいモデルは、アプリケーションコードと同じ前処理を施した、同じ形状と形式の入力データでトレーニングされなければならない。

出力

:
新しいモデルの出力は同じ形式でなければならない：各クラスに1つずつ、確率のテンソルである。

トレーニングデータ

:
どの新しい単語を選ぶにせよ、新しいモデルを訓練するために、人々がその単語を口にする様子をたくさん録音する必要がある。

最適化

:
このモデルは、限られたメモリーしか持たないマイクロコントローラー上で効率的に動作するように最適化されなければならない。

幸いなことに、我々の既存のモデルはTensorFlowチームが公開したスクリプトを使ってトレーニングされており、このスクリプトを使って新しいモデルをトレーニングすることができる。また、トレーニングデータとして使える音声のデータセットも無料で入手できる。

次のセクションでは、このスクリプトを使ってモデルをトレーニングするプロセスを説明する。そして[「プロジェクトでモデルを使う](#ch08.html#micro_speech_using_model_in_project)」では、新しいモデルを既存のアプリケーション・コードに組み込む。その後、[「モデルがどのように機能するか](#ch08.html#micro_speech_how_the_model_works)」で、モデルが実際にどのように機能するかを学ぶ。最後に、「[自分のデータでトレーニングする](#ch08.html#micro_speech_training_with_your_own_data)」では、自分のデータセットを使ってモデルをトレーニングする方法を見る。

### GPUトレーニングを有効にする
[第4章](#ch04.html#chapter_hello_world_training)では、少量のデータで非常に単純なモデルを訓練した。今トレーニングしているモデルはもっと洗練されたもので、データセットももっと大きく、トレーニングにはもっと時間がかかる。平均的な最新のコンピューターのCPUでは、トレーニングに3、4時間かかるだろう。

モデルのトレーニングにかかる時間を短縮するには、*GPUアクセラレーションと*呼ばれるものを使えばいい。*GPUとは*、グラフィック・プロセッシング・ユニットのことだ。コンピュータが画像データを素早く処理できるように設計されたハードウェアの一部で、ユーザインタフェースやビデオゲームのようなものをスムーズにレンダリングできるようにする。ほとんどのコンピューターに搭載されている。

画像処理では多くのタスクを並列実行する。ディープラーニング・ネットワークのトレーニングも同様だ。つまり、GPUハードウェアを使ってディープラーニングのトレーニングを高速化することが可能なのだ。トレーニングをGPUで実行すると、CPUに比べて5倍から10倍速くなるのが一般的だ。

トレーニングの過程でオーディオの前処理が必要なため、このような大幅なスピードアップは見込めないが、それでもGPUを使えばモデルのトレーニングはかなり速くなる。

### トレーニングを設定する
学習スクリプトは、モデルのアーキテクチャから分類するために学習させる単語まで、すべてを制御するコマンドラインフラグの束によって設定される。

スクリプトを実行しやすくするために、ノートブックの最初のセルには、いくつかの重要な値を環境変数に格納している。これらはスクリプトが実行されるときに、スクリプトのコマンドラインフラグに代入される。

最初の`WANTED_WORDS` 、モデルを訓練する単語を選択することができる：

```
os.environ["WANTED_WORDS"] = "yes,no"
```

デフォルトでは "yes "と "no "が選択されているが、データセットにある以下の単語を自由に組み合わせることができる：

* 一般的なコマンド：*はい*、*いいえ*、*上*、*下*、*左*、*右*、*オン*、*オフ*、*ストップ*、*Go*、*後退*、*前進*、*フォロー*、*学習*
* ゼロから9までの数字：*ゼロ*、*1*、*2*、*3*、*4*、*5*、*6*、*7*、*8*、*9*
* 好きな言葉：*ベッド*,*鳥*,*猫*,*犬*,*幸せ*,*家*,*マーヴィン*,*シーラ*,*木*,*ワオ*

単語を選択するには、カンマ区切りのリストに入れればよい。新しいモデルをトレーニングするために、"on "と "off "という単語を選んでみよう：

```
os.environ["WANTED_WORDS"] = "on,off"
```

リストに含まれていない単語は、モデルの学習時に「未知」カテゴリーに分類される。

#### 注
ここで2つ以上の単語を選択することは問題ない。アプリケーションのコードを少し修正すればよいだけだ。この方法については、[「プロジェクトでモデルを使う](#ch08.html#micro_speech_using_model_in_project)」で説明している。

`TRAINING_STEPS` と`LEARNING_RATE` の変数にも注目してほしい：

```
os.environ["TRAINING_STEPS"]="15000,3000"
os.environ["LEARNING_RATE"]="0.001,0.0001"
```

[第3章](#ch03.html#chapter_get_up_to_speed)では、モデルの重みとバイアスが漸進的に調整され、時間の経過とともにモデルの出力が望ましい値に近づいていくことを学んだ。`TRAINING_STEPS` は、学習データのバッチがネットワークを通して実行され、重みとバイアスが更新される回数を指す。`LEARNING_RATE` は、調整率をセットする。

学習率が高ければ、重みとバイアスは反復ごとに調整されるため、収束が早くなる。しかし、このような大きなジャンプは、理想値を飛び越え続ける可能性があるため、理想値に到達するのが難しくなることを意味する。学習率が低いと、ジャンプは小さくなる。収束にはより多くのステップを要するが、最終的な結果はより良くなるかもしれない。与えられたモデルに最適な学習率は、試行錯誤の末に決定される。

前述の変数では、トレーニング・ステップと学習率はカンマ区切りのリストとして定義され、トレーニングの各段階の学習率を定義する。先ほどの値では、モデルは学習率0.001で15,000ステップ、学習率0.0001で3,000ステップ学習する。合計18,000ステップとなる。

つまり、高い学習率で何度も反復を行い、ネットワークが素早く収束するようにする。その後、低い学習率でより少ない回数の反復を行い、重みとバイアスを微調整する。

今のところ、これらの値はそのままにしておくが、これらの値が何のためにあるのかを知っておくのは良いことだ。セルを実行してみよう。以下の出力が表示される：

```
Training these words: on,off
Training steps in each stage: 15000,3000
Learning rate in each stage: 0.001,0.0001
Total number of training steps: 18000
```

これは、モデルがどのようにトレーニングされるかの概要である。

### トレーニングを開始する

!python tensorflow/tensorflow/examples/speech_commands/train.py \
