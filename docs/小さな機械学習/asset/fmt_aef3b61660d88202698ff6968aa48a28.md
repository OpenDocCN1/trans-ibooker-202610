# 奥付

*TinyMLの*表紙を飾る動物は、南米北部に発見されたハチドリの一種、クリムゾントパーズ*（Topaza pella*）である。熱帯や亜熱帯の森林、樹冠の上層や中層に生息する。

オスのクリムゾン・トパーズの身長は平均8.7インチで、メスは5.3インチとかなり小さい。体重はオス・メスともに約10グラムである。ハチドリの中ではオオハチドリに次いで2番目に大きい種と考えられている。オスは虹色の赤にメタリックグリーンの喉と黒い頭がある。メスの羽はほとんどが緑色である。

クリムゾントパーズは他のハチドリと同様、主に花木の蜜を吸う。翼を水平に8の字パターンで回転させることで、アクティブ・ホバリング飛行（正味前進速度ゼロの静止飛行）を行うことができる。これにより、空中で花木の蜜を飲むことができる。これらの植物の多くは筒状の花を咲かせ、ハチやチョウが花粉に到達できないため、受粉をハチドリに頼っている。

このハチドリは、年に2回の繁殖期を除けば、一般的に単独で行動する。メスは、植物の繊維をクモの糸で束ねた小さな巣を作り、子供の成長に合わせて拡張する。メスは通常2個の卵を産む。幼鳥は孵化後約3週間で羽化する。メスは約6週間ヒナの世話をする。

クリムゾントパーズは生息地内ではよく見かけるが、地表近くにはほとんどいないため、あまり見かけることはない。オライリー・カバーに生息する動物の多くは絶滅の危機に瀕しているが、いずれも世界にとって重要な動物である。

表紙のイラストはカレン・モンゴメリーによるもので、*ライデッカーの『Royal Natural History*』に掲載されたモノクロのエングレーヴィングが元になっている。表紙のフォントはGilroy SemiboldとGuardian Sansである。テキストフォントはAdobe Minion Pro、見出しフォントはAdobe Myriad Condensed、コードフォントはDalton MaagのUbuntu Monoである。
