## データを作成する

ディープラーニング・ネットワークは、基礎となるデータのパターンをモデル化するために学習する。先に述べたように、正弦関数によって生成されたデータをモデル化するためにネットワークを訓練する。その結果、ある値`x` を受け取り、その正弦`y` を予測できるモデルができる。

その前にデータが必要だ。現実の世界では、センサーや生産ログからデータを収集するかもしれない。しかしこの例では、簡単なコードを使ってデータセットを生成する。

次のセルは、これが起こる場所だ。我々の計画は、正弦波に沿ったランダムな点を表す1,000個の値を生成することである。[図4-8を見て](#ch04.html#sine_wave_2)、正弦波がどのようなものか思い出してみよう。

波の全周期を*周期と*呼び、グラフから、 -軸上で約6単位ごとに全周期が終了することがわかる。グラフから、`x`-軸上で、およそ6単位ごとに1サイクルが完了することがわかる。実際、正弦波の周期は2×π、つまり2πである。

トレーニングに必要な正弦波データが揃うように、このコードでは`x` 、0から2πまでのランダムな値を生成する。そして、それぞれの値について正弦波を計算する。

![](assets/timl_0401.png)

これはNumPy（`np` 、先にインポートしたもの）を使って乱数を生成し、その正弦を計算している：

```
# We'll generate this many sample datapoints
SAMPLES = 1000

# Set a "seed" value, so we get the same random numbers each time we run this
# notebook. Any number can be used here.
SEED = 1337
np.random.seed(SEED)
tf.random.set_seed(SEED)

# Generate a uniformly distributed set of random numbers in the range from
# 0 to 2π, which covers a complete sine wave oscillation
x_values = np.random.uniform(low=0, high=2*math.pi, size=SAMPLES)

# Shuffle the values to guarantee they're not in order
np.random.shuffle(x_values)

# Calculate the corresponding sine values
y_values = np.sin(x_values)

# Plot our data. The 'b.' argument tells the library to print blue dots.
plt.plot(x_values, y_values, 'b.')
plt.show()
```

先に説明したことに加えて、このコードにはいくつか指摘すべき点がある。まず、`x` の値を生成するのに`np.random.uniform()` を使っていることがわかる。このメソッドは、指定された範囲の乱数の配列を返す。NumPyには、値の配列全体を演算する便利なメソッドがたくさんあり、データを扱うときにとても便利である。

次に、データを生成した後、シャッフルする。ディープラーニングで使われる学習プロセスは、データが本当にランダムな順序で与えられるかどうかに依存しているため、これは重要だ。もしデータが順番通りであれば、結果として得られるモデルの精度は落ちるだろう。

次に、NumPy の`sin()` メソッドを使って正弦値を計算している。NumPyは、`x` のすべての値を一度に計算し、配列を返すことができる。NumPyは素晴らしい！

最後に、Matplotlibのエイリアスである`plt` を呼び出す謎のコードが見えるだろう：

```
# Plot our data. The 'b.' argument tells the library to print blue dots.
plt.plot(x_values, y_values, 'b.')
plt.show()
```

このコードは何をするのか？データのグラフをプロットしているのだ。Jupyterノートブックの優れた点のひとつは、実行したコードから出力されたグラフを表示できることだ。Matplotlibは、データからグラフを作成するための優れたツールだ。データを視覚化することはマシン学習のワークフローの重要な部分なので、これはモデルを訓練する際に非常に役立つだろう。

データを生成してグラフとして表示するには、セル内のコードを実行する。コード・セルの実行が終わると、[図 4-9](#ch04.html#smooth_data_graph) のような美しいグラフがその下に表示されるはずである。

![](assets/timl_0409.png)

これが我々のデータだ！きれいで滑らかなサインカーブに沿ったランダムな点の選択である。これを使ってモデルを訓練することができる。しかし、これでは簡単すぎる。ディープ・ラーニング・ネットワークのエキサイティングな点のひとつは、ノイズからパターンを選別する能力だ。これによって、雑然とした実世界のデータで訓練しても予測を行うことができる。これを示すために、データポイントにランダムなノイズを加え、別のグラフを描いてみよう：

```
# Add a small random number to each y value
y_values += 0.1 * np.random.randn(*y_values.shape)

# Plot our data
plt.plot(x_values, y_values, 'b.')
plt.show()
```

[図4-10に](#ch04.html#noisy_data_graph)示すように、このセルを実行して結果を見てみよう。

ずっと良くなった！点はランダム化され、滑らかで完全な曲線ではなく、正弦波を中心とした分布を表すようになった。これは、一般的にデータが非常に乱雑である実世界の状況をより反映している。

## データを分割する

前章で、データセットがしばしば*トレーニング*、*検証*、*テストの*3つの部分に分割されることを思い出したかもしれない。訓練したモデルの精度を評価するためには、その予測値を実際のデータと比較し、どれだけ一致するかをチェックする必要がある。

この評価は、トレーニング中（バリデーションと呼ばれる）とトレーニング後（テストと呼ばれる）に行われる。それぞれのケースで重要なのは、モデルのトレーニングにまだ使われていない新鮮なデータを使うことだ。

評価に使用するデータを確保するため、トレーニングを始める前にいくつかセットしておこう。データの20％を検証用に、さらに20％をテスト用に確保しよう。残りの60％はモデルのトレーニングに使う。これはモデルをトレーニングする際の典型的な分割方法である。

以下のコードでは、データを分割し、それぞれのセットを異なる色でプロットしている：

```
# We'll use 60% of our data for training and 20% for testing. The remaining 20%
# will be used for validation. Calculate the indices of each section.
TRAIN_SPLIT =  int(0.6 * SAMPLES)
TEST_SPLIT = int(0.2 * SAMPLES + TRAIN_SPLIT)

# Use np.split to chop our data into three parts.
# The second argument to np.split is an array of indices where the data will be
# split. We provide two indices, so the data will be divided into three chunks.
x_train, x_validate, x_test = np.split(x_values, [TRAIN_SPLIT, TEST_SPLIT])
y_train, y_validate, y_test = np.split(y_values, [TRAIN_SPLIT, TEST_SPLIT])

# Double check that our splits add up correctly
assert (x_train.size + x_validate.size + x_test.size) ==  SAMPLES

# Plot the data in each partition in different colors:
plt.plot(x_train, y_train, 'b.', label="Train")
plt.plot(x_validate, y_validate, 'y.', label="Validate")
plt.plot(x_test, y_test, 'r.', label="Test")
plt.legend()
plt.show()
```

データを分割するために、もうひとつの便利なNumPyメソッドを使う：`split()` 。このメソッドは、データの配列とインデックスの配列を受け取り、指定されたインデックスでデータを分割する。

このセルを実行して、分割の結果を見る。[図4-11に](#ch04.html#split_data_graph)示すように、データの種類ごとに異なる色（本書の印刷版を読み取り中の場合は日陰）で表示される。

## 基本モデルの定義

さて、データが手に入ったので、次はそれに合うように訓練するモデルを作成しよう。

入力値（この場合は`x` ）を受け取り、それを使って数値出力値（`x` の正弦）を予測するモデルを構築する。この種の問題は、 *回帰と*呼ばれている。回帰モデルは、数値出力を必要とするあらゆる種類のタスクに使うことができる。例えば、回帰モデルは加速度計からのデータに基づいて、人の走る速度を時速マイルで予測しようとすることができる。

モデルを作成するために、シンプルなニューラルネットワークを設計する。これはニューロンの層を使って、学習データの根底にあるあらゆるパターンを学習し、予測を行えるようにするものだ。

これを実行するコードは、実際には非常に簡単だ。ディープラーニング・ネットワークを作成するためのTensorFlowの高レベルAPIである[*Kerasを*](https://oreil.ly/IpFqC)使用している：

```
# We'll use Keras to create a simple model architecture
from tf.keras import layers
model_1 = tf.keras.Sequential()

# First layer takes a scalar input and feeds it through 16 "neurons." The
# neurons decide whether to activate based on the 'relu' activation function.
model_1.add(layers.Dense(16, activation='relu', input_shape=(1,)))

# Final layer is a single neuron, since we want to output a single value
model_1.add(layers.Dense(1))

# Compile the model using a standard optimizer and loss function for regression
model_1.compile(optimizer='rmsprop', loss='mse', metrics=['mae'])

# Print a summary of the model's architecture
model_1.summary()
```

`Sequential` これは、[図3-](#ch03.html#network_layers)1で見たように、ニューロンの各層が次の層の上に積み重なっているモデルを意味する。次に、2つのレイヤーを定義する。ここで最初のレイヤーを定義する：

```
model_1.add(layers.Dense(16, activation='relu', input_shape=(1,)))
```

最初のレイヤーの入力は1つ（`x` ）、ニューロンは16個である。これは`Dense` （*完全連結*レイヤーとも呼ばれる）レイヤーで、推論中、つまり予測をするときに、入力がニューロンのひとつひとつに入力されることを意味する。そして、各ニューロンが一定程度*活性化される*。各ニューロンの活性化量は、トレーニング中に学習された*重みと* *バイアス*値、および*活性化関数に基づいて*いる。ニューロンの活性化は数値として出力される。

活性化は、Pythonで示された単純な式によって計算される。これはKerasとTensorFlowで処理されるため、自分たちでコーディングする必要はないが、ディープラーニングをさらに深めていく上で知っておくと役に立つだろう：

```
activation = activation_function((input * weight) + bias)
```

ニューロンの活性化を計算するには、入力に重みを乗じ、その結果にバイアスを加える。計算された値は活性化関数に渡される。結果として得られる数値が、ニューロンの活性化である。

活性化関数は、ニューロンの出力を形成するために使用される数学関数である。我々のネットワークでは、*rectified linear unit*、略して*ReLUと*呼ばれる活性化関数を使用している。これはKerasの引数`activation=relu` で指定される。

ReLUはシンプルな関数で、ここではPythonで示されている：

```
def relu(input):
    return max(0.0, input)
```

ReLUは、入力値とゼロのうち、大きい方の値を返す。入力値が負の場合、ReLUはゼロを返す。入力値がゼロ以上の場合、ReLUはそのままの値を返す。

[図4-12は](#ch04.html#relu)、ある範囲の入力値に対するReLUの出力を示している。

![](assets/timl_0412.png)

活性化関数がなければ、ニューロンの出力は常に入力の一次関数となる。これは、`x` と`y` の比が値の全範囲にわたって同じであるような線形関係しか、ネットワークがモデル化できないことを意味する。正弦波は非線形なので、これではネットワークは正弦波をモデル化できない。

ReLUは非線形であるため、複数のニューロン層が力を合わせ、複雑な非線 形関係をモデル化することができる。この場合、`y` の値は、`x` のインクリメントごとに同じ量だけ増加するわけではない。

###### 注

他にも活性化関数はあるが、ReLUが最も一般的に使われている。[Wikipediaの活性化関数の記事で](https://oreil.ly/Yxe-N)他の選択肢を見ることができる。それぞれの活性化関数には異なるトレードオフがあり、機械学習エンジニアは、与えられたアーキテクチャに最適なオプションを見つけるために実験を行う。

最初のレイヤーの活性化数は、次の行で定義される2番目のレイヤーの入力として与えられる：

```
model_1.add(layers.Dense(1))
```
