### Arduinoのコマンドに応答する

すべてのArduinoボードにはLEDが内蔵されており、`LED_BUILTIN` という便利な定数があるので、それを使ってピン番号を取得することができる。ピン番号はボードによって異なる。このコードをポータブルに保つため、出力に使うLEDは1つに絞ることにする。

これからやることはこうだ。推論が実行されていることを示すために、推論のたびにLEDを点滅させる。ただし、「イエス」という言葉が聞こえたら、LEDを数秒間点灯させる。

ノー」という言葉はどうだろう？まあ、これは単なるデモンストレーションなので、あまり気にしないことにしよう。しかし、検出されたコマンドはすべてシリアルポートに記録されるので、デバイスに接続してすべての一致を確認することができる。

Arduino用の代替コマンド・レスポンダは[`arduino/command_responder.cc`に](https://oreil.ly/URkYi)ある。そのソースを見ていこう。まず、コマンドレスポンダのヘッダファイルとArduinoプラットフォームのライブラリのヘッダファイルをインクルードする：

```
#include "tensorflow/lite/micro/examples/micro_speech/command_responder.h"
#include "Arduino.h"
```

次に、関数の実装を始める：

```
// Toggles the LED every inference, and keeps it on for 3 seconds if a "yes"
// was heard
void RespondToCommand(tflite::ErrorReporter* error_reporter,
                      int32_t current_time, const char* found_command,
                      uint8_t score, bool is_new_command) {
```

次のステップは、内蔵LEDのピンを出力モードにして、オンとオフを切り替えられるようにすることだ。これは、`is_initialized` と呼ばれる`static bool` のおかげで、一度だけ実行される`if` 文の中で行う。`static` 、変数は関数呼び出しの間、その状態を保持する：

```
static bool is_initialized = false;
if (!is_initialized) {
  pinMode(LED_BUILTIN, OUTPUT);
  is_initialized = true;
}
```

次に、最後に "YES "が検出されたときと、実行された推論の回数を記録するために、`static` 変数をもういくつかセットアップする：

```
static int32_t last_yes_time = 0;
static int count = 0;
```

ここからが面白いところだ。引数`is_new_command` が`true` の場合、何かを聞いたことがわかるので、`ErrorReporter` インスタンスでログに記録する。しかし、もし聞こえたのが「はい」であれば、`found_command` の文字配列の最初の文字をチェックすることで判断し、現在時刻を保存してLEDを点灯させる：

```
if (is_new_command) {
  error_reporter->Report("Heard %s (%d) @%dms", found_command, score,
                         current_time);
  // If we heard a "yes", switch on an LED and store the time.
  if (found_command[0] == 'y') {
    last_yes_time = current_time;
    digitalWrite(LED_BUILTIN, HIGH);
  }
}
```

次に、正確には3秒後にLEDを消す振る舞いを実装する：

```
// If last_yes_time is non-zero but was >3 seconds ago, zero it
// and switch off the LED.
if (last_yes_time != 0) {
  if (last_yes_time < (current_time - 3000)) {
    last_yes_time = 0;
    digitalWrite(LED_BUILTIN, LOW);
  }
  // If it is non-zero but <3 seconds ago, do nothing.
  return;
}
```

LEDが消灯したとき、`last_yet_time` を`0` にセットし、次に "yes "が聞こえるまでこの`if` ステートメントを入力しないようにする。`return` 。このインポート文は重要である。「はい」と聞こえたら、それ以降の出力コードが実行されないようにするもので、LEDはしっかり点灯したままである。

これまでの実装では、"yes "の声が聞こえると約3秒間LEDが点灯する。次のパートでは、推論のたびにLEDの点灯と消灯を切り替える。ただし、「イエス」モードの間は、前述の`return` 。

これが最後のコードの塊だ：

```
// Otherwise, toggle the LED every time an inference is performed.
++count;
if (count & 1) {
  digitalWrite(LED_BUILTIN, HIGH);
} else {
  digitalWrite(LED_BUILTIN, LOW);
}
```

推論ごとに`count` 変数をインクリメントすることで、実行した推論の合計数を記録する。`if` 条件付き内部では、`&` 演算子を使って、`count` 変数と数値`1` とのバイナリ AND 演算を行う。

`count` 、`1` とのANDを実行することで、最小ビットを除く`count`のすべてのビットをフィルタリングする。最小ビットが`0` 、つまり`count` が奇数の場合、結果は`0` となる。 C++の`if statement` 、これは`false` と評価される。

そうでない場合、結果は`1` となり、偶数を示す。`1` は`true` と評価されるので、LEDは偶数で点灯し、奇数で消灯する。これがトグルする理由である。

これで完成だ！これでArduino用のコマンド・レスポンダが実装できた。実際に動かしてみよう。

### SparkFun Edgeでコマンドに応答する

プログラミングが実行中であることを明確にするために、推論ごとに青いLEDの点灯と消灯を切り替えてみよう。イエス」と聞こえたら黄色のLEDを、「ノー」と聞こえたら赤のLEDを、未知のコマンドが聞こえたら緑のLEDを点灯させよう。

SparkFun Edgeのコマンドレスポンダは[`sparkfun_edge/command_responder.cc`に](https://oreil.ly/i-3eJ)実装されている。このファイルはいくつかのインクルードで始まる：

```
#include "tensorflow/lite/micro/examples/micro_speech/command_responder.h"
#include "am_bsp.h"
```
