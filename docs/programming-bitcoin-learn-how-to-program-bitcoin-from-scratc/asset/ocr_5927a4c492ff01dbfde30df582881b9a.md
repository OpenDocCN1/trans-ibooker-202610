An elliptic curve isn’t all that different:

y² = x³ + a x + b

The only real difference between the elliptic curve and the cubic curve in Figure 2-3 is the y² term on the left side. This has the effect of making the graph symmetric over the x-axis, as shown in Figure 2-4.
