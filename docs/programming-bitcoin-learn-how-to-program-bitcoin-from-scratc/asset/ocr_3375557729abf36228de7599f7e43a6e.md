x³ − (x₁ + x₂ + x₃)x² + (x₁x₂ + x₁x₃ + x₂x₃)x − x₁x₂x₃ = 0

From earlier, we know that:

x³ − s²x² + (a + 2s²x₁ − 2sy−1~)x + b − s²x₁² + 2sx−1~y₁ − y₁² = 0

There’s a result from what’s called Vieta’s formula, which states that the coefficients have to equal each other if the roots are the same. The first coefficient that’s interesting is the coefficient in front of x².

−s² = −(x₁ + x₂ + x₃)

We can use this to derive the formula for x₃:

x₃ = s² − x₁ − x₂

We can plug this into the formula for the line above:

y = s(x − x₁) + y₁

But we have to reflect over the x-axis, so the right side has to be negated:

y₃ = −(s(x₃ − x₁) + y₁) = s(x₁ − x₃) − y₁

QED.
