## 椭圆曲线

在本章中，我们将学习椭圆曲线。在第 3 章中，我们将椭圆曲线与有限域结合起来，构造椭圆曲线密码学。

与有限域一样，如果你以前没见过椭圆曲线，它们可能看起来很吓人。但同样，实际的数学并不难。关于椭圆曲线，你需要知道的大部分内容在代数课程之后就可以教授。在本章中，我们将探讨这些曲线是什么，以及我们可以用它们做什么。

### 定义

椭圆曲线就像你在学前代数中见过的许多方程一样。它们以某种形式在一边是 y，另一边是 x。椭圆曲线具有这样的形式：

```
y² = x³ + a x + b
```

你曾用过其他类似的方程。例如，你可能在学前代数中学过线性方程：

```
y = m x + b
```

你甚至可能记得这里的 m 叫做斜率，b 是 y 截距。你也可以画出线性方程的图形，如图 2-1 所示。

### 用 Python 编写椭圆曲线代码

由于稍后会明确的各种原因，我们感兴趣的不是曲线本身，而是曲线上的特定点。例如，在曲线 y² = x³ + 5x + 7 上，我们感兴趣的是坐标 (-1,1)。因此，我们将定义 Point 类为特定曲线上的一个点。曲线形式为 y² = x³ + ax + b，因此我们可以仅用两个数字 a 和 b 来定义曲线：

```
class Point:

    def __init__(self, x, y, a, b):
        self.a = a
        self.b = b
        self.x = x
        self.y = y
        if self.y**2 != self.x**3 + a * x + b: ①
            raise ValueError('({}, {}) is not on the curve'.format(x, y))

    def __eq__(self, other): ②
        return self.x == other.x and self.y == other.y \
            and self.a == other.a and self.b == other.b
```

① 我们在这里检查该点是否真的在曲线上。

② 当且仅当它们在相同的曲线上且具有相同的坐标时，点才相等。

我们现在可以创建 Point 对象，如果该点不在曲线上，我们会收到错误：

```
>>> from ecc import Point
>>> p1 = Point(-1, -1, 5, 7)
>>> p2 = Point(-1, -2, 5, 7)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "ecc.py", line 143, in __init__
    raise ValueError('({}, {}) is not on the curve'.format(self.x, self.y))
ValueError: (-1, -2) is not on the curve
```

换句话说，当点不在曲线上时，`__init__` 会引发异常。

### 点加法

椭圆曲线之所以有用，是因为一种叫做点加法的运算。点加法是指我们可以对曲线上的两个点进行某种运算，得到第三个点，该点也在曲线上。之所以称为加法，是因为该运算与数学上的加法运算有许多共同的直觉。例如，点加法是可交换的。也就是说，将点 A 加到点 B 上等价于将点 B 加到点 A 上。

- 通过 $P_1$ 和 $P_2$ 画一条直线，找到它第三次与椭圆曲线相交的点。
- 将所得点关于 x 轴反射。

我们将要使用的一个性质是点加法不容易预测。我们可以用公式很容易地计算点加法，但直观上，给定曲线上的两点，相加的结果几乎可能出现在任何地方。回到图 2-14，A + B 在两点右侧，A + C 会在 x 轴上 A 和 C 之间，而 B + C 会在两点左侧。用数学术语来说，点加法是非线性的。

## 点加法的数学

点加法满足我们与加法相关联的某些性质，例如：

- 单位元
- 交换律
- 结合律
- 可逆性

这里的 *单位元* 意味着存在零。即存在某个点 *I*，将其与点 *A* 相加结果为 *A*：

I + A = A

我们将称此点为 *无穷远点*（原因稍后会变得清晰）。

这与 *可逆性* 相关。对于某个点 *A*，存在另一个点 *−A*，其结果为单位元点。即：

A + (−A) = I

视觉上，这些点在曲线上关于 x 轴彼此相对（见图 2-15）。

![](img/6c915536bcfd43e412f7adef942edf23_56_0.png)

图 2-15. 垂直线相交

这就是我们称之为无穷远点的原因。椭圆曲线中多出一个点，使得垂直线与曲线第三次相交。

![](img/6c915536bcfd43e412f7adef942edf23_58_0.png)

图 2-17. A + (B + C)

为了编码点加法，我们将其分为三个步骤：

- 1. 点位于垂直线上或使用单位元点的情况
- 2. 点不在垂直线上，但点不同
- 3. 两个点相同

### 编码点加法

我们首先处理单位元点，或无穷远点。由于我们不能在 Python 中轻松使用无穷大，我们改用 None 值。我们希望它能这样工作：

```
>>> from ecc import Point
>>> p1 = Point(-1, -1, 5, 7)
>>> p2 = Point(-1, 1, 5, 7)
>>> inf = Point(None, None, 5, 7)
>>> print(p1 + inf)
Point(-1, -1)_5_7
```

### x₁≠x₂ 时的点加法

现在我们已经处理了垂直线，让我们考察点不同时的情况。当我们有 x 不同的点时，我们可以用一个相当简单的公式相加。为了帮助直觉，我们先找出两点形成的斜率。我们可以用来自初等代数的公式算出：

P₁ = (x₁,y₁), P₂ = (x₂,y₂), P₃ = (x₃,y₃)
P₁ + P₂ = P₃
s = (y₂ − y₁)/(x₂ − x₁)

这是斜率，我们可以用斜率计算 x₃。一旦知道 x₃，我们就可以计算 y₃。P₃ 可以用此公式推导：

x₃ = s² − x₁ − x₂
y₃ = s(x₁ − x₃) − y₁

记住 y₃ 是关于 x 轴的反射。

### 推导点加法公式

假设：

P₁ = (x₁,y₁), P₂ = (x₂,y₂), P₃ = (x₃,y₃)
P₁ + P₂ = P₃

我们想知道 P₃ 是什么。

让我们从直线经过 P₁ 和 P₂ 并且有此公式开始：

s = (y₂ − y₁)/(x₂ − x₁)
y = s(x − x₁) + y₁

第二个公式是与 P₁ 和 P₂ 都相交的直线的方程。利用此公式并代入椭圆曲线方程，我们得到：

y² = x³ + ax + b
y² = (s(x − x₁) + y₁)² = x³ + ax + b

整理所有项，我们得到这个多项式方程：

x³ − s²x² + (a + 2s²x₁ − 2sy₁)x + b − s²x₁² + 2sx₁y₁ − y₁² = 0

我们还知道 x₁、x₂ 和 x₃ 是这个方程的解，因此：

(x − x₁)(x − x₂)(x − x₃) = 0

x³ − (x₁ + x₂ + x₃)x² + (x₁x₂ + x₁x₃ + x₂x₃)x − x₁x₂x₃ = 0

从前面我们知道：

x³ − s²x² + (a + 2s²x₁ − 2sy₁)x + b − s²x₁² + 2sx₁y₁ − y₁² = 0

有一个来自所谓的 Vieta 公式的结果，指出如果根相同，则系数必须相等。第一个有趣的系数是 x² 前面的系数。

−s² = −(x₁ + x₂ + x₃)

我们可以用它推导出 x₃ 的公式：

x₃ = s² − x₁ − x₂

我们可以将其代入上面的直线公式：

y = s(x − x₁) + y₁

但我们必须关于 x 轴反射，所以右边必须取负：

y₃ = −(s(x₃ − x₁) + y₁) = s(x₁ − x₃) − y₁

证毕。

### 编码另一个例外

还有一个例外，这涉及切线垂直的情况（图 2-19）。

![](img/6c915536bcfd43e412f7adef942edf23_64_0.png)

图 2-19. 垂直且与曲线相切

这只能发生在 P₁ = P₂ 且 y 坐标为 0 时，在这种情况下斜率计算的分母会为 0。

我们用特殊情况处理它：

```
class Point:
    ...
    def __add__(self, other):
        ...
        if self == other and self.y == 0:
            return self.__class__(None, None, self.a, self.b)
```

① 如果两个点相等且 y 坐标为 0，我们返回无穷远点。
