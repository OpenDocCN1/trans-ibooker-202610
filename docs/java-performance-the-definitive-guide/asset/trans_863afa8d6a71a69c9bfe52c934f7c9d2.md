# Java 性能

编程与测试通常被视为不同的专业领域。在这本实用书籍中，Java专家Scott Oaks认为，任何使用Java工作的人都应当精通理解代码在Java虚拟机中的行为——包括可能有助于提升性能的调优。本更新后的第二版将帮助你利用JVM和Java平台深入了解Java应用程序性能的知识。

开发人员与性能工程师都将学习到多种特性、工具和流程，以改进Java 8和11 LTS版本的性能表现。虽然重点在于生产支持的版本和特性，本书也介绍了令人兴奋的新技术预览，如提前编译和实验性垃圾回收。

- 了解各种Java平台和编译器如何影响性能
- 学习Java垃圾回收的工作原理
- 应用四条原则从性能测试中获得最佳结果
- 使用JDK及其他工具了解Java应用程序的运行性能
- 通过调优和编程实践最小化垃圾回收器的影响
- 解决Java API中的性能问题
- 提升Java驱动的数据库应用程序性能

> “这是关于JVM性能与调优最彻底、最实用的资源。每个在JVM中工作并曾遇到令人困惑的异常系统行为、内存泄漏或垃圾回收问题的工程师都应阅读本书。”
> —Rod Hilton

Scott Oaks是Oracle公司的资深架构师，负责Oracle云软件的性能工作。在加入Oracle之前，他在Sun Microsystems工作多年，专精于从SunOS内核到网络编程和RPC、再到窗口系统和OPEN LOOK虚拟窗口管理器等多种不同技术。1996年，Scott成为Sun的Java布道者，并于2001年加入Java性能团队——此后一直专注于该领域。Scott还撰写了O'Reilly的《Java Security》《Java Threads》《JXTA in a Nutshell》和《Jini in a Nutshell》。
