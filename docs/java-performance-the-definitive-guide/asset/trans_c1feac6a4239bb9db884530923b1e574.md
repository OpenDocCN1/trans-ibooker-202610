## 关于作者

**Scott Oaks** 是 Oracle Corporation 的架构师，在那里他负责 Oracle 云和平台软件的性能。在加入 Oracle 之前，他在 Sun Microsystems 工作多年，专攻多种不同的技术，从 SunOS 内核，到网络编程和 RPC，到 Windows 系统和 OPEN LOOK 虚拟窗口管理器。1996 年，Scott 成为 Sun 的 Java 传教士，并在 2001 年加入其 Java 性能组——这一直是他此后的主要关注点。Scott 还撰写了 O’Reilly 的 *Java Security, Java Threads, JXTA in a Nutshell,* 和 *Jini in a Nutshell* 等书。

## 责任说明

《Java Performance》封面上的动物是西伯利亚盘羊 *Saiga tatarica*。它们最显著的特征是硕大而柔韧的鼻子，可作为空气过滤器。夏季，鼻子有助于过滤被群体扬起的尘土，同时还能冷却血液。冬季，鼻子会在空气进入肺部前加热冰冷的空气。

盘羊的毛皮也会随季节变化：冬季它们有厚实、淡色的毛发，颈部还有鬃毛，而夏季毛色变为肉桂色且明显变薄。这些动物肩高约 2–3 英尺，重 80–140 磅。盘羊有细长的腿，最高时速可达 80 英里。雄性盘羊有角，角粗壮、有环且略显半透明。

盘羊生活在大型群体中，迁徙时成千上万聚集。发情期始于 11 月下旬，群体南迁后开始。此时雄性吃得很少并激烈地互相争斗，导致许多因疲惫而死亡。获胜者会带领 5–50 只雌性的群体，雌性将在春季分娩。约三分之二的盘羊出生为双胞胎，其余为单只幼崽。

盘羊种群仅分布于俄罗斯和哈萨克斯坦，在蒙古有少量孤立亚种。它们从史前时期到 19 世纪后半叶的分布范围很广，当时盘羊角价格高昂需求旺盛导致过度捕猎。有一段时间，一些保护组织甚至鼓励猎杀盘羊，以替代猎杀濒危的犀牛。

盘羊现在极度濒危。O’Reilly 封面上的许多动物都濒临灭绝；它们对世界都很重要。
