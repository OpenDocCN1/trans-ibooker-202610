## 关于作者

**Scott Oaks** 是 Oracle Corporation 的架构师，在那里他负责 Oracle 云和平台软件的性能。在加入 Oracle 之前，他在 Sun Microsystems 工作多年，专攻多种不同的技术，从 SunOS 内核，到网络编程和 RPC，到 Windows 系统和 OPEN LOOK 虚拟窗口管理器。1996 年，Scott 成为 Sun 的 Java 传教士，并在 2001 年加入其 Java 性能组——这一直是他此后的主要关注点。Scott 还撰写了 O’Reilly 的 *Java Security, Java Threads, JXTA in a Nutshell,* 和 *Jini in a Nutshell* 等书。
