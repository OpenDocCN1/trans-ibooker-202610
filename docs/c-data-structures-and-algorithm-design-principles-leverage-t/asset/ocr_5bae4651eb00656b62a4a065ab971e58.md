7. As we can see, the time taken by the tabulated solution is longer than both the memoization and backtracking solutions. However, using the DP table returned by SubsetSum_Tabulation(), we can use the following code to find every possible subset sum:

```
int total = 0;

for(auto num : set)
{
    total += num;
}

vector<vector<bool>> DP = SubsetSum_Tabulation(set);

vector<int> subsetSums;

for(int sum = 1; sum <= total; sum++)
{
    if(DP[set.size()][sum])
    {
        subsetSums.push_back(sum);
    }
}
cout << "The set contains the following " << subsetSums.size() << " subset sums: ";

for(auto sum : subsetSums)
{
    cout << sum << " ";
}
cout << endl;
```

8. The output of this should begin and end like this:

```
The set contains the following 6760 subset sums: 3 7 9 10 12 13 16 19 20 22 ..... 6790 6791 6793 6797 6800
```

Thus, we have optimized the solution and also obtained the sum values of all the states.
