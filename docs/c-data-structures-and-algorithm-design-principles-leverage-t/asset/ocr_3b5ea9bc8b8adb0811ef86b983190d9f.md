+   4. The search continues by visiting an arbitrary unvisited neighbor vertex at each iteration. After R1 is visited, the search tries to look for the next unvisited vertex. Since there are none left, the search terminates:

While implementing the BFS, we used a queue to keep track of unvisited vertices. Since a queue is a **First-In, First-Out (FIFO)** data structure where vertices are removed from the queue in the same order as they are added to the queue, it was used by the BFS algorithm to ensure that vertices closer to the starting vertex are visited before the vertices farther away. Implementing DFS is remarkably similar to implementing BFS, except for one difference: instead of using a queue as a container for the list of vertices to be visited, we can now use a stack, while the rest of the algorithm remains the same. This approach works because on each iteration, DFS visits an unvisited neighbor of the current vertex, which can easily be tracked using a stack, which is a **Last-In, First-Out (LIFO)** data structure.
