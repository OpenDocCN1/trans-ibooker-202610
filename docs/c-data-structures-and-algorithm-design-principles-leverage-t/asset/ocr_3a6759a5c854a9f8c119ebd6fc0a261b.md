For the sake of simplicity, let's assume that our graph can be represented by an integer, V, the total number of vertices in the graph, and a vector, edges (a collection of pointers to 'edge' objects that define the graph's adjacencies). Let's also define an integer constant, UNKNOWN, which we can set to some arbitrary high value that will always be greater than the sum of any subset of edge weights in the graph (the INT_MAX constant defined in climits works well for this purpose):

```
const int UNKNOWN = INT_MAX;
```
