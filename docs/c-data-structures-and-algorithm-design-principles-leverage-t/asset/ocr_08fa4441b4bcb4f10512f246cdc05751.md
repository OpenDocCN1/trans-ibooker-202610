```
// to the lesser value.

if(distance[u] + w < distance[v])
{
    distance[v] = distance[u] + w;
}
}
}
```

7. At the end of our function, we can now iterate through the distance array and output the shortest distances from the source to every other node in the graph:

```
cout << "DISTANCE FROM VERTEX " << start << ":\n"

for(int i = 0; i < V; i++)
{
    cout << "\t" << i << ": ";

    if(distance[i] == UNKNOWN)
    {
        cout << "Unvisited" << endl;

        continue;
    }

    cout << distance[i] << endl;
}
```
