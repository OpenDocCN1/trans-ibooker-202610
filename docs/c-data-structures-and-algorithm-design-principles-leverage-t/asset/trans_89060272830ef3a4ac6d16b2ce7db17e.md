问题描述说明如下：

- 当且仅当两座房屋之间存在直接的水平、垂直或对角线路径时，才可以在它们之间修建道路。
- 道路不得穿越水体、山脉、森林等。
- 两座房屋之间修建道路的成本等于它们之间路径上的崎岖度值之和。

要测试第一个条件，我们只需比较两点的坐标，并判断以下三个条件中是否有任何一个成立：

- `A.x = B.x`（它们之间有一条水平线）
- `A.y = B.y`（它们之间有一条垂直线）
- `| A.x - B.x | = | A.y - B.y |`（它们之间有一条对角线）
