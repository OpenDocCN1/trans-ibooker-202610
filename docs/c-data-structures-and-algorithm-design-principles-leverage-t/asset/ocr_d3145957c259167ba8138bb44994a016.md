Reduce is an operation that aggregates values in a container, C, by applying a given function, f(acc, x), to each element, x, of C, and returning a single value. This is shown in the following diagram:

![](bbox=[0.13, 0.22, 0.85, 0.42])

Figure 4.22: Reducing the values of a container

The C++ Standard Library contains map and reduce operations, that is, std::transform() and std::accumulate(), respectively (std::reduce() is also available in C++17).

Note

> std::accumulate() is a restricted form of the reduce operation that uses only the addition function. The newer compilers also provide std::reduce(), which is more general and can be parallelized.
