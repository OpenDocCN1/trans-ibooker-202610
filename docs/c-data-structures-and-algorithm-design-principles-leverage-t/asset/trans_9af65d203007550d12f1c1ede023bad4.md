## 前言

### 关于

本节简要介绍作者、本书涵盖的内容、您需要具备的技术技能，以及完成所有包含的活动和练习所需的硬件和软件要求。

## 关于本书

C++ 是一种成熟的多范式编程语言，使您能够编写高级代码，并对硬件具有高度的控制力。如今，软件基础设施的很大一部分，包括数据库、浏览器、多媒体框架和 GUI 工具包，都是用 C++ 编写的。

本书首先介绍 C++ 数据结构以及如何使用链表、数组、栈和队列存储数据。在后续章节中，本书解释了基本的算法设计范式，例如贪心方法和分治方法，这些方法用于解决大量计算问题。最后，您将学习动态规划的高级技术，以优化实现本书中讨论的几种算法。

通过阅读本书，您将学会如何用高效且可扩展的 C++14 代码实现标准数据结构和算法。

## 学习目标

通过阅读本书，您将能够：

- 使用哈希表、字典和集合构建应用程序
- 使用布隆过滤器实现 URL 缩短服务
- 对字符串数据类型应用常见算法，如堆排序和归并排序
- 使用 C++ 模板元编程编写代码库
- 探索现代硬件如何影响程序的实际运行时性能
- 使用适当的现代 C++ 惯用法，例如 `std::array`，而不是 C 风格数组

## 目标读者

本书面向希望重新学习基本数据结构和算法设计技术的开发人员或学生。虽然不要求数学背景，但了解一些复杂度类别和大 O 记号的基础知识，以及算法课程的学习经历，将帮助您充分利用本书。假定您熟悉 C++14 标准。

## 方法

本书采用实践性和动手操作的方法来解释各种概念。通过练习，本书展示了理论上表现相似的不同数据结构在现代计算机上实际上表现迥异。本书不深入进行理论分析，而是专注于基准测试和实际结果。
