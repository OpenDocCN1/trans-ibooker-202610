# FileZilla

FileZilla is a free and open-source file transfer protocol application consisting of FileZilla Client and FileZilla Server (Figure 2-23). It allows us to deploy our files to the remote server used for hosting our test servers instead of copying them through the remote desktop protocol.

Download: [https://filezilla-project.org/download.php](https://filezilla-project.org/download.php)

+   - Mac

# What Does It Do?

FileZilla is a file transfer protocol (FTP) application that lets you quickly and easily transfer files between an FTP client (FileZilla Client) and an FTP server (FileZilla Server).
