You can create each file in your chart directory manually, or you can use Helm to create a blueprint for you as follows:

```
$ helm create examplechart
Creating examplechart
```

Then you can edit the files in the chart directory and package them into a chart archive:

```
$ helm package examplechart
Archived examplechart.1.-.tgz
```

Once you have packaged your chart, you can use it with helm install to create a release.

In this chapter, you learned how to create a Kubernetes cluster, both manually from scratch with Azure and by using Azure AKS as a managed service. We also explored Helm, which serves as a Kubernetes package manager that helps you create and manage your applications with a single template.

Given the underlying complexity of managing a Kubernetes cluster, it is evident that an approach such as AKS is a rather better way of managing services running on Kubernetes clusters.
