# Creating an Azure Account

You can create an Azure account by navigating to https://azure.microsoft.com and using the free plan. You will need to sign in with a Microsoft account; a Hotmail, Outlook, or Office 365 account will work, though we highly recommend using MFA as well. Follow the instructions on the Azure website to create your account. To continue, click the My Account link at the top-right corner or go straight to the Microsoft Azure portal: https://portal.azure.com.

Now let’s discuss how to use the Azure CLI.

# Installing the Azure CLI

The Azure CLI is a set of commands that can be used to create and manage Azure resources. You can use the CLI on the web browser in the Azure portal, or you can download (from https://docs.microsoft.com/en-us/cli/azure/install-azure-cli) an appropriate version to be installed locally on your machine. For example, on macOS you can install the Azure CLI with the command brew install azure-cli.
