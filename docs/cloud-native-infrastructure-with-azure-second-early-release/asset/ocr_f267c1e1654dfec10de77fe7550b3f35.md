In this example, we have two server blocks for the cloudnativeazure.io and root (.) server blocks. Both of them are listening on port 53. Also, several plug-ins are defined: log, to log every query that CoreDNS receives; errors, to log errors; and cache, to enable frontend cache (i.e., all records except zone transfers and metadata will be cached for up to 3600s). You can run the preceding Corefile by simply typing coredns in the same directory where Corefile is present, or do coredns -conf Corefile:

```
$ coredns -conf Corefile
```
