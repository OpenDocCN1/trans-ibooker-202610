# Enabling eBPF

The next step for setting up our Calico infrastructure is to enable the eBPF data plane. Enabling eBPF allows you to take advantage of new kernel features and remove the use of kube-proxy for load balancing. When eBPF is enabled, the use of kube-proxy will be disabled.
