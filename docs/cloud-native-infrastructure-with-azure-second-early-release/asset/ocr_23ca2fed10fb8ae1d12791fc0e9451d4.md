# Installing and Configuring CoreDNS

You can install CoreDNS by using the binary, which is available at this book’s GitHub location.³ Once you have grabbed the binary for your OS, you can move it to your local bin. For example, if you have downloaded the binary for macOS, coredns_1.8.1_darwin_amd64.tgz, you can unzip the file and move it to /usr/local/bin. Verify that CoreDNS is working fine by issuing the following command:

```
$ coredns -version
CoreDNS-1.8.1
darwin/amd64, go1.15.7, 95622f4
```
