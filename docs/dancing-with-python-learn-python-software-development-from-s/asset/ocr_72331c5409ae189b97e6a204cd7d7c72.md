```
sorted(unsorted_terms, key=(lambda term: term[1]), reverse=True)
```

[[3, 6], [-5, 4], [1, 1]]

The optional keyword argument key for sorted takes a function that returns some value for comparison. In this case, it returns the second item in a term, the exponent. sorted uses “<” to compare the results of key. If you set reverse=True, sorted uses “>”.
