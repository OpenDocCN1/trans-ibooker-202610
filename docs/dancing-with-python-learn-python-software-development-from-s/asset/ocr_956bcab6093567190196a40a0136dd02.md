# 13.1.10 Semi-log plots

Every plot we have seen in this chapter has each axis with a linear scale. That means we add some constant value to get from one labeled location on the axis to the next. A semi-log plot has one axis with a linear scale and the other with a logarithmic scale. This means that instead of showing y, the vertical axis shows 10^z where z = log(y). Frequently, the horizontal axis is linear, and the vertical axis is logarithmic.
