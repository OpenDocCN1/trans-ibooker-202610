Now let’s see how fast we can create the same list with a comprehension.

```
def build_list_2(n):
    [j for j in range(n)]

t_2 = timeit.timeit(stmt="build_list_2(100000)",
                    number=3, globals=globals())
print(f"Execution time = {t_2:.10f}")
```

Execution time = 0.0098197000

If you are filtering items or computing with them, the execution time difference might be much less than what we just saw for building simple lists. A comprehension may not be your fastest solution in every case, as Python knows how to create its built-in collections from functions like range.

```
def build_list_3(n):
    list(range(n))

t_3 = timeit.timeit(stmt="build_list_3(100000)",
                    number=3, globals=globals())
print(f"Execution time = {t_3:.10f}")
```

Execution time = 0.0062501000

```
def speed(n, m):
    ratio = eval(f"t_{n}") / eval(f"t_{m}")
    print(f"build_list_{m} is " +

```
