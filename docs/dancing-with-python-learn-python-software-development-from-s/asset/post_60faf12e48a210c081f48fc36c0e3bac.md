## 13.1.7 NumPy arrays

How big is a Python object if we measure it in bytes? Let’s look at the size of an empty string.

```

`getsizeof` is a function in the **sys** module that returns the number of bytes of memory an object uses. In the case of a string, it includes the length, the characters themselves, plus system overhead for processes like garbage collection. If we add some text, the size gets larger, as we expect.

getsiz​​eof measures an object’s size, **but not the size of the objects to which it refers.** In this example, `getsizeof` is not including the sizes of the strings in the lists. We can get a better approximation of the true total amount of memory used with a function like the following:

```
```python
def getsizeof_list(the_list):
    size = getsizeof(list)
    for item in the_list:
        size += getsizeof(item)
    return size
