In the general multi-dimensional case, we have more than one input, which I have called *x*. In four dimensions, the equation of a hyperplane is

$$y = w_1x_1 + w_2x_2 + w_3x_3 + b$$

where the $w_j$ and $b$ are constant numbers, and the $x_j$ are the independent variables. You may see other letters used instead of $w$: $a$ and $c$ are common. The value $b$ is a constant and is frequently 0. Within machine learning, we call $b$ “the bias.”
