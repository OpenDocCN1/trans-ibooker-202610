Coders usually shorten “hexadecimal” to “hex.” Hex is often used in RGB color definitions within HTML and CSS for the web. For example, #fff68f is a light yellow. The first two “hexits” are the red component, the 3rd and 4th are the green component, and the 5th and 6th are the blue component. #000000 is black, #ffffff is white, and gray shades have all three parts equal. ## 5.2.5 Unicode

This section is about characters in strings, but I delayed introducing the topic until we had seen hexadecimal.

A byte is eight bits or two hexits. The largest integer you can fit into a byte is 255 decimal or FF hex, so if you use single bytes for characters in a string, you are limited to 256 characters. The original character encoding was ASCII, and it used 7 bits for 128 characters.

Since the English language has 52 uppercase and lowercase letters, 10 digits, and less than 20 punctuation marks, 256 may seem more than enough. However, there are many languages, mathematical symbols, and emoji. The Unicode standard represents all these characters. As of May 2021, there are 144,697 of them in draft version 14.0. [UNI]

A mapping from characters to sequences of bytes is called an encoding. The most common encoding, and the one used by the majority of websites, is UTF-8. It uses one to four bytes. Its specification includes the ASCII characters in the first byte. The sequences of bytes represent integers, and we call them code points.

There are three essential things to note:

- 1. *sin* can take any real number represented by a **float** as its argument, but only produces values between −1.0 and 1.0 inclusive. Said another way, the *domain* of *sin* is the set of real numbers, and its *range* is the set of real numbers *y* such that −1 ≤ *y* ≤ 1.
- 2. The sine function is periodic: given a real number *x*, *sin*(*x*) = *sin*(*x* + 2*k*π) for any integer *k*. That’s why *sin* repeats itself as you move from one side of the graph to the other. We say that the sine is periodic with period 2π.
- 3. The inverse function *asin* has the domain −1 ≤ *x* ≤ 1 for any real number *x*, but we restrict the range to −π/2 ≤ *y* ≤ π/2.

Suppose you have a bank account that compounds interest continuously. This function computes the amount of money you have after years if you start with principal and the interest at annual_rate.

```
def compound_continuously(principal, annual_rate, years):
    return principal * math.exp(annual_rate * years)
```

In these examples, we used 2% interest and started with 100 units of currency. You doubled your money after 35 years. That’s not very impressive!

The logarithm is the inverse of the exponential. If

y = c a^x      then      log_a(y/c) = x.

We say, “log_a is the base a logarithm.” It is not defined for an argument less than or equal to 0. When c = 1 and a = 2, log_2(16) is the power to raise 2 to get 16.
