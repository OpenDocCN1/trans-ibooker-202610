# 4.6 Strings and slicing

The slicing rules we saw for lists in section 3.2.6 also work for strings, except that you cannot put a string slice on the left-hand side of an assignment.

```
word = "sesquipedalianism"
len(word)
```

17

```
print(word[3:9])
print(word[:7])
print(word[7:])
```
