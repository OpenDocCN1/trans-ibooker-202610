If you are presenting numbers in a table, you might want to specify the field width and pad on the left with spaces or zeros.

```
for j in [1, 141, 1441, 14441]:
    print(f"| {j:5} | {j*j:010} |")
```

|     1 | 0000000001 |
|   141 | 0000019881 |
|  1441 | 0002076481 |
| 14441 | 0208542481 |

j:5 means “format the value of j right-justified in a field 5 characters wide, and pad with blanks.” j*j:010 means “format the value of j*j right-justified in a field 10 characters wide, and pad with zeros.”
