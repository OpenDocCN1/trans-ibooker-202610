# 15.3.3 Mean normalization

Let μ be the mean of a column. The *mean normalization* of a column value x_old is

x_new = (x_old - μ) / (x_max - x_min)

We assume the denominator is not zero.

We again use **numpy** methods to compute this:

max_minus_min = locality.max() - locality.min()

new_locality = (locality - mu) / max_minus_min
