The process of “translating and compiling” is called transpiling. (I did not coin that word.) Qiskit does this automatically, but you can call the transpile function to see how it changes your circuit. The optimization_level optional argument tells transpile how hard it should work to improve the circuit. It tries harder as optimization_level increases. The default value is 1, and Qiskit does no optimization when optimization_level is 0.

```
new_circuit_hw = transpile(new_circuit, quantum_hw,
optimization_level=1)
```

```
new_circuit_hw.draw(**draw_kwargs)
```
