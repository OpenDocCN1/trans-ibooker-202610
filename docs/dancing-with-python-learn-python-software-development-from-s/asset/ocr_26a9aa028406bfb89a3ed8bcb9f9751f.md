# 11.3.3 3-qubit oracles

The controlled-controlled-Z gate (CCZ) is the oracle for |111⟩ when we have three qubits. The double-control means that both q0 and q1 must be |1⟩ for Z to be applied to q2.

We can use a CX gate with a Hadamard H on each side of it on q1 to create the CZ oracle for |11⟩. Similarly, we can use a CCX Toffoli gate to make a CCZ. We discussed the Toffoli gate in section 9.6.5.

Here is the Qiskit oracle circuit for |111⟩:

```
circuit = QuantumCircuit(3)
circuit.h(2)
circuit.ccx(0, 1, 2)
circuit.h(2)
```
