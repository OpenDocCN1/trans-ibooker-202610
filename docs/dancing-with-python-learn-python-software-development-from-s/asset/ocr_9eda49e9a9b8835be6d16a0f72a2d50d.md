```
10000000000000000000 == 10000000000000000000.1
```

# 2.6.1 Division and exponentiation

Subject to the above, division works as you would expect with two floating-point numbers, or a **float** and an **int**.

```
2.75/4.0
```

0.6875

```
2.75/4
```

0.6875

You must take care when dividing two integers. If you use “/”, you get a **float**.

```
11/4
```

2.75

```
-13/5
```

-2.6

What if you wanted the integer quotient? Since 11 divided by 4 is not an integer, we have a remainder. In particular, 11 divided by 4 is 2 with remainder 3: 2 * 4 + 3. We use the division operator with two slashes “//” for the integer quotient and the percent sign “%” for the remainder.

```
11 // 4
```
