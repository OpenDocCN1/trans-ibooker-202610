The function *random* computes a pseudo-random **float** greater than or equal to 0 and less than 1.

```
[random.random() for i in range(3)]
```

[0.20609823213950174, 0.81332125135732, 0.8235888725334455]

# 5.7.1 Pseudo-randomness

In classical computing, we start with some *seed* number and then perform a series of arithmetic and bit operations to get “random” numbers. If we begin with the same seed, we get the same sequence of numbers. By default, Python uses the computer system time as the seed, though you can set it via *seed*. For this reason, we call these *pseudo-random* numbers.

If I know your seed and I know your random number generation algorithm, I may be able to replicate the numbers you produce. For this reason, you must be very careful about using pseudo-random numbers for cryptography. The Python documentation states this in its discussion of **random**:

> **Warning:** The pseudo-random generators of this module should not be used for security purposes.
> For security or cryptographic uses, see the **secrets** module.

With this in mind, we continue with **random**.

# 5.7.2 Distributions

The function *random* provides a *uniform distribution* of numbers in the interval, meaning that any value is as likely to appear as any other. More generally, uniform(r, s) provides a random **float** *n* in the range *s ≤ n ≤ s*.

```
[random.uniform(0, 2) for i in range(3)]
```

[1.3069450678023515, 0.3204591130376393, 1.0413387192798491]

Those are three random numbers between 0 and 2 inclusive. You can’t tell that this is a uniform distribution with only three values, but you get a better idea with a million.
