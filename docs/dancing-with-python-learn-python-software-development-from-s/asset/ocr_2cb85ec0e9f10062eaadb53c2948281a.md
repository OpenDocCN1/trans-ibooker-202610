# The Y quantum gate

The **Y** gate is the first 1-qubit gate we have seen that uses a non-real complex number.

**Y**: $a\lvert 0\rangle + b\lvert 1\rangle \mapsto -bi\lvert 0\rangle + ai\lvert 1\rangle$

![](bbox=[0.72, 0.244, 0.866, 0.292])

**Y** is both a bit flip and a phase flip. We can rewrite this as

**Y**: $a\lvert 0\rangle + b\lvert 1\rangle \mapsto (-i)(b\lvert 0\rangle - a\lvert 1\rangle) = (-i)\,\mathbf{ZX}(a\lvert 0\rangle + b\lvert 1\rangle)$

Since $\lvert-i\rvert=1$, the quantum state we get by applying **Y** is equivalent to what we get by applying **X** and then **Z**. If we have **X** and **Z**, **Y** is superfluous.

# The H quantum gate

The **H** gate, also known as the Hadamard gate after Jacques Hadamard, operates on $\lvert 0\rangle$ and $\lvert 1\rangle$ as

$\mathbf{H}(\lvert 0\rangle)=(\sqrt{2}/2)(\lvert 0\rangle+\lvert 1\rangle)$ and $\mathbf{H}(\lvert 1\rangle)=(\sqrt{2}/2)(\lvert 0\rangle-\lvert 1\rangle)$.

![](bbox=[0.72, 0.691, 0.866, 0.736])

With a bit of algebra, we get

```
$\begin{aligned}
\mathbf{H}(a\lvert 0\rangle+b\lvert 1\rangle)
&=a\,\mathbf{H}(\lvert 0\rangle)+b\,\mathbf{H}(\lvert 1\rangle)\\
&=a(\sqrt{2}/2)(\lvert 0\rangle+\lvert 1\rangle)+b(\sqrt{2}/2)(\lvert 0\rangle-\lvert 1\rangle)\\
&=a(\sqrt{2}/2)\lvert 0\rangle+a(\sqrt{2}/2)\lvert 1\rangle+b(\sqrt{2}/2)\lvert 0\rangle-b(\sqrt{2}/2)\lvert 1\rangle\\
&=(\sqrt{2}/2)(a+b)\lvert 0\rangle+(\sqrt{2}/2)(a-b)\lvert 1\rangle.
\end{aligned}$
```
