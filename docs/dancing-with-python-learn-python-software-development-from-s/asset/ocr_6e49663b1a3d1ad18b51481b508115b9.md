Use return to have the function pass a value back to whatever called the function.

```
def g(x, y):
    return x + y
```

If you forget the return, you will get None.

```
def bad_g(x, y):
    x + y

bad_g(10, 23) is None
```

True

It’s a common mistake for coders to forget a return statement, especially with conditionals.

```
def bad_abs(x):
    if x < 0:
        return -x
    x

bad_abs(-2)**3
```
