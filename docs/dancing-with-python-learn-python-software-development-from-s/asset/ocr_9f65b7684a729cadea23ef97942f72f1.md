You can use a decorator with a function with regular and keyword arguments (section 6.5). In the next example, I use *args and **kwargs to collect positional and keyword arguments and pass them to the inner wrapper.

```
# first define without the decorator
def adder_with_carry(a, b, carry=0):
    return a + b + carry

adder_with_carry(10, 20, carry=1)
```

31

```
def say_the_date(func):
    def wrapper(*args, **kwargs):
        now = datetime.datetime.now().strftime("%B %d, %Y")
        print(f"The day is {now}")
        return func(*args, **kwargs)
    return wrapper

# now use the decorator

@say_the_date
def adder_with_carry(a, b, carry=0):
    return a + b + carry

adder_with_carry(10, 20, carry=1)
```

The day is August 11, 2021
