A successful match always has at least one group, and it is group number 0, the entire match. That's why my earlier definition of print_match takes a default value for the group_number argument:

```
def print_match(result, group_number=0):
    if result is not None:
        # Display the matched substring
        print(f"group({group_number}) = "
              f'{result.group(group_number)}' , end="")

        # Display the starting index and index after end of match
        print(f"start({group_number}) = {result.start(group_number)}  "
              f"end({group_number}) = {result.end(group_number)}")
    else:
        print(None)
```

Since I put explicit groups in the pattern with parentheses, I can access them as well, starting with number 1:

```
for g in range(1, 4):
    print_match(result, g)
```
