# Exercise 7.44

There is no comparison problem if you sort a list of **CatAge** enumeration members. Why?

Dictionary keys and set members must be immutable objects, as we saw in sections 3.9.1 and 3.10. Since you can’t change them, Python can compute fixed information with the *hash* function that speeds up equality checking and access time. For example, if two objects have different *hash* values, they cannot be equal.

When Python sees `hash(object)`, it looks for an instance method, `__hash__`, to call on object.

```
hash(-0.8367)

-1929298845809097728
```

```
hash(735678)

735678
```

```
hash("A solitary string")

5073272553319032547
```
