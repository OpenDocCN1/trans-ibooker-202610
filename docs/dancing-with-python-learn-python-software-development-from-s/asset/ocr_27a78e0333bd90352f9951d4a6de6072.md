The *Pearson correlation coefficient*, often just called the correlation coefficient *r*, is the covariance divided by the standard deviation of each dataset. This division normalizes the covariance to be between -1.0 and 1.0. Values close to either extreme are “strongly correlated.” Another way to say this is that there is a very strong linear relationship between the datasets. It does not imply causality.
