# 7.10.2 Constantly thinking

The constant coefficient is the coefficient of the term that has the exponent 0. I've implemented constant_coefficient as a Python property because it is an intrinsic part of a polynomial.

```
@property
def constant_coefficient(self):
    """The coefficient of the term with exponent 0."""
    if self.__terms and 0 in self.__terms:
        return self.__terms[0]
    return 0
```

```
UniPoly(3, 'x', 0).constant_coefficient
```

3

Similarly, is_constant is a Boolean-valued property that tells us if there are no terms with an exponent greater than 0. I defer showing you its implementation until the end of section 7.14 because I need to introduce other Python features first.

```
UniPoly(3, 'x', 7).is_constant, UniPoly(2, 'y', 0).is_constant
```
