# Escaping special characters

Characters such as “?”, “*”, “+”, “.”, “|”, “{”, “}”, “(”, “)”, “[”, and “]” have special meanings inside patterns, and you must escape them with a backslash if you wish to match them. You must also escape a backslash to match a backslash. This is why we use Python raw strings for regular expression patterns!
