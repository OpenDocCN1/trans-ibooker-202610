normcase is a convenience function mainly useful on Windows. It makes the pathname lowercase and converts any forward slashes to backslashes on Windows. The function does nothing under other operating systems.

glob and iglob return files as well as directories. You can test which is which with isfile and isdir.

```
directories = []

for name in glob.iglob("src/**", recursive=True):
    if os.path.isdir(name):
        dir = os.path.normcase(name)
        directories.append(dir)

print(directories)
```

['src\\', 'src\\appendices', 'src\\art', 'src\\backmatter', 'src\\code', 'src\\code\\linting', 'src\\code\\__pycache__', 'src\\css', 'src\\examples', 'src\\frontmatter', 'src\\images', 'src\\matplotlib', 'src\\matplotlib\\__pycache__', 'src\\part-i', 'src\\part-ii', 'src\\part-iii', 'src\\preface', 'src\\preliminary']

The combination of the "**" wildcard and the recursive=True keyword argument tells iglob to descend into the directory tree to find matches.
