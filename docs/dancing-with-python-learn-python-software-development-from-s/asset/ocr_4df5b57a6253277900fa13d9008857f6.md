# The Z quantum gate

The **Z** gate changes the sign of the amplitude of |1⟩.

Z: a |0⟩ + b |1⟩ ↦ a |0⟩ − b |1⟩

![](bbox=[0.718, 0.805, 0.868, 0.855])

We call **Z** a *phase flip* for reasons coming from the physics of quantum mechanics.
