Note how I coded __init__ to call the Guitar and Wooden initialization methods.

If I call a method on an instance of AcousticGuitar, Python looks first in AcousticGuitar itself, then Guitar, then MusicalInstrument, and finally in Wooden. This is called the method resolution order.

If there were a third class from which AcousticGuitar inherited, Python would search it and its parent’s class after Wooden.
