# 9.7.4 Building the circuit

We begin by creating a circuit from its constituent parts: a quantum register and a classical measurement register. Each register has one qubit or bit, and we prefix each with “q” or “meas”, respectively.

```
qreg_q = QuantumRegister(1, "q")
creg_c = ClassicalRegister(1, "meas")
```

We combine these into a circuit,

```
circuit = QuantumCircuit(qreg_q, creg_c)
```

and place an X gate on the qubit line.

```
circuit.x(qreg_q[0])
```
