The logarithm is the inverse of the exponential. If

y = c a^x      then      log_a(y/c) = x.

This means

x = a^{log_a(x)}      and      x = log_a(a^x).

We say, “log_a is the base a logarithm.” It is not defined for an argument less than or equal to 0. When c = 1 and a = 2, log_2(16) is the power to raise 2 to get 16.

```
math.log2(16)
```
