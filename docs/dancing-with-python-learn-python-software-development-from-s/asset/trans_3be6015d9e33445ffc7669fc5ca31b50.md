```
## 14.6 Converting categorical data

GENDER 列包含 *categorical data* 而不是数值。列中的项目属于一组固定的值，通常是字符串。在这种情况下，值是 'F' 和 'M'。虽然我们可以检查项目是否等于其中之一，但通常更容易将分类列转换为多个包含 0 和 1 的数值“虚拟列”。
```

