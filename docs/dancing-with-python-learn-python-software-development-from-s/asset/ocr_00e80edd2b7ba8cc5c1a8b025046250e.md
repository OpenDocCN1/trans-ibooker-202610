Most of the mathematical functions are in Python modules, and you must import them into your environment. We discuss modules in section 5.1.

*abs* and a few other functions are built in, and you can use them directly. The *round* function comes in two forms. In the first, it rounds to the nearest *int*.

```
round(2.7)
```

3

```
round(-7.51)
```

-8
