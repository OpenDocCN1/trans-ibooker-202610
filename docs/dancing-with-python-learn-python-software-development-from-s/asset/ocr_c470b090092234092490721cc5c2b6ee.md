# 3.9.10 Dictionary comprehensions

In a list comprehension, we use a for loop within a square-bracketed expression to construct a list. We do the same with dictionaries but use braces instead. Remember that we need to include both the new key and the new value.

```
{model : year for model, year
    in guitars.items() if 1950 < year and year < 1958}
```

{'Fender Stratocaster': 1954, 'Gibson Les Paul': 1952}
