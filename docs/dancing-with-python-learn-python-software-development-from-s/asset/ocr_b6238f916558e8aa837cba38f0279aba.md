In section 1.3, I introduced a **maximum** function that took two numbers. Python implements this as *max*. To get the minimum value, use *min*.

```
```python
max(0, 19.7)
```
```

19.7

```
```python
min(0, 19.7)
```
```

0

You are not limited to two numbers.

```
```python
max(0, 19.7, -8, 33.2)
```
```

33.2

```
```python
min(0, 19.7, -8, 33.2)
```
```

-8

You can also use a list as the sole argument to these functions.

```
```python
max([0, 19.7, -8, 33.2])
```
```

33.2

```
```python
min([0, 19.7, -8, 33.2])
```
```

-8
