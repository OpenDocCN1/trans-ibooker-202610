This result means that `math.cos(math.pi/2)` and `0.0` are the same to approximately 15 decimal places. The exact value you use for the absolute tolerance `abs_tol` depends on your application. There is no general default value that makes sense in all cases. [PEP485]

The **math** module does not provide direct support for the secant, cosecant, and cotangent functions. You can implement them yourself, but you must consider where they are not defined.
