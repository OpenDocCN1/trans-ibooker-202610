# 13.2.5 Side-by-side bars

A side-by-side bar chart makes it easy to see how corresponding results from different times vary. The trick to drawing a side-by-side bar chart is to specify the width of each bar and then shift the position of bars to the right by that width.

```
```python
import matplotlib.pyplot as plt
import numpy as np

plt.clf()

data = [[21, 14, 10, 9, 19],
        [17, 16, 4, 12, 14]]

# set the width of a bar
width = 0.4

# draw the first bar chart with each bar the specified width
bar_chart = plt.bar(np.arange(1, len(data[0]) + 1), data[0],
                    width=width, color="#505050")
