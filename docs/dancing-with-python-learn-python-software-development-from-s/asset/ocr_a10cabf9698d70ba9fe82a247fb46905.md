It would be nice to have a simpler and class-oriented way of doing this in Python. This functionality is the role of *enumerations.*

```
from enum import Enum

class Cookie(Enum):
    CHOCOLATE = "chocolate"
    SUGAR = "sugar"
    OATMEAL = "oatmeal"
    SHORTBREAD = "shortbread"
```

There is no comma at the end of a line assigning an enumeration value to its name. Each name-value pair is called an *enumeration member.*

We access a member using “.” syntax:

```
Cookie.SHORTBREAD
```

```
<Cookie.SHORTBREAD: 'shortbread'>
```

```
Cookie.SUGAR
```

```
<Cookie.SUGAR: 'sugar'>
```

# Exercise 7.10

What is the type of an enumeration member?

If you have a member, you can retrieve its name and value.

```
cookie = Cookie.OATMEAL
cookie.name
```

```
'OATMEAL'
```

```
cookie.value
```

```
'oatmeal'
```

Given the value, you can get the member.

```
Cookie("sugar")
```

```
<Cookie.SUGAR: 'sugar'>
```
