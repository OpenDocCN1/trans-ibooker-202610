# 10.3.2 Choose a good algorithm

When we looked at implementations of the factorial and Fibonacci functions in Chapter 6, Defining and Using Functions, we saw that selecting the right algorithm can make a large difference in execution time or memory usage. Note that you might not see this until the problem gets big enough, so you may not need to over-analyze what to do in small cases.

For example, do you really need to call sorted for a list of two items?

Suppose you want to add together all positive integers less than or equal to a given integer. You might code:

```
def adder_1(n):
    sum = 0
    for j in range(1, n + 1):
        sum += j
    return sum

adder_1(100)
```

5050

```
t = timeit.timeit(stmt="adder_1(1000000)",
                number=3, globals=globals())
print(f"{t:.10f}")
```

2.0824539000

Or, you could note that this sum is n (n + 1)/2.

```
def adder_2(n):
    return n * (n + 1) // 2
```
