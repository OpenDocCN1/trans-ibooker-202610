```python
pattern = re.compile(r"ecom")
```

```
Two substrings begin with "eco". To find them, we insert a *character class* into our pattern using square brackets:

```
```python
pattern = re.compile(r"eco[ls]")
pattern
```
```

`re.compile(r'eco[ls]', re.UNICODE)`

This pattern indicates that we should match the explicit characters 'e', 'c', and 'o', followed by either 'l' or 's'.

```
```python
result = pattern.search(string)
print_match(result)
```
```

`group(0) = ecol"  start(0) = 10  end(0) = 14`

We matched the first occurrence, "ecol". Use *findall* to get a list of all matching substrings:

```
```python
pattern.findall(string)
```
