If we make three calls to scatter, we can display each city’s points in different ways. Use the s argument to change the size of the marker as in this code:

```
axes.scatter(days, city_high_temperatures['A'], s=10)
axes.scatter(days, city_high_temperatures['B'], s=100)
axes.scatter(days, city_high_temperatures['C'], s=50)
```
