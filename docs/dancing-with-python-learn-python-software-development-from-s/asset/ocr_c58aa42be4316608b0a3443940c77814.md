```
string = "[1] Sutor, Robert S. (2019). Dancing with Qubits."
```

What does each of the following return?

```
re.compile(r"[1]").search(string)
re.compile(r"\[1\]").search(string)
```

What happens if you omit the r before the pattern?

To simplify the code ahead, I now define this helper function:

```
def print_matches(string, pattern):
    for match in re.compile(pattern).finditer(string):
        print(match)
```
