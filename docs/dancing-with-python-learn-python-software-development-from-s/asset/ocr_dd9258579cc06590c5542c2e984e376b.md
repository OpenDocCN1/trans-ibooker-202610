Given a Unicode string, we can encode it as a binary string. We can then use the binary string and write it to a binary file.

```
s = "Sîne klâwen æðelen XM ᚺᚱ ᚫᚱ ᚲᚾ ᚹ"
```

```
t = s.encode("utf-8")
t
```
