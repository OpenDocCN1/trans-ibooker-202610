# Searching and Changing Text

With replace, I would have needed to match against a specific phone number. With the regular expression, I can match against anything that looks like a phone number.

For privacy reasons, I might want to mask the number with asterisks. This substitution will do that:

```
```python
pattern.sub("***-***-****", string)
```
```

`'My phone number is ***-***-****.'`

I can use a back-reference to a group to modify the general text that the engine matched. Here, I am adding a US country code:

```
```python
pattern.sub(r"+1-1", string)
```
```

`'My phone number is +1-914-555-1234.'`

By default, `sub` works on all non-overlapping matches. If you give it a third positive `int` argument, it will perform at most that many substitutions. The default value for this argument is 0, which means “make all substitutions.”

```
```python
string = "212-555-0123    585-555-9876    320-555-3467"
pattern.sub("***-***-****", string)
```
```

`'***-***-****    ***-***-****    ***-***-****'`

```
```python
pattern.sub(r"+1-1", string, 2)
```
```

`'+1-212-555-0123    +1-585-555-9876    320-555-3467'`

The *subn* function returns the new string in a tuple with the number of substitutions performed.

```
```python
string = "212-555-0123    185-555-9876    320-555-3467"
pattern.subn("***-***-****", string)
```
```

`('***-***-****    185-555-9876    ***-***-****', 2)`
