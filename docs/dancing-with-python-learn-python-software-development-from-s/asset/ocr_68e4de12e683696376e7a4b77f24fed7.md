# Other controlled gates

We can add a control qubit to the execution of any quantum gate, not just X. In the circuit in Figure 9.10, we have the state of the top qubit controlling whether we apply X, Y, Z, and H gates to other qubits. From left to right, we have CX (= CNOT), CNOT (= CX), CY, CZ, CZ (alternative form), and CH.

![](bbox=[0.32, 0.26, 0.65, 0.35])

Figure 9.10: CX, CY, CZ, and CH quantum gates

The controls don’t need to go from top to bottom. They can go in either direction and, as you can see, can jump across qubits.

# Tensoring gates

Just as we can tensor two individual quantum states

|φ⟩ = a |0⟩ + b |1⟩ and |ψ⟩ = c |0⟩ + d |1⟩

to get a 2-qubit quantum state,

|φ⟩ ⊗ |ψ⟩ = (a |0⟩ + b |1⟩) ⊗ (c |0⟩ + d |1⟩) = ac |00⟩ + ad |01⟩ + bc |10⟩ + bd |11⟩

we can tensor two 1-qubit gates.

If A and B are two 1-qubit gates, then

(A ⊗ B)(|φ⟩ ⊗ |ψ⟩) = (A |φ⟩) ⊗ (B |ψ⟩)

is a 2-qubit gate.

For example, if A = B = H, the Hadamard gate, then

H |0⟩ = (√2/2) |0⟩ + (√2/2) |1⟩
