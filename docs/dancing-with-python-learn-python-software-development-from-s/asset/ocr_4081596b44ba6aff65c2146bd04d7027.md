# A

Tools

It’s one thing to read a book about writing software, and it’s quite another to install the tools you need and then use them. In this appendix, I discuss how to get and install Python, install modules and packages, start and use the Python interpreter, use integrated development environments, install and use Qiskit on your machine and online, and check your code via “linting.”
