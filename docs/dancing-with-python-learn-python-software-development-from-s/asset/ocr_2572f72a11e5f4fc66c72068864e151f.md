The √NOT gate goes by several other names and symbols: √X, √¬, and Sx. Whatever you call it, when you apply the √NOT twice to a quantum state, you get a bit flip of the state.

![](bbox=[0.78, 0.48, 0.9, 0.54])

![](bbox=[0.78, 0.55, 0.9, 0.6])

√NOT operates on |0⟩ and |1⟩ by

|0⟩ ↦ (1/2) ((1 + i) |0⟩ + (1 − i) |1⟩)
|1⟩ ↦ (1/2) ((1 − i) |0⟩ + (1 + i) |1⟩)
