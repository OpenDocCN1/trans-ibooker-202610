The *variance* is the square of the standard deviation, and so is σ². Like standard deviation, it measures the spread of data values about their mean.

variance = σ² = ((μ − d₁)² + ··· + (μ − dₙ)²) / n = (1 / n) ∑ⱼ₌₁ⁿ (μ − dⱼ)²

In the dataset ages at the beginning of section 14.1 with the ages of one hundred concert-goers, the unit for variance is years² (years-squared).

We compute variance with the *var* function.

```
np.var(ages)
```
