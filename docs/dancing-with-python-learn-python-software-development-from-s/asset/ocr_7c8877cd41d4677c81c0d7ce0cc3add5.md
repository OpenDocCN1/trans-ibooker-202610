# 3.5 The Comparison Tests

Suppose we have two series ∑aₙ and ∑bₙ with positive terms. If ∑bₙ is a known convergent series and aₙ ≤ bₙ, then ∑aₙ is convergent. If ∑bₙ is a known divergent series and aₙ ≥ bₙ, then ∑aₙ is divergent.

The Comparison Test is useful, but it requires that we have a known series to compare with. In many cases, we can use a geometric series or a p-series as the comparison series. However, finding the required inequality is not always easy, and the Limit Comparison Test provides a more flexible alternative.
