# Tools

Instead of using **.venv** under your home directory, you can specify any valid directory path for your virtual environment files. For example, on Windows, I could issue:

```
```bat
python -m venv c:\my-qiskit-env
c:\my-qiskit-env\Scripts\activate.bat
pip install qiskit
```
```
