We can do better with a version using division. Recall that divmod(x, y) returns the tuple (x // y, x % y). If we let q, r = divmod(x, y), then x == q*y + r and x - q*y = r.

# Exercise 6.18

Show that this equality implies that if prime p divides x and y, then p divides r.

```
def gcd(x, y, step=1):
    print(f"-> {step:>2}: {x = }  {y = }")
    x, y = abs(x), abs(y)

    if x < y:
        x, y = y, x

    if y == 0:
        return x

    # at this point, we know that x and y and positive integers > 1
    # with x >= y > 0

    return gcd(y, x % y, step + 1)
```
