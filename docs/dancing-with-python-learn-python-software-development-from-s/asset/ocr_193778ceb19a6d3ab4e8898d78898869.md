# 14.9.2 Venn diagrams

Many of us learned about Venn diagrams in school. They use overlapping circles to show how sets of data intersect.

To draw them with Python, we install matplotlib-venn from the operating system command line and import it: [VEN]

```
pip install matplotlib-venn
```

```
import matplotlib_venn
```

This module can draw Venn diagrams with two and three circles. I use the lists of grey, tan, and white colours from the last section as the data for a 3-circle diagram:

```
matplotlib_venn.venn3(
    subsets=(set(grey_colours), set(tan_colours), set(white_colours)),
    set_labels=("Grey", "Tan", "White")
)
```
