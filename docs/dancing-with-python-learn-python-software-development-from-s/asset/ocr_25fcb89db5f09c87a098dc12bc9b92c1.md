# 5.3.4 Exponentials and logarithms

An exponential function has the form

c a^x

for a > 0, a ≠ 1, and c ≠ 0. We frequently use e for a, where e is Euler's number. The Python function that computes e^x is exp.

```
math.e

2.718281828459045
```

```
math.exp(0.0)

1.0
```

```
math.exp(1.0)

2.718281828459045
```

```
math.exp(4.5)

90.01713130052181
```

Suppose you have a bank account that compounds interest continuously. This function computes the amount of money you have after years if you start with principal and the interest at annual_rate.

```
def compound_continuously(principal, annual_rate, years):
    return principal * math.exp(annual_rate * years)
```

```
compound_continuously(100, 0.02, 1)

102.02013400267558
```

```
compound_continuously(100, 0.02, 35)

201.37527074704767
```
