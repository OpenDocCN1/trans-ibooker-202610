# 3.9.1 What is a dictionary?

Let’s begin by putting our information about guitars into the table in Figure 3.6.

| Brand | Model | Year Introduced |
|---|---|---|
| Fender | Stratocaster | 1954 |
|  | Telecaster | 1950 |
| Gibson | Les Paul | 1952 |
|  | Flying V | 1958 |
| Ibanez | RG | 1987 |

Figure 3.6: Table of guitar brands, models, and years introduced

A Python dictionary is a collection of key-value pairs. For example, I could have the keys

```
"Fender Stratocaster", "Fender Telecaster",
"Gibson Les Paul", "Gibson Flying V",
"Ibanez RG"
```

and associate them with the values

```
1954, 1950, 1952, 1958, 1987,
```

respectively. The keys here are Python strings, and the values are integers. A key that is not present in a dictionary is invalid.

Keys are unique in a given dictionary and must be of an immutable type. In particular, the keys cannot be lists or sets, but they can be tuples if the tuples do not contain mutable objects.
