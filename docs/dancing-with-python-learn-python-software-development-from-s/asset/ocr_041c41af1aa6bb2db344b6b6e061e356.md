To remove one or more rows, use the *drop* method with a list of the row indices. As usual, specifying `inplace=True` changes the DataFrame itself instead of making a copy.

```
```python
small_df.drop([51], axis=0, inplace=True)
small_df
```
```

   Locality       Postcode  Breed  Colour  Gender

54 DANDENONG           3175  DOMLH  GREWHI       F

56 DANDENONG           3175  DOMSH  TRI          F
```

A DataFrame has two *axes*, not to be confused with **matplotlib** plot axes. Axis 0 refers to the rows, and axis 1 is for the columns. In the case of *drop*, the default axis is 0, but I included it for clarity. You can also use `axis="index"` and `axis="columns"` instead of `axis=0` and `axis=1`.

```
```python
small_df.drop([53, 54], axis="index")
```

   Locality       Postcode  Breed  Colour  Gender
