## 前言

数据整理，也称为数据准备或数据清洗，是数据分析过程中的关键步骤。它涉及将原始数据转换为干净、结构化的格式，以便进行分析。随着数据的指数级增长以及对数据驱动决策的需求日益增加，掌握数据整理的艺术对于从庞大而复杂的数据集中提取有价值的见解变得至关重要。
在本書中，我们将指导您完成一系列章节，每个章节都专注于 AWS 上数据整理的一个特定方面。我们将探索各种 AWS 服务和工具，使您能够高效地操作、转换和准备数据以进行分析。从 AWS Glue 和 Athena 到 SageMaker Data Wrangler 和 QuickSight，我们将深入探讨这些服务的强大功能，并揭示它们从您的数据中释放有价值见解的潜力。
在整个章节中，您将学习如何利用 AWS 的云基础设施和强大的数据处理能力来简化您的数据整理工作流程。您将发现实用的技术、最佳实践和动手示例，这些将使您具备解决现实世界数据挑战并从您的数据集中提取有意义信息的技能。
因此，无论您是刚刚开始数据整理之旅，还是希望在 AWS 生态系统中扩展您的知识，本书都是您掌握 AWS 上数据整理的综合指南。准备好利用 AWS 的尖端技术和工具释放数据的力量并发挥其全部潜力吧。
让我们深入其中，踏上令人兴奋的 AWS 数据整理世界之旅吧！

## 本书涵盖内容

第 1 章，*数据整理的入门*：在开篇章节中，您将踏上数据整理世界的旅程，并发现利用 AWS 进行高效有效的数据操作和准备的强大功能。本章作为坚实的基础，为您提供贯穿全书的关键概念和工具的概述。

第 2 章，*AWS Glue DataBrew 简介*：在本章中，您将发现 AWS Glue DataBrew 在数据整理和数据准备任务中的强大功能。本章将指导您使用 AWS Glue DataBrew 清理、转换和丰富您的数据，确保其质量和可用性以供进一步分析。

第 3 章，*介绍 AWS SDK for pandas*：在本章中，您将被介绍 AWS Data Wrangler 在 AWS 平台上进行数据整理任务的多功能能力。本章将为您提供对 AWS Data Wrangler 的全面理解，以及它如何使您能够高效地操作和准备数据以供分析。

第 4 章，*SageMaker Data Wrangler 简介*：在本章中，您将发现 Amazon SageMaker Data Wrangler 在 Amazon SageMaker 生态系统中的数据整理任务的能力。本章将为您提供知识和技能，使您能够利用 Amazon SageMaker Data Wrangler 的强大功能高效地预处理和准备数据以用于机器学习项目。

第 5 章，*使用 Amazon S3*：在本章中，您将深入了解 **亚马逊简单存储服务 (S3)** 的世界，并探索其存储、组织和访问数据的巨大潜力。本章将为您提供对 Amazon S3 的全面理解，以及它如何被用于有效的数据管理和操作。

第 6 章，*使用 AWS Glue*：在本章中，您将深入了解 AWS Glue 的强大功能，这是由 AWS 提供的完全托管的 **提取、转换和加载 (ETL)** 服务。本章将指导您使用 AWS Glue 自动化和简化数据准备和转换工作流程的过程。

第 7 章，*使用 Athena*：在本章中，您将探索 Amazon Athena 的强大功能，这是一种无服务器查询服务，可让您使用标准 SQL 查询直接在 Amazon S3 中分析数据。本章将指导您使用 Amazon Athena 从数据中释放有价值的见解，而无需复杂的<|message|>数据处理基础设施。

第 8 章，*使用 QuickSight*：在本章中，您将发现 Amazon QuickSight 的强大功能，这是由 AWS 提供的快速、云驱动的 **商业智能 (BI)** 服务。本章将指导您使用 QuickSight 创建交互式仪表板和可视化，从而能够从数据中获得有价值的见解。

第 9 章，*使用 AWS SDK for Pandas 构建端到端数据整理管道*：在本章中，您将探索 AWS Data Wrangler 和 pandas 的强大组合，pandas 是用于数据操作和分析的流行 Python 库。本章将指导您在 AWS Data Wrangler 中使用 pandas 操作来对数据集执行高级数据转换和分析的过程。

第 10 章，*使用 SageMaker Data Wrangler 进行机器学习数据处理*：在本章中，您将深入了解使用 AWS SageMaker Data Wrangler 的强大功能进行 **机器学习 (ML)** 数据优化的世界。本章将指导您使用 SageMaker Data Wrangler 预处理和准备数据以用于 ML 项目的过程，最大化 ML 模型的性能和准确性。

第 11 章，*数据湖安全与监控*：在本章中，您将被介绍 AWS 上的 **身份和访问管理 (IAM)**，以及 Data Wrangler 如何与 AWS 的安全功能紧密集成。我们将展示如何直接与 Amazon CloudWatch 日志交互、查询日志并将日志作为数据帧返回。
