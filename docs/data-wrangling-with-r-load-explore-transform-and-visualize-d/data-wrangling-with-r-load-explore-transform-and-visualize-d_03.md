# 第 2 部分：使用 AWS 工具进行数据整理

在本节中，我们将探索三种功能强大的 AWS 工具，旨在简化数据整理和准备任务。首先，我们将深入研究 AWS Glue DataBrew，了解如何清理、转换和丰富数据以确保高质量且可用的数据集。之后，我们将揭示 AWS SDK for pandas 的多功能性，全面了解 AWS 平台上的高效数据操作和准备。最后，我们将探索 Amazon SageMaker Data Wrangler，使您具备无缝预处理和准备数据以进行有影响力的机器学习项目的技能。

本部分包含以下章节：
- 第 2 章，AWS Glue DataBrew 简介
- 第 3 章，介绍 AWS SDK for pandas
- 第 4 章，SageMaker Data Wrangler 简介
