The next step is to address the data quality issues. To do so, the first step is to create a project.

To create a project, follow these steps:

+   1. Go to the DataBrew console and select **Projects**.
+   2. Click on **Create project**.
+   3. Enter a name for the project (e.g., `human-resource-project-data-quality-check`) under **Project name**.
+   4. Under **Select a dataset**, choose **My datasets**.
+   5. Select the `raw-human-resource` dataset.
+   6. Keep the sampling size at its default value.
+   7. Under **Permissions**, select the IAM role that was previously created for our DataBrew profile job under **Role name**.
+   8. Click **Create project**.

Once the project has been created, the Glue DataBrew interactive session will be launched. Now, let’s remove the duplicate values from the Emp ID column.

To do this, follow these steps:

+   1. Select the **Emp ID** column.
+   2. Click on the **More options** icon (three dots) to see all the available transforms for this column.
+   3. Choose **Remove duplicate values**.
