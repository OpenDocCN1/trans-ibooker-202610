## 关于作者

**Navnit Shukla** 是一位充满热情、热爱技术的个人。他在勒克瑙的 Dr. A.P.J. Abdul Kalam 技术大学（前身为 U.P.T.U）攻读电子与通信工程，为他未来的事业奠定了基础。25 岁时，他远渡重洋前往美国，如今与深爱的妻子和儿子一起居住在美丽的加利福尼亚州橙县。自 2009 年起投身 IT 领域，他在行业内积累了丰富的经验和知识。过去四年里，他在 **Amazon Web Services (AWS)** 担任分析师专家解决方案架构师。在此职位上，他负责协助各规模的组织在动态的 AWS 云平台上设计、构建并无缝运营解决方案。除专业追求外，他非常享受与家人朋友共度美好时光、探索新地方、创造珍贵回忆并开启激动人心的冒险。

> *我深深感谢那些在我旅途中始终陪伴在我身边、给予我坚定不移支持的人。我衷心感谢我深爱的妻子 Anchal Dubey 和我敬爱的父母，他们的鼓励和对我的信任弥足珍贵。*

**Sankar M** 自 2007 年起在 IT 行业工作多年，专注于数据库、数据仓库和分析领域。作为一名专业的数据架构师，他帮助客户构建和现代化数据架构，并帮助他们构建安全、可扩展且性能优异的数据湖、数据库和数据仓库解决方案。在加入 AWS 之前，他曾与多家客户合作实施复杂的数据架构。

**Sam Palani** 拥有超过 18 年的开发者、数据工程师、数据科学家、初创公司联合创始人和 IT 领导者经验。他拥有工商管理硕士学位，专业方向为信息技术双专业。他的职业生涯横跨 5 个国家，涉及金融服务、管理咨询和技术行业。他目前是 Amazon Web Services 的机器学习和人工智能高级负责人，负责多条业务线、产品战略和思想领导力。Sam 同时也是一名实践型数据科学家，拥有多篇出版物，是重要行业会议的演讲者，也是活跃的开源贡献者。工作之外，他喜欢徒步、摄影、尝试美食和阅读。

## 关于审阅者

**Naresh Rohra** 是一位出色的数据建模师和首席分析师，热衷于利用前沿技术从复杂数据集中挖掘有价值的见解。凭借在数据建模领域十多年的经验，他成功驾驭了数据整理和分析的动态格局，赢得了领先专家的声誉。他精通设计与 OLTP 和 OLAP 系统相关的各种数据模型。他曾与 TCS、Cognizant 和 Tech Mahindra 等知名组织合作。

*我衷心感谢我的同事和家人，在我审阅书籍的旅程中给予我持续的鼓励。致我深爱的女儿 Ginisha，你是我夜空中闪耀的星。*

**Roja Boina** 是一名工程高级顾问。她为企业提供数据驱动的解决方案。她以雷厉风行的态度为傲。她喜欢定义需求、设计、开发、测试和交付后端应用程序，并通过可视化传达数据。她非常热衷于成为 **Women in Tech (WIT)** 的倡导者并参与 WIT 社区。在 9-5 工作之外，她喜欢为非营利组织做志愿者并指导 STEM 领域的女性同行。她相信成长型思维。
