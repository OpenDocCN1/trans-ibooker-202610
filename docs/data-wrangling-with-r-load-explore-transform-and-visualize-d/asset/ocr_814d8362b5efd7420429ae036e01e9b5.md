# Data ingestion from a database (JDBC data stores)

AWS Glue is commonly used to bring data from databases to a data lake. This is typically done using JDBC connections in a batch manner. To connect to a database, you can use an AWS Glue Connection, which stores the login credentials of the database, URI string, and virtual private cloud (VPC) information. AWS Glue supports several types of connections, including JDBC, Amazon RDS, Amazon Redshift, Amazon DocumentDB, Kafka, and MongoDB. To create a JDBC connection, you can use the following format:

```
jdbc:protocol://host:port/db_name.
```

You can learn more about creating connections for various databases by reading the AWS Glue documentation (https://docs.aws.amazon.com/glue/latest/dg/connection-properties.html#connection-properties-required).
