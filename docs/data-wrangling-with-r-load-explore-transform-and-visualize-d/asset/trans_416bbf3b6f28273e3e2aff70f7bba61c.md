## 前言
欢迎来到 *在 AWS 上进行数据整理* 的世界！在这本全面的书籍中，我们将探索令人兴奋的数据整理领域，并揭示利用 **亚马逊网络服务 (AWS)** 进行高效有效的数据操作和准备的巨大潜力。无论您是数据专业人员、数据科学家，还是对利用数据力量感兴趣的人，本书都将为您提供在 AWS 平台上精通数据整理领域的知识和工具。
数据整理，也称为数据准备或数据清洗，是数据分析过程中的关键步骤。它涉及将原始数据转换为干净、结构化的格式，以便进行分析。随着数据的指数级增长以及对数据驱动决策的需求日益增加，掌握数据整理的艺术对于从庞大而复杂的数据集中提取有价值的见解变得至关重要。
在本書中，我们将指导您完成一系列章节，每个章节都专注于 AWS 上数据整理的一个特定方面。我们将探索各种 AWS 服务和工具，使您能够高效地操作、转换和准备数据以进行分析。从 AWS Glue 和 Athena 到 SageMaker Data Wrangler 和 QuickSight，我们将深入探讨这些服务的强大功能，并揭示它们从您的数据中释放有价值见解的潜力。
在整个章节中，您将学习如何利用 AWS 的云基础设施和强大的数据处理能力来简化您的数据整理工作流程。您将发现实用的技术、最佳实践和动手示例，这些将使您具备解决现实世界数据挑战并从您的数据集中提取有意义信息的技能。
因此，无论您是刚刚开始数据整理之旅，还是希望在 AWS 生态系统中扩展您的知识，本书都是您掌握 AWS 上数据整理的综合指南。准备好利用 AWS 的尖端技术和工具释放数据的力量并发挥其全部潜力吧。
让我们深入其中，踏上令人兴奋的 AWS 数据整理世界之旅吧！
## 本书适合谁
*在 AWS 上进行数据整理* 专为希望掌握数据整理的艺术并利用 AWS 的强大功能进行高效有效的数据操作和准备的各类人士而设计。本书面向以下读者：
- **数据专业人员**：在大型复杂数据集上工作的 数据工程师、数据分析师和数据科学家，希望在 AWS 平台上提升其数据整理技能
- **AWS 用户**：已熟悉 AWS 并希望探索用于数据整理的特定服务和工具的人士
- **业务分析师**：从事数据驱动决策和分析的专业人士，需要获取数据整理技能以从数据中得出有价值的见解
- **IT 专业人员**：希望扩展其在 AWS 平台上数据整理知识的技术爱好者和 IT 从业者
虽然具备数据整理或 AWS 的先前经验是有益的，但本书为初学者提供了坚实的基础，并逐步进展到更高级的主题。熟悉基本编程概念和 SQL 会有所帮助，但不是强制性的。本书结合了理论解释、实用示例和动手练习，使其对具有不同背景和技能水平的人士都易于理解。
