# Standard installation of awswrangler on a Glue Spark job

A Glue spark job can be created with the Glue 0.90 (Spark 2.2), Glue 1.0 (Spark 2,4), Glue 2.0 (Spark 2.4), and Glue3.0 (Spark3.1) versions. `awswrangler` has support only from Glue version 2.0 and before, as it has compiled dependencies (C/C++). The default is Glue 3.0, which is the latest version, and you should have the latest Glue 3.0 version for all new jobs and, wherever possible, upgrade to it.
