## 数据湖访问控制

为了保护数据湖，我们可以使用基于用户访问策略和基于资源访问策略的组合。用户策略附加到用户/角色，并控制用户/角色在帐户内可以执行的操作。除了基于用户的控制策略外，我们还可以将访问策略附加到 Amazon S3、Amazon SQS 等资源，以专门控制该资源的访问。这为保护 AWS 资源提供了另一层安全保障。作为一般最佳实践，访问策略应保持最小权限，仅允许在特定条件下执行所需操作。
