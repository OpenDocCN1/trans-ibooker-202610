# When to choose a file format

Parquet files are most commonly used and you can start with them if you are unsure about the choice of data storage format but you know the data will be used for analytical use cases. You can choose to use the Avro file format in case of real-time streaming needs where schema evolution is of primary concern and the data will be used for exploratory purposes.
