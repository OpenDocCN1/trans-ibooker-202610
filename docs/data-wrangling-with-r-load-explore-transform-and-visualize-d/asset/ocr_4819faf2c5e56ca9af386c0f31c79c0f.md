We will split the string using hyphens (-) if available and then generate a sequence with numbers between the left-hand to right-hand number. For example, `Level1-4` will generate a sequence of numbers from 1 (left side) to 4 (right side), which will be appended with the string `Level` and joined together using commas. If the hyphen is not available, then the data will be populated as such:
