From the recommendations list, the following data quality recommendations were selected and added to the ruleset:

These recommendations were provided as part of the data quality rule suggestions. To create custom data quality rules using the Glue DataBrew console, read on.

In order to create custom data quality rules using the Glue DataBrew console, we must first define what rules we want to build. Here are some rules we want to create:

- 1. **Validate the row count**: We have downloaded the dataset of 5 million records. Let’s validate whether the count matches.
- 2. **The employee ID, email address, and SSN should be unique**: These values should always be unique.
- 3. **The employee ID and email address should not be null**: Usually, we don’t want these values to be null.
- 4. **The employee ID and employee age in years shouldn’t have negative values**: We want to validate that the values in these columns are positive.
- 5. **The SSN data format should be in the format (xxx-xx-xxxx).**

Let’s start building the data quality rules:

- 1. Validate the row count.

To check the total row count, let’s perform the following steps:

- 1. Create a new rule.
- 2. Name the rule (e.g., `Row count == 5 million`).
- 3. Choose **Individual check for each column** for the data quality check scope.
- 4. Select **All data quality checks are met (AND)** as the rule success criteria.
- 5. Choose **Number of rows** as the data quality check.
- 6. Select **Is equals** as the condition.
- 7. Enter **5000000** as the value.

2. To verify that the specified columns contain only unique values, follow these instructions:

- 1. Click on **Add rule**.
- 2. Enter a name for the rule, for example, **Check Unique Values in Columns**.

3. To ensure that the employee ID and email address are not null, follow these steps:

- 1. Choose Add another rule.
- 2. Enter a name for the rule, such as Check for Null Employee ID and Email.
- 3. Choose Common checks for selected columns for Data quality check scope.
- 4. Choose All data quality checks are met (AND) for Rule success criteria.

- 5. Select **Emp ID** and **Email** under **Selected columns**.
- 6. For **Data quality check**, choose **Value is not missing**.
- 7. Choose **Greater than or equals** for **Condition**.
- 8. Enter **100** as the threshold value and select **%(percent) rows** from the drop-down menu.

4. To ensure that the employee ID and age columns contain only positive values, follow these steps:

- 1. Click **Add another rule**.
- 2. Enter a name for the rule, such as **Check emp ID and age for positive values**.
- 3. Choose **Individual check for each column** as the data quality check scope.
- 4. Select **All data quality checks are met (AND)** as the rule success criteria.
- 5. For the first check, choose **Numeric values** as the data quality check.
- 6. Select **Emp ID** from the drop-down menu.
- 7. Choose **Greater than or equal to** for the condition.
- 8. Select **Custom value** for the value and enter **0**.
- 9. Click **Add another quality check** and repeat steps 5-8 for the **Age in Yrs.** column.

5. Validate the SSN data format.

- 7. Select **Matches (RegEx pattern)** for **Condition**.

The next step is to address the data quality issues. To do so, the first step is to create a project.

To create a project, follow these steps:

- 1. Go to the DataBrew console and select **Projects**.
- 2. Click on **Create project**.
- 3. Enter a name for the project (e.g., `human-resource-project-data-quality-check`) under **Project name**.
- 4. Under **Select a dataset**, choose **My datasets**.
- 5. Select the `raw-human-resource` dataset.
- 6. Keep the sampling size at its default value.
- 7. Under **Permissions**, select the IAM role that was previously created for our DataBrew profile job under **Role name**.
- 8. Click **Create project**.

Once the project has been created, the Glue DataBrew interactive session will be launched. Now, let’s remove the duplicate values from the Emp ID column.

To do this, follow these steps:

- 1. Select the **Emp ID** column.
- 2. Click on the **More options** icon (three dots) to see all the available transforms for this column.
- 3. Choose **Remove duplicate values**.
