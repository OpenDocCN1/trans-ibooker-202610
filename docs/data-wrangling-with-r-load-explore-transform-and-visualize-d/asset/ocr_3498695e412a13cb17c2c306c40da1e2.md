# Access through Amazon Athena and the Glue Catalog

To enable data discovery for users who are comfortable with SQL-based access, we can catalog the datasets in the AWS Glue Data Catalog and explore the datasets for more complicated analysis.

Athena provides a SQL-based access mechanism to explore data without any file size limitation, supports SQL, and doesn’t require Python programming to explore datasets.
