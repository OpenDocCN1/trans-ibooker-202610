# 第 3 部分：AWS 数据管理与分析

在本节中，我们将探索用于有效数据管理和分析的基本 AWS 服务。*第 5 章* 介绍了 Amazon S3，揭示了其作为数据稳健存储和组织解决方案的潜力。*第 6 章* 深入探讨 AWS Glue，展示了这项强大的 ETL 服务如何自动化数据准备和转换工作流程。*第 7 章* 介绍了 Amazon Athena，这是一项无服务器查询服务，可通过直接对 Amazon S3 数据进行 SQL 查询来获得有价值的见解。最后，*第 8 章* 探索了 Amazon QuickSight，这是一项快速的 BI 服务，用于创建交互式仪表板和可视化，以从数据中获得有价值的见解。

本部分包含以下章节：

- *第 5 章*，使用 Amazon S3
- *第 6 章*，使用 AWS Glue
- *第 7 章*，使用 Athena
- *第 8 章*，使用 QuickSight
