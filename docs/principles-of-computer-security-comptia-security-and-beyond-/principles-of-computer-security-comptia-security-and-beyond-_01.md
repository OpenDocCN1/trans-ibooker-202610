# 计算机安全原理：CompTIA Security+ 及更进一步 - 实验手册 - (Exam SY0-601)

# 关于作者

**Jonathan S. Weissman** 是罗切斯特理工学院高级讲师（计算安全系），曾于 2014 年获 RIT 杰出教学奖、2018 年获 RIT GCCIS 杰出教育者奖，并于 2019 年获 RIT 杰出教师表彰计划荣誉。Weissman 为 edX RITx 网络安全微硕士项目开发并教授三门课程，全球超过 300,000 名学生学习。

Weissman 同时也是 Finger Lakes 社区学院的终身副教授兼网络与网络安全项目协调员（计算科学系），于 2021 年获纽约州立大学校长教学卓越奖。

总的来说，Weissman 已获得十项教学荣誉和奖项。Weissman 于 2001 年开始教学生涯，已教授超过 50 门研究生和本科课程，包括网络、网络安全、系统管理、道德黑客/渗透测试、数字取证、恶意软件逆向工程、密码学、编程、脚本编写、网页设计、数据库设计、计算机组织与体系结构、操作系统设计等。除了两份全职教学职位外，Weissman 还在雪城大学（电气工程与计算机科学系）和纳扎勒斯学院（商学院与领导力学院）兼职任教。

除本书外，Weissman 还是 *Mike Meyers’ CompTIA Network+ Guide to Managing & Troubleshooting Lab Manual*（第五版和第六版）以及 *Mike Meyers’ CompTIA Network+ Certification Passport*（第六版和第七版）的合著者。他还担任多本行业教材的技术编辑。

此外，Weissman 还为当地企业和个人提供网络和网络安全咨询。Weissman 经常作为网络和网络安全专家出现在电视新闻和谈话广播以及文章中。此外，他还在会议和网络研讨会上演讲，举办研讨会，并在播客中露面。

Weissman 拥有布鲁克林学院计算机科学硕士学位，并持有 44 项行业认证，包括 CCNP Enterprise、Cisco Certified Specialist - Enterprise Core、Cisco Certified Specialist - Enterprise Advanced Infrastructure Implementation、CCNA Security、CCNA、CompTIA Security+、CompTIA Network+、CompTIA A+、CompTIA Linux+、CompTIA Server+、EC-Council Certified Ethical Hacker、EC-Council Computer Hacking Forensic Investigator 和 IPv6 Forum Certified Network Engineer（金牌）等。
