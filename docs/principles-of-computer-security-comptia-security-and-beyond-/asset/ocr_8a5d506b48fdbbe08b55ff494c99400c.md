+   [*] WE GOT A HIT! Printing the output:

+   c. Provide fake credentials and log in to the fake Facebook site.

+   POSSIBLE USERNAME FIELD FOUND: email=
+   POSSIBLE PASSWORD FIELD FOUND: pass=
