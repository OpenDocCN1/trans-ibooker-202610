# # Counterfactual Fairness

Predictions are fair if they are the same in the actual world and in a counterfactual world where the individual belonged to a different protected group.

+   - **Example:** An algorithm recommends a therapy based on patient features. Consider a female patient. We compare the recommendation with what it would have been had that same patient been male.
+   - For the decision to be fair, the therapy recommendation must be the same in both the actual and counterfactual worlds.
+   - If the recommendation differs, the decision is unfair — the protected attribute (gender) influences the outcome.

> > “The central idea is that a decision is fair if it is invariant to the protected attribute in the counterfactual world.”

To estimate counterfactuals, we need a causal model of the data. The model usually assumes that the protected attribute is a cause of many observed features, and that some latent variables mediate the influence.
