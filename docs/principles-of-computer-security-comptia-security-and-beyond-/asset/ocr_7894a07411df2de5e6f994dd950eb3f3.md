# Note

Kali Linux 2021.1 changed the hash function for passwords from sha512crypt (listed as $6$ in the /etc/shadow file) to yescript (listed as $y$ in the /etc/shadow file). Read about yescript here:

https://www.openwall.com/yescrypt/

Also relevant to this chapter, from

https://openwall.com/john/doc/OPTIONS.shtml:
