
像之前一样保存并退出，su 到 alice，然后尝试更改 bob 的密码。通过失败……你会成功！

**d.** 可以更改 /etc/sudoers 的某些默认配置值。

这会使得 /etc/sudoers 读取 /etc/sudoers.d 目录中的另一个文件：

```
sudo visudo -f /etc/sudoers.d/defaults
```

文件名不一定要取为 defaults，但在本例中，将其命名为 defaults 是合理的。
