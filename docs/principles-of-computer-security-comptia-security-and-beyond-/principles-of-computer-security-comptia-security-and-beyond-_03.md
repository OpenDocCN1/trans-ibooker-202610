## 第 3 章：运营安全与组织安全

### 实验练习

- 3.01 策略
- 3.02 培训文档
- 3.03 互操作性协议
- 实验分析
- 关键术语测验

应该在用户入职当天就对他们进行教育，让他们了解组织对他们的期望。他们了解得越多，就越有能力应对可能威胁企业运营安全（确保企业高效有效地运行）和组织安全（实现企业目标：盈利）的各种情况。

如果没有计划，用户就会感到困惑、犯错，甚至可能作出恶意行为（有意或无意）。计划始于发布的策略——这些高层文档解释了组织的原则和指导方针，旨在指导用户确切地知道必须做什么才能合规。

程序是为实现策略而采取行动的逐步说明。在发生事件或灾难时，策略和程序应清晰指导后续步骤，以便所有员工确切知道自己的角色和职责。此外，这些程序文档可确保以符合策略要求的一致且可靠的方式完成任务。从常规工单录入程序到灾难恢复程序，一切都需要记录和引用。

确保用户通过教育、培训和测试来阅读策略和程序非常重要。否则，这些文档很容易被忽视，变得毫无价值。这也意味着员工可能没有按照公司政策行事，从而导致负面的安全结果，甚至不合规。

涉及多个不同方和组织之间行动的业务运营，要求各方之间进行沟通并签订书面协议，明确各方的责任和期望、业务目标以及实现这些目标的环境。

## 实验室练习 3.03：互操作性协议

组织在其业务运营中关联第三方是很常见的。供应商、供货商和业务伙伴既带来风险也带来回报的机会。第三方风险管理需要采取必要的缓解措施，将风险保持在可接受的范围内。互操作性协议是实现这一目标的好方法。
