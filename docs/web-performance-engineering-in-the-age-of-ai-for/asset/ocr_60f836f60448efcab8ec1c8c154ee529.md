WordPress 5.7+ (released March 2021) enabled lazy loading for iframes by default by adding loading="lazy" to iframe embeds, which remains the default behavior in current versions. Make sure this hasn’t been disabled by your theme or plug-ins.

# Use updated official widgets

Some third-party features can be achieved via server-side solutions. For instance, instead of a JavaScript-powered “related posts” widget that fetches after page load, use a plug-in that computes related posts server side and outputs them directly, eliminating the need for an extra script call on client.

# Limit plug-ins

The simplest advice: fewer plug-ins generally means fewer third-party scripts. Audit your plug-ins and remove any that aren’t providing significant value. Sometimes multiple plug-ins add overlapping third-party tags; consolidate those if possible.

# Leverage caching/CDN

Many third-party scripts might be cached by the user’s browser if they visit multiple pages. Encourage caching by using a CDN or service worker for your static assets, and set the third-party scripts to expire in the far future (most do already, via their CDN).

# Use GTM carefully

If you’re using GTM on WordPress, remove any tags not in use, and configure triggers not to fire on pages where they’re not needed.

# Convert third-party content to first-party

Instead of embedding a YouTube video player, consider using a preview image that links to YouTube or a lightbox that loads the video on click. Or use plug-ins like Embed Privacy that implement facades for you, like a placeholder for YouTube, until the user gives consent or clicks.
