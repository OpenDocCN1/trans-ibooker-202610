function processWork(deadline) {
  // deadline.timeRemaining() tells you how much time you have
  while (deadline.timeRemaining() > 0 && workQueue.length > 0) {
    const task = workQueue.shift();
    processTask(task);

  // If more work remains, schedule another callback
  if (workQueue.length > 0) {

Even then, break larger jobs into small chunks and yield regularly so that new input and rendering work can run in between idle slices.

Load is mostly about keeping startup work (including microtasks) from delaying the moment when primary content appears and becomes interactive. Use RAIL as a checklist: anything that is not critical to initial response, animation, or load can usually be pushed into idle time.
