## 你将学到什么

本书采用以用户体验为先的方法，将高级优化技术建立在用户感知和交互网络的基本原理之上。你将学习：

- 为什么性能*就是*用户体验，了解人类感知阈值以及速度对业务的影响（第一部分）
- 如何衡量和解读现代性能指标，特别是核心网页指标（Core Web Vitals，LCP、INP、CLS），并以此指导优化工作（第一部分和第二部分）
- 浏览器如何获取资源、解析代码、渲染布局和绘制像素，为优化每个阶段提供基础（第二部分）
- 针对每个核心网页指标的具体、可操作的优化策略，解决加载、交互性和布局稳定性方面的常见瓶颈（第二部分）
- JavaScript 的固有成本——网络、解析、编译和执行——以及现代技术如代码拆分、懒加载、水合策略和调度 API 如何减轻这些成本（第三部分）
- AI 生成代码如何改变性能格局：为什么大型语言模型（LLM）输出往往“正确但不最优”，AI 生成前端的常见陷阱，以及你可以应用的具体审查和优化技术，以保持 AI 编写的代码快速、可访问且可维护（第一部分和第二部分）
- 如何与 AI 辅助工具本身协作：使用 Chrome DevTools 的 AI 功能、Lighthouse 和 Chrome DevTools 模型上下文协议（MCP）来分析跟踪、发现长时间任务，并在保持人工在环的情况下迭代有针对性的性能修复（第二部分）
- 如何有效识别、审计和优化无处不在的第三方脚本的性能影响——包括 AI 驱动的小部件和聊天机器人——使用移除、延迟加载、懒加载、门面、卸载（Web Worker 和服务器端）以及条件加载策略（第四部分）
- 如何利用实验室工具（Lighthouse、Chrome DevTools、WebPageTest）和现场监控（RUM、web-vitals 库）来持续诊断问题并跟踪改进（第二部分和第四部分）
- 性能优化如何通过各行业的实践案例研究转化为现实世界的成功（第五部分），包括团队如何随着 AI 生成代码和 AI 驱动体验变得更常见而调整其实践

## 书籍结构

本书分为五个部分，从基础概念逐步构建到具体挑战和实际应用：

第一部分，“性能即用户体验”

建立网页性能与用户满意度之间的关键联系。我们探讨人类对速度的感知、介绍以用户为中心的关键指标如核心网页指标，讨论为不同设备和网络条件设计的重要性，以及建立性能文化的意义。本部分还探讨了 AI 辅助开发如何改变工程工作流程，以及无论是谁——或什么——编写代码，延迟、响应性和稳定性等基本原则为何不可妥协。

第二部分，“人工智能时代的 Web 性能优化”

深入技术细节。我们首先介绍浏览器内部的工作原理（网络、渲染管道、调度），然后专门用章节优化每个核心网页指标（LCP、INP、CLS），包括具体技术、高级浏览器内部机制和必要的测量工具。我们随后将这些基础扩展到 AI 生成的前端和 AI 辅助工作流程：如何审查和加固 LLM 编写的 UI 代码，如何负责任地使用 DevTools 的 AI 分析和 MCP 驱动的代理，以及在 AI 建议或修改代码时如何保持核心网页指标作为事实来源。
