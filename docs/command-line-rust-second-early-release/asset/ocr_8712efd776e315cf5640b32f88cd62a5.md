+   2. When the values are the same, print one of them in column 3.
+   3. When the first value is less than the second, print the first value in column 1.
+   4. Otherwise, print the second value in column 2.
+   5. When there is only a value from the first file, print it in column 1.
+   6. When there is only a value from the second file, print it in column 2.
