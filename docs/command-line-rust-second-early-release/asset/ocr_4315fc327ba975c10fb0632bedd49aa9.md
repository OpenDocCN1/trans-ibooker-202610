The echo utility exits 0 on success, and >0 if an error occurs.

# STANDARDS

The echo utility conforms to IEEE Std 1003.1-2001 ('POSIX.1') as amended by Cor. 1-2002.

By default, the text printed on the command line is terminated by a newline character. As shown in the preceding manual page, echo has a single option -n that will omit the newline. Depending on the version of echo you have, this may not appear to affect the output. For instance, the BSD version I'm using shows this:

```
$ echo -n Hello
Hello
$ ①
```

① The BSD echo shows my command prompt $ on the next line.

While the GNU version on Linux shows this:

```
$ echo -n Hello
Hello$ ①
```

① The GNU echo shows my command prompt immediately after Hello.
