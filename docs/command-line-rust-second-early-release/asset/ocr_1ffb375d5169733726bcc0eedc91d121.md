# Getting Started

The name of the challenge program should be `cutr` (pronounced *cutter*, I think) for a Rust version of `cut`. I recommend you begin with `cargo new cutr` and then copy the `08_cut r/tests` directory into your project. My solution will involve the following crates which you should add to your *Cargo.toml*:

```
[dependencies]
clap = "2.33"
csv = "1"
regex = "1"

[dev-dependencies]
assert_cmd = "1"
predicates = "1"
rand = "0.8"
```

Run `cargo test` to download the dependencies and run the tests, all of which should fail.
