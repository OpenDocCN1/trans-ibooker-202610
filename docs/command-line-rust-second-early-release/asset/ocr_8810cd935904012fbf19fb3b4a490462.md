I'll be using the `Regex` module to match file and directory names, which means that the `--name` value must be a valid regular expression. Regex syntax differs slightly from file glob patterns as shown in Figure 6-1. For instance, the asterisk (`*`) in the file glob `*.txt` means *zero or more of any character* and the dot has no special meaning², so this will match files that end in `.txt`. In regex syntax, however, the asterisk means *zero or more of the previous character*, so I need to write `.*` where the dot (`.`) is a metacharacter that means *any one character*.
