# NOTE

Earlier I stressed how this input file had a varying number and type of whitespace separating words. I did this in case you chose to iterate over the characters to find word boundaries. That is, you might have not found `str::split_whitespace` and instead used an iterator over `str::chars`. If you increment the number of words every time you find whitespace assuming there is only one between words, you might end up overcounting words. Instead, you would need to find runs of whitespace as the delimiter between words. Similarly, you might have been tempted to use a regular expression which would also need to consider one or more whitespace characters.
