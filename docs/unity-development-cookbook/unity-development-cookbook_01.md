## 前言

欢迎阅读《Unity 开发食谱》第二版！在过去二十年里，实时 3D 和游戏开发工具不断发展壮大，越来越多的人从事从大型“三 A”游戏到单人业余时间制作的爱好者项目的各种项目。

我们非常兴奋能够更新这本书，并且为我们在这本书上的工作感到自豪。我们希望它能成为您使用 Unity 引擎进行软件开发的有用伴侣。自 2007 年我们开始使用 Unity 以来，Unity 已经走了很远，您使用得越多，就会想出更多关于如何使用它、为什么可以使用它的新想法！一切都非常令人兴奋。相信我们，我们经历过。

在 Secret Lab，我们使用 Unity 构建大多数视频游戏。我们最出名的是在澳大利亚制作儿童游戏、获得 BAFTA 和 IGF 奖的《夜晚的森林》（Finji），以及广受欢迎的 Yarn Spinner 工具。自从我们发现它以来，我们就从未停止使用 Unity。

在这本书中，我们汇集了一系列食谱，用于解决我们在使用 Unity 构建时反复遇到并解决的常见问题。这本书不会涵盖您想了解的关于 Unity 的每一件小事，但它希望涵盖了视频游戏开发日常工作中大部分内容。本书的第二版增加了大量新材料，基于自上一本书以来 Unity 采用的变化，以及对所有已更改内容的更新。Unity 并没有以惊人的速度发展，但保持领先很重要。

这些食谱都是关于我们希望在第一次使用 Unity 时有人可以询问的事情。我们真的希望它们能帮助您！

现在是使用 Unity 的激动人心时刻。实时和游戏开发世界每天都在变得更大、更有趣，我们使用的工具和技术比以往任何时候都更好。去创造伟大的事物吧！

## 本书组织

本书分为 13 章：

- 第 1 章“在 Unity 中工作”，介绍了使用 Unity 所需了解的基本概念：游戏对象、组件、场景，以及如何使用 Unity 编辑器本身。
- 第 2 章“脚本编写”，涵盖了 Unity 的脚本接口，即您编写实际代码以定义项目工作方式的方式。在建立基础之后，我们将深入研究一些实用示例，包括如何编写保存和加载系统，如何高效地处理对象，以及如何以代码和 Unity 都能轻松使用的方式存储数据。
- 在第 3 章“输入”中，您将学习如何以键盘输入、鼠标和游戏手柄的形式从用户获取输入。我们还将讨论如何设置对输入事件做出反应的游戏对象，例如用户点击它们。
- 第 4 章“数学”涵盖了游戏开发中了解有用的一些数学概念的基础，例如向量、矩阵和四元数。我们还将研究这些概念的一些实际用途，例如检测对象是否在玩家面前。
- 第 5 章“2D 图像”讨论了 Unity 内置的 2D 图像和物理系统。您将学习如何显示精灵，对它们进行排序，并使它们相互弹开。
- 第 6 章“3D 图像”涵盖了 Unity 的材质和着色系统：材质和着色器如何工作，如何在 Unity 中构建着色器，以及如何在场景中获得最佳效果。
- 在第 7 章“3D 物理和角色控制”中，您将学习如何让 Unity 的 3D 物理系统满足您的需求，以支持常见的游戏任务，例如拾取和投掷对象，以及创建玩家可以乘坐的移动平台。
- 第 8 章“动画和移动”介绍了 Unity 中使用的动画系统，并涵盖了诸如如何设置角色在不同动画状态之间混合，以及如何将玩家移动与角色动画集成等主题。我们还将介绍 Unity 中的摄像机系统，并讨论如何设置跟随目标移动的摄像机。
- 第 9 章“逻辑和游戏玩法”全部关于创建玩家交互的游戏玩法。这里有一系列常见的游戏玩法任务，例如管理您给玩家的任务状态，跟踪赛车是否走得太近，以及管理游戏中对象之间伤害的分配。
- 在第 10 章“行为、模拟和 AI”中，您将学习如何为角色添加大脑，包括检测何时可以看到玩家的能力、在空间中导航并避开障碍的能力，以及找出它们无法被看到的地方的能力。该章节还简要探讨了使用 Unity 进行模拟，使用机器学习技术实现真正的 AI。
- 第 11 章“声音和音乐”介绍了 Unity 中的音频系统。我们将介绍播放声音的基础知识，然后转向更高级的功能，例如将音频路由到多个组，以及在角色说话时自动降低音乐音量。
- 第 12 章“用户界面”涵盖了为玩家构建界面以供查看和交互的工具。本章还包含如何通过扩展编辑器在 Unity 中构建自己的工具的部分。
- 第 13 章“文件、网络和截图”，我们的最后一章，探讨了网络、从网络获取数据以及从代码保存截图。
