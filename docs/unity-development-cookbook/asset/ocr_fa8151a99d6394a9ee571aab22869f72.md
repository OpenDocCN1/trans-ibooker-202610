Now we'll set up the profile that determines what post-processing effects to apply. We'll set up this profile to apply a bloom effect:

+   1. Click the New button next to the Profile field. A new post-processing profile asset will be created. Select it.
+   2. In the Inspector, click Add Effect and choose Unity → Bloom. A new bloom effect will be added.
+   3. Click the All button to mark that you'd like to override all settings from their defaults. Set the Intensity to 5, and the Threshold to 1.1 (Figure 6-7).
