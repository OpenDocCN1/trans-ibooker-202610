Figure 6-5. Installing the Post-processing package

Next, we’ll set up the post-processing volume. This controls what post-processing effects are in place, and what their settings are:

+   1. Create a new, empty game object. Name it “Post Process Volume.”
+   2. Add a new Post-Processing Volume component to it.
+   3. Turn on the Is Global setting. The effect will apply to the camera no matter where it is.
+   4. At the top-right corner of the Inspector, change the Layer to PostProcessing (Figure 6-6).
