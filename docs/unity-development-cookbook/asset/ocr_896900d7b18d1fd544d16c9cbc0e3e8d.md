Note that when you start using an SRP, you’ll need to modify your materials to use shaders that are designed for the new pipeline. To do this, select your Materials in the Project tab, open the Edit menu, and choose Rendering → Materials → Convert Selected Built-In Materials to URP Materials.

# 6.10 Creating a Shader Using the Shader Graph

# Problem

You want to use Unity’s Shader Graph tool to create new shaders, with which you can create your own custom materials.

# Solution

Create a new shader by opening the Assets menu and choosing Create → Shader → URP → Lit Shader Graph. Name the new shader.

You’ll see a new shader graph with a single node (Figure 6-13). Click Save Asset, and your shader is ready for use in a material.

# Discussion

The Shader Graph is a visual tool for building shaders. Shaders are normally written in a language called ShaderLab, which describes the behavior of the shader to Unity, and also includes the specific instructions on how to perform the shading using a second language, Cg.
