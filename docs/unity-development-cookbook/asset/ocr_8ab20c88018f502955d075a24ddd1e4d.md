# Solution

To load a scene, you first need to tell Unity that you’d like to include that scene in your project. If you don’t, the scene won’t be included in any built versions, and you won’t be able to load it.

To manage the list of scenes in your project, open the File menu and choose Build Settings. The Build Settings screen will appear (Figure 9-1). To mark a scene as loadable, drag and drop it from the Assets folder in the Project tab into the list at the top of the screen.

![](bbox=[0.142, 0.263, 0.858, 0.689])

Figure 9-1. The scene list in the Build Settings screen, with two scenes added

You’re now ready to write code that loads a scene. To use the SceneManager class, which handles scene loading for you, you’ll need to include the following using directive at the top of your script:

```
using UnityEngine.SceneManagement;
```
