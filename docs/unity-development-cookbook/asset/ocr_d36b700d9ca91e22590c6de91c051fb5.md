We can test the agent by choosing Heuristic Only under Behavior Type in the Behavior Parameters component of the BallAgent. With this done, press Play and use the arrow keys to drive the ball agent around the scene. If you hit the target, the scene (and episode) should reset with the target in a new location.

Finally, we’ll train the agent:

+   1. Using your favorite text editor, create a new file called BallAgentConfig.yaml, and add the following:

```
behaviors:
  RollerBall:
    trainer_type: ppo
    hyperparameters:
      batch_size: 10
      buffer_size: 100
      learning_rate: 3.0e-4
      beta: 5.0e-4
      epsilon: 0.2
      lambd: 0.99
      num_epoch: 3
      learning_rate_schedule: linear
      beta_schedule: constant
      epsilon_schedule: linear
    network_settings:
      normalize: false
      hidden_units: 128
      num_layers: 2
    reward_signals:
      extrinsic:
        gamma: 0.99
        strength: 1.0
    max_steps: 500000
    time_horizon: 64
    summary_freq: 10000
```

+   2. Train the agent by running mlagents-learn path/tp//BallAgentConfig.yaml --run-id=BallAgent1.

![](bbox=[0.13, 0.74, 0.25, 0.83])

You can use Tensorboard to monitor the training by running tensorboard --logdir results --port 6006.

Once the agent has completed training (this might take some time, depending on the power of your machine), you can drag the resulting .nnx model into the appropriate slot of the agent’s Inspector, and run it again using the trained model.
