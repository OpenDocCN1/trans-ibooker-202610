# 12.9 Attribute Drawers

# Problem

You want to customize how the Inspector draws a type of variable when a certain attribute is attached to it. For example, the Header attribute causes Unity to draw a label above a variable in the Inspector.

# Solution

We’ll add an attribute that lets you draw a help box above variables, like so:

```
public class HelpBoxDemo : MonoBehaviour {

    [HelpBox(text = "Here's a help box above the variable!")]
    [SerializeField] int integer;

}
```
