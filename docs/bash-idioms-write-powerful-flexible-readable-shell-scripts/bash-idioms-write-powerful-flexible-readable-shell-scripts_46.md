## 关于作者

Carl Albing 是一名教授、研究员和软件工程师，拥有丰富的行业经验。他是 O’Reilly《bash Cookbook》和《Cybersecurity Ops with bash》的合著者，也是 O’Reilly《Great bash》视频的作者，Carl 在大大小小的公司、多个行业中使用 bash 和许多其他语言进行软件开发。他拥有数学学士学位、国际管理硕士学位和计算机科学博士学位。

JP Vossen 自 80 年代初就开始使用计算机，自 90 年代初起从事 IT 行业，自 90 年代末起专注于信息安全。他自从第一次了解 autoexec.bat 就对脚本和自动化着迷，并在 90 年代中期发现 Linux 上 bash 和 GNU 的强大和灵活性后感到欣喜。他曾为《Information Security Magazine》和 SearchSecurity 等出版物撰稿。在他不使用电脑的少数时刻，他通常是在拆卸某物、组装某物，或两者兼而有之。
