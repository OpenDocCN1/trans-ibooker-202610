# bash Linter

Using a linter instead of or in addition to a style guide can also be handy. To be honest, we don’t use one, but we thought we should cover it. The one we know about is shellcheck, and we have mixed feelings about the results; it’s especially picky about quoting, and we don’t always agree with its suggestions on quoting or in general, but those things are somewhat adjustable. That said, it’s still very cool, and worth checking out.
