

然而，这会受到竞态条件的影响，而且显然是一个简单的模式。它在某种程度上是可预测的，但有时你想知道是什么代码在污染 $TMP。不要忘记设置一个陷阱（参见第 97 页的“It’s a Trap!”）来清理你自己的残留物。我们建议你考虑使用 mktemp，不过这是一个超出 bash 惯用法范围的大问题。

## $RANDOM 和 dash

$RANDOM 在 dash 中不可用，而 dash 在某些 Linux 发行版中是 /bin/sh。值得注意的是，当前版本的 Debian 和 Ubuntu 使用 dash，因为它比 bash 更小更快，从而有助于更快启动。但这意味着 /bin/sh，这个曾经是 bash 的符号链接，现在改为指向 dash，各种 bash 特定功能将无法工作。它在 Zsh 中是可以工作的。

## 命令替换

我们在第 2 章中已经大量使用了命令替换，但我们还没有谈论过它。旧的 Bourne 方式是使用 ``（反引号/反引号），但我们更喜欢更易读的 POSIX $( )。你会看到这两种形式很多，因为这就是你将输出拉入变量的方式；例如：

```
unique_lines_in_file="$(sort -u "$my_file" | wc -l)"
```

请注意，这两者是相同的，但第二个是内部的并且更快：

```
for arg in $(cat /some/file)
for arg in $(</some/file)    # Faster than shelling out to cat
```

## 命令替换

命令替换对于云和其他 DevOps 自动化至关重要，因为它允许你收集并使用仅在运行时才存在的各种 ID 和详细信息；例如：

instance_id=$(aws ec2 run-instances --image $base_ami_id ... \

state=$(aws ec2 describe-instances --instance-ids $instance_id \

## 嵌套命令替换

使用 `` 嵌套命令替换会变得非常丑陋，很快，因为你必须在每一层嵌套中转义内部的反引号。如果可以的话，使用 $( ) 会容易得多，如下所示：

```
### Just Works
$ echo $(echo $(echo $(echo inside)))
inside
```

```
### Broken
$ echo `echo `echo `echo inside```
echo inside
```

```
### "Works" but very ugly
$ echo `echo \`echo \\\`echo inside\\\`\`

```

## 风格和可读性：回顾

在 bash 中引用变量时，你有机会在设置或检索值时编辑该值。变量引用末尾的几个特殊字符可以从字符串值的开头或结尾删除字符，改变其字符为大写或小写，替换字符，或仅给你原始值的子字符串。这些方便功能的常见使用导致了默认值的惯用法，basename 和 dirname 的替代，以及在不使用显式 if 语句的情况下创建逗号分隔列表。

变量替换是 bash 中的一个很棒的功能，我们建议充分利用它们。然而，我们也强烈建议你对这些语句进行注释，以明确你试图进行的替换类型。你的代码的下一个阅读者会感谢你的。

## 表达式和算术

Bash 提供了许多不同的做同一件事的方法——以及一些几乎相同的语法来做非常不同的事情。通常，这只是几个特殊字符的区别。我们已经看到 ${VAR} 和 ${#VAR}，其中第一个表达式返回变量的值，但第二个返回其字符串长度（“Variable Reference”第 31 页）。或 ${VAR[@]} 和 ${VAR[*]} 及其引号差异（“Quotes and Spaces”第 14 页）。

其他 bash 惯用法可能会让你想知道：什么时候应该使用两组或仅一组方括号？甚至不用？$(( ... )) 和 (( ... )) 有什么区别，如果有的话？通常，符号在其各种用途中都有某种共同含义，这暗示了语法背后的一定程度的合理性。有时表达式的选择更多是出于历史原因。让我们看一下，看看我们是否可以解释一些这些惯用模式和算术表达式。

## 仅限整数

bash shell 仅使用整数算术。它的主要目的是计数：迭代次数、文件数量、字节大小。如果你想要或需要浮点计算怎么办？毕竟，sleep 命令现在允许分数值：sleep 0.25 将休眠四分之一秒。如果你想休眠四分之一秒的倍数怎么办？你可能想写 sleep $(( 6 * 0.25 ))，但这行不通。

最简单的解决方案是使用 bc 或 awk 等其他程序进行计算。例如，这里有一个名为 fp 的脚本，你可以将其放在你的 ~/bin 目录或 PATH 上的其他位置（并赋予其执行权限）：

```
# /bin/bash -
# fp - provide floating point, via awk
# usage: fp "expression"

awk "BEGIN { print $* }"
```

有了它，你就可以写 sleep $(fp "6 * 0.25") 来获得所需的浮点计算。它可能不是 bash 在做计算，但它是 bash 帮助你完成计算。

## 算术

虽然 bash 在很大程度上是一种面向字符串的语言，但每当你在 bash 中看到双括号时，就意味着正在进行算术求值——使用整数而不是字符串的算术。这对你来说很熟悉，来自使用双括号的 for 循环变体：

```
for ((i=0; i<size; i++))
```

请注意，我们在双括号内使用变量名时不需要使用 $。这在 bash 中使用双括号时始终如此。那么我们还在哪里找到双括号的使用？

首先，我们可以使用美元符号和双括号对 shell 变量执行算术计算以创建值，如下所示：

```
max=$( ( intro + body + outro - 1 ) )
median_loc=$( ( len / 2 ) )
```

再次注意，变量在双括号内使用时不需要美元符号引用。

其次，考虑双括号的这种用法：

```
if (( max - 3 > x * 4 )) ; then
    # Do something here
fi
```

这次我们使用的是没有前导美元符号的双括号。为什么？有什么不同？

在第一种情况下，对于变量赋值，我们想要表达式的值，所以就像使用变量一样，美元符号表示我们想要值。在第二种情况下，if 语句，我们不使用美元符号，因为我们只需要做出决定的 true/false 布尔值。如果双括号内（没有美元符号）的表达式是非零值，则括号表达式的返回状态为 0——在 bash 中被认为是“真”。否则，返回状态为 1（在 bash 中为“假”）。

请注意我们说“返回状态？”那是因为没有美元符号的双括号在语法上被使用，就好像你正在执行一个或多个命令一样。它不会返回一个值供你分配给变量。然而，你可以在某些情况下使用它为变量分配新值，因为 bash 支持一些 C 语言风格的赋值运算符。以下是一些示例。这些是完整的 bash 语句，每行一个：

```
(( step++ ))
(( median_loc = len / 2 ))
(( dist *= 4 ))
```

每个语句都在执行算术求值，但在每种情况下，赋值也在求值的一部分中发生。表达式不会返回任何值，只有返回状态——你可以在每个语句执行后在 $? 变量中检查它。

你能用美元符号-双括号语法写出前一个示例中的那三个计算吗？看起来更熟悉的写法是：

```
step=$(( step + 1 ))
median_loc=$(( len / 2 ))
dist=$(( dist * 4 ))
```

我们不想单独写一行 $((step++))，因为该表达式将返回一个数值——shell 然后会将其视为要执行的命令的名称。如果 step++ 计算为 3，shell 随后会查找名为 3 的命令。
