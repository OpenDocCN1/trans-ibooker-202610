## 序言

bash Idioms 封面上的动物是琴蛤（Harpa articularis）。通常被称为有节琴蛤，它是 Harpidae 科的一种海螺。Harpidae 科约有 55 个物种，其中大多数分布在印度-太平洋地区，只有两个物种分布在下加利福尼亚半岛沿岸的海水中。这种特定物种 Harpa articularis 分布于印度洋和南太平洋的浅水中，包括斐济和澳大利亚海岸。该物种以其贝壳精致的波浪状图案和颜色而闻名，大小在 50 至 110 毫米之间。

Harpidae 科可以通过其光滑抛光的外表面来识别。贝壳上沿长度方向有强壮的肋，孔口大而喇叭状，底部有缺口。它们没有厣（一种类似活门的片状结构，可防止螺内部的动物干涸）。相反，动物的巨大足部会延伸到贝壳边缘之外。

琴蛤是夜行性捕食者。白天它们埋在沙中，夜间出来捕食螃蟹和虾。它们通过用足覆盖猎物并将其包裹在黏液中来捕食。反过来，它们可能成为更大的螃蟹、鱼类和捕食性软体动物的猎物。为了自卫，琴蛤使用一种非常有趣的防御技术：它有能力切断足部的后部，该部分会继续蠕动并分散捕食者的注意力，而琴蛤本身则悄悄爬走。
