# bash Idioms

Shell 脚本无处不在，尤其是使用 bash 兼容语法的脚本。但这些脚本可能复杂且晦涩。复杂性是安全的敌人，但它也是可读性和理解性的敌人。本实践书籍将教你如何解读旧的 bash 代码，并编写尽可能清晰易读的新代码。

作者 Carl Albing 和 JP Vossen 展示了如何利用 shell 的强大功能和灵活性为己所用。你可能已经掌握足够的 bash 知识来应付日常工作，但本书将把你的技能从可管理提升到卓越。无论你使用 Linux、Unix、Windows 还是 Mac，你都将学会像专家一样阅读和编写脚本。未来的你会感谢现在的你。

你将探索应使用和应避免的清晰惯用法，以便：

- 以优雅的风格编写实用、灵活且可读的 bash 代码
- 解码 bash 代码，例如 `${MAKEMELC,,}` 和 `${PATHNAME##*/}`
- 在自动化任务时节省时间并确保一致性
- 发现 bash 惯用法如何让你的代码更简洁干净
