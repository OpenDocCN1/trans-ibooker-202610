4 The end-of-help marker is also indented with a tab to match the rest of the contents.

5 We can debate if exit code (“Exit Codes” on page 96) exit 0 for success or exit 1 (really anything greater than zero) for failure is correct there. If we asked for help, then we just got it, and it worked, so exit 0. But if we failed to provide the correct arguments, then we failed, so exit 1. Also, the script failed to actually do anything useful beyond showing a message, so that’s arguably an exit 1 fail. Pick a standard and go with it, but exit 1 is a better fail-safe.

We’ve also inlined the help/usage message here, but it sometimes makes sense for that to be its own function so you can call it from other places if needed, as we’ll see in Example 8-4.
