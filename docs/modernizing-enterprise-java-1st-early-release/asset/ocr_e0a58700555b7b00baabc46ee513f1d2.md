# API driven

The Microservices *mantra* is API-first. If you take a look again at Figure 6-1, you’ll notice that splitting a monolithic app into a bunch of microservices leads to the first challenge: how to let these pieces of software communicate with each other? In Monoliths, you rely on the app scope of modules, packages. Microservices usually communicate with each other via REST calls, where each one can be either producer or consumer of services.
