# JKube

[Eclipse JKube](https://www.eclipse.org/jkube/), a community project supported by the Eclipse Foundation and Red Hat, is another open source Java framework to help interacting with Kubernetes from a Java developer perspective. It supports building container images using Docker/Podman, Jib and Source-2-Image. Eclipse JKube also provides a set of tools to deploy automatically to Kubernetes, and manage the application with helpers for debugging and logging. It comes from Fabric8 Maven Plugin, as rebranded and enhanced project to target Kubernetes.
