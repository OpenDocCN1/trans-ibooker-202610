```
successThreshold: 1
failureThreshold: 3
```

+   1 Name for the Deployment object.
+   2 The label for this object.
+   3 The desired number of Pod replicas.
+   4 The selector to find which Pods to manage using labels.
+   5 The Pod template to use, including labels to inherit or containers to create.
+   6 The container image to use
+   7 Kubernetes uses readiness probes to know when a container is ready to start accepting traffic and a Pod is considered ready when all of its containers are ready. Here we define an HTTP health check on the root path as a readiness probe.
+   8 Kubernetes uses liveness probes to know when to restart a container. Here we define an HTTP health check on the root path as a liveness probe.
