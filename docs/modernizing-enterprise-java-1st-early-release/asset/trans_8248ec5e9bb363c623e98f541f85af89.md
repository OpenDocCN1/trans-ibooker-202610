除非您在过去几年中深居简出，否则您不可能没有注意到企业世界正在向采用云技术迈进。这包括微服务、Kubernetes、Linux 容器等方法。然而，尽管 Java 已成为企业开发人员二十多年的主力，但它在这一新的云世界中扮演重要角色却并不总是显而易见。Java 及其构建的框架和技术栈通常被视为单体、启动缓慢、消耗大量内存或磁盘空间，而 Java 本身的动态特性似乎与 Kubernetes 的不可变性假设相悖。对于数以百万计的 Java 开发人员来说，这可能是一个严重问题，尤其是如果我们需要在另一种语言中重建 Java 生态系统——IDE、第三方库等——这些年来帮助开发人员变得极其高效。

幸运的是，Java 社区的开发人员和厂商已正面迎接云原生 Java 的挑战。Java 语言、框架等的变更已被迅速做出并采用，使 Java 开发人员能够将技能带到这一新前沿。这些技术包括 Quarkus、GraalVM、Eclipse Vert.x、Spring Boot 和 OpenJDK。然而，在云环境中高效使用它们并不总是显而易见。CI/CD 在其中扮演什么角色？Linux 容器镜像和 Kubernetes 呢？微服务的监控、可观测性、健康检查，以及更多内容，对最有经验的开发人员来说也可能显得令人生畏。幸运的是，在本书中，Markus 和 Natale 提供了答案。在这些页面中，您将踏上一段理解和欣赏之旅，了解 Java 世界正在发生什么以更好地拥抱云，以及云中那些可能不熟悉却对确保分布式微服务良好运行至关重要的技术。无论您是经验丰富的 Java 开发人员还是相对新手，本书都是您进入云及更远之旅的绝佳起点！

*Mark Little, Vice President, Middleware Engineering, Red Hat*
