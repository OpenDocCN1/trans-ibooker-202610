Every object in Kubernetes contains the following values.

+   - **apiVersion**: Kubernetes API version used to create this object
+   - **kind**: The object type (e.g. Pod, Service)
+   - **metadata**: Pieces of information that help uniquely identify the object, such as a name or UID
+   - **spec**: The desired state for the object

We defined in this section the basic structure of any Kubernetes objects. Let’s explore now the fundamental objects to run applications on top of Kubernetes.

# Pod

A Pod is a group of one or more containers, with shared storage and network resources, and a specification for how to run the containers³.
