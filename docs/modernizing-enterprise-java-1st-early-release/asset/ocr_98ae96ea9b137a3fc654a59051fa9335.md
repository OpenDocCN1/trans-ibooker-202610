The API-driven, pluggable architecture of Kubernetes, enables external tools at ease to provide an ecosystem of software and utilities that reminds, but also extend the application server model for Java enterprise. Essentials tasks such as logging, monitoring or debugging apps are provided in a way that fits the cloud native model, where apps are ubiquituous, and can run in multi places and multiple clouds at the same time.
