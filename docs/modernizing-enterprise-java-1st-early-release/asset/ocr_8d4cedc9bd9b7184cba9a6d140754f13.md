# From public to private. Why clouds?

The differences between public clouds, private clouds, hybrid clouds, and multi clouds were once easily defined by location and ownership. Today, these two are no longer the only relevant drivers for the classification of clouds. Let’s start with a more comprehensive definition of the different target environments and why they are used.

A public cloud environment is usually created from resources not owned by the end-user that can be redistributed to other tenants. Private cloud environments solely dedicate their resources to the end-user, usually within the user’s firewall, data-center, or sometimes on-premises.
