Let’s create a Quarkus function inside the `coolstore` namespace that you created in the previous sections.

An example of a Quarkus function is listed below, which you can find in this [book’s GitHub repository](book’s GitHub repository).

To create a new Quarkus function, run this command specifying the -l option to select the language as follow:

```
$ func create -l quarkus quarkus-faas
```

You should get a similar output:

```
Project path: /home/bluesman/git/quarkus-faas
Function name: quarkus-faas
Runtime: quarkus
Trigger: http
```

This created a skeleton of a Maven project for Quarkus, with a POM file containing all dependencies needed.
