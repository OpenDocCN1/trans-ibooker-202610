## About the Author(s)

**Markus Eisele** 是 Red Hat 在 EMEA 的开发者采用项目负责人。他在不同厂商的 Java EE 服务器上工作超过 14 年，并在国际 Java 大会上就其最喜爱的主题发表演讲。他是 Java Champion、前 Java EE 专家组成员，以及德国第一大 Java 大会“JavaLand”的创始人。他热衷于教育开发者如何使微服务架构能够集成并补充现有平台，以及如何成功地使用 Java 和容器构建弹性应用。他也是 O’Reilly 出版的 [Modern Java EE Design Patterns](https://www.oreilly.com/library/view/modern-java-ee/9781449370176/) 和 [Developing Reactive Microservices](https://www.oreilly.com/library/view/developing-reactive-microservices/9781491969290/) 的作者。你可以在他的 [Twitter feed](https://twitter.com/myfear) 上关注更频繁的更新，并在 [LinkedIn](https://www.linkedin.com/in/myfear/) 上与他联系。

**Natale Vinto** 是一名软件工程师，在 IT 和 ICT 技术方面拥有超过 10 年的专业经验，并在电信和 Linux 操作系统方面具有扎实的背景。作为一名具有 Java 开发背景的解决方案架构师，他曾在 Red Hat 担任 EMEA OpenShift 专家解决方案架构师多年。今天 Natale 是 Red Hat 的 OpenShift 开发者倡导者，帮助社区和客户在 Kubernetes 和云原生战略方面取得成功。你可以在他的 [Twitter feed](https://twitter.com/nvinto) 上关注更频繁的更新，并在 [LinkedIn](https://www.linkedin.com/in/nvinto/) 上与他联系。
