## Colophon

*Modernizing Enterprise Java* 封面上的动物是驴羚 *Equus hemionus*，又称半驴或亚洲野驴。

驴羚在外观上与许多野生驴相似，但体型略小，毛色较浅，有一条浅棕色的背纹。它们分布于蒙古至沙特阿拉伯，以及最北至俄罗斯南部和哈萨克斯坦，栖息于沙漠的平坦地区及其周围的山麓。在这种恶劣的环境中，驴羚的饮食由稀少的草、灌木、草本植物和树叶组成，但它们必须靠近开阔的水源。

与马不同，驴羚不容易被吓到，天性好奇。这使它们特别容易受到猎人的伤害——过去人类曾猎杀驴羚获取肉和皮毛。自 1971 年伊朗开始，驴羚成为受保护物种，全年禁止猎杀。尽管努力遏制人类捕猎，据估计野外仅剩下 395 只成年驴羚。

O’Reilly 封面上的许多动物都濒临灭绝；它们对世界都很重要。
