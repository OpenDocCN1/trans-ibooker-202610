
## 先决条件

云服务提供商提供托管的 Kubernetes 服务，具体取决于您通常使用的环境。请查看以下内容：

- Amazon Elastic Kubernetes Service (EKS; [https://aws.amazon.com/eks/](https://aws.amazon.com/eks/))
- Azure Kubernetes Service (AKS; [https://learn.microsoft.com/en-us/azure/aks/](https://learn.microsoft.com/en-us/azure/aks/))
- Google Kubernetes Engine (GKE; [https://cloud.google.com/kubernetes-engine](https://cloud.google.com/kubernetes-engine))

您还需要以下 CLI 工具：

- `kubectl`—通过 Kubernetes 文档中的说明进行安装（[https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)）。
- `eksctl`—按文档中所述进行安装（[https://github.com/eksctl-io/eksctl#installation](https://github.com/eksctl-io/eksctl#installation)）。
- `Helm`—根据文档进行安装（[https://v3-1-0.helm.sh/docs/intro/install/](https://v3-1-0.helm.sh/docs/intro/install/)）。
- `jq`—通过文档进行安装（[https://jqlang.github.io/jq/download/](https://jqlang.github.io/jq/download/)）。
- `curl` and `watch`—应可在您的系统上使用；否则，请参阅您的 Linux 发行版或 Windows 文档。

我建议在数据平面中至少准备两个中等大小的节点。例如，我使用的是 EKS，拥有一个三节点集群，使用 `t2.large` ([https://instances.vantage.sh/aws/ec2/t2.large](https://instances.vantage.sh/aws/ec2/t2.large)) EC2 实例（每个节点具有两个 vCPU 和 8 GB RAM）。

要配置 EKS 集群，我使用 `eksctl` ([https://eksctl.io/](https://eksctl.io/)) 并使用配置文件 `otel-demo-cluster.yaml`，如下所示。

### 列表 A.2 EKS 集群配置

```
apiVersion: eksctl.io/v1alpha5
kind: ClusterConfig
metadata:
  name: otel-demo
  region: eu-west-1      ❶
  version: "1.24"
iam:
  withOIDC: true         ❷
nodeGroups:              ❸
- name: default-mng
  instanceType: t2.large
  desiredCapacity: 3
cloudWatch:              ❹
  clusterLogging:
    enableTypes: ["*"]
```

❶ 请确保将其设置为您的区域（此处为爱尔兰都柏林，`eu-west-1`）。

❷ 这将配置 OIDC 提供程序，以便您可以附加 IAM 策略，例如，如果您想更改 OpenTelemetry collector 配置，将指标发送到 Amazon Managed Service for Prometheus 或将跟踪发送到 AWS X-Ray。

❸ 数据平面——三个 `t2.large` EC2 实例

❹ 在 CloudWatch 中启用控制平面日志记录

然后，按如下方式配置并启动 EKS 集群：

```
$ eksctl create cluster -f otel-demo-cluster.yaml
```

等待 10 到 15 分钟，然后验证（根据您的设置，您可能会看到更少的节点）：

```
$ kubectl get nodes
NAME               STATUS   ROLES    AGE     VERSION
ip-1..7.eu-west-1  Ready    <none>   2d23h   v1.24.10-eks-48e63af
ip-1..4.eu-west-1  Ready    <none>   3d14h   v1.24.10-eks-48e63af
ip-1..1.eu-west-1  Ready    <none>   2d23h   v1.24.10-eks-48e63af
```

现在，我们准备进行演示演练。

## A.3 演示演练

首先，我们将安装 OpenTelemetry 演示。安装后，我们就可以使用它了！

### A.3.1 安装演示

使用以下命令安装演示。首先，我们需要添加演示的 Helm 仓库，如下所示：

```
$ helm repo add open-telemetry \
       https:/ /open-telemetry.github.io/opentelemetry-helm-charts
```

现在，我们可以安装演示：

```
$ helm install my-otel-demo \
       open-telemetry/opentelemetry-demo
```

### A.3.2 使用演示

要从本地机器使用演示（例如访问 Grafana UI），您首先需要将 Kubernetes 集群的网络流量转发到您的机器。

首先，我们将公开 `frontendproxy` 服务。使用以下命令实现此操作：

```
kubectl port-forward \
        svc/my-otel-demo-frontendproxy 8080:8080
```

为了从本地浏览器正确收集 spans，您还需要公开 OpenTelemetry collector（`4318` 是 OTLP 端口）：

```
kubectl port-forward \
        svc/my-otel-demo-otelcol 4318:4318
```
