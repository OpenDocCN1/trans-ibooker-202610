# EXERCISE 3.18

Write a function filter that removes elements from a list unless they satisfy a given predicate. Use it to remove all odd numbers from a List<Int>.

```
fun <A> filter(xs: List<A>, f: (A) -> Boolean): List<A> =
    foldRight(
        xs,
        List.empty(),
        { a, ls ->
            if (f(a)) Cons(a, ls)
            else ls
        })
```
