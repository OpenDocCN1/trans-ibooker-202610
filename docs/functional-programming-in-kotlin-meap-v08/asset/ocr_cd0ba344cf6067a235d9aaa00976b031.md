```
val unwieldy: Option<Option<String>> =
    lookupByName("Tim").map { it.manager }
```

When we apply flatMap, it will first map, then flatten the result¹⁹ so that we are left with a more useful Option<String> representing Tim’s manager. That can then in turn be dealt with by getOrElse for a more tangible result.

```
val manager: String = lookupByName("Tim")
    .flatMap { it.manager }
    .getOrElse { "Unemployed" }
```
