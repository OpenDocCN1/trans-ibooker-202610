```
flatMap(None) { a: A -> Some(a) } == None
None == None

Some(v) == Some(v)

flatMap(Some(None)) { a -> Some(a) } == Some(None)

flatMap(Some(Some(v))) { a -> Some(a) } == Some(Some(v))
```
