```kotlin

data class Leaf<A>(val value: A) : Tree<A>()

data class Branch<A>(
    val left: Tree<A>,
    val right: Tree<A>
) : Tree<A>()

TIP
Kotlin provides a handy builtin function called `maxOf` which determines the maximum of two values. For example, the maximum of x and y can be determined by `maxOf(x, y)`.
