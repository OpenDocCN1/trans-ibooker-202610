# [2021 IEEE 国际图像处理会议 (ICIP) (美国阿拉斯加安克雷奇 2021.9.19-2021.9.22)] 2021 IEEE 国际图像处理会议 (ICIP) ｜｜ 身份无关的面部表情








## ABSTRACT

提出了一种新颖的无身份条件生成对抗网络（IF-GAN）用于面部表情识别（FER），以显式减少由身份相关面部属性如年龄、种族和性别引起的高个体间差异。作为端到端系统的一部分，设计了一个 cGAN 将给定的输入面部表情转换为具有与输入相同表情的“平均”身份面部。然后，无身份 FER 成为可能，因为生成的图像具有相同的合成“平均”身份，仅在显示的表情上有所不同。在四个面部表情数据集上的实验，其中一个包含自发表情，表明 IF-GAN 超过了基线 CNN 并实现了 FER 的最先进性能。

Index Terms— 面部表情识别, 面部表情生成, 卷积神经网络, 生成对抗网络
