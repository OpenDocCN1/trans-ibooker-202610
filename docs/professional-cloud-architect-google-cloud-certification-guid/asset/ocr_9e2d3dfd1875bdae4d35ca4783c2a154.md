+   - **External read replica**: This replicates to a MySQL instance that is external to Cloud SQL. It can help reduce latency if you are connecting from an on-premises network and also offers a migration path to other platforms.
+   - **Replication from an external server**: This is where an external MySQL instance is the master and is being replicated into Cloud SQL. This also offers data replication to GCP.
