**Tensor Processing Units (TPUs)** are custom-developed application-specific integrated circuits designed using Google's experience in **Machine Learning (ML)** and can be used to maximize performance and flexibility in building TensorFlow compute clusters and other ML workloads. We can access TPUs from the navigation menu and go to **Compute Engine | TPUs**. Once we enable the API, we can create our first TPU node. From the following screenshot, you can see that we can assign **Zone**, **TPU type**, **TPU software version**, **Network**, and **IP address range**. The TPU should be in the same zone as the Compute Engine instance you wish to connect from:
