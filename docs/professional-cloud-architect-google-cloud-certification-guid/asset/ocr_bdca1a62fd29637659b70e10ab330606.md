# Always denied rules

There are also types of traffic that are always blocked, as follows:

+   - GRE traffic
+   - Protocols other than TCP, UDP, ICMP, AH, ESP, SCTP and IPIP
+   - Egress SMTP traffic on TCP port 25

# User-defined rules

Finally, user-defined rules are the rules that you would define to allow communication that's needed for your application that does not match the default, always allowed, or implied rules:
