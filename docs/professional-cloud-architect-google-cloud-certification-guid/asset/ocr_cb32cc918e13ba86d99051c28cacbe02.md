# GKE dashboard

> Tip
> Note that at the time of writing this book, Google Cloud's operations suite for GKE is available only for GKE clusters running on Google Cloud. This means that it does not include GKE clusters running on-premises or bare-metal servers.

The GKE dashboard is a single pane of glass for the most important metrics for the GKE clusters, including the following:

+   - Timeline with opened alerts for the GKE clusters
+   - Metrics such as CPU, memory, and disk utilization for the namespaces, nodes, workloads, services, pods, and containers
+   - Logs for pods and containers:
