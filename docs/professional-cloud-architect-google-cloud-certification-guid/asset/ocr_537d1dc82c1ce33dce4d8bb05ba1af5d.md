# Network Connectivity Center

Network Connectivity Center is a hub-and-spoke model for managing our network connectivity in Google Cloud. It allows us to connect our on-premises or other public cloud networks together using Google’s network as a Wide Area Network (WAN) for data transfer. Using this service enables access to the global range and reliability of Google’s network.
