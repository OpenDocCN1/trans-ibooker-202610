# Pricing

Bigtable charges based on several factors:

+   - Instance types are charged per hour, per node.
+   - Storage is charged per month and costs vary, depending on the use of SSD or HDD.
+   - Internet egress rates are charged depending on monthly usage. Ingress traffic is free.

For more specific details, please see the Bigtable pricing URL in the *Further reading* section.
