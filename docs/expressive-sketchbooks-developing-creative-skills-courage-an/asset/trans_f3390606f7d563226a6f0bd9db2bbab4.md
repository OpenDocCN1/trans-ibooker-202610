# 引言

## 什么是表意素描本？

### 培养你的创造力
一个表意素描本是你想象力的游乐场——一个培养创造力并发展你自己艺术风格的地方。在这本书中，我提供了许多指引来照亮你的道路，帮助你打造一本独一无二的素描本。
这本书关于探索你创造的召唤，并将那些想法引导到纸面上。它关于帮助你创作出只有你才能创造的艺术。
请记住，你的素描本不会充满完美无瑕的绘画或完美的结果。但有时凌乱而充满欢乐的实验将为发现和完善你自己的视觉风格和艺术声音铺平道路。请记住，素描本是你发展艺术实践的地方，而不是你完全成形的地方。它们是艺术旅程的一部分；它们不是最终目的地。

![图像](images/f0006-01.jpg)
通过创作和实验变得自信。通过更频繁地创作艺术，你所做的艺术会有所提升。

![图像](images/f0007-01.jpg)
探索对你重要的主题和想法。素描本是一个安全的尝试之地，让你更深入了解自己的兴趣和着迷之处。

### 将艺术融入生活
一本优秀的素描本无关完美的结果。它关乎通过实践学习和成长。素描本是一个让你对自己的创造力更有信心、更勇敢的安全之地。它也是你发展一种能点亮你的艺术方法和过程的地方，让你充满能量和热情。把你的素描本看作与自己进行创造性对话的地方。

![图像](images/f0007-02.jpg)
通过创作更多艺术变得更有灵感。不要等待感觉准备好才开始；通过开始并采取行动，我们才变得准备好。

### 实验与发现
素描本除了实验和发现之外没有规则。我们通过创作变得富有创造力。你的素描本可能包含很少的实际素描。对一些人来说，素描本可能完全是关于写生，而对另一些人来说，它是关于探索色彩和构图，或记录想法、记忆或概念。我希望这本书能给你一点创造性的火箭燃料，让你在自己的艺术方向上起飞。

![图像](images/f0008-01.jpg)
让你的素描本独属于你。它必须反映你这个人，并成为一个你可以探索与你产生共鸣的主题和题材的地方。

![图像](images/f0008-02.jpg)
素描本是一场艺术冒险。尝试不同的方法，并在过程中发现和揭示你的艺术声音。

![图像](images/f0009-01.jpg)
我的素描本看起来就像我做的。你的素描本将包含反映你的页面，它们看起来就像你做的。

![图像](images/f0009-02.jpg)
素描本是创作具有个人价值的艺术的地方。

# 第1章

## 魔力与动力
为什么要发展你自己的素描本练习？坚持素描本将帮助你培养自己的自我表达和创造力。本章旨在帮助你拆解可能阻碍你创造力的任何障碍和壁垒。它还将帮助你了解开始素描本的原因以及你希望素描本成为什么。寻找有关如何反思和记录你的艺术兴趣和灵感的技巧。

![图像](images/f0010-01.jpg)

### 开始素描本的理由
你现在可能没有意识到，但使用素描本可以提升生活。素描越多，你就越邀请创造性的炼金术进入你的生活。以下是开始你自己的素描本（或在感到卡住时继续）的几个原因。

![图像](images/f0012-02.jpg)![图像](images/f0012-01.jpg)
在素描本中玩耍以发展艺术技能。素描本是学习和成长的地方——它不会充满完美无瑕的杰作。有些页面看起来会像一团乱，但这无关紧要。

#### 探索想法
你的素描本是你理解、发展和探索你的艺术兴趣或执念的绝佳场所。拆解是什么让你对艺术和生活感到好奇，并将这些想法素描在页面上。在发展素描本的过程中，你将头脑或心中的想法带到纸上使其活起来。

![图像](images/f0013-01.jpg)
素描本提供了发现模式和反复出现的主题的机会。这两页素描本相隔数年创作。注意在图案背景上使用白色花卉剪影。通过翻阅旧素描本，你可以发现反复出现的主题并找到联系。

#### 记录你的创作之旅
用素描本记录你的创作觉醒。把你的素描本看作你在艺术旅程中的朋友和伴侣。

![图像](images/f0013-02.jpg)
素描本是理解和探索是什么让你好奇的地方。拿一个想法的萌芽并扩展和探索它。

#### 私密/安全之地
你的素描本是为你准备的。它可以是一个私密和个人的游乐场。你不必与任何人分享。你不需要展示其内容或将其挂在墙上。如果你愿意，你可以合上封面并将里面的内容保持私密，就像你与自己进行的对话一样。

![图像](images/f0014-01.jpg)
素描本的内容不需要公开分享。为自己创作艺术，只为创造的喜悦。素描本页面是为了发现，而不是展示。

![图像](images/f0014-02.jpg)
素描本记录你的艺术发展和成长。

#### 发展你的技能
我们通过创作学习创作。我们通过实践变得更好。你的素描本是创作和实践、发展和进步的地方。

![图像](images/f0015-01.jpg)
在无中生有中获得乐趣。通过实践发现和发展。小而渐进的行动随着时间的推移相互累积，以培养技能和自信。

#### 在数月或数年后回望
你的素描本捕捉了你生命中的一个季节。保留所有素描本并回望你在生命中的某个时期身在何处或感兴趣什么，这会非常有回报。社交媒体让我们如此容易地将自己、我们的生活、我们的创作产出和艺术作品与他人比较。我们往往倾向于将自己最糟糕的努力与他人的最佳努力进行比较。相反，我们应该将自己的作品与自己的作品比较，并问自己：我在学习吗？我在发展吗？我在表达自己吗？我对自己的产出感到满足吗？我在推动自己吗？

![图像](images/f0015-02.jpg)
回望旧素描本，发现过去的兴趣或着迷之处。素描本让你能够随时间追踪想法和进步。

![图像](images/f0016-01.jpg)
素描本是你想法的现成归档系统。

![图像](images/f0016-02.jpg)
完成的艺术页面共同存在于一本装订的卷册中。

#### 集中一处
你的素描本是一个绝妙的想法文件柜，所有内容都安全地保存在一处。

#### 一件美丽的物件
你的素描本可以发展成一件美丽的物件。你可能会非常欣赏素描本的完成页面如何共同保留在一本装订的卷册中。

#### 令人满足
为自己创作艺术可以滋养人心且令人满足。在素描本中实验可以提升你的精神并为生活带来喜悦。将空白页面变成充满意义或学习、色彩或线条的东西，有一种极其令人满意的感觉。

![图像](images/f0017-01.jpg)
将空白页面变成充满艺术和个人意义的页面是令人愉快和充实的。

#### 过程，而非结果
