# 未来的运行控制

## 简介

![](img/bgd6.jpg)

与所有有机会采用能够超越人力和脑力的技术流程的领域一样，IOC（运行控制中心）中的问题解决正日益成为高科技组织关注的焦点。人类保持在回路中（参与决策）的能力仍然至关重要，但越来越多的航空公司正在使用复杂的解决方案软件来协助管理中断。本章探讨了可能影响未来 IOC 运作方式的关键驱动因素。具体而言，行业的新挑战、技术的创新进步、人类日益增长的需求与对人的要求，以及正确且迅速应对各种外部影响的必要性，将决定未来 IOC 的构成和角色。

## 行业

![](img/bgd7.jpg)

行业挑战将继续考验最优秀 IOC 的决心。这与不可抗拒的力量遇上不可移动的物体这一悖论有着明显的相似之处。旅客和货运量的巨大增长、机场的扩建与发展，以及对更高效基础设施和配套服务的需求，正在推动旅行体验的发展势头。遏制这一强大动力的因素包括：严重的拥堵、日益加剧的污染、基于社会或环保舆论而产生的对旅行的警惕甚至抵制，以及面对持续中断时次优表现引发的普遍不满。这些既施加于行业又由行业引起的压力，将继续迫使航空公司认识到并解决在客户服务交付方面的不足。因此，IOC 需要承认可预见的冲突，并为自己配备正确的工具和人员。

## 技术

![](img/bgd8.jpg)

航空业可以说是有史以来最依赖技术的行业之一。机身和推进技术的持续改进驱动着旅行业务的本质，但在地面上、在世界任何地区任何机场运营航空网络的核心，则存在着一个庞大的复杂系统库。现有和新兴系统的改进驱动着运营的未来。航空公司运营的每一个方面都围绕着技术能力展开，例如：从改进的基于卫星的导航和着陆性能、用于监控、询问和评估飞行中运营的飞机维修系统，到能迅速将驾驶舱决策与客户结果联系起来的通信系统。在地面，增强机场设备和设施的先进技术必须在日益恶劣的天气和严峻的交通条件下实现显著效益（例如：更低的着陆最低标准、更好的空管流量）——即效率提升需要超过当前的局限性。接入更先进的全球数据库将实现更好的天气预测性，并提供规避火山或气旋活动等现象的机制。在 IOC 中，更完整、更强大的系统需要提供智能信息，这些信息经过筛选以确保准确性和相关性，但也包含能够正确告知并驱动决策过程的关键数据。

## 人员

未来的 IOC 需要由高素质人才组成。过去的招聘方法可能在一定程度上奏效，但未来的表现关键取决于寻找和确保合适特质与技能组合的策略。毫无疑问，需要一些改变。寻找、培训和留住那些能够吸收并（重要的是）洞察“大局”、能“跳出框架思考”，且拥有天生好奇且执着的心态从而驱动激情的人员，应成为重中之重。仅仅填补空缺在未来的 IOC 中不应有立足之地。现在比以往任何时候都更需要高绩效人员作为用人基础，因此招聘和选拔流程需要更有针对性地确定什么样的人适合这项任务，然后着手获取该资源。IOC 不再能容忍那些乍看符合标准，但经考核后短期内无法胜任、长期来看大概率也无法胜任的候选人。培训需求也必须得到满足，不仅要涵盖工作基础，还要通过高级技术培养出在问题识别、分析和解决方面精湛的技能。复训应成为该战略的一部分，以此激励和振兴员工契约，并借此促进个人成长和思维成熟。

## 外部影响

![](img/bgd9.jpg)

以往的中断管理策略对客户反应产生了重大影响。恶化为大面积地面滞留的航空公司中断事件，现在需要非常具体的管理。在过去的事件中，旅客曾长时间滞留在飞机上，甚至造成严重的不利健康和福祉影响。此举可能是航空公司为控制滞留旅客而采取的，也可能是基于情况即将好转从而恢复运营的判断。然而，出于消费者保护的利益，许多司法管辖区的立法现在禁止此类对待客户的行为。航空公司未能满足新要求所面临的法律（和财务）后果，现在远比早先盛行的负面社交媒体舆论严重得多。相应地，IOC 的理念也发生了变化。例如，影响特定运营的决策可能迫使航空公司考虑执行中航班上的客户管理，从而对严重的即将来临或已存在的天气状况等事件做出更早的反应。

## 社交媒体

社交媒体日益增长的影响力现在要求航空公司在 IOC 内嵌入社交媒体团队，并提供适当支持以监控和回应各种社交媒体平台和网络聊天网站。由于身处飞机上、因此正前往目的地的旅客能够制作并广播信息，该信息可能触达地面上广泛多样的社交媒体关注者，因此需要政策变更。过去，关于飞机上发生事件的信息很大程度上依赖记者在事件登上报纸或晚间新闻前向航空公司媒体团队核实。如今信息是即时的。信息很可能包含视频和声音，在许多情况下，其目标受众已在自己的设备上收到信息，而航空公司甚至还未察觉信息正在传播。确实，现在旅客在其便携设备上掌握的信息量几乎与运行控制中心相当。他们知道进港飞机在哪里，知道目的地天气如何，能查到使用中的跑道，并能获取衔接航班信息——所有这些都在 40,000 英尺的高空。此外，他们能在航空公司自身渠道发布的同时，及时直接从 IOC 接收延误或取消通知。

## 结束语

本文试图传达一些关于航空公司 IOC 的信息和流程。总有更多可说的内容，额外的场景可能多种多样，多达数百种，但重复的风险会导致反响平平。因此，本文第二部分的意图是突出航空公司面临的一些典型代表性问题，并提供足够的细节，向读者解释 IOC 手头任务的复杂性。作者相信该信息已得到有意义的阐释。

## 作者注

如果你有幸在 IOC 工作，或正考虑从事此工作，你会发现它令人沮丧、压力巨大，有时甚至极其困难。所做的决策将影响数百甚至数千名客户，包括内部和外部客户。在繁忙的日子里，你会精疲力竭地下班。但这份工作独一无二、回报丰厚，且真正能有所作为。它与航空公司内任何其他部门截然不同。
