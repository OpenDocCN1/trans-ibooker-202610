
# 9 运行控制

这一变革伴随着航空公司所有权的转变，许多政府剥离了对国家航空公司的参与。随着航空旅行的随后「爆发式」增长，拥堵开始成为世界许多地区的主要问题。机场扩建以应对更大的需求，次级机场开始被接受，发展更完善的基础设施以满足不断增长的国内需求，并经常促进国际服务。随着技术变革的实现，OCC 内部的活动稳步变得更加以系统为中心。软件供应商要么意识到潜力，要么受航空公司驱动，专注于提供这些发展，从而出现了增强控制员可用图形显示实用性的工具，从而提供更强大的功能以协助优化中断恢复。例如，为了更容易地管理重大天气中断（如暴风雪或飓风），较新的工具使影响大量航班阶段的大规模补救措施能在更短的时间框架内实施，从而实现更快的恢复，并减轻控制员的工作量。技术改进也促进了职能领域间更协调的方法，特别是那些涉及工程、商业和运营利益的领域，并形成了联合解决问题的文化。因此，从自我满足的部门追求向以航空公司为中心的综合决策结果的转变开始出现。为了支持这种方法，开发了联合指标来衡量、通报、分析和提升系统性能，从而在规划和运营中带来创新，但越来越多地关注全面的持续改进。这一过程的一部分是更多地关注收入保留和保护，以及重要的是成本控制。也有共同努力来精确定位成本削减机会，特别是针对高成本活动，如机组人员和维护资源，以及隔离与非核心活动相关的成本。结果，生产率提高，间接费用减少，备件和库存水平降低。外包在帮助减少员工规模和责任方面发挥了关键作用。例如，维修和大修曾在国内处理，现在可以外包给当地第三方承包商或离岸外包，航空公司员工队伍缩减，随着劳动力的临时化，全职雇佣转变为兼职或临时职位。当然，雇佣协议需要更多灵活性，以实现工作方式的重大变革。

# 10 运行控制

这一时期显著变化的是重新聚焦于客户并分析其对公司的相对价值。这很大程度上源于对日益激烈竞争的认识，不仅体现在新航空公司数量增加、旅客选择大幅增多上，还体现在不断进化的最先进飞机上，许多情况下配备复杂的高端客舱，提供广泛的产品和服务展示。选择多得多，加上客户几乎无惩罚地轻易转向竞争对手，这些都是重新聚焦客户旅程的驱动因素。因此，客户影响已成为运营决策的核心，特别是关于高价值客户（高端舱位旅客）或高忠诚度客户（来自其母航司或主要航司，或来自联盟和合作伙伴航空公司）。

## IOC 变革的驱动因素

有几个因素导致了 IOC 本身的哲学变革。首先，航空公司高层管理意识到 IOC 在管理航空公司资产中发挥的关键作用；这是从将 IOC 视为成本衍生物的观念中的哲学转变。鉴于 IOC 在日常工作中能触及航空公司的许多部分，现在公认它对航空公司的行为和绩效有重要的「感知」。此外，航空公司真正接受了 IOC 对利润的重要贡献。它已成为一个卓越中心。其次，作为信息和通信的核心，并通过其对航空公司行使积极控制的能力，IOC 已成为对航空公司绩效至关重要的结果的关键驱动力。它可以利用和协调广泛的资源，从而在运营领域实现更高效率。它还可以在帮助降低运营成本方面发挥作用，例如，通过更明智和更快的决策过程，或启动燃油政策等工具以优化燃油携带和消耗，或防范短缺或供应威胁。作为其自身绩效审查的一部分，IOC 能够评估其成员的角色。例如，它非常适合影响政策，游说改变机组人员可用性、排班或休息惯例，改进时刻表，或要求增加地面资源，这是由于识别出导致或加剧中断的根本原因。为了证实此类提议，它现在掌握了大量数据和其他支持证据来论证其观点。
