
# IOC 的组成

通过这种繁琐的过程可能不适合典型操作挑战的环境。这一缺陷暗示了使用替代决策方法的必要性。在问题结构不良、表现出不确定性和复杂性且面临相当大时间限制的环境中，直觉的使用通常更为普遍。

## 直觉思维——跳出框框思考

具有直觉是一种个人特质，这对于 IOC 成员来说是高度期望的，至少应该是。它被描述为拥有“预感”或“直觉”，或者对某事可能行得通或行不通有一种感觉。经验更丰富的高级控制员通常具有高度的直觉。自然地，他们能够以逻辑方式处理问题的变幻莫测。但真正使他们与众不同的是一种近乎潜意识的能力，能够超越显而易见或已知的量，使他们能够察觉到特殊性——事物表面上可能显而易见，但不知为何就是看起来不对劲。这种判断对错、可行与不可行的能力是一种极其宝贵的天赋，以至于逻辑可能指引他们以特定方式行事，但他们却能感知到其他影响因素。

例如，他们可能不会遵循通常采取的若干步骤（这对经验较少的控制员来说可能显而易见），而是本能地等待，感觉到某种不对劲，或者鉴于环境可能更有利。这种区分可辨别事物与更隐晦事物的天生能力是直觉思维的主要特征之一。

“跳出框框思考”或“跳出方框思考”等表达多次被用来强调一种能力，即通过解除人类隐性设定的边界来概念化问题和潜在解决方案。从小，人类就被给定思考和行动的参数，并被训练据此操作，甚至如果超越这些限制会受到惩罚或解雇。因此，正如预期的那样，问题的潜在解决方案是根据控制员的经验和专业知识水平来解释的。

新手或缺乏经验的控制员可能只看到问题的“黑白”方面，并决定看似简单直接的解决方案——例如，对一个表面上看似不可避免的航班实施延误。相比之下，更有经验且富有直觉的控制员可能感觉到延误可能不需要实施，也许是因为潜在的变化或其他影响。换句话说，这位控制员意识到过于狭窄的关注点可能只能部分解决问题，而部分解决方案可能来自隐晦或新出现的来源，甚至可能尚未被识别。

当代软件包的复杂性（如甘特图驱动和显示的软件）意味着有时只需几个按键就能获得相当复杂问题的现成解决方案。这为中断恢复提供了支持，例如飞机和机组模式以及乘客行程等功能。然而，具有讽刺意味的是，这些工具在某些情况下实际上可能阻碍决策过程。它们会产生某种解决方案，这可能是可以接受的，在时间压力下可能是当时最好的选择。但这可能不是正确的选择，因此需要人工干预并显示出其重要性。丰富的经验，特别是直觉，在确定 IOC 中中断软件建议解决方案的优劣方面起着至关重要的作用。

例如，在影响特定港口（如天气）的情况下，问题分析阶段可能涉及过滤甘特图显示的信息，以便仅显示通过该港口的移动。这种视觉信息的限制会降低整体态势感知。也许部分解决方案可能是考虑靠近港口的移动（飞越或通过附近港口运行）。从这个意义上说，经验丰富、富有直觉的控制员对软件表现出健康的尊重，但仍对系统生成的结果保持警惕。

# 解决问题的技能

正如预期的那样，IOC 的主要角色是解决问题。这通常是对情况的反应性响应。但解决问题过程的一部分是对网络或受监控特定区域发生的事情保持永无止境的感知。

## 网络监控

监控飞行计划的必要性显而易见，但除了从交接班或类似简报中建立初步感知外，持续的监督是保持对运营全面感知的主要手段。这部分原因解释了为什么经验丰富的控制员表现出对事件了如指掌的精通。没有中断时，监控就是观察出发和到达随着更新而变化。但这也是提前预测以计算天气变化等影响的情况。
