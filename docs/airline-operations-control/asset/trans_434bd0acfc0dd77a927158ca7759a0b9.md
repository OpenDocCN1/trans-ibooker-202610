
# IOC 组成

## 商业与客户旅程管理

商业职能的重点当然是客户。但在运营日之前（在 IOC 时间窗口内，例如 2–7 天），可能需要进行运力调整，这可能是由于之前的破坏性情况，或因特殊需求而需要额外运力（例如某航线需求突然增加）。因此，随着时刻表的微调以最大化机会，运力调整可能一直持续到运营日。

当然，该角色的很大一部分涉及中断管理以及保护客户所需的商业活动。正如前文多次提到的，CJM（客户旅程管理）角色的重要性日益增加。在 IOC 中设立这一关键角色，是为了确保运营决策考虑到影响流程的任何商业因素，从而实现并最小化对客户的影响。它是 IOC 内部的商业“代言人”或客户倡导者，其影响力有助于确定适当的中断管理途径，例如决定哪些航班应或不应成为延误或取消的目标。

重点关注领域包括：
- 为 IOC 决策做出贡献，提出影响最小的航班进行中断，或为受影响旅客制定恢复计划
- 识别 VIP 和 CIP 客户，并在旅程中断时予以保护

该职能在预防或最小化对客户的破坏性影响方面发挥着越来越重要的作用，但当这些情况发生时，该角色会考虑商业决策（涉及预算影响），例如：
- 在替代航班（或航空公司——无论是否与原航空公司结盟）上重新预订
- 提供住宿、交通、餐饮和客户赔偿

这些决策是与相关各方（如航空公司、机场工作人员、预订部门、酒店等）进行大量沟通和联络的结果。随着大多数航空公司拥有复杂的忠诚度计划，在恢复过程中识别高等级客户并给予适当待遇成为重点之一。

当然，了解客户、库存和预订系统对该角色至关重要，但分析局势并以客户最佳利益为出发点、同时兼顾商业责任寻找解决方案的技能同样重要。担任这些角色的人员必须极度专注于客户服务，并能跨越多元化的客户群进行沟通和互动。与 IOC 中的其他角色一样，他们必须对工作充满热情。

## ATC 流量控制/时隙控制

在许多机场，空中交通管理受制于空中交通流量管理（ATFM）的使用，ATFM 旨在优化机场内外空域的使用，并提供一个一致应用且对希望使用机场的航空公司公平的系统。

航空公司时隙控制员的角色（在美国，可能是被指派为 ATC 协调员的特殊分类调度员，或类似职位）是与空中导航服务提供商联络，以协商航空公司的到达和出发时隙。由于可用时隙有限，且航空公司中断会改变出发和到达时间，时隙控制员的部分职责还包括与系统的其他用户（其他航空公司）联络，以期在它们之间交换时隙，以满足所有相关方的需求。

随着许多机场交通量不断增加和拥堵问题加剧，该角色在 IOC 中发挥着基础性作用。但当中断严重恶化时，时隙控制员成为关键人物，因为恢复过程的很大一部分可能取决于能否成功获得可用的时隙时间。

## 机场协调员

一些 IOC 设有机场协调员或联络代表。该职位作为 IOC 与站长（或港口协调员）之间的联络点，提供直接的双向沟通，重要的是，为影响该港口的信息和决策提供传递渠道。这些港口职能是 IOC 的“眼睛和耳朵”，是运营环境中至关重要的齿轮。

机场工作人员与 IOC 代表之间的关系显然需要高度的相互依赖和合作，要记住在中断时期，每个机场都将争取自己的恢复，而不会具备平衡航空公司整体运营所需的全网容忍度。因此，作为 IOC 内部的机场代言人，需要根据各自优劣论证每个案例，同时充分意识到整体影响以及所有因素相互契合的必要性。

这要求人员深入了解各机场的运作方式，包括所有权和控制的细微差别，以及要求其表现的内部和外部压力。他们需要熟悉用于衡量机场绩效的工具，例如精准时刻表，其中每个流程和任务（如行李卸载、加油、餐饮供应）在飞机周转时间内都有特定的时间点和持续时间。重要的是，他们还需要认识到机场与航空公司客户之间关键关系的本质。

## 货运联络

在 IOC 中设立货运代表是运营链条中的另一个关键环节。货运职能对“机腹以下”装载的货物拥有监督权。最大化每个航班的有效载荷包括在可能的情况下最大化货运载量，航空公司与货运代理合作需要避免错失货运承运机会。在飞机最终配平阶段，他们持续与飞行计划和载荷控制联络，以在重量对运营至关重要时最大化货舱空间，这在超长航线航班中尤为典型。在这些更关键的运营中，至少容纳优先货运是高度可取的。

货运载量对 IOC 如此重要的原因有很多。例如：
- 航空公司可能已将货舱空间租赁给大型货运或邮政组织，履行这些合同协议是高优先级事项
- 可能涉及活体动物运输，例如动物园之间的转运或全球繁育计划相关运输
- 可能需要活体人体器官转运，要求精确协调，并特别注意机上和所服务机场的环境条件
- 有时需要遗体遣返，要求高度协调和组织，当然也需要一定的同情心
- 在某些情况下，一些国家可能还要求军事护送陪同遗体，并在飞机转运期间给予特别关注
