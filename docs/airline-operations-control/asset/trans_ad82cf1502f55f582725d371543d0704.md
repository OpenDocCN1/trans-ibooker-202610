
# IOC 运行控制员的构成

![](xhtml/images/bg2c.jpg)

运行控制员（或网络控制员）的角色性质要求具备适当技能的个人，能够在高压、快节奏且复杂的环境中胜任工作。有许多系统和工具可供辅助，以及手册、培训活动和其他支持该角色的手段。但即使拥有众多资源，教授和培训个人如何在中断管理角色中取得成功，以掌握解决复杂问题所需的技术，仍然是一个极其困难且令人沮丧的漫长过程。本节将更详细地探讨该角色及其职责，并重点关注在 IOC 中履职所需的个人特征和素质，随后再考虑招聘、选拔和培训等更具管理导向的目标。

## 角色

为避免重复并整合运行控制职能中的各种职位，"角色"一词涵盖了属于运行控制任务集的若干职位。因此，根据这一解释，下文描述的角色包括值班经理承担的部分任务，但概括了高级控制员、控制员、辅助控制员和运行官员（或用于区分不同层级人员的类似术语）的任务。从本质上讲，该角色是监控、控制和协调与按日执行已发布时刻表相关的活动，以服务于航空公司的网络。IOC 中的运行管理包括与正常和非正常运行（包括危机或应急管理）相关的活动，明确关注客户需求，同时考虑各种期望的商业和运行目标及制约因素。

## 职责

考虑到上述包含的头衔，运行控制员角色的主要职责非常广泛。控制员主要负责航空公司的运行绩效，包括达成特定目标（如准点率、效率、生产力），并在此过程中确保遵守监管要求、航空公司政策和任何工作场所协议。在日常工作中，更具体地说，他们负责监控实际飞机动态（包括起飞前、起飞、航路进展和到达），识别与时刻表的偏差，并相应地解决任何问题，以减轻对网络的潜在或实际影响。他们还负责在 IOC 内部和外部进行沟通，并跨越任何所需层级。他们必须确保收到的任何通信都能被迅速理解、解释并根据需要应用于具体情况。同样重要的是向关键人员传播信息。除了广播决策或建议外，这有时可能意味着根据事件性质，有选择地过滤特定细节或审慎地安排信息发布时机。他们的职责可能还延伸至积极规划机队承诺、协商时隙时间、协调航线和越境许可，以及办理其他批准。

## 个人素质

谁能成为一名优秀的控制员？这是较难回答的问题之一。从前面的章节似乎可以看出，控制员确实是一个拥有令人印象深刻技能阵列的特殊人物，能够以极高的能力单独评估和处理任何复杂问题，然后将构想的计划付诸行动，立即取得积极成果以解决困境，结果一切归于正轨。在理想世界中，也许可能！但现实是，该人员确实需要具备沟通、谈判、解决问题以及自我管理、他人管理和各类任务管理方面的卓越技能。要实现所有这些，需要最高水平的个人资质、实现目标不妥协的态度，有时还必须在相当大的时间限制下完成，因此会面临压力。

但这还不够。杰出的控制员拥有可谓"第六感"的特质；这是一种将其与他人区分开来的特质。这是一种与生俱来的感知异常的能力，例如识别通信何时包含混合信息，或看似显而易见的解决方案何时存在潜在陷阱或不良后果，或延迟决策或行动可能会产生进一步的、有时截然相反的信息，从而导致不同结果。这些细微差别体现了控制员之间不同层次的觉察力和直觉。通俗地说，这在他们的基因里！他们要么能做到，要么做不到，任何数量的培训都无法充分替代。如果 IOC 能配备这种素质的个人，它很可能会形成一个能力强得多的团队，能够产生好得多的成果。

## 背景与经验

过去，IOC 中的经验水平参差不齐，许多员工拥有稳定、长期的职业生涯，通常在相当专业的岗位上，但与 IOC 职能相关。在此期间，他们通过接触众多问题和挑战积累了丰富的知识，当然也积累了巨大的能力。确实，他们因对航空公司运行的掌控力而受到推崇，因为没有其他人真正能理解问题的程度，更重要的是，理解解决复杂问题所付出的巨大努力。随着时间的推移，由于退休、不合适的任命，或可能无法应对极端压力、日益增加的复杂性以及满足绩效目标的不断增长的要求，员工流动发生了变化。因此，IOC 内部员工的经验水平随时间大幅下降。当然，部分原因是技术的发展（例如更智能、更强大的系统，以及琐碎或重复性活动的数字化），这具有讽刺意味的是，也消除了对任务所涉及原则的某些基本或基线理解。这些系统改进使任务能够更高效、更有能力地执行，但也带来了负面影响。首先，熟练员工的总数减少了；其次，新员工作为其基础学习一部分传统上承担的"跑腿工作"现在由系统驱动，移除了这一重要的渐进步骤系列。这种学习和知识获取的短板需要在培训制度中得到认识、承认和补偿。尽管不断改进的技术为问题解决和决策提供信息并驱动它们，但由于上述原因，适当的人力资本供给仍然极为重要，因此这些人的资源配置至关重要。将几乎没有先前运行经验的"生手"任命到 IOC 中是毫无意义的，虽然这在过去可能发生过，但现在极不可能。因此，寻找具有合适背景的适当个人是当务之急。对各 IOC 运行控制员的普查将显示，大多数员工通常在该角色上拥有五年或以上的经验，尽管背景通常大相径庭。当然，有些人在另一家航空公司积累了先前的 IOC 经验，
