

# IOC 的组成

## 监控与风险管理

可能造成干扰的影响因素常见且频繁，因此监控工作变得更为紧张，旨在确定潜在的冲突和不和谐来源，这需要控制员投入大量精力。这种环境要求持续的风险管理流程。评估威胁或潜在干扰的有效性，关键在于时刻保持警觉和关注。

例如，一个相对简单的天气情况（如单跑道机场的强侧风）会立即引发连锁反应。在控制员脑海中，会浮现诸如以下的问题：
- 鉴于如果天气持续，备降至备选目的地的可能性很大，航班是否应在当前情况下继续飞行，还是现在就应执行备降？
- 如果航班备降，对下一趟（返程或后续）航班有何影响，机组工时是否面临风险？
- 如何安置（即营救）备降机场的乘客？

因此，监控角色从未真正处于休眠状态。无论问题多么微小或看似微不足道，这类心理推演始终处于运行的最前沿。

## 问题识别与分析

中断事件的发生，可能因从公认来源接收到的信息而被识别，也可能因原本可靠来源未提供信息而被识别。随后，控制员需识别问题的特征，确定其性质及对时刻表的潜在威胁。

视问题类型而定，确保信息与相关 IOC 职能部门共享，对于达成共同理解至关重要。例如，在控制员眼中看似简单、孤立的单一航班延误，可能不会对飞机运行模式造成任何干扰，但却可能对机务部门产生重大后果。因此，需要团队协作，共享并基于共同信息采取行动，以正确识别并探究潜在和实际问题的所有侧面。这是 IOC 结构完整性的基础。

一旦问题显现，分析阶段将涉及对问题程度的全面判定。此时，控制员需要验证所收到的信息，特别是确保其来源可信，并质疑任何可疑信息。问题分析将邀请其他 IOC 成员参与，因此乐于接受他人的观点和建议至关重要，以确保分析尽可能透彻。资深控制员的技能在此阶段显现，体现在洞察真实与潜在机遇，并识别所需采取的行动。

换句话说，问题分析不仅仅是设想事件发生时可能出现的情况。生成并评估各种方案的额外步骤——每个方案都有其预期结果和后果——同样重要，而这正是高度创造性和直觉性思维引领出更高级解决方案的地方。

## 问题决策点与实施

决策过程的关键在于识别必须做出决策的节点。过早决策，信息可能不完整，或其他 IOC 职能部门可能未来得及提供充分意见；过晚决策，可选方案可能已消失。这是一项平衡术，由支撑问题的多种因素、可用于优化解决方案的时间，以及至关重要的控制员经验和专长共同决定。

尽管上述列举了两种决策风格，控制员仍需确保已接收到足够信息，并考虑到任何可能的变化。然后，在适当咨询并权衡所有选项后，决策付诸实施，并将结果传达给所有利益相关者，包括客户。有时，控制员需要对自己的决策坚信不疑，并有意愿援引必要的选择，因为大多数决策都会产生赢家和输家。在复杂的中断中，选择最佳方案可能有利于航空公司的整体利益，但实际上往往需要妥协，导致时刻表的某些方面受损。

## 选拔合适人员

控制员的合理招聘、甄选和培训，对 IOC 的高效、有效运作至关重要。然而，IOC 承认在寻找和留住合适人才方面面临巨大困难。受聘人员可以被教授如何遵循政策、操作系统，并接受领导力、沟通等方面的培训。但极难做到的是，教会个人如何在中断管理中取得成功。这主要是因为该角色所需的先天素质和特质。因此，首次就找到合适的人选至关重要。

## 招聘与甄选控制员

潜在申请者的来源因航空公司的策略而异。实际上，其可选择外部或内部来源。

### 外部招聘

若 IOC 选择外部招聘控制员，通常的搜索目标是服务于其他航空公司（国内或国际）的现任控制员，或从事相关职务并希望进入 IOC 领域的个人。但全球范围内优秀、经验丰富的控制员（且愿意搬迁）极其有限。资深控制员和调度员可能因不同的条件和薪酬、或在更大公司或国家拓展角色的机会而被吸引。另一方面，考虑到个人情况，他们可能不愿离开现有职位。因此，寻找此级别的经验人员日益困难。

资历较浅的控制员则可能被吸引。值得注意的是，部分候选人甚至可能来自行业之外。例如，某地区性 IOC 曾面临巨大困难，难以吸引合格候选人来其所在城镇。为补救，他们发现招聘具有物流行业（木材采伐）背景的候选人——尽管其航空知识甚少——却取得了成功，因为候选人可留在成长的地区，而非搬往城市。这种方法的劣势在于外行术语的性质、缺乏与航空公司各利益相关方沟通的经验，以及适应航空高压环境的挑战。

有时，合适的未来人才来源是飞行员、空管员或飞行服务主任，他们选择转行，或因医疗条件等原因职业生涯终结。他们在各自领域的知识和专长对 IOC 往往极具价值，因为他们通常了解航空规则、实践、程序、术语及影响高效运行的因素。他们大多经历过运行环境、其压力与挑战，习惯在压力下做出理性决策。确实，他们条理分明且规避风险。因此，只要他们也具备上文提及的“跳出框架”思维技能，他们的思维模式就应支持 IOC 环境所需的关键思维过程。
