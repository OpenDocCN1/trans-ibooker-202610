

# 27 IOC 的组成

## 性情/气质

上一节内容可能给人一种印象，即这些高绩效者必须在工作中时刻保持高度兴奋，并受到充分激励，才能产生上述成果。并非如此。之所以能实现高质量的解决方案，并非源于一系列忙乱的应对，即使身处混乱的中断之中也是如此。相反，这归功于熟练管制员所具备的审慎、深思熟虑的方法。

毋庸讳言，IOC 有时会变得相当混乱。单独的常规问题按惯例处理即可，但复杂、多重且持续的情况终将考验所有管制员的意志。担任飞行员或空中交通管制员的基本要求之一是在压力下保持冷静，因为这些领域的决策至关重要。中断模式下 IOC 的性质（高压、嘈杂、人多、多事件、目标冲突）要求采取类似的方法，需要极其坚韧果断的人员，他们能全面剖析问题，并构建经过深思熟虑的解决方案。这不仅意味着具备多任务处理能力，还意味着擅长同时应对多个各有特点的问题。他们需要在该条件下发挥最佳水平，因此需要展现出与之匹配的职业道德。

## 自我管理与团队适配

在个人层面，身处此环境的个体需要保持良好的健康状态和体能。作为轮班工作者，开始时间各异，例如 0400、1200、1800 或 2300，每次工作时长在 8 到 12 小时之间，必须充分认识到全天候工作的严酷性，以及它如何导致工作内外累积的疲劳和倦怠。与航空运行中的其他角色类似，需要充足的高质量休息时间来恢复。人员排班（应）在缓解疲劳影响方面发挥关键作用，但个人也需对最大化休息负起自身责任。操作环境中轮班工作者通常享有的一个优势是：他们知道在经历充满挑战且颇具压力的一个班次后可以离开工作场所，第二天返回时却面临完全不同的境况。自然，相反的情况也会发生。但“将问题留在工作中”交由接班人处理，是身心恢复过程的重要组成部分。

# 28 IOC 的组成

为了保持冷静专业的举止，同时仍坚定地完成任务，个人需要高度的自控力和行为规范。这包括对时间管理的审慎运用，以及正如后续章节所讨论的，利用短暂的休闲时间作为短期逃避/调节的机会。部分任务使管制员能够自主工作，在极少互动的情况下执行一系列活动。但绝大多数工作依赖团队，需要与性格各异的成员密切配合，包容团队成员各自的目标和工作方式，同时参与并贡献于 IOC 的总体目标。高级管制员需要具备娴熟的领导技能，能在中断管理过程中带动他人，鼓励团队成员发挥创造力、机智和毅力。这对于确保合力朝着正确方向至关重要。

## 沟通技巧

运行管制员的一项典型要求是不仅能沟通，而且要**沟通得极好**！这要求在倾听、解读、联络、谈判以及通报与运行相关的相关信息方面给予极度的重视。这也要求高度的理解力，以及使用恰当的语言和术语。有时，清晰有力地阐述论点，或说服他人认识并接受某种观点，也可能至关重要。“在任何层面都能清晰沟通”固然是一句陈词滥调，但在该语境下却高度相关。这意味着要与各式各样的人打交道，例如团队成员、公司高层管理人员、航空公司机长、空中交通管制、国家监管机构或外国政府代表等。因此，知晓信息的含义、需向谁传达以及何时传达可能至关重要。结果是，语言各异，沟通技巧各异，甚至对特定信息的相关性或重要性的强调也各异。因此，适应这些及其他影响所需的技能也相当多样，以适应不同情境。有时管制员需要面对各方之间的冲突，可能需要在某些决策过程中扮演维和者的角色。有时，知道如何以及何时说“不”可能是必要的，敏锐地察觉到需要将沟通范围扩大或上报至更高层级也可能是必要的。沟通的性质在一定程度上取决于个人必须行使共情的程度，同时完全意识到并敏感地捕捉其他各方的利益和动机。

## 认知技能

运行管制员（确实也包括调度员）任务的关键部分是在高压、极具挑战的环境下，运用高级思维过程来评估和解决复杂问题。有几种方式可以思考决策方法。一种方法主张个人遵循理性过程。

### 理性、演绎思维

理性思维被描述为指“一种合乎逻辑的、循序渐进的、系统的决策方法”。[3](#0073.xhtml#fn5) 这种循序渐进的方法可能具有优势的场景是针对经验较少、因此接触中断较少——尤其是复杂中断——的新管制员。在基础层面上，他们可以遵循一个简单的流程（甚至写下具体编号的步骤以辅助），以获取适当信息、与正确的人交谈、考虑多个选项，并选择一个首选方案付诸行动。这种方法可作为一种有用的培训工具，引导新管制员完成决策过程，因为它可能帮助他们在达成结果时考虑所有途径。但在大多数中断情况下，当然，生成和分析可能备选方案的时间极其有限。此外，情况不断变化，信息往往稀缺、不可靠、令人困惑或相互矛盾。还有其他局限性。个人可能过度专注于确保遵循每个步骤，从而忽视了对任务本身的关注。正式的、或许是书面的步骤无法涵盖所有事件，因此也存在可靠性缺口。因此，循序渐进的方法可能适用于某些简单情况，但在许多其他情况下可能行不通，导致对该过程合法性的怀疑。当发生复杂中断时，不仅可用时间有限，而且情况往往变化迅速。因此，信息也随之快速变化并迅速积累，以至于梳理大量材料以澄清重要且相关的信息可能过于困难。另一个论点是问题本身未必定义清晰。这意味着着手
