

# 场景化信息流

## 维护监控

专家，在某些情况下直接与制造商联系，如图 5.2 所示。维护监控在场景中的作用是确定问题的确切性质，并与支持角色协作，确定让飞机在最短时间内恢复适航所需采取的措施。这可能意味着需要零件和其他设备来修复或更换组件。如果问题严重，需要大量工程支持，也可能需要卸下乘客和行李，并将飞机拖至机库。因此，维护监控人员与其他工程角色之间的沟通和行动至关重要。

## 机组与乘务员排班联系轨迹

面临即将发生或已知的航班问题时，当天的机长/副驾驶排班员和乘务员排班员对任何与机组相关的问题都有深入了解，例如：机组人员从何处为航班报到、他们的签到和值勤时间、限制、分配的值勤要求（即他们为该航班执行的具体角色）、航班衔接（往返该航班）、过夜基地和次日承诺等。重点显然是管理与当前航班相关的机组编制。他们可能已经在与机上执行机组人员交谈，以确定限制或请求更改现有排班表。此外，两个排班部门都可能正在评估进一步中断的可能性，甚至在这一早期阶段就评估为当前航班（如果延误过长或需要取消）和任何可能受影响的后续航班寻找替代机组的方法。为此，他们可能会仔细检查机组成员记录，以确保任何值勤变更合法，且符合工作惯例、公司疲劳管理系统和雇主协议。

协助排班员的是“运行日”支持人员，他们的角色可能包括更深远的影响，例如机组人员脱离模式、在“基地外”结束值勤，或无法前往培训任务等。这些支持职位有时可能需要咨询特定角色的专家，如值勤机长（飞行员排班）、机队行政人员和工会官员。

## 客户旅程管理联系轨迹

CJM 团队也会立即介入中断处理。根据中断发生的时间，客户可能身处各种地点。如果工程问题发生在计划起飞前数小时，可以建议客户不要前往机场，或告知延误起飞时间。然而，如果问题发生在所有客户已登机时（例如飞行前检查期间，甚至启动时），影响可能更严重。因此，CJM 流程可能需要涉及出发端的工作人员，照顾 VIP，甚至为特定客户提供替代旅行安排，而不是让他们承受严重延误或更糟的影响。部分职能还评估到达端的影响，查看初始目的地以外的衔接（包括航空公司内部和外部）、住宿或移民问题等。重新预订客户到其他航班或以任何其他方式协助他们的流程，可以由客户支持人员或官员执行并跟进，或通过第三方承包商完成。如果事态需要升级，将有一系列负有责任和权力的人员提供更高级别的支持，如图 5.5 所示。

![](xhtml/images/bga6.jpg)

**图 5.5 客户旅程管理联系轨迹**

```
Ops Control IOC
Customer Journey Management (DOM & INT)
Journey Officers (rebooking)
Customer Journey Operations
Senior Manager Customer Journey Ops
Contracted 3rd Party Providers
```

## 机场联系轨迹

每个（服务）机场的关键职能之一是港口协调员或机场站长/值班经理（或类似名称/级别）。本质上，这是一个航空公司角色（即不属于机场所有权或运营——而是航空公司在机场的最高代表）。IOC 内的机场联络角色与机场的该职位有直接联系。因此，两者之间的沟通和信息传递简洁、快速且与当前问题相关。港口协调员/站长将所有机场职能联系在一起，直接联系餐饮、加油、工程师、停坪官员、航站楼工作人员、机场当局、ATC、航空公司合作伙伴、竞争对手和签约的第三方供应商。该职位还监督可供员工和公众使用的信息系统（航班信息显示屏）。因此，关于延误和取消的信息控制不仅掌握在 IOC 手中，还需与港口协调员/站长协商，后者与旅客面对面接触，其工作场所可能直接受到大量中断（有时愤怒）旅客的影响，以及拥挤的登机口和停坪区域的影响。

如果延误过长或航班取消，这种中断开始考验机场能力。夜间可能因后续的交通、住宿和餐券需求而加剧。繁忙航站楼登机口的延误可能因有限的停机位而对到达交通产生连锁影响。在某些机场，专用登机口适合特定机型，会产生进一步的复杂性。图 5.6 描绘了机场联系轨迹。

![](xhtml/images/bga7.jpg)

**图 5.6 机场联系轨迹**

```
Ops Control IOC
Airport Liaison
Station Manager/Port Coordinator
Port Staff/Functions
Engineering Duty Manager (Airport)
Customer Service Supervisor
Contracted 3rd Party Providers
```

## 调度/时隙控制联系轨迹

运行控制发出的决策将对调度职能（并通过该职能影响飞行规划/导航/载荷控制服务）产生影响。例如，如果工程问题导致服务延误或取消、换机或换航班号，则需要通知 ATC。如果出发和到达机场中有一个或两个受时隙限制，IOC 中的时隙控制员（或同等职位）可能还需要与空中服务提供商协商替代安排，如图 5.7 所示。

**图 5.7 调度/时隙控制联系轨迹**

```
Ops Control IOC
Flight Dispatch/Planning
Slot Control
ATC
Air Service Provider
Navigation
Other Carriers
```
