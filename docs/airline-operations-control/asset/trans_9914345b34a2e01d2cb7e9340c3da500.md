
# 航空公司运行控制

本书是首批揭示航空公司运行控制中心错综复杂内部运作的文献之一；特别是其思维过程、信息流以及为缓解中断所采取的策略。*《航空公司运行控制》*深入描述、解释并详细阐述了一系列高度专业、经验丰富的员工管理航空公司“最前沿”端的活动。旨在填补空白，因为该领域鲜为人知，且鲜有著作面向航空业从业者。本书全面介绍了运行控制中心的组成、其组成部分，以及为准备和执行当日航班计划而发生的流程。多章节提供真实场景，演示运行控制中心如何应对不断演变的局势——它们需要考量哪些因素，以及当事态不妙时如何准备好备选方案B和方案C。本书旨在为新老航空业从业者提供关键运营方面的知识增益。此外，也为航空运输管理专业的学生提供了一本通俗易懂、基于真实世界视角的指南，介绍每家航空公司都具备的关键职能。

**Peter J. Bruce**在航空业工作近17年，其中绝大部分时间担任澳大利亚一家国内航空公司的运行控制员。他最近从墨尔本斯威本科技大学航空系退休。Peter持有FAA调度员执照。

**Chris Mulholland**1977年在澳大利亚跨洲航空开始航空生涯，曾在澳大利亚跨洲航空、澳洲航空及现在的澳航运行控制领域担任多个职位，现任澳航综合运行控制中心经理。

## 管理航空运营

**丛书主编：** Peter J. Bruce  
**副主编：** John M. C. King

本丛书旨在提供一套全面的材料，涵盖航空公司和机场运营的关键组成部分。迄今为止，这种创新方法在航空主题中尚未见到，更未应用于航空公司或机场的运营领域。虽然近期著作已开始简要探讨运营领域的各种特征，但《管理航空运营》丛书将以更广的广度和深度扩展覆盖面。航空公司和机场缺乏现成的、易读的、权威的特定主题知识资源。利用行业专业知识推动一系列关键利基产品，将以前所未有的方式为行业提供资源。因此，目标是提供一套专业化、国际化来源、专家撰写的书籍，作为行业专业人士易于获取的指南和参考。丛书编辑的重点将是确保产品质量、用户可读性和吸引力，以及整个系列的透明一致性。
