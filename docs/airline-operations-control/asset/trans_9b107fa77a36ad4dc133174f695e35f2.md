
# IOC 运行控制职能的组成

## 运行控制职能

![](xhtml/images/bg28.jpg)

运行控制职能（有时称为动态控制或飞机控制）通常是 IOC 的核心焦点。它通常实体位于 IOC 的中心位置，以便被确定并视为活动的核心，从而便于与关键职能领域进行即时沟通，并利用周围的专业知识采取协作方式解决问题。值得注意的是，不同 IOC 之间在人员职称和个人职能方面存在差异。在某些司法管辖区（如美国），运行控制员实际上是飞机动态控制员（也称为调度员），主要负责监控和调整飞机运行模式，视情况寻找更换飞机注册号/尾号的机会，并参与与停坪调度、载荷控制、工程、乘务、时隙控制和流量管理等部门的联络工作。然而，在这些司法管辖区之外，控制员拥有更大的投入和决策参与权。由于部分航空公司机队规模庞大，运行控制职能常被划分，以限制个人管控的航班数量。这种职责划分可能导致根据国际/国内航线、长途/短途运营，或按地理区域隔离系统来分配航班管控权。进一步的细分可能与机型相关。鉴于本文旨在聚焦运行控制职能，下文将详细讨论该任务所需的角色、特征和个人素质。

## IOC 高级管理层

IOC 的高级管理结构将形成某种层级，最高层（通常称为副总裁 (VP)、总监、集团经理或运行总监）通常直接向航空公司 CEO 汇报。其下通常设有 IOC 经理或运行经理，再下则是若干轮班值班的值班经理，负责监督日常运行。此外，下属管理人员可能负责运行绩效分析、系统与 IT 开发或其他相关职能。IOC 管理层的关键职责是确保航空公司安全、合法且高效的运行绩效。这意味着需遵守相关航空法规（全球范围及航空公司注册国的法规）、公司政策与惯例，以及适用于员工和其他人员的各类行业裁决。虽然本文承认包含航空公司运行控制部门的更广泛层级，并阐述了高级管理团队的职责分工，但其重点主要在于日常运行管理。因此，在探讨运行控制职能的履行时，范围向上限定至 IOC 值班经理级别（见下文）；即轮班中对整个 IOC 日常运行活动具有直接影响的最高职位。这将恰当地界定相关群体的范围。

## 内部关系

如果将 IOC 比作一个车轮，那么轮毂包含拥有整体决策权的中央监督职位（如值班经理或管理团队），而轮辐则描绘了实体内的关键职能领域。IOC 概念的成功得益于关键决策、职能科室或部门的纳入。这些科室大多由合格且经正式授权的决策者在 IOC 中代表，而各科室的支持团队（规模更大）则位于外围。例如，IOC 内将有来自技术（飞行员）乘务和客舱乘务科室的若干人员，他们有权做出日常乘务运行所需的相关决策。其他相关角色，如乘务编组或排班活动，将位于这个核心小组之外，因为这些角色要么发生在运行日之前，要么不属于处理扰乱的决策者职责范围。同样，其他职能领域也将在靠近中心轮毂的位置设有授权代表，支持角色则设在附近。当然，IOC 的构成取决于航空公司的规模和结构，以及纳入各职能领域的意愿。图 2.1 展示了上述关系的代表性结构。各职能的位置不暗示优先级或顺序。重要的是 IOC 是所有这些职能的整合。

## IOC 人员

现在关注分配到 IOC、负责管理航空公司日常运行的具体人员。上述各职能领域向值班经理负责，但也在各自的领域内负责（即向各自的管理团队负责）。

- 运行控制
- 载荷控制
- 飞行调度
- 飞行员乘务
- 客舱乘务
- 气象
- 航行/飞行计划
- 流量/时隙控制
- 维修监控
- 社交媒体
- 安保
- 货运
- 客户旅程管理
- 运行绩效
- 机场
- 飞机分配
- 排班/计划
- 餐饮
- 系统/IT

## IOC 值班经理

IOC 由值班经理或同等职位人员监管。从本质上讲，该角色是每日轮班中职位最高的人员，需向 IOC 高级管理层负责，确保航空公司每天 24/7 的运行顺利进行。考虑到图 2.1 所示的关系，这是核心角色，拥有权力确保 IOC 内每个职能的绩效都能胜任且有意义地为整体运行绩效和所需交付成果做出贡献。为实现这一点，需要高度的敏锐和洞察力，以驾驭各组成领域驻留的大量专业知识，因为建立和维持紧密工作关系的能力至关重要。特别是在重大扰乱时期，这种专业知识需求极高，此时问题复杂、时间往往紧迫、决策影响重大、工作环境性质紧张得不得了。有时，情况可能要求值班经理充当仲裁者，当协作但相互竞争的需求导致僵局时。在此类情况下，该角色侧重于协同各方努力、鼓励、共情、必要时安抚，但最重要的是提供强有力的领导和清晰的方向。该角色真正处于一线。

## 运行人员

现在重点关注运行控制人员；即负责做出无数运行决策的人员。视航空公司运营所在国家的司法管辖区而定，运行控制员和调度员的许多职能是共通的，可由其中一方执行。在紧接着的章节中，将详细探讨各自的特征和职能。任何重叠都不影响必须执行若干任务这一事实，很快就会明显看出某些职能在一定程度上有交叉。除这两个角色外，还将简述 IOC 中的其他角色。
