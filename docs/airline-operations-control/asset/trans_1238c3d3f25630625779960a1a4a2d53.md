
# 前言

本书旨在深入剖析航空公司的神经中枢——通常称为其运行控制中心（OCC），或航空公司为管理这一至关重要的业务方面而选用的同等名称（请见本章后文的“术语”）。

航空业是一个高度复杂、动态变化且极具吸引力的行业。在此环境下，安全至关重要，容不得半点妥协，本书后续内容均坚实地建立在这一指令之上。时刻铭记这一点，航空公司在法律、财务和经济利润极薄的边际中运营，所处环境充满了复杂的运行挑战和扰动。要在这样的环境中生存并发展，需要适当的管理与领域专业知识、最先进的设施，以及复杂精密的系统和程序。

为实现航空公司的运行目标，高效且负责任的运行控制职责被赋予了一个由高技能专家从业者组成的核心机构。本书探索的正是他们的世界。

本书主要面向从业者；即那些兴趣或职业路径位于航空业务运行侧内部、跨领域或以其他方式相关联的人员，重点清晰地聚焦于核心或中央运行实体的活动。

本书分为两个截然不同的部分。

在第一部分中，第1章描述并解释了运行中心、其存在的理由、目的与理念以及结构特征。

第2章聚焦于在中心内工作的关键人员，特别是解释了关键角色——运行控制员所需的特征和技能组合，并提出了一些指导意见，以协助航空公司管理层招聘、甄选和培训合适的人员。本章目的之一是让航空公司管理层对胜任此角色所需的人员性格特质有透彻的认识。本章还解释了许多OCC共有的大量内部和外部关系。

第3章探讨了通向运行当天的广泛活动。本章解释了影响运行计划和准备的业务、商业和运行因素，以及相关职能部门在移交至日常运行控制之前所采取的许多行动。

第一部分的最后一章解释了OCC内部为使其运作而配备的各种复杂系统和工具。本章还描绘了运行中心内发生的流程，深入解释了正常和非正常运行，以及管理扰动的方法。本章阐述了运行控制员开展任务的方式。

第二部分建立在此框架和背景材料之上，将其中的概念应用于现实情境。因此，本书第二部分的目的是考察大量具有代表性的运行扰动，并系统地聚焦于负责管理此类问题的控制员的认知过程。

相关章节考虑了四个真实场景。

第5章弥合了本书基础性第一部分的差距，通过展示决策制定和解决飞机工程问题的概念如何在综合运行控制中心（IOC）内部转化为通知和高级思维过程、与关键利益相关者的各种互动与沟通，以及用于分析、行动和从扰动中恢复的方法。

在第6、7、8章中，每章都构建了一个详细场景，以代表可能发生在世界不同地区的典型航空公司扰动。这些场景经过有条理且一致的结构安排，以阐述决策过程中涉及的各个步骤，例如通过信息获取积累和增强态势感知、与各职能领域沟通、评估决策备选方案、做出最终审议并适当传播决策。

为辅助这一过程，在可能的情况下，渐进式图形显示被放置在对页，以增强评论并说明问题不断演变的解决方案；而在正文中，则使用图标来标示IOC内部发生的信息传递、思维过程和行动。通过这种方式，读者能更深入地了解涌现的问题以及为实现最优决策和问题解决而纳入考量的因素。

本书读者无论其身处航空业内部或外部，甚至身处另一运行环境中的当前角色如何，很可能会对运行中心所从事工作的性质和强度感到惊讶，因此本书旨在让读者熟悉航空运行中通常遇到的大量问题，并清晰阐述在优化运行效率和绩效的同时解决这些问题所需的思维过程。

## 1 运行控制

### 简介

本章将介绍并描述航空公司运行控制中心（OCC）的概念及其背后的基本原理、其存在的目的及其在航空公司运营中的重要性。该中心的结构、选址和组成在物理布局、复杂性和参与方的参与度方面均存在显著差异。本章的重点将是考察这些参与方之间的联系及其外部隶属关系，因为建立和维护紧密的工作关系是高效识别和解决问题的关键。
