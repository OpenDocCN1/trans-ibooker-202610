> You will need to employ super user privileges to have the lsof utility work correctly. If you receive no output from the lsof program, most likely you are issuing the command as a standard user.

In snipped Listing 10.10, the lsof utility’s output is filtered to display network sockets in a state of listening (-sTCP:LISTEN) for only TCP packets (-iTCP).
