After you have made any necessary configuration file modifications, the command to use is ssh -X user@remote-host. Similar to earlier ssh command uses, the user is the user account that resides on the remote-host system. The remote-host has the GUI utilities you wish to employ and can be designated via an IP address or a hostname.
