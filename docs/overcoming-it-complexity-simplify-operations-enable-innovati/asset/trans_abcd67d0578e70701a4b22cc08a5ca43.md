# 关于作者

**Lee Atchison** 是云计算领域公认的行业思想领袖，也是畅销书 [*Architecting for Scale*](https://www.oreilly.com/library/view/architecting-for-scale/9781492057161/)（O’Reilly）的作者，目前已出版第二版。Lee 拥有 36 年行业经验，其中包括在 New Relic 工作八年、在 Amazon 和 AWS 工作七年，他领导创建了公司的首个软件下载商店，创建了 AWS Elastic Beanstalk，并管理了 Amazon 零售平台向新服务化架构的迁移。Lee 已为领先组织提供咨询，指导他们如何大规模现代化应用架构并转型组织。Lee 是行业专家，广泛被 *InfoWorld*、*Diginomica*、*IT Brief*、*Programmable Web*、*CIO Review* 和 *DZone* 等出版物引用。他曾在全球各地活动上担任特邀演讲嘉宾，从伦敦到悉尼，东京到巴黎，以及整个北美。
