

[Figure 4-7](#ch04.html#fig_7_multiple_people_using_multiple_methods_to_update_t) 显示了一个具有内部配置的路由器的示例。此路由器通过 Web 浏览器或 API 调用进行配置，正如你所见，位于不同地点的网络工程师可以根据需要更新配置。

![](assets/oitc_0407.png)

当多人独立操作同一配置时，变更经常会发生冲突或相互矛盾。一人可能做出变更导致另一人的变更失败。结果是路由器不稳定，进而导致网络不稳定。此外，如果该路由器损坏需要更换，替换设备将不具有相同的配置，因此最初创建配置时所投入的所有知识和专业经验都将丢失。此外，在企业环境中，该路由器不会单独存在于网络中，它需要与数百甚至数千台其他路由器协同工作。按照这种方法，每台路由器都将拥有由许多不同人员手工定制的不同且独立的配置。随着时间的推移，所有这些设备的配置变得越来越定制化，越来越专业化。由于它们各不相同，整个系统的复杂性变得非常高——这一切都源于这些路由器配置文件管理方式。

现在来看 [Figure 4-8](#ch04.html#fig_8_in_a_centralized_configuration_model_changes_are)。在这里，用于配置路由器的网页和 API 调用已被禁用，通过这些方式进行配置不被允许。相反，配置的副本存储在设备之外，位于某个集中位置。每个需要对路由器配置进行变更的工程师都对其离设备副本进行变更。一旦这些变更获得批准，离设备副本就会被推送或部署到路由器以使其生效。对路由器配置进行变更的唯一允许方式是修改离设备副本，然后将其部署到设备，并且可以保留这些变更的历史记录。

该模型具有许多优势：

* 所有人员所做的变更都集中化，可以在部署到路由器之前由所有相关方进行审查。这降低了由一名工程师所做的变更对另一名工程师所做的变更产生负面或不可预见影响的可能性。
* 每次变更都可以记录在版本控制系统中，以便跟踪变更。如果发生网络问题，可以轻松审查修改历史记录以尝试确定哪个变更可能导致了问题。甚至可以在必要时回滚变更并将路由器恢复到之前良好的状态，直到问题得到充分调查。
* 变更可以在部署到生产路由器之前经过测试和审查周期。这甚至可能包括推送到暂存路由器以验证更新后的配置按预期工作，然后再将其部署到生产网络。
* 由于所有配置都位于中央位置，因此可供检查和审查。这鼓励复用，降低整体复杂性。
* 将变更推送到生产环境需要某种形式的 CI/CD 流水线。这意味着使用共享层和模板的过程可以轻松自动化。
* 如果路由器出现故障，可以用新设备替换，并立即将最新的配置文件推送到替换路由器，使其立即进入与旧路由器相同的状态。这简化了硬件维护操作。

![](assets/oitc_0408.png)

使用集中管理的配置可降低系统整体复杂性，提高可靠性、问责制、网络可用性，并最终提高应用程序和公司的成功率。

# Summary

简化知识需求和知识管理是降低系统复杂性和认知负担的重要部分。维护集中化配置是改善知识管理的一种策略；除了上面描述的所有好处外，它还能在进行变更时增强信心，并限制管理应用程序所涉及的业务风险。

但知识管理远不止于集中化配置文件。它是关于提供方法以减少为维护和操作系统所需知识的数量和多样性，并促进复用、简化和标准化，同时不危及快速推进的价值和鼓励创新。

有效管理知识需要在敏捷性和统一性、速度和完整性、复杂性和可理解性之间找到正确的平衡。最终，知识管理是在复杂系统中平衡短期敏捷性和长期可靠性。

# Chapter 5. Creating Your Technology Investment Framework

在你管理构建和运营 IT 基础设施的过程中，你会做出影响对应用程序和基础设施哪些领域进行投资的决策。影响投资决策的因素超出了本书的范围，但了解它们对整体系统规模和复杂性的影响非常重要。

随着公司的建立、维护和成长，它所做的所有投资都将纳入一个特定的框架，该框架要么促进业务，要么阻碍业务。目标是将尽可能多的投资——金钱和精力——集中在为业务带来所需投资回报的事情上，而尽可能少地投入在那些虽然对运营业务必要，但对其运营并非 *战略性* 的事情上。

## Technology Investment Framework Categories

技术投资因组织类型而异。从框架角度来看，投资不可避免地会落入以下三个类别之一：

### Sustaining

这些投资使公司保持运转。它们包括对基础设施的投资——如通信技术（电子邮件、电话）、办公空间和物理基础设施、财务管理和控制，以及人力资源。

### Disruptive

这些投资旨在建立和壮大业务。这可能包括开发新产品创意、为现有产品构建新功能，或将现有产品扩展到新的有趣市场。

### Performance

这些投资旨在使业务更高效、更具生产力。这可能涉及对营销和销售的投资，降低已售商品成本（COGS）或基础设施成本，以及优化流程和系统。

通常，公司投资优先级的转移取决于组织的成熟度以及所面临的商业环境。事实上，成功的公司了解自己在何处投资，并在时间推移中根据需要更新其投资。

公司需要在所有这些类别中投入资金和精力，但应 *关注* 更重要的事情。例如，考虑你的企业电子邮件系统。公司投资建设这一通信渠道以促进员工之间、以及员工与客户、合作伙伴和其他第三方之间的沟通。它是现代公司必备的基础设施组件。

但你应该在电子邮件系统上投资多少？是否应该聘请一支庞大的电子邮件专家团队来构建有史以来最伟大的电子邮件系统？还是应该每位员工支付几美元并为每个人提供一个 Gmail 账户？还是投资应该在中间某个位置？

要回答这个问题，我建议只需考虑这个基本问题：你从事的是电子邮件业务吗？
