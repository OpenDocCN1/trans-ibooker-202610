## 版记

封面上的动物是 *Cloud FinOps* 上的蓝头太阳鸟 (*Cyanomitra alinae*)。它们是生活在撒哈拉以南非洲大湖地区的小鸟。作为 Nectarinidae 科的成员，它们具有向下弯曲的喙和短翼，能够快速、直接飞行。它们具有性二态性，雄鸟的羽毛比雌鸟色彩丰富得多；它们的羽毛在明亮的红色眼睛映衬下闪耀着虹彩的蓝绿色。太阳鸟可以在卢旺达的 Nyungwe Forest National Park 国家公园的热带雨林到乌干达西南部 Bwindi-Impenetrable National Park 国家公园的茂密山地森林之间任何地方找到。

蓝头太阳鸟白天大部分时间在林缘和空地寻找食物。它以昆虫和小型蜘蛛为食，也吃花蜜，就像美国蜂鸟和澳大利亚吸蜜鸟一样。虽然与新大陆的对应物种无关，但太阳鸟也偏好以红色和橙色的管状花为食，并且具有刷状舌尖，可以提取花蜜。

蓝头太阳鸟在非洲生态系统中发挥着关键作用，因为非洲大陆许多最具代表性的植物（如芦荟、银合欢和天堂鸟花）依赖它进行授粉——以至于人们普遍认为太阳鸟一直是推动非洲植物物种形成的主要力量。
