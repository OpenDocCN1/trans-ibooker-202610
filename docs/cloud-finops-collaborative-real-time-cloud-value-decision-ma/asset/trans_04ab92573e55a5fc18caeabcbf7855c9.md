**J.R. **Mike Fuller** 是一名首席工程师，已在 Atlassian 从事云和 FinOps 工作超过十年。自撰写《Cloud FinOps》书籍第一版以来，Mike 在 Atlassian 内部组建了专门的 FinOps 团队，将角色和职责从云卓越中心移出，形成了一个由数据工程师、分析师和 FinOps 实践者组成的小团队。Mike 的团队帮助 Atlassian 从其在云上的支出中获得最大价值。作为 Atlassian 的首席工程师，Mike 也是 Insights 团队的架构师，负责优化领域专家（安全、合规、FinOps、可靠性）与 Atlassian 全球员工工程师互动的方式的策略。

Mike 持有卧龙岗大学计算机科学学士学位，并完成了九项 AWS 认证。他在多场 AWS re:Invent 和 AWS Summit 活动中就 AWS 安全和 Cloud FinOps 等主题发表演讲。Mike 曾担任 FinOps 基金会技术顾问委员会成员，目前是其理事会成员。多年来，Mike 在全球范围内结识了许多在各自组织中担任 FinOps 领导者的朋友。这些联系帮助塑造了 Mike 对 FinOps 成功意味着什么的思考。

Mike 与妻子 Lesley 和两个孩子 Claire 和 Harrison 一起生活在澳大利亚南海岸。他们在让澳大利亚闻名的美丽海滩和乡村景观之间分配家庭时间。
