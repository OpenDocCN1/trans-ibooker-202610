# Summary

Congratulations! You have created an awesome sports graphic project! We have learned how to create a dynamic composited video project. Understanding how to track video footage, apply color correction, and apply lighting effects will help you to create convincing, professional quality projects. The tools are used in movies, television, and music videos. Anytime you see a 3D element in a movie, it is using 3D tracking software. Traditionally this process is done using an expensive camera tracker. But now, After Effects has its own camera tracker, and you know how to use it! Now, you can track a shot and add 3D elements to it all in After Effects. How cool is that! Movie standard effects at your fingertips! This chapter sets the tone for our next lesson on combining visual effects, live action footage, and 3D camera tracking. Join us in the next chapter, where we will continue working with effects, and learn about camera tracking.
