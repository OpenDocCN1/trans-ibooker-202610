# Importing Illustrator files into C4D

When you save your files from Illustrator, choose the Illustrator option. Here, you can choose the version you want to save your file as. Choose the old version of Illustrator 8; this version is compatible with C4D. See the following screenshot for the Illustrator Version option tab:
