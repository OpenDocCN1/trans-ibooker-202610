# Creating text in C4D

You're doing a great job with your C4D project! Let's create some 3D text with the text tool. The text tool is located in the spline tab. Navigate to the Text tool as indicated in the following screenshot:

![](bbox=[0.07, 0.18, 0.92, 0.5])

Text tool

To add a text object, follow these steps:

+   1. Click the spline tab
+   2. Click the Text tool

A text layer will appear in your project after selecting the Text tool:

Now let's type the word imagine in the Text tool object panel. This will create the text in your project. You can further edit your text's size, horizontal spacing, and the kerning of your text. In this panel, you also can select your fonts. Let's create geometry for our text by following the steps:

+   1. Use the Arial Black font for the text
+   2. Add an Extrude nurb
+   3. Make the text the child of the Extrude nurb
