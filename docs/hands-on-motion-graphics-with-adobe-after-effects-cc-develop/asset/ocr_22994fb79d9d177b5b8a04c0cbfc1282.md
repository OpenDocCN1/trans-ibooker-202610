This will add a duplicate of your material in the materials bin.

To add materials to your objects, simply select the material from the materials bin and drag it onto the object in the main composition. You will see an icon of that color in the layer panel. Additionally, you can add color to the caps for your text as well. Follow the steps to add color to your text caps:

+   1. Drag the colors you want to use onto your Text Extrude object.
+   2. Choose the material icon in the Layer panel.
+   3. Select the tag.
+   4. Choose the Selection in the tag panel.
+   5. Type C1 for the front color.
+   6. Type R1 for the side color. The following screenshot shows how to add multiple materials to an object. Look to the multiple materials on the far right of the object panel:
