Let's exit this view mode by clicking on the view port icon. Go back to the front view. As you can see, we have a spline that's parallel to the ground plane. Having your path parallel to the floor ensures the geometry of the ribbon will be correct; that why it's essential you model the path in the top view. Let's create some geometry for the spline to make it look more like a ribbon:

+   1. Click on the nurbs icon
+   2. Choose a Sweep nurb

Next we need to add another spline to our object. Let's add a rectangle to help to model our object:

+   1. Click on the spline icon
+   2. Choose the rectangle shape
+   3. Choose the scale tool and scale down the rectangle
+   4. Place the rectangle and the spline object in the sweep object
+   5. Select the rectangle object
+   6. Increase the height of the rectangle so the ribbon's height increases
