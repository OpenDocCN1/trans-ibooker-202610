Let's create the wings for our logo. We are going to follow the same steps as we did when we imported the crest shape. Follow these steps:

+   1. **Merge...** the Illustrator wings file into the project
+   2. Add the **Extrude** object to the project
+   3. Choose the **Extrude** nurb object
+   4. Check hierarchical
+   5. Adjust the far-right movement parameter as we did with the crest object
