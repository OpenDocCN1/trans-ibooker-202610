Let's animate our logo. Put all of the logo layers into a null called logo. Now we can animate the logo in a group. We want the logo to spin around and resolve with it facing the front. Follow the steps to animate the logo:

+   1. Select the logo null.
+   2. Choose the rotation tool.
+   3. Click the Record Active Objects button in the timeline. You will see a green key frame timeline.
+   4. Move down in the timeline.
+   5. Rotate the logo so it rotates several times.
