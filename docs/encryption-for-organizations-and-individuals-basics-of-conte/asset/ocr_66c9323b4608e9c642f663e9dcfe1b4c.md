The greatest common divisor is best derived using the basic Euclidean algorithm. This method refers to the factorizing of the two numbers in question and the multiplication of their common factors.

Here’s another example of the basic Euclidean algorithm as in how to count the greatest common divisor. Let’s have some jolly good fun with two composite numbers. The number 64 can be factored like this: 2 x 2 x 2 x 2 x 2 x 2. The other number we’ll pick, 1096, can be factored like so: 2 x 2 x 2 x 137. These numbers have three common factors (2 x 2 x 2).
