Here’s digital media organization in a yellow walnut: a *sector* on a **hard drive** usually refers to its smallest unit of storage spanning either 512 or 4096 bytes. The smallest unit of storage in a **solid-state drive (SSD)** is called a *page*. This usually refers to 4 kilobytes of data (i.e., 4096 bytes). *Blocks* are groups of sectors assigned by an operating system.

# The Wonders of File Systems

A *file system* is a piece of software which manages how and where data on a storage device is maintained. Different operating systems may have different, and sometimes incompatible, file systems. Commonly, an operating system has both a proprietary file system format and several more or less universally compatible file systems at its disposal. Let’s review some of the most common file systems and how they relate with one and other (see Table 4-1).

*Table 4-1. A summary of current-day file system support between operating systems*

| NTFS | Software required | Software required | Supported |
| Mac OS Extended (HFS+) | Supported | Configuration required | Software required |
| Apple File System (APFS) | Supported | Software required | Software required |
| FAT | Supported | Supported | Supported |
