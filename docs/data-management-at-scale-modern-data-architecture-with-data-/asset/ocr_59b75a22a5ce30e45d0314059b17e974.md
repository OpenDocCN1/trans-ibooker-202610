To see how the microservices architecture fits into the more comprehensive API architecture, take a look at Figure 5-5. In this figure, we see three different API patterns:

+   - At the top sit the modern applications, which can be exposed directly via the API gateway. In this pattern the application uses modern communication protocols, such as REST/JSON.
+   - In the middle are the legacy applications, which require additional decoupling via the ESB. The ESB service can be wrapped into the API gateway.
+   - At the bottom sit the microservices. Microservices communicate internally via the service mesh. APIs, which need to be exposed externally, are decoupled via the API gateway.
