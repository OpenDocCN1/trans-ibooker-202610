## 数据大规模管理

数据管理正面临颠覆。人工智能、云化、生态系统连接、微服务、开放数据、软件即服务和新的软件交付模式等趋势正在导致数据管理实践方式的范式转变。组织需要直面这样一个事实：去中心化是不可避免的。在这本实用书中，作者皮特海因·斯特伦霍尔特解释了如何建立具备未来保障且可扩展的数据管理实践。他将剖析数据网格和数据架构等新概念，并演示下一代数据架构的样子。

高管、架构师和工程师、分析团队以及合规和治理人员将学习如何根据自身需求塑造数据管理。斯特伦霍尔特提供了蓝图、原则、观察、最佳实践和模式，助你快速上手。

本指南将向你展示如何：

- 审查数据管理趋势，包括监管要求、隐私问题以及数据网格和数据架构等新发展
- 深入构建现代数据架构，包括云数据落地区域、领域驱动设计、数据产品设计等
- 探索数据治理和数据安全、主数据管理、自助数据市场以及元数据的重要性

皮特海因·斯特伦霍尔特是微软荷兰的首席数据官。他担任CDO的对话者，是社区和产品组的推动力。皮特海因也是多产的博主，经常就数据管理的最新趋势发表演讲，包括数据网格概念、数据治理和大规模战略。
