# Step 7: Admin Center – Setting Up Event Notification Subscription

Navigate to Admin Center ➤ Tools ➤ Event Notification Subscription.

The first step in “Event Notification Subscription” is to define a subscriber. You can add a new one by clicking “Edit Subscriber.” The only significant fields are the Subscriber Id, and you can set them to the same value.

Figure 8-7 is an example of a completed subscriber.

# Notes:

+   1. The important fields to configure are the Subscriber Id (this matches the vendorId in step 5), Name, and Client Id.
+   2. If the vendor you’re connecting to has a common endpoint for all customers, it’s a good practice to have a unique client ID for each customer.
