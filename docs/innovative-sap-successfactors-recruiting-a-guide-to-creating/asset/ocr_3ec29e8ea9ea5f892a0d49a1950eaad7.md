+   - The feed can be prefiltered using rules if the postings need to be categorized by specific countries, divisions, job functions, etc.
+   - The apply URL can have a campaign code parameter assigned specific to the rule (the UTM_Campaign parameter), to give more accurate advanced analytics information.
