# Step 15: Admin Center – Troubleshooting Your Integration

Navigate to Admin Center ➤ Event Notification Audit Logs. See Table 8-1 on how to set permissions. If the status says “Error Initiating Order” (Figure 8-19), you should then look at the event audit log. If the following status field indicates DELIVERED, then your integration is successful. If the status indicates FAILED, then you have to click the View hyperlink against each error. The audit log shows the request and response.
