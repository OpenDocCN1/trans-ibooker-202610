# Business Scenario

To quickly review, in our scenario, an HRIS system has passed minimum and maximum recommended salary values to our requisition as part of a requisition creation interface like you have built in Chapter 2. In addition, an assessment vendor has passed an assessment score to our application such as what has been built in Chapter 8. Using these as inputs, we can now build a rule that populates a recommended salary on the offer template. A diagram of this data flow is shown in Figure 11-13.
