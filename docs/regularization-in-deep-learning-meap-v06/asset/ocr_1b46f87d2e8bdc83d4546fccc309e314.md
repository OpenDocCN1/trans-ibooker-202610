The number of breakpoints further grows into a total of 2^5 = 32 when there are five hidden layers as shown in in figure 4.9. However, only a total of 2*5=10 nodes are used in the hidden layers, which corresponds to a maximum of ten breakpoints using a shallow neural network. The exponentially increasing linear segments also suggest that a deep neural network with multiple hidden layers can represent a much larger function class than shallow ones. Deep neural networks thus benefit from the exponential growth in expressivity compared with shallow counterparts.

Another empirically observed drawback for shallow networks is the tendency to memorize the input data directly instead of learning the underlying pattern to generalize to future unseen datasets. For example, an extremely wide network could eventually memorize the training data and produce zero training error. On the other hand, a deep neural network with multiple layers can learn features at different levels of abstraction, resulting in intermediate hidden features that eventually contribute to generalization. For example, low-level compositional features such as edge and corner in the early hidden layers are automatically extracted and learned in image recognition tasks. Together, they create more abstract and high-level features such as shapes and objects in the final hidden layers to facilitate more effective pattern recognition.

In summary, the number of breakpoints and linear segments, an indicator of model complexity, grows exponentially with the number of hidden layers in the neural network. The depth of the neural network increases complexity much more than the width, and a deep neural network is powerful enough to represent/approximate functions of arbitrary shapes.
