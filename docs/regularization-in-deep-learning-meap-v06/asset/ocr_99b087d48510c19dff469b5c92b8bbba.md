Let us look at a simple linear equation case consisting of two input variables, one output variable, and a single observation. In other words, we would like to solve for w = [w1, w2] in y = x^T w = x1w1 + x2w2. Since there is only one observation available, there are an infinite number of solutions of w that satisfies this equation. Graphically, we could plug in the observation value (x, y) and obtain a line on a coordinate system with w1 and w2 as the axes. This line represents all the possible (infinite) solutions that satisfy the constraint imposed by the linear equation, and any point on the line represents one solution. Figure 7.14 Visualizing the geometric interpretation of ridge regression. All possible solutions jointly form the line. Using the L2 norm gives a unique solution at the intersection between the line and the circle, where the radius is the smallest. Any other point would intercept a larger radius and thus a larger L2 norm.

Here, we keep drawing circles from the origin and increasing the radius until we intersect the line. This point of intersection represents the solution to the optimization problem. While the line is a collection of infinitely many, equally good solutions, using the L2 norm enforces a unique solution with the smallest radius among many circles, each corresponding to a different L2 norm. To see the correspondence between L2 norm and the radius of the circle, note that ||w||_2 = sqrt(w1^2 + w2^2). All points (solutions) on the circle thus share the same L2 norm.
