
In this chapter, we will uncover different forms of penalty terms in the objective function. The penalty term serves as an explicit regularizer that induces a desired property of the resulting estimator (i.e., the weight configuration), such as sparsity via $l^1$-norm-based (only a subset of features is selected in the final model) and $l^2$-norm-based regularity (a small weight is preferred over a large weight). Devising a composite objective function with novel and domain-specific penalty terms is an exciting research field. We aim to lay the foundation for readers in terms of common approaches currently used in training deep neural networks.

## 7.1 Introducing the regularization term

In the context of a deep neural network, we encountered sparsity as a form of regularization in the previous chapter. For example, when using the dropout technique during training, a sparse network is obtained by randomly disabling specific nodes in a neural network. The weight-sharing property in the convolution operation also plays the same role as having a sparse network. By reducing the number of parameters as a form of regularization, the algorithm is less likely to select an overly complex model and, therefore less prone to overfitting.

A sparse neural network is also computationally faster and more scalable. For example, although fruit flies or ants have roughly 250K neurons in their brains, they can still perform complex tasks such as motion sensing and food seeking. A neural network of this size is barely mid-sized in the modern deep-learning era. However, we would need a much bigger network to achieve a similar task, as shown by the increasingly complex models in autonomous robots. The neuron-level sparsity, i.e., each neuron is only connected to a subset of downstream neurons, is becoming an essential property in robust neural networks. When recognizing a face, only a specific part of our brain is activated, and the rest remains inactive. It is thus essential to channel the input signal to the right regions in a neural network and avoid redundant computations that contribute little to the correct prediction.

Similarly, of all the 86 billion neurons in a human brain, a typical neuron is only connected to dozens of thousands of other neurons on average. Such a sparse connection also manifests in a convolutional neural network, where each neuron of the current layer only receives input information from a small patch in the previous layer. As shared in the last chapter, the sparse connection in CNN is essentially a fully connected network (FCN) with zero weights in most of the connections. However, designing an architecturally sparse and efficient network is better than starting with an FCN and learning the nonzero weights since we can avoid multiplying the zero weights with the input matrix and summing up all the zeros for follow-up non-linear transformation.

A sparse representation is even more advantageous in the case of high-dimensional problems. For example, when treating each pixel as a separate feature in an image recognition task, there are as many weights to be estimated as the number of pixels when using a simple linear regression model. These weights are likely to be correlated, especially when physically close to each other. When one weight increases in value, the nearby weight may either go up (causing overfitting) or down (compensating for the increase). Therefore, we need to enforce certain conditions on the weights so as to induce a preference for a simple and parsimonious model.

Before we introduce the regularization term in the objective function to control the magnitude and/or sparsity of the estimated coefficients, let us revisit the linear regression setting where we aim to minimize the residual sum of squares (RSS).

### 7.1.1 The unregularized linear regression

To start, let us express the objective function as the cost function Q(w); that is, for a given set of weights w, there is a corresponding scalar cost value Q(w). In the context of linear regression, imagine we are given a training set { (xi, yi) }i=1n, where xi denotes the list of input features for the ith observation, yi is the corresponding scalar target, and there are a total of n observations in the dataset. Given a set of weights w, the linear regression model can make a prediction f(xi; w) for the ith observation, after which the predicted value f(xi; w) will be compared with the corresponding target value yi to indicate the quality of the prediction. The quality of all individual predictions will then be aggregated into a single evaluation metric, Q(w).

As covered in chapter 2, the cost function Q(w) can be expressed as the residual sum of squared error: Q(w) = Σi=1n(yi − f(xi; w))2 , where the squaring operation unifies both positive and negative errors, and larger errors incur a bigger cost than smaller ones. Alternatively, we can also express it as Q(w) = Σi=1n(yi − f w (xi))2 , where f w (xi) represents the prediction for xi given weights w. This is the most widely used cost metric for regression problems.

We can also rewrite the RSS Q(w) using matrix notation, a more compact way to represent the joint cost for all n observations. This gives Q(w) = ||y − Φw||2 , where Φ denotes the new design matrix after transforming the original design matrix X. Such notation is more general since Φ = X if there is no transformation to the input matrix. The RSS cost Q(w) is based on the linear model y = Φw + ϵ, where y is the target variable manifested in an n × 1 vector, Φ is an n × d design matrix, w is a d × 1 vector of weights, and ϵ is an n × 1 vector of random errors. We can equivalently express the RSS as Q(w) = Σi=1n(yi − φ(xi)T w)2 = (y − Φw)T (y − Φw). See figure 7.2 for an illustration on the linear model and the RSS objective function.

The minimizer to the unregularized linear regression model can be obtained by setting the gradient of \(Q(\mathbf{w})\) to zero, since \(Q(\mathbf{w})\) is a quadratic function of \(\mathbf{w}\). We can obtain the analytic gradient vector \(\nabla Q(\mathbf{w}) = -2\mathbf{\Phi}^T(\mathbf{y} - \mathbf{\Phi w})\). Setting the gradient vector to zero gives us the same normal equations as in chapter 2: \(\mathbf{\Phi}^T\mathbf{\Phi w}^* = \mathbf{\Phi}^T\mathbf{y}\). Multiplying by \((\mathbf{\Phi}^T\mathbf{\Phi})^{-1}\) at the beginning of both sides produces the closed-form solution for the least squares estimator \(\mathbf{w}^{LS} = \mathbf{w}^* = (\mathbf{\Phi}^T\mathbf{\Phi})^{-1}\mathbf{\Phi}^T\mathbf{y}\).

### 7.1.2 Norm-based penalty

The norm-based penalty is a common technique to encourage the model to prefer solutions with smaller weights and thus avoid overfitting.

As also covered in chapter 3, we would add a penalty term \(J(\mathbf{w}) = \int f''_w(x)^2 dx\) to control the curvature of the model and therefore prevent overfitting. This regularization term is often multiplied by a hyper-parameter \(\lambda\) to negotiate between the goodness of fit to the training data and the roughness of the resulting model. The penalized cost function thus becomes \(Q(\mathbf{w}) = \sum_{i=1}^n (y_i - f_w(\mathbf{x}_i))^2 + \lambda \int f''_w(x)^2 dx\), and the resulting model is called smooth splines.

In addition, we also touched upon ridge regression in chapter 2, where the penalty term becomes \(J(\mathbf{w}) = \|\mathbf{w}\|_2^2 = \sum_{i=1}^d w_i^2\), where \(d\) is the total number of features in the dataset, and \(\|\mathbf{w}\|_2 = \sqrt{\sum_{i=1}^d w_i^2}\). This is the squared \(L^2\) norm, which measures the magnitude of the estimated weights. Correspondingly, the penalty function using the \(L^1\) norm is \(J(\mathbf{w}) = \|\mathbf{w}\|_1 = \sum_{i=1}^p |w_i|\), which also gives a sparse solution as an added benefit of feature selection.
