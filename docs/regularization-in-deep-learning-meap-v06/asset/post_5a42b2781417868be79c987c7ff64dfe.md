Figure 7.6 Illustrating the coordinate-wise update rule using the gradient descent algorithm. Compared with the update rule for least squares using RSS only, the ridge regression will first scale down the original weight before going through the same update.

Note that compared with the update rule for unregularized least squares, the only change lies in the multiplier $(1 - 2\eta\lambda)$ for the first term, which effectively shrinks the scale of the original $w_j$. To see this, recall that both $\eta$ and $\lambda$ are manually selected positive numbers, often starting with small values. When $2\eta\lambda < 1$, the multiplier is essentially shrinking $w_j^{(t)}$ by a certain amount, followed by the same update term from the unregularized RSS. This interpretation is not necessarily the case when we set a big value for $\eta$ or $\lambda$, giving $2\eta\lambda > 1$.

Let us visualize the shrinkage effect in ridge regression. Figure 7.7 shows an example update path from $w_j^{(t)}$ to $w_j^{(t+1)}$. When using gradient descent update in ridge regression, the first operation is to shrink the current weight in order to control the model complexity in terms of the magnitude of the weight. Such an operation helps reduce overfitting. Afterwards, the update continues based on the goodness of fit between the model and the data. The unregularized linear regression model using least squares, however, only focuses on fitting the model to the data at every iteration, which increases the chance of running into overfitting.

![](img/ee98e91e6845f41077b163bec833ee40_231_0.png)

Figure 7.7 Comparing the least squares update and the ridge regression update using the coordinate-wise gradient descent algorithm.

The overall optimization algorithm using coordinate-wise gradient descent, where all observations are used to calculate the gradient in each update, can be described as follows. We will first initialize a starting point for the weight vector at the beginning of the optimization. This can be done by setting w = 0 or randomly. Then we would iterate through each weight/coordinate, applying the update rule using ridge regression. This completes one round of optimization. This process repeats until the L1 norm of the gradient of RSS or its percentage change is less than a preset parameter r, such as 0.01%. We can also use other criteria to determine if the optimization procedure has converged. Figure 7.8 describes the full optimization procedure.

Initialize $\mathbf{w}^t$ at the beginning of optimization when $t = 0$
While $\| \nabla RSS(\mathbf{w}^t) \|_1 > \tau$:
For each $j$ in $[1, ..., d]$:
$$ w_j^{(t+1)} \leftarrow (1 - 2\eta\lambda)w_j^{(t)} + 2\eta \sum_{i=1}^n \mathbf{\Phi}_{ij} \left( y_i - \sum_{k=1}^d \mathbf{\Phi}_{ik} w_k^{(t)} \right) $$
$t \leftarrow t + 1$

Before we jump into the implementation, let us look at one more important detail: handling the bias term.

### 7.2.3 Handling the bias term

The bias term, also called the intercept term, refers to a weight that does not multiply any feature in the model and acts as a level shift. When adding the bias term, the model becomes $y_i = \sum_{j=0}^d w_j \mathbf{\Phi}_{ij} + \epsilon_i = w_0 \mathbf{\Phi}_{i0} + w_1 \mathbf{\Phi}_{i1} + \dots + w_d \mathbf{\Phi}_{id} + \epsilon_i$ for the \(i^{th}\) observation, where \(\mathbf{\Phi}_{i0} = 1\) is an entry of value one added manually based on the bias trick covered in chapter 2, and there is a corresponding new entry of \(w_0\) at the beginning of the weight vector \(\mathbf{w}\).

Based on the formulation of the objective function for ridge regression, the total cost now becomes \(Q(\mathbf{w}) = RSS(\mathbf{w}) + \lambda ||\mathbf{w}||_2\), where the first entry \(w_0\) is also penalized and encouraged to be small in magnitude. However, penalizing the bias term is not advised as it does not contribute to the overfitting behavior of the model.

There are two workarounds for the bias term. We can choose not to penalize the bias term, making \(Q(\mathbf{w}) = RSS(w_0, w_{rest}) + \lambda ||w_{rest}||_2\), where the squared \(L2\) norm includes all the weights except for the first entry. To implement this in the closed-form solution of ridge regression, i.e., \(\mathbf{w}^{ridge} = (\mathbf{\Phi}^T \mathbf{\Phi} + \lambda \mathbf{I})^{-1} \mathbf{\Phi}^T \mathbf{y}\), we can set the first entry of the identity matrix \(\mathbf{I}\) to zero, giving a modified version of the identity matrix \(\mathbf{I}^{modified}\) and the corresponding analytic form \(\mathbf{w}^{ridge} = (\mathbf{\Phi}^T \mathbf{\Phi} + \lambda \mathbf{I}^{modified})^{-1} \mathbf{\Phi}^T \mathbf{y}\). As for the gradient descent algorithm, we can simply add a special case for \(w_0\) to make it follow the update rule based on RSS alone, namely \(w_0^{(t+1)} \leftarrow w_0^{(t)} + 2\eta \sum_{i=1}^n \mathbf{\Phi}_{ij} (y_i - \sum_{k=1}^d \mathbf{\Phi}_{ik} w_k^{(t)})\). In the case that you do not want to change either algorithm, one way is to transform the data by centering the target vector y. Centering the target variable ensures that it will have a mean of zero, so that it does not make a big difference whether we penalize the magnitude or not. In other words, we can run the closed-form solution or regular gradient descent update in ridge regression without differentiating the weight for the bias term.

Ridge regression thus allows us to account for many features in a standard linear regression setting. It gives us a handle (the hyperparameter \(\lambda\)) to balance bias and variance.
