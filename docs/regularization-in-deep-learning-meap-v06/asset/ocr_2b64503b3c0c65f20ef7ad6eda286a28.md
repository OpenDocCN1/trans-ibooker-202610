Before we end this chapter, it is important to note that the regularization term can be placed over certain groups/layers of parameters, instead of all the parameters in the network. Also, there are multiple ways to implement the regularization term. For example, when defining the optimizer using SGD, there is an argument called weight_decay, which we can use to specify the weight of the L2 penalty term.

Adding regularization as an additional loss term inside the objective function is an active area of research. We hope you get a good starting point after reading this chapter and continue exploring more exciting and domain-specific regularizing terms in your future adventure.
