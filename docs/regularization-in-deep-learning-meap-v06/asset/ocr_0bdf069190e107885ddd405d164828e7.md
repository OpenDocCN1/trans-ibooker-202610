Using matrix notation, the prediction functions can be written as \(f_w = \Phi w\), where \(\Phi\) represents the list of polynomial basis functions used to derive the new design matrix, and **w** contains the list of weights to be optimized. We can now rewrite the cost function as follows:

\(Q(w) = ||y - \Phi w||^2 + \lambda w^T \Omega w\)

where \((\Phi)_{jk} = \phi_k(\mathbf{x}_j) = \mathbf{x}^k_j\) in the new design matrix \(\Phi\) denotes the \(k^{th}\) polynomial function \(\phi_k\) applied to the \(j^{th}\) vector **x**_j_. The double vertical bars denote the squared norm of \(\mathbf{y} - \Phi w\), i.e., the sum of the square of each individual residual. \(\Omega\) denotes the integrated second derivatives after leaving out the weights, where \((\Omega)_{jk} = \int \Phi''(x) \Phi''(x) dx\).

As we will learn in a later chapter, this form of writing is similar to the cost function of ridge regression, with an extra \(\Omega\) term added in the penalty. For those who are familiar with ridge regression, the normal equations are \((\Phi^T \Phi + \lambda \mathbf{I})w = \Phi^T y\), where **I** represents an identity matrix, i.e., a square matrix with ones on the main diagonal and zeros elsewhere. The closed-form solution of our cost function _Q_(_w_) is more general: \((\Phi^T \Phi + \lambda \Omega)w = \Phi^T y\), which can be simplified to the solution for ridge regression when \(\Omega = \mathbf{I}\).
