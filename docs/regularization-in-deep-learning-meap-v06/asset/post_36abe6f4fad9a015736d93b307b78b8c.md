## 7.3 Sparse estimation via LASSO

The l1-norm-based penalty is also called LASSO, which stands for Least Absolute Shrinkage and Selection Operator. When penalizing the sum of the absolute value of the weights, we are essentially performing variable selection and model estimation at the same time. The variable selection comes as a natural byproduct of LASSO: when penalizing the magnitude of the weights using their absolute values, some weights will be set to zero, thus equivalently dropping out of these unimportant features from the total feature space. The features that survive in the final model are considered more important, and the resulting model is more parsimonious. Regularizing the l1 norm of the weights thus promotes a sparse solution to a system of linear equations.

Before we look at the driver of sparsity using l1 norm, let us revisit the l2 norm from a geometric perspective and build our intuition on LASSO-based sparsity from there.

### 7.3.1 Geometric interpretation of ridge regression

Ridge regression allows us to solve an under-determined system of equations by penalizing the L2 norm of the weights. That is, when there are more unknown variables than equations in a system of equations, the ridge penalty could produce a unique solution with a minimal L2 norm of the weights. In contrast, there are infinitely many solutions to the under-determined system without using any penalty on the weights.

Let us look at a simple linear equation case consisting of two input variables, one output variable, and a single observation. In other words, we would like to solve for w = [w1, w2] in y = x^T w = x1w1 + x2w2. Since there is only one observation available, there are an infinite number of solutions of w that satisfies this equation. Graphically, we could plug in the observation value (x, y) and obtain a line on a coordinate system with w1 and w2 as the axes. This line represents all the possible (infinite) solutions that satisfy the constraint imposed by the linear equation, and any point on the line represents one solution. See figure 7.14 for an illustration.

![](img/ee98e91e6845f41077b163bec833ee40_243_0.png)

Figure 7.14 Visualizing the geometric interpretation of ridge regression. All possible solutions jointly form the line. Using the L2 norm gives a unique solution at the intersection between the line and the circle, where the radius is the smallest. Any other point would intercept a larger radius and thus a larger L2 norm.

Here, we keep drawing circles from the origin and increasing the radius until we intersect the line. This point of intersection represents the solution to the optimization problem. While the line is a collection of infinitely many, equally good solutions, using the L2 norm enforces a unique solution with the smallest radius among many circles, each corresponding to a different L2 norm. To see the correspondence between L2 norm and the radius of the circle, note that ||w||_2 = sqrt(w1^2 + w2^2). All points (solutions) on the circle thus share the same L2 norm.

### 7.3.2 Introducing the L0 norm

In some cases, we would also want to obtain a solution that satisfies the linear equation and has as many zero weights as possible, thus being a sparse solution. A direct approach is to penalize the L0 norm of the weights to obtain a sparse solution where some weights are zero.

The L0 norm is defined as the number of non-zero elements in a vector. In our context, ||w||0 = #{i | wi != 0}, where i ∈ {1, 2}. Penalizing the L0 norm means finding the sparsest solution with the minimal number of non-zero elements, an NP-hard problem that requires evaluating all possible subsets of features. Figure 7.15 illustrates the scenario when solving the linear equation subject to a constraint on the L0 norm, where the solution has to live on either axis so that only one weight is non-zero. Note that we are still locating the solution with the minimum L0 norm; thus, any solution that grows out of the intersection point is ruled out. In this case, the bolded dot represents the optimal solution, which gives a sparse solution by setting w2 = 0.

![](img/ee98e91e6845f41077b163bec833ee40_244_0.png)

Figure 7.15 Geometric interpretation on solving the linear equation with L0-norm-based penalty. While all solutions have to live on the straight line, the L0 penalty only requires the solution to stay at either axis to generate a sparse solution. Solving the linear equation subject to L0 penalty is an NP-hard task as the usual convex optimization technique from before (setting the gradient to zero) fails in this case.
