Therefore, we can express the partial derivative of \(\lambda|w_j|\) with respect to \(w_j\) into three different cases. When \(w_j < 0\), the partial derivative of the LASSO penalty term is \(\lambda \partial_{w_j}|w_j| = -\lambda\). When \(w_j > 0\), we have \(\lambda \partial_{w_j}|w_j| = \lambda\). When \(w_j = 0\), we have \(\lambda \partial_{w_j}|w_j| = [-\lambda, \lambda]\).

Putting it together, the partial derivative of the objective function with respect to a single weight \(w_j\) can also be expressed in three cases. That is, when \(w_j < 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = 2z_j w_j - 2\rho_j - \lambda\); when \(w_j = 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = [-2\rho_j - \lambda, -2\rho_j + \lambda]\); when \(w_j > 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = 2z_j w_j - 2\rho_j + \lambda\).
