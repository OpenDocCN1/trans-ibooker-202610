Figure 1.8 Four possible bias-variance scenarios. The first region has high bias and low variance, due to the trained model being too simple and possibly underfitting. The second region is the ideal state, with bias and variance both being low. The third region has high bias and variance, suggesting that the model deserves further training to learn the underlying pattern. The fourth region indicates an overfitting model that has low bias but high variance.

In figure 1.8, the first and fourth regions correspond to underfitting and overfitting, respectively. When training a model, we usually start from the third region, where both errors are high. As the model gradually improves and becomes more complex, we will come across the first region due to better pattern recognition - the model's predictions become more stable by learning the underlying patterns. Now, if we are lucky, we may reach the second region, where both errors are low, without much trouble. However, it is more common in practical model training to see excessively trained and overly complex models that may get stuck in the fourth region.

Proper regularization could help us reach the target region, namely the low bias and low variance region, in multiple ways. As shown in figure 1.9, example training paths could follow 3 -> 1 -> 2, 3 -> 1 -> 4 -> 2, or others, depending on the specific regularization strategies used.

![](img/ee98e91e6845f41077b163bec833ee40_18_0.png)

Figure 1.9 Example model training paths using proper regularization. There are multiple ways to build a generalizable model with low bias and variance as in region 2. Depending on the similarity between the training set and the test set, as well as the model class and training strategy used, the model training path could travel in multiple ways. With proper regularization, the final trained model will hopefully reach region 2.

In order to reach a good balance between bias and variance, the model needs not be too simple or complex, assuming a decent amount of data that encompasses sufficient variability for the model to learn. In other words, it should not be underfitting or overfitting. In practice, we want to minimize the total error, consisting of both bias and variance. We will formalize the formulation of the total error in Chapter 2. Using proper regularization, we could reduce the model variance at the expense of a slight increase in the bias term, thus lowering the total error as a whole. A model with reduced variance is more likely to produce stable and robust results. Plus, with only a slight increase in the bias, we could still ensure the average prediction is within the close neighborhood of the true target.

It is worth noting that the trade-off between bias and variance may not always stand. Given enough training iterations, sufficiently parameterized models such as deep neural networks could learn to reduce variance even when the bias is zero. This is called the “double descent” phenomenon, as shown in figure 1.10.

![](img/ee98e91e6845f41077b163bec833ee40_19_0.png)

Figure 1.10 The double descent phenomenon using complex models such as deep neural networks. As the model continues to become more complex, we will start to observe increasing performance in the test data, where the variance continues to decrease when the bias is zero.

In this regime, the bias-variance decomposition may not necessarily imply a trade-off between the two. As long as we give enough training time for deep neural networks, we will eventually see the test performance pick up again and jump out from the curse of overfitting. Why do deep learning models still end up with generalizable models, even when they are highly complex and overfitting the training data? The short answer is that deep neural networks, especially when trained using stochastic gradient descent, implicitly regularize the model estimation process and thus are more likely to generalize to the test set. We will cover the “double descent” phenomenon in chapter 3 and the implicit regularization effect of the stochastic gradient algorithm in the later chapters.

## 1.5 More on the model training path

Let us dive slightly deeper into the model training path. The typical machine learning pipeline starts with the objective of minimizing a given loss function, typically the training set error, hoping that the trained model also performs well in the future test set. Similar to the exam case, four possible scenarios come out of this. First, both training set error and test set error are high. This means that the model has not been able to pick up the patterns from the training dataset, and requires further improvement by either training longer, adjusting other hyperparameters, or changing to another model class. This is the case of underfitting.

The training could also result in a high training set error, and surprisingly a low test set error. Is this likely to happen? Rarely, since an insufficiently trained model is unlikely to perform well in the test set. The test set is often assumed to follow the same data generating distribution as the training set. However, both are usually disrupted by random noises that obscure the actual pattern that maps the input to the output.

It is also possible to see a low training set error and a high test set error. This is the overfitting scenario, where we unnecessarily make the model overly complex to achieve near-perfect prediction in the training data. Although highly predictive in the training data, the model fails to generalize well to unobserved data in the test set. What we want to do, which is also the focus of this book, is to apply proper regularization techniques so that the model also works well for the test sets. Figure 1.11 illustrates these four scenarios.

![](img/ee98e91e6845f41077b163bec833ee40_20_0.png)

Figure 1.11 Four different scenarios at the end of training. We wish to build a model that not only achieves low training error, but also, and more importantly, low test error.

Let us now look at things from another perspective. We are essentially interested in identifying a model that does an excellent job in the training set and generalizes well to the test set out of many possible models. Each model corresponds to a specific set of parameters and their configuration of mathematical operations that regulate the flow and interaction of information, such as addition or multiplication. All these models jointly form a model class, and our goal is to find one out of possibly multiple, good models that generalize well to the test set by careful training using the training set. This is illustrated in figure 1.12, where the model class (assumed to be big enough such as using neural networks) contains all possible model configurations, some of which are good and others bad.

![](img/ee98e91e6845f41077b163bec833ee40_21_0.png)

Figure 1.12 The total space of a (big enough) model class. Each point represents a particular model, and the relative positioning is arbitrary in this example. Our goal is to develop a properly regularized model where both training error and test error are low.

In figure 1.12, the model training process essentially implies that we are jumping from one model to another in search of the best model based on a specific criterion. There are infinite traveling paths, depending on the specific model class, algorithm, and training schedule we use. Figure 1.13 shows an example path from training a CART (classification and regression tree) model. In the initial phase of growing the tree, the model will underfit due to insufficient model complexity, as the path from black to yellow point represents. Then, the tree grows into a seemingly complex one that consists of multiple branches and leaves, bringing us to the blue point. With careful pruning, we then regularize the model complexity by removing unnecessarily complex branches.
