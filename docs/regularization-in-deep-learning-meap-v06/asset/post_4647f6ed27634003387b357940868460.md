## 3.2.5 Sample non-monotonicity

One common view in both classical and modern generalization theory is that more data seem to be better. However, a bigger training set may not necessarily correspond to a lower test risk. In some cases, more data may be worse. This phenomenon is referred to as the sample non-monotonicity, i.e., changing the size of the training data may either improve or worsen the test performance.

To observe this phenomenon, let us repeat the above experiments by varying the number of training samples as well. The following codes plot multiple curves on the MSE against different polynomial degrees, each corresponding to a different training sample size.

### Listing 3.8 Examining model performance with a different sample size and model complexity

num_train_samples_max = num_train_samples #A
for tmp_num_train_samples in range(num_train_samples_min, num_train_samples_max + 1, 2): #B
