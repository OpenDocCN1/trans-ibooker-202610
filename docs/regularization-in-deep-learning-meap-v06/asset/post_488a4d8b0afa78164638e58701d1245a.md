## 6.4 Summary

- Inductive bias is a prior assumption introduced in the model training procedure to improve its predictive performance, such as translational invariance in convolutional neural networks
- The convolution operator enforces weight sharing through a special convolutional layer
- Dropout randomly disables certain nodes to promote a sparse representation
- Multi-task learning (MTL) is a training framework that learning multiple tasks at the same time
- MTL introduces an inductive bias over more generalizable hypotheses and performs implicit data augmentation for related tasks
- Popular MTL frameworks in deep neural networks include hard parameter sharing and soft parameter sharing, with the former being the most dominant approach and the latter gaining increasing attention in the research community

The objective function is the final stop of the forward pass when training a neural network. Also referred to as the cost function, the objective function determines the quality of prediction based on the current parameter configuration of the network. It guides the weight updates in the next iteration via gradient descent. By summarizing the prediction quality for all observations, the objective function offers a single metric that summarizes the amount of error for downstream optimization. That single metric is small in value if the predictions are close to the target values (on average) and large otherwise.

The directionality of the objective function applies to both regression and classification settings. We know that mean squared error (MSE) and cross-entropy loss (CEL) are popular choices of metric for regression and classification, respectively. MSE is lower bounded by zero, and we get a zero MSE when the algorithm perfectly interpolates all training data points. However, getting an exact zero CEL is impossible since the SoftMax operation is used. Minimizing these empirical loss functions in both situations keeps the optimization iterations running. When using big neural networks, we often run the optimization until the model interpolates the training set, and we accompany the process with some form of regularization to increase the likelihood of generalizing to the test set.

Recall the overall model training workflow shown in figure 7.1. The primary role of the objective function is to compare the model prediction with the corresponding target label, taking a classification setting, for example, without loss of generality. It provides a direct scalar value, often in the form of a cost to be minimized, to summarize the predictiveness of the current model. When the goal of the optimization procedure is to build an accurate model that performs well in the training set, optimizing the objective function means minimizing the prediction error by continuously changing the weights to the point that the prediction error is zero. In other words, the final state of maximizing the prediction accuracy _alone_ in the objective function is a model that perfectly interpolates the training dataset.

However, a complex model is prone to overfitting regardless of whether it exhibits perfect interpolation in the training dataset. Such complexity often leads to unstable predictions for a new test set with a slight variation. It turns out that we can include more than one metric in the objective function. For example, instead of optimizing the prediction accuracy alone, we can introduce an additional penalty term on the complexity of the model so that the resulting model is expected to trade off between prediction accuracy and model complexity. In other words, a complex and likely overfitting model will obtain a low prediction cost but at the same time, incur a significant penalty on the model complexity, causing the total value of the objective function to be high. On the other hand, a simple model gives a low value on the penalty term but lacks predictive power, leading to a high value of the objective function.
