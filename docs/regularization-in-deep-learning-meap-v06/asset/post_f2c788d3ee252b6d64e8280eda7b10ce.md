## Figure 5.6 Illustrative architecture of the LeNet variant model.

The following code listing shows the implementation of the network as a class. We double the depth of feature maps for each `CONV` layer as a common practice on parameter setting for `CONV` layers. Such an operation could increase the expressive power of the network to learn features from different perspectives. As the feature maps become deep, the 2x2 `MAXPOOLING` layer further halves the width and height of each feature map to reduce its spatial dimension. The final output is the ten output nodes of the last fully connected layer corresponding to the ten classes of objects.

## Listing 5.6 Implement the LeNet architecture

```
class LeNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3,
                                stride=1, padding=1) #A
        self.conv2 = nn.Conv2d(16, 32, 3, 1, 1, padding=1)
        self.conv3 = nn.Conv2d(32, 64, 3, 1, 1, padding=1)
        self.fc1 = nn.Linear(4*4*64, 500) #B
        self.dropout1 = nn.Dropout(0.5)
        self.fc2 = nn.Linear(500, 10) #C

    def forward(self, x):
        x = F.relu(self.conv1(x)) #D
        x = F.max_pool2d(x, 2, 2) #E
        x = F.relu(self.conv2(x))
        x = F.max_pool2d(x, 2, 2)
        x = F.relu(self.conv3(x))
        x = F.max_pool2d(x, 2, 2)
        x = x.view(-1, 4*4*64) #F
        x = F.relu(self.fc1(x))
        x = self.dropout1(x)
        x = self.fc2(x)

        return x
```

#A double the depth of feature maps for every conv layer
#B input image is 32*32, after 3 MaxPooling layers it reduces to 4*4 64 feature maps
#C 10 output nodes that map to 10 classes
#D apply relu to each conv layer output
#E max pooling layer with 2x2 kernel to shrink the size by half
#F flatten the images as 1D input to the fully connected layer

## Listing 5.7 Train LeNet without data augmentation

```
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr = 0.01)
epochs = 100
training_loss_history = []
training_accuracy_history = []
val_loss_history = []
val_accuracy_history = []

for e in range(epochs):
    training_loss = 0.0
    training_accuracy = 0.0
    val_loss = 0.0
    val_accuracy = 0.0
    for inputs, labels in training_loader: #A
        inputs = inputs.to(device) #B
        labels = labels.to(device) #B
        outputs = model(inputs) #C
        loss = criterion(outputs, labels) #D
        optimizer.zero_grad() #E
        loss.backward() #F
        optimizer.step() #G
        _, preds = torch.max(outputs, 1) #H
        training_loss += loss.item()
        training_accuracy += torch.sum(preds == labels.data) #I
    with torch.no_grad(): #J
        for val_inputs, val_labels in validation_loader:
            val_inputs = val_inputs.to(device)
            val_labels = val_labels.to(device)
            val_outputs = model(val_inputs)
            val_loss_model = criterion(val_outputs, val_labels)
            _, val_preds = torch.max(val_outputs, 1)
            val_loss += val_loss_model.item()
            val_accuracy += torch.sum(val_preds == val_labels.data)
```

#D Calculate CE loss

#F backpropagate the loss
#G Update the weights
#H Take the indexes of maximum logits as class prediction
#I count the correct predictions in a batch

## 5.2.2 Training with data augmentation

Data augmentation is a natural technique when working with image data as it can introduce a small number of transformations to the input image without changing the target label. These geometric transformations allow the model to iterate over more training images of the same class, which is especially helpful when the original dataset is small. The common transformations are also easy to implement when training convolutional neural networks in computer vision tasks.

In order to train a model using data augmentation, all we have to do is to build a new data loader for the training set that involves different forms of transformations to generate new images. See the code listing below for the series of transformations used, including flipping, rotation, zooming, shearing, and changing colors. We omit the full codes as it largely remains the same as before. For the full training process, please refer to the accompanying notebook at https://github.com/jackliu333/regularization_in_deep_learning/blob/main/Chapter_5.0.ipynb#b.

