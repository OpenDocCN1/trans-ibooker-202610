The most popular choice of activation function is the rectified linear unit (ReLU), which acts as an on/off switch that fires the input signal as it is if its value is above a specific threshold and mutes it by outputting zero if it is below the threshold. In other words, the ReLU operation is an identity function if the input is positive; otherwise, the output is set as zero. Without such nonlinear activation, a multi-layer neural network would simply become a series of linear functions stacked on top of each other, resulting in a linear model.

Let us look at an example. Suppose we have a simple two-layer neural network with a single node at the hidden and output layers for a two-dimensional input. The middle-layer output without activation function would be z = w11x1+w12x2+b1, where w11 represents the first weight in the first and only hidden layer. Similarly, the final output is y = wz + b2. Plugging in the definition of z gives y = w2(w11x1+w12x2+b1) + b2 = w2w11x1 + w2w12x2 + w2b1 + b2, which is again the manifestation of a linear model when we view w2w11 and w2w12 as the feature weights and w2b1 + b2 as the bias. The same line of reasoning applies if we expand to deeper and wider linear networks.

The two operations in a single perceptron can be interpreted as a function that projects the input vector X from one space to another via the matrix-vector multiplication with the weights and follow-up nonlinear transformation. Specifically, perceptron is a function f(X) = ϕ(wX + b), where b is a bias term used as a global shift that adjusts the preceding weighted sum upward or downward to represent more complex cases.
