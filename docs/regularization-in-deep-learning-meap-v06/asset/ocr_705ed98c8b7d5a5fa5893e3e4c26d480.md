The figure above shows that the fitted model is less generalizable to the test set when a high variance is present due to excessive model complexity. The bias-variance tradeoff is thus at the heart of classical generalization theory: the fitted model needs to find the “sweet spot” and properly balance underfitting and overfitting. A good model should be expressive enough to represent the underlying pattern in the data and simple enough to avoid fitting potentially spurious patterns due to random noise.

# 2.7 Summary

+   - Model training starts with data, which is often divided into three subsets: training set, validation set, and test set, although the validation set may be absorbed as part of the training set for model training
+   - The test set is used to assess the model’s generalization performance and calculate the empirical risk, a proxy to the true risk
+   - Feature engineering such as adding polynomial basis can increase model complexity by turning a linear fit into a nonlinear fit
+   - The bias trick is a convenient technique often used to ease the implementation of machine learning models
+   - The mean squared error is a widely used cost for regression task and also called the empirical risk in linear regression
+   - Optimization can be completed in one shot if the closed-form solution is available; otherwise, the gradient descent family of methods is most widely used
+   - There are three types of gradient descent method: the batch gradient descent, the mini-batch gradient descent, and the stochastic gradient descent; the difference lies in the number of examples used in each gradient descent update
+   - Setting a proper learning rate is crucial in ensuring model convergence
+   - The risk can be decomposed into three sources of error: the irreducible variance from the random noise, and the reducible squared bias and variance of the model
+   - The classical view on generalization states a tradeoff between the bias and the variance: a complex model has a lower bias but higher variance than a simpler model and is less likely to generalize well to the test set due to the high variance
