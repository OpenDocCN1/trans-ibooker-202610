### 5.3.8 Implicit bias in convolutional neural networks

When comparing a convolutional neural network and its equivalent fully connected counterpart in terms of network expressivity, i.e., a fully connected network that is capable of representing all functions a convolutional network can represent, empirical evidence shows that the convolutional network tends to obtain a lower empirical loss and thus generalizes better. A popular explanation is that SGD induces an implicit bias in the convolutional network by landing in a flat local minimum region instead of a sharp valley when the network starts to interpolate. Such a flat region happens to be a generalizable region. This is an important perspective on (implicit) regularization using optimization, which we will analyze more in a later chapter.

We can additionally obtain another perspective using the alternate decomposition framework. Instead of assessing the (implicit) quality of empirical minima obtained using SGD for convolutional and fully connected networks, we can also characterize the generalization performance by studying how quickly SGD (explicitly) optimizes over the population loss.

In the following code listing, we build a fully connected network class called `LeNet_FC`, which consists of five fully connected layers and contains a total of 95,748,510 parameters.

On the other hand, the original LeNet has 541,094 parameters. The relative ratio in the number of parameters between these two networks is about 1/200, which is similar to the one used in the original paper. By creating a much larger fully connected network in size, we hope that LeNet_FC subsumes LeNet in terms of expressive capability and approximating power. We could then compare their optimization speed to reduce population loss in the ideal world while keeping all other training configurations the same.

Listing 5.13 Build a fully connected version of LeNet

```
class LeNet_FC(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(32*32*3, 10000) #A
        self.fc2 = nn.Linear(10000, 5000)
        self.fc3 = nn.Linear(5000, 2500)
        self.fc4 = nn.Linear(2500, 1000)
        self.fc5 = nn.Linear(1000, 10) #B
        self.dropout1 = nn.Dropout(0.5)

    def forward(self, x):
        x = x.reshape(-1, 32*32*3) #C
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = F.relu(self.fc3(x))
        x = F.relu(self.fc4(x))
        x = self.dropout1(x)
        x = self.fc5(x)
        return x
```

A input is 32*32 channel-last color image
B 10 output nodes that map to 10 classes
C flattens the images as 1D input to the fully connected layer in the beginning

Upon receiving a channel-last color image, LeNet_FC would first reshape it into an array and apply a series of fully connected layers whose size roughly reduce in half, until the final layer. ## 5.4 Summary

- Regularization via data refers to a series of data-based methods that help build a regularized model
- Transformations on data can be applied to the input matrix, the output, the hidden layer activations in deep neural networks, and a combination of these components
- When transforming an input matrix for regularization purpose, horizontal treatments include manual feature engineering and automatic feature extraction, and vertical treatments include repeated sampling (bootstrap and oversampling) and data augmentation
- Label smoothing is a technique that smooths the “hard” one-hot encoded target to a “soft” target perturbed by a uniformly distributed noise that is controlled by a trade-off hyperparameter
- Data augmentation aims at generating artificial samples by applying slight transformations to the original data; it is the de facto data pre-processing step in modern computer vision tasks
- Data augmentation helps regularize the model training process and build a more generalized model in image classification using CIFAR-10
- The deep bootstrap framework provides an alternative perspective on generalization by connecting the offline generalization performance in the real world with online optimization speed in the ideal world

Suitable regularization, whether explicit or implicit, is essential to achieving good generalization performance when using over-parameterized models such as deep neural networks. As introduced in the previous chapter, data augmentation promises a performance boost in visual recognition tasks such as image classification. However, generating valuable artificial datasets using the available training dataset still depends on a good coverage of the population data in terms of data variety. There is not much we can augment when the training set is extremely limited.

Consider, for example, the case of a minimal training set in figure 6.1, which is also the exact figure we encountered in chapter 1. The true underlying function is a curve and is unavailable to us. In this scenario, we would avoid unnecessary complexity in the model as it will easily overfit the training dataset consisting of six data points. The same reasoning applies when the training data is even more reduced. In extreme uncertainties, it is better to remain conservative and avoid undue complexity.
