In addition, regularization can also be categorized as implicit or explicit. Implicit regularization refers to a particular operation that indirectly plays a regularizing role. For example, stochastic gradient descent (SGD) is a typical optimizer used to train deep learning models. By optimizing the model based on one or a small batch of data points in each iteration, the model is exposed to more diverse data variations and thus learns to be more robust by considering these variations. By decorrelating the nearby updates, SGD could indirectly regularize the model to be generalizable to the test set. On the other hand, explicit regularizers specifically target tweaking specific components during model training, such as controlling model complexity. Lastly, as shown in figure 1.19, regularization can also be categorized as strong or weak, depending on its effect. For example, explicit regularizers such as Lasso directly remove unimportant features by setting their coefficients to zero. This could be considered as having a strong regularizing effect. On the other hand, techniques such as data augmentation aim to provide different versions of the same dataset, hoping that the model could learn from the similarities and become robust to the variations in between, resulting in a more gentle, indirect, and thus weak regularizing effect.
