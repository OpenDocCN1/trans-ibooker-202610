
In order to calculate the derivative \(\frac{\partial f_L}{\partial \mathbf{w}}\) of function \(f_L\) with respect to the weights \(\mathbf{w}\), we would start by calculating the intermediate derivative \(\frac{\partial f_L}{\partial f_{L-1}}\) of \(f_L\) with respect to the previous layer’s prediction function \(f_{L-1}\), treating the whole chunk of \(f_{L-1}(\cdots f_1(\mathbf{w}))\) as a single entity. Equivalently, we can interpret \(\frac{\partial f_L}{\partial f_{L-1}}\) as \(\frac{\partial f_L(x)}{\partial x}\), where \(x=f_{L-1}(\cdots f_1(\mathbf{w}))\).

We would proceed similarly by calculating the intermediate derivative \(\frac{\partial f_{L-2}}{\partial f_{L-1}}\) of \(f_{L-1}\) with respect to its previous layer’s function \(f_{L-2}\), and so on. This process of deriving the intermediate derivatives continues until reaching the first (i.e., innermost) function \(f_1\), where we multiply the last derivative \(\frac{\partial f_1}{\partial \mathbf{w}}\). Finally, these intermediate derivatives are multiplied together. In other words, \(\frac{\partial f_L}{\partial \mathbf{w}}\) can be calculated as follows:

\(\frac{\partial f_L}{\partial \mathbf{w}} = \frac{\partial f_L}{\partial f_{L-1}} \frac{\partial f_{L-1}}{\partial f_{L-2}} \frac{\partial f_{L-2}}{\partial f_{L-3}} \cdots \frac{\partial f_2}{\partial f_1} \frac{\partial f_1}{\partial \mathbf{w}}\).

Figure 4.13 illustrates the process of calculating the derivative of the final-layer prediction function \(f_L\) with respect to the weights \(\mathbf{w}\) of the initial hidden layer. We would first follow the forward propagation process to generate a series of embedded predictions for the weights. Then the backward propagation kicks in and generates a series of intermediate derivatives for each pair of adjacent layers. Finally, the gradient of the outermost function \(f_L\) with respect to the weights \(\mathbf{w}\) is derived by multiplying the intermediate derivatives. These calculations are performed via the automatic differentiation functionality in most popular deep learning frameworks such as PyTorch.

## 4.2.3 Different modes of multiplication

So far, we have been looking at how to calculate the gradient of a multilayer neural network with respect to the weights in the first hidden layer. It is also straightforward to generalize to the weights for other layers. The gradient of the final cost with respect to the weights at the first layer can be derived by multiplying these intermediate derivatives of the middle layers. However, each pair of layers results in a matrix of partial derivatives whose element corresponds to each unique pair of nodes in both layers, and multiplying multiple matrices, if not properly planned, could take a long time to compute.

Let us focus on the multiplication of the first two matrices: $\frac{\partial \mathbf{f}_1}{\partial \mathbf{w}}$ and $\frac{\partial \mathbf{f}_2}{\partial \mathbf{f}_1}$. Assume $\mathbf{w}$ is a $p_0$-dimensional vector and $\mathbf{f}_1$ is a $p_1$-dimensional vector. Taking the partial derivative of each function in $\mathbf{f}_1$ against each weight in $\mathbf{w}$ gives us a matrix $\frac{\partial \mathbf{f}_1}{\partial \mathbf{w}}$ of dimension $p_1 \times p_0$. Similarly, $\frac{\partial \mathbf{f}_2}{\partial \mathbf{f}_1}$ will be a $p_2 \times p_1$ matrix. Based on our previous introduction on matrix multiplication, when two matrices multiply with each other, the inner dimension should match each other and the outer dimension will form the resulting shape of the output. In this case, $\frac{\partial \mathbf{f}_2}{\partial \mathbf{f}_1} \frac{\partial \mathbf{f}_1}{\partial \mathbf{w}}$ will be a $p_2 \times p_0$ matrix. In addition, from a computational perspective, multiplying $\frac{\partial \mathbf{f}_1}{\partial \mathbf{w}}$ and $\frac{\partial \mathbf{f}_2}{\partial \mathbf{f}_1}$ will need a total of $p_2 p_1 p_0$ operations. The number of operations indicates how long the multiplication will take.

When rolling up to the multiplication of all derivatives across the neural network, we will end up with different computational complexity depending on how the multiplication is spread across the composite function. For example, if we follow the style of forward propagation, i.e., multiplying in a *forward mode*, the sequence of multiplications as separated by the brackets will look like this:

```
\frac{\partial f_L}{\partial \mathbf{w}} = \frac{\partial f_L}{\partial f_{L-1}} \left( \frac{\partial f_{L-1}}{\partial f_{L-2}} \left( \frac{\partial f_{L-2}}{\partial f_{L-3}} \dots \left( \frac{\partial f_3}{\partial f_2} \left( \frac{\partial f_2}{\partial f_1} \frac{\partial f_1}{\partial \mathbf{w}} \right) \right) \dots \right) \right).
```

As shown in figure 4.14, the second layer of multiplication, i.e., $\frac{\partial f_2}{\partial f_1} \frac{\partial f_1}{\partial \mathbf{w}}$, would continue and result in a matrix of shape $p_3 \times p_0$ and incur a total of $p_3 p_2 p_0$ operations. This process of multiplying with the outer layer matrix continues until reaching the last layer. The total number of operations involved, which is an indicator of the computational cost in forward-mode multiplication, would thus become:

```
p_2 p_1 p_0 + p_3 p_2 p_0 + \dots + p_L p_{L-1} p_0 = p_0 \sum_{l=2}^L p_l p_{l-1}.
```

**Figure 4.14** Illustrating the forward-mode multiplication process and its computational cost. The multiplication starts at the innermost level at the beginning of the neural network and gradually expands to outer layers towards the end. We can also look at the chain of multiplications in a *backward mode*, multiplying the matrices of partial derivatives from the end to the beginning of the neural network. The backward mode would have the following sequence of multiplications:

$$\frac{\partial f_L}{\partial \mathbf{w}} = \left( \left( \cdots \left( \left( \frac{\partial f_L}{\partial f_{L-1}} \frac{\partial f_{L-1}}{\partial f_{L-2}} \right) \frac{\partial f_{L-2}}{\partial f_{L-3}} \right) \cdots \frac{\partial f_3}{\partial f_2} \right) \frac{\partial f_2}{\partial f_1} \right) \frac{\partial f_1}{\partial \mathbf{w}}.$$

Following a similar line of reasoning, the total number of operations required by the backward-mode multiplication would be:

$$p_L p_{L-1} p_{L-2} + p_L p_{L-2} p_{L-3} + \dots + p_L p_1 p_0 = p_L \sum_{l=1}^{L-1} p_l p_{l-1}.$$

Recall that our goal is to calculate the gradient vector that contains the partial derivatives of the model's cost with respect to each weight. Due to the large size of modern neural networks and the many rounds of optimization involved, we would hope to calculate the gradient efficiently. Therefore, we need to analyze and compare the computational cost of forward mode and backward mode multiplication and go with the faster option.

Apparently, the computational cost of these two modes varies depending on the size of layers in the composite function. Also, the formula for the computational cost derived earlier suggests that the forward mode relies on the constant multiplier $p_0$ and the backward mode relies on $p_L$. In a typical model training process, a scalar cost is often selected as the performance metric based on the current model's prediction. The single-valued cost indicates that $p_L = 1$. On the other hand, $p_0$ directly depends on the dimension of the input data, which can grow to hundreds of thousands of features per entry in the case of image data.
