# 8.1.3 Implicit regularization of SGD

To observe the difference in the learning behaviors between mini-batch SGD and full-batch GD, let us look at a simple cartoon example that involves two situations. As shown in figure 8.3, we plot the average loss curve of Q(**w**, D) (assumed to be MSE and indicated by the dashed curve) as a function of the weight vector **w**, assumed to be one-dimensional for simplicity. We will reduce the MSE using the gradient descent update based on the full training set, which eventually converges to the optimal **w***. We also plot the loss curves of different mini-batches when optimizing using SGD, where the mini-batch loss curves (solid curves) are similar in shape to the loss curve using full-batch GD (dashed curve). Based on the unbiasedness property of SGD, the full-batch loss curve is the average of the four mini-batch loss curves.

Figure 8.3 Visualizing the loss curves using full-batch GD and mini-batch SGD, where the latter curves are similar in shape and close to the former.

Using these individual mini-batches of the training set, we obtain a good estimate of the average loss curve based on the full-batch GD. In other words, each of these mini-batch loss curves could tell us something about where the optimal weight **w** lies, and the local minima from these mini-batch loss curves are within a close neighborhood of **w***. In each round of updates using SGD, we choose a random subset and (therefore) direct the next update of the weights based on the corresponding mini-batch loss curve. Almost all these mini-batch loss curves point us in the same direction using SGD, and there is little variance in terms of the update direction; SGD and GD will perform similarly in this situation.
