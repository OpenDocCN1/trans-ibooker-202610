With two neurons placed in each hidden layer, we can vary the model complexity by tweaking the `hidden_layers` argument and observing the model's final output change. In the coding listing below, we vary the size of the neural network by changing the number of hidden layers from zero to five and plotting the final output.

```
Listing 4.3 Sequentially changing the number of hidden layers
numlayers = 6
fig, axs = plt.subplots(numlayers, 1, figsize=(8,25))
for i, ax in enumerate(axs):
    ax.plot(xs, multilayer(xs, hidden_layers=i))
    ax.set_ylim([-3, 3])
    ax.legend(['$f_{{{}}}(x)$'.format(i)])
```
