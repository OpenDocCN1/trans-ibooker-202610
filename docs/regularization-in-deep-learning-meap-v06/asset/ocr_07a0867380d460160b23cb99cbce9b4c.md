# 6.2.3 Dropout in action

The dropout operation consists of dropping some nodes according to a preset probability and scaling up the weights of the rest of the nodes. Here, we specify the probability of dropping nodes (which is also a hyper-parameter) and not the probability of keeping nodes. This applies to both the example we will cover in the following and the dropout layer available in PyTorch.

When implementing dropout, the first part involves generating an indicator list of Boolean numbers to be multiplied with the nodes within the layer of assessment, be it the input layer or hidden layer. When a node is multiplied by zero, or equivalently a `FALSE` value in Python, the resulting feature value of the node will become zero and flow into the following operation, which amounts to dropping out or masking this node.
