The training could also result in a high training set error, and surprisingly a low test set error. Is this likely to happen? Rarely, since an insufficiently trained model is unlikely to perform well in the test set. The test set is often assumed to follow the same data generating distribution as the training set. However, both are usually disrupted by random noises that obscure the actual pattern that maps the input to the output.

It is also possible to see a low training set error and a high test set error. This is the overfitting scenario, where we unnecessarily make the model overly complex to achieve near-perfect prediction in the training data. Although highly predictive in the training data, the model fails to generalize well to unobserved data in the test set. We want to do, which is also the focus of this book, is to apply proper regularization techniques so that the model also works well for the test sets. Figure 1.11 illustrates these four scenarios.
