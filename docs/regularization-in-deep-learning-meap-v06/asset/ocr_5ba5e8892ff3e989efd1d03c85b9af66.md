The minimizer to the unregularized linear regression model can be obtained by setting the gradient of \(Q(\mathbf{w})\) to zero, since \(Q(\mathbf{w})\) is a quadratic function of \(\mathbf{w}\). We can obtain the analytic gradient vector \(\nabla Q(\mathbf{w}) = -2\mathbf{\Phi}^T(\mathbf{y} - \mathbf{\Phi w})\). Setting the gradient vector to zero gives us the same normal equations as in chapter 2: \(\mathbf{\Phi}^T\mathbf{\Phi w}^* = \mathbf{\Phi}^T\mathbf{y}\). Multiplying by \((\mathbf{\Phi}^T\mathbf{\Phi})^{-1}\) at the beginning of both sides produces the closed-form solution for the least squares estimator \(\mathbf{w}^{LS} = \mathbf{w}^* = (\mathbf{\Phi}^T\mathbf{\Phi})^{-1}\mathbf{\Phi}^T\mathbf{y}\).

# 7.1.2 Norm-based penalty

The norm-based penalty is a common technique to encourage the model to prefer solutions with smaller weights and thus avoid overfitting.

As also covered in chapter 3, we would add a penalty term \(J(\mathbf{w}) = \int f''_w(x)^2 dx\) to control the curvature of the model and therefore prevent overfitting. This regularization term is often multiplied by a hyper-parameter \(\lambda\) to negotiate between the goodness of fit to the training data and the roughness of the resulting model. The penalized cost function thus becomes \(Q(\mathbf{w}) = \sum_{i=1}^n (y_i - f_w(\mathbf{x}_i))^2 + \lambda \int f''_w(x)^2 dx\), and the resulting model is called smooth splines.

In addition, we also touched upon ridge regression in chapter 2, where the penalty term becomes \(J(\mathbf{w}) = \|\mathbf{w}\|_2^2 = \sum_{i=1}^d w_i^2\), where \(d\) is the total number of features in the dataset, and \(\|\mathbf{w}\|_2 = \sqrt{\sum_{i=1}^d w_i^2}\). This is the squared \(L^2\) norm, which measures the magnitude of the estimated weights. Correspondingly, the penalty function using the \(L^1\) norm is \(J(\mathbf{w}) = \|\mathbf{w}\|_1 = \sum_{i=1}^p |w_i|\), which also gives a sparse solution as an added benefit of feature selection.
