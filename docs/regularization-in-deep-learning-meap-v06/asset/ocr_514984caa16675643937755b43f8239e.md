It should be noted that these data augmentation techniques are empirically tested to be helpful in *some* cases only, in particular computer vision tasks. Given our observation on sample non-monotonicity, more training data may sometimes hurt test performance.

Our eventual goal is to increase the generalizability of the trained model. How does creating more (artificial) training data serve as a regularization technique and help contribute to this goal? The model is constantly presented with new and slightly modified data by introducing random noises and perturbations to the original training data. The model is more likely to learn robust features when the dataset is sufficiently diverse. These additional data points reflect our prior belief or inductive bias as we know introducing slight transformations to an image does not change its class label. In other words, we use data augmentation to increase the size of the training dataset and regularize the model training process so that the trained model will have low variance and is more likely to generalize well to the test set.

Data augmentation contributes to the generalization performance of the trained model by adding more plausible and realistic versions of training data so as to improve the test set performance. It is considered an *implicit regularization* technique, which is in contrast to *explicit regularization* techniques such as penalizing the norm of the weights.

Note that data augmentation does not apply to the test set; it is merely a preprocessing technique to augment the training dataset before the start of each training iteration. However, despite the tendency to increase the test set performance of the model, we *may* observe a decrease in the training set performance.
