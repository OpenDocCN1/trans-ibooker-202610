```
class MLP:
    def __init__(self, lr=1e-3, num_epochs=10, l1_weight=0, l2_weight=0):
        self.lr = lr
        self.num_epochs = num_epochs
        self.l1_weight = l1_weight

        self.test_accuracy = []
        self.model = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28 * 28 * 1, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 10)
        )

```

Next, we build a fit() method to perform model training. The following code snippet shows that this method requires two input arguments: the training and test set data loader. For each epoch, we would first extract the current batch of the training dataset and perform the usual forward pass to obtain the predictions and corresponding loss. If the weight for LASSO or ridge penalty is activated, we would add the additional penalty term(s) to the current loss. To calculate these penalties, we would first obtain all the model's parameters using self.model.parameters(), which then get stored in a list for follow-up calculation. These penalties terms are calculated using the function compute_l1_loss() and compute_l2_loss(), which are introduced shortly. After back-propagating the loss and updating the weights, we also score the model against the test set at the end of every epoch. The training loss per iteration and test set accuracy per epoch are stored in the attributes train_loss and test_accuracy, respectively.

## Listing 7.11 Class method on model fitting

```
def fit(self, trainloader, testloader):
    for epoch in range(self.num_epochs): #A
        print(f'Starting epoch {epoch+1}')
        for i, data in enumerate(trainloader, 0):
            X_train, y_train = data #B
            X_train, y_train = Variable(X_train).cuda(), Variable(y_train).cuda() #C
            self.optimizer.zero_grad() #D
            y_predicted = self.model(X_train) #E
            loss_train = self.criterion(y_predicted, y_train) #F

            if self.l1_weight != 0: #G
                l1_parameters = []
                for parameter in self.model.parameters():
                    l1_parameters.append(parameter.view(-1))
                l1 = self.l1_weight * self.compute_l1_loss(torch.cat(l1_parameters))
                loss_train += l1

            if self.l2_weight != 0: #H
                l2_parameters = []
                for parameter in self.model.parameters():
                    l2_parameters.append(parameter.view(-1))
                l2 = self.l2_weight * self.compute_l2_loss(torch.cat(l2_parameters))
                loss_train += l2

            loss_train.backward() #I
            self.optimizer.step() #J
            self.train_loss.append(loss_train.item()) #K

            with torch.no_grad(): #L
                X_test, y_test = iter(testloader).next()
                X_test = X_test.cuda()
                y_test_pred = self.predict(X_test.cpu()) #M
                self.test_accuracy.append(np.mean((y_test == y_test_pred).numpy())) #N
                print('Test accuracy: {}'.format(self.test_accuracy[-1]))

        return self
```

- #A Iterate over the DataLoader for training data
- #B get inputs
- #C send to GPU if available
- #D zero the gradients
- #E perform forward pass
- #F compute loss
- #G add L1 loss component
- #H add L2 loss component
- #I perform backward pass
- #J perform optimization
- #K add training loss
- #L get test set performance
- #M get predictions for the test set
- #N Store test set accuracy

We have a few more functions used within the class. First, the `predict()` function is used to score the test set data in the evaluation mode by setting `self.model.eval()`, and the final prediction per observation is the one with the maximal logit across all classes of digits via the `torch.max(outputs.data, 1)` command. See the code snippet below for the `predict()` function, which is the same function we introduced in the previous chapter.

## Listing 7.12 Class method on model prediction

```
def predict(self, x):
    model = self.model.eval()
    outputs = model(Variable(x))
    _, pred = torch.max(outputs.data, 1)
    model = self.model.train()
    return pred
```

Next, let us look at `compute_l1_loss()` and `compute_l2_loss()`. As shown in the following code snippet, both functions perform the element-wise operation (taking the absolute value for LASSO and squaring the weight for ridge), followed by summing over all weights to produce a single scalar value of magnitude.

```
def compute_l1_loss(self, w):
    return torch.abs(w).sum()

def compute_l2_loss(self, w):
    return torch.square(w).sum()
```

Note that the model with the combined regularization scheme is called elastic net, which refers to the weighted sum of the L1 and L2 norms of the coefficients as a joint penalty in the objective function. If our goal is to constrain the model weights alone, we can regularize the L2 norm alone; if we would like to perform feature selection and model estimation together at the same time, we can regularize the L1 norm alone; if we want to achieve both, apply the elastic net penalty.
