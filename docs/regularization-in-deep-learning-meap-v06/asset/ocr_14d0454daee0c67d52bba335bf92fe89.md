Note that the model with the combined regularization scheme is called elastic net, which refers to the weighted sum of the L1 and L2 norms of the coefficients as a joint penalty in the objective function. If our goal is to constrain the model weights alone, we can regularize the L2 norm alone; if we would like to perform feature selection and model estimation together at the same time, we can regularize the L1 norm alone; if we want to achieve both, apply the elastic net penalty.

When the training completes, we can compare the predictive performance of the four models. In the following code listing, we plot the training loss curves of the four models across different iterations.

Also, the unregularized model has the lowest training loss across iterations, a potential sign of overfitting compared to the higher loss curves from other models. The model with the L1 norm has a relatively strong regularizing effect compared with the L2 norm when assuming the same value of the hyperparameter λ.
