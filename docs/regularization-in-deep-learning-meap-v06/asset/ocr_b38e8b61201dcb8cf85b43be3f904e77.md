# 7.3.2 Introducing the L0 norm

In some cases, we would also want to obtain a solution that satisfies the linear equation and has as many zero weights as possible, thus being a sparse solution. A direct approach is to penalize the L0 norm of the weights to obtain a sparse solution where some weights are zero.

The L0 norm is defined as the number of non-zero elements in a vector. In our context, ||w||0 = #{i|wi != 0), where i ∈ {1,2}. Penalizing the L0 norm means finding the sparsest solution with the minimal number of non-zero elements, an NP-hard problem that requires evaluating all possible subsets of features. Figure 7.15 illustrates the scenario when solving the linear equation subject to a constraint on the L0 norm, where the solution has to live on either axis so that only one weight is non-zero. Note that we are still locating the solution with the minimum L0 norm; thus, any solution that grows out of the intersection point is ruled out. In this case, the bolded dot represents the optimal solution, which gives a sparse solution by setting w2 = 0.
