### 3.3 Summary

- The "double descent" curve, a widely observed phenomenon in training machine learning and deep learning models, subsumes the classical U-shaped curve on bias-variance tradeoff
- The twofold descent curve exists as a function of either model complexity or training iteration
- The problem of overfitting could be resolved by either increasing the number of parameters, which moves into the over-parameterization regime and implicitly regularizes the model using stochastic gradient descent, or reducing the model capacity by a proper and explicit regularization technique
- The effective model complexity is a recently proposed notion to denote the maximum number of samples on which a training procedure achieves close to zero training error on average
- More training data may not necessarily boost the model performance due to sample non-monotonicity
- The second derivative could be used as a measure of roughness of the fitted polynomial model and combined with MSE via a weighting factor to form the overall cost

So far, we have been dealing with the approximating power of the model to the true underlying function by adding more features and controlling the model complexity. For example, in the previous chapter, we learned that the polynomial function’s approximation capacity increases when more higher-degree polynomial terms are present. Such model fitting process essentially amounts to functional approximation, where we approximate a complex function using a combination of simpler ones. Our goal is thus to build a good machine learning model that is expressive enough to approximate the true underlying function.

In general, adding more parameters can lead to over-parameterization, a situation often avoided in the classical regime but somehow encouraged in the modern interpolation regime. For the case of neural networks, it is interesting to look at what underlying functions could be modeled and approximated. On this front, the universal approximation theorem, originally established in the paper “Multilayer Feedforward Networks are Universal Approximators” by urt et al. (1989), states that neural networks are expressive enough to approximate any function of interest. Based on this theorem, neural networks are powerful and flexible enough to represent any mapping of arbitrary shape to an arbitrary accuracy when proper weights and architecture are provided. How is this possible?

To understand its approximation behavior, we will start with the notion of perceptron, the basic computation unit in neural networks.

### 4.1 Multilayer perceptron

A typical neural network consists of an input layer representing the input data and an output layer to generate the output. It can also include any number of layers in between (called hidden layers). Each layer contains at least one neuron, interpreted as an extracted hidden feature. When it comes to the number of layers of a neural network, it refers to the hidden layer plus the output layer. For example, a perceptron is a single-layer neural network, meaning it has only input and output layers and does not have any hidden layer in between.

Being the fundamental constituent of a neural network, a perceptron is a single neuron that completes two steps of mathematical operations: the weighted sum and the nonlinear transformation. For a single observation with p dimensions x \in R^p, the perceptron first calculates the weighted sum \sum P_{i=1} WX_i between x and its corresponding weight vector w \in R^p, which is (and should be) also p-dimensional. The weighted sum is often accompanied by one more term called intercept or bias, which acts as an additional parameter to exercise a global level shift to the weighted sum to better fit the data.

After adding an intercept/bias term b, the sum passes through an activation function which introduces a nonlinear transformation to the weighted sum. Note that the bias term is added by inserting a column of ones in the input data, which is the same bias trick as linear regression. Such nonlinear transformation, together with the number and width of layers, determines neural networks' flexibility, expressivity, and approximating power. Figure 4.1 summarizes the process flow of a perceptron.

![](img/ee98e91e6845f41077b163bec833ee40_100_0.png)

Figure 4.1 The process flowchart of a perceptron, which consists of a weighted sum operation followed by an activation function. A column of ones is automatically added to correspond to the bias term in the weight vector.

The most popular choice of activation function is the rectified linear unit (ReLU), which acts as an on/off switch that fires the input signal as it is if its value is above a specific threshold and mutes it by outputting zero if it is below the threshold. In other words, the ReLU operation is an identity function if the input is positive; otherwise, the output is set as zero. Without such nonlinear activation, a multi-layer neural network would simply become a series of linear functions stacked on top of each other, resulting in a linear model.

Let us look at an example. Suppose we have a simple two-layer neural network with a single node at the hidden and output layers for a two-dimensional input. The middle-layer output without activation function would be z = w11x1+w12x2+b1, where w11 represents the first weight in the first and only hidden layer. Similarly, the final output is y = wz + b2. Plugging in the definition of z gives y = w2(w11x1+w12x2+b1) + b2 = w2w11x1 + w2w12x2 + w2b1 + b2, which is again the manifestation of a linear model when we view w2w11 and w2w12 as the feature weights and w2b1 + b2 as the bias. The same line of reasoning applies if we expand to deeper and wider linear networks.

The two operations in a single perceptron can be interpreted as a function that projects the input vector X from one space to another via the matrix-vector multiplication with the weights and follow-up nonlinear transformation. Specifically, perceptron is a function f(X) = ϕ(wX + b), where b is a bias term used as a global shift that adjusts the preceding weighted sum upward or downward to represent more complex cases. Here we denote ϕ(z) = max(z,0) as the ReLU activation function that returns the maximum between the original input and zero, where z = wX + b denotes the output of the linear operation before applying the activation function. In other words, a negative value is set to zero and a positive one remains as it is.

The following code snippet shows how to define the ReLU activation function and apply it to each element in an input list. The -1 is set to zero due to the zeroing effect for negative values, while the other two remain the same.

```
def relu(x):
    return np.maximum(x, 0)
>>> relu([1,-1,2])
array([1, 0, 2])
```

Figure 4.2 visualizes the ReLU function’s shape and summarizes the characteristics of the perceptron operation discussed so far. Other than the architectural flexibility of a neural network model in terms of the number and width of its layers, another main added flexibility lies in the nonlinear operation. In fact, many exciting and meaningful hidden features could be automatically extracted using ReLU as an activation function. For example, when training an image classifier using a special architecture called convolutional neural networks, low-level features in the initial hidden layers tend to resemble fundamental structural components such as lines or edges, while high-level features at later hidden layers start to learn structural patterns such as squares, circles, or even complex shapes like the wheels of a car. This is not possible if we are limited to the linear transformation of features and is considered an extremely difficult task if we were to manually engineer such informative features.
