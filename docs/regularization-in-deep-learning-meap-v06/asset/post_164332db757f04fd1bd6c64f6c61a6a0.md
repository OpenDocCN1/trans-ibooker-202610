Looking at the output, we can spot that the third last layer is a complex one: a sequential block that consists of three basic building blocks, each comprising a series of convolutional, batch normalization, and ReLU layers. Since our learning tasks are different, we can remove the last fully connected layer and keep only the layers before, acting as the backbone that supports hard parameter sharing of the three learning tasks.

Now we can wrap up the above codes and define a customized class on the multi-label classifier. As shown in the following code listing, we keep the resnet34 backbone architecture as the shared layers across the three tasks after removing its last fully connected layer, followed by expanding into three branches, each consisting of a dropout layer and a fully connected layer with a corresponding output shape.

## Listing 6.9 Defining the multi-class classifier

```
class MultilabelClassifier(nn.Module):
    def __init__(self, n_brand, n_vehicle_type, n_cohort):
        super().__init__()
        self.resnet = models.resnet34(pretrained=True) #A
        self.model_wo_fc = nn.Sequential(*(list(self.resnet.children())[:-1])) #B
        self.brand = nn.Sequential( #C
            nn.Dropout(p=0.2),
            nn.Linear(in_features=512, out_features=n_brand)
        )
        self.vehicle_type = nn.Sequential( #D
            nn.Dropout(p=0.2),
            nn.Linear(in_features=512, out_features=n_vehicle_type)
        )
        self.cohort = nn.Sequential( #E
            nn.Dropout(p=0.2),
            nn.Linear(in_features=512, out_features=n_cohort)
        )

    def forward(self, x): #F
        x = self.model_wo_fc(x)
        x = torch.flatten(x, 1)
        return {
            'brand': self.brand(x),
            'vehicle_type': self.vehicle_type(x),
            'cohort': self.cohort(x)
        }
```

Now we can define the training procedure. In the following code listing, we first define the `criterion()` function to calculate the total loss of a prediction as a sum of individual task-specific loss. Then in `training()`, we use the Adam optimizer as it is less sensitive to the learning rate setting, and apply the cross entropy loss for each individual loss. The training is performed in a nested loop for each batch in each epoch, where we apply the usual training pipeline we have seen in the previous examples. At last, we return the final combined loss for each epoch. We run the training procedure for a total of 10 epochs on a single GPU instance, which takes around half an hour. So, grab a cup of coffee while waiting for the training to complete.

## Listing 6.10 Training the MTL model

```
def criterion(loss_func, outputs, pictures):
    losses = 0
    for i, key in enumerate(outputs): #A
        losses += loss_func(outputs[key], pictures['labels'][f'label_{key}'].to(device))
    return losses

def training(model, device, lr_rate, num_epochs, train_loader):
    losses = []
    checkpoint_losses = []
    optimizer = torch.optim.Adam(model.parameters(), lr=lr_rate)
    n_total_steps = len(train_loader)
    loss_func = nn.CrossEntropyLoss()
    for epoch in range(num_epochs): #B
        for i, pictures in enumerate(train_loader):
            images = pictures['image'].to(device) #C
            outputs = model(images) #D
            loss = criterion(loss_func, outputs, pictures) #E
            losses.append(loss.item())
            optimizer.zero_grad() #F
            loss.backward() #G
            optimizer.step() #H

        if (i+1) % (n_total_steps) == 0:
            checkpoint_loss = torch.tensor(losses).mean().item()
            checkpoint_losses.append(checkpoint_loss)
            print(f'Epoch [{epoch+1}/{num_epochs}], Step [{i+1}/{n_total_steps}], Loss: {checkpoint_loss:.4f}')
    return checkpoint_losses

checkpoint_losses = training(model, device, 0.0001, 10, train_loader)
```
