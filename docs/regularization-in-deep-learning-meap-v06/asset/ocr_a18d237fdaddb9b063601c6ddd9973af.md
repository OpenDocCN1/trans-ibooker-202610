In practice, the random disabling effect happens based on a preset probability upon defining the network architecture. In addition, we would obtain the same network architecture as the original version and would not apply dropout during the test stage.

The probabilistic removal of hidden nodes happens during the training iterations. We would end up with the same network architecture as the original version since the dropout operation only happens during training iterations.

Randomly dropping out nodes can also be considered as sampling a thinned network from the original network, achieved by cutting all incoming and outgoing connections of a particular node. Since most of the nodes are present across multiple sampled networks, or sub-models, the dropout process allows weight sharing among these thin networks across different iterations, transferring and communicating the weights across multiple sub-models. This weight-sharing scheme is in a similar vein to multi-task learning, a topic we will cover shortly in a later section of the chapter.
