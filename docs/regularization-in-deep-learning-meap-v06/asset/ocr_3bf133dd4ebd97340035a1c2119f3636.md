All these models jointly form a model class, and our goal is to find one out of possibly multiple, good models that generalize well to the test set by careful training using the training set. This is illustrated in figure 1.12, where the model class (assumed to be big enough such as using neural networks) contains all possible model configurations, some of which are good and others bad.

In figure 1.12, the model training process essentially implies that we are jumping from one model to another in search of the best model based on a specific criterion. There are infinite traveling paths, depending on the specific model class, algorithm, and training schedule we use. Figure 1.13 shows an example path from training a CART (classification and regression tree) model. In the initial phase of growing the tree, the model will underfit due to insufficient model complexity, as the path from black to yellow point represents. Then, the tree grows into a seemingly complex one that consists of multiple branches and leaves, bringing us to the blue point. With careful pruning, we then regularize the model complexity by removing unnecessarily complex branches.
