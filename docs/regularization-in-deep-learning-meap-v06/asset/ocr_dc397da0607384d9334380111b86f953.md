added to the first fully connected layer to improve the training performance. See figure 5.6 for an illustration. Also, note that `RELU` and `DROPOUT` layers are not physical layers as they do not contain any weight.

# Figure 5.6 Illustrative architecture of the LeNet variant model.

The following code listing shows the implementation of the network as a class. We double the depth of feature maps for each `CONV` layer as a common practice on parameter setting for `CONV` layers. Such an operation could increase the expressive power of the network to learn features from different perspectives. As the feature maps become deep, the 2x2 `MAXPOOLING` layer further halves the width and height of each feature map to reduce its spacial dimension. The final output is the ten output nodes of the last fully connected layer corresponding to the ten classes of objects.

# Listing 5.6 Implement the LeNet architecture

```
class LeNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3,
                                stride=1, padding=1) #A
        self.conv2 = nn.Conv2d(16, 32, 3, 1, 1, padding=1)
        self.conv3 = nn.Conv2d(32, 64, 3, 1, 1, padding=1)
        self.fc1 = nn.Linear(4*4*64, 500) #B
        self.dropout1 = nn.Dropout(0.5)
        self.fc2 = nn.Linear(500, 10) #C

    def forward(self, x):
        x = F.relu(self.conv1(x)) #D
        x = F.max_pool2d(x, 2, 2) #E
        x = F.relu(self.conv2(x))
        x = F.max_pool2d(x, 2, 2)
        x = F.relu(self.conv3(x))
        x = F.max_pool2d(x, 2, 2)
        x = F.view(-1, 4*4*64) #F
        x = F.relu(self.fc1(x))
        x = self.dropout1(x)
        x = self.fc2(x)

        return x
```
