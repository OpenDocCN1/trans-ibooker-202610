We can also express the overall convolution operation of a 3x3 kernel in a way similar to the following, which describes the mechanism of a cross-correlation operation, another type of operation that largely resembles a convolution operation and eases the illustration of the mathematical operations. The only difference is that CNN flips the filter both horizontally and vertically, causing $IN_{i+x,j+y}$ to be $IN_{i-x,j-y}$ instead.

$Out_{i,j} = b + \sum_{x=0}^2 \sum_{y=0}^2 IN_{i+x,j+y} W_{x,y}$

In this expression, $IN$ denotes the input matrix, $W$ the kernel matrix of weights, and the $Out$ the resulting feature map that again serves as the input matrix for the following layer. There are two sets of zero-based indexes: $(i,j)$ as the global index that moves across input patches and $(x,y)$ as the local index that moves across elements of an input patch. $(i,j)$ uniquely locates each feature in the feature map $Out$, with $Out_{0,0} = 3$ as in the convolution example in figure 6.5. Since $IN$ is 6x6 and $W$ is 3x3, if the kernel sequentially convolves with each input patch, i.e., using a stride of 1, the resulting output $Out$ is 4x4, making both $i$ and $j$ in the range of 0 and 3. We will discuss the change of dimensions shortly.

For each convolution operation, both $x$ and $y$ vary between 0 and 2, resulting in a total of 9 combinations, or 9 element-wise multiplications between the input patch and the kernel matrix. The index pair $(x,y)$ thus uniquely identifies the input entry $IN_{i+x,j+y}$ (on top of the global input patch index $(i,j)$) and the weight entry $W_{x,y}$, performing the element-wise multiplication $IN_{i+x,j+y}W_{x,y}$ and summation $\sum_{x=0}^2 \sum_{y=0}^2 IN_{i+x,j+y}W_{x,y}$. We also note a bias term $b$ is added as a global adjustment to the output feature.
