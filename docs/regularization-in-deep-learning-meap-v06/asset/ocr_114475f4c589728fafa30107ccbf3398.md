After choosing a specific model family, we can generate predictions and measure the cost, a scalar value indicating how well the current model is doing. The optimization procedure then adjusts the model weights so that the model cost decreases to a minimum. When an optimal set of weights based on the training set is identified, the model is then used to generate predictions for the test set and calculate the corresponding cost, which takes the form of mean squared error for continuous output. The test set cost is the empirical risk to approximate the true risk and indicates how well the model generalizes to the unseen future dataset. After repeating the process for many rounds (epochs) until the training process has converged, we will finally choose a model that minimizes the empirical risk

Note that the optimization happens upon updating the weights based on the gradient of the current cost with respect to the current set of weights. The gradient descent algorithm thus requires us to be able to calculate the gradient vector $\nabla_w Q(w_t)$ that contains the partial derivatives of the cost with respect to each weight in w at timestamp t; in this case of neural networks, the weights in each layer.
