# Listing 7.10 Building a class to train FCN with different types of regularization

```
class MLP:
    def __init__(self, lr=1e-3, num_epochs=10, l1_weight=0, l2_weight=0):
        self.lr = lr
        self.num_epochs = num_epochs
        self.l1_weight = l1_weight
        self.l2_weight = l2_weight
        self.train_loss = []
        self.test_accuracy = []
        self.model = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28 * 28 * 1, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 10)
        )
        self.model.cuda()
        self.criterion = nn.CrossEntropyLoss().cuda()
        self.optimizer = torch.optim.SGD(self.model.parameters(), lr=self.lr)
```

Next, we build a fit() method to perform model training. The following code snippet shows that this method requires two input arguments: the training and test set data loader. For each epoch, we would first extract the current batch of the training dataset and perform the usual forward pass to obtain the predictions and corresponding loss. If the weight for LASSO or ridge penalty is activated, we would add the additional penalty term(s) to the current loss. To calculate these penalties, we would first obtain all the model’s parameters using self.model.parameters(), which then get stored in a list for follow-up calculation. These penalties terms are calculated using the function compute_l1_loss() and compute_l2_loss(), which are introduced shortly. After back-propagating the loss and updating the weights, we also score the model against the test set at the end of every epoch. The training loss per iteration and test set accuracy per epoch are stored in the attributes train_loss and test_accuracy, respectively.
