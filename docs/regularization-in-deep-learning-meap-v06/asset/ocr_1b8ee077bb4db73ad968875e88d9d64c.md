Note that falling into the region of confusion is not necessarily bad. When training large neural networks using real data, the loss curve will typically be highly dimensional and highly non-convex. Oscillations will push SGD away from sharp minima and move towards regions with small gradient norms, a property of implicit regularization as introduced in the previous section. However, when looking at this property from an optimization perspective, SGD is not a good optimizer due to these oscillations.

# 8.2.2 SGD's convergence in expectation

The SGD optimizer is a great tool that allows us to optimize over large datasets using randomized mini-batches and still obtain the same true gradient on average (the unbiasedness property). However, more than having an unbiased estimator is needed, as an estimator could suffer from a high variance problem but still displays the unbiasedness property. As a result, we would like to have an unbiased estimator that obtains a low variance with a high probability on average. And when the estimator's variance tends toward zero, we say that the estimator has converged.
