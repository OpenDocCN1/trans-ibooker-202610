For notational consistency, we use x to denote the input features (i.e., features that are provided by the input data), w to denote the weights between layers, and f as the intermediate function that operates on the input and weights from the previous layer to produce an output (i.e., a learned feature in the hidden space) for the next layer. We use the subscript to denote layer-wise index and the superscript to denote the index within a given layer. For example, x^j denotes the j^th node as the raw feature at the input layer, w^j_i denotes the j^th scalar weight (using relative positioning from top to bottom) of the i^th layer, and f^j_i denotes the j^th node of the i^th layer.

As shown by the two examples on f^2_2 and f_3, except at the input layer, each node is a result of matrix multiplication between the input nodes from the previous layer and the corresponding weights, followed by an activation function (ReLU in this case). The output of a node then becomes an input, a learned hidden feature, to the following layer, until reaching the final output layer.

The forward propagation is essentially a repeated operation of matrix multiplication (or equivalently weighted sum) and nonlinear transformation using the activation function. For example, the second node in the first hidden layer computes f^2_1 = ReLU(x^1 w^1_1 + x^2 w^1_4), whose output then becomes the input features for the same operation at the next layer. These input features in the hidden layer are automatically extracted and learned by the neural network and tend to be more disentangled and meaningful at different levels of abstraction.
