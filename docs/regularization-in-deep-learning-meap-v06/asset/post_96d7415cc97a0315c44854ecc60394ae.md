
collinearity exists in the original design matrix $\Phi$. Also, the larger the weighting factor $\lambda$ (technically should be $\sqrt{\lambda}$) becomes, the more these extended column vectors become orthogonal, making the solution of the normal equation stable as well.

Note that we could also derive the normal equation using the same approach based on the first order condition by setting the gradient to zero:

```
\frac{\partial Q(\mathbf{w})}{\partial \mathbf{w}} = \frac{\partial(\mathbf{y}-\Phi\mathbf{w})^T(\mathbf{y}-\Phi\mathbf{w}) + \lambda \mathbf{w}^T \Omega \mathbf{w}}{\partial \mathbf{w}} = -2 \Phi^T \mathbf{y} + 2 \Phi^T \Phi \mathbf{w} + 2 \lambda \Omega \mathbf{w} = 0
```

which gives the same normal equations $(\Phi^T\Phi + \lambda \Omega)\mathbf{w}=\Phi^T \mathbf{y}$ after arranging the terms. However, this would not give the same insight compared with the previous approach.

Also, note that matrix multiplication typically starts with transposing the first matrix. This depends on how we intend to arrange and interpret the rows and columns of the matrix, so that the result of the multiplication matches the expected shape.

## 3.2.4 Implementing the smoothing spline model

We will first start with the transformation function that maps the original univariate input X to a new design matrix $\Phi$, up to a pre-specified degree of polynomial. This is the same function as defined in chapter 2.

### Listing 3.2 Defining the polynomial transformation function

```
def polynomial(x, num_basis=2):
    Phi = np.zeros((x.shape[0], num_basis))
    for i in range(num_basis):
        Phi[:, i:i+1] = x**i
    return Phi
```

- #A Function to generate the new design matrix based on specified number of polynomial basis
- #B Create the matrix of zeros as placeholder
- #C Fill in each column based on the sequence of polynomials

As for the penalty term $J(\mathbf{w}) = \iint (m''(x))^2 dx$, it can be approximated via a discretized two-dimensional block when converting to $J(\mathbf{w}) = \mathbf{w}^T \Omega \mathbf{w}$. Specifically, $J(\mathbf{w})$ is approximated using the following:

$J(\mathbf{w}) = \sum_{q=2}^p \sum_{r=2}^q \beta_{q,r} w_q w_r$

where $\beta_{q,r}$ represents the elements of $\mathbf{\Omega}$ and calculated as follows:

$\beta_{q,r} = \frac{(q-1)q(r-1)r}{q+r-3}$

### Listing 3.3 Solving for the closed-form solution of the smoothing spline model

```
def estimate_coef(X, y, num_basis):
    Phi = polynomial(X, num_basis=num_basis)
    q = np.arange(2, num_basis).reshape(1, -1)
    r = q.reshape(-1, 1)
    omega = np.zeros((num_basis, num_basis))
    omega[2:, 2:] = (q - 1) * q * (r - 1) * r / (q+r-3)
    values, vectors = np.linalg.eig(omega)
    beta = vectors @ np.diag(values.clip(min = 0) ** 0.5)
    y_star = np.concatenate((y, np.zeros(omega.shape[0]).reshape(-1,1)), axis=0)
    Phi_star = np.concatenate((Phi, math.sqrt(rho) * beta.T), axis=0)
    w_star = np.linalg.lstsq(Phi_star, y_star, rcond=None)[0]
    return w_star
```

Next, we create a function to calculate the empirical risk, i.e., the mean squared error for a given dataset and set of coefficients.

### Listing 3.4 Calculating the mean squared error

```
def calculate_mse(X, y, coef, num_basis):
    Phi = polynomial(X, num_basis=num_basis)
    f_star = Phi@coef
    resid = y - f_star
    Q = np.dot(resid.T, resid).mean()
    return Q
```

- #C Calculate the residuals
- #D Cost with the optimal weight

Note that even when the model is complex enough to perfectly interpolate the training data, the exact MSE loss will not be reflected as zero during computation. Rather, it will be a very small number, such as $10^{-8}$, which can be assumed to be zero.

Finally, we create a function to allow multiple runs of the above steps and report the median result based on a pre-specified number of simulations. Specifically, we first create two placeholders (`mse_train` and `mse_test`) to store the results of multiple runs. For each run, we will generate a different dataset for training, allowing for the option to corrupt the target by a certain level of noise if needed. The generalization performance is assessed via a list of equally spaced points in X_test and the corresponding true target values in y_test. Next, we vary the model complexity by sequentially assessing models up to a different polynomial degree up to `num_basis_max`. Each assessment consists of estimating the model coefficients and calculating the corresponding cost. At the end of the function, we return the median cost for the training set and the test set across multiple runs.

### Listing 3.5 Calculating the median cost across multiple runs

```
def compute_performance(num_train_samples, num_runs, num_basis_max, train_noise_std=0):
    mse_train = np.zeros((num_runs, num_basis_max))
    mse_test = np.zeros((num_runs, num_basis_max))
    for k in range(num_runs):
        X_train = random.randn(num_train_samples).reshape(-1, 1)
        y_train = get_true_y(X_train).reshape(-1,1)
        if train_noise_std > 0:
            y_train = y_train + np.random.normal(0, 0.01, y_train.shape[0]).reshape(-1,1)
        X_test = np.linspace(0, 1, 100, dtype=X_train.dtype).reshape(-1,1)
        y_test = get_true_y(X_test).reshape(-1,1)
        for num_basis in range(1, num_basis_max + 1):
            fitted_coef = estimate_coef(X_train, y_train, num_basis)
            mse_train[k, num_basis-1] = calculate_mse(X_train, y_train, fitted_coef, num_basis)
            mse_test[k, num_basis-1] = calculate_mse(X_test, y_test, fitted_coef, num_basis)
    return np.median(mse_train, axis = 0), np.median(mse_test, axis=0)
```
