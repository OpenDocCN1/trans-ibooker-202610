## 6.1.2 Translational invariance in convolutional neural networks

Convolution is a unique operation designed to learn from geometric structures in image data effectively, assuming a 2D or 3D convolution operation. A convolutional layer uses much fewer parameters than a fully-connected layer and enjoys the benefit of weight sharing across different input features. That is, multiple features share the same weight, thus significantly reducing the effective number of weights employed by the neural network. Specifically, convolution is a mathematical operation where a function is passed over a sequence of values, and this process is known as convolving a function. It is also applicable to one-dimensional inputs such as sequence data, where 1D convolution can be used to capture the dependences within the data. Let us revisit the convolution operation and discuss how it surpasses the fully-connected layer in image recognition tasks.

As it turns out, we could tweak the design considerations of vanilla fully-connected neural networks using a particular type of inductive bias: convolution and pooling operations in a convolutional neural network, which turns out to be very effective in dealing with image data and beyond. Tweaking the design considerations constrains the neural network to exhibit specific desirable properties such as translational invariance, i.e., the network is able to recognize a particular object in an image no matter where it is located or translated. In other words, the network is invariant to positional translation of the object in the input image and can obtain the same classification result. This is one of the key benefits of convolutional neural networks due to the strong prior assumption that the object's location does not matter in terms of the final classification result.

Figure 6.4 illustrates the translational invariance property of a properly trained CNN that has high accuracy on MNIST dataset. Exposed to images with the digit 8 in different locations, a translationally invariant model such as CNN will generate the same class label of 8. This means that for an FCN to be able to correctly classify an image containing the digit 8, the FCN model must have encountered a similar digit 8 at similar positions during the initial training process, although an FCN trained long enough *may* figure out the location invariance property. CNN, on the other hand, is not sensitive to locations of the digit by design. This is principally due to the local filters, also called kernels, that manage to capture and utilize the essential signal on digit 8, no matter where it is positioned. A translationally variant model such as the FCN, however, may not necessarily produce the same classification result. This means that shuffling the pixels in the image data in a consistent manner would end up with the same FCN-based model due to its structure-agnostic nature. Without capturing the spatial relationship of the digit 8 on the image, an FCN will struggle to identify the same object, until it is trained long enough to develop meaningful representations and *learn* such property by itself.

It can recognize digit 8 as the same label, which is not easily achieved when training FCN-based models. Feed-forward architectures don't understand the structure or order in their inputs. Thus, when presenting a set of images and associated labels to a feed-forward network and performing the training, we would get the same result if we instead trained it after shuffling the pixel values in the images (in a consistent manner). Structural awareness is only built in CNN-based models.

Moving the object around without changing the classification result is thus an essential inductive bias exhibited in convolutional neural networks. Irrespective of the object location, a set of filters will move across the whole image (left to right, top to bottom) to perform the convolution operation. When meeting a particular edge-like region or other shapes of interest, specific nodes in the filters will activate, producing large values that “beat” the neighbors after the pooling operation. Therefore, it does not matter in terms of where the specific activation happens, if any, since it will eventually get pooled into the following layer. As long as a particular node fires, an adequately trained CNN will be able to capture such activation and realize that the noise is due to random translations. Translational invariance is thus a natural property embedded in CNN.

Besides translational invariance, we can also facilitate the learning of rotational invariance in a CNN by rotating the same object up to a certain degree. Provided that the new images with rotated objects still belong to the same class, we could generate more artificial and helpful images for the model to pick up and learn the desired property of rotational invariance. In fact, all the different data augmentation techniques covered in chapter 5 are designed to endow the model with some sort of invariance and robustness when recognizing the objects. These inductive biases are important accelerators to help the model understand different spatial connections of the objects and other visual properties specific to the current object recognition task. Other invariance properties, such as size invariance and illumination invariance, could also be similarly developed in the resulting model by providing corresponding augmented training data via data augmentation.

Note that rotational and scaling invariance properties can also be learned using the max pooling operation in CNN. For example, when the input image contains different degrees of rotation or scales, different filters in the hidden layer will get activated in terms of outputting a relatively large value. The max pooling layer will select the maximal activation from all filters, thus displaying invariance to possible rotation or scaling in the input image. Following the same reasoning, the max pooling, together with convolution operation to be discussed shortly, also contributes to translational invariance in CNN.

To achieve these desired properties, we need to constrain the connections in the FCN in a way that facilitates the network to learn local structures and pick up invariance properties. Specifically, we would like to embed relational inductive biases specific to different types of layers in a neural network. On the one hand, we exploit the locality of geometric objects in the input data so that the resulting CNN model is invariant to spatial translations. On the other hand, the sequentiality of objects (e.g., tokens in natural language processing, observations in a time series) is exploited in a recurrent neural network (RNN) so that the resulting model is invariant to temporal translations.

Before delving into how we can constrain the FCN to display the desired property, let us look at the convolution operation in more detail. In fact, as you will see in the following section, CNN is a special type of constrained FCN due to the convolution operation.

## 6.1.3 Understanding the convolution operator

The convolution operator is one of the main drivers for achieving the translational invariance property. Recall the convolution workflow figure in chapter 4, which is also shown in figure 6.5 here for ease of reference. The key takeaway is that we define a kernel/filter to sequentially convolve with different input patches and produce the resulting features in the feature map. Every single convolution consists of element-wise multiplications between the kernel and the input patch, followed by a summation operation.
