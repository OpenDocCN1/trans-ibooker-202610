Figure 6.15 Illustrating the hard parameter sharing scheme for three tasks. The architecture starts with a common set of shared layers used by all tasks for common representation learning, then branches into three separate sequences of layers for task-specific learning. When all learning tasks are related to each other, such architecture offers better generalization performance (with fewer parameters and thus lower risk of overfitting) as well as higher learning efficiency (again, with fewer learnable parameters compared with three separate networks). Note that the individual task-specific losses could be combined directly via using a weighting scheme following some prior preference or using an adaptive approach.

On the other hand, the soft parameter sharing scheme adds a soft constraint to encourage a similar representation among related weights of all learning tasks, instead of enforcing them to adopt the exact same value. The constraint often takes the form of a distance-based penalty measure among the model weights, such as the l1 norm as in the Lasso penalty and l2 norm as in the ridge penalty. Regularizing the distance among the weights of the model encourages these weights to be similar in value. This scheme thus offers more flexibility for the architectural design each learning task as it only loosely couples the shared feature representations.
