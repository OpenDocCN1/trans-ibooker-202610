In the case that you do not want to change either algorithm, one way is to transform the data by centering the target vector y. Centering the target variable ensures that it will have a mean of zero, so that it does not make a big difference whether we penalize the magnitude or not. In other words, we can run the closed-form solution or regular gradient descent update in ridge regression without differentiating the weight for the bias term.

Ridge regression thus allows us to account for many features in a standard linear regression setting. It gives us a handle (the hyperparameter \(\lambda\)) to balance bias and variance.
