error (SSE) being a most popular one. The SSE, defined as $Q(w) = L(yf_w(X)) = \sum_{i=1}^n 1/2 r_i^2 = \sum_{i=1}^n (y_i - f(x_i; w))^2$, not only enforces sign consistency for the positive and negative residuals, but also puts a bigger penalty on larger residuals due to the squaring operation. It also makes the follow-up optimization easier when solving for the closed-form solution or using iterative procedure such as gradient descent (more on this later).

We can also use the *mean squared error* (MSE) as the cost function by dividing SSE by the number of (training) observations, which is more often used in a standard linear regression case. Both SSE and MSE give the same coefficient estimate due to the same exact location that bears the minimal cost, although MSE gives a sense of how much an average prediction differs from the target.

In addition, $Q(w)$ is only a function of the changeable weights **w** and not a function of the unchangeable design matrix **X**. It is a non-negative scalar value that we wish to minimize. In a later section on empirical risk minimization, we will assume **X** also changes.

# 2.3.1 Expressing the cost function with linear algebra

In the context of linear regression, the cost function can be further written as $Q(w) = \sum_{i=1}^n (y_i - \phi(x_i)w)^2$, where $\phi(x)$ is a more general form to indicate additional transformation on the input features. In the case when no transformation is involved, we simply have $\phi(x) = x$. Besides, we can express the same operation using a more concise form of linear algebra: $Q(w) = (y - \Phi w)^T(y - \Phi w) = y^Ty - 2y^T\Phi w + w^T\Phi^T\Phi w$, where $\Phi$ is a shorthand for $\Phi = \Phi(X)$. This equation is based on the fact that $y^T\Phi w + w^T\Phi^Ty$, since the transpose of a symmetric matrix, in this case a scalar, is just equal to itself. Expressing the cost function in this way would facilitate our follow-up analysis when calculating its gradient.

Note that the cost function measures how close or far off the prediction is to the target value based on the current weight vector. The output of the cost function is thus a scalar distance measure that needs to be minimized using a particular optimization procedure.
