Similar challenges exist for text data as well. For instance, a document consists of a multitude of words, each of which could express a different meaning depending on the context. To effectively learn from text data and identify consistent patterns, the model needs to be able to derive word importance and their interaction effect. This process could easily result in tens of thousands of features.

Specific regularization approaches can effectively tackle the challenge of high dimensionality. For example, sparse learning aims to learn a small subset of significant features and discard the others. Such an approach essentially assumes that only a small subset of features is predictive, and the rest are removed by setting the coefficient to zero. Standard sparse learning techniques include Lasso and its variants, which work by adding a penalty on the magnitude of the coefficients, besides minimizing training error. For example, if we want to build a model to classify if the previous picture to be either country or city area, the features representing the tall buildings are more likely to be predictive than others. Using the sparsity constraints could help silence the irrelevant features by setting their resulting coefficient to zero, giving more focused attention to predictive features.
