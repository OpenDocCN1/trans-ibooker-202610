

Therefore, the backward-mode multiplication is generally more computationally efficient in most cases when doing automatic differentiation.

The backward-mode multiplication in automatic differentiation is also called _backpropagation_. Specifically, the series of matrix multiplication starts at the last layer, followed by multiplying the matrices of partial derivatives in previous layers until reaching the initial weights. Despite the faster computation than the forward mode, the backward mode requires more memory size to store the intermediate matrices of partial derivatives in each hidden layer. However, running the forward mode would compute these gradients of the current layer in the same order as the forward pass of the prediction function, and the gradients are discarded when moving to the next layer.

### 4.3.2 Defining the prediction function

At this point, we have been defining our model as a prediction function that takes input data, interacts with the model parameters via a series of matrix-vector multiplication and nonlinear transformation, and outputs model predictions. The prediction function achieves two goals in one shot: defining the model parameters and specifying the model architecture (i.e., interaction mechanism between weights and input). Achieving both objectives in one function works okay if the problem scale is small and the model is relatively simple. However, as the complexity increases in the data, the model, the cost, or the optimization procedure of the whole model training process, it is advisable to segregate the model parameters from the model architecture and modularize the respective codes according to the specific purpose. In other words, the model parameters and the model architecture that specifies the interaction between the data and the parameters would have their dedicated functions.

The common practice is to use a class to wrap all these different utility functions under one roof. Specifically, we can arrange the model parameters in one function, which often manifests as the class’s default __init__ function. The __init__ function contains attributes that are initialized when the class is first instantiated, meaning the abstract class is converted to a physical and tangible object. These attributes include essential building blocks of the class, i.e., layers for the neural network and the resulting parameters implied from the layers. Instantiation is similar to buying a lego toy set with all the parts provided based on its drawing specification. These parts can also be different sizes and structures, where a big component can consist of several small ones.

In addition, the function that defines the model architecture and regulates the flow of data goes into the forward function, which serves as the instruction sheet on how to assemble the parts. This is a special function that is automatically executed under the hood
