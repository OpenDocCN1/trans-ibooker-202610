# 2.6.3 Understanding bias and variance using bootstrap

The model bias refers to the gap between the expected model prediction (_f_) and the underlying true target _g_ : _Bias_[_f_] = _g_ − E[_f_]. The expectation here is again considering all different realizations of the dataset (**X**,**y**) sampled from the same joint data generating distribution P(**x**,**y**). A biased model is said to underfit the training data, since the relationship between the input features and the output label is not properly captured. A less biased model, on the other hand, could better capture the regularities and represent the underlying complexity well.

In figure 2.22, the squared bias term could be thought of as the error due to a simplifying assumption in the model, such as approximating an inherently nonlinear pattern _g_ using an under-capacitated linear model _f_. Such an assumption will lead to insufficient representation of the true pattern in the data. Improving the model complexity, such as using feature augmentation, will likely improve the model’s fitting capacity and thus reduce its bias due to better approximation. However, doing so may risk overfitting the data.

Variance, on the other hand, measures the expected movement of _f_ around its mean: _Var_[_f_] = [(_f_ − E[_f_])<sup>2</sup>]. Such movement also refers to the model’s sensitivity to possible changes in the data. As a result of overfitting the random noise, a model with high variance will be too complex and sensitive to small fluctuations in the data. Note that the level of complexity for a high-variance model _f_ is in terms of the current dataset and not the real complexity of the underlying function _g_; the latter is often much more complex in reality.

Since both bias and variance are highly dependent on the currently available dataset (**X**,**y**), one way to quantify the model’s bias and variance for other versions of (**X**,**y**) is to use the _bootstrap_ procedure. Bootstrap is a technique to generate artificial datasets by randomly sampling from the original dataset (**X**,**y**) with replacement. These artificial datasets now serve as additional realizations from P(**x**,**y**) and can be used to perform the same model fitting procedure for multiple times. The resulting multiple fits could then be used to estimate the bias and the variance of the original model _f_.
