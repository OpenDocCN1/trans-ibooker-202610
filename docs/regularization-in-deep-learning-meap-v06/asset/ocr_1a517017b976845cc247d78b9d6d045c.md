Let us look at a specific example by creating a model class called CNN, suggesting that this is a convolutional neural network. Convolution is a particular type of neural network layer that effectively processes image data. It takes the form of a small square filter (also called kernel) and operates on local regions of the input data by repeatedly scanning through the input surface. In the case of grayscale image data in MNIST, each image entry will manifest as a two-dimensional matrix where each cell stores a pixel value between 0 and 255.

As shown in figure 4.17, we create a 3x3 kernel to host a total of nine weights. The same kernel would then sequentially move around the input image data and interact with different patches, thus achieving feature sharing across different local input regions. The specific convolution mechanism, which should not surprise you, is still a weighted sum operation. In other words, each interaction between the kernel and a local region of the input data results in a scalar value, and the overall output data will shrink in size compared with the input data. The example provided in the figure has an output feature valued at 3 based on the convolution operation between the two input matrixes highlighted in solid line. The output is also called a feature map since the convolution operation essentially projects the input data from its original feature space to another, more refined and hopefully meaningful one.

Each convolution operation consists of element-wise matrix multiplication, followed by summing all the terms to produce a final scalar value in the resulting output feature map.
