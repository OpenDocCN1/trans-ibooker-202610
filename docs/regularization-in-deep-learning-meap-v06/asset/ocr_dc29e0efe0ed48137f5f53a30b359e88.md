# ## 5.3.7 Bootstrap error between real world and ideal world

We can now visualize the training and test set performances across the same number of SGD iterations between the real world and the ideal world. Note that we only take 100 snapshots across the whole training and testing process; the spaces between are automatically smoothly interpolated by the plotting function. Our experiment thus serves as an approximation to the more fine-grained version.
