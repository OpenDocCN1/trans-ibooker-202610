The multiplication process can also be viewed as a projection operation, projecting the data from the original input space for X to the output space for ŷ by multiplying w. The optimal projection is sought by minimizing a pre-defined cost function. Linear regression only involves one round of optimal projection between X and. When feature engineering is introduced, X is projected to a more expressive, possibly higher-dimensional space via a transformation function φ(X). In the context of deep neural networks, multiple projections are performed on top of each other, along with additional nonlinear transformations in between. See more details on the flow of information in neural networks in Chapter 4.

**Matrix multiplication**

A matrix is characterized by its shape, namely the number of rows and columns. A matrix is of shape (n,p) if it contains n rows and p columns. Given two matrices A of shape (n,p) and B of shape (q,k), for their multiplication to work, a necessary condition is the equality in the "inner dimension", i.e., p = q. The resulting matrix AB will take the shape of the "outer dimension", i.e., (n,k). Checking the change of dimensions is recommended when doing matrix multiplication.

# 2.2.2 The bias trick

In linear regression, a bias term w0 is often introduced to act as a global level shift to the prediction output, making ŷ = w0 + Xw. The additional term w0 is a learnable parameter, a global adjustment applied to all outputs. It is also referred to as the intercept term in the linear regression setting.

In practical implementation, a simplified linear algebraic form could be obtained by writing ŷ = XnewWnew, where Xnew is the new design matrix created by appending a column vector of ones to the beginning of X, and Wnew is simply one more parameter added to the beginning of the weight vector w. This is called the bias trick, allowing us to express the same operation using an algebraic form of a matrix vector multiplication. Besides, it also saves us the trouble of creating a separate parameter for w0, since the additional column vector of ones in Xnew will simply be treated as a separate feature. The added column vector of ones could thus make follow-up mathematical analysis more convenient, besides the benefit of more straightforward implementation by simply representing all parameters in one vector.
