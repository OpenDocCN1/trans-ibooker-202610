### 2.3 The cost function

Each model has an associated cost function to measure the goodness of fit to the training data. Given a prediction f(x_i;w) for the input x_i and the corresponding target y_i for the i-th data pair, the scalar difference or residual r_i in a regression setting can be calculated by taking their difference, i.e. r_i = y_i - f(x_i;w). These residuals, when reflected on a graph, refer to the vertical distances between the prediction and the actual training data points on the graph. There are multiple ways to aggregate these individual residuals, with the sum of squared error (SSE) being a most popular one. The SSE, defined as Q(w) = L(yf_w(X)) = Σ_{i=1}^n 1/2 r_i^2 = Σ_{i=1}^n (y_i - f(x_i; w))^2, not only enforces sign consistency for the positive and negative residuals, but also puts a bigger penalty on larger residuals due to the squaring operation. It also makes the follow-up optimization easier when solving for the closed-form solution or using iterative procedure such as gradient descent (more on this later).

We can also use the mean squared error (MSE) as the cost function by dividing SSE by the number of (training) observations, which is more often used in a standard linear regression case. Both SSE and MSE give the same coefficient estimate due to the same exact location that bears the minimal cost, although MSE gives a sense of how much an average prediction differs from the target.

In addition, Q(w) is only a function of the changeable weights w and not a function of the unchangeable design matrix X. It is a non-negative scalar value that we wish to minimize. In a later section on empirical risk minimization, we will assume X also changes.

### 2.3.1 Expressing the cost function with linear algebra

In the context of linear regression, the cost function can be further written as Q(w) = Σ_{i=1}^n (y_i - φ(x_i)w)^2, where φ(x) is a more general form to indicate additional transformation on the input features. In the case when no transformation is involved, we simply have φ(x) = x. Besides, we can express the same operation using a more concise form of linear algebra: Q(w) = (y - Φw)^T(y - Φw) = y^Ty - 2y^TΦw + w^TΦ^TΦw, where Φ is a shorthand for Φ = Φ(X). This equation is based on the fact that y^TΦw + w^TΦ^Ty, since the transpose of a symmetric matrix, in this case a scalar, is just equal to itself. Expressing the cost function in this way would facilitate our follow-up analysis when calculating its gradient.

Note that the cost function measures how close or far off the prediction is to the target value based on the current weight vector. The output of the cost function is thus a scalar distance measure that needs to be minimized using a particular optimization procedure. Feel free to expand Q(w) based on its definition and verify its shape. Figure 2.8 summarizes the different ways of expressing SSE as the cost function.

We now have a cost function, which is also referred to as the objective or loss function. The cost function serves as the one-to-one mapping function between the weight vector w and the scalar cost Q(w), an indicator on how well the current model (specifically, the weights) is doing. Next, we introduce the optimization procedure used to guide the modification of w in a way that minimizes Q(w). The specific procedure involved in the optimization process is also called an algorithm, designed to minimize the scalar-valued cost Q(w).

### 2.4 The optimization algorithm

Optimization involves tuning the model parameters based on a particular procedure, an algorithm to reduce the pre-defined cost function to a minimum value. In other words, the optimal weight vector w* is obtained when the cost function is minimized: w* = argmin_w Q(w). When visualizing the cost function on a graph, its minimum suggests that the derivative of the cost function at this particular point is zero. The minimum point is also called a stationary point.

In the case of multiple features, being at the stationary point means that the gradient vector with respect to the current weight vector is zero across all the weights. Note that the gradient vector contains the partial derivatives with respect to each weight. Based on the previous definition of Q(w) = y^T y - 2y^T Φw + w^T Φ^T Φw and its only dependence on w, its derivative with respect to w could be written as ∇wQ = -2Φ^T y + 2Φ^T Φw. Consequently, the goal of optimization is to reach a stationary point where all elements in ∇wQ are zero. This point then represents a model that potentially gives the minimal cost.
