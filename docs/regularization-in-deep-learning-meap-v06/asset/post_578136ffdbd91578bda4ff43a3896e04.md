
One of the reasons why ReLU (and its variants) remains the most popular activation function is its fast gradient computation. When the input is less than or equal to zero, the gradient (of a constant number) becomes zero, thus saving the need for back-propagation and parameter update. When the input is positive, the gradient (of the original input variable) is simply one, which gets back-propagated as it is.

Since a typical neural network model consists of multiple layers, we can express the perceptron operation of the \(l^{th}\) layer in a recursive manner as the following:

```
\(f_l(\mathbf{x}) = \phi(\mathbf{W}_l f_{l-1}(\mathbf{x}) + \mathbf{b}_l)\)
```

where **x** is the original input vector to the multi-layer neural network with a total of \(L\) layers. Note that since each layer typically consists of multiple nodes, the weights \(\mathbf{W}_l\) between layer \(l-1\) and layer \(l\) now become a matrix of shape \(|l-1| \times |l|\), where \(|l|\) denotes the number of nodes in layer \(l\). Similarly, \(\mathbf{b}_l\) contains a vector of biases of size \(|l|\). After applying the activation function \(\phi\), the output vector \(f_l(\mathbf{x})\) will have the same dimension as the input vector \(\mathbf{W}_l f_{l-1}(\mathbf{x}) + \mathbf{b}_l\). That is, the activation function does not change the input dimension since it is applied to each element in the input vector. As for the first layer, the output of the perceptron operation simply returns the input itself, i.e., \(f_0(\mathbf{x}) = \mathbf{x}\).

By plugging in the definition of previous perceptron \(f_{l-1}\) and more, we can re-express the final output of the multi-layered neural network as a series of perceptron operations, i.e., repeated matrix multiplications and nonlinear transformations based on the original input **x**:

```
\(f_L(\mathbf{x}) = \phi(\mathbf{b}_L + \mathbf{W}_L \phi(\mathbf{b}_{L-1} + \mathbf{W}_{L-1} \phi(\cdots \phi(\mathbf{b}_1 + \mathbf{W}_1 \mathbf{x}) \cdots)))\)
```

In practice, the input vector **x** can also be converted to a tensor representation in PyTorch, which is similar to a multi-dimensional array.

## 4.1.1 A two-layer neural network

Let us look at the approximation capacity of a simple two-layer neural network using ReLU activation function, i.e., a neural network with one hidden layer and one output layer. To make things simple, we assume a one-dimensional scalar input \(x\), a hidden layer with five nodes, and a one-dimensional output. The whole neural network could then be expressed via \(f(x)=\mathbf{w}_2^T \phi(\mathbf{w}_1 x + \mathbf{b}_1)\), where \(\mathbf{w}_1 = \{w^1_1, w^2_1, w^3_1, w^4_1, w^5_1\}\), \(\mathbf{b}_1 = \{b^1_1, b^2_1, b^3_1, b^4_1, b^5_1\}\) and \(\mathbf{w}_2 = \{b^1_1, b^2_1, b^3_1, b^1_4, b^1_5\}\) are all 5 x 1 weight vectors. For simplicity, we ignored the scalar bias term \(b_2\) between the hidden layer and the output layer, and used the weighted sum as the direct output for the final layer without activation function. The first bias vector \(\mathbf{b}_1\) contains five elements that correspond to the five neurons in the hidden layer. See figure 4.3 for an illustration of the network architecture.

Depending on the number of activation functions used in the hidden layer, the resulting output has a corresponding level of complexity in terms of the number of breakpoints or linear segments separated by these breakpoints. In other words, the model complexity in the final output is linearly correlated with the number of neurons in the hidden layer of a shallow neural network. The number of nodes, i.e., the width of a layer, thus directly determines the complexity and expressivity of the neural network model. This means that to have sufficient turning points (i.e., breakpoints) to approximate an elaborate function, a neural network model needs to be wide enough in the hidden layer (i.e., having enough hidden nodes). However, doing so would be computationally inefficient. The computational cost of having more nodes will likely outweigh the benefit of the added modeling flexibility.

Instead of making the shallow neural network wider, the mainstream approach to improve the representational power of a neural network is to make it deeper by stacking more layers. This is why it is called the deep neural network. In general, a neural network with more than two hidden layers can be called deep, although the depth can grow much more for large models. Building a deep neural network with multiple layers is more efficient to increase its approximating power than widening a shallow one.
