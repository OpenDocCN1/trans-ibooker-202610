collinearity exists in the original design matrix $\Phi$. Also, the larger the weighting factor $\lambda$ (technically should be $\sqrt{\lambda}$) becomes, the more these extended column vectors become orthogonal, making the solution of the normal equation stable as well.

Note that we could also derive the normal equation using the same approach based on the first order condition by setting the gradient to zero:

```
\frac{\partial Q(\mathbf{w})}{\partial \mathbf{w}} = \frac{\partial(\mathbf{y}-\Phi\mathbf{w})^T(\mathbf{y}-\Phi\mathbf{w}) + \lambda \mathbf{w}^T \Omega \mathbf{w}}{\partial \mathbf{w}} = -2 \Phi^T \mathbf{y} + 2 \Phi^T \Phi \mathbf{w} + 2 \lambda \Omega \mathbf{w} = 0
```

which gives the same normal equations $(\Phi^T\Phi + \lambda \Omega)\mathbf{w}=\Phi^T \mathbf{y}$ after arranging the terms. However, this would not give the same insight compared with the previous approach.

Also, note that matrix multiplication typically starts with transposing the first matrix. This depends on how we intend to arrange and interpret the rows and columns of the matrix, so that the result of the multiplication matches the expected shape.

# 3.2.4 Implementing the smoothing spline model

To observe the "double descent" phenomenon using the smoothing spline model, we will create the following function to represent the true underlying pattern:

```
y = ||x - 0.4| - 0.2| + \frac{x}{2} - 0.1
```

This is the true piecewise linear function to be approximated using the smoothing spline model. The code listing below implements the underlying function to be approximated.

```
Listing 3.1 Defining the true underlying function

def get_true_y(x):
    return np.abs(np.abs(x - 0.4) - 0.2) + x/2 - 0.1
```
