One way to visually examine if the learning rate is properly set is to plot the model cost as a function of the number of iteration. We can plot the cost after every iteration of gradient descent by setting the number of iteration on the horizontal axis and the cost on the vertical axis. By checking if the cost is steadily decreasing, this plot provides us with a tool to assess the appropriateness of the learning rate hyper-parameter. When the cost decreases very slowly, it shows the model has more or less converged to a stationary point. This monitoring tool also helps us detect if the cost is consistently increasing, which is an obvious sign of divergence.
