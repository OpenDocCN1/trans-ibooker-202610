Next, we will define two utility functions to support the coordinate-wise gradient descent algorithm. In the following code snippets, we define the function `calculate_mse()` to calculate the mean squared error and the `feature_derivative_ridge()` function to obtain the derivative for each feature. `calculate_mse()` is the same utility function we used in the previous chapter, where we first generate the list of predictions stored in `f_star`, calculate the residuals in `resid`, and finally return the total mean squared error in `Q`. The `feature_derivative_ridge()` function implements the exact closed-form derivative solution discussed earlier, where we separate the case when the weight is for the first bias term as it is not penalized. Note that both functions are included as part of the methods within the `GD_regression` class.

# Listing 7.4 Class methods to calculate MSE and derivative

```
def calculate_mse(self, X, y, weights): #A
    f_star = X@weights #B
    resid = y - f_star #C
    Q = np.dot(resid.T, resid).mean() #D
    return Q

def feature_derivative_ridge(self, errors, feature, weight, l2_penalty,
    feature_is_constant): #E
    if feature_is_constant == True: #F
        derivative = np.dot(feature, errors) * 2
    elif feature_is_constant == False: #G
        derivative = np.dot(feature, errors) * 2 + 2*l2_penalty*weight
    else:
        derivative = 'derivative not exist!!!'
    return derivative
```
