To solve for the optimal weight vector, we can use another iterative optimization procedure called coordinate descent, which updates each coordinate/weight one at a time while keeping all others fixed. In particular, the algorithm relies on the sub-gradient of $|w_j|$ when $w_j = 0$. Although the coordinate descent algorithm is not our main focus, understanding its derivation process helps us gain more insight into how LASSO obtains a sparse solution, which is using the soft thresholding rule, an update rule for each coordinate $w_j$. Let look at how the rule is derived.

Recall that the LASSO objective function is $Q(\mathbf{w}) = RSS(\mathbf{w}) + \lambda||\mathbf{w}||_1 = \sum_{i=1}^N (y_i - \sum_{k=0}^d \Phi_{ik} w_k) + \lambda \sum_{k=0}^d |w_k|$. When using the coordinate descent algorithm, assume we focus on updating the $j^{th}$ weight $w_j$ and keep all other weights $\mathbf{w}_{-j}$ fixed when setting the first partial derivative $\frac{\partial Q(\mathbf{w})}{\partial w_j}$ to zero to obtain the closed-form update for the current coordinate $w_j$. Figure 7.21 illustrates the derivation of the partial derivative for the first term $RSS(\mathbf{w})$. The key difference compared to the previous derivation process is that we keep the term involving $w_j$ separate from the rest, which is assumed to stay fixed and thus give a zero partial derivative. Note that $\rho_j$ could be considered as the correlation between the design matrix and prediction error without $w_j$.
