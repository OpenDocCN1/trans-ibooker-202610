## 7.4 Summary

- Regularization via the objective function refers to any regularization/penalty term added to the original unregularized loss term, where the regularization term is designed to penalize the magnitude of the model weights
- Common norm-based regularization terms include the LASSO penalty (L1 norm), ridge penalty (L2 norm), or the elastic net (a weighted combination of LASSO and ridge)
- When seeking the optimal weights, one can derive the closed-form solution and directly calculate the solution; when the closed-form solution is not available, we often resort to iterative procedures such as (stochastic) gradient descent or alternative optimization procedures such as coordinate descent
- The bias term is often not penalized and only the weights associated with the features are penalized in terms of the norm-based magnitude
- LASSO-based penalties tends to generate a sparse solution by setting some weight to zero and the rest towards zero based on the soft thresholding rule
- Both LASSO and ridge penalties have a nice geometric interpretation in terms of the regularization effect
- There is more than one way to implement the norm-based penalty, both from the ground up and off-the-shelf
- Tuning the hyperparameter for the regularization term(s) requires rounds of trial and error

The regularization techniques we have covered so far, including regularization via data, model, and objective function, involve additional treatments to the model training process in order to achieve a regularization effect. For example, we can regularize an overfit model by augmenting the training data, adding a dropout layer to the neural network, or penalizing the magnitude of the weights in the objective function. However, the optimization algorithm, the last component in the model training process and the topic of this chapter, can introduce an implicit regularization effect without any additional treatment. In other words, we reap the benefit of regularization while optimizing the model as usual.

The specific optimization algorithm that can simultaneously optimize and (implicitly) regularize a neural network model is stochastic gradient descent (SGD), an ancient yet the most widely used algorithm for training large-scale deep neural networks. We have encountered SGD quite a few times in the previous chapters, using this specific algorithm to optimize several neural networks. This chapter will examine its implicit regularization behavior by analyzing its theoretical properties and empirical performances. Our understanding of its contribution to generalization is still growing, as shown by recent research papers in this field. We hope to bring some of the latest findings about its regularizing attribute in this chapter.

## 8.1 Stochastic optimization

Generalization in deep learning is a unique and mysterious cuisine with multiple ingredients, with stochastic optimization serving as a major ingredient. Compared with deterministic optimization, stochastic optimization highlights the stochasticity component during the optimization process. Such stochasticity, or noise, may not necessarily be a bad thing. In fact, the stochastic behavior could often drive the optimizer toward a better solution compared with a deterministic optimizer, as shown by models trained using SGD versus full batch gradient descent algorithm.

Let us revisit the empirical risk minimization framework and analyze the gradient descent family of algorithms in this context.

### 8.1.1 Empirical risk minimization via gradient descent

Our journey in training deep neural networks boils down to an optimization problem: locating the solution in the parameter space that delivers the best generalization performance. Mathematically, for the loss function Q(w, D) that returns the loss given the current weight w and training dataset D, our objective is to find its (global, hopefully) minimum:

```
min_w Q(w, D) = min_w \sum_{i=1}^n Q_i(w, D_i)
```

Where the loss function is a sum of all individual losses, a finite sum problem. When n → ∞, we have a stochastic optimization problem.

Now recall the formulation of the gradient descent update algorithm covered in chapter 2, also shown here for ease of reference. In the following equation on one iteration of gradient descent update, we obtain the weight value of the next iterate w_{t+1} based on the current weight w_t, the gradient vector of partial derivatives ∇_w Q(w_t, D) (calculated by differentiating the current loss with respect to the weight), and a small learning rate η.

Here, Q(w_t, D) is our empirical loss function based on the training dataset D and current weight vector w_t. For now, we assume it is the direct loss term, such as the mean squared error (MSE), although it can include additional regularization terms, such as the L1 or L2 norm of the weights. The negative sign here suggests that w_t is moving toward the direction of the fastest descent of the loss function. We would then keep iterating the gradient descent update until this process converges (indicated by a minimal change in w_t) or the performance metric (i.e., MSE) on the holdout validation set (which approximates the unseen test set) no longer decreases.

Let us talk about the challenges of this gradient descent update. First, we need to use all observations in the training set D and sum up individual losses to obtain the total loss Q(w_t, D). When the number of observations in the training set becomes large, iterating through all the observations to calculate the individual loss would be time-consuming. Second, it is challenging to calculate Q(w_t, D) on a GPU instance with limited memory since we would need to fit all the data in the GPU memory to calculate the total loss and perform backpropagation update. The hardware limit on the GPU memory requires a reasonable amount of data to be processed during computation. Third, there is no need to use all the observations to calculate the average loss Q(w, D). Since the central limit theorem applies, we only need to use a fraction of D to calculate the average loss term MSE, which will converge to the MSE of the entire dataset after a reasonable number of iterations.

Because of these considerations, the stochastic gradient descent update rule based on subsets of D is often used. As shown in the following update equation, we use D_t to denote a random subset (also called minibatch) of D. In each iteration, we randomly sample a subset D_t and use it to perform one iteration of gradient descent update. The update rule is also referred to as minibatch-SGD, as covered in chapter 2.

```
w_{t+1} = w_t - \eta \nabla_w Q(w_t, D_t)
```

The random subset D_t can be considered a random variable consisting of a random subset of observations from D in each update. In practice, however, we often pre-divide the original training set D into different subsets (called mini-batches), perform gradient descent updates across different mini-batches in the inner loop, and repeat the process multiple times (called epochs) in the outer loop.

Note that we would treat the mini-batch D_t as a random variable in mathematical analysis to ensure that the mini-batches are independent of each other. To implement this, we would resort to the random number generator and produce random indexes to fetch the observations in a mini-batch, whose size also depends on that of D.

Also, using the stochastic gradient descent algorithm does not guarantee we will be able to descend the loss function at every step. Due to the randomness in the subset, we may even increase the loss value at a specific step, but the overall process will move towards a local optimum, stochastically.

Switching to a mini-batch in each gradient descent update facilitates the model training when D is quite large. However, we may ask whether the mini-batch gradient descent update algorithm converges to a local minimum of the cost function or keeps wandering around along the loss surface. Let us look at the convergence property SGD in the following section.

### 8.1.2 Convergence of SGD

For an algorithm to succeed and gain popularity, we would often ask if the algorithm converges into a solution and, if it does, the convergence rate. For the vanilla gradient descent, we know that the algorithm always converges to a particular local minimum solution for an adequately selected learning rate. Although the quality of the solution may not be excellent in terms of generalization performance, it still converges to a critical point (more specifically, a point with the gradient vector equal to zero) in the weight space.
