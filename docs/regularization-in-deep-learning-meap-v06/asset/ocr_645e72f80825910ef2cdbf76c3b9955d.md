# ## 1.8 Summary

+   - Regularization includes a suite of techniques used to generalize the trained model to the unseen test set
+   - Regularization can be applied across the four components of a model training pipeline: data, model, cost and optimization; it can be explicit or implicit, strong or weak
+   - Underfitting refers to an under-capacitated model that suffers from a high bias and fails to capture the underlying pattern, and overfitting refers to an over-capacitated model that suffers from a high variance and may accidentally learn a spurious relationship
+   - Model training needs to balance the bias and the variance and arrive at the right level of model complexity
