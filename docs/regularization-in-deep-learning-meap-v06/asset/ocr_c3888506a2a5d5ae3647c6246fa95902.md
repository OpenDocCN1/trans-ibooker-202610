Recall the overall model training workflow shown in figure 7.1. The primary role of the objective function is to compare the model prediction with the corresponding target label, taking a classification setting, for example, without loss of generality. It provides a direct scalar value, often in the form of a cost to be minimized, to summarize the predictiveness of the current model. When the goal of the optimization procedure is to build an accurate model that performs well in the training set, optimizing the objective function means minimizing the prediction error by continuously changing the weights to the point that the prediction error is zero. In other words, the final state of maximizing the prediction accuracy _alone_ in the objective function is a model that perfectly interpolates the training dataset.

However, a complex model is prone to overfitting irregardless of whether it exhibits perfect interpolation in the training dataset. Such complexity often leads to unstable predictions for a new test set with a slight variation. It turns out that we can include more than one metric in the objective function. For example, instead of optimizing the prediction accuracy alone, we can introduce an additional penalty term on the complexity of the model so that the resulting model is expected to trade off between prediction accuracy and model complexity. In other words, a complex and likely overfitting model will obtain a low prediction cost but at the same time, incur a significant penalty on the model complexity, causing the total value of the objective function to be high. On the other hand, a simple model gives a low value on the penalty term but lacks predictive power, leading to a high value of the objective function.
