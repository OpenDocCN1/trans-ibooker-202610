# 8.3 Summary

+   - SGD provides an implicit regularization effect that helps improving the generalization performance of the neural network in the test set
+   - Both GD and SGD minimize the empirical risk when training a deep neural network, with SGD taking on stochasticity in the gradient based on a mini-batch (one observation)
+   - SGD provides an unbiased estimator to GD and enjoys convergence property for both convex and nonconvex function approximators at a sublinear rate (under certain assumptions on the gradient norm)
+   - The implicit regularization property allows the SGD optimizer to prefer a region with a low variance of the gradient norm; this variance becomes an explicit penalty term when viewing SGD mean iterates as a gradient flow
+   - SGD variants such as momentum and Adam help accelerate optimization but hurt generalization compared with vanilla SGD; faster convergence is not preferred in nonconvex optimization of deep neural networks
+   - SGD exhibits fast progress in descending the loss in the far-out zone but starts to fluctuate and oscillate once it enters the region of confusion in a univariate linear regression setting with provable theoretical analysis
+   - SGD’s convergence in expectation shows that the expected variance of the gradient norm gets smaller as the number of iterations increases
+   - Theoretical understanding of SGD’s generalization performance remains an open problem and an active area of research
