$x_L y_i \ge x_i y_L$
$x_t x_i y_i \ge x_i^2 y_L$
\(\sum_{i=1}^N x_t x_i y_i \ge \sum_{i=1}^N x_i^2 y_L\)
\(x_L \sum_{i=1}^N x_i y_i \ge y_L \sum_{i=1}^N x_i^2\)
\(w^* = \frac{\sum_{i=1}^N x_i y_i}{\sum_{i=1}^N x_i^2} \ge \frac{y_L}{x_L} = L\)

Therefore, we have \(w^* \in [L, U]\). This is the region where the true minimum lies. Figure 8.12 summarizes the derivation process.
