
![](img/ee98e91e6845f41077b163bec833ee40_48_0.png)

There are a few things to pay attention to regarding the one-step calculation involved in the closed-form solution. First, using the closed-form solution may require expensive computation. For example, $\Phi^T\Phi$ could be a vast and dense matrix, making it infeasible to store and reliably compute the solution (especially the matrix inverse) in one shot. Second, the closed-form solution itself may not always be available, especially for most nonlinear regression problems. In such cases, a common approach uses iterative methods such as gradient descent, which is much more computationally efficient.

## 2.4.3 The gradient descent algorithm

Gradient descent is an algorithm that works on a differentiable cost function and iteratively updates the weight vector towards a stationary point or a local minimum of the function. Although using gradient descent sometimes lands in a local minimum or a saddle point instead of the global minimum, it is still the most widely used algorithm in the field of deep learning. As mentioned earlier, the gradient is a collection of partial derivatives of the cost function to the current value of the respective weight in the weight vector. These partial derivatives measure the sensitivity of the current weights to the change in the cost function. When a specific entry in the gradient vector is big, the cost changes a lot given a slight change in that weight entry.

When plotting the cost as a function of the weights, the gradient vector indicates the direction of the steepest descent towards a local minimum in its neighborhood. In the case of a single entry in the weight vector, the gradient would correspond to the slope of the cost function at the current weight. This means that the gradient vector provides two types of information regarding the next iteration: the direction to change the weights and the magnitude of the change. To utilize these two types of information, the gradient descent algorithm adopts the following scheme to iteratively update the weights:

```
w ← w - η∇Q(w)
```

where the ← sign indicates assigning the value on the right-hand side to the left hand side. Using this formula, a new weight vector **w** gets calculated by plugging the current value of **w** in **w** - η∇Q(**w**). η is a small positive number that is often called the learning rate or the step size. It is a hyper-parameter used to control the magnitude of each update. Since the objective is to minimize the cost function, the direction of travel is corrected by the minus sign in the equation. Using this update scheme, the next iteration would always move towards a local optimum. This intuition is conveyed in figure 2.12, which shows the cost function used in the linear regression with respect to a single parameter, each with a different starting point.

![](img/ee98e91e6845f41077b163bec833ee40_49_0.png)

### Figure 2.12 Visualizing the gradient descent update algorithm in the univariate linear regression.

Due to the design of the update equation, the new weight vector will always move towards the optimal weight vector, given a proper step size in each update. In other words, the process is iteratively looking for a better model that is closer to the best one.

In the case of the univariate linear regression, the gradient descent update will involve two parameters to form a straight-line model: the intercept or offset term w₀ and the slope term w₁. Following our previous process on model training, we will first generate a prediction ŷᵢ = w₀ + w₁xᵢ for the iᵗʰ observation based on a randomly initialized set of weights, followed by comparing with the true target value yᵢ to produce an error term eᵢ = yᵢ - ŷᵢ. The cost function could be calculated by summing the squared errors \(Q(w_0, w_1) = \sum_{i=1}^n (y_i - w_0 - w_1 x_i)^2\). We then calculate the gradient of the cost function with respect to each parameter \(w_0\) and \(w_1\) and use the gradients for iterative update. Figure 2.13 summarizes the derivation process for univariate linear regression.

### Figure 2.13 Deriving the system of equations for updating model parameters using the gradient descent algorithm in linear regression.

| Step | Details |
|------|---------|
| Current weights | \(\mathbf{w}^\top = [w_0, w_1]\) |
| Randomly initialized model weights | |
| Calculate the model prediction for each observation | \(\hat{y}_i = w_0 + w_1 x_i, i = 1, \dots n\) |
| Calculate the current cost | \(Q(w_0, w_1) = \sum_{i=1}^n (y_i - w_0 - w_1 x_i)^2\) |
| Derive the partial derivative of the cost function with respect to each weight | \(\frac{\partial Q(w_0, w_1)}{\partial w_0} = \sum_{i=1}^n (-2)(y_i - w_0 - w_1 x_i)\)<br>\(\frac{\partial Q(w_0, w_1)}{\partial w_1} = \sum_{i=1}^n (-2x_i)(y_i - w_0 - w_1 x_i)\) |
| Perform the gradient descent update | \(w_0 \leftarrow w_0 - \eta \frac{\partial Q(w_0, w_1)}{\partial w_0}\)<br>\(w_1 \leftarrow w_1 - \eta \frac{\partial Q(w_0, w_1)}{\partial w_1}\) |

At a high level, each set of weights corresponds to a particular cost, and gradient descent algorithm works by iteratively adjusting the weights in search of a minimal cost. In linear regression, such relationship could be plotted as a 3D mountain, where the x-axis and y-axis represent the weights \(w_0\) and \(w_1\) respectively, and the z-axis shows the cost as the height of the mountain. The gradient descent algorithm essentially changes the weights to descend the cost to the valley of the mountain. We can visualize the hill using a contour plot, where a circle suggests that all points along the circle have an equal cost. Our goal is thus to adjust the current weights in the direction along the steepest descent towards the center point, i.e., the stationary point with the lowest cost in the region.

The code listing below first creates a list of candidate values for both \(w_0\) and \(w_1\), followed by calculating the cost for each unique combination of parameters, as well as the partial derivatives at the initial starting point.

### Listing 2.7 Calculating the gradient

```
w0_vals = np.linspace(w_star[0]-3, w_star[0]+3, 100) #A
w1_vals = np.linspace(w_star[1]-1, w_star[1]+1, 100) #B
w0_grid, w1_grid = np.meshgrid(w0_vals, w1_vals) #C
Q_grid = np.zeros((100, 100)) #D
for i in range(Q_grid.shape[0]): #D
    for j in range(Q_grid.shape[1]): #D
        Q_grid[i, j] = ((y - w0_grid[i, j] - w1_grid[i, j]*X)**2).sum() #D
w0_grad = -2*(y - w[1]*X - w[0]).sum() #E
w1_grad = -2*(X*(y - w[1]*X - w[0])).sum() #F
```

The optimization process can gradually reduce the cost to a local minimum by iteratively applying the gradient descent update to the parameters. ### Listing 2.8 Performing gradient descent update

```
max_iters = 1000 #A
learning_rate = 0.001 #B

cp = ax.contour(w0_grid, w1_grid, Q_grid, colors='black', linestyles='dashed',

        fontsize=10) #C

plt.ylabel('w1') #C
plt.show() #C
```
