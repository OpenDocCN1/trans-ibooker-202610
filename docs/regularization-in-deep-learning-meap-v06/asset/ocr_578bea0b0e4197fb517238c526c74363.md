# 6.1.2 Translational invariance in convolutional neural networks

Convolution is a unique operation designed to learn from geometric structures in image data effectively, assuming a 2D or 3D convolution operation. A convolutional layer uses much fewer parameters than a fully-connected layer and enjoys the benefit of weight sharing across different input features. That is, multiple features share the same weight, thus significantly reducing the effective number of weights employed by the neural network. Specifically, convolution is a mathematical operation where a function is passed over a sequence of values, and this process is known as convolving a function. It is also applicable to one-dimensional inputs such as sequence data, where 1D convolution can be used to capture the dependences within the data. Let us revisit the convolution operation and discuss how it surpasses the fully-connected layer in image recognition tasks.

As it turns out, we could tweak the design considerations of vanilla fully-connected neural networks using a particular type of inductive bias: convolution and pooling operations in a convolutional neural network, which turns out to be very effective in dealing with image data and beyond. Tweaking the design considerations constrains the neural network to exhibit specific desirable properties such as translational invariance, i.e., the network is able to recognize a particular object in an image no matter where it is located or translated. In other words, the network is invariant to positional translation of the object in the input image and can obtain the same classification result. This is one of the key benefits of convolutional neural networks due to the strong prior assumption that the object's location does not matter in terms of the final classification result.

Figure 6.4 illustrates the translational invariance property of a properly trained CNN that has high accuracy on MNIST dataset. Exposed to images with the digit 8 in different locations, a translationally invariant model such as CNN will generate the same class label of 8. This means that for an FCN to be able to correctly classify an image containing the digit 8, the FCN model must have encountered a similar digit 8 at similar positions during the initial training process, although an FCN trained long enough *may* figure out the location invariance property. CNN, on the other hand, is not sensitive to locations of the digit by design. This is principally due to the local filters, also called kernels, that manage to capture and utilize the essential signal on digit 8, no matter where it is positioned. A translationally variant model such as the FCN, however, may not necessarily produce the same classification result. This means that shuffling the pixels in the image data in a consistent manner would end up with the same FCN-based model due to its structure-agnostic nature. Without capturing the spatial relationship of the digit 8 on the image, an FCN will struggle to identify the same object, until it is trained long enough to develop meaningful representations and *learn* such property by itself.
