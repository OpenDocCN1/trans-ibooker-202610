The specific mathematical function represents our *inductive bias*, a prior belief on the properties of the function, in the form of a hypothesis. In this process of learning from examples, the model parameters are optimized so that the shape of the learned function becomes more representative of the real one. A supervised learning model could then take in new input data and predict the corresponding output. Instead of explicitly programming the mapping rule, the model automatically learns the mapping logic, thus being more intelligent than traditional rule-based software engineering practices. As long as the proper input and output are provided, we can outsource the whole mapping and rule identification task to the supervised learning algorithm, which is very useful, especially in the presence of complex processes.

It is important to note that a model essentially represents a simplifying assumption to represent the underlying data generating process. The assumption is often accompanied by an *inductive bias*, such as the smoothness of the data generating function: one value should smoothly transition to another without sudden jumps. The pre-specified inductive bias, when properly used, could introduce a surprising generalization effect. The hypothesis on the true function could also come from our prior belief about the underlying data generating processes, such as regularities or other properties we wish to borrow from similar tasks via the transfer learning framework.

# 2.1 The data

All machine learning models start with some given training data. In supervised learning, the training data consists of input-output pairs. Suppose there are *n* pairs in total, and we focus on the *i*th pair of data, denoted by (**x**_i, y_i). The parenthesis means that each and every entry in the training set has to come with a pair, consisting of both the input **x**_i and output y_i. The input vector **x**_i, which is a one-dimensional array, is bolded to highlight the fact that it contains one or more features. The input features in **x**_i are used as predictors by the model to come up with a scalar prediction ŷ_i (single dimension and thus unbolded) for the *i*th observation.
