Another class of approach is to use data augmentation techniques to generate artificial samples by introducing random noise to the original input data, the activations in the hidden layers, or even the target output. All these transformations could happen at training or testing stage, except for the targets at test time as they are not revealed to us. When transforming the targets, a common approach is called label smoothing in a classification task, where the target label is mixed with a uniformly distributed random noise to encourage regularization. Note that these two approaches could be combined so that the resulting dataset has a bigger size in both directions.

Figure 5.1 illustrates the different data-based transformation methods for the input matrix. When transforming the feature space via either manual feature engineering or automatic feature extraction along the horizontal direction, we would expect to construct a more meaningful feature space to regularize and ease the training task. The same goes for vertical transformations via repeated sampling or data augmentation that aims at tweaking the data distribution for better and more regularized training. These two approaches are used in combination when using data augmentation in training deep neural networks, as we will show later in the chapter.
