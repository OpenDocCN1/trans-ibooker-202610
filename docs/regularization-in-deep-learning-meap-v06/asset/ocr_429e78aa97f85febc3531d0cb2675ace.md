The fitted model is complex enough to approximate the piecewise linear segments and interpolate all training points using up to the 6th polynomial degree. In particular, as shown in figure 3.12, we see an almost perfect fit from the second training point onward towards the figure's right. However, the model displays a high variance between the first and the second points, as shown by the deep downward valley. The model is too sensitive in this region and produces very different outputs given two points close to each other. This is a typical overfitting phenomenon from the classical generalization perspective. One might start reducing the model complexity to control the bias-variance tradeoff.
