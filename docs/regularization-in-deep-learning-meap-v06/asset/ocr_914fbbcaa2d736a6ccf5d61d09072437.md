# LINEAR REGRESSION USING A SINGLE-LAYER NEURAL NETWORK

To learn a linear regression model, let us define a one-layer fully-connected network (FCN). The input size equals the number of features, and the output size is one since there is only one scalar output for each input observation. In the following code listing, we define a class named FCN_regression to store the necessary attributes and methods. Upon initialization, the class requires a few input parameters: the number of input features in input_size, the learning rate for SGD in lr, the number of epochs in num_epochs, and the magnitude of the scalar hyperparameter for L2 penalty in l2_penalty. We also define the model architecture as a single linear layer stored in model, the loss function to be nn.MSELoss() stored in criterion, and SGD as the optimizer in optimizer.

```
Listing 7.8 Creating a class for single-layer FCN
class FCN_regression:
    def __init__(self, input_size, lr=1e-3, num_epochs=1000, l2_penalty=0):
        self.lr = lr
        self.num_epochs = num_epochs
        self.l2_penalty = l2_penalty
        self.train_loss = []
        self.test_loss = []
        self.model = nn.Linear(input_size, 1)
        self.criterion = nn.MSELoss()
        self.optimizer = torch.optim.SGD(self.model.parameters(), lr=self.lr)
```

Next, we will create a fit() method within the class to perform the model estimation task. As shown in the following code snippet, we take the training and test sets as the input for training and scoring purposes, which need to be converted to tensor format as we are working with PyTorch. Following the same zero-initialization strategy, we perform the same training procedure as training a typical neural network covered in chapter 4. Specifically, we perform a forward pass to obtain model predictions in y_predicted for the training set, calculate the loss in loss_train, add L2 penalty if any, clear the historical gradients in relevant variables, automatically calculate the current gradients via back-propagation, and finally perform stochastic gradient descent update for a total of epochs specified by num_epochs. In addition, we also calculate the test set MSE after each round of training in a gradient-free setting.

```
def fit(self, X_train, y_train, X_test, y_test):
    weights = np.zeros(X_train.shape[1]) #A
    epoch = 0 #B
    X_train = torch.from_numpy(X_train).float() #C
    X_test = torch.from_numpy(X_test).float() #C
    y_train = torch.from_numpy(y_train).float() #C
    y_test = torch.from_numpy(y_test).float() #C

    for epoch in range(self.num_epochs):
        y_predicted = self.model(X_train) #D
        loss_train = self.criterion(y_predicted, y_train) #E
        self.train_loss.append(loss_train.item())
```
