fig = plt.figure()

    e = float(tmp_num_train_samples - num_train_samples_min) / float(num_train_samples_max
    - num_train_samples_min) #C
    e = 0.2 + 0.6 * e #C
    ax.plot(np.arange(1, num_basis_max + 1), mse_train, color = (e, e, 1.0),
    label = 'f'Train N={tmp_num_train_samples}', linestyle = '-.-')
    ax.plot(np.arange(1, num_train_samples_max + 1), mse_test, color = (1.0, e, e),
    label = 'f'Test N={tmp_num_train_samples}')
ax.legend(frameon = False)
ax.axvline(x = 9,
color = 'gray', linewidth = 0.5, linestyle = '-.-')

+   - #A Set the minimum and maximum number of training samples
+   - #B Repeat the experiments with different number of training samples
+   - #C Set the color intensity for each number of training samples

The resulting plot, as shown in figure 3.15, shows an increasing test MSE as the training sample size increases in regions when the polynomial degree is up to the 9th. Therefore, more training data do not guarantee a better generalization performance. This is an exciting phenomenon recently found in the research community, suggesting that the generalization performance is also very much related to the specific data used in its size and domain. We would expect more research on why it appears this way.
