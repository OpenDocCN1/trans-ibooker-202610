$J(\mathbf{w}) = \sum_{q=2}^p \sum_{r=2}^q \beta_{q,r} w_q w_r$

where $\beta_{q,r}$ represents the elements of $\mathbf{\Omega}$ and calculated as follows:

$\beta_{q,r} = \frac{(q-1)q(r-1)r}{q+r-3}$

The following function performs coefficient estimation by performing the aforementioned steps for solving the smoothing splines problem using the new normal equations. Note that we use the `np.linalg.lstsq` procedure to solve for the least squares solution as it handles under-, well- and over-determined equations.

# Listing 3.3 Solving for the closed-form solution of the smoothing spline model

```
```python
def estimate_coef(X, y, num_basis): #A
    Phi = polynomial(X, num_basis=num_basis) #B
    q = np.arange(2, num_basis).reshape(1, -1) #C
    r = q.reshape(-1, 1) #C
    omega = np.zeros((num_basis, num_basis)) #C
    omega[2:, 2:] = (q - 1) * q * (r - 1) * r / (q+r-3) #C
    values, vectors = np.linalg.eig(omega) #D
    beta = vectors @ np.diag(values.clip(min = 0) ** 0.5) #D
    y_star = np.concatenate((y, np.zeros(omega.shape[0])).reshape(-1,1)), axis=0) #E
    Phi_star = np.concatenate((Phi, math.sqrt(rho) * beta.T), axis=0) #E
    w_star = np.linalg.lstsq(Phi_star, y_star, rcond=None)[0] #F
    return w_star

def calculate_mse(X, y, coef, num_basis):
    Phi = polynomial(X, num_basis=num_basis) #A
    f_star = Phi@coef #B
    resid = y - f_star #C
    Q = np.dot(resid.T, resid).mean() #D
return Q
