
## 4.1.2 Shallow versus deep neural network

When dealing with a shallow network, i.e., a neural network with one hidden layer followed by an output layer, the tuning knob on the model flexibility is limited to the number of nodes/neurons in the hidden layer. In order to create a model with a specific number of breakpoints or linear segments in the final output, we need to add the same number of nodes in the hidden layer. These hidden neurons serve as the basis functions to be linearly combined to generate the final output. In other words, the model complexity grows linearly with the number of nodes in the hidden layer.

However, a deep neural network requires much fewer nodes per layer to reach the same level of complexity. Specifically, the model complexity (i.e., number of breakpoints or linear segments in the final output) grows exponentially with the number of hidden layers in the deep neural network. We will illustrate this point with an example of a hand-designed deep neural network with ReLU activation and observe how its complexity changes as the network become deeper.

Suppose we would like to fit the following function in each hidden layer. The resulting network is also referred to as the “sawtooth” network model. Each layer is the absolute value of the previous layer multiplied by two and shifted downwards by two, resulting in a final sawtooth-like fit. The relationship between the current layer and the previous layer can be expressed as the following:

$f_l(x)=2|f_{l-1}(x)|-2$

As usual, we have $f_0(x)=x$. There are two cases when taking the absolute value of input: if the input is positive, the output remains the same as the input; if the input is negative, the output is the negation of the input. We can therefore decompose the absolute function into two parts, each implemented via a ReLU activation function as follows:

$f_l(x)=2|f_{l-1}(x)|-2=2\text{ReLU}(f_{l-1}(x))+2\text{ReLU}(-f_{l-1}(x))-2$

Note that the weights are fixed in this example and no actual learning happens. We are interested in assessing the approximating power of the “sawtooth” network.

The two-neuron hidden layer can be defined via the following code snippet.

```
def layer(x):
    return 2*relu(x) + 2*relu(-x) - 2
```

Next, we define a function to build a neural network by sequentially stacking the layers based on the specified number of layers.

```
def multilayer(x, hidden_layers=1):
    f = x #A
    for _ in range(hidden_layers): #B
        f = layer(f)
    return f
```

- #A First layer returns just the input itself
- #B Sequentially pass the output of current layer as the input to the next layer

With two neurons placed in each hidden layer, we can vary the model complexity by tweaking the `hidden_layers` argument and observing the model's final output change. In the coding listing below, we vary the size of the neural network by changing the number of hidden layers from zero to five and plotting the final output.

```
Listing 4.3 Sequentially changing the number of hidden layers
numlayers = 6
fig, axs = plt.subplots(numlayers, 1, figsize=(8,25))
for i, ax in enumerate(axs):
    ax.plot(xs, multilayer(xs, hidden_layers=i))
    ax.set_ylim([-3, 3])
    ax.legend(['$f_{{{}}}(x)$'.format(i)])
```

Another empirically observed drawback for shallow networks is the tendency to memorize the input data directly instead of learning the underlying pattern to generalize to future unseen datasets. For example, an extremely wide network could eventually memorize the training data and produce zero training error. On the other hand, a deep neural network with multiple layers can learn features at different levels of abstraction, resulting in intermediate hidden features that eventually contribute to generalization. For example, low-level compositional features such as edge and corner in the early hidden layers are automatically extracted and learned in image recognition tasks. Together, they create more abstract and high-level features such as shapes and objects in the final hidden layers to facilitate more effective pattern recognition.

In summary, the number of breakpoints and linear segments, an indicator of model complexity, grows exponentially with the number of hidden layers in the neural network. The depth of the neural network increases complexity much more than the width, and a deep neural network is powerful enough to represent/approximate functions of arbitrary shapes.

## 4.2 Automatic differentiation

The strong approximation capacity of a deep neural network makes it a powerful and expressive type of model. However, we still need to employ an optimization technique to search for optimal weights for given network architecture. In the previous chapters, we covered the gradient descent family of methods. The procedure to optimize a neural network model is to iteratively calculate the gradient of the current model cost concerning model weights and then apply the gradient to update the weights.

Such gradient-based optimization is also one of the reasons behind the great success of neural networks. In particular, neural networks trained using stochastic gradient descent algorithm tend to end up with low empirical risk and generalize well to the future unseen test sets. One distinguishing feature of the algorithm lies in the stochasticity of the gradient, where the gradient is calculated based on a single or a mini-batch of examples and is thus noisy compared to an averaged gradient based on a large batch of examples. The test performance starts to suffer when the noise reduces using the full gradient descent procedure that uses all examples for gradient calculation. Part of the reason is that SGD with a small batch size enables the optimizer to jump out of sharp local optima and move towards more flat optima that generalize better to the test set. The generalization capacity of neural networks is thus related to the specific algorithm and its configuration used along with the model complexity and sample size.

We will cover more on the regularization from the optimization perspective later. For now, let us look closely into the details of gradient-based optimization, especially when we have multiple weights to update in each iteration.

### 4.2.1 Gradient-based optimization

Let us revisit the entire model training process and refresh our memory on the mathematical operations in each link. As shown in figure 4.10, the model training process starts by dividing the original dataset into a training set and a test set. The training set serves to develop an optimal model, and the test set measures the generalization performance of the trained model. Two essential functions are used in the training process: prediction function and cost function. The prediction function takes the (fixed) input features and (changing) model weights as input and generates a set of predictions.

In contrast, the cost function summarizes the quality of these predictions into one single scalar value by calculating the total (or average) distance between the predictions with the target labels. The cost is then passed to an optimization procedure such as gradient descent to update the model weights and minimize the cost. Once the training process completes, the optimal set of weights based on the training set is used to get another final prediction set based on the test set features. These test set predictions are compared with the corresponding labels to produce a final cost (such as the mean squared error) for the test set.
