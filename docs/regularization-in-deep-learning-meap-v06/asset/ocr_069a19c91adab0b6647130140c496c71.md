To obtain the optimal solution, we would then set \(\lambda \partial_{w_j} Q(\mathbf{w}) = 0\), which again requires us to consider three different cases. When \(w_j < 0\), we have \(2z_j w_j - 2\rho_j - \lambda = 0\), which gives \(w_j = (\rho_j + \lambda/2)/z_j\) and requires \(\rho_j < -\lambda/2\) (since \(z_j > 0\)). When \(w_j = 0\), we require the range \([-2\rho_j - \lambda, -2\rho_j + \lambda]\) to contain zero, which means \(-2\rho_j - \lambda \le 0\) and \(-2\rho_j + \lambda \ge 0\) need to be satisfied at the same time. This gives \(-\lambda/2 \le \rho_j \le \lambda/2\). When \(w_j > 0\), we have \(2z_j w_j - 2\rho_j + \lambda = 0\), which gives \(w_j = (\rho_j - \lambda/2)/z_j\) and requires \(\rho_j > \lambda/2\). This is also called the soft thresholding rule, where some weights are set to zero and other are shrunken towards zero (by an amount of \(\lambda/2z_j\)).

In other words, when \(\rho_j \in [-\lambda/2, \lambda/2]\), the weight \(w_j\) is shrunken to zero. When either \(\rho_j < -\lambda/2\) or \(\rho_j > \lambda/2\), we add a bias term \(\lambda/2\) to reduce the magnitude of the least squares solution for \(w_j\); that is, when \(\lambda = 0\), the least squares solution is \(w_j = \rho_j / z_j\).
