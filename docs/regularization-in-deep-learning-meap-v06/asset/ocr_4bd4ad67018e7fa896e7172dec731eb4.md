Since $\Omega$ is a \( p \times p \) symmetric (square) matrix, this step essentially concatenates an additional \( p \) rows to $\Phi$. Note that since \(\lambda\) is a positive constant, it is fine to scale $\Omega$ by \(\sqrt{\lambda}\).

Similarly, the output vector \(\mathbf{y}\) is also extended with \( p \) zeros at the end, forming a new output variable \(\mathbf{y}_* = \binom{\mathbf{y}}{\mathbf{0}}\). Based on the original normal equations \(\Phi\mathbf{w} = \mathbf{y}\), we can construct a new set of normal equations: \(\Phi_*\mathbf{w} = \mathbf{y}_* = \binom{\mathbf{y}}{\mathbf{0}}\). We can then multiply both sides by \(\Phi_*^T\) and continue the derivation process:

```
\(\Phi_*^T\Phi_*\mathbf{w} = \Phi_*^T \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \sqrt{\lambda} \mathbf{B}^T) \begin{pmatrix} \Phi \\ \sqrt{\lambda} \mathbf{B} \end{pmatrix} \mathbf{w} = (\Phi^T \sqrt{\lambda} \mathbf{B}^T) \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \Phi + \lambda \mathbf{B}^T \mathbf{B}) \mathbf{w} = (\Phi^T \sqrt{\lambda} \mathbf{B}^T) \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \Phi + \lambda \Omega) \mathbf{w} = \Phi^T \mathbf{y}\)
```

This gives us the new set of normal equations, with the additional term \(\lambda \Omega\) added as a result of the penalty on model smoothness. We can also handle the derivation from the perspective of the cost function. By reformatting the input and output variables, we can now express the cost function as follows:

```
\(Q(\mathbf{w}) = ||\mathbf{y} - \Phi\mathbf{w}||^2 + \lambda \mathbf{w}^T \Omega \mathbf{w} = ||\mathbf{y}_* - \Phi_* \mathbf{w}||^2\)
```

This form looks similar to the original linear regression setting. Setting the gradient of \(Q(\mathbf{w})\) to zero gives the following normal equations:

```
\((\Phi_*^T \Phi_*) \mathbf{w} = \Phi_*^T \mathbf{y}_*\)
```

This could be solved using the same procedure as in the previous chapter. Note that the new output variable \(\mathbf{y}_*\) contains an additional list of zeros compared with \(\mathbf{y}\), thus the right hand side of the equation above is still equal to \(\Phi^T \mathbf{y}\). On the left hand side, an additional term \(\lambda \Omega\) is added to the original \(\Phi^T \Phi\), resulting in the new normal equations as follows:

```
\((\Phi^T \Phi + \lambda \Omega) \mathbf{w} = \Phi^T \mathbf{y}\)
```

Introducing \(\Phi_*\) and \(\mathbf{y}_*\) has multiple benefits in the derivation. Besides being more conceptually economical under the typical framework of solving least squares problems, it also helps extending to a new geometric view on the effect of the penalty term. Compared with \(\Phi\), the augmented design matrix \(\Phi_*\) has an enlarged column space that is extended from \(\mathbb{R}^n\) to \(\mathbb{R}^{n+p}\). Note that the penalty matrix \(\Omega\) will go through a certain transformation, such as eigen-decomposition, to ensure its column vectors are mutually orthogonal.
