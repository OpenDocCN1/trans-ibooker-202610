# 2.2.3 Implementing the prediction function

Let us implement the prediction function in code, also adding the bias trick for convenience. First, we create a new design matrix by adding a column vector of ones at the beginning of the design matrix. Adding the column vector of ones at the beginning of the original design matrix X could be achieved using the hstack function in numpy. We then initialize a random set of weights following a standard normal distribution, with the bias term automatically included based on the shape of X. Note that initializing the weight vector is only performed once at the beginning of a training process. The optimization procedure (to be introduced later) would then start the search for the optimal weights based on the initial value. Finally, with the input data and weights ready, we can generate the prediction for each input data point by combining these two components (design matrix and weights) via matrix-vector multiplication.
