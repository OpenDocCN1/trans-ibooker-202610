In this chapter, we will uncover different forms of penalty terms in the objective function. The penalty term serves as an explicit regularizer that induces a desired property of the resulting estimator (i.e., the weight configuration), such as sparsity via $l^1$-norm-based (only a subset of features is selected in the final model) and $l^2$-norm-based regularity (a small weight is preferred over a large weight). Devising a composite objective function with novel and domain-specific penalty terms is an exciting research field. We aim to lay the foundation for readers in terms of common approaches currently used in training deep neural networks.

# 7.1 Introducing the regularization term

In the context of a deep neural network, we encountered sparsity as a form of regularization in the previous chapter. For example, when using the dropout technique during training, a sparse network is obtained by randomly disabling specific nodes in a neural network. The weight-sharing property in the convolution operation also plays the same role as having a sparse network. By reducing the number of parameters as a form of regularization, the algorithm is less likely to select an overly complex model and, therefore less prone to overfitting.

A sparse neural network is also computationally faster and more scalable. For example, although fruit flies or ants have roughly 250K neurons in their brains, they can still perform complex tasks such as motion sensing and food seeking. A neural network of this size is barely mid-sized in the modern deep-learning era. However, we would need a much bigger network to achieve a similar task, as shown by the increasingly complex models in autonomous robots. The neuron-level sparsity, i.e., each neuron is only connected to a subset of downstream neurons, is becoming an essential property in robust neural networks. When recognizing a face, only a specific part of our brain is activated, and the rest remains inactive. It is thus essential to channel the input signal to the right regions in a neural network and avoid redundant computations that contribute little to the correct prediction.

Similarly, of all the 86 billion neurons in a human brain, a typical neuron is only connected to dozens of thousands of other neurons on average. Such a sparse connection also manifests in a convolutional neural network, where each neuron of the current layer only receives input information from a small patch in the previous layer. As shared in the last chapter, the sparse connection in CNN is essentially a fully connected network (FCN) with zero weights in most of the connections. However, designing an architecturally sparse and efficient network is better than starting with an FCN and learning the nonzero weights since we can avoid multiplying the zero weights with the input matrix and summing up all the zeros for follow-up non-linear transformation.

A sparse representation is even more advantageous in the case of high-dimensional problems. For example, when treating each pixel as a separate feature in an image recognition task, there are as many weights to be estimated as the number of pixels when using a simple linear regression model. These weights are likely to be correlated, especially when physically close to each other. When one weight increases in value, the nearby weight may either go up (causing overfitting) or down (compensating for the increase). Therefore, we need to enforce certain conditions on the weights so as to induce a preference for a simple and parsimonious model.
