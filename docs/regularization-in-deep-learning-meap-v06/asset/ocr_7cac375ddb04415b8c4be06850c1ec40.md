Booleans has the same length as the number of nodes and is generated by comparing a list of random numbers with the preset dropout probability, where the random numbers follow a uniform distribution between 0 and 1

The second part is to scale up the feature value of the nodes, which is equivalent to scaling up their outgoing weights. The reason is that after dropping out some nodes, the rest of the nodes need to be scaled up in value in order to compensate for those dropped nodes. In particular, suppose the dropout ratio is _p_, then each of the remaining nodes will be multiplied by 1/(1 - _p_).

The following code listing implements the dropout class that can be applied to the input layer or any hidden layer. Upon instantiating the class, it accepts a default dropout ratio of 0.5, which usually vary in the range of 0.5 to 1. The scaling factor is also calculated and stored as an attribute when the __init__() function is triggered automatically. Next, the forward() function specifies how the dropout operation is performed and is automatically triggered when applying this class. Specifically, we first create an indicator list called `selected_ind` to determine which nodes to mask/mute. The list of Boolean numbers is created by comparing a list of uniformly generated numbers in the range of 0 and 1 to the preset dropout_rate. The indicator list is later converted to a floating data type and wrapped in a variable, whose gradient propagation is disabled as there is no learning involved. Finally, we mask the nodes according to the indicator list and scale up the rest of the survivor nodes.

# Listing 6.1 Defining a customized dropout class

```
class Dropout(nn.Module):
    def __init__(self, dropout_rate=0.5):
        super(Dropout, self).__init__()
        self.dropout_rate = dropout_rate
        if self.dropout_rate < 1: #A
            self.scaling_fct = 1.0 / (1.0-dropout_rate) #A
        else: #A
            self.scaling_fct = 0.0 #A

    def forward(self, input):
        if not self.training: #B
            return input

        selected_ind = torch.Tensor(input.shape).uniform_(0,1) > self.dropout_rate #C
        if input.is_cuda: #D
            selected_ind = Variable(selected_ind.type(torch.cuda.FloatTensor),
                requires_grad=False) #D
        else: #D
            selected_ind = Variable(selected_ind.type(torch.FloatTensor),
                requires_grad=False) #D

        return torch.mul(selected_ind, input) * self.scaling_fct #E
```

+   - #A define the scaling factor to remaining nodes to compensate for dropped nodes
+   - #B only apply dropout during training mode
+   - #C indicator tensor of same size to label the selected nodes
+   - #D use GPU if available
+   - #E drop out some nodes and scale up the rest
