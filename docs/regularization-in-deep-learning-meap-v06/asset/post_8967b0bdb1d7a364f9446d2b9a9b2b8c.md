
Another class of approach is to use data augmentation techniques to generate artificial samples by introducing random noise to the original input data, the activations in the hidden layers, or even the target output. All these transformations could happen at training or testing stage, except for the targets at test time as they are not revealed to us. When transforming the targets, a common approach is called label smoothing in a classification task, where the target label is mixed with a uniformly distributed random noise to encourage regularization. Note that these two approaches could be combined so that the resulting dataset has a bigger size in both directions.

### 5.1.1 Data augmentation

Data augmentation essentially contributes to the diversity of the training data exposed to the model by introducing noise to the existing data (input, output, or both) and generating additional artificial data points, thus presenting new data that are different but similar to the original data. They could help alleviate some of the challenges on distributional inconsistency and insufficient representativeness of the training data. By increasing and augmenting the diversity of the training data, the model is forced to perform well on a broad spectrum of data points, making it less likely to experience a high variance over the original dataset and more likely to generalize to the test set.

Some of the most popular applications of data augmentation include image classification and object recognition in computer vision. For example, when training a model to classify digits based on image data, we could harvest more training data under the same category by making slight changes to the input images such as cropping, zooming/in/out, rotation, flipping, or adjusting the brightness. The introduced variety helps the model learn the consistent structure from different perspectives instead of overfitting and memorizing the original training data. Data augmentation has become a de facto data pre-processing step applied in most computer vision tasks, saving the need to gather more training data manually.

However, proper caution should be exercised when applying transformations to image data. For example, it is easy to confuse the digit “6” with “9” when rotating an image, as well as the letter “b” with “d” when flipping an image. The interested object may also be accidentally cropped out of the image. Since we would expect these newly created images obtained by transforming the existing ones still belong to the same category, the random noise introduced should not change the meaning of the original image data.

Figure 5.2 illustrates the augmentation process for image data under the same class label, where we project the images to points within a two-dimensional coordinate system for ease of visualization. Note that the concept of projection is central to deep neural networks, where each layer is a sort of projection from the last layer in some sense and the projected features are supposed to be more meaningful and informative through learning. In fact, we could even generate additional data at a certain hidden layer by interpolating among the hidden features. Such interpolation within the hidden layer could generate better-quality data since the hidden features are more linearized and uncorrelated deep in the network. This particular technique was recently proposed by Wang et al. in a 2019 NeurIPS paper titled "Implicit Semantic Data Augmentation for Deep Networks". We will learn more about this technique in a later chapter on regularization via objective function as the authors beautifully converted the augmentation task to a modified cost function, thus achieving implicit data augmentation.

It should be noted that these data augmentation techniques are empirically tested to be helpful in *some* cases only, in particular computer vision tasks. Given our observation on sample non-monotonicity, more training data may sometimes hurt test performance.

Our eventual goal is to increase the generalizability of the trained model. How does creating more (artificial) training data serve as a regularization technique and help contribute to this goal? The model is constantly presented with new and slightly modified data by introducing random noises and perturbations to the original training data. The model is more likely to learn robust features when the dataset is sufficiently diverse. These additional data points reflect our prior belief or inductive bias as we know introducing slight transformations to an image does not change its class label. In other words, we use data augmentation to increase the size of the training dataset and regularize the model training process so that the trained model will have low variance and is more likely to generalize well to the test set.

Data augmentation contributes to the generalization performance of the trained model by adding more plausible and realistic versions of training data so as to improve the test set performance. It is considered an *implicit regularization* technique, which is in contrast to *explicit regularization* techniques such as penalizing the norm of the weights.

Note that data augmentation does not apply to the test set; it is merely a preprocessing technique to augment the training dataset before the start of each training iteration. However, despite the tendency to increase the test set performance of the model, we *may* observe a decrease in the training set performance.

Now let us look at label smoothing, a slick technique that tweaks the target label to achieve regularization.

### 5.1.2 Label smoothing

Label smoothing is a regularization technique that alleviates overfitting by introducing a uniformly distributed noise in the one-hot encoded output label, assuming a classification task. The reason why we may want to perturb the target label is that the labels may be incorrectly tagged in the training dataset. By creating a “soft” target and reducing reliance on the original “hard” target output, we could prepare the model to get out of the potential mislabeling and prevent it from being overconfident about its predictions.

Mathematically, denote C as the total number of classes in the target output, \(y_{one\_hot}\) as the one-hot encoded output, and \(\alpha\) as a controlling hyperparameter that determines the intensity of the uniform noise. The transformed output \(y_{label\_smoothing}\) after label smoothing is expressed as the following:

\(y_{label\_smoothing} = (1 - \alpha)y_{one\_hot} + \alpha/C\)

When \(\alpha = 0\), we have the original one-hot encoding where the probability of the correct class label is one; we exploit this knowledge in calculating the training cost. When \(\alpha = 1\), the smoothed encoding vector contains a uniform distribution with equal probability for all classes, encouraging exploration across all classes. Thus, this is a version of balancing between exploitation and exploration, controlled by the hyperparameter \(\alpha\).

For example, assume we have a three-class classification problem where the label for one sample is the first class, i.e., \(y_{one\_hot} = [1,0,0]\). Upon setting \(\alpha = 0.3\), the smoothed encoding vector now becomes \((1 - 0.3)*[1, 0, 0] + \frac{0.3}{3} = [0.7, 0, 0] + 0.1 = [0.8, 0.1, 0.1]\), where we used the broadcasting mechanism in the second last step. We can see that the second and third classes are now also assigned a small probability, forming a soft target in the model.
