
\nabla_{\mathbf{w}} Q = \frac{\partial Q(\mathbf{w})}{\partial \mathbf{w}} = \frac{\partial (\mathbf{y}^\top \mathbf{y} - 2 \mathbf{y}^\top \mathbf{\Phi w} + \mathbf{w}^\top \mathbf{\Phi}^\top \mathbf{\Phi w})}{\partial \mathbf{w}}
= -2 \mathbf{\Phi}^\top \mathbf{y} + 2 \mathbf{\Phi}^\top \mathbf{\Phi w}
= \begin{bmatrix} \frac{\partial Q(\mathbf{w})}{\partial w_1} \\ \frac{\partial Q(\mathbf{w})}{\partial w_2} \\ \vdots \\ \frac{\partial Q(\mathbf{w})}{\partial w_p} \end{bmatrix} = \begin{bmatrix} -2 \sum_{i=1}^n \phi_i^1 y_i + 2 \sum_{i=1}^n \phi_i^1 \sum_{j=1}^p \phi_i^j w_j \\ -2 \sum_{i=1}^n \phi_i^2 y_i + 2 \sum_{i=1}^n \phi_i^2 \sum_{j=1}^p \phi_i^j w_j \\ \vdots \\ -2 \sum_{i=1}^n \phi_i^p y_i + 2 \sum_{i=1}^n \phi_i^p \sum_{j=1}^p \phi_i^j w_j \end{bmatrix}

Differentiating w.r.t. the weight vector **w**

Each resulting partial derivative in the gradient vector is only a function of the respective weight

By setting each element of the gradient vector to zero, we can solve for the set of weights at the stationary point

## Derivative of the quadratic form

The W^TΦ^TΦW term in the cost function Q(W) is a quadratic form in W. Differentiating this term with regard to W gives 2Φ^TΦW. To see how this works, we can derive the total derivative by treating Φ^TΦW as another function f(W) of W and apply the chain rule:

```
(W^TΦ^TΦ)^T = (W^Tf(W))
= (f(W))^T + W^T(f(W))'
= W^TΦ^TΦ + W^TΦ^TΦ
= 2W^TΦ^TΦ
```

where we have used the symmetry of W^Tf(W) to obtain the first term ((f(W))^T in the second step. When a matrix is symmetric, it is equal to its transpose. Lastly, the row vector W^TΦ^TΦ could be transposed to its corresponding column vector Φ^TΦW = (W^TΦ^TΦ)^T.

## 2.4.1 The multiple minima

Such stationary points, however, may not be unique. Depending on the shape of the cost function, there may exist multiple stationary points with zero gradients. Among these target candidate points, three scenarios may occur:

- 1. This stationary point is the unique solution we seek. It is a global optimum whose cost is minimal of all. Optimizing towards this point is easily achievable when the cost function is convex with regard to the weights.
- 2. It is a local optimum in a regional valley. Although other valleys may have a lower cost, the minimal regional cost is derived only concerning its neighborhood. In the face of multiple valleys or local minima, it is difficult to identify the global minimum without comparing it against all the local minima.
- 3. The point may happen to live in a flat region, where all points within this region show zero gradients. This is called a saddle point. We may quickly get stuck in this region since all the neighboring points show equal cost. It is also challenging to identify the global minimum without access to the complete picture of the cost function in this situation. Figure 2.10 summarizes these three scenarios.

Figure 2.10 Three different scenarios when locating the global minimum. The left figure shows a convex function where the only local minimum is the global minimum. The middle figure contains multiple local minima, and the right figure has a flat region with many saddle points. All these points have zero gradient with respect to the weight vector w. Without access to the full picture of the cost function, it is difficult to ascertain if the local minimum is a global minimum.

In the case of linear regression, the cost function Q(w) is quadratic in w, making it a convex function and thus easy to locate the global minimum. For example, the optimal weight vector w* in linear regression could be directly computed as a function of input X and output y. This function is also referred to as the closed-form solution. Therefore, the global minimum could be located in one step by simply plugging the input-output pairs in the closed-form solution, which may not always be available due to reasons such as matrix singularity.

Model training essentially means iteratively updating the weight vector following a particular algorithm. Such iteration is not necessary when a closed-form solution is available since we can directly compute the optimal parameters in one shot. In this case, the optimization only involves a one-step calculation. In most cases, however, we do not have access to a closed-form solution due to the cost function’s highly complex and possibly non-convex structure.

It should be noted that the zero derivatives at the stationary point may suggest a minimum, maximum or a saddle point. In the case of linear regression, the hessian matrix that contains the second derivatives of the cost function could be computed as ∇²_w Q = 2ΦᵀΦ, which is a positive scalar value. This suggests that the stationary point of the cost function happens to be a global minimum. Since the curvature of the cost function given by the hessian is positive definite and a constant value, the optimum obtained at the stationary point is a global minimum that is unique across the whole function surface.

In the following sections, we will first go through the derivation and implementation of its closed-form solution for linear regression, then discuss an alternative approach based on the most widely used algorithm – gradient descent.

## 2.4.2 The closed-form solution of linear regression

In order to find the stationary points of the cost function, we could solve for the weight vector when setting the partial derivatives in the gradient vector to zero:

```
-2Φᵀy + 2ΦᵀΦw = 0
```

where 0 contains a vector of zeros corresponding to each entry in the system of equations. Rearranging the equation gives us the following normal equations:

```
ΦᵀΦw = Φᵀy
```

This leads to the closed solution for the optimal weight vector w* = (ΦᵀΦ)⁻¹Φᵀy, assuming ΦᵀΦ is invertible. Although expressing w* in this way makes it mathematically easier to follow, computing the matrix inverse term (ΦᵀΦ)⁻¹ is intensive as it requires an additional algorithm itself. Plus, such computation also introduces a potential numerical stability issue. Therefore, solving the system of linear equations for w based on the form of ΦᵀΦw = Φᵀy is often preferred in practice.

Back to our example on the univariate linear regression, the optimal weight vector w* at the stationary point could be solved by the linalg.solve function in numpy. In the code listing below, we provide the left-hand side and right-hand side components of the normal equations to the optimization procedure and then calculate the new total cost.

```
Listing 2.6 Solving for the optimal weight vector via closed-form solution

w_star = np.linalg.solve(X_new.T@X_new, X_new.T@y) #A
f_star = X_new@w_star #B
resid = y - f_star #C
Q = np.dot(resid.T, resid) #D
>> Q
array([[6.33963636]])
```
