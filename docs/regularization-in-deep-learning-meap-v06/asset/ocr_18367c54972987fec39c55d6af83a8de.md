completed using the _softmax_ function, which applies a particular mathematical formula to turn a number into a probability while ensuring that the probabilities of all classes sum to one. The benefit of using probability is that we do not have to deal with specific and unbounded numbers; the probability will always be bounded between zero and one, making it easier for interpretation.

Specifically, the original output {ŷk k = 1, ...,10} for the _kth_ class will be transformed via S(ŷk) = e^ŷk / Σ i=1 to 10 e^ŷi. The transformation essentially applies the exponential function to each raw output and normalizes it by summing all the resulting exponentials to squash the output between zero and one, all of which are now bounded and sum to one. For example, given an array of [1,2,3], the transformed output using softmax function would be [0.09, 0.24, 0.67]. Note that the transformation is monotonic, meaning the relative ranking among these outputs remains the same, so we will still be able to identify the final prediction by locating the maximum. The softmax function can be implemented as follows.

```
Listing 4.7 Using softmax function to transform to probability output
import numpy as np
def softmax(x):
    return np.exp(x) / np.sum(np.exp(x), axis=0)
```
