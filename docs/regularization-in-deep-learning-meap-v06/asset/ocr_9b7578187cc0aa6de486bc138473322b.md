A disparate group of sharp mini-batch loss curves makes it difficult for SGD to converge. For example, the loss curve based on one mini-batch may send the optimizer in a totally different direction than another loss curve that sits on a different mini-batch. SGD has a hard time converging in the presence of sharp loss curves with high variance since the large gradients will likely cause the optimizer to diverge and jump out of the region that contains w*.

Therefore, we would expect SGD to prefer the first scenario with a homogeneous group of loss curves and little variance, as opposed to the second scenario with a disparate group of loss curves and high variance. SGC convergence would be relatively easy to achieve in the first scenario. The point is, if the SGD update is very sensitive to which mini-batch from the training set is currently used, then it will probably be very sensitive to the future test set and thus struggles to generalize well. When there are large differences among the mini-batches in the training set, as seen in figure 8.4, the difference between the training set and the test set will likely be high, thus ending up with poor generalization performance. SGD therefore prefers the first scenario and uses its stochasticity to induce a better generalization performance.
