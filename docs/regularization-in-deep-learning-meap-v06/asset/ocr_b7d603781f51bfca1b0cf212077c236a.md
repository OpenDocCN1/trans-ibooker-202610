good classifier, making it challenging to capture the weak signal embedded in the data.
These challenges will likely compromise the quality of the trained model based on the
existing data. We would need to transform and tweak the training data so that its distribution
better approximates the test set.

In this chapter, we will start with common data-based methods that could help
strengthen our training dataset, followed by practical examples of how to apply these
techniques to improve generalization performance. We refer to these techniques as
regularization via data, since they represent data-based transformations that regularize the
final trained model in a way that improves its generalizability.

# 5.1 Data-based methods

Data-based methods refer to a series of transformations applied to the data, including the
input design matrix, the output target, the hidden layer activations when using deep neural
networks, and a combination of these components. Such transformations can be row-wise or
column-wise. Since the model needs to fit a wide range of data after transformation, it is less
likely for the model to become overfitting and overconfident about its predictions. Let us
start with the design matrix to get a sense of how we could transform the data.

Imagine we have an input dataset **X** ∈ R<sup>n×p</sup>, i.e., a matrix with **n** rows and **p**. We could
perform the horizontal treatment by adding more informative and predictive features, which
effectively transforms and increases the original space of **p** features. This can be achieved by
manual feature engineering, such as adding basis functions as additional features as we saw
in chapter 2 or using automatic feature extraction through hidden layers in a deep neural
network. The latter may involve a larger or smaller feature space at a specific hidden layer
than the original input layer. When mapping/extracting the original feature space to a new
representation in the hidden layer, the learned features tend to be more disentangled and
thus more conducive to the current learning task.

We could also introduce vertical treatment by appending more artificial examples to **X**,
forming a larger and possibly infinite augmented training dataset **X**<sup>∗</sup>. To enlarge the sample
space, we could strategically sample the original dataset based on the specific type of
problem at hand. For example, **oversampling** the minority group with replacement from **X**
could often effectively combat the problem of class imbalance and lead to better models. By
boosting the presence of the minority samples using repeated sampling, this technique
provides an enlarged dataset that better fits training, despite the data distribution being
deliberately different from the ground truth distribution. Note that **undersampling** could also
reduce the presence of the majority group and strengthen the signal of the minority, thus
playing a regularizing effect.

Alternatively, one can also use **bootstrap sampling** to repeatedly draw samples from the
original dataset with replacement, creating multiple copies of the dataset, each containing a
different number of repeated samples. These datasets can then be used to create multiple
individual models, whose predictions would then get aggregated to produce the final
prediction. This form of **ensemble learning** is called **bootstrap aggregation** (or **bagging**),
which helps reduce overfitting and improve model stability.
