# 6.3 Implicit regularization in multi-task learning

Up till now, we have been focusing on optimizing over a single particular metric, such as the mean squared error. This involves training a single model or an ensemble of models for the specific task at hand, often through many rounds of fine-tuning and estimation. However, when we are exposed to more than one task, this approach would ignore the potentially useful information from other related tasks. In this case, we can consider building shared representations among these similar tasks using multi-task learning (MTL) in order to improve the generalization performance on the original task. In other words, the domain-specific characteristics embedded in related tasks could help the model trained by MTL generalize better.

MTL refers to a learning paradigm where multiple tasks are learned in parallel as opposed to being treated as independent tasks using a single-task approach. When simultaneously learning multiple tasks, the knowledge and experiences acquired in one task could (hopefully) be shared and transferred to other similar tasks, which is one of the fundamentals in human learning process. Indeed, we as humans often apply the knowledge acquired through related tasks when learning a new task. As a dedicated field in machine learning, MTL offers benefits in terms of learning efficiency and predictive accuracy. By leveraging the information embedded in the signals of auxiliary tasks, MTL could exploit the similarities and relations among multiple learning problems and thus contribute to test set generalization. The improved generalization performance is a result of the implicitly induced regularization effect when optimizing the model’s performance over all learning tasks.

MTL can also viewed as a form of overlaying inductive bias, causing the model to prefer certain hypotheses (a set of models in the entire space of all possible models) over others. The inductive bias is provided by the joint training of the auxiliary tasks, since a model trained using MTL is tilted towards hypotheses that are able to explain more than one task, thus leading to better generalization. By biasing the model to favor representations which other tasks also prefer, it will also help the model generalize well to new tasks outside the training data, as long as the tasks are similar in nature and originate from the same data generating process.

In addition, MTL can be considered as a form of implicit data augmentation, which effectively increases the sample size used in the training procedure. This interpretation comes from the fact that all the learning tasks are often perturbed by different levels of noise. When training a model on one task, the ultimate goal in a typical single-task training process is to learn a good enough representation that ignores the data-dependent noise and captures the underlying pattern, which helps it generalize well to the test set. Since different tasks are exposed to different noises, jointly learning two tasks will allow the model to acquire a more general representation and overcome task-specific noises. By lowering the risk of overfitting to a single learning task, simultaneously learning more than one task allows the model to average out the noise patterns and thus generalize better to both tasks.
