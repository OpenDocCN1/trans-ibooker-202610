Next, we will define two utility functions to support the coordinate-wise gradient descent algorithm. In the following code snippets, we define the function `calculate_mse()` to calculate the mean squared error and the `feature_derivative_ridge()` function to obtain the derivative for each feature. `calculate_mse()` is the same utility function we used in the previous chapter, where we first generate the list of predictions stored in `f_star`, calculate the residuals in `resid`, and finally return the total mean squared error in `Q`. The `feature_derivative_ridge()` function implements the exact closed-form derivative solution discussed earlier, where we separate the case when the weight is for the first bias term as it is not penalized. Note that both functions are included as part of the methods within the `GD_regression` class.

## Listing 7.4 Class methods to calculate MSE and derivative

```
def calculate_mse(self, X, y, weights): #A
    f_star = X@weights #B
    resid = y - f_star #C
    Q = np.dot(resid.T, resid).mean() #D
    return Q

def feature_derivative_ridge(self, errors, feature, weight, l2_penalty,
    feature_is_constant): #E
    if feature_is_constant == True: #F
        derivative = np.dot(feature, errors) * 2
    elif feature_is_constant == False: #G
        derivative = np.dot(feature, errors) * 2 + 2*l2_penalty*weight
    else:
        derivative = 'derivative not exist!!!'
    return derivative
```

- # A function to calculate the mean squared error
- # B generate model prediction
- # C calculate the residuals
- # D MSE as the final cost
- # E function to calculate feature-wise closed-form derivative
- # F compute the derivative of the weight corresponding to the bias term
- # G compute the derivative of all other weights

Finally, we will define the `fit()` method to perform the fitting and estimation procedure. As shown in the following code snippet, we first initialize an array of zeros stored in `weights`, and start the optimization loop for a total of rounds specified by the `num_epochs` input parameter. This is different from the stopping condition based on the RSS of the feature norm and is used here for convenience. We compute the predictions and errors for all observations in each epoch, then enter a loop over all the weights to perform the coordinate-wise gradient descent update. We then score the current weights using the training and test sets and store the results in train_loss and test_loss, respectively.

## Listing 7.5 Class method on model fitting

```python
def fit(self, X_train, y_train, X_test, y_test): #A
    weights = np.zeros(X_train.shape[1]) #B
    epoch = 0 #C
    while epoch < self.num_epochs: #D
        epoch += 1 #E
        predictions = np.dot(X_train, weights) #F
        errors = predictions.reshape(-1,1) - y_train.reshape(-1,1) #G
        for i in range(len(weights)): #H
            if i == 0: #I
                derivative = self.feature_derivative_ridge(errors,
                X_train[:,i].reshape(1,-1), weights[i], self.l2_penalty, True) #J
            else:
                derivative = self.feature_derivative_ridge(errors,
                X_train[:,i].reshape(1,-1), weights[i], self.l2_penalty, False) #K
                weights[i] = weights[i] - self.lr * derivative #L

        self.train_loss.append(self.calculate_mse(X_train, y_train, weights)) #M
        self.test_loss.append(self.calculate_mse(X_test, y_test, weights)) #M
        # store the final weights
        self.weights = weights
    return self
```

- #A function to estimate model coefficients
- #B initialize weights to be an array of zeros
- #C iteration counter
- #D while not reaching maximum number of iterations
- #E increment iteration counter
- #F compute the predictions based on current weights
- #G compute the errors as predictions – output
- #H coordinate wise gradient descent over each weight
- #I compute the derivative for the ith weight
- #J compute the derivative of the constant weight when i=0
- #K compute the derivative of all other weights
- #L gradient descent update for each coordinate/weight
- #M score using training and test sets

When there is only one input layer and one output layer (also called a single-layer neural network), the neural network model is essentially equivalent to a linear regression model. ## LINEAR REGRESSION USING A SINGLE-LAYER NEURAL NETWORK

To learn a linear regression model, let us define a one-layer fully-connected network (FCN). The input size equals the number of features, and the output size is one since there is only one scalar output for each input observation. In the following code listing, we define a class named FCN_regression to store the necessary attributes and methods. Upon initialization, the class requires a few input parameters: the number of input features in input_size, the learning rate for SGD in lr, the number of epochs in num_epochs, and the magnitude of the scalar hyperparameter for L2 penalty in l2_penalty. We also define the model architecture as a single linear layer stored in model, the loss function to be nn.MSELoss() stored in criterion, and SGD as the optimizer in optimizer.

## Listing 7.8 Creating a class for single-layer FCN

```
class FCN_regression:
    def __init__(self, input_size, lr=1e-3, num_epochs=1000, l2_penalty=0):
        self.lr = lr
        self.num_epochs = num_epochs
        self.l2_penalty = l2_penalty
        self.train_loss = []
        self.test_loss = []
        self.model = nn.Linear(input_size, 1)
        self.criterion = nn.MSELoss()
        self.optimizer = torch.optim.SGD(self.model.parameters(), lr=self.lr)
```

Next, we will create a fit() method within the class to perform the model estimation task. As shown in the following code snippet, we take the training and test sets as the input for training and scoring purposes, which need to be converted to tensor format as we are working with PyTorch. Following the same zero-initialization strategy, we perform the same training procedure as training a typical neural network covered in chapter 4. Specifically, we perform a forward pass to obtain model predictions in y_predicted for the training set, calculate the loss in loss_train, add L2 penalty if any, clear the historical gradients in relevant variables, automatically calculate the current gradients via back-propagation, and finally perform stochastic gradient descent update for a total of epochs specified by num_epochs. In addition, we also calculate the test set MSE after each round of training in a gradient-free setting.

```
def fit(self, X_train, y_train, X_test, y_test):
    weights = np.zeros(X_train.shape[1]) #A
    epoch = 0 #B
    X_train = torch.from_numpy(X_train).float() #C
    X_test = torch.from_numpy(X_test).float() #C
    y_train = torch.from_numpy(y_train).float() #C
    y_test = torch.from_numpy(y_test).float() #C

    for epoch in range(self.num_epochs):
        y_predicted = self.model(X_train) #D
        loss_train = self.criterion(y_predicted, y_train) #E
        self.train_loss.append(loss_train.item())
```
