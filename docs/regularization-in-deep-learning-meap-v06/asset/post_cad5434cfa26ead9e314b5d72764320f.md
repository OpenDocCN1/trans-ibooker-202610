X_test = X[idx for idx in range(len(X)) if not idx in train_idx] #E
y_test = y[idx for idx in range(len(X)) if not idx in train_idx] #E

#A Reshape to a column representation, -1 means the number of rows is inferred
#B Define the split ratio for the training set
#C Randomly sample a list of integer indexes to go into the training set
#D Allocate training and test set based on selected training indexes
#E Allocate training and test set based on indexes not in training set

Note that both X and y are explicitly converted to a column vector upon initialization, corresponding to our way of mathematically representing these variables earlier. Index-based referencing is a common technique in deep learning, especially when referencing multi-dimensional tensors such as the weights in neural networks.

## 2.2 The model

Earlier we introduced the four components of a model, including parameters and architecture. The parameters, also called weights, are the adjustable tuning knobs of the model, each being a scalar value. We hope to obtain the optimal set of parameters based on certain criteria. Since one feature often corresponds to one weight in the linear regression setting, we will use **w** to denote the set of weights for the features in **X**. That is, **w**^T = [**w**₁,**w**₂, ... **w**ₚ] represents the set of weights we wish to optimize.

As mentioned in Chapter 1, the architecture of the model governs the interaction between the input features in **X** and weights in **w**. The model often assumes the process: **y** = f(**X**) + ε, where f represents the assumed functional form to approximate the true pattern, and ε denotes the additive random noise which is often assumed to be uncorrelated with **X** and follow a Gaussian distribution with zero mean and fixed variance. The output of these interactions forms the model prediction ŷ^T = [ŷ₁,ŷ₂,...,ŷₙ].

### 2.2.1 The prediction function

The model architecture we have discussed so far serves as a function that takes **X** and **w** as the input and predicts ŷ as the output. In other words, it is a prediction function ŷ = f(**X**;**w**) = f<sub>**w**</sub>(**X**), where the output ŷ is dependent on both **X** and **w**. This is also referred to as a parametric model, since the function f is parameterized by a set of weights **w** and belongs to some parametric family F<sub>**w**</sub>. Note that **X** is treated as an unchangeable input; it is given by the initial training set. **w**, however, represents a set of changeable weights.

### Parametric versus non-parametric model

A parametric model refers to a function of a particular form that has a small and fixed number of parameters. A non-parametric model, on the other hand, is a very flexible function with many free parameters. Linear regression is a parametric model given its explicit model structure and a limited number of parameters. The deep neural network model, however, varies depending on the model architecture. Technically speaking, a standard deep neural network is a parametric model given its fixed number of parameters. However, most deep neural networks could be interpreted as non-parametric due to an extensive set of parameters involved.

In linear regression, the data interaction highlights a weighted sum, a matrix-vector multiplication between the **X** and **w**, plus a bias term w₀, assuming no additional transformation on **X**. That is, f(**X**;**w**) = w₀ + **Xw**.

### Matrix multiplication

A matrix is characterized by its shape, namely the number of rows and columns. A matrix is of shape (n,p) if it contains n rows and p columns. Given two matrices A of shape (n,p) and B of shape (q,k), for their multiplication to work, a necessary condition is the equality in the "inner dimension", i.e., p = q. The resulting matrix AB will take the shape of the "outer dimension", i.e., (n,k). Checking the change of dimensions is recommended when doing matrix multiplication.

### 2.2.2 The bias trick

In linear regression, a bias term w₀ is often introduced to act as a global level shift to the prediction output, making ŷ = w₀ + Xw. The additional term w₀ is a learnable parameter, a global adjustment applied to all outputs. It is also referred to as the intercept term in the linear regression setting.

In practical implementation, a simplified linear algebraic form could be obtained by writing ŷ = Xnew Wnew, where Xnew is the new design matrix created by appending a column vector of ones to the beginning of X, and Wnew is simply one more parameter added to the beginning of the weight vector w. This is called the bias trick, allowing us to express the same operation using an algebraic form of a matrix vector multiplication. Besides, it also saves us the trouble of creating a separate parameter for w₀, since the additional column vector of ones in Xnew will simply be treated as a separate feature. The added column vector of ones could thus make follow-up mathematical analysis more convenient, besides the benefit of more straightforward implementation by simply representing all parameters in one vector.
