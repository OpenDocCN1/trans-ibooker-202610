Third, there is no need to use all the observations to calculate the average loss Q(w, D). Since the central limit theorem applies, we only need to use a fractional of D to calculate the average loss term MSE, which will converge to the MSE of the entire dataset after a reasonable number of iterations.

Because of these considerations, the stochastic gradient descent update rule based on subsets of D is often used. As shown in the following update equation, we use Dt to denote a random subset (also called minibatch) of D. In each iteration, we randomly sample a subset Dt and use it to perform one iteration of gradient descent update. The update rule is also referred to as minibatch-SGD, as covered in chapter 2.

```
w_{t+1} = w_t - \eta \nabla_w Q(w_t, D_t)
```

The random subset Dt can be considered a random variable consisting of a random subset of observations from D in each update. In practice, however, we often pre-divide the original training set D into different subsets (called mini-batches), perform gradient descent updates across different mini-batches in the inner loop, and repeat the process multiple times (called epochs) in the outer loop.

Note that we would treat the mini-batch Dt as a random variable in mathematical analysis to ensure that the mini-batches are independent of each other. To implement this, we would resort to the random number generator and produce random indexes to fetch the observations in a mini-batch, whose size also depends on that of D.

Also, using the stochastic gradient descent algorithm does not guarantee we will be able to descend the loss function at every step. Due to the randomness in the subset, we may even increase the loss value at a specific step, but the overall process will move towards a local optimum, stochastically.

Switching to a mini-batch in each gradient descent update facilitates the model training when D is quite large. However, we may ask whether the mini-batch gradient descent update algorithm converges to a local minimum of the cost function or keeps wandering around along the loss surface. Let us look at the convergence property SGD in the following section.

# 8.1.2 Convergence of SGD

For an algorithm to succeed and gain popularity, we would often ask if the algorithm converges into a solution and, if it does, the convergence rate. For the vanilla gradient descent, we know that the algorithm always converges to a particular local minimum solution for an adequately selected learning rate. Although the quality of the solution may not be excellent in terms of generalization performance, it still converges to a critical point (more specifically, a point with the gradient vector equal to zero) in the weight space.
