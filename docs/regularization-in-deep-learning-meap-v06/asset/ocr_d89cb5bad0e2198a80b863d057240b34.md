# Listing 4.8 Define the cross entropy loss function

```
def cross_entropy(actual, predicted):
    EPS = 1e-15
    predicted = np.clip(predicted, EPS, 1 - EPS)
    loss = -np.sum(actual * np.log(predicted))
    return loss
```

# A Cap and floor the probability between 0 and 1

Let us look at an example. Suppose we are dealing with a three-class classification problem with the true label being the first class, i.e., the target label is one-hot encoded as [1, 0, 0]. We have a good prediction of [0.8, 0.1, 0.1] and a bad prediction of [0.1, 0.6, 0.3]. Let us see how their CEL results differ.

```
>>> y = np.array([1, 0, 0])
>>> pred_good = np.array([0.8, 0.1, 0.1])
>>> pred_bad = np.array([0.1, 0.6, 0.3])
>>> loss_good = cross_entropy(y, pred_good)
>>> loss_bad = cross_entropy(y, pred_bad)
>>> print('The good prediction loss: {:.4f}'.format(loss_good))
>>> print('The bad prediction loss: {:.4f}'.format(loss_bad))
The good prediction loss: 0.2231
The bad prediction loss: 2.3026
```

The result matches our expectation that a worse prediction leads to a higher CEL. In PyTorch, however, the one-hot encoding for the target label and softmax transformation for the prediction array is automatically applied when using the torch.nn.CrossEntropyLoss function. The codes below show that we can pass in the original class label and the prediction array to calculate CEL.

```
>>> cost_func = nn.CrossEntropyLoss() #A
>>> y = torch.tensor([0]) #B
>>> pred_good = torch.tensor([[2, 0.8, 0.5]])
>>> pred_bad = torch.tensor([[1, 6, 0.2]])
>>> loss_good = cost_func(pred_good, y)
>>> loss_bad = cost_func(pred_bad, y)
>>> print('The good prediction loss: {:.4f}'.format(loss_good.item()))
>>> print('The bad prediction loss: {:.4f}'.format(loss_bad.item()))
```

Understanding the construct of CEL is essential when assessing the whole model training process since it represents the model's goodness of fit. While a high level of goodness of fit to the training data may cause the model to overfit, an additional cost term on model complexity could be added. The additional cost term acts as an explicit regularizer on the magnitude of the parameters.
