Next, we introduce the optimization procedure used to guide the modification of w in a way that minimizes Q(w). The specific procedure involved in the optimization process is also called an algorithm, designed to minimize the scalar-valued cost Q(w).

# 2.4 The optimization algorithm

Optimization involves tuning the model parameters based on a particular procedure, an algorithm to reduce the pre-defined cost function to a minimum value. In other words, the optimal weight vector w* is obtained when the cost function is minimized: w* = argminᵥQ(w). When visualizing the cost function on a graph, its minimum suggests that the derivative of the cost function at this particular point is zero. The minimum point is also called a stationary point.

In the case of multiple features, being at the stationary point means that the gradient vector with respect to the current weight vector is zero across all the weights. Note that the gradient vector contains the partial derivatives with respect to each weight. Based on the previous definition of Q(w) = yᵀy - 2yᵀΦw + wᵀᵀΦᵀΦw and its only dependence on w, its derivative with respect to w could be written as ∇wQ = -2Φᵀy + 2ΦᵀΦw. Consequently, the goal of optimization is to reach a stationary point where all elements in ∇wQ are zero. This point then represents a model that potentially gives the minimal cost.
