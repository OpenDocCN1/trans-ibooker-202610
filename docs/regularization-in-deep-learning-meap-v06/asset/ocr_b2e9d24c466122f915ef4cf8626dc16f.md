Figure 6.4 A typical convolutional neural network is invariant to translations of the object (digit 8) across different locations on the input image. It can recognize digit 8 as the same label, which is not easily achieved when training FCN-based models. Feed-forward architectures don't understand the structure or order in their inputs. Thus, when presenting a set of images and associated labels to a feed-forward network and performing the training, we would get the same result if we instead trained it after shuffling the pixel values in the images (in a consistent manner). Structural awareness is only built in CNN-based models.

Moving the object around without changing the classification result is thus an essential inductive bias exhibited in convolutional neural networks. Irrespective of the object location, a set of filters will move across the whole image (left to right, top to bottom) to perform the convolution operation. When meeting a particular edge-like region or other shapes of interest, specific nodes in the filters will activate, producing large values that “beat” the neighbors after the pooling operation. Therefore, it does not matter in terms of where the specific activation happens, if any, since it will eventually get pooled into the following layer. As long as a particular node fires, an adequately trained CNN will be able to capture such activation and realize that the noise is due to random translations. Translational invariance is thus a natural property embedded in CNN.

Besides translational invariance, we can also facilitate the learning of rotational invariance in a CNN by rotating the same object up to a certain degree. Provided that the new images with rotated objects still belong to the same class, we could generate more artificial and helpful images for the model to pick up and learn the desired property of rotational invariance.
