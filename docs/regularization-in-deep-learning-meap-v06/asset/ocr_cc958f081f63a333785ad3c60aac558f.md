# 8.2.1 SGD in univariate linear regression

We can glean further insight into the convergence properties of SGD from a simple framework: a univariate model with the single-observation SGD update rule. Our objective function to be minimized thus becomes:

$$Q(\mathbf{w}) = \frac{1}{2} \sum_{i=1}^n (y_i - f(\mathbf{x}_i; \mathbf{w}))^2 = \frac{1}{2} \sum_{i=1}^n (y_i - x_i w)^2$$

Where we multiply 1/2 to facilitate the mathematical analysis later on. As the objective function of this single-dimensional optimization problem is convex, we can differentiate it and set the gradient to zero to obtain the solution at the local minimum, which is also the global minimum for the current random sample $(x_i, y_i)$. All variables are now one-dimensional and thus easy to analyze, thus writing $Q(\mathbf{w})$ as $Q(w)$.

Since the cost function $Q(w)$ is quadratic in $w$, we can set its gradient to zero to obtain the closed-form expression for the optimal solution $w^*$ as follows.

```
$$\nabla_w Q(w) = \sum_{i=1}^n (y_i - x_i w)x_i = 0$$

$$w^* = \frac{\sum_{i=1}^n X_i y_i}{\sum_{i=1}^n x_i^2}$$
```
