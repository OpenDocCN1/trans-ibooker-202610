# 7.3.5 The soft-thresholding rule

So far, we have been looking at obtaining the optimal weights using the gradient information of the objective function, both in the derivation of a closed-form solution (setting the first derivative to zero) and in the iterative gradient descent algorithm. However, the gradient of the objective function \(Q(\mathbf{w}) = RSS(\mathbf{w}) + \lambda \|\mathbf{w}\|_1\) in LASSO regression is not directly usable.

Specifically, for each \(w_j\) in the weight vector \(\mathbf{w}\), we need to compute the derivative of \(|w_j|\) with respect to \(w_j\), namely \(d|w_j|/dx\). When \(w_j > 0\), we have \(|w_j| = w_j\), whose derivative will be 1. Correspondingly, the derivative will be -1 if \(w_j < 0\). However, there is no derivative at the point when \(w_j = 0\), a problem point that rules out the availability of a closed-form solution and the use of a gradient-based optimization algorithm. See figure 7.20 for an illustration on the graph of \(|w_j|\) and its derivative at different values of \(w_j\).
