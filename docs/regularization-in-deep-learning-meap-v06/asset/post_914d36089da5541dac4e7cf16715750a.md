Note that the optimization happens upon updating the weights based on the gradient of the current cost with respect to the current set of weights. The gradient descent algorithm thus requires us to be able to calculate the gradient vector $\nabla_w Q(w_t)$ that contains the partial derivatives of the cost with respect to each weight in w at timestamp t; in this case of neural networks, the weights in each layer.

Now, recall the functional form of the multilayer perceptron:

$$f_L(x) = \phi(b_L + W_L \phi(b_{L-1} + W_{L-1} \phi(\cdots \phi(b_1 + W_1 x)\cdots)))$$

The final prediction $f_L(x)$ can be considered as a multi-layered composite function of the initial input weights $W_1$ and $b_1$ at the first hidden layer. When the cost is calculated, we need to cascade it all the weights for gradient calculation, including those early in the layers such as $\mathbf{W}_1$ and $\mathbf{b}_1$. To simplify the discussion, we will use $\mathbf{w}$ to represent all the beginning weights in the network (i.e. $\mathbf{W}_1$ and $\mathbf{b}_1$), and see how to calculate the *Jacobian* (i.e., first order partial derivatives of the cost for each weight). In other words, the nested prediction function based on the multilayer perceptron now becomes:

$$f_l(f_{l-1}(\cdots f_1(\mathbf{w})))$$

where for each $l^{th}$ layer out of total $L$ layers, the function $f_l$ is a differentiable multivariate function that maps the input vector of $p_{l-1}$ dimensions to the output vector of $p_l$ dimensions. The differentiability in the intermediate functions is essential to the gradient-based optimization. When these functions are not differentiable, we cannot calculate the gradient, let alone proceed with gradient descent update.

## 4.2.2 The chain rule with partial derivatives

When a function is composite, such as the multilayer perceptron prediction function, we can generally represent it *f(g(x))*, where *f* is a function of another function *g* (and so on). To calculate the derivative of a composite function, we would rely on the *chain rule*, which essentially passes down the derivative operation through each intermediate function until the raw input. Specifically, the chain rule says that the composite function could be differentiated as the following:

$$\frac{d}{dx}[f(g(x))] = f'(g(x))g'(x)$$

The above formula corresponds to a direct backward execution of differentiation. In order to calculate the derivative of the (two-layer) composite function with respect to the raw input, we would first calculate the derivative of the outer function *f* with respect to the entire inner function *g(x)* as a whole, giving *f'(g(x))*. Then we continue the calculation at the inner function *g*, resulting in *g'(x)*. Finally, these intermediate derivatives are multiplied together. The derivative calculation step passes backwards through all composing functions.

More generally, to calculate the partial derivatives of the composite multilayer perceptron function for each weight in the neural network, we would rely on the chain rule to pass through the derivative calculation through all hidden layers in a backward fashion. This process also corresponds to the forward propagation in prediction followed by the backward propagation in the derivative calculation when training neural networks. In the forward propagation, we use the prediction function to sift through essential signals by repeated matrix multiplication and nonlinear transformation, resulting in a set of predictions which are then summarized into a single metric via the cost function. In the backward propagation, the cost is back-propagated to the last hidden layer to calculate the partial derivative for each weight in that hidden layer. This process continues for the second last hidden layer and repeats to the first hidden layer.

To augment the understanding of these two propagations, we can look at a simple neural network that has two hidden layers with two nodes each, two input nodes and one output node. Figure 4.11 shows the process flow of the forward propagation. For notational consistency, we use x to denote the input features (i.e., features that are provided by the input data), w to denote the weights between layers, and f as the intermediate function that operates on the input and weights from the previous layer to produce an output (i.e., a learned feature in the hidden space) for the next layer. We use the subscript to denote layer-wise index and the superscript to denote the index within a given layer. For example, $x^j$ denotes the $j^{th}$ node as the raw feature at the input layer, $w^j_i$ denotes the $j^{th}$ scalar weight (using relative positioning from top to bottom) of the $i^{th}$ layer, and $f^j_i$ denotes the $j^{th}$ node of the $i^{th}$ layer.

Figure 4.11 Schematic of forward propagation in a simple neural network with two hidden layers, each having two nodes. The bias term is ignored for simplicity. The nodes and weights along the arrows are explicitly annotated for clarity in each forward pass. As shown by the two examples on $f^2_2$ and $f_3$, except at the input layer, each node is a result of matrix multiplication between the input nodes from the previous layer and the corresponding weights, followed by an activation function (ReLU in this case). The output of a node then becomes an input, a learned hidden feature, to the following layer, until reaching the final output layer.

The forward propagation is essentially a repeated operation of matrix multiplication (or equivalently weighted sum) and nonlinear transformation using the activation function. For example, the second node in the first hidden layer computes $f^2_1 = \text{ReLU}(x^1 w^1_1 + x^2 w^1_4)$, whose output then becomes the input features for the same operation at the next layer. These input features in the hidden layer are automatically extracted and learned by the neural network and tend to be more disentangled and meaningful at different levels of abstraction. When the forward propagation reaches the final layer, we have $f_3 = \text{ReLU}(f^2_1 w^1_3 + f^2_2 w^3_2)$ as the final prediction of the model. The cost is then calculated based on the final model prediction $f_3$ and the corresponding true target $y$, completing the forward pass.

The backward propagation then gets triggered to send the feedback (i.e., partial derivative) to each weight in the neural network. However, this process involves multiple embedded functions and thus relies on the chain rule to perform gradient calculation. As shown in figure 4.12, the calculation process essentially proceeds from the final output and sequentially expands backward until reaching the initial weights in the first hidden layer. For better illustration, the partial derivatives are explicitly annotated for direct correspondence with the weights in the previous figure. If we want to calculate the partial derivative of the cost Q with respect to the weight $w_1^1$ in the first hidden layer, we need to traverse backwards through the dash-dotted lines, starting from the cost and passes through all interconnected partial derivatives, all the way to the very beginning at $w_1^1$. This cascading process essentially follows the chain rule.
