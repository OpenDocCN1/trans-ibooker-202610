Finally, we create a function to allow multiple runs of the above steps and report the median result based on a pre-specified number of simulations. Specifically, we first create two placeholders (`mse_train` and `mse_test`) to store the results of multiple runs. For each run, we will generate a different dataset for training, allowing for the option to corrupt the target by a certain level of noise if needed. The generalization performance is assessed via a list of equally spaced points in X_test and the corresponding true target values in y_test. Next, we vary the model complexity by sequentially assessing models up to a different polynomial degree up to `num_basis_max`. Each assessment consists of estimating the model coefficients and calculating the corresponding cost. At the end of the function, we return the median cost for the training set and the test set across multiple runs.

# Listing 3.5 Calculating the median cost across multiple runs

```
def compute_performance(num_train_samples, num_runs, num_basis_max, train_noise_std=0): #A
    mse_train = np.zeros((num_runs, num_basis_max)) #B
    mse_test = np.zeros((num_runs, num_basis_max)) #B
    for k in range(num_runs): #C
        X_train = random.randn(num_train_samples).reshape(-1, 1) #D
        y_train = get_true_y(X_train).reshape(-1,1) #D
        if train_noise_std > 0: #E
            y_train = y_train + np.random.normal(0, 0.01, y_train.shape[0]).reshape(-1,1)
    #E
    X_test = np.linspace(0, 1, 100, dtype = X_train.dtype).reshape(-1,1) #F
    y_test = get_true_y(X_test).reshape(-1,1) #F
    for num_basis in range(1, num_basis_max + 1): #G
        fitted_coef = estimate_coef(X_train, y_train, num_basis) #H
        mse_train[k, num_basis-1] = calculate_mse(X_train, y_train, fitted_coef,
                                                    num_basis) #I
        mse_test[k, num_basis-1] = calculate_mse(X_test, y_test, fitted_coef,
                                                    num_basis) #I
    return np.median(mse_train, axis = 0), np.median(mse_test, axis=0)
```
