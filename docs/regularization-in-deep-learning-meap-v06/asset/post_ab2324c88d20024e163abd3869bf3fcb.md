In PyTorch, common data augmentations are achieved via the transforms module from the torchvision library. To demonstrate the effect of random perturbation, we will include three kinds of augmentation, including horizontal flipping via the RandomHorizontalFlip() function, rotation via the RandomRotation() function, and color jittering via the ColorJitter() function. Each function has its own parameters to control the level of random noise and is chained together using the Compose() function into the img_augment variable. Besides, the augmented image is converted into a tensor object to work with the PyTorch framework. See the coding listing below for the full specification.

## Listing 5.2 Specify the data augmentation scheme

```
img_augment = transforms.Compose([transforms.RandomHorizontalFlip(), #A
              transforms.RandomRotation(10), #B
              transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2), #C
             ])
transforms.ToTensor() #D
```

- #A flip the image w.r.t horizontal axis
- #B rotate the image up to 10 degrees
- #C randomly changes image brightness, contrast and saturation up to a certain degree
- #D convert to tensor object to work with torch

Let us now apply the specified data augmentation scheme to the city view image and visualize some of the randomly generated images. In the code listing below, we first define a function `gen_img()` to transform the image tensor (referenced as a copy to avoid changing the original object) into a PIL image format so that we can apply data augmentation. The augmented image is then reshaped by moving the channel dimension from the first to the last so that it can be properly plotted. Then we apply the function to generate 10 images plotted two rows.

## Listing 5.3 Visualize the augmented images

```python
import copy
def gen_img(img):
    img2 = transforms.ToPILImage()(copy.copy(img)) #A
    img2 = img_augment(img2) #B
    img2 = np.transpose(img2, (1, 2, 0)) #C
    return img2

fig = plt.figure(figsize=(10, 4))

for idx in np.arange(10): #D
    ax = fig.add_subplot(2, 5, idx+1, xticks=[], yticks=[])
    plt.imshow(gen_img(img))
    ax.set_title(idx)
```

Figure 5.4 shows the augmented images after running the codes above. The generated images now vary in the level of rotation, flipping, brightness, contrast, and saturation, all of which are pre-specified and introduced as random perturbations to the original image. These artificial images can then serve as the additional training data to build a more robust model.

## 5.2.1 Training without data augmentation

The CIFAR10 dataset is a commonly used benchmark dataset in many research papers and will also be the dataset we will use within this chapter. This section will look at the baseline performance if we do not apply any data augmentation to the training procedure. In the CIFAR10 dataset, the images are grouped into ten classes: plane, car, bird, cat, deer, dog, frog, horse, ship, and truck. Let us get a feel of these images by visualizing a random sample for each class.

In the following code list, we start by downloading the CIFAR10 dataset and apply a series of transformations: normalizing the pixel values from the original range of [0,1] to [-1,1] and converting the image object to tensor format. Note that the mean and standard deviation parameters in the Normalize() function are set as a uniform 0.5 across all three color channels. However, a more appropriate approach would be to derive these channel-wise statistics from all the image data. Since the difference is minor and we are only interested in limiting the pixel values to a small and similar range, we use 0.5 across all channels for implementation convenience. The rest of the codes follow the same structure as in the previous chapter, where we load 100 images for each batch.

## Listing 5.4 Load CIFAR10 dataset

```
transform = transforms.Compose([transforms.ToTensor(),
                                      transforms.Normalize(mean=(0.5, 0.5, 0.5), std=(0.5,
                                                           0.5, 0.5))]) #A
training_dataset = datasets.CIFAR10(root='./data', train=True, download=True,
                                      transform=transform) #B
validation_dataset = datasets.CIFAR10(root='./data', train=False, download=True,
                                       transform=transform) #B
training_loader = torch.utils.data.DataLoader(training_dataset, batch_size=100,
                                              shuffle=True) #C
validation_loader = torch.utils.data.DataLoader(validation_dataset,
                                                batch_size = 100, shuffle=False) #C
```

- #A transformation steps for training and test sets upon loading the dataset
- #B download the CIFAR10 dataset
- #C define data loader that reads 100 images at a time

Running the above codes will download the CIFAR10 dataset under the data folder and pump into the data loaders training_loader and validation_loader for training and validation respectively.

Next, we will define a function to convert the image to NumPy format for visualization using matplotlib. We also convert the image back to the original range scale of [0,1] and reshape it to be channel-last. This function then applies for each of the first ten images from the first batch of training_loader, as shown in the code listing below.

## Listing 5.5 Visualize ten images from CIFAR10

```
def convert_tensor_to_np(tensor_img):
    image = tensor_img.clone().numpy() #B
    image = image.transpose(1, 2, 0) #C
    image = image * np.array((0.5, 0.5, 0.5)) + np.array((0.5, 0.5, 0.5)) #D
    image = image.clip(0, 1)
    return image

dataiter = iter(training_loader)
images, labels = dataiter.next()
classes = ['plane', 'car', 'bird', 'cat', 'deer', 'dog', 'frog', 'horse', 'ship', 'truck'] #F
fig = plt.figure(figsize=(10, 4)) #G
for idx in np.arange(10):
    ax = fig.add_subplot(2, 5, idx+1, xticks=[], yticks=[])
    plt.imshow(convert_tensor_to_np(images[idx]))
    ax.set_title(classes[labels[idx].item()])
```

- #A format the image for plotting
- #B convert to numpy
- #C move color channel to the last
- #D unscale the image back to [0,1]
- #E get some random training images from the first batch
- #F define the class labels for visualizing purpose
- #G plot the images in a 2x5 grid
