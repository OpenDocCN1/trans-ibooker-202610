A common choice is to use the second derivative of the fitted function and penalize the integrated squared second derivatives while minimizing the *residual sum of squares* (RSS) between the model prediction and the target outcome. Denote the penalty on the second derivative as $J(\mathbf{w}) = \int f''_w(x)^2 dx$. $J(\mathbf{w})$ will be used to control the curvature of the model. In this case, the resulting model, which is called the smoothing spline, has the following cost function:

$Q(\mathbf{w}) = \sum^n_{i=1} \left(y_i - f_w(\mathbf{x}_i)\right)^2 + \lambda \int f''_w(x)^2 dx$

where $\lambda$ is a weighting factor that controls the tradeoff between the goodness of fit to the training data and the roughness of the resulting functional form. This is a hyper-parameter that is often selected based on cross validation procedure. A large $\lambda$ generates a smooth curve while a small $\lambda$ results in a rough curve. As $\lambda$ approaches zero, the cost function will be RSS driven, leading to an interpolating spline that produces zero training error but takes a wiggly shape. When $\lambda$ approaches infinity, the roughness penalty based on the second derivative of the model becomes paramount, which constrains the form of the model to be linear. The second derivative is a measure of the roughness of the curve and acts as a penalization term in the cost function. More roughness in the curve will result in a higher penalty in the cost function. Besides, this roughness penalty also saves the trouble of deciding how many knots to use when fitting the model.

## 3.2.2 Rewriting the smoothing spline cost function

Recall that the closed-form solution for the linear regression can be derived by setting the gradient of $Q(\mathbf{w})$ to zero and solving a system of normal equations: $\Phi^T \Phi \mathbf{w} = \Phi^T \mathbf{y}$. To derive the closed-form solution after introducing a new penalty term $J(\mathbf{w})$, we will follow a similar approach using the first order gradient.

Using matrix notation, the prediction functions can be written as \(f_w = \Phi w\), where \(\Phi\) represents the list of polynomial basis functions used to derive the new design matrix, and **w** contains the list of weights to be optimized. We can now rewrite the cost function as follows:

\(Q(w) = ||y - \Phi w||^2 + \lambda w^T \Omega w\)

where $(\Phi)_{jk} = \phi_k(\mathbf{x}_j) = \mathbf{x}^k_j$ in the new design matrix $\Phi$ denotes the $k^{th}$ polynomial function $\phi_k$ applied to the $j^{th}$ vector $\mathbf{x}_j$. The double vertical bars denote the squared norm of $\mathbf{y} - \Phi w$, i.e., the sum of the square of each individual residual. $\Omega$ denotes the integrated second derivatives after leaving out the weights, where $(\Omega)_{jk} = \int \Phi''(x) \Phi''(x) dx$.

As we will learn in a later chapter, this form of writing is similar to the cost function of ridge regression, with an extra $\Omega$ term added in the penalty. For those who are familiar with ridge regression, the normal equations are $(\Phi^T \Phi + \lambda \mathbf{I})w = \Phi^T y$, where **I** represents an identity matrix, i.e., a square matrix with ones on the main diagonal and zeros elsewhere. The closed-form solution of our cost function _Q_(_w_) is more general: $(\Phi^T \Phi + \lambda \Omega)w = \Phi^T y$, which can be simplified to the solution for ridge regression when $\Omega = \mathbf{I}$. Figure 3.7 summarizes and compares the three sets of models in terms of the penalty term, the cost function and the normal equations.

| | Linear regression | Ridge regression | Smoothing spline |
|---|---|---|---|
| **Penalty** | None | \(||w||_2^2\) | \(\int f''_w(x)^2 dx\) |
| **Cost function** | \(||y - \Phi w||^2\) | \(||y - \Phi w||^2 + \lambda ||w||_2^2\) | \(||y - \Phi w||^2 + \lambda w^T \Omega w\) |
| **Normal equations** | \(\Phi^T \Phi w = \Phi^T y\) | \((\Phi^T \Phi + \lambda \mathbf{I})w = \Phi^T y\) | \((\Phi^T \Phi + \lambda \Omega)w = \Phi^T y\) |

## 3.2.3 Deriving the closed-form solution

To construct the normal equations similar to the case of linear regression, we will use a new symbol \(\Phi_+\) to denote an augmented new design matrix, which consists of \(\Phi\) and additional rows from the penalty term: $\Phi_* = \binom{*}{\lambda \mathbf{B}}$, where $\mathbf{B}^T\mathbf{B} = \Omega$. Since $\Omega$ is a \( p \times p \) symmetric (square) matrix, this step essentially concatenates an additional \( p \) rows to $\Phi$. Note that since \(\lambda\) is a positive constant, it is fine to scale $\Omega$ by \(\sqrt{\lambda}\).

Similarly, the output vector \(\mathbf{y}\) is also extended with \( p \) zeros at the end, forming a new output variable \(\mathbf{y}_* = \binom{\mathbf{y}}{\mathbf{0}}\). Based on the original normal equations \(\Phi\mathbf{w} = \mathbf{y}\), we can construct a new set of normal equations: \(\Phi_*\mathbf{w} = \mathbf{y}_* = \binom{\mathbf{y}}{\mathbf{0}}\). We can then multiply both sides by \(\Phi_*^T\) and continue the derivation process:

```
\(\Phi_*^T\Phi_*\mathbf{w} = \Phi_*^T \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \sqrt{\lambda} \mathbf{B}^T) \begin{pmatrix} \Phi \\ \sqrt{\lambda} \mathbf{B} \end{pmatrix} \mathbf{w} = (\Phi^T \sqrt{\lambda} \mathbf{B}^T) \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \Phi + \lambda \mathbf{B}^T \mathbf{B}) \mathbf{w} = (\Phi^T \sqrt{\lambda} \mathbf{B}^T) \binom{\mathbf{y}}{\mathbf{0}}\)

\((\Phi^T \Phi + \lambda \Omega) \mathbf{w} = \Phi^T \mathbf{y}\)
```

This gives us the new set of normal equations, with the additional term \(\lambda \Omega\) added as a result of the penalty on model smoothness. We can also handle the derivation from the perspective of the cost function. By reformatting the input and output variables, we can now express the cost function as follows:

```
\(Q(\mathbf{w}) = ||\mathbf{y} - \Phi\mathbf{w}||^2 + \lambda \mathbf{w}^T \Omega \mathbf{w} = ||\mathbf{y}_* - \Phi_* \mathbf{w}||^2\)
```

This form looks similar to the original linear regression setting. Setting the gradient of \(Q(\mathbf{w})\) to zero gives the following normal equations:

```
\((\Phi_*^T \Phi_*) \mathbf{w} = \Phi_*^T \mathbf{y}_*\)
```

This could be solved using the same procedure as in the previous chapter. Note that the new output variable \(\mathbf{y}_*\) contains an additional list of zeros compared with \(\mathbf{y}\), thus the right hand side of the equation above is still equal to \(\Phi^T \mathbf{y}\). On the left hand side, an additional term \(\lambda \Omega\) is added to the original \(\Phi^T \Phi\), resulting in the new normal equations as follows:

```
\((\Phi^T \Phi + \lambda \Omega) \mathbf{w} = \Phi^T \mathbf{y}\)
```

Introducing \(\Phi_*\) and \(\mathbf{y}_*\) has multiple benefits in the derivation. Besides being more conceptually economical under the typical framework of solving least squares problems, it also helps extending to a new geometric view on the effect of the penalty term. Compared with \(\Phi\), the augmented design matrix \(\Phi_*\) has an enlarged column space that is extended from \(\mathbb{R}^n\) to \(\mathbb{R}^{n+p}\). Note that the penalty matrix \(\Omega\) will go through a certain transformation, such as eigen-decomposition, to ensure its column vectors are mutually orthogonal.
