How can we obtain a sparse solution while scaling the same approach to large problems with high-dimensional datasets? This is where the L1 norm comes in, which allows us to achieve a sparse solution in a convex manner and scale to bigger problems more efficiently. By penalizing the L1 norm, the model will tend to generate a sparse solution by setting some weights to zero.

## 7.3.3 Introducing the L1 norm

The L1-norm-based linear regression, or LASSO regression, can handle high-dimensional problems and implicitly produce a sparse set of weights in a computationally efficient way. The L1 norm over the weights is defined as ||w||₁ = Σ|wᵢ| = |w₁| + |w₂|. In our running example, by minimizing the RSS of the fit along with the (scaled) L1 norm of the weights, the model estimation process will arrive at a unique solution (out of infinitely many solutions) that has the minimal L1 norm.

Let us visualize the estimation process graphically. As shown in figure 7.16, the L1 norm is expressed as a diamond, which means that all weights on the same diamond share the same value of L1 norm. To see this, let us set the L1 norm to an arbitrary constant C, namely |w1| + |w2| = C. Considering the modulus operation (taking the absolute value) on the weights, there are a total of four different combinations: w1 ≥ 0 & w2 ≥ 0, w1 ≥ 0 & w2 < 0, w1 < 0 & w2 ≥ 0, and w1 < 0 & w2 < 0. This gives four different linear equations, namely w1 + w2 = C, w1 – w2 = C, –w1 + w2 = C and –w1 – w2 = C. Jointly, these four equations (lines) form a diamond. All points on the diamond share the same L1 norm. All points on the diamond are also referred to as the level set.

- The diamond represents weights with equal L1 norm
- The unique optimal solution obtained by penalizing the L1 norm
- Each diamond denotes the graph of |w1| + |w2| = C, where C is an arbitrary constant
- Different diamonds represent different solutions with different L1 norm

This is not a coincidence; the LASSO penalty introduces an additional preference over sparse solutions. Therefore, the L1 norm promotes sparse solutions for the under-determined system, especially in a high-dimensional setting with many more free parameters than observations.

## 7.3.4 Understanding LASSO

LASSO regression produces a sparse solution and an interpretable model that is less likely to overfit. Robert Tibshirani introduced it in 1996 in his paper titled “Regression Shrinkage and Selection via the Lasso”. Since then, the LASSO penalty has taken off and seen wide applications in many domains that require an interpretable model. Interpretability is an important consideration in the adoption of a functioning model. When trying to understand the decision-making process of a model, we often prefer a less complex model with a relatively small number of factors to help explain the logic and trace the information flow. This is one of the main reasons behind its popularity.

Note that LASSO regression applies to both under-determined and over-determined problems. An under-determined problem refers to the case when there are more free variables (thus weights) than observations when solving a system of linear equations, and an over-determined system is the opposite: more observations than variables. In both cases, we may wish to obtain a sparse solution with minimal selected features yet maintain good predictive accuracy.

When dealing with high-dimensional problems, optimizing using the least squares essentially assumes that all factors are important and, thus, should remain in the final model. When using LASSO, we lift this assumption by keeping only a subset of the original features, assuming that not all variables are relevant. Minimizing the L1 norm of the weights promotes sparsity by highlighting only a few entries in the weight vector besides generating a good fit. For example, suppose we have one model with 50 features and another with 5 features, both of which have the same level of predictive accuracy. We would definitely prefer the second model as it is more interpretable and communicable. Building on the principle of parsimony, we would go with the simplest model that decently describes our data. A sparse model is also more robust as it is less likely to overfit the data.

The hyperparameter lambda controls the sparsity level when minimizing the regularized objective function Q(w) = RSS(w) + λ||w||₁. When λ = 0, it recovers the least squares solution that gives the best linear fit to the training data but is likely to overfit the test data. When λ is pretty big, the model is over-parsimonious and performs badly in both training and test set. Selecting a proper λ is often performed using cross-validation, where a validation set is used to serve as the test set and approximate the generalization error of the model. As shown in figure 7.17, when plotting out the training and validation set error (i.e., MSE) across a sequence of λ, and each λ often corresponds to several folds of validation (called K-fold cross-validation), the λ value with the lowest validation error is selected. Note that the optimal λ selected using the cross-validation procedure tends to produce a less sparse solution than the optimal choice for a sparse solution as the former focuses more on predictive accuracy. Also, note that the x-axis uses the inverse of λ so that the left end indicates a large λ and the right end indicates a small (all the way to zero) λ.

![](img/ee98e91e6845f41077b163bec833ee40_248_0.png)

Figure 7.17 Training and validation error curves for different values of the hyperparameter $\lambda$. As $1/\lambda$ goes from small to big, the validation error curve will display a typical U-shaped curve that transitions from underfitting to overfitting in a typical linear regression problem. The optimal $\lambda$ is selected by minimizing the validation error.

Again, not all values of $\lambda$ lead to a sparse solution. When $\lambda$ is relatively small, the resulting weights are still likely to be all non-zero. A sparse solution will occur when $\lambda$ increases to a specific value, whose increase will incur further sparsity in the resulting weights. Let us revisit the same contour plot in a slightly different context to better appreciate the geometric interpretation behind the LASSO-induced sparsity. This time, we will assume a general setting with many observations instead of one in the previous example. We will still use two weights for illustration purposes.

As shown in figure 7.18, the objective function consists of the RSS term $\sum_{i=1}^N (y_i - w_0 \phi_{i0} - w_1 \phi_{i1})^2$ and the $L1$ norm of the weights $(|w_0| + |w_1|)$, weighted by the hyperparameter $\lambda$. When $\lambda = 0$, the solution is least squares as denoted by the solid dot on the left plot. When $\lambda \rightarrow \infty$, the solution is the origin, denoted by the solid dot on the right plot. The left contour plot consists of ellipses representing different level sets for the weights. For example, when setting the RSS term to a specific constant, we have $\sum_{i=1}^N y_i^2 + w_0^2 \sum_{i=1}^N \phi_{i0}^2 + w_1^2 \sum_{i=1}^N \phi_{i1}^2 + cross terms = constant$, which is exactly the expression of an ellipse on a plot. A bigger constant corresponds to a bigger ellipse. Similarly, we can visualize the level sets as diamonds for the $L1$ norm. Graphically, LASSO regression is thus a weighted combination of an ellipse and a diamond.
