By setting the stride parameter to 2, the kernel will skip the following pixel and "jump" to the one after. A bigger stride will result in a smaller feature map since the number of element-wise multiplications between the kernel and the input patches reduces.

In addition, since the pixels on the border of the image are only convolved once with the kernel, we can adjust the padding parameter to account for this and ensure the same number of interactions with the kernel for all pixels. For example, we can surround the edges of the input image with an additional layer of pixels whose values are all zero. This is called zero padding, or same padding, which adds a padding of zeros around the outside of the input image, and is particularly useful if we can want to preserve the shape/dimension of the input image in the resulting output feature map, so as to capture the information along the edges of the input image. Padding introduces zeros around the edges to enlarge the virtual size of the input matrix.

Note that another advantage of padding is that the dimensions of the image are preserved from layer to layer, and we don't have to worry too much about the dimensions of the tensors.

Figure 6.6 illustrates these two tuning parameters, where we set a padding of 1 and a stride of 2. These parameters are set in advance when defining a convolution layer. They essentially influence the shape of the resulting output array and belong to the increasingly long list of hyperparameters in a neural network. Although achieving the best hyperparameter configuration is a tedious process that requires trial and error, we would normally go with settings that seem to work well in many domains. For example, using 3x3 kernel, zero padding, and a stride of 1 when learning low-level local structures in the early hidden layers.
