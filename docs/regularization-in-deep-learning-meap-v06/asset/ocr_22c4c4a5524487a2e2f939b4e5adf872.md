magnitude of the change. To utilize these two types of information, the gradient descent algorithm adopts the following scheme to iteratively update the weights:

```
w ← w - η∇Q(w)
```

where the ← sign indicates assigning the value on the right-hand side to the left hand side. Using this formula, a new weight vector **w** gets calculated by plugging the current value of **w** in **w** - η∇Q(**w**). η is a small positive number that is often called the learning rate or the step size. It is a hyper-parameter used to control the magnitude of each update. Since the objective is to minimize the cost function, the direction of travel is corrected by the minus sign in the equation. Using this update scheme, the next iteration would always move towards a local optimum.
