### 7.3.5 The soft-thresholding rule

So far, we have been looking at obtaining the optimal weights using the gradient information of the objective function, both in the derivation of a closed-form solution (setting the first derivative to zero) and in the iterative gradient descent algorithm. However, the gradient of the objective function \(Q(\mathbf{w}) = RSS(\mathbf{w}) + \lambda \|\mathbf{w}\|_1\) in LASSO regression is not directly usable.

Specifically, for each \(w_j\) in the weight vector \(\mathbf{w}\), we need to compute the derivative of \(|w_j|\) with respect to \(w_j\), namely \(d|w_j|/dw_j\). When \(w_j > 0\), we have \(|w_j| = w_j\), whose derivative will be 1. Correspondingly, the derivative will be -1 if \(w_j < 0\). However, there is no derivative at the point when \(w_j = 0\), a problem point that rules out the availability of a closed-form solution and the use of a gradient-based optimization algorithm. See figure 7.20 for an illustration on the graph of \(|w_j|\) and its derivative at different values of \(w_j\).

![](img/ee98e91e6845f41077b163bec833ee40_251_0.png)

Figure 7.20 Illustrating the derivative of $|w_j|$ at different values of $w_j$.

To solve for the optimal weight vector, we can use another iterative optimization procedure called coordinate descent, which updates each coordinate/weight one at a time while keeping all others fixed. In particular, the algorithm relies on the sub-gradient of $|w_j|$ when $w_j = 0$. Although the coordinate descent algorithm is not our main focus, understanding its derivation process helps us gain more insight into how LASSO obtains a sparse solution, which is using the soft thresholding rule, an update rule for each coordinate $w_j$. Let us look at how the rule is derived.

Recall that the LASSO objective function is $Q(\mathbf{w}) = RSS(\mathbf{w}) + \lambda||\mathbf{w}||_1 = \sum_{i=1}^N (y_i - \sum_{k=0}^d \Phi_{ik} w_k) + \lambda \sum_{k=0}^d |w_k|$. When using the coordinate descent algorithm, assume we focus on updating the $j^{th}$ weight $w_j$ and keep all other weights $\mathbf{w}_{-j}$ fixed when setting the first partial derivative $\frac{\partial Q(\mathbf{w})}{\partial w_j}$ to zero to obtain the closed-form update for the current coordinate $w_j$. Figure 7.21 illustrates the derivation of the partial derivative for the first term $RSS(\mathbf{w})$. The key difference compared to the previous derivation process is that we keep the term involving $w_j$ separate from the rest, which is assumed to stay fixed and thus give a zero partial derivative. Note that $\rho_j$ could be considered as the correlation between the design matrix and prediction error without $w_j$.

$$\frac{\partial}{\partial w_j} RSS(\mathbf{w}) = -2\Phi_j^T (\mathbf{y} - \Phi \mathbf{w})$$
$$= -2 \sum_{i=1}^n \Phi_{ij} \left( y_i - \sum_{k=1}^d \Phi_{ik} w_k \right)$$
[Separate \( w_j \) with other fixed terms]
$$= -2 \sum_{i=1}^n \Phi_{ij} \left( y_i - \sum_{k \neq j} \Phi_{ik} w_k - \Phi_{ij} w_j \right)$$
[Express \( w_j \) as a standalone term]
$$= -2 \sum_{i=1}^n \Phi_{ij} \left( y_i - \sum_{k \neq j} \Phi_{ik} w_k \right) + 2w_j \sum_{i=1}^n \Phi_{ij}^2$$
[Re-express for notational convenience]
$$= -2\rho_j + 2w_j z_j$$

Where \(\rho_j = \sum_{i=1}^n \Phi_{ij} (y_i - \sum_{k \neq j} \Phi_{ik} w_k)\) and \(z_j = \sum_{i=1}^n \Phi_{ij}^2\)

Figure 7.21 Deriving the first-order partial derivative of RSS with respect to a single weight \( w_j \).

Moving on, let us calculate the partial derivative of the LASSO penalty with respect to \( w_j \). Since the gradient is not available for \( |w_j| \) when \( w_j = 0 \), we can resort to the notation of sub-gradient, which generalizes the gradient to non-differentiable points and refers to all planes (sets of candidates) that lower bound the raw function, in this case \( |w_j| \). Pictorially, as shown in figure 7.22, the sub-gradient at the origin, which is non-differentiable, is a collection of all dotted lines below the function \( |w_j| \). Denoting the sub-gradient as \( V \), we have \( V \in [-1,1] \) when \( w_j = 0 \).

![](img/ee98e91e6845f41077b163bec833ee40_253_0.png)

Figure 7.22 Introducing the sub-gradient at the origin.

Therefore, we can express the partial derivative of \(\lambda|w_j|\) with respect to \(w_j\) into three different cases. When \(w_j < 0\), the partial derivative of the LASSO penalty term is \(\lambda \partial_{w_j}|w_j| = -\lambda\). When \(w_j > 0\), we have \(\lambda \partial_{w_j}|w_j| = \lambda\). When \(w_j = 0\), we have \(\lambda \partial_{w_j}|w_j| = [-\lambda, \lambda]\).

Putting it together, the partial derivative of the objective function with respect to a single weight \(w_j\) can also be expressed in three cases. That is, when \(w_j < 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = 2z_j w_j - 2\rho_j - \lambda\); when \(w_j = 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = [-2\rho_j - \lambda, -2\rho_j + \lambda]\); when \(w_j > 0\), \(\lambda \partial_{w_j} Q(\mathbf{w}) = 2z_j w_j - 2\rho_j + \lambda\). Figure 7.23 summarizes the expression of the sub-gradient.

\(\lambda \partial_{w_j} |w_j| = \begin{cases} -\lambda, & w_j < 0 \\ [-\lambda, \lambda], & w_j = 0 \\ \lambda, & w_j > 0 \end{cases}\)

Sub-gradient of the lasso penalty term

Add \(\frac{\partial}{\partial w_j} RSS(\mathbf{w}) = -2\rho_j + 2w_j z_j\)

\(\lambda \partial_{w_j} Q(\mathbf{w}) = \begin{cases} 2w_j z_j - 2\rho_j - \lambda, & w_j < 0 \\ [-2\rho_j - \lambda, -2\rho_j + \lambda], & w_j = 0 \\ 2w_j z_j - 2\rho_j + \lambda, & w_j > 0 \end{cases}\)

Sub-gradient of the objective function

Figure 7.23 Expressing the sub-gradient of the LASSO penalty and the objective function.

To obtain the optimal solution, we would then set \(\lambda \partial_{w_j} Q(\mathbf{w}) = 0\), which again requires us to consider three different cases. When \(w_j < 0\), we have \(2z_j w_j - 2\rho_j - \lambda = 0\), which gives \(w_j = (\rho_j + \lambda/2)/z_j\) and requires \(\rho_j < -\lambda/2\) (since \(z_j > 0\)). When \(w_j = 0\), we require the range \([-2\rho_j - \lambda, -2\rho_j + \lambda]\) to contain zero, which means \(-2\rho_j - \lambda \le 0\) and \(-2\rho_j + \lambda \ge 0\) need to be satisfied at the same time. This gives \(-\lambda/2 \le \rho_j \le \lambda/2\). When \(w_j > 0\), we have \(2z_j w_j - 2\rho_j + \lambda = 0\), which gives \(w_j = (\rho_j - \lambda/2)/z_j\) and requires \(\rho_j > \lambda/2\). This is also called the soft thresholding rule, where some weights are set to zero and others are shrunken towards zero (by an amount of \(\lambda/2z_j\)).

In other words, when \(\rho_j \in [-\lambda/2, \lambda/2]\), the weight \(w_j\) is shrunken to zero. When either \(\rho_j < -\lambda/2\) or \(\rho_j > \lambda/2\), we add a bias term \(\lambda/2\) to reduce the magnitude of the least squares solution for \(w_j\); that is, when \(\lambda = 0\), the least squares solution is \(w_j = \rho_j / z_j\).
