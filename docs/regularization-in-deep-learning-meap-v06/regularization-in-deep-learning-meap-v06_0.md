# 深度学习正则化 (MEAP V06)







## 欢迎

感谢您购买《深度学习中的正则化》MEAP 版。

在构建机器学习（尤其是深度学习）模型时，最重要的目标之一是在测试数据集上取得良好的泛化性能。当我们获得一个可泛化的模型（通常借助训练过程中的适当正则化）时，训练任务即视为完成。尽管泛化理论至今仍是谜团，但它是一个活跃的研究领域，不断有新见解被提出。

目前，已有大量正则化技术在特定训练场景中被证明在实证上有效。然而，这些资料往往零散且彼此脱节。本书旨在通过对不同正则化技术提供系统且插图丰富的视角来弥合这一差距，涵盖数据、模型、代价函数和优化流程。它更进一步，将最新研究突破与深度学习模型中正则化的实用代码示例相结合。

本书以独特的方式阐述了这一复杂且不断发展的主题。它以插图丰富的方式介绍了最少的数学和技术概念，并通过循序渐进的方式提供实用示例和代码演示。教学设计旨在直观、自然且渐进，而非强行灌输某个特定概念。

希望您阅读本书愉快，并掌握一些实用工具来构建性能更佳的模型。我们也鼓励您在 liveBook 讨论论坛中发布关于本书内容的任何问题或评论。我们非常感谢您告知我们可以改进的地方，以提升您对该主题的理解。
