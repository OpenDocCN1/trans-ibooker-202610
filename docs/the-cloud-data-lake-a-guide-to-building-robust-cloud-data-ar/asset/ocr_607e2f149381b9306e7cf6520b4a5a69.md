In this case, the flash-drive-based storage increased the performance due to a better storage system but didn’t quite solve the problem, so it returned when the dataset increased again. The right solution was to fix the antipattern around small files. Flash-based storage systems are very useful when you have a small set of data that is heavily transacted; the typical scenario here is machine learning.
