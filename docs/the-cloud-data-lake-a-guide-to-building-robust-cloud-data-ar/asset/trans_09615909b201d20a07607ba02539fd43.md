## 云数据湖

组织比以往任何时候都更加理解云数据湖架构对于从数据中获取价值的重要性。但是，考虑到需要将多种工具和选项协同工作，以提供从数据到洞察的无缝端到端管道，构建一个稳健、可扩展且高性能的数据湖仍然是一项复杂的工程。

这本实用书籍简明而全面地介绍了云数据湖的设置、管理和治理。作者Rukmani Gopalan是一位产品管理领导者和数据爱好者，她引导数据架构师和工程师了解云数据湖工作的主要方面，从设计考量和最佳实践，到数据格式优化、性能优化、成本管理和治理。

- 了解基于云的大数据策略为你的组织带来的益处
- 获取设计高性能、可扩展数据湖的指导和最佳实践
- 审视架构和设计选择以及数据治理原则和策略
- 构建随着组织和业务需求增长而扩展的数据策略
- 在云中实现可扩展的数据湖
- 使用基于云的高级分析来从数据中获取更多价值
