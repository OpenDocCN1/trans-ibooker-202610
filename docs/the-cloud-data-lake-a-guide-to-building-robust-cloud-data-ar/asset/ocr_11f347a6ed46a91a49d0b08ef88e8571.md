# Spark cluster configurations

This class of configurations corresponds to the amount of resources, in terms of memory and CPU, that are allocated to the PaaS or IaaS where you run Spark. PaaS will expose this configuration in terms of the resources you can allocate to the drivers and the worker nodes. As a reminder, the driver is the primary orchestrator of the Spark job that determines how the data is distributed to the workers, and the workers perform the actual computations—that is, actually execute the Spark job on a sliver of the dataset that is assigned to them.
