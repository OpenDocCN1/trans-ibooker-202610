## 我为何撰写本书

多年来，我与来自各个行业的数百名客户进行了交流——医疗保健、消费品、零售和制造业，仅举几例——并帮助他们在云上满足大数据分析需求。我还推动了组织本地分析工作负载向云迁移，以实现更好的成本管理并利用机器学习等新兴技术。可以理解的是，每位客户来找我时都有不同的动机和问题。然而，有一个共同点将他们联系在一起：强烈希望从数据中获得价值。五年前我还在与他们讨论大数据分析基础的客户，现在已经发展到运行非常成熟的实现，并在数据湖上运行部分业务关键型工作负载。作为这些对话的一部分，有几个关键问题归结为设置、组织、保护和优化数据湖实现。在理想情况下，这些考虑因素已融入数据湖架构设计中，而在一些不幸的情况下，我们在客户出现问题被迫重新架构或重新设计时才讨论这些问题。

利用云数据湖无限可能性的承诺，伴随着理解和处理构建和运营云数据湖应用所涉及复杂性的另一面。我相信，虽然行业在随着时间的推移简化这一过程，但对云数据湖解决方案概念的基础理解，对于构建经得起时间考验的稳健数据湖架构大有裨益。我非常享受帮助我的客户、合作伙伴和团队建立这种基础理解，并看着他们完全获得能力，为其团队或组织推动变革性洞察。

在本書中，我希望将所有这些对话和相关经验教训凝练成一种方法，为数据从业者提供帮助，让您设计出可扩展的云数据湖架构，从而为您的业务提供信息并实现转型。

## 谁应该阅读本书？

本书主要面向希望全面了解设置和运营云数据湖各个方面的数据架构师、数据开发人员和数据运维专业人员。阅读完本书后，您将了解以下内容：

- 组织采用云端大数据战略的好处
- 架构和设计选择，包括现代数据仓库、数据湖仓和数据网格
- 设计高性能和可扩展数据湖的指导和最佳实践
- 数据治理原则、策略和设计选择

无论您是迈出第一步还是希望在云上现代化您的数据湖，我希望您能够准备好与您的云服务提供商和工程团队进行有见地的设计对话，并能够就时间、精力和金钱方面的工程投资进行规划和预算。大数据分析是开发、技术和范式转变在眨眼间发生的领域之一。对我来说，这说明了现在可能实现的丰富机会。我将保持对任何特定技术的中立考虑，因此当新技术出现时，我们将能够在所有可用技术选择的背景下应用这些基础知识。

## 介绍 Klodars Corporation

在本書中，我们将把云数据湖的概念应用于一个虚构组织 Klodars Corporation，以利用一个大多数人都能产生共鸣的业务问题来最好地说明它们。

Klodars Corporation 是一个虚构的组织，在华盛顿州西雅图销售雨伞和雨具（陈词滥调吗？）。除了网站销售外，Klodars 还雇佣销售人员联系零售商，在西雅图地区批量分销其雨伞。它有一个小型软件开发团队，编写应用程序来管理库存和销售，利用运行在办公室维护的服务器上的 SQL Server 作为运营数据库。它还利用 Salesforce 来管理其客户资料和互动。

由于其雨具的质量和出色的销售渠道，Klodars Corporation 正在华盛顿州乃至邻近的俄勒冈州和爱达荷州迅速扩张。其面向消费者的直接业务通过其网站蓬勃发展，其市场部门在社交媒体上开展了出色的营销活动。此外，Klodars 希望根据客户需求扩大业务，销售冬季装备。因此，它计划收购另一家销售冬季装备的企业。虽然这对业务来说是令人振奋的消息，但它正处于这样一个转折点，即其数据库技术无法完全满足不断增长的需求，并且正在评估向云迁移。
