##### Reddit Access

Log in to your Reddit account via a web browser and, if you haven’t done so already, subscribe to a couple subreddit topics you’re interested in. Use the Search field on the Reddit home page to find subreddit topics you may be interested in following. Verify that it successfully prints out your Reddit username. If it fails, make sure your app and user account credentials were correctly copied without spaces in the GOES_HERE placeholder text. Also confirm that your Pi is connected to the Internet.

Notice when the script runs successfully the Terminal will initially print out Your Reddit username is... and wait a few seconds before finally printing out your username. That’s because we’re making a nonblocking asynchronous call to authenticate to and retrieve data from Reddit. That’s also why the structure of this script looks different from any others we’ve run thus far in the book.

We could have used the standard PRAW[83] library instead of the new and improved Async PRAW, but because we need the functionality of PRAW in a Discord bot, the results awaiting to be received and displayed by our bot must be asynchronous. This allows our bot to continue to do things while it waits for results to return from our calls to Reddit.

Depending on server load, number of submissions, amount of data returned, and other factors, this can be right away or take several or more seconds to complete. If we didn’t make these function calls asynchronous, our script would come to a standstill, waiting for all the results to be received before executing any other instructions. Doing so would make our bot unresponsive



and, in a worst case scenario, crash entirely.

在 Python 中使用异步库需要额外的规划以及对 Python 的 async 和 await 关键字有更深入的理解。幸运的是，我们为完成本项目所需的脚本易于阅读和使用，无需深入 Python 异步调用的深处。但如果你打算构建更复杂的机器人或脚本，这些脚本需要在等待第三方网络服务返回结果的同时保持运行，请投入时间学习更多[84]关于 Python 3.7 及更高版本中的异步编程。

##### 将密码替换为刷新令牌

为了保持良好的安全标准，并让开发者能够在无需删除用户账户的情况下撤销受损的安全密钥，Reddit 采用了身份验证令牌来代替用户名和密码，以对应用程序及其用户进行身份验证。

如果你打算与其他人共享脚本的功能，或担心将明文 Reddit 用户名和密码通过 Async PRAW 使用的各种 Python 库传递，考虑创建 *refresh token*。这个唯一密钥在生成时需要多做一些工作，但这样做可以使你的 Reddit 应用程序更安全。

如果令牌因任何原因被泄露，只需重新生成一个新令牌即可；无需删除用户账户，尽管在怀疑发生安全漏洞时更改账户密码仍然是良好的安全实践。虽然生成刷新令牌超出了本书的范围，但如果你注重安全，我强烈建议你通过阅读 Async PRAW 文档进一步深入该主题。[85]

##### 显示新 Reddit 帖子的标题

Async PRAW 使与 Reddit 内容的交互变得简单。得益于这个强大的 Python 库，我们可以用几行代码遍历子版块中所有最近发布的帖子。现在通过创建一个名为 reddlist.py 的新 Python 脚本文件并填充以下代码来实现：

```
redditbot/reddlist.py

import asyncio
import asyncpraw

async def main():
    reddit = asyncpraw.Reddit(client_id="APP_CLIENT_ID_GOES_HERE",
        client_secret="APP_CLIENT_SECRET_GOES_HERE",
        password="REDDIT_USER_PASSWORD_GOES_HERE",
        user_agent="RedditBot",
        username="REDDIT_USERNAME_GOES_HERE")

    async for mysubreddit in reddit.user.subreddits(limit=None):
        current = mysubreddit.display_name
        print('Subreddit: ' + current)
        subreddit = await reddit.subreddit(current)
        async for submission in subreddit.new(limit=20):
            print(submission.title)

    await reddit.close()
```

```
if __name__ == "__main__":
    loop = asyncio.get_event_loop()
    loop.run_until_complete(main())
```

让我们更仔细地查看检索订阅子版块列表然后遍历每个子版块以获取新帖子列表的指令。

- ① 使用 for 循环遍历当前用户订阅的每个子版块。
- ② 每次遍历订阅的子版块时，打印正在处理的当前子版块名称。
- ③ 同样，遍历当前正在遍历的子版块中发布的每个新帖子。请注意，我们将处理的最新帖子总数限制为 20。此数量最多可提高到 50 个新帖子，但检索文章标题所需的时间会更长。你订阅的子版块越多，此脚本整体执行所需的时间就越长。

##### 隐藏新 Reddit 帖子

创建一个名为 reddhide.py 的新 Python 脚本并复制以下代码到其中：

import asyncio
import asyncpraw

async def main():
    reddit = asyncpraw.Reddit(client_id="APP_CLIENT_ID_GOES_HERE",
        client_secret="APP_CLIENT_SECRET_GOES_HERE",
        password="REDDIT_USER_PASSWORD_GOES_HERE",
        user_agent="RedditBot",

##### 机器人交互

使用 discord Python 库构建 Discord 机器人是一件简单的事情。在 Python 脚本中导入 discord 库后，你只需要实例化一个机器人对象并传递在机器人应用程序配置期间生成的令牌即可。discord Python 库利用了一个很酷的 Python 特性叫做装饰器^[89]^，它像一个函数或类一样工作，包装另一个函数或类并改变其行为。这不仅允许多个函数和类的链式调用，而且装饰器语法使 Python 代码免于不必要的复杂性和冗长。

对于我们的 Discord RedditBot，我们需要它响应三种不同的输入：

- !list
- !hide
- !clear

!list 将调用我们之前编写的子版块提交标题例程。此外，为了使此结果更有用，我们将嵌入对提交中引用的网页的网页链接。这将允许 RedditBot 用相应的超链接突出显示标题结果。

!hide 将调用我们之前编写并测试过的子版块隐藏提交例程。当发出此命令时，最近的二十个新提交将被标记为隐藏。这样，它们将不再出现在后续的 !list 请求中。

!clear 将收件箱零实践扩展到 Discord 频道。那些喜欢在频道中保留旧 Discord 帖子的人很可能也是那些不在乎在收件箱中看到成千上万封已读邮件的人。虽然你可以选择永远不调用此函数，但它会在你需要清理 #reddit 频道时提供帮助。

使用装饰器，Python discord 库允许简单地创建这些命令并将它们分配给实例化的机器人对象。可以包含命令别名和帮助消息的附加参数。例如，在使用 RedditBot 一段时间后，每次需要清除频道中的过去消息时都必须输入 !clear 会很麻烦。分配像 !c 这样的别名会更快并实现相同的目标。

牢记这些基本准则，你可以使用 @bot.command 装饰器创建一个新的机器人命令。以下是列表命令的机器人命令分配：

```
@bot.command(name='list', aliases=['l'], \
help='List new posts in subscribed reddits.')
```

一旦定义了命令，它就需要有一个对应的函数来调用，同时传递机器人交互的频道的上下文。例如，这里是 reddlist() 函数从我们之前编写的 reddlist.py 脚本中复制而来，分配给 !list @bot.command()：

            embed = Embed(title=submission.title, url=submission.url)

前往你的 Discord 桌面、智能手机或网页应用并访问 #reddit 频道。你现在应该能看到你的 RedditBot 在线并准备交互。通过发送 !help 消息刷新可以提交给它的命令列表。借助于我们在各自命令初始化中包含的帮助语句，RedditBot 应该会回复它能够处理的命令列表。发送一个 !list 命令。如果有任何新的、未隐藏的提交可用，RedditBot 将列出这些提交标题以及指向其引用的网页的超链接。发出 !hide 命令以隐藏这些提交，使其不再在未来的 !list 请求中显示。最后，提交一个 !clear 命令以清除你在 #reddit 文本频道中发布的内容。这一条命令比手动右键单击每一行并从相应的弹出菜单中选择 Delete message 要容易得多。

我真的很喜欢 RedditBot 显示的 Messages deleted 条目自行清理的方式，它在发布后四秒钟删除自己的消息，正如这行代码所定义的那样：

```
ctx.send('Messages deleted.', delete_after=4)
```

在 Supervisor 中设置脚本以便在你的 Pi 启动时自动运行并在后台保持运行，准备随时处理你的下一个 Reddit 查询，真是创建你自己的自定义 RedditBot 的出色工作！所有剩下的工作就是：

```
redditbot/redditbot.conf

[program:redditbot]
directory = /home/YOURUSERNAME/projects/redditbot
command = /usr/bin/nohup /usr/bin/python3 redditbot.py &
user = YOURUSERNAME
environment=HOME="/home/YOURUSERNAME",USER="YOURUSERNAME"
autostart = true
autorestart = true
stdout_logfile = /var/log/supervisor/redditbot.log
stderr_logfile = /var/log/supervisor/redditbot.log
```

重启 Supervisor 服务或重启你的 Pi 以运行脚本。使用你喜欢的任何 Discord 应用（桌面、移动、网页）验证你的 RedditBot 是否在线，然后尽情使用命令吧！
