Next, install the Python-based Streamlink application using pip3 in a Terminal window:

```
$ sudo pip3 install streamlink
```

Running this command will install Streamlink and the additional third-party Python libraries it depends on to function correctly. You can check to see which version of Streamlink was installed by asking for its version in the Terminal:

```
$ streamlink --version
streamlink 2.0.0
```

Streamlink is a powerful and flexible command-line utility that gives users the ability to redirect media streams like those used by Twitch and YouTube to media players like VLC. Due to its flexibility, the number of arguments capable of being passed to the streamlink command can be daunting. You can learn more about the variety of parameters that can accompany the streamlink commmand by reading the program’s User Guide.[32] While there are literally dozens of parameters that can be used, we’ll focus on specific Twitch arguments for this project.
