Before you can query the data that the SensorHub is collecting, you must enable the Pi’s ARM I2C kernel module. Do so via the raspi-config program:

```
$ sudo raspi-config
```

Select Option 3, Interface Options from the main menu, and then choose the P5 I2C menu option to Enable the automatic loading of I2C kernel module.
