# IFTTT

Grant https://ifttt.com/ access to your Pushbullet profile and data.

![](bbox=[0.25, 0.46, 0.52, 0.515])

Enter the message you want Pushbullet to send to the Pushbullet listener script we have yet to create. The title is optional and isn’t something we’re going to parse, anyway. As a placeholder, you can add Google Voice Command or something more descriptive if you prefer. It’s the body of the message that we’ll be parsing in the script, so it’s not necessary to make this a long message. Something like WAKE_PC is more than adequate and distinct for our needs, as shown in this next screenshot.
