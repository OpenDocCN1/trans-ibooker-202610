Finally, we instruct the pbapp instance to run_forever(), or at least until we escape out of the program via the Ctrl+Z keyboard combination.

Save and run the pbreceiver.py Python script:

```
$ python3 pbreceiver.py
```

With the script running, ask your smart assistant to “Turn on the computer,” and a few seconds later, you should see the message body print out on the Terminal:

```
Latest message body received:
```

```
WAKE_PC
```

If you don’t see any message appear, log in to the IFTTT website and double-check the configuration. View the applet’s activity to make sure it ran and sent the WAKE_PC text in the body of the Pushbullet note. Verify that the pbreceiver.py script is working correctly before proceeding. You can quit the program by escaping the running script or simply closing the Terminal window it’s running in.
