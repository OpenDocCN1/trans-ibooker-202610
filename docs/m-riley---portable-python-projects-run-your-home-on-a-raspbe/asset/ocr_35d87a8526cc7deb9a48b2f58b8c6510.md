Check your network router’s ability to assign IP addresses based on device MAC addresses. Every router manufacturer does this in their own way. For example, on my Google Home WiFi setup, I have to go into the Advanced networking settings and select the DHCP IP Reservations to locate and add my Pi. Should the Pi ever go offline for an extended duration or connect to another DHCP-based network, I don’t have to worry about the Pi acquiring a different IP address from my router since it will always be assigned the same one set in the router’s IP Reservations. Doing so will also make it much easier to securely remotely connect to the Pi, as well as store and execute new scripts on it, because it will always have the same IP address assigned to it.
