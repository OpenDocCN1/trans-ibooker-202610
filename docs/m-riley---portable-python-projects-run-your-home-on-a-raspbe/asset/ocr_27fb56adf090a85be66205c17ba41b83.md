Let’s do a quick review of some of the new code fragments in this final version of the RedditBot codebase.

+   ① Initialize the bot object and assign the exclamation point character as the identifier to precede a bot command. You can change this character to anything you prefer, but the common Discord bot practice is to use an exclamation point.

+   ② The routines for listing new subreddit submissions and hiding those submissions were copied straight from the previously written reddlist.py and reddhide.py scripts.

+   ③ For the !clear bot command, the channel.purge function is called, with a limit of 100 prior text messages to be searched through and potentially removed. Only messages that are less than two weeks old will be deleted when this command is issued.

+   ④ The @bot.event responds to events that may occur, such as errors. In the event that the bot receives an undefined command such as using !show in place of !list, the bot responds with I don’t understand that command.
