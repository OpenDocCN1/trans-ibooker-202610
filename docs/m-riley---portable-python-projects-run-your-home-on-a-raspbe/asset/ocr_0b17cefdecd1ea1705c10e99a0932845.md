⑥ Add a few extra timers and system calls to account for the number of Streamlink subprocesses being unexpectedly closed when we terminate the VLC player. If you commented out these commands via the # character and ran the script, you would likely see a slew of errors appear in your Terminal when the script terminates. The time.sleep(5) function waits five seconds before calling the os._exit(-1) and sys.exit(-1) functions. Doing so accomplishes the objective of gracefully quitting the stream and closing the player.
