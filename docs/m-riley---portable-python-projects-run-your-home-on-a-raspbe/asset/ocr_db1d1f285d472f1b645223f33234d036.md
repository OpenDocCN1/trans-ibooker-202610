# Water Leak Notifier

As demonstrated in our previous project, the Pi can be used as an inexpensive laptop or desktop replacement, capable of running Python scripts that can also run on other operating systems. What makes the Pi so interesting in the home automation world is its diminutive size and expansive ports and GPIO pins. Sensors and actuators can be attached to the Pi via these interfaces, giving the Pi a wide spectrum of inputs to process. One of the simplest of inputs is a switch.

For this project, we’ll use a very basic water sensor that turns on (completes or closes an electrical circuit) when water is detected across its two probes and turns off (breaks or opens an electrical circuit) when water is no longer present across both probes. To make this switch more useful, we’ll write a Python script that not only detects if the switch is on or off but also sends an email when water is detected.
