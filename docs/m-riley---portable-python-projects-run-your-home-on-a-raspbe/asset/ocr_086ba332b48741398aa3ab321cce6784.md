# Move It

The last objective is to programmatically move the faster.mp3 file into the GoogleDrive folder that was created when Rclone was configured in Rclone. To do so, call upon Python’s built-in shutil library to move and rename the file. Create a movefile.py Python script in the same directory as the faster.mp3 file and use the following code to move the file into the GoogleDrive folder:

```
pispeak/movemp3file.py
① from pathlib import Path
import platform
import shutil
② homedirectory = str(Path.home())
③ if platform.system() == 'Windows':
    syncfolder = '\\GoogleDrive\\'
else:
    syncfolder = '/GoogleDrive/'
④ mp3name = "faster.mp3"
⑤ mp3destination = homedirectory + syncfolder + mp3name
⑥ shutil.move(mp3name, mp3destination)
```

Let’s do a quick review of the listing before we run the script.

+   ① Import the necessary pathlib, platform and shutil Python libraries used to identify the current working and home directory paths and operating system that the script is running on.
+   ② Convert the Path.home() object into a string to obtain the file path to the current user’s home directory.
+   ③ Call the platform.system() function to see what operating system is running
