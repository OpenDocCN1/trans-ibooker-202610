Return to your Terminal window to map and mount your configured Rclone’d Google Drive to the newly created ‘GoogleDrive‘ folder using the following command:

```
$ rclone --vfs-cache-mode writes mount GDrive: ~/GoogleDrive
```

This command tells Rclone to allow cached writes and mount the Google Drive to the GoogleDrive folder that was created. Assuming everything was entered correctly, you should now see a Google Drive icon appear on your desktop.
