# Setup

Here’s what you need to build this project.

# Hardware

+   - Smartphone, Mac, or PC running the official Discord app

# Software

+   - Async PRAW:[77] the Asynchronous Python Reddit API Wrapper
+   - Discord[78] Python library

# Services

+   - Discord[79] user account (free)
+   - Reddit[80] user account (free)

Install the two necessary Python library dependencies for the project.

```
$ sudo pip3 install asyncpraw
```

```
$ sudo pip3 install discord
```

With the Python dependencies installed, we’re ready to start coding.
