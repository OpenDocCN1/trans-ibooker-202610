# Where can I learn more about how to use Git?

Git is a very powerful source control system that has many more features and commands beyond the simple clone, add, commit, and push commands used in our projects. As your code becomes more sophisticated and you want to try out different ideas, you can create additional branches to your files to test without affecting the main source files. Branching comes in handy when you have other people contributing to your project. You can learn more about Git by visiting the Git website.[19]
