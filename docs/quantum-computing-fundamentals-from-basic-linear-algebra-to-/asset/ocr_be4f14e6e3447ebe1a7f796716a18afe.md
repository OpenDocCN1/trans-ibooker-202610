# 1.1 What Is Linear Algebra?

It seems like a rather elementary question, but it is a good place to start our examination of linear algebra. Again, this chapter does not assume any prior knowledge on the part of the reader. While linear algebra has applications in many fields, including quantum physics, it began as a way to solve systems of linear equations (thus the name). Linear equations are those for which all elements are of the first power. Thus, the following three equations are linear equations:

```
a + b = 20
2x + 4 = 54
2x + 3y - z = 21
```

However, the following are not linear equations:

```
2x^2 + 3 = 10
4y^2 + 2x + 3 = 8
```

The first three equations have all elements to the first power (often with a number such as x^1, the 1 is simply assumed and not written). However, in the second set of equations, at least one element is raised to some higher power. Thus, they are not linear.
