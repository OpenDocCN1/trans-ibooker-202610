# 2.3 Complex Numbers Graphically

It is often helpful to view complex numbers graphically. The way this is generally done is to use a typical Cartesian coordinate system, as you see in Figure 2.2.

![](bbox=[0.066, 0.222, 0.433, 0.508])

FIGURE 2.2 Cartesian coordinate system

The x-axis is used for real numbers, and the y-axis for imaginary numbers. This is fairly easy to use. A pure real number such as 3 would simply appear on the x-axis as shown in Figure 2.3.

![](bbox=[0.066, 0.643, 0.433, 0.928])

FIGURE 2.3 Plotting the number 3
