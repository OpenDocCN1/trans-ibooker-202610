Now we turn to something that should remind you of Chapter 1. Let us determine precisely how far our point 3 + 2i is from the origin (0, 0). Just as when working with vectors, we will use the Pythagorean theorem. Given a complex number z, the length of z from the origin is the absolute value of z, or |z|. This is typically $\sqrt{a^2 + b^2}$. In this case it is

```
$\sqrt{(3)^2 + (2i)^2}$
3^2 = 9
i^2 = -1
Thus, 2i^2 = -2
So, |z| = \sqrt{9-4}
|z| = \sqrt{5}
|z| = 2.2361
```

If you look at the graph, this actually seems intuitively correct. That appears to be about the length of the vector. It must also be noted that |z| is always a nonnegative number. Thus, if the formula leads to a negative answer, then the positive should be used. Consider this example:

```
4 + 4i
```
