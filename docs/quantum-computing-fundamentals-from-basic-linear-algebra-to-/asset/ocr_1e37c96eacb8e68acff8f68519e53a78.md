# 10.8 Summary

This chapter examined several quantum algorithms. This chapter is likely to be one that was difficult for many readers. You might need to read it more than once before continuing. Many of these algorithms you will see again in later chapters, and actually coding them might clarify the algorithms for you. The algorithms most important for you to understand from this chapter are Deutsch, Shor, and Grover’s algorithms.
