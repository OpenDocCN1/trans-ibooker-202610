This should now remind you of the Pythagorean theorem: a² + b² = c².

Let us try this with another example that should help clarify this situation for you:

z₁ = 7 + 3i
z₂ = 2 – 2i

Recall from earlier in this chapter the basic form:

```
\sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2}
```

Thus, in our specific example, this would be the following (notice we are not worried about the i itself, just the real coefficient):

```
\sqrt{(2-7)^2 + (-2-3)^2}
= \sqrt{(-5)^2 + (-5)^2}
= \sqrt{25+25}
= \sqrt{50}
= 7.07
```
