

## 9.5.2 测量平面

有些人会将测量平面视为量子数据平面的一部分；然而，它至少在概念上是分离的。

这是负责测量量子比特的硬件。

这有时也被称为控制和测量平面。

此测量平面负责执行量子比特操作所需的控制信号，以及接收和处理量子比特测量的输出。

### 9.5.3 控制处理器平面

此层识别并触发特定的门操作以及测量。

换句话说，控制处理器平面将执行由主机处理器提供的程序代码。

有些来源称其为控制处理器平面和主机处理器，这是由于与处理器的紧密耦合。

## 9.6 量子网络

量子网络与量子计算机密切相关。

这与经典计算机与传统计算机网络之间的关系非常相似。

量子网络背后的概念是利用量子物理学传输信息。

量子网络上的节点是一个或多个量子比特的量子处理器。

通信线路可以各不相同，但已使用光纤。

如果要与超过两个节点进行通信，则需要切换机制。

第 7 章“量子纠缠和 QKD”讨论了量子密钥交换。

类似技术也可用于量子通信。

交换的不是密钥的比特，而是消息的比特。

### 9.6.1 东京 QKD

东京 QKD 网络是一个使用与量子密钥交换类似技术的量子网络示例。

该网络采用三层架构。

量子层由生成安全密钥的点对点量子链路组成。

中间层负责密钥管理。

然后，通信层处理安全视频链路等标准通信。

本质上，该网络依赖量子层来实现安全性。

通过在东京大手町（东京的一个区）和小金井之间设置安全电视会议，已证明了这一点。

### 9.6.4 分布式量子计算

分布式量子计算是量子网络的一种应用，目的略有不同。

其目标不是通信数据，而是协调计算。

本质上，量子处理器通过某种量子网络相互连接。

这允许组成处理器之间交换量子比特。

本质上，这是在创建量子集群计算。

这不仅像经典计算机集群那样易于扩展，而且可能有助于对抗退相干。

随着量子处理器变得更加复杂，退相干更难以控制。

拥有共享数据的较小量子处理器，使控制每个处理器的相干性更加容易。

### 10.1 什么是算法？

虽然这可能看起来是一个过于吹毛求疵的话题，但并非所有读者都有严格的计算机科学背景并熟悉算法和算法分析等主题。

第 4 章为你提供了算法的简单定义和对算法分析的基本理解。

在深入研究量子算法之前，加深对算法的理解（或者对一些读者来说，复习）很重要。

第 4 章将算法定义为本质上是一份食谱，这是一种通俗的定义。

虽然不不准确，但这实在太不正式了。

在数学中，算法是解决问题或一类问题的一组明确定义的有限指令序列。

引用我最喜欢的算法教科书之一的话：“从通俗地说，算法是任何明确定义的计算过程，它以某个值或某组值作为输入，并产生某个值或某组值作为输出。

因此，算法是将输入转换为输出的一系列计算步骤。”1

算法必须是明确的。

这意味着步骤清晰且定义明确，输出基于输入可预测。

这与第 4 章的食谱类比相符。

算法为完成某项任务提供清晰的逐步过程。

算法的具体步骤必须是一组明确定义的有限步骤序列。

既然你对什么是算法有了更清晰的理解，让我们来讨论几个关于算法的问题。

算法是否正确实际上是一个非常简单的问题。

如果对于每个输入，算法在一致地找到正确输出时停止，那么该算法就是正确的。

事实上，“一致地”一词可能有点过于苍白。

算法应该可靠且始终产生正确的输出。

“一致地”不一定意味着“每次”，算法应该每次都能正常工作。

显然，我们关注的是计算机算法，随着本节的推进，我们将研究几个算法——更具体地说，是量子算法。

但是，必须指出，算法可以以多种形式表达，包括使用你偏好的语言的词语。

上述食谱是一个算法。

完成任何任务的特定步骤集是一个算法。

欧几里得算法是一个经典算法，阐明了算法的本质。

对于数学和计算机科学专业的学生，这将非常熟悉。

欧几里得算法是一种发现两个整数最大公约数的方法。

这可能看起来是一项微不足道的任务，但随着整数变大，问题很快就会变得重大。

欧几里得算法进行一系列明确定义的步骤，使每个步骤的输出作为下一个步骤的输入。

设 n 为计算算法步骤的整数，从零开始。

因此，初始步骤对应 n = 0，下一个步骤对应 n = 1，以此类推。

第一步之后的每个步骤都从前一步的两个余数 r_{n-1} 和 r_{n-2} 开始。

你会注意到，在每个步骤中，余数都小于前一步的余数，即 r_{n-1} 小于其前驱 r_{n-2}。

这是有意为之，也是算法运作的核心。

第 n 步的目标是找到商 qn 和余数 r_n，使得方程

```
r_{n-2} = q_n r_{n-1} + r_n
```
