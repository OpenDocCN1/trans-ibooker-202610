- 量子步骤 1: 初始化寄存器。
- 量子步骤 2: 构造 f(x) 量子函数并将其应用于状态。

## 10.7 格罗弗算法

格罗弗算法本质上是一种搜索算法。它由洛夫·格罗弗于 1996 年开发。当然，本节稍后我们还会探讨其他关于它的描述，但目前，您可以将其视为一种搜索算法。为了解释算法的工作原理，请考虑一个具有 N 个条目的未排序数据存储。给定 N 个元素，经典查询的最坏情况是需要 N 次查询。平均情况是 N / 2。格罗弗算法的工作复杂度为 √N，这比经典方法有了显著改进。

现在要在我们的 N 个元素数据存储上使用格罗弗算法，我们需要进行一些初始设置。必须有一个 N 维状态空间，由 log2N 个量比特提供。我们将此状态空间称为 H。现在我们将数据存储中的每个条目从 0 编号到 N - 1，类似于编程中的任何标准数组。然后，我们必须选择一些作用于状态空间 H 的可观测量。许多来源用符号 Ω 表示该可观测量。该可观测量必须具有 N 个特征值，且均已知。Ω 的每个特征态编码数据库中的一个条目。特征态使用 bra-ket 表示法表示：

{|0>, |1>, |2>, ..., |N - 1>}

当然，特征值的表示方式也类似：

{λ0, λ1, λ2, ..., λN-1}

现在我们需要一个算子，用于根据某些标准比较数据库条目。格罗弗算法未指定该算子或其标准。这将根据特定的数据存储和搜索来选择。但是，该算子必须是一个通过态叠加来工作的量子子程序。该算子通常表示为 Uω。

当我们的算子作用于前面提到的特征态（我们将其表示为 |ω>）时，具有以下属性：

Uω|ω> = -|ω>

但是，对于所有不是 ω 的 x，我们希望有以下关系：

Uω|x> = |x>

换句话说，我们试图识别 Uω 对其作用方式与其他特征态不同的特定特征态 |ω>。或者，我们可以识别与该特征态相关的特征值。该算子 Uω 通常被称为量子预言机。它是作用于两个量比特的幺正算子。这定义了 Uω 算子。

还有一个算子，即 Us。s 是可能态的叠加（我们稍后将详细讨论）。该算子为

Us = 2|s><s| - I

现在我们已经建立了初步条件，让我们来看算法的具体步骤。第一步是将系统初始化到一个状态。该状态通常表示为以下叠加态：

|s> = 1/√N ∑^{N-1}_{x=0} |x>

不要被这个看似复杂的公式吓倒。我们只是说明状态 |s> 是所有可能态 |x> 的叠加。

现在我们执行一个称为格罗弗迭代的步骤 r，并且执行 N 次。这个步骤 r 只是应用算子 Uω 并应用算子 Us。这两个算子之前已经描述过。

现在第三步是执行可观测量 Ω 的测量。这次测量将提供一些特征值 λω。随着我们不断迭代，最终会得到正确的答案。步骤总结如下：

- 步骤 1. 将系统初始化到一个状态。
- 步骤 2. 执行迭代 r(N) 次。
- 步骤 3. 执行测量。

格罗弗算法的有效性已在数学上以多种方式证明。它是确认一旦退相干问题得到解决，量子计算机将带来的算力的算法之一。

当前的非对称算法全部基于某些计算上难以求解的数学问题。更准确地说，这意味着无法在多项式时间内求解的问题。然而，已经证明，许多此类问题可以由量子计算机在多项式时间内求解。这对当前的网络安全构成了重大威胁。在后续章节中，我们将探讨已被提议为抗量子标准的算法。在本章中，我们将详细探讨最当前且广泛实现的非对称算法。这将使您全面了解相关问题。

一些读者可能不完全清楚什么是多项式时间。如果完成算法所需的步骤数为 O(n^k)（其中 k 为某个非负整数），则该算法可在多项式时间内求解。n 表示输入的复杂性。回顾第 4 章《面向量子计算的基础计算机科学》中关于数组的讨论。许多处理数组的算法使用 n 作为数组大小。任何可以由多项式时间算法求解的问题都被视为可处理问题。

## 11.1 RSA

RSA 可能是当今最常用的非对称算法。它无疑也是最广为人知的算法之一。该算法最早于 1977 年由罗纳德·里维斯特、阿迪·沙米尔和伦纳德·阿德曼发表。RSA 名称取自每位数学家姓氏的首字母。该算法基于将大数分解为其质因数的困难性。使用当前经典计算机，对大整数已知最有效的分解算法是一般数域筛法。回顾第 4 章中关于计算复杂性和大 O 表示法的讨论。一般数域筛法的复杂度如下：

O{exp{C(log n)^{2/3}(log log n)^{2/3}}}

即使该表示法看起来有些令人生畏，也请牢记，它不是一种高效算法。这就是 RSA 足够安全以供当前使用的原因。现在让我们深入探讨 RSA，以更好地理解为什么整数分解是 RSA 安全性的关键。对于有兴趣了解更多一般数域筛法的读者，它是分解大整数最有效的经典算法。有关更多详细信息，您可以查阅以下资源：

https://citeseerx.ist.psu.edu/viewdoc/download?doi=10.1.1.219.2389&rep=rep1&type=pdf

https://mathworld.wolfram.com/NumberFieldSieve.html

要探讨 RSA，让我们从密钥生成开始。要创建公钥和私钥对，第一步是生成两个大小大约相等的大随机质数 p 和 q。您需要选择两个数字，使得它们相乘后的乘积为您想要的大小（例如，2048 比特、4096 比特等）。

下一步是将 p 和 q 相乘得到 n。这是一个相当简单的方程：

n = pq

第三步是分别对这两个质数（p 和 q）的欧拉函数相乘，以得到 n 的欧拉函数。
