首先，定义一个我们称之为 E 的子集：

```
E := { -⌊q/4⌋,...,⌊q/4⌋ } of Zq = { -(q-1)/2 ,...,(q-1)/2 }
```

该函数是 E 补集的特征函数。“特征函数”一词在不同语境下可能有不同含义。在这种情况下，它是一个子集的指示函数。“指示函数”一词表示该函数指示元素是否属于该子集。如果值是子集的成员，则返回 1；如果值不是子集的成员，则返回 0。实际的信号函数 (S) 如下：

```
S(v) = 1 if v ∈ E; S(v) = 0 if v ∉ E
```

```

```

```

```

## 13.3 求解格问题

随后会应用诸如 Lenstra-Lenstra-Lovász (LLL) 或 Block-Korkine-Zolotarev (BKZ) 之类的格基约减算法，其目的是将 B 矩阵基约减为形成同一格的另一基，但该基的“基长度”更小。格约减算法通常基于 Gram-Schmidt 正交化和分解。

格基约减的概念相对简单。给定某个整数格基作为输入，尝试找到另一基，其向量更短且近似正交。回顾我们之前关于基向量的讨论。试图找到另一基向量，它更短，但除此之外与用于此格的向量非常相似。这创造了一个比原始问题更容易求解的数学问题。当应用于密码学时，它提供了一种有概率推导私钥的方法。

本章的目标不是专注于格约减，而是向你介绍该过程在格密码学中的应用。为了读者的启发，提供了一个关于 LLL 的完整小节，包含大量细节；然而，这只是一种格约减算法。还有其他算法，例如 Block-Korkine-Zolotarev (BKZ)、Seysen Reduction 等。对此类算法也有相当大量的研究。

### 13.3.1 Lenstra-Lenstra-Lovász (LLL)

LLL 在多项式时间内找到一个近似短向量，保证其在实际最短向量的 (2/3) n 倍因子以内。LLL 生成一个格的“约减”基，结果包含一个近似短基向量。该算法的细节也会相当复杂，但大多数读者仍可跟上其大致轮廓。首先，有必要介绍一些预备知识。存在一个格 L 和一个基 B = {b₁, b₂, ..., b_d}，其具有 n 维整数坐标，且 d ≤ n。LLL 算法计算一个约减的格基。

此 Gram-Schmidt 正交基可表示如下：

```
B* = {b1*, b2*, ..., bn*}
```

一旦有了基 B，下一步就是定义其 Gram-Schmidt 过程正交基。对于不熟悉它的读者，Gram-Schmidt 是正交归一化一组向量的过程。Gram-Schmidt 过程取一组有限的线性无关向量，并生成一组正交向量，该组向量张成与原始集合相同的 k 维子空间。

接下来是投影算子的使用。在线性代数中，投影是从向量空间到其自身的线性变换 P，使得如果投影算子 P 应用两次，结果与应用一次相同 P2 = P。这种操作被称为幂等。幂等性是算子可以多次应用，且首次应用后结果不再改变的属性。顺便提一下，“幂等”一词源自 idem，意为“相同”，以及 potent，表示力量或能力。因此，该词字面意思是“相同的力量”。

方程 13.16 显示了 Gram-Schmidt 过程的投影算子。

```
proj_u (v) = (<u, v> / <u, u>) u
```

方程 13.16 Gram-Schmidt 过程投影算子

在方程 13.16 中，<u, v> 表示向量 u 和 v 的内积。此投影将向量 v 正交投影到向量 u 张成的直线上。

Gram-Schmidt 过程随后经历一系列投影步骤，其细节在此讨论中并不关键。然而，Gram-Schmidt 系数是相关的，如方程 13.17 所示。

```
μ_i,j = (<b_i, b_j^*> / <b_j^*, b_j^*>) , for any 1 <= j < i <= n
```

方程 13.17 Gram-Schmidt 系数

然后，如果存在一个通常用 δ 表示的参数，使得以下条件成立，LLL 算法将约减基 B：

- 1. 对于 1 <= j <= i <= n: |μ_i,j| <= 0.5
- 2. 对于 k = 2, 3, ..., n: δ||b_k^*|| ^2 + μ_{k,k-1}^2 ||b_{k-1}^*|| ^2

这对某些读者来说可能显得相当绕且不太清晰。那么，让我们稍微探讨一下。第一个问题是参数 δ。LLL 的关键在于找到正确的参数。Lenstra、Lenstra 和 Lovász 最初使用 δ = 3/4。其他人使用过 δ = 1 和 δ = 1/4。找到合适的参数是使 LLL 正常工作的问题之一。接下来，让我们讨论 B 和 B*。B 是格 L 的基向量集合。B* 是 Gram-Schmidt 过程正交基。其概念是寻找约减的基向量，以便求解格问题并潜在地破解依赖于该格问题的密码算法。

值得注意的是，一般而言格约减，特别是 LLL，并不能保证能破解某个算法。它们只是有概率能够做到这一点。即使这些方法有效，也不是即时的。事实上，它们可能需要花费大量时间。关注这些算法的原因是，它们破解基于格的密码算法所需的时间比通常情况下更短。从对 LLL 的讨论中得到的关键启示是，任何提出的基于格的算法都应结合格约减算法进行彻底分析。对于熟悉 Mathematica 的读者，它有一个名为 LatticeReduce 的函数，使用了 LLL。此外，GitHub 上还有 fplll 中 LLL 的独立实现 https://github.com/fplll/fplll。
