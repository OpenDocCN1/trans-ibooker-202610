Recall from Chapter 1 our discussion of the dot products of vectors. Now let us consider two column vectors:

```
[ 1 ] [ 3 ]
[ 2 ] [ 2 ]
[ 1 ] [ 1 ]
```

The dot product is found as follows: (1 * 3) + (2 * 2) + (1 * 1) = 8.

A tensor product of two vector spaces basically takes the elements and multiplies them together. Here is a representation of a tensor product:

```
[ 1 ] ⊗ [ 3 ]
[ 2 ] [ 2 ]
[ 1 ] [ 1 ]
```

```
[ 1*3 ]
[ 1*2 ]
[ 1*1 ]
```
