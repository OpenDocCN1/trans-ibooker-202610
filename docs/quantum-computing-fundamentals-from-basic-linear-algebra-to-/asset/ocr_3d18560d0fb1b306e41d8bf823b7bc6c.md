The concept again is quite simple, but inefficient. By using three qubits, if there is no error, we should have all three give the same result. If one has an error, then we will have a single qubit that does not match. Due to the obvious inefficiency of this approach, it is not recommended for actual quantum computing; however, it is an excellent way for you to become familiar with the concept.
