### 13.1.1 最短整数问题

最短整数问题，有时也称为短整数解问题（SIS），如下所述：给定一个 m x n 格 A，它由 m 个均匀随机向量（即整数向量）组成，也可表示为 A ∈ z_q^{n x m}，找到一个非零的短整数向量 v，使得 Ax = 0 mod q。这个问题构成了 Ajtai 密码学基元的基础。在一些文献中，你会找到表述这个问题的其他方式；然而，这里使用这种形式是因为它最清晰。

### 13.1.2 最短向量问题

最短向量问题（SVP）经常被用作基于格的密码学系统的基础。该问题是，给定一个特定的格及其一个范数 N，在 L 中按 N 衡量找到 V 中最短的非零向量。更正式地说，SVP 是按范数 N 在向量空间 V 中找到最短向量。请记住，范数是一个数学函数，它为向量空间中的每个向量分配一个正整数，即该向量的长度或大小。最短向量必须是非零向量。

更正式地说，给定格 L、向量 v 和范数 n，则

```
N(v) = λL
```

其中 λL 表示格 L 中最短非零向量的长度。

解决这个问题有几种不同的方法，但即使有量子计算机，也没有一种方法能在实用时间内解决该问题。这意味着 SVP 是基于格的密码学的良好基础。本章稍后我们将回顾解决基于格的问题的方法。请记住，所使用的格非常大，无法简单地通过观察来找到这个或其他基于格的问题的解。

最短向量问题的一个变体是差距最短向量问题（GapSVP）。该问题从格的维度 N 的一个固定函数开始。我们将此函数称为 β，它是格 L 维度的一个固定函数。给定格的一组基，算法试图确定 λ(L) ≤ 1 还是 λ > β。

### 13.1.3 最近向量问题

基于格的密码学中使用的另一个数学问题是最近向量问题（CVP）。该问题是，给定一个特定的向量空间 V，以及格 L 的一个度量 M 和一个向量 v（v 在向量空间 V 中，但不一定在格 L 中），如何在格 L 中找到与向量 v 最接近的向量？这个问题与之前讨论的最短向量问题相关，也是计算上难以解决的。事实上，CVP 是 SVP 的推广。

鑒于 CVP 与 SVP 的关系，你可能会假设存在一个 GapCVP，就像存在一个 GapSVP 一样。如果你这样假设，你是正确的。对于 GapSVP，输入由一个格基和一个向量 v 组成，算法必须确定以下陈述之一是否正确：

- 存在一个格向量 w，使得 w 与 v 之间的距离最多为 1。
- 格中的每个向量与 v 之间的距离都大于 β。

## 13.2 密码学算法

格问题对于构建密码学算法很有效。1996 年，第一个基于格的密码学算法被发表。该算法由 Milos Ajtai 创建，并基于短整数解问题（SIS）。该算法已被证明存在各种漏洞，因此今天不再实际用于密码学。然而，它是格在密码学中应用的第一个演示，因此通常在任何关于基于格的密码学的讨论中被提及。在本节中，我们将回顾三种最广泛使用的基于格的密码学算法。

### 13.2.1 NTRU

NTRU（N 次截断多项式环单位）最初于 1996 年由 Jeffrey Hoffstein、Jill Pipher 和 Joseph Silverman 公开描述。自最初发表以来，还开发了该算法的其他变体。NTRU 最好定义为一组相关的密码学算法。这一组算法一直是研究最多的基于格的密码体制之一。它是一组非常重要的算法，特别是因为 NTRU 的两个变体已进入 NIST 寻找抗量子密码学标准项目的第二轮。

NTRU 基于格中的最短向量问题。NTRU 的安全性基于在给定的截断多项式环中对某些多项式进行因式分解的计算难度。这要求我们简要探讨多项式环的概念，以便那些可能不熟悉此概念的读者。

多项式环是由一个或多个不定式（即变量）的多项式集合与另一个环中的系数形成的环。回顾第 1 章中关于环的讨论。环是一个具有两个运算、一个单位元和第一个运算逆运算的集合。多项式是由变量和系数组成的表达式。变量的另一个术语是不定式，就像在多项式环的定义中一样。

举个多项式环的例子，考虑环 R[X]。这是在域 r 上关于 X 且系数为 p 的环。它可以定义如下：

```
p = p₀ + p₁X + p₂X² + ... + pₙ₋₁Xⁿ⁻¹ + pₙXⁿ
```

截断多项式环是仅由多项式次数不超过某个设定值的多项式组成的环。本质上，多项式的次数被限制或截断。

$h = pf * g (mod q)$
