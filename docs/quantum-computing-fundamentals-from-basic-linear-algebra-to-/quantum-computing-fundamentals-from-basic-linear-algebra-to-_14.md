基于格的算法是基于与格相关的数学问题的密码学算法。请回想，RSA 的安全性基于将整数分解为其质因数的计算难度。Diffie-Hellman 及其变体的安全性基于求解离散对数问题的计算难度。各种基于椭圆曲线的算法依赖于在椭圆曲线及曲线外一点的参考下求解离散对数的难度。所有这些当前使用的算法的安全性都基于某个数学问题。基于格的算法的安全性基于与格相关的数学问题。

本章将更详细地探讨基于格的密码学的数学基础，但首先做个简要介绍。基于格的密码学只是基于格数学中某些问题的密码系统。基于格的密码学中最常用的问题之一是最短向量问题 (SVP)。本质上，这个问题是，给定特定的格，如何在格中找到最短向量？更具体地说，SVP 涉及根据范数 N 找到向量空间 V 中最短的非零向量。范数是一个函数，为向量空间中的每个向量分配严格正的长度或大小。SVP 是后量子计算的一个良好选择。

非对称密码学基于难以求解的数学问题。事实上，这些问题如此困难以至于在实际时间段内无法找到解决方案。

格的另一个数学问题是最近向量问题 (CVP)。该问题可概括为：给定向量空间 V，以及格 L 的度量 M 和向量 v（v 在向量空间 V 中，但不一定在格 L 中），找到格 L 中最接近向量 v 的向量。这个问题与先前讨论的最短向量问题相关，也难以求解。

## 13.1 基于格的数学问题

格可以定义为某个空间中具有 n 个维度并具有周期结构的一组点。格的基向量用于生成格。公式 13.1 提供了格的数学描述。

```
$$\mathcal{L}(b_1 ... bn) = \left\{ \sum_{i=1}^r x_i b_i : x_i \in Z \right\}$$
```

公式 13.1 格的定义

在公式 13.1 中，值 b1...bn 是基向量。或者，这可以表示为所有都是整数集合 (Z) 元素的向量 x 的总和 (Σ)。

格由向量组成。格使用线性无关向量。如果集合中的任何一个向量可以定义为其他向量的线性组合，则一组向量被称为*线性相关*。反之，如果集合中没有向量可以以这种方式定义，则这些向量被称为*线性无关*。这些向量构成了格的基础。

这是格定义的一个方面，但不是唯一的方面。格也出现在几何和群论中。考虑实数 R^n。格是群 R^n 的子群，与整数群 Z^n 同构。当然，这要求我们定义什么是子群。在群论中，子群定义如下：如果 G 是在某个运算下的群，而 H 是 G 的子集，并且在该运算下也构成一个群，那么 H 是 G 的子群。考虑在加法运算下的整数群。这显然是在整数运算下的有理数群的子群。

同样重要的是，您要理解此语境下的术语 _同构_。人们经常在图论中看到这个术语；但是，它在群论和其他数学领域都有应用。在任何数学领域，同构是两个结构之间保持结构并可以通过逆映射反转的映射。同构很重要，因为两个同构结构也将具有相同的属性。

一个有些平凡的例子是加法下的实数群 (R,+)。该群与乘法下的正实数群 (R^+,×) 同构。

现在我们已经从两个不同的角度定义了格的概念，可以进一步探讨格。其中一些材料是新的，有些是对第 1 章中某些概念的简要回顾。这些是理解基于格的密码学的关键概念。

术语 _向量空间_ 对基于格的密码学至关重要。首先，考虑一个向量。向量是一组值。这些值可以是实数、复数、整数等。在这种向量的集合中，如果对向量加法封闭且对标量乘法封闭，则称为向量空间。更正式地说，考虑一组向量 V，在该集合中选择任意两个向量 w 和 v，以及一个标量 α。V 要成为向量空间，必须满足以下条件：

-   给定 v, w ∈ V，则 v + w ∈ V

-   给定 v ∈ V 和标量 α，则 αv ∈ V

这些并不是向量空间的唯一属性。存在许多结合律和交换律属性。但是，刚才列出的两个属性通常是限制某组向量是否为向量空间的属性。但是，为了完整起见，以下是给定向量空间 V 中的向量 v 和 w 以及标量 α 的其他属性：

-   v + w = w + v（加法交换律）。

-   (u + v) + w = u + (w + v)（加法结合律）。

-   α (v + w) = αv + αw（分配律）。

-   (α + β)v = αv + βv（分配律）。

-   存在一个向量 z ∈ V，使得 z + v = v（即零向量）。

-   对于每个 v，存在一个 -v ∈ V，使得 v + (-v) = z（加法逆元）。

向量有许多实际应用，但为了当前目的，我们可以简单地将它们视为数学对象。向量空间 V 的维度是在其上的向量数



基础域。这通常被称为向量空间 V 的基数。一组向量 B 在向量空间 V 中构成一个基，如果 V 中的每个向量都可以写成 B 中向量的有限线性组合。那么 B 是向量空间 V 的基向量集合。向量空间 V 完全可能拥有一个以上的基集合 B。然而，所有这样的基集合必须具有相同的元素数量，因为那是向量空间 V 的维度。

线性代数中另一个在基于格的密码学中经常使用的概念是正交性。向量空间中的两个元素（u 和 v）如果其点积为零，则被称为正交。点积是两个向量对应元素乘积之和。本质上，点积用于从两个向量或两个矩阵中产生一个单一的数字，即标量。这与张量积形成对比。在数学中，张量是一个具有多个索引的对象，例如顶点或数组。两个向量空间 V 和 W 的张量积 V ⊗ W 也是一个向量空间。

单模矩阵也用于某些基于格的算法。单模矩阵是一个整数方阵，其行列式为 +1 或 -1。行列式是从方阵的元素中计算出的一个值。矩阵 A 的行列式记作 |A|。以下是一个单模矩阵的示例：

```
[ 2 3 2 ]
[ 4 2 3 ]
[ 9 6 7 ]
```

回顾第 1 章，我们取三个子矩阵行列式来得到该矩阵的行列式：

```
2[ 2 3 ] -3[ 4 3 ] +2[ 4 2 ]
    [ 6 7 ]   [ 9 7 ]   [ 9 6 ]
```

回顾每个行列式是通过 ad – bc 计算的。因此，我们有

```
2[(2 * 7) – (3 * 6)] – 3 [(4 * 7) – (3 * 9)] + 2[(4 * 6) – (2 * 9)]
```

这进而得出

```
2[14 – 18] – 3[28 – 27] + 2[24 – 18]
```

即

```
-8 – (3) + 12
```

```
= 1
```

### 13.1.1 最短整数问题

最短整数问题，有时也称为短整数解问题（SIS），如下所述：给定一个 m x n 格 A，它由 m 个均匀随机向量（即整数向量）组成，也可表示为 A ∈ z_q^{n x m}，找到一个非零的短整数向量 v，使得 Ax = 0 mod q。这个问题构成了 Ajtai 密码学基元的基础。在一些文献中，你会找到表述这个问题的其他方式；然而，这里使用这种形式是因为它最清晰。

### 13.1.2 最短向量问题

最短向量问题（SVP）经常被用作基于格的密码学系统的基础。该问题是，给定一个特定的格及其一个范数 N，在 L 中按 N 衡量找到 V 中最短的非零向量。更正式地说，SVP 是按范数 N 在向量空间 V 中找到最短向量。请记住，范数是一个数学函数，它为向量空间中的每个向量分配一个正整数，即该向量的长度或大小。最短向量必须是非零向量。

更正式地说，给定格 L、向量 v 和范数 n，则

```
N(v) = λL
```

其中 λL 表示格 L 中最短非零向量的长度。

解决这个问题有几种不同的方法，但即使有量子计算机，也没有一种方法能在实用时间内解决该问题。这意味着 SVP 是基于格的密码学的良好基础。本章稍后我们将回顾解决基于格的问题的方法。请记住，所使用的格非常大，无法简单地通过观察来找到这个或其他基于格的问题的解。

最短向量问题的一个变体是差距最短向量问题（GapSVP）。该问题从格的维度 N 的一个固定函数开始。我们将此函数称为 β，它是格 L 维度的一个固定函数。给定格的一组基，算法试图确定 λ(L) ≤ 1 还是 λ > β。

### 13.1.3 最近向量问题

基于格的密码学中使用的另一个数学问题是最近向量问题（CVP）。该问题是，给定一个特定的向量空间 V，以及格 L 的一个度量 M 和一个向量 v（v 在向量空间 V 中，但不一定在格 L 中），如何在格 L 中找到与向量 v 最接近的向量？这个问题与之前讨论的最短向量问题相关，也是计算上难以解决的。事实上，CVP 是 SVP 的推广。

鑒于 CVP 与 SVP 的关系，你可能会假设存在一个 GapCVP，就像存在一个 GapSVP 一样。如果你这样假设，你是正确的。对于 GapSVP，输入由一个格基和一个向量 v 组成，算法必须确定以下陈述之一是否正确：

- 存在一个格向量 w，使得 w 与 v 之间的距离最多为 1。
- 格中的每个向量与 v 之间的距离都大于 β。

## 13.2 密码学算法

格问题对于构建密码学算法很有效。1996 年，第一个基于格的密码学算法被发表。该算法由 Milos Ajtai 创建，并基于短整数解问题（SIS）。该算法已被证明存在各种漏洞，因此今天不再实际用于密码学。然而，它是格在密码学中应用的第一个演示，因此通常在任何关于基于格的密码学的讨论中被提及。在本节中，我们将回顾三种最广泛使用的基于格的密码学算法。

### 13.2.1 NTRU

NTRU（N 次截断多项式环单位）最初于 1996 年由 Jeffrey Hoffstein、Jill Pipher 和 Joseph Silverman 公开描述。自最初发表以来，还开发了该算法的其他变体。NTRU 最好定义为一组相关的密码学算法。这一组算法一直是研究最多的基于格的密码体制之一。它是一组非常重要的算法，特别是因为 NTRU 的两个变体已进入 NIST 寻找抗量子密码学标准项目的第二轮。

NTRU 基于格中的最短向量问题。NTRU 的安全性基于在给定的截断多项式环中对某些多项式进行因式分解的计算难度。这要求我们简要探讨多项式环的概念，以便那些可能不熟悉此概念的读者。

多项式环是由一个或多个不定式（即变量）的多项式集合与另一个环中的系数形成的环。回顾第 1 章中关于环的讨论。环是一个具有两个运算、一个单位元和第一个运算逆运算的集合。多项式是由变量和系数组成的表达式。变量的另一个术语是不定式，就像在多项式环的定义中一样。

举个多项式环的例子，考虑环 R[X]。这是在域 r 上关于 X 且系数为 p 的环。它可以定义如下：

```
p = p₀ + p₁X + p₂X² + ... + pₙ₋₁Xⁿ⁻¹ + pₙXⁿ
```

截断多项式环是仅由多项式次数不超过某个设定值的多项式组成的环。本质上，多项式的次数被限制或截断。

对于希望获得更严谨的多项式环数学处理的读者，我推荐以下资源：

https://people.seas.harvard.edu/~saili/am106/fall09/lec16.pdf

http://www.math.umd.edu/~immortal/MATH403/lecturenotes/ch16.pdf

在介绍了这些初步数学信息后，我们可以回到 NTRU 算法。NTRU 专门使用方程 13.3 中所示的截断多项式环。

$R = Z[x]/(x^N - 1)$

### 方程 13.3 NTRU 的截断多项式环

Z 是整数集合，X 是整数集合的一个元素。

N 被理解为质数。密钥生成过程首先选择 N，然后选择必须满足 gcd(p,q) = 1 条件的 p 和 q。q 通常是 2 的某个幂，而 p 通常相对较小。

下一步是生成两个多项式，通常标记为 f 和 g，每个多项式的次数最多为 N–1。这两个多项式的系数在 {–1,0,1} 中（例如，–x^3, –x^2+x–1）。多项式 f 还必须同时对模 p 和模 q 具有逆元。如果 f 对模 p 和模 q 都没有逆元，则必须选择不同的 f 值。下一步是实际计算 f mod p 和 f mod q 的逆元。它们通常分别标记为 f_p 和 f_q。公钥根据方程 13.4 生成。

$h = pf * g (mod q)$

### 方程 13.4 NTRU 密钥生成，步骤 2

h 是公钥。多项式 f、f_p 和 g 是私钥。现在我们有了密钥，如何将其应用于加密和解密？我们将使用传统的 Alice 和 Bob 进行讨论。假设某个消息 m 以多项式的形式存在。我们已经有了 h 和 q。Alice 想要加密消息 m 并将其发送给 Bob。Alice 现在选择某个随机多项式 r，通常具有小系数。现在进行加密，Alice 执行方程 13.5 中所示的方程。

$e = r * h + m (mod q)$

### 方程 13.5 NTRU 密钥生成，步骤 3

当 Bob 收到这条消息时，他需要对其进行解密。Bob 获取加密消息 e 并使用方程 13.6 进行解密。

$a = f * e (mod q)$

### 方程 13.6 NTRU 密钥生成，步骤 4





请注意，Equation 13.6 中的 a 是我们希望检索的明文的一个中间步骤。请记住，e 只是 r * h + m，而 f、fp 和 g 是私钥。这意味着我们可以像 Equation 13.7 所示重写 Equation 13.6。

```
a = f * ( r * h + m ) ( mod q )
```

### EQUATION 13.7 NTRU 密钥生成，步骤 5

密钥生成过程应当告诉你，h 实际上就是 pfqg(mod q)，因此我们可以将 Equation 13.7 重写为 Equation 13.8 中所示的形式。

```
a = f * ( r * pfq * g + m ) ( mod q )
```

### EQUATION 13.8 NTRU 密钥生成，步骤 6

你无需考虑解密方程的置换。你可以继续使用 *a = f * e (mod q)* 版本。重要的是你要完全理解这个过程。现在 Bob 需要计算一个通常称为 b 的多项式，以满足 Equation 13.9。

```
b = a ( mod p )
```

### EQUATION 13.9 NTRU 密钥生成，步骤 7

回顾一下，Bob 的密钥是 f、fp 和 g，我们尚未使用所有这些值。现在，使用 Equation 13.10，Bob 将利用它们来恢复 Alice 发送的消息 m。

```
m = f_p * b ( mod p )
```

### EQUATION 13.10 NTRU 密钥生成，步骤 8

如前所述，NTRU 实际上是一类算法。刚才描述的是 NTRUEncrypt。你现在已对 NTRUEncrypt 的密钥生成、加密和解密有了扎实的理解。该算法之所以作为抗量子密码学的候选方案而备受关注，有很多原因。首先，截至撰写本文时，尚未证明它易受任何量子攻击（例如 Shor 算法）的影响。此外，NTRU 的性能优于 RSA。性能在实际应用中至关重要。

除了上述的 NIST 标准项目外，还有其他标准正在评估 NTRU 变体。欧盟的 PQCRYPTO 项目正在审查 NTRU 的 Stehlé-Steinfeld 版本，作为可能的欧洲标准。该版本可证明是安全的，但效率不如原始 NTRU。

IEEE 1363.1 是基于格难题的公钥密码技术的 IEEE 标准。该标准发布于 2008 年，已不再是活跃标准；然而，在该标准活跃期间，它明确推荐了 NTRUEncrypt。

还有公开的开源 NTRU 库。GitHub 上有一个完整的 NTRU 开源项目 (https://github.com/NTRUOpenSourceProject)。你还可以在 GitHub 上找到 NTRU 的开源 Java 实现 (https://github.com/tbktu/ntru)。面向 .NET 的 Cipher EX V1.5 项目包含 NTRU 库 (https://www.codeproject.com/Articles/828477/Cipher-EX-V)。

针对 NTRU 算法（包括许多年前的 NTRU 签名方案）已经进行了多次密码分析研究。然而，所有这些研究都基于涉及 NTRU 实现而非基础数学的攻击。所有这些攻击也都集中在 NTRU 签名算法上。所有加密算法都基于正确实现。实现不当会显著降低任何加密算法的性能。

较近期的密码分析研究侧重于支撑 NTRU 的数学假设。这些研究表明，NTRU 对多种密码攻击具有很强的抵御能力。结合早期研究来看，较新的 NTRU 研究表明，NTRU 在数学上是可靠的，但可能因实现不当而被削弱。

### 13.2.2 GGH

GGH 算法以其发明者 Oded Goldreich、Shafi Goldwasser 和 Shai Halevi 的姓氏命名，是一个广泛研究的基于格的密码系统。它是一种非对称算法，已被证明能够抵抗密码分析。该算法于 1997 年首次公开描述。该算法使用最近向量问题（CVP）构建。私钥是格 L 的基向量 B 和一个单模矩阵 U（回顾本章前面关于单模矩阵的讨论）。

该基向量具有某些特性，例如近似正交的向量，以及一个单模矩阵 U。公钥是同一格的另一组基，形式为 B' = UB。消息 M 是一个消息空间，由向量 (m1, ..., mn) 组成，取值范围为 -M < mi < M。

消息通过将消息向量乘以公钥 B' 进行加密。这在 Equation 13.11 中以数学形式展示。

$v = \sum m_i b'_i$

### EQUATION 13.11 GGH，步骤 1

请记住，m 由整数值组成，而 B' 是一个格点。这意味着我们可以像 Equation 13.12 所列那样描述密文。

$c = v + e$

### EQUATION 13.12 GGH，步骤 2

e 是一个误差修正向量，(1, –1)。要解密消息，将密文 c 与 B 的逆 B⁻¹ 相乘。其数学表达如下：

M = c B⁻¹

这是一个相对易于理解的算法。尽管它已被广泛研究，但已发生过成功的密码分析攻击。2010 年，H. Lee 和 C. Hahn 证明，明文的部分信息有助于解密 GGH 算法的密文。尽管他们的方法针对的是当时提出的最高维 GGH，但还需要与 Nguyen 的攻击相结合。Lee 和 Han 的方法也需要一些明文知识；因此，可以认为这次对 GGH 的密码分析很有趣，但不太可能代表真实世界的密码分析条件。

2015 年，Charles de Barros 和 L. M. Schechter 进行的研究对 GGH 进行了改进建议。作者首先简要地描述了 GGH，如下：

> 其核心思想是将消息编码为格向量 v，添加一些小扰动 r 并生成密文 c=v+r。向量 r 的范数必须足够小，使得 v 是最接近 c 的格向量。

接着，他们描述了攻击 GGH 最直接的方法，即约简公钥以找到一个可应用 Babai 算法的基。de Barros 和 Schechter 还指出，即使无法推导出私钥，消息也可能被检索出来。

零化攻击对多种 GGH 变体已取得成功。在其 2015 年论文《GGH 的二次零测试密码分析》中，Brakerski 等人将此类攻击描述如下：

> 粗略地说，零化攻击首先诚实地计算许多顶层的零编码，然后使用规定的零测试过程来建立并求解方案中秘密参数的多线性方程组。这些攻击在很大程度上依赖于零测试过程的线性，因此近来已有人尝试设计非线性的替代零测试过程。

### 13.2.3 Peikert 的环

Peikert 的环算法用于密钥分发，类似于你在第 11 章“当前非对称算法”中看到的 Diffie-Hellman。该算法有多种变体，例如带错误的环学习密钥交换算法（RLWE-KEX）。该算法旨在抵御量子计算机攻击。

带错误的环学习（RLWE）使用模某个多项式的多项式环。回顾本章前面关于多项式环的讨论。该多项式通常用符号 \(\Phi(x)\) 表示。系数位于模 q 的整数域中。乘法和加法模 \(\Phi(x)\) 约减。密钥交换算法大致可描述如下：

存在一个通常表示为如下形式的多项式：

a(x) = a_0 + a_1x + a_2x^2 + ... a_{n-3}x^{n-3} + a_{n-2}x^{n-2} + a_{n-1}x^{n-1}.

该多项式的系数是模 q 的整数。该多项式本身是一个循环多项式。对于不熟悉循环多项式的读者来说，这个话题在数学上更为严谨。你不必完全理解它才能对 RLWE 有总体性的工作知识。不过，为了完整起见，此处将对其进行描述。

简短的定义是，循环多项式是其复根为原根的多项式。然而，只有在熟悉原根以及一般根的情况下，这才有帮助。n 次原根，其中 n 是正整数，是满足 Equation 13.13 所示相当简单方程的某个数 x。

x^n = 1

### EQUATION 13.13 原根

这解释了原根，我猜这比你想象的要简单得多。然而，它并未解释原根（primitive roots of unity）。对于一个给定的原根（我们称其为 n），如果它不是某个更小的 m 的 m 次原根，则被称为原根。换句话说，假设你找到了一个原根（x^n = 1）。要被视为原根，它还必须满足 Equation 13.14 所示的条件。

x^m \neq 1 for m = 1, 2, 3, 4, ..., n-1.

### EQUATION 13.14 原根

对于寻求更严格数学定义的读者，n 次循环多项式是 Equation 13.15 所示公式给出的多项式。

\(\Phi_n(x) = \prod_{\zeta} (x - \zeta)\)

### EQUATION 13.15 n 次循环多项式

如果这个解释对你来说仍然比较晦涩，也无需过分担心。如果你没有坚实的数论基础，这完全正常。不过，你当然可以继续阅读并理解 RLWE 的大致内容，即使你对原根的理解比较模糊。

现在，继续介绍密钥生成，密钥交换通常有一个发起方；我们将使用符号 I 来代表该方。然后还有一个响应方，我们将用 R 表示。双方都知道 q、n 和 a(x) 的值，并可以根据分布 X\alpha 生成小多项式，依据分布 X\alpha 与



参数 α. 值 q 是一个素数。值 a(x) 是发起方 I 和应答方 R 共享的固定多项式。现在我们可以探讨密钥生成的步骤：

- 1. 生成两个系数较小的多项式。这些多项式通常称为 s_I 和 e_I（是的，下标表示发起方，如你稍后将看到，下标表示应答方）。
- 2. 计算 p_I = as_I + 2e_I。现在发起方将 p_I 发送给应答方。此时，应答方将生成两个多项式 s_R 和 e_R。
- 3. 计算 p_R = as_R + 2e_R。接收方随后将从 X_α 生成一个小的 e'_R。
- 4. 计算 k_R = p_I s_R + 2e'_R。
- 5. 计算 k_R = as_R + 2e_I s_R + 2e e_R。

接下来，将使用信号函数。此函数尚未描述。信号函数相当复杂。如果你不完全理解它，这不会成为理解其余密钥生成过程的障碍。同样，为了完整性起见，信号函数的工作原理如下：

首先，定义一个我们称之为 E 的子集：

```
E := { -⌊q/4⌋,...,⌊q/4⌋ } of Zq = { -(q-1)/2 ,...,(q-1)/2 }
```

该函数是 E 补集的特征函数。“特征函数”一词在不同语境下可能有不同含义。在这种情况下，它是一个子集的指示函数。“指示函数”一词表示该函数指示元素是否属于该子集。如果值是子集的成员，则返回 1；如果值不是子集的成员，则返回 0。实际的信号函数 (S) 如下：

```
S(v) = 1 if v ∈ E; S(v) = 0 if v ∉ E
```

继续密钥生成，我们现在将刚才描述的信号函数应用于 k_R 的每个系数：

```
w = S(k_R)
```

应答方的密钥流 sk_R 如下计算：

```
sk_R = Mod2(k_R, w)
```

现在应答方将 w 和 p_R 发送给发起方。

发起方接收这两个值，现在将从 X_α 取样 ė₁ 并计算

Kᵢ = pᵣ sᵢ + 2ė₁

skᵢ = mod2(Kᵢ, w) 是发起方的密钥流。

你可能会认为这是一组相当复杂的步骤——而你是对的。这明显比 GGH 或 NTRU 中的密钥生成更复杂。它也比你在第 11 章中看到的 Diffie-Hellman 密钥生成更复杂。

该密钥交换算法的安全性将取决于参数的大小。经常建议使用 n = 1024、q = 40961 和 Φ(x) = x¹⁰²⁴ + 1 等大小（或类似大小）。已有大量研究致力于通过参数大小的变化，在达到可接受安全性的同时，保持足够的效率。

## 13.3 求解格问题

随后会应用诸如 Lenstra-Lenstra-Lovász (LLL) 或 Block-Korkine-Zolotarev (BKZ) 之类的格基约减算法，其目的是将 B 矩阵基约减为形成同一格的另一基，但该基的“基长度”更小。格约减算法通常基于 Gram-Schmidt 正交化和分解。

格基约减的概念相对简单。给定某个整数格基作为输入，尝试找到另一基，其向量更短且近似正交。回顾我们之前关于基向量的讨论。试图找到另一基向量，它更短，但除此之外与用于此格的向量非常相似。这创造了一个比原始问题更容易求解的数学问题。当应用于密码学时，它提供了一种有概率推导私钥的方法。

本章的目标不是专注于格约减，而是向你介绍该过程在格密码学中的应用。为了读者的启发，提供了一个关于 LLL 的完整小节，包含大量细节；然而，这只是一种格约减算法。还有其他算法，例如 Block-Korkine-Zolotarev (BKZ)、Seysen Reduction 等。对此类算法也有相当大量的研究。

### 13.3.1 Lenstra-Lenstra-Lovász (LLL)

LLL 在多项式时间内找到一个近似短向量，保证其在实际最短向量的 (2/3) n 倍因子以内。LLL 生成一个格的“约减”基，结果包含一个近似短基向量。该算法的细节也会相当复杂，但大多数读者仍可跟上其大致轮廓。首先，有必要介绍一些预备知识。存在一个格 L 和一个基 B = {b₁, b₂, ..., b_d}，其具有 n 维整数坐标，且 d ≤ n。LLL 算法计算一个约减的格基。

此 Gram-Schmidt 正交基可表示如下：

```
B* = {b1*, b2*, ..., bn*}
```

一旦有了基 B，下一步就是定义其 Gram-Schmidt 过程正交基。对于不熟悉它的读者，Gram-Schmidt 是正交归一化一组向量的过程。Gram-Schmidt 过程取一组有限的线性无关向量，并生成一组正交向量，该组向量张成与原始集合相同的 k 维子空间。

接下来是投影算子的使用。在线性代数中，投影是从向量空间到其自身的线性变换 P，使得如果投影算子 P 应用两次，结果与应用一次相同 P2 = P。这种操作被称为幂等。幂等性是算子可以多次应用，且首次应用后结果不再改变的属性。顺便提一下，“幂等”一词源自 idem，意为“相同”，以及 potent，表示力量或能力。因此，该词字面意思是“相同的力量”。

方程 13.16 显示了 Gram-Schmidt 过程的投影算子。

```
proj_u (v) = (<u, v> / <u, u>) u
```

方程 13.16 Gram-Schmidt 过程投影算子

在方程 13.16 中，<u, v> 表示向量 u 和 v 的内积。此投影将向量 v 正交投影到向量 u 张成的直线上。

Gram-Schmidt 过程随后经历一系列投影步骤，其细节在此讨论中并不关键。然而，Gram-Schmidt 系数是相关的，如方程 13.17 所示。

```
μ_i,j = (<b_i, b_j^*> / <b_j^*, b_j^*>) , for any 1 <= j < i <= n
```

方程 13.17 Gram-Schmidt 系数

然后，如果存在一个通常用 δ 表示的参数，使得以下条件成立，LLL 算法将约减基 B：

- 1. 对于 1 <= j <= i <= n: |μ_i,j| <= 0.5
- 2. 对于 k = 2, 3, ..., n: δ||b_k^*|| ^2 + μ_{k,k-1}^2 ||b_{k-1}^*|| ^2

这对某些读者来说可能显得相当绕且不太清晰。那么，让我们稍微探讨一下。第一个问题是参数 δ。LLL 的关键在于找到正确的参数。Lenstra、Lenstra 和 Lovász 最初使用 δ = 3/4。其他人使用过 δ = 1 和 δ = 1/4。找到合适的参数是使 LLL 正常工作的问题之一。接下来，让我们讨论 B 和 B*。B 是格 L 的基向量集合。B* 是 Gram-Schmidt 过程正交基。其概念是寻找约减的基向量，以便求解格问题并潜在地破解依赖于该格问题的密码算法。

值得注意的是，一般而言格约减，特别是 LLL，并不能保证能破解某个算法。它们只是有概率能够做到这一点。即使这些方法有效，也不是即时的。事实上，它们可能需要花费大量时间。关注这些算法的原因是，它们破解基于格的密码算法所需的时间比通常情况下更短。从对 LLL 的讨论中得到的关键启示是，任何提出的基于格的算法都应结合格约减算法进行彻底分析。对于熟悉 Mathematica 的读者，它有一个名为 LatticeReduce 的函数，使用了 LLL。此外，GitHub 上还有 fplll 中 LLL 的独立实现 https://github.com/fplll/fplll。





## 13.4 总结

本章介绍了基于格的问题和基于格的密码学算法。理解这些问题非常重要，因为它们是寻找能够抵御量子计算机攻击的密码学算法工作的一部分。虽然本书的重点是量子计算本身，但抗量子密码学也是该主题的一部分。你还简要了解了用于攻击基于格密码学的格约简方法。
