## 前言

2017 年，在明尼阿波利斯市中心的一个小办公室里，Karl 和我坐在白板前。我刚加入 NetSPI，Karl 热心地帮助我适应环境，并就新的增长想法和计划进行头脑风暴。会议结束时，白板上只写了一个词，那就是 *cloud*（云）。Karl 便从那里开始，将他多年来积累的安全测试知识全部应用到云平台上。此后，Karl 被广泛公认为云安全领域的领导者，他组建了许多团队，构建了许多工具，并发表了许多关于该主题的博客文章。在与 David（一位杰出的云架构师、测试人员和培训师）合作中，他们为这本书带来了超过二十年的行业领先经验和云安全洞见。云计算的概念并不新鲜，如今一些组织诞生于云端，本地 IT 足迹几乎为零。但对于那些背负着大量遗留应用技术债务的传统大型企业而言，云采用的步伐自然会慢一些。随着这些大型组织达到云迁移的临界点，向云迁移的步伐正在加快。云迁移的投资和优先级已提升至董事会层面，许多企业都下达了按时完成企业级迁移的指令。而在迁移的紧迫和匆忙之中，错误就会发生，遗漏就会出现，漏洞也会敞开。此外，许多公司也将那些遗留应用中的旧漏洞带到了云端，这些漏洞在云环境中可能产生更大的影响。在这本书中，David 和 Karl 为云安全从业者编写了一份实用且循序渐进的指南，其中包括设置和测试 Azure 云环境的详细说明，以及必要的辅助工具。David 和 Karl 不仅描述了如何攻击云环境，他们还花时间详细说明了为什么某些事项很重要。本书的实用性使其应成为任何云安全渗透测试人员以及云架构师的入门读物。本书作者带领我们经历了一段技术之旅，从设置 Azure 环境、发现错误配置漏洞、入侵 Azure AD 帐户、提升权限，到攻击 Azure 中的虚拟机、获取凭据以及持久化选项。如果使用所建议的工具正确应用本书的原则和教训，我想你会对发现的结果感到惊讶。

—— *Charles Horton*

*NetSPI 首席运营官*
