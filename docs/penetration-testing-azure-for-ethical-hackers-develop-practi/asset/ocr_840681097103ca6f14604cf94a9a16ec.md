8. On your client system, open a Remote Desktop Protocol (RDP) client and enter the pentest-vm-dns value you made a note of earlier. Click on Connect. The instructions here describe the use of a Windows RDP client. If you are using a different RDP client, the instructions may be different for you.

To open the Windows RDP client, execute mstsc from the Windows Run dialog, or type mstsc in the Windows Start menu.
