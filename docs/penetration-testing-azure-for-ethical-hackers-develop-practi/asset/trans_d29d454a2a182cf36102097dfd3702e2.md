## 前言

欢迎阅读 *Penetration Testing Azure for Ethical Hackers*。本书将涵盖你在对 Azure 环境进行渗透测试期间可以使用的大量技术和攻击。无论你是希望在云领域获得优势的经验丰富的渗透测试人员，还是刚刚进入渗透测试领域的人，本书都应为你提供有价值的信息。

我们将从介绍 Azure 服务和平台整体架构开始。本书的第一部分将涵盖渗透测试期间常用的服务，以及支持它们的服务。这就是我们为本书其余攻击奠定基础的地方，因为攻击通常利用这些服务的架构和配置，而与更传统的协议和代码相关渗透测试攻击不同。

然后，我们将介绍如何创建和配置易受攻击的测试环境，以便跟随本书中的练习。对于有构建和维护订阅经验的人来说，这可能是一个复习章节，但请记住，这些初始信息将指导本书其余内容。

本书中间部分将涵盖你在渗透测试期间将使用的攻击和技术。本节中特定攻击的实用性因人而异，因为你在 *正常* 渗透测试期间可能不会遇到我们涵盖的所有服务和配置。作为在数百个 Azure 订阅中工作过的渗透测试人员，我们希望能给你一个关于公司正在使用的核心服务以及易受利用的服务的良好概念。

对于攻击部分，我们将根据订阅权限级别（Reader、Contributor 等）和在这些权限下各个服务的可用攻击来分解单个攻击。由于不同的权限允许不同的攻击，我们将从更基础的只读攻击开始，然后转向更高级（更大权限）的攻击。

本书最后一章侧重于在 Azure 环境中保持持久性。在渗透测试期间，你可能会发现自己需要维持对某些 Azure 环境部分的访问。我们将回顾在 Azure 环境中隐藏的多种技术。
