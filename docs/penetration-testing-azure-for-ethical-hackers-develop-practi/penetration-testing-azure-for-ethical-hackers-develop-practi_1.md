## 前言

2017 年，在明尼阿波利斯市中心的一个小办公室里，Karl 和我坐在白板前。我刚加入 NetSPI，Karl 热心地帮助我适应环境，并就新的增长想法和计划进行头脑风暴。会议结束时，白板上只写了一个词，那就是 *cloud*（云）。Karl 便从那里开始，将他多年来积累的安全测试知识全部应用到云平台上。此后，Karl 被广泛公认为云安全领域的领导者，他组建了许多团队，构建了许多工具，并发表了许多关于该主题的博客文章。在与 David（一位杰出的云架构师、测试人员和培训师）合作中，他们为这本书带来了超过二十年的行业领先经验和云安全洞见。云计算的概念并不新鲜，如今一些组织诞生于云端，本地 IT 足迹几乎为零。但对于那些背负着大量遗留应用技术债务的传统大型企业而言，云采用的步伐自然会慢一些。随着这些大型组织达到云迁移的临界点，向云迁移的步伐正在加快。云迁移的投资和优先级已提升至董事会层面，许多企业都下达了按时完成企业级迁移的指令。而在迁移的紧迫和匆忙之中，错误就会发生，遗漏就会出现，漏洞也会敞开。此外，许多公司也将那些遗留应用中的旧漏洞带到了云端，这些漏洞在云环境中可能产生更大的影响。在这本书中，David 和 Karl 为云安全从业者编写了一份实用且循序渐进的指南，其中包括设置和测试 Azure 云环境的详细说明，以及必要的辅助工具。David 和 Karl 不仅描述了如何攻击云环境，他们还花时间详细说明了为什么某些事项很重要。本书的实用性使其应成为任何云安全渗透测试人员以及云架构师的入门读物。本书作者带领我们经历了一段技术之旅，从设置 Azure 环境、发现错误配置漏洞、入侵 Azure AD 帐户、提升权限，到攻击 Azure 中的虚拟机、获取凭据以及持久化选项。如果使用所建议的工具正确应用本书的原则和教训，我想你会对发现的结果感到惊讶。

—— *Charles Horton*

*NetSPI 首席运营官*

## 前言

欢迎阅读 *Penetration Testing Azure for Ethical Hackers*。本书将涵盖你在对 Azure 环境进行渗透测试期间可以使用的大量技术和攻击。无论你是希望在云领域获得优势的经验丰富的渗透测试人员，还是刚刚进入渗透测试领域的人，本书都应为你提供有价值的信息。

我们将从介绍 Azure 服务和平台整体架构开始。本书的第一部分将涵盖渗透测试期间常用的服务，以及支持它们的服务。这就是我们为本书其余攻击奠定基础的地方，因为攻击通常利用这些服务的架构和配置，而与更传统的协议和代码相关渗透测试攻击不同。

然后，我们将介绍如何创建和配置易受攻击的测试环境，以便跟随本书中的练习。对于有构建和维护订阅经验的人来说，这可能是一个复习章节，但请记住，这些初始信息将指导本书其余内容。

本书中间部分将涵盖你在渗透测试期间将使用的攻击和技术。本节中特定攻击的实用性因人而异，因为你在 *正常* 渗透测试期间可能不会遇到我们涵盖的所有服务和配置。作为在数百个 Azure 订阅中工作过的渗透测试人员，我们希望能给你一个关于公司正在使用的核心服务以及易受利用的服务的良好概念。

对于攻击部分，我们将根据订阅权限级别（Reader、Contributor 等）和在这些权限下各个服务的可用攻击来分解单个攻击。由于不同的权限允许不同的攻击，我们将从更基础的只读攻击开始，然后转向更高级（更大权限）的攻击。

本书最后一章侧重于在 Azure 环境中保持持久性。在渗透测试期间，你可能会发现自己需要维持对某些 Azure 环境部分的访问。我们将回顾在 Azure 环境中隐藏的多种技术。

## 本书适合谁

本书适合希望学习如何使用云入侵中对手使用的战术、技术和流程来模拟真实世界 Azure 攻击的新手和经验丰富的信息安全从业人员。任何使用 Azure 平台的技术专业人员（包括 Azure 管理员、开发人员和 DevOps 工程师）如果对攻击者如何利用 Azure 主机基础设施、应用程序和服务中的漏洞感兴趣，都将从本书中受益。

## 本书涵盖内容

*第 1 章，Azure 平台和架构概述，* 介绍了 Azure 平台的工作原理基础。

*第 2 章，构建自己的环境，* 解释了如何创建一个可用于跟随本书动手练习的测试环境。

*第 3 章，查找 Azure 服务和漏洞，* 解释了如何利用匿名攻击来查找 Azure 主机服务并攻击它们以获得对环境的初始访问权限。

*第 4 章，利用 Reader 权限，* 涵盖了使用 Azure 中权限最低的角色之一（Reader）可用的攻击。

*第 5 章，利用 IaaS 服务上的 Contributor 权限，* 解释了使用 Contributor 角色可以执行的可用基础设施攻击。

*第 6 章，利用 PaaS 服务上的 Contributor 权限，* 解释了如何使用 Contributor 角色攻击平台托管服务以获取凭据、身份和权限提升机会。

*第 7 章，利用 Owner 和特权 Azure AD 角色权限，* 介绍了如何使用订阅和 Azure AD 中的特权角色进行横向移动并提升租户权限。

*第 8 章，在 Azure 环境中保持持久性，* 解释了持久性的目标以及攻击者用于隐藏在 Azure 环境中的技术。
