# Using the OpenAI API with Go

Developers often claim that Google’s Go language is the C for the twenty-first century when it comes to syntax.

Go is an open-source programming language that makes it easy to build simple, reliable and efficient applications. The core idea behind creating Go was to combine the ease of programming of an interpreted, dynamically typed language with the efficiency and safety of a statically typed, compiled language. In simple terms, Go combines the best features of other programming languages.

Go is the language of preference for building projects that require high security, high speed, and high modularity. This makes it an attractive option for many projects in the fintech industry. Key features of Go are as follows:

+   - Ease of use coupled with state-of-the-art productivity
+   - High-level efficiency along with static typing
+   - Advanced performance for networking and the full use of multi-core power.

If you are completely new to the Go language and want to give it a try, you can follow this documentation to get started: https://golang.org/doc/install

Once you are done with the installation and understand the basics of Go programming, you can follow these steps to use GPT-3 with Go. We will use the following framework to create GPT-3 powered applications using Go programming.

Let’s start with creating a go module that we can use to track and import the code dependencies. In order to learn more about how to create a go module, we recommend you to check out this tutorial - https://golang.org/doc/tutorial/create-module. For our use case, let’s create and initialize the “gogpt” module using the following command:

```
D:\GPT-3 Go> go mod init gogpt
```
