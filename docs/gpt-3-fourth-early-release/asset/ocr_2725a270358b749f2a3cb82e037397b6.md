# Execution Engine

The execution engine determines the language model used for execution. Choosing the right engine is the key to determining your model’s capabilities and in turn getting the right output. GPT-3 comes with four execution engines of varying sizes and capabilities: Davinci, Ada, Babbage, and Curie. Davinci is the most powerful and the Playground’s default.

# Response Length

The response length sets a limit on how much text the API includes in its completion. Because OpenAI charges by the length of text generated per API call (as noted, this is translated into tokens, or numeric representations of words), response length is a crucial parameter for anyone on a budget. A higher response length will use more tokens and cost more.
