
## Using the OpenAI API with Go

Developers often claim that Google’s Go language is the C for the twenty-first century when it comes to syntax.

Go is an open-source programming language that makes it easy to build simple, reliable and efficient applications. The core idea behind creating Go was to combine the ease of programming of an interpreted, dynamically typed language with the efficiency and safety of a statically typed, compiled language. In simple terms, Go combines the best features of other programming languages.

Go is the language of preference for building projects that require high security, high speed, and high modularity. This makes it an attractive option for many projects in the fintech industry. Key features of Go are as follows:

- Ease of use coupled with state-of-the-art productivity
- High-level efficiency along with static typing
- Advanced performance for networking and the full use of multi-core power.

If you are completely new to the Go language and want to give it a try, you can follow this documentation to get started: https://golang.org/doc/install

In this example, we will show how to prime GPT-3 to summarize a given text document to a level that can be easily understood by a 2nd grader. We will use the same training prompt as mentioned in section 3.1, using OpenAI API with Python.

Let’s import the necessary dependencies and packages for starters:

```
# Calling the package main
package main
# Importing Dependencies
import (
    "fmt"
    "io/ioutil"
    "context"
    gogpt "github.com/sashabaranov/go-gpt3"
)
```

Go programming organizes source files into system directories called packages, which facilitate reusability of code across Go applications. In the first line of the code we call the package “main” and tell the Go compiler that the package should compile as an executable program instead of a shared library.

### NOTE

In Go, whenever you build reusable pieces of code, you will develop a package as a shared library. But when you develop executable programs, you will use the package “main” to make the package an executable program. By calling this package the main function in the package “main” will be set up as the entry point of our executable program.

After importing the dependencies and packages, let’s create a main function that will host the entire logic of reading the training prompt providing us with the completion output. We will use the following configuration for the API parameters:

```
Maximum tokens=100, Execution Engine="davinci",
Temperature=0.5, Top-p=1, Frequency Penalty = 0.2,
Stop Sequence = ["\n\n"]
```

```
func main() {
    c := gogpt.NewClient("OPENAI-API-KEY")
    ctx := context.Background()
    prompt, err :=
    ioutil.ReadFile("prompts/summarize_for_a_2nd_grader.txt")
    req := gogpt.CompletionRequest{
        MaxTokens: 100,
        Temperature: 0.5,
        TopP: 1.0,
        Stop: []string{"\n\n"},
        FrequencyPenalty: 0.2,
        Prompt: string(prompt),
    }
    resp, err := c.CreateCompletion(ctx, "davinci", req)
    if err != nil {
        return
    }
    fmt.Println("----------------------")
    fmt.Println(resp.Choices[0].Text)
    fmt.Println("----------------------")
}
```

In the code we perform the following tasks step-by-step:

- 1. We start with setting up a new API client by providing it with the API token and then we put it to run in the background.
- 2. In the next step, we read the following prompt “” in the form of a text file from the prompts folder.
- 3. We then create a completion request, by providing the training prompt and specifying the value API parameters like temperature, top-p, stop sequence, etc..
- 4. After creating the completion request, we call the create completion function by providing it with the API client, completion request and the execution engine.
- 5. The function will generate a response in the form of completion which we print towards the end in the console.

We can then save the code file as ‘text_summarization.go’ and run it from the terminal to generate the output. You can use the following command to run the file from your root folder:

```
(base) PS D:\GPT-3 Go> go run text_summarization.go
```

Once we executed the file, our console printed the following output:

```
-------------------
Olive oil is a liquid fat that comes from olives. Olives grow on a tree called an olive tree. The olive tree is the most common tree in the Mediterranean. People use the oil to cook with, to put on their salads, and as a fuel for lamps.
-------------------
```
