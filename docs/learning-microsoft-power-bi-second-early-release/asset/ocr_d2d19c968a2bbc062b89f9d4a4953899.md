# The Clipboard Subsection

So let’s get back to the Home tab. You’ll first see the Clipboard subsection with items for your standard Cut, Copy, and Paste functionality. You can use Format Painter to apply one visual’s formatting to another, in the same way you would if you were using format painting in Excel or PowerPoint.
