BI actually does a good job at detecting data types, but there are situations where it’s not perfect, so if you need to make a manual adjustment, you’ll do that here.

First Row as Headers is pretty self-explanatory, and Power BI will often try to detect whether or not the first row is comprised of column headers, depending on the data source. If you click the arrow next to the First Row as Headers button, you will also see an option to make your headers the first row instead, the inverse operation. Replace Values allows you do a find and replace of values in a given column. A common use case here would be to either treat zeros as nulls or nulls as zeroes, depending on your analysis. It’s important to note that you cannot edit individual cells because cells are not a concept that is known to Power Query; it only understands columns.

The Combine section allows us to merge queries, append queries, and combine files. Merge Queries functions like a SQL JOIN statement. You have column A in table A and column A in Table B, and you want to add Column N from table B to Table A. A JOIN statement says where the value in Column A table A and Column A Table B are equal, give me the Column N value and add it. We’re doing the same thing here.

Append Queries allows you to take two queries and effectively smash them together to get a single result encompassing all the columns and values between the two. That’s what it does, but in my view, that’s not its intended use. Its intended use is to take multiple queries where the data is the same shape and format and to consolidate them into one longer query, more like a UNION statement from SQL. Combine Files allows you to get ahead of the issue in Append Queries by precombining multiple files into a single view.

Finally, the AI Insights section has items that allow you to connect to Azure AI Services that your organization may use. It’s important to note that these features require Power BI Premium to be used if they’re going to be refreshed. It’s quite probable your organization does not have these resources, so I’m not going to spend time on this except to say that they’re there. Ask your Azure Administrator if the organization does use Azure Machine Learning Studio or Cognitive Services to learn more.
