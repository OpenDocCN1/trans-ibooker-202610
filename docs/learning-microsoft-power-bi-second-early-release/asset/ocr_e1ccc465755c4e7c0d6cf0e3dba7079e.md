If you want to try modifying the M directly from the editor here, make a copy of your currently functioning code in a text file or some other backup before making changes. The reason is that whatever changes you make and then press Done, that's what you'll get, whether your code is functional or not; so, as always in programming, have a backup!

Finally, the Manage button is poorly named. When you press this button, you'll see three options: Delete, Duplicate, and Reference. Duplicating a query takes the query as it currently exists and duplicates it. This is straight forward and does, in fact, mean you are storing that data twice.

Reference does something a bit different. It makes a new query, and it looks at first like a duplicate, but it's not. It takes whatever query it is referencing, in whatever its final shape is, and allows you to work from there. This does mean that if you should make changes to the parent query, the referenced query will change as well, and that could cause errors in that query, so be careful.

The Manage Columns area has two buttons, Choose Columns and Remove Columns. They both get you to the same place, but in different ways. The Choose Columns button, when pressed on the top will bring up a dialogue window where you will choose which columns you wish to keep in the query, discarding the others. The bottom half of this button allows you to go the Choose Columns dialogue box just mentioned or to go to a specific column in the query. This second feature can be useful when you have many columns in a query and aren’t sure where it is in the column order. The top half of Remove Columns button just removes the column. It does not give you a dialogue window. It takes whatever column(s) are selected and throws them into the abyss. The bottom part brings a second option in its drop-down menu to Remove Other Columns. This takes all the columns you don’t have selected and throws them out.
