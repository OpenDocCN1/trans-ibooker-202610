# # The Q&A Subsection

Finally, we have the Q&A subsection. The Q&A Setup button brings up a large wizard that shows how you can fine-tune the Q&A engine to adapt to more natural language around your users also displayed in Figure 2-20. You can use this to teach the engine synonyms so that when you ask a question with a certain word, the Power BI engine knows what that word means in the context of your data model.

![](bbox=[0.147, 0.283, 0.852, 0.589])

*Figure 2-20. The Natural Language Wizard.*

Select the Language button to get a list of eligible languages for Q&A. I expect the list of languages to grow in the future.

Lastly, the Linguistic Schema button has a drop-down that allows you to import or export a linguistic schema file. If you have more interest in this subject, I suggest you go to https://powerbi.microsoft.com/en-us/blog/editing-q-a-linguistic-schemas/ and download the example linguistic schema file and example PBIX file.
