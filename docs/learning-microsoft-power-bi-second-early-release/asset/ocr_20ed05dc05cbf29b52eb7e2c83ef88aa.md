# # The Page Options Subsection

In this subsection, you have three buttons to select from. You can show the Gridlines, you can have items Snap to Grid, and you can Lock Objects.

Gridlines are helpful in giving you guiding references for where your items are in respect to other items.

Snap to Grid only has a function while in Mobile layout and will force all visuals to fit neatly into a given pixel density.

Lock Objects prevents items on a page from being moved around.
