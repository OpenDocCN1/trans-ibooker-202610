“But Jeremey!” I can already hear some of you yelling at the page, “I can write a SQL statement that has multiple join conditions between two tables!” Yes. Yes, you can. However, Power BI does not run SQL when it queries its internal database, it runs DAX. If you need to create a relationship between two tables with multiple columns, my suggestion is to create a column with a composite value of the columns you want to join in both tables and create your single relationship then, with your new concatenated column.

Next, let’s talk about cardinality and direction. These two things go hand in hand. There are three types of relationships that we can create in Power BI. One-to-one relationships, one-to-many relationships, and many-to-many relationships.

I don’t like many-to-many relationships. The best practice when building a data model avoids many-to-many relationships wherever possible because they’re not performant and can sometimes give you strange results compared to what you might expect. Many-to-many relationships are more akin to a full outer join, for you SQL people. You can identify quickly if a relationship is many-to-many by looking at the line connecting the two tables and seeing if there are stars on both ends of the line.

A one-to-one relationship is a scenario where all the values in column A table A are unique, and all the values in column A table B are unique. You can identify a one-to-one relationship quickly by seeing the number 1 on both ends of the line connecting two tables.

A one-to-many relationship is where all the values in column A table A are unique, but the values in Column A table B aren’t unique. You can recognize this type of relationship quickly in your model by seeing that one end of the line will have a “1”, and the other end of the line will have a star in the model view. The benefit of both of these types of relationships is that I’m looking for one value and comparing those values in the other column, as opposed to looking for every copy of that value and comparing it to every other copy of that value.
