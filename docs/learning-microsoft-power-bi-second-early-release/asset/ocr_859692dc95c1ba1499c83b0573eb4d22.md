In the previous chapter, we went into great detail to help you understand the UI functions of the Report and Data views. This chapter deals with the user interface of Power Query and the Model view. By the end of this chapter, we’ll have imported the mockup class data into a Power BI Desktop file and used that data to demonstrate some of the basic capabilities of Power Query for data manipulation and shaping.

In our discussion of the Model view, we’ll demonstrate what relationships are in a data model and what they do. Finally, this is the first chapter where we’ll go through the data and actively try things with it. If you’re a hands-on learner, I highly recommend you take the sample data and follow along with me to try to replicate the steps and results.
