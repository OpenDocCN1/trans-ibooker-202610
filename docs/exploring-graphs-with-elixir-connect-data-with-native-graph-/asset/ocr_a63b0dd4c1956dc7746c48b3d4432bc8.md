In addition to computing averages, you may use other specialized functions to compute min and max. If you want to compute the average, min, and max all at the same time, you might wonder if you have to use each one of the individual specialized methods separately. That's one option, but that will make the code verbose, and you'll also end up iterating over the same collection three times instead of just once. Collectors provides specialized methods to get multiple statistical results from a collection in one shot; use summarizingDouble, summarizingInt, or summarizingLong depending on the type of result you would like.

transforming/fpij/Statistics.java

```
package fpij;

import static java.util.stream.Collectors.*;
import static fpij.Person.SAMPLE_DATA;

public class Statistics {
public static void main(String[] args) {
var statistics = SAMPLE_DATA.stream()
.collect(
summarizingDouble(person -> person.emailAddresses().size()));

System.out.println("Number of people: " + statistics.getCount());
System.out.println(
"Number of email addresses: " + statistics.getSum());
System.out.println(
"Average number of email addresses: " + statistics.getAverage());
System.out.println(
"Max number of email addresses: " + statistics.getMax());
System.out.println(
"Min number of email addresses: " + statistics.getMin());
}
}
```
