# Adding Multiple Filters

The design is good so far; now let's mix two filters—a brighter one and a darker one—to see the effect of chaining.

designing/fpij/Camera.java

```
camera.setFilters(Color::brighter, Color::darker);
printCaptured.accept("brighter & darker filter");
```

We passed two method references to the setFilters method—just essence, no ceremony. (We could've passed in lambda expressions instead of method references.) The two filters are now chained, and the filter reference in the Camera instance is referring to the head of the chain. A call to the capture method will now route the color processing through each of these filters, as we see in the following figure:
