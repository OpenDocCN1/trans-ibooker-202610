```
final Function<Person, Integer> byAge = person -> person.getAge();
final Function<Person, String> byTheirName = person -> person.getName();

printPeople("Sorted in ascending order by age and name: ",
people.stream()
.sorted(comparing(byAge).thenComparing(byTheirName))
.collect(toList()));
```

We first created two lambda expressions: one to return the age of a given person and the other to return that person’s name. We then combined these two lambda expressions in the call to the sorted method to compare on both properties. The comparing method created and returned a Comparator to compare based on age. On the returned Comparator we invoked the thenComparing method to create a composite comparator that compares based on both age and name. The output from this code shows the net result of sorting by age first and then by name.

```
Sorted in ascending order by age and name:
John - 20
Jane - 21
Sara - 21
Greg - 35
```
