We saw how lambda expressions and the Stream
implementations work in tandem to make the execution
efficient. While lambda expressions and method references
make code elegant, expressive, and concise, the real
performance gains in Java applications will come from Streams.
Lambda expressions are the gateway drug to Java, but Streams
are the real addiction—be ready to get hooked on them as you
develop Java applications.

fine to take a few minutes to admire the power of lambda
