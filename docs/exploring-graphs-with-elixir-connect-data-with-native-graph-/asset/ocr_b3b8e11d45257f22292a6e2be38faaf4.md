```
iterate(1900, year -> year <= upto, year -> year + 4)
```

The loop can start at the value of 1900. The second argument, a Predicate can check if the year as it progresses through the iteration is within the limits of the value in upTo. The third argument, a Function can increase the value of year by the desired step value of 4. The iterate function will generate a stream of numbers, starting at the seed value and stepping by the given increments up to the value checked in the Predicate. We can use this stream to refactor the imperative style code:

```
public int countFrom1900(int upTo) {
return (int) IntStream.iterate(
1900, year -> year <= upTo, year -> year + 4)
.filter(Year::isLeap)
.count();
}
```
