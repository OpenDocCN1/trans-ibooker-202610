# # Exception Handling vs. Functional Style

It's worth reiterating:

**Exception Handling**

Exception handling is fundamentally an imperative style of programming idea. Exception handling and functional programming are incompatible.

Some programmers think the issue with the `Stream` API and exception handling is the fact that the functional interfaces used by methods like `filter`, `map`, and so on don't deal with checked exceptions. This leads them towards a poor solution of throwing an unchecked exception that wraps the underlying checked exceptions. This may provide a temporary relief by quieting the compiler from complaining that the exception should be caught or thrown. But this doesn't address the fundamental issue of how the error is handled by the program.
