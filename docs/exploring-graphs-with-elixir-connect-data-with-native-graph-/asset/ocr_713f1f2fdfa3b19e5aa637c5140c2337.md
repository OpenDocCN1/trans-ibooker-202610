Our Try may exist in one of two forms: a Success, which carries data or a result, or a Failure, which carries an exception in the form of Throwable. We'll build our functional pipeline so that each stage in the pipeline will process the result that's carried in the Try given to it. In response, each stage will create another Try. This Try will contain the result of that stage if successful or an error otherwise. If a stage in the pipeline receives a Failure instead of receiving a Success, the function in that stage will merely pass along that failure downstream without processing.
