Suppose we're asked to get a list of all email addresses of everyone in a list. We'll have to use the `emailAddresses()` method for this operation. Given a single instance of Person, the `emailAddresses` method returns a collection of email addresses with zero or more elements. Whereas the `firstName` is a *one-to-one* function, the `emailAddresses` is a *one-to-many* function. Using `map()` for this problem won't yield the best results. Let's see why and look at how `flatMap()` will nicely solve the problem.

Let's examine the consequences of passing a *one-to-many* function, the `emailAddresses` method, to the `map` function:

```
List<List<String>> listOfListOfEmailAddresses = SAMPLE_DATA.stream()
.map(Person::emailAddresses)
.toList();

System.out.println(listOfListOfEmailAddresses);
```

As we iterated over the `SAMPLE_DATA` collection, we took each element and applied the `emailAddresses` method and collected the result into a list using the `toList` method. The output of this code is:

```
[[], [sara@example.com], [mike@example.com, baker@example.com],
[dev@example.com, shah@example.com], [slee@example.org, lee@example.com],
[nancy@example.com, xie@example.com, nx@example.com], [jill@example.com]]
```

In the output, we have a list of strings embedded within an outer list. In the code, we stored the result of the iteration into the variable `listOfListOfEmailAddresses` of type `List<List<String>>`.
