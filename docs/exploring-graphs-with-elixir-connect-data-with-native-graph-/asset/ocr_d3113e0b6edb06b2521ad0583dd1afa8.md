# # Online Resources

A number of web resources referenced throughout the book are collected in Appendix 3, Web Resources. Here are a couple that will help you get started with this book:

The OpenJDK website[1] for downloading the version of Java used in this book.

This book's page[2] on the Pragmatic Bookshelf website. From there you can download all the example source code for the book.
