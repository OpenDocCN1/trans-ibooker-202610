```
designing/fpij/AssetUtil.java
public static int totalAssetValues(final List<Asset> assets) {
    return assets.stream()
        .mapToInt(Asset::getValue)
        .sum();
}
```

We used the convenience of lambda expressions within this function. We transformed the List of Assets into a Stream, then mapped that into a Stream of values using the mapToInt method. Finally, we reduced or totaled the values in this stream to arrive at a single value using the sum method.
