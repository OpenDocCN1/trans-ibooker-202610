它创建名为 `affyQC` 的文件夹，其中包含 pdf 文件中的所有质量检查：箱线图、直方图、MA图、MAD图像、RNA降解图 和 QCstat。

#### 8.2.4.1 箱线图

箱线图是比较不同阵列的对数强度分布的图形表示（[图 8.2a](#c08.xhtml#fig8-2)）。这些箱线图评估归一化过程；因此，箱线图在归一化前后绘制。

#### 8.2.4.2 密度直方图

除了箱线图之外，`affyQAReport` 还生成对数强度的直方图（[图 8.2b](#c08.xhtml#fig8-2)）。原始数据的密度曲线未经平滑，而归一化后曲线变得平滑。

#### 8.2.4.3 MA图

MA图用于识别依赖于对数强度的偏差。MA图将每个阵列的对数强度与其参考阵列进行比较（[图 8.2c](#c08.xhtml#fig8-2)）。图的 Y 轴为一个阵列相对于参考中位阵列的对数比强度（“M”），X 轴为两个阵列的平均对数强度（“A”）。在重复组内，探针水平预计不会有很大差异，因此我们期望 MA 图从低强度到高强度以 Y = 0 轴为中心。每个重复的 MA 图单独显示参考阵列是每个组的中间阵列。这些图用于检查归一化方法的功效，因为归一化预计会校正依赖于对数强度的偏差。

#### 8.2.4.4 NUSE图

该图显示探针集的均一性。归一化未缩放标准误差 Normalized Unscaled Standard Error (NUSE) 图用于可视化来自探针水平模型拟合的标准误差（[图 8.2d](#c08.xhtml#fig8-2)）。对于每个基因，中位标准误差的值为 1。质量差的阵列具有更高的中位标准误差。

#### 8.2.4.5 RLE图

RLE（相对对数表达 Relative Log Expression）图表示基因或探针集的估计表达与中位表达的比率。假设所有探针均未差异表达；因此，RLE 图以 0 为中心（[图 8.2e](#c08.xhtml#fig8-2)）。如果图未以 0 为中心，则阵列质量较低。

#### 8.2.4.6 RNA降解图

为了结果的准确性，用于微阵列实验的 RNA 应具有良好的质量。RNA 降解图用于评估实验中使用的 RNA 质量。该图还可用于识别微阵列中的伪影。具有相似 RNA 降解模式的阵列可用于进一步分析。RNA 质量差的阵列将从 5′ 到 3′ 具有非常陡峭的斜率（[图 8.2f](#c08.xhtml#fig8-2)）。

#### 8.2.4.7 QCstat

QC 图提供平均背景、比例因子、被判定为存在的基因数量、对照基因 β-actin 和 GAPDH 的 3′:5′ 比率以及 spike-in 对照转录物的值等信息。图形从底部绘制，即第一个芯片绘制在基部，最后一个芯片绘制在顶部。每个由水平虚线分隔的图代表每个样本。每个图包含单个芯片的信息。蓝色区域表示比例因子在所有芯片平均比例因子的三倍范围内的区域。比例因子绘制为从中心线抬起的水平蓝色线。如果比例因子落在蓝色区域之外，则绘制为红色线（[图 8.2g](#c08.xhtml#fig8-2)）。

## 8.3 使用 RMA 方法对微阵列数据进行归一化

原始数据由于许多未知的变异来源总是存在偏差。为了消除偏差，进行数据归一化。该过程去除偏差以确保具有最高准确性的结果。此处使用稳健多阵列平均 Robust multi-array average (RMA) 方法进行数据归一化 [4]。该方法涉及三个步骤将对数强度值转换为基因表达值。

### 8.3.1 背景校正

此步骤通常校正背景噪声和强度。背景噪声可能来自许多来源，例如探针非特异性结合和洗涤不良引起的荧光。正在使用不同的方法校正背景噪声，稳健多阵列平均 RMA 算法是其中流行的方法。此步骤对于特异性杂交的准确测量是必需的。
