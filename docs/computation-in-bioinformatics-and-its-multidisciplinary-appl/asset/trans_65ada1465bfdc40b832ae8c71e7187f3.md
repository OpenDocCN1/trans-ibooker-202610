
## 13.2 同源建模

一般而言，与单独的序列相比，蛋白质的结构信息对药物发现过程更有价值。在生物科学中，基因序列的数量很容易获得，同时，经实验解析的蛋白质结构却非常少。因此，同源建模方法对于预测最终模型结构至关重要，该结构取决于靶蛋白与模板蛋白序列之间的进化关系。同源建模的两个主要观察结果包括三维结构决定氨基酸序列、蛋白质结构保守以及进化过程中与序列相关的微小变化 \[14\]。一般而言，同源建模的流程包括四个步骤：鉴定潜在靶点、序列比对、模型构建和模型优化。经实验解析的蛋白质结构可作为蛋白质结构建模的模板。从所得模板来看，选择模板的结构有一些标准，如查询序列与模板序列之间的相似度水平、经实验解析的结构质量，以及是否存在配体或辅因子。同源建模是基于蛋白质结构相似性和序列相似性进行预测的。因此，给定模板的实验结构来生成靶序列，其显著序列同一性高于30%。然而，结构预测包含错误，且实验上准确的结构很少达到。因此，靶模板序列30%的同一性在同源建模中仍然具有挑战性。同源模型的正确性受三个因素影响：(I) 靶蛋白与模板具有结构相似性，(II) 准确的靶模板比对，以及 (III) 优化模型的能力 \[15\]。

### 13.2.2 流程

构建具有相似模型结构精度的蛋白质模型已使用了多种不同的方法。以下流程可用于构建模型结构。
1. 从 `UniProtKB` 数据库获取蛋白质序列时，序列文件将以 `fasta` 格式下载。科学界为蛋白质序列提供了一种独特的文件格式。`fasta` 文件以 `>` 符号开头，该符号提供有关序列的特定信息。
```
>sp|-------|OPSD_
MNGTEGPNFYVPFSNATGVVRSPFEYPQYYLAEPWQFSMLAAYM FLLIVLGFPINFLTL
```
2. 对序列进行比对以发现与氨基酸序列最相似的靶标的模板序列。序列比对最广泛使用的算法是 `BLAST`（基本局部序列比对搜索工具）。`BLAST` 搜索会给出模板 `PDB` ID 及其同一性百分比的列表。
3. 创建蛋白质模型需要模板与靶序列之间的序列比对。可使用 `ClustalW` 服务器进行多序列比对（MSA），从而给出进化关系。`ClustalW2` 表示的共识符号如下：
* `*` 表示完美的序列比对。
* `:` 表示与显示强相似性的组相关的位点。
* `.` 表示与显示较弱相似性的组相关的位点。

比对后，基于查询序列与模板序列获得的较高相似性，将为靶蛋白构建三维蛋白质模型。最后，所得模型将用于评估和验证，可使用 `PROCHECK` 和 `WHATCHECK` 服务器进行。两个服务器均提供立体化学评估（键级、键长、键级、极性、非极性残基、坏接触等），以提高建模蛋白质结构的结构质量。

## 13.3 同源建模涉及的步骤

整体同源建模流程包括七个步骤：模板识别、序列比对、骨架生成、环建模、侧链建模、模型优化和模型验证。

### 13.3.1 模板识别

同源建模过程的起点可用于从 `PDB`、`SCOP`、距离矩阵比对和 `CATH` \[16, 17\] 中识别模板结构。有多种工具可用于搜索靶氨基酸序列的模板，采用不同的方法。其中，相似序列可通过 `BLAST` 搜索，该工具可提供成对序列比对以检测20%–30%序列同一性范围内的进化关系，并允许将靶序列与 `PDB` 数据库进行比较以识别可共享高度相似性的最佳模板结构。模板序列与靶序列的序列相似性可生成高精度的模型三维结构 \[18\]。

### 13.3.2 序列比对

序列相似性分析是发现同源序列最重要的步骤之一。选择一个或多个合适的模板后，序列相似性的程度将通过 `ClustalW`、`Clustal Omega` 和 `T-Coffee` 等序列比对工具进行分析。然后将同时进行比对校正。对于比对校正，如果比对序列之间存在缺失序列或多余序列，则序列将分别自动插入或删除。此过程可提高三维蛋白质结构的质量。

### 13.3.3 骨架生成

骨架生成是模型结构的关键过程之一，可使用 `Modeller` 或 `CASP` 等不同工具进行。序列比对后，可借助比对序列启动真正的模型构建以生成骨架。如果比对的残基不同，则可复制骨架坐标（N、Cα、C 和 O）及 Cβ。然后，保守残基被完全复制并生成三维模型 \[19\]。

### 13.3.4 环建模

同源建模中的环区在构建可参与活性位点和结合位点的三维模型结构中起重要作用。已为众多药物发现应用开发了多种环建模方法。在大多数情况下，靶序列与模板序列之间通过插入和删除存在少量间隙，同时骨架链发生少量构象变化。环区构象变化的预测非常困难。然而，这仅发生在诸如螺旋和链等二级结构元件中。但由于多种原因，构象变化不能发生在二级结构元件中。原因在于，首先，表面环可参与形成模板与靶之间的晶体接触；其次是小基团与大基团之间的相互交换；最后，如果脯氨酸氨基酸侧链中存在5元环且甘氨酸结构中存在氢原子，则从 Ramachandran 图中预测非常困难。此外，很难从甘氨酸或脯氨酸检测环残基的突变 \[20\]。

### 13.3.5 侧链建模

侧链建模是使用同源建模方法构建蛋白质结构的重要步骤。一般而言，侧链建模可通过将侧链放置到父结构骨架坐标上并生成 *从头* 建模模拟来完成。蛋白质侧链的低能量构象有限数量称为 rotamers。根据能量函数和搜索策略，rotamers 与优选蛋白质序列和正确骨架坐标一起被选出。对于侧链建模，可利用 `RAMP` 和 `SCWRL` \[21\] 服务器 \[22\]。
