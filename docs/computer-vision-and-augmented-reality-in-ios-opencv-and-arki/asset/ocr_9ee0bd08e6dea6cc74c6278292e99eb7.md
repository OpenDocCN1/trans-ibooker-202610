# Why Do You Use OpenCV instead of Core ML?

# Multiple Platforms Are Supported

Although Core ML could be the best option for an iOS 11-only iPhone app, whenever you want backward compatibility or would like to support multiple platforms, you will have to instead build a custom approach for each platform or use OpenCV.

Machine Learning isn’t right for every issue. Although Apple offers a couple of free open source models for items like object as well as scene detection, the field of computer vision is far bigger than just machine learning, and OpenCV is the most convenient way to get access to these resources.
