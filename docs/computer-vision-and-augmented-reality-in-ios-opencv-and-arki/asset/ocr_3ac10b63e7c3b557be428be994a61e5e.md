# Object Tracking

In any given scene, this applies to tracking one or more moving objects (Figure 4-11). This has historically been implemented after the original object has been observed to track real-world encounters. It is a very significant part of self-driving vehicles that will be launched by companies such as Uber and Tesla. It is possible to break object detection into two categories: generative and biased. The generative approach would describe visible features and minimize reconstruction errors in the hunt for the subject.

The discriminatory process is more efficient and accurate. It can be used to tell the difference between the issue and the meaning and has been the preferred way of monitoring. It goes with the name tracking by detection.
