To apply a Gaussian filter, kernels are used for image filtering. The dot product in a given portion of an image is determined using a kernel. The center of a kernel within the pixel are overlapped when the new pixel value is calculated. The nearby pixel values are multiplied by the necessary kernel values. A value that coincides with the center of the kernel is allocated with the pixel.
