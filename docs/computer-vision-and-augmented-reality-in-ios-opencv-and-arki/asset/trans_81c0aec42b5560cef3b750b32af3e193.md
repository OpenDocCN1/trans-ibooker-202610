## 利用 C++，扫描和读取条形码

让我们看看如何使用 Aspose.BarCode for C++ 来扫描和读取条形码。使用此功能的过程如下：

- 从 Barcode Reader 类创建一个实体。
- 创建一个包含条形码及其符号的图片文件的 Barcode Reader 示例。
- 使用 Barcode Reader->Read () 工具获取条形码的文本或形式。

以下编程示例演示了如何在 C++ 中搜索和解释条形码：

```
// Create instance of BarcodeGenerator class
System::SharedPtr<BarCodeReader> reader = System::MakeObject<BarCodeReader>(u"Code128.png", DecodeType::Code128);
while (reader->Read())
{
    // Display code text and Symbology Type
    System::Console::WriteLine(System::String(u"CodeText: ") + reader->GetCodeText());
    System::Console::Write(System::String(u"Symbology Type: ") + reader->GetCodeType());
}
reader->Close();
```

## C++ 用于读取具有多种符号的条形码

在大多数情况下，一张图片只包含一种条形码符号。即使如此，在某些情况下，一张图片可以在相对相似的时间内包含来自多种符号的条形码。在这种情况下，您应该有一组待扫描和读取的条形码符号。以下程序示例演示了如何使用 C++ 扫描包含多种条形码符号的图片：

```
// Set barcode symbologies

System::SharedPtr<BarCodeReader> reader = System::MakeObject<BarCodeReader>(u"RecognizingMultipleSymbologies.png", objArray);

```

## 概述

增强现实，也称为 AR，是一种允许我们在视野中看到虚拟对象和细节的技术。我们可以通过增强现实获得我们可以看到的对象的详细信息。这通过结合现实世界组件来改进屏幕。例如，如果我将手机指向一条街道，这将为我提供额外的信息，如餐馆、健身中心、医生的名称等。增强现实被称为数字知识与个人世界的实时结合。用户可以通过增强现实技术与其自然环境中的虚拟对象进行交互。佩戴虚拟现实眼镜的人使用手机或平板电脑屏幕来查看他们正在查看的任何对象的详细信息。

这里讨论了三种不同类型的 AR。

## 基于标记的 AR

数字世界与物理世界相互连接。我们必须知道用户将摄像机对准特定页面以将教育动画直接显示在期刊的纸张上。因此，系统最初应检测您从摄像机的实时视图中正在查看的是哪一页。这将通过使用页面上的独特图像或形状来实现。图像将被识别，动画将立即开始，跟踪到页面上的正确位置。用户也可以将该实际书籍移动以查看虚拟世界是否遵循页面的真实表面。系统识别的可识别图像被称为标记。几乎任何东西都可以用作标记，只要它具有足够独特的视觉特征即可。

## 无标记 AR

虚拟对象由用户移动。考虑一种增强现实技术，允许您将虚拟家具放置在客厅中。它使我们能够尝试不同的对象设计，以及位置组合。客户必须在该过程中确定虚拟对象的放置位置。它被称为“无标记 AR”。

## 基于位置的 AR

虚拟世界存在于现实世界中。

基于位置的 AR 将增强现实技术连接到特定位置。假设您走在一条不熟悉的公共道路上，看到手机摄像机显示一个虚拟街道标志，显示街道名称，那就是基于位置的 AR。而且，就像我们的 AR City 应用程序一样，这可以帮助您通过在您面前的实际路径上方叠加路线来移动到该位置。
