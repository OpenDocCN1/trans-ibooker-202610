# 第一章. 什么是微服务？
微服务在过去的五年里，即自撰写本书第一版以来，已成为一种日益流行的架构选择。我不能为随后的人气爆炸式增长邀功，但人们纷纷采用微服务架构的热潮意味着，虽然我之前记录的许多想法现在已被验证和测试，但新的想法也加入其中，同时一些早期的实践已不再流行。因此，我们再次需要提炼微服务架构的精髓，突出使其发挥作用的核心概念。
