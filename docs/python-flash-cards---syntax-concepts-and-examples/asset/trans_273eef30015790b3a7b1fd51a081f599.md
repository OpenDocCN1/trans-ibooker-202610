

## 列表切片

- 什么是切片？
- 如何创建从列表开头开始的切片？
- 如何创建列表末尾的切片？

列表副本让你可以在操作副本内容的同时，不影响原列表。

通过切片并省略两个索引，即可创建列表的副本。这会生成一个从列表开头到结尾的切片。

```python
>>> states = ['CA', 'CO', 'CT', 'DE']
>>> my_states = states[:]
>>> my_states
['CA', 'CO', 'CT', 'DE']
```

你对新列表所做的修改不会影响原列表：

```python
>>> my_states.append('HI')
>>> my_states
['CA', 'CO', 'CT', 'DE', 'HI']
>>> states
['CA', 'CO', 'CT', 'DE']
```

## for 循环可以让你每次处理列表中的一个元素

使用 for 循环遍历列表中的所有元素：

```python
countries = ['CAN', 'CHL', 'IND', 'AUS']
for country in countries:
    print(f"I'm flying to {country}.")
```

我要飞往 CAN。
我要飞往 CHL。
我要飞往 IND。
我要飞往 AUS。

使用切片遍历列表的一部分：

```python
for country in countries[:2]:
    print(f"I've been to {country}.")
```

我去过 CAN。
我去过 CHL。

## 列表排序

- 如何临时对列表排序？
- 如何永久对列表排序？

要以自然顺序的反向对列表排序，请将 reverse 参数设置为 True：

```python
>>> vowels = ['a', 'i', 'e', 'u', 'o']
>>> sorted(vowels, reverse=True)
['u', 'o', 'i', 'e', 'a']
```

reverse 参数也适用于 sort() 和 sorted()。若要反转列表的原始顺序，请使用 reverse() 方法：

```python
>>> vowels = ['a', 'i', 'e', 'u', 'o']
>>> vowels.reverse()
>>> vowels
['o', 'u', 'e', 'i', 'a']
```

sort() 或 sorted() 的 reverse 参数会得到自然顺序的反向；reverse() 方法会反转列表的原始顺序。

## 列表推导式是在一行中定义列表的紧凑方式：

```python
>>> nums = [10**exp for exp in range(5)]
>>> nums
[1, 10, 100, 1000, 10000]
```

列表推导式使用方括号、一个生成列表中每个元素的表达式，以及一个作为列表基础的 for 循环。

列表推导式可以修改现有列表中的每个元素：

```python
>>> states = ['CA', 'CO', 'CT']
>>> lower_states = [state.lower()
...   for state in states]
>>> lower_states
['ca', 'co', 'ct']
```

## 字典

![](img/b4d4158283a99b0f9a7bef8cfd6e5671_111_0.png)

字典允许你在各条信息之间建立联系，例如州的缩写和全名。字典中可以存储的信息量没有限制。

与列表一样，你可以处理字典中的全部信息，也可以处理字典中的任意部分。这些卡片展示了如何创建和使用字典。

## 字典方法

- 字典方法 get() 有什么作用？
- keys() 方法有什么作用？
- values() 方法有什么作用？
- items() 方法有什么作用？

如果字典中存在某个键，get() 方法会返回与该键关联的值。如果键不存在，get() 返回 None，而不是报错。

如果键不存在，你还可以传入一个默认值作为返回值（示例延续自卡片 4.1）：

```python
>>> capitals.get('AK')
'Juneau'
>>> capitals.get('WY')
>>> capitals.get('WY', 'unknown')
'unknown'
```

keys()、values() 和 items() 方法返回字典的不同方面，也有助于你遍历字典：

```python
>>> capitals.keys()
dict_keys(['AK', 'AL', 'AZ'])
>>> capitals.values()
dict_values(['Juneau', 'Montgomery', 'Phoenix'])
>>> capitals.items()
dict_items([('AK', 'Juneau'), ('AL', 'Montgomery'), ('AZ', 'Phoenix')])
```

根据你要对每个元素执行的操作，选择其中一个方法。

## 遍历字典

- 如何遍历字典中的所有键？
- 如何遍历字典中的所有值？
- 如何遍历字典中的所有键值对？

遍历字典可以只访问键。这是遍历字典时的默认行为（示例延续自卡片 4.1）：

```python
for state in capitals:
    print(f"State: {state}")
```

```
State: AK
State: AL
State: AZ
```

你也可以只访问字典中的值：

```python
for capital in capitals.values():
    print(f"Capital: {capital}")
```

```
Capital: Juneau
Capital: Montgomery
Capital: Phoenix
```

若要同时处理键和值，请使用 items() 方法：

```python
for state, capital in capitals.items():
    print(f"{capital}, {state}")
```

```
Juneau, AK
Montgomery, AL
Phoenix, AZ
```

## 字典示例

- 包含多个相似对象的字典是什么样的？
- 表示单个对象的字典是什么样的？

如果某个字典包含关于一个对象的多种信息，那么将一组字典存储在列表中会很有帮助：

```python
musicians = []

e_fitzgerald = {
    'first': 'Ella',
    --snip--
}
musicians.append(e_fitzgerald)

j_joplin = {
    'first': 'Janis',
    --snip--
}
musicians.append(j_joplin)
--snip--
```

要处理这类数据，请遍历列表，并依次处理每个字典：

```python
for musician in musicians:
    full_name = f"{musician['first']} "
    full_name += f"{musician['last']}"
    print(full_name)
```

```
Ella Fitzgerald
Janis Joplin
```

字典的键可以与一个值列表相关联：

```python
states_visited = {
    'Eric': ['AK', 'WY', 'WA', 'NH'],
    'Isaac': ['CO', 'NY', 'AK'],
    --snip--
}
```

当你遍历这些字典项时，每个值都是一个列表。为此，请在用于遍历字典的 for 循环内嵌套一个用于遍历列表的 for 循环：

```python
for name, states in states_visited.items():
    print(f"{name} has visited:")
    for state in states:
        print(f"  {state}")
```

```
Eric has visited:
AK
WY
WA
NH

Isaac has visited:
CO
NY
AK
```

## 条件语句

![](img/b4d4158283a99b0f9a7bef8cfd6e5671_125_0.png)

条件语句根据你设定的条件控制程序流程。这使你的代码能够根据这些条件以特定方式作出响应。你可以定义任意一组条件，并编写出能够完全按需响应的代码。

条件语句在执行其代码之前会检查某个条件是否为真：

```python
if truck_cost > 10000:
    print("That's too much!")
```

每个条件语句都有一个逻辑测试，该测试会评估条件以确定其是 True 还是 False。这些值就是布尔值。

下面是一些常用的逻辑测试：

| 逻辑测试 | 结果 |
|---|---|
| age == 21 | 相等 |
| age != 21 | 不相等 |
| age < 21 | 小于 |
| age <= 21 | 小于或等于 |
| age > 21 | 大于 |
| age >= 21 | 大于或等于 |
| name == 'jesse' | 字符串相等 |
| name != 'jesse' | 字符串不相等 |

你还可以检查某个元素是否在列表中：

```python
my_state in northwest_states
my_state not in northwest_states
```

if 语句由一行条件测试以及在该测试返回 True 时运行的一条语句或一个语句块组成：

```python
if plant_height < 3:
    print("Keep it in the greenhouse!")
```

if 语句还可以测试一个布尔值，并在该值为 True 时运行：

```python
if game_active:
    print("Let's play!")
```
