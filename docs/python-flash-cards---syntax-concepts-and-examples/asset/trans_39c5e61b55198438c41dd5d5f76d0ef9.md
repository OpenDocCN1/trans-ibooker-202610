## 操作系统

- 什么是操作系统？
- 操作系统做什么？
- Python 如何与操作系统交互？

*操作系统（OS）* 是控制计算机内部运行的软件。

操作系统执行底层功能，例如读写内存，并与硬盘、RAM、CPU、图形处理器、显示器、电池等外部硬件设备进行交互。Windows、macOS 和 Linux（如 Ubuntu 和 Fedora）都是主流的操作系统。

Python 是一种*跨平台编程语言*。你可以在任何操作系统上编写 Python 代码，它能在任何其他操作系统上运行。

## 文本编辑器

- 什么是文本编辑器？
- 什么是语法高亮？
- 有哪些适合初学者的文本编辑器？
- 有哪些更高级的文本编辑器？

*集成开发环境*（IDE）是一种具有**强大的项目管理功能**的文本编辑器。

典型的 IDE 功能包括调试工具、某些代码元素的自动填充，以及在你输入代码时捕获错误的能力。对于跨多个文件的项目，IDE 会检查这些文件，并帮助维护整个项目的一致性。

IDE 可以使代码测试更容易，并识别出你可以重构的代码部分。IDE 能帮助你与其他项目元素交互，例如 Web 应用程序中的 HTML 和 JavaScript，还能帮助你处理数据库。

流行的 Python IDE 包括 PyCharm、PyDev、Spyder 和 Visual Studio。

## 注释

- 什么是注释？
- 为什么注释在编程中很有用？
- 你应该写哪些类型的注释？

*注释*是程序中的代码行，程序在执行时会忽略它们。它们允许你添加关于程序工作方式的说明，帮助你自己和其他开发人员理解代码。

使用注释来说明：

- 引入重要变量时它们的作用
- 在考虑多种方法后你是如何处理某个问题的
- 你的函数有什么功能
- 程序中类的用途

编写注释能在你日后重新查看代码时提醒你代码的作用。注释还能帮助程序员团队有效协作。

项目规范（project specification，简称 spec）列出了程序需要完成的需求。

清晰的规范对于各种规模的项目都很重要，这样你才能清楚地了解目标是什么，以及项目是否成功。如果没有清晰的规范，你会浪费时间，并面临项目失败的风险。

项目规范说明了需要解决的问题以及用户将如何与程序交互。它应当规定程序将处理哪些类型的输入，以及程序需要生成哪些输出。

在学习编程时，你尝试的每个练习都是一个小型规范。定义良好的问题比定义不佳的练习更容易解决。优秀的程序员在协作处理现有项目时会寻找规范，并在投入新项目之前制定完整的规范。

## 框架

- 什么是框架？
- Python 有哪些可用的框架？

*版本控制*是随着项目的发展保存项目不同版本的过程。如果你弄坏了程序，你可以返回到之前可用的版本，或者简单检查程序在先前版本中的工作方式。

版本控制系统的工作原理是允许你进行*提交（commit）*，即保存项目中所有文件的当前状态。在实现一个新功能后，你会进行一次提交。

如果你犯了错误且不知道如何修复程序，你可以*检出（check out）*之前的提交，并从项目的一个可用版本重新开始。

*仓库（repository）*是你对项目所做的所有提交的集合；它还包含管理项目所需的其他资源。

*分布式版本控制系统*允许多个人在同一个项目上进行提交，并提供在协作项目中解决冲突的工具。

在撰写本文时，Git 和 Mercurial 是最常用的版本控制系统。

*数据库*是一种允许你存储和检索信息的程序。优秀的数据库经过高度优化，能够高效、可靠地处理大量数据。

数据库存储了世界上大部分信息。每当你从网站检索信息或向网站发布内容时，这些信息都是在读取或写入数据库。程序员参与的许多项目都会与数据库交互。

*结构化查询语言（SQL）*是一种专门用于与数据库交互的语言，但你不必懂 SQL 也能使用数据库。许多语言和框架会为你生成 SQL，因此你可以通过这些语言来操作数据库。然而，如果你认真对待编程，学习 SQL 是个好主意。

SQLite、PostgreSQL、MySQL、SQL Server 和 Oracle 是编程中最常用的数据库。
