# A while loop runs as long as a condition is True:

```
num = 0
while num < 3:
    print(num)
    num += 1
```

```
0
1
2
```

A list with at least one item evaluates to True. This loop runs until the list is empty:

```
bugs = ['bug 1', 'bug 2', 'bug 3']
while bugs:
    bug = bugs.pop(0)
    print(f"Fixing {bug}.")
print("All bugs fixed.")
```

```
Fixing bug 1.
Fixing bug 2.
Fixing bug 3.
All bugs fixed.
```
