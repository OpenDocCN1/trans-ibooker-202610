

## 设置参数的*默认值*允许函数调用使用默认值，除非调用时指定了其他值。

这个函数提供一杯咖啡。你可以指定杯子的大小，如果不指定，你会得到一杯 12 盎司的咖啡：

```python
def coffee(size=12):
    """Serve a cup of coffee."""
    print(f"Here's your {size} oz coffee!")

coffee()
coffee(16)
```

这里我们得到一杯 12 盎司的咖啡和一杯 16 盎司的咖啡：

```text
Here's your 12 oz coffee!
Here's your 16 oz coffee!
```

默认值很有用，因为它们使某些参数成为可选的。

## 模块

- 什么是模块？
- 如何创建模块？

模块是包含多个函数或类的 Python 文件。通过将这些函数存储在单独的文件中，你可以在程序中调用它们，而不必每次都输入完整的函数代码。

这个 area_functions.py 模块包含两个函数：

```python
"""A set of functions for calculating areas."""

def area_rect(w, h):
    """Calculate the area of a rectangle."""
    --snip--

def area_circle(r):
    """Calculate the area of a circle."""
    --snip--
```

这个文件中没有任何函数调用，因此这段代码在主编程序调用它之前不会运行。当你为模块中的函数添加功能或进行改进时，这些更改会立即可供所有使用它们的程序使用。

### 使用 import 关键字导入模块并访问其函数。

导入后，通过提供模块名称、一个点和函数名称来使用任何模块函数：

```python
import area_functions
my_area = area_functions.area_rect(4, 5)
print(my_area)
```

这段代码的输出与包含所有函数代码时的输出相同：

```text
20
```

使用 as 为模块指定别名，以便使用更短的函数调用。这里我们用 af 代替 area_functions：

```python
import area_functions as af
my_area = af.area_rect(4, 5)
print(my_area)
```

### 关于类

类将数据与操作组合在一起并组织代码。要使用类，需要创建类的一个实例。属性是与类关联的变量，方法是与类关联的函数。

这个类表示一条路径（例如一条徒步路径），包含两个属性 self.dest 和 self.len，以及一个方法 __init__()：

```python
class Trail():
    """A class to represent trails."""

    def __init__(self, dest, len=0):
        self.dest = dest
        self.len = len
```

Python 类通常使用首字母大写。当创建类的实例时，__init__() 方法会自动运行。在这段代码中，__init__() 需要一个参数 dest，并且有一个可选参数 len。

第一个参数 self 引用类的当前实例。将值 dest 和 len 附加到 self 上，使它们可供类中的所有方法以及类的任何实例使用。

### 继承

- 什么是继承？
- 什么是父类？
- 什么是子类？
- 如何使用继承？

通过使用*继承*，你可以创建一个继承原始类**属性**和**方法**的新类。

我们将创建一个表示自行车道的类：*父类*是 Trail，*子类*是 BikeTrail。定义子类的方式与普通类相同，但要在括号中包含父类名称：

```python
class BikeTrail(Trail):
    """Represent a bike trail."""

    def __init__(self, dest, len=0):
        super().__init__(dest, len)
        self.paved = True
        self.bikes_only = True
```

子类的 __init__() 方法通常需要使用 super() 调用父类的 __init__() 方法。super() 函数引用父类，允许你调用父类中的方法。子类可以定义属于自己的其他属性。例如，self.bikes_only 属性表示该路径是否对非骑行人员关闭。

### 重写父类方法

- 子类如何修改父类方法的行为？

### 子类可以通过使用 `super()` 访问父类方法来定制这些方法的行为。

这个 BikeTrail 类修改了 `run_trail()` 方法的行为。

```python
class BikeTrail(Trail):
    """Represent a bike trail."""

    def __init__(self, dest, len=0):
        --snip--

    def run_trail(self):
        """Simulate running the trail."""
        if self.bikes_only:
            print("You can't run this trail!")
        else:
            super().run_trail()

cross_trail = BikeTrail("Harbor Mountain", 5)
cross_trail.run_trail()
```

该方法首先检查这是否是一条仅供自行车使用的路径；如果是，则打印相应的消息：

```text
You can't run this trail!
```

如果路径允许跑步者，该方法将调用父类方法 `run_trail()`，从而继承普通 `Trail` 的行为。

### 你将类存储在模块中，并像函数一样导入它们。

这里我们将类 Trail 和 BikeTrail 存储在 trails.py 文件中：

```python
class Trail():
    """A class to represent trails."""
    --snip--

class BikeTrail(Trail):
    """Represent a bike trail."""
    --snip--
```

现在我们可以将这些类导入到另一个文件中：

```python
from trails import Trail, BikeTrail

verst = Trail("Mt. Verstovia", 4)
cross_trail = BikeTrail("Harbor Mt", 5)
```

使用点表示法导入整个模块：

```python
import trails

verst = trails.Trail("Mt. Verstovia", 4)
cross_trail = trails.BikeTrail("Harbor Mt", 5)
```

导入类时可以使用别名。通过存储类来组织代码，并使这些类可供多个程序使用。

### UNITTEST 模块

- 什么是 unittest 模块？
- 如何编写测试用例？
- unittest.assertEqual() 方法有什么作用？
- 还有哪些可用的断言方法？

unittest 模块提供了用于代码测试的工具，例如 TestCase 类。该类的断言方法确保你的代码生成正确的结果；其 setUp() 方法允许你在多个测试中使用相同的初始条件。

要测试函数或类，请将测试代码导入到一个新文件中，并编写一个继承自 unittest.TestCase 的测试用例。然后编写方法来测试代码行为。在修改代码、修复错误和添加功能时使用该模块。你可以在测试代码中进行以下断言：

| 断言 | 描述 |
| --- | --- |
| `assertEqual()` | 两个值匹配 |
| `assertNotEqual()` | 两个值不匹配 |
| `assertTrue()` | 值为 True |
| `assertFalse()` | 值为 False |
| `assertIn()` | 项目在列表中 |
| `assertNotIn()` | 项目不在列表中 |
