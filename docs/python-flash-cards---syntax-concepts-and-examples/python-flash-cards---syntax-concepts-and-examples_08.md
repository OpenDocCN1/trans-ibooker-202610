math 库提供了许多函数，用于执行平方根、三角函数以及处理数学常量等操作：

```
>>> import math
>>> math.sqrt(9)
3.0
>>> PI = math.pi
>>> PI
3.141592653589793
>>> math.sin(PI/2)
1.0
>>> math.log(100, 10)
2.0
```

标准库和第三方库也提供了更多的数学函数。在编写自己的数学算法来解决问题之前，请务必先查找现有的函数或库。
