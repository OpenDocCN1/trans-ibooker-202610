## 数据结构和类型

- 什么是数据结构？
- 什么是数据类型？
- 为什么数据结构很重要？
- 最常见的数据结构有哪些？

**数据结构**定义了你在编程语言中如何存储数据。每种编程语言都有核心的数据结构集合。*数据类型*指的是你正在使用的数据结构或存储在这些数据结构中的信息种类。

编程很大程度上专注于处理数据。你通过代码表示数据的方式会影响你能对该数据做什么：如果很好地建模数据，你的程序就更容易使用。

选择特定的数据建模方法会影响你思考数据的方式，因此了解编程语言中可用的数据结构将帮助你最好地表示项目中的信息。

最常见的数据结构包括变量、序列、映射、类和对象。Python 还有基于文本的数据类型，例如字符串，以及数值数据类型，例如整数和浮点数。

### 变量

- 什么是变量？
- 为什么变量很重要？
- 什么是静态类型语言？
- 什么是动态类型语言？
- 什么使 Python 成为动态语言？

**在 Python 中，_变量_是附加到数据片段的名称。你首先定义一个变量，然后在使用该数据片段时使用该名称。**

在_静态类型语言_中，你在定义变量时必须声明该变量表示的数据种类。Python 是一种_动态类型语言_，意味着你不必声明变量将表示的数据种类。在 Python 中，解释器在程序生命周期内检查与变量关联的数据并为你管理类型问题。

动态语言优先考虑程序员的时间而非处理器的高效使用，但在正确使用时仍然可以快速高效。静态语言优先考虑处理器效率而非程序员的时间。静态语言中的程序更长、更冗长，但可以高度优化。

字符串是由文本组成的值。字符串的经典示例是代码 "Hello, world!"。

字符串是任何语言中最简单的数据类型之一。程序内部和之间传递的大量信息都是字符串。

字符串被视为字符集合，因此字符串 "123" 与数值 123 不同。子字符串是字符串的一部分。

你可以用字符串执行许多操作：

- 将字符串连接在一起，称为拼接
- 将变量的值插入到字符串中，称为插值
- 更改字符串的大小写
- 从字符串中删除多余的空白
- 在字符串中搜索子字符串
- 替换字符串中的某些字符

在 Python 中，字符串使用单引号或双引号括起来。

### 序列

- 什么是序列？
- 为什么序列很重要？
- 你可以用序列做什么？
- Python 中有哪些序列？
- 什么是可变序列？

序列是一种以特定顺序存储项目集合的数据结构。在某些语言中，序列只能包含一种类型的项目；在其他语言中，包括 Python，序列可以包含不同类型的项目。

当你需要以特定顺序存储项目时，序列很重要。例如，网站用户列表可能按每个用户注册的时间排序。使用序列，你可以执行以下操作：

- 添加和删除项目
- 处理单个项目或项目组
- 确定值是否在序列中
- 查找重复或唯一项目
- 遍历序列并对每个项目执行某些操作
- 处理符合特定条件的项目。

在 Python 中，主要的序列类型是列表。列表是可变的，意味着你可以在创建后修改它们。元组是不可变序列，意味着它们在定义后不能更改。字符串是一种特殊的序列类型：序列中的每个元素都是一个字符。

### 映射

- 什么是映射？
- 为什么映射很重要？
- 你可以用映射做什么？
- Python 中主要的映射类型是什么？

映射是一种将两个或多个信息连接起来的数据结构，通常称为键值对。当你请求一个键时，你会得到其关联的值。一个映射结构可以存储许多键值对。

映射不仅仅存储数据。它们允许你在数据之间建立关系。例如，你可以将每个用户名与密码配对，将每个国家与其首都配对，并将每本书与其作者配对。

映射不限于单个数据片段：你可以使用单个数据片段作为键，使用序列作为值。例如，你可以将用户名与一组其他用户的序列配对，以定义一个用户与其他用户之间的关系。这是许多社交网络实现的核心。

在 Python 中，字典是主要的映射类型。确保你理解字典，因为许多高级 Python 数据结构都由字典表示。

### 类

- 什么是类？
- 什么是属性和方法？
- 什么是实例？
- 你可以用类做什么？

类是一种结构，允许你将与特定任务相关的数据和功能组合在一起。类的变量是属性。类的函数是方法。

类可以表示现实世界的对象或抽象概念。在定义类之后，你通过创建该类的实例或对象来使用它。你可以从一个类创建任意多个实例。

例如，你可能会使用一个类来表示网站用户。该类将具有与用户的用户名、密码、注册日期等相关的属性。方法将定义用户可以采取的操作，例如注册、身份验证、登录和注销。然后你可以为在网站上注册的每个用户创建一个实例。

许多外部库都是以类编写的，因此学习使用类可以更轻松地使用许多现有项目。

### 继承

- 什么是继承？
- 什么是父类？
- 什么是子类？

*继承*是基于另一个类构建一个类的思想，以便新类可以使用现有的方法和属性。当你的类建模的是相似的事物时，使用继承而不是从头开始一个新类。

想象你想建模一本书，因此你编写了一个名为 Book 的类。类属性可能是作者、标题和主题，方法可能是 describe_book()、show_sample_page() 和 review_book()。电子书是一种书籍，因此你可以让 EBook 从 Book 继承，以便它拥有 Book 的所有属性和方法。然后你只需要定义电子书特有的任何额外属性和方法，例如 file_size 属性和 download_book() 方法。

在这个例子中，Book 是父类，EBook 是子类。子类从父类继承。当你编写子类时，你可以添加父类中不存在的任何属性或方法，以及自定义从父类继承的行为。

布尔值表示 true 或 false。在 Python 中，这些值写为 True 和 False。

布尔值可以表示程序的状态或某个条件。例如，你可以使用 game_active、can_edit 和 polling_open 等变量，它们取 True 或 False 值。当这些值为 True 时，程序运行时某些代码段会被启用。

空值表示无。你会将空值赋给没有定义值的变量。在 Python 中，这写为 None。在逻辑比较中，None 评估为 False。

空值在许多情况下很有用。例如，你可以用它使函数的某些参数可选。如果提供了值，参数将被赋予给定值。如果未提供值，参数对程序没有影响。函数在无法完成工作时也可以返回 None，而不是生成可能导致程序崩溃的错误。

### 循环

- 什么是循环？
- 循环有什么用途？
- 什么是 for 循环？
- 什么是 while 循环？
- 什么是嵌套循环？

循环是一段可多次运行的代码块。当你需要根据特定条件多次重复操作时，可使用循环。两种循环类型是 for 循环和 while 循环。

for 循环按你指定的次数重复，或对序列中的每个元素各执行一次。例如，你可以编写一个运行 100 次的 for 循环来重复某个操作 100 次。你也可以编写一个 for 循环，对集合中的每个元素各运行一次。

while 循环在某个条件为真时持续运行。假设你有一个游戏循环，只要 game_active 变量被设置为 True 就一直运行。然后你可以在循环内设置多种情况，使 game_active 变为 False 从而结束游戏。你也可以使用 while 循环处理集合中的元素，该集合可能在循环运行期间不断有新的元素加入。只要集合中还有元素，你就可以继续处理它。当集合为空时，循环停止运行。

嵌套循环是另一个循环内部的循环。假设你需要一个循环来检查图像中的每个像素。你可以编写一个循环遍历一行中的每个像素，并在该循环内部添加第二个循环，遍历该行每一列中的每个像素。

在 Python 中，模块是包含代码的文件。模块用于将大型程序分解为更小的部分，以便更易于管理代码。

模块将复杂的程序划分为若干独立的部分。程序员将较大的项目拆分为不同的文件，每个文件都专注于项目的一个方面。这使得大型项目更容易编写和团队协作：每个程序员只需专注于自己负责的模块。

要创建模块，请将具有特定用途的代码移动到一个单独的文件中。要使用模块，请将其导入到你正在处理的文件中，使代码可用。你可以导入整个模块，也可以只导入所需的部分。

### 字符串

在此示例中，"I love Python!" 是赋给变量 message 的字符串：

```
>>> message = "I love Python!"
>>> print(message)
I love Python!
```

单引号和双引号都可以用于字符串，因此你可以在字符串中使用引号：

```
>>> python_quote = 'I said, "I love Python!"'
>>> print(python_quote)
I said, "I love Python!"
```

使用特殊序列 \t 和 \n 在字符串中插入制表符和换行符：

```
>>> message = "Grocery list:\n\tmilk\n\teggs"
>>> print(message)
Grocery list:
    milk
    eggs
```

字符串的长度没有限制。

### 字符串方法

- 什么是字符串方法？
- 如何更改字符串的大小写？
- 如何去除字符串中的空白？

### 

要更改字符串的大小写，请使用 `title()`、`upper()` 和 `lower()` 方法：

```
>>> name = 'ella fitzgerald'
>>> name.title()
'Ella Fitzgerald'
>>> name.upper()
'ELLA FITZGERALD'
>>> name = 'Ella Fitzgerald'
>>> name.lower()
'ella fitzgerald'
```

`lstrip()`、`rstrip()` 和 `strip()` 方法会删除字符串中多余的空白，有助于清理数据：

```
>>> name = '  jordan  '
>>> name.lstrip()
'jordan  '
>>> name.rstrip()
'  jordan'
>>> name.strip()
'jordan'
```

字符串方法可用于以特定格式呈现数据，或清理用户提交的数据。

在 Python 3.6 及更高版本中，你可以直接在字符串中使用变量：

```
>>> username = 'efermi'
>>> print(f"Welcome back, {username}!")
Welcome back, efermi!
```

f 是 format（格式）的缩写，告诉 Python 将大括号中列出的变量的值插入字符串中。这告诉 Python 使用给定变量的值来格式化字符串。

在 Python 3.5 及更早版本中，你必须使用 format() 方法：

```
>>> username = 'efermi'
>>> msg = "Welcome back, {}!".format(username)
>>> print(msg)
Welcome back, efermi!
```

占位符 {} 将被 format() 调用中包含的第一个变量替换。你可以根据需要包含任意数量的变量：

```
>>> msg = "Welcome, {} and {}!".format(
    username_0, username_1)
```
