*版本控制*是随着项目的发展保存项目不同版本的过程。如果你弄坏了程序，你可以返回到之前可用的版本，或者简单检查程序在先前版本中的工作方式。

版本控制系统的工作原理是允许你进行*提交（commit）*，即保存项目中所有文件的当前状态。在实现一个新功能后，你会进行一次提交。

如果你犯了错误且不知道如何修复程序，你可以*检出（check out）*之前的提交，并从项目的一个可用版本重新开始。

*仓库（repository）*是你对项目所做的所有提交的集合；它还包含管理项目所需的其他资源。

*分布式版本控制系统*允许多个人在同一个项目上进行提交，并提供在协作项目中解决冲突的工具。

在撰写本文时，Git 和 Mercurial 是最常用的版本控制系统。

*数据库*是一种允许你存储和检索信息的程序。优秀的数据库经过高度优化，能够高效、可靠地处理大量数据。

数据库存储了世界上大部分信息。每当你从网站检索信息或向网站发布内容时，这些信息都是在读取或写入数据库。程序员参与的许多项目都会与数据库交互。

*结构化查询语言（SQL）*是一种专门用于与数据库交互的语言，但你不必懂 SQL 也能使用数据库。许多语言和框架会为你生成 SQL，因此你可以通过这些语言来操作数据库。然而，如果你认真对待编程，学习 SQL 是个好主意。

SQLite、PostgreSQL、MySQL、SQL Server 和 Oracle 是编程中最常用的数据库。
