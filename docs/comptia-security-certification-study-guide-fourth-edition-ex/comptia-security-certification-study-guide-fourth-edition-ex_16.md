**内核模式**  又称特权模式，可直接访问硬件。过去作为用户模式组件运行的 Windows 的某些组件现在作为内核模式组件运行。这些是 Windows 管理器、图形设备接口（GDI）和图形设备驱动程序。

**密钥分发中心（KDC）**  Kerberos 中的一项服务，负责提供会话票证。

**每秒千位（Kbps）**  每秒 1024 位的数据传输速度。

**延迟**  网络性能变慢，通常由可用带宽需求增加引起。

**LAN**  *参见局域网。*

**租期**  指定 DHCP 客户端在必须向 DHCP 服务器续租之前可以使用 IP 地址的时间长度。该持续时间可以设置为无限期或预定时间段。您可以选择配置作用域以保留特定 IP 地址供 DHCP 客户端使用，甚至为网络上未启用 DHCP 的系统保留。

**最低有效位**  构成一个字节的 8 位中的最右位。注意，构成一个字节的 8 位中最左位被称为*最高有效位*。

**lmhosts 文件**  驻留在客户端硬盘上的文本文件，有助于将 NetBIOS 名称映射到 IP 地址。

**负载**  网络上存在的数据量。也称为网络流量。

**局域网（LAN）**  由两个或多个计算机连接以在小范围内进行通信组成，通常不超过一栋建筑。*另请参阅* 虚拟局域网。

**本地组**  位于 Windows 系统本地 SAM 数据库中的组，用于为该系统上的资源分配权限。

**注销（或退出）**  终止与系统会话的程序。

**登录（或登入）**  检查到网络的程序，以便您可以访问文件和其他网络信息。当您有权访问网络时，称您已登录。

**环回地址**  以 127.*x.x.x* 开头的任何地址，用于验证 TCP/IP 软件堆栈是否已加载并在系统上正常运行。

**Microsoft Message Analyzer**  由微软提供的抓包工具。Microsoft Message Analyzer 已取代 Microsoft Network Monitor。

**MIME**  *参见多用途互联网邮件扩展。*

**镜像**  将信息复制到另一块硬盘。如果一块硬盘出现故障，另一块硬盘会立即提供完全相同的信息。

**调制解调器**  *参见调制器/解调器。*

**调制器/解调器（调制解调器）**  用于将计算机的数字信号转换为可在电话线上传输的模拟信号的设备。也称为数据电路终接设备。

**最高有效位**  构成一个字节的 8 位中最左边的位。另请注意，8 位值的最右位被称为*最低有效位*。

**MS-CHAP**  *参见 Microsoft Challenge Handshake Authentication Protocol。*

**多宿主系统**  配置了多于一个网络适配器的计算机。

**多用途互联网邮件扩展（MIME）**  一种互联网协议，允许电子邮件消息中包含不同形式的数据，如文本、音频、视频和图像。

**NAT**  *参见网络地址转换。*

**NBTSTAT**  用于排查 NetBIOS 名称与 IP 地址之间名称解析的实用程序。

**NetBIOS**  *参见网络基本输入/输出系统。*

**NetBT**  NetBIOS over TCP/IP。一种软件标准和命名约定，用于在 TCP/IP 协议上使用 NetBIOS 服务。

**netcat**  用于在系统上打开端口并从网络另一端向该端口发送数据的程序。

**netstat**  用于报告协议统计信息和当前活动连接的 TCP/IP 命令行实用程序。

**网络**  两个或多个计算机连接以便能够通信。

**网络访问控制（NAC）**  在允许系统访问网络之前评估系统状态的技术。

**网络适配器**  *参见* 网络接口卡。

**网络地址转换（NAT）**  一种服务，允许来自私有地址的请求被转换为公共地址——从而隐藏内部网络资源。

**网络基本输入/输出系统（NetBIOS）**  PC BIOS 的网络扩展，使 I/O 请求能够从远程计算机发送和接收。常称为应用程序编程接口（API）。

**网络基础设施**  将计算机连接到网络的物理设备。这包括用于控制网络的电缆、集线器、路由器和软件。

**网络接口卡（NIC）**  安装在计算机中以使其能够通过网络与其他计算机通信。NIC 将计算机内部的并行信号转换为通过网络电缆传输的串行信号。也称为适配器卡、接口卡或媒体访问卡。

**网络层**  OSI 模型的第 3 层，负责逻辑寻址和路由。

**网络地图**  网络的详细地图。包括机器和其他硬件的清单、电缆布局地图以及记录网络的其他信息。

**网络监视器**  Windows 工具，可“嗅探”网络上的数据包并帮助诊断协议相关问题。截至 2012 年，网络监视器已被 Microsoft Message Analyzer 取代。

**网络分段**  通过将不同类型的系统分离到网络的不同部分来优化网络并控制通信的一种方法。





**离线存储**  一种用于存储数据备份的媒体，例如磁带，且不易访问。数据必须从磁带复制回硬盘才能访问。

**异地存储**  与文件服务器位于不同地点的场所，用于存放备份磁带。完整的备份应始终保存在异地。

**在线备份**  存储在在线的备份，因此可以立即使用。

**开放系统互连（OSI）模型**  这是 PC 网络中最常用的网络模型，由七层组成：应用层、表示层、会话层、传输层、网络层、数据链路层和物理层。

**OSI**  *参见* 开放系统互连。

**数据包**  在网络上传输的、大小可控的数据块。数据包必须包含头部区、数据区，以及在大多数情况下的循环冗余校验（CRC）区，也称为尾部。

**PAP**  *参见* 密码验证协议。

**分区**  物理磁盘的逻辑划分，被视为独立的硬盘。分区硬盘后，需要决定哪个分区为系统分区，哪个为活动分区。*另见* 活动分区 *和* 系统分区。

**直通身份验证**  当凭据不在本地目录服务数据库中时发生。

**密码**  登录时访问网络的密钥。

**密码验证协议（PAP）**  一种身份验证协议，客户端通过向服务器传递用户名和密码来对自身进行身份验证。服务器随后将此信息与密码存储进行比较。由于密码以明文形式传递，因此在安全问题至关重要的环境中不推荐使用。

**渗透测试**  一种安全测试类型，测试人员使用黑客技术入侵系统，以确定系统是否安全。

**独立磁盘冗余阵列（RAID）** 一种容错磁盘配置，其中部分物理存储包含有关存储在磁盘上的数据的冗余信息，从而在访问硬盘数据时出现问题时最大限度地减少数据丢失。

**注册表**  Windows 系统上所有软件和硬件设置的中央数据库。

**注册表编辑器**  用于查看和修改注册表的 Microsoft 工具（REGEDIT.EXE 或 REGEDT32.EXE）。

**远程访问服务**  运行在服务器上的拨号服务，使用电话线路使用户能够远程访问网络。

**远程身份验证拨入用户服务（RADIUS）**  一个中央身份验证服务器，可用于验证尝试连接有线或无线网络、拨入 RAS 服务器或“vpn”到 VPN 服务器的个人。

**远程过程调用（RPC）**  程序员用于创建由多个过程组成的应用程序的进程间通信（IPC）机制——部分在本地计算机上运行，其他部分通过网络在远程计算机上运行。另指程序向网络上的计算机发送的请求，要求计算机执行任务。

**请求评论（RFC）**  由互联网工程任务组（IETF）发布的文档，定义了 TCP/IP 的标准。

**保留**  为特定 DHCP 客户端保留的 IP 地址。

**RFC**  参见 请求评论。

**RJ-45 连接器**  与双绞线电缆一起使用的连接器。它看起来像电话连接器，但更宽。有八个针脚；因此有八根导线。Ethernet 实现可以使用四根或全部八根导线。如果仅使用四根导线，应了解的针脚为 1、2、3 和 6。RJ-45 补丁电缆可以直接插入双绞线网络适配器的背面，或较少见地连接到外部收发器。补丁电缆通常连接到墙上插座，插座通过配线架最终连接到布线集线器。

**基于角色的访问控制（RBAC）**  访问权限基于用户被分配的角色授予。

**根**  （1）目录结构的顶层，其之上无法进行引用。（2）UNIX/Linux 中找到的管理员账户。

**路由**  可用于添加、修改、删除和显示一个或所有接口的路由信息的命令。用于配置网络路由表。

**路由器**  连接一个以上物理网络或网络段的设备。当数据包到达路由器时，路由器读取网络地址并将其转发到目的地或另一个路由器。

**路由**  将数据包从一个段转发到另一个段，直到到达最终目的地的过程。路由器在将数据包传递之前通过查看收到的网络包的网络地址来决定将网络数据包发送到何处。

**路由表**  路由器所知的可用路由列表。路由器用于确定数据是否 destined for 本地网络。

**RPC**  参见 远程过程调用。

**SAM**  参见 安全访问管理器数据库 和 安全账户管理器。

**可扩展**  具有根据需求变化的能力。

**脚本**  一种小型未编译程序，用脚本语言编写，可在系统上或网页内执行。

**密钥加密**  使用密钥管理服务器中的单个密钥，即称为批量加密密钥的密钥，对消息进行加密和解密。密钥加密的两个示例是 DES 和 CAST。

**安全散列算法（SHA）**  用于验证数据完整性的散列算法。

**安全套接层（SSL）**  用于加密通信的基于证书的协议。

**安全账户管理器（SAM）数据库**  一个安全数据库，维护 Windows 系统上的所有用户和组，以及他们的密码和其他属性。

**会话**  两台计算机之间可靠的对话。由于面向连接的服务可以提供可靠的通信，因此在两台计算机需要在会话中通信时使用。会话在两台计算机决定通信结束时保持。会话就像电话呼叫一样。你通过拨号（握手）建立电话呼叫，与对方交谈（交换数据），说“再见”，完成后挂断。

**共享**  使打印机、光驱和目录等资源可供网络上的用户使用的设置。

**外壳**  提供服务器与客户端或用户与操作系统之间通信的程序。

**屏蔽双绞线（STP）**  在导电线芯与外部绝缘之间具有箔包屏蔽的双绞线电缆。

**SID**  *参见 security ID.*

**简单邮件传输协议（SMTP）**  用于在互联网上传送邮件的协议。

**简单网络管理协议（SNMP）**  用于监控和配置网络设备的互联网标准。SNMP 网络由管理系统和代理组成。

**单点登录（SSO）**  只需登录一次即可访问不同环境中的资源。

**SMTP**  *参见 简单邮件传输协议.*

**嗅探器**  一种网络监控工具，分析网络上的流量并可帮助解决与基础设施相关的问题。

**SNMP**  *参见 简单网络管理协议.*

**SSID**  *参见 Service Set Identifier.*

**静态条目**  手动添加的条目。这可能适用于静态配置的路由器，其中路由表由网络管理员手动更新，ARP 缓存或 hosts 文件和 DNS。

**双绞线电缆**  一种导线绞合以帮助减少干扰的电缆类型。双绞线电缆有两种类型：屏蔽和非屏蔽。*另见* 同轴（或同轴）电缆 *和* 光纤电缆。

**UDP**  *参见* 用户数据报协议。

**无人值守备份**  当备份程序在计划时间启动、执行指定的备份然后终止时发生。

**UNC**  *参见* 通用命名约定。

**统一资源定位符（URL）**  提供万维网上文档的地址。

**不间断电源（UPS）**  常见于文件服务器的电池备份系统，用于在停电时保护数据。

**通用命名约定（UNC）**  连接到计算机上共享资源的一种标准化方式。语法始终为 \\computername\sharename。

**Unix**  一种功能强大的多任务操作系统，可以在后台运行许多进程，同时使用户能够在前台使用应用程序。多用户功能使许多用户能够使用同一台机器。Unix 曾是多种强大且多样化实用程序的领导者，这些实用程序已被移植到其他操作系统。

**非屏蔽双绞线（UTP）**  在导电线芯与外部绝缘之间没有任何屏蔽的双绞线电缆。

**UPS**  *参见* 不间断电源。

**URL**  *参见* 统一资源定位符。

**用户**  任何访问网络的人。

**用户账户**  代表访问计算机或网络资源的用户。用户账户不一定代表个人；它们也可以是服务的账户，例如 SQL Server 账户。






- **用户数据报协议（UDP）** 提供无连接的数据报服务，是一种不可靠的“尽力而为”交付方式。UDP 不保证数据报的到达，也不承诺交付的数据包顺序正确。不需要数据接收确认的应用会使用 UDP。

- **用户模式** 也称为非特权处理器模式。应用程序和各种子系统在此模式下运行。用户模式旨在防止应用程序导致操作系统崩溃。

- **用户权利** 允许用户在计算机上执行特定操作。通过设置用户权利，可以控制用户或组执行的操作。有些供应商可能使用术语“系统权限”。

- **用户名** 用户用于登录计算机系统的名称。

- **UTP** 请参阅非屏蔽双绞线。

- **虚拟局域网（VLAN）** 在较大的网络中，将需要彼此通信的少量 PC 划分为一个小分组。可以通过指定 PC 所连接交换机上的端口来实现。

- **虚拟机** 由虚拟化软件（虚拟机监控程序）提供的模拟计算机，可运行 Windows Server、Windows 客户端和 Linux 等操作系统。

- **虚拟内存** 当计算机需要更多内存时，由 Windows 创建的用于模拟 RAM 的机制。它根据需要利用计算机的硬盘来实现这一点。

- **虚拟专用网络（VPN）** 通过公共网络提供带安全通信信道的隧道。VPN 使用 L2TP 和 SSTP 等协议，在隧道创建后加密客户端与服务器之间的通信。

- **病毒** 对系统造成危害的恶意代码。

- **病毒特征库** 已知病毒的数据库，防病毒软件在扫描文件以消除病毒时使用该数据库。病毒特征库必须保持更新。

- **VLAN** 请参阅虚拟局域网。

- **卷** 物理驱动器上被视为单个单元的空间的逻辑划分。卷是硬盘上用于存储信息的一部分。

- **卷集** 将任意类型硬盘（IDE、SCSI 或 ESDI）上不同大小的可用空间区域合并为单个卷（驱动器号）。卷集不提供任何容错或性能提升，仅用于将多个可用空间区域合并为一个卷。

- **VPN** *请参阅*虚拟专用网络。

- **漏洞测试** 一种安全测试类型，涉及运行软件来检查系统配置中的弱点。

- **WAP** *请参阅*无线接入点。

- **知名端口** *请参阅*端口号。

- **捕鲸攻击** 针对非常重要人物（例如公司首席执行官）的网络钓鱼攻击。

- **Wi-Fi 保护访问（WPA）** 一种无线安全协议，旨在加密无线通信并提供身份验证服务。

- **Wi-Fi 保护访问 2（WPA2）** 一种无线安全协议，已取代 WPA，旨在加密无线通信并提供身份验证服务。WPA2 经过改进，使用了更安全的 AES 对称协议。

- **Windows 更新** 一种服务，你可以连接并查看系统的可用更新，也可以从系统安装这些更新。

- **有线等效加密（WEP）** 一种旧的无线安全协议，使用对称密钥加密无线通信。WEP 已弃用，并被 WPA2 取代。

- **无线接入点（WAP）** 一种网络设备，允许无线客户端连接到无线网络。无线客户端连接到接入点，并通过接入点向网络上的其他主机发送数据。

- **无线局域网（WLAN）** 允许系统通过无线连接进行通信的网络。

- **无线组网** 配置为使用红外、蜂窝或微波等通信技术的网络，因此无需电缆连接。

- **工作组** 一组各自独立管理的计算机。

- **工作站** 用于访问网络的客户端计算机。

- **零日漏洞利用** 对制造商未知且尚无安全补丁的软件或硬件的利用。
