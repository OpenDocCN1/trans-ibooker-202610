## 引言

CompTIA Security+ 认证是一项快速增长的认证，涵盖安全的各个方面，包括物理安全、密码学、操作安全和网络安全主题。这是一项全面的认证，将测试您对安全概念的技术知识和对安全的行政知识。

本引言的目的是告知您如何进行 Security+ 认证考试以及在考试中可能遇到哪些类型的问题。我们将首先了解获得 Security+ 认证的价值，然后回顾考试的结构。接下来，我们将了解如何安排考试，然后我们将检查考试中可能遇到的不同类型的问题。最后，我们将介绍考试准备清单，其中列出了每个目标以及可在其中找到该目标覆盖内容的章节。

## Security+ 认证的价值

当今 IT 行业最热门的话题之一是安全，CompTIA Security+ 认证是证明您对安全和安全原则有扎实知识的绝佳方式。CompTIA Security+ 认证是一个厂商中立的认证，涵盖防火墙、安全策略、入侵检测系统和安全评估等热门主题，仅举几个热门技能。获得 Security+ 认证是向潜在雇主展示您拥有帮助其组织创建安全环境所需的技能的绝佳方式。

通过 Security+ 考试的候选人证明他们对安全的许多方面都有知识。以下是 Security+ 考试测试您的安全领域：

- **1.0 威胁、攻击和漏洞** 涵盖网络攻击类型、应用程序攻击、恶意软件、漏洞、威胁行为者和威胁向量以及安全评估类型等主题。
- **2.0 架构与设计** 涵盖安全网络设计、虚拟化和云计算、安全应用程序开发和部署、身份验证和授权、网络安全弹性、物理安全和密码学概念等主题。





- **3.0 实施** 涵盖诸如实施安全协议、实施主机和应用安全、实施安全网络设计、安装和配置无线安全设置、实施安全移动和云解决方案、实施身份验证和授权解决方案，以及实施 PKI 基础设施等主题。
- **4.0 运维与事件响应** 涵盖诸如用于评估组织安全的工具、事件响应、事件后应用缓解技术以及数字取证等主题。
- **5.0 治理、风险与合规** 涵盖诸如安全控制类型、法规和标准、安全策略、风险评估以及数据隐私解决方案等主题。

## 测试结构与规范

Security+ 考试（SY0-601）大约包含 90 道题目，你有 90 分钟完成考试。通过考试所需的分数为 750，分值范围为 100 至 900。

通过 Security+ 考试后，你的认证有效期为通过之日起三年。三年后，你需要参加并通过当前版本的考试以维持认证。

以下是 Security+ 认证考试将测试你的安全域列表。每个域都显示了一个百分比，表示考试中大约有多少题目会涵盖该域。

| --- | ---: |
| 1.0 威胁、攻击与漏洞 | 24% |
| 2.0 架构与设计 | 21% |
| 3.0 实施 | 25% |
| 4.0 运维与事件响应 | 16% |

## 安排考试

当你准备参加 CompTIA Security+ 考试时，你可以通过 Pearson VUE 安排考试，Pearson VUE 是一家认证测试提供商。你可以在 www.vue.com/comptia 通过 VUE 安排考试，或致电 1-877-551-7587（美国和加拿大）。通过 VUE 的 OnVUE 在线测试解决方案进行安全的在线测试也是一个选项。请查看 VUE 网站了解有关在家测试的更多信息。

以下是你的考试详情：

- **考试名称：** CompTIA Security+ 认证
- **考试编号：** SY0-601
- **允许时间：** 90 分钟
- **题目数量：** 大约 90 道
- **通过分数：** 750（分值范围为 100 至 900）
- **价格：** $370 USD

你需要安排的考试是 SY0-601 考试（2021 年 Security+ 认证考试）。安排考试后，请务必遵循以下一些常见做法来帮助你为考试日做准备：

- **复习：** 在考试前几天，翻阅本书的章节并重读每章末尾的 Exam Watch 注释和 Two-Minute Drill。
- **滋养大脑：** 确保在考试前一晚睡个好觉并吃一顿营养早餐。你要确保自己在精神上为考试做好准备。
- **提前到达：** 建议你提前 15 分钟到达考试现场以确保你已准备就绪。
- **阅读所有选项：** 回答问题时，请阅读所有选项然后再选择你的答案。

## 题目类型

计算机化测试题目可以以多种方式呈现。本节描述了一些可能的问题格式，并指出你在 Security+ 认证考试中可能遇到的格式。

**多选题** Security+ 认证的大多数题目都是多选题格式，要么只有一个正确答案，要么有多个正确答案需要你选择。多选题中一个有趣的变化是是否告知你正确答案的数量——你可能会被告知选择所有适用项。

**性能型** Security+ 考试将包含若干性能型题目，旨在验证你对主题的理解。对于性能型题目，你可能被要求在图表中标记项目，将术语框拖到正确的定义上，甚至在图形中识别关键元素。
