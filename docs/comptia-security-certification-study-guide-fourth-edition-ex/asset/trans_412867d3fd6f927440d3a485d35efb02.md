
- **拒绝服务（DoS）** 一种攻击类型，黑客向系统发送大量数据包，导致系统崩溃或繁忙到无法处理合法请求。
- **设备驱动程序** 系统用来与系统中各种硬件组件通信的小程序。
- **DHCP** *参见*动态主机配置协议。
- **差异备份** 仅备份自上次完整备份或差异备份以来发生变化的文件，并且不修改存档位。*另请参阅*完整备份和增量备份。
- **临时迪菲-赫尔曼（DHE）** TLS 用于确保通信安全的密钥协商协议。
- **目录路径** 文件系统上指向某个目录的路径，可能包含服务器名称、卷以及其他通往该目录的路径名。
- **目录复制** 出于容错原因，将目录数据库从一个系统复制到另一个系统的过程。
- **目录服务** 负责维护环境中的对象目录的服务。Active Directory 和 eDirectory 是目录服务的示例。
- **目录同步** 将目录数据库复制或同步到远程系统的过程。
- **目录树** 文件结构，包括根目录下的目录和子目录布局。
- **自主访问控制（DAC）** 当创建文件或文件夹的人就是所有者并负责其安全时的访问控制。
- **磁盘双工** 与磁盘镜像类似，但使用两块磁盘控制器卡——镜像集中的每个驱动器各用一块卡。这样可在其中一个控制器发生故障时提供冗余。*另请参阅*磁盘镜像。
- **磁盘镜像** 通过将一个硬盘上的数据镜像到另一个硬盘来提供冗余。如果活动驱动器发生崩溃或其他问题，操作系统会自动开始使用备份驱动器并通知您切换。*另请参阅*磁盘双工。
- **带奇偶校验的磁盘条带化** *参见*独立（或廉价）磁盘冗余阵列。
- **无盘工作站** 没有硬盘驱动器的工作站。无盘工作站是一个已经存在一段时间的概念。设计用于规模相当大的环境，最初有两个目标。第一是通过移除终端用户的本地存储并要求所有数据和应用程序存储在服务器上来增强网络安全性。通过使用服务器权限管理用户对此信息的访问，局域网管理员可以更有效地控制环境。无盘工作站的第二个目标是大容量存储的成本。通过消除本地存储的成本，特别是随着工作站数量的增加，公司可以省钱。随着大容量存储成本的下降，这个问题已变得不那么重要。
- **分布式应用程序** 在网络中的计算机之间分担处理任务的应用程序，例如客户端/服务器应用程序，其中处理任务在客户端计算机和更强大的服务器计算机之间划分。通常，在客户端计算机上运行的部分称为前端，在服务器计算机上运行的部分称为后端。
- **分布式拒绝服务（DDoS）** 一种攻击类型，黑客使用多个系统作为攻击源，以产生足够的流量使受害者的系统崩溃。
- **DLL** *参见*动态链接库。
- **DLP** *参见*数据丢失防护。
- **DNS** *参见*域名系统。
- **域** 包含域控制器的一组计算机，它们共享账户信息并拥有一个集中式账户数据库。（不要与互联网域混淆，例如 microsoft.com。）
- **域控制器** 保存 Active Directory 数据库的系统。
- **域名系统（DNS）** 一种将 IP 地址映射到完全限定域名的服务。它将主机名解析为 IP 地址，反之亦然（通过反向查找）。
- **容错** 确保数据和资源（如互联网连接和服务器）保持正常工作的能力。例如，如果某段电缆断裂，流量将被重新路由。如果服务器崩溃，则另一台服务器会启动以取代它。
- **FDE** *参见*全盘加密。
- **光纤电缆** 可在物理层使用的三种物理介质之一，以调制光脉冲的形式传输数字数据信号。光纤由一根极细的玻璃圆柱体（称为纤芯）组成，周围环绕着一层同心玻璃层，称为包层。对于大多数光纤电缆，导电元件是一种特殊的玻璃纤维，而不是铜或其他导电金属。光纤电缆的美妙之处在于它不受电磁干扰，并且比大多数电缆类型具有多得多的带宽。每条电缆中有两根光纤——一根用于发送，一根用于接收。*另请参阅*同轴电缆和双绞线电缆。
- **文件分配表（FAT）** 用于 DOS 和早期 Windows 版本的旧文件系统，不支持任何安全功能，如权限、加密和审核。
- **文件分配表 32（FAT32）** 一种较旧的文件系统，不支持权限、加密和审核等安全功能。FAT32 是 FAT 的 32 位版本，用于较旧的 Microsoft 操作系统，已被 NTFS 取代。
- **文件和打印服务器** 控制和共享打印机及大量数据的服务器。这些服务器通常是高性能计算机，专门用于尽可能快速地在磁盘和网络之间移动文件。文件和打印服务器在允许用户访问文件或使用打印机之前，还会检查每个资源的访问控制列表（ACL）。如果用户或用户所属的组未列在 ACL 中，则不允许用户使用该资源。
- **文件服务器** 运行网络操作系统并处理来自工作站的请求的网络计算机。
- **文件系统** 网络操作系统用于处理和存储文件的规则。
- **文件传输协议（FTP）** 一种主要设计用于通过网络传输数据的协议。FTP 既表示协议，也表示用于此目的的工具。它被创建用于将一个主机的数据文件快速高效地传输到另一个主机，而不影响远程主机的资源。
- **主机文件** 用于将完全限定域名映射到 IP 地址的文件。主机文件用于名称解析，每个 IP 地址及关联名称占一行。
- **HTTP** *参见*超文本传输协议。
- **HTTPS** *参见*安全超文本传输协议。
- **集线器** 星型拓扑中用于将计算机连接到 LAN 的设备。集线器被视为不安全的网络设备，已被交换机取代。*另请参阅*有源集线器。
- **超文本传输协议（HTTP）** 互联网上使用的协议，允许客户端从 Web 服务器请求网页，并允许客户端与这些 Web 服务器进行交互。HTTP 是一种无状态协议，这意味着 Web 服务器不知道客户端请求过或未请求过什么，也无法跟踪请求过特定内容的用户。这种系统不允许与 Web 服务器进行良好的交互，但确实允许检索存储在网站上的 HTML 页面。
- **安全超文本传输协议（HTTPS）** HTTP 的安全版本，允许您使用安全套接字层（SSL）以加密格式连接到网站并接收和发送内容。HTTPS 最常用于电子商务网站，允许您发送个人信息而不必担心互联网黑客正在查看此信息，尤其是信用卡号和其他机密数据。您可以通过网站地址以 https:// 而不是 http://（即常规 HTTP 协议）开头来判断是否使用了 HTTPS。另一个使用 HTTPS 的迹象是：在浏览器中，状态栏或地址栏中出现锁形图标，表示正在使用安全连接。HTTPS 不会用于整个电子商务网站，因为加密和解密过程会减慢连接时间，因此只有包含个人信息的页面才使用 HTTPS。
- **ICMP** *参见*Internet 控制消息协议。
- **IDS** *参见*入侵检测系统。
- **IEEE** *参见*电气与电子工程师协会。
- **ifconfig** 一个用于查看和排查 TCP/IP 设置的 Linux 命令行工具。
- **IIS** *参见*Internet 信息服务。
- **IMAP** *参见*Internet 消息访问协议。
