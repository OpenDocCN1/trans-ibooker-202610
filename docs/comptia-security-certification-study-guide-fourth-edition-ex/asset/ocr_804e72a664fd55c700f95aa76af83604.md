Platform as a Service (PaaS) With PaaS, the cloud provider provides a development environment, also known as a runtime environment, to cloud customers that allows them to create applications in the cloud. Examples of PaaS are programming tools, code libraries, web servers, web services, and database environments. The benefit is that a developer can use these features in the cloud without needing to install them as on-premises servers, which would traditionally be the case. Using Azure SQL Database is an example of PaaS.

Infrastructure as a Service (IaaS) IaaS is a way to create a virtual data center in the cloud because it allows you to provide servers, virtual machines, storage, networks, and other data center resources in the cloud. When a customer subscribes to IaaS, they only pay for the resources used. For example, when you use Azure Virtual Machine, you are using IaaS. Note that with IaaS, you only pay for the resources you use.

Anything as a Service (XaaS) The previous three models were the original three cloud models, but that has changed over time and now everything (or anything) is available as a service in the cloud. For example, a company could pay for security services in the cloud now, which could fall into the Anything as a Service category.
