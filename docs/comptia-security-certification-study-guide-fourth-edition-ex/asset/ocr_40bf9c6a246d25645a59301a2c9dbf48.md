# Virtualization and Virtualization Security

+   - Virtualization allows you to run multiple operating systems on a single host computer.
+   - Ensure that each virtual machine is patched and secured. Be sure that the host computer is physically secured.
+   - VM sprawl is when a company loses track of the number of virtual machines that have been created within the organization, and there is no process in place for the creation, management, and decommissioning of virtual machines.
+   - VM escape is a security risk to virtualization environments that are unpatched. VM escape allows an application to access the host system from within the VM. For the exam, remember that you need to patch your virtualization environment to protect against VM escape.
