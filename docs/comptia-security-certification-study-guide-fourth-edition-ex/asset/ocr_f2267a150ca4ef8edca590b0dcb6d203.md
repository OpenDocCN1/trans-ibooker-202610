# Fundamental Tools

Various security testing tools and web sites can help you perform a penetration test. The following web sites publish vulnerability information on different products:

+   - www.securityfocus.com/
+   - https://packetstormsecurity.org/files/

Tools have been developed that you can use to perform a penetration test. The following are some popular penetration testing tools available on the Web:

+   - **Kali Linux** Kali Linux is a special distribution of Linux you can download from www.kali.org that contains a number of security tools preinstalled within the operating system. Most of the tools mentioned in this section are preinstalled with Kali Linux. Kali Linux includes tools to crack passwords, crack wireless encryption, and do passive testing such as OSINT, DNS profiling, and researching a company. The cool thing about Kali Linux is that when you look at the menu system, the software is organized to follow the hacking process (see Figure 20-10).

+   - **Metasploit** This is a suite of exploits against different products. You can learn more about Metasploit and download it from www.metasploit.com. Metasploit is also preinstalled into Kali Linux and ready to use.
