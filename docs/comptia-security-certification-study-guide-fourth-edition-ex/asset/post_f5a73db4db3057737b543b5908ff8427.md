
Who manages the security  It is critical to find out what services are being provided by the provider and whether you are responsible for the security configuration of the system. Most public cloud providers must periodically undergo third-party security audits.

When looking at deploying network services and applications, you have the choice of installing them on-premises, having them hosted by someone else, or using a cloud service. The following list outlines each of these options:

- On-premises  On-premises means you install the application or service on a server within your site. This involves a lot of up-front time and cost, including planning the deployment and purchasing the servers, software, and high-availability solution. You are also responsible for maintaining the servers.
- Hosted  With a hosted solution, your organization still purchases the software and licenses and maintains the servers, but you pay a third-party company to provide the servers and infrastructure to host the application on.
- Cloud  With a cloud solution, you pay a monthly subscription fee and the software is already installed on servers in the background (that you do not have access to). You can make configuration changes to the software and services to meet your needs, but you do not need to maintain the servers—they are maintained by the cloud provider.

Here are some other terms and concepts related to cloud computing you should be familiar with for the Security+ certification exam:

- VDI/VDE  Virtual desktop infrastructure (VDI) and virtual desktop environment (VDE) are virtualization features that host the desktop environment for a user on a central server, which is then delivered to a thin client. The user interacts with the desktop OS as if it were installed locally.

## Resiliency and Automation

A number of resiliency and automation tools and features are available with virtualization and cloud services that can help reduce security risks within your environment.

### Automation/Scripting

To help reduce security risks, it is important to automate as many tasks as possible.
The benefit of automation is that you make fewer mistakes because you simply run the automated tasks or scripts day in and day out. Fewer configuration mistakes translates to fewer vulnerabilities in the environment.

Not only should you have automated courses of action (configuration steps), but you also should automate any continuous monitoring steps to help ensure that you do not miss any security alerts or notifications. You also want to automate configuration validation, which is the process of reviewing the configuration settings of the environment to ensure they are accurate.

### Templates and Master Image

Templates in cloud-based environments allow you to apply standard configuration settings to virtual machines as they are being created. Combining these templates of configuration settings with the operating system's master image allows you to quickly provision virtual machines and have them running in minutes.

### Nonpersistence

When working with cloud solutions or virtualized environments, you have a number of ways to undo changes made to the systems. The following list outlines solutions to undo changes:

- **Create snapshots** Within the virtualization environment, you can create snapshots, which are like save points of the configuration state.
- **Revert to a known state** You can revert your system to a snapshot to undo changes since that snapshot.
- **Roll back to a known configuration** Some software automatically saves your configuration state and enables you to roll back to one of those saved configuration states.

### Elasticity and Scalability

Elasticity and scalability are two important characteristics of any cloud-based solution. Elasticity in the context of cloud computing refers to spinning up new servers as the workload demands it and then shutting down those servers when the workload decreases. Scalability is ensuring that as your needs grow, the solution can grow with you.

### Distributive Allocation

A great feature of many private cloud solutions is distributive allocation, which allows you to distribute the virtual machines across many host systems. Most private cloud solutions will look at the existing workload on the host systems and give a recommendation regarding which host system a virtual machine should run on.

## Cloud Features

The new Security+ exam has expanded on some of the cloud concepts you must understand in order to pass the certification exam. In this section you are introduced to some of the different cloud-related features.

### Containers

As mentioned earlier in the chapter, a container is a feature that allows you to run an application in an isolated environment that has its own resources assigned to it, much like a virtual machine. A container differs from a VM in the sense that a container is more lightweight because it shares the OS kernel of the host system. This is why a container performs better than a VM while still providing the isolation features of a VM. Docker is an example of software that provides containers and is a feature of Windows 10.

### Microservices/API

A microservice is a piece of functionality, or component, that is programmed into an application programming interface (API) that can then be called by other applications. The benefit of the microservice is that each component is a complete unit of work and can be released and updated separately from other components in the API.

An application programming interface is a collection of functions a developer creates that allows other developers to call upon this functionality. For example, let’s say we run a company that creates a firewall product. As part of the firewall device, we have a web interface that has all the common firewall configuration options to allow administrators to configure it. As the creator of the product, we could also create an API with a list of functions that are the different types of configuration changes that can be made to the device (see Figure 16-3). The benefit of creating the API is that it allows other developers to create their own web admin pages if they do not like the web page we created. When a developer creates their web page, they simply add links or buttons to it that make calls to the API. Note that today we call these “web APIs” because they occur over HTTP traffic.

### Infrastructure as Code

One of the big benefits of cloud-based environments and infrastructure components integrated within the cloud is that we can leverage technologies such as software-defined networking and software-defined visibility:

- Software-defined networking (SDN) SDN is a way to manage network device configuration from a central point. SDN uses a controller application and APIs to centrally deploy configuration changes to network devices.
- Software-defined visibility (SDV) SDV is a method to monitor the entire network environment with the capability to respond to security incidents in real time.

### Other Cloud Features

There are a number of other cloud features you should be aware of from a terminology point of view:

- **Serverless architecture** A serverless architecture is one of the big benefits to cloud computing because you do not need to invest in server hardware; instead, you simply create an instance of that service in the cloud. For example, in Azure, you do not need to install a SQL server to be able to host a database; you can simply create a database directly in Azure, and behind the scenes the cloud service provider (Microsoft) takes care of the server infrastructure.
- **Services integration** Services integration is a delivery model for cloud computing that allows on-premises data to interact with cloud data.
- **Resource policies** Cloud resource policies allow you to manage the resources that exist in the cloud, such as VMs, databases, and web applications. You can configure different types of policies to manage these resources, such as cost control policies that help manage how much you spend on these resources per month, hygiene policies that allow you to clean out unneeded resources over time, and compliance policies that allow you implement security controls to protect the resources.
- **Transit gateway** A transit gateway is a mechanism that gives you a secure, private link that allows you to extend your on-premises network to your cloud network.
