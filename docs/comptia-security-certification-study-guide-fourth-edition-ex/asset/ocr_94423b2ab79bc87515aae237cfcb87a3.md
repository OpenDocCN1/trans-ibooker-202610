The world of computing has changed over the last number of years, and companies are looking to reduce the number of servers they need to purchase to provide services to clients on the network. In this chapter you will learn about how virtualization is used to reduce the number of servers by running multiple virtual machines on each server and the security issues surrounding virtualization. You will also learn about hosting services in the cloud, different cloud models, and security features you should look to in order to secure cloud resources.
