- **administrator account（管理员账户）**：用于管理 Windows 服务器和网络设置的账户。该账户在安装期间创建，对服务器拥有无限访问权限。以管理员身份登录服务器时必须格外小心，因为管理员访问权限包括关闭服务器和删除关键数据的能力。

- **American Standard Code for Information Interchange（ASCII，美国信息交换标准码）**：以计算机可读的二进制格式表示标准字母和其他键盘字符的一种表示方法。

- **application layer（应用层）**：OSI 层，提供一种一致的方式供应用程序发起网络请求。应用层协议的例子有 HTTP、SMTP 和 FTP。

- **application server（应用服务器）**：运行网络应用程序（如电子邮件或数据库应用程序）的服务器。通常，客户端从用户桌面连接到应用服务器。

- **archiving（归档）**：将旧文件从文件服务器移出以释放磁盘空间供新文件使用的过程。如果日后需要旧文件，可以取消归档并检索。归档数据可保存到 CD、DVD 或磁带。

- **ARP**：*参见 Address Resolution Protocol（地址解析协议）。*

- **arp**：一个 TCP/IP 命令行实用程序，用于操作系统上的 ARP 缓存。

- **array controller（阵列控制器）**：一种接口卡，连接到 RAID 解决方案中的所有驱动器，并提供硬件级容错。

- **ASCII**：*参见 American Standard Code for Information Interchange（美国信息交换标准码）。*

- **asymmetric encryption（非对称加密）**：一种加密方案，使用用户的公钥加密数据，并使用用户的私钥解密数据。

- **attribute-based access control（ABAC，基于属性的访问控制）**：根据用户账户的特征授予访问权限。

- **attributes（属性）**：文件的特性。文件可以指定不同的文件系统属性或文件系统特性，如只读、系统、隐藏和存档。

- **authentication（身份验证）**：向系统证明你的身份，以便访问资源。

- **client（客户端）**：(1) 在客户端/服务器模型中访问资源的工作站。(2) 支持各种网络服务通信的软件。(3) 访问网络上资源的计算机。

- **coaxial (or coax) cable（同轴电缆）**：一种电缆类型，有一根导线（实心线）贯穿电缆中央，周围有绝缘层。*另请参见 twisted-pair cable（双绞线）和 fiber-optic cable（光纤）。*

- **collision domain（冲突域）**：一组系统，它们的数据可能相互冲突。冲突的数据通常因损坏而必须重传。

- **command line（命令行）**：一种面向计算机应用的字符模式界面，依赖命令而非图形界面来处理信息。

- **compression（压缩）**：一种数学技术，分析计算机文件以将其压缩到更小的尺寸。大多数备份系统和许多文件服务器会压缩文件以增加存储容量。

- **computer virus（计算机病毒）**：一种为破坏或摧毁计算机或网络而编写的计算机程序。

- **connectionless communication（无连接通信）**：一种通信形式，目的计算机在收到信息时不会通知源计算机。这种通信被认为不可靠，因为没有通知表明数据已收到。由于无需跟踪哪些数据已发送以及通信另一端已收到哪些数据的开销，无连接通信可能比面向连接的通信更快。

- **connection-oriented communication（面向连接的通信）**：一种通信形式，通过使用序列号和确认号确保数据从发送方到接收方的可靠传输。消息中的每一段数据都被分配一个序列号，接收方使用该编号确认收到数据。

- **cookies（Cookie）**：存储在客户端计算机上的小文件，会自动提交给 Web 服务器进行处理。

- **CRC**：*参见 cyclical redundancy check（循环冗余校验）。*

- **cross-site scripting（跨站脚本攻击）**：一种基于软件的攻击，黑客将恶意脚本代码输入字段，使其被应用程序处理。

- **cryptography（密码学）**：通过加密和哈希等服务提供安全服务，以保护数据的机密性和完整性。

- **cyclical redundancy check（CRC，循环冗余校验）**：一种错误检查形式，将单个字节或字节组通过数学算法运行，以产生表示数据的单个位或字节（CRC 值）。CRC 值与数据一起传输。当数据到达目的地时，接收方通过相同的数学算法运行数据。将结果与原始 CRC 进行比较，如果匹配，则接收计算机假定数据正确。如果不匹配，接收方必须丢弃数据并重试。

- **daily backup（每日备份）**：复制执行备份当天所有已修改的所选文件，但不将其标记为已备份。

- **data link layer（数据链路层）**：OSI 层，负责处理网络上帧的拆解和重组。

- **data loss prevention（DLP，数据丢失防护）**：一组防止数据泄露的技术。

- **database management system（DBMS，数据库管理系统）**：一种管理数据库的数据库环境，包括数据库中数据的组织、存储、安全、检索和完整性。

- **datagram（数据报）**：由用户数据报协议（UDP）使用的一种自包含、独立的数据片段，包含足够的信息，无需来自源计算机或目的计算机的帮助即可从源计算机路由到目的计算机。网络使用数据的自包含信息来确定如何发送数据报。数据报就像一封邮政邮件。你将邮件投入邮筒，邮票和地址足以让邮政服务将邮件路由到收件人。但是，邮局可能会丢失邮件，而且无法追踪邮件何时或在哪里丢失。

- **DBMS**：参见 database management system（数据库管理系统）。

- **DDoS**：参见 distributed denial of service（分布式拒绝服务）。

- **default gateway（默认网关）**：通常连接到本地子网的路由器，使 IP 数据包能够传递到其他网段。当客户端系统需要在其自身子网之外通信时，需要默认网关。

- **demilitarized zone（非军事区）**：两个防火墙之间的区域，公共服务器（如 Web 服务器和 DNS 服务器）应放置在该区域以确保安全。
