# Performing a Port Scan

In this exercise, you will use Kali Linux to do some port scanning on the 10.0.0.0 network. Ensure that Windows 10 VM, ServerA VM, and Kali Linux are started.

+   1. Go to the Linux VM and then open a terminal (command prompt). Normally, you can do this by right-clicking the desktop and choosing New Terminal.
+   
+   2. To do a TCP connect scan on the 10.0.0.1 system, type
+   
+      ```
+      nmap -sT 10.0.0.1
+      ```
+   
+   3. To perform a TCP connect scan of 10.0.0.1 and specify you wish to scan for ports 21, 25, and 80, type
+   
+      ```
+      nmap -sT 10.0.0.1 -p 21,25,80
+      ```
+   
+   4. Which of those ports are open on the system?

+      ________________________________
+   
+   5. To perform a SYN scan of 10.0.0.1 and specify your wish to scan for ports 21, 25, and 80, type
+   
+      ```
+      nmap -sS 10.0.0.1 -p 21,25,80
+      ```
