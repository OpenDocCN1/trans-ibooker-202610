# Backing Up and Restoring Data on a Windows Server

In this exercise you learn how to back up files on your Windows Server by using the Windows backup software and how to restore a file after it has been accidentally deleted. Be sure to check out the video of this exercise contained in the online resources that accompany this book.

+   1. Switch to the ServerA VM. In Server Manager, install the Windows Server Backup feature by choosing Manage | Add Roles and Features. Continue with the wizard and install the Windows Server Backup feature.
+   2. After installation of the Windows Server Backup software, ensure you are still in Server Manager and choose Tools | Windows Server Backup.
+   3. Choose Local Backup on the left.
