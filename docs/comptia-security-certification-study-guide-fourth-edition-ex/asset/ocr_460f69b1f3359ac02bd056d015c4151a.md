The Security+ exam expects you to understand the characteristics of vulnerability scans and the considerations that should be made when performing them:

+   - **Passively testing security controls**  Know that performing a vulnerability scan is considered passively testing the security of a system because you are not actually trying to hack into the system or exploit it.

+   - **Identifying vulnerabilities**  The goal of the vulnerability scan is to identify vulnerabilities, or weaknesses, in the system. For example, if this system is not up to date with patches, that is considered a vulnerability.

+   - **Identifying the lack of security controls**  When performing a vulnerability assessment, you are looking to identify if there are any security controls that should be used that are not currently being used. For example, you may assess the security of a database server and notice that it is not being protected by a firewall. In this case, you should report that the system could use a firewall to control communication to the database server.
