## 关于作者

**Glen E. Clarke**，持有 CCT、CCNA、MCITP、MCSE、MCSD、MCDBA、MCT、CEH、CHFI、CISSO 以及 CompTIA Security+、PenTest+、Network+、A+ 认证，是 DC Advanced Technology Training（DCATT）的所有者。该公司位于新斯科舍省哈利法克斯，是一家 IT 培训公司，专注于提供 IT 认证培训以及网络、安全和编程领域技术的咨询服务。Glen 大部分时间都在讲授 Windows Server、Microsoft 365、Hyper-V、SQL Server、Exchange Server、SharePoint、Visual Basic .NET 和 ASP.NET 的认证课程。Glen 还教授多门安全相关课程，涵盖道德黑客与对策、计算机取证与调查、信息系统安全官员、漏洞测试、防火墙设计和数据包分析等主题。

Glen 是一位经验丰富的作者和技术编辑，其已出版作品曾获 Referenceware 卓越奖提名。Glen 撰写了众多认证备考指南，包括 *CompTIA Network+ 认证学习指南*、*CCT/CCNA 路由与交换一体式考试指南*、*CompTIA PenTest+ 认证达人指南* 以及畅销的 *CompTIA A+ 认证一体式达人指南*。

不工作的时候，Glen 喜欢与妻子 Tanya 以及他们的四个孩子 Sara、Brendon、Ashlyn 和 Rebecca 共度美好时光。您可以访问 www.dcatt.ca 在线了解 Glen，或通过 glenclarke@dcatt.ca 与他联系。
