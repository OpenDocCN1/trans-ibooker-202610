
- **Security control testing:** Ensure that you test all security controls in the virtualized environment to be sure they are working as expected. Virtualization technology also makes it easy to create additional test systems in order to validate security features on the network.
- **Sandboxing:** You can create sandboxes, which are restricted environments, to control what the virtual machines have access to.

### Cloud Computing Concepts

Now that you understand virtualization and security concerns related to virtualization, let us move on to cloud computing. In this section you will learn about the benefits of cloud computing, the cloud models, and security issues related to cloud computing.

### Cloud Computing Overview

Cloud computing has become the way of the future and has many advantages and disadvantages. In this section you will learn about cloud computing and discover some of those advantages and disadvantages.

With cloud computing you can quickly and easily create application environments with minimal cost up-front. For example, I wanted an e-mail server environment, so I created a Microsoft 365 subscription account. Within minutes I had an e-mail server environment up and running (known as Exchange Online), which allowed me to create some mailboxes and then start sending e-mail. The best part of this example is that I did not have to purchase server hardware or software, and I didn't need to plan for high availability. It is all part of what the cloud service offers!

### Cloud Terminology

Before we dive into the different cloud models (which is important for the exam), let's start by defining some terms you will hear on a regular basis that relate to cloud computing:

- **Cloud service provider (CSP):** The cloud service provider (CSP) is the company that you subscribe to in order to receive cloud services. For example, if you subscribe to Azure, then Microsoft is the cloud service provider.
- **Managed service provider (MSP)/managed security service provider (MSSP):** A managed service provider (MSP) is a company that manages the cloud environment for you and handles many of the IT functions, such as provisioning users, managing the cloud services, performing data backups and recovery, and monitoring activity. A managed security service provider (MSSP) is a company that handles the management of security for your environment. MSSPs are used for security configuration of your cloud environment, monitoring of activity, management of intrusion detection systems (IDSs) and firewalls, patch management, responding to security incidents, and performing security assessments within the organization.

### On-premises vs. off-premises

On-premises is the term we use for a system that is installed in one of your office locations on the LAN. Off-premises is the term used to describe a system that may be at an alternate site.

### Fog computing/edge computing

Fog computing is the concept that you can have your edge devices (such as routers and firewalls that reside on the edge of the network and are connecting to the Internet) process data before sending the data to the cloud. As an example of edge computing, think of a network environment where you may have all logged data sent to the cloud for processing. This wastes bandwidth because some of that logged data is not needed. With fog computing, the processing is done closer to the user network where the data is generated, and then only processed information is forwarded to the cloud to be analyzed, thus saving bandwidth. Fog computing is also known as fogging or edge computing.

### Thin client

A thin client, also known as a dumb client, is a system that doesn't perform much processing and simply connects to a remote server or cloud service for all processing. For example, you can have a thin-client machine that has minimal CPU power, memory, and no hard drive and connects to a Microsoft Terminal server, which in turn sends application screenshots to the thin client. The user can use their mouse on the thin client to click options in the application, which then sends those click operations to the server, causing the screen to refresh. The point is that you are using the processing power of the server and not the client.

### Cloud Computing Models

With different implementations of cloud computing, you need to be familiar with these different cloud models for the Security+ certification exam (shown in Figure 16-2):

### Software as a Service (SaaS)

With SaaS, an application is provided by the cloud provider to the customer so that the customer can use the application from anywhere in the world where they have an Internet connection. If you use a free e-mail service such as Gmail or Outlook.com, that is an example of SaaS. A better example is Microsoft 365, where you get services such as Exchange, SharePoint, and Microsoft Office available to you once you subscribe. The cloud provider manages the application infrastructure and maintains it for you by performing tasks such as applying updates.

### Platform as a Service (PaaS)

With PaaS, the cloud provider provides a development environment, also known as a runtime environment, to cloud customers that allows them to create applications in the cloud. Examples of PaaS are programming tools, code libraries, web servers, web services, and database environments. The benefit is that a developer can use these features in the cloud without needing to install them as on-premises servers, which would traditionally be the case. Using Azure SQL Database is an example of PaaS.

### Infrastructure as a Service (IaaS)

IaaS is a way to create a virtual data center in the cloud because it allows you to provide servers, virtual machines, storage, networks, and other data center resources in the cloud. When a customer subscribes to IaaS, they only pay for the resources used. For example, when you use Azure Virtual Machine, you are using IaaS. Note that with IaaS, you only pay for the resources you use.

### Anything as a Service (XaaS)

The previous three models were the original three cloud models, but that has changed over time and now everything (or anything) is available as a service in the cloud. For example, a company could pay for security services in the cloud now, which could fall into the Anything as a Service category.

There are a number of different ways to implement cloud services. You could implement a cloud in the following ways:

- **Private cloud:** A private cloud means that you create the cloud services internally for your company, allowing your company to take advantage of cloud features such as elasticity and self-serve functionality. For example, you could have a private cloud that allows your IT staff to spin up virtual machines as needed. The key point with private cloud is that the data is stored inside the company.
- **Public cloud:** A public cloud is provided by a service provider, and your data stored in the cloud would be located on that provider's servers. It is important to stress that many organizations are not allowed to store sensitive data in a public cloud where the servers are hosted outside of the country. It should be noted that cloud providers are creating data centers in different countries to address this concern.
- **Hybrid cloud:** A hybrid cloud is a mix of public and private cloud. The company may store nonsensitive data in the public cloud but keep sensitive data stored in the private cloud.
- **Community cloud:** This type of cloud pools computing resources to make IT services available to multiple organizations with common needs, such as real-time access to a back-end database.
- **Cloud storage:** One of the great benefits of cloud technologies is the use of cloud storage. Users are now able to easily store their data in the cloud and access that data from a number of different devices such as desktop PCs, laptops, tablets, and phones. Cloud storage can be used to store personal files such as pictures and documents, but also to store configuration settings for the device so that if you need to wipe the device, the configuration can be easily restored.

### Cloud Computing Considerations

The purpose of cloud computing is to provide an organization with features such as database, e-mail, or other services without the organization having to host those services itself. For example, to host your own database server or e-mail server, you need the server hardware and software, which cost money. It may be easier to have those services hosted by someone else (and let them purchase the hardware and software) while you pay a monthly subscription fee to access those services across the Internet. With many cloud services, you only pay for the services you use and the data storage you use.

Although an organization could save the initial cost of purchasing hardware and software by having the services hosted by someone else across the Internet, there are some security considerations for cloud computing:

- **Many customers sharing the service:** If multiple customers are subscribing to the same service, is it possible that one customer can gain access to another customer's data? You are trusting the provider to keep customer information partitioned from other subscribers. This is often accomplished using virtualization technologies.
- **Legal issues:** In most cases, if law enforcement has legal reasons for the cloud provider to give access to the information they have stored, they will have to provide full disclosure of the information.
