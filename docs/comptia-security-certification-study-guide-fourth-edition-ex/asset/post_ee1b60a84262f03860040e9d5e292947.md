## Acquire Image

Once you have securely wiped any target drives, it is time to capture an image of the suspect’s drive. When you capture an image of the suspect’s drive, you typically have a few choices as to how you want to capture the image:

- Disk-to-image  A very popular method of doing an investigation is to create an image of a disk and save the image in an image file.
- Disk-to-disk  Larger organizations that do computer forensics typically acquire the evidence by doing a low-level copy (at the sector level) from one disk to another disk.
- Image-to-disk  The final scenario is taking an image file obtained off the suspect’s drive and then sending that to a disk to do the investigation off the target disk.

The benefit of doing a disk-to-image file is that you do not need to have spare disks around to capture the image. A lot of times, forensics investigators will capture the drive to an image file, and then when ready to do the analysis, they may send the image to a target drive. In this scenario the investigator would perform the analysis on the target drive—this way, the suspect’s original drive has not been touched, and the initial image has not been touched during an analysis. A really cool point to remember for Linux users is that Linux has the capabilities to mount a dd image file directly for read-only analysis! This means that you do not need additional software to perform the analysis.

If you would like to capture an image of a disk by using FAU, you can use the following command (dd is a command-line tool to acquire an image, if stands for “input file,” and of stands for “output file”):

```
dd.exe if=\\.\F: of=e:\Case20110203_Drive1.img conv=noerror -localwrt
```

## Using FTK Imager to Capture an Image of a Suspect’s Drive

In this exercise, you learn how to use FTK Imager to acquire an image of a USB drive. Keep in mind that you can create an image of a regular hard drive using the same steps, but I use a USB drive in this example because it is smaller and takes less time.

- 1. Download FTK Imager from https://accessdata.com/product-download/ftk-imager-version-4-5 and then install it.
- 2. Insert a USB flash drive into your system.
- 3. Start FTK Imager.
- 4. To capture an image of a drive, choose File | Create Disk Image.
- 5. You are prompted for the type of evidence source you would like to image, such as a physical drive (the whole disk), a logical drive (a partition on the drive), an image file, the contents of a folder, or a DVD. Choose Physical Drive and then choose Next.
- 6. You are presented with a list of drives on the system. Select the USB drive and then choose Finish.
- 7. You then must specify the image file to write to in the Image Destination field. Choose Add, choose Raw (dd) as the image type, and then choose Next. The dd image is the standard image format supported by many forensics tools.
- 8. You are then asked for information about the evidence. Input the following information and then choose Next:
  - Case Number: 20210602_001
  - Evidence Number: 100
  - Unique Description: Suspect’s USB drive
  - Examiner: Bob Smith
  - Notes: Suspect’s USB drive found in top desk drawer
- 9. Use the following information for the image destination and then choose Finish:
  - Image Destination Folder: c:\forensicsimages
  - Image Filename: suspect_usb_drive.dd
  - Image Fragment Size (MB): 0 (which means do not break into multiple image files)
- 10. Choose Start to create the forensic image of the USB drive (this will take a while, depending on the size of the USB drive).
- 11. Close FTK Imager when the image is completed.
- 12. Verify you see the image file located in the c:\forensicsimages folder in Windows.

## Using Autopsy to Investigate the Local Disk

In this exercise, you use Autopsy to investigate the contents of your local hard drive and locate items such as Internet sites visited and user accounts as well as to identify encrypted files on the system.

- 1. Download Autopsy from https://www.autopsy.com/download/ and install it on your system.
- 2. After installing Autopsy, right-click the Autopsy icon on the Desktop and choose Run As Administrator. Choose Yes on the User Account Control dialog box about elevating your privileges.
- 3. Choose New Case, enter the following information, and then choose Next:
  - 20210603_Exer21-4
  - Leave all other options as is.
- 4. Type the following optional information for the case and then choose Finish:
  - Number: 20210603_Exer21-4
  - Examiner Name: Bob Smith
  - Phone: 555-5555
  - Email: bobsmith@companyxyz.loc
- 5. When asked to add a data source, note that Local Disk is selected. Also note that you can add a disk image (which you created in the previous exercises). In this exercise, we are going to add your local disk because it will allow you to see information about your own system. Choose Next.
- 6. Choose Select Disk and then choose the hard drive that Windows is installed on (in my case it is Drive 0 of 447GB). Choose OK.
- 7. Choose Next.
- 8. Autopsy wants to use ingest modules on the drive. These are used to located key information on the drive, such as web sites visited. Leave all the modules selected and choose Next. Note that it will take some time to add the drive because it is parsing the information due to the ingest modules.
- 9. After the local drive has been added to Autopsy, expand out Results on the left and then expand Extracted Content. This is where Autopsy displays information typically useful to an investigator about the contents of the drive.
- 10. Select Encryption Suspected to see a list of files on the hard drive that are encrypted.
- 11. Select Installed Programs to see a list of software installed on the system.
- 12. Select Operating System User Account to see a list of user accounts on the system.
- 13. Choose one of the user accounts on the right to view more data about the account in the bottom-right pane.
- 14. Select Recent Documents on the left to see a list of recently accessed files by the suspect. Note that you can select a file to display more information about the file.

## Hex Editors

Another important tool for a forensics investigator is a hex editor. A hex editor allows you to view the low-level content of a file or disk. With a hex editor, you can review file headers to identify the type of file you are dealing with, no matter what the file extension might be.
