# Creating a Security Template

In this exercise you will create a security template and then apply that template to the local security policy of a Windows system.

+   1. Ensure that you have the ServerA and Windows 10 VMs running.
+   2. Go to the Windows 10 VM.
+   3. Create a custom MMC and load the Security Templates snap-in:
+      a. On the Start menu, type MMC. Right-click mmc.exe in the search results and choose Run As Administrator. Click Yes to allow the program to make changes to your system.
+      b. Choose File | Add/Remove Snap-in.
