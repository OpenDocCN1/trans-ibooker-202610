# Report on Findings

During the analysis of the evidence, most forensics software allows you to bookmark items of interest and to have them added to a report that you can generate. It is critical as you are performing your investigation to also be planning the report on your findings by logging all of your steps and marking items of interest. The report should contain the following:

+   - Items of interest  Your report should list any item of interest from the image. This may include e-mail messages, images, movies, and deleted files.
+   - Log of actions taken  Some forensics software logs each action you perform within the software. This could be very useful in validating the actions you have taken. If the software does not log your actions, you will need to do so manually so that you can explain the steps you took and re-create the results by following the same steps.
+   - Report of the investigation  The report should have a summary of the evidence found during the investigation. For example, if you have recovered a deleted file that contains potentially incriminating evidence, then it should be noted.

When performing your investigation, it is critical to record all your activities and the time of each activity. Recording the time you start each action and how long it took is critical to the success of the investigation. Record time offset is an important setting for the investigator to configure when performing an investigation. Configuring record time offset involves the investigator configuring the time zone in the forensics software to match the time zone of the suspect’s system so that all timestamp information in the evidence is accurate.

# Where to Find Evidence

When you are conducting a computer forensics investigation, it is critical that you understand where you can find the evidence and understand the order of volatility. The following is a listing of the places where you may find evidence when conducting a computer investigation:

+   - Memory/RAM  Memory contains information used recently. This may include items such as the contents of documents or even recently used passwords. This is considered volatile evidence because the information will be in memory for only a short time. Be sure to have a tool such as dd or FTK Imager handy so you can capture the contents of memory if needed.
+   - Swap file/page file  Information is constantly dumped from RAM to the pagefile .sys swap file on the Windows system. Newer versions of Windows such as Windows 10 also have a file called swapfile.sys that is also used to swap the contents of memory to disk. Be sure to look at the swap file when trying to find volatile memory.
+   - Hard disk  Most investigations involve imaging a hard drive (or multiple drives) and looking for evidence stored on disk in the registry, e-mail, or the file system.
