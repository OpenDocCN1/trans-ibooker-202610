# Using FTK Imager to Capture an Image of a Suspect’s Drive

In this exercise, you learn how to use FTK Imager to acquire an image of a USB drive. Keep in mind that you can create an image of a regular hard drive using the same steps, but I use a USB drive in this example because it is smaller and takes less time.

+   1. Download FTK Imager from https://accessdata.com/product-download/ftk-imager-version-4-5 and then install it.
+   2. Insert a USB flash drive into your system.
+   3. Start FTK Imager.
+   4. To capture an image of a drive, choose File | Create Disk Image.
+   5. You are prompted for the type of evidence source you would like to image, such as a physical drive (the whole disk), a logical drive (a partition on the drive), an image file, the contents of a folder, or a DVD. Choose Physical Drive and then choose Next.
+   6. You are presented with a list of drives on the system. Select the USB drive and then choose Finish.
+   7. You then must specify the image file to write to in the Image Destination field. Choose Add, choose Raw (dd) as the image type, and then choose Next. The dd image is the standard image format supported by many forensics tools.
+   8. You are then asked for information about the evidence. Input the following information and then choose Next:
+      - Case Number: 20210602_001
+      - Evidence Number: 100
+      - Unique Description: Suspect’s USB drive
+      - Examiner: Bob Smith
+      - Notes: Suspect’s USB drive found in top desk drawer
+   9. Use the following information for the image destination and then choose Finish:
+      - Image Destination Folder: c:\forensicsimages
+      - Image Filename: suspect_usb_drive.dd
+      - Image Fragment Size (MB): 0 (which means do not break into multiple image files)
+   10. Choose Start to create the forensic image of the USB drive (this will take a while, depending on the size of the USB drive).
+   11. Close FTK Imager when the image is completed.
+   12. Verify you see the image file located in the c:\forensicsimages folder in Windows.
