
## Cloud Computing Concepts
- Cloud computing allows you to use the services of a provider from across the Internet to host your e-mail and database servers while you remotely connect and manage those servers.
- The *cloud service provider (CSP)* is the company providing cloud services to you.
- The *managed service provider (MSP)* is a company that manages the cloud environment for you and handles many of the IT functions, such as provisioning users, managing the cloud services, performing data backups and recovery, and monitoring activity.
- The *managed security service provider (MSSP)* is a company that handles the management of security for your environment. MSSPs are used for security configuration of your cloud environment, monitoring of activity, management of IDSs and firewalls, patch management, responding to security incidents, and performing security assessments within the organization.
- In the Software as a Service (SaaS) cloud model, an application is provided to the client without the client needing to install the application (such as Hotmail, Gmail, or Microsoft 365).
- With the Platform as a Service (PaaS) cloud model, the CSP supplies the runtime environment and development tools to create applications in the cloud.
- With Infrastructure as a Service (IaaS), the cloud service provider gives the customer a way to create a virtual data center, including creating virtual networks, storage, and virtual machines.

## Cybersecurity Solutions for the Cloud
- You should secure storage resources with permissions, encryption, and replication technology.
- You should use network security controls to create virtual networks, public and private subnets, and segmentation features.
- Look to use security groups and container security with compute resources.

## SELF TEST ANSWERS

### Virtualization and Virtualization Security
1. ☑ C. One of the benefits of virtualization is that you need to implement physical security controls on fewer systems because less hardware is used as a result of virtualization.
☒ A, B, and D are incorrect. You will need to patch and virus-protect the host operating system and each of the virtual machines. Encryption may still be needed based on any drives you would like to maintain confidentiality on.

2. ☑ D. VM escape is when an attacker leverages a vulnerability within the virtualization platform that allows the attacker to access the host system from within a virtual machine. To remove the vulnerability, keep the virtualization environment up to date with patches.
☒ A, B, and C are incorrect. Resource policies allow you to manage the resources that exist in the cloud, such as VMs, databases, and web applications. There are different types of resource policies—you can implement security with resource policies or ensure resources are removed after a specific amount of inactivity. Private subnets are cloud networks that are not reachable from the Internet. Sandboxing is when you run in an isolated environment—in this case, the VM is supposed to be isolated, but due to a vulnerability, the attacker is able to make calls to the host system.

3. ☑ A. VM sprawl is when a company loses track of the number of virtual machines that have been created within the organization and there is no process in place for the creation, management, and decommissioning of virtual machines.
☒ B, C, and D are incorrect. VM escape is when an attacker leverages a vulnerability within the virtualization platform that allows the attacker to access the host system from within a virtual machine. To remove the vulnerability, keep the virtualization environment up to date with patches. VM memory leaks would be a flaw by the coders of the virtualization platform and would typically get fixed with a patch. VM patching is something that should be done and could be at risk of VM sprawl, because now you have more VMs to patch if you are not managing the number of VMs.

### Cloud Computing Concepts
4. ☑ C. A managed security service provider (MSSP) is a company that handles the management of security for your cloud environment.
☒ A, B, and D are incorrect. A cloud service provider (CSP) is a company that you subscribe to in order to receive cloud services. A managed service provider (MSP) is a company that manages the cloud environment for you and handles many of the IT functions, such as provisioning users, managing the cloud services, and performing data backups and recovery. Data loss prevention (DLP) is not a company you hire, but rather a compliance control to prevent sensitive data from leaking out of the company.

10. ☑ D. You should change the secret keys on a regular basis to ensure that only authorized applications are accessing cloud services and resources.
☒ A, B, and C are incorrect. You would not disable a form of encryption, whether it be asymmetric or symmetric, because many environments use both. In this scenario, the availability of a resource is not in question, so you would not implement high availability. A private subnet would allow you to host VMs on the subnet that are not accessible from the Internet.
