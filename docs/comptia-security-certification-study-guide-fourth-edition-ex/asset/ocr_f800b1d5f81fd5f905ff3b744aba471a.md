# ## String Arrays

It is often useful to define an array of strings, sometimes called string arrays. The following declarations and initialization create an array of four strings:

```
```c
char *strArr[4] = {
    "first string",
    "second string",
    "third string",
    "fourth string"
};
```
```

The declaration is interpreted as: strArr is an array of 4 pointers to char. The initialization places the address of the first character of each literal string into the array elements:
strArr[0] -> "first string"
strArr[1] -> "second string"
strArr[2] -> "third string"
strArr[3] -> "fourth string"

![](bbox=[0.6, 0.2, 0.95, 0.42])

Since each element of the array is a pointer, the strings can be printed using a for loop with a pointer or subscript:
`for (i = 0; i < 4; i++)`
`    printf("%s\n", strArr[i]);`

# ## Individual characters

Individual character within a string can be accessed with the bracket notation. Since strArr[0] is a pointer to the first string, strArr[0][0] is the first character of the first string: 'f'. The following loop examines the characters in the second string:

```
```c
#include <stdio.h>
int main() {
    char *strArr[4] = {"first string", "second string", "third string", "fourth string"};
    int i;

    for (i = 0; strArr[1][i] != '\0'; i++)
        printf("%c", strArr[1][i]);
    printf("\n");
    return 0;
}
```
