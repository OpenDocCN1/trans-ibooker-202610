# Redundancy with Replication

Another technique for adding redundancy is to replicate data from a source to a destination at regular intervals. Here are two common technologies that use replication:

+   Storage area network (SAN)  A storage area network is a group of storage drives that are connected with high-speed links. You can replicate the data on one SAN to a SAN at another site by using replication—what is known as SAN-to-SAN replication. This ensures that the data is at multiple locations should one location experience a disaster.

+   Virtual machines (VMs)  You can have VMs that are running on one server replicate to another server. The VM replication technology allows you to control which VM is currently running. This is a great way to ensure that you have redundancy on a virtual machine.

> exam Watch For the Security+ exam, know the different solutions for disk redundancy, network redundancy, power redundancy, and replication. Especially focus on RAID, multipath, load balancers, NIC teaming, dual power supply, and UPS.

# Nonpersistence and Diversity

The Security+ exam calls out objectives related to nonpersistence and diversity as they relate to cybersecurity resilience. Nonpersistence by definition is the losing of data when a system is shut down or an application is closed. The following are ways that a system could have nonpersistence:

+   Revert to known state  Applications such as Deep Freeze can be used to revert the system to a previous state. With Deep Freeze, the administrator saves the state of the computer and then, when the system is rebooted, it reverts to that saved state so that any changes are lost. This is a common application found in school computer labs. Another example is the Windows System Restore feature, which can be used to revert to a previous state.

+   Last known-good configuration  There are tools that allow you to revert to the previous known-good configuration. As an example, Windows has a boot option that allows you to revert to the configuration of the system the last time you logged in.

+   Live boot media  Live boot media is a live operating system you boot off from a DVD or USB drive. Examples would be a WinPE disk or a live version of Ubuntu that allows you to boot to the operating system that resides on the removable media. Live media allows you to run tools from the live operating system but does not permanently store data after shutting the system down.
