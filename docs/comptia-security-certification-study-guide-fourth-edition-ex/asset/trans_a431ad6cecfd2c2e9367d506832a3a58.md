


- **用户数据报协议（UDP）** 提供无连接的数据报服务，是一种不可靠的“尽力而为”交付方式。UDP 不保证数据报的到达，也不承诺交付的数据包顺序正确。不需要数据接收确认的应用会使用 UDP。

- **用户模式** 也称为非特权处理器模式。应用程序和各种子系统在此模式下运行。用户模式旨在防止应用程序导致操作系统崩溃。

- **用户权利** 允许用户在计算机上执行特定操作。通过设置用户权利，可以控制用户或组执行的操作。有些供应商可能使用术语“系统权限”。

- **用户名** 用户用于登录计算机系统的名称。

- **UTP** 请参阅非屏蔽双绞线。

- **虚拟局域网（VLAN）** 在较大的网络中，将需要彼此通信的少量 PC 划分为一个小分组。可以通过指定 PC 所连接交换机上的端口来实现。

- **虚拟机** 由虚拟化软件（虚拟机监控程序）提供的模拟计算机，可运行 Windows Server、Windows 客户端和 Linux 等操作系统。

- **虚拟内存** 当计算机需要更多内存时，由 Windows 创建的用于模拟 RAM 的机制。它根据需要利用计算机的硬盘来实现这一点。

- **虚拟专用网络（VPN）** 通过公共网络提供带安全通信信道的隧道。VPN 使用 L2TP 和 SSTP 等协议，在隧道创建后加密客户端与服务器之间的通信。

- **病毒** 对系统造成危害的恶意代码。

- **病毒特征库** 已知病毒的数据库，防病毒软件在扫描文件以消除病毒时使用该数据库。病毒特征库必须保持更新。

- **VLAN** 请参阅虚拟局域网。

- **卷** 物理驱动器上被视为单个单元的空间的逻辑划分。卷是硬盘上用于存储信息的一部分。

- **卷集** 将任意类型硬盘（IDE、SCSI 或 ESDI）上不同大小的可用空间区域合并为单个卷（驱动器号）。卷集不提供任何容错或性能提升，仅用于将多个可用空间区域合并为一个卷。

- **VPN** *请参阅*虚拟专用网络。

- **漏洞测试** 一种安全测试类型，涉及运行软件来检查系统配置中的弱点。

- **WAP** *请参阅*无线接入点。

- **知名端口** *请参阅*端口号。

- **捕鲸攻击** 针对非常重要人物（例如公司首席执行官）的网络钓鱼攻击。

- **Wi-Fi 保护访问（WPA）** 一种无线安全协议，旨在加密无线通信并提供身份验证服务。

- **Wi-Fi 保护访问 2（WPA2）** 一种无线安全协议，已取代 WPA，旨在加密无线通信并提供身份验证服务。WPA2 经过改进，使用了更安全的 AES 对称协议。

- **Windows 更新** 一种服务，你可以连接并查看系统的可用更新，也可以从系统安装这些更新。

- **有线等效加密（WEP）** 一种旧的无线安全协议，使用对称密钥加密无线通信。WEP 已弃用，并被 WPA2 取代。

- **无线接入点（WAP）** 一种网络设备，允许无线客户端连接到无线网络。无线客户端连接到接入点，并通过接入点向网络上的其他主机发送数据。

- **无线局域网（WLAN）** 允许系统通过无线连接进行通信的网络。

- **无线组网** 配置为使用红外、蜂窝或微波等通信技术的网络，因此无需电缆连接。

- **工作组** 一组各自独立管理的计算机。

- **工作站** 用于访问网络的客户端计算机。

- **零日漏洞利用** 对制造商未知且尚无安全补丁的软件或硬件的利用。
