### 9.6.1 Basic Properties

Consider the S-T process {Z(s, t)|s ∈ D; t ∈ Dt}, where D ⊂ Rd with d > 0 and Dt ⊂ R. In practice, we only observe data at a finite number of locations, say {si|i = 1, ..., m}, and a finite number of time points, say {tj|j = 1, ..., T}, where m and T are positive integers. For convenience, we write Z' tj = [Z(s1, tj), ..., Z(sm, tj)]′ and Z(si) = [Z(si, t1), ..., Z(si, tT)]′. That is, Z tj is the m-dimensional vector of observations at time tj and Z(si) is the T-dimensional vector of observations at location si. We start with some basic concepts. Associated with the observed process Z(s, t), there is an underlying S-T process Y(s, t), i.e. Z(s, t) = Y(s, t) + ϵ(s, t) with ϵ(s, t) being iid measurement errors.

Let D be a domain of interest. For spatial processes, D ⊂ Rd. For time series, D is the set of integers if time is discrete and D ⊂ R if time is continuous. For S-T processes, D ⊂ Rd × R or D ⊂ Rd × {..., -1, 0, 1, ...}. A function {g(u, v)|u, v ∈ D} defined on D × D is said to be nonnegative-definite if for any complex numbers {bi|i = 1, ..., m}, and any locations {ui|i = 1, ..., m} in D, and any positive integer m, we have

\[
\sum_{i=1}^{m} \sum_{j=1}^{m} b_i \bar{b}_j g(u_i, u_j) \ge 0, \tag{9.62}
\]

where \(\bar{b}_i\) is the complex conjugate of \(b_i\). If the inequality holds in Eq. (9.62) for any non-zero \(b = (b_1, ..., b_m)'\), then \(g(\cdot, \cdot)\) is said to be *positive-definite*. We shall focus on S-T processes with covariance function (to be defined shortly) that is positive-definite.

A function \(g(u, v)\) is a *stationary S-T covariance function* on \(R^d \times R\) if it satisfies the condition in Eq. (9.62) and can be written as

\[
g((s_1, t_1), (s_2, t_2)) = C(s_1 - s_2, t_1 - t_2), \quad s_i \in R^d, t_i \in R. \tag{9.63}
\]

A S-T process \(Y(s, t)\) is said to be *second-order stationary* if \(E[Y(s, t)] = \mu\), a constant, and it has a stationary covariance function. More precisely, \(Y(s, t)\) is second-order stationary if \(E[Y(s, t)] = \mu\) and

\[
\sum_{i=1}^m \sum_{j=1}^m b_i \bar{b}_j C_y(s_i - s_j, t_i - t_j) \ge 0, \tag{9.64}
\]

for any \(b = (b_1, ..., b_m)'\), any \(\{(s_i, t_i) | i = 1, ..., m\}\) and any \(m\), where \(C_y(\cdot, \cdot)\) is the covariance function of \(Y(s, t)\).

The stationary S-T correlation function of \(Y(s, t)\) is defined as

\[
\rho_y(h, \tau) = \frac{C_y(h, \tau)}{C_y(0, 0)}, \quad h \in R^d, \tau \in R. \tag{9.65}
\]

The concept continues to apply for continuous-space and discrete-time models. Some related concepts of covariance function are as follows:

- Spatial stationarity:
  \(\text{Cov}[Y(s_1, t_1), Y(s_2, t_2)] = C_y(s_1 - s_2, t_1, t_2).\)

- Temporal stationarity:
  \(\text{Cov}[Y(s_1, t_1), Y(s_2, t_2)] = C_y(s_1, s_2, t_1 - t_2).\)

- Spatial isotropy:
  \(\text{Cov}[Y(s_1, t_1), Y(s_2, t_2)] = C_y(\|s_1 - s_2\|, t_1, t_2).\)

- Geometric spatial anisotropy:
  \(\text{Cov}[Y(s_1, t_1), Y(s_2, t_2)] = C_y(\{h_1(s_{11} - s_{21})^2 + \cdots + h_d(s_{1d} - s_{2d})^2\}^{1/2}, t_1, t_2),\)
  where \(s_i = (s_{i1}, ..., s_{id})'\) and \(h_i > 0\) for \(i = 1, ..., d\).

- Geometric S-T anisotropy:
  \(\text{Cov}[Y(s_1, t_1), Y(s_2, t_2)] = C_y(\{h_1(s_{11} - s_{21})^2 + \cdots + h_d(s_{1d} - s_{2d})^2 + h(t_1 - t_2)^2\}^{1/2}),\)
  where \(s_i = (s_{i1}, ..., s_{id})'\), \(h_i > 0\) for \(i = 1, ..., d\), and \(h > 0\).

Another important concept is the separability of S-T correlations. A random process \(Y(s, t)\) is said to have a *separable S-T covariance function* if, for all \(s_i \in R^d\) and \(t_i \in R (i = 1, 2)\), we have

\[
\text{Cov}[Y(\boldsymbol{s}_1, t_1), Y(\boldsymbol{s}_2, t_2)] = C^{(s)}(\boldsymbol{s}_1, \boldsymbol{s}_2) \times C^{(t)}(t_1, t_2), \tag{9.66}
\]

where \(C^{(s)}\) and \(C^{(t)}\) are spatial and temporal covariance functions, respectively. For stationary functions, Eq. (9.66) becomes

\[
C_y(\boldsymbol{h}, \tau) = C^{(s)}(\boldsymbol{h}) \times C^{(t)}(\tau), \quad \boldsymbol{h} \in R^d, \tau \in R. \tag{9.67}
\]

The separability also implies that the S-T correlation function can be written as

\[
\rho(\boldsymbol{h}, \tau) = \rho^{(s)}(\boldsymbol{h}, \mathbf{0}) \times \rho^{(t)}(\mathbf{0}, \tau), \quad \boldsymbol{h} \in R^d, \tau \in R. \tag{9.68}
\]

In practice, separability says that the spatial and temporal effects of the process \(Y(\boldsymbol{s}, t)\) are orthogonal to each other, and they can be parameterized by separate functions. Conversely, if the S-T correlation is the product of a spatial correlation function and a temporal correlation function, then the process is separable. Thus, Eq. (9.68) is a characterization of separability in second-order stationary processes. Therefore, the equation provides a way to check the separability assumption by comparing \(C_y(\boldsymbol{h}, \tau)\) with \(C_y(\boldsymbol{h}, \mathbf{0}) \times C_y(\mathbf{0}, \tau)\).

Figure 9.14 shows a contour plot of a nonseparable S-T correlation given by Eq. (6.3) of Cressie and Wikle (2011). From the plot, it is seen that the correlations are nonlinear functions of spatial distance \(h\) and temporal lag \(\tau\). In the literature, many models have been proposed for the S-T processes. These models have various features in their S-T covariance functions. See, for instance, the regional-effect model of Reinsel et al. (1981) and the mixture model of Oehlert (1993), among others.
