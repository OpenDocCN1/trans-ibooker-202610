# ## 7.6.3 Boosting for Classification

The first application for Boosting was for binary classification with the AdaBoost algorithm of Freund and Schapire (1996, 1997). In the statistical literature, Breiman (1998, 1999) showed that the AdaBoost algorithm can be represented as a steepest descent algorithm in function space. As discussed in Chapter 5, given a set of n elements and a vector of classification variables, x, for each element, a classifier is a function C(x) that assigns to each element a value C(x_i) \in {-1,1} for 1 \le i \le n. Assuming we have a vector y = (y_1, ..., y_n)' with values y_i \in {-1,1} with the correct classification, the error rate in the set of the classifier C(x) is given by

\[\text{Err} = \frac{1}{n} \sum_{i=1}^n I(C(\boldsymbol{x}_i) \neq y_i) \quad (7.51)\]
