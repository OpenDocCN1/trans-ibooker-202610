# 9.7.4 Spatial Principal Component Analysis

Instead of using prespecified spatial basis functions, one can use empirical principal component analysis (PCA) to select suitable basis functions for random-effects modeling of spatial data. Wang and Huang (2017) propose a regularized PCA approach, which is relatively easy to use and data adaptive.

For simplicity, assume that there are no covariates, and _Y_(**s**, _t_) is zero mean with a common spatial covariance function _C<sub>y</sub>_(**s**<sub>1</sub>_,_**s**<sub>2</sub>) = Cov[_Y_(**s**<sub>1</sub>, _t_), _Y_(**s**<sub>2</sub>, _t_)] for all _t_ = 1, ..., _T_. As before, we assume that the data are observed at locations **s**<sub>1</sub>, ..., **s**_<sub>m</sub>_ on the spatial domain _D_ ⊂ _R<sup>d</sup>_ with independent measurement errors. Furthermore, assume that {_Y_(**s**, _t_)} are mutually temporally uncorrelated. Consider a rank _K_ spatial random-effects model for _Y_(**s**, _t_):

```
Y(\mathbf{s}, t) = [\psi_1(\mathbf{s}), \dots, \psi_K(\mathbf{s})]\boldsymbol{\xi}_t = \sum_{i=1}^K \xi_{ti}\psi_i(\mathbf{s}), \quad \mathbf{s} \in D; t = 1, \dots, T, \quad (9.88)
```

where \(\{\psi_i(\mathbf{s})\}\) are unknown orthonormal basis functions, \(\boldsymbol{\xi}_t = (\xi_{t1}, \dots, \xi_{tK})' \sim (\mathbf{0}, \boldsymbol{\Lambda})\) (_t_ = 1, ..., _T_) are uncorrelated random variables and \(\boldsymbol{\Lambda}\) is an unknown symmetric nonnegative-definite matrix.

Write \(\boldsymbol{\Lambda} = [\lambda_{ij}]_{K \times K}\). The spatial covariance function of _Y_(**s**, _t_) is

```
C_Y(\mathbf{s}_1, \mathbf{s}_2) = \sum_{i=1}^K \sum_{j=1}^K \lambda_{ij} \psi_i(\mathbf{s}_1)\psi_j(\mathbf{s}_2). \quad (9.89)
```

Let \(\boldsymbol{\Lambda} = \mathbf{V} \boldsymbol{\Lambda}^* \mathbf{V}'\) be the eigen-decomposition of \(\boldsymbol{\Lambda}\), where _V_ consists of the _K_ orthonormal eigenvectors and \(\boldsymbol{\Lambda}^* = \text{diag}\{\lambda_1^*, \dots, \lambda_K^*\}\), where \(\lambda_1^* \ge \cdots \ge \lambda_K^*\) are the corresponding eigenvalues.
