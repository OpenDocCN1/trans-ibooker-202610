
For time series analysis, the approach has been studied for ARMA mixtures by Xiong and Yeung (2004) and from a Bayesian point of view by Frühwirth-Schnatter and Kaufmann (2008). These procedures start with some initial estimation of the allocation of the series to the groups. Then, compute the parameters of the mixture and with those parameters make a new allocation of the series to the groups, and iterate these two steps until convergence. The estimation is carried out group by group and the best solution is selected by the BIC criterion or the posterior probability.

## 5.3.3.1 Maximum Likelihood (ML) Estimation of the AR Mixture Model

Suppose that each series is generated by a Gaussian AR(p) model, where \(p < k\), of one of \(G\) groups with different AR parameters and residual variances. The series are independent and each one \(\boldsymbol{z}_i = (z_{i1}, \dots, z_{iT})'\), \(i=1, \dots, k\), can be considered as generated by a mixture of distributions:

\(f(\boldsymbol{z}_i) = \sum_{g=1}^G \pi_g f_g(\boldsymbol{z}_i | \boldsymbol{\phi}_g, \sigma_g^2),\) (5.29)

where \(\pi_g\) is the unknown probability of the \(g\) group, \(\boldsymbol{\phi}_g = (\phi_{1g}, \dots, \phi_{pg})'\) is the vector of AR parameters and \(\sigma_g^2\) is the variance of the noise in group \(g\), and \(f_g\) is the joint density of the univariate observations generated by a Gaussian AR(p), see section 2.8.3. Calling \(\boldsymbol{\omega}_g = (\boldsymbol{\phi}'_g, \sigma_g^2)\), and \(\boldsymbol{\beta} = (\pi_1, \dots, \pi_G, \boldsymbol{\phi}'_1, \dots, \boldsymbol{\phi}'_G, \sigma_1^2, \dots, \sigma_G^2)'\) to all the parameter vector of the mixture model in Eq. (5.29), the joint conditional log-likelihood for \(\tilde{\boldsymbol{z}}_i = (z_{i,p+1}, \dots, z_{i,T})'\), for \(i=1, \dots, k\), is

\(L_C(\boldsymbol{\beta}) = \sum_{i=1}^k \log \left( \sum_{g=1}^G \pi_g f_g(\tilde{\boldsymbol{z}}_i | \boldsymbol{\psi}_g) \right),\) (5.30)

where \(f_g(\tilde{\boldsymbol{z}}_i | \boldsymbol{\psi}_g)\) is the joint density function of \(\tilde{\boldsymbol{z}}_i\) conditioned on the first \(p\) observations. This function has many maximums, linked to solutions where each density is determined precisely by an observation. In order to avoid these singularities, we assume that there are at least \(p+1\) observations from each group and try to find a local maximum of this function. An additional problem with this likelihood function is that the normal distributions are not identified, since the ordering \(1, \dots, G\) is arbitrary. To solve this problem, we can assume that the distributions \(1, \dots, G\) correspond to \(\pi_1 \ge \pi_2 \ge \dots \ge \pi_G\).

To maximize the function in Eq. (5.30) with respect to the probabilities \(\pi_g\), the restriction \(\sum_{g=1}^G \pi_g = 1\) is introduced with a Lagrange multiplier and the function to be maximized is

\(L_C(\boldsymbol{\beta}) = \sum_{i=1}^k \log \sum_{g=1}^G \pi_g f_g(\tilde{\boldsymbol{z}}_i | \boldsymbol{\psi}_g) - \lambda \left( \sum_{g=1}^G \pi_g - 1 \right).\) (5.31)

Taking the derivatives of the function with respect to the group probabilities \(\pi_g\):

\(\frac{\partial L_C(\boldsymbol{\beta})}{\partial \pi_g} = \sum_{i=1}^k \frac{f_g(\tilde{\boldsymbol{z}}_i | \boldsymbol{\psi}_g)}{\sum_{g=1}^G \pi_g f_g(\tilde{\boldsymbol{z}}_i | \boldsymbol{\psi}_g)} - \lambda = 0\)

and multiplying by \(\pi_g\) (assuming that \(\pi_g \neq 0\), as otherwise the model g is redundant), we write

$$\lambda \widehat{\pi}_g = \sum_{i=1}^k \widehat{\pi}_{ig}.$$

where \(\widehat{\pi}_{ig}\) is the posterior probability, given the data \(\vec{\mathbf{z}}_i\), that series \(i\) was generated by the gth distribution. These probabilities are calculated by Bayes' theorem

$$\widehat{\pi}_{ig} = \frac{\pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\sum_{g=1}^G \pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)},$$

and \(\sum_{g=1}^G \widehat{\pi}_{ig} = 1\). In order to determine the value of \(\lambda\), adding up (5.32) for all the groups, we find \(\lambda = k\), and, substituting this value in (5.32), the prior group probabilities are estimated by

$$\widehat{\pi}_g = \frac{1}{k} \sum_{i=1}^k \widehat{\pi}_{ig}.$$

To estimate the AR parameters, we take the derivative of Eq. (5.31) with respect to them that can be written as

$$\frac{\partial L_C(\boldsymbol{\beta})}{\partial \boldsymbol{\phi}_g} = \sum_{i=1}^k \frac{\pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\sum_{g=1}^G \pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)} \frac{\partial \log f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\partial \boldsymbol{\phi}_g} = 0.$$

Using Eq. (5.33) and the results of section 2.8.1, we have

$$\frac{\partial L_C(\boldsymbol{\beta})}{\partial \boldsymbol{\phi}_g} = 0 = \sum_{i=1}^k \widehat{\pi}_{ig} (\widetilde{\mathbf{Z}}'_i \vec{\mathbf{z}}_i - \widetilde{\mathbf{Z}}'_i \widetilde{\mathbf{Z}}_i \boldsymbol{\phi}_g),$$

where \(\widetilde{\mathbf{Z}}_i\) is the \((T-p) \times p\) matrix of lagged values. Therefore,

$$\widehat{\boldsymbol{\phi}}_g = \left( \sum_{i=1}^k \widehat{\pi}_{ig} \widetilde{\mathbf{Z}}'_i \widetilde{\mathbf{Z}}_i \right)^{-1} \left( \sum_{i=1}^k \widehat{\pi}_{ig} \widetilde{\mathbf{Z}}'_i \vec{\mathbf{z}}_i \right),$$

which is the standard equation to estimate the parameters using all the series but each series is weighted by the estimated posterior probability of the series belonging to the groups. A similar equation is obtained for the innovation variances. However, to compute \(\widehat{\boldsymbol{\phi}}_g\) we need the \(\widehat{\pi}_{ig}\), that are computed by (5.33) and requires the model parameters. Intuitively, we could iterate between both steps, which is the solution provided by the expectation-maximization (EM) algorithm.

## 5.3.3.2 The EM Algorithm

The EM algorithm is a powerful iterative method to find ML estimates of missing values and also missing variables (latent variables). It was introduced by Dempster et al. (1977). With missing variables, as in our case, the algorithm iterates between an expectation (E) step, finding the expectation of the log-likelihood with respect to the missing variables using the current estimates of the parameters, and a maximization (M) step, maximizing the log-likelihood with respect to the parameters, given the values of the missing variables.

In order to apply the EM algorithm we transform the problem by introducing a set of unobserved or missing vector variables ($s_1, \dots, s_k$), where $s_i$ is a $G$-dimensional vector of multinomial variables with only one component equal to one, that corresponds to the group to which $\tilde{z}_i$ belongs, and all the rest equal zero. For example, if $\tilde{z}_i$ comes from the first model $s_{i1} = 1$ and $s_{i2} = \cdots = s_{iG} = 0$. Then $\sum_{g=1}^G s_{ig} = 1$ and $\sum_{i=1}^k \sum_{g=1}^G s_{ig} = k$. With these new variables, the density function of $\tilde{z}_i$ conditional on $s_i$ can be written

$$f(\tilde{z}_i|s_i) = \prod_{g=1}^G f_g(\tilde{z}_i|\psi_g)^{s_{ig}}. \quad (5.36)$$

Analogously, the probability function of the missing variables $s_i$ will be

$$p(s_i) = \prod_{g=1}^G \pi_g^{s_{ig}}. \quad (5.37)$$

On the other hand, the joint density function of the observed variables $\tilde{z}_i$ and the missing variables $s_i$ is

$$f(\tilde{z}_i, s_i) = f(\tilde{z}_i|s_i)p(s_i),$$

that can be written, by Eqs. (5.36) and (5.37), as

$$f(\tilde{z}_i, s_i) = \prod_{g=1}^G (\pi_g f_g(\tilde{z}_i|\psi_g))^{s_{ig}},$$

and the joint log-likelihood function is

$$L(\beta) = \sum_{i=1}^k \log f(\tilde{z}_i, s_i) = \sum_{i=1}^k \sum_{g=1}^G s_{ig} \log \pi_g + \sum_{i=1}^k \sum_{g=1}^G s_{ig} \log f_g(\tilde{z}_i|\psi_g). \quad (5.38)$$

The EM algorithm begins with an initial estimate $\hat{\beta}^{(0)}$ of the vector of parameters, usually computed with Hierarchical clustering or $k$-means. In step E, we calculate the expectations of the missing values in the complete likelihood (5.38) conditional on the initial parameters and on the observed data. Since the likelihood is linear in $s_{ig}$, this is equivalent to substituting the missing variables by its expectations. The missing variables, $s_{ig}$, are binomial with values 0,1, and

$$E(s_{ig}|\hat{\beta}^{(0)}, Z) = p(s_{ig} = 1|\hat{\beta}^{(0)}, Z) = \hat{\pi}_{ig}^{(0)}$$
