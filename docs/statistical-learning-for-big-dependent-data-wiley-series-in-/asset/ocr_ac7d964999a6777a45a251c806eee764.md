For instance, consider the simplest case of a stationary zero-mean univariate time series, \(x_t\), and \(k=m=1\), with linear activation functions and \(d=1\). Then, \(s_t = wh_{t-1} + ux_t = h_t\) and the state is also the memory function, and \(\hat{y}_t = \hat{x}_{t+1} = vh_t\). Assuming \((w, u, w) < 1\), we have that \(s_t = u(1 + wB + w^2B^2 + \cdots + w^tB^t)x_t\) and, for large \(t\), \((1 - wB)s_t = ux_t\) and \(\hat{x}_{t+1} = w\hat{x}_t + uwx_t\). Thus, the forecast generated by this simple RNN corresponds to that of an ARMA(1,1) process. Increasing the dimension \(d\) and for \(k=1\), other univariate autoregressive integrated moving-average (ARIMA) forecasts can be generated. For \(k > 1\), the output is a vector time series. An RNN can generate forecasts for nonlinear autoregressive with exogenous variables (NARX) models

```
\(\hat{y}_t = F(\mathbf{y}_{t-1}, \dots, \mathbf{y}_{t-p}, \mathbf{x}_t, \dots, \mathbf{x}_{t-h}).\)
```

See Siegelmann et al. (1997). Another type of RNN is the Jordan (1997) network given by

```
\(\mathbf{h}_t = g_h(\mathbf{W}\mathbf{y}_{t-1} + \mathbf{U}\mathbf{x}_t + \mathbf{b}),\) (8.27)
```

```
\(y_t = g_y(\mathbf{V}\mathbf{h}_t + c),\) (8.28)
```

where \(g_h(.)\) and \(g_y(.)\) are activation functions. Here the state \(\mathbf{s}_t\) is omitted.

In general, the output \(y_t\) of an RNN follows certain probability distribution and the maximum likelihood function is used to estimate the parameters. Also, a deep RNN may assume feedback in many ways. It can be from a hidden layer to a hidden layer to a hidden layer or from nodes to nodes. See Goodfellow et al. (2016) for some examples. One can think of RNNs as networks that allow information to pass through certain neurons multiple times. Training an RNN can also be done by similar methods to those of a feedforward network. The only change needed is to compute the gradient recursively.
