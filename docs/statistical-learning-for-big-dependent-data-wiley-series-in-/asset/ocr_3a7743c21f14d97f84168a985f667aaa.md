# ## 4.3.1.1 Effects on Residuals and Estimation

An MAO leaves certain trace in the residual series of \(z_t\) that can be used to detect the outlier. For simplicity in discussion, suppose that the true parameters of the VAR model are known. Then, from Eq. (4.18), we have

```
\(e_t = X_t^A \omega_A + a_t,\) \tag{4.19}
```

where \(e_t = \Phi(B)z_t\) are the residuals of the observed time series and \(X_t^A\) is a square matrix given by \(X_t^A = \Phi(B)I_t^{(h)}\). Using \(B^j I_t^{(h)} = I_{t-j}^{(h)} = I_t^{(h+j)}\), it is easy to see that

```
\(X_t^A = \begin{cases} \mathbf{0}, & \text{if } t < h, \\ I_k, & \text{if } t = h, \\ -\Phi_j, & \text{if } t = h + j, \text{ with } j = 1, \dots, p, \\ \mathbf{0}, & \text{if } t > h + p, \end{cases}\)
```

where \(I_k\) is the \(k \times k\) identity matrix. Consequently, Eq. (4.19) implies that an MAO at \(t = h\) affects \(p + 1\) residuals of \(z_t\) starting at \(t = h\). Specifically,

```
\(e_{h+j} = -\Phi_j \omega_A + a_{h+j}, \quad j = 0, \dots, p\) \tag{4.20}
```

with \(\Phi_0 = -I_k\). Equation (4.20) shows that an AO at \(t = h\) has a complicated impact on the residuals \(e_t\) of the series \(z_t\). In theory, the MAO affects \(e_t\) for \(t = h, \dots, h + p\). However, it is possible that \(\Phi_j \omega_A = \mathbf{0}\) for some \(j\). In this case, the MAO does not affect \(e_{h+j}\). Also, if \(\omega_A\) is the \(i\)th unit vector, i.e. \(\omega_{jA} = 1\) if \(j = i\) and \(\omega_{jA} = 0\), otherwise, then the product \(-\Phi_j \omega_A\) is the \(i\)th column of \(-\Phi_j\), indicating that an MAO that only happens in a single series can affect all the other time series.

These results can easily be generalized to a VARMA process via its AR representation. For \(\pi(B)y_t = a_t\), provided that \(\pi(B)\) is known, the observed residuals are \(e_t = \pi(B)z_t\) and Eq. (4.20) becomes

```
\(e_{h+j} = -\pi_j \omega_A + a_{h+j}, \quad j = 0, 1, \dots,\)
```

where \(\pi_0 = -I_k\). Consequently, in theory, an MAO at \(t = h\) for a vector time series \(z_t\) may affect all of its residuals \(e_t\) for \(t \ge h\). In the presence of multiple MAOs, effect on the residuals of the observed vector time series, \(z_t\), can become complicated.

The global effect of an AO or an MAO in a time series is to bias its sample ACFs toward zero and, depending on the components of \(\omega_A\), also bias the cross-correlations toward zero. Therefore, parameter estimates of a model for the series are also biased. We illustrate the effect using the simple case of a scalar zero-mean AR(1) process with an AO of size \(\omega_A\) at time \(h\). The least squares estimate of the AR parameter is \(\hat{\phi} = \sum (z_t - \bar{z})(z_{t-1} - \bar{z}) / \sum (z_t - \bar{z})^2\), where \(\bar{z}\) denotes the sample mean. As \(z_h = y_h + \omega_A\), and \(z_t = y_t, t \neq h\), then \(\bar{z} = \bar{y} + \frac{1}{T} \omega_A\), and assuming \(T\) large, so that \(\omega_A / T \simeq 0\) and \(\bar{z} \simeq 0\), we have

```
\(\hat{\phi} = \frac{\sum y_t y_{t-1} + \omega_A(y_{h-1} + y_{h+1})}{\sum y_t^2 + \omega_A^2 + 2\omega_A y_h}.\)
```

Therefore, the size of the outlier appears linearly in the numerator, but quadratically in the denominator, suggesting that when \(\omega_A\) is very large the value of \(\hat{\phi}\) will be small. This result can be generalized to the vector case depending on the values \(\Phi_j \omega_A\). In general, the effect of the AO decreases with the sample size and the magnitude of the outlier.
