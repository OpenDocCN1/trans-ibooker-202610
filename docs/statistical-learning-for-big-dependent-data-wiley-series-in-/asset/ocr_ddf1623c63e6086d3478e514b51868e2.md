By Eqs. (3.36) and (3.37), we have

\(z_{n+1} = z_n(1) + a_{n+1}.\) (3.38)

For \(h = 2\), using Eqs. (3.35) and (3.38), we have

\(z_{n+2} = \phi_0 + \phi_1 z_{n+1} + \phi_2 z_n + \cdots + \phi_p z_{n+2-p} + a_{n+2}\)
\(= \phi_0 + \phi_1[z_n(1) + a_{n+1}] + \phi_2 z_n + \cdots + \phi_p z_{n+2-p} + a_{n+2}\)
\(= \phi_0 + \phi_1 z_n(1) + \phi_2 z_n + \cdots + \phi_p z_{n+2-p} + a_{n+2} + \phi_1 a_{n+1}.\)

It is then clear that the 2-step ahead prediction and its associated error are

\(z_n(2) = E(z_{n+2}|F_n) = \phi_0 + \phi_1 z_n(1) + \phi_2 z_n + \cdots + \phi_p z_{n+2-p}\) (3.39)
\(e_n(2) = z_{n+2} - z_n(2) = a_{n+2} + \phi_1 a_{n+1}\) (3.40)
\(V[e_n(2)] = \Sigma_a + \phi_1 \Sigma_a \phi_1'.\)

In general, one can repeat the process to obtain that, for the \(h\)-step ahead prediction,

\(z_n(h) = \phi_0 + \sum_{i=1}^p \phi_i z_n(h-i)\) (3.41)
\(e_n(h) = a_{n+h} + \sum_{j=1}^{h-1} \psi_j a_{n+h-j}\) (3.42)
\(V[e_n(h)] = \Sigma_a + \sum_{j=1}^{h-1} \psi_j \Sigma_a \psi_j',\) (3.43)

where \(\psi_i\) is the \(i\)th \(\psi\)-weight coefficient matrix of \(z_t\); see Eq. (3.19). In Eq. (3.41), it is understood that \(z_n(\ell) = z_{n+\ell}\) for \(\ell \le 0\), i.e. \(z_n(0) = z_n\) and \(z_n(-1) = z_{n-1}\). Eqs. (3.41) and (3.43) imply that the forecasts and their associated covariance matrices of a VAR(\(p\)) model can be calculated recursively.

Using \(\phi_0 = (\mathbf{I} - \sum_{i=1}^p \phi_i)\mu\), Eq. (3.41) can be rewritten as

\(z_n(h) - \mu = \sum_{i=1}^p [z_n(h-i) - \mu].\)

Then, by using the \(kp\)-dimensional model representation in Eq. (3.18), one can easily derive that, if \(z_t\) is a stationary time series, we have \(z_n(h) - \mu \to \mathbf{0}\) as \(h \to \infty\). That is, \(z_n(h) \to \mu\) as \(h \to \infty\). This is referred to as the *mean reverting* of a stationary vector AR process. Furthermore, from Eq. (3.43), we have \(\text{V}[e_n(h)] \to \text{V}(z_t)\) as \(h \to \infty\).

**Case 2: Parameter uncertainty.** In practice, the coefficient matrices \(\phi_i\) are unknown and one may consider parameter uncertainty in forecasting. For VAR models, the result is relatively simple. Note that the estimates \(\hat{\phi}_i\) and \(\hat{\Sigma}_a\) are available given \(F_n\) so that the model can be written as

\(z_{n+h} = \hat{\phi}_0 + \sum_{i=1}^p \hat{\phi}_i z_{n+h-i} + [\phi_0 - \hat{\phi}_0] + \sum_{i=1}^p [\phi_i - \hat{\phi}_i] z_{n+h-i} + a_{n+h}.\) (3.44)
