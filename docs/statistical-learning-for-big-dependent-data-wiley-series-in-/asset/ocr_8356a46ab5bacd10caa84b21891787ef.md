and multiplying by \(\pi_g\) (assuming that \(\pi_g \neq 0\), as otherwise the model g is redundant), we write

```
\(\lambda \widehat{\pi}_g = \sum_{i=1}^k \widehat{\pi}_{ig}.\)
```

where \(\widehat{\pi}_{ig}\) is the posterior probability, given the data \(\vec{\mathbf{z}}_i\), that series \(i\) was generated by the gth distribution. These probabilities are calculated by Bayes' theorem

```
\(\widehat{\pi}_{ig} = \frac{\pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\sum_{g=1}^G \pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)},\)
```

and \(\sum_{g=1}^G \widehat{\pi}_{ig} = 1\). In order to determine the value of \(\lambda\), adding up (5.32) for all the groups, we find \(\lambda = k\), and, substituting this value in (5.32), the prior group probabilities are estimated by

```
\(\widehat{\pi}_g = \frac{1}{k} \sum_{i=1}^k \widehat{\pi}_{ig}.\)
```

To estimate the AR parameters, we take the derivative of Eq. (5.31) with respect to them that can be written as

```
\(\frac{\partial L_C(\boldsymbol{\beta})}{\partial \boldsymbol{\phi}_g} = \sum_{i=1}^k \frac{\pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\sum_{g=1}^G \pi_g f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)} \frac{\partial \log f_g(\vec{\mathbf{z}}_i | \boldsymbol{\psi}_g)}{\partial \boldsymbol{\phi}_g} = 0.\)
```

Using Eq. (5.33) and the results of section 2.8.1, we have

```
\(\frac{\partial L_C(\boldsymbol{\beta})}{\partial \boldsymbol{\phi}_g} = 0 = \sum_{i=1}^k \widehat{\pi}_{ig} (\widetilde{\mathbf{Z}}'_i \vec{\mathbf{z}}_i - \widetilde{\mathbf{Z}}'_i \widetilde{\mathbf{Z}}_i \boldsymbol{\phi}_g),\)
```

where \(\widetilde{\mathbf{Z}}_i\) is the \((T-p) \times p\) matrix of lagged values. Therefore,

```
\(\widehat{\boldsymbol{\phi}}_g = \left( \sum_{i=1}^k \widehat{\pi}_{ig} \widetilde{\mathbf{Z}}'_i \widetilde{\mathbf{Z}}_i \right)^{-1} \left( \sum_{i=1}^k \widehat{\pi}_{ig} \widetilde{\mathbf{Z}}'_i \vec{\mathbf{z}}_i \right),\)
```

which is the standard equation to estimate the parameters using all the series but each series is weighted by the estimated posterior probability of the series belonging to the groups. A similar equation is obtained for the innovation variances. However, to compute \(\widehat{\boldsymbol{\phi}}_g\) we need the \(\widehat{\pi}_{ig}\), that are computed by (5.33) and requires the model parameters. Intuitively, we could iterate between both steps, which is the solution provided by the expectation-maximization (EM) algorithm.
