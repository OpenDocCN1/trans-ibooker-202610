\(\alpha_T = \widehat{\phi}_{p,T} = (W'_T W_T)^{-1} W'_T \omega^T_{p+1},\)

where the subscript \(T\) is used to denote the data \(w^T_1\), and the associated covariance matrix is

\(S_{T+1|T} = S_T = \text{Cov}(\widehat{\phi}_{p,T}) = (W'_T W_T)^{-1} \sigma^2_{a,T}.\)

The prediction error of the new observation \(\varpi_{T+1}\) at the forecast origin \(T\) is

\(e_{T+1} = \widehat{a}_{T+1|T} = \varpi_{T+1} - \widehat{\phi}_{p,T} \omega^T_{T-p+1},\) (2.97)

with variance (see Eq. (2.73))

\(p_{T+1|T} = E(e^2_{T+1}) = [(\omega^T_{T-p+1})'(W'_T W_T)^{-1}(\omega^T_{T-p+1}) + 1]\widehat{\sigma}^2_{a,T}\)
\(= (1 + h_{T+1|T})\widehat{\sigma}^2_{a,T}.\) (2.98)

where

\(h_{T+1|T} = (\omega^T_{T-p+1})'(W'_T W_T)^{-1}(\omega^T_{T-p+1}),\)

and the new estimate of the parameters, given \(\varpi_{T+1}\), is

\(\alpha_{T+1} = \widehat{\phi}_{p,T+1} = \widehat{\phi}_{p,T} + (W'_T W_T)^{-1} \omega^T_{T-p+1} e^{T+1} / (1 + h_{T+1|T}).\) (2.99)

Note that the changes in the parameters are proportional to the prediction error \(e_{T+1}\), and if this prediction error is zero the parameters are not updated. Otherwise, the parameter updates depend on the vector of regressors \(\omega^T_{T-p+1}\). The new covariance matrix of the parameters is given by

\(S_{T+1} = (W'_{T+1} W_{T+1})^{-1} \widehat{\sigma}^2_{a,T+1},\) (2.100)

that can be written

\(S_{T+1} = (W'_T W_T)^{-1} \widehat{\sigma}^2_{a,T} [I - \omega^T_{T-p+1} (\omega^T_{T-p+1})'(W'_T W_T)^{-1} / (1 + h_{T+1|T})].\) (2.101)

Since \(\widehat{\sigma}^2_a(T) = \sum^T_{t=p+1} (\varpi_t - \widehat{\phi}'_p(T) \omega^{t-p}_{t-1})^2 / (T - p)\) and \(\widehat{\sigma}^2_a(T+1) = \sum^{T+1}_{t=p+1} (\varpi_t - \widehat{\phi}'_p(T+1) \omega^{t-p}_{t-1})^2 / (T + 1 - p)\) are known, we can compute \((W'_{T+1} W_{T+1})^{-1}\) by Eqs. (2.100) and (2.101) without the need to compute the inverse matrix directly.

For ARMA models an approximate updating scheme can also be derived by using the linear model representation Eq. (2.96). In fact, the updating algorithm given by Eqs. (2.97) to (2.99) was obtained by Plackett (1950) for any linear model of the form \(y_t = x'_t \beta_t + u_t\). Calling \(e_{T+1} = y_{T+1} - x'_{T+1} \widehat{\beta}_T\), the updating is

\(\widehat{\beta}_{T+1} = \widehat{\beta}_T + (X'_T X_T)^{-1} x_{T+1} e_{T+1} / (1 + h_{T+1|T}),\) (2.102)
