
We prove next the fourth property about multiple roots in the characteristic equation. To begin, we show that when two roots are equal the two corresponding terms \(A_t G_t^t\) can be written as \((A_1 + A_2 t)G^t\). Let us assume Eq. (2.115), whose characteristic equation is

\((1 - \phi_1 B - \phi_2 B^2) = 0.\) (2.124)

If there is a double root in this equation, \(G_0^{-1}\), it is verified:

\((1 - G_0 B)^2 = (1 - \phi_1 B - \phi_2 B^2),\)

which implies \(\phi_2 = -G_0^2\) and \(\phi_1 = 2G_0\), thus

\(\phi_1 G_0 + 2\phi_2 = 0.\) (2.125)

We check that if \(G_0^t\) is a solution to Eq. (2.124), \(t G_0^t\) is also a solution. Substituting

\((1 - \phi_1 B - \phi_2 B^2)t G_0^t = t G_0^t - \phi_1 (t - 1) G_0^{t-1} - \phi_2 (t - 2) G_0^{t-2},\)

and taking out common factors, we have:

\(t G_0^{t-2}(G_0^2 - \phi_1 G_0 - \phi_2) + G_0^{t-2}(\phi_1 G_0 + 2\phi_2) = 0.\)

The first term is zero, because \(G_0\) is a solution, and the second as well, according to Eq. (2.125). Hence, we conclude that the general solution is

\(x_t = (A_1 + A_2 t)G_0^t.\)

These results can be extended to equations of any order and with roots that are equal or different. We assume a homogeneous linear difference equation

\((1 - \phi_1 B - \phi_2 B^2 - \cdots - \phi_h B^h)x_t = 0.\) (2.126)

If there are roots repeated \(r\) times, that is, a term exists with the form \((1 - G_0 B)^r\), it is easy to prove, as in the case \(r = 2\), that the solution associated with this term is

\(x_t = (A_1 + A_2 t + \cdots + A_r t^{r-1})G_0^t.\) (2.127)

Therefore, the general solution of Eq. (2.126) contains: (1) a term of type \(A_t G_t^t\) for each non-repeated real root; (2) a polynomial term of order \((r - 1)\) that multiplies \(G_0^t\) for each real root repeated \(r\) times; (3) a sinusoidal term for each pair of complex conjugate roots.

Finally, we prove the fifth property. Suppose the equation \(\phi(B)x_t = c\). We are going to prove that if \(y_t\) is a solution then so is \(y_t + q_t\), where \(q_t\) is a solution to the homogeneous equation, \(\phi(B)q_t = 0\). This is straightforward to show, since

\(\phi(B)(y_t + q_t) = \phi(B)y_t = c.\)

## Validity of a Solution and Initial Values

A variable can verify a difference equation from a defined point in time. Thus, the solution to the equation provides values of the variable that verify the equation not only from this defined point, but also for the previous times that are necessary for calculating the solution. That is, if the equation is valid for $t \ge t_0$ and it needs $h$ initial values to solve it, the solution will be valid for values from $t \ge t_0 - h$, that is, from the origin of the equation minus the number of initial values required to calculate the solution.

To illustrate this result, we start with the first-order equation:

$$x_t - \phi x_{t-1} = 0, \quad t \ge t_0.$$

If the equation is valid for $t = t_0$, we have $x_{t_0} = \phi x_{t_0-1}, x_{t_0+1} = \phi x_{t_0} = \phi^2 x_{t_0-1}$, and, in general,

$$x_t = \phi^{t-t_0+1} x_{t_0-1}.$$

Note that this solution is valid for $t \ge t_0 - 1$. Indeed, for $t = t_0 - 1$ it provides the result $x_{t_0-1} = x_{t_0-1}$, which is trivially true. Therefore, we conclude that the solution is valid for the interval of definition of the equation, minus the number of initial values needed to initiate the sequence.

We check this rule in a second-degree equation:

$$x_t - \phi_1 x_{t-1} - \phi_2 x_{t-2} = 0, \quad t \ge 1.$$

From the above results we know that the solution is:

$$x_t = A_1 G_1^t + A_2 G_2^t,$$

where $G_1^{-1}$ and $G_2^{-1}$ are the roots of the characteristic equation. Let us check that this solution is valid for $t \ge -1$. For $t = 0$ we obtain

$$x_0 = A_1 + A_2,$$

and for $t = -1$, we have

$$x_{-1} = A_1 G_1^{-1} + A_2 G_2^{-1}.$$

We now prove that the three values $x_1, x_0$ and $x_{-1}$ verify the equation. Substituting in the second-degree equation

$$x_1 = A_1 G_1 + A_2 G_2 = \phi_1 x_0 + \phi_2 x_{-1}$$
$$= \phi_1(A_1 + A_2) + \phi_2(A_1 G_1^{-1} + A_2 G_2^{-1}),$$

and grouping terms

$$A_1 G_1 + A_2 G_2 = A_1(\phi_1 + \phi_2 G_1^{-1}) + A_2(\phi_1 + \phi_2 G_2^{-1}),$$

which is always true, as is proved by using the relationship between the parameters and the roots, $\phi_1 = G_1 + G_2$ and $\phi_2 = -G_1 G_2$, which was obtained by solving the second-degree equation.

Generalizing, if we have a difference equation of order $h$ valid for $t \ge t_0$ we need $h$ initial values to begin the sequence. Since these initial values are obtained with the equation that provides the solution, the solution provides the valid values of the sequence for $t \ge t_0 - h$.
