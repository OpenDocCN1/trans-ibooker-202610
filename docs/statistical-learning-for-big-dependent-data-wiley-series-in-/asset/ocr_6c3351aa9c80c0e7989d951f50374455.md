For \( j = 1, \dots, h \), define recursively

```
\(\hat{z}_n(j) = \hat{\Phi}_0 + \sum_{i=1}^p \hat{\Phi}_i \hat{z}_n(j-i),\) (3.45)
```

where it is understood that \(\hat{z}_n(\ell) = z_{n+\ell}\) for \(\ell \le 0\). Also, let

```
\(\hat{e}_n(j) = z_{n+j} - \hat{z}_n(j), \quad j=1, \dots, h\) (3.46)
```

be the \( j \)-step ahead forecast error under parameter uncertainty. By Eq. (3.46), we have

```
\(\hat{e}_n(j) = z_{n+j} - z_n(j) + z_n(j) - \hat{z}_n(j) = e_n(j) + [z_n(j) - \hat{z}_n(j)].\) (3.47)
```

Since \( e_n(j) = a_{n+j} + \sum_{i=1}^{j-1} \Psi_v a_{n+v} \) and both \( z_n(j) \) and \( \hat{z}_n(j) \) are functions of \( F_n \), the two terms on the right side of Eq. (3.47) are uncorrelated for \( j \ge 1 \) and we have

```
\(\text{V}[\hat{e}_n(j)] = \text{V}[e_n(j)] + E\{[z_n(j) - \hat{z}_n(j)][z_n(j) - \hat{z}_n(j)]'\}\)
\(\equiv \text{V}[e_n(j)] + \text{MSE}[z_n(j) - \hat{z}_n(j)],\) (3.48)
```

where \(\equiv\) denotes equivalence. It remains to derive the MSE term. For the VAR models, one can derive a closed-form solution for the MSE. See, for instance, Tsay (2014, section 2.9.2) and the references therein. For a VAR(\( p \)) model and 1-step ahead prediction, we have MSE[\( z_n(1) - \hat{z}_n(1) \)] = \( (kp+1)\Sigma_a/(T - p) \). Therefore, we obtain

```
\(\text{V}[\hat{e}_n(1)] = \frac{(T - p) + kp + 1}{T - p} \Sigma.\) (3.49)
```

Since \( kp + 1 \) is the number of parameters for the component \( z_{it} \) of a fitted VAR(\( p \)) model, Eq. (3.49) implies that for each estimated parameter of an VAR(\( p \)) model, it increases the uncertainty in 1-step ahead prediction by a factor of \( 1/(T - p) \), where \( T - p \) is the effective number of observations used in fitting the VAR(\( p \)) model. In practice, the result says that it pays to use an adequate, parsimonious VAR model in prediction.

# 3.2.6 Forecast Error Variance Decomposition

Consider the \( h \)-step ahead forecast error in Eq. (3.42). In addition, let \( \eta_t = \Sigma_a^{-1/2} a_t \), where \( \Sigma_a^{1/2} \) denotes the square-root matrix of \( \Sigma_a \). Then, we have V(\( \eta_t \)) = \( I_k \), the \( k \times k \) identity matrix. The forecast error can then be written as

```
\( e_n(h) = \Psi_0 \eta_{n+h} + \sum_{j=1}^{h-1} \Psi_j \eta_{n+h-j},\) (3.50)
```

where \( \Psi_0 = \Sigma_a^{1/2} \) and \( \Psi_j = \Psi_j \Sigma_a^{1/2} \). By Eq. (3.50), we have

```
\(\text{V}[e_n(h)] = \sum_{j=0}^{h-1} \Psi_j \Psi_j'.\) (3.51)
```
