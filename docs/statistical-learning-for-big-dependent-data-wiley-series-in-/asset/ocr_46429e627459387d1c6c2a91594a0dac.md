The term $2e'X(\hat{\beta} - \beta^0)$ is referred to as the *empirical process* of the problem. That is, it is the random part of the problem and it can be bounded by the $\ell_1$ norm of the parameters involved as below:

$2|e'X(\hat{\beta} - \beta^0)| \le \left( \max_{1 \le j \le k} 2|e'X_{\cdot j}| \right) \|\hat{\beta} - \beta^0\|_1,$

where $X_{\cdot j}$ denotes the $j$th column of $X$. The idea of the penalty is then to dominate the empirical process of the problem. Therefore, define

$F = \left\{ \max_{1 \le j \le k} 2|e'X_{\cdot j}|/n \le \lambda_0 \right\}, \quad (79)$

where we assume that $\lambda > 2\lambda_0$ to ensure that on the set $F$ we can get rid of the random part of the problem. Let $\hat{\sigma}_j^2$ be the $(j,j)$th element of $\hat{\Sigma} = X'X/n$, which is the estimate of the variance of the $j$th predictor. The following result confirms that the set $F$ is not small.

# **Lemma 7.1** Assume that $\hat{\sigma}_j = 1$ for $j = 1, ..., k$. Then, for all $t > 0$ and for $\lambda_0 = 2\sigma_e \sqrt{\frac{t^2+2\log(k)}{n}}$, we have

$P(F) \ge 1 - 2 \exp(-t^2/2).$

# **Proof:** Under the assumption $\hat{\sigma}_j = 1$, the variable $U_j = e'X_{\cdot j}/(\sqrt{n\sigma_e^2})$ follows a $N(0, I)$ distribution. Therefore,

$P\left( \max_{1 \le j \le k} |U_j| > \sqrt{t^2+2\log(k)} \right) \le 2k \exp\left[ -\frac{t^2+2\log(k)}{2} \right] = 2 \exp\left( \frac{-t^2}{2} \right).$

Using the basic inequality and Lemma 7.1, we can obtain the consistency of the Lasso estimator.

# **Theorem 7.1** Assume that $\hat{\sigma}_j = 1$ for all $j$. For $t > 0$, let the penalty parameter be

$\lambda = 4\hat{\sigma}_e \sqrt{\frac{t^2+2\log(k)}{n}},$

where $\hat{\sigma}_e$ is an estimate of the standard error $\sigma_e$ of the error $\epsilon_i$. Then, with probability at least $1 - \alpha$, where $\alpha = 2 \exp[-t^2/2] + P(\hat{\sigma}_e \le \sigma_e)$,

$2\|X(\hat{\beta} - \beta^0)\|_2^2 \le 3\lambda\|\beta^0\|_1.$

See corollary 6.1 of Bühlmann and van de Geer (2011). It says that, for the linear model in Eq. (76), by taking the penalty (or regularization) parameter $\lambda$ of the order $\sqrt{\log(k)/n}$ and assuming that the $\ell_1$-norm of the true parameter $\beta^0$ is of smaller order than $\sqrt{n/\log(k)}$, we obtain the consistency result of the Lasso estimator.

The same result can be obtained when the design matrix is random, i.e. $X$ consists of random variables. In general, let

$\Sigma_X = \begin{cases} X'X/n, & \text{if the design is fixed,} \\ \text{Cov}(x_t), & \text{if the design is random.} \end{cases}$
