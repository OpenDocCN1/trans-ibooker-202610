Information criteria: An alternative approach to specify the order of a TFM is to use information criteria. The delay b is relatively easy to identify. For a given b, the order (r, s) can be selected by any information criterion such as Akaike’s information criterion (AIC) or Bayesian information criterion (BIC) with some pre-specified upper bounds (r_max, s_max), see Section 2.8.4.
