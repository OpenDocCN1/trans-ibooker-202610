
### 4. Find the new residuals:

```
\(\eta_i = \eta_{i-1} - o_i p'_i, \quad f_i = f_{i-1} - o_i q'_i.\)
```

From the Steps 1 and 4, it is clear that the algorithm at each step m gives two representations

```
\(X = \mu_X + p_1 o'_1 + \cdots + p_m o'_m + \eta_m, \quad Y = \mu_Y + q_1 o'_1 + \cdots + q_m o'_m + f_m. \quad (7.45)\)
```

From the properties of LS regression, it is clear from steps 3 and 4 that the residuals \(\eta_i\) is uncorrelated with \(o_i\) so that the scores \(o_1, \dots, o_m\) are uncorrelated. Furthermore, it can be shown that the weights \(w_1, \dots, w_m\) are also uncorrelated. From the algorithm, it is also clear that the linear dependence between **_Y_** and the residuals \(\eta_i\) is used to construct the scores **_X_**, which is then used to predict **_Y_**.

Finally, several R packages are available for PLS regression. The package **pls** and **plsdepot** provide PLS analysis. **plsdof** considers the degrees of freedom of PLS, **plsRglm** gives PLS analysis of generalized linear models, and **plsVarSel** provides variable selection of PLS.

## 7.6 BOOSTING

Boosting algorithms are proposed originally as ensemble methods, that is, methods that combine forecasts of several models (or approaches) to obtain an optimal prediction. The basic idea of boosting is to generate multiple predictions from adjusted data which are then aggregated, using linear combination or majority voting, to build the final estimator or prediction. It is similar to model averaging. Good references for boosting are Bühlmann and van de Geer (2011, chapter 12) and Hastie et al. (2009). Friedman et al. (2000) and Friedman (2001) develop a more general statistical framework which gives a direct interpretation of boosting as a statistical method for function estimation.

Given the data \(\{(\mathbf{x}_t, y_t) | t = 1, \dots, n\}\), boosting consists of two key ingredients. The first ingredient is called a *weak learner*, which is an easy to compute statistical prediction method. Examples of weak learner include a simple regression tree or a simple linear regression. The second ingredient is a method for data adjustment, where the variables to be fit are adjusted at each iteration in a way that often depends on the weak learner. Consider the model

```
\(y_t = f(\mathbf{x}_t) + \epsilon_t,\)  \(\text{(7.46)}\)
```

where \(\epsilon_t\) is the error term and \(f(.)\) is the unknown real-valued function of interest. A boosting algorithm works as follows:

- Adjusted data 1 \(\rightarrow\) weak learner \(\hat{f}^{(1)}(.)\)
- Adjusted data 2 \(\rightarrow\) weak learner \(\hat{f}^{(2)}(.)\)
- \(\vdots \quad \vdots\)
- Adjusted data \(r\rightarrow\) weak learner \(\hat{f}^{(r)}(.)\)

where \(r\) is a prespecified positive integer. Then, the aggregated result is

\(\text{aggregation} : \hat{f}_A = \sum_{i=1}^r \alpha_i \hat{f}^{(i)}(.), \quad (7.47)\)

where \(\alpha_i\) are suitable coefficients or weights. Obviously, the choice of weak learner, the number of iterations, and the selection of weights \(\alpha_i\) are important issues for boosting to be useful in application.

Mathematically speaking, to estimate the function \(f(.)\) of Eq. (7.46), we often employ a proper loss function and minimize it over some space of measurable functions. That is,

\(f_o(.) = \text{arg min}_{f \in S} E[L(f(X), y)] \quad (7.48)\)

where \(S\) denotes a space of measurable functions and \(L(f(.), y)\) is a loss function which is assumed to be differentiable and convex with respect to \(f(.)\). For the squared error loss, \(L(f(.), y) = (y - f(.))^2\) and the associated population minimizer is \(f_o(x) = E[Y|X=x]\).

Friedman (2001) gives a functional gradient descent (FGD) algorithm to estimate \(f_o(.)\). The algorithm is as follows:

### FGD Algorithm:

- 1. Initialize \(\hat{f}^{(0)}(.)\) such as \(\hat{f}^{(0)}(.) \equiv 0\) or

\(\hat{f}^{(0)} = \text{arg min}_c \frac{1}{n} \sum_{i=1}^n L(c, y_i).\)

Set \(r=0\).

- 2. Increase \(r\) by 1, i.e. \(r \leftarrow r+1\). Generate a new set of response variables by computing the negative gradient \(-\frac{dL(f,y)}{df}\) and evaluating it at \(\hat{f}^{(r-1)}(x_t)\). That is, compute

\(v_t = -\frac{\partial L(f, y_t)}{\partial f} |_{f=\hat{f}^{(r-1)}(x_t)}, \quad t=1, \dots, n.\)

- 3. Fit the new response variables \(v_1, \dots, v_n\) by the explanatory variables \(x_1, \dots, x_n\) by the weak learner, i.e.

\((x_t, v_t) \rightarrow \text{weak learner } g^{(r)}(.).\)

- 4. Update \(\hat{f}^{(r)}(.) = \hat{f}^{(r-1)}(.) + \delta \times \hat{g}^{(r)}(.),\) where \(0 < \delta \le 1\) is a step-size parameter.

- 5. Iterate Steps 2 to 4 until \(r = r_o\) for a prespecified positive integer \(r_o\).
