
## 5.5.2 Quadratic Classification and Admissible Functions

In time series classification, often the covariance matrices of the states are different. For instance, we have seen that two stationary time series models are generated by two Gaussian populations with different covariance matrices. Here c = 2. Then, we classify the series x_{0t} in state 1 if it is more likely that the observation x_0 is generated by this state, which implies

$$ \log |V_1| + (\mathbf{x}_0 - \boldsymbol{\mu}_1)' \mathbf{V}_1^{-1} (\mathbf{x}_0 - \boldsymbol{\mu}_1) > \log |V_2| + (\mathbf{x}_0 - \boldsymbol{\mu}_2)' \mathbf{V}_2^{-1} (\mathbf{x}_0 - \boldsymbol{\mu}_2), $$

and, therefore, if

$$ \mathbf{x}_0' (\mathbf{V}_1^{-1} - \mathbf{V}_2^{-1}) \mathbf{x}_0 - 2\mathbf{x}_0' (\mathbf{V}_1^{-1} \boldsymbol{\mu}_1 - \mathbf{V}_2^{-1} \boldsymbol{\mu}_2) > c, \quad (5.50) $$

where \( c = \log(|V_2|/|V_1|) + \boldsymbol{\mu}_2' \mathbf{V}_2^{-1} \boldsymbol{\mu}_2 - \boldsymbol{\mu}_1' \mathbf{V}_1^{-1} \boldsymbol{\mu}_1 \). This is a quadratic discriminant rule. Specifically, define

$$ \mathbf{V}_d^{-1} = (\mathbf{V}_1^{-1} - \mathbf{V}_2^{-1}), $$

and the new variable

$$ \mathbf{y}_0 = \mathbf{V}_d^{-1/2} \mathbf{x}_0. $$

Calling \( \mathbf{y}_0 = (y_{01}, \dots, y_{0p})' \) and defining \( \mathbf{m} = (m_1, \dots, m_p)' \) as

$$ \mathbf{y} = \mathbf{V}_d^{1/2} (\mathbf{V}_1^{-1} \boldsymbol{\mu}_1 - \mathbf{V}_2^{-1} \boldsymbol{\mu}_2), $$

Eq. (5.50) can be written as \( \mathbf{y}_0' \mathbf{y}_0 - 2 \mathbf{y}_0' \mathbf{m} > c \), or

$$ \sum_{i=1}^p y_{0i}^2 - 2 \sum_{i=1}^p y_{0i} m_i > c, $$

which is a quadratic equation in the new variables \( y_{0i} \).

In the general case of c states, an observation \( \mathbf{x}_0 \) is classified in the state in which

$$ D_i(\mathbf{x}_0) = \log |\mathbf{V}_i| + (\mathbf{x}_0 - \boldsymbol{\mu}_i)' \mathbf{V}_i^{-1} (\mathbf{x}_0 - \boldsymbol{\mu}_i) \quad (5.51) $$

is the largest.

When the parameters must be estimated, in the linear case we have to estimate cp mean parameters and \( p(p+1)/2 \) parameters for the covariance matrix. In the quadratic case this number grows to \( c(p + p(p+1)/2) \) and, if the dimension of the vector of features is large, this estimation requires a large sample. Friedman (1989) proposed to use a shrinkage estimator of the covariance matrices by

$$ \widehat{\mathbf{V}}_i(\alpha) = \alpha \widehat{\mathbf{V}}_i + (1 - \alpha) \widehat{\mathbf{V}}, $$

where \( \widehat{\mathbf{V}}_i \) is the estimation of the covariance matrix in the ith group, and \( \widehat{\mathbf{V}} \) the pooled covariance matrix in Eq. (5.49).

An alternative approach in these situations is to obtain a good linear discriminant rule according to some criteria. This is the idea of admissible linear procedures by Anderson and Bahadur (1962). The set of admissible linear procedures are in the form:

$$ \mathbf{w} = (t_1 \mathbf{V}_1 + t_2 \mathbf{V}_2)^{-1} (\boldsymbol{\mu}_2 - \boldsymbol{\mu}_1), \quad (5.52) $$
where $t_1$ and $t_2$ are positive numbers such that the matrix $(t_1 V_1 + t_2 V_2)$ is positive definite. Then the cutoff point $\tau$ for the classification is $\tau = w' \mu_1 + t_1 w' V_1 w = w' \mu_2 - t_2 w' V_2 w$. In order to find $t_1$ and $t_2$, we can fix $t_1 = 1$ and find $t_2$ by computing the classification errors and making the sum as small as possible. Admissible linear procedures can be obtained by information measures. An alternative of these linear admissible procedures is to find linear procedures in a larger space that includes nonlinear transformations of the variables, which is discussed via the Support Vector Machines.

## 5.5.3 Logistic Regression

Often the parameters of the feature distribution are unknown and must be estimated from previous time series data. When this distribution is multivariate normal, the Fisher LDF with the estimated Mahalanobis distances is optimal with equal covariance matrices and usually works well in large samples. However, when the distribution of the features used for classification is not normal, we have no guarantee that LDF will be optimal.

One possibility is to construct a model to predict the values of the classification variable using the features as explanatory variables. For example, if we wish to discriminate between those loans which will be repaid and those that will be difficult to collect, a new variable $y$ can be added to the database which takes the value zero when the loan is repaid and the value of one, otherwise. The problem of classification becomes one of predicting the value of the dummy variable, $y$, in a new element from which we know the vector of variables $\boldsymbol{x}$. If the predicted variable is closer to zero than to one, we classify the element in the first state; otherwise, we place it in the second.

Suppose that the sample to build the classifier consists of elements $(y_i, x_i)$, where $y_i$ is the value of the binary classification variable in this element and $x_i$ is the vector of $p$ features used as explanatory variables. The simplest approach to predict the value of the classification variable in a new element whose variables $x$ are known is to formulate a regression model:

```
y = \beta_0 + \beta_1'x + u, (5.53)
```

and it is easy to see that a classification with this equation estimated by least squares is equivalent to Fisher's LDF. Note that given a fixed value of $x = x_0$ the variable $y$ is binomial with possible values one and zero, probabilities $p_0(x_0) = P(y = 0|x_0)$ and $p_1(x_0) = P(y = 1|x_0)$ that must add to one and expected value $p_1(x_0)$. Taking expectations in (5.53) we obtain

```
p_1(x_0) = \beta_0 + \beta_1'x_0. (5.54)
```

However, we cannot guarantee that the value $\widehat{\beta}_0 + \widehat{\beta}_1'x_0$ will be between zero and one to be interpreted as a probability. To avoid this problem, we transform (5.54) to

```
p_1(x) = F(\beta_0 + \beta_1'x), (5.55)
```

where taking as $F$ any distribution function $p_1(x)$ will be between zero and one. The logistic distribution function is often selected because then

```
p_1(x) = \frac{e^{\beta_0 + \beta_1'x}}{1 + e^{\beta_0 + \beta_1'x}}. (5.56)
```

And \( p_1(\mathbf{x}_0) = 1/(1 + e^{\beta_0 + \beta'_1 \mathbf{x}_0}). \) We can estimate a linear equation by the *Logit* variable, \( g_i \) defined by:

\( g_i = \log \frac{p_1(\mathbf{x}_i)}{p_0(\mathbf{x}_i)} = \beta_0 + \beta'_1 \mathbf{x}_i \) (5.57)

that represents the difference between the probabilities of belonging to both populations in a log scale. It is easy to see that if the features follow a normal distribution, they follow the logistic model but, in this case, estimating this model is less efficient than estimating the Fisher LDF. The logistic model defined by probabilities (5.57) can be estimated by ML; see Hosmer and Lemeshow (1989). Logistic models are specific cases of the generalized linear models; see McCullagh (2018).

The model is easily extended for G classes, taking one class as a reference, for instance the last one, and assuming that the probabilities of each class are given, generalizing (5.57),

\( P_g(\mathbf{x}) = \frac{e^{\beta_{0g} + \beta'_{1g} \mathbf{x}}}{1 + \sum_{j=1}^{G-1} e^{\beta_{0j} + \beta'_{1j} \mathbf{x}}}, \quad g = 1, \dots, (G-1). \) (5.58)

These probabilities imply \( G-1 \) logit models as (5.57), where now \( g_i \) is the log ratio of the probabilities of the ith class divided by the probability of the reference class. Thus, the multinomial model defined by (5.58) has \( (G-1)(p+1) \) parameters, the coefficients of the explanatory variables, and can be estimated by ML. Once the parameters that define the probabilities (5.58) are estimated new data is classified in the most likely class. With many variables and classes it is recommended, as in regression with many correlated variables, to use a shrinkage estimate, the Lasso method, discussed in Chapter 7, which is a good alternative. See McLachlan (2004) for the ML estimation of the logistic model and references about its applications.

We have 200 time series of individuals with T = 4096 observations of EEG. The first 100 series, type A, correspond to healthy volunteers whereas the second 100 series, type E, consist of EEG recordings during seizure activity of patients.
