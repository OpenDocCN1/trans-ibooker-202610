To introduce the basic properties of Lasso estimator, consider the linear model

$$y_i = \sum_{j=1}^k \beta_j x_{i,j} + \epsilon_i, \quad i = 1, \dots, n,$$ (7.6)

where the design matrix $X$ is fixed and the error vector $\epsilon = (\epsilon_1, \dots, \epsilon_n)' \sim N(0, \sigma_e^2 \mathbf{I})$. Assume that the linear model in Eq. (7.6) is the true model and denote the true parameter vector by $\hat{\beta}^0$. If $n > k$, $X$ is full rank and the LS estimator $\hat{\beta} = (X'X)^{-1}(X'Y)$ enjoys various nice properties. Furthermore,

$$\|X(\hat{\beta} - \beta^0)\|_2^2/\sigma_e^2 \sim \chi_k^2,$$

where $\chi_k^2$ denotes the chi-square distribution with $k$ degrees of freedom. Therefore,

$$E\|X(\hat{\beta} - \beta^0)\|_2^2/n = \frac{\sigma_e^2}{n}k.$$

This means that, after re-parameterization so that the columns of $X$ are orthogonal, each parameter $\beta_j^0$ is estimated with squared accuracy $\sigma_e^2/n, j = 1, \dots, k$.

Turn to the case of $k > n$. Here certain restriction is needed. It can be shown (Bühlmann and van de Geer, 2011) that for the Lasso estimate $\hat{\beta}$ we have

$$\frac{\|X(\hat{\beta} - \beta^0)\|_2^2}{n} \le C \|\beta^0\|_1 \sqrt{\log k/n},$$

so that if $\|\beta^0\|_1$ has a smaller number of non-zero coefficients than $\sqrt{n/\log k}$, say $\|\beta^0\|_1 = o(\sqrt{n/\log k})$, the Lasso estimator is consistent when both $k$ and $n$ go to infinity. Let

$$S_0 = \{j | \beta_j^0 \neq 0\}$$

be the set of indexes with non-zero true coefficients and $s_0 = |S_0|$ be the number of non-zero coefficients of $\beta^0$. In the literature, $s_0$ is the *sparsity index* of $\beta^0$ and $S_0$ can be regarded as the *active set* of the linear model (7.6). If $S_0$ were known, then we can simply select those columns of $X$ associated with non-zero parameters to perform the analysis. But $S_0$ is unknown in practice. Under regularized estimation with a properly chosen penalty parameter $\lambda$ (of order $\sigma_e \sqrt{\log(k)n}$), we have the *oracle inequality*, see Candes (2006) for an illustration of this concept, the Lasso estimator satisfying

$$\frac{\|X(\hat{\beta} - \beta^0)\|_2^2}{n} \le c \frac{\sigma_e^2 \log(k)}{n} s_0,$$ (7.7)

with a large probability, where the constant $c$ depends on $k$ or $n$ through the Gram matrix $\hat{\Sigma} = X'X/n$. Compared with the case of $k < n$, we have added the factors $\log(k)$ to the inequality.

Next, consider the linear model of Eq. (7.6). By the definition of Lasso estimator, we have

$$\|Y - X\hat{\beta}\|_2^2/n + \lambda \|\hat{\beta}\|_1 \le \|Y - X\beta^0\|_2^2/n + \lambda \|\beta^0\|_1.$$

Consequently, by rewriting $Y - X\hat{\beta} = (Y - X\beta^0) - X(\hat{\beta} - \beta^0)$, we have the following basic inequality

$$\|X(\hat{\beta} - \beta^0)\|_2^2/n + \lambda \|\hat{\beta}\|_1 \le 2\epsilon' X(\hat{\beta} - \beta^0)/n + \lambda \|\beta^0\|_1.$$ (7.8)
