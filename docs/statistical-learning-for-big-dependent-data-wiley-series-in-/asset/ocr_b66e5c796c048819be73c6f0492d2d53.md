This is the method we use in this book. Once a reader is comfortable with the package, more sophisticated NN models can be built using the other two methods. The package contains many different types of network layer, including layer_dense, which is a densely connected layer of the traditional NN, layer_dropout, which governs randomly dropping of some input nodes, layer_lstm, which is a LSTM layer, among many others. Readers are recommended to experiment with it to learn more about DL in R.
