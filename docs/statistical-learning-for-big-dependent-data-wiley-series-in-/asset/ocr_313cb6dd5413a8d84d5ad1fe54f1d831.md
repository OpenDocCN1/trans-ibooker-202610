In order to apply the EM algorithm we transform the problem by introducing a set of unobserved or missing vector variables ($s_1, \dots, s_k$), where $s_i$ is a $G$-dimensional vector of multinomial variables with only one component equal to one, that corresponds to the group to which $\tilde{z}_i$ belongs, and all the rest equal zero. For example, if $\tilde{z}_i$ comes from the first model $s_{i1} = 1$ and $s_{i2} = \cdots = s_{iG} = 0$. Then $\sum_{g=1}^G s_{ig} = 1$ and $\sum_{i=1}^k \sum_{g=1}^G s_{ig} = k$. With these new variables, the density function of $\tilde{z}_i$ conditional on $s_i$ can be written

$$f(\tilde{z}_i|s_i) = \prod_{g=1}^G f_g(\tilde{z}_i|\psi_g)^{s_{ig}}. \quad (5.36)$$

Analogously, the probability function of the missing variables $s_i$ will be

$$p(s_i) = \prod_{g=1}^G \pi_g^{s_{ig}}. \quad (5.37)$$

On the other hand, the joint density function of the observed variables $\tilde{z}_i$ and the missing variables $s_i$ is

$$f(\tilde{z}_i, s_i) = f(\tilde{z}_i|s_i)p(s_i),$$

that can be written, by Eqs. (5.36) and (5.37), as

$$f(\tilde{z}_i, s_i) = \prod_{g=1}^G (\pi_g f_g(\tilde{z}_i|\psi_g))^{s_{ig}},$$

and the joint log-likelihood function is

$$L(\beta) = \sum_{i=1}^k \log f(\tilde{z}_i, s_i) = \sum_{i=1}^k \sum_{g=1}^G s_{ig} \log \pi_g + \sum_{i=1}^k \sum_{g=1}^G s_{ig} \log f_g(\tilde{z}_i|\psi_g). \quad (5.38)$$

The EM algorithm begins with an initial estimate $\hat{\beta}^{(0)}$ of the vector of parameters, usually computed with Hierarchical clustering or $k$-means. In step E, we calculate the expectations of the missing values in the complete likelihood (5.38) conditional on the initial parameters and on the observed data. Since the likelihood is linear in $s_{ig}$, this is equivalent to substituting the missing variables by its expectations. The missing variables, $s_{ig}$, are binomial with values 0,1, and

$$E(s_{ig}|\hat{\beta}^{(0)}, Z) = p(s_{ig} = 1|\hat{\beta}^{(0)}, Z) = \hat{\pi}_{ig}^{(0)}$$
