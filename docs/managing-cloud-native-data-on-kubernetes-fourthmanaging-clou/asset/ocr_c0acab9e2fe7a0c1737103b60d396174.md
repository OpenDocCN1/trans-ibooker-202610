Let’s take a look at how the integration works. First, let’s consider how the Cassandra nodes expose metrics. As discussed above in the Cass Operator section, Cassandra exposes management capabilities via JMX, and this includes metrics reporting. The [Metrics Collector for Apache Cassandra](Metrics Collector for Apache Cassandra) (MCAC) is an open source project that exposes metrics so that they can be accessed by Prometheus or other backends that use the Prometheus protocol via HTTP. K8ssandra and Cass Operator use a Cassandra Docker image that includes MCAC as well as the Management API as additional processes that run in the Cassandra container.
