The goal of a cloud native AI/ML stack should be to get the insights produced by AI/ML as close to your users as possible, which means shortening the distance between backend analytic processes and making use of their output in frontend production systems. Data exploration happens using algorithms provided in libraries such as Scikit-Learn, PyTorch, Tensorflow, XGBoost. Python is the most commonly used language with Machine Learning libraries. The systems we discussed in Chapter 9 including as Apache Spark, Dask, and Ray are used to scale up the processing required to use Python libraries to build models. Kubeflow and similar tools allow data engineers to create ML workflows for model generation. The flows output model files to object storage, providing the bridge between the backend processes and front-end production use.

Models are meant to be used, and this is the role of real-time model serving tools such as KServe, Seldon, and BentoML. These tools perform predictions on behalf of applications using existing models from object storage and features provided by a feature store such as Feast.
