# USE NAMESPACES TO HELP ISOLATE RESOURCES

One thing you’ll notice from the output above is that the Helm release has been installed in the default Kubernetes namespace. If you want to install a Helm release in its own namespace in order to work with its resources more effectively, you could run something like the following:

```
helm install mysql bitnami/mysql --namespace mysql --create-namespace
```

This creates a namespace called mysql and installs the mysql release inside of it.

In order to obtain information about the Helm releases you’ve created, use the helm list command, which produces output such as this (formatted for readability):

```
NAME NAMESPACE REVISION UPDATED
mysql default 1 2021-10-21 20:39:19
```

```
STATUS CHART APP VERSION
deployed mysql-8.8.8 8.0.26
```

If you haven’t installed the release in its own namespace, it’s still simple to see the compute resources that Helm has created on your behalf, because they have all been labeled with the name of your release:

```

pod/mysql-secondary-0 1/1 Running 0 3h40m
```
