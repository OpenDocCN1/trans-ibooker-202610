## 使用代码搜索引擎

除了通用搜索引擎，许多编码平台还允许在仓库内搜索，如图 5.2 所示，或通过以下链接在线查找：[https://github.com/corona-warn-app/cwa-app-android/search?q=teletan](https://github.com/corona-warn-app/cwa-app-android/search?q=teletan)

![](assets/context_examination_487104_02.png)

搜索一个术语时，你可以在搜索结果的左侧看到找到了多种类型的结果。让我们逐步了解一下结果的类型以及你可以从中学到什么。我强烈建议你如果可能的话自行浏览这些结果！

**代码**

: 第一类结果是代码。在某些情况下，你可以深入代码本身，并利用前几章的技术从中了解更多关于概念的信息。然而，本章的目标是将你的搜索范围扩大到代码库之外。GitHub 代码搜索的好处在于，如果你点击左侧的“Code”，将只显示代码结果，你可以快速浏览所有 `teletan` 的实例，以帮助了解与其搭配使用的操作。这将允许你像练习 3.6 那样，检查应用于 `teletan` 的不同操作有哪些。例如，你可以看到 `teletan` 可以是有效或无效的，可以被屏蔽，并且从一个测试中，你可以了解到 `teletan` 允许你“获取注册令牌”。

**提交**

: GitHub 搜索提供了除代码之外的稳健来源，你也可以在 IDE 中搜索这些来源。点击左侧的“Commits”将显示所有与搜索词匹配的提交。

这再次让你能够扩展关于该概念内涵的知识；你可以看到 `teletans` 不应在错误报告中可见 (`0ff23e7`)，存在“原始” `teletan` 这种东西 (`1628fe`)，它从 7 个字符扩展到了 10 个字符 (`b31fd1d`)，并且输入可以被验证 (`4dc73f1`)。通过这种方式，甚至无需克隆或复刻项目，你就能轻松获得关于代码库中发生什么的一些见解。

![](assets/context_examination_487104_03.png)

**议题**

: 同样，点击“Issues”会显示所有议题，它们通常与提交相关，但并非总是如此。例如，议题 77 ([https://github.com/corona-warn-app/cwa-app-android/issues/77](https://github.com/corona-warn-app/cwa-app-android/issues/77)) 提到了 `teletan` 并给出了清晰的定义：*“提交阳性 COVID-19 结果是一项安全/隐私敏感任务，涉及扫描二维码或输入 `teleTAN`。此过程中涉及的数据应受到保护。”* 当我自己阅读代码库时，该议题中的描述对理解 `teletan` 最有帮助，且包含了我在代码、注释或文档中找不到的信息！
