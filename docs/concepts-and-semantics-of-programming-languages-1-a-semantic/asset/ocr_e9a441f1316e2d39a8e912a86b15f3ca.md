# Exercise 4.2

The language Lang3 is extended with the construct: repeat c until e where c ∈ Lang3 and e ∈ Exp3. Its informal semantics is: “execute c until e takes the value true”.

+   1) Give the inference rules expressing the big-step semantics of this construct.

+   2) Give the execution tree for the following program c:

```
repeat (z :=↓ z*↓ x ; x :=↓ x – 1) until ↓ x = 0
```

in a state (Env, Mem) = ((z, r_z) ⊕ (x, r_x) ⊕ Env0, Mem0[r_x := 2][r_z := 3]).

+   3) Prove that:

```
repeat c until e ≡ c; if e then skip else repeat c until e
```

+   4) Prove that:

```
while e do c ≡ if e then repeat c until not e else skip
repeat c until e ≡ c; while not e do c
```

Hint. With the notations:

+   c1 : while e do c
+   c2 : if e then repeat c until not e else skip
+   c3 : repeat c until e
+   c4 : c ; while not e do c

prove the following properties and then conclude:

+   (P1) ∀Mem, Mem' ∈ M <Mem, c1> →Env Mem' ⇔ <Mem, c2> →Env Mem'
+   (P2) ∀Mem, Mem' ∈ M <Mem, c2> →Env Mem' ⇔ <Mem, c1> →Env Mem'
+   (P3) ∀Mem, Mem' ∈ M <Mem, c3> →Env Mem' ⇔ <Mem, c4> →Env Mem'
+   (P4) ∀Mem, Mem' ∈ M <Mem, c4> →Env Mem' ⇔ <Mem, c3> →Env Mem'

Proofs of (P1) and (P3) can be obtained by structural induction over an inference tree; implications (P2) and (P4) are very easy to prove using (P1) and (P3).
