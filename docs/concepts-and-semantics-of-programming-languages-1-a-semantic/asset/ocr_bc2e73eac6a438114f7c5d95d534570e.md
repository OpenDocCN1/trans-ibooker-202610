The strict order \(\prec_{\text{Env}}\) associated with \(\preceq_{\text{Env}}\) is thus defined by:

```
Mem1 \(\prec_{\text{Env}}\) Mem2 \(\Leftrightarrow\)
\big(
\big(
  Mem1(Env(x)) \neq Mem2(Env(x))
  or Mem1(Env(y)) \neq Mem2(Env(y))
\big)
and Mem1(Env(x)) \le Mem2(Env(x))
and Mem1(Env(y)) \le Mem2(Env(y))
and \forall z \in \text{X} \\ \{x, y\} Mem1(Env(z)) = Mem2(Env(z))
\big)
```

In the below proof, it is helpful to note that if Mem1 \(\prec_{\text{Env}}\) Mem2, then Mem1(Env(x)) < Mem2(Env(x)) or Mem1(Env(y)) < Mem2(Env(y)). Relation \(\preceq_{\text{Env}}\) clearly defines an order relation (i.e. it is reflexive, anti-symmetric and transitive).

Let us prove that \(\preceq_{\text{Env}}\) is well founded.

Suppose that there exists a strictly decreasing infinite sequence:

+   Mem1 \(\succ_{\text{Env}}\) Mem2 \(\succ_{\text{Env}}\) \(\cdots\)

The memories in \(M_{\text{Env}}\) only associate strictly positive values to variables \(x\) and \(y\) and these values themselves decrease or remain the same. As there is no infinite decreasing sequence of strictly positive integers, there exists some rank \(k\) such that all elements of this infinite sequence of rank greater than \(k\) are equal. Thus, we would have:

```
\forall j \ge k \quad \text{Mem}_k(\text{Env}(x)) = \text{Mem}_j(\text{Env}(x)) \text{ and } \text{Mem}_k(\text{Env}(y)) = \text{Mem}_j(\text{Env}(y))
```

But, by definition, if \(\text{Mem}_k \succ_{\text{Env}} \text{Mem}_{k+1}\), then:

```
\text{Mem}_k(\text{Env}(x)) \neq \text{Mem}_{k+1}(\text{Env}(x)) \text{ or } \text{Mem}_k(\text{Env}(y)) \neq \text{Mem}_{k+1}(\text{Env}(y))
```

This is a contradiction: our hypothesis is false.
