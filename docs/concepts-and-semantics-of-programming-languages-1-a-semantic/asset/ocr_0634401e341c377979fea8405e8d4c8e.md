This semantics is unable to take account of possible interleavings between the executions of c1 and c2. Small-step semantics, on the other hand, allows us to describe the execution of just one part of a program:

```
(S_P^1) <c1, Mem> <-Env-> <c1', Mem'>
-----------------------------
<c1 || c2, Mem> ->Env <c1' || c2, Mem'>
```

```
(S_P^2) <c2, Mem> <-Env-> <c2', Mem'>
-----------------------------
<c1 || c2, Mem> ->Env <c1 || c2', Mem'>
```

```
(S_P^3) <c1, Mem> <-Env-> <skip, Mem'>     (S_P^4) <c2, Mem> <-Env-> <skip, Mem'>
----------------------------------     ----------------------------------
<c1 || c2, Mem> ->Env <c2, Mem'>       <c1 || c2, Mem> ->Env <c1, Mem'>
```

These rules can be used to describe the following three executions of the program c:

```
<c, Mem> <-Env-> <x := 3 ; x := ↓ x * ↓ x, Mem[Env(x) := 2]>
    <-Env-> <skip ; x := ↓ x * ↓ x, Mem[Env(x) := 3]>
    <-Env-> <x := ↓ x * ↓ x, Mem[Env(x) := 3]>
    <-Env-> <skip, Mem[Env(x) := 9]>

<c, Mem> <-Env-> <x := 2 || (skip ; x := ↓ x * ↓ x), Mem[Env(x) := 3]>
    <-Env-> <x := 2 || x := ↓ x * ↓ x, Mem[Env(x) := 3]>
    <-Env-> <x := 2, Mem[Env(x) := 9]>
    <-Env-> <skip, Mem[Env(x) := 2]>

<c, Mem> <-Env-> <x := 2 || (skip ; x := ↓ x * ↓ x), Mem[Env(x) := 3]>
    <-Env-> <x := 2 || x := ↓ x * ↓ x, Mem[Env(x) := 3]>
    <-Env-> <x := ↓ x * ↓ x, Mem[Env(x) := 2]>
    <-Env-> <skip, Mem[Env(x) := 4]>
```
