\(\forall Env \in \mathbf{E} \forall Mem, Mem' \in \mathbf{M} \langle Mem, c_1 \rangle \Rightarrow_{Env} Mem' \Leftrightarrow \langle Mem, c_2 \rangle \Rightarrow_{Env} Mem'\)

### EXAMPLE 4.6. Consider the following two programs:

\(c_1 : c ; (if \ e \ then \ c' else \ c'') \quad c_2 : if \ e \ then \ c; c' else \ c; c''\)

To show that \(c_1 \not\equiv c_2\), it is enough to build a counterexample where \(c\), \(c'\) and \(c''\) are instructions \(x := 0\), \(x := \downarrow x + 1\) and \(x := \downarrow x + 5\), respectively, and where \(e\) is the expression \(1 \le \downarrow x\). Starting from a state \((Env, Mem)\) such that \(Env(x) = r_x \in \mathbf{R}\) and \(Mem(r_x) = 2\), we obtain:

\(\langle Mem, c ; (if \ e \ then \ c' else \ c'') \rangle \Rightarrow_{Env} Mem_1 \text{ with } Mem_1(x) = 5\)

\(\langle Mem, if \ e \ then \ c; c' else \ c; c'' \rangle \Rightarrow_{Env} Mem_2 \text{ with } Mem_2(x) = 1\)

## 4.5.2. Program termination

The existence of an inference tree describing the execution of a program guarantees that this execution is finite. As all inference trees are finite, showing that a program $c$ terminates from a starting state $(\text{Env}, \text{Mem})$ using big-step operational semantics comes down to proving the existence of a memory state $\text{Mem}'$ such that $\langle \text{Mem}, c \rangle \rightarrow_{\text{Env}} \text{Mem}'$.

### EXAMPLE 4.7. Returning to the program fragment used in example 4.1:

while not(↓x = ↓y) do if ↓x ≤↓y then y := ↓y - ↓x else x := ↓x - ↓y

Let us show that the execution of this program terminates when starting from any memory state storing strictly positive integer values at locations $x$ and $y$. Formally, we must prove that:

\(\forall \text{Env} \in \mathbf{E} \forall \text{Mem} \in \mathbf{M}\)
\((\text{Mem}(\text{Env}(x)) \ge 1 \text{ and } \text{Mem}(\text{Env}(y)) \ge 1) \Rightarrow \exists \text{Mem}' \in \mathbf{M} \langle \text{Mem}, c \rangle \rightarrow_{\text{Env}} \text{Mem}'\)

To prove this property, given an environment $\text{Env} \in \mathbf{E}$, we define the set:

\(M_{\text{Env}} = \{ \text{Mem} \mid \text{Mem}(\text{Env}(x)) \ge 1 \text{ and } \text{Mem}(\text{Env}(y)) \ge 1 \} \subseteq \mathbf{M}\)

and we must prove that:

\(\forall \text{Mem} \in M_{\text{Env}} \exists \text{Mem}' \in \mathbf{M} \langle \text{Mem}, c \rangle \rightarrow_{\text{Env}} \text{Mem}'\)

The proof is obtained by well-founded induction. First, we define a relation $\preceq_{\text{Env}}$ over the elements of $M_{\text{Env}}$. Then we show that this relation is a well-founded order relation, that is, there is no strictly decreasing infinite sequence of values according to $\preceq_{\text{Env}}$. Finally, we prove that for any element $\text{Mem} \in M_{\text{Env}}$, under the hypothesis $P_{\text{Env}}(\text{Mem}')$ for all $\text{Mem}' \prec_{\text{Env}} \text{Mem}$, we can get $P_{\text{Env}}(\text{Mem})$.

Since at least one value associated with the two variables $x$ and $y$ decreases for each execution of the loop body, the relation $\preceq_{\text{Env}}$ over $M_{\text{Env}}$ can be defined as follows:

\(\text{Mem}_1 \preceq_{\text{Env}} \text{Mem}_2 \Leftrightarrow \left( \begin{array}{l} \text{Mem}_1(\text{Env}(x)) \le \text{Mem}_2(\text{Env}(x)) \\ \text{and } \text{Mem}_1(\text{Env}(y)) \le \text{Mem}_2(\text{Env}(y)) \\ \text{and } \forall z \in \mathbf{X} \setminus \{x, y\} \text{ Mem}_1(\text{Env}(z)) = \text{Mem}_2(\text{Env}(z)) \end{array} \right)\)

The strict order \(\prec_{\text{Env}}\) associated with \(\preceq_{\text{Env}}\) is thus defined by:

\(\text{Mem}_1 \prec_{\text{Env}} \text{Mem}_2 \Leftrightarrow \big( \big( \text{Mem}_1(\text{Env}(x)) \neq \text{Mem}_2(\text{Env}(x)) \text{ or } \text{Mem}_1(\text{Env}(y)) \neq \text{Mem}_2(\text{Env}(y)) \big) \text{ and } \text{Mem}_1(\text{Env}(x)) \le \text{Mem}_2(\text{Env}(x)) \text{ and } \text{Mem}_1(\text{Env}(y)) \le \text{Mem}_2(\text{Env}(y)) \text{ and } \forall z \in \mathbf{X} \setminus \{x, y\} \text{ Mem}_1(\text{Env}(z)) = \text{Mem}_2(\text{Env}(z)) \big)\)

In the below proof, it is helpful to note that if Mem1 \(\prec_{\text{Env}}\) Mem2, then Mem1(Env(x)) < Mem2(Env(x)) or Mem1(Env(y)) < Mem2(Env(y)). Relation \(\preceq_{\text{Env}}\) clearly defines an order relation (i.e. it is reflexive, anti-symmetric and transitive).

Let us prove that \(\preceq_{\text{Env}}\) is well founded.

Suppose that there exists a strictly decreasing infinite sequence:

- Mem1 \(\succ_{\text{Env}}\) Mem2 \(\succ_{\text{Env}}\) \(\cdots\)

The memories in \(M_{\text{Env}}\) only associate strictly positive values to variables \(x\) and \(y\) and these values themselves decrease or remain the same. As there is no infinite decreasing sequence of strictly positive integers, there exists some rank \(k\) such that all elements of this infinite sequence of rank greater than \(k\) are equal. Thus, we would have:

\(\forall j \ge k \quad \text{Mem}_k(\text{Env}(x)) = \text{Mem}_j(\text{Env}(x)) \text{ and } \text{Mem}_k(\text{Env}(y)) = \text{Mem}_j(\text{Env}(y))\)

But, by definition, if \(\text{Mem}_k \succ_{\text{Env}} \text{Mem}_{k+1}\), then:

\(\text{Mem}_k(\text{Env}(x)) \neq \text{Mem}_{k+1}(\text{Env}(x)) \text{ or } \text{Mem}_k(\text{Env}(y)) \neq \text{Mem}_{k+1}(\text{Env}(y))\)

This is a contradiction: our hypothesis is false.

Now, let us prove \(P_{\text{Env}}(\text{Mem})\) by well-founded induction. Take \(\text{Mem} \in M_{\text{Env}}\). By induction hypothesis, we have \(\forall \text{Mem}' \prec_{\text{Env}} \text{Mem}, P_{\text{Env}}(\text{Mem}')\) and we must prove the property \(P_{\text{Env}}(\text{Mem})\). Let \(\text{Mem}(\text{Env}(x)) = m\) and \(\text{Mem}(\text{Env}(y)) = n\). Two cases are possible:

- 1) if \(m = n\), then we get \(P_{\text{Env}}(\text{Mem})\) since we can construct the following tree:

```
(C_7) [[e]]_Env^Mem = (false, Mem)
      <Mem, c> ->Env Mem
```

- 2) if \(m \neq n\), then there are two possible subcases:

- a) if \(m \le n\), then we can construct the tree \(\nabla_1\) :

```
[[e]]_Env^Mem = (true, Mem)   (C_1) [ [↓y - ↓x]_Env^Mem = (n - m, Mem) ]
-----------------------------------------------------------------------
<Mem, c_1> ->Env Mem[Env(y) := n - m]
(C_4) <Mem, c_w> ->Env Mem[Env(y) := n - m]
```

But, by definition, Mem[Env(y) := n - m] <Env Mem, and by induction hypothesis, we obtain the tree \(\nabla_2\) :

```
::
(Ci) <Mem[Env(y) := n - m], cw> →Env Mem'
```

- b) if \(m > n\), then we can build the tree \(\nabla_1\) :

```
[[e]]_Env^Mem = (false, Mem) (C1) [[↓x - ↓y]]_Env^Mem = (m - n, Mem)
(C5) <Mem, c2> →Env Mem[Env(x) := m - n]
-------------------------------------------
<Mem, cw> →Env Mem[Env(x) := m - n]
```

Once again, we obtain Mem[Env(x) := m - n] <Env Mem, and using the induction hypothesis, we obtain the tree \(\nabla_2\) :

```
::
(Cj) <Mem[Env(x) := m - n], cw> →Env Mem'
```

In all cases, we get the result since we can construct the following tree:

```
[[e]]_Env^Mem = (true, Mem) V1 V2
(C6) -----------------------------------
<Mem, c> →Env Mem'
```

This proof is typically used to show that a program terminates: first, a well-founded order must be built (a point which is not always immediately obvious), then the proof can be done by well-founded induction.

## 4.5.3. Determinism of program execution

To ensure that the same program executed from the same state will always produce the same result, we prove that the execution of instructions is deterministic.

### PROPOSITION 4.1. Determinism of instruction execution:

\(\forall c \in \text{Lang3} \forall \text{Env} \in \text{E} \forall \text{Mem}, \text{Mem}_1, \text{Mem}_2 \in \text{M}\)
\((\langle \text{Mem}, c \rangle \rightarrow_{\text{Env}} \text{Mem}_1 \text{ and } \langle \text{Mem}, c \rangle \rightarrow_{\text{Env}} \text{Mem}_2) \Rightarrow \text{Mem}_1 = \text{Mem}_2\)

We first attempt to prove this proposition by induction over the program structure. For the program while e do c, by induction hypothesis, we may suppose that the property is verified for c. Using the following two trees

```
(V1) (Cj) :: ... (V2) (Cj') :: ...
```

we therefore obtain Mem1 = Mem'1.
