will terminate, as no strictly decreasing infinite sequence exists over the set of natural numbers IN. For example, we can prove the total correctness expressed by the following triple:

```
{ ↓ x ≤ b }while ↓ x < b do x := ↓ x + 1 { ↓ x = b }
```

by considering the variant V = b − ↓ x. The precondition guarantees that V ≥ 0 and V strictly decreases at each iteration of the loop (as ↓ x is strictly increasing).

```
(Aff)
----------------
{ ↓ x + 1 ≤ b and b − ↓ x − 1 < n }
x := ↓ x + 1 { A5 }
          A6
(ConsG)
---------------------------------- (I3)
{ ↓ x ≤ b and ↓ x < b and b − ↓ x = n } x := ↓ x + 1 { ↓ x ≤ b and b − ↓ x < n }
          A4                                      A5
(WT)
{ A1 } while ↓ x < b do x := ↓ x + 1 { ↓ x ≤ b and not ↓ x < b }
                                   A3
(ConsD)
---------------------------------- (I1)
{ ↓ x ≤ b } while ↓ x < b do x := ↓ x + 1 { ↓ x = b }
      A1                           A2
```

The choice of rules (ConsG) and (ConsD) is correct, as I1 and I3 are implications A3 ⇒ A2 and A4 ⇒ A6, which are easy to verify. Rule (WT) is also used correctly, as I2 corresponds to the implication ↓ x ≤ b ⇒ b − ↓ x ≥ 0.
