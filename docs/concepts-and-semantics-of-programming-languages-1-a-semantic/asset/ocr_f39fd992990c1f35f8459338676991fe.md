The notion of substitution is used to define instances of a type scheme.

**DEFINITION 5.6.–** _Instance_: $\tau'$ is said to be an instance of the type scheme $\sigma = \forall \alpha_1 \dots \alpha_k . \tau$ and we note it $\sigma \le \tau'$ if there exists a substitution $\theta$ such that $\text{dom}(\theta) = \{\alpha_1, \dots, \alpha_k\}$ and $\tau' = \theta(\tau)$. In this case, the type $\tau'$ is said to be compatible with $\tau$.

# ## 5.3.3. Typing rules and typing trees

We can now give the rules used to ensure that an expression is well-typed. These rules are shown in Box 5.1, with the notation already used for the description of the big-step operational semantics of **Exp**<sub>2</sub> in section 3.3. We give a formal definition of the relation \(\text{Env} \vdash e : \tau\), which means that in a typing environment Env, the expression \(e\) is of type \(\tau\).

\((T_\text{true}) \frac{}{\text{Env} \vdash true : \text{bool}} \quad (T_\text{false}) \frac{}{\text{Env} \vdash false : \text{bool}} \quad (T_\text{int}) \frac{}{\text{Env} \vdash i : \text{int}}\)
\((T_\text{var}) \frac{\text{Env}(x) \le \tau}{\text{Env} \vdash x : \tau} \quad (T_\text{unop}) \frac{\text{Env} \vdash \text{op} : \tau_1 \to \tau_2 \quad \text{Env} \vdash e : \tau_1}{\text{Env} \vdash \text{op } e : \tau_2}\)
\((T_\text{binop}) \frac{\text{Env} \vdash \text{op} : \tau_1 \to \tau_2 \to \tau_3 \quad \text{Env} \vdash e_1 : \tau_1 \quad \text{Env} \vdash e_2 : \tau_2}{\text{Env} \vdash e_1 \text{ op } e_2 : \tau_3}\)

\((T_\text{fun}) \frac{(x, \forall \emptyset . \tau_1) \oplus \text{Env} \vdash e : \tau_2}{\text{Env} \vdash \text{fun } x \mapsto e : \tau_1 \to \tau_2}\)
\((T_\text{let}) \frac{\text{Env} \vdash e_1 : \tau_1 \quad \sigma = \text{Gen}(\tau_1, \text{Env}) \quad (x, \sigma) \oplus \text{Env} \vdash e_2 : \tau_2}{\text{Env} \vdash \text{let } x = e_1 \text{ in } e_2 : \tau_1 \to \tau_2}\)
\((T_\text{rec}) \frac{(f, \forall \emptyset . \tau_1 \to \tau_2) \oplus (x, \forall \emptyset . \tau_1) \oplus \text{Env} \vdash e : \tau_2}{\text{Env} \vdash \text{rec } f \, x = e : \tau_1 \to \tau_2}\)
\((T_\text{app}) \frac{\text{Env} \vdash e_1 : \tau_2 \to \tau_1 \quad \text{Env} \vdash e_2 : \tau_2}{\text{Env} \vdash (e_1 \, e_2) : \tau_1}\)
