
## PROPOSITION 4.5.- Take two partial functions \(f_b : \mathbf{M} \rightarrowtail \mathbf{IB}\) and \(f_0 : \mathbf{M} \rightarrowtail \mathbf{M}\). Function \(F : f \mapsto \mathbf{cond}(f_b, f, f_0)\) is continuous.

PROOF.- First, let us prove that the function \(F\) is monotonic.

Let \(f_1\) and \(f_2\) be two functions in \([\mathbf{M} \rightarrowtail \mathbf{M}]\) such that \(f_1 \sqsubseteq f_2\), and let us show that \(F(f_1) \sqsubseteq F(f_2)\). Assume \(\mathsf{Mem} \in \mathbf{M}\) such that \((F(f_1))(\mathsf{Mem}) \neq \mathsf{undef}\); we show that \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\).

If \(f_b(\mathsf{Mem}) = 1\), then:

```
\((F(f_1))(\mathsf{Mem}) = f_1(\mathsf{Mem})\) and \((F(f_2))(\mathsf{Mem}) = f_2(\mathsf{Mem})\)
```

Since \(f_1 \sqsubseteq f_2\) and \(f_1(\mathsf{Mem}) = (F(f_1))(\mathsf{Mem}) \neq \mathsf{undef}\), we have \(f_1(\mathsf{Mem}) = f_2(\mathsf{Mem})\) and therefore \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\), establishing that \(F(f_1) \sqsubseteq F(f_2)\). If \(f_b(\mathsf{Mem}) = 0\), then \((F(f_1))(\mathsf{Mem}) = f_0(\mathsf{Mem})\) and \((F(f_2))(\mathsf{Mem}) = f_0(\mathsf{Mem})\), hence \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\), which allows us to establish that \(F(f_1) \sqsubseteq F(f_2)\). If \(f_b(\mathsf{Mem}) = \mathsf{undef}\), then \((F(f_1))(\mathsf{Mem}) = \mathsf{undef}\), which is contradictory.

Let us show that for any non-empty chain \(Y\) in \(([\mathbf{M} \rightarrowtail \mathbf{M}], \sqsubseteq)\), \(\sqcup F(Y) = F(\sqcup Y)\).

Since we know that \(F\) is monotonic, by lemma 4.5, we get \(\sqcup F(Y) \sqsubseteq F(\sqcup Y)\). It remains to prove that \(F(\sqcup Y) \sqsubseteq \sqcup F(Y)\), i.e. \(F(\sqcup Y) \sqsubseteq \sqcup \{F(f) \mid f \in Y\}\). Take \(\mathsf{Mem}_1 \in \mathbf{M}\). Let us prove that if \((F(\sqcup Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2 \neq \mathsf{undef}\), then \((\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\). If \(f_b(\mathsf{Mem}_1) = 1\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = (\sqcup Y)(\mathsf{Mem}_1) = \mathsf{Mem}_2\) and, by proposition 4.4, there exists \(f \in Y\) such that \(f(\mathsf{Mem}_1) = \mathsf{Mem}_2\). By definition, for all \(f \in Y\), we have \(F(f) \sqsubseteq \sqcup F(Y)\) and we therefore obtain \((\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\). Otherwise, if \(f_b(\mathsf{Mem}_1) = 0\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = f_0(\mathsf{Mem}_1) = \mathsf{Mem}_2\) and for some function \(f \in Y\):

```
\((F(f))(\mathsf{Mem}_1) = f_0(\mathsf{Mem}_1) = \mathsf{Mem}_2 \neq \mathsf{undef}\)
```

Once again, by definition, for all \(f \in Y\), we have \(F(f) \sqsubseteq \sqcup F(Y)\) and we thus obtain \((\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\). Finally, if \(f_b(\mathsf{Mem}_1) = \mathsf{undef}\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = \mathsf{undef}\), which is contradictory.

## PROPOSITION 4.6.- Take \(f_0 : \mathbf{M} \rightarrowtail \mathbf{M}\). The function \(F : f \mapsto f \circ f_0\) is continuous.

PROOF.- First, let us prove that \(F\) is monotonic. Let \(f_1\) and \(f_2\) be two functions of \([\mathbf{M} \rightarrowtail \mathbf{M}]\) such that \(f_1 \sqsubseteq f_2\), and let us prove that \(F(f_1) \sqsubseteq F(f_2)\). Take \(\mathsf{Mem} \in \mathbf{M}\) such that \((F(f_1))(\mathsf{Mem}) \neq \mathsf{undef}\): we can show that \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\). By definition, \((F(f_1))(\mathsf{Mem}) = f_1(f_0(\mathsf{Mem})) \neq \mathsf{undef}\), hence \(f_0(\mathsf{Mem}) \neq \mathsf{undef}\) and since \(f_1 \sqsubseteq f_2\), we obtain \(f_1(f_0(\mathsf{Mem})) = f_2(f_0(\mathsf{Mem}))\), allowing us to conclude. Now, we must prove that \(F\) is continuous:

\((F(\sqcup Y))(\mathsf{Mem}_1) = (\sqcup Y)(f_0(\mathsf{Mem}_1)) = \mathsf{Mem}_2\)
\(\Leftrightarrow \exists f \in Y\ f(f_0(\mathsf{Mem}_1)) = \mathsf{Mem}_2\) (see proposition 4.4)
\(\Leftrightarrow \exists f \in Y\ (F(f))(\mathsf{Mem}_1) = \mathsf{Mem}_2\)
\(\Leftrightarrow (\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\) (see proposition 4.4)

## PROPOSITION 4.7.-- The functional \(F : f \mapsto \text{cond}([\![e]\!]_{\text{Env}}, f \circ [\![c]\!]_{\text{Env}}, id)\) is a continuous function.

PROOF.-- Taking \(F_1 : f \mapsto \text{cond}([\![e]\!]_{\text{Env}}, f, id)\) and \(F_2 : f \mapsto f \circ [\![c]\!]_{\text{Env}}\), we have \(F(f) = F_1(F_2(f)) = F_1(f \circ [\![c]\!]_{\text{Env}}) = \text{cond}([\![e]\!]_{\text{Env}}, f \circ [\![c]\!]_{\text{Env}}, id)\) hence \(F = F_1 \circ F_2\). According to proposition 4.5, function \(F_1\) is continuous, and according to proposition 4.6, function \(F_2\) is continuous. Lemma 4.6 thus gives the conclusion.

## 4.7.1.2.4. Least fixpoint of a continuous function over a ccpo

Now let us show how the least fixpoint of the functional \(F\) can be computed incrementally. This construction is based on the theorem as follows.

## THEOREM 4.2.-- Let \((D, \sqsubseteq)\) be a ccpo and \(f : D \to D\) a continuous function:

\[
\text{lfp}(f) = \sqcup(\{f^n(\bot) \mid n \ge 0\})
\]

PROOF.-- First, let us prove the existence of \(\sqcup(\{f^n(\bot) \mid n \ge 0\})\). It is easily done by a proof by induction over \(n\):

\[
\forall n \in \mathbb{N}\ \forall m \in \mathbb{N}\ m \ge n \Rightarrow f^n(\bot) \sqsubseteq f^m(\bot)
\]

(since, according to lemma 4.2, \(\bot\) is the least element of \(D\) and \(f\) is continuous, and thus monotonic). \(\{f^n(\bot) \mid n \ge 0\}\) is therefore a chain, and since \((D, \sqsubseteq)\) is a ccpo, \(\sqcup(\{f^n(\bot) \mid n \ge 0\})\) exists. Now, we can show that \(\sqcup(\{f^n(\bot) \mid n \ge 0\})\) is a fixpoint of \(f\):

\[
f(\sqcup(\{f^n(\bot) \mid n \ge 0\})) = \sqcup(f(\{f^n(\bot) \mid n \ge 0\})) \quad \text{as } f \text{ is continuous}
\]
\[
= \sqcup(\{f^n(\bot) \mid n \ge 1\}) = \sqcup(\{f^n(\bot) \mid n \ge 1\} \cup \{\bot\}) = \sqcup(\{f^n(\bot) \mid n \ge 0\})
\]

It remains to prove that \(\sqcup(\{f^n(\bot) \mid n \ge 0\})\) is the least fixpoint of \(f\). Let \(d \in D\) be a fixpoint of \(f\). According to lemma 4.2, \(\bot \sqsubseteq d\) and thus for any natural number \(n\), we have \(f^n(\bot) \sqsubseteq f^n(d)\) (which can be proved by induction over \(n\) since \(f\) is continuous and thus monotonic). Furthermore, we get \(\forall n \in \mathbb{N}\ f^n(d) = d\), by induction over \(n\) since \(d\) is a fixpoint of \(f\). \(d\) is therefore an upper bound of \(\{f^n(\bot) \mid n \ge 0\}\) and since \(\sqcup(\{f^n(\bot) \mid n \ge 0\})\) is the least upper bound of \(\{f^n(\bot) \mid n \ge 0\}\), we obtain \(\sqcup(\{f^n(\bot) \mid n \ge 0\}) \sqsubseteq d\).

## 4.7.1.2.5. Example

Consider the following program, which computes ↓y = ↓x! where ↓x is a strictly positive integer:

```
y := 1; while not(↓x = 1) do (y := ↓y × ↓x; x := ↓x - 1)
```

Let us compute the result of executing this program in a state (Env₀, Mem₀) such that Mem₀(Env₀(x)) = 5 and Env₀(y) ∈ R. In what follows, we suppose that Env(x) and Env(y) are elements of R noted r_x and r_y respectively. By definition, the functions associated with each of the components of this program are as follows:

```
[[c1]]_Env : Mem ↦ Mem[ry := 1]

[[e]]_Env : Mem ↦ {
    1 if Mem(r_x) ≠ 1
    0 if Mem(r_x) = 1
}

[[c3]]_Env = [[c5]]_Env ∘ [[c4]]_Env
[[c3]]_Env : Mem ↦ [[c5]]_Env(Mem[ry := Mem(ry) × Mem(rx)])
           = Mem[ry := Mem(ry) × Mem(rx)][rx := Mem(rx) - 1]

[[c2]]_Env = lfp(F) where F : f ↦ cond([[e]]_Env, f ∘ [[c3]]_Env, id)
F(f) : Mem ↦ {
    f([[c3]]_Env(Mem)) if Mem(r_x) ≠ 1
    Mem              if Mem(r_x) = 1
}
```

The function [[c3]]_Env describes the state obtained after executing the body of the loop. When the body of the loop is executed twice, function [[c3]]²_Env = [[c3]; c3]]_Env = [[c3]]_Env ∘ [[c3]]_Env is defined by:

```
Mem ↦ (
    Mem [
        ry := Mem(ry) × Mem(rx)
        rx := Mem(rx) - 1
        ry := Mem(ry) × Mem(rx) × (Mem(rx) - 1)
        rx := Mem(rx) - 1 - 1
    ]
)
= (
    Mem [
        ry := Mem(ry) × Mem(rx) × (Mem(rx) - 1)
        rx := Mem(rx) - 2
    ]
)
```

More generally, when the body of the loop is executed \( n \) times, the function \(\llbracket c_3 \rrbracket^n_{\text{Env}}\) is defined by:

```
\(\text{Mem} \mapsto \left( \text{Mem} \begin{bmatrix} r_y := \text{Mem}(r_y) \times \text{Mem}(r_x) \times (\text{Mem}(r_x) - 1) \\ \vdots \\ r_x := \text{Mem}(r_x) - n \end{bmatrix} \right)\)
```

Thus, in a state such that \(\text{Mem}(r_x) = p\), we have:

```
\(\llbracket c_3 \rrbracket^{p-1}_{\text{Env}}(\text{Mem}) = \left( \text{Mem} \begin{bmatrix} r_y := \text{Mem}(r_y) \times p \times (p - 1) \times \dots \times 2 \\ r_x := \text{Mem}(r_x) - 1 \end{bmatrix} \right)\)
\(= \text{Mem}[r_y := \text{Mem}(r_y) \times p!][r_x := \text{Mem}(r_x) - 1]\)
```

Using theorem 4.2, we can compute \(\text{lfp}(F) = \sqcup \{ F^n(\perp) \mid n \ge 0 \}\) from \(F^0(\perp) = \perp : \text{Mem} \mapsto \text{undef}\). By definition, we have:

```
\(F^1(\perp) = F(\perp) : \text{Mem} \mapsto \begin{cases} \text{undef} & \text{if } \text{Mem}(r_x) \neq 1 \\ \text{Mem} & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```

Similarly:

```
\(F^2(\perp) = F(F^1(\perp)) : \text{Mem} \mapsto \begin{cases} F^1(\perp)(\llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem})) & \text{if } \text{Mem}(r_x) \neq 1 \\ \text{Mem} & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```

and since \(\llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem})(r_x) = \text{Mem}(r_x) - 1\), we have:

```
\(F^2(\perp) : \text{Mem} \mapsto \begin{cases} \text{undef} & \text{if } \text{Mem}(r_x) \neq 1 \text{ and } \text{Mem}(r_x) \neq 2 \\ \llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = 2 \\ \text{Mem} & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```

With a further iteration, we obtain:

```
\(F^3(\perp) = F(F^2(\perp)) : \text{Mem} \mapsto \begin{cases} F^2(\perp)(\llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem})) & \text{if } \text{Mem}(r_x) \neq 1 \\ \text{Mem} & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```

hence:

```
\(F^3(\perp) : \text{Mem} \mapsto \begin{cases} \text{undef} & \text{if } \text{Mem}(r_x) \neq 1 \text{ and } \text{Mem}(r_x) \neq 2 \text{ and } \text{Mem}(r_x) \neq 3 \\ \llbracket c_3 \rrbracket^2_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = 3 \\ \llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = 2 \\ \text{Mem} & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```

By induction, we obtain:

```
\(F^n(\perp) : \text{Mem} \mapsto \begin{cases} \text{undef} & \text{if } \text{Mem}(r_x) \neq 1 \text{ and } \text{Mem}(r_x) \neq 2 \text{ and } \dots \text{ and } \text{Mem}(r_x) \neq n \\ \llbracket c_3 \rrbracket^{n-1}_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = n \\ \llbracket c_3 \rrbracket^{n-2}_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = n - 1 \\ \dots \\ \llbracket c_3 \rrbracket_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = 2 \\ \llbracket c_3 \rrbracket^0_{\text{Env}}(\text{Mem}) & \text{if } \text{Mem}(r_x) = 1 \end{cases}\)
```
