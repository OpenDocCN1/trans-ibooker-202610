# EXAMPLE 7.8.-

```
C++
#include <stdio.h>

int times2 (int v) {
return (2 * v);
}

int main () {
int i = 46 ;
int& j = 10 ;
int& k = times2 (i) ;
return 0 ;
}
```

Attempts to compile this program using the g++ compiler will result in an error regarding the initializations of j and k:

```
$ g++ refs2.cpp

2 errors generated.
```

Using an array to represent a memory zone, it is possible to create a reference to a cell, as shown in example 7.9.

# EXAMPLE 7.9.-

```
C++
#include <stdio.h>

int main () {
int t[2] = { 12, 21 } ;
int& i = t[1] ;
i = i + 1 ;
printf ("i = %d t[1] = %d\n", i, t[1]) ;
return 0 ;
}
```

The variable i is a reference to an integer representing the second cell in the array t. As t denotes a zone in the memory, the second cell will also denote a zone in the memory. Running this program will return the expected result i = 22 t[1] = 22.

References can also be used as function parameters in order to “silently” pass a parameter by address, as shown in example 7.10.
