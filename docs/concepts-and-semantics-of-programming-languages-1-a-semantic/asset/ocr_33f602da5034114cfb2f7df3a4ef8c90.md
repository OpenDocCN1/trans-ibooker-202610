# 5.6.3. Typing polymorphic definitions

In a language that accepts polymorphism, the introduction of references creates an additional difficulty. Consider the definition let x = $\uparrow$ []; where [] is the value of an empty list. Suppose that the type of this list is polymorphic, and thus of the form $\alpha$ list, where $\alpha$ is the type of the elements. If we assign the type scheme $\forall \alpha$. ($\alpha$ list) ref to x, then the rules of polymorphism can be used, for example, in:

```
x := [1] ;
x := [true] ;
1 + head (\(\downarrow\) x) ;
```
