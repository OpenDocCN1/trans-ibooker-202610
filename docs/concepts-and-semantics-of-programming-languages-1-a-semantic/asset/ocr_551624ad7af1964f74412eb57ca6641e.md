A substitution is represented by an association list, i.e. a list of pairs in which the first component represents the name of the type variable and the second component the type to replace the variable. If the association list contains only one element, then the substitution is said to be elementary.

def apply_one (transf, ty) :
if isinstance (ty, T_int) or isinstance (ty, T_bool) : return ty
elif isinstance (ty, T_fun) :
return T_fun (apply_one (transf, ty.t1), apply_one (transf, ty.t2))

(fst_transf, snd_transf) = transf
if fst_transf == ty.vname : return snd_transf
else : return ty
else : raise ValueError
