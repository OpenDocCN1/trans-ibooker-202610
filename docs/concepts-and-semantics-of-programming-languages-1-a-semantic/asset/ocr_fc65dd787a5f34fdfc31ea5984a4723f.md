+   c) For each step $\langle e_i, \text{Env} \rangle \leftrightarrow \langle e_{i+1}, \text{Env} \rangle$, we have:

$(\mathcal{N}_V(e_{i+1}), \mathcal{N}_O(e_{i+1})) \prec (\mathcal{N}_V(e_i), \mathcal{N}_O(e_i))$

and since $\preceq$ is a well-founded order relation over $\mathbb{N} \times \mathbb{N}$, there is no strictly decreasing infinite sequence:

$(n_0, n'_0) \succ (n_1, n'_1) \succ (n_2, n'_2) \succ \cdots$

so we can conclude that any transition sequence is of finite length.

+   d) This property is no longer verified if we add rule $AS_{11}$ since:

+   3) We prove that there is a transition sequence $\langle e, \text{Env} \rangle \stackrel{*}{\leftrightarrow} n$ by induction over the evaluation tree for $\text{Env} \vdash e \leadsto n$.

+   - If the evaluation tree for $\text{Env} \vdash e \leadsto n$ has been obtained using rule $F_1$, then $e = n \in \mathbb{Z}$ and we clearly have $\langle n, \text{Env} \rangle \stackrel{*}{\leftrightarrow} n$.

+   - If the evaluation tree for $\text{Env} \vdash e \leadsto n$ has been obtained using rule $F_{11}$, then $e = x \in \mathbf{X}$ and $n = \text{Env}(x) \in \mathbb{Z}$. Rule $AS_1$ can then be used to construct a tree for $\langle x, \text{Env} \rangle \leftrightarrow \langle \text{Env}(x), \text{Env} \rangle$ and we can establish that $\langle x, \text{Env} \rangle \stackrel{*}{\leftrightarrow} \text{Env}(x)$.

+   - If the evaluation tree for $\text{Env} \vdash e \leadsto n$ has been obtained using rule $F_4$ and the binary operator $+$:

```
  ⋮ (Fi)   Env ⊢ e₁ ↝ n₁       ⋮ (Fj)   Env ⊢ e₂ ↝ n₂
------------------------------------------------------
        (F4) Env ⊢ e₁ + e₂ ↝ n₁ + n₂
```

then, by induction hypothesis, we have:

$\langle e_1, \text{Env} \rangle \stackrel{*}{\leftrightarrow} \text{Env}(n_1) \text{ and } \langle e_2, \text{Env} \rangle \stackrel{*}{\leftrightarrow} \text{Env}(n_2)$

and there exist two transition sequences:

$\langle e_1, \text{Env} \rangle = \langle e_1^0, \text{Env} \rangle \leftrightarrow \langle e_1^1, \text{Env} \rangle \leftrightarrow \langle e_1^2, \text{Env} \rangle \leftrightarrow \cdots \\ \cdots \leftrightarrow \langle e_1^{k_1}, \text{Env} \rangle = \langle n_1, \text{Env} \rangle$ [A.1]
