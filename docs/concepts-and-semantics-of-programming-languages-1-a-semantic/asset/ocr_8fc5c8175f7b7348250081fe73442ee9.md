transition \(\langle \textbf{while}~e~\textbf{do}~c, Mem_1 \rangle \mapsto_{Env} \langle \textbf{skip}, Mem_2 \rangle\) and since \(\langle \textbf{skip}, Mem_2 \rangle\) is a terminal configuration, we obtain \(\langle \textbf{while}~e~\textbf{do}~c_0, Mem_1 \rangle \mapsto^*_{Env} Mem_2\).

(<=) Since, by hypothesis \(\langle c, Mem_1 \rangle \mapsto^*_{Env} Mem_2\), there exists a sequence of transitions of length \(k\):

\(\langle c, Mem_1 \rangle \mapsto_{Env} \langle c'_1, Mem'_1 \rangle \mapsto_{Env} \cdots \mapsto_{Env} \langle c'_k, Mem'_k \rangle = \langle \textbf{skip}, Mem_2 \rangle\)

Proof is obtained by well-founded induction over \(k\) then by case over the first transition in this sequence. If \(k = 0\), then the starting configuration is terminal, \(Mem_1 = Mem_2\) and rule \(C_2\) allows us to conclude. Otherwise, there are several possible cases.

+   - If the first transition is \(\langle x := e, Mem_1 \rangle \mapsto_{Env} \langle \textbf{skip}, Mem[r := v] \rangle\) (obtained using rule \(S_1\)), then \(k = 1\) since \(\langle \textbf{skip}, Mem[r := v] \rangle\) is a terminal configuration, and using rule \(C_1\) we get:

\(\langle Mem_1, x := e \rangle \mapsto_{Env} Mem[r := v]\)

+   - If the first transition is obtained using rule \(S_2\):

\(\langle c_1 ; c_2, Mem_1 \rangle \mapsto_{Env} \underbrace{\langle c''_1 ; c_2, Mem'_1 \rangle}_{c'_1} \mapsto_{Env} \cdots \mapsto_{Env} \underbrace{\langle c'_k, Mem'_k \rangle}_{= (\textbf{skip}, Mem_2)}\)

with \(\langle c_1, Mem_1 \rangle \mapsto_{Env} \langle c''_1, Mem'_1 \rangle\), then, by lemma 4.1, there exists two integers \(k_1\) and \(k_2\) such that \(\langle c_1, Mem_1 \rangle \mapsto^{k_1}_{Env} Mem'\) and \(\langle c_2, Mem' \rangle \mapsto^{k_2}_{Env} Mem_2\) with \(k_1 + k_2 + 1 = k\). Hence \(k_1 < k\) and \(k_2 < k\) and, by induction hypothesis, we get \(\langle Mem_1, c_1 \rangle \mapsto_{Env} Mem'\) and \(\langle Mem', c_2 \rangle \mapsto_{Env} Mem_2\) and we can conclude by building the tree:

\(\begin{array}{c} (C_i) \frac{\vdots}{\langle Mem_1, c_1 \rangle \mapsto_{Env} Mem'} \qquad \qquad (C_j) \frac{\vdots}{\langle Mem', c_2 \rangle \mapsto_{Env} Mem_2} \\ (C_3) \frac{ }{\langle Mem_1, c_1 ; c_2 \rangle \mapsto_{Env} Mem_2} \end{array}\)

+   - If the first transition is obtained using rule \(S_3\):

\(\langle \textbf{skip} ; c'_1, Mem_1 \rangle \mapsto_{Env} \langle c'_1, Mem'_1 \rangle \mapsto_{Env} \cdots \mapsto_{Env} \underbrace{\langle c'_k, Mem'_k \rangle}_{= (\textbf{skip}, Mem_2)}\)

with \(Mem_1 = Mem'_1\), then we get \(\langle Mem_1, c'_1 \rangle \mapsto_{Env} Mem_2\) by induction hypothesis and we can conclude by constructing the tree:

\(\begin{array}{c} (C_2) \frac{\vdots}{\langle Mem_1, \textbf{skip} \rangle \mapsto_{Env} Mem_1} \qquad \qquad (C_i) \frac{\vdots}{\langle Mem_1, c'_1 \rangle \mapsto_{Env} Mem_2} \\ (C_3) \frac{ }{\langle Mem_1, \textbf{skip} ; c'_1 \rangle \mapsto_{Env} Mem_2} \end{array}\)
