```

1) In what follows, we assume that Env(a) and Env(b) are elements in R,
denoted as ra and rb, respectively. Let vx and vy be the values Env(x) and Env(y).
By definition, the functions associated with each of the components of this program
are as follows:

```
[[c1]]Env : Mem ↦ Mem[ra := 0]

The function [[c3; c4]]Env describes the state obtained after executing one
iteration of the loop. When the body of the loop is executed twice, the function
[[c3; c4]]2Env = [[c3; c4]]Env ◦ [[c3; c4]]Env is defined by:

```
Mem ↦ ( Mem [rb := Mem(rb) − vy][ra := Mem(ra) + 1]
       [rb := Mem(rb) − vy − vy][ra := Mem(ra) + 1 + 1] )
   = Mem[rb := Mem(rb) − 2vy][ra := Mem(ra) + 2]
```

More generally, when the body of the loop is executed n times, we have (by an
easy induction on n):

```
[[c3; c4]]nEnv : Mem ↦ Mem[rb := Mem(rb) − nvy][ra := Mem(ra) + n]
```
