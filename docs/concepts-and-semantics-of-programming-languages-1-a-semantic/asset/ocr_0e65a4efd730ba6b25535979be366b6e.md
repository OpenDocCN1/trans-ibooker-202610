def valeur_ref(mem,a):

The following function writes a value into the memory:

```
def write_mem(mem,a,v):
    if len(mem) == 0: return [(a,v)]
    else:
        a1,v1 = mem[0]
        if a == a1: return [(a1,v)] + mem[1:]
        else: return [(a1,v1)] + write_mem(mem[1:],a,v)
```

```
let rec write_mem mem a v = match mem with
  | [] -> [(a, v)]
  | (a1, v1) :: t ->
      if a = a1 then (a1, v) :: t else (a1, v1) :: (write_mem t a v)
val write_mem : ('a * 'b) list -> 'a -> 'b -> ('a * 'b) list
```

# 2.1.3. State

A state is defined as a pair $(\text{Env}, \text{Mem}) \in \mathbf{E} \times \mathbf{M}$ such that any reference in the domain of Mem is accessible from a binding in Env. A reference is said to be *accessible* if its value can be read or written from an identifier contained in Env by a series of operations of reading, writing, or reference manipulation.

Given an environment Env, the set of identifiers **X** is partitioned into two subsets: $\mathbf{X}^{\text{ref}}_{\text{Env}}$, which contains the identifiers bound to a reference, and $\mathbf{X}^{\text{cst}}_{\text{Env}}$, which contains the others:

$\mathbf{X}^{\text{ref}}_{\text{Env}} = \{x \in \mathbf{X} \mid \text{Env}(x) \in \mathbf{R}\} \qquad \mathbf{X}^{\text{cst}}_{\text{Env}} = \{x \in \mathbf{X} \mid \text{Env}(x) \in \mathbf{V} \setminus \mathbf{R}\}$

The value associated with an identifier $x$ in $\mathbf{X}^{\text{ref}}_{\text{Env}}$ is a reference $\text{Env}(x) = r$ where a value $\text{Mem}(r)$ is stored, which can be modified by writing. Identifiers of $\mathbf{X}^{\text{ref}}_{\text{Env}}$ are generally called *mutable variables*.
