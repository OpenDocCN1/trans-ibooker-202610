# PROPOSITION 4.5.- Take two partial functions \(f_b : \mathbf{M} \rightarrowtail \mathbf{IB}\) and \(f_0 : \mathbf{M} \rightarrowtail \mathbf{M}\). Function \(F : f \mapsto \mathbf{cond}(f_b, f, f_0)\) is continuous.

PROOF.- First, let us prove that the function \(F\) is monotonic.

Let \(f_1\) and \(f_2\) be two functions in \([\mathbf{M} \rightarrowtail \mathbf{M}]\) such that \(f_1 \sqsubseteq f_2\), and let us show that \(F(f_1) \sqsubseteq F(f_2)\). Assume \(\mathsf{Mem} \in \mathbf{M}\) such that \((F(f_1))(\mathsf{Mem}) \neq \mathsf{undef}\); we show that \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\).

If \(f_b(\mathsf{Mem}) = 1\), then:

```
\((F(f_1))(\mathsf{Mem}) = f_1(\mathsf{Mem})\) and \((F(f_2))(\mathsf{Mem}) = f_2(\mathsf{Mem})\)
```

Since \(f_1 \sqsubseteq f_2\) and \(f_1(\mathsf{Mem}) = (F(f_1))(\mathsf{Mem}) \neq \mathsf{undef}\), we have \(f_1(\mathsf{Mem}) = f_2(\mathsf{Mem})\) and therefore \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\), establishing that \(F(f_1) \sqsubseteq F(f_2)\). If \(f_b(\mathsf{Mem}) = 0\), then \((F(f_1))(\mathsf{Mem}) = f_0(\mathsf{Mem})\) and \((F(f_2))(\mathsf{Mem}) = f_0(\mathsf{Mem})\), hence \((F(f_1))(\mathsf{Mem}) = (F(f_2))(\mathsf{Mem})\), which allows us to establish that \(F(f_1) \sqsubseteq F(f_2)\). If \(f_b(\mathsf{Mem}) = \mathsf{undef}\), then \((F(f_1))(\mathsf{Mem}) = \mathsf{undef}\), which is contradictory.

Let us show that for any non-empty chain \(Y\) in \(([\mathbf{M} \rightarrowtail \mathbf{M}], \sqsubseteq)\), \(\sqcup F(Y) = F(\sqcup Y)\).

Since we know that \(F\) is monotonic, by lemma 4.5, we get \(\sqcup F(Y) \sqsubseteq F(\sqcup Y)\). It remains to prove that \(F(\sqcup Y) \sqsubseteq \sqcup F(Y)\), i.e. \(F(\sqcup Y) \sqsubseteq \sqcup \{F(f) \mid f \in Y\}\). Take \(\mathsf{Mem}_1 \in \mathbf{M}\). Let us prove that if \((F(\sqcup Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2 \neq \mathsf{undef}\), then \((\sqcup F(Y)) = \mathsf{Mem}_2\). If \(f_b(\mathsf{Mem}_1) = 1\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = (\sqcup Y)(\mathsf{Mem}_1) = \mathsf{Mem}_2\) and, by proposition 4.4, there exists \(f \in Y\) such that \(f(\mathsf{Mem}_1) = \mathsf{Mem}_2\). By definition, for all \(f \in Y\), we have \(F(f) \sqsubseteq \sqcup F(Y)\) and we therefore obtain \((\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\). Otherwise, if \(f_b(\mathsf{Mem}_1) = 0\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = f_0(\mathsf{Mem}_1) = \mathsf{Mem}_2\) and for some function \(f \in Y\):

```
\((F(f))(\mathsf{Mem}_1) = f_0(\mathsf{Mem}_1) = \mathsf{Mem}_2 \neq \mathsf{undef}\)
```

Once again, by definition, for all \(f \in Y\), we have \(F(f) \sqsubseteq \sqcup F(Y)\) and we thus obtain \((\sqcup F(Y))(\mathsf{Mem}_1) = \mathsf{Mem}_2\). Finally, if \(f_b(\mathsf{Mem}_1) = \mathsf{undef}\), then \((F(\sqcup Y))(\mathsf{Mem}_1) = \mathsf{undef}\), which is contradictory.
