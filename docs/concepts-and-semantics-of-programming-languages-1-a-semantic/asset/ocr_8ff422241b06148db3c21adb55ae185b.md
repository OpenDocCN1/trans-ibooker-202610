# ## 4.3. Evaluation of definitions

Definitions introduced with language Def3 only modify execution environments. Their semantics is defined by:

(Env, Mem) --let x = e;-->_{Def_3} ((x, v) \oplus Env, Mem') if [[e]]^{Mem}_{Env} = (v, Mem')

This definition adds the binding (x, v) to the environment Env and sets the memory to Mem' when [[e]]^{Mem}_{Env} = (v, Mem'). Using a finite sequence of definitions d = [d_1, ..., d_n] and an initial state (Env_0, Mem_0), this relation computes the state (Env_n, Mem_n):

((Env_0, Mem_0) -->_{d_1 --> Def_3} (Env_1, Mem_1) -->_{d_2 --> Def_3} ... -->_{d_n --> Def_3} (Env_n, Mem_n)

This sequence of transitions is denoted by: (Env_0, Mem_0) -->*_{d} Def_3 (Env_n, Mem_n).
