```
\((S_1) \frac{\text{ENV}(x) = r \in \mathbf{R} \quad \llbracket e \rrbracket_{\text{Env}}^{\text{Mem}_1} = (v, \text{Mem}_2) \in \mathbf{V} \times \mathbf{M}}{(x := e, \text{Mem}_1) \mapsto_{\text{Env}} \langle \text{skip}, \text{Mem}_2[r := v] \rangle}\)

\((S_2) \frac{\langle c_1, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c'_1, \text{Mem}_2 \rangle}{\langle c_1 ; c_2, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c'_1 ; c_2, \text{Mem}_2 \rangle} \qquad (S_3) \langle \text{skip} ; c, \text{Mem} \rangle \mapsto_{\text{Env}} \langle c, \text{Mem} \rangle\)

\((S_4) \frac{\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}_1} = (\text{true}, \text{Mem}_2)}{\langle \text{if } e \text{ then } c_1 \text{ else } c_2, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c_1, \text{Mem}_2 \rangle}\)

\((S_5) \frac{\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}_1} = (\text{false}, \text{Mem}_2)}{\langle \text{if } e \text{ then } c_1 \text{ else } c_2, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c_2, \text{Mem}_2 \rangle}\)

\((S_6) \frac{\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}_1} = (\text{true}, \text{Mem}_2)}{\langle \text{while } e \text{ do } c, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c ; \text{while } e \text{ do } c, \text{Mem}_2 \rangle}\)

\((S_7) \frac{\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}_1} = (\text{false}, \text{Mem}_2)}{\langle \text{while } e \text{ do } c, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle \text{skip}, \text{Mem}_2 \rangle}\)
```

# Box 4.3. Small-step operational semantics of Lang$_3$.

A sequence of computations is a sequence, possibly infinite, of the form:

```
\(\langle c_0, \text{Mem}_0 \rangle \mapsto_{\text{Env}} \langle c_1, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c_2, \text{Mem}_2 \rangle \mapsto_{\text{Env}} \cdots\)
```

such that there exists an inference tree for \(\langle c_i, \text{Mem}_i \rangle \mapsto_{\text{Env}} \langle c_{i+1}, \text{Mem}_{i+1} \rangle\) for all \(i \ge 0\). The relation \(\mapsto^*_{\text{Env}}\) can then be defined by \(\langle c, \text{Mem} \rangle \mapsto^*_{\text{Env}} \text{Mem}'\) if, and only if, there exists a sequence of computations, containing only a finite number of transitions (or zero transitions)

```
\(\langle c_0, \text{Mem}_0 \rangle \mapsto_{\text{Env}} \langle c_1, \text{Mem}_1 \rangle \mapsto_{\text{Env}} \langle c_2, \text{Mem}_2 \rangle \mapsto_{\text{Env}} \cdots \mapsto_{\text{Env}} \langle c_k, \text{Mem}_k \rangle\)
```

such that \(c = c_0\), \(\text{Mem} = \text{Mem}_0\) and \(\text{Mem}' = \text{Mem}_k\) and such that the configuration \(\langle c_k, \text{Mem}_k \rangle\) is terminal (i.e. \(c_k = \text{skip}\)). If we know the length of the sequence, as in this case, we write \(\langle c, \text{Mem} \rangle \mapsto^k_{\text{Env}} \text{Mem}'\).
