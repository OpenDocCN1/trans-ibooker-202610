Note here that the precondition \(\downarrow x + 1 = 3\) (equivalent to \(\downarrow x = 2\)) corresponds to the postcondition \(\downarrow x = 3\) where \(\downarrow x\) (where \(x\) is the left member of the assignment) has been replaced by \(\downarrow x + 1\) (the right member of the assignment), noted \((\downarrow x + 3) [\downarrow x \leftarrow \downarrow x + 1]\). In this rule, \(P[\downarrow x \leftarrow e]\) designates the assertion obtained by replacing \(\downarrow x\) by \(e\) in \(P\): the substitution mechanism depends on the specification language used to express the assertions.

Using the extensional approach described above, the assertion \(P[\downarrow x \leftarrow e]\) satisfies:

\([[P[\downarrow x \leftarrow e]]]^{\text{Mem}}_{\text{Env}} = [[P]]^{\text{Mem}'}_{\text{Env}}\) where \(\text{Mem}' = \text{Mem}[\text{Env}(x) := [[e]]^{\text{Mem}}_{\text{Env}}]\)

Rule (Seq) states that if the execution of \(c_1\) in a state that satisfies \(P_1\) leads to a state that satisfies \(P_2\) and if the execution of \(c_2\) in such a state leads to a state that satisfies \(P_3\), then the execution of the sequence \(c_1 ; c_2\) in a state that satisfies \(P_1\) leads to a state that satisfies \(P_3\). For example, we have:

(Aff) \(\{0 + x \ge 0\} a := 0 \{ \downarrow a + x \ge 0 \}\)   (Aff) \(\{ \downarrow a + x \ge 0 \} b := x \{ \downarrow a + \downarrow b \ge 0 \}\)
(Seq) \(\frac{}{\{0 + x \ge 0\} a := 0 ; b := x \{ \downarrow a + \downarrow b \ge 0 \}}\)

In this example, we wish to write the precondition in a simpler form, replacing \(0 + x \ge 0\) with \(x \ge 0\) and expressing the postcondition in the form \(\downarrow a \ge - \downarrow b\). This transformation is possible using rule (Cons): if every state which satisfies \(x \ge 0\) also satisfies \(0 + x \ge 0\) and if the execution of the sequence \(a := 0 ; b := x\) from such a state leads to a state which satisfies \(\downarrow a + \downarrow b \ge 0\), which must verify \(\downarrow a \ge - \downarrow b\), then \(\{x \ge 0\} a := 0 ; b := x \{ \downarrow a \ge - \downarrow b \}\) is a provable triple:

(Seq) \(\frac{\{0 + x \ge 0\} a := 0 ; b := x \{ \downarrow a + \downarrow b \ge 0 \}}{\{x \ge 0\} a := 0 ; b := x \{ \downarrow a \ge - \downarrow b \}}\)   (Cons) \(\begin{pmatrix} x \ge 0 \Rightarrow 0 + x \ge 0 \\ \downarrow a + \downarrow b \ge 0 \Rightarrow \downarrow a \ge - \downarrow b \end{pmatrix}\)

The transformation of the assertions of a Hoare triple done by this rule is based on logical implications, which must be established. With the extensional approach, proving \(P_1 \Rightarrow P_2\) requires us to show that for any state \((\text{Env}, \text{Mem})\), if \([[P_1]]^{\text{Mem}}_{\text{Env}} = 1\), then \([[P_2]]^{\text{Mem}}_{\text{Env}} = 1\). It is possible to only transform one of the two assertions in a Hoare triple, using one of the following two rules:

(Consg) \(\frac{\{P'_1\} c \{P_2\}}{\{P_1\} c \{P_2\}} (P_1 \Rightarrow P'_1)\)   (Consd) \(\frac{\{P_1\} c \{P'_2\}}{\{P_1\} c \{P_2\}} (P'_2 \Rightarrow P_2)\)

These rules can be deduced directly from rule (Cons). Rule (Cond) expresses the postcondition of a conditional instruction as a function of the boolean expression
