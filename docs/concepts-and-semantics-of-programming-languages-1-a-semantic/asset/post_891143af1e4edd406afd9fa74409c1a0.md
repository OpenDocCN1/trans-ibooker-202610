
$$ \langle e_2, \text{Env} \rangle = \langle e_2^0, \text{Env} \rangle \leftrightarrow \langle e_2^1, \text{Env} \rangle \leftrightarrow \langle e_2^2, \text{Env} \rangle \leftrightarrow \cdots \leftrightarrow \langle e_2^{k_2}, \text{Env} \rangle = \langle n_2, \text{Env} \rangle $$

Rule $AS_5$ allows us to transform each transition $\langle e_1^i, \text{Env} \rangle \leftrightarrow \langle e_1^{i+1}, \text{Env} \rangle$ in sequence [A.1] into a transition $\langle e_1^i + e_2, \text{Env} \rangle \leftrightarrow \langle e_1^{i+1} + e_2, \text{Env} \rangle$. We can thus obtain the following transition sequence:

$$ \langle e_1 + e_2, \text{Env} \rangle = \langle e_1^0 + e_2, \text{Env} \rangle \leftrightarrow \langle e_1^1 + e_2, \text{Env} \rangle \leftrightarrow \langle e_1^2 + e_2, \text{Env} \rangle \leftrightarrow \cdots \leftrightarrow \langle e_1^{k_1} + e_2, \text{Env} \rangle = \langle n_1 + n_2, \text{Env} \rangle $$

Rule $AS_6$ allows us to transform each transition $\langle e_2^i, \text{Env} \rangle \leftrightarrow \langle e_2^{i+1}, \text{Env} \rangle$ in sequence [A.2] into a transition $\langle n_1 + e_2^i, \text{Env} \rangle \leftrightarrow \langle n_1 + e_2^{i+1}, \text{Env} \rangle$. We thus obtain the sequence:

$$ \langle n_1 + e_2, \text{Env} \rangle = \langle n_1 + e_2^0, \text{Env} \rangle \leftrightarrow \langle n_1 + e_2^1, \text{Env} \rangle \leftrightarrow \langle n_1 + e_2^2, \text{Env} \rangle \leftrightarrow \cdots \leftrightarrow \langle n_1 + e_2^{k_2}, \text{Env} \rangle = \langle n_1 + n_2, \text{Env} \rangle $$

Finally, rule $AS_2$ allows us to consider the transition $\langle n_1 + n_2, \text{Env} \rangle \leftrightarrow \langle n, \text{Env} \rangle$ where $n$ is the value of $n_1 + n_2$, and by concatenating sequences [A.3] and [A.4] with this transition, we finally obtain $\langle e_1 + e_2, \text{Env} \rangle \leftrightarrow^* n_1 + n_2$.

- For the binary operators * and -, a similar reasoning to that shown above is used.

4) We proceed by induction over expression $e_1$.

- If $e_1 = n \in \mathbb{Z}$, then hypothesis $\langle e_1, \text{Env} \rangle \leftrightarrow \langle e_2, \text{Env} \rangle$ results in a contradiction since $\langle e_1, \text{Env} \rangle$ is a terminal configuration.

- If $e_1 = x \in \mathbf{X}$, then we must have $e_2 = \text{Env}(x) \in \mathbb{Z}$ and $v = \text{Env}(x)$. It is thus possible to conclude our proof by constructing the tree:

$$ (F_{11}) \overline{\text{Env} \vdash x \leadsto v} $$

- If $e_1 = a_1 \text{ op } a_2$ (with $\text{op} \in \{+, *, -\}$), three cases are possible.

Case 1: If $a_1, a_2 \in \mathbb{Z}$, then $e_2 = v$ with $v = a_1 \text{ op}_{\mathbf{V}} a_2 \in \mathbb{Z}$ and we can conclude our proof by constructing the tree:

$$ (F_4) \frac{(F_1) \overline{\text{Env} \vdash a_1 \leadsto a_1} \quad (F_1) \overline{\text{Env} \vdash a_2 \leadsto a_2}}{\text{Env} \vdash a_1 \text{ op } a_2 \leadsto v} $$

Case 2: If $a_1 \in E_A \setminus \mathbb{Z}$, then $e_2 = a_1' \text{ op } a_2$ with $\langle a_1, \text{Env} \rangle \leftrightarrow \langle a_1', \text{Env} \rangle$. The evaluation tree for $\text{Env} \vdash a_1' \text{ op } a_2 \rightsquigarrow v$ must contain the subtrees:

$$ (F_j) \frac{\vdots}{\text{Env} \vdash a_1' \rightsquigarrow v_1'} \qquad (F_k) \frac{\vdots}{\text{Env} \vdash a_2 \rightsquigarrow v_2'} $$

and thus, by induction hypothesis, we obtain $\text{Env} \vdash a_1 \rightsquigarrow v_1'$ and, from the evaluation tree for $\text{Env} \vdash a_2 \rightsquigarrow v_2'$, rule $F_4$ allows us to obtain the evaluation tree for $\text{Env} \vdash a_1 \text{ op } a_2 \rightsquigarrow v$.

Case 3: If $a_1 \in \mathbb{Z}$ and $a_2 \in E_A \setminus \mathbb{Z}$, then a similar reasoning to that used in the previous case brings us to our conclusion.

5) Since $\langle e, \text{Env} \rangle \leftrightarrow^* v$, there exists a transition sequence:

$$ \langle e, \text{Env} \rangle = \langle e^0, \text{Env} \rangle \leftrightarrow \langle e^1, \text{Env} \rangle \leftrightarrow \cdots \leftrightarrow \langle e^k, \text{Env} \rangle $$

with $e^k = v \in \mathbb{Z}$. The proof is obtained by induction over the length $k$ of this sequence. Let us prove this property for $k=0$, for $k=1$ and for $k>1$, which we assume to be true for $k-1$ and $k-2$.

- If $k=0$, then $e = v \in \mathbb{Z}$ and rule $F_1$ concludes our proof. Else, if $k=k_0+1$, then we proceed by case over the first transition in the sequence.

- If $k=1$, then two cases are possible.

Case I: If the transition has been obtained using rule $AS_1$: $\langle x, \text{Env} \rangle \leftrightarrow \langle \text{Env}(x), \text{Env} \rangle$, then $e=x$ and $v=\text{Env}(x)$ and rule $F_{11}$ concludes our proof.

Case 2: If the transition has been obtained using rule $AS_2$, $AS_3$ or $AS_4$:

$$ \langle n_1 \text{ op } n_2, \text{Env} \rangle \leftrightarrow \langle n, \text{Env} \rangle $$

with $\text{op} \in \{+, -, *\}$, then $n = n_1 \text{ op}_{\mathbb{V}} n_2$ and rule $F_4$ concludes our proof:

$$ (F_1) \frac{\text{Env} \vdash n_1 \rightsquigarrow n_1}{} \qquad (F_1) \frac{\text{Env} \vdash n_2 \rightsquigarrow n_2}{} \qquad (F_4) \frac{\text{Env} \vdash n_1 \text{ op } n_2 \rightsquigarrow n}{} $$

- If $k \ge 2$, then two cases are possible.

Case I: If $\langle e_1 \text{ op } e_2, \text{Env} \rangle \leftrightarrow \langle e'_1 \text{ op } e_2, \text{Env} \rangle \leftrightarrow \cdots \leftrightarrow \langle e^k, \text{Env} \rangle$ is the considered sequence, with $\langle e_1, \text{Env} \rangle \leftrightarrow \langle e'_1, \text{Env} \rangle$ (the first transition is obtained using rule $AS_5$, $AS_7$ or $AS_9$), then, by induction hypothesis over a transition sequence of length $k-1$, we have $\text{Env} \vdash e'_1 \text{ op } e_2 \rightsquigarrow v$ and, from the previous question, we obtain $\text{Env} \vdash e_1 \text{ op } e_2 \rightsquigarrow v$.

Case 2: If $\langle e_1 \text{ op } e_2, \text{Env} \rangle \leftrightarrow \langle e_1 \text{ op } e'_2, \text{Env} \rangle \leftrightarrow \dots \leftrightarrow \langle e^k, \text{Env} \rangle$ is the considered sequence, with $\langle e_2, \text{Env} \rangle \leftrightarrow \langle e'_2, \text{Env} \rangle$ and $e_1 \in \mathbb{Z}$ (the first transition is obtained using rule $AS_6$, $AS_8$ or $AS_{10}$), then this sequence may be decomposed as follows:

$$ \langle e_1 \text{ op } e_2, \text{Env} \rangle \leftrightarrow \underbrace{\langle e_1 \text{ op } e'_2, \text{Env} \rangle \leftrightarrow \dots \leftrightarrow \langle e_1 \text{ op } v'_2, \text{Env} \rangle}_{\text{length } k-2} \leftrightarrow \langle v, \text{Env} \rangle $$

where the last transition is obtained with rule $AS_2$, $AS_3$ or $AS_4$ and thus $v'_2 \in \mathbb{Z}$ and $v = e_1 \text{ op}_{\mathbf{V}} v'_2$. The sequence of length $k-2$ corresponds to a simplification sequence of expression $e_2$, from which we can construct the sequence $\langle e'_2, \text{Env} \rangle \leftrightarrow \dots \leftrightarrow \langle v'_2, \text{Env} \rangle$ of length $k-2$. Since $v'_2 \in \mathbb{Z}$, by induction hypothesis we have $\text{Env} \vdash e'_2 \rightsquigarrow v'_2$ and since $e_1 \in \mathbb{Z}$, rule $F_1$ allows us to obtain $\text{Env} \vdash e_1 \rightsquigarrow e_1$. Following rule $F_4$, we thus have $\text{Env} \vdash e_1 \text{ op } e'_2 \rightsquigarrow v$. From the previous question, since $\langle e_1 \text{ op } e_2, \text{Env} \rangle \leftrightarrow \langle e_1 \text{ op } e'_2, \text{Env} \rangle$, we obtain $\text{Env} \vdash e_1 \text{ op } e_2 \rightsquigarrow v$.

## Solution to exercise 4.1

1) Let Mem and $\text{Mem}_3$ be two memory states. We have to prove that:

$$ \langle \text{Mem}, c_1 ; (c_2 ; c_3) \rangle \Rightarrow_{\text{Env}} \text{Mem}_3 \Leftrightarrow \langle \text{Mem}, (c_1 ; c_2) ; c_3 \rangle \Rightarrow_{\text{Env}} \text{Mem}_3 $$

An inference tree for $\langle \text{Mem}, (c_1 ; c_2) ; c_3 \rangle \Rightarrow_{\text{Env}} \text{Mem}_3$ can be obtained from an inference tree for $\langle \text{Mem}, c_1 ; (c_2 ; c_3) \rangle \Rightarrow_{\text{Env}} \text{Mem}_3$, and vice versa. Indeed, from the tree:

```
(Ci) 1       (Cj) 2              (Ck) 3
<mem, c1> -->env mem1   <mem1, c2> -->env mem2   <mem2, c3> -->env mem3
   \___________________________________________/
               <mem1, c2 ; c3> -->env mem3
   \___________________________________________________________/
                         <mem, c1 ; (c2 ; c3)> -->env mem3
```
