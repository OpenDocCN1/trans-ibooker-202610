# ### Solution to exercise 2.1

+   1) \(\mathbf{X}^{\text{ref}}_{\text{Env}_0} = \{y, z\}\) and \(\mathbf{X}^{\text{cst}}_{\text{Env}_0} = \{x\}\).

2) The evaluation of the sequence of definitions \(\mathbf{d} = [\text{var } z = 2;\text{let } x = 8;\text{var } y = 5;\text{let } x = 3;]\) leads to the state \(\eta_{\text{at}0}\) as follows:

```
([], []) \(\xrightarrow{\text{var } z = 2;\rightarrow_{\text{Def}1}} [((z, r_z)], [(r_z, 2))] \xrightarrow{\text{let } x = 8;\rightarrow_{\text{Def}1}} [((x, 8), (z, r_z)], [(r_z, 2))] \xrightarrow{\text{var } y = 5;\rightarrow_{\text{Def}1}} [((y, r_y), (x, 8), (z, r_z)], [(r_y, 5), (r_z, 2))] \xrightarrow{\text{let } x = 3;\rightarrow_{\text{Def}}} \eta_{\text{at}0}\)
```

There are several sequences of definitions, which lead to state \(\eta_{\text{at}0}\). For example, in the sequence d, the definition let \(x = 8\) may be replaced by let \(x = !z + 6\) since, in state \([((z, r_z)], [(r_z, 2))]\), the expression \(!z + 6\) is evaluated as 8.

+   3) Let us develop this expression as follows:

```
\([[(!y + !z) + x]^{\text{Memo}}_{\text{Env}_0}] \text{=} [[!y + !z]^{\text{Memo}}_{\text{Env}_0}] + [[x]^{\text{Memo}}_{\text{Env}_0}] \text{=} [[!y]^{\text{Memo}}_{\text{Env}_0}] + [[!z]^{\text{Memo}}_{\text{Env}_0}] + \text{Env}_0(x) \text{=} (\text{Mem}_0(\text{Env}_0(y)) + \text{Mem}_0(\text{Env}_0(z))) + 3 \text{=} (\text{Mem}_0(r_y) + \text{Mem}_0(r_z)) + 3 \text{=} (5 + 2) + 3 \text{=} 10\)
```

+   4) In state \(\eta_{\text{at}0}\), the evaluation of the expression \(!x\) triggers an error, as \(x\) is not a mutable variable in \(\text{Env}_0\); the evaluation of \(y + x\) triggers an error, as \(y\) is evaluated as a reference to which addition cannot be applied, and the evaluation of the identifier \(w\) triggers an error, as it is unbound in \(\text{Env}_0\).
