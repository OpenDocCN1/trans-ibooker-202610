## Solution to exercise 3.5

We proceed by induction over $a$ (proving the implication in only one direction, since the relation $=_X$ is clearly symmetrical).

- If $a = k \in \mathbb{Z}$, then $\mathcal{F}(a) = \emptyset$, the evaluation tree for $\text{Env}_1 \vdash k \rightsquigarrow n$ must have been obtained using rule $F_1$ with $k = n$ and, using the same rule, we can clearly construct an evaluation tree for $\text{Env}_2 \vdash k \rightsquigarrow n$.

- If $a = x \in \mathbf{X}$, and thus $\mathcal{F}(a) = \{x\}$, the evaluation tree for $\text{Env}_1 \vdash x \rightsquigarrow n$ must have been obtained using rule $F_{11}$ with $\text{Env}_1(x) = n$. Since, by hypothesis, $\text{Env}_1 =_{\mathcal{F}(a)} \text{Env}_2$, we obtain $\text{Env}_2(x) = n$ and, by applying rule $F_{11}$, we obtain an evaluation tree for $\text{Env}_2 \vdash x \rightsquigarrow n$.

- If $a = a_1 \text{ op } a_2$ (op $\in \{+, -, *\}$), the evaluation tree for $\text{Env}_1 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$ must have been obtained using rule $F_4$:

```
$(F_i)$   $(F_j)$
::   ::
$\text{Env}_1 \vdash a_1 \rightsquigarrow n_1$  $\text{Env}_1 \vdash a_2 \rightsquigarrow n_2$
---------------------------------
$(F_4)$ $\text{Env}_1 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$
```

with $n = n_1 \text{ op}_{\mathbf{V}} n_2$. Since $\mathcal{F}(a_1) \subseteq \mathcal{F}(a)$ and $\mathcal{F}(a_2) \subseteq \mathcal{F}(a)$ (giving us $\text{Env}_1 =_{\mathcal{F}(a_1)} \text{Env}_2$ and $\text{Env}_1 =_{\mathcal{F}(a_2)} \text{Env}_2$), by induction hypothesis, there exists an evaluation tree for $\text{Env}_2 \vdash a_1 \rightsquigarrow n_1$ and for $\text{Env}_2 \vdash a_2 \rightsquigarrow n_2$. From these two trees, we can then build an evaluation tree for $\text{Env}_2 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$ by applying rule $F_4$.

- If $a = (\text{let } x = a_1 \text{ in } a_2)$, the evaluation tree for $\text{Env}_1 \vdash \text{let } x = a_1 \text{ in } a_2 \rightsquigarrow n$, must have been obtained using rule $F_{13}$:

```
$(F_i)$   $(F_j)$
::   ::
$\text{Env}_1 \vdash a_1 \rightsquigarrow n_1$  $(x, n_1) \oplus \text{Env}_1 \vdash a_2 \rightsquigarrow n_2$
-----------------------------------------------
$(F_{13})$ $\text{Env}_1 \vdash \text{let } x = a_1 \text{ in } a_2 \rightsquigarrow n_2$
```

Since, by definition, $\mathcal{F}(a) = \mathcal{F}(a_1) \cup (\mathcal{F}(a_2) \setminus \{x\})$, we have $\mathcal{F}(a_1) \subseteq \mathcal{F}(a)$ and thus $\text{Env}_1 =_{\mathcal{F}(a_1)} \text{Env}_2$, which allows us, by induction hypothesis over $a_1$, to obtain the evaluation tree for $\text{Env}_2 \vdash a_1 \rightsquigarrow n_1$. Furthermore, since $\text{Env}_1 =_{\mathcal{F}(a)} \text{Env}_2$, we obtain $(x, n_1) \oplus \text{Env}_1 =_{\{x\} \cup \mathcal{F}(a)} (x, n_1) \oplus \text{Env}_2$ and since $\mathcal{F}(a_2) \subseteq \mathcal{F}(a) \cup \{x\}$, we have $(x, n_1) \oplus \text{Env}_1 =_{\mathcal{F}(a_2)} (x, n_1) \oplus \text{Env}_2$, and the induction hypothesis can be used over $a_2$ to obtain an evaluation tree for $(x, n_1) \oplus \text{Env}_2 \vdash a_2 \rightsquigarrow n_2$. Applying rule $F_{13}$ from the two evaluation trees constructed in this way, we obtain an evaluation tree for $\text{Env}_2 \vdash \text{let } x = a_1 \text{ in } a_2 \rightsquigarrow n_2$, concluding our proof.

## Solution to exercise 3.6

We proceed by induction over $e$.

- If $e = k \in \mathbb{Z}$, then $[[k[x \leftarrow e']]]_{\text{Env}} = [[k]]_{\text{Env}} = k = [[k]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}}$

- If $e = z \in X$, then if $z = x$ we obtain:

```
[[x[x \leftarrow e']]]_{\text{Env}} = [[e']]_{\text{Env}} = [[x]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}}
```

otherwise, if $z \neq x$ we obtain

```
[[z[x \leftarrow e']]]_{\text{Env}} = [[z]]_{\text{Env}} = \text{Env}(z) = [[z]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}}
```

- If $e = e_1 \text{ op } e_2$, then:

```
[[(e_1 \text{ op } e_2)[x \leftarrow e']]]_{\text{Env}}
= [[e_1[x \leftarrow e'] \text{ op } e_2[x \leftarrow e']]]_{\text{Env}}          (substitution)
= [[e_1[x \leftarrow e']]]_{\text{Env}} \operatorname{op}_{\mathbf{V}} [[e_2[x \leftarrow e']]]_{\text{Env}}   (evaluation function)
= [[e_1]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}} \operatorname{op}_{\mathbf{V}} [[e_2]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}} (induction hypothesis)
= [[e_1 \text{ op } e_2]]_{(x, [[e']]_{\text{Env}}) \oplus \text{Env}}   (evaluation function)
```

## Solution to exercise 3.7

- 1) The transition sequence is as follows:

```
⟨(z + (x - y)) * (x + 7), Env⟩ ↔ ⟨(2 + (x - y)) * (x + 7), Env⟩
↔ ⟨(2 + (1 - y)) * (x + 7), Env⟩ → ⟨(2 + (1 - 3)) * (x + 7), Env⟩
↔ ⟨(2 + -2) * (x + 7), Env⟩ → ⟨0 * (x + 7), Env⟩ ↔ ⟨0 * (1 + 7), Env⟩
↔ ⟨0 * 8, Env⟩ → ⟨0, Env⟩
```

- 2) a) We consider the lexicographic order $\sqsubseteq$ over $\mathbb{N} \times \mathbb{N}$, defined from the order relation $\leq$ over $\mathbb{N}$:

```
(n_1, n_2) \sqsubseteq (n'_1, n'_2) \text{ if } (n_1 < n'_1) \text{ or } (n_1 = n'_1 \text{ and } n_2 \leq n'_2)
```

- b) Let $P(\langle e, \text{Env} \rangle \mapsto \langle e', \text{Env} \rangle)$ be the property:

$(\mathcal{N}_V(e'), \mathcal{N}_O(e')) \prec (\mathcal{N}_V(e), \mathcal{N}_O(e))$

and let us show, by induction, that this property is verified considering each rule in the inference system presented in Box 3.5.

- Rule $AS_1$: Since $\text{Env}(x) \in \mathbb{Z}$, we have $\mathcal{N}_V(x) = 1$ and $\mathcal{N}_V(\text{Env}(x)) = 0$ which concludes our proof.

- Rule $AS_2$: On the one hand, $\mathcal{N}_V(n_1 + n_2) = \mathcal{N}_V(n) = 0$ (since $n, n_1, n_2 \in \mathbb{Z}$) and, on the other hand, $\mathcal{N}_O(n) = \mathcal{N}_O(n_1 + n_2) - 1$, which concludes our proof.

- Rules $AS_3$ and $AS_4$: Similar reasoning to that used for rule $AS_2$.

- Rule $AS_5$: By induction hypothesis, we have:

$(\mathcal{N}_V(e'_1), \mathcal{N}_O(e'_1)) \prec (\mathcal{N}_V(e_1), \mathcal{N}_O(e_1))$

Additionally, either $\mathcal{N}_V(e'_1) < \mathcal{N}_V(e_1)$ and we obtain:

$\mathcal{N}_V(e'_1 + e_2) = \mathcal{N}_V(e'_1) + \mathcal{N}_V(e_2) < \mathcal{N}_V(e_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1 + e_2)$

which concludes our proof, or $\mathcal{N}_V(e'_1) = \mathcal{N}_V(e_1)$ and $\mathcal{N}_O(e'_1) < \mathcal{N}_O(e_1)$ and we obtain:

$\mathcal{N}_V(e'_1 + e_2) = \mathcal{N}_V(e'_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1 + e_2)$ and
$\mathcal{N}_O(e'_1 + e_2) = \mathcal{N}_O(e'_1) + \mathcal{N}_O(e_2) + 1 < \mathcal{N}_O(e_1) + \mathcal{N}_O(e_2) + 1 = \mathcal{N}_O(e_1 + e_2)$

which also brings us to our conclusion.

- Rules $AS_7$ and $AS_9$: Similar reasoning to that used for rule $AS_5$.

- Rule $AS_6$: By induction hypothesis, we have:

$(\mathcal{N}_V(e'_2), \mathcal{N}_O(e'_2)) \prec (\mathcal{N}_V(e_2), \mathcal{N}_O(e_2))$

Additionally, either $\mathcal{N}_V(e'_2) < \mathcal{N}_V(e_2)$ and we obtain:

$\mathcal{N}_V(n_1 + e'_2) = \mathcal{N}_V(e'_2) < \mathcal{N}_V(e_2) = \mathcal{N}_V(n_1 + e_2)$

which concludes our proof, or $\mathcal{N}_V(e'_2) = \mathcal{N}_V(e_2)$ and $\mathcal{N}_O(e'_2) < \mathcal{N}_O(e_2)$ and we obtain:

$\mathcal{N}_V(n_1 + e'_2) = \mathcal{N}_V(e'_2) = \mathcal{N}_V(e_2) = \mathcal{N}_V(n_1 + e_2)$
$\mathcal{N}_O(n_1 + e'_2) = \mathcal{N}_O(e'_2) + 1 < \mathcal{N}_O(e_2) + 1 = \mathcal{N}_O(n_1 + e_2)$

which also brings us to our conclusion.

- Rules $AS_8$ and $AS_{10}$: Similar reasoning to that used for rule $AS_6$.

- c) For each step $\langle e_i, \text{Env} \rangle \leftrightarrow \langle e_{i+1}, \text{Env} \rangle$, we have:

$(\mathcal{N}_V(e_{i+1}), \mathcal{N}_O(e_{i+1})) \prec (\mathcal{N}_V(e_i), \mathcal{N}_O(e_i))$

and since $\preceq$ is a well-founded order relation over $\mathbb{N} \times \mathbb{N}$, there is no strictly decreasing infinite sequence:

$(n_0, n'_0) \succ (n_1, n'_1) \succ (n_2, n'_2) \succ \cdots$

Rule $AS_1$ can then be used to construct a tree for $\langle x, \text{Env} \rangle \leftrightarrow \langle \text{Env}(x), \text{Env} \rangle$ and we can establish that $\langle x, \text{Env} \rangle \stackrel{*}{\leftrightarrow} \text{Env}(x)$.

then, by induction hypothesis, we have:

$\langle e_1, \text{Env} \rangle \stackrel{*}{\leftrightarrow} n_1 \text{ and } \langle e_2, \text{Env} \rangle \stackrel{*}{\leftrightarrow} n_2$

and there exist two transition sequences:
