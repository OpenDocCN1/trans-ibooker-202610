# 4.6.2. Procedures

# 4.6.2.1. Language of definitions

A new syntactic construct is added to Def3 : proc p(x){c}. This construct defines a procedure named p (which is an identifier), having a parameter denoted by a variable x and a body which is a program c in Lang3. For the sake of simplicity, we shall limit our discussion to procedures with a single parameter. The descriptions below can easily be extended to procedures with multiple parameters, for example by replacing the single parameter with an n-uple. For procedures without arguments, the argument is a value of the “empty” type.

> We implement the syntactic construct used to define procedures in Def3. With Python, we define the following class:
