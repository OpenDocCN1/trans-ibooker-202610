C++ has another special feature: exceptions are not necessarily class objects. Any value of any type can be raised as an exception, as shown in example 8.8.

# EXAMPLE 8.8.--

```
```cpp
#include <iostream>
#include <exception>
using namespace std ;

struct pair_t { int left ; int right ; } ;

int main () {
try { throw 42 ; }
catch (int e) { cout << e << '\n' ; }
try { throw "Catch me" ; }
catch (char const *e) { cout << e << '\n' ; }
try { throw 3.14159 ; }
catch (double e) { cout << e << '\n' ; }
try {
struct pair_t pair = { 0, 1 } ;
throw pair ;
}
catch (struct pair_t e) { cout << e.left << ", " << e.right << '\n' ; }
return (0) ;
}
```
```

```
```
$ ./a.out
42
Catch me
3.14159
0, 1
```
```

The first handler catches an exception, which is an integer, and the second handler catches an exception, which is a string. It is important to note that the declared type of the exception is char const * and not simply char *. As the string "Catch me" is constant, it is implicitly qualified as const by the compiler. If this detail is omitted, the handler will not catch the exception. The third handler concerns an exception of type float. Once again, the constant 3.14159 is considered to be of type double, not float, by the compiler. The declared type of the exception must therefore be double, otherwise the exception will not be caught. The final handler shows that it is possible to raise values constructed from user data structures, and not only values of basic scalars, as exceptions.
