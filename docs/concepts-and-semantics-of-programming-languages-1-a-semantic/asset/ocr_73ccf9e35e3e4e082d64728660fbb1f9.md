Consider the program $c_d$ that computes the quotient and the remainder of the Euclidean division of $x$ by $y$, by using successive subtractions defined by:

```
$(a := 0 ; b := x) ; \mathbf{while} \downarrow b \ge y \mathbf{do} b := \downarrow b - y ; a := \downarrow a + 1$
```

+   1) Compute $[[c_d]]_{\text{Env}}$ and deduce that $[[c_d]]_{\text{Env}}(\text{Mem})(\text{Env}(a))$ is the quotient of the integer division of $\text{Env}(x)$ by $\text{Env}(y)$ and $[[c_d]]_{\text{Env}}(\text{Mem})(\text{Env}(b))$ is the remainder of this division.

+   2) Prove the total correctness of the following Hoare triple:

```
$\{x \ge 0 \text{ and } y > 0\} c_d \{x = (\downarrow a \times y) + \downarrow b \text{ and } \downarrow b < y\}$
```
