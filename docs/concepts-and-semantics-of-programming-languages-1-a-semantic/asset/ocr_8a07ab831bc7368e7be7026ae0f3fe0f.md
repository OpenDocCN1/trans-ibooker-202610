# Solution to exercise 3.5

We proceed by induction over $a$ (proving the implication in only one direction, since the relation $=_X$ is clearly symmetrical).

+   - If $a = k \in \mathbb{Z}$, then $\mathcal{F}(a) = \emptyset$, the evaluation tree for $\text{Env}_1 \vdash k \rightsquigarrow n$ must have been obtained using rule $F_1$ with $k = n$ and, using the same rule, we can clearly construct an evaluation tree for $\text{Env}_2 \vdash k \rightsquigarrow n$.

+   - If $a = x \in \mathbf{X}$, and thus $\mathcal{F}(a) = \{x\}$, the evaluation tree for $\text{Env}_1 \vdash x \rightsquigarrow n$ must have been obtained using rule $F_{11}$ with $\text{Env}_1(x) = n$. Since, by hypothesis, $\text{Env}_1 =_{\mathcal{F}(a)} \text{Env}_2$, we obtain $\text{Env}_2(x) = n$ and, by applying rule $F_{11}$, we obtain an evaluation tree for $\text{Env}_2 \vdash x \rightsquigarrow n$.

+   - If $a = a_1 \text{ op } a_2$ (op $\in \{+, -, *\}$), the evaluation tree for $\text{Env}_1 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$ must have been obtained using rule $F_4$:

```
$(F_i)$   $(F_j)$
::   ::
$\text{Env}_1 \vdash a_1 \rightsquigarrow n_1$  $\text{Env}_1 \vdash a_2 \rightsquigarrow n_2$
---------------------------------
$(F_4)$ $\text{Env}_1 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$
```

with $n = n_1 \text{ op}_{\mathbf{V}} n_2$. Since $\mathcal{F}(a_1) \subseteq \mathcal{F}(a)$ and $\mathcal{F}(a_2) \subseteq \mathcal{F}(a)$ (giving us $\text{Env}_1 =_{\mathcal{F}(a_1)} \text{Env}_2$ and $\text{Env}_1 =_{\mathcal{F}(a_2)} \text{Env}_2$), by induction hypothesis, there exists an evaluation tree for $\text{Env}_2 \vdash a_1 \rightsquigarrow n_1$ and for $\text{Env}_2 \vdash a_2 \rightsquigarrow n_2$. From these two trees, we can then build an evaluation tree for $\text{Env}_2 \vdash a_1 \text{ op } a_2 \rightsquigarrow n$ by applying rule $F_4$.

+   - If $a = (\text{let } x = a_1 \text{ in } a_2)$, the evaluation tree for $\text{Env}_1 \vdash \text{let } x = a_1 \text{ in } a_2 \rightsquigarrow n$, must have been obtained using rule $F_{13}$:

```
$(F_i)$   $(F_j)$
::   ::
$\text{Env}_1 \vdash a_1 \rightsquigarrow n_1$  $(x, n_1) \oplus \text{Env}_1 \vdash a_2 \rightsquigarrow n_2$
-----------------------------------------------
$(F_{13})$ $\text{Env}_1 \vdash \text{let } x = a_1 \text{ in } a_2 \rightsquigarrow n_2$
```
