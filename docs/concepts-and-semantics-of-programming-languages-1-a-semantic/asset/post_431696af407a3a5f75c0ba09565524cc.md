
### Solution to exercise 2.2

- 1) Depending on the order in which expressions e1 and e2 are evaluated and the state in which these evaluations are carried out, there are several possible options for evaluating the expression e1 + e2:

- [[k]]^{Mem}_{Env} = (k, (Env, Mem)) (for k in Z);
- [[x]]^{Mem}_{Env} = (Env(x), (Env, Mem)) if x in X and x in dom(Env);
- [[x]]^{Mem}_{Env} = (Err, (Env, Mem)) if x in X and x not in dom(Env);
- [[e_1 + e_2]]^{Mem}_{Env} = (v_1 + v_2, (Env_2, Mem_2)) if [[e_1]]^{Mem}_{Env} = (v_1, (Env_1, Mem_1)) and [[e_2]]^{Mem_1}_{Env_1} = (v_2, (Env_2, Mem_2)) and v_1, v_2 in Z;
- [[e_1 + e_2]]^{Mem}_{Env} = (Err, (Env_2, Mem_2)) if [[e_1]]^{Mem}_{Env} = (v_1, (Env_1, Mem_1)) and [[e_2]]^{Mem_1}_{Env_1} = (v_2, (Env_2, Mem_2)) and v_1 in Z and v_2 not in Z;
- [[e_1 + e_2]]^{Mem}_{Env} = (Err, (Env_1, Mem_1)) if [[e_1]]^{Mem}_{Env} = (v_1, (Env_1, Mem_1)) and v_1 not in Z;
- [[!x]]^{Mem}_{Env} = (Mem(Env(x)), (Env, Mem)) if x in X^{ref}_{Env};
- [[!x]]^{Mem}_{Env} = (Err, (Env, Mem)) if x not in X^{ref}_{Env};
- [[x++]]^{Mem}_{Env} = (Mem(Env(x)), (Env, Mem[Env(x) := Mem(Env(x)) + 1])) if Env(x) in R and Mem(Env(x)) in Z;
- [[x++]]^{Mem}_{Env} = (Err, (Env, Mem)) if Env(x) not in R or Mem(Env(x)) not in Z;
- [[++x]]^{Mem}_{Env} = (Mem(Env(x)) + 1, (Env, Mem[Env(x) := Mem(Env(x)) + 1])) if Env(x) in R and Mem(Env(x)) in Z;
- [[++x]]^{Mem}_{Env} = (Err, (Env, Mem)) if Env(x) not in R or Mem(Env(x)) not in Z.

- 2) We have [[!x]]^{Mem}_{Env} = (6, (Env, Mem)), then [[x++]]^{Mem}_{Env} = (6, (Env, [(r_x, 7)])) hence [[x + (x++)]]^{Mem}_{Env} = (12, (Env, [(r_x, 7)])). Furthermore, since [[!x]]^{Mem}_{Env}[(r_x, 7)] = (7, (Env, [(r_x, 7)])), then [[(x++) + !x]]^{Mem}_{Env} = (13, (Env, [(r_x, 7)])) and so [[x + (x++)]]^{Mem}_{Env} \neq [[(x++) + !x]]^{Mem}_{Env}.

- 3) If x is not a mutable variable or if the value stored in the memory for x is not an integer, then:

[[++x]]^{Mem}_{Env} = [[(x++) + 1]]^{Mem}_{Env} = (Err, (Env, Mem))

Otherwise, by definition, we have:

[[++x]]^{Mem}_{Env} = (Mem(Env(x)) + 1, (Env, \underline{Mem[Env(x) := Mem(Env(x)) + 1]})_{Mem_1})

Furthermore, and also by definition, [[x++]]^{Mem}_{Env} = (Mem(Env(x)), (Env, Mem_1)) and since [[1]]^{Mem_1}_{Env} = (1, (Env, Mem_1)), we obtain:

[[(x++) + 1]]^{Mem}_{Env} = (Mem(Env(x)) + 1, (Env, Mem_1))

and thus [[++x]]^{Mem}_{Env} = [[(x++) + 1]]^{Mem}_{Env}.

- 4) The extension of the relation is as follows:

(\text{Env}, \text{Mem}) \xrightarrow{x:=e}_{\mathbf{Lang}_1} (\text{Env}', \text{Mem}'[\text{Env}(x) := v])

if:

[[e]]^{\text{Mem}}_{\text{Env}} = (v, (\text{Env}', \text{Mem}')), v \neq \text{Err} \text{ and } x \in \mathbf{X}^{\text{ref}}_{\text{Env}}

(\text{Env}, \text{Mem}) \xrightarrow{x:+:=e}_{\mathbf{Lang}_1} (\text{Env}', \text{Mem}'[\text{Env}(x) := v + \text{Mem}(\text{Env}(x))])

if:

[[e]]^{\text{Mem}}_{\text{Env}} = (v, (\text{Env}', \text{Mem}')), v \in \mathbb{Z}, \text{Mem}(\text{Env}(x)) \in \mathbb{Z} \text{ and } x \in \mathbf{X}^{\text{ref}}_{\text{Env}}

- 5) By definition

[[++x]]^{\text{Mem}_0}_{\text{Env}_0} = \begin{pmatrix} \text{Mem}_0(\text{Env}_0(x)) + 1, \\ (\text{Env}_0, \underline{\text{Mem}_0[\text{Env}_0(x) := \text{Mem}_0(\text{Env}_0(x)) + 1]}) \\ = (3, \text{Env}_0, \underline{[(r_x, 3)]})_{\text{Mem}_0} \end{pmatrix}

and so:

```
(Env_0, Mem_0) \xrightarrow{x:=++x}_{\text{Lang}_1} (Env_0, Mem'_0[Env_0(x) := 3 + Mem_0(Env_0(x))])
```

We therefore obtain etat_1 = [((x, r_x)], Mem'_0[r_x := 3+2]) = [((x, r_x)], [(r_x, 5)]].

- 6) Let (Env_0, Mem_0) be an arbitrary state. If x \notin \mathbf{X}^{ref}_{Env_0}, or if the value stored in Mem_0 for x is not an integer, the three assignments lead to the same state (Env_0, Mem_0). Otherwise, by definition:

```
[[x++]]^{Mem_0}_{Env_0} = \left( \begin{array}{c} Mem_0(Env_0(x)), \\ (Env_0, Mem_0[Env_0(x) := Mem_0(Env_0(x)) + 1]) \end{array} \right) \text{Mem}_1 \\
[[++x]]^{Mem_0}_{Env_0} = \left( \begin{array}{c} Mem_0(Env_0(x)) + 1, \\ (Env_0, Mem_0[Env_0(x) := Mem_0(Env_0(x)) + 1]) \end{array} \right) \text{Mem}_2 \\
[[1]]^{Mem_0}_{Env_0} = (1, (Env_0, Mem_0))
```

and thus:

```
(Env_0, Mem_0) \xrightarrow{x:=x++}_{\text{Lang}_1} (Env_0, Mem_1[Env_0(x) := Mem_0(Env_0(x))]) \\
\phantom{(Env_0, Mem_0)} \xrightarrow{x:=x++}_{\text{Lang}_1} \underline{= Mem_0} \\
(Env_0, Mem_0) \xrightarrow{x:=++x}_{\text{Lang}_1} (Env_0, Mem_2[Env_0(x) := Mem_0(Env_0(x)) + 1]) \\
\phantom{(Env_0, Mem_0)} \xrightarrow{x:=++x}_{\text{Lang}_1} \underline{= Mem_2 = Mem_0[Env_0(x) := 1 + Mem_0(Env_0(x))]} \\
(Env_0, Mem_0) \xrightarrow{x:=+1}_{\text{Lang}_1} (Env_0, Mem_0[Env_0(x) := 1 + Mem_0(Env_0(x))]) \\
\phantom{(Env_0, Mem_0)} \xrightarrow{x:=+1}_{\text{Lang}_1} \underline{= Mem_2}
```

The two assignments x := ++x and x := + 1 thus result in the same state when they are executed from the same state, but this state is different to that which would be reached by executing the assignment x := x++, which does not modify the state in which it is executed in any way.
