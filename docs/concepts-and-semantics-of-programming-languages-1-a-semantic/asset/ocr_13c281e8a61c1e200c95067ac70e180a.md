+   b) Let $P(\langle e, \text{Env} \rangle \mapsto \langle e', \text{Env} \rangle)$ be the property:

$(\mathcal{N}_V(e'), \mathcal{N}_O(e')) \prec (\mathcal{N}_V(e), \mathcal{N}_O(e))$

and let us show, by induction, that this property is verified considering each rule in the inference system presented in Box 3.5.

+   – Rule $AS_1$: Since $\text{Env}(x) \in \mathbb{Z}$, we have $\mathcal{N}_V(x) = 1$ and $\mathcal{N}_V(\text{Env}(x)) = 0$ which concludes our proof.

+   – Rule $AS_2$: On the one hand, $\mathcal{N}_V(n_1 + n_2) = \mathcal{N}_V(n) = 0$ (since $n, n_1, n_2 \in \mathbb{Z}$) and, on the other hand, $\mathcal{N}_O(n) = \mathcal{N}_O(n_1 + n_2) - 1$, which concludes our proof.

+   – Rules $AS_3$ and $AS_4$: Similar reasoning to that used for rule $AS_2$.

+   – Rule $AS_5$: By induction hypothesis, we have:

$(\mathcal{N}_V(e'_1), \mathcal{N}_O(e'_1)) \prec (\mathcal{N}_V(e_1), \mathcal{N}_O(e_1))$

Additionally, either $\mathcal{N}_V(e'_1) < \mathcal{N}_V(e_1)$ and we obtain:

$\mathcal{N}_V(e'_1 + e_2) = \mathcal{N}_V(e'_1) + \mathcal{N}_V(e_2) < \mathcal{N}_V(e_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1 + e_2)$

which concludes our proof, or $\mathcal{N}_V(e'_1) = \mathcal{N}_V(e_1)$ and $\mathcal{N}_O(e'_1) < \mathcal{N}_O(e_1)$ and we obtain:

$\mathcal{N}_V(e'_1 + e_2) = \mathcal{N}_V(e'_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1) + \mathcal{N}_V(e_2) = \mathcal{N}_V(e_1 + e_2)$ and
$\mathcal{N}_O(e'_1 + e_2) = \mathcal{N}_O(e'_1) + \mathcal{N}_O(e_2) + 1 < \mathcal{N}_O(e_1) + \mathcal{N}_O(e_2) + 1
= \mathcal{N}_O(e_1 + e_2)$

which also brings us to our conclusion.

+   – Rules $AS_7$ and $AS_9$: Similar reasoning to that used for rule $AS_5$.

+   – Rule $AS_6$: By induction hypothesis, we have:

$(\mathcal{N}_V(e'_2), \mathcal{N}_O(e'_2)) \prec (\mathcal{N}_V(e_2), \mathcal{N}_O(e_2))$

Additionally, either $\mathcal{N}_V(e'_2) < \mathcal{N}_V(e_2)$ and we obtain:

$\mathcal{N}_V(n_1 + e'_2) = \mathcal{N}_V(e'_2) < \mathcal{N}_V(e_2) = \mathcal{N}_V(n_1 + e_2)$

which concludes our proof, or $\mathcal{N}_V(e'_2) = \mathcal{N}_V(e_2)$ and $\mathcal{N}_O(e'_2) < \mathcal{N}_O(e_2)$ and we obtain:

$\mathcal{N}_V(n_1 + e'_2) = \mathcal{N}_V(e'_2) = \mathcal{N}_V(e_2) = \mathcal{N}_V(n_1 + e_2)$
$\mathcal{N}_O(n_1 + e'_2) = \mathcal{N}_O(e'_2) + 1 < \mathcal{N}_O(e_2) + 1 = \mathcal{N}_O(n_1 + e_2)$
