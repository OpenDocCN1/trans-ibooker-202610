## Exercise 3.7

Small-step operational semantics. In this exercise, we consider the language $E_A$ defined in exercise 3.5 without the *let-in* construct (the operational semantics is defined using only rules $F_1$, $F_4$ and $F_{11}$ from Box 3.2 and Box 3.3). A small-step operational semantics can be defined to evaluate the expressions in $E_A$. The small-step semantics allows us to take into account the steps leading to the result of a computation at a level finer than that obtained by using the big-step semantics. A configuration is defined as a pair $\langle e, \text{Env} \rangle$, where $e \in E_A$ and $\text{Env} \in \mathbf{E}$. We define a configuration transition relation using the inference system presented in Box 3.5. Intuitively, $\langle e, \text{Env} \rangle \mapsto \langle e', \text{Env} \rangle$ means that the evaluation of expression $e$ in environment $\text{Env}$ leads us to evaluate the "simpler" expression $e'$ in the same environment. For example:

```
\langle 3 + (2 * 8), Env \rangle \mapsto \langle 3 + 16, Env \rangle
```

### Box 3.5. Small-step operational semantics

A transition sequence is a potentially infinite sequence of the form:

```
\langle e_0, Env \rangle \mapsto \langle e_1, Env \rangle \mapsto \langle e_2, Env \rangle \mapsto \cdots
```

such that for all \(i \ge 0\), there exists an inference tree for \(\langle e_i, Env \rangle \mapsto \langle e_{i+1}, Env \rangle\). A configuration is said to be *terminal* if it takes the form $\langle n, \text{Env} \rangle$ where $n \in \mathbb{Z}$ (as, in this case, the result of the evaluation is available). Relation $\xleftrightarrow{*}$ is then defined by $\langle e, \text{Env} \rangle \xleftrightarrow{*} n$ if, and only if, there is a transition sequence of finite positive or zero length:

$\langle e_0, \text{Env} \rangle \leftrightarrow \langle e_1, \text{Env} \rangle \leftrightarrow \langle e_2, \text{Env} \rangle \leftrightarrow \dots \leftrightarrow \langle e_m, \text{Env} \rangle$

such that configuration $\langle e_m, \text{Env} \rangle$ is terminal with $e_m = n$.
