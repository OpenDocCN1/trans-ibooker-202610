where the construction of \(\nabla_2\) is given as:

(F_{11}) \frac{\text{Env}_2 \vdash f \rightsquigaret F_{foo}}{} \quad (F_{11}) \frac{\text{Env}_2 \vdash x \rightsquigaret 2}{} \quad (F_{18}) \frac{\text{Env}_2 \vdash (fx) \rightsquigaret}{} \quad \vdots \\
(F_{18}) \frac{((f, F_{foo}) \oplus (x, 2) \oplus \text{Env} \vdash (fx) \rightsquigaret)}{\text{Env}_2}

This semantics can only be used to describe terminating executions. In other terms, Env \(\vdash e \rightsquigaret v\) expresses the fact that \(v\) is the value of \(e\) obtained by a finite evaluation tree, constructed using the inference rules presented in Box 3.2 and Box 3.3. There is no such evaluation tree for expression [36]. This semantics is called *big-step operational semantics*: Env \(\vdash e \rightsquigaret v\) does not describe the computation, only the result. To describe and reason using computations, including non-terminating computations, the semantics may be formalized as *small-step semantics* (or reduction semantics), a subject discussed at length in Chapter 4.

# 3.3.3. Recursive and mutually recursive functions

Two occurrences of \(e_f\) occur on either side of the symbol \(\vdash\) in rule \(F_{18}\), which concerns the application of a recursive function. At first glance, this may seem paradoxical: evaluating \(e_f\) on the right leads us to evaluate \(e_f\) on the left. As we saw in section 3.2.5, this question may be expressed directly by using rule \(F_{16}\) and binding \(f\) to the closure:

\(F = \langle x, e, (f, F) \oplus \text{Env} \rangle\)

Once again, \(F\) appears on both sides of the equals sign. The existence of value \(F\) can be proven using the mathematical theory of the least fixpoint (LFP), briefly presented in section 4.7.1; a more detailed description can be found in [JAU 16]. Taking this approach, rules \(F_{16}\), \(F_{17}\) and \(F_{18}\) can be condensed into two rules:

(N_{16}) \text{Env} \vdash \text{rec } f \ x = e \rightsquigaret \langle x, e, (f, F) \oplus \text{Env} \rangle \stackrel{\text{Env}_f}{=} F

(N_{17\_18}) \frac{\text{Env} \vdash e_1 \rightsquigaret \langle x, e, \text{Env}_f \rangle \quad \text{Env} \vdash e_2 \rightsquigaret v_2}{(x, v_2) \oplus \text{Env}_f \vdash e \rightsquigaret v} \text{Env} \vdash (e_1 e_2) \rightsquigaret v

Applications of recursive and non-recursive functions are based on the same mechanism. The LFP theory allows us to be sure that the evaluation of any expression with a finite number of recursive calls will terminate. Furthermore, the same theory can be used to prove that the two approaches define the same semantics for \(\text{Exp}_2\).
