
In the case where e is evaluated as true, we must prove the equality between two memory states Mem1 and Mem2, obtained in the following manner (note that the evaluation of expressions is deterministic):

```
[e]EnvMem = (true, Mem')    :
(Ck) <Mem1, while e do c>Env Mem2
(C6) <Mem, while e do c>Env Mem2

[e]EnvMem = (true, Mem')    :
(Ck) <Mem1, while e do c>Env Mem2
(C6) <Mem, while e do c>Env Mem2
```

The induction hypothesis over c establishes the equality Mem1 = Mem1. To deduce Mem2 = Mem2, an induction hypothesis over the instruction while e do c would also be needed but there is no way to get it.

Hence, reasoning by induction over the structure of programs is not sufficient to prove the determinism of program execution. In this case, instead of using the induction scheme generated by the inductive definition of Lang3, we need to use the induction scheme generated by the inference system defining the relation Mem, c Env Mem. This leads to reason by induction over executions instead of programs. A formal definition of this induction scheme is shown in Box 4.4.

```
if Mem M Env(x) = r R and [e]EnvMem = (v, Mem') V M
Mem, x := e Env Mem'[r := v]
and Mem M P(< Mem, skip > Env Mem)
and c1, c2 Lang3 Mem, Mem1, Mem2 M
(P(< Mem, c1 > Env Mem1) and P(< Mem1, c2 > Env Mem2))
< Mem, c1 ; c2 > Env Mem2)
and c1, c2 Lang3 Mem, Mem1, Mem2 M e Exp3
[e]EnvMem = (true, Mem1) and P(< Mem1, c1 > Env Mem2))
P(< Mem, if e then c1 else c2 > Env Mem2)
and c1, c2 Lang3 Mem, Mem1, Mem2 M e Exp3
[e]EnvMem = (false, Mem1) and P(< Mem1, c2 > Env Mem2))
P(< Mem, if e then c1 else c2 > Env Mem2)
and c Lang3 Mem, Mem1, Mem2, Mem3 M e Exp3
[e]EnvMem = (true, Mem1) and P(< Mem1, c > Env Mem2)
and P(< Mem2, while e do c > Env Mem3))
P(< Mem, while e do c > Env Mem3)
and c Lang3 Mem, Mem1 M e Exp3
[e]EnvMem = (true, Mem1) P(< Mem, while e do c > Env Mem1)
then c Lang3 Mem, Mem' M P(< Mem, c > Env Mem')
```

### Box 4.4. Reasoning scheme by structural induction over Mem, c Env Mem

Proof.– (This is the proof of proposition 4.1)

The property to prove \(P(\langle Mem, c \rangle \rightarrow_{Env} Mem_1)\) is defined by:

\(\forall Mem_2 \in \mathbf{M} \langle Mem, c \rangle \rightarrow_{Env} Mem_2 \Rightarrow Mem_1 = Mem_2\)

We prove the following points.

- The form of the tree for \(\langle Mem, x := e \rangle \rightarrow_{Env} Mem_1\) can only be:

\((C_1) \frac{Env(x) = r \in \mathbf{R} \quad \llbracket e \rrbracket_{Env}^{Mem} = (v, Mem') \in \mathbf{V} \times \mathbf{M}}{\langle Mem, x := e \rangle \rightarrow_{Env} Mem'[r := v]}\)

hence \(Mem_1 = Mem'[r := v]\). As the evaluation of expressions is deterministic, this is the only possible tree for \(\langle Mem, x := e \rangle \rightarrow_{Env} Mem_2\), so \(Mem_1 = Mem_2\).

- The form of the tree for \(\langle Mem, \mathbf{skip} \rangle \rightarrow_{Env} Mem_1\) can only be:

\((C_2) \frac{}{\langle Mem, \mathbf{skip} \rangle \rightarrow_{Env} Mem}\)

This is also the only possible tree for \(\langle Mem, \mathbf{skip} \rangle \rightarrow_{Env} Mem_2\), so \(Mem_1 = Mem = Mem_2\).

- The tree for \(\langle Mem, c_1 ; c_2 \rangle \rightarrow_{Env} Mem_1\) must take the form:

\((C_i) \vdots \quad (C_j) \vdots\)
\((C_3) \frac{\langle Mem, c_1 \rangle \rightarrow_{Env} Mem' \quad \langle Mem', c_2 \rangle \rightarrow_{Env} Mem_1}{\langle Mem, c_1 ; c_2 \rangle \rightarrow_{Env} Mem_1}\)

Similarly, the tree for \(\langle Mem, c_1 ; c_2 \rangle \rightarrow_{Env} Mem_2\) must take the form:

\((C_{i'}) \vdots \quad (C_{j'}) \vdots\)
\((C_3) \frac{\langle Mem, c_1 \rangle \rightarrow_{Env} Mem'' \quad \langle Mem'', c_2 \rangle \rightarrow_{Env} Mem_2}{\langle Mem, c_1 ; c_2 \rangle \rightarrow_{Env} Mem_2}\)

By induction hypothesis, we have \(P(\langle Mem, c_1 \rangle \rightarrow_{Env} Mem')\) and thus \(Mem' = Mem''\) and since we have, still from the induction hypothesis, \(P(\langle Mem', c_2 \rangle \rightarrow_{Env} Mem_1)\), we finally obtain \(Mem_1 = Mem_2\).

- When \(\llbracket e \rrbracket_{Env}^{Mem} = (true, Mem')\), the tree for \(\langle Mem, \mathbf{if} e \mathbf{then} c_1 \mathbf{else} c_2 \rangle \rightarrow_{Env} Mem_1\) must take the form:

\(\llbracket e \rrbracket_{Env}^{Mem} = (true, Mem') \quad (C_i) \vdots\)
\((C_4) \frac{}{\langle Mem, \mathbf{if} e \mathbf{then} c_1 \mathbf{else} c_2 \rangle \rightarrow_{Env} Mem_1}\)

Similarly, the tree for \(\langle \text{Mem}, \text{if } e \text{ then } c_1 \text{ else } c_2 \rangle \rightarrow_{\text{Env}} \text{Mem}_2\) must take the form:

```
\(\begin{array}{c}
\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{true}, \text{Mem}') \qquad (C_j) \qquad \vdots \\
\hline \\
(C_4) \quad \langle \text{Mem}, \text{if } e \text{ then } c_1 \text{ else } c_2 \rangle \rightarrow_{\text{Env}} \text{Mem}_2
\end{array}\)
```

By induction hypothesis, we have \(P(\langle \text{Mem}', c_1 \rangle \rightarrow_{\text{Env}} \text{Mem}_1)\) and thus \(\text{Mem}_1 = \text{Mem}_2\). The reasoning used when \(\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{false}, \text{Mem}')\) is similar.

- When \(\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{true}, \text{Mem}')\), the tree for \(\langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_1\) must take the form:

```
\(\begin{array}{c}
\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{true}, \text{Mem}') \qquad (C_i) \qquad \vdots \qquad (C_j) \qquad \vdots \\
\hline \\
(C_6) \quad \langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_1
\end{array}\)
```

Similarly, the tree for \(\langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_2\) must take the form:

```
\(\begin{array}{c}
\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{true}, \text{Mem}') \qquad (C_{i'}) \qquad \vdots \qquad (C_{j'}) \qquad \vdots \\
\hline \\
(C_6) \quad \langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_2
\end{array}\)
```

By induction hypothesis, we have \(P(\langle \text{Mem}', c \rangle \rightarrow_{\text{Env}} \text{Mem}'_1)\) and thus \(\text{Mem}'_1 = \text{Mem}'_2\), and since we have, here again by induction hypothesis, \(P(\langle \text{Mem}'_1, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_1)\), we finally obtain \(\text{Mem}_1 = \text{Mem}_2\).

- When \(\llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{false}, \text{Mem}')\), the tree for \(\langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_1\) must take the form:

```
\(\begin{array}{c}
(C_7) \quad \llbracket e \rrbracket_{\text{Env}}^{\text{Mem}} = (\text{false}, \text{Mem}') \\
\hline \\
\langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}'
\end{array}\)
```

This is also the only possible tree for \(\langle \text{Mem}, \text{while } e \text{ do } c \rangle \rightarrow_{\text{Env}} \text{Mem}_2\) and we therefore obtain \(\text{Mem}_1 = \text{Mem}' = \text{Mem}_2\).

## 4.5.4. Big steps versus small steps

Big-step and small-step operational semantics provide two ways to describe the execution of programs in \(\text{Lang}_3\). These descriptions are based on different formalisms, but are identical from a semantic perspective. As we can see from examples 4.3 and 4.4, the same finite execution of a program may be described by a tree, in the case of big-step semantics, or by a transition sequence in the case of small-step semantics; the results obtained using the two approaches are identical. We now formally prove this semantic equivalence. We begin by proving the following lemma.

LEMMA 4.1.- If \(\langle c_1 ; c_2, \text{Mem} \rangle \leftrightarrow^k_{\text{Env}} \text{Mem}''\), then there exists \(\text{Mem}' \in \mathbf{M}\) and two integers \(k_1\) and \(k_2\) such that \(\langle c_1, \text{Mem} \rangle \leftrightarrow^{k_1}_{\text{Env}} \text{Mem}'\) and \(\langle c_2, \text{Mem}' \rangle \leftrightarrow^{k_2}_{\text{Env}} \text{Mem}''\) with \(k = k_1 + k_2 + 1\).

PROOF.- We proceed by induction over \(k\). If \(k=0\), the property is trivial (since in this case the hypothesis \(\langle c_1 ; c_2, \text{Mem} \rangle \leftrightarrow^0_{\text{Env}} \text{Mem}\) cannot be verified, since \(\langle c_1 ; c_2, \text{Mem} \rangle\) is not a terminal configuration). If \(k = k_0 + 1\), two cases are possible:

- 1) If the transition sequence in the hypothesis is:

\(\langle c_1 ; c_2, \text{Mem} \rangle \leftrightarrow_{\text{Env}} \langle c'_1 ; c_2, \text{Mem}_1 \rangle \leftrightarrow_{\text{Env}} \dots \leftrightarrow_{\text{Env}} \langle \text{skip}, \text{Mem}'' \rangle\)
sequence of length \(k_0\)

with \(\langle c_1, \text{Mem} \rangle \leftrightarrow_{\text{Env}} \langle c'_1, \text{Mem}_1 \rangle\), then, by induction hypothesis, there exists two integers \(k'_1\) and \(k'_2\) such that \(\langle c'_1, \text{Mem}_1 \rangle \leftrightarrow^{k'_1}_{\text{Env}} \text{Mem}'_1\) and \(\langle c_2, \text{Mem}'_1 \rangle \leftrightarrow^{k'_2}_{\text{Env}} \text{Mem}''\) with \(k_0 = k'_1 + k'_2 + 1\). We construct the following sequence of length \(k'_1 + 1\):
\(\langle c_1, \text{Mem} \rangle \leftrightarrow_{\text{Env}} \langle c'_1, \text{Mem}_1 \rangle \leftrightarrow^{k'_1}_{\text{Env}} \text{Mem}'_1\)

which allows us to conclude with \(k_1 = k'_1 + 1\) and \(k_2 = k'_2\).

- 2) If the transition sequence in the hypothesis is:

\(\langle \text{skip} ; c_2, \text{Mem} \rangle \leftrightarrow_{\text{Env}} \langle c_2, \text{Mem} \rangle \leftrightarrow_{\text{Env}} \dots \leftrightarrow_{\text{Env}} \langle \text{skip}, \text{Mem}'' \rangle\)
sequence of length \(k_0\)

then we can conclude directly, with \(k_1 = 0\) and \(k_2 = k_0\). □

The equivalence between the big-step and small-step operational semantics can now be proved.

PROPOSITION 4.2.- \(\forall c \in \mathbf{Lang}_3 \forall \text{Env} \in \mathbf{E} \forall \text{Mem}_1, \text{Mem}_2 \in \mathbf{M}\):
\(\langle \text{Mem}_1, c \rangle \to^*_{\text{Env}} \text{Mem}_2 \Leftrightarrow \langle c, \text{Mem}_1 \rangle \leftrightarrow^*_{\text{Env}} \text{Mem}_2\)

PROOF.-

\((\rightarrow)\) We proceed by induction over \(\langle \text{Mem}_1, c \rangle \to^*_{\text{Env}} \text{Mem}_2\) (applying the induction scheme presented in Box 4.4).
