The generalization function proceeds in three stages. First, all variables present in the type to be generalized are fetched. Then the set of free variables in the environment is computed. The final step computes the list of variables present in the type, excluding those found in the environment. In OCaml, this filtering operation is carried out using the `List.filter` function from the standard library, which only retains those elements of a list that satisfy a given predicate. In Python, filtering is carried out by defining this predicate using the construct `lambda`.

Conversely, to type an expression which is an identifier, we need to generate a type from the type scheme bound to this identifier in the environment. This is done by the `instantiation` operation, which returns an `instance` of a scheme by “specializing” it. The formal definition of an instance uses the notion of `substitution`, presented as follows.

**DEFINITION 5.5.- Substitution:** _a substitution is a partial function from the set of type variables to the type algebra, which has a finite domain._ 
\([\alpha_1 \leftarrow \tau_1; \dots; \alpha_n \leftarrow \tau_n]\) denotes the substitution \(\theta\). The domain of \(\theta\), denoted as \(\text{dom}(\theta)\), is the set \(\{\alpha_1, \dots, \alpha_n\}\). The codomain of \(\theta\), denoted as \(\text{codom}(\theta)\), is the set \(\{\tau_1, \dots, \tau_n\}\). \(\theta\) associates the type \(\tau_i\) to the variable \(\alpha_i\).

_For the sake of simplicity, in what follows, we suppose that the variables of_ \(\text{dom}(\theta)\) _are all different and that:_

\(\text{dom}(\theta) \cap \bigcup_{\tau \in \text{codom}(\theta)} \mathcal{F}(\tau) = \emptyset\)

Substitutions naturally extend to a partial function from types to types, still with a finite domain, in the following manner:

\(\overline{\theta}(\text{int}) = \text{int} \quad \overline{\theta}(\text{bool}) = \text{bool}\)

\(\overline{\theta}(\alpha) = \begin{cases} \alpha(\alpha) & \text{if } \alpha \in \text{dom}(\theta) \\ \alpha & \text{else} \end{cases}\)

\(\overline{\theta}(\tau_1 \to \tau_2) = \overline{\theta}(\tau_1) \to \overline{\theta}(\tau_2)\)

From now on, we shall consider the substitution \(\theta\) and its extension \(\overline{\theta}\) to be one and the same and both shall be denoted as \(\theta\). The hypotheses used in defining a substitution guarantee that, for any type \(\tau\), \(\overline{\theta}(\overline{\theta}(\tau)) = \overline{\theta}(\tau)\) (in this case, \(\theta\) is said to be _idempotent_).
