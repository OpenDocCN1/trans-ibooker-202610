## 前言

自 20 世纪 40 年代以来，计算机程序在我们的生活中扮演着越来越核心的角色，因此这些程序的质量已成为一个至关重要的问题。编写高质量程序——即完成所需任务且高效、健壮、易于修改、易于扩展等的程序——是一项智力挑战性的任务，需要采用严谨的开发方法。然而，首要的是，创建此类程序取决于对所使用编程语言的深入了解，包括其语法和至关重要的语义，即程序执行时发生的情况。

对此语义的描述揭示了最基本的概念，包括值、引用、异常或对象。这些概念是编程语言理论的基础。掌握这些概念是区分资深程序员与初学者的关键。某些概念——如值的概念——在所有编程语言中都通用；其他概念——如函数的概念——在不同语言中的运作方式不同；最后，其他概念——如对象的概念——仅存在于某些语言中。计算机科学家常提及“编程范式”来考虑一类语言共享的概念集合，这些概念暗示了一种特定的编程风格：命令式、函数式、面向对象、逻辑式、并发式等。尽管如此，对概念本身的理解是必不可少的，因为多个范式可能在同一语言中交织。

关于任何特定语言的编程入门教材不难找到，许多出版书籍也涉及语言语义的基本概念。更为罕见的是像本卷这样的书籍，它们建立并考察概念与程序员日常使用的语言（如 C、C++、Ada、Java、OCaml 和 Python）中这些概念的实现之间的联系。作者在这些语言中提供了大量示例，阐明并赋予他们所提出的概念以生命力。他们提出了通用模型，例如第 2 卷中介绍的工具包，从而对不同概念提供统一视角；这使读者更容易理解流行编程语言中使用的结构，并便于比较。这部详尽详细的著作使读者理解这些概念，尤其是理解如何使用这些概念来创建高质量程序，从而在计算领域构建一个更安全、更可靠的未来。

## 前序

这部两卷本著作涉及编程领域。首先，它旨在使读者掌握函数式或命令式编程的基础，并深入了解涉及的模块和类机制。在我们看来，研究编程时语义方法最为合适，因为不同语言之间的语法差异影响有限。还将探讨由计算机和/或“智能”设备的物理特性决定的实际考量。两卷本将采用相同的方法，同时使用数学公式和内存状态图。借助本书，我们希望帮助读者理解编程语言参考手册中描述的结构的含义，并通过批判性审查，为推理和评估其自身程序的正确性奠定坚实基础。简而言之，我们的目标是促进安全可靠程序的开发。

第 1 卷从第 1 章开始介绍计算机，首先从物理层面——作为组件的集合——介绍，然后作为执行程序的工具。第 2 章对语言语义进行了直观的、循序渐进的介绍，旨在使读者熟悉这种编程方法。在第 3 章中，我们对该主题进行了详细讨论，并正式呈现了函数特性的执行语义。第 4 章延续同一主题，探讨命令式特性的执行语义。在这两章中，使用了清晰的数学框架来支持我们的介绍。此外，我们在这两章中引入的所有概念都在 Python 和 OCaml 中实现，以帮助初次接触相关语义概念的读者。两种情况下都提供了多个带有详细解答的练习。第 5 章关于类型化的主题，首先探讨用于检查程序的类型规则；接着我们介绍用于推导多态类型的算法及相关数学概念，均在两种语言中实现。最后，探讨了将类型化扩展到命令式特性的问题。在第 6 章中，我们


介绍主要的数据类型和模式匹配方法，使用以不同编程语言表达的多种示例。第 7 章侧重于低级编程特性：字节序、指针和内存管理；这些概念主要使用 C 和 C++ 来介绍。第 1 卷以使用异常进行错误处理的讨论结束，其语义在 OCaml 中呈现，Python、Java 和 C++ 中使用的异常管理机制也有描述（参见第 8 章）。

因此，第 1 卷旨在对编程的函数式和命令式特性进行广泛概述，从可以在数学上建模的概念到与计算机硬件配置本身相关的概念。第 2 卷侧重于模块化和面向对象编程，建立在第 1 卷奠定的基础之上，因为模块、类和对象本质上是组织函数式或命令式构造的手段。第 2 卷首先分析开发人员在软件架构工具方面的需求。基于这一研究，制定了一种称为 kit 的原创语义模型，共同呈现可以满足这些需求的模块和对象的所有特性。这些 kit 的语义以相当非正式的方式定义，因为该领域的研究尚未导致这组特性的数学模型，同时保持相对简单。从这个模型出发，我们考虑一组新出现的问题，其目的是指导语言的习得。随后，通过研究 Ada、OCaml 和 C 的模块系统来举例说明这种方法。最后，将使用相同的方法推导类和对象特性的语义模型，这将用于从统一视角呈现 Java、C++、OCaml 和 Python 中的类。

本作品面向相对广泛的读者群，从经验丰富的开发人员——他们将在语言语义方面找到有价值的补充信息——到仅编写过短程序的初学者。对于初学者，我们建议使用 OCaml 或 Python 中的实现来研究第 1 卷中描述的语义概念，以便于吸收。所有读者都可以从研究编程语言的参考手册中受益，同时在所提问题的指导下，将手册中给出的构造呈现方式与此处给出的方式进行比较，这些问题在第 2 卷中有提及。

请注意，我们在此不讨论数据处理的算法方面。但是，选择符合规范要求的算法和数据表示是程序开发的一个关键步骤。关于此主题已出版了许多优秀作品，我们鼓励读者进一步探究该主题。我们还建议使用所选编程语言提供的标准库。这些库包含许多不同算法的经过验证的实现，通常可以假设其正确。
