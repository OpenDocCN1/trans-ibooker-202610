# **前言**

无论你是否意识到，网络无处不在。网络影响着你与谁建立联系、你的信息获取渠道以及工作完成的方式。如果我告诉你，通过学习如何培育和维持某些网络，你将有机会解锁协作、解开压迫性系统并创造前所未有的价值，你会怎么想？如果我告诉你，你可以创建一个可持续的组织结构，这种结构减少了推力的需求，引入了更多的拉力和自主流动，你会怎么想？当你开始通过网络视角来观察和参与世界时，新的机遇、洞察和视角便会随之而来。

网络自古以来就存在。但直到最近，我们才能够利用多个领域——包括网络科学、社区建设、系统思维和组织发展——以及一系列协作软件工具，有意识地创建网络，不仅用于社会连接，还用于集体行动。网络不仅是我们自然形成的有机社会结构；它们可以被培育，以加速学习、激发协作并催化系统性变革。

网络是连接人或事物关系网。当它们旨在解决社会和环境问题时，被称为影响力网络。这种特殊类型的网络基于共同目的，将个人和组织聚集在一起进行学习和协调行动。影响力网络提供了一种变革性的合作方式，跨越那些常常阻碍我们的典型界限。它们为更公平、相互依存的世界提供了协作基础设施。作为一个强大且灵活的组织系统，能够跨越地区、组织和各种孤岛，影响力网络支撑着全球一些最引人注目和大规模的变革努力。

本书探讨如何培育影响力网络，使不同群体能够在组织内部和跨组织之间建立连接、协调和协作，从而共同完成单凭自身无法实现的工作。鉴于我们社会及所面临问题的日益复杂性，我们通过网络形成、成长和工作能力比以往任何时候都更加至关重要。

•••

这本书是为所有认识到比以往任何时候都更需要协作的人而写的，为那些正在解决任何个人或组织都无法独自解决的重大问题的人而写的，以及为那些寻找方法与多样化的利益相关者协作以应对我们时代棘手挑战的变革者而写的。

这本书也适合任何对协作网络感兴趣、参与或领导此类网络的人，包括那些协调、编织和引导网络的人；那些资助和支持网络的人；以及所有与他人协作以完成任务的人。协作网络可能被称为许多种名称：协会、联盟、联合、协作、集体影响力倡议、联合体等。无论它们叫什么，网络协作方法与许多层级组织中看到的命令与控制方法有着根本的不同。同样，引导网络所需的领导形式也与世界上仍然普遍存在的专制领导形式有很大不同。如果你正在支持或与一组参与者合作以解决复杂问题并推进共同目标，那么这本书就是为你写的。

我写这本书是因为我坚信影响力网络的力量，它有助于创造一个适合所有人发展的未来。网络方法在隔阂之间架起桥梁，优先基于信任的关系，分享领导力，并承认我们生活和工作中的固有相互联系。网络是让当今社会运作的组织系统，也能使我们未来蓬勃发展。
