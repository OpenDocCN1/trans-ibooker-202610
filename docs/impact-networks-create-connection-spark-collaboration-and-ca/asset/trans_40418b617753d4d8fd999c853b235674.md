## 设想未来

设想你想要实现的现实是关于梦想、分享你希望看到的东西的声音表达（通过对话、艺术和其他方式），以及共同创造一个未来的形象。共同设想未来能激发能量和创造力，帮助网络明确其目的。

Resonance Network 提供了如何利用引人注目的愿景将人们聚集在一起并为未来的工作规划方向的示例。Resonance Network 源自 NoVo 基金会的为期十年的 Move to End Violence 项目，已发展成为一个不断壮大的致力于建设一个没有暴力的世界的人群的集合。

在网络发展的初始阶段，领导者们认识到需要对他们想要创造的世界有一个清晰的图景。“为了生活在这些时代并融入其中，需要一种全新的存在方式，”他们写道。“创造新解决方案和可能性的艺术始于我们知道我们想要如何生活。”16

在一个为明确网络目的而召开的早期会议上，三十位领导者在波士顿聚集了三天，房间里充满了艺术作品、翻页纸和便利贴。在他们共度的时光里，他们探讨了一个深刻的问题，由政治战略家和禅宗僧侣 Norma Wong 提出：“在一个根植于相互依存、归属以及与他人和地球和谐共处的世界里，你对我们想要的一百年后的这个世界有何愿景？”为了从多个角度探讨这个问题，他们还提出了后续问题，例如“我们如何获取食物？”“我们与水的关系是什么？”“孩子们如何学习？”“我们如何让人们安全？”“孩子们如何出生？”以及“人们如何死亡？”

参与者开始感知他们希望看到的未来。他们开始构思，在翻页纸上作画，在彼此的愿景基础上构建，并突出共同的主题。随后，引导者向小组提问：“好吧，如果那是你在一百年后看到的，我们必须在五十年内处于什么位置才能实现这一百年愿景？”经过更多构思时间后，参与者被要求考虑一个缩短的时间范围：“为了实现这一五十年愿景，我们必须在二十五年内处于什么位置？”

随着每一步的推进，参与者被挑战将他们的愿景一步步拉近到当下，确定可能在长期产生变革性影响的潜在策略。逆向工作，人们被问到：“我们必须在两年内处于什么位置？”最后，“我们现在必须处于什么位置？”

“起初，人们对愿景的宏大以及我们将愿景写在纸上的大胆感到不知所措，”网络联合主任 Alexis Flanagan 回忆道。“然后人们变得充满活力。他们看到了我们现在需要做什么才能开始实现这一切。”17 会议结束时，参与者退后一步，审视他们所做的工作。网络存在的理由变得清晰：通过建立一个根植于深厚关系、充满活力的社区以及与我们星球的联系的世界，来转变暴力的根源。

## 制定集体目的

Santa Cruz Mountains Stewardship Network 的形成提供了一个关于一群不同利益相关者如何定义集体目的的示例。当十多个组织最初聚集在一起，思考如何更有效地合作时，关于网络为何成立存在重大疑问。人们担心存在隐藏议程，没有单一议题能引起每个人的兴趣，而参会的组织有着截然不同的短期优先事项。

在成员能够就其集体目的达成一致之前，他们首先需要明确“管理”一词的含义。定义关键术语是新网络常见的早期任务——只有在就管理意味着什么达成一致后，参与者才能开始使其付诸行动。

他们还需要对系统形成共同理解：影响该地区管理的历史和现实因素。他们完成了历史分析，通过情景规划审视外部趋势和力量，并确定希望和担忧。

通过多次丰富的讨论，参与者开始找到共同点。大多数人同意，有效的管理需要多方面、马赛克式的方法。他们认识到开发和气候变化带来的威胁。而且几乎每个人都同意，加强联系和协作关系将有利于他们的工作和该地区。虽然人们对如何最有效地管理土地存在很多分歧，但人们对为什么有效管理很重要也有很多共识。

最终，参与者准备好制定和完善他们的集体目的。作为引导者，我们要求他们通过完成短语“我们如何……”来阐述网络的目的。我们随后根据他们分享的内容提供了一个初步版本，供他们完善。我们发现，让大群体改进一份草案声明，比让他们从零开始构建一份声明更容易。

参与者在小组中辩论草案并提出改进建议。与其进行小组文字润色练习——这很少是时间的有效利用——一支志愿者团队同意在休息期间根据网络的反馈完善声明。当天晚些时候，该团队分享了他们提出的宗旨：“培育一个充满韧性、充满活力的地区，让人类和自然系统世代繁荣。”使用第十章中概述的基于同意的决策过程，所有参与者都同意正式采纳该句子作为网络的目的，并理解如果必要，网络可以在未来任何时候重新审视它。在接下来的六个月里，这一目的演变成一份更完整的网络章程，其中包含原则、参与协议和高层级优先事项，该章程在网络第三次会议上由网络的二十一位成员批准（网络章程将在本章后面更详细地解释）。18

## 定义共同原则

价值观是网络认为重要的基本信念，而原则则是相应的指导决策和行动的准则。原则使价值观具体化。因此，原则是对网络所代表的内容以及它将在世界中如何展现的最终表述。当集体创建时，它们提供了一个强大的基石，使参与者能够要求自己和彼此对其言行负责，以共同推进网络的目的。拥有明确的原则意味着“随着条件的改变，存在对什么重要的共同理解，有一种方式可以回到共同的实践和行为”，*Emergent Strategy* 的作者 adrienne maree brown 写道。19
