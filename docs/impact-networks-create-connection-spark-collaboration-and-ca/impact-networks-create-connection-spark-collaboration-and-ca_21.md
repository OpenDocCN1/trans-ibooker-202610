**Berrett-Koehler** 是一家独立出版商，致力于一个雄心勃勃的使命：*连接人与思想，创造一个对所有人都有效运作的世界。*

我们的出版物涵盖多种格式，包括印刷、数字、音频和视频。我们还提供在线资源、培训和聚会。我们将继续扩展我们的产品和服务以推进我们的使命。

我们相信，世界问题的解决方案将来自我们所有人，在各个层面共同努力：在我们的社会、我们的组织和我们自己的生活中。我们的出版物和资源为创造一个更公正、更公平、更可持续的社会提供了途径。它们帮助人们使自己的组织更具人性化、民主化、多元化和有效性（我们认为这之间没有任何矛盾）。它们指导人们在自己的生活中创造积极变化，并使个人实践与对更好世界的愿望保持一致。

我们力求身体力行，这就是我们所说的“BK 之道”。这种方法的核心是*管理*，即对为所有利益相关者群体谋福利而管理公司承担深切责任，包括作者、客户、员工、投资者、服务提供商、销售合作伙伴以及我们周围的社区和环境。我们所做的一切都围绕着管理以及我们的其他核心价值观*质量、合作、包容*和*可持续性*构建。

这就是为什么 Berrett-Koehler 是第一家既是 B 机构（严格认证）又是公益公司（营利性法律地位）的图书出版公司，这两者共同要求我们遵守最高的企业、社会和环境绩效标准。这也是为什么我们建立了许多开创性实践（您可以在 www.bkconnection.com 了解），包括 Berrett-Koehler 宪法、BK 作者权利与责任宣言，以及我们独特的作者日。

我们感谢我们的读者、作者和其他朋友对我们使命的支持。我们请您在 www.bkconnection.com/impact 与我们分享 BK 出版物和资源如何在您的生活、组织和社区中产生影响的例子。
