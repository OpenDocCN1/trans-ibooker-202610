
# 第 8 章  

## 会计部门中的大数据

### 学习目标

*   区分适用于会计操作的大数据概念。
*   识别数据分析如何在会计部门中应用。

### 简介

既然您已对大数据有了良好的理解，该如何将其专门应用于会计概念呢？会计师熟悉访问和处理结构化会计数据，例如以下内容：

*   账户名称
*   账户总账代码
*   交易金额
*   供应商名称
*   SKU 编号

会计师通常不熟悉包含在备忘字段、传统报表或数据库未访问的杂项字段，或以非结构化格式构建数据的系统（如电子邮件）中的非结构化数据。
