
另一个促进 Excel 长盛不衰的关键特性是会计师的经验。从 Lotus 到 Excel 的过渡有一些缺点。软件中一些最成功的变革是那些允许个人在新旧两种模式下操作的变革。过渡时间可能会更长，但生产力和挫败感水平表现更好。

在雇佣员工方面，还有一个非常重要的概念。Excel 是一个标准。当求职者从一家将财务分析工具放在不同商业智能平台的公司跳槽时，他或她实际上是倒退了一步。一个人也可能因为财务规划与分析限制了其专业知识而限制了自己的流动性。当程序员专精于某种编程语言时，也面临着同样的问题。

## 会计的大数据问题 [^10]

根据 [CFO.com](http://CFO.com) 的报道，除非会计师和财务高管为提供或交付数据产品和服务的公司工作，否则他们可能不会成为大数据趋势的参与者，因为他们中的大多数人几乎只接受过结构化数据（适合放入表格、Excel 电子表格、数据库等的数据）的培训，而非非结构化数据。

请记住，非结构化数据代表了现有数据中最大的部分，并且很可能产生最大的效益。

非结构化数据的一个例子来自 Trax —— 一家总部位于新加坡的公司，提供图像识别应用程序，从零售店货架照片中收集数据。这些照片使组织能够更好地管理库存。

> 在最近接受 PYMNTS 采访时，Trax 全球零售业务总经理 David Gottlieb 讨论了该公司对数字化实体零售商的愿景，包括如何利用图像识别和人工智能 (AI) 来简化货架管理。
>
> Gottlieb 解释说，在 Trax 和其他同类公司提供解决方案之前，货架管理无法频繁进行，主要是因为它需要人工且劳动密集型的流程。
>
> “在一天中的某个时刻，你会让一名店员穿梭于店内寻找空缺，然后可能用扫描枪扫描它们，”他解释道。这通常会消耗大量时间，特别是对于拥有大型门店或广泛库存的零售商而言。
>
> Trax 的系统旨在通过使用摄像头进行实时货架监控，减少执行货架管理任务所需的时间。
>
> 它依靠基于 AI 的图像识别来识别库存变化，帮助确保零售商准确掌握有哪些产品可供销售或需要补货。[^11]
>
> 然而，这些图像的用途不仅限于货架库存信息。Gottlieb 解释说，这些图片还被存储下来，提供大量的客户和产品信息，随后可用于分析目的。
>
> “我们提供的不仅仅是图像识别技术，”他说。“我们在多个层面存储数据——从图像生成的原始数据、关键绩效指标数据，再到元数据、主数据。”

非结构化数据的另一个例子可以在企业发布的以下文本来源中找到：

*   新闻稿

## 大数据术语

与任何新领域一样，大数据有一些必须掌握的术语。以下列表并非旨在面面俱到，但它列出了许多与大数据、分析和商业智能相关的常用术语。

**人工智能 (AI)。** 指在机器中模拟人类智能，使其被编程为像人类一样思考并模仿人类行为。该术语也可应用于表现出与人类思维相关特征的任何机器，例如学习和解决问题。[^12]

**商业智能 (BI)。** 数据、技术、分析和人类知识的整合，以优化商业决策并最终推动企业的成功。BI 项目通常将企业数据仓库与 BI 平台或工具集相结合，将数据转化为可用、可操作的商业信息。[^13]

**数据分析 (DA)。** 以从中得出结论为目的检查原始数据的科学。DA 被广泛应用于许多行业，使公司和组织能够做出更好的商业决策，在科学领域用于验证或反驳现有的模型或理论。[^14]

**云计算。** 一种提供信息技术服务的模型，其中资源通过基于 Web 的工具和应用程序从互联网检索，而不是直接连接到服务器。数据和软件包存储在服务器中。然而，云计算允许只要电子设备能访问网络就能访问信息。这种系统允许员工远程工作。[^15]

**仪表板。** 一种 BI 软件界面，提供预配置或客户自定义的指标、统计数据、洞察和当前数据的可视化。它允许 BI 软件的最终用户和高级用户即时查看业务或 DA 的实时性能状态。[^16]

**数据湖。** 一个集中式存储库，允许您按任何规模存储所有结构化和非结构化数据。您可以按原样存储数据，无需先对数据进行结构化，即可运行不同类型的分析——从仪表板和可视化到大数据处理、实时分析和机器学习，以指导更好的决策。[^17]

**数据挖掘。** 在大量计算机化数据中搜索以发现有用模式或趋势的做法。[^18]

**数据科学家。** 擅长分析数据（特别是大量数据）的员工或 BI 顾问，帮助企业获得竞争优势。[^19]

**数据可视化。** 以图表或图形格式呈现数据。

**深度学习 (DL)。** 一种 AI 功能，模仿人脑处理数据和创建模式以用于决策的工作方式。DL 是 AI 中机器学习的一个子集，拥有能够从非结构化或未标记数据中无监督学习的网络。也称为*深度神经学习*或*深度神经网络*。[^20]

**Hadoop。** 一个免费的、基于 Java 的编程框架，支持在分布式计算环境中处理大型数据集。它是 Apache 项目的一部分，由 Apache 软件基金会赞助。[^21]

**OLAP。** (联机分析处理)。一种用于数据发现的强大技术，包括无限制报表查看、复杂分析计算和预测性“假设”场景（预算、预测）规划功能。[^22]

**机器学习。** 一种自动化分析模型构建的数据分析方法。它是 AI 的一个分支，基于这样的理念：系统可以从数据中学习、识别模式，并在极少人工干预的情况下做出决策。[^23]

**预测分析。** 从现有数据集中提取信息以确定模式并预测未来结果和趋势的做法。预测分析不会告诉你未来会发生什么。它以可接受的可靠性水平预测未来可能发生的事情，并包括假设场景和风险评估。[^24]
