

# 商业中的大数据应用

## Red Roof Inn：天气数据与航班取消

恶劣天气会导致人们减少出行，从而减少过夜住宿的购买。然而，一些连锁酒店正利用恶劣天气为己所用。Red Roof Inn 发现了恶劣天气、航班取消和滞留乘客之间的联系。当航班因恶劣天气取消时，乘客就变成了潜在且急需住宿的客户。Red Roof Inn 获取现成的航班取消和天气信息，并利用这些信息增加预订量。公司构建了一个算法，按酒店和航空航站楼区域进行排序。该算法可用于向乘客推送酒店优惠信息。考虑到旅客会通过手机搜索酒店，Red Roof Inn 利用多个移动平台专门针对搜索住宿的旅客，并使他们预订酒店变得尽可能简单。

考虑大数据的影响。请注意，每天有 1% 到 3% 的航班被取消，这意味着每天有 150 到 500 个航班（换句话说，25,000 到 90,000 名滞留乘客）。通过使用大数据定位这些乘客，Red Roof Inn 成功将其业务从 2013 年到 2014 年增长了 10%。^([24](#c07.xhtml#c07-fn-24))

## 披萨连锁店：天气与停电

披萨连锁店也利用天气来定位潜在客户。一家披萨连锁店根据恶劣天气和停电情况发放优惠券。该企业了解到停电时人们无法做饭，因此通过移动广告活动针对这些人群，吸引他们购买披萨。该定向营销活动的响应率为 20%，高于全国平均水平。^([25](#c07.xhtml#c07-fn-25))

## John Deere：田间传感器

农业先驱 John Deere 正利用大数据在行业中掀起波澜。John Deere Field Connect 系统监测湿度水平，并通过无线连接将信息发送给农民查看。这些天然传感器还测量“空气和土壤温度、风速、湿度、太阳辐射、降水量和叶面湿度”。

这些信息将帮助农民了解作物何时接近理想的水分水平。有了这些数据，农场主可以做出灌溉系统决策。模式数据还可以显示季节如何影响水分保持。^([26](#c07.xhtml#c07-fn-26))

## EMI：社交网络

唱片公司 EMI 利用大数据预测未来的音乐趋势。EMI 密切关注音乐购买者消费新发行音乐的方式。例如，EMI 查看音乐在社交媒体网络上被引用的情况，以及在流媒体服务上被播放的情况。公司随后分析数据，按位置、人口统计特征和亚文化进行细分，协助音乐分销商投放精准广告，并以高置信度预测产品需求。这一概念也适用于其他零售商，他们也可以聚合来自社交网络的信息流，以建立对新产品将如何被新市场或现有市场接受的理解，甚至了解他们的产品和公司声誉在公众中的认知度。^([27](#c07.xhtml#c07-fn-27))

## Target：婴儿礼物清单与怀孕预测

一个值得特别关注的零售大数据案例是 Target 的怀孕预测。Target 将婴儿礼物清单信息与其 Guest ID 计划相关联，以辨别顾客何时可能怀孕。Target 的 Guest ID 是一个唯一的客户 ID，用于追踪购买历史、信用卡使用情况、调查回复、客户支持互动、邮件点击率和网站访问记录。该组织用人口统计信息补充购物者活动，如年龄、种族、教育程度、婚姻状况、子女数量、估计薪资、工作经历和生活事件（如离婚、申请破产或搬家）。

通过查看在婴儿礼物清单上登记的顾客及其 Guest ID 的购买历史，零售商可以跟踪顾客在整个怀孕期间购物倾向的变化。例如，在最初的 20 周内，孕妇开始购买钙、镁和锌等补充剂。在第二孕期，她们开始购买大码裤子和更多的洗手液、无香润肤露、无香清洁剂和大包装棉球。总的来说，零售商可以精准定位出孕妇在整个怀孕期间购买的约 25 种商品。

通过将这些购买习惯应用于所有顾客，Target 能够在顾客未直接通知 Target 或任何其他人的情况下，识别出哪些顾客怀孕了。Target 随后利用怀孕预测模型预测每位购物者怀孕的可能性。有了这个模型，Target 为顾客分配了一个评分，以评估其怀孕的可能性。这些数字被用来识别特定的孕妇群体，然后针对怀孕的每个阶段向她们发送有针对性的促销活动。这些顾客不仅购买婴儿用品，她们的整体购买行为都有所提升。通过使用大数据，Target 的收入从 2002 年的 440 亿美元增加到 2010 年的 670 亿美元。尽管该零售商未公开评论该计划，但 Target 的 CEO 曾向金融专家表示，公司“加大对吸引特定客户群体（如妈妈和婴儿）的商品和品类的关注”极大地促进了零售商的成功。^([28](#c07.xhtml#c07-fn-28))

尽管必须审视客户安全和广告方面的考量，但这对零售商来说是一个重要的教训。

## Morgan Stanley：投资组合分析

Morgan Stanley 从 Target 的经验中吸取教训，并试图效仿。“我们倾倒了我们能获取的每一个日志，包括网络日志和所有不同的数据库日志，将它们放入 Hadoop 并运行基于时间的相关性分析，”企业信息管理执行总监 Gary Bhattacharjee 说道。^([29](#c07.xhtml#c07-fn-29)) 该公司随后能够看到市场活动，以及它如何与网络问题和数据库读写问题相对应。

当 Morgan 尝试进行一些投资组合分析时，发现传统数据库和网格计算无法扩展以应对其数据科学家所需的海量信息。IT 部门使用 Hadoop 连接了 15 台旧服务器。与处理较小的数据集不同，Hadoop 允许银行从多个角度处理海量信息。它允许 Morgan Stanley 将廉价基础设施引入框架，安装 Hadoop 并让它运行。公司现在拥有一个用于投资组合分析的高度可扩展的解决方案。

## Ford Fusion：汽车数据生成

Ford 拥有一个庞大、碎片化的环境来获取大数据。此外，Ford 在创造更多联网机器（包括汽车）方面投入巨资。例如，Ford 目前的混合动力 Fusion 车型每小时产生高达 25 GB 的数据。只要他们能从信息中提取知识，这些信息就是 Ford 的潜在金矿。
