# 第9章：大数据伦理与隐私

## 学习目标

- 识别大数据如何在无意造成伤害的情况下被滥用。
- 认识到每个人如何在大数据系统中被追踪和记录。
- 回顾大规模视频监控工具以及在全国范围内追踪个人能力的影响。

## 简介

大数据最大的弊端之一是可能侵犯个人隐私。在本章中，我们将探讨大数据被用于可能伤害个人或从隐私角度构成侵扰的方式的示例。每个组织评估大数据如何影响其伦理政策非常重要。

## 伦理问题

贯穿全文，我们考虑了许多不同的大数据示例。不幸的是，关于数据的使用、积累或共享的伦理影响，并未跟上大数据量剧增的步伐。请考虑以下情况：

- 数据所有者将数据推送给提供商（即使已获得访问权限），但数据所有者并不知情。
- 用户知晓数据但未授权访问，如个人照片。
- 用户知晓数据但从未想过会用于此类目的，例如：
  - 保险和健康信息，或
  - 短信状态（尤其是在发生事故时）。
- 从互联网冲浪模式中收集的数据。
- 嵌入其他对象（如视频、音频或照片）中的数据。
- 个人生成的大数据所有权，这些数据成为更大数据库的一部分。
- 你或你的公司对员工或应聘者做出的假设和结论是否得当？
- 你的组织拥有哪些未使用的非结构化大数据，但如果其他人获得访问权限，他们却可以加以利用？（想想电子邮件。）

## 知识检验

1. 伦理政策在涉及大数据方面的现状如何？
   1. 伦理政策现状良好。
   2. 伦理政策未跟上大数据爆发式增长的步伐。
   3. 伦理政策只需微调即可纳入大数据内容。
   4. 大数据政策已由IT政策涵盖。

## 伦理影响[¹](#c09.xhtml#c09-fn-01)

致力于欧洲数字未来的欧盟委员会于2019年4月收到了人工智能高级别专家组提交的报告，该报告提出了可信赖人工智能的伦理准则。以下准则列出了可信赖AI的三大主题：

1. **合法** — 遵守所有适用的法律法规
2. **合乎伦理** — 尊重伦理原则和价值观
3. **稳健** — 既从技术视角出发，又考虑其社会环境

此外，准则还强调了AI系统被视为可信赖所需满足的七项关键要求。

1. **人类能动性与监督**：AI系统应赋能人类，使其能够做出知情决策并维护其基本权利。同时，必须确保适当的监督机制，这可通过人在回路中、人在回路上、人在指挥中的方法来实现。
2. **技术稳健性与安全性**：AI系统需要具有弹性和安全性。它们需要安全（确保在出现问题时有备选方案），并需要准确、可靠、可复现。这也是确保将非故意伤害最小化和预防的唯一途径。
3. **隐私与数据治理**：除了确保充分尊重隐私和数据保护外，还必须确保适当的数据治理机制，兼顾数据质量与完整性，并确保合法的数据访问。
4. **透明度**：数据、系统和AI商业模式应保持透明。可追溯机制有助于实现这一点。此外，AI系统及其决策应以适应相关利益相关者的方式进行解释。人类需知晓自己正在与AI系统交互，并必须被告知系统的能力与局限性。
5. **多样性、非歧视与公平性**：必须避免不公平的偏见，因为这可能产生多重负面影响——从弱势群体的边缘化，到偏见与歧视的加剧。促进多样性，AI系统应面向所有人可及，无论是否有残疾，并在其整个生命周期中让相关利益相关者参与。
6. **社会与环境福祉**：AI系统应造福全人类，包括后代。因此，必须确保其可持续且环保。此外，它们应考虑环境（包括其他生物），并仔细考量其社会影响。
7. **问责制**：应建立机制，确保对AI系统及其结果负责且可被问责。可审计性（即对算法、数据和设计过程进行评估的能力）在此发挥关键作用，尤其是在关键应用中。此外，必须确保充分且可获得的补救措施。
