## 解答

### 第 1 章

#### 练习题解答

1. 大数据包含大容量、高速度和多样性的信息资产，这些资产需要具有成本效益的创新信息处理形式，以增强洞察力和决策能力。大数据可分为结构化数据、非结构化数据和流数据等领域。

2. 描述性、诊断性、预测性和规范性。

3. Hadoop 是一个免费的、基于 Java 的编程框架，支持在分布式计算环境中处理大型数据集。它是 Apache 软件基金会赞助的 Apache 项目的一部分。

4. 数据科学家是指擅长分析数据（特别是大量数据）以帮助企业获得竞争优势的员工或商业智能顾问。

#### 知识检验解答

1. 
   1. 错误。大数据适用于任何组织，而不仅仅是跨国公司。
   2. 正确。结构化数据、非结构化数据和流数据。
   3. 错误。大数据超越了 ERP 系统。它包含所有数据：结构化数据、非结构化数据和流数据。
   4. 错误。大数据指的是一种数据类型。串行处理与大数据无关，但大规模并行处理相关。

2. 
   1. 错误。Instagram 用户每天每分钟分享约 55,000 张照片，而非 25,000 张。
   2. 正确。Instagram 用户每天每分钟分享约 55,000 张照片。
   3. 错误。Instagram 用户每天每分钟分享约 55,000 张照片，而非 75,000 张。
   4. 错误。Instagram 用户每天每分钟分享约 55,000 张照片，而非 100,000 张。

3. 
   1. 错误。1 PB 可存放 5×1000 亿页。1 PB 是 1 后面跟 15 个零，约相当于 5000 亿页标准文本。
   2. 正确。1 PB 是 1 后面跟 15 个零，约相当于 5000 亿页标准文本。
   3. 错误。1 PB 是 1 后面跟 15 个零，可存放 5000 亿页标准打印文本，而非 9000 亿页。
   4. 错误。1 PB 是 1 后面跟 15 个零，可存放 5000 亿页标准打印文本，而非 7500 亿页。

4. 
   1. 正确。大数据决策更明智、更快速、更准确。
   2. 错误。大数据决策并非更慢。它更快速、更明智、更准确。
   3. 错误。大数据决策并非更慢或更透明。它更快速、更明智、更准确。
   4. 错误。大数据更明智、更快速、更准确，而非速度相同且更结构化。
