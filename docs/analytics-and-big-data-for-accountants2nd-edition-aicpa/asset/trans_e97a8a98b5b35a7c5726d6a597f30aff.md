
# 会计与技术的历史

1494年，弗拉·卢卡·帕乔利（他在数学、神学、建筑学、博弈论、军事战略和商业等领域著书立说）出版了*《算术、几何、比例与比例性大全》*（*Summa de Arithmetica, Geometria, Proportioni et Proportionalita*，即《算术、几何、比例与比例性汇编*）。书中有一节包含复式记账论述，这一节使帕乔利在历史上确立了“会计之父”的地位，尽管他并未发明会计实务——而是描述了复式记账流程，即威尼斯记账法。^([4](#c02.xhtml#c02-fn-04))

他的系统包含了我们今天所知会计循环的大部分内容。他发表了关于日记账和总账用法的信息，并描述了借方和贷方的记录过程，包括借方必须等于贷方这一事实。“正如帕乔利所言，这是威尼斯记账法中最重要的注意事项：‘所有债权人必须出现在总账的右侧，所有债务人出现在左侧。总账中的所有分录必须是复式分录——即如果你记录一个债权人，就必须记录一个债务人。’”^([5](#c02.xhtml#c02-fn-05))

他的总账包括资产（包含应收账款）、存货、负债、资本、收入和费用账户。《大全》最终被翻译成德语、俄语、荷兰语和英语。

帕乔利的系统是当今仍在使用的会计系统的基础。从根本上说，尽管经历了工业革命和公司制的兴起，但变化不大。然而，美国会计史上的一个关键事件发生在1913年，当时第16条修正案获得批准。该修正案要求所有在美国工作的个人缴纳联邦所得税。在起步阶段，所得税和公司税鲜为人知且遭到强烈抵制。结果，大多数公司和个人干脆不申报，或申报错误。

几年后的1917年，美联储发布了*《统一会计》*，该文件试图为财务报表的组织方式设定行业标准，既用于报税也用于财务报告。

## 计算机器

计算机器的历史几乎与记账历史一样悠久。第一台计算机器——算盘，早在公元前2400年就已投入使用。

17世纪的早期计算器为几个世纪后发生的计算革命奠定了基础。制表机自19世纪以来一直被会计行业使用。以下是Gizmodo图片时间线上的几个关键日期：^([6](#c02.xhtml#c02-fn-06))

*   1642年：帕斯卡林或帕斯卡计算器，由布莱兹·帕斯卡发明。它能对两个数进行加、减、乘、除运算。
*   1820年：算术机，第一台批量生产的机械计算器，由查尔斯·泽维尔·托马斯·德·科尔马发明。
*   19世纪：差分机，第一台机械计算机，由查尔斯·巴贝奇在19世纪初发明。
*   1948年：手摇计算器Curta，由库尔特·赫兹施塔克发明。Type II型于1954年推出，生产至1972年。
*   1971年：夏普公司发明了袖珍计算器。

## 计算机

现代计算机出现于20世纪。它通过提高速度、实现自动化和引入电子表格，彻底改变了会计行业。虽然我们大多数人亲历了这一演变过程，但以下列出了关键日期的时间线：

*   1911年：IBM成立。
*   1938年：Z1计算机诞生，发明者康拉德·楚泽。它是一台使用穿孔带的二进制数字计算机。
*   1947年：威廉·肖克利在贝尔实验室发明了晶体管。
*   1958年：高级研究计划局和NASA成立。杰克·基尔比和罗伯特·诺伊斯制造出第一块集成电路，即硅芯片。
*   1971年：雷·汤姆林森发明了电子邮件。詹姆斯·费加森开发了液晶显示器（LCD）。大卫·诺布尔与IBM共同创造了软盘。因其柔韧性而昵称为“floppy”（软盘）。
*   1973年：罗伯特·梅特卡夫和大卫·博格斯开发了以太网，一种局域网（LAN）协议。微型计算机施乐Alto是个人计算机发展史上的里程碑。
*   1977年：苹果公司的Apple II（首台具有彩色图形的个人电脑）发布。沃德·克里斯滕森编写了“MODEM”程序，允许两台微型计算机通过电话线交换文件。
*   1980年：IBM聘请保罗·艾伦和比尔·盖茨为新PC开发操作系统。他们购买了西雅图电脑产品公司开发的一个简单操作系统的版权，并以此为模板开发了DOS。

## 互联网

鉴于互联网已成为日常生活不可或缺的一部分，很难相信它的历史不足50年。1969年，美国国防部建立了高级研究计划局网络（ARPANET），旨在创建一个能抵御任何灾难的计算机网络。它成为了当今互联网的第一块基石。

1990年，蒂姆·伯纳斯-李和罗伯特·卡约为互联网和万维网提出了HTML超文本协议。同年，第一家商业互联网拨号接入服务商上线。第二年，万维网向公众开放。

互联网发展史上的几个更多关键日期：

*   1994年：万维网联盟由蒂姆·伯纳斯-李创立，旨在协助万维网通用协议的发展。雅虎成立。
*   1995年：Java推出。杰夫·贝佐斯推出[Amazon.com](http://Amazon.com)。皮埃尔·奥米迪亚尔创立eBay。杰克·史密斯和萨比尔·巴蒂亚创建Hotmail。
*   1998年：谢尔盖·布林和拉里·佩奇创立谷歌。彼得·蒂尔和马克斯·列夫钦创立PayPal。苹果PowerBook G3发布。
*   2001年：比尔·盖茨推出Xbox。Windows XP发布。
*   2005年：蓝光光盘推出。YouTube上线。
*   2009年：Windows 7发布。
*   2012年：微软Windows 8和微软Surface发布。电子商务销售额突破1万亿美元。
*   2015年：微软Windows 10发布。

## 云计算

云计算是互联网应用最新的发展之一。数据和程序不再维护在单个计算机或本地服务器上，现在可以在“云端”访问。“云”一词创于1997年，指代共享数据服务和第三方访问的概念。云计算的其他近期发展包括2002年Amazon Web Services的成立、2005年应用服务提供商（ASP）的出现以及2006年Hadoop的诞生。

2018/2019年值得关注的主要趋势如下：

*   IT基础设施持续向云托管服务迁移。
*   混合云的兴起。
*   强调集成和工作流。
*   基于云的商业智能。^([7](#c02.xhtml#c02-fn-07))
*   边缘计算。

## 物联网

物联网（IoT）指的是“能够收集和交换数据的互联网连接对象网络。”^([8](#c02.xhtml#c02-fn-08)) 每个对象都有唯一标识符，并具备机器间通信能力，无需任何人工干预。例如，当门锁被破坏时，家庭入侵报警系统会自动发送信号。以下是“物联网”的简要时间线：^([9](#c02.xhtml#c02-fn-09),[10](#c02.xhtml#c02-fn-10),[11](#c02.xhtml#c02-fn-11))

*   1832年：俄罗斯的施林男爵发明了电磁电报。一年后，德国人卡尔·弗里德里希·高斯和威廉·韦伯发明了一种编码，可在1200米距离上通信。
*   1961年：通用汽车在新泽西工厂引入首台工业机器人——Unimate。
*   1969年：ARPANET连接了UCLA和斯坦福大学。
