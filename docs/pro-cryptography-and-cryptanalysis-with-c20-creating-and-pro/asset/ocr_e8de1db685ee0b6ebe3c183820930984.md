# Theorem 9-1. Adding points on elliptic curve E has the following properties:

+   1. (Commutativity) P₁ + P₂ = P₂ + P₁, ∀ P₁, P₂ ∈ E;
+   2. (Neutral element) P + ∞ = P, ∀ P ∈ E;
+   3. (Inverse existence) ∀ P ∈ E, ∃ P′ ∈ E in such way that P + P′ = ∞. The P′ point is noted usually with −P.
+   4. (Associativity) (P₁ + P₂) + P₃ = P₁ + (P₂ + P₃), ∀ P₁, P₂, P₃ ∈ E.
