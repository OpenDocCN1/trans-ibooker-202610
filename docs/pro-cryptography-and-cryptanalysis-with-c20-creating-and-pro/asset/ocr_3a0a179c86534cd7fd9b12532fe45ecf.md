# New Features in C++20

In C++20, new features have been introduced. These new features will impact how the code is written by increasing the elegance, reliability, and security metrics.

Cryptographers and information security engineers will find in these features new challenges and interesting concepts that can be incorporated in the source code of their implementations. In this chapter, we will cover the most important features and how they can be used in order to improve code for cryptographic applications.

The new features of C++20 are divided in three categories: *language features*, *library features*, and *headers features*. We will examine most of the features from a cryptography and cryptanalysis point of view and we will present how they can be used in the implementation of cryptographic algorithms.
