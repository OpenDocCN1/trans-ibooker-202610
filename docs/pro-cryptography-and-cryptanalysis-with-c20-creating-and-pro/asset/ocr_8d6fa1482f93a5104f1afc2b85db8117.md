# Complex Numbers – Short Overview

Complex numbers represent an extension of real numbers. The motivation behind complex numbers is in the desire to provide a way of solving algebraic equations that normally (using traditional real numbers) have no solution. As an example, x² + 1 = 0 has no real solution. For this situation, a symbolic solution has been created and it is known as the imaginary unit i, which has the following property:

```
i² = −1
```
