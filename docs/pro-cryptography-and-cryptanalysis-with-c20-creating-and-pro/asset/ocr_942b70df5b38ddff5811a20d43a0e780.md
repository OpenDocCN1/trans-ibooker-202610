We know already two roots of this equation, x = 0 and x = 1, which are the coordinates on the Ox axis of the intersection points between the equation of the line and the curve. For three real numbers, a, b, c, we know

```
(x − a)(x − b)(x − c) = x³ + (a + b + c)x² + (ab + ac + bc)x − abc.
```

In our situation, for roots 0, 1, x we will obtain 0 + 1 + x = 3/2, finding the coordinate point (1/2, 1/2). Because of the symmetry of the curve, we have also the coordinate point (1/2, −1/2).

Continuing with the technique illustrated above for points (1/2, −1/2) and (1, 1), we will obtain the equation of the line y = 3x − 2, which will intersect the given curve, getting the following:

```
(3x − 2)² = x(x + 1)(2x + 1) / 6
```

equivalent to

```
x³ − 51/2 x² + … = 0.
```

We already know the roots 1/2 and 1, so we will obtain

```
1/2 + 1 + x = 51/2,
```

from which we have x = 24 and y = 70, which means

```
1² + 2² + 3² + … + 24² = 70².
```

If there are 4900 balls, they can be arranged as a pyramid with a height of 24 and they can be arranged in a squared pyramid with 24 lines and 24 columns.
