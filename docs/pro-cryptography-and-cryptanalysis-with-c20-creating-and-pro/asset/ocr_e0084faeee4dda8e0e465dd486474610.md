# Figure 12-7. The result of computing (x² + 2)

For checking, if you calculate 3² + 2 you obtain 11, whose hexadecimal representation is 0xB; the noise budget is greater than 0, which means the decryption can be made.

Observe that the bfv_evaluate object allows applying operations directly over the encrypted data. The collector variable for this example is square_x_plus_two. First, this variable keeps the encrypted value raised at power 2, i.e. x², using the method square(). Further, you add plain value 2, through the method add_plain_inplace(), which gives x² + 1. Remember that in this example x = 3. The methods square() and add_plain_inplace() methods have two parameters, namely a source and a destination.

Similarly, you compute (x + 1)² using as a collector variable x_plus_one_square (see Listing 12-12).
