```
int a{4};      //** 4 is an integer
double b{3.0};   //** 3.0 represents a floating point (with no
                 //** suffix - double type by default)
float c{6.0f};   //** 6.0 represents a floating point (f is the
                 //** suffix which means a float type)
```

}
