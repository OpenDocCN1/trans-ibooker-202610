# Theorem 20-2 [1, Theorem 2, p. 114].

Let’s consider (G, *) a finite abelian multiplicative group. The subgroup of elements of order 1 or 2 is denoted as H = {g ∈ G : g * g = 1}. We consider writing p(G) as being the product ∏_{g∈G} g of all the elements of G. Next, we consider p(G) = ∏_{h∈H} h. More, it is very important to understand the following analogy: p(G) ∈ H, i.e. p(G) * p(G) = 1.

As an example, if we have G = (Z/pZ)* where p is prime, p(G) will be −1, p(G) = −1. This is proved using Wilson’s theorem.
