After finishing that wizard, I revisit WEB3 and, low and behold... my D: volume is still sitting at 5 GB. What gives? Even though we have now successfully expanded the virtual disk to 20 GB, the D: volume inside Windows has only ever been configured for 5 GB, and the Windows instance inside the VM has no idea what you want to accomplish with this extra free space. Perhaps we intend to expand the D: volume, or we could even use this new space to create a new E: volume should we have the need.

Right-click on the **Start** menu and open **Disk Management**. Inside you will see the status of disks plugged into the VM, where it is clear the second disk has now been expanded to the larger size:
