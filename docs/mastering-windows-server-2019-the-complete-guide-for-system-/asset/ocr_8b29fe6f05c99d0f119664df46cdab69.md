Yet, none of them are issuing themselves to my computers. This is because we need to adjust the security settings on our new DirectAccess Machine template. Currently, we have it configured so that all domain computers have **Enroll** permissions, but if you remember that **Security** tab within the cert template's properties, there was an additional security identifier called **Autoenroll**. Every certificate template has the **Autoenroll** permission identifier, and it is not allowed by default. Now that the light switch has been flipped ON for auto-enrollment in our domain, we need to enable the **Autoenroll** permission on any template that we want to start distributing itself. As soon as we enable that permission, these certificates will start flowing around our network.

Head into the certificate-management section of your CA server and open **Properties** of your new template, then make your way to the **Security** tab and allow **Autoenroll** permissions for the **Domain Computers** group. This should tell the CA to start distributing these certificates accordingly:
