The last step of the wizard is whether or not you want to confirm the outgoing trust. Since at this point we have only created one side of the trust, remember we still need to visit fabrikam.local's domain controller and set up the other side of the trust; at this point we do not want to confirm the outgoing trust because the trust setup is not yet complete.

Now that one side of the trust is established in contoso.local, log in to a domain controller in fabrikam.local and walk through the same setup process. Once complete, you now have a complete, two-way transitive trust configured between your two forests:
