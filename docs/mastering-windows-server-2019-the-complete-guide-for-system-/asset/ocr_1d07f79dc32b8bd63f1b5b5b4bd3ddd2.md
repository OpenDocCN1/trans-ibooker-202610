Still inside the Perfmon console, look just a little further down the tree for **Reports**. Inside **User Defined** reports, you'll find a folder for your new data collector set. Each time that your collector set runs, it will generate a new file here with a date stamp. Scheduled Perfmon datasets can be extremely useful when troubleshooting regularly occurring performance problems on a server. In the example of an RDSH server that we discussed earlier, when tackling reported slowness on that server, you could establish a Perfmon data collector set that took metrics surrounding hardware utilization. You could include session count metrics to see how many users are logged in during the same timestamps. This Perfmon report could then shed some very interesting and helpful light on the situation; perhaps you simply have too many people connected during the times that hardware is taxed. Or maybe, you'll find that the server slows down at the top of every hour and then use that information to realize that you have backups running at the top of every hour, which leads you in the direction of problem resolution.
