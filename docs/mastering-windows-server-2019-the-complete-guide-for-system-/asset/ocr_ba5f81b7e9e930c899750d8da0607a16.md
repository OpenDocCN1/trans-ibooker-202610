The first screen where we need to make some decisions is **Specify Name and Location**. Create a name for your new VM, which is easy enough. Then you also have the chance to store your VM in a new location. If you set a good default location for your virtual machines during Hyper-V role installation, chances are that you won't have to modify this field. But in my case, I chose the default options when I installed the role, and so this wizard was going to place my VM somewhere inside C:\ProgramData, and I didn't like the look of that. So I selected the checkbox and chose a location that I like for my VM. You can see that I am using a dedicated disk to store my VMs, which is generally a good practice.
