It is important to note that you can only use a double-colon once within an IP address. If you had two places where it could be applicable within the same address, you can only implement it in one of those places, and you will have to spell out the zeros in the other place. For example, changing 2001:AABB:0000:0000:0001:0000:0000:0123 into 2001:AABB::1::123 would cause your computer grief, as it would not know what to do with that double-colon. With the information provided here, you should be able to put together your own semblance of IPv6 and start issuing some IPv6 addresses to computers or servers in your network. There is so much more that could be learned on this subject that an entire book could be written, and indeed there are numerous offerings to choose from.
