Moving away from the home screen, useful as it is, try clicking on one of the tools listed along the left side of the screen, such as **Events**. Without WAC, if you wanted to troubleshoot an issue on a Server Core, it would make sense to look into the Windows Event Logs on that server, but how would you go about doing that from a command-line interface? I suppose you could have logged on to the Server Core console and used **Task Manager** to launch EventVwr, but opening up WAC and simply clicking on **Events** is much easier:
