However, since I am sitting on Windows Server 2019, my license for the server also includes licensing for Docker Enterprise, which can be pulled down without having to visit Docker Hub. If I open an elevated PowerShell prompt and run the following two commands, my server will reach out and grab Docker Enterprise, and install it onto my server:

```
Install-Module -Name DockerMsftProvider -Repository PSGallery -Force
Install-Package -Name docker -ProviderName DockerMsftProvider -Force
```
