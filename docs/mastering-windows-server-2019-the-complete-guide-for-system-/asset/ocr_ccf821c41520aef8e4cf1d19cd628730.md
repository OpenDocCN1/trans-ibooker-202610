# Group Policy

Simply copy your new Chrome ADMX files into **PolicyDefinitions**, and then copy the accompanying language ADML language file from its folder, into the corresponding language folder inside **PolicyDefinitions**. That's it! If you now close and reopen Group Policy Management Console, looking inside **Administrative Templates** displays the new Google Chrome settings, there are tons of them in here from those two little ADMX files:

![](bbox=[0.13, 0.2, 0.87, 0.61])

Figure 5.20: Google Chrome GPO settings

> For this particular example, I am working with my test lab and making the assumption that you have a single domain controller in your environment. If you have multiple DCs, you will either have to copy these files into `%systemroot%\PolicyDefinitions` on each of your domain controller servers or continue reading the next section of this chapter to learn more about the Central Store.
