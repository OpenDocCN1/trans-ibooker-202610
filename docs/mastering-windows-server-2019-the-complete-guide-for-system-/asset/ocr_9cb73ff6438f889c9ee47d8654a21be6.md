# External virtual switch

The external virtual switch is the most common type to use for any VMs that need to contact a production network. Each external virtual switch binds to a physical NIC that is installed on the Hyper-V Server. If you click on an external virtual switch, you can see that you have some options for configuring this switch and that you can even change a switch type.
