Other useful settings screens are the Processor and Network Adapter sections. Here you define the number of virtual processors currently assigned to the VM, and performance weights associated with these processors. In the Network Adapter screen, you can change which virtual switch your virtual NICs are plugged into. I find myself accessing this section often as I move servers from one location to another.
