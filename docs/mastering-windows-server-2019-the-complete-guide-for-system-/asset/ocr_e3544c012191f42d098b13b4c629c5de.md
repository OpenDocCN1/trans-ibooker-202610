While it never hurts to learn something new, using Server Core no longer comes with the requirement that you must be fluent in PowerShell. The early days of Server Core came with a requirement to be really good with PowerShell, as this was the only reliable way to configure and interface with your tiny servers, but these new tools allow us to utilize the smaller platform and administer it without memorizing a bunch of new cmdlets.

Security is the primary reason that we should all be considering Server Core as our new standard. The Windows graphical interface adds a lot of code and grants a lot of ability to those logged in to the servers, such as the ability to browse the internet. This opens up all kinds of doors to vulnerabilities that simply don't exist in Server Core.
