+   - CERTMGR.MSC: Current User Certificates Store

+   - shell:startup: While not an MSC, this is a shortcut that opens the logged in user's Start Menu\Programs\Startup folder. +   - shell:common startup: Similar to shell:startup, but this launches into the Public User's Startup folder. Shortcuts added here will auto-launch whenever any user logs into the system
