6. The VM can now be started like any other VM.

# Connecting an NFS Share to a Linux System

You can connect a Linux system to an NFS share. Although it is best practice to have an NFS share dedicated to an ESXi host, in the past I have found it useful to connect an NFS share to a Linux host while troubleshooting issues. We will connect the Windows NFS share to the Ubuntu system that we had previously installed on our ESXi host (Figure 9-6).
