# Testing Attached Drives

Thumb drives were designed for a far different workload than HDD, SSD, or NVMe drives. However, the Pi only has a USB connector, not an NVMe or SATA connector. However, these devices can be placed in an enclosure and attached to the Pi via the USB port. By doing this, you will be using a device that was designed for this type of workload.
