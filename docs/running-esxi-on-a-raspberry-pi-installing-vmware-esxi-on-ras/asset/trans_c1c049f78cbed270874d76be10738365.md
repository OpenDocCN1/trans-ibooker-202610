## 机箱注意事项

你需要确保 Arm 处理器得到适当的冷却，要么使用散热片被动冷却，要么使用风扇主动冷却。Pi 内置了电路，当检测到温度达到 60 摄氏度时，会降低 Arm 处理器的速度以防止 Pi 过热。在 80 摄氏度时，它可能会完全停止工作。

## 拇指驱动器注意事项

一个选择，也是强烈推荐的，是使用另一个 USB 3.0 设备作为你在 Pi 上运行的虚拟机的存储。你可以使用拇指驱动器或 USB 连接存储。我建议为初始安装使用高质量的 USB 3.0、64GB（或更大）的拇指驱动器。如果你需要更多的虚拟机存储空间，后续可以再添加另一个 USB 存储设备。在后面的章节中，我将讨论当前可用的不同存储选项。

你可能会想使用物理尺寸很小的 USB 拇指驱动器，如 Samsung FIT Plus 或 SanDisk Ultra Fit USB 拇指驱动器（见图 4-2）作为数据存储，但由于你会进行相当多的读写操作，使用物理尺寸更大的驱动器会更好。

### 低成本裸机构建

在我的低成本裸机构建中（表 4-1），我的目标是组装尽可能便宜的构建。我使用了一块 4GB 的 Pi，其容量足以运行一台或最多两台虚拟机。我使用了一块我目前拥有的 USB 驱动器，既用于安装，也用于虚拟机存储。为了最小化此套件，我没有包含机箱或 Arm 处理器的任何冷却机制。这可能导致处理器运行过热，进而导致其降低速度并降低性能。

据报道，如果你打算在没有任何额外冷却的情况下运行 Pi，你应该将其放置在 GPIO 引脚朝下、HDMI 端口朝上的位置，如图 4-4 所示。这样设置可以让空气在板子周围更好地流通，并增加设备的散热表面积。

你必须使用 M.2 SATA 驱动器与此机箱；NVMe 驱动器将无法工作。对于我的构建，我使用了一块 Kingston 240GB SATA SSD 设备。Argon 还制造了一个 M.2 扩展板，它只是此机箱的底部，允许你将 M.2 SATA 驱动器与普通 Argon ONE 机箱一起使用。

### Geekworm Armor 铝合金被动散热机箱

我决定购买 Geekworm Armor 铝合金被动散热机箱（见图 4-8），因为整个铝制机箱就像散热片一样，而且仅需 $13（表 4-5）。它配有三个 0.5mm 热垫，将主要集成电路与外壳主体接触以散发热量。机箱顶部用四个六角螺丝固定在底部。螺丝和内六角扳手以及两个 GPIO 延长器都随机箱附带。

我使用此机箱在 Pi 上运行了一些繁重的负载。Pi 没有变慢，机箱也只略微变暖。
