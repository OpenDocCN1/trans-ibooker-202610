# Network Storage Options for ESXi

Network storage is a huge game changer for vSphere – it both frees ESXi hosts from the physical limits of how much storage a host can support and allows the VMs stored on it to run on any host with access.

In this chapter, I will be going over and explaining how to set up two different network storage methods: Network File System (NFS) and Internet Small Computer Systems Interface (iSCSI). I will demonstrate how to provide network storage using a Windows and Linux system and will use a Type 2 hypervisor to run the Linux system as a VM on a laptop.

> Note A key difference between NFS and iSCSI to remember as you work through this chapter is that NFS shares files over the network, whereas iSCSI shares a block device over it; NFS is for files, and iSCSI is for blocks.

So far, we have only used local storage to create and store VMs. While this setup is acceptable for limited use cases, the real power of virtualization lies within the layers of abstraction that it provides. These layers allow a VM to be started on any server that has access to those files.
