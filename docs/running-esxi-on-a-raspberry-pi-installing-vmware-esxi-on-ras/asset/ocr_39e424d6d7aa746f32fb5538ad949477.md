# CHAPTER 3

# ESXi on Arm on Pi
Use Cases

ESXi on Arm running on a Raspberry Pi is a low-cost entry point into the world of virtualization and VMware, but, as we discussed in the previous chapter, its hardware does limit what this setup can do. This said, it is still able to accomplish some remarkable feats for something so small. In this chapter, we’ll take a look at use cases for ESXi on Arm on Pi, some of which are actively being used, while others less so. Some are simple uses that I’ve seen for this setup but have not actually tried myself.

To unlock many of the functions of a true VMware vSphere environment, you will also need to install vCenter Server. Fortunately, there is a trial version currently available, but it only comes with a 60-day nonrenewable trial. The vCenter Server Appliance (VCSA) comes prepackaged as an OVF file and needs to be installed on a VMware hypervisor, but the hypervisor must be an x64 – not an Arm hypervisor. At first blush, this may be an issue as you may assume that you will also need to set up an x64 ESXi system, but fortunately it can also be used with VMware Player, a free Type 2 x64 hypervisor. We’ll walk through this process later in this book.
