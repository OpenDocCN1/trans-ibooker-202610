

## 安装后配置：VMware 主机控制台

ESXi 上的时间准确至关重要。

你可以使用基于 Web 的 VMware 主机客户端来配置 ESXi 主机上的时间。我发现树莓派上的时间通常与实际时间相差数月甚至数年，因此我先手动设置时间，然后启动 NTP 服务，以保持树莓派上的时间准确。

1. 在 Web 浏览器中输入 ESXi 系统的 IP 地址，并在其前面加上 `https://`。这将带你进入 VMware 主机客户端。

2. 在 **用户名** 文本框中输入 *root*，在 **密码** 文本框中输入安装 ESXi 时设置的密码，然后点击 **登录**（见图 5-27）。

![](img/430161835ae267467687add4a1cdc429_112_0.png)

*图 5-27. 登录 VMware 主机控制台*

3. 在主页上，确认你正在树莓派上运行 ESXi on ARM Fling（见图 5-28）。

![](img/430161835ae267467687add4a1cdc429_113_0.png)

*图 5-28. VMware 主机控制台主页*

4. 在导航器窗格中，选择 **管理**，选择 **系统** 选项卡，然后选择 **时间和日期**（见图 5-29）。

![](img/430161835ae267467687add4a1cdc429_114_0.png)

*图 5-29. 时间和日期设置*

5. 点击 **编辑 NTP 设置**。

6. 选择 **手动配置此主机上的日期和时间**，将日期设置为当前 UTC 时间，然后点击 **保存**（见图 5-30）。

![](img/430161835ae267467687add4a1cdc429_115_0.png)

*图 5-30. 手动时间设置*

7. 点击 **编辑 NTP 设置**。

8. 选择 **使用网络时间协议**，选择 **随主机启动和停止**，输入 `0.pool.ntp.org`、`1.pool.ntp.org`，然后点击 **保存**（见图 5-31）。

## 小结

在 Arm 平台上安装 ESXi 所涉及的步骤要比 x64 系统多得多，后者只需从安装介质启动并安装即可。

第一次在 Arm 系统上安装 ESXi 可能需要一个小时左右，但如果你按照上述说明操作，应该会比较顺利。在接下来的章节中，我们将进一步使用 VMware 主机控制台，并向 ESXi 主机添加存储和虚拟机。

# 第 6 章

## VMware 主机客户端

在上一章中，你已经了解了 VMware 主机客户端。在本章中，我们将更深入地了解它。本章篇幅较短，但很重要，因为从现在开始，你使用 ESXi 主机所做的大部分工作都将涉及 VMware 主机客户端或 vSphere 客户端。本章的目的是让你从高层次了解客户端的用途，而不是执行实际任务，这些任务将在后续章节中介绍。

## 客户端概述

VMware 主机客户端最初以 VMware Fling 的形式发布，名为 *ESXi Embedded Host Client*。当 vSphere 6.5 U2 发布时，VMware 主机客户端被整合到 ESXi 中。该客户端允许使用 HTML5 Web 浏览器来查看和管理单个 ESXi 主机。如果你想或需要管理多个 ESXi 主机，则需要使用 vCenter Server 和 vSphere 客户端。

由于 VMware 主机客户端基于 Web，因此几乎可以在任何操作系统上使用：Windows、OS X、Android 或任何其他支持 HTML5 浏览器的操作系统。ESXi 主机上嵌入了 Web 服务器，因此只需将 Web 浏览器指向 ESXi 主机的 IP 地址，然后登录即可（见图 6-1）。要访问该主机，请输入 *root* 作为用户名，并输入安装 ESXi 时设置的密码。

![](img/430161835ae267467687add4a1cdc429_120_0.png)

*图 6-1. 登录 VMware 主机客户端*

## 使用主机客户端管理 ESXi

登录后，你将看到一个分为不同部分的仪表板。屏幕左侧的导航器允许你自定义主仪表板上显示的内容。最近任务窗格位于主仪表板的底部。主仪表板本身提供系统摘要。如果你点击 **操作**，将看到可以对 ESXi 主机执行的操作列表，例如重新启动主机以及创建/注册虚拟机。

## 管理 ESXi 和虚拟机

可以使用客户端完成基本管理功能。要查看可用的管理功能，请在导航器窗格中点击 **管理**。

## 更改默认超时时间

默认情况下，客户端的超时时间为 900 秒（15 分钟）。由于我的客户端位于安全环境中，我将超时设置为允许的最大时长（120 分钟）。如果你也想这样做，请选择 **系统** 选项卡，然后选择 **高级设置**。在搜索框中输入 *SessionTimeout*，然后选择 **UserVars.HostClient.SessionTimeout**。选择 **编辑** 选项并输入 *7200*（即 120 分钟），然后点击 **保存**（见图 6-2）。

![](img/430161835ae267467687add4a1cdc429_122_0.png)

## 图 6-2. 会话超时

高级设置选项卡下还有许多其他值，但除非明确要求，否则最好不要更改这些值，因为可能会发生严重的意外结果。

## 自动启动虚拟机

我发现其中一个有用的设置是让虚拟机在 ESXi 服务器启动时自动启动。当 ESXi 因断电或其他意外事件而宕机时，这一设置会很有用，尤其是对于承载关键应用程序（如 Active Directory（AD）服务）的虚拟机。

要让虚拟机自动启动，请选择 **系统** 选项卡，然后点击 **自动启动**。图 6-3 看起来会与你现在系统上看到的不同，因为你还没有创建任何虚拟机，但此截图展示了如何为虚拟机启用自动启动，然后为它的启动和关闭时间指定延迟。当你希望一个依赖另一个虚拟机的虚拟机在其他虚拟机之前或之后启动时，这些时间设置非常有用。一个典型的例子是，让承载数据库的虚拟机在承载依赖该数据库的应用程序的虚拟机之前启动。

## 使用主机客户端监控 ESXi

与 vSphere 客户端和一些第三方工具相比，主机客户端的监控功能比较基础；但是，这些工具可以让你了解主机上正在发生的事情。

主机客户端允许你查看主机及其上虚拟机的资源使用情况。性能信息仅存储一小时。要找到此信息，请点击 **导航器** 窗格中的 **监控**，然后选择 **性能** 选项卡。从下拉菜单中选择 **CPU**、**内存**、**网络**，然后选择 **磁盘**。

由于目前只有 ESXi 在运行，这些值会很低或不存在，而且我们还没有向其添加任何存储或虚拟机。图 6-9 显示 ESXi 仅使用约 1.3 GB 内存，其余内存留给虚拟机。在配备 8 GB 内存的树莓派上，这剩下 6.6 GB 内存；在配备 4 GB 内存的树莓派上，这仅剩 2.6 GB 内存。
