# # Post-configuration of the Ubuntu VM

Unless you only plan on running a single VM on your ESXi host, you will want to reduce the resources that your VM is using.

+   1. Power down the VM. This can be done from the VM, the VMRC, or the host client.
+   2. From the ESXi Host Client, right-click the VM and select **Edit settings**.
