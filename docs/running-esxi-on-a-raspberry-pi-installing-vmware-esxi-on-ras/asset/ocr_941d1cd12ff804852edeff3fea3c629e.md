In the following exercise, you will create an internal-only switch:

+   1. Log in to the ESXi Host Client as root.
+   2. In the Navigator pane, select **Networking**. Then select the **Virtual switches** tab, and click **Add standard virtual switch**.
+   3. In the **vSwitch Name** text box, enter *InternalOnly0*.
+   4. Expand the **Link discovery** and **Security** drop-down menus and examine the options.
