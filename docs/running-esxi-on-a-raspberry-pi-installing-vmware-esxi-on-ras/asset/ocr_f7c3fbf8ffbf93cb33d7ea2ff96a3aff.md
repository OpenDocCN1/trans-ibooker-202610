+   4. Accept the installation defaults.

+   5. When instructed, remove the installation media and press **Enter** to reboot the system.

+   6. If your system shows Figure 5-24 for more than a few minutes, power the Pi off manually.

# Modify RPi Boot Order

After ESXi is installed, you will specify the boot drive for it.

+   1. Power on the Pi.

+   2. Repeatedly press the **Esc** key while the Pi boots up.

+   3. From the Pi UEFI configuration screen, use the keyboard to select **Boot Maintenance Manager ➤ Boot Options ➤ Change Boot Order** (see Figure 5-25).
