# Installing VMware Tools on Photon

VMware Tools should be installed on all guest OSs if possible. Fortunately,
you can install open-vm-tools as a package rather than having to build it.

+   1. Power on the VM and log in to it as root from VMRC
+      or SSH.

+   2. Install the open-vm-tools package by entering

```
```bash
tdnf -y install open-vm-tools
```
```

+   3. Enable and start VMware Tools by entering

```
```bash
systemctl enable vmtoolsd.service
systemctl start vmtoolsd.service
```
