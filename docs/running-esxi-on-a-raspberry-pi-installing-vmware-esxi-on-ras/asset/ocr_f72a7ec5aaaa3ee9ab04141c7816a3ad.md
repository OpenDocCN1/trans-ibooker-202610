Once the Xming server is listening for an X11 client, a network connection will need to be established between the two, which you can accomplish by taking the following steps:

+   1. Launch PuTTY.
+   2. In the PuTTY configuration window, select Connection ► SSH ► X11.
+   3. Check the Enable X11 forwarding checkbox.
