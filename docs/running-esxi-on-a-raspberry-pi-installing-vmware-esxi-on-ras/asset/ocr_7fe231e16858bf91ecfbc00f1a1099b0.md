# Connecting to Fedora Desktop with RDP

RDP was the original protocol used with Windows machines. It was originally known as Terminal Services and was based on Citrix’s MultiWin technology.

An RDP client is shipped with all Windows systems and can be launched from the Windows command line by entering mstsc.exe. RDP clients and servers have been developed for a wide variety of machines including Fedora.
