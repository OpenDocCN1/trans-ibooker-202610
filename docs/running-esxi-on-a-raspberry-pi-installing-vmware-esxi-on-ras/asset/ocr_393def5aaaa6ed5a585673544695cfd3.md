In the past I used a couple low-end, low-cost ($20–$50) USB capture cards and found the output range from fuzzy to pretty good. Occasionally they would fail or stop working, and I would need to disconnect and reconnect them to get them working again.

Then I got a chance to review an Intel NUC 11 Computer Element (CE) AV system (see Figure 5-2). This is a small yet powerful system with an Intel i7 Core processor, 16GB of RAM, and two NICS.
