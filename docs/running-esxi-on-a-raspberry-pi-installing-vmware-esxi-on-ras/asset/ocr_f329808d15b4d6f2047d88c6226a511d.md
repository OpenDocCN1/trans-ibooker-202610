# CHAPTER 13　MANAGING ESXI SYSTEMS WITH VCSA

You can explore the storage with the vSphere Client by doing the following:

+   1. In the **Menu** drop-down, select **Storage**.

![](bbox=[0.09, 0.212, 0.87, 0.392])

+   2. Verify that the **Storage** icon is underlined at the top of the navigation pane, and then expand the datacenter.

![](bbox=[0.095, 0.506, 0.87, 0.661])

+   3. At the top of the main pane, select the **Datastores** tab.
