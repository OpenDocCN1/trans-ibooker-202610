# Virtual Machine Files

A virtual machine is a collection of files. The files shown in the following contain data and have information that the hypervisor needs to run the VM.


The following are a few of the files and their purpose:

+   - nvram - Contains the state of the VM’s BIOS.
+   - vmdk - This stores the contents of a VM’s virtual disk. You can have multiple virtual disks on a VM.
+   - vmsd - Stores metadata about snapshots of a VM.
+   - vmx - The configuration file for a VM. It stores the virtual machine settings.
+   - log - Contains logs.
