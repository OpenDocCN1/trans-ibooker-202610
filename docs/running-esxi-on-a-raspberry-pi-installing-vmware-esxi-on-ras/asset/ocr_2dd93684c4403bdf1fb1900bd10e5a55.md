# Edge Server/Data Collection Point

One likely use case of a Pi or other small, low-cost Arm devices is as an edge server or data collection point. In this case, a small inexpensive edge device captures the data and then completes some rudimentary data functions on it before passing it back to a datacenter for further analysis and permanent storage.
