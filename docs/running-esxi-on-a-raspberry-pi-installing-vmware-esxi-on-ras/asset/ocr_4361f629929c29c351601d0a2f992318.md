# # Adding an iSCSI Target to an ESXi Host

You will add the iSCSI target to your ESXi host. It can be used as the backing for a VMFS datastore.

+   1. Log in to your VMware Host Client.
+   2. In the Navigator select **Storage**.
+   3. Select **Adapters, and click Software iSCSI**.
