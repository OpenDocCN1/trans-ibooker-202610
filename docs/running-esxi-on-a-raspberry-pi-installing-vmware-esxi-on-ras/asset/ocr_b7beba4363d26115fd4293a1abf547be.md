# Networking

To explore networking using the vSphere Client, follow these steps in the following:

+   1. In the **Menu** drop-down, select **Networking**.

![](bbox=[0.09, 0.258, 0.869, 0.441])

+   2. Verify that the **Networking** icon is underlined at the top of the navigation pane, and then expand the datacenter.

![](bbox=[0.09, 0.552, 0.869, 0.709])

+   3. At the top of the main pane, select the **Networks** tab.
