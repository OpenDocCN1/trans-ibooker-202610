# Installing RDP Server on Fedora

To install an RDP server on a Fedora system, take the following steps:

+   1. Log in to the Fedora system using SSH or the console.
+   2. Install the RDP server, enable it, and open the firewall to it by entering

```
dnf -y install xrdp tigervnc-server
systemctl enable --now xrdp
firewall-cmd --add-port=3389/tcp --permanent
firewall-cmd --reload
```

# Connecting to a Linux Desktop Using RDP

You can connect to the Fedora machine from a Windows machine by following these steps:

+   1. From Windows Start, enter mstsc.exe.
+   2. In the Remote Desktop Connection panel, enter the IP address of the Fedora system.
