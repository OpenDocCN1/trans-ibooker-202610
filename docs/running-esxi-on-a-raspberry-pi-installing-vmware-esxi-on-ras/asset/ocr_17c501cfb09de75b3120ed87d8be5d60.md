# CHAPTER 7

# Local Storage
for ESXi

When VMware first started to support enterprise servers with their hypervisors, they realized that they needed a different type of storage object to store them on. This storage object needed to store not only the files that create a virtual machine (VM) but also the ISO images that are used to install VMs. It also needed to be accessed from multiple ESXi hosts. The term that VMware came up with was datastore. In this chapter, we will create a datastore on the Raspberry Pi that can be used by a single ESXi host.

# Different Types of Datastores

ESXi supports different types of datastores, including

+   - Virtual Machine File System (VMFS) – Examples of VMFS include block storage devices like local SSDs, HDDs, and NVME devices. VMFS also supports Internet Small Computer Systems Interface (iSCSI) for network-attached storage and Fibre Channel storage.
+   - Network File System (NFS) – An ESXi host can use an NFS 3 or NFS 4.1 share as a datastore.
