# Starting the OS

+   1. Open a VMRC console to the new VM and power it on.
+   2. In the pop-up window, select **I Copied It**, and click **Answer**.
+   3. Log in to the Ubuntu system.
+   4. Gain root permissions by entering
+   
+   `sudo bash`
+   5. Verify that it has a different IP address than the VM that you copied it from by entering
+   
+   `ip add`
+   6. Verify that it has the same name as the VM that it was copied from by entering
+   
+   `hostname`
