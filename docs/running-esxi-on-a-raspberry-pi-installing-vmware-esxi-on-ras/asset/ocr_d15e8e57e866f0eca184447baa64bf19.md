In production environments, ESXi is almost always used with shared storage. Very seldom will you see a production ESXi host with just local storage. Setting up a Windows or Linux server to act as an iSCSI host is very simple, and it allows you to store considerably more VMs than the local storage and allows them to run on any of the ESXi hosts attached to it.

The performance of the underlying storage has a direct impact on the performance of the VM. In the next chapter, I will measure the performance of many different storage devices.
