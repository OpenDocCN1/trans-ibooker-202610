# Configuring vCenter Server

After the VCSA has been installed, it will present a web page to configure it. At this point, follow these steps listed in the following:

+   1. In the web browser, click **Set Up**.

![](bbox=[0.09, 0.26, 0.87, 0.47])

+   2. Enter the root password.

+   3. Click **Next**.

+   4. Verify the network information. Then, from the **SSH access** drop-down menu, select **Enabled**.

+   5. Click **Next**.
