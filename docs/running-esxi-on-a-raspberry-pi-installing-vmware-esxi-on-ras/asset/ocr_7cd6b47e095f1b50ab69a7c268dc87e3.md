To have a VM start up with the host, follow these steps:

+   1. In the Menu drop-down, select Hosts and Clusters.

![](bbox=[0.13, 0.18, 0.91, 0.4])

+   2. Verify that the Hosts and Clusters icon is underlined at the top of the navigation pane, and then expand the datacenter.

+   3. In the navigator, select an ESXi host, and then open the Configure tab.

![](bbox=[0.13, 0.57, 0.91, 0.8])
