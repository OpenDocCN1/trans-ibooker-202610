I will be installing Fedora 34, but many other releases are known to work with ESXi on Arm.

The process of creating a Fedora VM is very similar to installing Ubuntu and many other Linux distributions.

The download site for the Arm Fedora images is https://getfedora.org/en/server/download/.

I will download *Fedora 34: Standard ISO image for aarch64* directly from this website to an ESXi datastore.
