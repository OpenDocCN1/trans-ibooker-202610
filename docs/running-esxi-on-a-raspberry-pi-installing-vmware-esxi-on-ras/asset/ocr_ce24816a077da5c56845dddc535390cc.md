# CHAPTER 13　MANAGING ESXI SYSTEMS WITH VCSA

To clone a VM using the vSphere Client, take the following steps:

+   1. In the navigator, right-click a VM and select **Clone ➤ Clone to Virtual Machine.**

![](bbox=[0.092, 0.21, 0.87, 0.536])

+   2. Enter the information for your cloned VM, accept the defaults, verify your settings, and click **Finish.**

![](bbox=[0.091, 0.625, 0.87, 0.857])
