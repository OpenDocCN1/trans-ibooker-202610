# Summary

As mentioned at the start of this chapter, NFS is used to share the files that make up a VM, while iSCSI shares a block device (such as a disk over the network). When used with an ESXi host, NFS has slightly less overhead as all the overhead associated with a file system is done by the NFS Server, but with iSCSI (as the file system is being managed by the ESXi host) it may have features that are unavailable on an NFS share.
