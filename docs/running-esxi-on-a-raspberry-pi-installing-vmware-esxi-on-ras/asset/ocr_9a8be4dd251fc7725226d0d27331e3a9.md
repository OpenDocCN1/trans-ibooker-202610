# Share a Windows Server Directory via NFS

Once NFS has been installed, you can share a folder on your Windows system via NFS.

+   1. Create a new folder on the desktop called WinServerNFS01.
+   2. Right-click the **WinServerNFS01** folder, select **Properties**, and select **NFS Sharing**.
+   3. Click **Manage NFS Sharing**.

![](bbox=[0.22, 0.36, 0.74, 0.68])

+   4. Click **Share this folder**, click the **Permissions** button, and click **Allow root access**.
