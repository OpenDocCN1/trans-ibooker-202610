# Cloning Virtual Machines

You can clone a VM with the vSphere Client. When using the ESXi Host Client, we needed to manually copy the files to make a copy of a VM. You can clone powered-on and powered-off VMs, but cloning a powered-on VM will take longer. When cloning a VM, you can select a different datastore for the VM.
