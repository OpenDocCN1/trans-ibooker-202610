# Micron M500DC in a Sabrent Docking Station

I tested an 800GB Micron M500DC SATA SSD in a Sabrent 3.5/2.5" USB 3.0 docking station with a built-in cooling fan (EC-DFFN). The M500DC is an extremely popular SATA SSD drive, and the Sabrent enclosure has a fan in it to keep the drive cool.

The results of the test.

|  | Fio 4K – RAND Read | Fio 4K – RAND Write | Fio 4K – SEQ Read | Fio 4K – SEQ Write |

| M500DC SATA/Sabrent | bw=9.2MiB/s | bw=19.7MiB/s | bw=79.9MiB/s | bw=82.4MiB/s |
