## 使用 vCenter Server 管理 ESXi

从信息和功能的角度来看，ESXi 主机客户端中可用的所有内容也都在 vSphere Client 中可用，但 vSphere Client 还包含其他功能。vCenter Server 是一个功能非常强大的工具，用于为服务器提供无与伦比的业务连续性、灵活性和可用性。在以下部分中，我们将对这些功能中的一部分进行非常基本的概述。
