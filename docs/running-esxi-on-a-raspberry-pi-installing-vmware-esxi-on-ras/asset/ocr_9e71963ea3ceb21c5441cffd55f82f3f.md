# CHAPTER 7 LOCAL STORAGE FOR ESXI

If you wish to download it directly to your ESXi host, the following are the steps to do so:

+   1. From the host client, select Networking in the Navigator and select Firewall rules. In the search box, enter HTTP. Right-click httpClient and then click Enable.

![](bbox=[0.09, 0.28, 0.86, 0.47])

+   2. Use SSH to connect to your ESXi host.

+   3. Download the script to the /tmp directory and make it executable by entering

```
cd /tmp
wget https://raw.githubusercontent.com/FentonTom/AutoMountUSB/main/AutoMountUSB.bash
chmod 755 ./AutoMoutUSB.bash
```
