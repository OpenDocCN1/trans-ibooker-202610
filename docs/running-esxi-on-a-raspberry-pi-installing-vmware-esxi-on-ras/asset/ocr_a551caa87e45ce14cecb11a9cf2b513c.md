Once a vSwitch has been created, you can then add port groups to it, and these port groups can have security attributes just like vSwitches. These attributes are inherited from the vSwitch by default.

In the following exercise, you will create a port group on the *InternalOnly0* vSwitch:

+   1. Select the **Port groups** tab, and click **Add port group**.
