# Virtual NICs

vNICs emulate physical NICs and allow VMs to communicate to virtual switches (see Figure 12-5). While VMware provides a wide variety of vNICs, there are currently only three available with ESXi on Arm:

+   - E1000 – An emulation of the Intel 82545EM Gigabit Ethernet NIC.
+   - E1000E – An emulation of the Intel 82574 Gigabit Ethernet NIC.
+   - VMXNET3 – This vNIC does not emulate an NIC but was designed by VMware from scratch for optimal performance for VMs.
