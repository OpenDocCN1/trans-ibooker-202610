# Using iPerf3 Between VM and Physical Machine

In the previous section, we verified the bandwidth between two VMs on the same ESXi host. The network traffic didn’t need to go on any physical networking infrastructure (i.e., NICs, switches, etc.) as they were on the same ESXi host. In this section, we will check the bandwidth between a VM and a physical host (see Figure 12-11).

![](bbox=[0.09, 0.31, 0.88, 0.66])

Figure 12-11. VM to Physical Server

I ran iPerf3 in forward and reverse modes. In both cases, due to the limitations of the physical hardware, the bandwidth was 0.90Gbps (see Figure 12-12).
