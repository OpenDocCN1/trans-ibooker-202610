# Setting Up an NFS Server on Windows

Windows Server has long supported acting as an NFS Server. The following instructions were done using Windows 2016 Server, but other versions of Windows Server will work as well.

+   1. In the Run command window, enter `ServerManager.exe`.
+   2. Click **Add roles and features**.

![](bbox=[0.093, 0.344, 0.86, 0.603])

+   3. In the Add Roles and Features Wizard, click **Next**.
+   4. Selected **Role-based or feature-based installation**, and click **Next**.
+   5. Click **Next**.
+   6. Expand **File and Storage Services**, and expand **File and iSCSI Services**.
