# Stress Testing a Thumb Drive

Thumb drives are not designed to have a continual load placed on them; they are designed for occasional loads and to be written to intermittently. To see how well the drive would hold up, I completely wrote to the Samsung BAR Plus 256GB drive 100 times using the following script:

```
for ((i=1;i<=100;i++));
do

echo " Start of loop $i"
time fio --filename=/dev/sdb --ioengine=libaio --rw=write
--bs=128k --numjobs=1 --size=100% --iodepth=32 --end_fsync=1 --name=4kSeqWrite --status-interval=600
done
```
