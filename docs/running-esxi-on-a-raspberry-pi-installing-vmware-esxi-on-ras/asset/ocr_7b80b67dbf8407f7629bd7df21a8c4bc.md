# Copying a VM Stored on a Local Datastore to an NFS Share

NFS shares are shown under /vmfs/volumes like the local datastores we created. In the following, I will show you how to copy an existing VM from a local datastore to NFS from the ESXi host command line.

+   1. Log on to your ESXi host from the host console or using SSH.

+   2. Change to the datastore directory by entering

```
cd /vmfs/volumes
```

+   3. Create a new directory and copy an existing VM to it. I used the time command to see how long the copy took by entering

```
mkdir WinServerNFS01/Ubuntu_NFS01
time cp -r rPi-USB-Datastore-01/Fresh_Ubuntu2004/* WinServerNFS01/Ubuntu_NFS01
```
