
**1** 你可以在步骤 3 中使用缝纫机代替手工缝制。设置好[缝纫机](#026-029_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0049)。找到针迹类型选择器并选择直线针迹。然后在针距选择器上选择 3–3.5。

![DK](Images/Page_051_02.png)

**2** 将物品放在缝纫机上（这可能有点棘手，取决于补丁的位置），在受损区域来回缝制。翻转衣物，使下一行针脚与第一行针脚成直角，以加固修补处。

**实用贴士**

根据破洞的大小、面料类型和破洞的位置选择修补方法。

# 补织破洞

在心爱的羊毛衫或针织衣物上发现破洞会让人难过，但这不意味着它的寿命就此终结。补织破洞比本书中的其他修补方法稍微耗时一些，但发挥你内心的“奶奶精神”绝对值得，因为这能延长衣物的使用寿命。

| **所需工具** | 补织针、补织线（选择颜色接近的线以使修补处融为一体，或选择对比色以制作显性修补）、剪刀/剪线钳、补织蘑菇或补织蛋（或饮用杯底、橘子）（可选） |
| --- | --- |
| **惯用左手？** | 如果反方向操作更舒服，请按此处所示的相反方向进行 |

![DK](Images/Page_052_01.png)

**1** 在补织针上穿一根约 20 英寸（50 厘米）长的补织线。线头不打结。将物品正面朝上（下方垫上补织蘑菇），将针尖插入距离破洞约 ⅝ 英寸（1.5 厘米）处。

![DK](Images/Page_052_02.png)

**2** 始终将针保持在衣物正面。再次将针尖刺出，位置距离插入点 ⅛ 英寸（4 毫米）。从上方向上拉出针和线，但留出约 1⅝ 英寸（4 厘米）长的线尾。

![DK](Images/Page_053_01.png)

**3** 继续让针在织物中上下穿插，形成一排直线针脚。尽量保持针脚细小均匀，长度不超过 ⅛ 英寸（4 毫米）。继续缝制，直到这一行延伸至破洞上方至少 ⅝ 英寸（1.5 厘米）处。

![DK](Images/Page_053_02.png)

**4** 在行末留一个小线圈，换个方向，再缝一排直线针脚，紧挨第一排但方向向下。以此方式继续上下缝制以覆盖整个区域。每行末端的小线圈可为缩水留出余地。

![DK](Images/Page_053_03.png)

**5** 缝制横向的直线针脚行，在经过破洞时在纵向针脚间上下穿插。这将在破洞上方形成新的“织物”。如果破洞处看起来不够密实也不必担心，因为补织线会因穿着而起毛变厚实，从而填补空隙。

![DK](Images/Page_053_04.png)

**6** 修补过程中，你很可能需要给针重新穿更多的线，最后补织边缘会有松散的线头。逐个处理每个线头，穿上针，将其编织进修补处以隐藏并固定。

# 修补撕裂

此时，你已掌握几招处理衣物破洞的妙招。但如果袖子撕裂或破了个口子怎么办？别担心，这里还有两招。

| **所需工具** | |
| --- | --- |
| **牢固修补法：** | 粘合衬、布剪、熨斗、熨衣板、熨烫布、手缝针、配色线、剪刀/剪线钳 |
| **隐形修补法：** | 大头针、织物标记工具、手缝针、配色线、剪刀/剪线钳、熨斗、熨衣板 |

| **用缝纫机？** | |
| --- | --- |
| **牢固修补法：** | 按步骤 1 和 2 操作，然后在撕裂处使用宽之字针迹代替包边针 |
| **隐形修补法：** | 按步骤 1 和 2 操作，然后使用直线针迹（设为长度 2）代替直线针脚 |

**实用贴士**

如果撕裂周围区域也受损，你可能需要给它打补丁（参见[从正面补洞](#040-043_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0087)）。如果只是单纯的裂口或撕裂，请使用此处展示的方法之一。

# 牢固修补法

让我们重温并再次运用[包边针](#046-051_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0103)。虽然这种方法比下一种更显眼，但它能为经常穿着的衣物提供更稳固、牢靠的修补效果。

![DK](Images/Page_057_01.png)

**1** 选择与衣物面料厚度相似的粘合衬；它会在缝制前稳固撕裂区域。剪一块宽约 1 英寸（2.5 厘米）、比撕裂口长 1 英寸（2.5 厘米）的长方形。

![DK](Images/Page_057_02.png)

**2** 将衣物反面朝上放在熨衣板上。将撕裂的边缘对齐拼合，将粘合衬（胶面朝下）覆盖在撕裂处上方。垫上熨烫布，用熨斗小心熨烫。

![DK](Images/Page_057_03.png)

**3** 正面朝上，像[步骤 2](#036-039_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0075)那样准备好针线。从撕裂口下方、距离撕裂口至少 ⅛ 英寸（3 毫米）处开始，从背面将针刺入并从正面拉出。

![DK](Images/Page_057_04.png)

**4** 将针穿过到撕裂口的另一侧。刺穿织物，形成一个跨过撕裂口的针脚。从背面将针线向下拉出。不要拉得太紧，以免“绞紧”织物。

![DK](Images/Page_058_01.png)

**5** 从背面将针斜向上移动。将针穿过粘合衬和织物从正面刺出，这次位置在第一个针脚上方约 ⅛ 英寸（3 毫米）处。从正面拉出针线。重复步骤 4 完成第二个针脚。

![DK](Images/Page_058_02.png)

**6** 重复步骤 4 和 5，沿着撕裂口长度缝出整齐的“梯子状”针脚。在撕裂口末端再缝一两个针脚。然后在背面重叠缝两个小针脚固定。剪去多余线头。

# 隐形修补法

直线针脚有助于制作隐形修补效果（适合有图案的面料，不太适合易脱线的面料）。

![DK](Images/Page_058_03.png)

**1** 将衣物正面相对折叠，使撕裂口的长度方向沿着折边。将大头针垂直插在折边上，保持织物平整且位置固定。

![DK](Images/Page_058_04.png)

**2** 物品平铺，用织物标记工具画一条缝制引导线——一条平滑的曲线，距离撕裂口边缘约 ³/₁₆ 英寸（5 毫米）。起止位置距离两端各约 ⅜ 英寸（1 厘米）。

![DK](Images/Page_059_01.png)

**3** 像[步骤 2](#036-039_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0075)那样准备好针线。从紧贴折边处开始，从背面将针穿过两层织物刺向正面。从正面拉出针线。

![DK](Images/Page_059_02.png)

**4** 沿着线条再向前约 ⅛ 英寸（3 毫米）将针刺回背面。从背面将针线向下拉出。目标是针脚紧密，但要尽量保持织物平整，避免起皱。

![DK](Images/Page_059_03.png)
