
# 暗针修补衣摆

如果您的衣物衣摆原本是用几乎看不见的针脚缝制的，请使用下面的暗针法来修补衣摆，使其完美融合。

![DK](Images/Page_037_01.png)

**1** 以原有的折痕线为基准，重新折好松脱的衣摆部分，如有必要用熨斗烫平折痕。用别针固定衣摆，将别针水平放置在距离衣摆内边缘约 ⅝ 英寸（1.5 厘米）处，别针尖朝左。

![DK](Images/Page_037_02.png)

**2** 穿好一根长度不超过 18 英寸（45 厘米）的单股线在尖针上。在线的一端打个结。拿住衣物，使衣摆的折边朝向自己，从右向左缝纫。

![DK](Images/Page_037_03.png)

**3** 将针从衣摆背面穿到正面，距离上边缘约 ³⁄₁₆ 英寸（5 毫米）处，以此固定线头，使结隐藏在衣摆后面。

![DK](Images/Page_037_04.png)

**4** 斜向左上方挑取衣摆上方面料的几根线，针脚长度不超过 ⅜ 英寸（1 厘米）。拉过线完成针脚，但不要拉得太紧。

![DK](Images/Page_038_01.png)

**5** 将针尖斜向左下方移动。再次挑取衣摆面料的几根线，针脚长度不超过 ⅜ 英寸（1 厘米）。拉过线完成针脚。以此方式继续缝制，重新固定衣摆。

![DK](Images/Page_038_02.png)

**6** 收尾时，拔出别针，仅在衣摆面料上重叠缝两个约 ³⁄₁₆ 英寸（5 毫米）长的小针脚。剪掉靠近面料处的多余缝纫线。用熨斗轻轻烫压修补好的衣摆，使针脚定型。

# 明线衣摆修补法

用明线修补衣摆比暗针法甚至更简单！现在来学习如何回针缝。

![DK](Images/Page_038_03.png)

**1** 仔细清除断裂针脚处残留的线头。将衣摆朝外（衣物正面朝上）摆放。如有必要，用别针将断裂的衣摆部分固定回原位，别针水平放置。

![DK](Images/Page_038_04.png)

**2** 请参考[缝纽扣](#030-031_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0056)的步骤 1 来准备针线。将针从原衣摆针脚行最后两个完好针脚之间穿出。从正面拉出针线。

![DK](Images/Page_039_01.png)

**3** 将针向后（远离断裂针脚处）移动。在针穿出位置后方一个针脚长度处将针穿入面料背面。从背面拉出针线；这些重叠的针脚应能防止脱线。

![DK](Images/Page_039_02.png)

**4** 仍将针握在衣摆背面，将针向断裂处移回。在左侧两个针脚长度处将针从面料背面穿到正面。从正面拉出针线。再缝一个回针，向右一个针脚长度。

![DK](Images/Page_039_03.png)

**5** 现在您已在原针脚上缝了两针。重复步骤 4，沿着断裂的衣摆部分继续缝回针。请尽量使针脚长度与原衣摆针脚一致，以便新针脚融为一体。

![DK](Images/Page_039_04.png)

**6** 当回针行缝到原针脚处时，再缝两针。将衣摆翻到里面。收尾时，拔出别针，在一个回针后面重叠缝两个小针脚；这些针脚从正面不应可见。剪掉多余的线。

# 从正面修补破洞

把衣服上的破洞看作是一场有趣的创作机会吧！打上补丁；效果可以是低调的、美观的，或是疯狂独特的。然后，用刺子绣风格的针法来庆祝您的修补成果。

修补不想凸显的区域时（如牛仔裤的臀部），可使用与衣物颜色相匹配的补布和线。或者，您也可以在膝盖、肘部或任何想引人注目的地方，使用对比色的线或补布本身作为亮点。

| **所需工具** | | 卷尺、制作补丁或贴布的面料、布料标记工具、布剪、熨斗、熨衣板、大头针（如果面料易被大头针损坏，请改用缝纫别针）、手缝针、线（颜色搭配或对比）、剪刀/剪线钳、100% 棉质刺子绣线（可选） |
| --- | --- | --- |
| **缝纫机？** | | 按步骤 1 至 3 准备并固定补丁或贴布，然后尝试用宽锯齿针沿形状边缘缝制 |
| **左撇子？** | | 如果觉得更舒服，可按相反方向操作 |

> **小贴士**
>
> 补丁面料的厚度和类型要与衣物匹配。无弹性的紧密织物适合做补丁。

![DK](Images/Page_041_01.png)

**1** 检查破洞的形状和位置，并查看周围区域是否有薄弱或损坏。决定补丁的形状；简单的长方形或正方形最适合入门。

![DK](Images/Page_041_02.png)

**2** 测量补丁需要多宽多深才能盖住破洞（如有必要，包括受损区域）。每边额外增加 1 英寸（2.5 厘米），用标记工具在补丁面料上画出这个放大后的形状。如果您愿意，补丁可以做得更大。

![DK](Images/Page_041_03.png)

**3** 小心剪下面料形状。补丁正面朝下，将每条边向内折 ⅜ 英寸（1 厘米）并用熨斗烫平。

![DK](Images/Page_041_04.png)

**4** 将补丁居中置于破洞或受损区域上方并用别针固定。如[步骤 1](#030-031_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0057)所示，穿一根约 39 英寸（1 米）长的线在缝纫针上。现在您有了双股线。

![DK](Images/Page_042_01.png)

**5** 从一个角开始。从背面将针在距离补丁边缘约 ³⁄₁₆ 英寸（5 毫米）处穿出。从正面拉出针线，然后在左侧约 ³⁄₁₆ 英寸（5 毫米）处将针穿回背面，重复此动作。

![DK](Images/Page_042_02.png)

**6** 重复步骤 5，直到绕补丁所有边缘缝完。保持针脚长度均匀且距离边缘 ³⁄₁₆ 英寸（5 毫米）。从背面仅穿过衣物面料，重叠缝两个小针脚收尾。剪断线。

# 基础刺子绣风格针法

为了增加牢固度和美观度，为什么不试试刺子绣风格的针法呢？

> **小贴士**
>
> 如果没有刺子绣线，可用两股普通缝纫线，将四个线头打结在一起（形成四股线）。

![DK](Images/Page_042_04.png)

**1** 按照[步骤 1](#040-043_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0089)至[步骤 3](#040-043_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0091)准备补丁。使用刺子绣线效果最好，但用普通线（见[小贴士](#040-043_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0096)）缝四股线也能达到类似效果。使用单股刺子绣线，一端打结。

![DK](Images/Page_043_01.png)

**2** 按照[步骤 5](#040-043_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0093)完成一行水平针脚。尽量保持针脚长度均匀，最后一针距离补丁边缘 ³⁄₁₆ 英寸（5 毫米）处结束。

![DK](Images/Page_043_02.png)
