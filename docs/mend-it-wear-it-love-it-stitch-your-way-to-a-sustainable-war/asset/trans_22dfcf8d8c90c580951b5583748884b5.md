# 简介

我们的衣物为我们辛勤服务。它们让我们保暖舒适、外观出众，还能彰显我们的个性。所以，当它们开始显露出辛劳的痕迹时，我们难道不该拿起针线回报它们吗？

在深入探讨对抗磨损迹象的技巧之前，先让我们调整心态。此时，你可能会对在心爱衣物附近挥舞大头针和缝衣针（更别提剪刀！）感到有些紧张，甚至怀疑这到底是不是个好主意。请铭记这一信念：任何能让衣物多穿一次的修补都是巨大的成功，值得庆祝。仅仅尝试让衣物更耐穿，你就是慢时尚运动的积极参与者——恭喜你！

> 任何能让衣物多穿一次的修补都是巨大的成功。

## 大胆还是低调？

衣物修补可以介于“超级整齐、肉眼不可见”到“显而易见地延长了衣物寿命”之间的任何位置。在网上探索 #visiblemending（可见修补）以了解并沉醉于这种方法的理念。许多人认同这种做法，他们喜欢展示而非隐藏衣物经历的旅程。

衣物在你衣橱中的角色和你的个人风格将影响你对特定修补选择的方法。无论你的目标是什么，请不要认为修补必须看起来完美，甚至不必显得模糊整齐才算成功；但遵循一些 [`基本规则`](#024-025_Mend_it_Wear_It_Love_It.xhtml#DK_MEND_0048) 有助于获得最佳效果。

如果你没有信心，或正在尝试新方法，请先在布料碎片上测试该技巧。

## 灵活运用新技能

本书包含的技巧为你应对大多数衣物修补提供了绝佳基础。随着时间的推移，当衣物出现问题时，你将有机会尝试并熟悉这些技巧。你很可能在某些技巧上大获全胜，而另一些可能需要几次尝试才能达到预期效果。

本书中的每种修补技巧都适合初学者。然而，实际上，处理任何修补工作可能有多种不同方法。如果你愿意，请随意实验和调整这些技巧，以不同方式应用，甚至开发出自己的方法。

享受乐趣，动手创造，并为此自豪！

为增加修补成功的几率，请遵循以下基本规则：

*   一旦发现需要修补，请在解决问题前不要再穿这件衣物。也不要清洗它。在修补前继续穿着或清洗衣物很可能会加剧问题，导致日后更难修复。
*   不要尝试在穿着衣物时进行修补。你需要将衣物平铺并仔细检查问题，以便做出最佳修补。
*   尽量在光线良好的环境下修补衣物。深色衣物在光线不足或人造光下尤为难以操作。
*   如果你没有信心，或正在尝试新方法，请先在布料碎片上测试该技巧。慢慢来没关系——毕竟这是慢时尚。
*   如果面料精致、细薄、严重起毛或极其昂贵，请考虑送往裁缝店或修改专家处。挑选适合自己的项目没关系。取回修补好的衣物时，询问他们采用了什么修补方法，以便日后你能尝试类似做法。

# 使用缝纫机

为使修补更快捷、完成度更整齐，请使用缝纫机。抛弃学校家政课留下的不愉快回忆（如果你上过的话），如果你能借到、求到或偷到一台机器，为什么不试一试？

最初你需要掌握一些基本功能——绕底线、穿线、选择和调节针脚，以及定位工件以便缝制。假设你不是机器主人，且他们无法教你，请查看机器说明书是否能指导你完成这些步骤。如果拿不到实体版，你或许能买到 PDF 版或找到视频教程；在网上搜索机器的品牌名称和型号。

掌握机器基本功能后，请参考这些实用小贴士，助你缝制成功。

## 贴士 1：使用超锋利的针

购买一包包含多种规格（通常为 8 到 16 号）的缝纫机针。大多数机器适用通用机针，但部分（通常是老款）机型使用不同类型。还要根据面料类型匹配机针：通用机针适合梭织面料，而针织和弹力面料则需要圆头针。

定期更换缝纫机针，因为很难肉眼判断是否受损。使用损坏或钝化的机针反而会损坏你试图修补的物品面料。

## 贴士 2：使用合适尺寸的针

始终将机针尺寸与你即将缝制的面料厚度相匹配（见下表）。基本上，数字越大，机针越粗。

| 机针尺寸 | 面料类型 |
| --- | --- |
| 8(60) 和 10(70) | 轻薄面料，如棉细布、丝绸和薄纱 |
| 12(80) | 中等厚度面料，如针织布、平纹布、衬衫布和亚麻布 |
| 14(90) 和 16(100) | 厚重面料，如棉斜纹布、牛仔布和灯芯绒 |
