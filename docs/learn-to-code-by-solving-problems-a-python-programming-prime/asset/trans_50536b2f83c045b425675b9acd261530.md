# 作者简介

Daniel Zingaro 博士是多伦多大学计算机科学副教学教授，也是获奖教师。他的主要研究领域是计算机科学教育，研究学生如何学习（有时不学习）计算机科学材料。他是《算法思维》（No Starch Press, 2021）的作者，该书帮助学习者理解和使用算法和数据结构。

# 技术审校简介

Luke Sawczak 是经常的自由编辑和业余程序员；他的最爱项目包括散文到诗歌转换器、用于切正确数量蛋糕片的视觉辅助工具，以及为数学辅导员制作的数字版 Boggle。他目前在多伦多郊外教授法语和英语。他还写诗并为钢琴作曲，如果能靠此为生就好了。他的在线地址为 https://sawczak.com/。
