Answer: B. There are two nested loops here, so your first instinct might be to claim that this is a quadratic-time algorithm. Be careful, though, because the outer for loop iterates only 10 times, independent of the value of n. The total number of steps in this algorithm, therefore, is 10n. There’s no n² here; 10n is linear, just like n. So, this is a linear-time algorithm, not a quadratic-time algorithm. We’d write its efficiency as O(n).
