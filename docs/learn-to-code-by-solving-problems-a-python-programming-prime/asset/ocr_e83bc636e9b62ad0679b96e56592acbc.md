```
```python
>>> '**'.join(lst)
'Toronto**Ontario**Canada'
```
```

Technically, join can join the values in any sequence, not just in a list. Here’s an example of joining the characters from a string:

```
```python
>>> '*'.join('abcd')
'a*b*c*d'

45.6
