completes all of its iterations before the next iteration of the outer loop begins. The same holds for while loops. Here’s an example:

```
>>> i = 0
>>> while i < 3:
...     j = 8
...     while j < 11:
...         print(i, j)
...         j = j + 1
...     i = i + 1
...
0 8
0 9
0 10
1 8
1 9
1 10
2 8
2 9
2 10
```

Each value of i is involved in three lines of output, one for each iteration of the inner j loop.
