# 第2章. 适应度函数测试金字塔：架构测试和指标的类比

Rene Weiss

适应度函数是一个源自进化计算的概念，也是一种简洁的方法，可用于定义软件系统指标。本章将展示适应度函数如何帮助你为系统定义量身定制的指标，并利用它们改进系统的架构，无论你当前是在构建新系统还是改进现有系统。将适应度函数和指标与测试金字塔概念相结合，可以帮助你定义、优先排序和平衡指标，并能够衡量实现目标的进展。

## 适应度函数和指标

在他们的书 *构建进化式架构* 中，Neal Ford、Rebecca Parsons 和 Patrick Kua 将适应度函数定义为“用于总结预期设计方案实现既定目标的接近程度的目标函数”。^([1](#ch02.html#ch01fn25)) 这样的函数通常输出一个离散值，即你试图实现或改进的指标。为了知道是否达到目标，你需要一种测试或验证机制来衡量所需的指标。理想情况下，你希望它能自动化，但这并不是适应度函数的必要条件！

我喜欢使用适应度函数来创建目标指标的想法，因为它们非常灵活。你也可以使用适应度函数来描述和集成典型的指标（如代码覆盖率或代码结构指标如圈复杂度），^([2](#ch02.html#ch01fn26)) 但它们的开放性使你能够根据系统和上下文定制架构指标。

[图 2-1](#ch02.html#fitness_function_concept_map) 中的概念图说明了适应度函数与目标指标之间的关系。适应度函数定义目标指标并描述相关上下文，我称之为 *适应度函数上下文*。这可能包括影响测试的环境、定义和限制的额外信息；我将把这些信息分为若干类别，并在后面更详细地描述。

![](assets/sarm_0201.png)

*架构测试* 生成目标指标。通常，这类测试还会直接验证创建的指标是否高于（或低于）某个阈值。通常，这些测试是自动化的，并在持续集成 (`CI`) 工作流的一部分中执行。有些甚至可以在没有特定触发器的情况下持续运行和验证。我使用 *架构测试* 和 *架构验证* 这些术语来明确将其与功能测试区分开来。例如，功能测试可能会查看是否能在系统中正确创建新客户；而架构测试可能会查看是否能在实现架构或质量目标的同时创建10个客户。例如，此场景中的架构测试为这10个客户的创建速度创建了一个指标，并验证是否在10毫秒以内。

适应度函数、其上下文和实际目标指标紧密相关。我们在 *设计时* 定义这三者。架构测试是在之后创建的，不是适应度函数及其指标定义的一部分。

如果架构测试是自动化的，我强烈推荐，实施后，指标将自动生成。你可能需要在系统或架构中更改某些内容，评估新工具和框架，并在实施测试时在“工程”方面发挥创造力。所有这些都是在你定义目标和指标之后完成的。何时以及如何定义适应度函数并实施架构测试是 [“开发你的适应度函数和指标”](#ch02.html#developing_your_fitness_functions_and_m) 的一部分。

简而言之，适应度函数充当你对“好”的定义。让我们看一些例子。

### 适应度函数：测试覆盖率

在这个假设系统中，保持单元测试覆盖率高于90%的阈值至关重要。^([3](#ch02.html#ch01fn27)) 自动集成测试的目标是高于50%的行覆盖率。让我们看看如何将这两个目标描述为具有上下文的适应度函数（示例 [2-1](#ch02.html#ff1.1) 和 [2-2](#ch02.html#ff1.2)）。

#### 示例 2-1. 一个适应度函数

```
Unit Test Coverage > 0.9; 
Execute on each CI Build; Fail when below target coverage
```

#### 示例 2-2. 一个适应度函数

```
Integration Test Coverage > 0.5; 
Execute on each nightly integration test build; 
Fail when below target coverage
```

正如这些简单示例所示，适应度函数定义了需要满足的目标指标（测试覆盖率）、与指标相关的上下文（要执行的测试类型以及执行时间）以及自动验证指标所需的额外上下文信息。

实际实现（如在测试执行期间测量代码覆盖率，如 [示例 2-1](#ch02.html#ff1.1) 中所述；或设置特定测试环境、执行测试并验证结果，如 [示例 2-2](#ch02.html#ff1.2) 所述）是实施架构测试的一部分。

### 适应度函数：具有网络延迟的集成测试

你正在测试的系统正在使用 `REST/JSON API` 与第三方系统集成。如果该 API 缓慢或无响应，你自己的系统的稳定性和性能将会下降，因此你希望验证你的系统是否能正确处理此类事件并按预期执行。以下是适应度函数可能的样子（[示例 2-3](#ch02.html#ff2.1)）。

#### 示例 2-3. 一个适应度函数

```
Integration test errors = 0% (when network latency is 10s for third-party API call); 
Execute on each nightly integration test build; Fail when integration test fails
```
