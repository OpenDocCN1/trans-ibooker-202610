

当重大战略投资失败时，董事会仅声称已将责任委托给首席执行官是不够的。董事会拥有可衡量的进度指标和明确的结果至关重要，并且应定期监控结果。任何低于此标准的做法都可被视为治理失败。⁴

作为一名经验丰富的董事，您了解治理的基本原理，但当对话变得“过于”技术化时，可能会出现差距。您可以采取以下措施：

- **进行更多对话式交流。** 通过更真诚地参与讨论，您可以提出更好的挑战，并寻求提交给董事会的观点质量的改进。使用各章中提供的聪明问题。然后，积极倾听答案并不断提问，直到您了解所需了解的内容。

- **给予您的疑虑时间和优先权。** 您之所以成为董事，是因为您已证明自己的直觉非常敏锐。如果您不理解某个话题，您有理由持怀疑态度。您不必接受首席信息官或任何其他人所推销的一切。使用以下聪明问题，要么消除您的疑虑，要么直接说不。

- **不要被技术术语分散注意力。** 如果您正在阅读本书，说明您已准备好投入足够精力，以理解您被要求做出的决策。如果您的首席信息官无法帮助您了解所需了解的内容，那么您可能找错了首席信息官。

- **不要容忍董事会同事出现“眼神呆滞”的情况。** 如果其他董事似乎不投入，请寻求您的领导团队将对话提升到一个引人入胜的水平。找到一个能引起共鸣的类比，以阐明问题和需要做出的决策。使用示例。如果有必要，私下讨论；只有另一位董事才能指出这种行为所构成的问题。

- **寻求独立意见。** 使用类似前文“如何避免群体思维”的方法，以做出偏差更小、校准更好的决策。

- **避免“因筋疲力尽而达成一致”。** 杜鲁门总统手下的国务卿迪安·阿奇逊创造了这个短语，用来描述专家不屈不挠的情况。决策得以批准，是因为决策者希望讨论停止。

- **以勇气领导您的团队。**

- **采取知情且经过计算的风险。**

- **全力承诺。** 了解为实现所需结果需要付出什么。

技术治理的核心在于立即开始；之后会变得更容易。挑战自己，做得更好。请参见图 10.2 中所示的聪明问题。

#  buzzwords、缩写和合法术语

| 术语 | 定义 |
|------|------------|
| AASB | 审计与鉴证标准委员会（另见 ISAE） |
| Agile（敏捷） | 一种项目管理方法，尤其用于软件开发，其特点是将任务划分为短阶段工作，并频繁重新评估和调整计划 |
| Android 手机 | 由 Google 开发的智能手机操作系统（OS） |

# 人工智能（AI）

机器表现出的智能，与人类和其他动物展示的自然智能（NI）相对；通常定义为任何感知其环境并采取行动的设备；口语中，当机器模仿人类将其他人类心智与之关联的认知功能（如学习和问题解决）时

# 增强现实

对物理现实世界环境的直接或间接视图，其元素由计算机生成的感知信息增强；通常用于多种感觉模态，包括视觉、听觉、触觉、体感和嗅觉

# 条形码

数据的光学、机器可读表示，通常描述携带条形码的对象的某些信息或标识该对象；传统条形码通过改变平行线的宽度和间距来表示数据；最近，条形码包括具有独特识别能力的二维几何图案

# BCI

脑机接口（使用人类神经活动，信息被编码并用于刺激大脑）

# 大数据

极大的数据集，可以通过计算分析来揭示模式、趋势和关联，尤其是与人类行为和交互相关的关联

# 黑天鹅事件

偏离情况通常预期且极难预测的事件或发生；黑天鹅事件通常被认为是随机且意外的

# 区块链

一种分布式记账概念，具有独特的数字属性，可以管理独特访问并保持数据不可变

# CCSS

加拿大网络安全战略

# CFAA

计算机欺诈和滥用法（美国立法，禁止未经授权或超出授权访问计算机）

# CCIRC

加拿大网络事件响应中心

# CISA

网络信息共享法（美国）

# 封闭架构

一种技术规范未公开的系统；限制第三方构建与其接口或增强的产品；与开放架构相对

# 云计算

一种信息技术（IT）范式，能够普遍访问共享的可配置系统资源池和更高级别的服务，这些服务可以快速配置，只需最小的管理努力，通常通过互联网；通常被认为是依赖资源共享以实现连贯性和规模经济的计算，类似于公用事业

# 认知计算

在计算机模型中模拟人类思维过程；自我学习系统，使用数据挖掘、模式识别和自然语言处理来模仿人脑的工作方式

# 可配置

一种为计算机系统设置参数以管理输入的方法，允许管理员从定义好的参数或选项集中选择，而不是开发自定义软件代码来定义格式或选项。例如，大多数企业软件允许选择可用于姓名格式的可配置选项；头衔的选项可能很多，管理员可以定义一个更易管理的列表，简单选项包括 Mr.、Mrs. 或 Miss。更全面的选项集可能包括 Dr. 和 Ms.——这就是一个可配置的决定。

# COTS

常用现成软件，一个用于识别正在使用的行业标准软件而非定制或内部开发系统软件的短语

# CRM

客户关系管理，一种管理公司与当前和潜在客户互动的方法；通常使用关于客户历史的数据分析来改善业务关系；为客户分析、建模和保留提供基础数据来源的软件；通常被视为销售增长的推动者
