
在上一个输出中，`user` 字段显示累计 CPU 时间，`real` 字段显示墙钟时间。两者的比率约为 `7x`。该比率会因系统 CPU 核心数而异（此例中为八核）。若编译器能实现 `100%` 并行化，该系统比率可达 `8x`。注意，尽管使用了八核，实际执行时间提升仅约 `1.3x`。这可能是因为向量的分配和初始化占用了大部分时间。这是 **Amdahl 定律** 的一个案例：当可并行部分并行化后，程序的串行部分主导执行时间。尽管如此，我们的代码获得了 `1.3x` 加速，这是一个非常好的优化结果。

到目前为止，我们介绍了现代编译器中一些影响较大的优化特性。除此之外，还有其他优化标志，但性能提升可能不大。有两个特定优化标志适用于包含众多源文件的大型项目：**链接时优化** 或 **链接时代码生成**。这些值得在大型项目中启用。下一节将探讨源代码微优化。

### 源代码微优化

这些技术涉及在源代码中使用特定惯用模式，通常比等效写法更快。早期编译器不够智能，微优化效果显著。但现在编译器技术高度发达，微优化效果不再明显。尽管如此，养成这些习惯很好，因为即使不开启优化也能加快代码运行。即使在开发构建中，更快的代码也能节省测试和调试时间。下一节将介绍 `std::vector` 容器：

### 高效使用 std::vector 容器

`std::vector` 是标准库中最简单实用的容器之一。它比普通 C 风格数组无额外开销，却具备动态增长和可选边界检查能力。当元素数量在编译期未知时，几乎总应使用 `std::vector`。

`std::vector` 常见惯用法是在循环中调用 `push_back()` —— 随增长，向量会重新分配更大缓冲区（增长因子确切值取决于标准库实现）。理论上重新分配成本极低（因不频繁发生），但实践中，向量调整大小涉及将元素从旧缓冲区复制到新分配的更大缓冲区，开销可能很大。

若预知向量将包含多少元素，调用 `reserve()` 方法预分配存储可显著减少多次分配和复制。下一节通过练习优化向量增长。

### 练习 7：优化向量增长

本练习将计时对比循环中使用 `push_back()` 方法、是否调用 `reserve()` 的效果。首先将前几节使用的 `Timer` 类提取到单独的头文件和实现文件中，以便后续代码片段复用。按以下步骤完成：

5. 创建 `Timer.cpp` 并包含 `Timer.h`。在其中编写构造函数、析构函数和 `dump()` 方法的实际实现：

```cpp
#include <string>
#include <iostream>
#include <cstdint>
#include "Timer.h"

using std::map;
using std::string;
using std::cerr;
using std::endl;

// 构造时保存名称和当前时钟时间
Timer::Timer(string sName) : m_sName(sName)
{
    m_tmStart = std::chrono::high_resolution_clock::now();
}

// 析构时累加耗时并增加该名称下的计数
Timer::~Timer()
{
    auto tmNow = std::chrono::high_resolution_clock::now();
    auto msElapsed = std::chrono::duration_cast<std::chrono::milliseconds>(tmNow - m_tmStart);
    ms_Counts[m_sName]++;
    ms_Times[m_sName] += msElapsed.count();
}

// 打印每个被测代码块/函数的统计信息
void Timer::dump()
{
    cerr << "Name\t\t\tCount\t\t\tTime(ms)\t\tAverage(ms)\n";
    cerr << "-----------------------------------------------------------------------------------\n";
    for (const auto& it : ms_Times)
    {
        auto iCount = ms_Counts[it.first];
        cerr << it.first << "\t\t\t" << iCount << "\t\t\t" << it.second << "\t\t\t" << it.second / iCount << "\n";
    }
}

// 定义静态成员
map<string, int64_t> Timer::ms_Counts;
map<string, int64_t> Timer::ms_Times;
```

6. 创建 `Snippet5.cpp`，编写两个函数：均使用 `push_back()` 方法向向量填入前 `1,000,000` 个整数。第二个函数预先调用 `reserve()`，第一个不调用：

```cpp
#include <vector>
#include <string>
#include <iostream>
#include "Timer.h"

using std::vector;
using std::cerr;
using std::endl;

const int N = 1000000;

void withoutReserve(vector<int> &v)
{
    TIME_IT;
    for (int i = 0; i < N; ++i)
    {
        v.push_back(i);
    }
}

void withReserve(vector<int> &v)
{
    TIME_IT;
    v.reserve(N);
    for (int i = 0; i < N; ++i)
    {
        v.push_back(i);
    }
}
```
