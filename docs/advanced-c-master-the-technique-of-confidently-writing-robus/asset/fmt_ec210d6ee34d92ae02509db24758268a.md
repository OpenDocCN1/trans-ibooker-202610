## 总结

本章涵盖了大量复杂材料。优化代码是一项困难但必要的技能，对任何现代 C++ 开发者而言至关重要。机器学习、超写实游戏、大数据分析和节能计算的需求使这一领域成为任何 C++ 专业人士必须学习的重要内容。我们了解到性能优化过程分为两个阶段。

首先，优化始于适当的性能测量策略，测试条件需镜像真实世界的数据和使用模式。我们学习了通过多种方法测量性能——研究汇编代码、手动计时、源代码插桩和使用运行时分析器。一旦获得准确的测量数据，我们就能真正理解程序中哪些部分实际上很慢，并将精力集中在那里以获得最大改进。

第二阶段涉及实际修改程序——我们学习了几种策略，从为代码使用最佳编译器选项、使用并行化特性、利用配置文件数据帮助编译器开始，接着是一些简单的代码转换，它们在无需重大代码更改的情况下产生微小但有用的性能增益。然后我们学习了如何通过以对分支预测更友好的方式构建循环和条件语句来提高性能。

接着，我们了解了缓存对性能的显著影响，并研究了一些技术（如 SOA 模式），使我们的代码能利用现代 CPU 中的缓存。最后，我们通过一个真实世界的单词计数程序和简单的拼写检查器示例，将所有这些知识结合起来，进行实践。还有许多其他高级技术和理论需要在本章材料之上进一步学习，但我们在这里涵盖的内容应为任何学生未来的学习打下坚实基础。

到这些章节结束时，你已经探索了许多与使用高级 C++ 相关的主题。在前几章中，你学习了如何编写可移植软件，利用模板发挥类型系统的优势，并有效使用指针和继承。然后你探索了 C++ 标准库，包括流和并发，这些是构建大型真实应用程序的必备工具。在最后几节中，你学习了如何测试和调试程序，并优化代码以高效运行。在广泛使用的编程语言中，C++ 或许是最复杂、同时也是表达力最强的语言。本书只是一个开始，将为你继续深造提供坚实的平台。

### 活动 1：向项目添加新的源文件-头文件对

在此活动中，我们将创建一个包含名为 `sum` 的新函数的源文件-头文件对。它接受两个参数并返回它们的和。此文件对将添加到现有项目中。按以下步骤实现此活动：

1.  首先，在 *练习 3* “向 CMake 和 Eclipse CDT 添加新源文件” 中创建的现有项目中打开 Eclipse IDE。在 **Project Explorer** 面板中右键点击 **src** 文件夹。

    #### 注意

    我们可以分别创建 `.cpp` 和 `.h` 文件，或使用新建类向导稍后删除类代码。使用新建类向导很方便，因为它还会创建我们将利用的有用样板代码。

2.  从弹出菜单中选择 **New** | **Class**。输入 **SumFunc** 并点击 **Finish** 按钮。

3.  接下来，编辑 `SumFunc.h` 文件使其如下所示：

```cpp
#ifndef SRC_SUMFUNC_H_
#define SRC_SUMFUNC_H_

int sum(int a, int b);

#endif /* SRC_SUMFUNC_H_ */
```

注意，我们实际上将删除类并仅提供一个函数。我们本可以分别创建这两个文件。然而，**add class** 功能会同时创建它们并添加一些我们将利用的样板代码。在这里，我们的文件以 **include guard** 开始和结束，这是防止重复包含问题的常用策略。我们有函数的前向声明，这允许其他文件在包含此头文件后调用该函数。

4.  接下来，按如下所示编辑 `SumFunc.cpp` 文件：

```cpp
#include "SumFunc.h"
#include <iostream>

int sum(int a, int b) {
    return a + b;
}
```

在此文件中，我们包含头文件并提供函数体，该函数添加并返回两个给定的整数。

5.  编辑 `CMakeFiles.txt` 文件，使其 `add_executable` 部分反映以下代码：

```cmake
add_executable(CxxTemplate
    src/CxxTemplate.cpp
    src/ANewClass.cpp
    src/SumFunc.cpp
)
```

这里，我们将 `src/SumFunc.cpp` 文件添加到可执行源文件列表中，以便它被链接到可执行文件中。

6.  在 `CxxTemplate.cpp` 中进行以下更改：

```cpp
#include "CxxTemplate.h"
#include "ANewClass.h"
#include "SumFunc.h" //add this line
...
```
