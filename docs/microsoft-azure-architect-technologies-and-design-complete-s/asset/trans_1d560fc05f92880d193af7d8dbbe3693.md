## 评估测试答案

1. A, B, D. 使用 FTP 协议允许连接但不提供配置 VM 的任何手段。其他选项均有效。

2. B, C. 使用 SQL 可以创建由 Key 和 Value 命名的一列两列表；然而，其性能不如 Azure Cosmos DB 或 Azure Table Storage 产品。选项 B 和 C 均具有专门为键/值对数据库实现而设计的功能。

3. D. Azure Policy 提供了限制和强制执行基于资源管理和治理的限制的能力。内置的 Azure Policy 模板针对特定的区域和/或行业法规。也可以创建和应用自定义策略并在订阅范围内应用。

4. E. 请记住，你需要了解 Azure 上可用的所有产品，能够描述它们，并理解每个产品的用例。这将在考试中为你带来很大帮助。

5. D. 任何正确答案都需要包含 Action 值为 Deny 才可能是答案，因为问题是关于阻止连接流的。只有选项 D 包含 Deny 值，因此是正确答案。

6. C. 要使用 NSG 阻止连接，Action 值必须为 Deny。选项 D 中 NSG 的名称不是最佳名称，但名称对规则没有影响。选项 C 是唯一可能的答案。

7. A, C. 当你应用 NSG 时，它会实现在网络接口和 Azure 子网上。没有可能将 NSG 绑定到 Azure 虚拟机或虚拟网络。

8. A. 当 NextHopType 的值为 None 时，数据包会被丢弃。这将导致客户端收到数据包被丢弃的错误消息。

9. B. 正如该值的名称所暗示的，匹配 NextHopType 为 Internet 的数据传输会被路由到互联网。

10. C. 正如该值的名称所暗示的，匹配 NextHopType 为 VirtualNetwork 的数据传输会被路由到路由表条目所绑定的虚拟网络内的资源。

11. B. 你可以创建自定义用户定义路由 (UDR) 并将该前缀链接到任何受支持的 NextHopType 值。因此，答案是取决于它链接到什么。默认情况下它链接到互联网。

12. D. 2^(32-27) = 2^5 - 2 = 30。减去两个 IP 地址用于网络寻址（例如，172.19.3.0）和广播（例如，172.19.3.31）。
