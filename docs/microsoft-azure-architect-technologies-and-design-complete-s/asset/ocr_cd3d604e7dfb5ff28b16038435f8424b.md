# Add a Custom Domain to Azure Active Directory

In Exercise 2.1, you will add a custom domain to your Azure Active Directory. By doing this, you will be able to add users with that custom domain as part of their identity.

# EXERCISE 2.1

# Adding a Custom Domain to AAD

+   1. Log in to the Azure Portal at portal.azure.com.
+   2. Click the Azure Active Directory link, select Custom Domain Names, select + Add Custom Domain, enter your custom domain in the Custom Domain Name text box, and click the Add Domain button. See Figure 2.3.
