# Site-to-Site Overview

The section “Azure Relay/Hybrid Connection Manager” gets into a little more detail about the internals of S2S connectivity. In this context, S2S means the connection between a VNet in Azure or the series of VNets (i.e., pattern dependent) and some other network not on Azure. As illustrated in Figure 3.33, the connectivity is managed through a gateway subnet and a VPN tunnel.
