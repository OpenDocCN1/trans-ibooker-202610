Azure Active Directory 与 Azure 内部用于专门控制对 Azure 资源访问的安全机制之间存在区别。这种机制称为基于角色的访问控制，将在下一节讨论。这里需要注意的一点是，AAD 是一个可用于跨不同产品对用户进行身份验证的租户，而 RBAC 控制对 Azure 门户内 Azure 资源的访问。在下一节介绍 RBAC 时，你将授予用户对订阅的访问权限，并根据角色和组限制访问。
