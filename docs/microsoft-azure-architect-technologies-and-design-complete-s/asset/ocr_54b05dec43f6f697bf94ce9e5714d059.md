# Deploying with Visual Studio

If you are an individual developer working on a project alone, then this is by far the easiest way to get a relatively complex application deployed to Azure App Service. You can create an app service on Azure App Service directly in the Azure Portal. Using Visual Studio can be a bit challenging, so those who master it will also master the creation of complex code. Exercise 8.5 will guide you through the deployment of the code that you were introduced to in the previous chapter.
