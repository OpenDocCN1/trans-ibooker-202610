There are a few options that remained at their default settings. Let’s discuss them a bit more now, starting with Gateway Type. It is correct to assume that the configuration of ExpressRoute also requires a VPN gateway where the type is ExpressRoute. When you select the ExpressRoute radio button, the list of SKU types changes to those available for that type. The scenario for Exercise 3.12 is for a VPN, and therefore the default remained as VPN. The options available in the SKU drop-down list concern price, the number of tunnels, connections, and redundancy. Table 3.16 summarizes the limits.

# TABLE 3.16 VPN Gateway SKU Types

| SKU | Tunnels/Connections | Throughput | Zone Redundant |
|---|---|---|---|
| Basic | 10/128 | 100 Mbps | x |
| VpnGw1 | 30/128 to 250 | 650 Mbps | x |
| VpnGw3 | 30/128 to 1000 | 1.25 Gbps | x |
| VpnGw1AZ | 30/128 to 250 | 650 Mbps | ✓ |
| VpnGw3AZ | 30/128 to 1000 | 1.25 Gbps | ✓ |
