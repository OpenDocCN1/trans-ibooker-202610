There are two prerequisites to deploying to a virtual machine from Visual Studio. The requirements are the same if you were to deploy to any machine, whether on the Azure platform or not. First be sure the Azure virtual machine has an endpoint that you can deploy to. Ideally this would be a public domain or IP address. Second, the Azure VM must be configured to support ASP.NET web deployments. This means you need to have the Web Deploy module installed and configured on the Azure VM.
