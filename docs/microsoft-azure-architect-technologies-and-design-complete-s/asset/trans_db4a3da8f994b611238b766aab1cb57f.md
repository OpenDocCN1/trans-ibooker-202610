## 关于作者

**本杰明·珀金斯**目前在德国慕尼黑的微软公司担任 IIS、ASP.NET 和 Azure 应用服务的高级升级工程师。他在 IT 行业专业工作已有二十多年。他在11岁时用 Atari 1200XL 台式电脑开始用 QBasic 编程。他乐于接受技术问题排查带来的挑战，并享受编写优秀程序的回报。高中毕业后，他加入了美国陆军。成功完成兵役后，他就读于德克萨斯州大学城的德克萨斯 A&M 大学，获得管理信息系统工商管理学士学位。他还获得了欧洲大学的工商管理硕士学位。

他在 IT 行业的角色涵盖了整个范畴，包括程序员、系统架构师、技术支持工程师、团队领导者和中层管理。在惠普任职期间，他获得了许多奖项、学位和认证。他对技术和客户服务充满热情，期待排查问题并编写更多世界级的技术解决方案。“我的方法是带着支持意识编写代码，一次正确完整地编写，这样我们就不必再次回访，除非是为了增强它。”

本杰明撰写过多篇杂志文章和培训课程，并且是活跃的博主。他的书籍系列涵盖 C# 编程、IIS、NHibernate、开源和 Microsoft Azure。
