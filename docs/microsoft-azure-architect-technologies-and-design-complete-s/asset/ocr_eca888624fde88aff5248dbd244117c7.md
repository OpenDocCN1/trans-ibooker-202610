In Figure 6.24, the sender is illustrated by an Azure Web App and the receiver by an Azure Function. In practice, a sender can be any entity that has the ability to send a text-based message to the Service Bus endpoint. The same goes for a receiver. Any entity that has been granted access to the Service Bus can monitor the queue and, when a message is found, retrieve and process it. A scenario where you configure an Azure Function to monitor and process Service Bus queues is common. You can do the same with a Service Bus topic.
