Notice that the Insertion time of 11-Q2-1600 happened before the other message, which is what is used to enforce the FIFO processing of Azure Queue messages. Another interesting attribute of messages is the expiration time that has a default and maximum of seven days; the minimum is one second. After the expiration date threshold is breached, the platform logic removes the message from the queue.
