# Create a Conditional Access Policy

In Exercise 2.4, you will create a *conditional access policy* that will block all guest users who have a suspicious sign-in with a calculated value of Low when accessing the Azure Management Portal.

You need to take caution when you create conditional access policies. You can lock yourself out with ease. Make sure you have multiple accounts just in case you lock yourself out. There is the “What If” feature to check who is impacted by the new policy, but this is available only after you have applied it. Be careful.

This is a rather restrictive policy; however, I want to make sure no guest has any chance of abusing their access in any way. To clarify, the algorithm to calculate the risk level is proprietary and part of AAD. You simply need to configure it.
