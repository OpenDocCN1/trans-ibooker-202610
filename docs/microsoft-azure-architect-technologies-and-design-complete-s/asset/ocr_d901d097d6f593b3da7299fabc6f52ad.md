# TABLE 8.5 Azure DevOps Service Descriptions

| Service | Description |
|---|---|
| Boards | Provides an interface for work item assignment and tracking |
| Repos | The location to store and manage your application source code |
| Pipelines | An interface for building, testing, and deploying your application |
| Test Plans | A location to create and store application testing modules and plans |
| Artifacts | A single location to store application-dependent packages |
