# Understand Azure networking products

There are many Azure networking products, and they all have specific use cases and sets of features. Knowing the features of each, and knowing the requirements of your application are crucial in making the decision about which to use. This is important because many of the products have overlapping capabilities but also include unique features not available in other products. Azure Load Balancer, Application Gateway, and Azure Traffic Manager all have the capability to route traffic to a group of backend pool resources, for example; however, they are all a little different.
