The tool you should seriously consider using to move an Azure virtual machine to another region or virtual network is Azure Site Recovery (ASR). The best way to learn about this migration is by doing it. Complete Exercise 8.3 where you will move a VM to another virtual network in the same region. In Exercise 8.4 you will replicate an Azure virtual machine to another region.

# EXERCISE 8.3

# Moving an Azure Virtual Machine to Another Virtual Network in the Same Region

+   1. Log in to the Azure Portal at portal.azure.com.
+   2. Click the menu button on the top-left corner of the web page, click the + Create A Resource link, click IT & Management Tools, select Backup and Site Recovery, and enter the subscription and resource group into which you want the Recovery Service vault placed. Provide a vault name, enter the region, and click the Review + Create button. Now, click the Create button.
+   3. Once the provision has completed, navigate to the resource’s Overview blade and click the + Backup menu item. Select Azure and Virtual Machine from the drop-down lists, as illustrated in Figure 8.14; then click the Backup button.
