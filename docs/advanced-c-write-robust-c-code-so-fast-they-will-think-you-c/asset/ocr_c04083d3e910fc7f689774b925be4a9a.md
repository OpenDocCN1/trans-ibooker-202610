# Synchronous Execution

The term synchronous execution means that each subtask will be performed sequentially, one by one. In other words, this means that if we have a few tasks to execute, each of them can only start its work after the previous one has finished its work. This term does not specify a way to perform tasks, or whether they will be performed in a single or several threads. It only tells us about the execution order. Let's go back to the philosophers' dinner example. In a single-threaded world, the philosophers will eat one after the other.

The first philosopher takes two chopsticks and eats their sushi. Then, the second philosopher takes two chopsticks and eats their sushi. They take turns until all of them have finished their sushi.
