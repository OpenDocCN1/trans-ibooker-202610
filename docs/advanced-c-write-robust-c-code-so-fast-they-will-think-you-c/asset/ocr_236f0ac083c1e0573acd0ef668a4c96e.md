# Using Macros

In the activity for this chapter, we will use macro definitions to simplify and beautify our code, so let's do a refresher on how to use them. Macro definitions are preprocessor directives. The syntax of the macro definition is as follows:

```
```c
#define [name] [expression]
```
```

Here, [name] is any meaningful name and [expression] is any small function or value.

When the preprocessor faces the macro name, it replaces it with the expression. For example, let's say you have the following macro:

```
```c
#define MAX_NUMBER 15
```
```

Then, you use it in a few places in your code:

```
```c
if (val < MAX_NUMBER)

while (val < MAX_NUMBER)
```
```

When the preprocessor finishes its work, the code will be as follows:

```
```c
if (val < 15)

while (val < 15)
```
```

The preprocessor does the same work for functions. For example, let's say you have a macro for getting the maximum number:

```
```c
#define max(a, b) a < b ? b : a
```
```
