As the name implies, **scoped enumeration** places the enumerators inside the scope of the enumeration name. In addition, a scoped enumeration will no longer be implicitly converted into an integer (hence the if statement will fail to compile). You can still convert the enumerator into an integer, but you will need to cast it:

```
int value = static_cast<int>(Option::Play);
```
