# Activity 1: The Logging System for The Art Gallery Simulator

In this activity, we are going to develop a logger that will output formatted logs to the Terminal. We will output logs in the following format:

```
[dateTime][threadId][logLevel][file:line][function] | message
```

We will implement macro definitions for different logging levels that will be used instead of straightforward calls. This logger will be thread-safe, and we will invoke it from different threads simultaneously. Finally, we will integrate it into the project – The Art Gallery Simulator. We will run the simulation and observe pretty-printed logs. We will create an additional stream, use streams with concurrency, and format the output. We will implement almost everything that we have learned about in this chapter. We will also employ a synchronization technique from the previous chapter.

Thus, before attempting this activity, ensure that you have completed all the previous exercises in this chapter.
