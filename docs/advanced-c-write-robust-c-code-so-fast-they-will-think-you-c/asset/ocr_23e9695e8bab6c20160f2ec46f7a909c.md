There is a reason for the new feature in C++11 where alias declaration may be incorporated easily into templates – they can be templatized. A typedef cannot be templatized and while it is possible to achieve the same outcome with typedef, the alias declaration (using) is the preferred method as it results in simpler and easier to understand template code.
