Let's change our Dialog implementation to use smart pointers. Firstly, the header files changes to introduce the **#include <memory>** line and the destructor can be removed as the **unique_ptr** deletes the implementation class automatically.

```
#pragma once

#include <memory>

class Dialog
{
public:
    Dialog();
    void create(const char* message);
    bool show();

private:
    struct DialogImpl;
    std::unique_ptr<DialogImpl> m_pImpl;
};
```

Obviously, we remove the destructor from the implementation file, and we modify the constructor to use **std::make_unique**.

```
Dialog::Dialog() : m_pImpl(std::make_unique<DialogImpl>())
{
}
```
