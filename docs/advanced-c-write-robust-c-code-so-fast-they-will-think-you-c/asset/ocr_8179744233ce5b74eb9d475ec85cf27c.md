The programming language Python has a membership operator called "in" that can be used on any sequence, that is, list, sequence, set, string, and so on. Even though C++ has over 100 algorithms, it does not have an equivalent method to achieve the same. C++ 20 introduced the contains() method on std::set, but that is not enough for us.
