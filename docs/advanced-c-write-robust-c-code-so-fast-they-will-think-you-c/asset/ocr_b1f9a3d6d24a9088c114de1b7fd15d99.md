The **ios_base** abstract class is responsible for managing stream status flags, formatting flags, callbacks, and private storage. The **basic_streambuf** abstract class provides an interface for buffering input or output operations and provides access to the source of input, such as a file, socket, or sink of output, such as a string or vector. The **basic_ios** abstract class implements facilities for work with derived classes from the **basic_streambuf** interface. The **basic_ostream**, **basic_istream**, and **basic_iostream** abstract classes are wrappers for derived classes from the **basic_streambuf** interface and provide a high-level input/output interface, respectively.
