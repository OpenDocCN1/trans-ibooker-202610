To attain the preceding objective, we have the following definitions:

Addition  a/b + c/d = (a.d + b.c)/(b.d)  Multiplication  a/b × c/d = (a.c)/(b.d)
Subtraction  a/b - c/d = (a.d - b.c)/(b.d)  Division  a/b ÷ c/d = a/b × d/c = (a.d)/(b.c)
