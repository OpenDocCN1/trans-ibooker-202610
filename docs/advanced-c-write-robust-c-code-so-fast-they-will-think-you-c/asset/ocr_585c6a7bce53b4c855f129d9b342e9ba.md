# I/O Manipulators for Other Numeric Formatting

If you need to output a positive numeric value with a "+" sign, you can use another I/O manipulator from the <ios> header – the std::showpos function. The opposite of meaning manipulator also exists – the std::noshowpos function. They both have an effect on the output. Their use is very easy. Let's consider the following example:

```
std::cout << "Default formatting: " << 13 << " " << 0 << std::endl;
std::cout << "showpos flag is set: " << std::showpos << 13 << " " << 0 <<
std::endl;
std::cout << "noshowpos flag is set: " << std::noshowpos << 13 << " " << 0 <<
std::endl;
```
