## 短路逻辑运算符

&& 和 || 逻辑运算符是**短路**的，这意味着：

- 如果 || 运算符左侧为 **true**，则不计算右侧。
- 如果 && 运算符左侧为 **false**，则不计算右侧。

通过把更不可能成立（或开销更小）的表达式放在左侧，我们可以减少需要完成的工作量。在下一节中，我们将解决一个练习，学习如何最优地编写逻辑表达式。
