But it's more convenient to store a bunch of threads in an STL container, for example, the vector of threads:

```
std::vector<std::thread> threads;
```

STL containers cannot be used with objects that don't support copy semantic. Thanks to the move semantic, we can store non-copiable objects that have a move constructor and move the assignment operator to the containers. Then, we can use a vector of threads with the std::move() function. To initialize the threads in the container, we can do something like the following:

```
for (int i = 0; i < 10; i++)
{
    auto t = std::thread([i]()
    {
        std::cout << "thread: " << i << "\n";
    });
    threads.push_back(std::move(t));
}
```

Then, we can join or detach all of them:

```
for (auto& thr: threads)
{
    if (thr.joinable())
    {
        thr.join();
    }
}
```
