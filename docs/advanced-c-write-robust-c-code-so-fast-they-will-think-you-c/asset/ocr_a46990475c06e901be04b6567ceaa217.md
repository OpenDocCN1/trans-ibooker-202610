```
for (std::string::const_iterator iter = bufIn.begin(); iter != bufIn.end(); iter++)
{
    if (*iter >= 97 && *iter <= 122)
    {
        bufferOut += static_cast<char>(static_cast<int>(*iter) - 32);
    }
    else
    {
        bufferOut += *iter;
        getException();
    }
}
}
catch(const std::exception& ex)
{
    result.set_exception(std::make_exception_ptr(ex));
}

result.set_value(bufferOut);
}
```

# Note

There are a few ways to set an exception to the promise. First of all, we can catch std::exception and convert it into std::exception_ptr using the std::make_exception_ptr() function. You can also use the std::current_exception() function, which returns the std::exception_ptr object.
