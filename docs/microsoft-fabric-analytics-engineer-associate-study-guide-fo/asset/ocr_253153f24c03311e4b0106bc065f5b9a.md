The result of this DAX measure will provide the answer you’re looking for, but when you review it, you’ll see that you’re repeating one part of the measure twice:

```
CALCULATE([Total Units Sold], SAMEPERIODLASTYEAR('Date'[Date]))
```

Not only is repeating inefficient, but it also makes the measure appear far more complex than it is, making it harder to read. We can simplify this by using a variable. Here’s what this DAX formula looks like after we add a variable:

```
Units Sold YoY Growth % variable =
VAR PrevUnitSales =
    CALCULATE([Total Units Sold],
SAMEPERIODLASTYEAR('Date'[Date]))
RETURN
    DIVIDE(
        [Total Units Sold] - PrevUnitSales,
        PrevUnitSales
    )
```
