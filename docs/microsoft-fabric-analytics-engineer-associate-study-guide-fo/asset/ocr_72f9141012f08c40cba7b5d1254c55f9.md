Each calculation item has its own name and DAX expression. Some examples for time-intelligence are as follows:

# Month to Date

```
MTD = CALCULATE(SELECTEDMEASURE(), DATESMTD(DimDate[Date]))
```

# Year to Date

```
YTD = CALCULATE(SELECTEDMEASURE(), DATESYTD(DimDate[Date]))
```
