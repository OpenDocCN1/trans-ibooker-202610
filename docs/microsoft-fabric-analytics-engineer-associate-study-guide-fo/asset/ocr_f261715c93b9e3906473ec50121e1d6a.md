```
Sales blank to 0 =
IF(
    ISBLANK([Total Sales]),
    0,
    [Total Sales]
)
```

The results of this DAX measure would include a 0 instead of the NULL value (see Figure 6-14).

Visually, this might be more intuitive, but will it impact your calculations? In many cases, Power BI handles this surprisingly well. Say you use your “blank to 0” version in a DIVIDE() measure like this:
