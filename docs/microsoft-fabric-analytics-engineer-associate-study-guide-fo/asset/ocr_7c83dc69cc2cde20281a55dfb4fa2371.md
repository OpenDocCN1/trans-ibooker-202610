Using field parameters is a simple but powerful way to make your reports more flexible. Instead of showing everything at once, you can give users control over what they want to see. Whether it’s switching between dimensions or measures, field parameters help you keep your reports clean, focused, and easier to use.

# Limitations

There are a few limitations on field parameters that we need to keep in mind. We need to use a slicer to switch between the dimensions and measures, and when nothing is selected, everything is shown. This means we need to keep in mind that we need to activate “Force selection” for the slicer. Also, field parameters don’t work with a live connection, so the model needs to be in Import mode. They also only work with explicit measures.
