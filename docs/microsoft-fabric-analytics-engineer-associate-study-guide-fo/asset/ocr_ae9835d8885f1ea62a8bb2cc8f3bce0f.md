# Setting Up GitHub and Azure DevOps Version Control

We can configure version control at the workspace level in Fabric. To do this, we open the workspace where we want to enable version control and go to “Workspace settings.” Then, in the settings menu, we’ll find a section called “Git integration,” where we can choose and set up either GitHub or Azure DevOps (see Figure 8-1). We can link each workspace to only one of these options at a time, so we’ll need to pick the one that best fits our environment or organization.
