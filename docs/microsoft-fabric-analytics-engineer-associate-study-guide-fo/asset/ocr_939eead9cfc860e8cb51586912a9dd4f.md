When manipulating data from the Kusto database, you get the best experience if you use KQL. Yes, you could use the T-SQL language, and we’ll go into that in the next section, but the full experience and feature set comes from using the KQL script language.

Before we dive into where to find the KQL statements, you must know how to get started. The list of Microsoft Fabric Real-Time Intelligence items we included at the beginning of this section includes KQL querysets. These are special items that hold KQL queries and scripts to be reused or used as a form of documentation for future developers to read and understand.

You can create a KQL queryset in two different ways: through autocreation and by creating a standalone queryset.
