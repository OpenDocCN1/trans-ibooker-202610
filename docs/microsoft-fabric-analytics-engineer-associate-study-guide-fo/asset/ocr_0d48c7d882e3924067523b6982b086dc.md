# Viewing the Query Plan

You can right-click a specific step within a query box to view that step’s query plan (see Figure 4-14).

![](bbox=[0.14, 0.185, 0.86, 0.65])

Figure 4-14. View of query plan from visual query editor

In this query plan view, we can now begin to see the flow of data from the SQL database (on the right) to the native query (on the left). When you click “View details” in Value.NativeQuery, it will bring up the Value.NativeQuery statement on the right-hand side of the screen. When you click “View details” in Sql.Database, it will bring up the server name, the database name, and the options configuration of the connection (see Figure 4-15).
