# Benefits and Limitations of Version Control

Version control is not just a nice-to-have. It’s important for collaboration, auditing, and maintaining quality in Power BI and Fabric projects. Knowing who changed what and when makes troubleshooting faster and keeps everyone aligned. Even if we’re the only ones working on a project, over time, just keeping notes in our head will not be enough. Version control acts as a built-in history and documentation system that will save us time and headaches down the road.

But before we finish this section, we need to also look into the limitations of version control in Fabric:

+   - In GitHub, only cloud versions are supported; on-premises setups aren’t. Also, you can’t commit files larger than 50 MB all at once. If your changes are bigger than that, you need to split them into smaller commits. Also, GitHub doesn’t support cross-geo checks, which can cause issues if your team works in different regions.
