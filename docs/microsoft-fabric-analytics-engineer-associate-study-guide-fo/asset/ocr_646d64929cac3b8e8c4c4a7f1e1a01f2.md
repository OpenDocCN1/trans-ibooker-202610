# Modifying field parameters

Now you might wonder, what if I want to make a change to the field parameter, like adding a dimension or changing the sorting order? You can’t get back to the pop-up window that you used previously, but when you click on your parameter in the data overview, the DAX pane will open and you’ll see the configuration of your field parameter (see Figure 5-24).
