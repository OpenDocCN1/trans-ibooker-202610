Figure 6-23. Running sum measure in DAX for different years

The DAX for this is as follows:

```
DAX
Window Running Sum by Year =
SUMX (
    WINDOW (
        1, ABS, 0, REL,
        ALLSELECTED (
            'Date'[Year],
            'Date'[Month Of Year]
        ),
        PARTITIONBY ( 'Date'[Year] )
    ),
    [Total Sales]
)
```
