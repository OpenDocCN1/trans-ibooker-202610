# Dataflow Gen2

The Dataflow Gen2 Fabric workspace item is the new and updated version of Dataflow Gen1 that brings in a lot of new features and capabilities. It comes with a completely new backend engine and even more options to work with and load data from different sources.

As with Gen1, you find Gen2 in the Get data and Prepare data sections of the New item screen (see Figure 2-12).

When you select the Dataflow Gen2 option, the next window will ask you for a name and give you the option to disable “Enable Git integration, deployment pipelines and Public API scenarios” (see Figure 2-13).
