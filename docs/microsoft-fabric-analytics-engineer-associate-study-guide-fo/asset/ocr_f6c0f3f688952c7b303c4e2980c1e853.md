# Creating a Power BI Data Source File

To create a Power BI data source file, we can export an existing data source connection from one of our files. To do this, we need to open a Power BI report in Power BI Desktop, go to Home > Transform data, and then select “Data source settings” (see Figure 8-24).

![](bbox=[0.14, 0.34, 0.86, 0.55])

Figure 8-24. Opening the Data source settings to create a .pbids file

That will bring up all the data sources in the current file and the global permissions. If we want to export a data source in our current file, we can click on the data source and then click the Export PBIDS button at the bottom of the page (see Figure 8-25).
