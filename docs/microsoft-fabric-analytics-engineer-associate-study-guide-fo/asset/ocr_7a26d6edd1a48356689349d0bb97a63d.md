Also note that you can use the aggregate function to get distinct values, but then, you need a column across which to do the aggregation. But with the distinct function, you don’t need an aggregation column to get unique values.

# Filtering a Results Set

To filter your result set based on column values, you can use the where operator in your KQL statement, like this:

```
Weather
| where State == "FLORIDA"
```
