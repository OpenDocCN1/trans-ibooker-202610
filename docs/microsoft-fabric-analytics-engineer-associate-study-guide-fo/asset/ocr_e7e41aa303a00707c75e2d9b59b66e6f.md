# NOTE

The limits in this table correspond to the compressed size of the dataset in Power BI. The actual amount of data in the source tables can be much larger. Power BI uses highly efficient columnar compression, and typical compression ratios range from 5x to 10x. That means a 5 GB dataset in Power BI could represent 25–50 GB of raw source data.

To enable the large semantic model storage format, we need to go to the Power BI service, which is the online Power BI environment. There, we can either create a new workspace with the large storage format or change an existing one.

To create a new workspace, we select “New workspace,” go to the workspace settings, and select “Large semantic model storage format” (see Figure 5-34).
