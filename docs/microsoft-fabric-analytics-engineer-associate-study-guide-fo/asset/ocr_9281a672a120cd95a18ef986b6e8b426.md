# Using the Lineage View

In every workspace in Microsoft Fabric, you have two options for viewing items: as the default list or as a lineage view.

The lineage view button is in the top-right corner of the workspace. Figure 8-48 shows you the full lineage view.

![](bbox=[0.14, 0.27, 0.86, 0.57])

Figure 8-48. Lineage view in Microsoft Fabric

The lineage view shows you each item in the workspace, and their dependencies on each other. For instance, the Blob storage in the upper lefthand corner feeds data to the Finance lakehouse to its right.

You can select any item in the lineage view to highlight its connections and dependencies (see Figure 8-49).
