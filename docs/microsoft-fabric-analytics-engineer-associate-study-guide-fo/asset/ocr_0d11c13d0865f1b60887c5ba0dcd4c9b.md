Figure 8-12. “Source control” button showing one uncommitted change in the Fabric workspace

When we click the “Source control” button, a side window called “Source control” opens in the workspace. There, we’ll see the current branch, which is “main” in this example but could be any branch that was chosen. Below that, there’s a free text field where we can write a commit message describing the changes we’re about to commit. This is important, especially when working with others, because it helps everyone understand what each synchronization includes. We’ll also see a list of the items and their status (see Figure 8-13).
