# Other

This covers any remaining time not included in the preceding sections, including time spent preparing queries, waiting for other visuals to finish, or running background processes.

Instead of refreshing all visuals, you can also test one visual at a time by clicking the “Analyze this visual” icon (which is highlighted in Figure 6-10). This will refresh only that visual and display its performance metrics, which is helpful when you’re trying to identify a single visual that’s slowing down a page.
