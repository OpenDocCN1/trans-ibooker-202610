# Filtering in a Fabric Lakehouse with Dataflow Gen2

In Dataflow Gen2, we perform filtering visually in the Power Query editor. When we select a column that we want to filter, we can click on the arrow next to the column name and select the action. For example, in a date column, we can choose Date filters (see Figure 3-16).

![](bbox=[0.14, 0.28, 0.86, 0.68])

Figure 3-16. Filter options in Power Query for a date column

Here we can choose “is in the previous,” which will open a new window where we can define what we mean by previous, like the previous 30 days (see Figure 3-17).
