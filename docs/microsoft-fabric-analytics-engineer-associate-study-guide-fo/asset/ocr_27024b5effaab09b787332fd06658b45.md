# Counting Rows

To count the number of rows in a results set, you can use the count operator as shown here:

```
Weather
| count
```

This script will give you the results set (see Figure 4-23).

# Getting a Subset of Rows of Data and the First n Rows

You can take an arbitrary subset of data from a results set by using the take operator. This gives you the first n rows of data that the Kusto engine reads from the database. Here’s an example of how you can use the take operator:

```
Weather
| take 5
```
