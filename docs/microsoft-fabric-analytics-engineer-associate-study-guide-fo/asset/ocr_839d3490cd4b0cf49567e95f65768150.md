You’ll often need to create these tables yourself, since most data sources don’t deliver data structured like this. For each dimension table, you need to define a primary key, and for the fact table, you need to include foreign keys that reference the keys in the dimension tables. By creating the different tables and providing the keys, you create the base for a star schema in your lakehouse that Power BI can consume.
