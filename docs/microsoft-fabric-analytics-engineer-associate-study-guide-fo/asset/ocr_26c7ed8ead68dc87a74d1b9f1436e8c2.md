After we click on “Add account” we need to provide some information for Fabric to be able to connect to GitHub. First, we choose a display name, just for reference within Fabric. Next, we add a personal access token from GitHub, which we can generate in the developer settings in GitHub. This token authorizes Fabric to connect to our GitHub account securely.
