# Deduplication in a Fabric Warehouse with SQL

In a Fabric warehouse, we can use SQL to select only the rows that are unique by using the DISTINCT statement:

```
SELECT DISTINCT CustomerID
FROM orders_with_issues;
```

Figure 3-22 shows the results this statement produces.

We can also choose to remove duplicates based on specific columns:

```
SELECT DISTINCT OrderID, CustomerID, OrderDate
FROM orders_with_issues;
```
