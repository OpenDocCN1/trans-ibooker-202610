# Show similarity scores

Checking this box adds a new column to the dataset that includes the scoring of the similarity match done by the engine. The score and the number in the column will have the same possible values as the ones you can configure in the “Similarity threshold” mentioned previously.

# Number of matches

From the UI, we get this description when we hover our cursor over the circled i:

+   - This option controls the maximum number of matching rows that will be returned for each input row. For example, if you only want to find one matching row for each input row, specify a value of 1.

This almost says it all. If you want to control the output of matching rows within the threshold of the setting, you can set this value to a different number. Note, though, that if this value is higher than 1, the resulting row will be copied for each match and we’ll have to do the selection ourselves.
