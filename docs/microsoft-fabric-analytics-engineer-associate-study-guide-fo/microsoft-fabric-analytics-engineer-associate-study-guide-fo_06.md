## Part II. Implementing and Managing Semantic Models

在接下来的两章中，我们将学习如何在 Power BI 和 Microsoft Fabric 中设计和优化语义模型。

在第 5 章中，我们将指导你使用星型模式、关系、字段参数和计算组等最佳实践构建高效、结构良好的模型。我们还将看看当我们拥有非常大的语义模型时，使用大型存储模型我们可以做什么，以及复合模型如何帮助我们在具有不同导入设置的不同数据源时。

在第 6 章中，我们将专注于使我们的语义模型在规模上表现良好。本章涵盖了加快查询和可视化的基本技术，优化你的数据分析表达式（DAX）代码，以及配置增量刷新等高级功能。

这两个章节共同为构建可扩展、可维护且高性能的语义模型奠定了基础，这些模型可以支持现实世界的业务需求。阅读这些章节将帮助你不仅了解如何构建语义模型，还了解如何在企业环境中使它们高效可靠。
