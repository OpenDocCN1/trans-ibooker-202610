# Abstract

Retrieval of accurate medical information is a big challenge in today’s time due to the enormous growth of medical literature. Ontologies are used to enhance databases in different levels and can be used to eliminate vagueness in the structured query language of the database. Here we depict ontology based information retrieval from medical literature database MEDLINE. The main focus of this article is to enhance the features of information retrieval of medical literature database and make more clarity to the search. In this research, our approach is a preliminary design and execution of ontology based intelligent agent system with application of Semantic Web language which benefits efficient systematic retrieval of medical information.

MEDLINE Ontology system will be very useful in the area of medical and health sciences. Medicine information details can be retrieved with a much easier way. It will reduce the cognitive burden of MEDLINE information search. It can be overcome difficulty faced in the traditional database and provides more accuracy level of semantic outcome for the query. To get a better accurate result, the precision of the query can be tested with the help of reasoners. The present research dealt with the application ontology based intelligence system for the semantic search in the field of medicine. The domain ontology was created and the system includes various phases namely pre-processing, rule based approach and reasoning of the user query. At the final stage, the validity was checked, the correctness of the query was identified with the help of reasoner, and most relevant result was established.
