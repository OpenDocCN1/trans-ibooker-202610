HPO-based phenotype analysis also permitted the matching of human phenotypes to mouse phenotypes through crossover testing, thereby helping to discover a dominant enhancement of SRC functional mutation that causes thrombocytopenia, myelofibrosis, bleeding and bone abnormalities [37]. The Matchmaker Exchange Platform (MME) offers a systematic strategy for the discovery of rare gene disease with an integrated phenotype-genotype database network allowing data sharing and data discovery [37] through a robust API [29].

The HPO is the main repository by phenotype for data exchange. Currently, MME connects over 30,000 cases of uncommon diseases to patients through six separate repositories. The HPO is a computational method enabling algorithms to “calculate over” clinical phenotype data through a growing number of HPO Cooperative tools and other classes mentioned in Table 9.3. The tools use the ontological structure of the HPO that allows the connection of individual words to a knowledge content, a specificity metric, or the underlying conceptual meanings of the words, so that HPO terms can be related to other resources such as models.
