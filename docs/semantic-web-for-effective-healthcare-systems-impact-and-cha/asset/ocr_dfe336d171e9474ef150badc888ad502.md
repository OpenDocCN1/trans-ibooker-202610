**Descriptive analytics** as the name implies refers to the statistical inference of the data which can be used for other operations in a useful way [9]. It is more data-driven and is describes the data “as is” and hence the name. It uses a lot of visualizations. This can graphically represent details about patient’s hospitalizations, physician performance, and utilization of resources to name a few. Queries about patient’s count, revenue generated, identifying high-risk patients are all answered using descriptive analytics.

As evident from its name Predictive analytics makes predictions about unknown future events with reasoning using advanced analytics [9]. Predictive analytics. In the healthcare sector, Predictive analytics enables decision making allowing personalized care for each individual. To implement predictive analytics, it requires a large volume of real-time data to be generated accurately, and precise information for clinicians [12].

The blending of clinician minds and software tools yields predictive analytics whose main objective is to widen training data set beyond individual experiences and in turn, helps in giving timely and accurate treatment to patients.

**Prescriptive analytics** refers to the type of data analytics that recommends actions for smart decision-making [17]. It can tell a user what course of action would produce the highest likelihood of maximum benefit when a predicted event does occur. So it does provide information, not just about answers to a certain question but also the consequences of those choices.

# 5.3.1 Artificial Intelligence/Machine Learning-Based Predictive Analytics

Healthcare Analytics and Artificial Intelligence (AI)/Machine Learning (ML) go hand in hand to reach out to the patients without them even realizing it [18]. Machine Learning can be deployed for various pivotal applications in healthcare such as machine learning based behavior modifications, clinical trial and research, and epidemic prediction. Moreover, machine learning for image analysis is more popular in healthcare (for example, cancer cell drug sensitivity prediction drug targeted interaction strength prediction, etc.).

Currently, image-based diagnostics focus on machine learning based on deep learning and radionics. These aim to extract, structured, reproducible, quantitative, machine-readable information out of medical images, and supplement the prognosis of a medical practitioner.
