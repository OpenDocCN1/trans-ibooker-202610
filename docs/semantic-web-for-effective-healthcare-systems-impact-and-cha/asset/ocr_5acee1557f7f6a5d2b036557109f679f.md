# 6.3.1  Architectural Diagram

The research emphasis the features of information retrieval from medical literature database and improve the quality of the search with the help of ontology based system. The overall process consists of various phases which include the pre-processing procedure, keyword extraction construction of rules and query reasoning. In the last step include the validation technique implementation which will help to produce the net effect of most relevant and accurate result.

The primary step of this process is the knowledge extraction and followed by preprocessing. The Parts of Speech (POS) method is used in which the grammatical medical information type is assigned to each word in a text. The POS tagger used by the system search information from the user query. The search process within the ontology can be demonstrated by the stemming method, which helps to identify the root word of the medicine. The system will provide the result of the query of the existing medicine information stored in the ontology. If it is not, the ontology is updated with a novel key word. The query can be understood in a better way with the help of parse tree method. The ontological parser has two important functional elements namely lexer and a parser. The sentence lexers take a sentence and change that into a sequence of ontological entities and parser which convert the sequence of ontological entities into predicate structures.

SVM based tagger was used in Tej Bahadur *et al.* [39] study in which, it showed an efficient, portable, accessible, and trainable. Support vector machine (SVM) was introduced in supervised learning method and showed good performance and generalization ability. SVM has been effectively implemented in text classification and revealed that SVM can handle enormous features and is resist of over fitting [39].
