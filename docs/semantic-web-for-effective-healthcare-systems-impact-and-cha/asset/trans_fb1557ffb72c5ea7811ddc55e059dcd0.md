# 生物医学科学与医疗保健信息学中的机器学习

**系列编辑：** Vishal Jain 和 Jyotir Moy Chatterjee

本系列的重点集中于机器学习在生物医学工程和医疗保健领域中的各种应用，特别强调最具代表性的学习技术，即基于深度学习的方法。机器学习任务通常根据学习系统是否可用“标签”或“反馈”分为两大类：监督学习和无监督学习。本系列还介绍了生物医学工程领域中的各种机器学习任务，从分类（监督学习）到聚类（无监督学习）。该系列的目标是汇编生物医学科学和医疗保健信息学的各个方面，从基本原理到当前先进概念。
