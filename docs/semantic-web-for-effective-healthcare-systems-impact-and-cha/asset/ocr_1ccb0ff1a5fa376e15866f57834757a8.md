# 10.3.1 RDF Model and Technology

The RDF model is based on describing the resources using properties that also the attributes or characteristics. The properties are uniquely identified using the Uniform Resource Identifier (URI) and the resource corresponding to the property are identified using the property type which has its matching values. The property type links a resource to a value that could be another resource or an atomic value or literals like a data value having text strings or integers. A description is a group of properties linked to the same resource. RDF is founded on its capacity to represent a resource and its descriptions using a syntax independent model [43–45, 47].

The resource, its property type and the property value form a triple in which the resource is the subject, its property type is the relationship or predicate and the property value is the object. The RDF model consisting of the triple form the foundation of the RDF technology and is the basis for the integration of data from various heterogeneous data sources. The RDF technology allows the data from varied source to be formatted as a semantic description containing the description of resources and the relationship between the resources. Such liberty in representing data is the reason why RDF technology is popular in knowledge representation for knowledgebase systems and artificial intelligence. The basic requirement for RDF technology is that the resources are identified by the URI and the fundamental conditions for data exchange, that is, the data is represented as a set of triples. Duplication of triples is to be strictly avoided but it does not matter in which position the triple is placed [48, 49].

# 10.3.2 Metadata and URI

The word metadata was probably first used by Philip Bagley in 1968, in his book “Extension of Programming Language Concepts” in which he describes metadata as a secondary data element like an identifier or an access code that contains information about the contents of the primary data element. He terms such information containing secondary elements as the metadata elements. Earlier to it, the word metadata was used to describe publications, library catalogs, subject indexes, various classifiers, and article abstracts. From the early stages of the development of computer systems, although the word metadata was not specifically mentioned, the features of metadata were visible in the properties of source code, compiler design and file storage.
