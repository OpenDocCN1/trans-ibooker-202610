The native systems can be further classified as those that make use of the main memory and those that use disk storages. The main memory storage relies on parsing and loading the RDF files in a portion of the main memory which may be indexed for faster retrieval. The disk storage models make persistent use of indices which causes an operational bottleneck. The non-native RDF stores make use of the existing well-developed database systems to store RDF data. These RDF stores use either a relational database or a NoSQL backend for storage and retrieval of information. The relational database that is used by non-native RDF stores could be a schema-based or a schema-free approach. In comparison, the native approach is more efficient than the non-native approach for a knowledgebase system although it requires a lot of effort in the design and implementation of such systems [60, 62, 66].

# 10.4 Knowledgebase Systems and Knowledge Graphs

The knowledgebase is a storage of knowledge in a structured form using knowledge representation techniques on which a knowledgebase system can be built [67]. Knowledge can be defined in so many different ways that there is no single definition that encompasses its complete meaning [68–70]. For knowledgebase systems, knowledge can be defined as processed information that is used to solve a given problem. So, the various solutions to the problem for which the system is designed are representatively stored in the in a knowledgebase of the system. The system then retrieves the relevant knowledge from the knowledge base when required.

# 10.4.1 Knowledgebase Systems

Knowledgebase Systems are systems that hold solutions to problems of a particular domain in their knowledge base. The knowledge-based systems sprouted out of expert systems that were itself an offshoot of Artificial Intelligence [71]. Knowledgebase systems and expert systems were terms interchangeably used because the expert systems that were developed earlier contained knowledge of experts coded in the system, they performed tasks like human experts and were used to solve problems [72].
