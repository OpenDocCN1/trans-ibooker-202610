Though semantics is key to interoperability and integration of health-related data, assessing semantic heterogeneity in domain-associated data elements is very challenging. Brown et al. [34] use an expert-based method that complements a data-driven method to assess semantic heterogeneity for empirically generated data elements in HIV-associated data dictionaries. Integrating biodiversity data from distributed heterogeneous sources for research is challenging because of the variety of terms, vocabularies, and languages used to record data. Laurenne et al. [35] contrast using a traditional relational database with Linked Data approach for expressing taxonomic information within the checklists of species being studied. Being compatible with Linked Data, semantic web technologies nicely describe species checklists. As an added advantage, Linked Data prevents formation of silos in absence of inter-linkable distributed information.

Without semantic interoperability, integrating data trapped inside various clinical registries designed on vendor-specific custom information models is a humongous task. Lu et al. [36] propose a solution based on openEHR for the problem of semantic interoperability of clinical data registries. They verify the feasibility of the proposed approach using a Coronary Computed Tomography Angiography registry. Similarly, to open access to rich sources of health data for secondary data usage, full interoperability within and between population-based patient-registry domains needs to be enabled. Nicholson et al. [37] discuss an implementation that is based on the concept of federated semantic metadata registries.

Like health IT applications, the Internet of Things (IoT) enabled smart home devices and wearable health devices record vast amounts of data in silos. Unavailability of easy to adopt common standards hinder integration of health data from the heterogeneous eHealth and IoT data models. Peng et al. [38] present a method to incorporate health data with data from home environment using heterogeneous implementation of health services and Web of Things services. Zhengru et al. [39] propose a lightweight, extensible, and configurable framework for building clinical NLP systems with external NLP APIs. Their solution is programming language independent, fast to develop, cost-efficient and flexible. Also, users have the freedom to choose an NLP API vendor and integrate with multiple APIs for unfamiliar NLP tasks for better results.
