# 2.4.4.1  *Phishing Attacks*

Phishing attacks are becoming more common nowadays and the user must be educated on the possible threat are hiding in their inbox. It can be coming from email, text messages, or can be from web chat links. It will be looks like the general message which is deal with by users daily. It is generally a kind of link which redirect user on the suspicious website and ask from the user for the credentials [25].

These types of attacks can be failed by the smartness of the user. The hospital staff and general user as well should make sure the link is coming from an authenticated source or not. If it is not then the user should not open the link and mail or even download any attachment coming from the unknown link, mail.

# 2.4.4.2  *Malware and Ransomware*

Malware is a type of program which can enter into the system through several channels such as network, downloaded file, and utility software. They hack the access and sneak the information or can be damage the system.

Ransomware is very popular on the list because the semantic web is frequently updated and also stored much information, so they are ideal for hackers. This type of attack is dangerous because the patient can suffer in emergency conditions. There is a need to make a strong network so the hackers are not able to acquire the access which they are looking for. Additionally, IT staff should also continuously inspect the network for the possible loophole for malware [25].
