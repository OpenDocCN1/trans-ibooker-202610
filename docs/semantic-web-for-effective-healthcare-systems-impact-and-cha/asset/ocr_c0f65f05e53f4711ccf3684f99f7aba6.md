Using this data or information, compatibility can be generated between human, machines, devices and services. Ontology plays an important role for generating compatibility between various machines. In order to provide complete compatibility between the systems, their semantic web based content should be same. Ontology basically represents the design or structure of information representation of any system. In Healthcare sector, a large amount of information has been used. For utilizing this data for various reasons, this data must be shared among machines. Hence ontology is used as information foundation for a common architecture in Healthcare based system. IoT based devices are much widespread these days as it has the capability of sharing the data universally and precisely. Healthcare sector aims at providing customize service to individual patient. In order to achieve this aim, IoT based system gathers data of remote patients with the help of various sensors and IoT based devices and transfers that data to the healthcare professionals for offering the patient’s prompt and good service of treatment. The whole system works by collecting data from healthcare based gadgets like BP Monitor, Sugar Monitor, etc., to smart devices and further data from the smart devices will be transferred over cloud. While transferring these data, the system also takes care of data security and accuracy.
