## 2.4.7 Standard for Data Protection

As the healthcare data is going to be digitalized and advance. The new types of threats are coming into knowledge for healthcare records. In starting there was no strong policy for security and privacy. Additionally, given these emerging threats, there is a need for a strong healthcare protection standard.

The United States (US) imposed several rules and regulations, which also includes privacy and security rules under HIPAA (1996) and State Alliance for eHealth (2007).

In the U.S healthcare provider strongly influenced by the HIPAA regulations. It confirms that the healthcare provider and organization are up to date and also fulfilling the latest requirement. It also ensures that the organization and healthcare basically HIPAA includes two key primary components.

Managerial, physical, and technical dealing with personal health information requires some standards which are described by security rules.

HIPAA Security Rule—HIPAA security provides security for digital health information. It protects the creation, utilization, and backing of healthcare data. This is provided by HIPAA covered organization. The main motive of this rule is to set the standard managerial, physical, and technical dealing with electronic health information [29].

HIPAA Privacy Rule—Privacy is very important for the health record because the health record contains very sensitive information. There is a need to provide the safeguard for the health record, insurance record, hospital record, lab report, and other private details. This HIPAA privacy rule protects the information from misuse by controlling the usage of information [29].

### 2.4.7.1 Healthcare Standard in India

Let us discuss the security and privacy policies in India as well. There are three standards for security and privacy

- 1. Security technical standards
- 2. Administrative safeguards standards
- 3. Physical safeguards standards

### 2.4.7.2 Security Technical Standards

The actual purpose of this standard is to secure and protect data as per technical aspects. Healthcare includes the following requirements (30).

- 1. Authentication
- 2. Automatic log off
- 3. Access control
- 4. Access Privileges
- 5. Audit log
- 6. Integrity
- 7. Encryption
- 8. Digital Certificates

### 2.4.7.3 Administrative Safeguards Standards

This Safeguard needs healthcare service providers to create and execute security the executive's procedure that incorporates arrangements and strategies that address the full scope of their security weaknesses. It includes a security management process standard, assigned security responsibility, security awareness program, information access management, security incident procedures, evaluation [30].

### 2.4.7.4 Physical Safeguard Standards

Physical safeguards standards are safety efforts to secure a healthcare service supplier's electronic data frameworks, related hardware, structures lodging the frameworks from common and natural dangers, and unapproved interruption. Medicinal services suppliers must satisfy the accompanying guidelines. These types of standards are access control standard, workstation utilizes standard, workstation security standard, gadget, and media device controls standard [30].
