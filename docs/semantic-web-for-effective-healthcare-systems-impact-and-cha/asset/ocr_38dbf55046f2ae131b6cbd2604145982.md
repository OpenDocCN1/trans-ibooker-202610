# 10.5.3 Evaluation Methodology

There are many measures that are used to evaluate the knowledge base. These measures are based on whether the RDF triple is relevant or irrelevant to the particular knowledge base. Accordingly, a contingency matrix of positives and negatives can be formed as shown in Table 10.1. If the RDF triple that is retrieved by the query is relevant it is true positive otherwise it is a false positive. Similarly, if a relevant triple is not retrieved then it is a false negative and if it is not relevant and not retrieved, it is a true negative. For the knowledge bases curation, measures such as precision, recall, accuracy, F-measure, G-measure, error rate, miss rate, fallout and so on could be used on the RDF triples that are retrieved from the relevant RDF triples in the document [125, 126].

Evaluation of the queried result is done also using community benchmarking campaigns such as the Text Retrieval Conference (TREC), Initiative for the Evaluation of XML Retrieval (INEX), DBpedia-Entity Test Collection and so on which makes use of text collections consisting of a dataset, a set of information needs and the corresponding relevance assessments [127].
