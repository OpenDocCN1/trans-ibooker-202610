# 11.5.4 UMLS Data Access

The access to UMLS information sources does not require any expenses. However, UMLS clients are expected to agree to a licensing agreement before the information is obtained. Under this arrangement, all vocabulary may be used within a base for research purposes, although some vocabularies for different purposes may be limited in use. UMLS sources are both CD-ROM and FTP available.

The social documents of the UMLS can be stacked and accessed via SQL requests. On the contrary, an item-situated UMLS model has been late developed that allows customers to assemble Java applications against the NLM archive through an API, much like XML queries. The Knowledge Source Server is an online tool for the collection and dissemination of UMLS data. These three components expect UMLS licensees to be customers.
