+   - **Ranking Results:** Based on keywords and concepts highlighted from background knowledge (i.e., ontologies) and uses Proxy-Based Solutions. The filtering mechanism reduces the search results substantially to small number of relevant results.

# 4.3.4.3.8  BioTCM

It is a semantic search engine prototype for IR of Modern biology and Traditional Chinese medicine. It builds an ontology that combines contents from different data sources and convert it into RDF format based corresponding ontology schema [15]

+   - **Ranking Results:** A web application is offered using which biomedical knowledge can be browsed through a single access point. SPARQL is used for execution of the user query based on semantic rule set.

# 4.3.4.3.9  BEST

It is Keyword based search engine that extract entities from text [44] based on a dictionary-based approach. For construction of entity dictionary, entity names from 12 different sources have been integrated. Then entities and abstracts are indexed based on document-entity list pair indexing.

+   - **Ranking Results:** Common search operations such as Boolean operators, proximity search and term boosting are supported. The results are based on:
+     - Term match score (T<sub>d</sub>(q))
+     - Entity number score (N<sub>d</sub>)
+     - Reputation score (Q<sub>d</sub>)
+     - Recency score (R<sub>d</sub>)
