Kumari et al. follows the traditional Term Frequency Inverse Document Frequency (TF-IDF) method and uses a dictionary of data for the specific domain. The dictionary defines the synonyms of each words and the semantic similarity between words can be calculated by TF-IDF. It is an information retrieval technique in which the weights of the relevant words of documents can be calculated [6]. Escalante et al. developed a framework for the study of combining the set of basic words to discriminative term weighting system [9].

Narula et al. developed a Multimedia Information Retrieval (MIR) Model handling different data types including text, images and video documents [10]. It uses different IR techniques Extended Boolean Approach, Bayesian Network Model, etc., which provide relevance thus satisfying user’s query.

Amir Zidi and Mourad Abed described a generalized framework public transportation system using ontology which supports to retrieve information related to a public transportation system. Here the semantic information about the public transportation system extracted from different data source and mapping will be done through the ontology. The scalability is an improved version for entity based semantic indexing retrieval method. Finally, it evaluated with real world data sources and provides meaningful search results [13].

Suganyakala and Rajalaxmi developed a framework for movie related semantic search system using ontology. This framework aims to solve the limitations of traditional information retrieval and improve retrieval effectiveness. A query interface requires the user input in their natural language and movie domain-specific ontology is developed to give the output. The semantic ontology prototype proposed model improves search accuracy [15].

K. Soner et al. developed an ontology-based retrieval system using semantic indexing. It deals with the issues in semantic search, namely, usability, scalability, and retrieval performance and proposed to a keyword-based semantic retrieval approach [16, 24].

Turhan deals with on the importance of Description Logic reasoning for Semantic web ontologies. There are families of knowledge representation formalisms that have formal semantics. This family of logics is represented the terminological knowledge of an application domain in a structured manner [20, 29].
