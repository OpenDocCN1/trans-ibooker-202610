The correctness of the query must be validated with the support of reasoner. Figure 3.1 shows the conceptual diagram for Patient’s Monitoring System and explains the different phases of the system.

In the pre-processing, the system utilizes a Parts of Speech (POS) tagger, which helps to identify the search terms from the user input query. The stemming process must be applied to find the root word and the search has been established within the ontology. If the word is already stored in the ontology, the system will give the result for the query. Otherwise, the ontology has to be updated automatically with the new keyword. Then the parse tree has to be constructed to understand the query in a better way. From the pre-processed keyword, the similarity measure must be done with the words in the ontology. TF-IDF (Term Frequency—Inverse Document Frequency) method is used for weight calculation and distance measure between words.

The ontology system also supports rule which helps to infer new knowledge. In OWL (Web Ontology Language), rules are expressed with the help of SWRL (Semantic Web Rule Language) is the rule language of the semantic web. With the support of Description Logic, there is a necessitate writing SWRL rules for the given concept and the relationship with the classes. Reasoner is used to derive the information from the knowledge base with the help of the inference engine. Reasoners detect inconsistent ontologies. The entire searched keyword is checked for the correctness with the three reasoners, namely, Fact++, HermiT, and Pellet. Pellet is the best reasoner by comparing the other two reasoners because of its debugging feature. The inference engine supports to generate new rule on the search keyword. The correctness of the inference is validated by the reasoned. Finally, the information has been retrieved by SPARQL. SPARQL is the query language
