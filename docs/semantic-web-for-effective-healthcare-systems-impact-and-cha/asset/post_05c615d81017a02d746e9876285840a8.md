## 4.2.2 Scope and Benefits of Semantics in Healthcare Systems

Semantic web technologies have become a key driver for innovation and change in many domains, including eCommerce, education, eGovernment, entertainment, healthcare, social networks, and software engineering, among others. Semantic Web technologies and semantics provide us with a new approach to information management and processes, the basic principle of which is the creation and use of semantic metadata. Metadata is a data set that provides information about other data [6]. The use of semantic metadata is also crucial for integrating information from heterogeneous sources, whether within an organization or across organizations. Various schemes are used to describe and classify information, and different terminologies are used together with information. By creating different schemes, it is possible to create a unified view and achieve interaction between processes that use the information. Semantic descriptions can also be applied to processes presented as web services. When the function of an Internet service can be described semantically, then the web service can be more easily detected. When existing web services are provided with metadata describing their function and context, then new services can be automatically compiled from a combination of existing services.

## 4.2.3 Issues in Incorporating Semantics

Semantic Web enabled solutions can provide end-to-end solutions for information sharing among all the stakeholders and in a meaningful way [6].

Information is stored in heterogeneous distributed Health Information Systems, in different file formats which are mainly proprietary [3]. So, the systems sharing information need to be interoperability compatible so that the semantics of the shared information are preserved, and no information is lost due to semantic and syntactic differences [7]. Some of the issues that need to be considered are [8]:

- **Common Standards/Guidelines:** For information sharing and reuse, it is required to analyze and decide upon the rules to resolve policy-conflicts so as to ensure that the modified rule is syntactically and/or semantically valid.
- **Ensuring mapping of data:** Taking attributes and values from different systems and combining them often results in semantic differences, which further leads to partial mapping of data. This happens due to incompatible or non-formalized structuring of data.
- **User involvement:** Developing systems for users involve them to as to correctly identify all common terms and their meanings. If this is not done, it leads to undue disclosure of data.
- **Domain vocabulary:** creation of a vocabulary with correct identification of terms with multiple meanings that can be used to determine the semantic relationships between one attribute value and another.
- **Ontology Mapping:** to reach out to an optimal solution which fits in globally across the domain for mapping concepts from different ontologies. Semantics associated with them also need to be considered.

## 4.2.4 Existing Semantic Web Technologies

In simple words, Semantic web adds meaning to information which further enables computers and people to work in cooperation. Semantic technologies are emerging and several applications ranging from business process management to information security have demonstrated encouraging prospects of its benefits.

The Semantic Web Stack shown in [9] illustrates the architecture of the Semantic Web. The functions and relationships of the components can be summarized as follows [9].

- XML is a markup language that defines the elemental structure within documents.
- XML Schema describe the structure of XML document.
- RDF refers to objects and their relationships and provides language support to various data models.
- RDF Schema is a basic vocabulary for describing hierarchies of properties and classes.
- OWL extends vocabulary support for properties and classes.
- SPARQL is a protocol and query language for semantic web data sources.
- RIF is an XML language for enabling rule exchange that different systems can execute. It stands for the Rule Interchange Format.

## 4.3 Searching Techniques in Healthcare Systems

Search engines retrieve documents for a user’s keywords from a large index and rank them by various criteria. While such keyword-based search is fast and powerful to retrieve single documents, it is far from the vision of answering a user’s questions by “understanding” the user’s query. Web is also accessed to obtain medical and health information by the general public [11]. It has been found that the most common health and medical topics searched on the Internet are about a specific disease or medical problem, certain medical treatment, diet, nutrition and vitamins, and exercise or fitness, as well as prescription drugs [11]. In particular, researchers have classified and analyzed the information needs of users to improve search engines [11]. A medicine-related information search is different from other information searches, since users often use medical terminology, disease knowledge, treatment options, and so on.

### 4.3.1 Keyword-Based Search

Keyword-based search will give output in response to the term entered by the user but one also need to search using synonyms and variations of the search term to make sure that you have retrieved all of the relevant records [12].

For example, if the user is looking for information on “heart attack” using a text word search, it is also needed to search using the terms “heart attacks,” “myocardial infarction,” “myocardial infarctions” and so on. However, keywords are often ambiguous and could have multiple meanings. For example, given a keyword ‘Alzheimer’, the user intent can be searching the information for this disease or for some drugs to treat it [13].

To address this problem, *semantic search* was proposed to improve search accuracy by understanding user intent and search context.

### 4.3.2 Controlled Vocabularies Based Search

Controlled vocabularies are also used by researchers which are standardized, hierarchical lists designated to represent the major subject concepts and conditions contained within a database [12]. They can change from database to database. The hierarchical nature of the vocabularies benefits search strategies by allowing broad concepts to be narrowed in a manner that stays consistent within that framework.

The formal representation mechanism of Ontologies enables unification by matching classes, different types of properties and instances with one another.
- The intent of semantic web allows facilitates knowledge sharing and reuse across applications and organizations. Non availability of standards for information exchange, improper syntactic and semantic rules have been a problem for Sharing of information in the medical sciences field. Semantic web technologies can be applied to tackle all these problems.
- Semantic Search improves searching precision by understanding the purpose of the search and the contextual significance of words as they appear in the searchable data space [16], whether on the web to generate more relevant result [14].
- The data model, Resource Description Framework [5] is based on graph theory and it suits the representation mechanism for biomedical data by using subject–predicate–object triples.
- For fetching information from ontology, there is language support available in terms of ontology editors such as Protege [8], ontology reasoners such as Pellet, SPARQL endpoint, etc.
