# 12.5 A Brief Classification

Taking into consideration the importance of rare disease worldwide, the proper classification of rare diseases is immensely significant. Proper classification can help healthcare experts and researchers in preventing, diagnosing, and treating rare diseases. However, there is not any specific classification system but there are various databases, organizations, and machinery tools. These contain information about all the discovered rare diseases. Nowadays, there are many non-profit organizations engaged in rare disease research. Each of these organizations has its classification criteria. For example, the Orphanet classification system is a multi-level classification divided into three levels: barrier group, barrier, and barrier subtype.
