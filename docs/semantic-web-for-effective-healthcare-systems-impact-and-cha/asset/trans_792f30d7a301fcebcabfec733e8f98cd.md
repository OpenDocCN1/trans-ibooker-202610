## 本书总结了 Web 语义学的趋势和当前研究进展，描述了现有的工具、技术、方法学和研究解决方案

语义网技术有机会改变医疗保健提供者利用技术从数据中获取见解和知识并做出治疗决策的方式。大数据和语义网技术可以相互补充，应对挑战，并为医疗保健管理系统增添智能。

本书旨在分析当前语义网如何用于解决健康数据集成和互操作性问题，以及它如何提供先进的数据链接能力来改善医学数据的搜索和检索。各章分析了语义健康数据分析和知识发现的工具与方法。本书讨论了在将医疗保健数据存储到存储库之前，语义技术在提取和转换这些数据中的作用。它还讨论了集成异构医疗保健数据的不同方法。

这本创新性著作提供了：

- 它是同类首创，重点介绍了应用于医疗保健和临床信息系统的本体驱动信息检索机制与技术；
- 全面审视了语义网领域的新兴研究；
- 讨论了本体工程、语义标注和语义情感分析等新研究领域；
- 帮助读者理解语义网在生物医学工程和医疗保健领域应用中的关键概念；
- 涵盖了语义网的关键应用领域。
