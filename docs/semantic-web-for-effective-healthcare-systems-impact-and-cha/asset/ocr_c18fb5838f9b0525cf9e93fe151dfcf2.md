# 2.4.7 Standard for Data Protection

As the healthcare data is going to be digitalized and advance. The new types of threats are coming into knowledge for healthcare records. In starting there was no strong policy for security and privacy. Additionally, given these emerging threats, there is a need for a strong healthcare protection standard.

The United States (US) imposed several rules and regulations, which also includes privacy and security rules under HIPAA (1996) and State Alliance for eHealth (2007).

In the U.S healthcare provider strongly influenced by the HIPPA regulations. it confirms that the healthcare provider and organization are up to date and also fulfilling the latest requirement. It also ensures that the organization and healthcare basically HIPPA includes two key primary components.

Managerial, physical, and technical dealing with personal health information requires some standards which are described by security rules.

HIPAA Security Rule—HIPPA security provides security for digital health information. It protects the creation, utilization, and backing of healthcare data. This is provided by HIPPA covered organization. the main motive of this rule is to set the standard managerial, physical, and technical dealing with electronic health information [29].

HIPAA Privacy Rule—Privacy is very important for the health record because the health record contains very sensitive information. There is a need to provide the safeguard for the health record, insurance record, hospital record, lab report, and other private details. This HIPPA privacy rule protects the information from misuse by controlling the usage of information [29].
