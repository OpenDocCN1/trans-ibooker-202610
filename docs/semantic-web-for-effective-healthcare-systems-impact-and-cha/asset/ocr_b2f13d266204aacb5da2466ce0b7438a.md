# 12.7 Information Retrieval of Rare Diseases Through a Web Search and Other Methods

# 12.7.1 What Is Information Retrieval (IR)?

Information retrieval is a task where the clinicians or researchers use symptoms as queries for diagnosing the disease correctly. Several features define the standard web information retrieval which consists of all the developing approaches for the rare disease domain. Lately, the IR systems have gained much importance for all the clinicians and researchers that allow them to work on the difficult rare diseases in a highly comprehensive manner. There can be both offline retrieval and Google web search ways. Offline retrieval can be achieved from a specialized collection of rare diseases [6, 25].

The main objective of IR systems is to acquaint with the challenges and characteristics of the diagnosis of rare diseases.

# 12.7.2.1 Web Search for a Diagnosis

Recently, the use of the web for retrieving information has been a very important tool for studying various rare diseases. Google Search, PubMed, and Semantic Web are the most widely used interfaces. Other highly specialized interfaces, e.g., FindZebra, Omim.org, etc. have also been used. But PubMed proves to be the major database of all the medical abstracts in the world. These search engines not just help in compiling the differential diagnosis but also provides the list of most likely rare diseases [6–25]. FindZebra is a specified search engine for rare diseases powered by open-source search technology. It uses freely available online medicated data and information. The FindZebra search engine is available at http://www.findzebra.com/ [25]. It emphasizes authoritative resources and that can improve the performance for searching the required information. It is a very straightforward and open-source experimental IR system providing functionalities for rare diseases diagnosis. The limitations occur in constructing the appropriate queries based upon the descriptions of the symptoms of the disease. The collection of the queries also proves to be a very challenging task.
