# 8.7 Semantic Web, Ontology, and Its Usage in Healthcare Sector

Semantic Web is an extension of World Wide Web but the main difference is that in this semantic web the information is fabricated not only by machines but also by human beings. The main job of semantic web is to increase the possibility that machines would be able to work with human beings parallel. Semantic web provides the tools that make possible the distribution of information among various systems. Semantic Web is basically a state space where all the knowledge base can be kept collectively in such a way that it represents the meaningful information to the users. Semantic Web is responsible for showing meaningful information on a variety of websites and also helpful for research community for searching the data over various websites. As the main issue in the medical field is production of information and knowledge from a variety of data sources, the semantic web has the ability to provide such information to the healthcare system. The semantic web can escalate the merger of various data sources for the purpose of getting more appropriate results.

Ontology in the field of semantic web can be specified as the file used to represent the relation between various objects. Ontology relationship gives a tree like shape to the semantic web. In some ontology, this tree like structure enhances the features of the ontologies. The main point to be followed before the designing of the ontology is to make it capable to understand and easy to use by the users.
