# 6.1 Introduction to Semantic Search

Semantic search states to the query understanding, data understanding and suitable depiction of knowledge permitting meaningful retrieval. Semantic search is also referred to as search with meaning [1]. It helps to achieve the high level accuracy and pertinence by distinguishing three vital perspectives called meaning, context, and intent of the inquiry given by the user. A sort of modifiable semantic structure, in which the system can recover the information from a relational database and supports an effective ranking on bibliographic content established on the different cross reference in scientific articles [2]. A combination of semantic and statistical techniques can too be utilized to retrieve information from XML database in which weight to rank the results built on structural locations in the terms in XML files [3]. In a typical semantic web classified into two distinctive types called as ontological and instant data. In the actual data, the user is seeking for individual class effect but in the case of ontology, the knowledge domain and the relationship is designated predominantly as class relationships. Semantic search is facilitated via intensifying the query part or by interacting with the various entity features, which gives an idea of utmost recurrent entities to make narrow down the retrieved information [4].
