### 4.3.4.3.2 Quertle

It relies on natural language processing techniques to match search against actual assertions made by the author, rather than simple keyword matching or proximity. It uses ontology extensively so that all the meanings, forms, aliases of the search term are applied automatically [40]. The ontology also allows sub concepts to be found; for example, a search for “rodent” will find “mice,” “rats,” etc.

- **Ranking Results:** Relevance of the results is decided by the number of times the document supports the assertion.

### 4.3.4.3.3 FACTA+

It is an index based entity search engine [41]. It is used for finding associated biomedical concepts and these concepts are presented to user along with textual evidence of associations between query item and concept. Several biomedical databases like UniProt, BioThesaurus, UMLS, KEGG, and DrugBank are used for building indexes using conceptID and their names/synonyms.

- **Ranking Results:** The ranking is done based on co-occurrence statistics. The search space that is uses is PubMed.

### 4.3.4.3.4 THALIA

This semantic search engine recognizes concepts occurring in biomedical abstracts [42]. Thalia stands for Highlighting, Aggregating and Linking Information in Articles. It uses text mining tool Argo to recognize the entities using various models based on dictionary matching and CRF models trained using human annotated data.

- **Ranking Results:** The search space that it uses is PubMed. Same concept is present in the query and the retrieved documents. Searching API also has options for filtering documents according to Publication Year, Journal Name, Author, Publication Type, and MeSH tag.

### 4.3.4.3.5 LitVar

It is an entity based search engine for linking genomic variant data. It Process entire set of articles (PUBMED abstracts and PMC-OA full-text) using advanced text mining techniques to compute and extract relationships between variants and other associated entities such as diseases and chemicals/drugs by integrating Pubmed, PMC-OA, dbSNP, and ClinVar [43].

- **Ranking Results:** The search space used by LitVar is PubMed + PMC-OA. The results are ordered by publication date. Results can be filtered on Top Journals, Publication, Year, Publication Type, and Part of publication matching the query .With entity level filters, it can focus on articles with the sentence level co-occurrence of gene, disease, chemical, variant entities.

### 4.3.4.3.6 CTGA

As described in [38], in this Graph based search, neural information extraction model is used to turn text into tuples. Then, these tuples of a query or document are represented as a knowledge graph of linked concept nodes and finally uses efficient graph based algorithms to return related documents asper structured knowledge. It applies MIMO (multi-input multi-output), a deep neural information extraction model for extraction of factual and conditional tuples from unstructured content. Then this extracted information is represented using three-layer knowledge graph.

- **Ranking Results:** The search space used by it is PubMed and mean reciprocal rank (MRR) is used to rank results.

### 4.3.4.3.7 GoWeb

It is a semantic search engine which uses text-mining and ontologies in semantic web. It uses filter mechanism for long list of search results which are in accordance to the categories provided by GENE ontology and medical sub headings (MeSH) [23]. The result of search operation gives summaries in text form for web documents, known as snippets. Further, entity recognition techniques are used to map concepts form background knowledge to snippets.
