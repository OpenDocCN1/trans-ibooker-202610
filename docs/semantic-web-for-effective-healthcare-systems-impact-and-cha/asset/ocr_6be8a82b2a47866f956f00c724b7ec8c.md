# Fuzzy-Based Approach

The ontology can be classified into two categories, classical and the fuzzy based ontology. In the case of classical types ontology, the crisp is considered as value of concept, however majority of the actual system in form of fuzzy expressions. There for both the crisp ontology and fuzzy logic together shows much better method to maintain the system from not précised information and attain the indicator value. In fuzzy set components with a suitable set present the values among 0 and 1, which is known as the degree of membership. In a mathematical way, the membership function μF can be utilized to describe fuzzy set, F, and A, which states element A in the interval zero and one

μF (A) : A 0 → [0, 1]

The fuzzy inference layer mainly composed of four elements; they are fuzzification, inference, defuzzification, and knowledge-and rule-based ontology. Fuzzy ontologies encompass all visited URLs, supporting words, therapeutical terms, improper expressions, and normal words. It also gives a semantic web rule language (SWRL) rule-based knowledge platform for relevant information mining and intelligent classification to automatically recognize the type of webpage or document. The use of ontology helpful to specify different category of information, which includes features and key words. The user’s query for a URL is allocated to the web crawler, the content information’s were retrieved, and keywords and values are then mined from the retrieved information with the help of the fuzzy ontology to compute the indicator value for the decision making system. Moreover, knowledge- and SWRL-rule-based ontology states rules (if-then) for the decision system. The fuzzy inference layer is combined with the ontology to certainly mine information and find the relevant document type.
