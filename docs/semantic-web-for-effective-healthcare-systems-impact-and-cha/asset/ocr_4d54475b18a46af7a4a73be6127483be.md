This can be easily employed using ontology matching techniques. The main objective of ontology matching is to harmonize the variations among the two ontologies, each designed with different perspectives and described using a different vocabulary.

Advantage of ontology matching as follows:

+   - Connect ontologies with the information sources described there helps to discover common semantics between two sources;
+   - Connect different ontologies used in an integration system thereby enabling the convergence of terminological standardization;
+   - Add knowledge (query concept expansion) to a user’s query thereby enabling semantic retrieval.

Literature offers various proposals that use ontology and ontology matching techniques to combine ontology and deep learning techniques for the extraction of clinical intelligence. However, converting it into actionable content is still a challenge with the concerns being designing a machine learning model that can access and process the clinical knowledge abstraction provided by the ontology. The second concern is that the healthcare domain knowledge representation in a small set of axioms, i.e., ontology is a challenging process.
