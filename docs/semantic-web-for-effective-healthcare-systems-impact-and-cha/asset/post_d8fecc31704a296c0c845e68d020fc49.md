## 8.3 Phases of IoT-Based Healthcare

The rapid growth of IoT devices in healthcare has opened vast opportunities as the large volume of data gathered by these devices can have the capability of transforming the healthcare [28]. IoT architecture used in Healthcare Industry can be divided into four phases. These phases are connected in such a way that output data of one phase is used as input data to next sub sequential phase and so on [29].

- Phase 1. First Phase is composed of various interconnected devices like cameras, sensors, monitors, etc., used to gather the data [16].
- Phase 2. Data gathered from these devices is digitalized for processing [30].
- Phase 3. After preprocessing, data have been saved to the cloud for storage [31].
- Phase 4. At the end, the data are analyzed and based upon this analysis decisions making is to be done.

## 8.5 IoT-Based Sensors for Health Monitoring

Smart Healthcare help out the patients and elder people in living the life on their own. Here, The IoT based Sensors have been used for recording their health conditions and alerting in case any emergency has been found. But in case of slight variation in the vitals of the patient, the IoT based application is self-capable of suggesting the treatment [32]. Here sensor based applications of IoT in Healthcare sector are elaborated, which are broadly categorized as:

- 1. Applications based on single condition—These are the applications that have been used to treat a single disease.
- 2. Applications based on multiple or clustered condition—These applications are used to treat multiple diseases at a time [33].

Applications based on Single Condition are divided as:

- a) Sensor for Monitoring Glucose Level: In diabetes, the sugar level in the blood of the patient remains high for a long duration. Glucose Monitoring Device monitors the glucose level of the person and recommends the diet, exercise and medicines according to the severity of the disease to the patient. If this monitoring system should be connected with Internet based IoT device, then the IoT device will collect and transmits the data to the healthcare worker or physician for taking appropriate decision on medication on suitable time and reduces the chances of any mishappening [11].
- b) Sensor for monitoring Blood Pressure: Blood Pressure is the pressure with which the heart circulates the blood in the body. IoT based technology can be used to monitor the blood pressure and other necessary vitals of the body using various sensors. IoT device checks for the routine BP and sends the signal in case of any variation in the value from the normal value [34]. Sensor for monitoring the temperature of the body: Sensors can be attached with the body to measure the body temperature and then the information has been sent to the IoT device which further collects the data and sends the same to the doctor [35].
- c) Monitoring System for measuring the absorption of oxygen in to the body: A device named oximeter has been used by patients as well doctors for monitoring the absorption of the oxygen in to the blood. For improvisation of the services, this oximeter can be used with IoT based technology for providing treatment to the remote patients [36].
- d) Monitoring System for measuring the ECG of the body: ECG device has been used to observe the ECG wave pattern of the body, and creates the report based upon these wave patterns to check the functioning of the heart. IOIO-OTG microcontroller.
Converts ECG signals to digital numbers by using the analog to digital converter, and then the generate binary file is uploaded to the cloud network for analysis and identification of improper health state [13].

Applications based upon Multiple Conditions are:

- a) Device Management—As wheel chairs or stretchers are of great use for patients or people with some physical disability, if these devices could be implemented with IoT based sensors, it would become quite easy to keep track of the movement of the patient and to monitor the condition of the patient as well [37].
- b) Mobile Phone based Healthcare Solution—In the current scenario; the mobile phones along with the sensors are controlling various electronic devices. In healthcare industry, various mobile base applications have been used to provide service to the patients [38]. Examples of various healthcare solution providers’ applications are BP Watch, Pulse Watch, etc.
