# 6.3.2 Agent Ontology

Ontologies describe the usage of vocabulary includes the agents, their characteristics functionalities, and the operating domains. A multi-agent system allows an application developer to fragment a complex assignment into the easiest subtasks. According to its role, the individual agents will get a specific task. In the context of multi-agent system can be described by two organizations. The distribution of tasks to agents identifies the task-based organization of MAS development. Knowledge is embedded in agents is an integral part of the knowledge depends on organization. In a single agent in a MAS system, it is essential for three different sources of knowledge namely domain knowledge, agent knowledge, and computational knowledge. Agents control information related to some specific application domain and the domain knowledge can be integrated into domain ontology.

There is an essential need to the structuring of domain-based knowledge shared between various agents and use again for making multi agent system that works on same kind of domains. The agent must know the characteristic features of the interacting or connecting agents. Proper agent ontology definitely helps in the explanation of a set of common and unambiguous features to portray the various classes of agents. The semantic web offers heterogeneous, dissimilated information, permit applications to communicate user requirements and obtain data resources. Agents contribute highly and are capable to provide skills in progress of Semantic Web applications. Nevertheless, agent centered tools could not be achieved commonly usable till sufficient expansion of infrastructures availability of multi agent system [40].
