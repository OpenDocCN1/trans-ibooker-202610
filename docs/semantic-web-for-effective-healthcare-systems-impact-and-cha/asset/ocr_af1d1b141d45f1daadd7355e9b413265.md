Open Information Extraction (OpenIE) systems published by Stanford University, Freiburg University and the University of Washington among others are very promising knowledge extraction techniques [118, 119].

OpenIE can be used to construct RDF Knowledge Graphs from texts [120–124] from which relevant knowledge can be queried using SPARQL for the curation of the CDSS knowledge base. The URI of the texts that have been already referred to is held in a table to avoid repetition of information extraction from the same text. The RDF Knowledge Graph that is constructed from the text is only stored temporarily until the SPARQL query results are added to the knowledge base to reduce the space complexity of the system. In the proposed model, as shown in Algorithm 10.1, the system will query the RDF Knowledge Graph that is temporarily constructed using SPARQL with the keywords that are used in the CDSS. If any RDF triples are returned, they are added to the knowledge base of the CDSS. Otherwise, the system checks for any new document that is to be considered and which is not in the URI table of already checked documents.

# Algorithm 10.1 Curating the CDSS knowledge base using RDF knowledge graph.

```
URI table U = {u₁, u₂, ..., uₙ}
RDF Knowledge Graph G ={V,E} where V ∈ {v1,v2,...,vn} and E ∈ {e1,e2,...,en}
RDF triple S = {s, p, o} (subject(s), predicate(p), object(o))
CDSS Keyword K = {k₁, k₂,...kₙ}
1 Read uᵢ (URI of a new document)
2 If uᵢ ∈ U GOTO Step 9
3 Else use OpenIE to create G
4 For every K
5 use SPARQL query to find kᵢ in G
6 For every S found
7 If S not in CDSS knowledge base
8 Append S to CDSS knowledge base
9 If another document exists GOTO Step 1
10 Else STOP
```
