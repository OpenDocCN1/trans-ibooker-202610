Information is stored in heterogeneous distributed Health Information Systems, in different file formats which are mainly proprietary [3]. So, the systems sharing information need to be interoperability compatible so that the semantics of the shared information are preserved, and no information is lost due to semantic and syntactic differences [7]. Some of the issues that need to be considered are [8]:

+   - **Common Standards/Guidelines:** For information sharing and reuse, it is required to analyze and decide upon the rules to resolve policy-conflicts so as to ensure that the modified rule is syntactically and/or semantically valid.
+   - **Ensuring mapping of data:** Taking attributes and values from different systems and combining them often results in semantic differences, which further leads to partial mapping of data. This happens due to incompatible or non-formalized structuring of data.
+   - **User involvement:** Developing systems for users involve them to as to correctly identify all common terms and their meanings. If this is not done, it leads to undue disclosure of data.
+   - **Domain vocabulary:** creation of a vocabulary with correct identification of terms with multiple meanings that can be used to determine the semantic relationships between one attribute value and another.
+   - **Ontology Mapping:** to reach out to an optimal solution which fits in globally across the domain for mapping concepts from different ontologies. Semantics associated with them also need to be considered.
