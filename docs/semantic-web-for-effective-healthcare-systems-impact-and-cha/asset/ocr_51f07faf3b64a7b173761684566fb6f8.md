# (iii) Retrieval Process From Ontology

When Ontology is queried using Sparql, the query language for Ontology, there could be four different types of queries. The procedure for retrieving data from Ontology is explained:

```
<fScore> queryOntology(Q)
// Qₜ is the set of terms of query documents
// search Qₜ in domOntology
begin
  for each q in Q
    for each t in q
      fᵢ <- ontoMap(t)
        where t ∈ Qₜ , fⱼ ∈ F, i = 1, ..., k and k is the number of features (or topics)
// Type 1 Query
  if t maps to same fᵢ
    fScore (fⱼ) = Σ LDAscore(t), t ∈ Qₜ
    cum_fScore (fⱼ) = fScore (fⱼ) + LDAscore(fᵢ)
    q(f) <- cum_fScore (fⱼ) // returns f' for query document 'q'
// Type 2 Query
  else if {tᵢ} maps to fₐ and {tⱼ} maps to f_b (fₐ ≠ f_b)
    cum_fScore (fₐ) = LDAscore(fₐ) + Σ LDAscore(tᵢ), tᵢ ∈ Qₜ
    cum_fScore (f_b) = LDAscore(f_b) + Σ LDAscore(tⱼ), tⱼ ∈ Qₜ
    q(f) <- max(cum_fScore (fₐ), cum_fScore (f_b))
// Type 3 Query
  else if tᵢ maps to fₐ , f_b (fₐ ≠ f_b)
    cum_fScore (fₐ) = LDAscore(fₐ) + score(nearestTerms), tᵢ ∈ Qₜ
    cum_fScore (f_b) = LDAscore(f_b) + score(nearestTerms), tᵢ ∈ Qₜ
    q(f) <- max( cum_fScore (fₐ), cum_fScore (f_b))
// Type 4 Query
  else 't' is a new term
    CreateOrUpdateOntology(q)
      // rebuild CFSlda model, then Ontology
end
```
