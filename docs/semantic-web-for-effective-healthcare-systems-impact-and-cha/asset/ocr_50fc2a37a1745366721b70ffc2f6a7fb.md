# 3.4.1 SPARQL Results

Any semantic application requires semantic query language to retrieve the data. SPARQL is the query language which retrieves RDF based semantic data. This research work depends on semantic information and the database is also created with semantic meaning. The data stored in the ontology follows the semantic structure. Figure 3.5 shows the sample query.

```
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
PREFIX info: <http://www.patinfor.com/info#>
SELECT ?Patient ?DName
WHERE { ?Patient info:DName ?DName }
```
