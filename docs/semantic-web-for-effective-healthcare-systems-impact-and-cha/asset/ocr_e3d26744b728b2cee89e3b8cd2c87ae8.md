Later with the advent of the world wide web and the use of Hypertext Markup Language, the markup tags became metadata resources. These metadata resources were exploited by the recent semantic web technologies for knowledge representation, data search and logical inferencing. Metadata has now become a necessary element to describe properties associated with a subject domain [50].

Metadata can be categorized into different types based on the function of the metadata. Descriptive metadata describes the content of the resources and the assistance rendered by the metadata in finding or understanding the resources. The administrative metadata contains information regarding the creation or the management of the resources. The preservation metadata is about the long-term support for the metadata or its future migration or about matching the digital files. The technical metadata has information of the digital file that is essential to decrypt and extract them. The technical and preservation metadata could be treated as part of the administrative metadata. Structural metadata consists of information about the relationship between the parts of the resources. The rights metadata has information with regards to licensing, copyrights and the like. Markup languages are also considered as a type of metadata that contains flags or formatting information that help in situating paragraphs, titles, headings, lists, name, date and the so on [51, 52]. There can also be other categories of metadata that could deal with information regarding statistics, references, indices and others.

There is more than one approach to manage metadata. Some metadata management approaches for the structured and semi-structured database are annotations, provenance, quality parameter, schema and mapping, security, super-imposed information and time. Since there is wide heterogeneity in the kinds of metadata that require a high degree of specialization for the management of the metadata, the inter-operability of the metadata is quite a challenging task. Moreover, there was no distinction between data and metadata that can be made while querying. In other words, the system cannot distinguish whether the result of a query is a data or metadata. Many attempts were made to arrive at a clean and simple approach for a uniform model and to query data. The RDF is considered predominantly as the solution to representing interlinked data. RDF was primarily introduced as a means of representing the metadata available on the web. The metadata that is on the web may not be only web domains but could also be other metadata. So, in RDF, the web data is considered as resources and the web domain is represented using unique URI [53].
