
## 8.6 IoT Applications in Healthcare

A lot of problems of the healthcare industry can be managed with the usage of IoT. Solutions provided with the IoT devices can help in providing better treatment and better patient monitoring too. Here are some applications of IoT in Healthcare:

- 1. Remote monitoring of the patient—Although the medical facilities are rapidly increasing, still remote monitoring of the patient is a difficult situation to handle in developing countries. Apart from this many emergency situations can be controlled if medical facility is provided to the patient at the proper time. So with the help of IoT based solution, above problems can be solved and remote monitoring of patient will be done more effectively. Sensor based wearable gadget can be used by the patient for providing timely notification of the health status to the doctor [13].
- 2. Robot to look after the patient—IoT based robots can be used as assistant in the hospitals as well at homes for the patients living alone for assisting the patient to provide better care. It can monitor the vitals of the patients, help the patient in giving medication on time and can provide timely reminders of routine activities [39].
- 3. Management of Clinical waste—Management of clinical waste in health sector is a huge problem. If not solved properly, this problem can lead to the infection among the patients or hospital staff. So sensor based bins can be used in order to solve this problem. These sensors work by sending timely alerts when bin is completely filled so that the garbage should be dumped timely at proper place [40].
- 4. GPS enables shoes for Dementia Patients [41]—Patients suffering from dementia or any other related neural disorder forget their routine activities and even can forget its home location also. GPS enabled shoes can be used to keep track of the patient's location all the time, which further sends an alert to the patient's family via IoT device if patient leaves its home location.
- 5. Overall Management of Hospitals—IoT devices can be helpful for the overall management of hospitals including booking of appointments, hospital staff management, reduction of the queues of OPD, inventory management, etc. [39].
- 6. Proactive Treatment of Asthma Patients—The irreversible nature of Asthma makes it a very life critical disease, the only remedy being the use of inhalers throughout the life of patient [27]. The defined symptoms of a patient tentatively getting an attack are visible from half an hour to up to 8 h before the episode occurs. The IoT tools may be very instrumental in providing the aid to the patient. An inhaler that is connected with some smart sensor capable of being actuated from a factor like temperature or air pollen to avoid any such attack of asthma to the patient [7].

## 8.7 Semantic Web, Ontology, and Its Usage in Healthcare Sector

Semantic Web is an extension of World Wide Web but the main difference is that in this semantic web the information is fabricated not only by machines but also by human beings. The main job of semantic web is to increase the possibility that machines would be able to work with human beings parallel. Semantic web provides the tools that make possible the distribution of information among various systems. Semantic Web is basically a state space where all the knowledge base can be kept collectively in such a way that it represents the meaningful information to the users. Semantic Web is responsible for showing meaningful information on a variety of websites and also helpful for research community for searching the data over various websites. As the main issue in the medical field is production of information and knowledge from a variety of data sources, the semantic web has the ability to provide such information to the healthcare system. The semantic web can escalate the merger of various data sources for the purpose of getting more appropriate results.

Ontology in the field of semantic web can be specified as the file used to represent the relation between various objects. Ontology relationship gives a tree like shape to the semantic web. In some ontology, this tree like structure enhances the features of the ontologies. The main point to be followed before the designing of the ontology is to make it capable to understand and easy to use by the users.

## 8.8 Semantic Web-Based IoT Healthcare

Semantic Web is the extended web in which data are represented in the form that it provides complete meaning of that data and thus actuates much better association between human and machine. In semantic Web the available information is based upon the real world problems. Using this data or information, compatibility can be generated between human, machines, devices and services. Ontology plays an important role for generating compatibility between various machines. In order to provide complete compatibility between the systems, their semantic web based content should be same. Ontology basically represents the design or structure of information representation of any system. In Healthcare sector, a large amount of information has been used. For utilizing this data for various reasons, this data must be shared among machines. Hence ontology is used as information foundation for a common architecture in Healthcare based system. IoT based devices are much widespread these days as it has the capability of sharing the data universally and precisely. Healthcare sector aims at providing customize service to individual patient. In order to achieve this aim, IoT based system gathers data of remote patients with the help of various sensors and IoT based devices and transfers that data to the healthcare professionals for offering the patient’s prompt and good service of treatment. The whole system works by collecting data from healthcare based gadgets like BP Monitor, Sugar Monitor, etc., to smart devices and further data from the smart devices will be transferred over cloud. While transferring these data, the system also takes care of data security and accuracy.
