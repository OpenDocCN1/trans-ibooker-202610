The main Objective of this system is to serve the patient by taking decisions using the collected information and using a healthcare semantic web to validate the gathered information and knowledge about healthcare system. The above system has four components as: lowest layer is sensor based layer which has various sensors and IoT based devices used to gather the data of the patient. Layer above sensor based layer is intercommunication Layer and its purpose is to provide the communication between sensor based layer and the upper layers. This layer contains various means of networking and communication. Layer above Intercommunication layer is Semantic Web Layer. This layer performs various tasks sequentially. It first gathers data from multiple available sources like sensors and IoT devices and get the detailed information of the patient. After collecting the information, it takes out the data related to the specific disease which the doctor is treating that time. After the extraction of the related data, it has been compared with the available rule based model. By looking at the rule based model, the solution of the problem has been carried out and stored in the database of the patient for future reference. The topmost layer of the system is application layer which acts as an interface between the users of Healthcare sector and the system.
