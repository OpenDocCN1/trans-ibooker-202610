#### 摘要

医疗信息系统是使用良好的工程概念构建的。在记录详细而复杂的数据方面，它胜过同类系统。本章考察医学术语工具的最新改进及其在语义推理和医疗互操作性方面的应用方法。

医疗保健信息是多方面、敏感且孤立的。医学术语系统旨在促进不同医疗保健信息系统之间的语义互操作性。由于数据粒度要求，当前能够在卫生系统之间实现数据语义互操作性的参考术语映射解决方案较为重量级。卫生专业人员难以使用和维护它们。它们不适合非临床或非专家使用。曾经的被动患者现在成了主动消费者。理解和整合消费者健康语言有助于医疗保健消费者和专业人员更好地沟通。

快速增长的医疗保健分析跨学科领域试图提供语义标准化的语言，以帮助临床决策支持系统和相关技术取得积极进展。尽管近期有所进展，但在可预见的未来，一个能够根据本地需求容纳所有临床和管理数据的全面术语系统仍将是一个遥远的梦想。不同的利益相关者需要共同努力，审视当前碎片化的上游、中游和下游护理协议。

**关键词：** 医疗保健、健康数据、关联数据、临床数据、语义互操作性、临床文本、数据集成、语义数据

##### 13.1 引言

使用纸张记录疾病的详细事实和数据始于20世纪初。随着医疗实践的发展，文书工作量也随之增加。单个患者臃肿的病历档案使医疗从业者难以在头脑中处理，也使病案部门难以在病案库中存储和维护。到20世纪中叶，大量其他问题掩盖了纸质病历的内在效率，并促成了使用计算机来解决医疗实践中的“信息爆炸”。计算机开始用于补充传统纸质记录，通过在病历中捕获和组织关键数据 [1–3]。

在初期阶段，医疗领域采用信息技术（IT）支持护理流程的进度比金融等其他领域落后数十年，这通常归因于普遍的不确定性，尤其是采购和运营的高成本。20世纪末 IT 的改进在一定程度上推动了计算机的采用。美国医学研究所报告称，电子患者记录是所有医学记录的基本标准。美国总审计局报告称，医疗记录通过提高效率和降低成本，为改善患者护理带来了巨大潜力。该报告还呼吁制定标准，以确保医疗信息的统一电子记录和传输 [4–6]。

到20世纪末，加拿大、澳大利亚等许多国家的医疗保健系统都围绕电子健康记录（EHRs）运转。随着IT系统开始生成和汇总健康数据，分析数据和推断知识的方法促使人们定义系统，以辅助临床环境中的决策支持。用于医学知识表示的全部健康数据来自各种来源，如问题和用药清单、手术和治疗记录、健康的社会决定因素以及基因组学和蛋白质组学数据。改进的网络技术使计算机能够连接起来共享患者信息，以保持护理的连续性，从而催生了对数据交换标准和接口术语的需求 [7–10]。

到21世纪初，医学实践在IT的支撑下经历了许多经济转型。医疗信息系统使用健全的工程原理进行构建。在记录详细而复杂的数据方面，它不逊于同类系统中的任何一个。与此同时，IT的进步以本世纪无法企及的规模和成本变得可用。在当前IT时代，从不缺少从病案系统库中汇集的大量EHR数据中挖掘难以解读知识的工具和技术。然而，由于健康数据固有、独特和多方面的特征，它仍然是一把双刃剑。理论上，EHR系统能够收集、存储、分析和交换近乎无限量的健康信息。实际上，缺乏互操作性和数据标准不完整等IT系统障碍，阻碍了健康数据在整个护理连续体中的收集、共享和可用性。

医疗保健服务系统支离破碎的历史遗留结构需要重大变革。在医疗保健服务成本与质量之间寻找微妙而难以捉摸的平衡仍未实现。不同健康数据源库之间的差异，为挖掘结构化和非结构化数据的真实而完整价值带来了奇怪的挑战 [11, 12]。在一份特别出版物 [13] 中，美国国家医学院报告了当前和近期的人工智能解决方案；重点介绍了人工智能开发、采用和维护的挑战、局限性和最佳实践。该报告进一步强调，在平衡现有健康和技术驱动差距进一步加剧的同时，需要提供周到且包容的医疗AI。

##### 13.2 注意语言

不断演变的医疗实践使得为临床技术格局设定基线充满挑战。健康数据主要是异质的、高度敏感的，并且通常是孤立的。获取和处理此类事务性数据并非一项直截了当的任务。医学术语系统旨在为不同的医疗保健信息系统提供语义互操作性。健康信息和卫生技术中常用的术语标准包括 SNOMED-CT、RxNORM、LOINC、ICD-x-CM 和 UMLS。这些标准词汇和代码集有特定用途。由于数据粒度限制，当前在卫生系统之间实现数据语义互操作性的参考术语映射解决方案非常重量级。卫生专业人员认为它们难以使用且维护成本高昂。它们不适合非临床或非专家使用。昔日的被动患者如今是健康信息的主动消费者。理解和整合消费者健康词汇将改善医疗保健消费者与卫生专业人员之间的健康对话。

本节总结了医疗保健中的语义问题以及实际采用的一般解决方案趋势。

###### 13.2.1 为什么词语很重要

自古以来，医生一直使用自由文本叙述格式，记录健康评估的发现和护理方案的结果。使用自然语言进行叙述应能理解词语的含义（语义）和词语意图的含义（语用），这是沟通的两个基本要素。事实上，自由文本叙述缺乏结构，且在很大程度上有赖于使用者的沟通风格，因此对其他使用者而言容易产生歧义。借助计算机，以高度结构化的格式输入数据成为可能。然而，这剥夺了医生采用叙述格式的表达力和灵活性。此外，由于上下文（语用）信息的丢失，从结构化数据中解释和重建（语义）含义通常也很困难 [14–17]。

###### 13.2.2 哪些词语很重要

临床信息系统捕获多模态数据。相比之下，医学术语系统（如词汇表、分类法和本体）支持将人类可读的临床术语转换为计算机可处理的格式。因此，医学术语定义领域术语的上下文无关含义，而临床信息模型使用领域术语定义情境上下文，两者共同为有意义临床信息的交换提供了标准。在实践中，多个领域或学科特定的术语体系以及不同抽象和详细程度的重叠信息模型来表示临床数据 [18]。各种行业特定协会、标准组织和供应商为特定用例的系统化临床数据记录构建各自的术语或本体 [19]，因为不存在单一的普遍接受的临床概念表示标准 [20–22]。



### 13.2.3 词汇的重要性

Ivo 等人[23]调查了文献，试图找到一种全球通用的分类法开发方法，因为缺乏经过验证的领域特定行业分类法设计方法，阻碍了完整、全面且无差错的领域特定行业分类法的开发。他们提出了一种名为“行业分类法工程方法”（ITAXEM）的方法，以结构化的方式设计行业分类法。该方法借鉴了现有方法，并在其基础上补充缺失部分，同时考虑利益相关者的观点。这一方法使 ITAXEM 能够适用于任何行业。

由于医学术语的复杂性，以及同一个医学术语在不同语境下可能含义不同，非专业人士很容易误解医生常用术语。Cosic 等人[24]测试了患者在骨科住院和急诊环境中对常用术语的理解程度。这项研究的两个关键发现是：患者（1）并未完全理解专业人员常用的医疗术语，并且（2）对自己对骨科术语理解不佳这一事实并不知情。该研究的发现凸显了使用清晰术语的重要性，这有助于：（a）医疗专业人员与患者之间的有效沟通；（b）与患者进行透明且知情的对话以获得护理同意；（c）患者对健康结果的满意度。

#### 13.3 语义分析与认知计算：近期趋势

自十九世纪初以来，统计技术已为医疗保健领域带来了显著变革。近几十年来在设计、工程和分析方面的进步，为长期存在的问题提供了更强的能力和颠覆性的解决方案。“数据归一化”“语义分析”“认知计算”“电子健康素养”是近年来医疗大数据分析这一跨学科领域中流行的行业热词，旨在利用语义归一化的医学术语，为临床决策支持系统及相关技术带来积极转变。

尽管在知识和自然语言处理（NLP）技术方面已取得诸多进展，但在临床文档中无限制地使用自由文本，其结果仍远未令人满意。本节展示了这一不断发展的跨学科领域中的若干研究趋势，以引起读者对相关研究问题复杂性的关注——正是这些复杂性使得寻找实用解决方案变得困难而难以捉摸。

##### 13.3.1 语义数据分析

自二十世纪末以来，信息学家和数据科学家一直在不懈探索新的解决方案，以提取、标准化和分析存储在健康数据仓库中作为叙事性自由文本的健康数据。认知计算工具的进步为将 NLP 技术融入日常临床护理提供了令人兴奋的机遇。

对于医学信息学通才，Nadkarni 等人[25]提供了 NLP 及现代 NLP 系统设计的概述和教程。作者从 NLP 的历史演变入手，描述了 NLP 的关键子问题，并提请读者关注若干医学 NLP 方面的努力。Velupillai 等人[26]回顾了用于语义分析临床文本的临床 NLP 进展。该综述聚焦于三个主题领域：（1）语料库构建；（2）语义构建块；（3）临床实用性。Nenadic 等人[27]研究了不同类型的 NLP 任务及其在机器学习算法支持下应用的适用性。他们还探讨了用于训练模型所需的文本数据中必须具备的属性。他们展示了数据标注如何成为临床机器学习广泛采用的主要障碍之一。Deng 等人[28]展示了一种通过构建基于神经网络的查询匹配处理流程来解决医学程序分类中标注障碍的方法。具体而言，他们展示了如何向语义网络的原始输入添加相关概念来改进语义匹配。

识别患者问题、临床治疗方案和医学检验之间的关系，是临床文本认知处理所需的最重要能力之一。为了发现医学概念之间的关系并为其分配语义类型，Rink 等人[29]使用了一个单一的支持向量机分类器。在 2010 年 i2b2 挑战赛测试中，该技术在关系抽取任务上取得了最高的 F1 分数。是否可以使用像统一医学语言系统（UMLS）这样的医学本体，仍有待观察。

尽管语义对于健康相关数据的互操作性和集成至关重要，但评估领域相关数据元素中的语义异构性非常具有挑战性。Brown 等人[34]使用一种基于专家的方法，辅以数据驱动方法，来评估 HIV 相关数据字典中经验生成的数据元素的语义异构性。由于记录数据所使用的术语、词汇和语言多样，整合来自分布式异构源的生物多样性数据用于研究是具有挑战性的。Laurenne 等人[35]对比了使用传统关系数据库与链接数据方法来表达所研究物种清单中的分类信息。语义网技术能够很好地描述物种清单，并且与链接数据兼容。附加优势是，链接数据避免了在缺乏可互连分布式信息时形成信息孤岛。

如果没有语义互操作性，整合被困在各种基于供应商特定自定义信息模型构建的临床注册数据中将是一项艰巨的任务。Lu 等人[36]提出了一种基于 openEHR 的解决方案，用于解决临床数据注册中心的语义互操作性问题。他们使用冠状动脉计算机断层扫描血管造影注册中心验证了所提出方法的可行性。类似地，为实现二次数据使用而开放丰富的健康数据源，需要在基于人群的患者注册中心领域内部和之间实现完全互操作性。Nicholson 等人[37]讨论了一种基于联邦语义元数据注册中心概念的实现。

与健康 IT 应用一样，物联网（IoT）支持的智能家居设备和可穿戴健康设备在孤立环境中记录了海量数据。缺乏易于采用的通用标准阻碍了来自异构电子健康和 IoT 数据模型的健康数据集成。Peng 等人[38]提出了一种方法，通过异构实现健康服务和 Web of Things 服务，将健康数据与家庭环境数据相结合。Zhengru 等人[39]提出了一个轻量级、可扩展且可配置的框架，用于使用外部 NLP API 构建临床 NLP 系统。他们的解决方案与编程语言无关，开发快速、成本效益高且灵活。此外，用户还可以自由选择 NLP API 供应商，并为不熟悉的 NLP 任务集成多个 API 以获得更好的结果。

##### 13.3.3 语义应用

临床模型（CMs）驱动初级保健环境中临床检查、筛查或测量的文档记录，并针对不同的临床工作流程进行本地定义。**Gøeg 等人** [40]基于 SNOMED-CT 和语义相似度估计，使用平均值和最佳匹配平均值聚合技术，对临床模型进行层次聚类。树状图能够可视化层次聚类，并比较两种聚合技术的结果。在二级保健环境中，当临床路径（CPs）中的护理计划经过调整以个性化治疗体验时，其作用会更大。护理计划在其标准化形式下过于泛化，难以提供价值。**Wang 等人** [41]使用数据驱动的方法对医院历史临床数据进行语义分析和推理，从而定制临床路径。作者通过向临床路径添加本地本体来表示医院特定术语。医院特定的临床数据经过语义转换后存储到语义数据模型中，疾病特定的治疗流程包含医生常用的医疗干预措施。“标准化，还是不标准化”在临床实践中仍是一个难以回答的问题，因为患者的护理需求因医疗环境而异。挑战在于兼顾本地定制，同时达到信息模型和术语通过语义互操作实现全球标准化的最高点。

决策需要可操作的信息，这些信息从智能数据中综合而来。**Panahiazar 等人** [42]使用语义网技术来集成和重用异构资源以进行知识发现。他们通过用本体概念标注非结构化和半结构化数据来标准化数据。网络代理使用标注后的数据从图像、文本和 XML 文件等资源中解读知识。作者在强调使用大数据所面临的挑战的同时，提出了实际用例，以强调语义数据驱动环境的必要性。**Jovanovik 等人** [43]开发了一组可重用的方法和工具，将由独立分布式来源提供的异构药物产品数据集转换为全面的链接药物数据集。药物数据通过自动化系统从二十三个国家的国家官方药品注册中心收集，随后对数据进行清洗，并为其转换为五星链接数据做好准备。整合后的链接数据集随后发布到网上供公众使用。

从临床叙述中提取时间信息，并将其表示规范化以进行推理和构建临床时间线，是另一项具有挑战性的任务。**Madkour 等人** [44]研究了在护理点构建临床时间线的问题。他们整合了临床领域中时间和时间相关概念表示的解决方案趋势；医学 NLP 方法用于时间推理

系统之系统工程（SOS）是系统工程的分支领域之一。SOS是由独立、分布式且不断演进的组成系统所构成的系统组合，这些系统通过利用彼此之间的协同作用，共同朝统一目标行动。电网技术、交通运输、生产和军事企业是存在可运行SOS系统实例的一些领域。Nielsen等人[46]回顾了SOS工程中基于模型的技术的当前状况。

在国家研究资源中心主办的远程医疗未来会议上举行的一次分组讨论会[47]根据规模和复杂性，将远程医疗认定为一个SOS。与会者确定了远程医疗的关键议题，并从以下三个角度讨论了已知障碍：（1）患者；（2）系统；（3）数据。从数据的角度来看，阻碍医疗保健提供者之间数据收集、整合和传输，以及阻碍研究目的数据可访问性的已识别障碍包括：（a）缺乏数据标准，以及（b）围绕数据安全、隐私和信任的问题。

由于资源的分布式和异构特性，将语义技术应用于资源受限的基于物联网的系统颇具挑战。Ryu等人[48]提出了一个集成语义服务平台（ISSP），用于在智慧城市的各种基于物联网的服务领域中创建本体模型。该方法旨在解决在物联网系统中提供集成语义服务时存在的问题领域，如语义发现、动态语义表示和语义数据存储库。智能家居环境配备了许多异构传感器，用于监测家中特殊需求用户的健康和环境参数。Alirezaie等人[49]提出了一个物联网基础设施系统E-care@home，该系统利用本体从异构来源收集测量数据，并整合这些数据，以实现家庭环境中基于活动和基于事件的上下文识别的语义解释。Huang等人[50]提出了一种基于本体的语义方法，用于风险识别和规则推理，以表达上下文信息，为智能家居社区的安全服务提供决策支持。

数字流行病学领域提供了将IT应用于数字疾病检测的方法，以支持传染病监测和监控，或了解人们对传染病的态度和关注点。在其补充论文中，McClure等人[51]旨在考察信息和通信技术进步所带来的变革。他们提请关注基于互联网的研究以及社交媒体在流行病学和医疗保健中的使用所带来的功能性和技术性挑战。Denecke在其论文[52]中强调了在将数字流行病学与现有实践整合时需要考虑的伦理问题。Ioppolo等人[53]对社会是否已准备好接纳智能技术以实现远程连接、从而持续监测和收集数据以得出可操作结果的准备程度提出了质疑。在简要讨论了技术创新与医疗保健部门之间的联系后，他们探讨了为推动未来研究所需的变革观点。

#### 13.5 结论

医疗保健领域目前没有一种被普遍接受、临床适用且语义上可互操作的标准语言。当前推动医疗保健语义计算发展的当务之急并非寻找另一种合并医学术语的方法。将现有术语合并为通用词汇表将固有地包含临床上显著的差异。尽管机器学习/人工智能、NLP和自动化数据处理技术近来取得了诸多进展，但一个能够根据当地健康需求涵盖所有临床和行政数据，同时又能与消费者互动的全面词汇系统，在可预见的未来仍将是一个梦想。

不同的利益相关者必须携手合作，重新审视现有碎片化的上游、中游和下游护理方案。随着护理变得更加全面和包容，个体层面“健康需求”和社区层面“健康决定因素”中的冗余和特质性问题将得到缓解。这将为轻量级数据交换解决方案铺平道路，通过为整个健康连续过程中的相关临床和行政数据之间的相互作用创建共享词汇表，使得数据能够以有意义的方式进行交换。

数据经济时代医疗保健的发展方向，取决于原始数据和与数据相关的产品如何共享。为了使数据经济在当前和未来的环境中取得成功，我们需要利用来自所有已知来源、各种规模和形式的数据。在其观点论文中，Tang等人[54]明确阐述了这一事实，并预见了健康数据经济中经济集群效应的出现，其潜力通过数据产品的共享得以最大化。法律和伦理限制将持续限制敏感数据在组织边界之间的共享。诸如欧盟《通用数据保护条例》（GDPR）等国家和国际法规对保护敏感个人数据提出了严格要求。新的新兴方法旨在使用驻留在原始存储库中的数据，例如“个人健康列车”（Personal Health Train）计划[55]，为解决数据传输需求带来了巨大潜力。

简而言之，数据和数据互操作性的标准不再是必要且充分的条件。首要焦点应放在制定知识和知识互操作性的必要且充分的标准上。
