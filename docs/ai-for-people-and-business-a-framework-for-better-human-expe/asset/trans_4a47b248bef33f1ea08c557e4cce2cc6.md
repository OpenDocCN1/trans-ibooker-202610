
对于处理或学习任务所需的数据大于单台计算机系统内存（RAM）的情况，您可以使用超出内存、外部内存或增量学习技术和算法。

# 生产可扩展性

可扩展性——系统处理预期负载的能力——是在构建生产级 AI 解决方案时非常重要的考虑因素。所需的可扩展性通常通过使用 *纵向扩展*（垂直扩展）或 *横向扩展*（水平扩展）的服务器来实现。

纵向扩展意味着增加单台机器的内存容量和处理能力（有时还包括磁盘存储），而横向扩展则意味着添加额外的低成本、通用计算资源来分担工作负载。后者通常被称为 *分布式计算*。这两种选项通常都会导致成本增加。

另一种用于横向扩展以处理大量需要通过生产模型处理数据的并发请求（例如，进行预测）的技术是，将同一模型部署到多台不同的机器上并通过路由（例如，负载均衡）分发请求，或使用 AWS 的 Lambda 等技术启动临时、按需的 *无服务器* 工作器。Lambda 等无服务器技术具有高度可扩展性，且无需创建、维护以及运行完整且持久服务器的一般开销。

其他选项包括使用平台即服务（PaaS；例如，Heroku）或像 AWS 或 GCP 这样的基础设施即服务（IaaS）提供商。这些平台有助于抽象掉与系统和网络管理、DevOps/DataOps 以及站点可靠性工程等相关的许多复杂性。例如，还有越来越多的可扩展的专用 API 以服务形式提供，提供各种 AI、机器学习和其他高级分析相关功能。

# 学习与解决方案维护

最后，如前所述，AI 解决方案是在本地或远程开发环境中训练的。在您开发和测试它们之后，可交付成果随后部署到生产环境中，新数据和未见过的数据通过它以产生期望的益处和结果。这可以离线以批处理方式处理，实时处理（最少时间延迟），或接近实时处理（例如，可接受的延迟为数秒或数分钟）。

离线学习（又称批学习）是指在生产环境之外对整个数据集或数据子集（小批量）进行可交付成果的训练。这其中一部分涉及从关系数据库、NoSQL 数据库、数据仓库或数据湖等数据存储中存储和访问数据。

在线学习，另一方面，是指在生产环境中使用生产数据在线进行可交付成果的重新训练和重建以及性能评估的过程。该过程通常以可重复的间隔（节奏）进行，该间隔可以是几分钟、几天或更长。

在线学习旨在解决基于变化数据的目标性能的维护和保养问题，如批学习情况所述，但它也旨在在不重新训练整个数据集的情况下增量更新和改进已部署的解决方案。这需要高性能且可用的数据存储和访问，并且取决于网络通信、延迟和网络资源可用性等因素。

在线学习与在线算法的概念相关联，在在线算法中，算法随时间接收输入，而非像离线情况那样一次性接收。在线学习还与增量学习技术相关联，即模型在新数据到达时继续学习，同时保留先前学习的信息。

由于数据以及 AI 解决方案所基于的底层信息会因趋势、行为和其他因素而随时间变化，因此解决方案应定期更新。这使它们能够捕捉这些变化并保持期望的性能水平。如果不这样做，性能下降或漂移很常见，尤其是在预测模型中。

手动可交付成果训练和优化迭代通常在将新的优化可交付成果部署到生产环境之前进行。或者，自动化学习是自动化这些可交付成果更新的另一种方法。自动化学习是指模型训练、验证、性能评估和优化按常规节奏自动化，然后将新的改进模型部署以替换生产环境中的现有模型。部署过程可以是自动化的，也可以是手动的（用于额外的安全检查）。

这种方法应包括某种形式的模型性能跟踪和比较框架，以确定自动生成和验证的模型相对于先前或基线模型是否有所改进。
