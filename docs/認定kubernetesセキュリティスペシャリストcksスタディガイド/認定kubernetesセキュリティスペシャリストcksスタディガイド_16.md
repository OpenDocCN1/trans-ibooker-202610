## 版权页

*Certified Kubernetes Security Specialist (CKS) Study Guide 的*封面描绘的动物是家鹅。这些鸟是从野生灰雁*（Anser anse*）和鸿雁*（Anser cygnoides domesticus*）通过选择性繁殖培育而来的。已引入除南极洲外的所有大陆。考古证据表明，鹅至少在 4,000 年前就已被驯化。

与野生鹅 7～9 磅的体型相比，家鹅为追求体型而繁殖，体重可达 22 磅。由于脂肪分布，家鹅比其野生祖先的水平姿势更直立。此外，由于体型较大，飞行较少，但仍能进行一定程度的飞行。

历史上，鹅因其肉、蛋、羽毛而被驯化。最近，鹅被饲养为后院宠物，或因其吃杂草和树叶而用于庭院维护。由于鹅性格吵闹且具攻击性，会大声喧哗以察觉威胁或入侵者，因此也用于保护财产。

家畜未被 IUCN 评估。许多装饰 O'Reilly 封面的动物濒临灭绝，但它们都是对世界而言重要的动物。
