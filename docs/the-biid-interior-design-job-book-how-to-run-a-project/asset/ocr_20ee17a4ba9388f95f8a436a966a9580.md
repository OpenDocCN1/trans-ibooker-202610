# C Notes on site report and condition schedules

**Site visit** When the designer has been formally appointed, it is wise to revisit the site to carefully inspect those areas relevant to the brief.

**Site report** If the project will affect the exterior, e.g. a new extension, then a site report should be prepared, commenting on the condition of relevant exterior elements and any aspects of neighbouring properties that might affect the proposed works.

**Condition schedules** When it is not necessary to prepare a building survey (if one has recently been prepared or if the proposed works are relatively minor) then it is often useful for the designer to prepare condition schedules for the spaces to be affected by the works. These will assist in later preparing work schedules for the spaces as part of the contract documents.
