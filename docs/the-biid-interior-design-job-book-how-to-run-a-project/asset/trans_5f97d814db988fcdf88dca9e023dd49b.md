## 服务范围

设计师的声誉（理所当然地）建立在其设计工作的质量之上，因此设计师在为新项目投标时倾向于强调工作的这一方面。然而，客户（或为客户提供建议的人，例如财务总监或配偶）通常关心自己的资金应当被明智地使用。建筑项目因超期超支而臭名昭著，客户因此常常可以理解地感到紧张。

设计师可以通过向潜在客户解释其执行工作时将遵循的程序，有效地解决这些顾虑，这将展示一种对项目采取谨慎方法的做法，其中包含频繁的时间和成本估算。

与普通大众的许多成员一样，缺乏经验的客户通常不了解设计师为了提供服务必须执行的众多任务。在服务范围文件中列出将要执行的具体任务有时很有用。这可以帮助设计师协商合理的费用，并解释为什么需要时间来完成全套服务。

服务范围文件的基础可以是本书每章开头工作计划阶段描述中列出的任务，并根据所涉项目进行定制。

## 拟议服务范围样本

普乐尔企业是世界领先的小玩意、小装置和小杂物开发商和制造商之一。其管理层希望制定一项策略，以确定适合在未来两年内将办公室员工迁入、并预留未来扩展空间的合适场地/建筑。

这份简短报告概述了该策略如何制定、达成一致并随后实施。

第一步将是收集所考虑建筑物/场地的关键信息，包括：

- 1. 合适建筑物/场地的量测图纸和摄影调查
- 2. 可能存在的任何原始建筑合同文件，并将关键图纸数字化
- 3. 建筑物竣工以来进行的任何建筑或设备调查。

除了签名设计师事务所提供室内设计服务外，还应就以下事项寻求建议：

- 1. 成本和时间估算
- 2. 任何拟议的重大建筑改造或新扩建部分的建筑设计
- 3. 健康与安全建议（任命CDM协调员）

并且可能还需要就以下事项寻求建议：

- 4. 现有建筑机械和电气系统的分析
- 5. 可持续性。

组建设计团队后，下一步将是通过以下方式界定普乐尔的需求：

- 1. 识别和评估可能的场地和/或建筑物
- 2. 汇总可容纳所需功能的空间列表并编制房间清单
- 3. 采访关键员工以确定每个空间的精确要求并编制房间需求清单
- 4. 分析期望的毗邻关系并编制毗邻关系矩阵

![](img/3a2f79b2faeefd4a54f8d2fd202acc56_97_0.png)

- 5. 基于毗邻关系矩阵编制空间关系图
- 6. 基于空间关系图编制规划图
- 7. 将规划图提供给工料测量师以进行时间与成本的概算
- 8. 协助普乐尔根据概算成本确定优先级，并在必要时修改平面图，可能分阶段实施
- 9. 就替代翻新方案和FF&E采购策略向普乐尔提供建议
- 10. 制定企业室内策略，包括展示一般设计理念的情绪板。

*交付成果：场地/建筑分析、房间清单、房间需求清单、毗邻关系矩阵、空间关系图、成本和时间概算、采购策略选项、企业室内策略。*

### 实施

在确定客户需求后，下一步将是选择合适的场地/建筑并编制设计：

### 设计阶段（RIBA工作阶段 CDE）

- 1. 分析普乐尔的需求，并编制展示各空间布局以及材料和FF&E初步清单的设计方案
- 2. 提供信息以与其他顾问讨论方案并纳入其意见
- 3. 向工料测量师提供信息以编制初步成本和时间估算。

*交付成果：设计图纸、材料初步清单、FF&E初步清单、成本和时间估算、顾问报告。*

### 施工前阶段（RIBA工作阶段 FGH）

- 1. 与相关法定机构举行讨论并提出任何必要的申请
- 2. 编制翻新工程的技术图纸、规范和合同条件，展示施工类型、材料和外观，并附带技术细节
- 3. 从FF&E供应商处获取报价并编制带成本的FF&E清单；为任何定制物品编制设计
- 4. 提供信息以与其他顾问讨论方案并纳入其意见
- 5. 向工料测量师提供信息以编制详细成本和时间估算

- 6. 与普乐尔商定翻新合同形式
- 7. 如寻求投标，就翻新合同的投标人名单向普乐尔提供建议并获得其批准
- 8. 向工料测量师提供信息以编制工作计划，以获取有竞争力的投标或商定协商价格（取决于所选采购途径），并编制预投标估算
- 9. 邀请并获取翻新合同的投标书并提交给普乐尔
- 10. 在接受投标后，编制执行所需的施工文档。

*交付成果：法定申请、技术图纸、规范、合同条件、带成本的FF&E清单、预投标成本和时间估算、顾问报告、投标书。*

### 施工阶段（RIBA工作阶段 JK）

- 1. 向承包商提供所需的任何进一步技术信息
- 2. 管理翻新合同的条款
- 3. 视察工地以监控工程进度和整体质量，并与承包商定期召开现场会议以审查进度
- 4. 根据工料测量师的定期估值，向翻新承包商签发付款证书
- 5. 代表普乐尔按标准格式采购制造的FF&E物品，并监控定制FF&E物品的制造
- 6. 监控FF&E物品的交付和安装
- 7. 进行最终检查，监控缺陷的整改
- 8. 向工料测量师提供信息以编制最终账目
- 9. 协助普乐尔获取和安装艺术品。

*交付成果：进一步技术信息、现场会议纪要、付款证书。*
