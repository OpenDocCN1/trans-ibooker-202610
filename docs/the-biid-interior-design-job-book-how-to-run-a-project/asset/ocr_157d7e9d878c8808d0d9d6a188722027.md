# # £E Giving evidence in a hearing (continued)

# ## Being questioned

> *An architect, when asked in court if he knew the current whereabouts of the client's former solicitor, truthfully replied simply, 'Brio', the Czech town from which he had last received a postcard from him. On reflection, it might have been better if he had clarified his answer (although it would have made no difference to the outcome).*

However, there are a number of ways of preparing for a hearing so that the designer can be sure that he/she gives effective evidence. A witness should:

+   - ask his/her solicitor before the hearing what the correct form of address is: 'sir', 'your honour', 'my lord'
+   - listen very carefully to the question and answer it only when he/she is sure of its meaning. It can be useful for the witness to re-state the question in clear terms before answering it to ensure that he/she fully understands it and to gain time to consider it carefully. There is no stigma in asking for clarification of a question
+   - resist any pressure to rush to answer. A careful, considered answer will carry more conviction
+   - make the answer as clear as possible in lay terms
+   - consider questions as opportunities to stress relevant matters that support the designer's case
+   - not give an answer which he/she is not sure about or is outside his/her expertise
+   - generally decline to speculate or answer hypothetical questions
+   - always be courteous to all parties, particularly when being questioned by the other side's barrister. Firmly (but never angrily) reject any suggestion put to him/her which the designer believes not to be true or fair
+   - address his/her comments to the adjudicator/arbitrator/judge
+   - not be tempted to fill silences
+   - if the questioner attempts to limit the answer, give the answer to the question asked, then turn to the adjudicator/arbitrator/judge and make clear there is more to be said
+   - frankly admit any points which are not in the designer's favour but add any rider or explanation that he/she wishes to give. Trying to evade a difficult question only makes a witness appear unreliable
+   - never attempt to be humorous. (This is the adjudicator/arbitrator/judge's prerogative!).

However, if the designer has followed the procedures in this book, the chances of having to become involved in a legal action or give evidence in a hearing are much reduced.
