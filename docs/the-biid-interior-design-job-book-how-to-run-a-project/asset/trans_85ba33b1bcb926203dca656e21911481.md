

## B 关于简要时间表和图表的注释

### 房间时间表

在收到（或准备）设计简报后，设计师在任何空间规划工作中的首要任务是安排房间，或者如果尚未明确，则安排新设施所需的功能。

### 房间要求

其次，设计师应与将使用每个房间的客户关键员工合作，安排每个房间的详细要求。所示示例时间表可能不适用于所有类型的项目，因此这些表格应针对每个项目进行定制。

除已识别的空间外，设计师还应预留常规辅助空间，例如卫生间、清洁工储物间、通道等。

### 邻近关系

接下来，设计师应通过邻近关系矩阵查看每个空间的邻近/分离要求。这是一种试错过程，可能需要多次迭代，以将需要紧密邻近的空间分组。

### 空间关系

这将导致编制空间关系（或“气泡”）图，显示每个空间与其他空间的关系。同样，这可能是一个迭代过程。

### 规划

从空间关系图出发，设计师可以开始引入内部通行、外部进入点、楼层划分等，以制作规划图。

### 平面图

然后，规划图可在下一阶段用作生成平面图的基础。

## B 关于向客户确认阶段批准的信函注释

### 阶段批准

重要的是要书面记录每个阶段何时获得客户批准以及可能指示的任何更改，以便能够开票收取该阶段结束时的费用。设计师还应确认客户是否希望进入下一阶段。尽管示例涉及阶段 B，但所有阶段完成后都应发送类似信函。

### 客户变更

如果客户要求对提交内容进行变更，应予以记录；如果这些变更会在已商定阶段按百分比或固定费用计费的情况下增加设计师的工作量，则设计师应向客户出具客户指令（参见“d 客户指令示例”，第 140 页）。

设计师应牢记，只要其设计令人满意地满足简报要求（以及规划许可、建筑法规和物理定律等其他基本标准），他们就有权获得已完成工作的报酬。除非在设计师聘任协议中另有约定（或除非已按工时基础商定费用），否则不应期望他们在不收取额外费用的情况下提出替代方案。
