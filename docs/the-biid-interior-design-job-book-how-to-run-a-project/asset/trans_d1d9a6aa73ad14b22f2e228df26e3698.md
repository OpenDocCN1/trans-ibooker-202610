## C 致勘察招标者函件的说明

### 报价

除极小型项目外，所有项目的首要任务之一，是设计师为现场及任何现有建筑物获取必要勘察的报价。

### 客户直接签约

与他人提供的所有服务一样，设计师应注意，勘察员的合同应直接与客户签订，否则设计师将对勘察员的任何疏忽承担责任。

### 量测图纸

整个房产的量测图纸的常规规格是绘制所有平面图、所有立面图以及至少两个剖面图。如果拟议的工程仅影响建筑物的一部分，则勘察可仅限于这些部分。

装饰线条的轮廓测量对细节有用，但会增加勘察成本，除非该建筑是列入保护名录的建筑或新工程需要与现有细节紧密衔接，否则可能不需要。

信息通常以数字形式提供，但如果设计师或客户要求，图纸也可以按适当比例绘制在绘图膜纸上提供。

### 建筑勘察

建筑勘察（及共用墙咨询）是高度专业化的工作，应由特许测量师学会（RICS）的专业会员执行。

设计师应向客户明确，建筑勘察员只能对易于到达的建筑区域出具报告。他们不检测公用设施供应，也不检查家具或地毯下方。如果勘察报告表明可能存在隐藏问题，则可以在合同文件中包含的应急费用中为解决这些问题留出余量，并且可以在施工期间进行检查，以便暴露或充分测试可疑区域。

### 共用墙勘察

当建筑物为半独立式或联排式时，任何会影响邻居共用的墙壁或楼板/天花板的拟议重大工程均受 1996 年《共用墙等法案》的约束。该法案允许建筑所有者对共用墙进行某些工程，同时保护可能受该工程影响的其他人。代表客户行事的共用墙勘察员与其他受影响方进行谈判，并获得关于共用墙裁决的书面协议，以便客户可以：

- 切入墙体以承受梁的重量
- 安装防潮层
- 提高、拆除和重建和/或加固共用墙
- 通过在相邻建筑物中切入防水层来处理相邻墙壁或建筑物的接口
- 开挖基础：(a) 在邻居结构三米以内且低于其基础，和/或 (b) 在邻居结构六米以内且低于从其基础底部向下画出 45° 线的位置
- 在两个房产之间的边界上建造新墙。

该法案不适用于诸如固定插座、拧入墙壁单元或搁板、添加或更换电气布线或插座或重新抹灰墙壁等小型工作。
