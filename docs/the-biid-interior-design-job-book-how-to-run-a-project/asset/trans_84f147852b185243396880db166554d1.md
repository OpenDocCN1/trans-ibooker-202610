

## P3 为什么使用 ID/10？

当明确客户有意委托某事务所承担项目室内设计服务，且条款有待商定时，设计师应准备一份书面合同。

设计师常常出于可以理解但错误的顾虑，不愿与客户正式签订合同。设计师有时过于渴望拿下项目，以至于草率达成不令人满意的协议。这样做以后可能给其事务所带来巨大损害。

这种不愿往往源于：

- 担心客户会因为要签署详细合同而却步。设计师应指出，正式合同为客户提供了若干重要保障（见下文“客户保障”）
- 认为所有客户都是“绅士”，会因为要将口头达成的协议以书面形式承诺而感到恼火。作者多年来了解到，有不少此类客户并不犹豫试图反悔协议
- 认为要求之前合作成功的客户签署合同是侮辱。客户可能去世，继承人可以方便地忽略口头协议；同样，公司高管可能离职，其继任者可能决定不再按原来方式进行。

> 《泰晤士报》2009年2月6日关于建筑师理查德·泰勒（Richard Tyler，94岁）的讣告中提到，他专门修复大型乡村住宅，文中写道：“泰勒擅长应对有时资金紧张的棘手客户，包括一些客户在他向他们出示账单时感到震惊，因为他们原本希望他以红酒和一个冷房间作为回报，提供建议和图纸。”

在这个阶段审慎行事的理由，与胜任完成工作本身的理由一样多。不必认为客户会自动反对设计合同。相反，设计师准备一份详细协议，是其专业能力的表现。

向客户解释 ID/10 已成为室内设计服务采购的行业标准表格，并且它在客户和设计师的利益之间提供了公平平衡，这很有用。

## 客户保障

合同中有若干客户保障措施（ID/10条款编号显示在括号中）：

- 室内设计师详细列出其将为酬金提供的服务，并说明该酬金将如何计算。
- 设计师会在涉及时间、成本和遵循设计简报的问题出现后尽快告知客户（第2.2条）。
- 设计师在执行工作时将运用合理的技能、注意和勤勉（第2.1条）。
- 设计师只在客户批准的情况下对项目进行实质性变更（第2.6.1条）。
- 设计师投有专业责任保险（PII），并将在约定限额内维持该保险（第7.4条），并在项目结束后约定的期间内维持（第7.1条）。
- 提供了一种相对快速且成本低廉的争议解决方法（第9.2条）。

> “建筑师作为一个阶层，并不以敏锐的商业头脑著称，尤其是在他们与客户自己的合同方面。许多客户不会犹豫利用这一点。”大卫·查佩尔在《建设合同问答》中援引SEA/99（建筑师版本的ID/10）时所说。

## 客户义务

- 包含在七天内取消合同的权利（第10条）。
- 为了工作的顺利进行，设计师应向客户解释，他/她将需要：
  - 在单独协议下委任必要的顾问（第3.8条）
  - 遵守《建筑（设计与管理）条例》（CDM）
  - 迅速做出决定（第3.3条）
  - 向设计师说明设计简报、预算和时间表的相对优先级（第3.4条）
  - 在到期时支付酬金、费用、垫支等（第5.15条）。

## 设计师保障

- 设计师通过以下方式受到保护：
  - 禁止抵销（第5.20条）
  - 鼓励客户及时付款的激励。第5.21条规定对迟付款项收取利息
  - 支付花费在追讨到期款项及为不成功或放弃的索赔进行辩护的时间（第5.22条）
  - 设计师作品受版权保护（第6.1条）
  - 发布项目照片的权利（第2.9条）
  - 责任时限和上限（第7.1条和第7.2条）
  - 净额分担条款（第7.3条）
  - 一种相对快速且成本低廉的争议解决方法（第9.2条）
  - 禁止申请诉讼费担保（第9.3.2条）。

这些条款的详细效果如下所述（参见“P3 ID/10条款解释”，第46页）。

大多数经验丰富的设计师都通过痛苦的经验了解到，某些潜在客户是严重的负担，他们的事务最好不与其合作。通常在项目进行得相当深入之前无法识别此类客户，但早期迹象可能是对拟议设计合同的不合理反对，或试图强加对设计师不公平的条件。

无论如何强调都不过分的是，在项目实质性工作开始之前，设计师与客户之间必须签订一份适当的书面合同。

然而，没有任何合同能完全防范的风险包括客户行为欺诈或在英国境外司法管辖区运营。如果设计师无法获得客户的良好信用报告，或客户在英国没有资产，建议设计师要求预付款，始终保持项目的正现金流。

> 美国建筑师有一句恰当的说法：“对于某些潜在客户，给他们1000美元让他们走人会更便宜。”

## P3 如何使用 ID/10

### 委任

客户与设计师之间的委任合同应包含以下几个部分：

- 委任信
- 委任条件
- 服务附表
- 费用和开支附表
- 项目数据附表

以及以下内容（如果由客户提供），应附于已签署的委任副本：

- 设计简报
- 附件。

（参见“P3 委任信备注”，第36页，以及示范信，第37–41页。）

### 条件

ID/10方便地装订在一本小册子中，包含委任条件、服务附表、备注和示范信。设计师应始终撕出备注和示范信（中间的白色页面），如果服务已在委任信中列明，也应移除服务附表。

应使用两份ID/10，一份归客户，一份归设计师存档。第1页底部的方框应在两份中填写。

根据设计师将履行的职能，ID/10的以下部分将适用：

- 当设计师纯粹作为设计师行事时，仅适用主要条件（第1.1至10.4条）
- 当作为承包商行事时，还适用附录A
- 当作为代理采购FF&E时，还适用附录B的B1和B2部分
- 当作为主体（即零售商）供应FF&E时，还适用附录B的B1和B3部分。

协议中不适用的部分应用一条对角线划去。

### 协商条款

消费者受到立法保护，尤其是1999年不公平合同条款条例（UTCCR 99）。如果客户是消费者，设计师应解释拟议设计合同的条款，逐条带领客户阅读合同，即使有引起乏味的风险。应解释说，作为专业人士，设计师正在为客户在巨额资金支出方面维护客户的利益。
