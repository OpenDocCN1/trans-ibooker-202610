Generally The designer should also:

+   - immediately confirm in writing if new instructions are given altering the initial brief (see ‘d Specimen client’s instruction’, page 140)
+   
+   - deal immediately with any complaints, either overt or implied, by explaining in detail why he/she took the course of action complained about
+   
+   - notify his/her professional indemnity insurers if any allegation of negligence is suggested by anyone (see ‘fC Notes on letter to professional indemnity insurers’, page 262)
+   
+   - if the client instructs a change, particularly during the construction phase, carefully investigate the full implications of the change (including its effects on consultants’ work), analyse the cost and time implications including any additional fees, and advise the client before proceeding to implement the change
+   
+   - if a job has been suspended for some time and then resumed, review the work done on the project carefully before proceeding. This is particularly important if a partially completed job has been taken over from another practice
+   
+   - if a design error has been made, rectify it as soon as it is discovered and try to limit its consequences. The designer should advise his/her professional indemnity insurers
+   
+   - avoid cash transactions. It can be difficult to later evidence such payments and they are often used to evade tax, a practice that the designer would be well advised to have no connection with.
