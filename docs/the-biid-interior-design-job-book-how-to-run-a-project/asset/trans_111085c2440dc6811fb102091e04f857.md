## 致摄影师信函说明

关于建筑摄影师拍摄时开着满载家具的大搬家车出现，并以自家家具替换客户家具的流传故事不胜枚举。当然，室内设计师无需忍受这种失礼之举。

### 项目照片

设计师为已完工项目拍摄照片以用于执业推广非常重要。ID/10第2.9条赋予设计师在协议日期后两年内拍摄项目并发布这些照片的权利（对于大型项目，在签订协议时可能需要延长该期限）。

### 保密

一些客户特别注重保护隐私，设计师可能需要同意在发布项目时不披露客户姓名和/或地址。这些事项应在协商设计师委任时讨论并达成一致。

### 摄影师

设计师不应指望亲自为项目拍照，而应获得符合出版所需高标准的照片。即使是普通专业摄影师通常也不具备必要技能。为了获得最佳效果，设计师应聘请专业的建筑室内摄影师。

设计师在选择摄影师时应谨慎。他们应浏览几位摄影师的网站，然后要求查看可能合适摄影师的作品集。设计师应查看室内照片；该领域许多摄影师专攻建筑，这与拍摄室内有微妙的不同。

### 摄影费用

建筑摄影师通常期望收取拍摄照片的初始费用，以及图片发表的费用。因此，他们有经验知道哪些出版物会对图片感兴趣，以及如何拍摄以最大化发表可能性。设计师可能会发现，了解承包商、客户和/或其他顾问是否愿意分摊摄影师费用会很有帮助。

### 准备

拍摄前，设计师应：

- 与摄影师一同勘查现场，并就每张图片的视角和细节达成一致
- 确保拍摄提议日期可进入现场
- 确保所有灯具都安装了正常工作的灯泡
- 确定家具是否需要移动
- 确保拍摄当天现场整洁干净。

### 布置

空间在照片中往往与现实看起来截然不同。它们通常使用广角镜头拍摄，这可能会不成比例地强调前景。因此，图片前景放置一个有趣的物体会有所裨益。一些摄影师会提供这些物体，但最好由设计师提供。

### 审批

设计师应保留权利，确保项目图片不会在不适当的媒体上发表。

如果客户的项目在不合适的语境下发表，客户可能会反对。
