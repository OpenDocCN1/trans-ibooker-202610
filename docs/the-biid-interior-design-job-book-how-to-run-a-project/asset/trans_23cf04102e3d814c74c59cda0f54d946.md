## FFE 供应  

### 描述  

本章节涵盖设计师（作为零售商）向客户供应家具、陈设和设备（FF&E）。当设计师作为客户的代理人采购FF&E时，请参见“k FF&E采购订单样本（作为代理人）”，第207页。  

设计师应了解以这两种方式执行这些任务所涉及的不同风险和责任。  

## FFE 关于信函及FF&E销售订单（作为主方）的注释  

### 销售订单  

销售订单表格用于设计师根据ID/10的B1和B3章节以主方身份（实际上作为零售商）采购FF&E的情况，也是设计师向雇主的供应合同。销售订单应寄送两份给雇主，一份供设计师存档。作为零售商，设计师必须遵守《货物销售法》。  

为确保客户希望购买FF&E物品，应在向制造商下订单之前，将一份精确描述物品的销售订单寄送给客户，并由客户签署一份副本退还给设计师。  

### 定金  

作为主方供应定制FF&E物品和面料的设计师，通常要求客户在向制造商下订单之前支付全额价格。或者，对于现成物品，设计师可以要求在下订单前支付一笔可观的定金，例如价格的一半，并在交付和安装前支付余款。  

有时，尽管设计师竭力解释某件物品交付后的外观，客户在交付时看到实物后可能会改变主意并拒绝付款。因此，确保设计师在采购过程的任何阶段都不垫付资金非常重要。  

### 样品  

当订单中包含面料或地毯时，设计师应将面料或地毯样品附在订单的所有副本上。对于大宗订单，可以添加补充页。
