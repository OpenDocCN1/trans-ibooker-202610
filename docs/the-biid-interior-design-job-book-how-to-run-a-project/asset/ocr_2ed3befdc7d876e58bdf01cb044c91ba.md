# # A Notes on letter to client re appraisal

Appraisal

When a complex project is contemplated by a client, often he/she knows only the overall need (in the following example new office accommodation) but not precisely its detailed requirements. Important information, such as the cost and timescale, on which the client will base a decision, cannot be estimated with any degree of accuracy at this preliminary stage.

Designers can perform a valuable service by collecting information about the client's general requirements, assembling a design team and investigating alternative options, e.g. converting an existing building or building new space.
