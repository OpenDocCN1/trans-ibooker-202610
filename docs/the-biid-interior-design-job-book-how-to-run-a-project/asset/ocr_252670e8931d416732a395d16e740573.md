# P1 Notes on expenses records

# Expenses records

Expenses records, as with time sheets, should be kept by all members of the practice (including directors/partners). They can be included as a proportion of charges to a client.

Expenses are divided into two categories:

+   - Recoverable: those expenses that can be charged to a client under the terms of the appointment: generally travel, subsistence and various sundries including document printing and copying. Designers should be careful not to charge any item, e.g. a lunch, unless it is strictly necessary for the carrying out of the project.
+   - Irrecoverable: those expenses that are necessary for the running of the practice but cannot be fairly charged to a client.

Recoverable expenses incurred on projects on which expenses are to be individually claimed are collected up each month, along with any agreed handling charge, so that they can be included in the next client invoice. See ‘fC Specimen expenses schedule’, page 250, for an example of how expenses should be scheduled to support an invoice.

See also ‘P3 Notes on Schedule of Fees and Expenses’, page 42, for alternative methods of charging expenses.
