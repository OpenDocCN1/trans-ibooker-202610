### 说明  

本节涵盖在客户不愿支付时，强制执行设计师应得费用及其他款项的事宜。  

### 一般事项  

不幸的是，少数不讲信用的客户有时会试图避免支付应付款项，常以设计师疏忽为由拒绝付款，尤其在项目结束阶段，当他们认为不再需要设计师的服务时。这通常表现为客户投诉设计师未遵循其指示或未胜任工作。  

发生这种情况时，设计师应仔细审查“£C 款项追收”第258页中列出的可选方案。  

### £E 致职业责任保险公司的信函注释  

### 情况  

PII保单的一项重要条款是，保险公司必须及时以书面形式获悉任何可能导致针对设计师的索赔的“情况”。此类情况可能包括：  

- 对设计师绩效、其任何下属或其任何直接雇佣的顾问的明示或暗示批评，无论是否有理  
- 有人可能会针对设计师提出索赔的任何暗示  
- 意识到执业机构在执行项目中犯了错误  
- 关于应付费用的未解决争议  
- 项目严重超时和/或超支  
- 显然需要进行补救工程时  
- 提出某种形式的争议解决方案时。  

### 通知  

设计师常常不愿通知保险公司，抱怨的客户可能不会追究此事，或者认为通知会导致明年的保险费用上涨。事实上，保险公司非常清楚，有时客户甚至会对最好的执业机构提出投诉，并且常将偶尔的通知视为执业机构勤勉的证据。PII的一项最重要的优点是，在保单免赔额用完后，辩护索赔所产生的法律费用由保单承保。设计师绝不应因通知不及时而冒失去保单重要保障的风险。  

### 行动  

当发现一种情况时（即使设计师认为索赔没有理据，无论索赔损害赔偿金额多少），设计师应立即采取以下行动：  

- 向保险公司提供指控的全部详情，连同相关文件副本、导致指控的事件时间表，包括设计师首次得知指控的日期、对设计师参与情况的说明以及项目中任何其他方的角色。  
- 在保险公司调查此事期间全力配合。  
- 如果以书面形式提出投诉，设计师应记录收讫，并仅回复将处理此事。  

设计师不应：  

- 作出任何承认或让步  
- 在未事先获得PII保险公司书面同意的情况下，不得提出或同意支付任何款项。如果设计师认为索赔有理或索赔可以和解，他/她应向保险公司清楚说明立场。  
- 提及保险公司的参与。  

如果设计师认为索赔仅仅是出于逃避支付应付费用的意愿，他/她可以寻求法律意见。根据ID/10，除非索赔成立，否则法律费用最终可以向客户追偿。然而，此类事项仍应通知设计师的PII保险公司。
