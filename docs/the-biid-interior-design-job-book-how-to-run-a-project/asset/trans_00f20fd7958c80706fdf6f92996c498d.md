## J 动员准备阶段

阶段描述
阶段 J，动员准备（所选承包商调集资源的时期），涵盖建筑合同文件的准备和执行（应在承包商接管场地前完成）以及向承包商发出施工所需的生产信息副本。

### RIBA 工作计划
RIBA 2007 工作大纲计划将本阶段的关键任务描述为：“签订建筑合同，委任承包商。向承包商发出信息。安排向承包商移交场地。”

### ID/10
阶段 J 是 ID/10 室内设计服务进度表 A 页中的“安装管理阶段”。

### 任务：室内设计师/首席顾问
当作为设计团队中的室内设计师或作为首席顾问行事时，设计师仅执行以下七项任务（交付成果以粗体显示）：

- **就承包商的委任以及各方和建筑合同下的合同管理人（CA）的职责向业主提供建议**。
- 协助工料测量师准备**建筑合同**并安排执行。
- 向承包商和专业分包商提供**施工信息**，包括足够的详细图纸和规范信息以用于项目施工。
- 接收承包商提交的**保险单据**；就业主是否需要投保向其提供建议。
- 接收承包商提交的**进度计划**。
- 接收承包商提交的**健康与安全计划**。
- 如有需要，安排业主雇佣**现场检查员**。

### 承包商
当根据 ID/10 附录 A 作为承包商行事时，设计师仅执行以下任务：

- **调集资源**以执行建筑工程。
- 订立任何必要的专业**分包合同**。
- 就业主是否需要投保向其提供建议；办理/修订并向业主提交任何必要的**保险单据**副本。

- 编制**进度计划**。
- 编制**健康与安全计划**。

在小型项目中，阶段 J、K（施工至实务竣工）和 L（实务竣工后）通常在同一工作中完成。

## J 施工前函件说明

### 致承包商
当投标人被选中时，设计师应写信给投标人：

- 附上两份合同文件副本，要求投标人执行并退回
- 要求提供投标人相关保险单据副本以及已支付相关保费的证明。如果 MW 05 是合同形式，则根据以下条款需要保单：

5.3：人身伤害或死亡；财产损伤或损害的保险

连同：

5.4A：承包商和业主联名对工程进行的保险（当工程不是对现有建筑的扩建或改造时）

或

5.4B：承包商和业主联名对现有建筑和工程进行的保险（当工程是对现有建筑的扩建或改造，且业主可以联名投保时）

或

5.4C：业主以其自身名义对现有建筑进行的保险（当工程是对现有建筑的扩建或改造，且业主是住宅占用人且无法联名投保时）。如果选择此条款，条款 5.4A 也应保持有效，以便承包商需要以联名方式对工程进行保险

- 要求提供施工进度计划副本
- 要求提供预期付款计划副本。

由于业主常常有直接指示建造商的诱惑，因此明确警告承包商非常重要：不属于合同或设计师指示主题的工作将不会得到付款（或许还要说明，移除它的成本将被扣除）。

同时，也很重要要让建造商清楚：质量控制是他/她的责任，而不是设计师的责任。

### 致业主
当建造商正确执行合同文件并将其退还给设计师时，设计师应将两份副本发送给业主执行，并要求将两份副本退还给设计师。设计师随后应将一份副本退还给投标人，并将另一份保存在设计师的项目档案中。

就在施工开始前，设计师应写信给业主，提醒他/她：

- 根据条款 5.4B（或条款 5.4C，如果建筑合同中的任何一项是规定）对工程进行投保
- 仅在承包商允许的情况下进入建筑工地区域
- 向承包商提供现场服务
- 遵守安全预防措施
- 不直接指示承包商
- 在合同规定的时间内（MW 05 中为 14 天）根据设计师的证书付款
- 在未发出适当通知的情况下，不从证书所示金额中扣除款项
- 不干扰设计师的证书签发功能。
