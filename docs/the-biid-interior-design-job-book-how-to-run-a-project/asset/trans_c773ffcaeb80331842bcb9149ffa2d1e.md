## 附录A 从事建筑工程的设计师

如果设计师充当承包商，则适用附录A。应在服务进度表的“第3部分 建筑工程”中勾选相应服务。

### A1 投标与接受

根据服务进度表第3部分，若设计师将实施建筑工程，当客户书面接受设计师实施工程的投标时，本附录A中的这些补充条件即适用。

### A2 账目与付款

应付予设计师的执行建筑工程的款项（包括设计师的费用和开支）为投标中规定的金额、合同价款或其任何商定的变更。设计师应按照第5.15.2条提交付款账目。

该款项中不超过5%的最终款项，应在设计师通知客户所有建筑工程已完成，并在该通知后6周内免费纠正客户通知的任何缺陷后到期。

### 建筑工程成本

A3 自投标接受之日起6个月届满后，定价规格或建筑工程和/或装饰的投标进度表中引用的费率应根据消费者物价指数进行调整。

### A4 建筑工程的执行与完成

设计师应按勤勉且专业的方式，按照图纸和规格，使用适合每项任务的熟练技工，在投标中确定的完成日期或各方书面商定的其他日期之前，执行或安排执行并完成建筑工程。

### A5.1 场地占有

客户应允许设计师：
- (a) 占领正在进行建筑工程的场所部分；
- (b) 根据需要使用合理的空间来存放材料和工具；
- (c) 使用厕所和洗涤设施、供暖、水和电；
- (d) 在周一至周五（含周五）上午08:00至下午18:00期间进行工作。

- A5.2 设计师应使房产保持清洁整洁，并在每天结束时清除因工程产生的垃圾。
- A5.3 在建筑工程期间，如果客户不在场，设计师应对房产的合理安全负责。
- A5.4 设计师应警告客户建筑工程产生的任何危险。
- A5.5 客户不得允许其他人员（特别是儿童）暴露于建筑工程的任何危险之中。

(参见《施工前给客户的J型范文》，第200页。)

### 进度

- A6.1 设计师在意识到建筑工程进度或合同价款有任何变更或潜在变更时，应通知客户。
- A6.2 设计师不对因设计师的员工、分包商或供应商以外的人员造成的建筑工程缺陷或完成延误负责；但是
- A6.3 设计师有权获得合理的工期延长以及任何增加费用的付款。

### 法定义务

- A7 设计师应遵守适用于建筑工程的任何法定规定，并在要求时发出所有通知并支付产生的任何费用。

### 责任

A8 从事建筑工程的设计师（包括本附录A项下的任何装饰），应自实际完工之日起6年内，对建筑工程执行中或其中使用的货物和材料的任何缺陷（正常磨损除外）承担责任。

与上述建筑工程和/或装饰有关或与之相关的任何诉讼或程序（无论是基于合同、侵权、法定义务或其他），均应在责任期届满前提起。

### 保险

- A9.1 服务进度表第3部分中指定的一方应以客户和设计师的共同名义，为在建筑工程完成前，因火灾、爆炸、暴风、风暴、洪水、水箱、设备或水管破裂或溢出、地震、航空器及其他空中装置或从其中掉落的物品、骚乱和民间骚乱而导致的现有结构、任何内容物以及建筑工程和所有未固定材料的损失或损坏风险投保。
- A9.2 设计师应在建筑工程完成前，维持针对人员死亡或受伤以及财产损坏的公众责任保险。

应一方要求，另一方应提供合理要求的证据，证明已采取上述第A9.1和A9.2段所述的行动。

设计师应在建筑工程开始前，提醒客户其有义务为工程投保（参见《施工前信函备注》，第196页）。

## 设计师作为代理人或供应商提供FF&E

如果设计师正在采购或提供（或两者兼有）FF&E，则适用附录B。应在服务进度表的“第2部分 – 安装管理”和/或“第4部分 – 由设计师提供的FF&E”中勾选相应服务。

### FF&E – 一般条款

如果设计师提供或采购FF&E，本部分始终适用。

### 采购物品

- 当设计师作为代理人或委托人进行采购、供应、交付和/或安装时，设计师应采取一切合理措施，确定此类FF&E物品：
- (a) 从制造商或其他供应商处获取，其销售条件不包含不合理的责任免除或限制；
- (b) 质量合理且适合其用途，并在任何商定的交付日期前以良好状态交付至场地；
- (c) 按本附录的规定进行采购；以及
- (d) 如有缺陷，应在产品耐用性范围内合理期限内通知后，按照销售条件进行补救或必要时更换。

### 订单取消

- 客户确认：
- (a) 如果客户指示取消设计师作为代理人或委托人下达给FF&E供应商的任何订单，客户应向设计师偿付由此产生的费用；以及
- (b) 定制FF&E物品在下订单日期全额付款；以及
- (c) 取消库存物品可能会产生取消费用。

定制物品在开始制作后不得取消，客户应在下达制作此类物品的订单之前向设计师全额付款。

### 供应物品的价格

供应物品应按投标FF&E进度表中报价的价格收取。

- 如果出现以下情况，设计师应通知客户合同价款的变更：
- (a) 设计师无法获得其合理控制范围之外的任何指定FF&E物品，且客户指示设计师替换替代物品；或
- (b) 任何物品的价格在交付前由制造商/供应商变更。
