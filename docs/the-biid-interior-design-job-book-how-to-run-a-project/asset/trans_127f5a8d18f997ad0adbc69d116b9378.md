## C 概念阶段

**阶段描述** 阶段 c，概念，是大多数项目开始的阶段。

**RIBA 工作计划** RIBA 2007 年工作大纲计划将本阶段的关键任务描述为，“实施设计简介并准备额外数据。准备概念设计，包括结构和建筑服务系统的大纲提案、纲要规范说明和初步成本计划。审查采购途径。”

虽然设计团队的主要任务将是确定空间的总体布局，但重要的是要确保这些空间的尺寸和比例在布置家具后通常仍然可行。如果已委托建筑师，例如，设计新建筑或现有建筑的新扩建部分，那么设计师通常会为建筑师的概念规划提供通用家具布局。

**ID/10** 阶段 c 是 ID/10 附表第 6 页上的“设计阶段”。

**任务：室内设计师** 作为设计团队中的室内设计师工作时，设计师将仅执行以下两项任务（交付成果以 **粗体** 标注）：

- 在概念方案图纸上展示大致的 FF&E 布局。
- 开展研究以确定总体室内设计方案，准备情绪板，向客户展示并与其审查。

**首席顾问** 担任首席顾问时，设计师将执行上述两项任务以及以下所有事项：

- 评估客户的设计简介，识别并获取所需的任何勘查和其他场地信息。
- 就客户根据 CDM 法规承担的责任、顾问或专家服务的必要性以及获得法定批准的必要性向其提供建议。
- 分析客户的要求并准备概念方案图纸（包括主要元素的总体布局以及结构和建筑服务系统的概念性提案）。
- 准备材料表。
- 与其他顾问讨论提案并采纳他们的意见。
- 向工料测量师提供信息，以便编制施工成本和时间概算。
- 必要时与法定机构协商。
- 就采购途径、适当的合同形式以及各方在每种情况下的责任向客户提供建议，并获得客户批准（参见“P3 设计师对客户的责任”，第 26 页和“P3 ID/10 术语解释，附录 A 和 B”，第 70 页）。
- 向客户展示概念方案（包含上述交付成果），并与客户审查选项。

在较小的项目中，阶段 c、d（设计深化）和 e（技术设计）通常在同一练习中进行。

## C 关于就勘查事宜致函客户的说明

**勘查** 通常客户既没有场地也没有现有建筑的充分图纸。房地产经纪人的平面图细节很少，而且通常不准确，因此不应依赖。根据 ID/10 第 3.8 条，客户有义务提供进行设计工作所需的勘查。如果这些勘查此前尚未准备，设计师可以安排进行。这些可以是实测勘查、状况勘查和共墙勘查，通常均由不同的专业勘测员执行。

**实测图** 在小型项目中，设计师可以自行测量建筑，前提是图纸仅供设计师本人使用且不提供给客户。但是，设计师应当记住，当按时间收费时，出于对客户的公平性考虑（除最小的项目外），他/她可能不具备合格勘测员的专业知识，但其时间收费率却往往更高。

对于新建筑，通常需要对场地进行地形勘查，显示点高程和等高线、边界、毗邻建筑和道路、植被、排水管道和检查井等。地质土壤勘查通常也是必要的。

对于现有建筑，通常需要详细的平面图、剖面图、外立面图和内立面图。如果建筑的特征很重要，则应测量包边线等木制品的轮廓。如果计划对场地或排水管道进行工作，则需要上述地形勘查。

**建筑勘查** 如果拟对现有建筑进行工作，则应勘查拟施工部分的建筑状况。如果建筑状况看起来合理，则可以由设计师进行。但是，如果设计师有任何理由相信该建筑的结构、服务系统或构造可能存在重大问题，则应建议客户聘请建筑勘测员编制书面报告，包括对可能结构缺陷、虫害、沉降、潮湿、装饰状况等的调查。应将此报告副本交给设计师，以便在施工过程中解决任何必要的整改工作。

**共墙勘查** 如果拟在与毗邻业主边界相邻的现有或拟建建筑上进行建筑工作，则应征求共墙勘测员的意见。

在理解共墙立法时，毗邻业主想象他们共同拥有整面共墙通常很有帮助。通常，一个业主不能阻止另一个业主对该墙进行施工，但有权要求施工方修复因施工而对墙体或其自身财产造成的任何损害。关于此事的详细规则复杂，最好留给专业的共墙勘测员处理。

**照片** 拍摄大量场地和/或建筑的数字照片（使用广角（甚至鱼眼）镜头）非常有用，可作为项目设计阶段的参考以及施工开始前场地和/或建筑的记录。这些照片可以由设计师或实测图勘测员拍摄。

**先前同意** 设计师还应检查最近的任何建筑扩建或改动是否已获得必要的同意。
