## 英国室内设计学会

英国室内设计学会（BIID）是英国唯一代表室内设计师的最古老专业团体。该学会成立于1965年，原名室内设计师和装饰师协会（IDDA），2005年与国际室内设计师协会合并，成为英国室内设计协会（BIDA）。2009年，公司注册处代表科学与创新大臣，授予该协会将“Institute”一词纳入其名称的权利。公司注册处仅将此特权授予“地位最高的专业团体”。

2005年，BIDA与英国皇家建筑师学会（RIBA）合作制定了ID/05，这是设计师与客户之间的咨询合同格式，现已成为行业标准。该文件现已更新为ID/10。

2009年，BIID受邀成为建筑业委员会（CIC）的成员，该委员会是建筑业咨询机构的协会。这使得室内设计行业的声音能够在行业和政府最高层面被听到。
