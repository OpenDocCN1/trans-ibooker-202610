## 设计

随设计进展，以下几点很重要：

- 客户知悉所有所需的许可，并且这些许可在适当阶段申请并获得（详见下文各阶段描述）
- 确保客户履行其在健康与安全立法下的义务（参见“f 致客户函关于CDM法规的注释”，第164页）
- 不要依赖公用事业公司提供的初步信息；这些信息常常是错误的
- 定期咨询客户，并获得客户对每个阶段不断发展的设计的批准
- 设计师在每个阶段结束时获得施工成本和进度表的估算，并在进入下一个阶段之前获得客户批准
- 如果客户指示修改方案以削减预算和/或进度，设计师应充分解释这些削减可能对项目产生的任何不利影响
- 任何指定的创新设计或材料都应提请客户注意，并充分解释相关风险
- 不要就设计师无资格提供建议的事项提供建议（例如房产价值）
- 仔细核对并协调顾问信息与设计师的图纸和规范
- 在向施工方发放合同文件前彻底检查（并确保费用中包含足够的检查费用预留）。如果可能，此工作应由之前未参与该项目的人员进行
- 设计师应强烈建议客户不要让任何朋友担任供应商或承包商

## 施工

客户常常认为设计师对施工质量提供保证，即使设计师仅以专业身份行事。设计师需要：

- 向客户解释，设计师不可能在物理上检查所有施工工作。如果客户需要详细检查，他/她应考虑聘请驻场监督员（参见“H 致客户函关于驻场监督员的注释”，第178页）
- 向客户解释其关于保险的责任，确保客户（如有要求）和承包商都已投保适当的保单，并检查保单以确认其充足且将在预期的建筑工程期间提供保障
- 向客户解释施工期间应遵循的程序（参见“l 施工前致客户示范信函”，第200页）
- 在施工开始时要求承包商提供一份所需进一步设计信息的清单以及在建筑进度延误前交付这些信息的最晚日期

## P3 风险规避（续）

- 随着施工进展，保存详细的书面和照片记录。设计师应仔细记录现场会议纪要，并在他人提供的与施工相关的书面记录经过检查和批准之前不予接受
- 如果在现场发现问题，应立即书面通知客户，说明如何整改及其对成本和进度可能产生的影响。在下次现场勘查时确认是否已整改
- 不接受替换指定材料或瑕疵施工。中期估价不仅应扣除瑕疵工程的费用，还应进一步削减以覆盖清除费用
- 除非必要，否则避免在现场给出指示。任何此类指示应在24小时内以书面形式确认
- 如果项目由不同的事务所分别设计和检查（例如，因场地位于国外），应确保职责分工明确。应告知客户，在设计和施工前阶段不可能覆盖所有细节，一些次要设计决定将不得不由检查设计师在现场作出
- 避免任何暗示他在签发付款和其他证书时受到客户影响。设计师在签证时必须使用（并且看起来使用）其完全独立的判断

一般来说，设计师还应：

- 如果新指示更改了初始任务说明，应立即书面确认（参见“d 客户指示范本”，第140页）
- 立即处理任何明示或暗示的投诉，通过详细解释他/她采取被投诉行动的原因
- 如果有人暗示疏忽指控，应通知其职业责任保险公司（参见“fC 致职业责任保险公司函的注释”，第262页）
- 如果客户指示变更（尤其是在施工阶段），应仔细调查变更的全部影响（包括对顾问工作的影响），分析成本和时间影响（包括任何额外费用），并在实施变更前向客户提出建议
- 如果一个项目暂停一段时间后恢复，在继续之前应仔细审查项目已完成的工作。如果是从另一家事务所接手的部分完成项目，这一点尤为重要
- 如果出现设计错误，应在发现后尽快纠正，并尽量限制其后果。设计师应通知其职业责任保险公司
- 避免现金交易。此类付款日后可能难以提供证据，并且常被用于逃税，设计师最好与之毫无瓜葛

## P3 ID/10背景

室内设计服务委托协议（ID/05）于2005年由RIBA和BIID（当时为BIDA）发布，有着显著的渊源。它源于建筑师委托标准协议（SFA/92），该协议最初于1992年发布，1999年发布了修订版（SFA/99），并在2000年和2004年略作修订。还发布了略有简化的版本CE/95和CE/99。2010年，ID/05进行了修订，以考虑立法变化和用户反馈，并更名为ID/10。

自这些表格发布以来，已积累了一小部分判例法（参见“适用判例法”，第282页），强化了其效力并确立了其在建筑行业中的地位。这些表格通常被视为在客户与建筑师或设计师的利益之间提供了公平的平衡，并且在正确使用时，这些表格具有完全的强制执行力。

这并不是说这些表格被所有类别的客户普遍接受。经常委托建筑师和室内设计师的大型组织，例如开发商、政府等，通常有自己的定制表格，并试图强加给其顾问。这种表格通常会通过移除各种保障措施（例如执行付款的能力）并增加沉重的责任，从而显著不利于顾问，因此只有在征求专业法律意见后才应考虑。

以下是ID/05中在ID/10中发生重大变化的条款的简要摘要：

- 对CDM法规的引用已被省略（ID/05第1.7条和第8.22条）。这样做的理由是，遵守这些法规是法律要求的，因此在协议中提及它们是不必要的。建议设计师将经验不足的客户的注意力引向他们在这些法规下的责任（如有）。
- 已增加提及设计师代表的条款（ID/10第2.7条）。
- 对驻场监督员（工程监督员）的引用已被省略（ID/05第3.10条）。这些人员可以根据ID/10第4.3条聘用。
- ID/10中的成本追偿采用按正常基础（而非赔偿基础），并且现在同样适用于设计师和客户（ID/10第5.22条）。
- 已添加于2008年10月1日生效的消费者取消权（ID/10第10节）。
- ID/10附录B中已增加若干关于FF&E的条款。

以下是对ID/10的逐条解释（参见“P3 ID/10条款解释”，第46页），旨在确保设计师在签订此类委托协议时了解自己和客户同意的内容，如何正确填写，以及如何向消费者客户进行解释。
