## H 关于获取投标的注释  

- **投标** 当雇主决定使用竞争性投标来选择承包商时，设计师应遵循谨慎的程序，以确保投标过程对雇主有效且对投标人公平。  

- **投标人** 通常认为，要求三到五家承包商提交投标是合理的。太少，则存在收到的有效投标不足的风险；太多，设计师可能会发现没有承包商愿意未来投标。  

- **虚标价** 截至2009年，承包商对特定项目不感兴趣投标，但又不想因拒绝邀请而得罪顾问的情况，很常见，他们会提交一个“虚标价”。这是通过从另一投标人处获得高于其他承包商投标价的价格来确定的，从而确保该投标不具竞争性。这一非法行为曾被公平贸易办公室调查，该年对103家大型承包商处以总额近1.3亿英镑的罚款。然而，这种做法似乎仍在持续，因此设计师向投标人保证拒绝邀请不会影响其未来项目的机会，这很有帮助。  

- **专业工程** 当某些专业工作项目特别重要时，设计师可能希望单独安排获取分包投标，并将成功的分包投标人提名给主承包商。若遵循此程序，分包投标人名单应列在主合同投标文件中，以便主承包商有机会提出反对。  

- **通知** 收到投标后，向投标人告知结果是公平的。审慎的做法是对最低投标进行核查，并将第二低的投标人告知该情况，以便必要时他们仍可提供服务。
