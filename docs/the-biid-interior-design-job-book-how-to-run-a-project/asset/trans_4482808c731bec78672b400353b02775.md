## P1 费用记录说明

### 费用记录

费用记录，与工时表一样，应由执业机构的所有成员（包括董事/合伙人）保存。它们可以作为向客户收取费用的一部分列入。

费用分为两类：

- 可收回：根据委任条款可以向客户收取的费用：通常包括差旅、膳食以及各种杂费（如文档打印和复印）。设计师应谨慎处理，除非某项费用（如午餐）对项目实施是严格必要的，否则不得收取。
- 不可收回：执业机构运营所必需但无法公平地向客户收取的费用。

针对需单独索取费用的项目所产生的可收回费用，连同任何约定的手续费，将每月汇总，以便列入下一张客户发票。有关如何列出费用以支持发票的示例，请参见‘fC 样本费用计划表’，第 250 页。

另请参见‘P3 费用和开支表说明’，第 42 页，了解收取费用的替代方法。

## P2 建议书阶段

### 阶段描述

此初步阶段涵盖向潜在客户提交的文件的准备，描述设计师对拟议项目的资格，包括以下内容：

### 建议书

项目始于设计师发现潜在工作，或潜在客户联系执业机构请求提出建议书。设计师应首先考虑自己是否具备执行该项目的专业能力，以及在时间和人员方面是否有足够的资源。

设计师希望向客户描述执业机构可以提供的服务以及使其符合项目资格的相关经验。刚刚成立自己执业机构的设计师可以引用在之前工作中获得的相关经验，前提是他们向潜在客户说明这一点。错误陈述过往经验从来都不明智，如果客户认为自己受到欺骗，可能会导致法律诉讼。

作为有限公司或有限责任合伙企业运营的执业机构（在当今多诉讼的世界中，这强烈建议如此）应记住，其公司账目是公共记录，尽管通常滞后一两年。客户可以使用这些信息来决定执业机构是否有能力承担拟议的工作。

如果潜在客户对设计师来说不熟悉，执业机构可能希望同样检查客户的财务报告（如果有的话）以及客户的信用记录。有关英国有限公司的信息可以通过访问 http://www.companieshouse.gov.uk 支付少量费用获得。

### 执业机构信息

准备充分的公司将随时掌握一般执业机构信息，以及可用于验证其对所涉项目适合性的更详细的项目信息。此类印刷的执业机构信息应由专业平面设计师按照高标准设计，以正面反映执业机构，并可能包括：

- 关键员工的履历，强调其在拟议项目类型方面的经验
- 相关过往项目的图片。（必须专业拍摄执业机构的已完成项目——请参见‘I 致摄影师的范本信函’，第 231 页。）
- 执业机构历史，强调其在拟议项目类型方面的过往经验
- 过往客户名单，特别是那些委托过类似项目的客户。

### 服务范围

从未经历过设计然后执行项目过程的潜在客户可能对该过程涉及的内容知之甚少，并且常常想象它可以以很低的成本和在很短的时间内完成。对于此类客户，详细列出设计师将遵循的执行工作的程序通常很有用（请参见‘A 拟议服务范围样本’，第 83 页）。

即使是首次考虑使用设计师的有经验的客户，看到明确表明设计师将适当关注实现...的服务范围时，也可能会感到安心。
