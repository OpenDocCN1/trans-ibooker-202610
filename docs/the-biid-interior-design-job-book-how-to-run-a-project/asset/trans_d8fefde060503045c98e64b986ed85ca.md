## L 实质性竣工后阶段

### 阶段描述

阶段 L，实质性竣工后，涵盖实质性竣工后的建筑合同管理及最终检查的执行。收取额外费用的情况下，设计师可协助客户占用建筑并审查其使用性能。

同样应当注意的是，合同管理人有责任识别并补救缺陷，因此设计师应监控工程以识别任何其他缺陷，并确保在签发最终付款证书前全部得到补救。

### RIBA 工作计划

RIBA 2007 年概要工作计划将本阶段的关键任务描述为：'L1：（实质性竣工后）实质性竣工后的建筑合同管理及最终检查。L2：协助建筑使用者在初期占用期间。L3：审查项目使用性能。'

### ID/10

除非设计师充当承包商，否则阶段 L 是 ID/10 内部设计服务时间表 A 页上的“安装管理”阶段，在此情况下它是“建筑工程”阶段。

如果设计师提供家具、装置及设备，则该任务显示在时间表 D 页的“由设计师供应家具、装置及设备”阶段中。

### 任务：室内设计师/首席顾问

当在设计团队中担任室内设计师或担任首席顾问时，设计师只执行以下五项任务（交付成果以 **粗体** 显示）：

- 编制缺陷清单。
- 访问工地以监督缺陷的补救。
- 向工料测量师提供信息，以编制最终账目。
- 签发缺陷修复完工证书。
- 签发最终证书。

### 承包商

当根据 ID/10 附录 A 担任承包商时，设计师只执行以下三项任务：

- 协助家具、装置及设备的安装和调试。
- 补救任何缺陷。
- 向客户开具最终发票并收取款项。

### 家具、装置及设备采购

根据 ID/10 附录 B 中的 B1 和 B2 部分采购家具、装置及设备时，设计师执行以下两项任务：

- 监控专业项目和/或家具、装置及设备的交付/安装。
- 向客户提供关于家具、装置及设备的维护建议。

### 家具、装置及设备供应

根据 ID/10 附录 B 中的 B1 和 B3 部分供应家具、装置及设备时，设计师执行以下任务：

- 供应/安装专业项目和/或家具、装置及设备。
- 向客户提供关于家具、装置及设备的维护建议。

在较小项目中，阶段 J（进场）、K（施工至实质性竣工）和 L 通常在同一过程中完成。
