

## K 关于有缺陷工作的注释

### 缺陷

如果设计师发现，或有充分理由相信，施工工作未按照建筑合同进行，他/她应首先确定缺陷是轻微还是严重。

### 轻微

如果缺陷轻微，设计师应要求予以补救，并立即将不合格材料从现场移走，并应将所有这些情况记录在现场访问报告中。用更便宜、更劣质的油漆品牌替换，是此类缺陷的典型表现。

### 严重

如果缺陷严重，设计师应采取以下措施：

- 拍摄有缺陷工作的详细照片并准备报告
- 采集并保存任何有缺陷或不合格材料或设备的样品（包括任何产品标签）
- 如有必要，安排进行独立测试并编制报告
- 在现场访问报告中记录缺陷及所采取的所有措施
- 指示承包商移除有缺陷的工作，进行补救工作，并尽量挽回因缺陷造成的任何延误
- 通知客户缺陷、其可能的影响，例如补救措施及其对工期的影响、是否需要开启已完成的类似工作、是否需要征求其他顾问的意见、设计师和/或顾问在处理缺陷方面产生的任何额外费用等。设计师不应忘记，处理缺陷所造成的任何额外工作将根据ID/10第5.8条产生额外费用，他/她应在严重缺陷显现时尽快通知客户。客户可能能够从应付给承包商的款项中抵扣此费用。
- 客观考虑客户是否（即使不合理地）可能认为他/她有理由声称缺陷是由设计师的疏忽造成的（例如未能精确规定），如果是，则通知设计师的职业责任保险公司
- 向承包商发出扣付通知，以允许与有缺陷工作相关的款项从应付款项中抵扣
- 调整下一次估价（或如果项目聘有工料测量师，则通知工料测量师），以减少应付给承包商的有关有缺陷工作的款项
- 工作结束时，计算由缺陷及其补救造成的对项目的任何最终延误，并适用任何适当的约定赔偿金。如果在实质完工证书签发后才发现缺陷，可能会有进一步的赔偿金需支付给客户。

必须允许，甚至应鼓励承包商补救缺陷。但是，如果他/她不愿意这样做，设计师应建议客户如何采购补救工作并追回任何合理的相关费用。

## K 关于证书的注释

### 证书

作为主顾问管理建筑合同时，设计师的职能之一是在不同阶段签发证书。这些证书分为两类：*payment certificates*和*completion certificates*。以下页面的样本仅涉及JCT小型工程建筑合同（MW 05），第2次修订版，2009年。

### 进度付款

在建筑合同执行期间，此付款证书应每四周（或另行商定）签发一次，用于支付已完工程款项，扣除保留金（通常为5%）。如果雇主根据非MW 05形式的合同聘用了工料测量师（QS），则QS将签发每四周或每月一次的估价，并在设计师对已完工程质量满意的前提下，签发相应的进度付款证书。

如果未聘用QS，则设计师必须检查承包商的付款申请，并努力确定其是否公平反映已完工程和现场材料的价值。设计师必须认识到，承包商有利于‘front load’付款，即在工程早期阶段尽可能多地收款，以改善其现金流。应在项目开始时告知雇主，如果未聘用QS，设计师不一定具备精确衡量工程中期价值的技能。

### 实质完工

当工程实质完工时签发此完工证书。‘实质完工’从未被精确定义，但通常是指设计师证明工程除了轻微缺陷外没有已知缺陷，并且为实际目的而完工，即为了允许雇主占用工程并按预定用途使用。

抵押贷款机构和其他资金方通常会在签发实质完工证书之前不释放付款。样本费用和开支清单（见第44页）中的脚注3规定，在设计师签发实质完工证书之前，应支付截至包括K工作阶段的所有到期费用和开支，从而鼓励客户支付任何未付费用。

### 次末付款

此付款证书在签发实质完工证书后签发。它证明剩余应付款项，并释放保留金的一半，通常为2.5%。

### 缺陷修补完工

此完工证书在缺陷修补期结束时签发，此时承包商已令设计师满意地修补了在签发实质完工证书时或缺陷期间发现的所有缺陷。

### 最终付款

此付款证书在签发缺陷修补完工证书后签发，并释放应付给承包商的所有剩余款项，包括保留金余额。

### 副本

所有证书的正本连同承包商副本一起签发给承包商。进一步副本发给雇主和设计师档案。承包商将把正本提交给雇主，以支持其付款索赔。

必须告知客户，他们绝不应试图干涉设计师公平签证的职责。此类干涉可能导致设计师的公正性遭到成功挑战。
