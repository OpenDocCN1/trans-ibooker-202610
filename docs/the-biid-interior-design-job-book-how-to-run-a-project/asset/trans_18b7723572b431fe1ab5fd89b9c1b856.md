## C 现场报告和状况表说明

### 现场勘察
设计师正式受聘后，最好重新勘察现场，仔细检查与要求书相关的区域。

### 现场报告
如果项目会影响外部（例如新扩建部分），则应准备一份现场报告，对相关外部构件的状况以及可能影响拟议工程的任何邻近房产方面进行评述。

### 状况表
当无需准备建筑勘察报告（如果最近刚准备过一份，或者拟议工程相对较小）时，设计师为受工程影响的空间准备状况表通常很有用。这些状况表将有助于日后将空间的工作进度表作为合同文件的一部分来准备。

## C 致潜在顾问信函说明

除了极小型项目外，大多数项目通常需要设计师专业领域之外的专家建议。设计师不应尝试提供其不具备资格或经验的建议，因为：

- 这不符合项目或客户的利益
- 这可能不包括在设计师的职业责任保险范围内，在疏忽索赔情况下会使设计师无法获得保护。

当设计师意识到需要专家建议来满足客户的要求书时，他/她应建议客户聘请合适的顾问。

由于客户可能不知道谁适合这项任务，设计师可以推荐他/她过去使用过、表现令人满意的顾问。但是，设计师应明确告知雇主，他/她无法保证任何顾问（即使被推荐）在该项目中表现良好。

任何顾问都应由客户直接聘用，而不是由设计师聘用，否则设计师可能会被追究顾问所谓疏忽的责任。
