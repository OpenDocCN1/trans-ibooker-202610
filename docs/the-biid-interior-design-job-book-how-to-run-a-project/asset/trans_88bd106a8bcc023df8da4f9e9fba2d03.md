### F 生产信息阶段

**阶段描述**

阶段 F，生产信息，涵盖合同文件的完成（参见“e 合同文件说明”，第 144 页），这些文件将发给投标人，用于工程报价和施工。

**RIBA 工作计划**

RIBA 2007 工作计划大纲将本阶段的关键任务描述为：“准备施工详细信息。申请法定批准。根据建筑合同要求准备进一步的施工信息。审查专家提供的信息。”

**ID/10**

阶段 F 是 ID/10 中室内设计服务进度表第 a 页上的“安装管理阶段”。

**任务：室内设计师/首席顾问**

当设计师在设计团队中担任室内设计师或担任首席顾问时，设计师将执行以下所有任务（交付成果以粗体显示）：

- 将技术设计图纸开发为生产信息图纸，展示所有结合结构与服务的各部位施工情况，包括所有木作、卫生和电气配件的细节，细节程度足以编制投标。
- 向其他顾问提供信息，与其讨论方案，纳入并协调其他顾问的意见，编制生产信息。
- 向工程造价师提供信息，以便编制工程量清单或施工进度表用于投标。
- 向客户展示生产信息（包含上述交付成果），并与客户审查选项。

**承包商**

如果设计师根据 ID/10 附录 a 担任承包商，那么本阶段 f 的工作，连同阶段 g（招标文件）和阶段 h（投标行动），将在阶段 h 结束时执行并提交给客户。

在小型项目中，阶段 f、g（招标文件）和 h（投标行动）通常在同一工作中完成。
