## K 直至实际完成的施工阶段

### 阶段描述
k阶段，直至实际完成的施工，涵盖建筑合同的管理以及根据要求向承包商发出任何进一步信息。

### RIBA工作计划
RIBA 2007大纲工作计划将本阶段的关键任务描述为：“直至实际完成的建筑合同管理。根据合理要求向承包商提供进一步信息。审查承包商和专家提供的信息。”

### ID/10
除非设计师担任承包商，否则k阶段是ID/10室内设计服务清单A页上的“安装管理”阶段；在这种情况下，它是“建筑工程”阶段。

- **任务：室内设计师** 作为设计团队中的室内设计师时，设计师将只执行以下任务（交付成果以粗体显示）：
  - 建议应邀请提交专业物品和/或FF&E投标的公司；邀请、评估并向客户报告投标。

- **首席顾问** 作为首席顾问时，设计师将执行上述任务以及以下五项任务：
  - 管理建筑合同。
  - 与承包商召开会议以审查进度。
  - 按施工阶段适当的间隔视察现场，以监控建筑工程的进度和总体质量，并接收现场检查员的报告。
  - 向工料测量师提供信息，以便编制已完成工作的估价和向客户提交的财务报告。
  - 签发付款证书和实际完成证书。

- **承包商** 在ID/10附录A项下担任承包商时，设计师将只执行以下两项任务：
  - 执行并完成建筑工程，并移交给客户。
  - 定期向客户开具发票并接收付款。

- **FF&E 采购** 在ID/10附录B部分B1和B2项下采购FF&E时，设计师将执行以下两项任务：
  - 与客户就支付FF&E物品的基础达成一致（例如，以预付格式发票或从客户账户支付）。
  - 以客户名义（向客户提供副本）为FF&E物品签发采购订单。

- **FF&E 供应** 在ID/10附录B部分B1和B3项下供应FF&E时，设计师将执行以下任务（在“FF&E供应”阶段显示，第234–241页）：
  - 为FF&E物品向供应商签发采购订单，并为供应此类物品向客户签发销售订单。

在较小项目中，j阶段（进场准备）、k阶段和l阶段（实际完成后）通常在同一工作中完成。
