# # P1 Notes on document issue

# **Document issue**

All documents issued externally should be accompanied by a documents issue form to allow the recipient to confirm that he/she has received all the documents sent and as a record in the project file. Copies of the documents sent should also be included in the file.

Designers often think it unnecessary to file copies of draft documents as they will be filed when completed. This is a mistake as it may be important at a later date to establish the state of the document at the time of issue.

Extra pages can be added to the document issue form as necessary.
