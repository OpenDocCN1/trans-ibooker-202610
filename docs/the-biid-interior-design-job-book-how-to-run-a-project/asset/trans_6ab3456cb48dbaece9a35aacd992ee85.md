## C 关于资源预测的说明

### 资源估算

当事务所与客户签订合同，按百分比或总价基础开展工作时，估算工作成本非常重要，首先是为了计算费用，然后随着每个阶段的完成进行更新，最终以显示实际耗时成本与估算成本的对比。

### 预测

相对页的资源预测样本说明了事务所在项目推进过程中所产生的时间成本的约数滚动估算。或者，设计师可以尝试更精确地预测每项任务所需的时间量，但由于这些时间量在不同工作之间可能有很大差异，此类预测往往相当不准确。

插图显示了一个典型项目，其建筑成本在整个过程中不断增加，可能是由于客户指示或现场遇到的意外问题。当设计师的费用按百分比基础计算时，费用会按比例增加。然而，如果建筑成本因客户削减项目摘要等原因而下降，设计师根据 ID/10 条款 5.7.2 受到保护。

### 薪资成本

薪资成本应基于每个人的年薪加上国民保险缴费及其他与薪资直接相关的成本进行计算。这应除以每年 1,600 至 1,750 个工作小时，以得出每小时薪资成本。董事/合伙人的年薪假定为与其年龄和经验相称的名义水平，其薪资成本亦按此类似计算。

### 每小时费率

每位工作人员的每小时收费费率应定为其薪资成本的倍数。一个粗略的假设是办公室间接费用等于薪资成本，通常倍数为薪资成本的 2.5 到 3 倍。这代表薪资成本（1.0）加上间接费用（±1.0）加上利润（约 0.5–1.0）的总计。

不同阶段的各个项目会根据项目预算和事务所可用资源，分配具有相应经验的不同董事/合伙人和员工。

### 应急

为每个阶段预留应急时间是明智的，并请记住，施工阶段的耗时几乎总是大于预测。

### 未来

建立工作成本记录将有助于设计师在考虑通货膨胀后估算未来项目的费用。

## C 关于材料清单的说明

### 材料清单

除了设计师准备的用于传达拟议设计基本原则的概念图纸外，还应制定一份初步材料清单，以：

- 提交给客户以供讨论和批准
- 提供给工料测量师以进行初步成本估算。如果精确细节尚未确定，注明所期望的质量范围很有用
- 支持规划申请（如相关）
- 成为大纲规范的基础，最终成为施工规范（参见“d 大纲规范样本”，第 137 页和“e 规范样本”，第 151 和 152 页），后者最终将构成施工合同文件的一部分。

材料规范可以通过情绪板、相关室内图像（不一定是设计师设计的）来支持，以表明拟议室内设计的关键方面。

在以下示例中，材料选择的很大一部分将在就作为工程一部分的新扩建部分咨询建筑师后作出。

在多个领域，精确的材料规范尚未确定，工料测量师将不得不在这个阶段使用其判断来列入临时金额。

材料清单稍后将发展为大纲规范（阶段 d）和施工规范（阶段 e）。

### 排列

材料清单按照 1959 年建立的、现今在建筑行业广泛使用的英国版 CI/SFB 建筑分类系统进行排列。其名称代表 Construction Indexing/Samarbetskommittén för Byggnadsfrågor，后者是最初开发它的瑞典组织。

CI/SFB 的要素部分，按建筑要素对建筑进行分解，在该早期阶段使用。
