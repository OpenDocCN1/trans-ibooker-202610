

# 可视化成功的公开演讲有助于提升你的沟通和演示技能。

当我有一场重要的演讲需要发表时，我会在演讲前几天就开始可视化这个演讲过程。我会想象自己穿着什么，走上舞台，看到观众对我的第一个笑话发笑。我会想象那种感觉，尤其是当我赢得一阵掌声时。

可视化不仅仅适用于大型演讲。如果你有一场重要的客户会议或团队会议，甚至是一次艰难的一对一会面，或者求职面试，不妨尝试一下可视化，或许会有意想不到的效果。

# 尝试与众不同

我曾合作的一位高级领导被要求在午餐后主持会议环节。会议在一个大房间举行，大约有250人围坐在每桌十人的桌子旁。

他没有走上舞台，而是决定从房间的最后方开始说话。他佩戴了一个领夹麦克风，声音清晰可闻，但看不见身影，因此每个人都在四处张望寻找他。只花了几秒钟，他们就找到了他。然后，他慢慢地穿过大部分桌子走向前方，直到走上舞台才结束演讲。这位领导通过做一点点与众不同的事情，并结合分享个人故事，产生了巨大的影响。

# 你仍然可以通过做一些不寻常或出乎意料的事情来展现专业性并彰显个性。

我在进行故事性演讲时也采用类似的方法。在某个时刻，我希望带领观众了解什么是故事，以及在商业中实施讲故事时的重要考量。我没有简单地列出内容，而是让观众进行讨论。通常我的观众围坐在桌子旁，因此可以轻松互动。几分钟后，我走下舞台，从房间后方开始分享他们的想法。这让我能够以更个人化的方式与观众互动。

房间的大小和布局将决定我如何做到这一点。如果我面对数千人演讲，我就不采用这种方法。同样，如果我在礼堂或讲座式布置中，这种方法也不适用。不过，只要可能，我都会要求参与者围坐在桌子旁。即使在观众中走动并不总是可行，要求人们讨论一个想法——即使在礼堂里两两讨论——仍然有效。

> 不要被你认为演讲应该是什么样子的期望所束缚。做你自己！

另一种掌控局面并摆脱传统演讲束缚的方法是，让别人采访你，而不是你发表传统演讲。这允许更随意的方式，并有助于融入更多故事来说明你的观点。

我记得曾与一位CEO合作他的演讲，他分享的个人故事清楚地展示了他的价值观。当我建议我们进行采访而不是演讲时，他如释重负的表情显而易见。他知道我会问什么问题以及他想传达的相应信息，但他也给了我自由提出额外问题。这种形式让他能够展示真实的自我。

# 选择能增强自信的衣服

在她的书《大胆去做》（*Daring Greatly*）中，布伦é·布朗（Brené Brown）分享了一个她在芝加哥一次全球最大的领导力活动中演讲的故事。活动组织者强烈建议她穿商务正装，她照做了。布朗随后描述自己与另一位演讲者坐在一起，“低头看着我的黑色西裤和高跟鞋，感觉自己像个冒牌货。或者说，像是要去参加葬礼”。她向另一位演讲者坦言，她感觉自己在玩“换装游戏”。另一位演讲者告诉她“看起来不错”，但布朗知道她的脸在说，“我知道。这很难。但我们能怎么办呢？”

于是，布朗再也忍不住了，抓起行李箱，去了洗手间，换上了牛仔裤、海军蓝衬衫和木屐——这是她感到自信的穿着，更重要的是，让她感到真实的穿着。

# —— 真实沟通 ——

当你的信息像布朗一样关注真实与勇气时，感到真实非常重要。看到她换衣服后，另一位演讲者说，“太棒了。你真勇敢”。

你穿什么会对你的自信产生重大影响。在为演讲或重要会议着装时，确保你穿着让**你**感到自信的衣服。（这里的 YOU 全大写，是因为你不希望被别人告诉你什么好看，或者你需要穿什么才能感到自信或看起来“专业”。）

# 如果你穿着不自信，那就不要穿。

关于演讲时穿什么，我有一个小小的原则：稍微高于观众的着装规范，或者至少与众不同。我经常穿着很好的布洛克鞋，与观众可能穿的截然不同——例如，可能是闪亮的银色或闪亮的。这些鞋子会成为引发对话的东西，并让我脱颖而出。

只要找到让你感到真实和自信的东西，因为这会影响你沟通时的自信。

# 停止躲藏

真实沟通的核心在于互动和连接。不幸的是，由于紧张或缺乏自信，我们中的许多人试图躲在笔记后面。

阅读笔记会立即与观众产生脱节。无论你是在会议中沟通还是在舞台上，都要尽量避免阅读笔记。没有人知道你的笔记里写了什么，如果你忘了什么，唯一知道的人只有你。即使观众知道了，他们也不在乎。

# 有勇气扔掉笔记。

人们在阅读笔记时常常诉诸讲台的安全感。这意味着你不仅在阅读，而且现在在你和观众之间设置了一道物理屏障。如果你个子矮，这简直是灾难，因为人们只能看到一个脑袋从顶部探出来！

尽可能要求使用领夹麦克风，这能让你在观众中间走动，并有助于建立更强的连接。如果你需要参考笔记，也可以随时走回讲台或桌子前。

> > 真实和真诚的沟通不是向人们倾倒一堆信息，而是尊重并促进他人的意见。

如果你想要一种更具吸引力和对话式的风格，而不是单向演讲，你应该考虑通过提问来让观众参与进来。

作为演讲者，要明白提问可能令人生畏，尤其是当你是大观众的一部分时。大多数人不喜欢公开演讲，有些人认为自己的问题或评论不合适，因此害怕显得愚蠢而不敢提问。我经历过在向观众征求提问后那令人恐惧的沉默，但你可以使用某些技巧来鼓励参与。

# 让每个人都参与进来

你是否曾经在会议中遇到过有人拿来打印的 PowerPoint 演示文稿，然后开始翻页？

这种情况发生时，我会做两件事：

- 我试图弄清楚这份文档有多少页，以便为自己做好“PowerPoint 致死”的心理准备。
- 我会 disengage，因为我认为这个人是来展示而不是交流的，他们会不顾一切地浏览完所有幻灯片和要点。

> > 最重要的是，有勇气站出来发表演讲——无论是面对面、电话中，还是在同伴满座的房间里。

# —— 真实沟通 ——

我倾向于在最初的几秒钟沉默中喝几口水来度过。实际上大约是10秒，但对观众中的其他人来说，感觉要长得多。然后我开个玩笑说我是按分钟拿钱的，所以我很乐意等下去。这总是会让人们发笑，并且总有人最终会提出一个问题。每个人都讨厌那种尴尬的沉默，包括你的观众，所以只是时间问题，总会有人“可怜”你并救你一命。

> 你可以，也应该，做某些事情来收集观众的意见——不要只是假设他们无话可说。

我在会议上演讲时，也总是会预留出休息后的时间。毫无疑问，我总会有人在休息期间走过来问我一个他们不敢在公开场合提出的问题。

你也可以给观众一分钟时间讨论演讲——无论是在他们的桌子旁（如果是那样的座位安排），还是与旁边的人讨论。之后，你可以根据他们讨论的内容征求问题或评论。这会产生一种“众人抱薪”的安全感，而且通常也能产生更高质量的意见。

# 关于 f-bomb 呢？

我记得第一次在新西兰的一次会议上在舞台上说 f-bomb。（我一直以为澳大利亚人是世界上最爱骂脏话的人，直到我开始在新西兰待了一段时间。）

当时观众大约有80人，规模相对较小，我的会议也相当互动。最后，一位先生站起来说：“我同意你说的，因为昨天有人在谈论战略品牌叙事，我当时在想，我甚至不知道那是什么意思。”我回答说：“你说得对。那到底是什么意思？”我几乎赢得了起立鼓掌，然后结束了我的会议。

会议结束后，一位女士走近我，解释说她是人力资源经理。我的心跳停止了，脑子里想着：“操，操，操，我因为说了 f-bomb 而大祸临头了。”但她却说：“那太他妈棒了。”
