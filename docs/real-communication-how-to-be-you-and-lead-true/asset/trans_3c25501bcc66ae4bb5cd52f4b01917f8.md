

# — 真实沟通 —

> 他难道忘记自己言行会产生影响了吗？他难道忘记该服务的患者极其脆弱，他的话语会造成伤害吗？这是政党有史以来最不负责任、最懦弱、最鲁莽的表现。

随后，她被时任雇主澳大利亚板球公司（Cricket Australia）解雇。该公司发布的一份声明称，“澳大利亚板球公司尊重个人发表意见的权利。然而，它期望员工避免发表违反组织政策的冒犯性言论”。

威廉姆森目前正起诉澳大利亚板球公司，指控其不当解雇。其律师发布的一份声明认为，

> 《公平工作法》规定，你不能因为政治观点而被解雇。安吉拉所做的正是如此，她在推特上表达了自己的政治观点，随后便被澳大利亚板球公司解雇。在这样的情况下，有人会被解雇，这似乎令人难以置信。她在澳大利亚板球公司的工作与塔斯马尼亚州关于获得生殖健康服务的公共辩论毫无关系。

在撰写本文时，威廉姆森仍在开展她的运动，以确保澳大利亚所有女性都能获得安全且负担得起的避孕药具和妊娠终止服务。

无论你是否同意威廉姆森或她表达观点的方式，她采取立场并敢于发言必然会带来后果。只有她自己才能判断这些后果是否值得。

几个月后的一次电视采访中，威廉姆森表示她不应该在推特上使用脏话，但她并不后悔推特的初衷。2018年9月，威廉姆森与澳大利亚板球公司达成了一项庭外和解协议，协议内容保密。

# 生活的调味剂

特蕾丝·斯派瑟（Tracey Spicer）在1990年代和2000年代一直是澳大利亚第十频道（Network Ten）的电视新闻播音员，后来成为天空新闻（Sky News）的国际主播。她现在是一位备受追捧的主题演讲嘉宾和媒体评论员。

2017年，她出版了《好女孩褪去伪装》（_The Good Girl Stripped Bare_），此前她在2014年的TEDx演讲《女士褪去伪装》（‘The Lady Stripped Bare’）中取得了巨大成功。2018年澳大利亚日，她被任命为澳大利亚勋章成员，表彰她“作为记者和电视主持人在广播媒体领域做出的重大贡献，以及作为社会福利和慈善团体大使的贡献”。同年晚些时候，斯派瑟被评为《澳大利亚金融评论》（_The Australian Financial Review_）100位有影响力女性奖项中社会企业和非营利组织类别的获奖者。

斯派瑟最引人注目的公开发声时刻发生在2017年，当时#METOO运动震撼了美国电影和电视行业。斯派瑟等待着类似的揭露从澳大利亚传来。由于她整个职业生涯都在这个行业工作，她深知这里充斥着类似的性骚扰和性侵害故事。于是她等待着有人在澳大利亚打破沉默并带头……却一直等待。

随后她意识到，打破沉默的人应该是她自己。出于几个原因，斯派瑟觉得自己“别无选择”只能采取行动。

首先，她感到内疚，因为她知道自己所在行业存在这种性骚扰，但从未真正采取过行动，除了为自己而战。她还知道，凭借自己的经验和技能，她非常适合带头行动。而且她觉得，这是一个千载难逢的机会，可以借助#METOO运动的势头带来改变。

她采取立场的开始是2017年10月18日上午8:34的一条推文：“目前，我正在调查我们媒体行业中的两名长期犯罪者。请私下联系我，讲述你的经历”。

数百名女性联系了斯派瑟，分享了她们遭受不公正待遇的经历。斯派瑟询问她们是否需要心理咨询、法律或警方支持，然后再请求她们选择匿名发言或面对镜头发言。

斯派瑟最初的推文以及随后与费尔法克斯媒体（Fairfax Media）和澳大利亚广播公司（ABC）合作的调查，导致澳大利亚媒体行业的一些知名男性被指控系统性性骚扰。该调查随后获得了两项沃克利奖（Walkley Awards）。（这些奖项表彰新闻业的卓越成就。）

_自斯派瑟最初的推文以来，已有超过2200人站出来分享他们遭受骚扰和虐待的经历。_

# — 真实沟通 —

在与这些受害者交谈时，斯派瑟发现了一个共同主题，即为什么这么多人最初没有发声。许多人说，他们知道不会被相信，或者害怕被解雇。有些人甚至因为对施暴者感到同情而不敢发声。

由于她的调查，斯派瑟收到了死亡和强奸威胁，以及针对她及其家人的威胁。

尽管这些威胁令人震惊，但斯派瑟告诉我，反弹正是她所预料到的。她从个人经历中知道，“当你谈论影响性别权力平衡的问题时，总会有后果和反弹”。然而，她愿意冒这个风险。

# 站还是不站？

考虑到前几节讨论的潜在后果，你可能会认为不说话、保持中立是对每个人最好的选择。然而，杜克大学富夸商学院（Fuqua School of Business）的亚伦·查特吉教授（Professor Aaron Chatterji）不同意这一观点。

在他的CEO行动主义研究中，他发现，“处于中立的中间地带，大多数公司一代以前都是这样，现在已不再可行”，并补充说，“这被视为缺乏真实性”。

另一项研究——由韦伯山德威克（Weber Shandwick）和KRC Research于2017年进行的《2017年CEO行动主义：高层正午》（‘CEO Activism in 2017: High Noon in the C-Suite’）——揭示，近一半（47%）的受访千禧一代认为，CEO应该就社会问题公开表态。这一比例在X世代和婴儿潮一代中下降到28%。

该报告还发现，超过一半（51%）的千禧一代更有可能从CEO就相关问题发声的公司购买产品。与前一年的数据相比，这一比例增长了11%。X世代的这一比例下降到33%，婴儿潮一代则下降到30%。

最后，研究表明，47%的受访者表示，不表态的CEO有可能招致批评，无论来自媒体、客户、员工还是政府，21%的人表示沉默的CEO有可能导致销售额下降。

# — 展现你真实的自我 —

我认识的其他CEO主动选择不就社会问题表态。虽然他们个人支持特定事业，但他们认为，以CEO的正式身份表态，对那些不支持该事业，甚至持相反观点的员工是不公平的。

这个论点是有道理的。

我在第9章中介绍过的克里斯·弗伦德（Chris Freund）就是这样一位CEO。克里斯在一些有争议的社会问题上有着强烈的个人价值观。例如，他相信全球应该将毒品使用非刑事化。作为湄公资本（Mekong Capital）的负责人，他决定不将个人观点与公司联系起来。

他知道并非所有员工和其他利益相关者都会同意，也不想将自己的观点强加给他们。他觉得这样做是不公平的，因此，他寻找其他更个人化的方式来为自己的事业做出贡献。

展现你真实的自我并不一定需要公开表态。公开表态总会带来后果，因此只有你自己才能决定采取什么行动。然而，真实领导力要求你的言行保持一致，要求你在个人生活和职业生活中所坚持的价值观保持一致。

> _请记住，你不需要领导头衔来展现领导力和你真实的自我。_

# 立即践行真实

- 保持在家和在工作时行为的一致性。
- 确保你的言行保持一致。
- 如果这对你很重要，就采取公开立场。
- 在采取行动之前，寻求建议以了解你行为可能带来的任何后果。
