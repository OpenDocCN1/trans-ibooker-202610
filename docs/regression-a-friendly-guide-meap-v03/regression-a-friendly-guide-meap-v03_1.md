## 1.1 什么是回归？

在简短的介绍之后，你可能会问回归到底是什么——好问题！回归实际上是一系列用于 *探索数据中的关系* 和 *基于先前观察预测未来结果* 的方法。为了使这个一般性描述具体化，请考虑在我们生活中可能出现的一些典型问题：

- 成人识字率对婴儿死亡率的影响是什么？
- 学院入学率如何依赖于出生趋势？
- 在特定年龄发展慢性病的几率是多少？
- 更大或更小的动物灭绝风险更高吗？





- 每周交通事故死亡人数如何变化？
- 明天可能提交多少条错误报告？

正如你在接下来的章节中会看到的，回归方法可以用来回答这些问题以及许多其他问题。虽然我们需要的数据类型和要进行的分析将取决于具体问题的细节，但这些问题在根本上是相同的。在每种情况下，我们都想知道一个量，即*响应变量*，如何依赖于另一个量，即称为*预测变量*的*解释变量*。一个好的回归模型阐明了这些变量之间的关系，并允许预测预测变量的某些取值下的响应。当然，关键在于获得一个*良好*的回归模型，使其能很好地完成这些任务！

构建回归模型的第一个步骤是为感兴趣的问题确定适当的方法。当响应变量是*定量*的——例如考试成绩、识字率或其他测量值——时，*线性回归*是基本工具。当响应变量是*二元*的——通常解释为成功或失败——时，*逻辑回归*是首选方法；逻辑模型产生概率，这些概率可以直接使用或用于分类。当响应变量是*计数*——像死亡人数或错误报告数量这样的非负整数——时，那么某种形式的*计数回归*就是起点。以下是这些内容如何适用于上述问题：

### 表 1.1. 响应变量、预测变量和回归方法

| 关系 | 预测变量 | 响应 | 回归方法 |
|---|---|---|---|
| 成人识字率与婴儿死亡率 | 国家成人识字率 | 国家婴儿死亡率 | 线性回归 |
| 大学入学人数与出生趋势 | 每年出生人数 | 20年后的本科入学人数 | 线性回归 |
| 慢性病与年龄 | 年龄（岁） | 患慢性病的概率 | 逻辑回归 |
| 灭绝风险与体型 | 物种体重（公斤） | 濒危的几率 | 逻辑回归 |
| 每周交通事故死亡人数 | 一年中的周 | 交通事故死亡人数 | 计数回归 |
| 按天提交的错误 | 星期几 | 错误报告数量 | 计数回归 |

这些方法的结构相似性甚至更深，提供了统一性，而杂乱的公式可能会掩盖这种统一性。预测是回归的常见应用，而凭借经验和常识，我们都知道一个优秀的预测策略：根据可用信息猜测平均值。假设，例如，你独自在繁忙的城市中行走。你接下来看到的成年人的身高会是多少？猜测成年人的平均身高。你接下来看到的成年女性的身高会是多少？猜测成年女性的平均身高。你接下来看到的老年女性的身高会是多少？猜测老年女性的平均身高。等等。虽然预测的准确性取决于用于做出预测的信息质量，但基本原则保持不变：平均值通常是最好的猜测。本书中的所有回归模型都是这一基本思想的实现——请在我们继续时牢记这一点！

为了明确这一点，这里是本书中的第一个线性回归模型，将在下一章开始时详细介绍：

```
Average height of sons = 33.8866 + 0.5141 * Father's height.
```

现在，只需知道这给出了所有父亲身高给定时的儿子的平均身高（单位为英寸）；例如，如果一个男人的身高为 70.21 英寸，那么该模型预测他儿子的身高为

```
Predicted height of son = 33.8866+0.5141*70.21 = 69.98 inches.
```

他的儿子可能不会正好这么高，但这是基于用于构建模型的数据所能做出的最佳猜测；正如我们稍后会看到的，该模型还提供了我们猜测可能偏差多远的信息。无论如何，这个例子清楚地说明了贯穿回归建模的主线，即*直接关联平均响应和预测变量*。解释这种关系如何在逻辑回归和计数回归模型中体现还需要做一些工作，但我们会在适当的时候做到。

现在你对回归是什么有了一些概念，你可能会想知道另一个问题：一个有用的模型不应该包含多个解释变量吗？这也是一个好问题，答案是：*也许*。在许多问题中，可能存在许多预测变量，确定要包含哪些是建模过程的一部分——事实上是一个棘手的部分！因此，在本书第 1 部分先从*简单回归模型*开始是有意义的，这些模型只涉及一个预测变量，然后在第 3 部分再转向*多元回归模型*，这些模型涉及两个或多个预测变量。理解简单回归和多元回归将为第 4 部分的更高级材料铺平道路。

## 1.2 你需要回归模型吗？

回归模型对于阐明数据中的关系和回答某些问题至关重要。然而，它们绝不是适合每项工作的正确工具，因此了解回归模型可能有帮助的情况很重要。大致来说，有两种情况你应该使用回归：当你想总结一些总体趋势以更好地了解数据时，或当你必须依赖统计模型从有限的数据中获得洞察时——如果你需要同时做这两件事，你绝对需要回归！

当与所研究问题相关的数据非常丰富时，除回归之外的方法可能会表现更好，应该首先尝试。为了说明原因，让我们考虑几个大数据情况。首先，假设我们有一个漂亮、干净的数据集，包含成千上万行和只有几列。在拥有如此多数据的情况下，我们不需要弄清楚适当的统计模型并将其拟合到数据——我们可以直接使用汇总统计量，并仔细探索它们如何依赖于可用的预测变量。例如，我们可能有一个关于软件开发人员及其薪水的广泛数据库；我们可以按经验和行业对开发人员进行分类，然后计算每种组合的平均薪水，从而发现平均响应如何依赖于预测变量。我们不需要假设响应与预测变量之间关系的特定函数形式，也不会被限制为使用通常的平均值——研究中位数薪水如何依赖于经验和行业可能更有意义，而使用中位数与使用均值一样简单。如果你能获得大量数据，请先从这种简单的探索性方法开始，然后再做复杂的事情。

拥有大量数据是件好事，但可能拥有超出处理能力的数据量——这就是真正的 Big Data 问题发生的情况，当存在数百万行和数百或数千个可能的解释变量时。在这种情况下，回归可能帮助不大，因为数据太多，人类只能以一种杂乱无章的方式处理。这时像降维和深度学习这样的机器学习方法大放异彩，因为算法可以系统地从噪声中提取信号，并且模型可以访问它们所需的充足训练集。

大数据在当今获得了大量关注，有一些非常好的原因：技术问题有趣且具有挑战性，解决这些问题的人会得到世界上一些最有影响力的科技公司的高额报酬。然而，从事数据分析的大多数人并没有被无法被机器学习算法消化的海量数据淹没：社会科学家通常最多进行几千人的调查，新医疗程序的试验通常涉及数百或数千名患者，许多成功的企业



拥有数百或数千个，而不是数百万个客户。此外，由于其中许多数据是由人们整理的，有时是通过精心设计的实验，响应变量和感兴趣的预测变量都是 well understood。回归方法非常适合这些问题，我们将在后面的章节中看到如何将它们应用于真实数据。

在决定如何分析数据以回答给定问题时，可用数据的数量是一个重要因素。另一个因素是所能获得的见解的 *可解释性*；在某些情况下，根据上下文或法律要求，可解释性实际上可能是压倒性的考虑。在这方面，回归远优于大多数机器学习方法，其中许多是不透明的黑箱。我们将讨论的回归方法都会产生明确的模型，可以向具有不同技术背景的受众解释，这是一个令人信服的使用理由，即使晦涩难懂的算法提供了表面上更强的结果。随着我们考虑各种回归方法，我们因此同等关注构建模型和解释输出。

可解释性是回归的主要卖点，*不确定性量化* 也是如此，即能够用误差范围来增强预测的能力。传统上，这是通过验证某些分布假设并应用统计推断的机制来实现的。例如，使用上面提到的身高模型，我们会预测身高为 70.21 英寸的男性，其儿子的身高可能满足

65.196inches ≤ Predicted height of son ≤ 74.766inches,

一个以我们之前看到的 69.98 英寸的最佳猜测为中心的区间。现在，我们有其他选择，可以避免显式分布假设的需要；像 bootstrap 这样的重采样程序允许直接使用数据来估计标准误差和不确定性。我们将解释何时以及如何使用这两种方法来最大化预测模型的效用。

最后，回归模型的 *简洁性* 补充了其可解释性，也是使用它们的主要原因之一。一个简约的回归模型提供了变量之间关系的简洁总结；该模型可以是本身的目标，也可以是更详细

调查的起点。

## 1.4 Summary

- Regression is a family of methods for exploring relationships in data and for predicting future outcomes based on previous observations.
- Regression might not be the best method for Big Data problems, when there is an overwhelming abundance of data related to the questions being studied.
- Regression is well suited to small- or medium-sized datasets, when fitting a statistical model provides insights that are otherwise unavailable.
- Regression provides results that users can interpret and explain plainly, unlike many inscrutable machine learning algorithms.
- The theory and practice of regression are equally important and should be learned together.
