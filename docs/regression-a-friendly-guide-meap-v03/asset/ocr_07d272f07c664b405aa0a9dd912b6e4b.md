Grouping the data into covariate classes makes the definition of the log-likelihood a bit different than it was earlier, though. Using the binomial distribution defining $Y_i$, the likelihood function is now

$L(a, b) \sim = \sim \prod_i P(Y_i = y_i) \sim = \sim \prod_i \binom{n_i}{y_i} \hat{\pi}_i^{y_i} (1 - \hat{\pi}_i)^{n_i - y_i},$

and the log-likelihood function is

$\log L(a, b) \sim = \sim \sum_i \log\left(\binom{n_i}{y_i} \hat{\pi}_i^{y_i} (1 - \hat{\pi}_i)^{n_i - y_i}\right) \sim = \sim \sum_i \left\{\log\binom{n_i}{y_i} + y_i \log \hat{\pi}_i + (n_i - y_i)\log(1 - \hat{\pi}_i)\right\}.$

Note that this reduces to the previous definition of the log-likelihood when working with individual responses, as every $n_i = 1$ in that case.

Instead, we’re going to use the statsmodels GLM function; we’ll package the observations as a matrix—successes in the first column and failures in the second column—and use this matrix as the response variable.
