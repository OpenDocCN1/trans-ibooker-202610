This calculation shows that the probability $\Pi_X$ is the mean response to this given value of the predictor; from this perspective, logistic regression and linear regression are the same, as both models relate the average response to a linear function of the predictor. As you work it out, note that the variance will change for different values of the predictor unless $\beta = 0$, so we’re not assuming constant variance as we do with linear regression.

What we’ve done so far concerns the first assumption of the theoretical logistic model: for each given value $X$ of the predictor, the response $Y$ is a Bernoulli random variable whose probability of success, $\Pi_X$, depends on $X$ as given above. This model has just one other assumption: different observations of the response variable are *independent*. This is an essential part of the model, as it justifies defining and working with the likelihood function, $L(\alpha, \beta)$; recall from the violet example in the last chapter that $L(\alpha, \beta)$ is the collective probability, according to the model, of the observed responses.
