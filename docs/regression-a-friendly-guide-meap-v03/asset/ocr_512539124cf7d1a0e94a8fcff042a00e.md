To explain why the deviances are so much smaller when working with binomial data, we have to discuss the actual definition of the deviance; the simplistic version we presented in Chapter 4 is a special case, as we’ll show in a moment. Whether we work with individual or grouped responses, the deviance always compares a logistic model to a hypothetical model that fits the observations perfectly—this ideal model, which no one ever actually builds, is called the saturated model. To predict probabilities that are identically equal to the empirical percentages, the saturated model necessarily has as many parameters as observations, which is impractical but theoretically useful.
