## 欢迎

感谢您购买 *回归：友好的指南* 的 MEAP 版本！回归模型是分析数据中关系和预测结果的绝佳选择，尤其是在可解释性很重要时——因此，解释如何解释和应用这些模型是本书的基本目标。读完之后，你将知道所有的术语、符号和输出意味着什么，你将知道如何穿透围绕回归和其他数据科学工具的表面炒作，你将知道如何做出合理、可辩护的数据驱动决策。与其一头扎进理论，我将帮助你逐步建立直觉和知识，使用精心挑选的数据集来激发和阐明问题。

本书将教你如何构建、评估和解释回归模型，从第 1 部分的单预测变量简单模型到第 3 部分和第 4 部分的多个变量复杂模型。你将学习线性回归、逻辑回归、计数回归、稳健回归和惩罚以及广义加性模型。在此过程中，你还将在第 2 部分学习模拟方法和现代工具，如自助法和交叉验证。

阅读本书的理想准备是具备一些基础统计学的先前经验：汇总统计量（均值、中位数、标准差、四分位数）、常见分布（正态、t、二项）、基础概率、常见可视化（直方图、条形图）和显著性检验。如果这些并不都熟悉也没关系，但请准备好在它们出现时做一些额外的作业，并在有疑问时让我知道。你应该能够使用 R、Python 或 Julia 等数据友好型语言进行编程；根据我自己的经验和偏好，我在整本书中使用了 R 和 tidyverse 工具，但核心统计思想是语言无关的。

作为 MEAP 读者，你可以通过让我知道我在你已知的知识上假设过多或过少、我的解释可以如何改进，以及我是否过于啰嗦或过于简略，来帮助我接触到目标受众——你和其他人！带着这个想法，请不要犹豫在 [liveBook Discussion forum](liveBook Discussion forum) 分享你的评论、问题和建议！我希望这本书能成为你在掌握回归之旅中的宝贵资源，因此你的反馈将产生巨大影响。

多年来，我做了很多改造和翻新，从拆除和框架到布线、管道、精装木工和至今仍让我膝盖疼痛的瓷砖工作。新项目的一部分吸引力在于购买精美工具和学习酷炫技术的可能性，但事实是，大多数工作都可以用一些标准工具和一些基本技能完成。这里的魔力词是 *技能*：一位经验丰富的木工用几件手工工具就能把一堆弯曲的木材变成漂亮的橱柜并完美悬挂，而一个新手即使拥有满屋闪亮的新工具也做不到。

像一个渴望自己动手的人在大型家居建材商店的过道里徘徊一样，有志于数据科学的人也会面临各种选择和炒作。在这两种情况下，找到一些好的入门项目是摆脱干扰并学习该行业基本工具的关键。在数据科学中，没有什么工具比回归更基本，而本书就是在这里帮助你彻底学习回归。具体来说，本书将教你如何构建、评估和解释线性回归模型、逻辑回归模型以及计数回归模型。无论你是数据科学的新手还是希望为你的工具箱增添一些分析专长的资深开发者，这方面的知识都将非常有用；回归方法可能是你在工作中唯一需要的，或者你可以基于这里学到的知识在你进一步涉足机器学习时进行扩展。

为了探索这些建模范式及其应用，我们将使用 Python，这是一种流行的通用编程语言，拥有一些优秀的经过实战检验的数据处理库。特别是，我们将为每个示例开发不同的 Jupyter notebook，逐步展示代码及其输出；这些代码集成在正文中，是叙述的重要组成部分。为了充分利用本书，你应该在阅读过程中在自己的电脑上完成示例——回归与其他技能一样，只能通过实践来学习。虽然你不需要是 Python 专家才能开始，但你应该已安装 Python，应该知道如何按需导入模块，并且应该知道如何启动 Jupyter notebook。当然，如果你愿意，你也可以自由使用其他数据友好的编程语言；例如，R 也是回归分析和数据科学的另一个绝佳选择。事实上，所有示例的代码都将在 GitHub 上以 Python 和 R 两种形式提供（分别作为 Jupyter notebook 和 R 脚本）。

除了具备 Python 或 R 等语言的一些经验外，了解一些数学和统计知识也会使阅读本书变得更容易。回归模型是从数据构建的，因此熟悉汇总统计量（均值、标准差、方差）、一些常见分布（正态、二项）、检验统计量（z 分数、t 分数）和初等概率会有所帮助——如果你上过标准的统计入门课程，所有这些内容都会很熟悉。你应该能够处理方程和函数，应该知道如何构建和解释图表，并且应该能够不时进行一些代数运算。如果你以前做过这些事情但感觉有点生疏，不用担心——在我们继续的过程中，你会得到大量使用所需知识的练习。

### 1.1 什么是回归？

在简短的介绍之后，你可能会问回归到底是什么——好问题！回归实际上是一系列用于 *探索数据中的关系* 和 *基于先前观察预测未来结果* 的方法。为了使这个一般性描述具体化，请考虑在我们生活中可能出现的一些典型问题：

- 成人识字率对婴儿死亡率的影响是什么？
- 学院入学率如何依赖于出生趋势？
- 在特定年龄发展慢性病的几率是多少？
- 更大或更小的动物灭绝风险更高吗？
