
and

119.6022 − (2.014 * 12.138) ≤ α ≤ 119.6022 + (2.014 * 12.138) ≡ 95.15 ≤ α ≤ 144.05.

Rounding the numbers in these calculations can introduce some additional error; to get more accurate confidence intervals— and to avoid doing these calculations by hand— use the model’s conf_int method:

```
>>> africa_fit.conf_int()
```

|  | 0 | 1 |
|---|---|---|
| Intercept | 95.154717 | 144.049736 |
| Literacy | -1.135228 | -0.505592 |

These quantitative estimates for the model parameters are what we’ve been after, and the inequality for β provides the single most important qualitative insight: we are confident that the slope in the theoretical model for the UNICEF data is negative, so we’re confident that infant mortality rates for African countries really do decrease as literacy rates among young women increase. With other datasets, the confidence interval for β might contain 0, implying that, for all we know, the theoretical slope could be positive, negative, or 0— when that happens, we can’t be confident that the response variable really depends on the predictor variable at all!

## 3.2.3 Significance tests for the coefficients

Instead of computing a confidence interval for β to see if there is evidence of a linear relationship between the variables, we can directly test whether it’s plausible that β = 0. To that end, pretend that this is true, and compute the corresponding t-score for the sample statistic b:

t = (b − 0) / SE(b) = b / SE(b).

The further this t-score is from 0, the less likely it is that the theoretical slope could be zero— to make this precise, compute the probability of getting a t-score of this magnitude or greater and then draw an appropriate conclusion. Using the UNICEF example again, the t-score for checking whether the theoretical slope could be 0 is

t = -.8204 / .156 = -5.26,

and the probability of getting a t-score with |t| > 5.26 when there are 45 degrees of freedom is quite small:

```
>>> 2*st.t.cdf(-5.26, df=45)
```

```
3.852717659625731e-06
```

The t.cdf function returns the area under a t-distribution relative to a given t-score; in this case, we double the area to the left of t = -5.26 to get the percentage of t-scores with |t| > 5.26. This probability is the p-value for the null hypothesis that β = 0, which is usually stated in the form

H₀: β = 0.

The competing possibility is the alternative hypothesis,

Hₐ: β ≠ 0.

This is a 2-sided alternative, but the small 1-sided p-value for the UNICEF data (half of the very small 2-sided p-value) provides strong evidence that β < 0, not just that β ≠ 0. This whole business is called null hypothesis significance testing and is a standard part of regression analysis— just remember that p-values only help us gauge evidence; they do not make decisions for us! In particular, we have to remain aware of how sample sizes affect test statistics and p-values. Since the RSE approximates the constant σ, the formulas for SE(b) and SE(a) show that the standard errors will generally decrease as the sample size n increases, making the corresponding test statistics increase and the p-values decrease. It is quite possible that the significance of a regression coefficient is merely an artifact of working with a large sample, so always look at the data and combine common sense with these other tools!

As with the other formulas and procedures we’ve been explaining, you need not conduct hypothesis tests in this painstaking step-by-step fashion every time— all of this is provided in the summary of the regression model built by smf.ols, as shown above for the UNICEF data. The t column gives the t-scores for the hypothesis tests, and the P>|t| column gives the p-values; as

with the confidence intervals, the values in the table are more accurate than calculations done with rounded values. The summary table tells us, for instance, that the t-score for the null hypothesis that α = 0 is 9.853, with a p-value that is practically 0. It is therefore exceedingly unlikely that the theoretical intercept is 0; in fact, we’re confident that the theoretical intercept is positive. Most of the time, what happens with the intercept is far less important and interesting than what happens with the slope, but now you know what the middle rows in the model’s summary mean. We’ll explain some other important numbers, such as the F-statistic and the Adj. R-squared, when we get to multiple regression.

## 3.2.4 Predicting average and individual responses

As discussed in Section 2.4, two of the main applications of regression models are

- estimating the average response for a given value of the predictor, and
- predicting the individual response for a given value of the predictor.

We explained then that both applications begin with the same point estimate: if x is the given value of the predictor variable, which will remain fixed for the rest of this section, then ŷ = a + b x is our single best estimate of y, the individual response to x, and of E(Y|x), the average of all possible responses to x. In each case, we know that this estimate is probably wrong, so we’d like to know how far off we’re likely to be— we need the relevant sampling distributions and standard errors so that we can compute interval estimates. Since sampling distributions are theoretical devices describing all possible responses, we have to work with the relevant random variables as in the previous section. Assuming that ε ~ N(0, σ), we have

Y ~ N(α + β x, σ)   and   Ŷ ~ ~A + B x.

Since B and A are linear combinations of the normally distributed random variables {Y₁, ..., Yₙ}, so is Ŷ. As outlined in one of the exercises, we can use this to determine the sampling distribution of Ŷ :

$\hat{Y} \sim N\left(E(Y|x), \sigma\sqrt{\frac{1}{n} + \frac{(x - \bar{x})^2}{(n - 1)s_x^2}}\right).$

The average of all of the possible $\hat{y}$'s we could obtain is therefore the average response $E(Y|x)$, as expected. Once we have data, we approximate $\sigma$ with the RSE as usual and get the standard error we need,

$SE(\hat{y}) \approx RSE\sqrt{\frac{1}{n} + \frac{(x - \bar{x})^2}{(n - 1)s_x^2}}.$

Working with this SE requires working with the $t(n-2)$ distribution, since

$\frac{\hat{y} - E(Y|x)}{SE(\hat{y})} \sim t(n-2).$

After selecting a confidence level $C$ and computing the critical value $t^*$, we then obtain a confidence interval for the average response $E(Y|x)$ as before:

$\hat{y} - t^* SE(\hat{y}) \le E(Y|x) \le \hat{y} + t^* SE(\hat{y}).$

This interval estimate complements the point estimate $\hat{y}$ and tells us about the possible values of the average response to $x$. We have to consider this range of values carefully to predict the *individual* response to $x$: the theoretical model says that

$Y = E(Y|x) + \varepsilon$

and reveals two sources of uncertainty when making predictions— we don’t know $E(Y|x)$, and we don’t know how much $\varepsilon$ will contribute to the response. The uncertainty of an individual response is therefore a combination of the variability of both of these quantities, and we find that

$SD(Y) = \sqrt{\sigma^2 + (SD(\hat{Y}))^2} \implies SE(y) = RSE\sqrt{1 + \frac{1}{n} + \frac{(x - \bar{x})^2}{(n - 1)s_x^2}}.$

The resulting interval estimate for the individual response $y$ is

$\hat{y} - t^* SE(y) \le y \le \hat{y} + t^* SE(y),$

which is called a *prediction interval* to distinguish it from the confidence interval for $E(Y|x)$. An important thing to notice is that prediction intervals are *always* wider than confidence intervals, since they combine two sources of variability.

We’ve gone through some of the details behind these interval estimates so that you’ll understand what they mean and how to interpret them, but of course no one uses these formulas when working with real data— we use an implementation like the one provided by the model’s predict method. Returning to the UNICEF data example, suppose that we want to understand the likely infant mortality rates corresponding to literacy rates of 50% and 80%. We create a DataFrame with these new predictor values, then pass that dataset to the predict function:

```
>>> new = pd.DataFrame(data = {"Literacy":[50,80]})
>>> africa_fit.predict( new )

    0    78.581723
    1    53.969422
dtype: float64
```

These are point estimates— the $\hat{y}$ values corresponding to $x = 50$ and $x = 80$. To get interval estimates, use the get_prediction method and look at its summary_frame:

```
>>> africa_fit.get_prediction( new ).summary_frame()
```

|   | mean | mean_se | mean_ci_lower | mean_ci_upper | obs_ |

| 0 | 78.581723 | 5.027890 | 68.455032 | 88.708414 | 33.6 |
