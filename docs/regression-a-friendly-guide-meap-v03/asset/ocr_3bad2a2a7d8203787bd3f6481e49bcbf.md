To quantify how well the null model fits this data, let’s compare its constant prediction— namely, 58.1064 for each country— with the observed infant mortality rates. The difference between an observed value and a predicted value is called an error or a residual, and we’ll soon see that regression is all about analyzing residuals. Here are a few of them, along with the corresponding observed values and null prediction, for four randomly selected countries:

# Table 2.3. Null model predictions and residuals

| Row number | Country | Infant mortality rate | Null model prediction | Residual |
|---|---|---|---|---|
| i = 16 | Ethiopia | y₁₆ = 52 | ȳ = 58.1064 | y₁₆ − ȳ = −6.1064 |
| i = 0 | Algeria | y₀ = 26 | ȳ = 58.1064 | y₀ − ȳ = −32.1064 |
| i = 12 | Côte d’Ivoire | y₁₂ = 81 | ȳ = 58.1064 | y₁₂ − ȳ = 22.8936 |

It might seem useful to compute the average residual, but the sum of the residuals for the null model is zero— this follows from the very definition of ȳ. To eliminate all of this cancellation and obtain a better measure of the fit, we apply the standard statistical trick of squaring the deviations before adding; this yields the total sum of squares (TSS),

```
TSS = Σᵢ (yᵢ − ȳ)².
```
