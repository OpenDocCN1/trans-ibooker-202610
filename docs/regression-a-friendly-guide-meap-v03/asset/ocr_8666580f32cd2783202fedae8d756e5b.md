```
y - ŷ = y - a - b x,
```

where y is the observed value of IMR corresponding to the value x for the case at hand. As noted when we analyzed the fit of the null model, we can’t just average these residuals directly; cancellations between positive and negative residuals would give us a false sense of a small overall error. To remedy this, we employ the same trick as before and square the deviations before adding— this yields the sum of squared residuals (SSR),

```
SSR = Σ_{x, y} (y - ŷ)^2 = Σ_{x, y} (y - a - b x)^2,
```

where the sum includes all of the observed data points. The SSR is a fundamental overall measure of the model’s fit and is the quantity we’re going to minimize. It’s important to realize that there are only two unknowns here, a and b ; the x and y values are all known numbers. In the UNICEF data, for example, there are 47 (x, y) pairs to use when computing the SSR for given values of a and b. Moreover, the SSR is a quadratic function of these two unknowns, with positive coefficients on the squared terms. If you’ve worked with quadratic functions before, you know that this means that there is a unique combination of values of a and b for which the SSR achieves its minimal value. In fact, there are nice explicit formulas for these coefficients!
