
Since the regression line approximates the deterministic component of the theoretical model, its predicted value $\hat{Y}$ approximates the mean response $E(Y|x)$ to a given value $x$ of the predictor:

```
$\hat{y} = a + b\,x \approx E(Y|x) = \alpha + \beta\,x.$
```

Clearly, then, the closer the estimates $a$ and $b$ are to the parameters $\alpha$ and $\beta$, respectively, the better the model is— but the parameters are unknown, so how can we possibly know how good these estimates are? This is the basic problem of *inferential statistics*: having collected some data, what do the sample statistics— the coefficients of the regression line, in this case— tell us about the unknown parameters, and with how much accuracy?

## 3.2.1 Sampling distributions of regression coefficients

To answer these questions, we have two options. One is to apply the bootstrap, a versatile modern tool that we’ll explain and use in a later chapter. The traditional choice, which we develop in this section, is to make the additional assumption that the error term $\varepsilon$ in the theoretical model is normally distributed. Since we’re already assuming that $\varepsilon$ has mean 0 and constant variance $\sigma^2$, this implies that

```
$\varepsilon \sim N(0, \sigma^2).$
```

Combining this distributional assumption with the theoretical model means that the response variable is also normally distributed for each given value of the predictor. In particular, if we’re working with $n$ fixed values $\{x_1, ..., x_n\}$ of the predictor variable and $Y_i$ is the response to $x_i$, then $Y_i \sim N(\alpha + \beta x_i, \sigma^2)$. Our dataset contains $n$ *realizations* of these random variables— the observed responses $Y_1, ..., Y_n$— but we have to remember that the observed values include chance errors and could have come out differently.

Having a bunch of normally distributed random variables is always a good thing, since linear combinations of them are again normally distributed and normal distributions are well understood. We can take immediate advantage of this, since the least squares estimates $A$ and $B$ of the model parameters— the realizations of which, based on data, are the regression coefficients $a$ and $b$— are linear combinations of the responses $Y_1, ..., Y_n$. This fact is not at all obvious from the formulas presented earlier, so one of the exercises shows how to tinker with the derivation of those formulas to verify that

$$B \sim \sum_{i=1}^{n} c_i Y_i, \quad \text{where} \quad c_i = \frac{x_i - \bar{x}}{(n-1)s_x^2}.$$

There is a similar formula for $A$, since $A = \bar{Y} - b \bar{x}$. This is why we have to think of the $n$ values $\{x_1, ..., x_n\}$ as being fixed, so that the coefficients $c_i$ are constants, not random variables. The upshot is that the least squares estimates $A$ and $B$ are normally distributed:

$$B \sim N\left(\beta, \frac{\sigma^2}{(n-1)s_x^2}\right) \quad \text{and} \quad A \sim N\left(\alpha, \sigma^2\left(\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}\right)\right).$$

Computing these is another exercise at the end of the chapter— these are the kinds of calculations that either have to be taken on faith or worked out for oneself, and the latter option is far better! In either case, what we have here are formulas for the *sampling distributions* of the least squares estimates: if we were to observe all possible sets $\{y_1, ..., y_n\}$ for fixed values of the predictor, then each set would yield its own $b$ and $a$; the average of all of these estimates would be $\beta$ and $\alpha$, respectively, which is precisely what it means for these estimates to be *unbiased*. In other words, the random variables $A$ and $B$ are unbiased estimates of the model parameters because $E(A)=\alpha$ and $E(B)=\beta$. The standard deviations describe how the realizations of these estimates will vary from one set of observations to another; there is a 95% chance, for instance, that the observed regression coefficients $b$ and $a$ will satisfy

$$\beta - 2\left(\frac{\sigma}{s_x \sqrt{n-1}}\right) \le b \le \beta + 2\left(\frac{\sigma}{s_x \sqrt{n-1}}\right)$$

and

$$\alpha - 2\left(\sigma \sqrt{\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}}\right) \le a \le \alpha + 2\left(\sigma \sqrt{\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}}\right).$$

## 3.2.2 Standard errors and parameter estimates

Knowing the sampling distributions is great, but there are some serious practical problems: we only observe one set of responses to our predictor values, we don’t know the parameters β and α, and we don’t know σ! What do we do? We use our one set of observations to approximate σ, then we rework the preceding inequalities to get estimates for β and α. Specifically, the RSE is our best available estimate of σ, and replacing σ with the RSE in the formulas above gives us the standard errors for the regression coefficients:

```
SE(b) ≈ RSE / (s_x √(n-1))   and   SE(a) ≈ RSE √[1/n + x̄² / ((n - 1)s_x²)] .
```

By definition, a standard error is the best estimate, using the data we have, of the standard deviation of the sampling distribution of the relevant sample statistic. (Try saying that out loud over and over again!) The notations SE(b) and SE(a) reflect the fact that these approximations, like the RSE, are computed from the available data; they are not random variables. We could work with these formulas by hand, but there’s really no reason to— we can (and should!) get the standard errors from the regression output. For example, here’s a summary of the africa_fit regression model:

The std err column in the middle provides the standard errors for the regression coefficients, and the numbers shown are exactly what the formulas give, as you can check. To use these standard errors, we have to deal with one more thing: the price we pay for using the RSE as our estimate of σ is that the distribution we need to work with is no longer normal— we have to use the t-distribution with (n − 2) degrees of freedom instead. If we knew the value of β, for example, and had all possible sets of responses to our fixed values of the predictor, we could compute the quantity

t = (b − β) / SE(b)

for each set of responses; the resulting t-scores would follow the distribution t(n − 2).

We can finally proceed to estimating β and α, by manipulating and modifying the inequalities above. The multiplier 2 that appears in them comes from the standard normal distribution: 95% of z-scores are within 2 standard deviations of the mean. In fact, the multiplier is actually closer to 1.96, as we can check using the norm.ppf function from the scipy.stats library:

```
>>> import scipy.stats as st
>>> st.norm.ppf(.975 )

    1.959963984540054
```

norm.ppf takes a percentile, 97.5% here, and returns the z-score with that percentile rank; since we want the middle 95% of z-scores, we add on the 2.5% in the left tail to get the correct percentile. We now have to replace this multiplier with the analogous quantity for the t-distribution t(n − 2)— we have to determine the middle 95% of t-scores when there are (n − 2) degrees of freedom, which we can do with the t.ppf function. For the UNICEF data,

for example, n = 47, so there are 45 degrees of freedom and the appropriate multiplier is about 2.014:

```
>>> st.t.ppf(.975, df=45)

    2.0141033848332923
```

There’s nothing special about 95% here; if we wanted the middle 99% of these t-scores, we would just compute

```
>>> st.t.ppf(.995, df=45)

    2.6895850193746385
```

and go from there. The percentage used is the confidence level, denoted C, and the corresponding multiplier is denoted t* — we’ve just found that, with 45 degrees of freedom,

C = 95% ⟹ t* = 2.014   and   C = 99% ⟹ t* = 2.6896.

Once we’ve chosen C and determined t*, we know, for example, that C percent of the least squares estimates of β will satisfy

β − t* SE(b) ≲ b ≲ β + t* SE(b),

with a similar result for estimates of α. Recalling the practical issues that got us here, we only have one dataset and one pair of regression coefficients, so we rearrange this inequality to estimate β :

b − t* SE(b) ≲ β ≲ b + t* SE(b).

We do not know that the parameter β satisfies this inequality. All we actually know is that, if we took lots of samples and computed the corresponding estimate b for each one, β would satisfy this inequality C percent of the time. To acknowledge all of this, we refer to this interval estimate of β as a confidence interval with confidence level C. Using the information in the summary of the regression model for the UNICEF IMR data, for example, we are 95% confident that its model parameters satisfy

−.8204 − (2.014 * .156) ≤ β ≤ −.8204 + (2.014 * .156)  ⟺  −1.135 ≤ β ≤ −.506
