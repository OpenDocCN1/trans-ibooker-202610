Observe that maximizing the log-likelihood is equivalent to minimizing the residual deviance— the residual deviance is analogous to the residual sum of squares in linear regression, a parallel that we’ll exploit below. (In fact, linear regression models can be based on maximum likelihood estimation if normality is assumed; in that approach, the resulting residual deviance is precisely the same as the residual sum of squares on which the least squares method relies.)

The difference between the deviances, denoted G², is the standard measure of whether adding a predictor improves a logistic model; for this example, G² = 217.6−80.37 = 137.2, which certainly seems like a big reduction. Before going into how to assess this number, we need to do some calculations and define one more term. Using the properties of logarithms and the definitions of the deviances, we can rewrite G² as follows:

G² = -2*log(null likelihood) - (-2*log(likelihood of logistic model)) = -2*log( null likelihood / likelihood of logistic model ).

The final formula for G² explains its name: G² is the likelihood ratio statistic. We can compute it straight from this definition,
