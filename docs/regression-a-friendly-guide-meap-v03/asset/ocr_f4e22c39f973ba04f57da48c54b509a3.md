We confronted the same issue in Chapter 3 with predictions based on simple linear regression models, and the next step is the same here: we need to augment these point estimates with interval estimates. Doing this is more involved than it was in Chapter 3, however, for two reasons. First, the connection between predicted probabilities and the linear combination $a + b x$ is nonlinear. Second, there are three sources of uncertainty to manage:

+   - there is some error in our estimate $a$ of $\alpha$,
+   - there is some error in our estimate $b$ of $\beta$, and
+   - the errors in these estimates can interact.

After dealing with these errors, we’ll see how to compute interval estimates for $\alpha + \beta x$, then we’ll convert those into interval estimates for $\Pi_X$ using the logistic function. To prepare for those calculations, we need to record the values of $a + b x$ for these three photoperiod lengths, using the numpy dot function to compute them directly from the model coefficients. This dot product multiplies each 1 in the design matrix’s Bias column by the intercept, multiplies each predictor value by the Photoperiod coefficient, then adds up the results for each predictor value:

```
links = pd.DataFrame({"Photoperiod":[13,13.5,14],
"Link":np.dot( chasm_fit.params, X.T)})
links
```
