Stay with me here… there’s just one more step to go. To convert these intervals into probability estimates, we need to transform them with the logistic function. A simple way to apply this function is to import it from the scipy.special module—you just have to know that it’s called expit. Here are the results:

```
predictions["Lower"] = expit( links["Lower"] )
```
