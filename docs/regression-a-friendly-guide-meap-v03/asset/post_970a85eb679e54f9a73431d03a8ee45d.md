
So what should we do? For years, the advice would have been to conduct the Hosmer-Lemeshow Test, which boils down to grouping the data in a certain way and then comparing the observed and expected counts. The ad hoc nature of the Hosmer-Lemeshow Test is problematic, however—a common issue when categorizing a quantitative variable!—and people have learned over time that different groupings can lead to radically different conclusions. As a consequence, many of us now think that the Hosmer-Lemeshow test is obsolete. The modern replacements of the Hosmer-Lemeshow Test have various technical complications, much like the calculation of exotic residuals, so we’ll only discuss one of them, a technique that seems to be gaining consensus as the preferred option.

What we’ll do is analyze the residuals, stored in throat_fit.resid_response. Specifically, to measure the model’s overall goodness of fit, we’ll compute the unweighted sum of squares

S~ = ~∑ᵢ (y − π̂ᵢ)².

In case you’re wondering, yes, S is indeed exactly the same as the residual sum of squares used to analyze linear regression models, but we’ll use it differently now. Here’s the value of this statistic for this fitted model:

```
np.sum( throat_fit.resid_response**2 )
```

```
5.659420755790276
```

This is straightforward enough, but getting the p-value is where things get tricky. For large samples—a condition that’s hard to state precisely—this sample statistic S happens to be approximately normally distributed, so we can standardize it to get a Z-score. Instead of attempting to explain all of the related details, we provide the relevant calculations in an Appendix and refer to the fundamental paper by Hosmer et al. [16] for more information. The punchline is that the $Z_p$-score is about 0.19, a small $Z$-score with a correspondingly large $p$-value of about 85%. Failing to reject the null hypothesis here means that, according to this goodness of fit metric—and assuming that the large sample condition is at least roughly satisfied—this model fits the data well.

Note that we’ve only analyzed the dependence of SoreThroat on Duration; we would still like to know how the response variable depends on the other available predictors! It would not be surprising, for example, to learn that the chance of having a sore throat also depends on the type of device used to keep a patient’s airway open during surgery. One way to investigate this possibility would be to divide the data into two groups, one for the laryngeal mask airway and one for the tracheal tube, and then construct separate logistic models for each group. That’s certainly doable—try it for practice!—but the resulting groups would be even smaller than the throat dataset, so assessing the models' fits would be even more difficult. It would be better to build a model that includes both Duration and Device as predictor variables. To do that, we’ll need to talk about working with categorical predictors and multiple logistic regression, two topics treated in upcoming chapters.

## 5.5 Summary

- Bernoulli random variables model binary responses. These are special cases of binomial random variables, which count the successes in binomial experiments and model grouped covariate classes.
- Use the standard errors for the fitted model coefficients to compute confidence intervals for the model parameters.
- Use the variance-covariance matrix to compute interval estimates for predicted responses on the link scale, then use the logistic function to convert those into interval estimates for the predicted probabilities.
- For better goodness of fit tests and model assessment, group the responses when possible and analyze the residuals for the fitted binomial logistic model. For fixed groups and large covariate classes, the deviance and Pearson’s $X^2$ statistic follow $\chi^2$ distributions.
