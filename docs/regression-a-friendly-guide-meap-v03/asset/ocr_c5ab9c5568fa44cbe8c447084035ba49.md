# 5.1 Bernoulli models for binary data

Since we don’t know what will happen with a binary response variable until we observe a specific outcome, the best we can hope for is to know the exact chance of each possibility. Mathematically, this defines a *Bernoulli random variable*, a random variable $Y$ satisfying

$P(Y = 1) = \Pi$ and $P(Y = 0) = 1 - \Pi$

for some known probability $\Pi$, where $P(\cdot)$ stands for the probability of the event in parentheses. If $Y$ corresponds to the result of flipping a fair coin, for example, with $Y = 1$ (a success) when it lands on heads and $Y = 0$ (a failure) when it lands on tails, then $\Pi = \frac{1}{2}$. When rolling a fair 6-sided die, we might define $Y = 1$ when rolling a 1 and $Y = 0$ otherwise, making $\Pi = \frac{1}{6}$.
