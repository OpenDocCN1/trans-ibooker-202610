## Welcome

Thank you for purchasing the MEAP edition of *Regression: A friendly guide*! Regression models are great options for analyzing relationships in data and for predicting outcomes, especially when interpretability is important -- explaining how to interpret and apply these models is therefore a basic goal of the book. After working through it, you’ll know what all of the lingo, notation, and output mean, you’ll know how to cut through the superficial hype surrounding regression and other data science tools, and you’ll know how to make sound, defensible data-driven decisions. Instead of just diving head-first into the theory, I’ll help you build up your intuition and knowledge incrementally, using carefully chosen datasets to motivate and illuminate things.

This book will teach you how to build, assess, and interpret regression models, from simple models with one predictor in Part 1 to complex models with many variables in Parts 3 and 4. You’ll learn to work with linear regression, logistic regression, regression for counts, robust regression and penalization, and generalized additive models. Along the way, you’ll also learn about simulation methods and modern tools like the bootstrap and cross-validation in Part 2.

The ideal preparation for this book is some previous experience with basic statistics: summary statistics (mean, median, standard deviation, quartiles), common distributions (normal, t, binomial), basic probability, common visualizations (histograms, bar charts), and significance tests. Don’t worry if these aren’t all familiar, but be prepared to do a little extra homework when they come up and let me know when you have questions. You should be comfortable programming in a data-friendly language like R, Python, or Julia; based on my own experience and preferences, I use R and tools from the tidyverse throughout the book, but the core statistical ideas are language agnostic..

As a MEAP reader, you can help me reach my intended audience -- you and others! -- by letting me know where I assume too much or too little about what you know, where my explanations could be improved, and where I’m being too long-winded or too terse. With that in mind, please don’t hesitate to share your comments, questions, and suggestions in the [liveBook Discussion forum](liveBook Discussion forum)! I want this book to be a valuable resource on your journey to mastering regression, so your feedback will make a huge difference.

— Matthew Rudd

## 1 Regression in the age of Big Data

### This chapter covers

- What regression is
- When you need regression (and when you don’t!)
- How to benefit from using regression
- Why the underlying theory is important

I’ve done a lot of remodeling and renovation over the years, from demolition and framing to wiring, plumbing, finish carpentry, and tile jobs that still make my knees hurt. Part of the allure of a new project is the possibility of buying a fancy tool and learning a cool technique, but the truth is that most jobs can be done with some standard tools and a few basic skills. The magic word here is *skill*: an experienced woodworker with a few hand tools can turn a pile of crooked lumber into a beautiful cabinet and hang it perfectly, something a novice with a shop full of shiny new tools could never do.

Like an eager do-it-yourselfer wandering the aisles of a big home improvement store, an aspiring data scientist faces a barrage of options and hype. In both cases, finding some good starter projects is the key to getting past the distractions and learning the fundamental tools of the trade. In data science, no tool is more fundamental than regression, and this book is here to help you learn regression thoroughly. Specifically, this book will teach you how to construct, assess, and interpret linear regression models, logistic regression models, and regression models for counts. Whether you are a newcomer to data science or a seasoned developer looking to add some analytics expertise to your arsenal, this knowledge will be enormously useful; regression methods may be all you ever need to use in your work, or you can build on what you learn here as you venture further into machine learning.

To explore these modeling paradigms and their applications, we’ll use Python, a popular general-purpose programming language with some excellent battle-tested libraries for working with data. In particular, we’ll develop a different Jupyter notebook for each example, showing the code and its output incrementally as we go; this code is integrated into the text and is an essential part of the narrative. To get the most out of the book, you should work through the examples on your own computer as you go— regression, like any other skill, can only be learned by doing and practicing. While you don’t need to be a Python expert to get started, you should have Python installed, you should know how to import modules as needed, and you should know how to launch a Jupyter notebook. Of course, you’re also free to use a different data-friendly programming language if you prefer; R, for example, is another fantastic choice for regression analysis and data science. In fact, code for all of the examples will be available on GitHub in both Python and R (as Jupyter notebooks and R scripts, respectively).

In addition to having some experience with a language like Python or R, knowing some mathematics and statistics will make working through the book easier. Regression models are built from data, so it will help to be familiar with summary statistics (mean, standard deviation, variance), some common distributions (normal, binomial), test statistics (z-scores, t-scores), and elementary probability— if you’ve taken a standard introductory course in statistics, all of this stuff will be familiar. You should be comfortable working with equations and functions, you should know how to construct and interpret graphs, and you should be able to do some algebraic manipulations from time to time. If you’ve done these things before but are feeling a little rusty, don’t worry— you’ll get plenty of practice using what you need as we go.

### 1.1 What is regression?

After this brief introduction, you may well be asking what regression actually is— good question! Regression is really a family of methods for *exploring relationships in data* and for *predicting future outcomes based on previous observations*. To make this general description concrete, consider some typical questions that might come up as we navigate our lives:

- What is the impact of adult literacy on infant mortality?
- How do college enrollments depend on birth trends?
- What is the chance of developing a chronic condition at a certain age?
- Are larger or smaller animals at higher risk of extinction?
