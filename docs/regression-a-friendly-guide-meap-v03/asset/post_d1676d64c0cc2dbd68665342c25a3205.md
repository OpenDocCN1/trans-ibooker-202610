Observe that maximizing the log-likelihood is equivalent to minimizing the residual deviance— the residual deviance is analogous to the residual sum of squares in linear regression, a parallel that we’ll exploit below. (In fact, linear regression models can be based on maximum likelihood estimation if normality is assumed; in that approach, the resulting residual deviance is precisely the same as the residual sum of squares on which the least squares method relies.)

The difference between the deviances, denoted G², is the standard measure of whether adding a predictor improves a logistic model; for this example, G² = 217.6−80.37 = 137.2, which certainly seems like a big reduction. Before going into how to assess this number, we need to do some calculations and define one more term. Using the properties of logarithms and the definitions of the deviances, we can rewrite G² as follows:

G² = -2*log(null likelihood) - (-2*log(likelihood of logistic model)) = -2*log( null likelihood / likelihood of logistic model ).

The final formula for G² explains its name: G² is the likelihood ratio statistic. We can compute it straight from this definition,

```
G2 = -2*np.log( null_likelihood / max_likelihood)

Once we have the likelihood ratio statistic, what do we do with it?
Unfortunately, it has no straightforward interpretation— it is not a percentage reduction in variability, like the coefficient of determination $R^2$, nor does it estimate a standard deviation, like the RSE. All we can really do is gauge its magnitude, using the fact that the likelihood ratio is a $\chi^2$ statistic with 1 degree of freedom. A proof [13] of this result is beyond the scope of this book, but we’ll use bootstrap methods in Chapter 5 to illustrate its validity.
Accepting it for now, we can use the scipy.stats chi2 function with df=1 to conduct the likelihood ratio test and determine whether $G^2$ is large or small:

```
1 - chi2.cdf(G2, df=1)
```

0.0

This is a $p$-value, and we’ll discuss the relevant hypothesis test in the next section. We can interpret it now, though: this very small $p$-value implies that the logistic model that includes Photoperiod is significantly better than the null model that excludes it. If the $p$-value for the likelihood ratio test had been large— typically, but not necessarily, larger than 5%— then we would have concluded that adding the predictor had not improved the model. The likelihood ratio test is a basic part of logistic regression analysis, and we’ll have much more to say about it when we consider and compare models with multiple predictors.

## Analogues of the coefficient of determination

Since the deviances and likelihood ratio defy easy interpretation, it would be nice to complement them with a diagnostic analogous to linear regression’s coefficient of determination, $R^2$. Several candidates have been proposed over the years, accompanied by various arguments for and against using them;

there is still no consensus on the single best substitute for $R^2$ for logistic regression models. With that caveat in mind, we’ll discuss three options: a promising recent proposal and two established ones based on the formula for $R^2$ that we studied in Section 2.3 of the last chapter. Take a moment to revisit that derivation, then come back here to see how we can modify it— I’ll be here when you get back!

As you just reviewed, the coefficient of determination for a linear regression model is defined to be

$R^2 = \frac{\text{TSS} - \text{RSS}}{\text{TSS}} = 1 - \frac{\text{RSS}}{\text{TSS}},$

where TSS is the total sum of squared deviations for the null model and RSS is the sum of the squared residuals. A common way to interpret these ingredients in the context of a logistic model is the following: in the expression on the far right for $R^2$, replace the TSS with the null deviance and replace the RSS with the residual deviance. This calculation leverages the analogy between the deviances and the sums of squares mentioned above; the result is known as McFadden’s pseudo-$R^2$, which we’ll denote by $R_M^2$:

$R_M^2 = 1 - \frac{\text{residual deviance}}{\text{null deviance}}.$

Be aware that there is no standard notation for this statistic, so be careful when you read other sources. This descriptive statistic measures the proportional reduction of the deviance and has two necessary properties:

- $R_M^2$ is 0 for a completely uninformative model, i.e., a model that is no better than the null model, and
- $R_M^2$ is 1 for a perfect model, i.e., a model for which $\hat{\pi}_i = y_i$ for every $i$. Note that, with only two parameters, a simple logistic model cannot be perfect.

While $R_M^2$ has 1 as its theoretical upper bound, a conventional rule of thumb is that logistic models with $R_M^2$ values between 0.2 and 0.4 have significantly better explanatory power than their null model counterparts. For the violet

data, we do even better:

```
R2_M = 1 - (chasm_fit.deviance / chasm_fit.null_deviance)
R2_M

0.6305945851796487

This shows that including Photoperiod as a predictor yields a significant relative reduction in the deviance!

Instead of replacing TSS and RSS with deviances in the definition of R², we can just use the native sums of squares for our logistic model. To do so, we have to pick one of the formulas for R²; the different expressions for R² are all the same in linear regression, but they are not the same when translated into the present context. In our original derivation of R², recall that we started with the sum of the squared deviations between the competing model predictions, which happens to equal TSS – RSS by the magic of ordinary least squares. Replacing this difference with the comparison of model predictions and then dividing by the sum of squared deviations for the null model is our second version of the coefficient of determination. Specifically, define R²_S by

R²_S = Σ( π̂_i − π̂ )² / Σ( y_i − π̂ )² .

Like McFadden’s pseudo-R², R²_S is bounded between 0 and 1; it equals 0 for an uninformative model and equals 1 for a perfect model. If we try replacing TSS – RSS with the other natural choice, Σ(y_i − π̂)² − Σ(y_i − π̂_i)², we get an alternative statistic that is typically close to R²_S; if evaluated for artificially degenerate data, this alternative statistic can be negative, providing a reason to prefer R²_S.
