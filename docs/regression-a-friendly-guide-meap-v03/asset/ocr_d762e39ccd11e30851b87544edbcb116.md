Theoretically—before being observed, in other words—the number of successes in the $i^{th}$ covariate class is the binomial random variable $Y_i \sim B\left(n_i, \Pi_i\right)$, where the theoretical probability of success, $\Pi_i$, depends on the predictor $X_i$:

$\log\left(\frac{\Pi_i}{1 - \Pi_i}\right) = \alpha + \beta x_i,$

for parameters $\alpha$ and $\beta$ that have to be estimated by fitting this model to the available data. The observed value $y_i$ is a realization of $Y$, and the computed Percentage is an empirical estimate of $\Pi_i$. As we’ve seen before, the fitted logistic model will be of the form

$\log\left(\frac{\hat{\Pi}_i}{1 - \hat{\Pi}_i}\right) = a + b x_i,$
