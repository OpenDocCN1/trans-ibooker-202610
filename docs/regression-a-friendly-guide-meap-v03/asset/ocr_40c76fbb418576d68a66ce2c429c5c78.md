According to this model, 39.36 years is the age at which having a chronic condition changes from being less likely to more likely— our eyeballed estimate of 40 as the transition age wasn’t far off! # The logistic function

If you haven’t worked with the logistic function before, a natural question after seeing this NAMCS example is: who thought of it in the first place? We all learn about the equations of straight lines in school, so linear regression doesn’t seem so strange the first time you see it. This crazy fraction involving the exponential function, on the other hand, is not something one would spontaneously think to use. And it’s not as if someone made it up randomly either— the logistic function arises as the solution of a differential equation introduced in 1844 by the Belgian mathematician Pierre Verhulst to model population growth. He’s the one who named it the logistic function, for reasons known only to him.
