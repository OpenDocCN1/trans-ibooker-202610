When deciding how to analyze data to answer a given question, the amount of data available is an important factor. Another is the *interpretability* of the insights that can be obtained; in certain circumstances, depending on context or legal requirements, interpretability can actually be the overriding consideration. In this regard, regression is far superior to most machine learning methods, many of which are opaque black boxes. The regression methods that we will discuss all produce explicit models that can be explained to audiences with varying technical backgrounds, a compelling reason to use them even when an inscrutable algorithm provides ostensibly stronger results. As we consider various regression methods, we therefore pay equal attention to building models and to interpreting the output.

Interpretability is a major selling point of regression, as is *uncertainty quantification*, the ability to augment predictions with margins of error. Traditionally, this has been done by validating certain distributional assumptions and applying the machinery of statistical inference. Using the heights model mentioned above, for example, we would predict a man of height 70.21 inches to have a son whose height likely satisfies

65.196inches ≤ Predicted height of son ≤ 74.766inches,

an interval centered on the single best guess of 69.98 inches that we saw earlier. Nowadays, we have other options that obviate the need for explicit distributional assumptions; resampling procedures like the bootstrap allow working directly with data to estimate standard errors and uncertainty. We will explain when and how to use both of these approaches to maximize the utility of our predictive models.

Finally, the *simplicity* of regression models complements their interpretability and is another major reason for using them. A parsimonious regression model provides a concise summary of relationships among variables; the model can either be an end goal in itself or be the starting point for a more detailed

investigation.

## 1.3 Is all that theory really necessary?

Absolutely![1] Think of it this way: you could easily go out and buy a chainsaw, gas it up, pull the handle, and start cutting trees with abandon, but there’s a good chance you’ll maim yourself if you don’t read the manual and get some experienced guidance from someone you trust. Similarly, anyone can start building regression models with Python or R in just a few minutes, but it takes much longer to learn to interpret and assess the results correctly. There’s obviously a much lower risk of personal injury if you misuse regression, but there can be significant consequences— bad business decisions or misguided policy choices, for example— if you don’t know what you’re doing. After hearing various people talk about regression over the years and reading lots of papers and blog posts about regression, there is clearly a need to educate people better on the subject and to disabuse them of some bad habits and misconceptions. Someone should really write a book to do just that!

This last comment is crucial. The practical and theoretical aspects of regression go hand in hand, so it’s best to use each to inform and illuminate the other.

## 1.4 Summary

- Regression is a family of methods for exploring relationships in data and for predicting future outcomes based on previous observations.
- Regression might not be the best method for Big Data problems, when there is an overwhelming abundance of data related to the questions being studied.
- Regression is well suited to small- or medium-sized datasets, when fitting a statistical model provides insights that are otherwise unavailable.
- Regression provides results that users can interpret and explain plainly, unlike many inscrutable machine learning algorithms.
- The theory and practice of regression are equally important and should be learned together.

Regression analysis began in the last half of the 19th century, when Victorians became obsessed with quantifying things and applying the scientific method to everything in sight; since people were easy to find and measure, much of the data that drove the development of regression consisted of body measurements. Heights of parents and their children played an especially prominent role in early regression analyses, so it seems fitting to use one such dataset for our first example in Section 1. (Pun intended! With that in mind, the main goal of this chapter is to explain how to construct and use simple linear regression models to understand relationships between quantitative variables.
