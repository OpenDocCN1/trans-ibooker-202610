The theoretical values that we are estimating are *parameters*, so simple linear regression requires estimating two *model parameters*.
```
$\sigma^2 \approx \frac{SSR}{n-2} \approx (RSE)^2.$
```

This is precisely how we used the RSE earlier, as a measure of the variability of the responses relative to the regression line. Chebyshev’s inequality is handy here, as it quantifies the role of the RSE in assessing predictive accuracy, without requiring $\varepsilon$ to have any particular distribution.

# Chebyshev’s inequality

This is a basic result about random variables— unpredictable quantities that are usually assumed to have certain statistical properties. This particular inequality makes no distributional assumptions, requiring only that the random variable in question have a finite average and a finite standard deviation. If $Y$ is such a random variable, then *Chebyshev’s inequality* guarantees that the probability that $Y$ is within $k$ standard deviations of its average is at least $1 - \frac{1}{k^2}$:

```
$P(|Y - \mu| \le k\,\sigma) \ge 1 - \frac{1}{k^2}, $
```

where $\mu$ and $\sigma$ are the average and standard deviation, respectively, of $Y$, and $P(\cdot)$ denotes the probability of the result in parentheses.
