To quantify how well the null model fits this data, let’s compare its constant prediction— namely, 58.1064 for each country— with the observed infant mortality rates. The difference between an observed value and a predicted value is called an error or a residual, and we’ll soon see that regression is all about analyzing residuals. Here are a few of them, along with the corresponding observed values and null prediction, for four randomly selected countries:

It might seem useful to compute the average residual, but the sum of the residuals for the null model is zero— this follows from the very definition of ȳ. To eliminate all of this cancellation and obtain a better measure of the fit, we apply the standard statistical trick of squaring the deviations before adding; this yields the total sum of squares (TSS),

```
TSS = Σᵢ (yᵢ − ȳ)².
```

For the infant mortality rates, the TSS is

```
>>> africa_tss = ((africa.IMR - y_bar)**2).sum()
>>> africa_tss

    34308.46808510638
```

The average of these squared residuals is the *variance* of the observed responses, denoted Var(y):

Var(y) ≈ ~ 1/(n−1) Σ_i (y_i − ȳ)^2

where n is the number of observations. At first sight, it might seem strange to compute the average squared deviation by dividing by n − 1 instead of n, so let’s make sense of this before moving on. With n observations, there are n deviations from their average value ȳ; since the sum of these deviations is zero, only n − 1 of the deviations actually need to be computed— the remaining one is just the amount needed to make the sum zero. It’s like figuring out the batting order for a softball team with 12 players: once you’ve written down the first 11 names, you’ve also figured out who bats last. We say that there are n − 1 degrees of freedom among the deviations, and we divide by the number of degrees of freedom to compute the appropriate average. We’ll learn to work with degrees of freedom in several other contexts as we go.

To compute the variance of the infant mortality rates, use the pandas var function:

```
>>> africa.IMR.var()

    745.836262719704

>>> (n_countries - 1)*africa.IMR.var()

    34308.46808510638
```

The second calculation just illustrates the formula above: the variance of the infant mortality rates times n − 1 = 46 is the TSS that we just computed.

The variance is a common and useful measure of variability, but it doesn’t

have the same units as the original observations, complicating its interpretation. Taking the square root of the variance fixes this problem easily and defines the *standard deviation*, $s_y$, of the response variable:

```
$s_y = \sqrt{\frac{1}{n-1}\sum_{i}(y_i - \bar{y})^2}$.
```

The standard deviation $s_x$ of the predictor variable, which is unrelated to the null model but will be needed in the next section, is calculated similarly:

```
$s_x = \sqrt{\frac{1}{n-1}\sum_{i}(x_i - \bar{x})^2}$.
```

To compute these standard deviations, just use the pandas std function [4]:

```
>>> s_x = africa.Literacy.std()
>>> s_x

    20.512941245879194

>>> s_y = africa.IMR.std()
>>> s_y

    27.31000297912294
```

You can check for yourself that these agree with the square roots of the variances of these variables. As mentioned earlier when we introduced the heights dataset, the standard deviation is a measure of the *average deviation from the average*. If we randomly select one of these African countries, for example, its infant mortality rate will likely be within one standard deviation of the average, i.e., between

```
$\bar{y} - s_y = 58.1064 - 27.31 = 30.7964$  and  $\bar{y} + s_y = 58.1064 + 27.31 = 85.4164$.
```

Without knowing more about the specific distribution of infant mortality rates (e.g., normal or otherwise), we don’t know the precise probability that a randomly chosen country’s infant mortality rate will lie in this range. On the other hand, an interesting result known as *Chebyshev’s inequality*, stated precisely in the next chapter, guarantees that there is at least a 75% chance that it will be within two standard deviations of the average, between

ȳ − 2*s_y = 58.1064 − (2*27.31) = 3.4864   and   ȳ + 2*s_y = 58.1064 + (2*27.31) = 112.7264.

This range is admittedly less useful than the previous interval, but these inequalities show how the standard deviation of the response variable quantifies the null model’s predictive error. We should expect to do better by incorporating information about the predictor, so let’s see what happens when we do.

If we computed the residuals for all of the countries using this equation, we would get a pretty even mix of positive and negative residuals— this model overestimates the infant mortality rates for some countries and underestimates them for others. To have a model that predicts infant mortality rates as accurately as possible, we need these residuals to be as small as possible, and we should proceed systematically rather than by trial and error. Mathematics to the rescue! After setting up some more notation that we’ll use from now on, we’ll apply the famous method of least squares to solve this optimization problem and obtain a better predictive model.

To find the line that minimizes the residuals, we have to find the optimal intercept and slope— we need to use the available data to compute two numbers. Letting a and b denote, respectively, the intercept and the slope to be determined, we’re going to use the equation

```
ŷ = a + b x
```

to work abstractly with predictions and analyze residuals. x denotes an observed value of Births, as before, and ŷ ("y hat") denotes the corresponding predicted value of IMR; statisticians use this odd hat notation to

indicate quantities that are computed from observations. The residual for this prediction is

```
y - ŷ = y - a - b x,
```

where y is the observed value of IMR corresponding to the value x for the case at hand. As noted when we analyzed the fit of the null model, we can’t just average these residuals directly; cancellations between positive and negative residuals would give us a false sense of a small overall error. To remedy this, we employ the same trick as before and square the deviations before adding— this yields the sum of squared residuals (SSR),

```
SSR = Σ_{x, y} (y - ŷ)^2 = Σ_{x, y} (y - a - b x)^2,
```

where the sum includes all of the observed data points. The SSR is a fundamental overall measure of the model’s fit and is the quantity we’re going to minimize. It’s important to realize that there are only two unknowns here, a and b ; the x and y values are all known numbers. In the UNICEF data, for example, there are 47 (x, y) pairs to use when computing the SSR for given values of a and b. Moreover, the SSR is a quadratic function of these two unknowns, with positive coefficients on the squared terms. If you’ve worked with quadratic functions before, you know that this means that there is a unique combination of values of a and b for which the SSR achieves its minimal value. In fact, there are nice explicit formulas for these coefficients!
