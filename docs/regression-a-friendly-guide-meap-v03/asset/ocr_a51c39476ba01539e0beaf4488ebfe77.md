As for the corresponding $Z$-scores, these $p$-values are practically 0: we have evidence that Bud depends on Photoperiod.

# Predicting theoretical probabilities

Once we’re satisfied that we have an appropriate model that fits the data and captures a genuine relationship between the variables, we often want to use the model to make predictions. With a logistic model, that means getting a

good estimate of the theoretical probability $\Pi_X$ corresponding to a given predictor value $X$; based on the data used to build the model, our best point estimate of $\Pi_X$ is just $\hat{\Pi}_X = \sigma(a + b X)$, which the fitted model’s predict method readily provides. For example, here are estimates of the probabilities of violet bud formation for photoperiods of 13, 13.5, and 14 hours:

```
X = pd.DataFrame({"Bias":[1,1,1],
"Photoperiod":[13,13.5,14]})
predictions = pd.DataFrame({"Photoperiod":[13,13.5,14],
"Probability":chasm_fit.predict( X )})
predictions
```

Photoperiod  Probability
0  13.0        0.940411
1  13.5        0.499087
2  14.0        0.059181

We’ve organized the predictor values into the DataFrame X (often called the design matrix) along with a column of ones named Bias (a convention in the machine learning community), and we’ve organized the predictions into their own DataFrame. As we see in its Probability column, it’s very likely that a bud will form when the photoperiod lasts 13 hours, it’s very unlikely that a bud will form when the photoperiod lasts 14 hours, and there’s a 50-50 chance that a bud will form when the photoperiod is 13.5 hours.
