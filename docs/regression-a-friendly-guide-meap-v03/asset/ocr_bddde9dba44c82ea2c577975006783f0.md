If we only look at the correlation and the coefficient of determination, the regression model looks good; the coefficient of determination tells us that including Ratio as a predictor reduces the null model’s variability by about 43%. The scatterplot above tells a very different story, however: Strength does not depend linearly on Ratio, so a linear regression model is not appropriate!

So what do we do now? In general, if there’s some reason to think that a linear model should be relevant, the next step would be to try transforming the variables to obtain a linear relationship; typically, people try taking logarithms, as shown in the next example, or square roots of the variables to accomplish this. For this particular dataset, what we’ll do is define Ratio differently: we’ll divide Cement by water instead of the other way around, thereby taking the reciprocal of the predictor we tried first.
