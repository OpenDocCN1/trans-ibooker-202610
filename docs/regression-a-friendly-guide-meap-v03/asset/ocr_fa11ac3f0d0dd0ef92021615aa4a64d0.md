intervals for $\alpha$ and $\beta$, and this explains why we call the Wald statistic $Z$. For the coefficient of Photoperiod in the violet data, for example,

$Z \sim = \sim \frac{b}{SE(b)} \sim = \sim \frac{-5.5250}{0.9004} = -6.136,$

just as reported in the z column of the summary of chasm_fit. The Wald statistic for the intercept is also there, and we can check its value easily:

$Z \sim = \sim \frac{a}{SE(a)} \sim = \sim \frac{74.5837}{12.1322} = 6.148.$

The very small $p$-values given in the summary of chasm_fit reflect the fact that both of these Wald statistics are large in magnitude. It’s easy to check either of these $p$-values with norm.cdf:

```
st.norm.cdf( -6.136 )
```

One of the problems with the Wald test is the vague asymptotic nature of the large sample assumption mentioned above—that result about sampling distributions holds as the sample size approaches $\infty$, which is great for theorems but challenging to put into practice. Another problem is the possible aberrant behavior of Wald statistics, a phenomenon known as the Hauck-Donner effect that we’ll explore in Chapter 9.
