Whatever we do to accomplish that, it wouldn’t make any sense to predict a chance less than 0 (0%) or greater than 1 (100%), so there are some natural restrictions on any predictive model that we put together. Among other things, this rules out linear regression as a candidate, as the output of a linear equation could easily be negative or greater than 1.

## The logistic function

If you haven’t worked with the logistic function before, a natural question after seeing this NAMCS example is: who thought of it in the first place? We all learn about the equations of straight lines in school, so linear regression doesn’t seem so strange the first time you see it. This crazy fraction involving the exponential function, on the other hand, is not something one would spontaneously think to use. And it’s not as if someone made it up randomly either— the logistic function arises as the solution of a differential equation introduced in 1844 by the Belgian mathematician Pierre Verhulst to model population growth. He’s the one who named it the logistic function, for reasons known only to him.

Since the logistic function is also known as the sigmoid function, especially in the context of neural networks, it is often denoted σ(z). Its generic formula is

σ(z)

Logistic regression began in the 1940s when Joseph Berkson and others began using the logistic function in statistical modeling; they actually used the inverse of the logistic function, which Berkson named the logit function. Solving the equation y = σ(z) for z = f(y) yields its formula:

```
(y) = log( y / (1 - y) ),
```

where log denotes the natural logarithm, the inverse of the exponential function. Even though we won’t use this notation too much— there’s plenty of other notation to keep track of without it!— many people express logistic regression models in terms of the logit, so you need to know what it is. In these models, the logit connects probabilities with the predictor and is therefore known as the link function.

In terms of the logistic function σ(z), we can write the NAMCS model as

```
Probability of chronic condition = σ(-2.039383 + .051815 * Age),
```

revealing the connection between logistic and linear regression alluded to above: each model involves a linear function of the explanatory variable, just in a different way. In fact, logistic regression models are often presented in a form that showcases this linear function, unlike the expression above that’s better for calculating probabilities. To explain the other form of the model, we need to know how to compute the odds of something happening:

```
Odds of event = Probability of event / (1 - Probability of event).
```

The only problem with this definition is that the odds of an event are undefined when the probability is 1, as that makes the denominator 0. We’ll come back to this in a moment.

Odds are often written with a colon instead of as a fraction. For example, an event that has a 50-50 chance of happening, so that its probability is 1/2, has even odds, i.e., the odds are 1:1. If the probability of some other event is 2/3, then its odds are 2:1, twice as likely to happen as not to happen. If the odds of an event are given, the probability can be found by solving for it in the definition above:

Probability of event = Odds / (1 + Odds).

Although odds and probabilities are directly related, remember that they are not the same! With these definitions in place, we can now transform the expression above for the probability of a chronic condition into its other common form:

log(Odds of chronic condition) = −2.039383 + .051815 * Age.

With logistic regression, the probability of the event of interest— having a chronic condition, in this example— therefore depends linearly on the predictor, albeit indirectly through the natural logarithm of the odds. We’ll often write out the odds explicitly in terms of the probability; choosing between the options is mostly a matter of personal preference and convenience. There are two edge cases in which we can’t use this log-odds formulation, though: if the probability is 1, the odds are undefined; if the probability is 0, so are the odds and the logarithm is undefined.

There is yet another useful way to state the logistic model. This third and final version is the intermediate step when going back and forth between the other two— if we exponentiate the preceding log-odds formula and work with the exponents, we see that

Odds of having a chronic condition = e^(-2.039383) * e^(0.051815 * Age).

We can use this formulation to compute the multiplicative effect of changes in Age on the odds. For example,

Odds for 50-year-old = e^(-2.039383) e^(0.051815 * 50) = 1.736

and

Odds for 60-year-old = e^(-2.039383) e^(0.051815 * 50) e^(0.051815 * 10) = 1.736 * 1.679 = 2.914.
