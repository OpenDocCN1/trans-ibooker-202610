
model parameters $\alpha$ and $\beta$, respectively—are determined by maximizing the log-likelihood function. Grouping the data into covariate classes makes the definition of the log-likelihood a bit different than it was earlier, though. Using the binomial distribution defining $Y_i$, the likelihood function is now

$L(a, b) = \prod_i P(Y_i = y_i) = \prod_i \binom{n_i}{y_i} \hat{\pi}_i^{y_i} (1 - \hat{\pi}_i)^{n_i - y_i},$

and the log-likelihood function is

$\log L(a, b) = \sum_i \log\left(\binom{n_i}{y_i} \hat{\pi}_i^{y_i} (1 - \hat{\pi}_i)^{n_i - y_i}\right) = \sum_i \left\{\log\binom{n_i}{y_i} + y_i \log \hat{\pi}_i + (n_i - y_i)\log(1 - \hat{\pi}_i)\right\}.$

Note that this reduces to the previous definition of the log-likelihood when working with individual responses, as every $n_i = 1$ in that case.

Having set everything up, we can now fit models to the data and analyze the output. To work with these covariate classes, we’re not going to use a formula to fit the model as we’ve done before. Instead, we’re going to use the statsmodels GLM function; we’ll package the observations as a matrix—successes in the first column and failures in the second column—and use this matrix as the response variable. To construct the null binomial model, $\beta = 0$, corresponding to a theoretical model with $\beta = 0$, the Bias column of 1’s is the only predictor we need:

```
cohorts_null_model = sm.GLM( cohorts[["Successes","Failures"]],
```

To explain why the deviances are so much smaller when working with binomial data, we have to discuss the actual definition of the deviance; the simplistic version we presented in Chapter 4 is a special case, as we’ll show in a moment. Whether we work with individual or grouped responses, the deviance always compares a logistic model to a hypothetical model that fits the observations perfectly—this ideal model, which no one ever actually builds, is called the saturated model. To predict probabilities that are identically equal to the empirical percentages, the saturated model necessarily has as many parameters as observations, which is impractical but theoretically useful. In this example, the saturated model has 101 parameters, one per covariate class, and its i th prediction is

```
p̂_i = y_i / n_i ,
```

the observed percentage for the i th group. Since the saturated model fits the data perfectly, its log-likelihood, denoted log L_S, is guaranteed to be larger than the log-likelihood log L(a, b) of the fitted logistic model, and its exact value is

log L_S = Σ_i ( log( n_i \choose y_i ) + y_i log \hat p_i + (n_i - y_i) log(1 - \hat p_i) ).

The deviance measures how close log L(a, b) comes to this theoretical ideal; specifically, we multiply the log-likelihoods by -2 and compute their difference, resulting in the following general definition:

Deviance = -2 log L(a, b) - (-2 log L_S) = 2 Σ_i { y_i log( \hat p_i / \hat Π_i ) + (n_i - y_i) log( (1 - \hat p_i) / (1 - \hat Π_i) ) }.

Now think carefully about what happens when working with individual responses: n_i = 1 for every i, and every \hat p_i is either 0 or 1 (since \hat p_i = y_i); it follows that log L_S = 0 and the deviance reduces to the preliminary definition with which we started in the last chapter.

With this general definition in place, we can now check the deviances for ourselves. Of course, the point is not to memorize such formulas or to perform tedious calculations unnecessarily; the goal is to understand the regression output thoroughly.
