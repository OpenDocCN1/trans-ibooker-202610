The strong positive correlation, $r = 0.923$, corresponds to what we see in the scatterplot and yields a coefficient of determination of $R^2 = 0.8521$; using log(Length) to estimate log(Weight) reduces predictive variability by 85.21% relative to the null model. The fitted regression equation is

```
log(Weight) ~ = ~ -3.322617 + 2.681095 * log(Length),
```

and we can be confident that there really is a positive linear relationship between these variables. More on this in the next chapter!

To express the model in a form that’s more suitable for predicting fish weights from their body lengths, exponentiate to eliminate the logarithms and then do a little simplification:

```
Weight ~ = ~ e^{-3.322617 + 2.681095 * log(Length)} ~ = ~ e^{-3.322617} * e^{log(Length^{2.681095})} ~ = ~ .036 * Length^{2.681095}.
```

The data on fish lengths and weights thus reveals the *power law relationship*

```
Weight ~ = ~ .036 * Length^{2.68109},
```

which makes intuitive sense: if we grossly simplify this result, it says that a fish’s weight, which corresponds to its volume, is roughly proportional to the cube of its length. Of course, thanks to this rich dataset, we get a much more precise model that provides much more accurate estimates.
