As you just reviewed, the coefficient of determination for a linear regression model is defined to be

$R^2 = \frac{\text{TSS} - \text{RSS}}{\text{TSS}} = 1 - \frac{\text{RSS}}{\text{TSS}},$

where TSS is the total sum of squared deviations for the null model and RSS is the sum of the squared residuals. A common way to interpret these ingredients in the context of a logistic model is the following: in the expression on the far right for $R^2$, replace the TSS with the null deviance and replace the RSS with the residual deviance. This calculation leverages the analogy between the deviances and the sums of squares mentioned above; the result is known as McFadden’s pseudo-$R^2$, which we’ll denote by $R_M^2$:

$R_M^2 = 1 - \frac{\text{residual deviance}}{\text{null deviance}}.$

Be aware that there is no standard notation for this statistic, so be careful when you read other sources. This descriptive statistic measures the proportional reduction of the deviance and has two necessary properties:

+   - $R_M^2$ is 0 for a completely uninformative model, i.e., a model that is no better than the null model, and
+   - $R_M^2$ is 1 for a perfect model, i.e., a model for which $\hat{\pi}_i = y_i$ for every $i$. Note that, with only two parameters, a simple logistic model cannot be perfect.
