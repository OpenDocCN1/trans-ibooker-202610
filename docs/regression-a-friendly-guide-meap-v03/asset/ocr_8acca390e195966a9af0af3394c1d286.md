log L_S ~ = ~ Σ_i ( log( n_i \choose y_i ) + y_i log \hat p_i + (n_i - y_i) log(1 - \hat p_i) ).

The deviance measures how close log L(a, b) comes to this theoretical ideal; specifically, we multiply the log-likelihoods by -2 and compute their difference, resulting in the following general definition:

Deviance ~ = ~ -2 log L(a, b) - (-2 log L_S) ~ = ~ 2 Σ_i { y_i log( \hat p_i / \hat Π_i ) + (n_i - y_i) log( (1 - \hat p_i) / (1 - \hat Π_i) ) }.

Now think carefully about what happens when working with individual responses: n_i = 1 for every i, and every \hat p_i is either 0 or 1 (since \hat p_i = y_i); it follows that log L_S = 0 and the deviance reduces to the preliminary definition with which we started in the last chapter.
