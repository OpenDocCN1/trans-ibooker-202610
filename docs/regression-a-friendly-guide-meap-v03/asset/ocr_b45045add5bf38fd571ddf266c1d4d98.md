To have a model that predicts infant mortality rates as accurately as possible, we need these residuals to be as small as possible, and we should proceed systematically rather than by trial and error. Mathematics to the rescue! After setting up some more notation that we’ll use from now on, we’ll apply the famous method of least squares to solve this optimization problem and obtain a better predictive model.
