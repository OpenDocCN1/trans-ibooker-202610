## 3.1 Random variables and the theoretical model

When we fit a line to a scatterplot, we’re really acting on the belief that the response variable Y and the predictor variable x satisfy the theoretical model

y = α + β x + ε ,

for an intercept α and a slope β whose exact values can never be known and an unpredictable term ε that manifests as predictive uncertainty. The value of Y that we observe for a given value of x is the sum of the deterministic term α + β x and the random error term ε, making the response a random variable. To emphasize this fact, we henceforth use y to denote responses that have actually been observed, and we use Y to denote the random variable corresponding to responses that have not yet been observed. The theoretical model should therefore really be phrased in the form

Y = α + β x + ε .

From now on, we will generally use capital letters to denote random variables; their lowercase counterparts will denote observations or quantities computed from data. The reasons for adopting this notation will become clear as we go.

Since the error ε is random, we can’t predict how much it will contribute to an individual observation. We need to be able to say something, though, so we’re going to make some statistical assumptions about this term. To motivate the first one, fix a value x of the predictor variable and use the theoretical model to compute the average of all of the possible corresponding values of the response variable— this calculation is itself purely theoretical, as we can’t actually observe all possible responses to a given predictor value. What we obtain is the expected value or mean response of the random variable Y for the given value x, denoted E(Y|x) and read aloud as "the expected value of Y given x". Similarly, the average over all of these

possible responses of the error ε is denoted E(ε|x). These expected values are related by the equation

E(Y|x) = α + β x + E(ε|x),

since averaging is a linear process— just add up all of the responses and errors for this value of x and divide by how many there are. To deal with the expected value of the error, we invoke basic common sense: a random error is unpredictable, no more likely to be positive than to be negative, so its average should be zero, regardless of the value of the predictor. We therefore assume that E(ε|x) = 0 for every x, from which it follows that

E(Y|x) = α + β x.

The mean response E(Y|x) to a given value of x is thus a linear function of x, the deterministic component of the theoretical model. This is precisely what we observed in the heights data, and this is why we claimed that the regression line for the UNICEF data estimated the average infant mortality rate for all African countries with a given literacy rate among young women. This is the fundamental, defining property of the linear regression model.

The other basic assumptions about ε concern its behavior for different values of x. In particular, we assume that the errors for different observations are uncorrelated, i.e., that the random contribution from ε to one observation has no impact whatsoever on its contributions to other observations. We also assume that ε has constant variance, σ², so that its variability does not depend on the value of the predictor. (The fancy word for this is homoscedasticity; there is heteroscedasticity when the variance of ε is not constant.) These three assumptions enable an initial assessment of our approximation of the theoretical model, but note carefully that we are not assuming anything about the distribution of ε. More on that in the next section!

With only these three assumptions in place, we can’t say much more about the random part of the theoretical model. What we can do is approximate the deterministic part, by fitting a regression line of the form

ŷ = a + b x

to the available observations— the intercept $a$ is our best estimate of the theoretical intercept, $\alpha$, and the slope $b$ is our best estimate of the theoretical slope, $\beta$. The theoretical values that we are estimating are *parameters*, so simple linear regression requires estimating two *model parameters*. We saw earlier that we happen to have explicit formulas for the least squares estimates of these parameters:

```
$b = r\left(\frac{s_y}{s_x}\right)\quad\text{and}\quad a = \bar{y} - b\,\bar{x}.$
```

In addition to producing these coefficients, fitting the regression line to the data yields the best available estimate of the variance $\sigma^2$ of $\varepsilon$, namely

```
$\sigma^2 \approx \frac{SSR}{n-2} \approx (RSE)^2.$
```

This is precisely how we used the RSE earlier, as a measure of the variability of the responses relative to the regression line. Chebyshev’s inequality is handy here, as it quantifies the role of the RSE in assessing predictive accuracy, without requiring $\varepsilon$ to have any particular distribution.

### Chebyshev’s inequality

This is a basic result about random variables— unpredictable quantities that are usually assumed to have certain statistical properties. This particular inequality makes no distributional assumptions, requiring only that the random variable in question have a finite average and a finite standard deviation. If $Y$ is such a random variable, then *Chebyshev’s inequality* guarantees that the probability that $Y$ is within $k$ standard deviations of its average is at least $1 - \frac{1}{k^2}$:

```
$P(|Y - \mu| \le k\,\sigma) \ge 1 - \frac{1}{k^2}, $
```

where $\mu$ and $\sigma$ are the average and standard deviation, respectively, of $Y$, and $P(\cdot)$ denotes the probability of the result in parentheses.

To translate this into the context of linear regression, let $Y$ be the response variable; its standard deviation is $\sigma$, and $\mu = E(Y|X) = \alpha + \beta\,x$ when the

predictor equals x. Taking k = 2, Chebyshev’s inequality says that there is at least a 75% chance that

α + β x − 2σ ≤ Y ≤ α + β x + 2σ .

Of course, we don’t know α, β, or σ! Combining estimates based on the available data with Chebyshev’s inequality, we can be confident that most of the response values will be within 2 RSEs of the regression line. This is the most practical use of Chebyshev’s inequality— letting k = 1 just says that the probability is nonnegative, which is not helpful!

An important consequence of the three assumptions about ε is that the least squares estimates of the model parameters are optimal, in two ways:

- a and b are unbiased estimates of α and β, and
- this approach to estimating the parameters has minimal variance.

We’ll define the term unbiased in the next section; see the Gauss-Markov Theorem in the Appendix for a precise statement and a proof of these two facts. The practical takeaway is that we’re getting optimal results as long as the model’s assumptions hold. To determine whether they do, we analyze the residuals, as they provide estimates of ε's contributions to the observations. For the UNICEF IMR data, for instance, plotting the residuals versus literacy rates yields the following:

```
>>> africa_rse = np.sqrt( africa_fit.scale )
>>> sns.residplot(data=africa, x="Literacy", y="IMR", line_kws={"
>>> plt.axhline( 2*africa_rse, linestyle=":", color="black")
>>> plt.axhline( -2*africa_rse, linestyle=":", color="black")
>>> plt.title("IMR versus Literacy residuals")
```
