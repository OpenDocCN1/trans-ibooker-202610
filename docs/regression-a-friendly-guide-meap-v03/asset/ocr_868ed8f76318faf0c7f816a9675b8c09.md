As mentioned in the sidebar on the correlation coefficient, ȳ is the standard notation for the average of the response variable; x̄ denotes the average of the predictor variable. These correspond to the notation for the values in the dataset: y denotes an observed value of the response variable, and x denotes an observed value of the predictor variable. If we need to keep track of the individual observations, we use subscripts: xᵢ and yᵢ represent the values of the predictor and the response, respectively, in the iᵗʰ row of the dataset.
