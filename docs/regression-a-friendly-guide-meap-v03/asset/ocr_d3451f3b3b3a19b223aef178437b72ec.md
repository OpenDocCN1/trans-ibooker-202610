or we could just take twice the log of the ratio of the likelihoods that we computed above, the 6.185161e+29 that prompted all of this discussion of logarithms. Of course, having constructed the model chasm_fit, we can just use it to compute $G^2$ directly:

```
chasm_fit.null_deviance - chasm_fit.deviance
```

137.1942415307386

Once we have the likelihood ratio statistic, what do we do with it?
Unfortunately, it has no straightforward interpretation— it is not a percentage reduction in variability, like the coefficient of determination $R^2$, nor does it estimate a standard deviation, like the RSE. All we can really do is gauge its magnitude, using the fact that the likelihood ratio is a $\chi^2$ statistic with 1 degree of freedom. A proof [13] of this result is beyond the scope of this book, but we’ll use bootstrap methods in Chapter 5 to illustrate its validity.
Accepting it for now, we can use the scipy.stats chi2 function with df=1 to conduct the likelihood ratio test and determine whether $G^2$ is large or small:

```
1 - chi2.cdf(G2, df=1)
```

0.0

This is a $p$-value, and we’ll discuss the relevant hypothesis test in the next section. We can interpret it now, though: this very small $p$-value implies that the logistic model that includes Photoperiod is significantly better than the null model that excludes it. If the $p$-value for the likelihood ratio test had been large— typically, but not necessarily, larger than 5%— then we would have concluded that adding the predictor had not improved the model. The likelihood ratio test is a basic part of logistic regression analysis, and we’ll have much more to say about it when we consider and compare models with multiple predictors.
