This is why calling the deviance a goodness of fit statistic is a misnomer; it is more accurate to say that the deviance tells us whether we could improve the model significantly by adding parameters. To formalize this as a hypothesis test, we need to know the relevant distribution so that we can determine whether a given model’s deviance is small or large. Here’s the result, which we’ll investigate with simulations in Chapter 9: when the number $n$ of covariate classes is *fixed* and the covariate classes are all *large*, the deviance is roughly a $\chi^2_p$ statistic with $\left(n - p\right)$ degrees of freedom, where $p$ is the number of predictors in the model. This should make you wonder about several things:

+   - How good is this distributional approximation?
+   - How large do the covariate classes need to be for the approximation to be valid?
+   - How are covariate classes determined when the predictor is continuous?

The first two of these questions don’t have simple answers, but working through lots of examples provides the experience needed to deal with them. The third question is of a different sort. For the NAMCS data, for example, the covariate classes we’ve been using—patient ages—are quite natural, but we could just as reasonably organize the subjects into 5-year intervals, decades (which we did earlier), or groups like adolescents, young adults, middle-aged adults, and elderly patients. Since these options produce different numbers of covariate classes, the ensuing deviances would be $\chi^2$ statistics with very different numbers of degrees of freedom and could easily have very different $p$-values. What this means is that interpreting the deviance relies on a combination of theory, common sense, experience, and context.
