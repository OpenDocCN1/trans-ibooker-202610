# Figure 2.2. Heights of fathers and sons

![](bbox=[0.2, 0.2, 0.75, 0.62])

Each point in this *scatterplot* corresponds to one father and his son; the point’s horizontal position is the father’s height in inches, and the point’s vertical position is the son’s height in inches, with the axes labeled accordingly. Scatterplots are essential for presenting quantitative data like this, so we’ll use them extensively. This particular scatterplot confirms what we expected to see: shorter fathers tend to have shorter sons, while taller fathers tend to have taller sons.
