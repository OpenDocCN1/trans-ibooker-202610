
The coefficient of Photoperiod is $b = -5.5250$, with a standard error of $SE(b) = 0.900$. Following the procedures for computing confidence intervals that we went through in Chapter 3, we are 95% confident that the model parameter $\beta$ satisfies

$-5.5250 - (1.96*0.900) \le \beta \le -5.5250 + (1.96*0.900) \Rightarrow -7.29 \le \beta \le -3.76.$

Similarly, we are 95% confident that $\alpha$ satisfies

$74.5837 - (1.96*12.132) \le \alpha \le 74.5837 + (1.96*12.132) \Rightarrow 50.80 \le \alpha \le 98.36,$

since $a = 74.5837$ and $SE(a) = 12.132$. The multiplier 1.96 here is the 97.5% cutoff for the standard normal distribution, meaning that 97.5% of $Z$-scores are less than 1.96; equivalently, 95% of $Z$-scores are between -1.96 and 1.96. We saw how to compute this cutoff earlier with the scipy.stats function norm.ppf:

```
import scipy.stats as st
st.norm.ppf(.975 )
```

1.959963984540054

## Hypothesis tests for the parameters

Having chosen a modeling paradigm like logistic regression, hypothesis testing is a standard—and deservedly contentious—tool for evaluating the dependence of the response variable on a predictor. The problem with hypothesis testing is mindless adherence to rules based on p-values; as long as you think carefully about what the tests do and how to interpret the results, they can provide very useful diagnostics. Just remember to make decisions with all of the information at hand, not just a p-value! Having said that, let’s proceed to the specific test of interest: using the data we have, we want to know if it’s plausible that the model parameter β = 0, which would mean that the response Y does not depend on the predictor. The two competing hypotheses are therefore

H₀ : β = 0  and  Hₐ : β ≠ 0.

To determine which hypothesis is better supported by our data, we compute the relevant test statistic, obtain a p-value from it, and then draw a conclusion. In this case, there are two popular choices for the test statistic: the likelihood ratio statistic discussed earlier,

G² = -2*log( null likelihood / likelihood of logistic model ) = null deviance - residual deviance,

and the Wald statistic,

z = b / SE(b).

To get a p-value from the likelihood ratio, we rely on the fact that it’s a χ² statistic with one degree of freedom. (Recall from the last chapter that, for the violet example, G² = 137.19 and the p-value is practically 0.) In general, the smaller the p-value, the stronger the evidence against the null hypothesis: remember that a p-value is the probability, assuming that the null hypothesis is true, of observing a test statistic at least as large in magnitude as what we compute from our data. More plainly, think of the p-value as the chance of getting what you got if the null is true—just don’t ever write that in a book or paper. If this evidence against the null hypothesis is sufficiently strong, we reject it and can be confident that the response does depend on the predictor; on the other hand, if the evidence against the null is sufficiently weak, we fail to reject it and cannot be confident that the response depends on the predictor.

Using the likelihood ratio in this way is the likelihood ratio test, the preferred method for assessing whether β could be 0 in a simple logistic model. The Wald test, based on the Wald statistic just defined, is also commonly used and is often reported by statistical software, as in the summary of chasm_fit above. It’s therefore important to be comfortable with Wald statistics, too—and it’s just as important to understand why the likelihood ratio test is usually better. The Wald test relies on the fact that, when working with large samples, the relevant sampling distributions are roughly normal and unbiased. We already exploited this when we constructed confidence

intervals for $\alpha$ and $\beta$, and this explains why we call the Wald statistic $Z$. For the coefficient of Photoperiod in the violet data, for example,

$Z = \frac{b}{SE(b)} = \frac{-5.5250}{0.9004} = -6.136,$

just as reported in the z column of the summary of chasm_fit. The Wald statistic for the intercept is also there, and we can check its value easily:

$Z = \frac{a}{SE(a)} = \frac{74.5837}{12.1322} = 6.148.$

The very small $p$-values given in the summary of chasm_fit reflect the fact that both of these Wald statistics are large in magnitude. It’s easy to check either of these $p$-values with norm.cdf:

```
st.norm.cdf( -6.136 )
```

4.231257833108574e-10

which is (reasonably!) rounded to 0 in the summary table above. One of the problems with the Wald test is the vague asymptotic nature of the large sample assumption mentioned above—that result about sampling distributions holds as the sample size approaches $\infty$, which is great for theorems but challenging to put into practice. Another problem is the possible aberrant behavior of Wald statistics, a phenomenon known as the Hauck-Donner effect that we’ll explore in Chapter 9.

Fortunately for us and the violet data, the likelihood ratio test and the Wald test are consistent in this example: we have strong evidence that $\beta$ is negative and that $\alpha$ is positive. In the dry language of significance testing, we reject the null hypotheses $H_0: \beta = 0$ and $H_0: \alpha = 0$ and conclude that the probability of bud formation does depend on the photoperiod length.

Be aware that some other sources define Wald statistics to be the squares of the test statistics we just calculated—you might see the Wald statistics for the violet model reported instead as

$\left(\frac{b}{SE(b)}\right)^2 = 37.6505 \quad \text{and} \quad \left(\frac{a}{SE(a)}\right)^2 = 37.7979.$

Since the square of a $Z$-score is, by definition, a $\chi^2$ statistic, we have to use a $\chi^2$ distribution to interpret these versions of the Wald statistics.

Specifically, we can use the $\chi^2$ distribution with 1 degree of freedom to compute the relevant $p$-values:

```
1 - st.chi2.cdf( (74.5837/12.132)**2, df=1 )
```

7.862256401480749e-10

```
1 - st.chi2.cdf( (-5.5250/0.900)**2, df=1 )
```

8.310065968686331e-10

As for the corresponding $Z$-scores, these $p$-values are practically 0: we have evidence that Bud depends on Photoperiod.

## Predicting theoretical probabilities

Once we’re satisfied that we have an appropriate model that fits the data and captures a genuine relationship between the variables, we often want to use the model to make predictions. With a logistic model, that means getting a

good estimate of the theoretical probability $\Pi_X$ corresponding to a given predictor value $X$; based on the data used to build the model, our best point estimate of $\Pi_X$ is just $\hat{\Pi}_X = \sigma(a + b X)$, which the fitted model’s predict method readily provides. For example, here are estimates of the probabilities of violet bud formation for photoperiods of 13, 13.5, and 14 hours:

```
X = pd.DataFrame({"Bias":[1,1,1],
"Photoperiod":[13,13.5,14]})
predictions = pd.DataFrame({"Photoperiod":[13,13.5,14],
"Probability":chasm_fit.predict( X )})
predictions
```

Photoperiod  Probability
0  13.0        0.940411
1  13.5        0.499087
2  14.0        0.059181

We’ve organized the predictor values into the DataFrame X (often called the design matrix) along with a column of ones named Bias (a convention in the machine learning community), and we’ve organized the predictions into their own DataFrame. As we see in its Probability column, it’s very likely that a bud will form when the photoperiod lasts 13 hours, it’s very unlikely that a bud will form when the photoperiod lasts 14 hours, and there’s a 50-50 chance that a bud will form when the photoperiod is 13.5 hours.
