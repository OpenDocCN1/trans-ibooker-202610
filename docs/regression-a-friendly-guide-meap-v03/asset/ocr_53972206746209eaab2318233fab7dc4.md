Bernoulli random variables, each of which corresponds to one of the trials in the experiment. Consequently, the average of $Y$ is just the sum of the averages of the Bernoulli variables, so that $E(Y)=n\pi$. Using the same trick, the variance of $Y$ is $Var(Y)=n\pi(1-\pi)$, making its standard deviation $\sqrt{n\pi(1-\pi)}$. When the probability $p$ is close to 0.5 or the number $n$ of trials is large, the binomial distribution is roughly normal, so that $B(n,p)\approx N\left(n\pi,\sqrt{n\pi(1-\pi)}\right)$. This is easy to see when we plot $B(20,.5)$ and $B(250,.1)$, for example, overlaying the approximating normal distributions on each (in magenta):
