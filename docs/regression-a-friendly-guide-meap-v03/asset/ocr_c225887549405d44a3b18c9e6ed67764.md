# Listing 2.8. Load the FishBase species data

```
>>> fish = pd.read_csv("fish.csv")
>>> fish.shape

(34299, 101)
```

We see that this dataset has 101 columns of information about 34,299 fish species. Of the many available variables, we’re really only concerned with two in this example: Length, the characteristic length of the fish species in centimeters, and Weight, the characteristic weight of the fish species in grams. We also need to keep track of the scientific name of each species, so let’s pare things down accordingly:
