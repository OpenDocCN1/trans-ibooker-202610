Also perfect! Now that we know what happens under the hood to compute these deviances, let’s use them to compare the null and logistic binomial models. The difference between deviances for nested models like these is the likelihood ratio statistic, $G^2$, which follows a $\chi^2$ distribution with 1 degree of freedom; there is 1 degree of freedom since the logistic model has 1 more parameter than the null model. The likelihood ratio test puts all of this together:

You can easily check that these are exactly the same as the likelihood ratio statistic and the likelihood ratio test for ungrouped responses, just as the model coefficients are. These commonalities demonstrate a basic fact: if all we care about is understanding the dependence of the response variable on the predictor variable, it doesn’t matter whether we group the responses or work with them one at a time. Whichever way we package the NAMCS data, for example, we get the same astronomically small $p$-value from the likelihood ratio test. As a consequence, we can be confident that the model parameter $\beta$ really is positive, meaning that the chance of a chronic condition really does increase with age, and we can see that the logistic model that includes Age has much more predictive power than the null model that ignores it.
