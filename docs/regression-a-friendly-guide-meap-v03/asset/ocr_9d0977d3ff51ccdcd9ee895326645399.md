Knowing the sampling distributions is great, but there are some serious practical problems: we only observe one set of responses to our predictor values, we don’t know the parameters β and α, and we don’t know σ! What do we do? We use our one set of observations to approximate σ, then we rework the preceding inequalities to get estimates for β and α. Specifically, the RSE is our best available estimate of σ, and replacing σ with the RSE in the formulas above gives us the standard errors for the regression coefficients:

```
SE(b) ≈ RSE / (s_x √n − 1)   and   SE(a) ≈ RSE √[1/n + x̄² / ((n − 1)s_x²)] .
```

By definition, a standard error is the best estimate, using the data we have, of the standard deviation of the sampling distribution of the relevant sample statistic. (Try saying that out loud over and over again!) The notations SE(b) and SE(a) reflect the fact that these approximations, like the RSE, are computed from the available data; they are not random variables. We could work with these formulas by hand, but there’s really no reason to— we can (and should!) get the standard errors from the regression output. For example, here’s a summary of the africa_fit regression model:

```
>>> print( africa_fit.summary() )
```
