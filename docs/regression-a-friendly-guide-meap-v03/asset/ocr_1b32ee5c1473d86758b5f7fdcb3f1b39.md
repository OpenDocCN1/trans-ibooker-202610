obvious from the formulas presented earlier, so one of the exercises shows how to tinker with the derivation of those formulas to verify that

$$B \sim \sum_{i=1}^{n} c_i Y_i, \quad \text{where} \quad c_i \sim \frac{x_i - \bar{x}}{(n-1)s_x^2}.$$

There is a similar formula for $A$, since $A = \bar{Y} - b \bar{x}$. This is why we have to think of the $n$ values $\{x_1, ..., x_n\}$ as being fixed, so that the coefficients $c_i$ are constants, not random variables. The upshot is that the least squares estimates $A$ and $B$ are normally distributed:

$$B \sim N\left(\beta, \frac{\sigma}{s_x \sqrt{n-1}}\right) \quad \text{and} \quad A \sim N\left(\alpha, \sigma \sqrt{\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}}\right).$$

Computing these is another exercise at the end of the chapter— these are the kinds of calculations that either have to be taken on faith or worked out for oneself, and the latter option is far better! In either case, what we have here are formulas for the *sampling distributions* of the least squares estimates: if we were to observe all possible sets $\{y_1, ..., y_n\}$ fixed values of the predictor, then each set would yield its own $b$ and $a$; the average of all of these estimates would be $\beta$ and $\alpha$, respectively, which is precisely what it means for these estimates to be *unbiased*. In other words, the random variables $A$ and $B$ are unbiased estimates of the model parameters because $E(A)=\alpha$ and $E(B)=\beta$. The standard deviations describe how the realizations of these estimates will vary from one set of observations to another; there is a 95% chance, for instance, that the observed regression coefficients $b$ and $a$ will satisfy

$$\beta - 2\left(\frac{\sigma}{s_x \sqrt{n-1}}\right) \sim \le \sim b \sim \le \sim \beta + 2\left(\frac{\sigma}{s_x \sqrt{n-1}}\right)$$

and

$$\alpha - 2\left(\sigma \sqrt{\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}}\right) \sim \le \sim a \sim \le \sim \alpha + 2\left(\sigma \sqrt{\frac{1}{n} + \frac{\bar{x}^2}{(n-1)s_x^2}}\right).$$
