# Hypothesis tests for the parameters

Having chosen a modeling paradigm like logistic regression, hypothesis testing is a standard—and deservedly contentious—tool for evaluating the dependence of the response variable on a predictor. The problem with hypothesis testing is mindless adherence to rules based on p-values; as long as you think carefully about what the tests do and how to interpret the results, they can provide very useful diagnostics. Just remember to make decisions with all of the information at hand, not just a p-value! Having said that, let’s proceed to the specific test of interest: using the data we have, we want to know if it’s plausible that the model parameter β = 0, which would mean that the response Y does not depend on the predictor. The two competing hypotheses are therefore

H₀ : β = 0  and  Hₐ : β ≠ 0.
