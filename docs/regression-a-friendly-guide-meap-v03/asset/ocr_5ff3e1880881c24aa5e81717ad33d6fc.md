and

119.6022 − (2.014 * 12.138) ≤ α ≤ 119.6022 + (2.014 * 12.138) ≡ 95.15 ≤ α ≤ 144.05.

Rounding the numbers in these calculations can introduce some additional error; to get more accurate confidence intervals— and to avoid doing these calculations by hand— use the model’s conf_int method:

```
>>> africa_fit.conf_int()
```

| Literacy | -1.135228 | -0.505592 |

These quantitative estimates for the model parameters are what we’ve been after, and the inequality for β provides the single most important qualitative insight: we are confident that the slope in the theoretical model for the UNICEF data is negative, so we’re confident that infant mortality rates for African countries really do decrease as literacy rates among young women increase. With other datasets, the confidence interval for β might contain 0, implying that, for all we know, the theoretical slope could be positive, negative, or 0— when that happens, we can’t be confident that the response variable really depends on the predictor variable at all!

# 3.2.3 Significance tests for the coefficients
