Fortunately for us and the violet data, the likelihood ratio test and the Wald test are consistent in this example: we have strong evidence that $\beta$ is negative and that $\alpha$ is positive. In the dry language of significance testing, we reject the null hypotheses $H_0: \beta = 0$ and $H_0: \alpha = 0$ and conclude that the probability of bud formation does depend on the photoperiod length.

Be aware that some other sources define Wald statistics to be the squares of the test statistics we just calculated—you might see the Wald statistics for the violet model reported instead as

$\left(\frac{b}{SE(b)}\right)^2 = 37.6505 \quad \text{and} \quad \left(\frac{a}{SE(a)}\right)^2 = 37.7979.$

Since the square of a $Z$-score is, by definition, a $\chi^2$ statistic, we have to use a $\chi^2$ distribution to interpret these versions of the Wald statistics.

Specifically, we can use the $\chi^2$ distribution with 1 degree of freedom to compute the relevant $p$-values:

```
1 - st.chi2.cdf( (74.5837/12.132)**2, df=1 )
```

7.862256401480749e-10

```
1 - st.chi2.cdf( (-5.5250/0.900)**2, df=1 )
```
