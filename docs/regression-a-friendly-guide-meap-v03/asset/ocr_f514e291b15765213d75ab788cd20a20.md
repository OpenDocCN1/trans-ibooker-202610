Instead of replacing TSS and RSS with deviances in the definition of R², we can just use the native sums of squares for our logistic model. To do so, we have to pick one of the formulas for R²; the different expressions for R² are all the same in linear regression, but they are not the same when translated into the present context. In our original derivation of R², recall that we started with the sum of the squared deviations between the competing model predictions, which happens to equal TSS – RSS by the magic of ordinary least squares. Replacing this difference with the comparison of model predictions and then dividing by the sum of squared deviations for the null model is our second version of the coefficient of determination. Specifically, define R²_S by

R²_S = Σ( π̂_i − π̂ )² / Σ( y_i − π̂ )² .

Like McFadden’s pseudo-R², R²_S is bounded between 0 and 1; it equals 0 for an uninformative model and equals 1 for a perfect model. If we try replacing TSS – RSS with the other natural choice, Σ(y_i − π̂)² − Σ(y_i − π̂_i)², we get an alternative statistic that is typically close to R²_S; if evaluated for artificially degenerate data, this alternative statistic can be negative, providing a reason to prefer R²_S.
