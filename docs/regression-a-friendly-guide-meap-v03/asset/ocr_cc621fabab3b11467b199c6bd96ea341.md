If all we want are confidence intervals for the model parameters, we can use the standard errors SE(a) and SE(b) to handle the uncertainties in our estimates of α and β; that’s what we did earlier with the fitted model’s conf_int method. To address the interaction of these errors, though, we have to work with something new: we have to estimate the covariance of the random variables whose one-time realizations are the computed coefficients a and b.

# Variances and covariances
