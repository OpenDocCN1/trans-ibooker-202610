# The Calculator’s Home Page

The home page will be stateful because it will have to reflect user interactions and input, so we’ll define a simple StatefulWidget:

```
layout/calculator/lib/main.dart

class CalculatorHomePage extends StatefulWidget {
  CalculatorHomePage({Key key, this.title}) : super(key: key);
  final String title;

  @override
  _CalculatorHomePageState createState() => _CalculatorHomePageState();
}
```

and its state:

```
layout/calculator/lib/main.dart

class _CalculatorHomePageState extends State<CalculatorHomePage> {
}
```
