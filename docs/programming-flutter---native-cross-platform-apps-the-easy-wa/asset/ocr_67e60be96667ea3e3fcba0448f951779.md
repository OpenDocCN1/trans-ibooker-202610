# Displaying a SnackBar

In most apps, when a ListTile is dismissed, a SnackBar[23] is displayed at the bottom of the screen.

Displaying a SnackBar using Flutter is really simple:

```
Scaffold.of(context).showSnackBar(
  SnackBar(
    content: Text(
      "Tile ${i+1} was dismissed"
    ),
  ),
```
