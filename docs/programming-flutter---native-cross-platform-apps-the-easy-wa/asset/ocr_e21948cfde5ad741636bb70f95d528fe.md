# Change the ExpansionTile’s attributes

Most of the properties are the same as the `ListTile`’s (except for `onTap`, which doesn’t exist for `ExpansionTiles`), but `trailing` is different this time: if it is not specified it will be an arrow which, when clicked, rotates to show whether the widget is expanded or not.

There are four main `ExpansionTile`-specific arguments:

+   - `initiallyExpanded`, which can be set to true if you want the initial state of the widget to be the expanded state.
+   - `children`, which is the list of widgets to be displayed below the tile when it expands.
+   - `backgroundColor`, which is the background color of the list of children widgets.
+   - `onExpansionChanged`, with which you can set a function to be called when the tile is expanded.

For example, the following code:

  leading: Icon(Icons.list),
  title: Text("title"),

        Text("Left on first row"),
        Text("Right on first row"),
      ],
    ),
    Text("Second row"),
  ],
)
