They are used really often to display contact names inside some SMS or email apps, but also for filtering, making choices, and performing actions.

They are very small and are usually made of a round image or icon (called an avatar) and some text (called a label). It can optionally have a deleteIcon that calls the VoidCallback set as the onDelete option.

A Chip with a simple round CircleAvatar and a label can be built using the following code:

```
Chip(
  avatar: CircleAvatar(
    backgroundImage: NetworkImage(
      "http://www.carminezacc.com/manstick.png"),
    ),
  label: Text("A Bot"),
),
```
