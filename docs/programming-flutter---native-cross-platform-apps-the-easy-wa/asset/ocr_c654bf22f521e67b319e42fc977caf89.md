# # The http Package

To make GET requests we need to use the *http* package.\nYou can find the http package on Dart Pub.[^36]

Let’s start by creating a new Flutter app project using:

```
```bash\n$ flutter create xkcd_app\n```
```

and installing the HTTP package by adding the following\nto `pubspec.yaml`:

```
```yaml\n# networking/xkcd_app/pubspec.yaml\ndependencies:\n  http: "^0.12.0+1"\n```
```

Run flutter packages get to download and install the package if\nyou aren’t using the IDE plugins (which will do it\nautomatically for you after you make changes to\n`pubspec.yaml`).

# ## USING THE HTTP PACKAGE

The HTTP package can be used to make HTTP requests\nof all kinds.[^37]

All of them are asynchronous, which means that, by\ndefault, they are ran in a separate thread without\naffecting the rest of the app’s execution. You can choose\nto make them behave exactly like synchronous functions\nif their return value is vital to the prosecution of the\napp’s execution.

# ### Asynchronous Code in Dart

There are many ways to run asynchronous code in Dart,\noutlined in *Asynchronous Code in Dart: The dart:async\nLibrary*, but the basic concept has already been\nexplained in the previous chapter: calls to functions that\nreturn a `Future` (or `Stream`, which we won’t be using in this\nchapter) and run in a separate thread are called\nasynchronous.
