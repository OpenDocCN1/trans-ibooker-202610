As we explained in *Fetching Packages from Locations Other Than Pub*, you can just add:

```
packagename:
  path: ../packagename/
```

to the dependencies in `pubspec.yaml` and add:

```
import 'package:packagename/packagename.dart';
```

to `app/lib/main.dart` and you will be able to access the package
just like you would if you had used Pub.
