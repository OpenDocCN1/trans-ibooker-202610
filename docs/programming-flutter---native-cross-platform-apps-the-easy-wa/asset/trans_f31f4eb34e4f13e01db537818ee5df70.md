

## 定义自定义 Widget

现在，在 OurButton 的大括号内，我们将定义构造函数参数，并将它们设为“必需”，因为我们需要所有这些参数，并且将在代码中设置所有这些参数：

`firstapp/lib/OurButton.dart`

```dart
OurButton({
  Key key,
  @required this.text,
  @required this.textColor,
  @required this.backgroundColor,
  @required this.splashColor,
  @required this.onPressed
}) : super(key: key);
```

对于这些参数中的每一个，我们都需要一个变量来存储它们，就像我们在以下行中所做的那样：

`firstapp/lib/OurButton.dart`

```dart
final String text;
final Color textColor, backgroundColor, splashColor;
final VoidCallback onPressed;
```

现在，像所有 widget 一样，我们需要一个 build 方法，在这种情况下，它将是：

`firstapp/lib/OurButton.dart`

```dart
@override
Widget build(BuildContext context) {
  return RawMaterialButton(
    onPressed: onPressed,
    fillColor: backgroundColor,
    splashColor: splashColor,
    padding: ButtonTheme.of(context).padding,
    child: Text(
      text,
      style: TextStyle(color: textColor),
    ),
    shape: StadiumBorder(),
  );
}
```

我们制作的按钮是一个 `RawMaterialButton`，它是一个最基本的按钮类，允许我们自定义其外观远比更简单的 `FlatButton` 更多。

更具体地说，我们传递给其构造函数的参数是：

- `onPressed`，它与我们之前见过的其他 `onPressed` 属性相同，我们将其分配给 `OurButton` 的 `onPressed` 属性。
- `fillColor`，它与本章前面用于 `FlatButton` 的 `color` 属性相同：它是按钮的背景颜色，将设置为 `OurButton` 的 `backgroundColor` 属性，以展示我们的自定义按钮的属性名称可以与我们基于其构建的 widget 不同。
- `splashColor` 是用于墨水水波纹效果的颜色。
- `padding` 用于为我们的按钮提供正常（默认）的内边距。
- `child` 只是 `Text`，使用 `OurButton` 参数中指定的颜色作为文本颜色。
- `shape` 是按钮的形状，我们使用 `StadiumBorder()` 来为我们的按钮提供想要的圆角。

整个 `OurButton.dart` 源代码是：

`firstapp/lib/OurButton.dart`

```dart
import 'package:flutter/material.dart';

class OurButton extends StatelessWidget {
  OurButton({
    Key key,
    @required this.text,
    @required this.textColor,
    @required this.backgroundColor,
    @required this.splashColor,
    @required this.onPressed
  }) : super(key: key);

  final String text;
  final Color textColor, backgroundColor, splashColor;
  final VoidCallback onPressed;

  @override
  Widget build(BuildContext context) {
    return RawMaterialButton(
      onPressed: onPressed,
      fillColor: backgroundColor,
      splashColor: splashColor,
      padding: ButtonTheme.of(context).padding,
      child: Text(
        text,
        style: TextStyle(color: textColor),
      ),
      shape: StadiumBorder(),
    );
  }
}
```

## 在我们的应用中使用自定义按钮

要在 `main.dart` 文件中使用我们的自定义按钮，我们需要通过在文件顶部插入以下内容来导入我们刚刚创建的文件：

```dart
import 'OurButton.dart';
```

并且，在 `_MyHomePageState` 的 build 方法中，将：

`firstapp_starting/lib/main.dart`

```dart
floatingActionButton: FloatingActionButton(
  onPressed: _incrementCounter,
  tooltip: 'Increment',
  child: Icon(Icons.add),
),
```

替换为：

`firstapp/lib/main.dart`

```dart
floatingActionButton: OurButton(
  text: 'Make the counter ${_counter+1}',
  textColor: Colors.white,
  backgroundColor: Theme.of(context).primaryColor,
  splashColor: Theme.of(context).primaryColorLight,
  onPressed: _incrementCounter,
),
```

我们传递的参数中有一个包含表达式 `_counter+1` 的字符串，这需要用大括号将其括起来。

之后，我们就完成了！

完整的 `main.dart` 源代码是：

`firstapp/lib/main.dart`

```dart
import 'package:flutter/material.dart';
import 'OurButton.dart';

void main() => runApp(MyApp());

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        primarySwatch: Colors.green,
      ),
      home: MyHomePage(title: 'An app that can count to'),
    );
  }
}

class MyHomePage extends StatefulWidget {
  MyHomePage({Key key, this.title}) : super(key: key);
  final String title;

  @override
  _MyHomePageState createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> {
  int _counter = 0;
  String _displayedString;

  void _incrementCounter() {
    setState(() {
      _counter++;
    });
  }

  void _resetCounter() {
    setState(() {
      _counter = 0;
    });
  }

  @override
  Widget build(BuildContext context) {
    if (_counter == 0) {
      _displayedString = "None";
    } else {
      _displayedString = _counter.toString();
    }
    return Scaffold(
      appBar: AppBar(
        title: Text('${widget.title} $_counter'),
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: <Widget>[
            Text(
              'You have pushed the button this many times:',
            ),
            Text(
              _displayedString,
              style: Theme.of(context).textTheme.display1,
            ),
            FlatButton(
              onPressed: _resetCounter,
              color: Colors.red,
              child: Text(
                "Reset counter",
                style: Theme.of(context).textTheme.button,
              ),
            ),
          ],
        ),
      ),
      floatingActionButton: OurButton(
        text: 'Make the counter ${_counter+1}',
        textColor: Colors.white,
        backgroundColor: Theme.of(context).primaryColor,
        splashColor: Theme.of(context).primaryColorLight,
        onPressed: _incrementCounter,
      ),
    );
  }
}
```

### 介绍布局 Widget

有多个 widget 可用于布局目的，其中一些看起来可能非常相似。

从上面示例中所需且在下一章中解释的 widget 开始，我们显然会提到简单的垂直和水平视觉布局结构：

- Column，详细描述于 The Column，允许你像我们在第 1 章中所做的那样垂直堆叠 widget。它不应与 Stack 混淆，后者实际上用于在其他 widget 之上显示 widget。
- ListView，详细描述于 The ListView，允许你创建（潜在无限的）可滚动的 widget 列表。
- Row，详细描述于 Horizontal Layout: The Row，允许你并排显示 widget。
- GridView，详细描述于 The GridView，用于创建可滚动网格，就像 ListView 用于创建可滚动的一维列表一样。

此外，本章还将介绍 Expanded widget（在 Fill the Space Available in the View Using Expanded 中），它用于创建不同大小的 Column 或 Row 子项。

我们还将讨论 Slivers（在 Slivers, Custom Scrollables, and Collapsible App Bars 中），它用于高级滚动，以及 Key（在 The Key 中），我在上一章中告诉你忽略它。

在下一章中，我们将结合本章介绍的许多 widget（更多内容请参见第 3 章 Building a Calculator App）。

那么让我们开始吧。

我们将从简单且无处不在的 Padding 和 Container 开始，因为你在构建应用时将与许多其他 widget 一起使用它们，然后我们将讨论如何将自己的资源添加到应用中。
