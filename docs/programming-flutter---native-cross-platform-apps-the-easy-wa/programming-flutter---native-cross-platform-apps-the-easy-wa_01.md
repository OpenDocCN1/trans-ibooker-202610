# 第一部分：Flutter 入门

尽管 Flutter 非常容易上手，但我们仍需真正了解它能为我们做什么，以及它是如何实现的。

本部分各章正是围绕这一点展开：你将编写第一个应用，并在此过程中了解 Flutter 组件是什么，以及如何使用它们来创建用户界面。

之后，你将开始组合越来越多的 Flutter 组件，并且在第一部分结束时，你将学会如何使用 Dart 包来获取 Google 开发的库和第三方库，从而构建更多使用 Flutter（或 Dart）标准库中不具备的功能的应用。

你还将学习如何运行用原生 Swift/Objective-C 和 Kotlin/Java 编写的方法，以便与 Flutter 中原本无法访问的底层特性进行交互。
