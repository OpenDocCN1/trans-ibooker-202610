
# 3D Printing and Maker Lab for Kids

在《3D Printing and Maker Lab for Kids》中，我们通过*材料操控*的概念，探讨设计实体对象的过程。

许多物体由通常以固定形状和尺寸提供的原材料制成——例如金属卷、纸张、铁条等——我们可以通过操控这些原材料来创建想要的物体。这包括组合不同形状、改变尺寸、拆解、部分连接，以及连接两种或多种不同材料。通常，这些操作需要中间步骤：粘合以组合、锯切以拆解、或铰链以制作柔性连接。相比之下，在计算机辅助设计（通常称为 `CAD`）的世界里，这些步骤可以被消除。在本书中，我们将逐一探讨这些过程，并构建各种物体来解释它们在 `CAD` 中如何工作。

《3D Printing and Maker Lab for Kids》还展示了如何在两个不同的 `CAD` 程序中创建设计：`Tinkercad` 和 `SketchUp`。这两个应用程序都是免费的；你只需要一个互联网连接和一个网页浏览器即可访问。虽然两者对初学者都相当容易上手，但我们使用 `Tinkercad` 制作大多数项目，因为它的学习曲线更短。剩余项目在 `SketchUp` 中制作，它与 `Tinkercad` 不同，使用必须转换为 3D 的预设 2D 对象。

## 3D 打印基础

3D 打印的过程本质上是一种制造技术，使用各种材料加热到允许其形成不同形状的温度，来创建三维物体（相对于在纸上进行的 2D 文档打印）。由于价格合理的桌面 3D 打印机在市场和当地图书馆大量普及，它在过去几十年中获得了极大的流行度。它是创建原型、定制物品或家用物品替换零件（其中一些在本书中讨论）的便捷方式。

3D 打印有多种类型；然而，本书讨论的一种也被称为增材制造。3D 打印机本质上在二维平面铺设材料，然后不断在前一层之上添加层以创建三维物体。材料（`filament`）被送入 `extruder`，在那里被加热到约 `215°C`，此时熔化，`extruder` 将其从 `nozzle` 挤出，很像从管子挤出的牙膏。`extruder` 基于由设计确定的命令序列在三个方向移动（左右、前后、上下）。设计通常在独立于打印机的软件中创建（如 `Tinkercad` 或 `SketchUp`）。完成的软件文件被发送到 3D 打印机软件，后者将其解释为 3D 打印机可理解的文件。打印机软件将其转换为 `extruder` 的运动命令。大多数 3D 打印机允许在打印中途暂停，这是查看打印机如何确定物体内部设计的好方法。打印机出厂时带有各种默认设置，以最小化打印物体的时间和材料。然而，大多数打印机允许用户修改默认设置，因此你可以选择加热 `filament` 的温度、外壁厚度、填充量、填充图案和其他细节。

### Getting Started with Tinkercad

`Tinkercad` 是一种计算机辅助设计（`CAD`）软件，通过使用其预创建的 3D 形状库来创建 3D 数字模型。`Tinkercad` 账户可以在 [`Tinkercad.com`](http://Tinkercad.com) 免费在线创建。创建账户并登录后，软件会提示你完成几个教程。建议完成所有教程以熟悉软件。

完成教程后，你将进入一个提供**创建新设计**选项的页面（图 1）。点击此选项。

![Image](images/f0013-01.jpg)

**图 1：** 点击 `Create New Design` 按钮开始在 `Tinkercad` 中工作。

这将带你进入创建设计的页面。请注意页面的以下部分：

- **左上角是文件名。** `Tinkercad` 会自动创建一个随机名称。通过点击并输入所需名称来重命名文件。

- **文件名正下方的顶部功能区** 拥有在工作平面上 **复制**、**粘贴**、**复制**、**删除**、**撤销** 和 **重做** 工作的工具。图 2 中的箭头标识了顶部功能区。悬停按钮可查看其用途。

- **顶部功能区右侧** 有更多工具：**组合**、**取消组合**、**导入**、**导出** 和其他。见图 2 右侧。

![Image](images/f0013-02.jpg)

**图 2：** 顶部功能区有文件名，其下方有 `Copy`、`Paste`、`Duplicate`、`Delete`、`Undo` 和 `Redo` 按钮。

- **页面左侧** 有工作平面查看工具：**缩放**、**顶视图**、**前视图** 和 **主页视图**。详见图 3。点击视图进行探索。

![Image](images/f0014-01.jpg)

**图 3：** 左侧是 `Zoom`、`Top View`、`Front View` 和 `Home View` 工具，控制视图大小和角度。

- **页面中央部分** 是 **工作平面**。这是创建和操控设计的主要暂存区域，使用来自页面各部分的工具。工作平面标有网格，以协助准确放置设计和形状。网格比例可通过工作平面右下角的 **编辑网格** 按钮修改。图 4 中的箭头标记了 **捕捉网格** 菜单，允许增量尺寸变化的幅度变化。
