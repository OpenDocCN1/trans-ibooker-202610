| Names | Example | Notes |
|---|---|---|
| RY | `qc.ry(math.pi/8,0)` | Applies RY gate with π/8 rotation to qubit 0. See “RYGate”. |
| RZ | `qc.rz(math.pi/2,1)` | Applies RZ gate with π/2 rotation to qubit 1. See “RZGate”. |
| S | `qc.s(3)` | Applies S gate to qubit 3. Equivalent to P gate with π/2 phase rotation. See “SGate”. |
| S† | `qc.sdg(3)` | Applies S† gate to qubit 3. Equivalent to P gate with 3π/2 phase rotation. See “SdgGate”. |
| SX | `qc.sx(2)` | Applies SX (square root of X) gate to qubit 2. This is equivalent to an RX gate with a π/2 rotation. See “SXGate”. |
| T | `qc.t(1)` | Applies T gate to qubit 1. Equivalent to P gate with π/4 phase rotation. See “TGate”. |
| T† | `qc.tdg(1)` | Applies T† gate to qubit 1. Equivalent to P gate with 7π/4 phase rotation. See “TdgGate”. |
| U | `qc.u(math.pi/2,0,math.pi,1)` | Applies rotation with 3 Euler angles to qubit 1. See “UGate”. |
| X, NOT | `qc.x(3)` | Applies X gate to qubit 3. See “XGate”. |
| Y | `qc.y([0,2,3])` | Applies Y gates to qubits 0, 2 and 3. See “YGate”. |
