We’ll follow those two steps to define a custom controlled gate that applies a π/16 phase rotation when both of its control qubits are |1⟩. First, Example 1-24 defines a circuit that contains a π/16 P gate and converts it to a custom gate, with Figure 1-21 showing a drawing of the custom gate.

# Example 1-24. Creating a custom π/16 phase gate

```
p16_qc = QuantumCircuit(1)
p16_qc.p(math.pi/16, 0)

p16_gate = p16_qc.to_gate()

p16_gate.definition.draw()
```
