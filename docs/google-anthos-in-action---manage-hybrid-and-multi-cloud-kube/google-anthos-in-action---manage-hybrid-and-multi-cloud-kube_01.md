# 欢迎

感谢您购买 *Google Anthos in Action* 的 MEAP 版。我希望您所获得的内容能立即用于开发云软件，并且在您的帮助下，最终的书会非常棒！

要充分利用本书，您需要对云计算有一定的了解。不必担心，因为我们会在本书的前几章中回顾微服务和服务网格等基本概念。

无论您是软件开发者、对技术感兴趣的企业人士、技术研究者，还是仅仅想了解计算机和人类世界的走向，了解 Anthos 都是至关重要的。本书不仅能让您理解一项关键的技术，还能让您了解促使我们创造 Anthos 的趋势和思考。因此，它也会让您对未来有清晰的认识。

当我们开始在 Google 内部审视 Anthos 时，我们受到了一个简单原则的启发：让我们抽象掉运行计算基础设施运维中大部分低效的工作，并移除那些对构建和运行软件服务并非核心的惯性约束。Kubernetes 以及使用 DevOps 运行托管服务的 SRE 原则，是构建我们新产品基础的核心概念。Anthos 是进一步简化开发者工作的重大一步，这得益于一个以客户为中心、可在任何地方运行的分布式开发平台的创建，它可以自动化利用率、减少昂贵的依赖并促进生产状态。

这确实是一本大部头的书，我希望您阅读它时能像作者、策展人和审阅者制作它时一样觉得有趣。我的建议是，您先深入阅读前五六章，然后按照您喜欢的顺序选择相关的后续主题。
