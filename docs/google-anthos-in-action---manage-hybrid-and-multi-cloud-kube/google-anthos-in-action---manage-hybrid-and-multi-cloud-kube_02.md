## 1.1 现代应用的剖析

软件已经在吞噬世界一段时间了。作为消费者，我们已经习惯了那些让我们在叫车或存入薪水等事情上更快、更智能、更高效的应用。我们的健康、教育、娱乐、社交生活和就业也在日益被现代软件应用所增强。在这些应用的另一端，是一个由大大小小的企业组成的链条，它们提供这些改进的体验、服务和产品。现代应用不仅部署在消费者手中，也部署在企业供应链的各个节点上。零售、媒体、金融服务、教育、物流等许多传统行业中的大型事务系统，正在逐渐被现代微服务所取代，这些微服务频繁自动更新、高效扩展并融入更多实时智能。新的数字优先初创公司正利用这个机会颠覆传统商业模式，而现有企业则竞相实现系统现代化，以便竞争并避免被颠覆。
