# ## 21.2 Anthos Bare Metal Architecture

While Anthos on VMware cluster nodes are deployed from pre-configured VM images provided by Google, Anthos on Bare metal relies on customers to provide a supported operating system version that is managed and patched by the customer themselves. As you can see in the figure 2 below, the operating system can be installed directly on a physical server or on a VM running on any virtualization platform (KVM, OpenStack) that supports one of the Linux distributions compatible with Anthos on bare metal.
