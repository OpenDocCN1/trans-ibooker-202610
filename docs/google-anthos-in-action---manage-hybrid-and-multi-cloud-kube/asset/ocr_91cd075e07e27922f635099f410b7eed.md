If the cluster deployment will use the bundled load balancer:

+   - The load balancing nodes need to be in the same L2 network, while other connections, including worker nodes, only require L3 connectivity.
+   - All VIPs must be in the load balancer machine subnet and fully routable.
+   - The gateway of the load balancer subnet must listen to gratuitous ARP messages and forward ARP packets to the load balancer nodes.

# 21.3.5 Google Cloud Platform requirements

The Anthos on bare metal installation has a few GCP project requirements, including required API’s, service accounts, and required roles.

# Required GCP APIs

For a successful deployment, the project where the cluster will be connected to must have a number of API’s enabled. This can be done manually, or they can be enabled automatically as an option when you execute the deployment using bmctl.
