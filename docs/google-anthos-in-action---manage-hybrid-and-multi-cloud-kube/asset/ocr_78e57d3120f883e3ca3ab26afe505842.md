# 14.3.4 Kustomize for generating environment specific configuration.

In real life scenarios you will deploy your application to multiple environments. In the CI/CD pipeline you need to have a tool that will adjust the configuration of your app for each of environment without changing the actual code base.

Kustomize is a standalone tool to customize Kubernetes resources with use of a kustomization.yaml file. The good news is that since version 1.14 of Kubernetes, Kustomize has been merged into the kubectl tool.
