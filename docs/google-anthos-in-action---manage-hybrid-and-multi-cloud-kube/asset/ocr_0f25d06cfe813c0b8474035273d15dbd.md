+   1. The first step is to define the delivery pipeline with the progressions (the promotion sequence) and optionally the runtime targets. In this example we will create separate target files. For this example, we can define the following pipeline:

# 14.4.3 delivery-pipeline.yaml

```
apiVersion: deploy.cloud.google.com/v1beta1
kind: DeliveryPipeline
metadata:
    name: web-app
description: web-app delivery pipeline
serialPipeline:
  stages:
  - targetId: test
  - targetId: staging
  - targetId: prod
```

+   2. The targets can be defined as separate files. You can define a separate file per target. You will end up having 3 files:
+       - target_test.yaml
+       - target_staging.yaml
+       - target_prod.yaml
