4. Now test the application by running a curl query:

```
curl http://helloworld-python.default.1.2.3.4.xip.io
```

Note that the xip.io domain is so called Magic DNS you can configure it when installing Knative (see: [https://knative.dev/docs/serving/using-a-custom-domain/](https://knative.dev/docs/serving/using-a-custom-domain/)).

5. You should see the following output

```
Hello Python Sample v1!
```

You have successfully deployed your first Knative application!
