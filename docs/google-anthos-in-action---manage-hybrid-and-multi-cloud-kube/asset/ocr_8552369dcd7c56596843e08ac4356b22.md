# # Initiating Skaffold

You can generate a skaffold.yaml configuration automatically by running:

```
```bash
skaffold init
```
```

This will detect the source files in the current folder and create a very simple configuration file with build and deploy sections. Let’s create three files:

+   - `Dockerfile` - container image definition
+   - `main.go` - simple “Hello world” Go application
+   - `k8s-pod.yaml` - Kubernetes pod definition
+   - [https://skaffold.dev/docs/references/yaml/](https://skaffold.dev/docs/references/yaml/)

**Dockerfile content:**

```
```dockerfile
FROM golang:1.12.9-alpine3.10 as builder
COPY main.go .
ARG SKAFFOLD_GO_GCFLAGS
RUN go build -x -gcflags="${SKAFFOLD_GO_GCFLAGS}" -o /app main.go
FROM alpine:3.10
runtime
ENV GOTRACEBACK=single
CMD ["./app"]
COPY --from=builder /app .
```
```

**Main.go content:**

```
```go
package main
import (
    "fmt"
    "time"
)

func main() {
    for {
        fmt.Println("Hello world!")
        time.Sleep(time.Second * 1)
    }
}
```
```
