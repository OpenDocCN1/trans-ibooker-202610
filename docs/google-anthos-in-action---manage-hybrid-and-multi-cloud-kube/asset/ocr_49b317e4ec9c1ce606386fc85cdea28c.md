Now that we have understood the basis of how Cloud Build works let's have a look at Cloud Builders.

# Cloud Builders

As we have already learned, Cloud Build runs a series of steps defined in the `cloudbuild.yaml` file. Those steps are executed within containers. The containers are deployed using container images defined in the name attribute of each step. Those container images are called Cloud Builders. They are specially packaged images that run a specific tool like docker, git or kubectl etc. with a set of user defined attributes. There are free types of builders.

+   - Google supported builders
+   - Community supported builders
+   - Custom developed builders

# Google supported builders
