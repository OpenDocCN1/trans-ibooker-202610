# # 10 Anthos, at the edge and telco world

by Giovanni Galloro

# ## This chapter covers:

+   - Evolution of Telco Network Functions towards Cloud Native Network Functions
+   - Edge Applications use cases
+   - Anthos specific capabilities for supporting Telco and Edge workloads
+   - Google Distributed Cloud Edge

This chapter is about using Anthos as an enabling platform for edge and telco workloads, where these workloads fall mainly in 2 categories:

+   1. **Cloud Native Network Functions:** An evolution of Telecom Network Functions, either already virtualized or still deployed as physical appliances, towards containerized workloads to reach greater efficiency, performance, and ease of management. This evolution will be driven also by new 5G related Network Functions.
+   2. **New Edge Applications:** Workloads to be deployed in edge locations, near to the end-customer, to reduce latency at minimum and enable new types of applications such as: autonomous driving, smart cities, smart video surveillance, augmented reality, virtual reality, remote healthcare/surgery. Often this type of applications will benefit and be powered by 5G networks and in large part will be deployed as containerized workloads.
