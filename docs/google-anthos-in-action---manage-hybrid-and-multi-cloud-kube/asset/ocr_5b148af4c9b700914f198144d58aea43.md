# 14.2.1 Setting up local preview Minikube cluster

Minikube[^5] is a popular software that allows you to run Kubernetes applications locally on your laptop. It runs on Windows, Linux and MacOS. Instead of deploying your application to an Anthos cluster you can deploy it locally and preview your application even before pushing the code to the Git repository.
