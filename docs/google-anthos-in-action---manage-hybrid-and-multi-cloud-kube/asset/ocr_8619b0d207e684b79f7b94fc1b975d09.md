# Customizing

Customization allows you to patch your resources with specific values. This uses two method:

patchesStrategicMerge [28]

+   - patchesJson6902 [29]

As an example you can patch my-deployment Deployment defined in deployment.yaml file with number of replicas by creating below files.

```
```yaml
# increase_replicas.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-deployment
spec:
  replicas: 3
```
```

```
```yaml
# kustomization.yaml

resources:
- deployment.yaml
patchesStrategicMerge:
- increase_replicas.yaml
```
```

and run

```
```bash
kubectl kustomize ./
```
```
