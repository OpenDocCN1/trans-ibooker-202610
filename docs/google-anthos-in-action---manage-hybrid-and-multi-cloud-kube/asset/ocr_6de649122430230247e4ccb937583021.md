# Login to GCP and download the bmctl tool

Remember, that Google supplies a tool to deploy Anthos on bare metal called bmctl. On the workstation that you will use to deploy the cluster, download the bmctl tool by following the steps below (For our example, we will assume the working directory is ~/baremetal)

+   1. Login with gcloud, using `gcloud auth application-default login`, as a user that has the roles described in the Installing account role requirements section of the Installation Requirements paragraph.
+   2. Download the bmctl tool from the url or storage bucket you will find in the documentation - at the time of writing, bmctl is available for Anthos 1.9 at:

```
gsutil cp gs://anthos-baremetal-release/bmctl/1.9.0/linux-amd64/b
```

+   3. Make bmctl executable:
+   4. `chmod a+x bmctl`

Now that we have the bmctl executable, we can move on creating the cluster configuration.

# Create the cluster configuration

To deploy a cluster, we need to have a cluster configuration file that contains all of the parameters and options for the deployment. The bmctl tool can create a new configuration file for us by using the *create config* option:

```
bmctl create config -c CLUSTER_NAME --project-id=CLOUD_PROJECT_ID
```
