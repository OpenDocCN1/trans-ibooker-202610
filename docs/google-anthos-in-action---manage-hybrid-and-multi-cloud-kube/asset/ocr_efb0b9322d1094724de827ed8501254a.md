You can interact with it like with a regular cluster using the kubectl command line interface.

Minikube can be run on any laptop that fulfills the below minimum requirements:

+   - 2 CPUs
+   - 2GB of free memory
+   - 20GB of free disk space
+   - Internet connectivity
+   - Virtualization software like Virtual Box.
