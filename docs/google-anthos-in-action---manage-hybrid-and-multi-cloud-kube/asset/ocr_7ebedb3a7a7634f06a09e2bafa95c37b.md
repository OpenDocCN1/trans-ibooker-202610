# 14.6 Summary

As we already learned in this chapter, modern application delivery CI/CD platforms play a significant role in the modern enterprise application delivery process. They come with the following benefits:

+   - Developers can focus on applications, which increase the performance and efficiency of development teams.
+   - Same applies to operators that are able to control application delivery on early stages, offload daily routines and configuration overhead.
+   - Automated pipelines unify the ways of working with application and infrastructure.
+   - Security teams become an inseparable part of the integration and delivery process.
