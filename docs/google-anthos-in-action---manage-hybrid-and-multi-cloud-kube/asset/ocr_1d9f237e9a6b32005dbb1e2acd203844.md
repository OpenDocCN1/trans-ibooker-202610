# 15.4.1 Giving BigQuery Access to Data in AWS

In order to enable BigQuery Omni to do a query on data residing on AWS, a user needs to have an AWS account and permission to modify the *Identity and Access Management (IAM)* policies of the S3 data to grant BigQuery access. There are several steps associated with the process, as outlined in the following sections.

# Creating an AWS IAM Role and Read Policy

The user must first create an AWS IAM role and a read policy for the S3 the user wants to give BigQuery access to, and then attach the role and the policy together.
