# External Connectivity requirements

All Anthos on bare metal nodes will need outbound https connectivity to the internet, in order to:

+   - Register to GCP console and be managed from there through GKE Connect
+   - Send metrics and logs to Cloud Operations endpoints
+   - Pull images from Google Container Registry

This connectivity can use the public internet, a http proxy, or a private connection like Google Cloud VPN or Dedicated Interconnect.

# Internal Connectivity requirements
