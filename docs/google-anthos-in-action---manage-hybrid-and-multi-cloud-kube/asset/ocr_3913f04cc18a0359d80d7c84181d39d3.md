# 21.1 Introduction to Anthos on Bare Metal

As described in previous chapters, Anthos is a platform designed for multiple deployment environments, as summarized in the following picture:

Figure 21.1. Anthos deployment environments

![](bbox=[0.12, 0.26, 0.875, 0.565])

Anthos on bare metal is a deployment option to run Anthos on physical servers, deployed on an operating system provided by the customer. Anthos on bare metal ships with built-in networking, lifecycle management, diagnostics, health checks, logging, and monitoring. Additionally it supports CentOS, Red Hat Enterprise Linux (RHEL), and Ubuntu, all validated by Google. With Anthos on bare metal, it is possible to use an organization’s standard hardware and operating system images, taking advantage of existing investments, which are automatically checked and validated against Anthos infrastructure requirements.
