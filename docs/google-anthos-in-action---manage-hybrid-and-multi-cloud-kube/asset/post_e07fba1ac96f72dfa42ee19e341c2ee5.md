## Physical Machines

+   - Requires hardware expertise
+   - Often leads to under-utilized resources
+   - Often slow and expensive to scale up or out

## Virtual Machines

+   - Lowers overall cost by sharing the physical server with multiple VM’s
+   - Building a virtual server requires very little knowledge of the hardware
+   - Offers faster deployment for new servers, but dynamic scaling is a challenge

## Containers

+   - Removes management of Virtual Machine from Developers
+   - Lowers overall cost by removing the need to run a VM for a single app
+   - Allows easy, dynamic, application scaling

## Serverless (FaaS)

+   - Removes management of Containers from Developers
+   - Frees up resources when not in use (pay as you go model)
+   - Allows easy, dynamic, application scaling
