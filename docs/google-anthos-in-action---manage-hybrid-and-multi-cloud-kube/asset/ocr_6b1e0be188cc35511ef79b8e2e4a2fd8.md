# Summary of Cloud Build

Cloud Build, though very simple to use, can actually deliver E2E CI/CD experience for delivering your Anthos applications.

If you want to get more hand-on experience with E2E pipelines we encourage you to follow a tutorial at your own pace:

https://github.com/GoogleCloudPlatform/gke-gitops-tutorial-cloudbuild. In this tutorial you will you will develop a pipeline a that will support:

+   - Test of the commited code
+   - Build container image
+   - Push image to the registry
+   - Update K8s manifests and push it environment repository
+   - Detect changes on the branch
+   - Apply manifest to Anthos GKE Cluster
+   - Update the production branch with the K8s manifest applied
