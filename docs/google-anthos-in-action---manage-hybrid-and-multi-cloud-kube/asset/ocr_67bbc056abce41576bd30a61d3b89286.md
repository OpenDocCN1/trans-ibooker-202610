# 21.4.1 Create an admin, hybrid or standalone cluster

As we have detailed, Anthos on bare metal can be deployed using a few different cluster models, including separate admin/user clusters, hybrid clusters, or standalone clusters. In this section, we will discuss the process of deploying each model.

# Summary of installation flow

The first cluster that is installed in a specific deployment environment, regardless of the selected model, is installed using the bmctl tool. Additional user clusters in the same environment can be created by applying an Anthos on bare metal user cluster configuration file, which is similar to the first cluster configuration, with a few minor changes.

The high level steps to create the first cluster are:

+   1. Download bmctl tool
+   2. Use bmctl to create a cluster config template file
+   3. Modify the config file with desired settings
+   4. Run bmctl to create the cluster
