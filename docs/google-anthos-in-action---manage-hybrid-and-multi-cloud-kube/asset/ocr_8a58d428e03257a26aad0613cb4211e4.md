# Load balancing requirements

Before installing Anthos on bare metal you need to choose an architecture for load balancing (manual vs bundled) and, in the case of bundled, deciding if your load balancers will be installed on control plane nodes or dedicated worker nodes.

Whatever solution is chosen, the following Virtual IP addresses must be reserved:

+   - **1 VIP for the control plane for each cluster.**
+     If using the bundled load balancer this will be automatically created based on the configuration defined during installation.
+     If using a manual load balancer this needs to be manually associated with a backend server group containing all the IP addresses of the cluster's control plane nodes. The backend port the control plane listens on is 6444.
+   - **1 VIP for the Ingress service for each user cluster.**
+     If using the bundled load balancer this will be automatically created based on the configuration defined during installation.
