+   - **vPE:** Virtualization of PE (Provider Edge) Routers. In this approach, the routers deployed in the Service Provider Edge that typically connect with the ones deployed in customer premises are also virtualized.
+   - **vEPC:** EPC (Evolved Packet Core) Virtualization: Virtualization of Network Functions that are part of Mobile Core Networks and IP Multimedia Subsystem (IMS) as Mobility Management Entity (MME), Serving Gateway (SGW), Packet Data Network Gateway (PGW).
+   - **vCDN:** Virtualization of CDNs. This use case aims at virtualization of the 3rd party CDN appliances usually deployed in operator premises.
+   - **vRAN:** Virtualization of Mobile base stations in Radio Access Network (RAN) was initially considered as an use case for NFV, mainly because mobile base stations are some of the components that account for most of the TCO and energy consumption of mobile networks. This approach didn’t effectively materialize in NFV but the aim to get the benefits of containerized workloads described above and the need of new Radio Network Functions related to 5G is pushing the transformation of these functions to CNFs.

# Evolution to Cloud Native Network Functions
