# Setting cross-cutting fields

Using Setting cross-cutting fields you can set the following attributes to you your Kubernetes resources:

+   - namespace
+   - namePrefix
+   - nameSuffix
+   - commonLabels
+   - commonAnnotation

In the below example we set namespace to ‘my-namespace’ to for the deployment.yaml definition. Note: you can use resources attribute to define the resources you want be affected.

```
# kustomization.yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
namespace: my-namespace
resources:
- deployment.yaml
```

# Generating Resources

With Kustomize you can generate ConfigMaps and Secrets resources. As we have already learned they are used for feeding in configuration and credentials to your application. Objects can be generated either from a literal or a file. The following generators are supported:

+   - configmapGenerator
+   - secretGenerator

As an example to generate a ConfigMap with the key value pair you can use the following file

```
# kustomization.yaml

configMapGenerator:
```
