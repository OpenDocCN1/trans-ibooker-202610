# How to Add Alerts and Subscriptions

To implement this recipe, use the following steps:

+   1. Open the **North American Sales** dashboard in the Power BI service.
+   2. Hover over the **Monthly Customers** KPI tile, click the ellipsis (...) in the upper-right corner, and select **Manage alerts**.
+   3. In the **Manage alerts** pane, click **Add alert rule**.
+   4. Edit **Alert title**, **Condition**, and **Threshold** and ensure that the **Send me email, too** checkbox is selected.
