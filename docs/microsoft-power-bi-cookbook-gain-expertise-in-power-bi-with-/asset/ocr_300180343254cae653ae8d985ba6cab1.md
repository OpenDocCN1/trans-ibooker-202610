# How to install Analyze

+   1. In the upper-right corner of any Power BI service page, click the ellipsis and then choose **Download** and then **Analyze in Excel updates**.
+   2. On the splash screen that appears, choose the **Download** button.
+   3. Once the file downloads, choose the **Open file** link or run the file from your **Downloads** folder.
+   4. The installation wizard for **Microsoft Analysis Services OLE DB Provider Setup** launches. Click the **Next** button.
+   5. Accept the licensing terms and click the **Next** button.
