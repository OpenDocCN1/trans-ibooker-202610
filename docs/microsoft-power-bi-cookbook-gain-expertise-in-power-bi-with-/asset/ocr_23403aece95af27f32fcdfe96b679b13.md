# How to do it...

To implement this recipe, do the following:

+   1. With the Analysis Services resource open, click **Overview** and obtain the **Server name**.

![](bbox=[0.2, 0.431, 0.867, 0.523])

+   2. If multiple models are on the server, confirm the model name and optionally the perspective to connect to. All models on the AAS server are also listed in the Azure portal.
+   3. Open a new Power BI Desktop file, click on **Get Data**, and choose **Analysis Services**.
+   4. Enter or paste the server name and the database (the name of the model) and press the **OK** button:
