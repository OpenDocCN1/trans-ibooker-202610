

## 使用 Teams 分发内容

Microsoft Teams 是一个统一的协作和通信平台，将视频会议、电话呼叫、文件存储、持久化工作场所聊天和应用程序集成组合到统一的界面中。Teams 是 Microsoft 365 办公生产力套件的一部分，与 Word、PowerPoint、Excel 和 SharePoint Online 原生集成。此外，功能扩展提供了与第三方应用程序集成的支持。

近年来，Microsoft Teams 经历了爆炸式增长，尤其是在 2020 年疫情期间。事实上，在 2020 年 3 月至 6 月之间，Microsoft Teams 增长了近 900%。对于超过五十万家组织而言，Microsoft Teams 已成为每天用于推动沟通和协作的基本工具。因此，微软最近发布了 Power BI 与 Teams 之间的集成，使 Teams 能够作为仪表板、报表和其他内容的分发渠道也就不足为奇了。

本食谱演示如何利用 Teams 分发和协作 Power BI 内容。

### 准备工作

为准备本食谱，请执行以下步骤：

1. 确保您已将报表、仪表板或应用发布到 Power BI 服务。
2. 打开 Microsoft Teams 并加入或创建一个团队。

您现在已准备好完成本食谱。

### 如何操作...

要实现本食谱，请使用以下步骤：

1. 在 Teams 中，选择导航窗格中的 **Teams**，然后选择团队中的一个频道。
2. 在团队的标题区域（选项卡）中，选择加号图标 (+) 以 **添加选项卡**。
   ![](img/0b67f3eabca89f1e12f62eac78fb9ffb_584_0.png)
   图 12.51： 在 Microsoft Teams 中添加选项卡
3. 在添加选项卡对话框中，搜索 Power BI 并选择 Power BI 应用。
   图 12.52： 在 Microsoft Teams 中添加 Power BI 选项卡
4. 在 Power BI 对话框中，从工作区、应用或共享给我中选择一个仪表板或报表。
   图 12.53： 向 Teams 添加 Power BI 内容
5. 单击保存按钮。
6. 报表或仪表板名称将作为团队的选项卡添加。
7. 如果选中了 **在此选项卡上向频道发帖**，则会在 **常规**频道的 **发帖**选项卡中出现一条帖子。

恭喜您将第一个 Power BI 报表发布到 Teams！

### 工作原理...

在 Teams 中添加 Power BI 选项卡不会像 **发布到网络**或在 SharePoint Online 中嵌入那样生成嵌入代码，而是利用 Teams 的功能扩展功能与 Power BI 集成。此外，在 Teams 中创建 Power BI 选项卡并不会授予通过 Teams 分发的仪表板或报表的权限。给定团队的成员必须通过 Power BI 服务获得 Power BI 内容的权限。

### 更多内容...

在 Microsoft Teams 中向团队添加 Power BI 选项卡并不是 Power BI 与 Microsoft Teams 集成的唯一方式。还存在另外两种集成，**在 Teams 中聊天**和将 Power BI Windows 10 应用固定到 Teams 导航窗格。要了解这些额外集成的工作方式，请执行以下步骤：

1. 登录 Power BI 服务并打开仪表板、报表或应用。
2. 在标题栏中，单击 **Chat in Teams**。
   ![](img/0b67f3eabca89f1e12f62eac78fb9ffb_586_0.png)
3. 搜索团队或频道以共享 Power BI 内容的链接。
   ![](img/0b67f3eabca89f1e12f62eac78fb9ffb_586_1.png)
4. 单击 **Share** 按钮。
5. 包含指向 Power BI 内容的链接的帖子将被发布到所选团队和频道的 **发帖**选项卡。
   ![](img/0b67f3eabca89f1e12f62eac78fb9ffb_587_0.png)
   图 12.56： Power BI 报表链接共享到 Teams 发帖选项卡
6. 在 Teams 中，从导航窗格中选择省略号 (...) 并搜索 *Power BI*。
   ![](img/0b67f3eabca89f1e12f62eac78fb9ffb_587_1.png)
   图 12.57： 在 Teams 中添加 Power BI 应用
7. 选择 Power BI 应用，然后单击 **Add** 按钮。

## 13 将 Power BI 与其他应用程序集成

Power BI 工具和服务包括 Power BI Desktop、Power BI Web 服务和 Power BI 移动应用程序本身就构成了现代、强大的商业智能和分析平台。Power BI Premium 进一步扩展了 Power BI 解决方案的可扩展性和部署选项，使组织能够通过 Power BI 服务中的应用、嵌入到自定义应用程序中、本地 Power BI 报表服务器或这些分发选项的组合，将 Power BI 内容交付给大量用户。

然而，许多组织要么已经在其他工具中拥有广泛的自助式和企业 BI 资产和技能，例如 Excel、Analysis Services（Azure Analysis Services（AAS）或 SQL Server Analysis Services（SSAS））和 SQL Server Reporting Services（SSRS），要么有兴趣将这些工具的独特功能作为其 Power BI 解决方案的一部分。例如，组织可能会选择保留许多现有的 Excel 报表在 Excel 中，而不是将它们转换为 Power BI 报表，因为 Excel 具有立方体公式等独特功能。同样，一些组织可能会继续使用现有的 AAS 资源用于语义模型，而不是在一段时间内将这些模型迁移到 Power BI Premium，因为这些模型存在重大的报表依赖关系。此外，鉴于 Power BI 数据集的许多附加功能和优势，拥有基于旧版 Excel 的数据模型（以前称为 Power Pivot）的组织可能会选择将这些资产迁移到 Power BI。

本章中的食谱重点介绍了 Power BI 与 SSRS、Analysis Services、Excel、PowerPoint、Power Apps 和 Power Automate 之间的强大集成点。在本章中，我们将介绍以下食谱：

- 集成 SSRS 和 Excel
- 从 Excel 的 Power Pivot 迁移到 Power BI
- 在 Excel 中访问和分析 Power BI 数据集
- 将 Power BI 报表构建到 PowerPoint 演示文稿中
- 连接到 Azure Analysis Services
- 与 Power Automate 和 Power Apps 集成
- 利用 Dataverse 和 Dynamics 365
- 连接 Dynamics 365 Finance and Operations 和 Power Platform

在本章结束时，您将对 Power BI 如何工作以及如何与其他 Microsoft 技术集成有坚实的理解。

### 集成 SSRS 和 Excel

Power BI Desktop 是发布到 Power BI 服务的内容以及嵌入到自定义应用程序中的 Power BI 报表可视化的主要报表创作工具。然而，对于许多组织而言，使用 SSRS 和 Excel 构建的现有或遗留报表工作负载的大部分必须维护。在许多情况下，现有的 SSRS 和 Excel 报表可以转换为现代 Power BI 报表和仪表板，但 Power BI 并不是这些其他工具所有功能和用例的完全替代品。除了通过 Power BI Premium 支持分页报表（即 SSRS 报表）和针对 Power BI 数据集构建的 Excel 报表的刷新外，Power BI 服务还提供进一步的方法将来自 Excel 和 SSRS 的内容集成到 Power BI。此外，鉴于 Power BI、Excel 的 Power Pivot 和 Analysis Services 的通用数据库引擎和 DAX 语言，BI 团队可以通过编写自定义 DAX 查询来完全控制在 SSRS 和 Excel 中呈现的报表。

本食谱包含两个从 SSRS 和 Excel 创作和发布内容到 Power BI 的示例。
