

## 前言

如今，我们通常使用论坛和博客上找到的各种信息来学习新材料，并依赖我们遇到的信息。取决于在这些文章上花费的时间，你经常会跳过一些基本概念，即使是经验丰富的程序员在发现做某事的新且更简单的方法时也会感到惊讶。本书涵盖了 Liquid 的基础知识以及一些高级概念，这些概念将为你将 Liquid 添加到你的作品集铺平正确的道路。

Liquid 是一个由 Shopify 联合创始人兼首席执行官 Tobias Lütke 创建的开源项目。作为一种模板语言，Liquid 变量将 Shopify 商店的数据连接到我们主题中的静态 HTML 内容，使我们能够将静态模板转变为完全动态且功能强大的电子商务商店，产生令人印象深刻的结果。自 2006 年以来，Liquid 不断成长和演进。今天，许多不同的 Web 应用程序都依赖于 Liquid，Shopify 就是其中之一，这表明对 Liquid 的需求与日俱增。

我们可以将本书分为三个主要部分。在第一部分中，我们将熟悉有关 Shopify 的一些基本信息，了解 Shopify 界面及其主题结构，并开始熟悉 Liquid。尽管这些主题可能听起来并不那么重要，但它们将使我们能够在基础层面理解 Shopify 和 Liquid。通过理解这些基础知识，我们将学会如何面对这些领域中不可避免且频繁出现的问题。

本书的第二部分将完全致力于 Liquid 的核心功能，如果没有这些功能，我们将无法创建许多奇妙复杂的组件。虽然我们不会介绍存在的每个对象、标签和过滤器，但我们将了解 Liquid 核心的本质，并关注一些常用的开发技术。

本书的第三部分也是最后一部分将带我们进入幕后，在那里我们将学习如何使用 JSON 来创建易于配置的选项，这些选项是 Shopify 电子商务商店的灵魂。最后，我们将学习如何使用 Shopify Ajax API 结合前面介绍的 Liquid 功能来创建强大的功能并使我们的代码更具动态性。

- 第 5 章，使用过滤器深入 Liquid 核心，是 Liquid 核心的关键主题，这将使我们能够创建或操作不同类型的数据，这是一个引人注目的功能。有了 Liquid 过滤器，我们将更深入地了解 Liquid 的工作原理以及我们如何轻松输出动态数据，例如图像 HTML 标签、计算产品折扣以及处理字体变体。

- 第 6 章，配置主题设置，帮助我们了解 JSON 设置以及为什么这些文件对我们如此重要。稍后，我们将以更直接的方式转向该主题，通过学习我们可以在 JSON 文件中使用的设置类型以及基本输入设置和专用输入设置之间的区别。

- 第 7 章，使用静态和动态区块，将帮助我们理解区块是什么以及如何使用它们通过 Shopify 主题编辑器创建易于配置的内容。我们将学习如何创建静态和动态区块及其对应的区块，这些区块在主题开发中发挥着相当大的作用。最后，我们将更深入地了解新引入的 JSON 类型模板，以及我们如何将它们与元字段结合起来，在任何页面上创建真正独特且易于配置的内容。

- 第 8 章，探索 Shopify Ajax API，将带我们了解 Shopify Ajax API 并解释其要求、限制和可能的用例。此外，我们将学习如何向 Shopify API 发出不同类型的请求。我们将学习如何检索产品信息、将任意数量的产品添加到购物车会话中，并读取购物车的当前内容。最后，我们将学习如何通过 Shopify API 发出请求并检索必要的信息以创建产品推荐和预测搜索功能。

- 附录，常见问题，包含额外的指南、建议以及刚开始进入 Shopify 和 Liquid 世界的开发人员常见问题的答案。

- 测评包含所有章节问题的答案。

```
