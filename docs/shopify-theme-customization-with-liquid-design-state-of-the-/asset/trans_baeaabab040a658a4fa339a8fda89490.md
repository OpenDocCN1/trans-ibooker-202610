

注意我们在条件语句两端添加的连字符是如何移除两侧空白的。然而，我们只在`collection.title`的闭合括号上添加了一个连字符，以移除其右侧的空白。如果我们还在左侧添加一个连字符，就会移除分隔动词“is”和集合名称的那个空格。

## 控制Liquid的流程

在前几章中，我们见到了一些控制流标签，例如`if`、`and`和`or`的实际运用；现在我们将进一步深入这个主题，了解所有类型的控制流标签以及如何使用它们。控制流标签是一种Liquid编程逻辑，它通过允许我们在特定条件下选择应执行哪个代码块来告诉我们的Liquid代码该做什么。我们可以将控制流标签分为四组：

+   - `if/else/elsif`
+   - `and/or`
+   - `case/when`
+   - `unless`
