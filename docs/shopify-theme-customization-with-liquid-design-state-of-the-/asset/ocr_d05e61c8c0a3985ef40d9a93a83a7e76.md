Notice how the hyphens we added on both ends within our conditional has removed the whitespace on both sides. However, we have only added one hyphen on the closing bracket of the `collection.title` to remove the empty whitespace on its right side. If we were to add a hyphen to the left side as well, we would have removed the space separating the verb "is" and the collection name.
