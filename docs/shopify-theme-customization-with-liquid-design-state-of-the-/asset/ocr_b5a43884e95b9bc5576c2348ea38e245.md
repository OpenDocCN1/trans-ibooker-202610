# The url input

The url type input provides us with a special URL entry field where we can either manually enter the external URL or use a series of dropdowns to select the path to one of the following resources:

+   - Articles
+   - Blogs
+   - Collections
+   - Pages
+   - Products
+   - Policies

We can also include a link to sites outside of our store by simply pasting the URL and consequently clicking on the link inside the drop-down menu confirming the selection:
