# ### 5.2.4 Implementing queries with HTTP GET

The loyalty program microservice can handle the commands it needs to handle, but it can’t answer queries about registered users. Remember that the loyalty program only needs one endpoint to handle queries. As mentioned previously, the endpoint handling queries is an HTTP GET endpoint at URLs of the form “/users/{userId},” and it responds with a representation of the user. This endpoint implements both queries in figure 5.3.

```
**Listing 5.8 GET endpoint to query a user and their loyalty point by user ID**

```csharp
namespace LoyaltyProgram.Users
{
    using System;
    using System.Collections.Generic;
    using Microsoft.AspNetCore.Mvc;

    [Route("/users")]
    public class UsersController : ControllerBase
    {
        private static readonly Dictionary<int, LoyaltyProgramUser>
            RegisteredUsers = new();

        [HttpGet("{userId:int}")]
        public ActionResult<LoyaltyProgramUser> GetUser(int userId) =>
            RegisteredUsers.ContainsKey(userId)
                ? (ActionResult<LoyaltyProgramUser>) Ok(RegisteredUsers[userId])
                : NotFound();

    }
}
