# A.5 Azure CLI

In this book, I use Azure to set up a small Kubernetes cluster that I can deploy the microservices to as an example of a production environment. To follow along with that, you will need an Azure account and the Azure CLI.

To create an Azure account go to https://azure.microsoft.com/en-us/free/. To get the Azure CLI, head to https://docs.microsoft.com/en-us/cli/azure/install-azure-cli and follow the installation instructions for your platform. When you have installed the Azure CLI, you can log the CLI into your Azure account by running `az login` in your shell.

Now that you have an IDE, the `dotnet` command-line tool, a tool for working with HTTP requests, Docker, Kubernetes, and the Azure CLI, you’re all set to code along with the examples throughout the book.
