Dapper is a simple tool that provides some convenient extension methods on IDbConnection to make working with SQL in C# easier. It also provides some basic mapping capabilities. For instance, when the rows returned by a SQL query have column names equal to the property names in a class, Dapper can automatically map to instances of the class.

Dapper doesn’t try to hide the fact that you’re working with SQL, so you see SQL strings in the code. This may feel like a throwback to the earliest days of .NET. I find that as long as I’m working with a simple database schema—as I usually am in microservices—the SQL strings in C# code aren’t a problem.

Writing a shopping cart to the database is also done through Dapper. The implementation is the following method in ShoppingCartStore.
