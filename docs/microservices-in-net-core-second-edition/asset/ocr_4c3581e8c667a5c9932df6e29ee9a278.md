Tells HttpClient to perform the HTTP GET asynchronously

This is pretty straightforward. The only thing to note is that by executing the HTTP GET request asynchronously, the current thread is freed up to handle other things in the shopping cart while the request is processed in the product catalog. This is good practice because it preserves resources in the shopping cart microservice, making it a bit less resource intensive and more scalable.

For ASP.NET to be able to inject the HttpClient in ProductCatalogClient we need to register ProductCatalogClient as typed http client, which we do by adding this to the ConfigureServices method in Startup:

```
services.AddHttpClient<IProductCatalogClient, ProductCatalogClient>();
```

Now ASP.NET can resolve ProductCatalogClient, which can in turn be injected into other types—the ShoppingCartController, for instance.
