This approach clearly doesn’t work for all situations. If a user is waiting for a response, it makes no sense to retry an hour later, because the user will have given up long before, so the software should also give up and give a degraded response sooner. On the other hand, if the request is initiated based on something the system does on its own—for example, as part of handling an event—you can often wait a long time.
