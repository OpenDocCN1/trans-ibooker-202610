

## .NET 中的微服务

第二版

Christian Horsdal Gammelgaard

![](img/608267d7803dc57a1a896ad121f37868_0_0.png)

简而言之，微服务是一个非常聚焦的服务，具有以下特征：

- 微服务负责单一能力。
- 微服务可单独部署。
- 微服务由一个或多个进程组成。
- 微服务拥有自己的数据存储。
- 一个小型团队可以维护几把手微服务。
- 微服务可替换。

你可以用这两种方式使用这些特征：指导微服务的设计和实现，并在看到时识别微服务。
