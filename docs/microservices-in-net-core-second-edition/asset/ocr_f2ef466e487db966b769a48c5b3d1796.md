A service-level test for the loyalty program microservice could do the following:

+   1. Send a command to create a user.
+   2. Wait for the loyalty program microservice to query a mock special offer microservice for events and then receive a hardcoded event about a new special offer.
+   3. Record any commands sent to the notifications microservice and assert that a command for a notification to the new user about the new special offer was sent.

When a test like this passes, you can have confidence that important aspects of the loyalty program microservice work. When it fails, you know that the problem is within the loyalty program itself.
