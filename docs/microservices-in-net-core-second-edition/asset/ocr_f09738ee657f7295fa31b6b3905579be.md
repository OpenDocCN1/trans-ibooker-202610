Call the method to process the events in this batch. ProcessEvents also updates the start variable.

This programs is called on a schedule and handles reading one batch of events. Once a batch has been read, each event must be processed with code like the following.

# Listing 7.6 Handling a batch of events

```
private async Task ProcessEvents(string rawEvents)
{

        JsonSerializer.DeserializeAsync<SpecialOfferEvent[]>(content)
```
