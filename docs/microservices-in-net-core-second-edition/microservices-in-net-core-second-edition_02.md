# 第 1 部分

## 微服务入门

第一部分将解释什么是微服务以及为什么你应该关注它。我将首先讨论六个特征，你可以用它们来识别和指导你的微服务设计。在此过程中，我们还会探讨微服务的收益与成本。

在第 1 章接近结尾时，我会带你快速了解全书使用的技术栈；该技术栈由 .NET、ASP.NET 和 ASP.NET MVC Web 框架组成。第 2 章将进入构建第一个微服务的示例。你会看到开始所需的成本有多低，并开始领略 ASP.NET 的优势。第 3 章展示如何将第 2 章的微服务容器化，以及如何将其部署到 Azure 中的 Kubernetes。

到第 1 部分结束时，你将拥有第一个运行在云端的微服务。
