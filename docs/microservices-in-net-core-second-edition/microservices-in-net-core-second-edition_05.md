# 第 2 部分：构建微服务

在本书的这一部分，你将学习如何设计和编码一个微服务。这些各式各样的话题都围绕着如何设计和编码出良好、可维护、可靠的微服务：

- 第 4 章解释了如何将一个系统拆分组合为一组内聚的微服务。你将学到三条经验法则，帮助你判断每个微服务中应该包含什么。
- 第 5 章展示了微服务如何协作以向最终用户提供功能。你还会了解三类协作方式以及何时使用它们。
- 第 6 章探讨了在微服务系统中数据应该放在哪里，以及哪些微服务应该对哪些数据负责。
- 第 7 章教你一些简单的技术，使微服务系统比原本更加健壮。利用这些技术，你可以创建一个在网络故障和单个微服务崩溃时仍能持续运行的系统。
- 第 8 章转向测试。你将学习如何为微服务系统创建有效的自动化测试套件，从广泛的系统级测试到聚焦的单元测试，一应俱全。

到第 2 部分结束时，你将知道如何设计微服务、如何使用 .NET 编写它们，以及如何使用 Kubernetes 运行它们。
