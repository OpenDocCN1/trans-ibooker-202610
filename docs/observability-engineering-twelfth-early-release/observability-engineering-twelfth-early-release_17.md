# 第四部分. 大规模的可观测性

在 [第三部分] 中，我们专注于克服入门障碍以及有助于改变社会和文化实践的新工作流程，以便为你的可观测性采用计划提供动力。在本部分中，我们将检查采用光谱另一端的情况：当可观测性采用成功并在大规模实践时会发生什么？

就可观测性而言，“大规模”可能比大多数人想象的更大。作为一个粗略的衡量标准，当每天生成的遥测事件达到数亿高位或数十亿低位时，你可能就存在规模问题。本章探讨的概念在以规模运行可观测性解决方案时感受最强烈。然而，这些经验教训对走上可观测性道路的任何人来说通常都有用。

[第 15 章] 探讨了是否购买或构建可观测性解决方案的决定。在足够大的规模下，随着商业解决方案的账单增长，团队会开始考虑是否可以通过自己构建可观测性解决方案来节省更多。本章提供了如何最好地处理该决定的指导。

[第 16 章] 探讨了数据存储必须如何配置才能满足可观测性工作负载的需求。为了实现迭代和开放式调查的功能要求，必须满足几个技术标准。本章以 Honeycomb 的 Retriever 引擎为模型，展示了如何满足这些要求。

[第 17 章] 探讨了如何减少大规模管理大量遥测数据的开销。本章介绍了几种技术，以确保高保真度的可观测性数据，同时减少必须捕获和存储在后端数据存储中的事件总数。
