# 第五部分：传播可观测性文化

在[第四部分]中，我们重点解决了大规模实践可观测性时面临的挑战。在最后的这一部分中，我们将探讨可用于推动整个组织采用可观测性的文化机制。

可观测性通常始于组织中的某个特定团队或业务部门。要传播可观测性文化，团队需要来自整个业务中各个利益相关者的支持。本节详细介绍了这些支持如何汇聚在一起，以帮助推广可观测性实践。

[第 19 章] 介绍了实际成果、组织挑战，以及如何通过审视采用可观测性实践背后的业务收益来构建商业案例。

[第 20 章] 探讨了工程团队之外的团队如何利用可观测性工具来实现自己的目标。帮助相邻团队学会理解和使用可观测性数据来实现其目标，将有助于建立盟友，推动您的可观测性采用计划向前发展。

[第 21 章] 研究了行业领先的数据，这些数据可以帮助您了解和衡量在前几章中阐述的实现可观测性收益方面的进展。该模型可作为粗略的指南，而非僵化的处方。
