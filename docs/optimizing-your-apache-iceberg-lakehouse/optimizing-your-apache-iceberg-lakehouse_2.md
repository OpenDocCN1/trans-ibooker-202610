## 关于作者

**Lester Martin** 是一位经验丰富的开发者倡导者、培训师、博主、开发者和架构师，在软件开发和数据工程领域拥有三十年的经验。他在过去十年中专注于使用 Trino、Iceberg、Hive、Spark、Flink、Kafka、NiFi、NoSQL 数据库以及当然的经典 RDBMS 进行数据管道和数据湖分析。他在职业生涯的各个阶段都使用过 SQL。Lester 是一名多语言程序员，但在 Java 和 Python 中感觉最有成效。他精通各种 Dataframe API。自 2022 年以来，Lester Martin 一直就 Apache Iceberg 提供咨询、教学、撰写和演讲，是优化 Iceberg 湖仓的专家。
