To change the cost of an interface manually, use the following configuration:

```
Router(config)# interface type [slot_#/]port_#
Router(config-if)# ip ospf cost cost_value
```

Notice that the cost is assigned within an interface. This value can range from 1 to 65,535. Note that each vendor might use a different calculation to come up with a cost value.

![](bbox=[0.14, 0.62, 0.24, 0.68])

**CAUTION** It is very important that the costs for a link match for every router on a given segment. Mismatched cost values on a segment can cause routers to run the SPF algorithm continually, greatly affecting the routers’ performance.
