**TIP** VTP is a Cisco-proprietary protocol that traverses trunks. It is used to create a consistent VLAN configuration across all switches in the same domain. A VLAN can be added on one switch and propagated to other switches; however, switches will ignore VTP messages from other VTP domains.

# VTP Modes

When you are setting up VTP, you can choose from three different modes for your switch’s configuration:

+   - Client
+   - Server
+   - Transparent

Table 10-1 shows the differences between these VTP modes.

| Description | Server | Client | Transparent |
|---|---|---|---|
| Can add, modify, and delete VLANs | Yes | No | Yes |
| Can generate VTP messages | Yes | No | No |
| Can propagate VTP messages | Yes | Yes | Yes |
| Can accept changes in a VTP message | Yes | Yes | No |
| Default VTP mode | Yes | No | No |
| Saves VLANs to NVRAM | Yes | No | Yes |
