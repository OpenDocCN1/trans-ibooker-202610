Figure 18-1 North-bound and south-bound APIs

APIs use a client/server architecture in which each execution requires a client and a server. The client is the component receiving the data, and the server is the component sending the data. So with the north-bound API, the server is the application and the client is the controller. With the south-bound API, the server is the controller and the client is the network device.
