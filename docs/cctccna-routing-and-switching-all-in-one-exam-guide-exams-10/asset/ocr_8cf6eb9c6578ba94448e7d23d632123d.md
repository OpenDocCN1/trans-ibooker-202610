When you look at the configuration file, you can see that all of the passwords, except the secret, are stored in plain text. This means that if someone can gain physical access to your router, he or she can view the configuration file and see the passwords you are using. From a security point of view, this is a very bad configuration!

You can encrypt all passwords in your Cisco configuration files with a quick, simple command, **service password-encryption**:

```
VAN-R1#config term
VAN-R1(config)#service password-encryption
VAN-R1(config)#do write
```
