**EXAM TIP** For the exam, you’ll need to remember that FF02::1 is a multicast address that represents all IPv6 devices (similar to a broadcast address in IPv4). FF02::2 is a multicast address that represents all routers on an IPv6 segment or VLAN. Also note that all multicast addresses start with FF in IPv6.
