To configure the router as a DHCP relay agent, use the following:

```
Router(config)# service dhcp
Router(config)# interface g0/0
Router(config-if)# ip helper-address DHCP_server_IP_address
```

The service dhcp command is enabled by default—you need to execute this only if the DHCP service has been manually disabled. You then navigate to the interface you want to configure to listen for DHCP messages.
