# Installing FTP Server Software

Although you can use any FTP server software to back up your Cisco configuration or IOS image files, the Cisco CCT certification objectives reference FileZilla as the example software to use. FileZilla has FTP server software that you can download and install from https://filezilla-project.org/. Note that FileZilla also has FTP client software, but we are interested in the server software, so we can copy our Cisco IOS to the FTP server.
