Displays all of the IP routing protocols that are configured.

Displays the routes in the routing table.

Displays the collection of OSPF links learned from other OSPF routing devices.

Displays the router ID, the ID of the DR and BDR, timer values, the number of neighbors and the number of adjacencies.

Displays all of your router's OSPF neighbors.

Displays the OSPF packets as they are sent or received.
