NOTE The main disadvantage of dual stacking on a segment is that devices configured using only one stack must forward their traffic to a dual stacked device, such as a router, which must then forward the traffic back to the same segment using the other stack. This is an inefficient use of bandwidth, but it does enable devices using both protocol stacks to coexist on the same network segment.
