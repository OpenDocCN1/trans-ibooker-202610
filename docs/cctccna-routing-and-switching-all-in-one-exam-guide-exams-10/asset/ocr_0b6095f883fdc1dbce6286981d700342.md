# The TCP/IP Model

The TCP/IP model, also referred to as the TCP/IP Model, is a four-layer model similar in concept to the seven-layer OSI Reference Model. The four layers of the TCP/IP model map to the seven layers of the OSI version, but the TCP/IP model combines multiple layers of the OSI model, as shown in Figure 3-1. Several protocols direct how computers connect and communicate using TCP/IP within the TCP/IP protocol suite, and each protocol runs on different layers of the TCP/IP Model.
