# Automation and Programmability

In this chapter, you will

+   - Learn about the difference between traditional network management and controller-based automation
+   - Learn about software-defined networking (SDN) and the Cisco Digital Network Architecture (DNA)
+   - Learn about data exchange formats such as XML and JSON

Our last chapter is a new topic for the Cisco CCNA exam and provides an introduction to automation and software-defined networking (SDN). I am sure that SNA will be a big focus in future versions of the CCNA exam; for the current version of the exam, however, you just need to know the purpose of automation and the related concepts.
