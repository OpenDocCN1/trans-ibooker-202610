# Calculate the Broadcast Address

The broadcast address is used to send messages to all systems on the network. The broadcast address is not to be assigned to a system on the network, but it is an address you should be familiar with. To calculate the broadcast address, you set all host bits (the bits to the right of the bolded subnet bits) to 1 and then convert the entire address to decimal, as shown here:
