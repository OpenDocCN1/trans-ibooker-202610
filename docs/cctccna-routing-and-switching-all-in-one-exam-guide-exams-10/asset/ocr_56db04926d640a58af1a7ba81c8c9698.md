+   3. Configure the host-based firewall on the TFTP server to allow UDP port 69 traffic through to the system (that is the port used by TFTP which your firewall may block by default).
+   4. Verify that the TFTP software is running.

After downloading the software, you can install it on a system such as a server, desktop, or laptop—wherever you would like to store a backup of the configuration files and the Cisco IOS. After installing the software, you should ensure that you configure your host-based firewall to allow UDP port 69 traffic through to the system.

Before trying to back up the configuration of a device, or the IOS, to the newly installed TFTP server, verify that the server software is running. You can launch the SolarWinds TFTP server software by clicking the Start button and then typing **TFTP**. You should see the program called TFTP Server. Choose the program to launch it.
