You should know how to identify the console port on a Cisco device, which is usually labeled “Console” or “Con0.” Figure 6-3 displays a close-up of the console port. Notice the USB port to the left of the console port; this is a USB serial port, a five-pin mini-USB type B port that you can use as the console connection instead of using the traditional console port (the RJ-45 type of console port). Also notice the LEDs labelled “EN,” for “enabled”. One LED lights up for whichever port you are using to console into the device.
