# Table 6-3 Fourth Hex Character Configuration Register Values

+   2. It examines the configuration file in NVRAM for **boot system** commands, which tell the bootstrap program where to find the IOS. These commands are shown shortly.
+   3. If no **boot system** commands are found in the configuration file in NVRAM, it uses the first valid IOS image found in flash.
+   4. If no valid IOS images are in flash, it generates a TFTP local broadcast to locate a TFTP server (this is called a *netboot* and is not recommended, because it is very slow and not very reliable for large IOS images).
+   5. If no TFTP server is found, it loads the Mini-IOS in ROM (RXBOOT mode).
+   6. If there is a Mini-IOS in ROM, it loads the Mini-IOS and enters RXBOOT mode; otherwise, the router either retries to find an IOS image or loads ROMMON and goes into ROMMON mode.
