Once the product is installed, the administration interface is launched automatically (see Figure 8-3). Enter the IP address of the FTP service (localhost by default), the port of the administration site (14147 by default), and the password (which has not been configured yet), and then click Connect.

Figure 8-3 FileZilla FTP server software installation

Once the software is launched, you can modify the configuration of the server software by choosing Edit | Settings. Within the settings, you can configure the port that FTP is using (TCP port 21 by default), and information such as the maximum number of users that can connect at a time and the welcome message will displayed after a connection.

You can also manage a list of usernames and passwords that are authorized to connect to the FTP server by choosing Edit | Users.
