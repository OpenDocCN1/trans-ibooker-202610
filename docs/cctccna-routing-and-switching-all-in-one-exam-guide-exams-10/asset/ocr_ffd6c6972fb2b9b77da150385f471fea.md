# Rapid Spanning Tree Protocol

The 802.1d standard was designed back when waiting for 30 to 50 seconds for layer 2 convergence wasn’t a problem. However, in today’s networks, this can cause serious performance problems for networks that use real-time applications, such as voice over IP (VoIP) or video. To overcome these issues, Cisco developed proprietary bridging features called PortFast (discussed earlier), UplinkFast, and BackboneFast. The problem with these features, however, is that they are proprietary to Cisco.

RSTP is an IEEE standard, defined in 802.1w, which is interoperable with 802.1d and an extension to it. With RSTP, there are only three port states:

+   - Discarding
+   - Learning
+   - Forwarding
