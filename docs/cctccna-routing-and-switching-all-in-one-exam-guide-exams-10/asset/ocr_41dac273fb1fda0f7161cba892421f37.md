When looking at this output, you can also see information about the WIC cards, below the device information, that are installed in the slots of the device. Notice the first WIC card is an HWIC CSU/DSU in slot 0/0, with a model number of HWIC-1DSU-T1 and a serial number on the card of FOC19092U9T. Note the second card is a HWIC-2T that is in slot 0/1 with a serial number of FOC14226262.

If you run the **show inventory** command and you do not see your new hardware module. it could be because the hardware module is not supported by the device or you are not running the minimum IOS version. Always check the documentation for the card (hardware module) to ensure you know the supported devices and minimum IOS version.
