As you can see from this output, CDP is enabled and generating updates every 60 seconds. The hold-down timer is set to 180 seconds. This timer determines how long a CDP neighbor’s information is kept in the local CDP table without seeing a CDP update from that neighbor. These are the default timers for CDP.
