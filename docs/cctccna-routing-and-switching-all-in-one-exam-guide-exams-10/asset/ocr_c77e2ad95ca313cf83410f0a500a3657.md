# Adding a Port Description

From time to time, you may want to add a description to the port that specifies what the port is used for. For example, if a web server is connected to a port, you may want to add a “Web Server” description label. The following code example labels the port “UpLink Port,” because it connects to another switch:

```
VAN-SW1>enable
VAN-SW1#config term
Enter configuration commands, one per line.  End with CNTL/Z.
VAN-SW1(config)#interface GigabitEthernet1/0/1
VAN-SW1(config-if)#description UpLink Port
```
