Another item to point out about this configuration is the two commands on the VTYs. The **login local** command specifies the use of the local database (**username** command) for authentication; this causes the IOS device to prompt for both a username *and* password for authentication. Without the **local** parameter, the IOS device prompts only for a password, using the **password** command on the line to do the authentication (this process was discussed in Chapter 7). SSH requires the use of both usernames and passwords. The **transport input ssh** command restricts access to the VTYs to SSH use only; by default, all forms of remote access, including telnet, are allowed.
