# Logging CLI Example

I’ll use the network example shown in Figure 13-9 to illustrate how to set up a router to send log messages to a syslog server (10.0.0.1). Here’s the configuration:

![](bbox=[0.12, 0.2, 0.88, 0.4])

Figure 13-9 Logging example

```
Router(config)# logging 10.0.0.1
Router(config)# logging trap 5
Router(config)# logging source-interface fa0/0
Router(config)# logging on
```

Notice that the router will send log messages only from level 5 and lower and that the router sources log messages from the FA0/0 interface.
