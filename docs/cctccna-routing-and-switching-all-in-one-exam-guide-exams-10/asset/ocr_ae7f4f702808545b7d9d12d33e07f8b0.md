# ICMP Header

The ICMP header is a very small header compared to the IP header and the TCP header. Figure 3-8 displays the ICMP header, and a listing of the fields follows:

![](bbox=[0.13, 0.53, 0.85, 0.7])

Figure 3-8 The ICMP header

+   - **Type** This 8-bit field indicates the ICMP type being used.
+   - **Code** This 8-bit field indicates the ICMP code being used.
+   - **Checksum** This 16-bit field is used to verify the integrity of the ICMP header.
