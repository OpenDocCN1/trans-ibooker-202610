To correct this problem, Cisco switches use STP, a loop prevention protocol that places one of the ports causing the loop in a blocking state. If a port is in a blocking state, it cannot send or receive any data until it is placed back in a forwarding state. STP will automatically detect when the other link goes down and will change the state to forwarding on the link that was originally blocked. You will learn more about STP in Chapter 10.
