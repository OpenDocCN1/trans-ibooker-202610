```
Router# show access-lists
Extended IP access list 100
  permit tcp 172.16.0.0 0.0.255.255 any established
    (189 matches)
  permit udp host 172.16.1.39 any eq domain
    (32 matches)
  permit icmp host 199.199.199.1 any
IPX sap access list 1000
  deny FFFFFFFF 7
  permit FFFFFFFF 0
```

First, notice that the router keeps track of matches on each statement. The first statement in ACL 100 has had 189 matches against it.

![](bbox=[0.14, 0.36, 0.24, 0.42])

TIP It is recommended that you put a deny ip any any command at the end of an extended ACL, even though the implicit deny statement will drop the traffic. By putting this statement at the end of your ACL, you can see the hit counts of all the denied traffic: since the implicit deny command is invisible, you can’t see the hit counts for it.

You can clear these counters with this command:

```
Router# clear access-list counters [ACL # or name]
```

![](bbox=[0.14, 0.68, 0.24, 0.74])

EXAM TIP For the Cisco CCNA exam, know the commands you can use to troubleshoot ACLs. Use the show ip interfaces command to see whether or not an IP ACL is applied to your router’s interfaces. Use the show access-lists command to view all of the ACLs on your router. The show ip access-list command lists only the IP ACLs on your router.
