+   Console port password: labconpass
+   Auxiliary port password: labauxpass
+   VTY passwords: labvtypass
+   5. Configure the following enable password and secret values:
+   Enable password: labenablepass
+   Enable secret: labenablesecret
+   6. Save your changes to NVRAM with the do write command.
+   7. Verify your configuration with the do show running-config command.
