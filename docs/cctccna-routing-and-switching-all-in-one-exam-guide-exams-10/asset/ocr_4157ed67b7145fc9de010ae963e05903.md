```
IOS# disable
IOS>
```

Again, by examining the prompt, you can tell that you are now in user EXEC mode.

**EXAM TIP** For the Cisco CCT certification exam, know the three different modes in IOS—user EXEC, privileged EXEC, and configuration modes—and what you can do in each mode. Also know that you use the **enable** command to go from user EXEC mode to privileged EXEC mode, use the **disable** command to go from privileged EXEC mode to user EXEC mode, and use the **exit** command to log out of the IOS device from either of these two modes.
