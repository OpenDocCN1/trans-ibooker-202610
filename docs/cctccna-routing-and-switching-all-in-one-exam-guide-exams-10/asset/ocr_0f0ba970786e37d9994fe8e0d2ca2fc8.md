**EXAM TIP** For the exam, remember how to create a one-to-one static translation with the **ip nat inside source static** and **ip nat outside source static** commands.

After you configure your translations, you must specify which interfaces on your router are considered to be on the inside and which are on the outside with the following configuration:

```
Router(config)# interface type [slot_#]/port_#
Router(config-if)# ip nat {inside | outside}
```

Specify **inside** for interfaces connected to the inside of your network and **outside** for interfaces connected to external networks, such as your ISP.
