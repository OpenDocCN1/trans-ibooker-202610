**EXAM TIP** For the CCNA exam, remember that you can use the **vlan** command to create a VLAN. Use the **switchport mode access** and **switchport access vlan** commands to assign a VLAN to an interface. Also remember that if an interface is configured as an access port, it cannot form a trunk. The **show vlan** command displays VLAN information: if the same interface is displayed for multiple VLANs, this interface is probably a trunk port.
