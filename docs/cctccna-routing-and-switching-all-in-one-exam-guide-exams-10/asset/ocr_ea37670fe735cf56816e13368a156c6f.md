In certain cases, for a specific destination, you might see three asterisks (***) in the output. Don’t be alarmed if you see this, since it can occur for a variety of reasons: for instance, there may be an inconsistency in how the source and destination devices have implemented traceroute, or the destination may be configured not to reply to these messages. However, if you continually find the same destination repeated in the output with these reply messages, this indicates a layer 3 problem starting with either this device or the device preceding it.

**TIP** If you have DNS lookups enabled on your IOS device (this is the **ip domain-lookup** command), IOS will attempt to resolve the IP address to a domain name before printing the output line for that device. If your traces seem to take a long time, DNS lookups is usually the culprit. You can disable DNS lookups on your IOS device with the **no ip domain-lookup** command.
