# FIGURE 7.4 Life Cycle of Private Equity Funds

# STAGE 1: INVESTMENT PERIOD

Capital calls are made (drawn down) and the proceeds are used to invest in portfolio companies.

# STAGE 2: VALUE CREATION

Portfolio manager attempts to create value in the portfolio companies through operational, financial, managerial, and other improvements.

# STAGE 3: HARVEST PERIOD

Portfolio manager exits underlying portfolio companies, often through a strategic sale or IPO, locking in value created, and returns capital to investors.
