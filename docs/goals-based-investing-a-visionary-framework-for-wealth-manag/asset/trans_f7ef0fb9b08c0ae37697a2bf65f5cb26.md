
- 6. 建议的二分化（机器人顾问和财富顾问）
- 7. 高净值投资者要求高度定制的建议
- 8. 超级团队的兴起
- 9. 财富顾问需要将其实践调整至适当规模
- 10. 顾问评级的引入

未来的顾问将比以往任何时候都更年轻、更多元化。他们将拥抱技术，并使其投资组合与宗旨保持一致。在未来10年里，财富管理行业将出现人口结构转变，女性、少数族裔和千禧一代顾问的增长率将是整个行业的两倍。这种增长将由客户要求看到更多与自己相似的顾问，以及由白人男性主导的实践老龄化所推动。随着财富顾问继续采用团队结构来满足高净值投资者的需求，他们将寻求团队内更大的多元化，以更好地匹配其客户群。

年轻的顾问将认识到技术在提供规模和效率方面的重要性，并不会将其视为其价值主张的威胁。大型财富管理公司仍将大力投资技术，因为其利润率继续承受压力。针对高净值投资者的高度定制和个性化建议，与针对较小客户的更多数字化建议服务（财务规划、资产配置、直接指数化）之间，将出现更明显的二分化。

基于目标的投资将成为常态，技术将发展到能够更高效地同时建立并跟踪多个目标的进度。技术还将使投资者偏好在投资组合中的对齐更加容易，无论这意味着纳入可持续性筛选还是直接指数化：让投资者创建自己的股票篮子。女性和千禧一代将继续拥抱可持续性和直接指数化，随着利益获得更普遍的认可，其吸引力将扩展到其他群体。

技术进步和对顾问经济模式的压力加大，将推动较小投资者转向机器人服务。这些客户可能只能接触到服务中心——没有财务顾问。大型财富管理公司已经朝这个方向发展。虽然技术提供了效率，但这些公司无法负担付钱给顾问来提供商品化解决方案。许多研究表明，技术将意味着未来几年顾问数量大幅减少，许多顾问将在没有充分继任计划的情况下退休。

随着技术支持的解决方案让财富顾问能够更高效地服务更多客户，高净值家庭将要求更大的定制和整合，以解决其复杂需求。为高净值投资者服务的财富顾问将需要拥有跨多个学科的专门团队：投资管理、税务管理、信托与遗产，以及集中头寸的处理。为了提供所需的深入支持，财富顾问将需要*将其实践调整至适当规模*，确定他们能够妥善处理多少高净值家庭。在大型券商将有更多超级团队（六人或以上团队），许多最终将独立，因为他们会超越这种模式。

顾问在绩效、服务、投资专业知识和实践多样性等一系列问题上的评级将出现。投资者将能够扫描评级，为自己选择最佳顾问，并通过在几分钟内找到合适替代方案来更换顾问。这既可能是威胁，也可能是机会，这取决于顾问的评级如何以及他们如何适应这种不断变化的模式。

目前，几个组织对财富顾问和注册投资顾问（RIA）进行评级（Barron’s、Wealthmanagement.com、FT等），但公司通常付费以被列入并提名顾问，通常基于实践规模。客户满意度可能将推动未来评级，评论将通过类似于Yelp、Expedia或Groupon的应用程序，由客户和潜在客户提供。评级将关注对客户重要的事项：团队的专业水平、服务质量、资源深度、顾问的同理心以及实现投资者目标的能力。客户将基于体验而非公司付费参与来确定评级。

## 趋势与机遇

未来10年，以下几种趋势将显现：

- 1. 注册投资顾问（RIA）细分市场将继续增长。
- 2. 财富管理公司需要重新定义其价值主张。
- 3. 财富顾问将获得更大权力。
- 4. 新的经济模式（订阅制）将发展。
- 5. 新竞争者将出现。

越来越多的顾问将考虑独立执业，要么加入RIA集成商（Hightower、Focus Financial或Mercer Advisors），要么挂牌自立门户，以消除利益冲突和/或改善其经济模式。这些顾问将宣扬其独立性、受托身份以及在服务客户方面的利益一致性。注册投资顾问（RIA）也将认识到规模能带来效率，RIA整合将加速。

大型券商在服务高净值投资者方面不会过时，但需要在某种程度上重塑自身，强调其顾问教育计划、独特的投资渠道以及资源深度。他们将需要更加努力地留住优秀顾问，因为在未来几年里，天平将向顾问倾斜。如果财富顾问决定留在当前公司或独立执业，他们将有更多选择。投资者将继续质疑顾问的独立性和经济价值，对费用将有更严格的审查。

财富顾问、资产管理公司和财富管理公司之间的经济安排将面临压力，不同的定价模式将出现，以更好地使费用与价值保持一致。根据麦肯锡报告，“到2030年，多达80%的新财富管理客户希望以Netflix风格的模式获取建议——即数据驱动、超个性化、持续的，并且可能是按订阅制的。”

我不会对新竞争者的出现感到惊讶，包括来自金融服务行业之外的公司——Google、Amazon、Apple、Walmart——特别是针对市场低端。随着零售市场变得越来越商品化和技术化，非传统提供商可能更有能力成为强大的竞争者。科技巨头已表现出进入新市场的意愿，并理解技术在满足消费者需求方面的价值。如果零售投资者不重视顾问，并且一心寻找最低价格，那么想象Amazon能开发出更好的算法捕鼠器，并以相当大的折扣进入市场，这并非不可能。

## 投资机遇

从投资角度来看，过去几年里我们已经看到一些重大变化，并且可能会看到产品创新的延续。未来10年值得关注的投资趋势包括以下几点：

- 1. 私募市场将对更广泛的投资者群体更容易进入。
- 2. 对冲基金将重新出现，但定价将降低。
- 3. 可持续投资将变得更加主流。
- 4. 直接指数化和主动ETF将作为可行的投资选择出现。
- 5. 模型投资组合将继续演变，以满足顾问和投资者的需求。

如本书所述，私人公司远多于上市公司，我并不预料这一趋势会在短期内逆转。私人公司保持私有化的时间更长，因为存在替代资本来源，并且作为私人公司，它们能更好地执行长期战略，而非回应股东的短期需求。

随着高净值家庭需求的增长以及产品演进以满足该需求，更广泛的投资者群体将能够获得更多私募市场机会。认识到这一需求，大型资产管理公司和私募股权公司已开始通过喂养基金和注册基金向更广泛的投资者群体提供这些投资。在罕见的举措中，我们看到监管机构承认需要使这些有价值的投资更容易获得，包括在退休计划中。

随着私募市场投资的主流化，财富顾问需要主导教育投资者，让其了解这些投资在多元化投资组合中所起的作用，以及其结构性权衡。财富顾问的价值主张将继续从管理投资组合转变为担任四分卫和教育者，以适当权重将拼图的正确部分组合在一起。

在未来十年，随着市场波动、赢家和输家之间更大的差距以及地缘政治风险上升，对冲基金将重新流行起来。随着对冲基金采用多方面的方法回应市场状况，财富顾问需要了解策略之间的差异，并有效地组合它们以实现客户目标。然而，为了获得高净值投资者的更广泛接受，对冲基金策略需要降低费用和最低投资额。

注册基金在经典有限合伙结构和较低最低投资额可提供的更具流动性结构之间架起了一座桥梁。但如果它们无法提供与对冲基金和私募市场等效物相比的回报，投资者将寻找其他类型的投资。财富顾问应预期在提供更好的流动性时会看到一些权衡，管理人员需要向市场交付高质量产品。总体而言，第一代流动替代品是对冲基金策略的稀释版本，未能兑现其承诺。顾问和投资者未来必须对结构性权衡更加挑剔。
