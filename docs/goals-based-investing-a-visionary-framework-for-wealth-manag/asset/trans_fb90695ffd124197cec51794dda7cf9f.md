

底层持仓方面，财富顾问需要在教育投资者和构建一系列可持续投资选项方面发挥牵头作用。投资者开始理解，基于可持续性对证券进行筛选和加权有助于识别在环境、社会问题和董事会治理方面拥有健全政策的优秀公司。

随着零碎股份（fractional shares）的引入以及投资者日益增长的将其价值观体现在投资组合中的兴趣，直接指数化（direct indexing）在未来10年有望实现大幅增长。直接指数化让投资者可以定制其证券篮子以反映其观点。随着主动ETF的迅速增长，这两种工具可以帮助遏制许多主动管理者在过去十年左右经历的资金外流。我不确定它们是否对不断发展的ETF市场构成威胁，而是作为更昂贵的主动管理选项的替代品。这并非暗示主动管理的终结。我只是建议，通过为更多投资者提供更多选择，整个蛋糕可以做大。优秀的主动管理者将蓬勃发展，其他选项将取代较弱的选项。

模型提供商的数量、模型多样性以及模型在市场上的整体接受度将继续增长。能够帮助投资者实现目标的资产配置模型将对财富顾问及其客户变得越来越有价值，提供规模、效率和更好的结果。随着模型提供商建立更长的往绩记录和更多忠实采用者，这将成为资产管理者业务中一个大得多的部分。开放架构模型相对于仅专有模型应会获得市场份额，因为顾问要求“最好的最好”解决方案，且模型需要扩展底层投资的数量和类型。另类投资将是一个合乎逻辑的演进步骤，但起初解决差异化费用问题可能具有挑战性。

未来十年可能出现的另外两种投资趋势是比特币（Bitcoin）和特殊目的收购公司（SPACs）。比特币将继续获得关注，并被对冲基金和个人投资者接受，但我很难将其视为不仅仅是一种投机性投资。它不像黄金那样是商品，也不像美元那样是货币，我认为其价格波动更多由供需关系而非基本面估值驱动。比特币和其他加密货币可能会用于支付，并最终可能受到监管。不幸的是，我无法制定出充分描述投资者应如何在投资组合中使用比特币以及如何正确估值的投资论点。因此，我鼓励财富顾问和投资者谨慎行事。

从2020年开始并贯穿2021年，SPACs已充斥金融市场。SPAC是一家没有商业运营的公司，严格通过首次公开募股（IPO）筹集资金，目的是收购一家现有公司。SPACs也被称为“空头支票公司”（blank check companies），因为它们在没有运营业务或既定收购目标的情况下开始。SPACs已存在数十年，但它们在2020年变得越来越受欢迎，部分原因是许多估值超过10亿美元的私营公司上市所带来的狂热。当然，SPACs与传统IPO之间存在重大差异，主要在于尽职调查和披露。

与直接上市（direct listings，另一种上市方式）类似，SPACs可能会存在一段时间。然而，我不确信它们会取代典型的IPO，并且担心个人投资者没有充分理解与这种投资工具相关的风险。

财富顾问在向投资者介绍即将进入市场的新产品和改进策略方面可以发挥关键作用。有些将是有益的，并有助于民主化获取曾经难以触及的投资；而有些则无法满足客户期望，并会让投资者对那些似乎偏爱对冲基金、机构和家族办公室的市场投资感到畏缩。

## 财富管理的未来

多年来，财富管理行业发生了巨大演变。每当有人预言其终结时，该行业都会自我重塑，并以服务投资者的不同方式出现。当佣金于1975年5月1日放开管制时，该行业通过引入包干费账户并转向顾问费来响应，以更好地与客户利益保持一致。当行业注意到SMAs效率低下且顾问难以获得客户对投资组合调整的许可时，该行业引入了全权委托计划，这些计划在多个账户之间执行订单时提供了规模和效率，无需征求许可。当行业注意到顾问在整合多个包干账户方面困难时，它发明了统一管理账户（UMA），以更高效地在单一账户中捕捉家族持仓。

行业将如何应对新一系列挑战？未来10年该行业可能发生的变化包括以下几种：

- 1. 财富管理部门分拆
- 2. 教育作为差异化因素
- 3. 规模与效率溢价
- 4. 所有公司提供免佣金交易
- 5. 利用人工智能定向服务

### 财富管理分拆

随着对利益冲突的审查日益增加，未来10年内，一家或多家大型券商（wirehouses）可能会分拆其财富管理部门。为改善整体经济效益，财富管理公司鼓励顾问交叉销售关联资产管理和银行产品。关联资产管理者在向关联经纪交易商销售产品方面一直困难重重，并将面临来自监管机构和投资者的日益增加的压力，要求分拆这两项业务。监管机构担心投资者不完全了解关联方之间固有的利益冲突或相关经济安排。披露无法解决问题，投资者对顾问推销自有产品持戒备态度。

2016年，富国银行员工创建了数百万个欺诈性银行和信用卡账户，最终导致巨额罚款，包括首席执行官在内的几名高管被解雇。监管机构调查此事时发现，数百万投资者遭受了该银行激进交叉销售行为的损害。从2018年开始，该银行及其财富管理部门被罚款或要求退还数十亿美元，其中包括4月份与抵押贷款相关问题的10亿美元罚金，5月份涉及虚假账户的4.8亿美元，6月份涉及财富管理客户的1.14亿美元，7月份涉及外汇的5.05亿美元，以及8月份涉及有害销售行为的21亿美元。除了罚款和退款，该公司还遭受了无法弥补的声誉损害。

富国银行丑闻，以及全球金融危机后暴露的其他滥用行为，将焦点投射到了业务线之间的冲突上，从银行和财富管理到研究和投资银行。高净值投资者对这些问题有了更高的认识，并担心顾问是否真的在为其最佳利益工作。

我预测一家大银行将分拆其业务并消除这些潜在的利益冲突。如果一家银行将其业务拆分为独立组织，其他银行可能会效仿，尤其是如果分拆后的业务展示出增长能力。
