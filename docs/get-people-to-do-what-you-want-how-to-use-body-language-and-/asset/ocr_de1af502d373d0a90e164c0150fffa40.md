# 绘制动画场景

+   1. 打开动画场景
+       在Animate中创建或打开一个动画场景。动画场景是包含3D模型的场景。
+   2. 绘制动画草图
+       使用笔工具在场景中绘制草图。草图将作为动画的参考。
+   3. 添加动画关键帧
+       在时间轴中添加动画的关键帧。关键帧是动画中重要的位置。
+   4. 创建动画补间
+       在两个关键帧之间的中间帧，或者自动创建
+   5. 绘制动画
+       设置动画参数并绘制动画。
+   6. 预览动画
+       使用播放按钮预览动画。
+   7. 保存文件
+       使用快捷键Ctrl+S保存文件。
+   8. 导出动画
+       使用导出命令将动画导出为视频或GIF格式。可导出为GIF动图
