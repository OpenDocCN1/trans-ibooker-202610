+   4. On the next screen, your account will appear as the owner. Name your copy of the repo *leaflet-map-simple*, the same as ours. Click the green “Create repository from template” button.

The upper-left corner of the next screen will say *USERNAME/leaflet-map-simple* generated from *HandsOnDataViz/leaflet-map-simple*, where *USERNAME* refers to your GitHub account username. This confirms that you copied our template into your GitHub account, and it contains only three files:

+   *LICENSE*

+   Shows that we’ve selected the MIT License, which allows anyone to copy and modify the code as they wish

+   *README.md*
