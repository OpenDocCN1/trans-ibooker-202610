# Line Chart with Chart.js

Line charts are often used to show temporal data, or change of values over time. The x-axis represents time intervals, and the y-axis represents observed values. Note that unlike column or bar charts, y-axes of line charts don’t have to start at zero because we rely on the position and slope of the line to interpret its meaning.
