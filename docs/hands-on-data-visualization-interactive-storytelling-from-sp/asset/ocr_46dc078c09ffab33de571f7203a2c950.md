# ROWS VERSUS COLUMNS IN TIME-SERIES DATA

Tables and charts approach time-series data from opposite directions. When designing a chart, the proper method is to place dates horizontally as column headers, so that we read them from left to right, like this:[^4]

| Year | 2000 | 2010 | 2020 |
|---|---|---|---|
| Series1 | … | … | … |
| Series2 | … | … | … |

When designing a line chart in Google Sheets and several other tools, we organize the spreadsheet by placing the dates vertically down the first column, so that the tool reads them as labels for a data series, like this:

| Year | Series1 | Series2 |
|---|---|---|
| 2000 | … | … |
| 2010 | … | … |
| 2020 | … | … |

Learn how to convert data from tables to charts in “Transpose Rows and Columns”.

# Stacked Area Charts

Area charts resemble line charts with filled space underneath. The most useful type is a stacked area chart, which is best for combining two previously mentioned concepts: showing parts of the whole (like a pie chart) and continuous data over time (like a line chart). For example, the line chart shows how the availability of three different meats changed over time. However, if you also wish to show how the total availability of these combined meats went up or down over time, it’s hard to see this in a line chart. Instead, use a stacked line chart to visualize the availability of each meat and the total combined availability per capita over time. Stacked line charts show both aspects of your data simultaneously.
