Let’s begin with a simple example of splitting pairs of geographic coordinates, separated by commas, into separate columns:

+   1. Open the [Split Coordinate Pairs](#) sample data in Google Sheets, sign in with your account, and go to File > “Make a copy” to create a version you can edit in your Google Drive.
+   
+   2. Select the data you wish to split, either the full column or just several rows. Note that you can split data only from one column at a time.
+   
+   3. Make sure there is no data in the column to the right of the one you’re splitting, because all the data there will be written over.
+   
+   4. Go to Data and select “Split text to columns.”
