In this chapter, you learned how to create different types of interactive charts with Google Sheets, Datawrapper, and Tableau Public. For more advanced chart design with open source code, see Chapter 11, which gives you ever-more control over how you design and display your data, but also requires learning how to edit and host code templates with GitHub in Chapter 10.
