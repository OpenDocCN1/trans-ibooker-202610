
*   ![$$ \overrightarrow{\mathrm{J}}=-\left({\mathrm{m}}_\mathrm{B}{\overrightarrow{\mathrm{V}}}_\mathrm{B2}-{\mathrm{m}}_\mathrm{B}{\overrightarrow{\mathrm{V}}}_\mathrm{B1}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq36.png)

或当求解 ![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{B2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq37.png) 时

*   ![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{B2}={\overrightarrow{\mathrm{V}}}_\mathrm{B1}-\frac{\overrightarrow{\mathrm{J}}}{{\mathrm{m}}_\mathrm{B}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq38.png)   **(4)**

从数学公式中抽离出来，思考一下这个公式陈述了什么。这符合直觉。该方程表明速度的变化与物体的质量成反比。换句话说，物体质量越大，碰撞后其速度变化越小。冲量法实现了这一观察结果。

回顾一下，公式 (1) 和 (2) 分别根据碰撞法线和切线方向描述了碰撞后的相对速度。冲量作为一个向量，也可以表示为碰撞法线和切线方向上分量 `j[N]` 和 `j[T]` 的线性组合：

*   ![$$ \overrightarrow{\mathrm{J}}={\mathrm{j}}_\mathrm{N}\hat{\mathrm{N}}+{\mathrm{j}}_\mathrm{T}\hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq39.png)

将此表达式代入公式 (3) 和 (4) 得到以下结果：

*   ![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{A2}={\overrightarrow{\mathrm{V}}}_\mathrm{A1}+\frac{{\mathrm{j}}_\mathrm{N}}{{\mathrm{m}}_\mathrm{A}}\hat{\mathrm{N}}+\frac{{\mathrm{j}}_\mathrm{T}}{{\mathrm{m}}_\mathrm{A}}\hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq40.png)   **(5)**

*   ![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{B2}={\overrightarrow{\mathrm{V}}}_\mathrm{B1}-\frac{{\mathrm{j}}_\mathrm{N}}{{\mathrm{m}}_\mathrm{B}}\hat{\mathrm{N}}-\frac{{\mathrm{j}}_\mathrm{T}}{{\mathrm{m}}_\mathrm{B}}\hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq41.png)   **(6)**

注意，`j[N]` 和 `j[T]` 是这两个方程中唯一的未知数，其余项要么由用户定义，要么可根据几何形状计算得出。即，量 ![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{A1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq42.png)、![$$ {\overrightarrow{\mathrm{V}}}_\mathrm{B1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq43.png)、`m[A]` 和 `m[B]` 由用户定义，而 ![$$ \hat{\mathrm{N}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq44.png) 和 ![$$ \hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq45.png) 可以计算得出。

> **注意**
>
> ![$$ \hat{\mathrm{N}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq46.png) 和 ![$$ \hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq47.png) 向量已归一化且相互垂直。因此，这些向量与自身点积的值为 1，与彼此点积的值为 0。
