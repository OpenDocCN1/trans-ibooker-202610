# 12. 构建示例游戏：从设计到完成

结束摘要

第 [`1`](#334805_2_En_1_Chapter.xhtml) 至 [`11`](#334805_2_En_11_Chapter.xhtml) 章主体部分所包含的项目始于简单形状，并逐步引入角色和环境以阐释各章概念；这些项目侧重于个别行为和技术（如碰撞检测、物体物理、光照等），但缺乏提供完整游戏体验所需的结构化挑战。*“设计考量”* 部分的项目演示了如何引入将基本行为转化为完善游戏机制所需的逻辑规则和挑战类型。本章现在将重点转移到强调从早期概念到功能原型的设计过程，通过使用前几章中的一些角色和环境，以及第 [`11`](#334805_2_En_11_Chapter.xhtml) 章 *“设计考量”* 部分中解锁平台游戏的基本理念，整合并扩展了早期项目的工作。与早期章节一样，此处采用的设计框架从一个简单灵活的起始模板开始，并有意逐步增加复杂性，以便让游戏以受控方式发展。

直到现在，设计练习一直避免考虑第 [`1`](#334805_2_En_1_Chapter.xhtml) 章 *“如何制作一款优秀的电子游戏？”* 部分所述的游戏设计九大要素中的大多数，而是专注于打磨基本游戏机制，以便清晰地定义和完善游戏本身的核心特征。本书采用的设计方法是一个自底向上的框架，强调先处理孤立的游戏机制，然后再考虑游戏的类型或背景设定；当你开始融入背景设定，并在核心机制之上构建包含额外设计要素的关卡时，游戏玩法将随着游戏世界的扩展而向独特的方向成长和演变。游戏机制及你设计的相关游戏循环存在无尽的潜在变体。你会惊讶于相同的游戏玩法基础元素会因你做出的创意选择而以截然不同的方式发展和演变。

## 第 1 部分：完善概念

此时你应该已拥有一个雏形概念，采用 2D 跳跃和解谜机制，核心是解锁屏障并获得奖励。回顾图 [`12-1`](#334805_2_En_12_Chapter.xhtml#Fig1)，这是第 [`11`](#334805_2_En_11_Chapter.xhtml) 章的最终屏幕布局和设计。

![图 12-1 ¶ 第 11 章的 2D 实现](`images/334805_2_En_12_Chapter/334805_2_En_12_Fig1_HTML.jpg`)

图 12-1 ¶ 第 [`11`](#334805_2_En_11_Chapter.xhtml) 章的 2D 实现

该设计已包含多阶段解决方案，要求玩家同时展示基于时机的敏捷性和解谜逻辑。在当前设计中，玩家控制主角角色（可能使用 `A` 和 `D` 键左右移动，使用 `spacebar` 跳跃）。玩家可以在同一层的水平平台间跳跃，但若不使用会上下移动的中间“电梯”平台，就无法到达上方的平台。如果玩家触碰水平“能量场”，将会被电击，导致游戏重置。完成关卡的明确步骤如下：

1. 玩家必须让主角角色（图 [`12-1`](#334805_2_En_12_Chapter.xhtml#Fig1) 中心带有字母 *p* 的圆圈）跳上移动的电梯平台（图 [`12-1`](#334805_2_En_12_Chapter.xhtml#Fig1) 中的 #1），并在触碰能量场前跳离至右侧柱子的中间平台。
2. 玩家通过让主角角色与其碰撞来激活能量场的关闭开关（#2，图 [`12-1`](#334805_2_En_12_Chapter.xhtml#Fig1) 中用灯泡图标表示）。
3. 当能量场关闭后，玩家乘坐电梯平台到达顶部（#3），并让主角跳至右侧柱子的顶层平台。
4. 玩家让主角与代表锁图标顶部三分之一的小圆圈（#4）碰撞，激活锁图标对应部分并使其发光。
5. 玩家让主角跳回电梯平台（#5），然后跳至右侧柱子的底层平台。
6. 玩家让主角与对应锁图标中间部分的形状（#6）碰撞，激活锁图标对应部分并使其发光。锁图标现在有三分之二发光，表明进度。
7. 玩家再次让主角跳上电梯平台（#7），然后跳至左侧柱子的顶层平台。
8. 玩家让主角与对应锁图标底部部分的形状（#8）碰撞，激活图标的最后一部分并解锁屏障。

写出这个序列（或*游戏流程图*）在你已创建模拟屏幕的情况下可能显得多余。然而，设计师必须详细了解玩家必须按确切顺序做的每一件事，以确保你能在不陷入复杂性或不失去对玩家如何通过关卡的洞察的情况下，调整、平衡和演变游戏玩法。例如，从绘制前面的游戏流程图可以清楚地看出，电梯平台是该关卡的核心，完成每个动作都需要它；在示意图表示和游戏流程描述中拥有这一信息非常有价值，因为它提供了一个机会，让你能智能地优化游戏玩法逻辑，从而直观地看到每次更改对关卡整体流程的影响。
