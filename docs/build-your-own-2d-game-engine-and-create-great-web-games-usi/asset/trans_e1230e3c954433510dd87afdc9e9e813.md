## 摘要

本章有三个简单的要点。首先，你了解到粒子（带有适当纹理且无尺寸的位置）可用于描述有趣的物理效果。其次，与其他物体碰撞和交互的能力有助于在游戏场景中集成和放置粒子。最后，为了呈现熟悉的物理效果，粒子的发射应持续一段时间。

你开发了一个简单而灵活的粒子系统，以支持对单个粒子及其发射器的一致管理。你的系统之所以简单，是因为它仅包含一个组件，定义在 `particle_system.js` 中，只有三个简单的辅助类定义在 `src/engine/particles` 文件夹中。系统之所以灵活，是因为实际创建粒子的回调机制，游戏开发者可以自由定义和生成具有任意行为的粒子。

你构建的粒子系统用于演示基础知识。要增加粒子行为的复杂性，你可以从简单的 `Particle` 类派生子类，定义额外参数，并相应修改 `update()` 函数。要支持额外的物理效果，你可以考虑修改或从 `ParticleEmitter` 类派生子类，并根据你想要的公式发射粒子。

### 游戏设计考量

正如第 [9](#334805_2_En_9_Chapter.xhtml) 章所讨论的，游戏中的临场感并非完全通过在游戏环境中重现现实世界的体验来实现；虽然引入现实世界的物理规律通常是将玩家带入虚拟世界的有效方式，但还有许多其他设计选择能非常有效地将玩家吸引进游戏，无论是配合物体物理还是独立作用。例如，想象一个具有 2D 漫画书视觉风格的游戏，每当发生爆炸时就会显示基于文本的“BOOM!”图像；当然，现实世界中物体爆炸时不会显示“BOOM!”一词，但如图 [10-4](#334805_2_En_10_Chapter.xhtml#Fig4) 所示，在漫画书视觉美学的语境下，对“BOOM!”的风格化且熟悉的使用本身就能非常有效地将玩家与游戏世界中发生的事情联系起来。

## 简介

到此为止，你的游戏引擎已经能够照亮 2D 图像以生成高光和阴影，并模拟基本的物理行为。为了完成本书的引擎开发，本章重点介绍创建游戏世界环境的通用支持，包括背景平铺和视差，以及解放游戏程序员不必管理绘制顺序。

背景图像或物体被包含进来以装饰游戏世界，进一步吸引玩家。这通常要求图像规模巨大，具有微妙的视觉复杂性。例如，在横向卷轴游戏中，背景必须始终存在，简单的运动视差可以创造深度感，进一步抓住玩家的兴趣。

在计算机图形学和视频游戏的语境下，平铺是指沿 x 和 y 方向复制图像或图案。在视频游戏中，用于平铺的图像通常经过策略性构建，以确保内容在复制边界处连续。图 [11-1](#334805_2_En_11_Chapter.xhtml#Fig1) 展示了一个策略性绘制的背景图像在 x 方向平铺三次、y 方向平铺两次的示例。请注意复制边界处完美的连续性。适当的平铺仅通过创建单个图像就能传达出无边游戏世界的复杂感。

![图 11-1 ¶ 策略性绘制的背景图像平铺](images/334805_2_En_11_Chapter/334805_2_En_11_Fig1_HTML.png)

图 11-1 ¶ 策略性绘制的背景图像平铺

视差是指从不同位置观察时物体的明显位移。图 [11-2](#334805_2_En_11_Chapter.xhtml#Fig2) 展示了一个阴影圆的视差示例。从中间眼位观察时，中心阴影圆似乎覆盖了中心矩形块。然而，从底部眼位观察时，同一个阴影圆似乎覆盖了顶部矩形块。运动视差是指当观察者移动时，近处物体似乎比远处物体移动得更快。这是深度感知的基本视觉线索。在 2D 游戏中，模拟运动视差是引入深度复杂性以进一步吸引玩家的直接方法。

![图 11-2 ¶ 视差：从不同观察点看时物体出现在不同位置](images/334805_2_En_11_Chapter/334805_2_En_11_Fig2_HTML.png)

本章介绍了一个用于平铺相机 `WC` 边界的通用算法，并描述了一个隐藏视差滚动细节的抽象。随着背景视觉复杂性的增加，本章讨论了图层管理器的重要性并创建了一个，以减轻游戏程序员对绘制顺序细节的负担。
