## 考虑旋转的相对速度

回顾上一节，物体 `A` 和 `B` 碰撞前后的相对速度定义如下：

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}1}-{\overrightarrow{\mathrm{V}}}_{\mathrm{B}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq86.png)
*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}2}-{\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq87.png)

这些速度根据方程 (1) 和 (2) 中的碰撞法线和切线方向分量进行分析，为方便起见重新列出如下：

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}\bullet \hat{\mathrm{N}}=-\mathrm{e}\left({\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}\bullet \hat{\mathrm{N}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq88.png) (1)
*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}\bullet \hat{\mathrm{T}}=\mathrm{f}\left({\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}\bullet \hat{\mathrm{T}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq89.png) (2)

这些方程是在不考虑旋转的情况下推导出来的，且该公式假设速度在整个形状上是恒定的。为了支持旋转，这些方程必须推广并在碰撞点 `P` 处求解。

*   ![$$ {\overrightarrow{\mathrm{V}}}_{ABP2}\bullet \hat{\mathrm{N}}=-\mathrm{e}\left({\overrightarrow{\mathrm{V}}}_{ABP1}\bullet \hat{\mathrm{N}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq90.png) (13)
*   ![$$ {\overrightarrow{\mathrm{V}}}_{ABP2}\bullet \hat{\mathrm{T}}=\mathrm{f}\left({\overrightarrow{\mathrm{V}}}_{ABP1}\bullet \hat{\mathrm{T}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq91.png) (14)

在这种情况下，![$$ {\overrightarrow{\mathrm{V}}}_{ABP1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq92.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{ABP2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq93.png) 分别是碰撞前后碰撞位置 `P` 处的相对速度。这些向量仍然由物体 `A` 和 `B` 在碰撞前（![$$ {\overrightarrow{\mathrm{V}}}_{AP1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq94.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{BP1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq95.png)）和碰撞后（![$$ {\overrightarrow{\mathrm{V}}}_{AP2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq96.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{BP2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq97.png)）各自碰撞位置 `P` 处的速度差来定义。

*   ![$$ {\overrightarrow{\mathrm{V}}}_{ABP1}={\overrightarrow{\mathrm{V}}}_{AP1}-{\overrightarrow{\mathrm{V}}}_{BP1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq98.png) (15)
*   ![$$ {\overrightarrow{\mathrm{V}}}_{ABP2}={\overrightarrow{\mathrm{V}}}_{AP2}-{\overrightarrow{\mathrm{V}}}_{BP2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq99.png) (16)

现在你已经准备好将冲量法推广以支持旋转，并推导出一个解来近似线速度和角速度：![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq100.png)，![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq101.png)，![$$ {\overrightarrow{\upomega}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq102.png)，以及 ![$$ {\overrightarrow{\upomega}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq103.png)。

## 考虑旋转的冲量法

继续上一节的冲量法讨论，物体 `A` 和 `B` 碰撞后，冲量法通过一个冲量 ![$$ \overrightarrow{\mathrm{J}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq104.png) 来描述它们线速度的变化，该冲量按其对应质量 `m[A]` 和 `m[B]` 的倒数进行缩放。线速度的这种变化在方程 (3) 和 (4) 中描述，为方便起见重新列出如下：

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}1}+\frac{\overrightarrow{\mathrm{J}}}{{\mathrm{m}}_{\mathrm{A}}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq105.png) (3)
*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}2}={\overrightarrow{\mathrm{V}}}_{\mathrm{B}1}-\frac{\overrightarrow{\mathrm{J}}}{{\mathrm{m}}_{\mathrm{B}}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq106.png) (4)

一般来说，旋转是碰撞的内在结果，同一个冲量必须恰当地描述碰撞前后角速度的变化。请记住，惯性，或称转动惯量，是旋转质量。与线速度和质量的情况类似，碰撞中角速度的变化也与转动惯量成反比。如图 [9-29](#334805_2_En_9_Chapter.xhtml#Fig29) 所示，对于转动惯量为 `I[A]` 和 `I[B]` 的物体 `A` 和 `B`，碰撞后，角速度 ![$$ {\overrightarrow{\upomega}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq107.png) 和 ![$$ {\overrightarrow{\upomega}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq108.png) 可描述如下，其中 ![$$ {\overrightarrow{\mathrm{R}}}_{AP} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq109.png) 和 ![$$ {\overrightarrow{\mathrm{R}}}_{BP} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq110.png) 是各物体的位置向量：

*   ![$$ {\overrightarrow{\upomega}}_{\mathrm{A}2}={\overrightarrow{\upomega}}_{\mathrm{A}1}+\left({\overrightarrow{\mathrm{R}}}_{AP}\times \frac{\overrightarrow{\mathrm{J}}}{{\mathrm{I}}_{\mathrm{A}}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq111.png) (17)
