

## 第 8 章概述

Phong 光照模型及对逐对象材质属性的需求是在镜面反射示例中介绍的。实现了 Phong 光照模型的半程向量版本，以避免为每个像素计算光源反射向量。光源类型项目演示了如何通过模拟现实世界中的不同光源，实现微妙但重要的光照变化。最后一个示例解释了精确的阴影计算并非易事，并介绍了一种近似算法。尽管生成的阴影模拟从现实世界的角度来看是不准确且有局限性的，但它在美学上可能很吸引人，并能传达许多相同的关键视觉线索。

本书前四章介绍了游戏引擎的基本基础和组件。第 [5](#334805_2_En_5_Chapter.xhtml)、[6](#334805_2_En_6_Chapter.xhtml) 和 [7](#334805_2_En_7_Chapter.xhtml) 章分别扩展了核心引擎功能，以支持绘制、游戏对象行为和相机控制。本章作为第 [5](#334805_2_En_5_Chapter.xhtml) 章的补充，将引擎渲染高保真场景的能力提升到了一个新的水平。在接下来的三章中，这种互补模式将重复出现。第 [9](#334805_2_En_9_Chapter.xhtml) 章将介绍物理行为模拟，第 [10](#334805_2_En_10_Chapter.xhtml) 章将讨论粒子效果，第 [11](#334805_2_En_11_Chapter.xhtml) 章将通过为相机提供包括平铺和视差在内的更高级支持，完成引擎开发。

### 游戏设计考量

您在第 [7](#334805_2_En_7_Chapter.xhtml) 章“*游戏设计考量*”一节中为创建一个基本的、结构良好的游戏机制所做的工作，最终需要与游戏设计的其他要素相结合，才能创造出让玩家感到满意的体验。除了基本的游戏循环，您还需要考虑游戏的系统、背景设定和元游戏，以及它们如何帮助决定您设计的关卡类型。当您开始定义背景设定时，就会开始探索视觉和音频设计的创意。

与大多数视觉艺术一样，游戏在很大程度上依赖于有效地利用光照来传达背景设定。一款发生在午夜墓地的恐怖游戏，通常会使用与一款专注于积极、快乐主题的游戏截然不同的光照模型和调色板。许多人认为光照主要适用于能够模拟真实光影的 3D 引擎创建的游戏，但光照的概念也适用于大多数 2D 游戏环境；请看 Playdead 工作室的 2D 横向卷轴平台游戏 *Limbo* 所呈现的示例，如图 [8-30](#334805_2_En_8_Chapter.xhtml#Fig30) 所示。

![Figure 8-30 ¶ Playdead and Double Eleven's Limbo, a 2D side-scrolling game making clever use of background lighting and chiaroscuro techniques to convey tension and horror. Lighting can be both programmatically generated and designed into the color palettes of the images themselves by the visual artist and is frequently a combination of the two (image copyright Playdead media; please see www.​playdead.​com/​limbo for more information)](images/334805_2_En_8_Chapter/334805_2_En_8_Fig30_HTML.jpg)

图 8-30 ¶ Playdead 和 Double Eleven 的《Limbo》，一款 2D 横向卷轴游戏，巧妙地利用背景光照和明暗对照法来传达紧张感和恐怖感。光照既可以通过程序生成，也可以由视觉艺术家设计进图像的调色板本身，且通常是两者的结合（图片版权归 Playdead 所有；更多信息请访问 [www.​playdead.​com/​limbo](http://www.playdead.com/limbo)）

光照除了营造氛围外，也常被用作游戏循环的核心元素；玩家或许在黑暗中借助虚拟手电筒导航的游戏就是一个显而易见的例子，但灯光也可以通过提供关于游戏环境的重要信息来间接支持游戏机制。红色脉冲灯通常预示危险区域，某些类型的绿色环境灯可能预示安全区域或充满致命气体的区域，地图上的闪烁灯光可以帮助引导玩家前往重要位置，等等。

在“*简单全局环境光*”项目中，您看到了彩色环境光照对游戏背景设定的影响。在该项目中，主角在金属面板、管道和机械的背景前移动，或许是飞船的外部。环境光是红色的，且可以脉动——注意当强度设置为相对较低的 1.5 与设置为超饱和的 3.5 等值时对情绪的影响，并想象在这两个值之间脉动如何传达故事或增加张力。在“*简单光照着色器*”项目中，一盏灯被附着在主角身上（此处为点光源），您可以想象主角必须在环境中导航，收集仅在光照下可见的物体以完成关卡（或激活仅在光照下才开启的物体）。

“*多光源*”项目展示了各种光源和颜色如何为环境增加相当大的视觉趣味（有时称为局部环境光照）。改变光源的类型、强度和颜色值，往往能让环境看起来更生动、更吸引人，因为现实世界中遇到的光通常源自许多不同的光源。本章中的其他项目也都起到了类似增强游戏关卡临场感的作用；当您使用漫反射着色器、法线贴图、镜面高光、不同光源类型和阴影时，请考虑如何将其中一些或所有技术整合到关卡的视觉设计中，使游戏对象和环境感觉更生动有趣。
