## 修改 `rigid_rectangle_collision.js`

在 `src/engine/rigid_shapes` 文件夹中，编辑 `rigid_rectangle_collision.js`，修改 `collisionTest()` 函数，当参数为圆形时调用新定义的 `collideRectCirc()`：

```javascript
RigidRectangle.prototype.collisionTest = function (otherShape, collisionInfo) {
    let status = false;
    if (otherShape.mType === "RigidCircle") {
        status = this.collideRectCirc(otherShape, collisionInfo);
    } else {
        status = this.collideRectRect(this, otherShape, collisionInfo);
    }
    return status;
}
```

# Movement

Movement 是描述对象在模拟世界中位置如何变化的。数学上，Movement 可以用多种方式表述。在第 6 章中，你体验了通过不断将位移累加到对象位置来处理 Movement。如下面的方程和图 9-19 所示，你一直在使用基于恒定位移来描述 Movement。

*   `p[new] = p[current] + displacement`

![Figure 9-19 ¶ Movement based on constant displacements](images/334805_2_En_9_Chapter/334805_2_En_9_Fig19_HTML.png)

**Figure 9-19 ¶ Movement based on constant displacements**

当需要随时间改变位移量时，基于恒定位移公式的 Movement 会变得受限。牛顿力学通过在 Movement 公式中考虑时间来解决这一限制，如下面的方程所示：

*   `v[new] = v[current] + ∫ a(t)dt`
*   `p[new] = p[current] + ∫ v(t)dt`

这两个方程代表基于牛顿力学的 Movement，其中 `v(t)` 是描述位置随时间变化的速度，`a(t)` 是描述速度随时间变化的加速度。

注意，速度和加速度都是矢量量，同时编码大小和方向。速度矢量的大小定义了速率，归一化的速度矢量标识了对象移动的方向。加速度矢量让你知道对象是加速还是减速，以及对象移动方向的变化。作用在对象上的力会改变加速度。例如，如果你向空中抛出一个球，重力会随时间影响对象的加速度，进而改变对象的速度。

## Explicit Euler Integration

Euler 方法，或 **Explicit Euler Integration**，基于初始值近似积分。这是最直接的积分近似方法之一。如下面的两个方程所示，在牛顿 Movement 公式中，对象的新速度 `v[new]` 可以近似为当前速度 `v[current]` 加上当前加速度 `a[current]` 乘以经过的时间。类似地，对象的新位置 `p[new]` 可以近似为对象的当前位置 `p[current]` 加上当前速度 `v[current]` 乘以经过的时间。

*   `v[new] = v[current] + a[current] * dt`
*   `p[new] = p[current] + v[current] * dt`

图 9-20 左图展示了使用 **Explicit Euler Integration** 近似 Movement 的简单示例。注意，新位置 `p[new]` 基于当前速度 `v[current]` 计算，而新速度 `v[new]` 则被计算用于下一个更新周期的位置移动。

![Figure 9-20 ¶ Explicit (left) and Symplectic (right) Euler Integration](images/334805_2_En_9_Chapter/334805_2_En_9_Fig20_HTML.png)

**Figure 9-20 ¶ Explicit (left) and Symplectic (right) Euler Integration**

## Symplectic Euler Integration

你将实现 **Semi-implicit Euler Integration** 或 **Symplectic Euler Integration**。使用 **Symplectic Euler Integration** 时，后续近似使用中间结果而非当前结果，从而更好地模拟实际 Movement。以下方程展示了 **Symplectic Euler Integration**。注意，它与 Euler 方法几乎相同，只是在计算新位置 `p[new]` 时使用了新速度 `v[new]`。这实质上意味着使用下一帧的速度来计算当前帧的位置。

*   `v[new] = v[current] + a[current] * dt`
*   `p[new] = p[current] + v[new] * dt`

图 9-20 右图展示了使用 **Symplectic Euler Integration** 时，新位置 `p[new]` 基于新计算的速度 `v[new]` 计算。

项目的控制方式与之前相同，并增加了控制选中对象行为和质量的命令：

### Behavior controls

*   **`V` key**：切换所有对象的运动
*   **`H` key**：向所有对象注入随机速度
*   **`G` key**：随机创建一个新的刚体圆形或矩形

### Draw controls

*   **`C` key**：切换所有 `CollisionInfo` 的绘制
*   **`T` key**：切换所有对象的纹理
*   **`R` key**：切换 `RigidShape` 的绘制
*   **`B` key**：切换每个 `RigidShape` 边界的绘制

### Object controls

*   **Left-/right-arrow key**：依次选择对象
*   **`WASD` keys**：移动选中的对象
*   **`Z/X` key**：旋转选中的对象
*   **`Y/U` key**：增加/减小选中对象的 `RigidShape` 大小；这不会改变对应 `Renderable` 对象的大小
*   **Up-/down-arrow key + `M`**：增加/减小选中对象的质量

项目目标如下：

*   完成 `RigidShape` 类的实现，包含相关的物理属性
*   基于 **Symplectic Euler Integration** 实现 Movement 近似

除了实现 **Symplectic Euler Integration**，该项目还指导你定义碰撞模拟和响应所需的属性，如质量、惯性、摩擦力等。正如将要解释的，这些属性中的每一个都将在对象碰撞响应的模拟中发挥作用。这些直接的信息在此呈现，是为了避免在后续项目中讨论更复杂的概念时分散注意力。
