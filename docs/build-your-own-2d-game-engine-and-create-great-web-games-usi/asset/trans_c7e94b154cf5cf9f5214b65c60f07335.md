
你现在正在尝试关卡布局的各种变体，使其随场景演进，并寻找增加玩家投入度同时提高挑战性（如果需要）的方法。在添加地板之前，关卡有两种风险：未能落在平台上而触发失败条件，以及与能量场碰撞而触发失败条件。添加地板消除了坠落风险，并可能降低关卡的挑战性，但你可能会决定地板能鼓励玩家更自由地探索、实验，并更密切地关注环境。你现在也越来越熟悉这一机制和布局的游戏玩法与流程，所以让我们引入一个新元素：攻击性敌人（我们不能让前几章的那些机器人设计白费）！图[12-8](#334805_2_En_12_Chapter.xhtml#Fig8)介绍了两种基本的敌人机器人类型：一种发射弹丸，一种只是巡逻。![图12-8 ¶ 关卡中引入了两种新对象类型：一种射击机器人（#1），垂直移动并以恒定速率射击；一种巡逻机器人（#2），在特定范围内来回移动](images/334805_2_En_12_Chapter/334805_2_En_12_Fig8_HTML.jpg)

你现在已达到该关卡设计的一个转折点，此时场景开始对机制和游戏循环的演进产生重大影响。该机制的核心自第[11](#334805_2_En_11_Chapter.xhtml)章以来未变，这关卡本质上仍是关于按正确顺序激活锁的各个部分以移除屏障，但移动平台和攻击性敌人是额外的障碍，且深受你所选特定场景的影响。

当然，你完全可以在仍使用抽象形状和纯机制时就添加攻击性敌人行为。然而值得注意的是，机制变得越复杂、越多阶段，场景就越需要顺应实现；这就是为什么在机制仍相当基础时，从纯抽象机制设计过渡到在特定场景背景下布局关卡（或部分关卡）会有所帮助。设计师通常希望游戏机制让人感觉与游戏场景深度融合，因此让两者同步发展是有益的。找到那个最佳平衡点可能很有挑战：有时机制主导设计，但随着场景演进，它往往会转为主导地位。过早引入场景会让你失去对纯游戏玩法打磨的专注；过晚引入场景则会让游戏世界感觉像是事后诸葛亮或生硬拼凑上去的。

## 总体考量

回到图[12-8](#334805_2_En_12_Chapter.xhtml#Fig8)所代表的当前设计，你现在拥有创建一个真正引人入胜的、置身于新兴场景中的序列所需的所有元素。你也可以相当容易地调整单个单位的移动和位置，以使事情变得更具挑战性或更简单。玩家需要观察平台和敌人的移动模式，以把握跳跃时机，从而在不被电击或撞击的情况下通过关卡，同时发现并解开解锁谜题。注意关卡如何迅速从极易完成变为可能相当有挑战性：使用多个移动平台增加了复杂性，而需要利用时机跳跃和躲避攻击性敌人——即使是图[12-8](#334805_2_En_12_Chapter.xhtml#Fig8)中那些被锁定在基本移动模式中的简单敌人——也以可控且有意图的方式开启了创造棘手谜题的近乎无限的可能性。

如果你还没这样做，现在是用代码原型化你的关卡设计（包括交互）以验证游戏玩法的好时机。对于这个早期关卡原型，重要的是主要行为（奔跑、跳跃、弹丸发射、移动平台、物体激活等）和完成关卡所需的步骤（谜题序列）得到正确实现。有些设计师坚持在这个阶段，从未接触过该关卡的玩家应该能够玩完整个体验，并在几乎无需协助的情况下完全理解他们需要做什么，而另一些设计师则愿意提供指导，填补缺失的屏幕UI和未完成的谜题序列留下的空白。在这个阶段进行游戏测试并验证主要游戏玩法部分是常见做法，并向测试玩家提供额外指导，以弥补不完整的UI或未实现的序列部分。一般来说，在这个阶段你越不需要依赖过肩指导玩家，你对整体设计的洞察就越好。你在这个阶段将实现的早期关卡原型的数量也取决于你设计的规模和复杂性。大型且高度复杂的关卡可能需要分几块（或许多块）实现和测试，然后才能一次性玩完整个关卡，但即使对于大型复杂关卡，目标也是尽早让完整体验可玩。

> **注意**
>
> 如果你一直在探索随书附带的工作原型，你会发现本章的设计概念与可玩关卡之间存在一些细微差异（例如，工作原型中不包含能量场）。考虑使用附带资源探索替代设计实现；探索和即兴发挥是创意关卡设计过程的关键要素。你能创造出多少当前机制的延伸？

## 第3部分：整合额外设计元素

你在本章构建的原型在其当前开发水平下可作为完整游戏的有效概念验证，但它仍缺少完整游戏体验通常所需的许多元素（包括视觉细节和动画、声音、计分系统、胜利条件、菜单和用户界面[UI]元素等）。用游戏术语说，原型关卡现在处于“框架+”阶段（*框架* 是一个用来描述包含布局和功能性玩法但缺乏其他设计元素的原型的术语；此处包含一些额外概念美术即为“+”）。现在是开始探索音频、计分系统、菜单和屏幕UI等的好时机。如果这个原型在游戏工作室处于制作中，一小组人可能会将当前关卡推向最终制作级别的打磨和完整度，而另一个团队则致力于设计和原型化额外关卡。被推向最终制作的单个关卡或部分关卡被称为*垂直切片*，意味着游戏的一个小部分包含了随最终产品发布的所有内容。创建垂直切片有助于让团队专注于最终体验的外观、手感和声音，并可用于与测试玩家验证创意方向。

### 视觉设计

虽然你已开始整合一些与场景和叙事相符的视觉设计资产，但此时游戏通常几乎没有（如果有的话）最终制作资产，且任何动画要么粗糙要么尚未实现（游戏音频也是如此）。虽然让游戏玩法与游戏场景并行演进是良好的实践，但工作室不愿在团队确信关卡设计已定型、且知道需要什么对象以及它们将放在哪里之前，花费时间和资源创建制作资产。
