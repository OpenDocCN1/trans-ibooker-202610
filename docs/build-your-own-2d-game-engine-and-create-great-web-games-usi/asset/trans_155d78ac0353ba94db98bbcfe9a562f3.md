
注意 ![$$ \hat{\mathrm{N}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq10.png) 分量前面的负号。你可以在图 [9-25](#334805_2_En_9_Chapter.xhtml#Fig25) 中看到，由于碰撞，向量 ![$$ {\overrightarrow{\mathrm{V}}}_2 $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq12.png) 的 ![$$ \hat{\mathrm{N}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq11.png) 分量指向与 ![$$ {\overrightarrow{\mathrm{V}}}_1 $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq13.png) 相反的方向。此外，请注意在切线方向 ![$$ \hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq14.png) 上，![$$ {\overrightarrow{\mathrm{V}}}_2 $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq15.png) 继续指向同一方向。这是因为切线分量平行于墙壁，不受碰撞影响。在一个没有摩擦且动能不损失的完美世界中，这种分析普遍适用于任何碰撞。

### 碰撞形状的相对速度

将向量分解为碰撞的法线方向和切线方向，也可以应用于两个碰撞形体都在运动的一般情况。例如，图 [9-26](#334805_2_En_9_Chapter.xhtml#Fig26) 说明了两个运动的圆形 A 和 B 发生碰撞的情况。

![图 9-26 ¶ 两个运动圆之间的碰撞](images/334805_2_En_9_Chapter/334805_2_En_9_Fig26_HTML.png)

在图 [9-26](#334805_2_En_9_Chapter.xhtml#Fig26) 的情况下，碰撞前，物体 A 以速度 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq16.png) 运动，而物体 B 以速度 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq17.png) 运动。碰撞的法线方向 ![$$ \hat{\mathrm{N}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq18.png) 定义为两个圆心之间的向量，碰撞的切线方向 ![$$ \hat{\mathrm{T}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq19.png) 是在碰撞点处与两个圆相切的向量。为了解决这次碰撞，必须计算碰撞后物体 A 和 B 的速度 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq20.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq21.png)。

碰撞后的速度是基于两个形体之间的相对速度确定的。形体 A 和 B 之间的相对速度定义如下：

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}1}-{\overrightarrow{\mathrm{V}}}_{\mathrm{B}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq22.png)

现在可以将碰撞向量分解应用到相对速度的法线方向和切线方向上，其中碰撞后的相对速度是 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq23.png)：

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}\bullet \hat{\mathrm{N}}=-\mathrm{e}\left({\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}\bullet \hat{\mathrm{N}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq24.png) **(1)**
*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}\bullet \hat{\mathrm{T}}=\mathrm{f}\left({\overrightarrow{\mathrm{V}}}_{\mathrm{AB}1}\bullet \hat{\mathrm{T}}\right) $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq25.png) **(2)**

恢复系数 e 和摩擦系数 f 模拟了现实世界中碰撞期间部分动能转化为其他形式能量的情况。公式 (1) 中的负号表示碰撞后，物体将沿着与初始碰撞法线方向相反的方向运动。公式 (2) 表示碰撞后，摩擦会减小速度大小，物体将继续沿同一切线方向运动，但速度降低。请注意，公式 (1) 和 (2) 右侧的所有变量都是已定义的，因为它们在碰撞时刻是已知的。重要的是要记住

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{AB}2}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}2}-{\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq26.png)

目标是推导出 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq27.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq28.png) 的解，即碰撞后碰撞物体的各自速度。你现在可以建立一个模型来近似 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq29.png) 和 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{B}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq30.png)。

**注意**

恢复系数 e 描述了弹性或碰撞后保留的速度比例。恢复系数值为 1.0 意味着碰撞前后的速度相同。相反，摩擦直观上与碰撞后损失的比例或减速有关。例如，摩擦系数为 1.0 意味着无限大的摩擦，碰撞会导致速度变为零。为了公式的一致性，公式 (2) 中的系数 f 实际上是 1 减去直观的摩擦系数。

### 冲量

准确描述碰撞涉及复杂的考量因素，包括能量形式转换、不同材料属性产生的摩擦等。不考虑这些高级问题，发生在形体上的碰撞的简单描述是：一个恒定质量的物体在与另一个物体接触后，其速度从 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq31.png) 变为 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq32.png)。方便的是，这就是冲量的定义，如下所示：

*   ![$$ \overrightarrow{\mathrm{J}}={\mathrm{m}}_{\mathrm{A}}{\overrightarrow{\mathrm{V}}}_{\mathrm{A}2}-{\mathrm{m}}_{\mathrm{A}}{\overrightarrow{\mathrm{V}}}_{\mathrm{A}1} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq33.png)

或当求解 ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq34.png) 时

*   ![$$ {\overrightarrow{\mathrm{V}}}_{\mathrm{A}2}={\overrightarrow{\mathrm{V}}}_{\mathrm{A}1}+\frac{\overrightarrow{\mathrm{J}}}{{\mathrm{m}}_{\mathrm{A}}} $$](images/334805_2_En_9_Chapter/334805_2_En_9_Chapter_TeX_IEq35.png) **(3)**
