
# 光源

观察你的周围环境，你可以看到许多类型的光源，例如，你的台灯、来自太阳的光线，或一个孤立的灯泡。孤立的灯泡可以描述为一个向各个方向均匀发光的点，即点光源。点光源是你开始分析光源的地方。

从根本上说，点光源照亮指定点周围的一个区域或半径。在三维空间中，这个照明区域就是一个球体，称为照明体积。点光源的照明体积由光源的位置（即球心）和光源照射的距离（即球的半径）定义。要观察光源的效果，必须有物体存在且位于照明体积内。

正如本章介绍中提到的，2D引擎将需要涉足第三维度，以正确模拟光能的传播。现在，考虑你的2D引擎；到目前为止，你实现了一个所有东西都是2D的系统。另一种解释方式是：引擎在`z = 0`的单个平面上定义和渲染所有内容，并通过绘制顺序对物体进行分层。在这个系统上，你将添加存在于3D空间中的光源。

要观察光源的效果，其照明体积必须与定义物体的XY平面上的物体重叠。图[8-2](#334805_2_En_8_Chapter.xhtml#Fig2)显示了位于`z = 10`处的简单点光源的照明体积与`z = 0`处的平面相交。这种相交导致平面上出现一个被照亮的圆。下一个项目实现了图[8-2](#334805_2_En_8_Chapter.xhtml#Fig2)，你将采用面向对象的方法来研究光源，同时遵循光源照亮场景的预期行为。这可以通过定义一个`Light`对象来表示光源来实现。

## GLSL实现与游戏引擎集成

回顾一下，引擎通过`SimpleShader`/`Renderable`对的相应子类与GLSL着色器进行接口交互。`SimpleShader`及其子类与GLSL着色器交互，而`Renderable`及其子类为程序员提供了操作具有相同着色器类型的多个几何体副本的便利。例如，`texture_vs.glsl`和`texture_fs.glsl`通过`TextureShader`对象与游戏引擎交互，而`TextureRenderable`对象允许游戏程序员创建和操作由`texture_vs`/`fs`着色器着色的几何体的多个实例。图[8-3](#334805_2_En_8_Chapter.xhtml#Fig3)描绘了下一个项目如何扩展此架构以实现点光源照明。`Light`类封装了点光源的属性，包括位置、半径和颜色。这些信息通过`LightShader`/`LightRenderable`对传递给GLSL片段着色器`light_fs`，用于计算适当的像素颜色。GLSL顶点着色器`texture_vs`被重用，因为光源照明涉及在每个顶点处处理相同的信息。

![图8-3 ¶ LightShader/LightRenderable对及对应的GLSL LightShader](images/334805_2_En_8_Chapter/334805_2_En_8_Fig3_HTML.png)

图8-3 ¶ LightShader/LightRenderable对及对应的GLSL LightShader

最后，重要的是要记住，GLSL片段着色器会为相应几何体覆盖的每个像素调用一次。这意味着你即将创建的GLSL片段着色器每帧将被调用多次，可能达到数十万甚至数百万次。考虑到游戏循环以实时速率（即每秒约60帧重绘）启动重绘，GLSL片段着色器每秒将被调用数百万次！实现的效率对于流畅的体验至关重要。

项目的控制方式如下：

*   **WASD键**：移动屏幕上的主角角色
*   **WASD键 + 鼠标左键**：移动主角角色和光源在屏幕上移动
*   **左/右箭头键**：降低/增加光照强度
*   **Z/X键**：增加/减少光源的Z位置
*   **C/V键**：增加/减少光源半径

项目目标如下：

*   理解如何模拟点光源的照明效果
*   观察点光源照明
*   实现支持点光源照明的GLSL着色器

### 创建GLSL光源片段着色器

与上一节一样，实现将从GLSL着色器开始。不需要定义新的GLSL顶点着色器，因为涉及的逐顶点信息和计算与`texture_vs`相同。必须定义一个新的GLSL片段着色器来计算被照亮的圆。

1.  在`src/glsl_shaders`文件夹中，创建一个新文件并将其命名为`light_fs.glsl`。
2.  参考`texture_fs.glsl`并复制所有uniform和varying变量。这是一个重要步骤，因为`light_fs`片段着色器将通过`LightShader`类与游戏引擎交互。而`LightShader`类将作为`TextureShader`的子类实现，其中假定这些变量存在。

```
precision mediump float;
// The object that fetches data from texture.
// Must be set outside the shader.
uniform sampler2D uSampler;
// Color of pixel
uniform vec4 uPixelColor;
uniform vec4 uGlobalAmbientColor;
// this is shared globally
uniform float uGlobalAmbientIntensity;
// "varying" keyword signifies that the texture coordinate will be
// interpolated and thus varies.
varying vec2 vTexCoord;
... implementation to follow ...
```

3.  现在，定义支持点光源的变量：开/关开关、颜色、位置和半径。重要的是要注意，位置和半径的单位是像素。
