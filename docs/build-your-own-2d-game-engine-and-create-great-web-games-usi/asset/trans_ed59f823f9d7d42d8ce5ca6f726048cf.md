
# 漫反射与法线贴图

## 项目实验

运行项目以检查实现。尝试使用 `0`、`1`、`2` 和 `3` 键选择灯光，并切换选中灯光的开/关状态。注意，游戏程序员可以控制哪个灯光照亮哪个对象：所有灯光都照亮背景，而主角仅由灯光 `0` 和 `3` 照亮，左侧小兵仅由灯光 `1` 和 `3` 照亮，右侧小兵仅由灯光 `2` 和 `3` 照亮。

使用 `WASD` 键移动主角对象，观察其穿过光源 `0` 的近半径和远半径时照明如何变化。选中光源 `0` 后（按 `0`），按 `C` 键增加光源的近半径。注意，随着近半径接近远半径的值，照亮的圆形边界边缘也会变得更锐利。最终，当近半径大于远半径时，你可以再次观察到边界处的突然亮度变化。你正在观察底层照明模型的一个隐含假设被违反的情况：即近半径总是小于远半径。按 `N` 键减小远半径也可以创造完全相同的情况。

你可以使用方向键移动光源，以观察光的叠加特性。尝试改变光源的 `z` 位置及其近/远值，观察如何通过不同的 `z`/近/远设置实现相似的照明效果。特别地，尝试使用 `K/L` 键调整光强，以观察过度曝光和几乎难以察觉的照明效果。你可以持续按 `L` 键直到强度变为负值，从而创建一个从场景中移除颜色的光源。场景中的两个恒定颜色方块用于确认未被照明的对象仍然可以被渲染。

## 漫反射照明

人眼对光照的观察，是光源发出的可见能量经物体表面反射后到达眼睛的结果。漫反射、哑光或朗伯表面会向各个方向均匀地反射光能量。漫反射表面的例子包括普通打印纸或哑光漆面。图 [8-9](#334805_2_En_8_Chapter.xhtml#Fig9) 展示了一个光源照亮三个漫反射表面元素位置 A、B 和 C 的情况。首先，注意从被照亮位置指向光源的方向被定义为该位置的光线向量 `\hat{L}`。重要的是要注意，`\hat{L}` 向量的方向始终指向光源，并且这是一个大小为 1 的归一化向量。

![Figure 8-9 ¶ Normal and light vectors and diffuse illumination](`images/334805_2_En_8_Chapter/334805_2_En_8_Fig9_HTML.png`)

图 8-9 ¶ 法线与光线向量及漫反射照明

图 [8-9](#334805_2_En_8_Chapter.xhtml#Fig9) 还通过示例展示了漫反射照明，即漫反射的大小。位置 A 无法从给定光源接收任何能量，因为其法线向量 `\hat{N}` 与其光线向量 `\hat{L}` 垂直，即 `\hat{N} \bullet \hat{L} = 0`。位置 B 可以接收所有能量，因为其法线向量与其光线向量指向相同方向，即 `\hat{N} \bullet \hat{L} = 1`。一般来说，如位置 C 所示，漫反射表面接收并反射的光能量比例与其法线与光线向量之间夹角的余弦成正比，即 `\hat{N} \bullet \hat{L}`。在照明模型中，包含 `\hat{N} \bullet \hat{L}` 计算的项被称为漫反射分量或朗伯分量。

## 3D 形状感知

人类视觉系统主要基于 `\hat{N} \bullet \hat{L}`（即漫反射分量）来推断 3D 几何形状轮廓。例如，图 [8-10](#334805_2_En_8_Chapter.xhtml#Fig10) 展示了带有（左图）和不带有（右图）相应漫反射分量的球体和环面（甜甜圈形状物体）。显然，在两种情况下，物体的 3D 轮廓都被带有漫反射分量的左侧图像所捕捉。

## 2D 中的法线贴图

在 2D 世界中，如你的游戏引擎那样，所有对象都表示为 2D 图像或纹理。由于所有对象都是定义在 xy 平面上的 2D 纹理图像，因此所有对象的法线向量都相同：即 `z` 方向的向量。这种对象缺乏独特法线向量的情况意味着无法为对象计算独特的漫反射分量。幸运的是，正如纹理映射解决了每个几何体只能拥有单一颜色的限制一样，法线贴图可以解决每个几何体只能拥有单一法线向量的问题。
