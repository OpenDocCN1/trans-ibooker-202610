

# Phong 光照模型

Phong 光照模型通过 `(\hat{V} \bullet \hat{R})^n` 项来模拟镜面反射的特性。当 `\hat{V}` 和 `\hat{R}` 对齐，或者当 α=0° 时，镜面项的值为 1，并且根据余弦函数，当 `\hat{V}` 和 `\hat{R}` 之间的夹角增加到 90° 或 α=90° 时，该项下降到 0。幂 `n` 被称为光泽度，描述了随着 α 增加，镜面高光衰减的速度。`n` 值越大，余弦函数随 α 增加而减小的速度越快，镜面高光衰减得越快，表面看起来就越光滑。例如，在图 [8-14](#334805_2_En_8_Chapter.xhtml#Fig14) 中，左、中、右三个球体对应的 `n` 值分别为 0、5 和 30。

虽然 `(\hat{V} \bullet \hat{R})^n` 项能有效模拟镜面高光，但为每个着色像素计算 `\hat{R}` 向量的开销可能很大。如图 [8-17](#334805_2_En_8_Chapter.xhtml#Fig17) 所示，半程向量 `\hat{H}` 定义为 `\hat{L}` 和 `\hat{V}` 向量的平均值。观察到 β（即 `\hat{N}` 和 `\hat{H}` 之间的夹角）也可以用来表征镜面反射。虽然略有不同，但 `(\hat{N} \bullet \hat{H})^n` 产生的结果与 `(\hat{V} \bullet \hat{R})^n` 相似，且每像素计算成本更低。半程向量将在你的实现中用于近似镜面反射。

**图 8-17 ¶ 半程向量**

如图 [8-18](#334805_2_En_8_Chapter.xhtml#Fig18) 所示，你将要实现的 Phong 光照模型变体，包含通过三个不同的项来模拟场景中三个参与元素的相互作用。这三个参与元素分别是：全局环境光、光源以及待照明物体的材质属性。前面的示例已经解释了前两项：全局环境光和光源。因此，为了支持 Phong 光照模型，物体的材质属性可以用 `K[a]`、`K[d]`、`K[s]` 和 `n` 来表示。它们分别代表三种颜色（环境反射率、漫反射率和镜面反射率）和一个浮点数（物体的光泽度）。结合全局环境光强度 `I[a]` 和颜色 `C[a]`，以及光源强度 `I[L]` 和颜色 `C[L]`，Phong 光照模型的三个项如下：

*   **环境光项**：`I[a] * C[a] * K[a]`
*   **漫反射项**：`I_L * C_L * K_d * (\hat{N} \bullet \hat{L})`
*   **镜面反射项**：`I_L * C_L * K_s * (\hat{N} \bullet \hat{H})^n`

请注意，前两项（环境光项和漫反射项）已在之前的示例中涵盖。上一个示例中的 `illum_fs` GLSL 片元着色器实现了这两项，包含光距离衰减，但不包含 `K[a]` 和 `K[d]` 材质属性。本项目将指导你构建对每个物体材质属性的支持，并在 `IllumShader`/`IllumRenderable` 对象对的引擎支持下，在 `illum_fs` GLSL 着色器中完成 Phong 光照模型的实现。

## 材质与镜面反射项目

该项目演示了利用法线贴图和相机位置实现的一种 Phong 光照模型版本。它还实现了一个系统，用于存储并转发每个 `Renderable` 对象的材质属性给 GLSL 着色器以进行 Phong 光照计算。你可以在图 [8-20](#334805_2_En_8_Chapter.xhtml#Fig20) 中看到项目运行的示例。该项目的源代码位于 `chapter8/8.5.material_and_specularity` 文件夹中。

该项目的主要控制与前一个项目相同：

*   **`WASD` 键**：移动屏幕上的主角角色

**光照控制：**

*   **数字键 `0`、`1`、`2` 和 `3`**：选择对应的光源
*   **方向键**：移动当前选中的光源
*   **`Z`/`X` 键**：增加/减少光源的 z 位置
*   **`C`/`V` 和 `B`/`N` 键**：增加/减少选中光源的近裁剪和远裁剪距离
*   **`K`/`L` 键**：增加/减少选中光源的强度
*   **`H` 键**：切换选中光源的开/关

**材质属性控制是本项目新增的：**

*   **数字键 `5` 和 `6`**：选择左侧小兵和主角
*   **数字键 `7`、`8` 和 `9`**：选择选中角色（左侧小兵或主角）的 `K[a]`、`K[d]` 和 `K[s]` 材质属性
*   **`E`/`R`、`T`/`Y` 和 `U`/`I` 键**：增加/减少选中材质属性的红、绿、蓝通道
*   **`O`/`P` 键**：增加/减少选中材质属性的光泽度

项目目标如下：

*   理解镜面反射和 Phong 镜面项
*   在 GLSL 片元着色器中实现镜面高光照明
*   理解并体验控制被照明物体的 `Material`
*   检查被照明图像中的镜面高光
