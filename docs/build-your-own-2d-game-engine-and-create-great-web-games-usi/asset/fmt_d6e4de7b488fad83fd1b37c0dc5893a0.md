
背景图像的法线贴图经过精心生成，因此最适合检查镜面反射效果。你可以在背景图像的垂直边界处观察到红色高光。如果不确定，请注意背景图像右上角区域，选择光源 3（按 `3` 键），并切换开/关开关（按 `H` 键）。注意当光源从关切换到开时，整个右上角区域变亮，垂直边界处出现红色高光。这种红色高光是光源 3 向相机的反射。现在，在光源 3 开启的情况下，将其向左和向右移动（左/右箭头键）。观察高光如何随着半程向量 ![$$ \\hat{H} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq44.png) 和面法线向量 ![$$ \\hat{N} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq45.png) 之间夹角的变化而增强然后减弱。

你也可以调整材质以观察英雄模型上的镜面反射。现在，选择英雄对象（按 `6` 键），将其漫反射材质属性降低到 0.2 左右（同时按 `R`、`Y` 和 `I` 键），并将镜面反射属性增加到 1 以上（按 `9` 选择 Specular，然后同时按 `E`、`T` 和 `U` 键）。使用此设置，漫反射项减弱而镜面高光增强，你可以观察到一个带有明亮高光点的暗色英雄模型。如果不确定，尝试切换光源 0（按 `0` 键）开/关（按 `H` 键）。此时，你可以按住 `P` 键降低光泽度 `n` 的值。随着 `n` 值减小，你可以观察到高光点尺寸增大且亮度降低。如图 [8-14](#334805_2_En_8_Chapter.xhtml#Fig14) 中间的球体所示，较小的 `n` 值对应较不光滑的表面，通常表现为高光区域较大但强度较低。

相对较小的物体（如英雄模型）占据的像素不多；相关的高光可能跨越更少的像素，难以观察。镜面高光可以传达微妙且重要的效果；然而，其使用也可能难以掌握。

# 光源类型

此时，你的游戏引擎支持由单一类型光源（点光源）的多个实例进行照明。点光源的行为很像现实世界中的灯泡。它从单个位置发光，具有近、远半径，物体可以被光源完全、部分或完全不照亮。大多数游戏引擎中还有两种流行的光源类型：方向光和聚光灯。

方向光与点光源相反，没有光源位置或范围。相反，它向特定方向照亮所有东西。虽然这些特性可能看起来不直观，但它们非常适合通用背景照明。现实世界中就是这种情况。白天，太阳照亮整个环境，太阳光线可以方便地建模为方向光。从地球视角看，太阳光线几乎是平行的，来自固定方向，并照亮所有东西。方向光是一种简单的光源类型，只需要一个方向变量，没有距离衰减。方向光通常用作照亮整个场景的全局光源。

聚光灯模拟带有锥形灯罩的台灯。如图 [8-21](#334805_2_En_8_Chapter.xhtml#Fig21) 所示，聚光灯是一个被指向特定方向（光照方向）的锥体包围的点光源，具有内、外锥角的角度衰减参数。类似于距离衰减的近、远半径，内锥角内的物体完全被照亮，外锥角外的物体不被照亮，两个角度之间的物体部分被照亮。就像点光源一样，聚光灯常用于在游戏场景的特定区域创建照明效果。聚光灯具有方向和角度衰减参数，为模拟游戏中特定区域的局部效果提供了更精细的控制。 ![Figure 8-21 ¶ A spotlight and its parameters](images/334805_2_En_8_Chapter/334805_2_En_8_Fig21_HTML.png)

## The Directional and Spotlights Project

该项目演示如何将方向光和聚光灯集成到引擎中，以支持更广泛的照明效果。你可以在图 [8-22](#334805_2_En_8_Chapter.xhtml#Fig22) 中看到项目运行示例。该项目的源代码位于 `chapter8/8.6.directional_and_spotlights` 文件夹中。 ![Figure 8-22 ¶ Running the Directional and Spotlights project](images/334805_2_En_8_Chapter/334805_2_En_8_Fig22_HTML.jpg)

Figure 8-22 ¶ Running the Directional and Spotlights project

项目控制如下：

*   **`WASD` 键**：移动屏幕上的英雄角色

光照控制：

*   **数字键 `0`、`1`、`2` 和 `3`**：选择对应的光源。
*   **方向键**：移动当前选中的光源；注意这对方向光（光源 1）无效。
*   **按住空格键 + 方向键**：改变当前选中光源的方向；注意这对点光源（光源 0）无效。
*   **`Z`/`X` 键**：增加/减少光源的 z 位置；注意这对方向光（光源 1）无效。
*   **`C`/`V` 和 `B`/`N` 键**：增加/减少选中光源的内、外锥角；注意这些仅影响场景中的两个聚光灯（光源 2 和 3）。
*   **`K`/`L` 键**：增加/减少选中光源的强度。
*   **`H` 键**：切换选中光源开/关。

材质属性控制：

*   **数字键 `5` 和 `6`**：选择左侧小兵和英雄
*   **数字键 `7`、`8` 和 `9`**：选择选中角色（左侧小兵或英雄）的 `K_a`、`K_d` 和 `K_s` 材质属性
*   **`E`/`R`、`T`/`Y` 和 `U`/`I` 键**：增加/减少选中材质属性的红、绿、蓝通道
*   **`O`/`P` 键**：增加/减少选中材质属性的光泽度

项目目标如下：

*   理解两种额外的光源类型：方向光和聚光灯
*   检查所有三种不同光源类型的照明结果
*   体验控制所有三种光源类型的参数
*   在引擎和 GLSL 着色器中支持三种不同的光源类型
