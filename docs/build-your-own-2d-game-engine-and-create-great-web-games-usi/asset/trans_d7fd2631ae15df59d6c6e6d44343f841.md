

## 安装 ESLint

*   前往 [https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) 并点击安装。
*   系统将提示打开 VS Code，您可能需要在应用程序内再次点击安装。

以下是一些使用 ESLint 的有用参考资料：

*   有关如何使用 ESLint 的说明，请参阅 [https://eslint.org/docs/user-guide/](https://eslint.org/docs/user-guide/)。
*   有关 ESLint 工作原理的详细信息，请参阅 [https://eslint.org/docs/developer-guide/](https://eslint.org/docs/developer-guide/)。

## 下载并安装 LiveServer

运行游戏引擎需要 VS Code 的 LiveServer 扩展。它通过 VS Code 在您的计算机本地启动一个 Web 服务器来托管开发的游戏。与 ESLint 非常相似，您可以通过以下步骤安装 LiveServer：

*   前往 [https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) 并点击安装。
*   系统将提示打开 VS Code，您可能需要在应用程序内再次点击安装。

## 在 VS Code 开发环境中工作

VS Code IDE 易于使用，本书中的项目仅需要编辑器。在父文件夹下组织的相关源代码文件会被 VS Code 解释为一个项目。要打开项目，请选择 `File ➤ Open Folder`（文件 ➤ 打开文件夹），然后导航并选择包含项目源代码文件的父文件夹。项目打开后，您需要熟悉 VS Code 的基本窗口，如图 [1-1](#334805_2_En_1_Chapter.xhtml#Fig1) 所示。

*   **`Explorer window`（资源管理器窗口）**：该窗口显示项目的源代码文件。如果您不小心关闭了此窗口，可以通过选择 `View ➤ Explorer`（视图 ➤ 资源管理器）将其调回。
*   **`Editor window`（编辑器窗口）**：该窗口显示并允许您编辑项目的源代码。您可以通过在资源管理器窗口中单击相应的文件名一次来选择要处理的源代码文件。
*   **`Output window`（输出窗口）**：我们的项目中不使用此窗口；您可以随意通过点击窗口右上角的“x”图标将其关闭。

### 在 VS Code 中创建 HTML5 项目

您现在已准备好创建第一个 HTML5 项目：

*   使用文件资源管理器，在您想要保存项目的位置创建一个目录。该目录将包含与您的项目相关的所有源代码文件。在 VS Code 中，选择 `File ➤ Open Folder`（文件 ➤ 打开文件夹）并导航到您创建的目录。

![Figure 1-2 ¶ Opening a project folder](images/334805_2_En_1_Chapter/334805_2_En_1_Fig2_HTML.png)

图 1-2 ¶ 打开项目文件夹

*   VS Code 将打开项目文件夹。您的 IDE 应类似于图 [1-3](#334805_2_En_1_Chapter.xhtml#Fig3)；请注意，当项目文件夹为空时，资源管理器窗口是空的。

![Figure 1-3 ¶ An empty VS Code project](images/334805_2_En_1_Chapter/334805_2_En_1_Fig3_HTML.png)

图 1-3 ¶ 空的 VS Code 项目

*   您现在可以创建第一个 HTML 文件 `index.html`。选择 `File ➤ New File`（文件 ➤ 新建文件）并将文件命名为 `index.html`。当应用程序启动时，这将作为主页或着陆页。

![Figure 1-4 ¶ Creating the index.html file](images/334805_2_En_1_Chapter/334805_2_En_1_Fig4_HTML.jpg)

图 1-4 ¶ 创建 index.html 文件

*   在编辑器窗口中，将以下文本输入到您的 `index.html` 中：

```html
<!DOCTYPE html> <!-- This is a comment! --> 
<html> 
    <head> 
        <title>TODO supply a title</title> 
    </head> 
    <body> 
        <div>TODO write content</div> 
    </body> 
</html>
```

第一行声明该文件为 HTML 文件。`<!--` 和 `-->` 标签内的块是注释块。成对的 `<html></html>` 标签包含所有 HTML 代码。在本例中，模板定义了 `<head>` 和 `<body>` 部分。`<head>` 设置网页标题，`<body>` 是网页所有内容的所在位置。

如图 [1-5](#334805_2_En_1_Chapter.xhtml#Fig5) 所示，您可以通过点击 VS Code 右下角的“`Go Live`”按钮或按 `Alt+L` `Alt+O` 来运行此项目。您第一次输入上述 HTML 代码后，“`Go Live`”按钮可能不会立即出现。在这种情况下，只需在资源管理器窗口中右键点击 `index.html` 文件，然后点击“`Open with Live Server`”菜单项以启动网页。首次之后，“`Go Live`”按钮将出现在 IDE 右下角区域，如图 [1-5](#334805_2_En_1_Chapter.xhtml#Fig5) 所示。

![Figure 1-5 ¶ Click the Go Live button to run a project](images/334805_2_En_1_Chapter/334805_2_En_1_Fig5_HTML.png)

图 1-5 ¶ 点击 Go Live 按钮运行项目

> **Note（注意）**
>
> 要运行项目，当点击“`Go Live`”按钮或输入 `Alt+L` `Alt+O` 键时，该项目的 `index.html` 文件必须在编辑器中打开。这在后续章节中将变得很重要，因为那时项目中会有其他 JavaScript 源代码文件。

图 [1-6](#334805_2_En_1_Chapter.xhtml#Fig6) 显示了运行时默认项目的外观示例。请注意，项目开始运行后，“`Go Live`”按钮会更新其标签以显示“`Port:5500`”。您可以再次点击此按钮，将 IDE 与网页断开连接，以再次观察“`Go Live`”标签。再次点击按钮将重新运行项目。

要停止程序，只需关闭网页即可。您已成功运行第一个 HTML5 项目。通过开发这个非常简单的项目，您已经熟悉了 IDE 环境。

## 如何使用本书

本书将指导您通过构建项目来开发游戏引擎，这些项目类似于您刚刚体验的项目。每一章涵盖典型游戏引擎的一个基本组件，每章中的各节描述了构建相应组件的重要概念和实现项目。全书中，每节的项目都建立在前面各节项目结果的基础之上。虽然这使得跳跃阅读本书略具挑战性，但它将为您提供实践经验，并让您扎实理解不同概念之间的联系。此外，您不再总是使用新的、极简的项目，而是在将新功能集成到不断扩展的游戏引擎中时，获得构建更大、更有趣项目的经验。
