
## 第一种设计技巧：密室逃脱场景

我们将探索的第一种设计技巧是一个简单的练习，它能让你开始学习游戏设计的“字母表”：一个只包含单一简单机制的“密室逃脱”场景，玩家必须完成一项任务才能解锁大门并获得奖励。这个练习将帮助你培养创建结构良好、逻辑严密、可被发现且一致的规则的洞察力，当任务被分解为基本交互时，这要容易实现得多。你已经在早期项目中探索过潜在的基于规则场景的雏形：回顾第 [4](#334805_2_En_4_Chapter.xhtml) 章的“键盘支持”项目，它建议你可以让玩家将一个较小的方块完全移入一个较大方块的边界内，以触发某种行为。那种单一交互（或“游戏字母表中的字母”）该如何组合，才能形成一个讲得通的游戏机制（或“单词”）呢？图 [7-13](#334805_2_En_7_Chapter.xhtml#Fig13) 为密室谜题设定了舞台。 ![图 7-13 ¶ 该图像代表一个被分为三个区域的单个游戏画面。左侧是一个可玩区域，包含一个主角角色（标记为 P 的圆圈），一个标有锁图标的不可通过屏障，以及右侧的奖励区域](images/334805_2_En_7_Chapter/334805_2_En_7_Fig13_HTML.jpg)

图 7-13 ¶ 该图像代表一个被分为三个区域的单个游戏画面。左侧是一个可玩区域，包含一个主角角色（标记为 P 的圆圈），一个标有锁图标的不可通过屏障，以及右侧的奖励区域

图 [7-13](#334805_2_En_7_Chapter.xhtml#Fig13) 中所示的画面是在探索新机制时一个有用的切入点。本练习的目标是创建一个合乎逻辑的挑战，玩家必须完成它才能解锁屏障并到达奖励处。任务的具体性质可以基于各种基本机制：可能涉及跳跃或射击、解谜、叙事情境等。关键在于保持这个首次迭代的**简单性**（第一个挑战应只有有限数量的组成部分构成解决方案）和**可发现性**（玩家必须能够通过实验学习交战规则，从而有意识地解决挑战）。你将在后续迭代中为机制增加复杂性和趣味性，并会看到基本机制如何演变以支持多种游戏类型。

图 [7-14](#334805_2_En_7_Chapter.xhtml#Fig14) 为一个逻辑关系机制设定了舞台，玩家必须与环境中的物体互动以学习规则。 ![图 7-14 ¶ 游戏画面布满了各种单独的物体](images/334805_2_En_7_Chapter/334805_2_En_7_Fig14_HTML.jpg)

图 7-14 ¶ 游戏画面布满了各种单独的物体

仅凭观察图 [7-14](#334805_2_En_7_Chapter.xhtml#Fig14) 并不能立刻看出玩家需要做什么来解锁屏障，因此他们必须通过实验来学习游戏世界运作的规则；正是这种实验构成了驱动玩家推进关卡的游戏机制的核心要素，而该机制的满意度取决于其规则的可发现性和逻辑一致性。在这个例子中，想象当玩家在游戏画面中移动主角角色时，他们会注意到当主角与物体互动时，物体总会以高亮形式“激活”，如图 [7-15](#334805_2_En_7_Chapter.xhtml#Fig15) 所示，有时还会导致锁图标的一个区段和锁周围环的三分之一发光。然而，某些形状被激活时不会导致锁和环发光，如图 [7-16](#334805_2_En_7_Chapter.xhtml#Fig16) 所示。 ![图 7-15 ¶ 当玩家在游戏画面中移动主角角色时，形状会以高亮“激活”（#1）；激活特定形状会导致锁的一个区段和周围环的三分之一发光（#2）](images/334805_2_En_7_Chapter/334805_2_En_7_Fig15_HTML.jpg)

敏锐的玩家会相当快地领会这个谜题的规则。仅凭观察图 [7-15](#334805_2_En_7_Chapter.xhtml#Fig15) 和 [7-16](#334805_2_En_7_Chapter.xhtml#Fig16)，你能猜出规则可能是什么吗？如果你感到困惑，图 [7-17](#334805_2_En_7_Chapter.xhtml#Fig17) 应该能提供足够的信息来解开谜题。 ![图 7-17 ¶ 在第一个物体被激活（右上角的圆圈）并导致锁的顶部区段和环的第一个三分之一发光后（如图 7-15 所示），正确序列中的第二个物体（#5）导致锁的中部区段和环的第二个三分之一发光（#6）](images/334805_2_En_7_Chapter/334805_2_En_7_Fig17_HTML.jpg)

图 7-17 ¶ 在第一个物体被激活（右上角的圆圈）并导致锁的顶部区段和环的第一个三分之一发光后，如图 [7-15](#334805_2_En_7_Chapter.xhtml#Fig15) 所示，正确序列中的第二个物体（#5）导致锁的中部区段和环的第二个三分之一发光（#6）

现在，你（和玩家）应该拥有学习该机制规则并解开谜题所需的所有线索。玩家可以与三种形状互动，每行每种形状只有一个实例；这些形状代表锁图标的顶部、中部和底部，正如图 [7-15](#334805_2_En_7_Chapter.xhtml#Fig15) 所示，激活圆形导致锁的对应区段发光。然而，图 [7-16](#334805_2_En_7_Chapter.xhtml#Fig16) 并未导致锁的对应区段发光，这种差异就是该机制的“钩子”（核心吸引点）：锁的区段必须按正确的相对位置激活：顶行激活顶部，中行激活中部，底行激活底部（你也可以选择要求玩家按正确顺序激活，从顶部开始，尽管仅从图 [7-15](#334805_2_En_7_Chapter.xhtml#Fig15) 到 [7-17](#334805_2_En_7_Chapter.xhtml#Fig17) 无法直接发现这一要求）。

恭喜，你现在已经创建了一个结构良好且逻辑自洽（尽管简单）的谜题，拥有构建更大、更宏大关卡所需的所有要素！这个解锁序列是一个没有叙事背景的游戏机制：在这个设计阶段，游戏画面刻意没有游戏设定、视觉风格或类型归属，因为我们不想让探索过早地背负任何预设期望。作为设计师，在添加叙事和类型等高层游戏元素之前，花时间探索游戏机制最纯粹的形式是大有裨益的，当你把这些简单机制构建出来时，你很可能会惊讶于它们将你带向的意想不到的方向。

像本例中的简单机制可以描述为“按正确顺序完成多阶段任务以达成目标”，并出现在许多类型的游戏中；例如，任何要求玩家收集物体部件并在物品栏中组合它们以完成挑战的游戏，都利用了这一机制。单个机制也可以与其他机制和游戏特性结合，形成复合要素，为你的游戏体验增加复杂性和风味。
