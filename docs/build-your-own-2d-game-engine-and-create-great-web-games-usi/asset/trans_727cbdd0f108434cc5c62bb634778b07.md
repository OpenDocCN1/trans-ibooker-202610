## 扩展关卡设计

现在是时候开始布局关卡，以充分利用额外的水平空间了。此时无需更改基本玩法；你只需扩展当前的关卡设计以适应游戏屏幕的新尺寸。

现在关卡有了额外的空间可供利用，有几个因素需要评估和调整。例如，图 [12-5](#334805_2_En_12_Chapter.xhtml#Fig5) 中主角的缩放比例已缩小，以增加在单个屏幕上可执行的垂直跳跃次数。注意，此时如果需要，你也有机会在设计中加入额外的垂直玩法，实现与左右移动摄像机相同的上下移动机制；许多 2D 平台游戏允许玩家在游戏世界中进行水平和垂直双向移动。为求简单，该关卡原型将移动限制在 `x` 平面（左右），尽管你可以轻松地在未来的迭代和/或后续关卡中扩展关卡设计以包含垂直玩法。

### 调整挑战与增加趣味性

在此设计阶段，谜题制作过程真正开始展开；图 [12-6](#334805_2_En_12_Chapter.xhtml#Fig6) 展示了仅凭你一直在使用的几个基本元素就能创造出极具吸引力的玩法的潜力。作者在各类游戏的头脑风暴会议中使用上述模板及类似变体——向一个被充分理解的机制引入一两个新颖元素并探索新增内容对玩法的影响——结果往往能开辟出令人兴奋的新方向。例如，你可以引入出现和消失的平台、开关激活后旋转的平台、移动的能量场、传送站等。当然，扩展该机制的方法列表是无限的，但目前的模板定义已足够清晰，以至于添加单个新元素在纸上实验和测试都相当容易。

新扩展的关卡设计有两个因素增加了挑战性。首先，水平移动平台的加入要求玩家更精确地把握跳向“电梯”平台的时机（如果他们在平台上升时跳跃，在能量场电击他们之前，几乎没有时间去关闭它）。第二个因素不那么显而易见，但同样具有挑战性：任何时候只能看到关卡的一部分，因此玩家无法像在单屏可见整个布局时那样，轻松建立整个关卡序列的心智模型。设计师理解显性挑战（如要求玩家把握在两个移动平台间跳跃的时机）和不那么明显（且往往是无意的）挑战（如任何时候只能看到关卡的一部分）都很重要。回想一下你玩过的某款游戏，感觉设计师指望你记住太多元素；这种挫败感往往是无意的挑战过度负担了玩家短期记忆所能合理容纳的内容所导致的。

作为设计师，你需要意识到隐藏的挑战和无意造成的挫败或困难区域；这些正是为什么至关重要地需要尽早、尽可能频繁地观察人们玩你的游戏的关键原因。一般来说，每当你 100% 确信自己设计的东西完全讲得通时，至少有一半玩你游戏的人会告诉你完全相反的情况。虽然详细讨论用户测试的益处超出了本书范围，但你应该计划从最早的概念验证一直到最终发布，都观察人们玩你的游戏。没有任何东西能替代你通过观看不同人玩你设计的内容所获得的洞见。

如前几幅图所述，该关卡目前假设主角只能站在平台上；虽然没有关于角色跳跃失误掉到屏幕底部会发生什么的设计计划，但玩家理所当然会认为这会导致失败状态并触发游戏重置。如果你在关卡中添加了“地板”，玩家策略将明显改变；除了消除一个重大风险外，玩家还能直接进入电梯平台，如图 [12-7](#334805_2_En_12_Chapter.xhtml#Fig7) 所示。
