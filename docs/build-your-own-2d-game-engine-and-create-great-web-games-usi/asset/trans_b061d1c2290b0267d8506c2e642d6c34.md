

## 测试法线贴图

与引擎中的所有其他着色器类似，必须定义一个 `IllumShader` 的默认实例以供共享。定义默认 `IllumShader` 实例所涉及的代码与本章前面介绍的 `LightShader` 完全相同，唯一直接的区别在于替换相应的变量名和数据类型。详情请参阅“定义默认 LightShader 实例”小节以及 `src/engine/core` 文件夹中的 `shader_resources.js` 源代码文件。

### 修改主角和小兵

测试新集成的法线贴图功能必须包括验证非法线贴图的简单颜色纹理是否正常工作。为实现这一点，背景、主角和左侧小兵将被创建为新定义的 `IllumRenderable` 对象，而右侧小兵将保持为 `LightRenderable` 对象。

`Hero` 和 `Minion` 对象应实例化为新定义的 `IllumRenderable` 对象：

1.  编辑 `src/my_game/objects` 中的 `hero.js`，修改 `Hero` 类的构造函数，以使用 `IllumRenderable` 实例化游戏对象：

```javascript
constructor(spriteTexture, normalMap) {
    super(null);
    this.kDelta = 0.3;
    this.mRenderComponent = new engine.IllumRenderable(
        spriteTexture, normalMap);
    this.mRenderComponent.setColor([1, 1, 1, 0]);
    ... identical to previous code ...
}
```

2.  在同一文件夹中，编辑 `minion.js`，修改 `Minion` 类的构造函数，以便在存在法线纹理贴图时，有条件地使用 `LightRenderable` 或 `IllumRenderable` 实例化游戏对象：

```javascript
constructor(spriteTexture, normalMap, atX, atY) {
    super(null);
    this.kDelta = 0.2;
    if (normalMap === null) {
        this.mRenderComponent = new engine.LightRenderable(
            spriteTexture);
    } else {
        this.mRenderComponent = new engine.IllumRenderable(
            spriteTexture, normalMap);
    }
    ... identical to previous code ...
}
```

## 观察

项目现已完成，你可以运行它并检查结果，以观察漫反射光照的效果。请注意，`Hero`、左侧 `Minion` 和背景对象都通过漫反射计算进行光照，并呈现出由光源带来的更多深度感。这些对象上的颜色和阴影变化丰富得多。

你可以验证图 [8-7](#334805_2_En_8_Chapter.xhtml#Fig7) 左侧图像中观察到的奇特效果已得到解决。为了更清晰地观察，关闭除 2 号灯光外的所有其他灯光（输入灯光编号后跟 `H` 键）。现在，移动灯光位置（使用 `方向键`）以照亮 `Hero` 角色身后的几何方块；你可以使用 `WASD` 键将其移开。验证你看到的结果是否与图 [8-7](#334805_2_En_8_Chapter.xhtml#Fig7) 右侧图像相似。你应该能清晰地观察到对应点光源位置的最亮点。此外，请注意，方块的底面仅当灯光位置*在*该面*前方*时，或者当漫反射项 ![$$ \hat{N}\bullet \hat{L} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq15.png) 为正时才会被照亮。

一般来说，当你移动光源时，观察具有垂直朝向的面，例如几何方块的侧面或缝隙。当光源位置移过此类边界时，![$$ \hat{N}\bullet \hat{L} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq16.png) 项的符号会翻转，相应的表面光照会发生剧烈变化（从暗变亮，或反之）。为了获得更显著的效果，降低光源的 `z` `height`（使用 `X` 键）至低于 5 的值。借助法线贴图和漫反射计算，你已将静态背景图像转变为由复杂 3D 几何形状定义的背景。尝试移动其他光源，并观察光源移过物体时所有物体上的光照变化。

最后，`Hero` 和左侧 `Minion` 略微呈现像素化和粗糙的外观，这证明这些对象的法线贴图是根据相应的颜色图像通过算法生成的，而非由美术师创建。

## 镜面反射与材质

你实现的漫反射光照适用于模拟哑光表面的光照，例如普通打印纸、许多室内涂料墙面，甚至传统黑板。Phong 光照模型通过引入镜面项来扩展这种简单的漫反射光照，以模拟光源在光滑表面上的反射。图 [8-14](#334805_2_En_8_Chapter.xhtml#Fig14) 展示了三个球体的示例：一个简单的哑光球体、一个具有中等镜面高光的球体和一个高度抛光的球体。右侧两个球体上的高光是 Phong 镜面项的结果。 ![图 8-14 ¶ 物体的镜面度与光泽度](images/334805_2_En_8_Chapter/334805_2_En_8_Fig14_HTML.jpg)

图 8-14 ¶ 物体的镜面度与光泽度

图 [8-15](#334805_2_En_8_Chapter.xhtml#Fig15) 说明了给定一个光亮或反射表面（如抛光地板或抛光塑料），当眼睛或摄像机位于光源的反射方向上时，光源的反射将可见。光源在光滑表面上的这种反射被称为*镜面反射*、*镜面高光*或*镜面度*。 ![图 8-15 ¶ 镜面度：光源的反射](images/334805_2_En_8_Chapter/334805_2_En_8_Fig15_HTML.png)

图 8-15 ¶ 镜面度：光源的反射

根据现实生活经验，即使眼睛的观察方向未与光源的反射方向完美对齐，镜面高光依然可见。如图 [8-16](#334805_2_En_8_Chapter.xhtml#Fig16) 所示，其中 ![$$ \hat{R} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq17.png) 向量是光向量 ![$$ \hat{L} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq18.png) 的反射方向，即使观察方向 ![$$ \hat{V} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq19.png) 未与 ![$$ \hat{R} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq20.png) 向量完美对齐，物体上的镜面高光依然可见。现实经验还告诉我们，![$$ \hat{V} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq21.png) 偏离 ![$$ \hat{R} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq22.png) 越远，或者角度 `α` 越大，观察到光反射的可能性就越小。事实上，当 `α` 为零时，你会观察到最大的光反射；当 `α` 为 90°，或者 ![$$ \hat{V} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq23.png) 与 ![$$ \hat{R} $$](images/334805_2_En_8_Chapter/334805_2_En_8_Chapter_TeX_IEq24.png) 垂直时，你会观察到零光反射。 ![图 8-16 ¶ Phong 镜面模型](images/334805_2_En_8_Chapter/334805_2_En_8_Fig16_HTML.png)
