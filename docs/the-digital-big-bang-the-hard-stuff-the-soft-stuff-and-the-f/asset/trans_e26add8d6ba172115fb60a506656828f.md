

## 数字大爆炸

与跨行业和组织的安保团队合作固然有利，但与公司非安全团队协作也有巨大益处。对于必须审慎使用预算和分配的企业来说，这不仅能取得更好的安全成果，也是对组织资金更明智、更高效的利用。在确定需要何种可见性之前，先检查一下你已有的可见性——它可能远比你意识到的要多。

在技术驱动的文化中，很容易陷入一种思维定势，即认为进步只体现在巨大的飞跃上。那些飞跃令人兴奋且令人满意——尤其是对分配预算并寻求稳健投资回报的人来说。但它们很快就会导致收益递减——更糟的是，产生虚假的安全感。

为自身目的而追求更高水平的可见性，并不等于更有效的安全。事实上，太多可见性反而会使人更难清晰地看到最危险的威胁。浪费时间和精力去查看不相关的数据，只会让罪犯更有能力大隐隐于市。渐进、稳步的可见性提升不仅是良好且值得称赞的——它也可能带来更佳的安全效果。即使从 1% 到 5% 的可见性提升，如果该提升由洞察力和理解力驱动，也能带来显著更好的结果。

这是一种视角和方法，将只会变得对可见性愈发根本。随着更多 IT 团队利用开源技术和新的业务系统与基础设施方法，我们现在看到的速度将继续加快。随着这种变化速度的加快，我们从过去的证据中得知，我们的对手会竭尽全力跟上。比任何其他因素更重要的是，威胁行为者有能力在跟上这一竞赛中击败防御者，这造成了我们最大的风险。阻止他们的关键在于了解他们要去哪里以及他们计划如何到达。使用新的可见性方法在他们到达之前将其拦截，可以成为这场竞赛中的关键工具。

## 可见性的挑战

*Daniel Hooper, PIMCO*

大多数组织今天面临的主要挑战不仅仅是应对已知未知，例如针对已知漏洞的 WannaCry 等威胁，还包括未知已知。谁在网络上、网络上有什么以及数据位于何处，正因技术 proliferate 和 IT 团队与业务创新速度加快而变得复杂。

技术增长的步伐正在加快，人工智能和机器学习正在推动技术的 proliferate 和复杂性，跟上这种变化始终是一个挑战。例如，在我于 PIMCO 的四年里，我们的核心 Oracle 数据库已从 80 TB 增长到超过 160 TB，我们预计在未来六个月内将超过 300 TB。与此同时，我们的分析人员正在利用机器学习、AI 以及 MapR 和 Apache Hadoop 等工具开发新的价格预测计算方法。

这些新技术、工作流程和应用程序驱动的输入和输出 proliferate 正在推动 IT 的增长以及风险的增长。开发在不同技术上运行的分散数据中心或为细分市场开发新产品的组织可能在开始时并未考虑安全。假设这些不同环境是隔离的，但现实是数据、流量和资源始终会渗入生产环境，一切开始混合。

在如此快速发展的环境中，弄清哪些系统在线——业务、个人、访客或客户——不仅困难，而且只是挑战的一部分。可视性不仅仅是了解网络上有什么——它还关乎网络之外有什么，例如影子 IT、并行网络或移动设备。现实是，组织内部的许多利益相关者完全有权自主运营。CIO 可能不认为他们会这样做，但很多时候他们只需要一个目标和一张公司信用卡就可以去 Amazon Web Services (AWS) 并启动一项服务。

### 可见性关乎的不仅是技术

CISO 的主要可见性挑战之一是看到即将到来的变化。实现这一点需要的不只是理解业务目标或 IT 计划。它还需要接入业务的正确领域，并与组织各地的各种利益相关者取得联系。这需要与各个团队和部门负责人建立关系，以了解他们的驱动因素和需求，而这些需求超出了 IT 所提供的。虽然 CIO 与其业务重点保持一致，但他们并未像个人利益相关者那样深入了解其需求。

主流业务之外的组织，例如人力资源，经常会自行启动离网系统和服务。原因是人力资源对员工绩效管理或招聘的需求可能与公司的核心业务不一致，这意味着现有 IT 可能无法满足其独特需求。例如，他们可能需要一个招聘广告服务来发布职位。随着在线上可用的服务如此之多，他们无需等待 IT 交付。但这也意味着他们可能正在积累需要受保护的候选人信息，尤其是在《通用数据保护条例》(GDPR) 等法规下。这些账外资源不仅会造成风险；它们会造成你甚至可能不知道的风险。

### 与关键利益相关者建立关系

与公司管理层建立关系通常能让你洞察他们所需的资源类型，以及他们的发展计划和资源部署。这包括参与指导小组和委员会，并与评估云供应商等职能部门负责人建立关系。一旦这些关系建立起来，你就可以建议他们暂停，以便你在项目被选定和部署之前了解如何将你的安全策略整合到他们的项目中。

### 胡萝卜加大棒

但即使这些利益相关者和领导者也可能无法完全了解其团队成员为完成工作而做的事情。你需要与批准费用的团队建立关系。他们可以为你标记在线服务和新技术的费用以供审查。此外，了解网络中运行何种并行或影子 IT 也意味着使用法务作为中央联系人来审查与服务提供商的工作合同。

所有这些数据随后可以汇总到供应商管理系统，帮助你了解这些供应商是谁、为何被聘用、如何使用以及他们持有何种信息。专有贸易信息、客户或员工的个人身份信息 (PII) 以及保存在未知地点、使用未经验证的应用程序和服务的营销和业务计划，可能已经使你的组织暴露于不必要的风险。

你不想以艰难的方式了解到这些挑战。缺乏可见性的后果会产生不愉快的意外，例如 FBI 发来邮件说他们在暗网上发现了你的公司信息，或一家控制 AWS 站点 S3（简单存储服务）信息的公司打电话告诉你他们刚刚发现的内容。

应对这一挑战需要胡萝卜加大棒的方法。你可以通过让管理层知道共享信息可以让他们获得使工作更轻松的 IT 服务（单点登录、多因素身份验证、联合 ID、Active Directory 服务以跟踪登录、技术集成、加快新技术或服务的审批等）来保持对新技术和资源的前沿了解。

大棒不必太严厉。从教育人们为什么不能仅仅因为容易就启动一个新聊天程序开始。解释他们保护员工和客户信息的义务，以及妥协是每个人的问题。帮助他们理解为什么他们需要带着请求来找技术团队。
