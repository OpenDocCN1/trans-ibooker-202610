## 进行设计研究的方法论框架与模型

## 引言

设计本位研究（DBR）是一种将理论与实践见解相结合的方法论，用于在真实环境中开发、测试和完善教育干预措施。用于开展 DBR 的各种框架和模型已经出现，每个框架都强调研究过程的不同方面，并以独特的方式为教育领域做出贡献。本章概述了几个突出的框架，强调了每个框架的重要性以及它们如何指导有效教育实践的发展。

## 进行 DBR 的主要框架与模型

## DBRC 框架（2003）

DBRC 框架（2003）是教育设计研究中一个开创性的框架，强调通过迭代、协作的方法解决复杂的教育问题。该框架包含关键阶段，包括识别重大的现实世界教育挑战、设计基于理论的创新解决方案、在真实情境中实施和完善这些干预措施，以及产生促进实践和理论理解的见解。DBRC 框架强调紧密联系设计和研究过程的重要性，以确保干预措施有效且可持续。该框架的标志性特征是其对设计、测试和完善的迭代循环的关注，这使研究人员和从业者能够根据反馈和观察结果调整干预措施。

DBRC 框架通过弥合理论与实践之间的差距，对教育设计研究领域做出了重大贡献。它将研究范式从孤立的理论研究转变为以情境为敏感、以协作为主、优先考虑现实世界影响的方法。通过强调与教育工作者共同创造解决方案并关注可扩展性和可转移性，DBRC 模型使得开发既切合实际又在理论上健全的干预措施成为可能。其对设计、实施和分析的整合已成为现代教育设计研究方法论的基石。

| Features | • 强调设计、实施、分析与修订的迭代循环。 • 专注于理论构建和解决现实世界问题。 |
| Distinct Contribution | 确立了 DBR 作为将创新与理论构建统一的范式。 |

| Example in Context | 一所学校希望改善数学中的协作解决问题能力。研究人员和教育工作者共同合作开发包含协作任务的新课程单元。初步实施后，研究人员收集学习者参与度和解决问题策略的数据，他们完善任务并重新测试，通过迭代直至实现最佳成果。 |

## Barab 和 Squire 的发展研究模型（2004）

Barab 和 Squire 的发展研究模型（2004）强调教育情境中理论与实践的共同演化。该模型以这样一个原则为基础：教育创新不仅应解决课堂的即时挑战，还应促进更广泛的理论理解。他们指出，DBR “要求不仅仅展示某种特定设计如何运作，而是要求研究人员生成基于证据的学习主张，这些主张解决当代理论问题并推进该领域的理论知识”（第 5–6 页）。发展研究模型（2004）具有设计、实施和完善的迭代循环，干预措施在真实学习环境中开发，并根据合作伙伴的反馈持续调整。该模型的一个独特方面是其对生态效度的关注，确保干预措施具有情境敏感性并适用于不同的教育环境。

倡导研究与实践之间的共生关系极大地丰富了我们对 DBR 的理解。它强调解决现实世界教育问题的同时生成推进学术理论的见解。通过将研究置于真实环境中并让从业者作为共同研究者参与，Barab 和 Squire 的方法确保创新既实用又可持续。该模型在促进适应性强、可扩展的教育解决方案的发展方面发挥了重要作用，并塑造了研究人员对 DBR 作为动态过程的迭代性质的思考，该过程会根据情境需求和挑战而演变。

| Features | - 优先同时推进理论理解和实践应用。 - 强调设计、实施和完善的重复循环，以逐步改进干预措施。 - 确保干预措施在真实学习环境中开发，反映现实世界的挑战和需求。 - 让教育工作者、学习者和其他合作伙伴作为共同研究者参与，促进协作解决问题。 - 强调创建具有情境敏感性且可扩展到不同教育环境的解决方案的重要性。 - 鼓励根据反馈和结果持续调整干预措施，以确保其保持有效和相关。 - 寻求在产生推进更广泛教育理论的见解的同时提供实用解决方案。 - 专注于设计不仅有效而且可适应长期使用和跨不同情境的创新。 |
| Distinct Contribution | 将 DBR 框定为在真实环境中理论与实践的共同演化。 |
| Example in Context | 一所学校为历史课程实施新的基于游戏的学习平台。教育工作者和研究人员合作将平台整合到课程中，基于课堂观察、教育工作者反馈和学习成果，迭代完善游戏的设计和教学对齐。 |

## Collins, Joseph 和 Bielaczyc 的设计实验（2004）

Collins, Joseph 和 Bielaczyc 的设计实验（2004）框架的一个关键优势是其使用多种数据源来捕捉课堂互动的复杂性，使研究人员能够解决即时的教育挑战和更广泛的系统性问题。Collins 等人（2004）引入了“设计实验”一词，反映了对自然情境中学习进行实证研究的重点。他们的模型将课堂视为检验学习理论在实践中如何运作的实验室。它与其他 DBR 模型不同之处在于其强烈的实证导向：系统收集和三角验证定量、定性和过程数据以理解学习的机制。虽然 DBRC 和 Barab 和 Squire 强调伙伴关系和理论-实践共同发展，但 Collins 等人专注于方法论严谨性，将 DBR 确立为分析复杂教学现象的科学可信方法。

| Features | • 迭代设计循环以研究自然情境中的学习。 • 专注于理解教学和学习的复杂性。 • 采用设计、实施、观察和完善的循环过程来改进干预措施。 • 旨在为即时的教育挑战提供实用解决方案并为更广泛的适用性生成理论见解。 • 鼓励研究人员与从业者密切合作，以确保干预措施相关且植根于课堂现实。 • 使用多种数据源（例如定性和定量）来捕捉教育环境的细微动态。 • 寻求开发可适应各种情境并长期持续的干预措施。 • 在构建现有教育理论的同时，也通过实证发现促进其演进。 |
| Distinct Contribution | 将课堂定位为研究实验室和先进方法论严谨性的场所。 |

### Example in Context

一个研究团队希望为三至六年级学习者开发一个个性化阅读计划，旨在提高理解力和参与度。该计划整合了自适应数字工具、教师指导活动和同伴协作。为了评估和完善干预措施，团队采用了稳健、多方面的资料收集策略：

+   1. 定量数据：
+      - 测前和测后评估衡量阅读理解和词汇发展。
+      - 参与度指标追踪在数字平台上花费的时间和任务完成率。
+   2. 定性数据：
+      - 课堂观察捕捉教育工作者-学习者互动和活动期间学习者协作情况。
+      - 与学习者的焦点小组提供其经验和偏好的见解。
+   3. 过程数据：
+      - 来自数字平台的学习分析追踪个别学习者进展，突出模式和系统可改进的领域。
+   4. 教育工作者反馈：
+      - 定期访谈和调查收集教育工作者对计划可用性、与课程目标的一致性以及观察到的学习成果的观点。

通过数据分析和干预完善的迭代循环，研究人员识别出什么有效、什么无效以及原因。例如，他们可能会发现学习者在某些自适应任务上遇到困难，并利用这些信息修改计划的难度调整算法。这种全面的数据收集方法不仅改进了阅读计划，还为个性化学习和数字干预设计理论做出了贡献。





## Reeves 设计研究模型（2000, 2006）

Reeves 设计研究模型（2000, 2006）的关键贡献在于将 DBR 运作为一种系统而灵活的方法论，可应用于课程设计、教育技术和专业学习。相较于早期的概念模型，Reeves 为 DBR 提供了实用的研究支架，确保透明度、可复制性和知识的累积构建。

该模型分为四个关键阶段：（1）实践问题的分析，在此阶段识别并彻底审视现实世界的问题，以确保研究植根于真实需求；（2）解决方案的开发，涉及针对已识别问题创建循证干预措施或工具；（3）迭代测试与完善，在真实环境中测试解决方案，并根据数据做出调整以提高其有效性；以及（4）反思以完善理论与实践，使研究人员能够评估研究结果的更广泛影响并为理论体系做出贡献，同时为教育者提供可操作的见解。

Reeves 模型的另一个显著特点是其对协作伙伴关系的关注，确保干预措施与教育者共同设计，以符合现实的教育情境。通过将理论严谨性与实践相关性相结合，该模型弥合了研究与应用之间的差距，促进了可持续且可扩展的创新。该模型在推进 DBR 在教育技术、课程开发和教育者培训中的整合方面发挥了重要作用。

|  | • 旨在解决现实的教育挑战，同时产生理论知识。 |

## McKenney 和 Reeves 的 EDR 框架（2012）

McKenney 和 Reeves（2012）开发的 EDR 框架被广泛认为是教育研究领域最具影响力的模型之一。基于对早期模型的分析，该框架提出了一个通用且可适应的结构，概括了 EDR 过程的本质。它强调三个关键阶段：分析/探索、设计/构建和评估/反思。这些阶段与现实实践无缝互动。框架的灵活性使其能够适应各种教育情境，同时保持其核心重点，即产生实践干预和理论知识的双重产出。这种双重目的方法确保研究结果不仅解决教育中的即时挑战，还为该领域的知识体系做出贡献。

McKenney 和 Reeves 的 EDR 框架（2012）对教育研究和实践具有重要意义。它通过明确阐述双重成果——可用的教育干预措施和完善的理论洞见——并在整个过程中嵌入持续的实践者协作，从而推动了该领域的发展。与早期的 DBR 形式不同，EDR 不是一种特定的设计循环，而是一种元方法论，可在不同情境和规模水平上进行调整。它还强调教师的能力建设，将教育者定位为通过参与设计而学习的共同设计者。通过专注于产生既可扩展又以证据为基础的干预措施，该框架支持可持续教育创新的发展。此外，理论洞见的产生丰富了对教学和学习过程的学术理解，促进了持续改进和创新。这种双重关注使 EDR 框架成为推进教育实践和研究的宝贵工具。

## Plomp 的 EDR 阶段（2013）

Plomp 的 EDR 阶段（2013）为通过系统且迭代的过程解决复杂的教育挑战提供了一个结构化框架。该模型包含三个核心阶段：初步研究，在此阶段识别问题并进行情境分析；原型设计，涉及通过迭代测试设计和完善干预措施；以及评估，评估干预措施的有效性和理论贡献。Plomp 方法的独特之处在于其在结构与灵活性之间的平衡：每个阶段都明确将实证研究与迭代设计联系起来。与 McKenney 和 Reeves 相比，Plomp 更强调评估和有效性的正式评估，提供了一个更线性但仍具迭代性的过程。他的模型广泛用于应用性教育开发项目，研究人员和实践者在此协作创建经过验证、可扩展的解决方案。

| Features | • 三个核心阶段：初步研究、原型设计和评估。 |
|  | • 持续的测试和反馈改进干预措施。 |
|  | • 平衡实践应用和理论进步。 |
|  | •  engaging 合作伙伴以确保与现实需求保持一致。 |
|  | • 促进研究人员与实践者之间的伙伴关系。 |
|  | • 设计可在不同情境中适应和持续的解决方案。 |
| Distinct Contribution | 简化了课程和教学设计项目的 EDR。 |
| Example in Context | 一个研究团队应用了 Plomp 的框架来开发学习者的数字素养课程。在初步研究阶段，他们通过调查和文献综述确定了在线安全、信息评估和编码技能方面的差距。 |

在原型设计阶段，他们设计了互动模块并在课堂上进行测试，通过学习者和教育者的迭代反馈完善课程。最后，在评估阶段，该课程在多所学校实施，学习者表现和参与度的数据突出了其有效性并为进一步完善提供了信息。

## DBIR 模型（2017）

DBIR 由 Fishman 等人（2013）阐述，代表了 DBR 的重要演进，将其关注点从课堂层面的创新扩展到系统性教育变革。传统 DBR 和 EDR 专注于开发和完善干预措施，而 DBIR 则将实施本身作为设计过程加以突出。它认识到，有效且持久的创新不仅依赖于设计良好的教学解决方案，还依赖于支持其采用和可持续性的组织、社会和政策基础设施。

DBIR 建立在四个指导原则之上：（1）与教育者共同识别的实践持续性问题；（2）将教育者作为平等合作伙伴参与的迭代共同设计过程；（3）对持续变革能力的承诺；以及（4）关于学习和实施的理论生成。实施不是终点，而是一个持续的适应性过程，通过在多个情境中进行设计、实施和反思的循环而不断演进。

与早期 DBR 的课堂界定取向不同，DBIR 专注于可扩展性、情境多样性和系统性改进。它研究的不仅是什么有效，还包括对谁有效、在什么条件下有效。通过考察使可持续创新成为可能的<|message|> 基础设施和能力，例如领导结构、数据系统和专业学习网络，DBIR 弥合了设计研究与实施科学之间的差距。它重新定位设计不仅是干预措施的创造，更是共同构建使教育变革得以扎根和持久的条件。

| Features | - DBIR 促进研究人员与教育工作者之间的紧密合作，确保干预措施植根于课堂现实。
- 该模式通常解决教育中的系统性挑战，旨在在多个情境中更广泛地应用干预措施。
- DBIR 鼓励根据从业者的实时反馈持续调整干预措施，促进对不断变化的教育需求做出响应。 |

## Recent Developments in DBR Thinking

近年来，学者们开始通过整合新的理论视角来扩展传统的 DBR 模型，这些视角强调动机、具身性和 lived experience。这些当代方法超越了将 DBR 纯粹视为方法论循环的观点，而是将其定位为探索学习如何在真实情境中展开的灵活框架。两个值得注意的例子包括 Tillmann 和 Wegner 在 2024 年在 DBR 框架内应用兴趣发展的四阶段模型，以及 Poizat 等人在 2024 年提出的 DBR 的具身视角，该视角重新构想了设计和学习是通过行动和经验共同建构的。

## An Integrative Perspective

总体而言，这些新贡献说明了 DBR 如何持续演进。早期的框架，如 DBRC（2003）和 McKenney 和 Reeves（2012）的框架，主要将 DBR 视为通过迭代循环设计、测试和完善教育干预的结构化过程。新模型在此基础上发展，但拓宽了视角。Tillmann 和 Wegner 展示了 DBR 如何用于研究和支持动机，即学习者的兴趣如何随时间发展和变化，而 Poizat 等人则展示了 DBR 如何关注学习者和教师的 lived experience，通过将学习视为通过真实活动 enact 的东西，而不仅仅是从外部观察。两种观点都提醒研究人员，DBR 不仅关乎改进教学设计，也关乎理解其中展开的复杂人类过程。

## Chapter Summary

本章所述的每个框架和模型都对教育探究不断发展的格局做出了独特贡献，为弥合理论与实践提供了结构化而灵活的方法。总体而言，它们突出了有效教育创新的关键原则：迭代完善、协作设计、现实情境化以及实践和理论知识的共同生成。虽然它们在侧重点上可能有所不同——有些优先考虑可扩展性，有些优先考虑生态效度或系统变革——但它们都致力于通过严谨、响应式的探究来解决真实的教育问题。

对于研究人员和从业者而言，这些框架和模型的多样性是一种优势。根据研究问题的性质、情境和期望成果，其中一种可能比另一种更合适。例如，旨在影响大规模政策或系统改革的项目可能受益于 DBIR 方法，而课堂层面的干预则可能更适合 Reeves 或 Collins 等人的设计实验模型。理解这些细微差别使研究人员能够采用最符合其目标的框架和模型，确保方法论的完整性和实践影响。随着教育设计研究领域的不断发展，这些框架和模型不仅提供指导，也提供灵感，鼓励创新是情境化的、协作塑造的和理论生成的。
