# Scaling Up a DBR Intervention: Checklist

Use this checklist as a planning and reflection tool as you prepare to scale your Design-based Research (DBR) project to new contexts. Tick off each item as you go, and make notes to support your thinking and documentation.

# Understanding the New Context

+   - Conducted a contextual analysis of the new setting
+   - Identified key differences in demographics, infrastructure, and teaching practices

# Building Stakeholder Support

+   - Engaged key stakeholders early (teachers, leaders, students, etc.)
+   - Clearly communicated goals and rationale
+   - Identified and supported local champions

# Designing for Flexibility

+   - Defined core vs. adaptable elements of the intervention
+   - Offered multiple implementation pathways (e.g., techn/no-tech)
+   - Encouraged practitioner-led innovation

# Collecting and Using Data

+   - Created a data collection plan (quantitative + qualitative)
+   - Collected data across different time points (pre/during/post)
+   - Used data to inform ongoing adaptations

# Anticipating Challenges

+   - Identified potential barriers and risks
+   - Planned for staff changes and training and mentoring
+   - Scheduled time for review and iteration

# Documenting Design Principles

+   - Tracked adaptations across settings
+   - Noted recurring patterns and successful practices
+   - Drafted design principles grounded in data and experience
