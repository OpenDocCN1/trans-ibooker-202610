# PRACTICAL TIPS

+   - Align the intervention with existing curricular goals to avoid competing for instructional time.
+   - Plan short, focused cycles with built-in flexibility.
+   - Anticipate delays and build in buffer periods.
+   - Prioritise core activities so the essential enquiry can continue even if some sessions are lost.
+   - Use classroom-based activities that double as instruction and data collection (e.g., exit tickets, quick oral check-ins).

# Balancing Rigour and Flexibility

# The Issue

As discussed, maintaining a controlled implementation in DBR is challenging because real classrooms rarely unfold as planned. Lessons may be interrupted, teachers may improvise, and learners may respond in unanticipated ways. This raises a genuine concern: if each educator adapts the intervention differently, can the research still generate valid and trustworthy insights? The tension between rigour (the need for systematic, credible data) and flexibility (the need to adapt to authentic contexts) is one of the defining challenges of DBR.

# What Can Help

The key is to approach implementation with a mindset of disciplined improvisation. Unlike a laboratory experiment, DBR does not aim for perfect consistency across sites. Instead, it seeks to capture how interventions function under real-world conditions. This requires you to be systematic about how you document, analyse, and interpret variation. Adaptations are not “noise” to be eliminated but data points that can shed light on why an intervention succeeds in one context and struggles in another.
