

## Reeves 设计研究模型（2000, 2006）

Reeves 设计研究模型（2000, 2006）的关键贡献在于将 DBR 运作为一种系统而灵活的方法论，可应用于课程设计、教育技术和专业学习。相较于早期的概念模型，Reeves 为 DBR 提供了实用的研究支架，确保透明度、可复制性和知识的累积构建。

该模型分为四个关键阶段：（1）实践问题的分析，在此阶段识别并彻底审视现实世界的问题，以确保研究植根于真实需求；（2）解决方案的开发，涉及针对已识别问题创建循证干预措施或工具；（3）迭代测试与完善，在真实环境中测试解决方案，并根据数据做出调整以提高其有效性；以及（4）反思以完善理论与实践，使研究人员能够评估研究结果的更广泛影响并为理论体系做出贡献，同时为教育者提供可操作的见解。

Reeves 模型的另一个显著特点是其对协作伙伴关系的关注，确保干预措施与教育者共同设计，以符合现实的教育情境。通过将理论严谨性与实践相关性相结合，该模型弥合了研究与应用之间的差距，促进了可持续且可扩展的创新。该模型在推进 DBR 在教育技术、课程开发和教育者培训中的整合方面发挥了重要作用。

## McKenney 和 Reeves 的 EDR 框架（2012）

McKenney 和 Reeves（2012）开发的 EDR 框架被广泛认为是教育研究领域最具影响力的模型之一。基于对早期模型的分析，该框架提出了一个通用且可适应的结构，概括了 EDR 过程的本质。它强调三个关键阶段：分析/探索、设计/构建和评估/反思。这些阶段与现实实践无缝互动。框架的灵活性使其能够适应各种教育情境，同时保持其核心重点，即产生实践干预和理论知识的双重产出。这种双重目的方法确保研究结果不仅解决教育中的即时挑战，还为该领域的知识体系做出贡献。

McKenney 和 Reeves 的 EDR 框架（2012）对教育研究和实践具有重要意义。它通过明确阐述双重成果——可用的教育干预措施和完善的理论洞见——并在整个过程中嵌入持续的实践者协作，从而推动了该领域的发展。与早期的 DBR 形式不同，EDR 不是一种特定的设计循环，而是一种元方法论，可在不同情境和规模水平上进行调整。它还强调教师的能力建设，将教育者定位为通过参与设计而学习的共同设计者。通过专注于产生既可扩展又以证据为基础的干预措施，该框架支持可持续教育创新的发展。此外，理论洞见的产生丰富了对教学和学习过程的学术理解，促进了持续改进和创新。这种双重关注使 EDR 框架成为推进教育实践和研究的宝贵工具。

## Plomp 的 EDR 阶段（2013）

Plomp 的 EDR 阶段（2013）为通过系统且迭代的过程解决复杂的教育挑战提供了一个结构化框架。该模型包含三个核心阶段：初步研究，在此阶段识别问题并进行情境分析；原型设计，涉及通过迭代测试设计和完善干预措施；以及评估，评估干预措施的有效性和理论贡献。Plomp 方法的独特之处在于其在结构与灵活性之间的平衡：每个阶段都明确将实证研究与迭代设计联系起来。与 McKenney 和 Reeves 相比，Plomp 更强调评估和有效性的正式评估，提供了一个更线性但仍具迭代性的过程。他的模型广泛用于应用性教育开发项目，研究人员和实践者在此协作创建经过验证、可扩展的解决方案。

|  | • 持续的测试和反馈改进干预措施。 |
|  | • 平衡实践应用和理论进步。 |
|  | •  engaging 合作伙伴以确保与现实需求保持一致。 |
|  | • 促进研究人员与实践者之间的伙伴关系。 |
|  | • 设计可在不同情境中适应和持续的解决方案。 |
| Distinct Contribution | 简化了课程和教学设计项目的 EDR。 |
| Example in Context | 一个研究团队应用了 Plomp 的框架来开发学习者的数字素养课程。在初步研究阶段，他们通过调查和文献综述确定了在线安全、信息评估和编码技能方面的差距。 |

在原型设计阶段，他们设计了互动模块并在课堂上进行测试，通过学习者和教育者的迭代反馈完善课程。最后，在评估阶段，该课程在多所学校实施，学习者表现和参与度的数据突出了其有效性并为进一步完善提供了信息。

## DBIR 模型（2017）

DBIR 由 Fishman 等人（2013）阐述，代表了 DBR 的重要演进，将其关注点从课堂层面的创新扩展到系统性教育变革。传统 DBR 和 EDR 专注于开发和完善干预措施，而 DBIR 则将实施本身作为设计过程加以突出。它认识到，有效且持久的创新不仅依赖于设计良好的教学解决方案，还依赖于支持其采用和可持续性的组织、社会和政策基础设施。

DBIR 建立在四个指导原则之上：（1）与教育者共同识别的实践持续性问题；（2）将教育者作为平等合作伙伴参与的迭代共同设计过程；（3）对持续变革能力的承诺；以及（4）关于学习和实施的理论生成。实施不是终点，而是一个持续的适应性过程，通过在多个情境中进行设计、实施和反思的循环而不断演进。

与早期 DBR 的课堂界定取向不同，DBIR 专注于可扩展性、情境多样性和系统性改进。它研究的不仅是什么有效，还包括对谁有效、在什么条件下有效。通过考察使可持续创新成为可能的<|message|> 基础设施和能力，例如领导结构、数据系统和专业学习网络，DBIR 弥合了设计研究与实施科学之间的差距。它重新定位设计不仅是干预措施的创造，更是共同构建使教育变革得以扎根和持久的条件。
