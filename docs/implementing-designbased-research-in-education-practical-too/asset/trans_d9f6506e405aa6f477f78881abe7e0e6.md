## DBRC 框架（2003）

DBRC 框架（2003）是教育设计研究中一个开创性的框架，强调通过迭代、协作的方法解决复杂的教育问题。该框架包含关键阶段，包括识别重大的现实世界教育挑战、设计基于理论的创新解决方案、在真实情境中实施和完善这些干预措施，以及产生促进实践和理论理解的见解。DBRC 框架强调紧密联系设计和研究过程的重要性，以确保干预措施有效且可持续。该框架的标志性特征是其对设计、测试和完善的迭代循环的关注，这使研究人员和从业者能够根据反馈和观察结果调整干预措施。

DBRC 框架通过弥合理论与实践之间的差距，对教育设计研究领域做出了重大贡献。它将研究范式从孤立的理论研究转变为以情境为敏感、以协作为主、优先考虑现实世界影响的方法。通过强调与教育工作者共同创造解决方案并关注可扩展性和可转移性，DBRC 模型使得开发既切合实际又在理论上健全的干预措施成为可能。其对设计、实施和分析的整合已成为现代教育设计研究方法论的基石。

| Features | • 强调设计、实施、分析与修订的迭代循环。 • 专注于理论构建和解决现实世界问题。 |
| Distinct Contribution | 确立了 DBR 作为将创新与理论构建统一的范式。 |

| Example in Context | 一所学校希望改善数学中的协作解决问题能力。研究人员和教育工作者共同合作开发包含协作任务的新课程单元。初步实施后，研究人员收集学习者参与度和解决问题策略的数据，他们完善任务并重新测试，通过迭代直至实现最佳成果。 |

## Barab 和 Squire 的发展研究模型（2004）

Barab 和 Squire 的发展研究模型（2004）强调教育情境中理论与实践的共同演化。该模型以这样一个原则为基础：教育创新不仅应解决课堂的即时挑战，还应促进更广泛的理论理解。他们指出，DBR “要求不仅仅展示某种特定设计如何运作，而是要求研究人员生成基于证据的学习主张，这些主张解决当代理论问题并推进该领域的理论知识”（第 5–6 页）。发展研究模型（2004）具有设计、实施和完善的迭代循环，干预措施在真实学习环境中开发，并根据合作伙伴的反馈持续调整。该模型的一个独特方面是其对生态效度的关注，确保干预措施具有情境敏感性并适用于不同的教育环境。

倡导研究与实践之间的共生关系极大地丰富了我们对 DBR 的理解。它强调解决现实世界教育问题的同时生成推进学术理论的见解。通过将研究置于真实环境中并让从业者作为共同研究者参与，Barab 和 Squire 的方法确保创新既实用又可持续。该模型在促进适应性强、可扩展的教育解决方案的发展方面发挥了重要作用，并塑造了研究人员对 DBR 作为动态过程的迭代性质的思考，该过程会根据情境需求和挑战而演变。

| Features | - 优先同时推进理论理解和实践应用。 - 强调设计、实施和完善的重复循环，以逐步改进干预措施。 - 确保干预措施在真实学习环境中开发，反映现实世界的挑战和需求。 - 让教育工作者、学习者和其他合作伙伴作为共同研究者参与，促进协作解决问题。 - 强调创建具有情境敏感性且可扩展到不同教育环境的解决方案的重要性。 - 鼓励根据反馈和结果持续调整干预措施，以确保其保持有效和相关。 - 寻求在产生推进更广泛教育理论的见解的同时提供实用解决方案。 - 专注于设计不仅有效而且可适应长期使用和跨不同情境的创新。 |
| Distinct Contribution | 将 DBR 框定为在真实环境中理论与实践的共同演化。 |
| Example in Context | 一所学校为历史课程实施新的基于游戏的学习平台。教育工作者和研究人员合作将平台整合到课程中，基于课堂观察、教育工作者反馈和学习成果，迭代完善游戏的设计和教学对齐。 |

## Collins, Joseph 和 Bielaczyc 的设计实验（2004）

Collins, Joseph 和 Bielaczyc 的设计实验（2004）框架的一个关键优势是其使用多种数据源来捕捉课堂互动的复杂性，使研究人员能够解决即时的教育挑战和更广泛的系统性问题。Collins 等人（2004）引入了“设计实验”一词，反映了对自然情境中学习进行实证研究的重点。他们的模型将课堂视为检验学习理论在实践中如何运作的实验室。它与其他 DBR 模型不同之处在于其强烈的实证导向：系统收集和三角验证定量、定性和过程数据以理解学习的机制。虽然 DBRC 和 Barab 和 Squire 强调伙伴关系和理论-实践共同发展，但 Collins 等人专注于方法论严谨性，将 DBR 确立为分析复杂教学现象的科学可信方法。

| Features | • 迭代设计循环以研究自然情境中的学习。 • 专注于理解教学和学习的复杂性。 • 采用设计、实施、观察和完善的循环过程来改进干预措施。 • 旨在为即时的教育挑战提供实用解决方案并为更广泛的适用性生成理论见解。 • 鼓励研究人员与从业者密切合作，以确保干预措施相关且植根于课堂现实。 • 使用多种数据源（例如定性和定量）来捕捉教育环境的细微动态。 • 寻求开发可适应各种情境并长期持续的干预措施。 • 在构建现有教育理论的同时，也通过实证发现促进其演进。 |
| Distinct Contribution | 将课堂定位为研究实验室和先进方法论严谨性的场所。 |

### Example in Context

一个研究团队希望为三至六年级学习者开发一个个性化阅读计划，旨在提高理解力和参与度。该计划整合了自适应数字工具、教师指导活动和同伴协作。为了评估和完善干预措施，团队采用了稳健、多方面的资料收集策略：

+   1. 定量数据：
+      - 测前和测后评估衡量阅读理解和词汇发展。
+      - 参与度指标追踪在数字平台上花费的时间和任务完成率。
+   2. 定性数据：
+      - 课堂观察捕捉教育工作者-学习者互动和活动期间学习者协作情况。
+      - 与学习者的焦点小组提供其经验和偏好的见解。
+   3. 过程数据：
+      - 来自数字平台的学习分析追踪个别学习者进展，突出模式和系统可改进的领域。
+   4. 教育工作者反馈：
+      - 定期访谈和调查收集教育工作者对计划可用性、与课程目标的一致性以及观察到的学习成果的观点。

通过数据分析和干预完善的迭代循环，研究人员识别出什么有效、什么无效以及原因。例如，他们可能会发现学习者在某些自适应任务上遇到困难，并利用这些信息修改计划的难度调整算法。这种全面的数据收集方法不仅改进了阅读计划，还为个性化学习和数字干预设计理论做出了贡献。
