# Visualizing What You Can Do with Bixby Vision

In Chapter 9, I point out the Bixby Vision option in the viewfinder. When you have the camera app open, you can tap the link to launch Bixby Vision. Bixby Vision can then tell you information about what the camera is pointed at:

+   » If it's an object, Bixby Vision can tell you what the object is and how much you can buy it for online.
+   » If it's a barcode or QR code, Bixby Vision can tell you what the code means.
+   » If it's text, Bixby Vision can read it and convert it to text. You can then translate that text into any of 108 languages.
