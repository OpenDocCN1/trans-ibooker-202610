>> **Device Name:** When this screen comes up, you'll see a text box that has the model name. You can keep this name for your phone, or you can choose to personalize it a bit. For example, you can change it to “Bill's Galaxy S10” or “Indy at 425-555-1234.” The purpose of this name is for connecting to a local data network, as when you're pairing to a Bluetooth device. If this last sentence made no sense to you, don't worry about it. (I go over all of this in Chapter 3.) Tap Finish. In a moment, you see the Home screen, as shown in Figure 1-2.
