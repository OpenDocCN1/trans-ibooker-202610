

## teardrop attack
一种 DoS 攻击类型，向目标系统发送分片数据包。旧版操作系统在其 TCP/IP 重组机制中存在漏洞，导致分片数据包重叠并使主机崩溃。

## telephoto lens
一种焦距较长的镜头，提供放大的视野。

## Telnet
一种应用客户端-服务器协议，可在计算机（或设备）与任何远程 Telnet 服务器之间建立连接。

## territorial reinforcement
这采用结构、系统和设备来防止未经授权的进入，并明确区分公共与私有的界限。

## threat
执行行动的潜在能力，意图造成疼痛、伤害、损害或其他敌对行为。

## threat agent
表示具有知识和意图发起攻击的个人、团体或设备。

## threat vector
一种常见的安全术语，指攻击者可能采用的方法以到达目标。

## threshold-based anomaly-detection systems
这些入侵检测系统旨在随时间跟踪特定事件的发生次数，然后在事件数量超过预定数量时生成入侵警告。

## time of check to time of use (TOCTOU)
当操作系统创建临时文件时会出现此情况。在操作系统检查文件是否存在与实际写入文件之间的时间间隔内，攻击者执行程序，使用临时文件的名称保存恶意代码包。

## time-of-day settings
大多数自动访问控制系统基于预配置的每日时间设置来决定有效或无效的进入请求，也称为交易。

## time of use (TOU)
一种电费计费计划，对在一天中的某些时间和一年中的某些季节消耗的能源收取更高的费用。

## top-level domain (TLD)
在互联网域名系统定义中，最高级别的域名，位于最右侧的点（.）之前。顶级域名通常分为商业和国家特定两类。

## Top Secret
通常是三级安全许可中的最高级别。

## topology
网络连接结构的物理和/或逻辑定义。

## TRACEROUTE
此网络实用程序将显示数据包从一个 IP 到另一个 IP 所经过的路由（路径）。

## tracking cookies
放置在主机计算机上的非恶意文本文件，旨在跟踪用户的网页浏览习惯。

## transparent proxy
此代理服务器代表主机机器进行通信，而不修改请求，与大多数代理服务相反。透明代理通常是用户甚至不知道正在使用的东西。

## Transport Layer Security (TLS)
SSL 协议的继任者，TLS 是一种用于确保通信应用程序之间隐私的协议。

## Trojans
看起来像是合法应用程序的恶意软件，以便用户被诱骗使用它们。虽然它们功能正常并能正常工作，但它们包含在应用程序启动时启动的恶意代码。

## TrouSerS
一个开源守护进程，通过单个模块控制与 TPM 的所有通信。

## trunk
一种通信链路，旨在处理和合并多个流量信号，通常是到其他网络设备，以实现物理端口使用的整合。

## Trusted Platform Module (TPM)
许多计算机主板设计包含一个内置微芯片，称为可信平台模块（TPM），用于存储加密信息，例如加密密钥（也称为启动密钥）。

## Trusted VPNs
这些 VPN 不使用加密隧道，而是信任底层网络在身份验证之外处理安全性。

## TrustedGrub
此 Linux 模块能够检测并支持 Linux 系统中的 TPM 功能。它是 Grub 启动加载器的可下载扩展，已为此目的进行了修改。

## tunneling
允许远程用户在建立互联网连接后安全地连接到内部资源。这是通过使用数据传输加密来保护传输中的数据来实现的。

## two-factor authentication
一种需要两个不同因素才能授予授权的过程，基于你所知道的、你所拥有的和你所知道的。

## two-man control
要求两个用户必须相互审查和批准彼此的工作才能完成项目。虽然这对于许多任务来说可能不切实际，但对于实施该措施的任务而言，它提供了高度的安全性。

## U

## UDP flood attack
一种 DoS 攻击，与 ping flood 攻击类似，使用用户数据报协议数据包。

## unauthorized
任何没有权限访问网络或资产的用户或设备。

## unauthorized access
个人在没有适当凭证的情况下获得对服务、应用程序、网络或设备的访问权限。

## unicast
单发送方与单接收方或网络之间的通信。

## unidirectional security gateways
用于在具有不同安全分类的网络或网络段之间创建单向连接。

## unified threat management (UTM) devices
安全设备，在单一产品中提供网关、反病毒、防火墙以及入侵预防和检测服务。

## Universal Disk Format (UDF)
一种开放的、厂商中立的文件系统，用于在各种介质中存储数据。

## Universal Plug and Play (UPnP)
一种零配置网络架构，可在不同品牌和类型的网络硬件之间带来一定的兼容性。虽然主要旨在帮助不熟练的家庭网络用户，但 UPnP 也得到一些非消费类硬件制造商的支持。

## Universal Serial Bus (USB)
现代个人计算机上最流行的硬件端口是通用串行总线（USB）端口。这种高速串行接口旨在提供一种快速、灵活的方法，将多达 127 个外围设备连接到计算机。

## Unix
Unix 系列操作系统提供模块化、多任务、多用户操作系统环境，最初开发用于运行在大型机和小型机上。Unix 操作系统的专有版本包括几种 BSD（伯克利软件发行版）变体，以及苹果的 OSX 和 iOS 操作系统和谷歌的 Android 操作系统。

## Unix File System
为原始 Unix 操作系统设计的第一个文件结构，至今仍在使用于 Unix 及其衍生系统。该文件系统标准的结构呈现出从主目录即根目录（/）开始的统一树形结构。

## unlocked condition monitoring
状况监控系统可以记录并发出信号，每当特定门或大门被解锁（授予访问权限）时，指示并记录授予了何种类型的访问权限。

## unmanaged switches
即插即用（PnP）设备，不包含任何用户配置选项。这些设备往往价格低廉，适用于住宅和小型办公环境。

## untagged packet
数据包头中未插入 VLAN ID 的数据包。

## update
服务包或补丁，可提高操作系统的可靠性、安全性和吸引力。操作系统更新最可靠的来源是操作系统制造商。某些更新可能使操作系统更方便，但不一定更安全。

## UPnP AV
通用即插即用 – 音视频。这是为了支持消费类媒体设备而发布的，如电视、家庭音响系统、摄像机和其他数字媒体设备。

## upstream interface
允许流量从客户端向服务器或客户端向互联网方向传输的接口。

## user password
此 BIOS 选项使管理员能够建立用户在启动过程中必须输入的密码，以完成启动过程并获得对操作系统的访问权限。

## utility files
允许用户管理系统资源、排除系统故障和配置系统的程序。

## V

## varifocal lens
包含多个可移动元件的光学组件，可允许改变监控摄像机的有效焦距（EFL）。与变焦镜头不同，可变焦镜头每次改变都需要重新聚焦。如果它具有可变焦镜头，并且可以根据用户的偏好在多个毫米设置下聚焦。

## VBScript
另一种仅适用于 Microsoft Windows Internet Explorer 的脚本语言。VBScript 与 JavaScript 类似，但由于与其他浏览器的兼容性有限，在网站中并不广泛使用。
