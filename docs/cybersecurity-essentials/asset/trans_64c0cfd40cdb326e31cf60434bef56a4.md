

# 外围

在给定区域或边界的第一道防线，其可以是物理的也可以是逻辑的。

# 覆盖网络

这是在另一个物理或底层网络之上构建的网络。

# 概览

这种摄像机视角通常覆盖宽广的视野，例如停车场或仓库地面。

# 所有者

资产的合法拥有者。

# 所有组

Linux 权限术语，指一组共同拥有数据访问权限的用户。

# 所有用户

Linux 权限术语，指对数据具有控制权和访问权的个人。

# 数据包

可由分组交换网络承载和传输的数据单元。

# 数据包分析器

也称为数据包嗅探器，是一种用于分析网络流量的计算机程序。

# 数据包过滤

根据源/目标地址、逻辑端口或协议，允许或阻止网络数据包通过的过程。

# 数据包过滤防火墙

配置了数据包过滤规则的防火墙，用于根据源地址、目标地址或端口号等因素允许或拒绝客户端访问。

# 数据包嗅探攻击

攻击者使用数据包嗅探器监听网络流量，寻找以明文形式在网络上传输的项目，例如密码和用户名，或敏感信息如信用卡或其他财务信息。

# 分页器

接收消息并向用户发出信号的移动射频设备。

# 配对过程

将两个蓝牙设备连接在一起的过程。

# 水平移动

摄像机左右移动；摄像机上下倾斜。

# 通道

从一个房间/区域到另一个房间/区域的封闭路径；它通常是一个瓶颈。

# 被动控制

已存在但不会根据任何操作进行调整的控制。

# 被动红外 PIR 探测器

PIR 探测器使用传感器外壳中的透镜机构来检测传感器覆盖的水平扇区内红外能量变化。这种探测器对静止物体不敏感，但会对视野中横向发生的快速变化做出反应。

# 无源 RFID 标签

由 RFID 阅读器传输的电磁能量供电的标签，允许进行身份验证。

# 密码短语

用于控制访问的单词或文本序列，类似于密码；然而，其字符数量通常更长。

# 密码

用作身份验证工具的秘密单词或随机字符串。

# 密码攻击

任何在不知道正确密码的情况下，通过密码提示成功进行身份验证的密码尝试。

# 密码认证密钥协商 PAKE

一种交互式方法，使两个或多个实体基于一个实体对密码的了解来建立加密密钥。

# 密码验证协议 PAP

与 PPP 一起使用，是一种利用密码的身份验证协议。

# 密码捕获

一种用于在身份验证过程中传输时查看并保存密码的技术。

# 密码破解

从存储数据或传输中数据中尝试恢复密码的过程，以便日后使用。

# 密码加密

将标准密码进行算法处理，使其对嗅探器、破解者或其他窃听者而言毫无意义的过程。

# 密码管理策略

为管理网络环境中用户的密码而制定的策略。

# 密码管理器

存储和组织用户密码的软件应用程序。

# 补丁星期二

微软的主要补丁发布日。

# 补丁

对已发布用于分发的特定操作系统或应用程序的一般改进。许多补丁和更新纯粹是外观上的便利附加功能，而另一些则是关键的安全升级，旨在应对特定病毒、发现的威胁或弱点。

# PathPing

一种在许多 Windows 系统上找到的实用程序，结合了 ping 和 traceroute 命令行工具。

# 支付卡行业数据安全标准 PCI-DSS

该标准要求使用防火墙和其他安全概念，例如网络分段，以确保所有存储的信用卡信息在物理和电子上都得到安全存储。

# 点对点网络

每台计算机以环形或总线方式连接到网络，并且与网络上的其他单元平等。

# 周界区域输入

包括周界每个开口处的传感器，包括门、窗、车库门和窗以及爬行空间的门。

# 权限

对特定数据和资产的定义特权和授权。

# 持久性 Cookie

也称为永久 Cookie，一种会在计算机硬盘上保留到指定过期日期的 Cookie。

# 个人区域网络 PANs

一种将个人设备如 PDA、手机、数码相机、PC、笔记本电脑和打印机结合在一起的网络类型。

# 域名劫持

一种恶意活动，将不知情的用户重定向到伪造的网站，希望获取个人信息。

# 钓鱼

一种社会工程技术，试图通过冒充可信组织来获取敏感信息，通常是登录凭证或信用卡数据。这些攻击通常涉及引导用户访问看似合法的虚假网站的电子邮件。

# 物理入侵检测系统

任何用于检测和发出入侵信号的设备，其目的包括运动传感器、读卡器、摄像机和警报器。

# 物理安全

任何关注保护物理边界和财产的过程或设备。

# 物理拓扑

网络的各种组件的放置，包括网络电缆和设备。

# 微微网

最多八个设备可以组合形成微微网，即小型蓝牙网络。

# PING

一种网络实用程序，用于评估到达另一台 IP 主机的能力。PING 实用程序将向目标主机发送 Internet 控制消息协议 ICMP 请求数据包，并等待响应以测量往返时间和任何数据包丢失。

# ping 洪水攻击

一种简单的 DoS 攻击，攻击者用 ICMP 回显请求 ping 数据包淹没受害者。

# 针孔镜头

一种非常小的孔镜头，可能是用针制作的，它将光线强制成平行线以形成清晰的图像。

# 插件

为现有软件应用程序添加新功能，例如搜索引擎和防病毒功能，这些脚本控件类似于 ActiveX 控件，但不能在 Web 浏览器之外执行。

# 销售点 POS

零售交易中使用的硬件和软件。

# 销售点 POS 终端

用于零售交易发生的时间和地点的智能网络终端。

# 策略

个人或企业采用的规则和程序。

# 多实例化

在这种数据库管理解决方案中，额外配置一台服务器作为用户和数据库服务器之间的第三方。中级服务器充当解释器和守护者，限制数据库访问仅限于授权用户和请求的数据库文件。

# 基于端口的 VLAN

在以太网交换机上定义为网络段的一系列端口。

# 端口扫描

探测或扫描服务器、客户端或主机以查找开放端口的过程。

# 端口扫描器

执行对网络设备开放端口探测的软件应用程序。

# 门户系统

HCP 通信系统的一部分的基于 Web 的界面。

# Poseidon POSIX 可移植操作系统接口

这是一套互操作性标准，旨在标准化 Unix 和类 Unix 操作系统的变体。POSIX 兼容系统 Unix、Linux 和 Apple OS X 系统支持某种类型的 ACL 来管理传统的 Unix 文件访问权限。

# 以太网供电 PoE

为每个智能设备提供电力，通过 UTP 网络电缆而不是专用电源供电。

# 压力垫

一种可放置在地毯下、走廊或楼梯踏板上的传感器。它们由于脚步压力激活警报而做出反应并报警。
