

### IEEE-1394

FireWire 总线规范。

### illegal

违反法律。

### in-band

这种虚拟化方案将设备放置在存储服务器与磁盘阵列之间的直接路径中。此配置消除了在每个服务器上安装设备相关软件的需求，而这是在带外配置中必需的。

### Information and Communications Technology (ICT)

涵盖任何通信设备或应用的统称。

### informative references

包含来自各组织安全利益相关方的具体标准、指南和实践的文件，以实现所列功能、类别和子类别的目标。

### infrastructure security

应用于为企业、组织或社会运行所需的基本物理和组织结构提供安全保障的物理安全举措。

### ingress

个人进入某处财产的权利。

### inherited access

非显式访问，通常因属于某个组而被授予。

### inner perimeter

此周界通常涉及物理屏障，如墙壁、门和窗——根据外周界的上下文，可能是外部或内部的。

### input devices

用于向电子设备中输入信息的设备。

### Input/Output (I/O) controller

智能电表负责在其他系统组件与外部世界之间提供物理连接兼容性的部分。

### insider threat

此种威胁存在于网络内部，通常为员工。

### intangible asset

任何非物理资产，定义为使用年限超过一年的资产。

### intangible property security

涉及对非物理性质财产进行保护，例如专利和商标。

### interior security

这是基础设施安全的最内层级别，涉及对内周界内部区域的监控。

### interior sounders

这些设备设计为以最大音量运行，以吓唬入侵者快速离开。

### Internet Assigned Numbers Authority (IANA)

负责向 ISP 分配 IP 地址的组织。

### Internet Engineering Task Force (IETF)

互联网协议（如 TCP/IP）的主要标准化机构。

### Internet gateways

用于将网络连接到始终在线的宽带互联网连接的路由器。

### Internet Key Exchange (IKE)

用于在 IPsec 中建立安全关联的协议。

### Internet of Things (IoT)

由具有网络连接并能够与其他对象通信以收集和交换数据的任何物理对象组成的网络。

### Internet Protocol Security (IPsec)

VPN 中常用的开放标准，实际上采用了一套用于加密和验证 IP 通信的协议。

### Internet zone

此区域包括所有不受个人或组织控制的网络（包括互联网）。因此，内容可以是公开的，也可以是属于受信任合作伙伴或客户的机密数据。

### interoperability

一种公司制造的设备能够与另一家公司相关设备进行接口的能力。

### intranet

单一组织范围内本地或受限的网络。

### intruders

未经授权的人，他们获得了对自己没有访问权限的资产的访问权。

### intrusion detection and reporting system

基本商业安全系统的集体组件。

### Intrusion Detection and Prevention System (IDPS)

设计用于监控系统（本地计算机或网络环境）、记录关键事件、策略违规、报告它们并按指示进行阻止。

### Intrusion Detection System (IDS)

这些系统主要设计用于监控系统（本地计算机或网络环境）、记录关键事件和策略违规，并按指示报告。

### iOS

这是苹果为支持其 iPhone 和 iPad 产品线而设计的移动操作系统。虽然 iOS 与 OS X 共享许多结构，但它与 OS X 应用程序不兼容。

### IP address

标识使用互联网协议在网络上通信的每个设备的唯一数字字符串。

### IPsec

建立安全通信的协议套件。IPsec 采用 AH 和 ESP 来验证和加密每个 IP 数据包。

### IP address spoofing

使用伪造的源 IP 地址创建 IP 数据包以隐藏身份的过程。

### IPv4

IPv4 地址以 XXX.YYY.ZZZ.AAA 的数字格式存在。每个地址由四个 8 位字段组成，用点（.）分隔。

### IP-based

任何具有 IP 地址并依赖无线通信或传统网络布线进行通信的设备。

### IPv6

IPv6 是一种较新的 IP 地址协议，旨在应对未来 IPv4 地址短缺的预期。在 IPv6 下，IP 地址已扩展到 128 位，采用十六进制格式，用冒号（:）分隔。

### IP-based notification

通过 IP 网络（如互联网）向监控站通知警报状况。

### ISO 15408

信息技术安全评估通用准则国际标准。

### IP blocking

一种安全形式，阻止特定 IP 或 IP 范围建立连接。

### ISO 2700xx

一组 ISO 信息安全管理体系标准，旨在为管理层提供明确的信息安全控制。

### IP cameras

数字 IP（互联网协议）设备，具有 IP 地址，可直接连接到网络或互联网，而不是直接连接到主机控制器或计算机。

### isolation

用于隔离或分隔网络各部分的物理或逻辑分段。

### IP header manipulation

一种用于更改 IP 或 TCP 网络数据包头部部分所包含信息的技术，以便在网络上隐藏自己的身份。

## J

### jamming

在设备或网络所使用的同一频率上故意传输任意噪声流。

### JavaScript

一种面向对象的编程语言，常用于网页浏览器中创建交互式网站。

### JFFS2

Android 默认的日志闪存文件系统（版本 2）。此文件系统版本取代了 YAFFS2（另一种闪存文件系统），成为早期内核版本中 Android 默认的闪存文件系统。

### journaling file system

一种在将更改提交到文件系统之前，先在循环日志文件中跟踪更改的文件系统，该日志文件称为日志。

## K

### Kerberos

一种网络身份验证协议，涉及受信任的第三方票证授予服务器（TGS）来验证客户端/服务器交互。

### kernel files

操作系统的基本逻辑文件，负责解释从软件程序获得的命令以供中央处理器使用。

### key

拥有密钥意味着该实体拥有或知道获取给定资产访问权限所需的信息。

### keyfob

一种无线钥匙扣设备，可用于锁定、解锁和报警设备。

### keypad

通常配备一组数字按键的输入设备。键盘用于编程、控制和操作各种访问控制和管理设备。

### keys

就密码学而言，密码密钥是用于加密或解密信息的字符串。加密密钥可以基于仅加密和解密数据的软件所知的秘密字符串，或可以随机生成。也可以是已知和随机因素的组合。

### KillerBee

用于利用 ZigBee 和其他 802.15.4 网络的框架。KillerBee 提供嗅探、数据包解码和操作，以及注入技术。

## L

### latency

输入系统到期望输出的延迟。
