

## Secure Shell (SSH)

一种用于安全客户端-服务器连接的加密网络协议。旨在取代 Telnet 等不安全的 shell 协议，SSH 采用公钥加密认证。

## Secure Sockets Layer (SSL)

一种用于管理客户端与服务器之间身份验证和通信的协议，同时使用公钥和私钥。SSL 使用套接字方法在客户端和服务器程序之间交换数据，通常是网站和浏览器。

## security

建立对个人、系统、媒体、内容和对象进行排除和纳入的系统的科学、技术和艺术。

## security administrator

在网络环境中，管理员负责实施组织的安保政策。这些政策应设计为反映信息安全经典模型相关的三个目标：保密性、完整性和可用性（CIA）。

## Security Associations (SAs)

在两个网络设备之间建立共享属性以支持安全连接。

## security baseline

该基线定义了保护组织信息系统保密性、完整性和可用性（CIA）的最低安全要求，以及这些系统处理、存储和传输的数据。

## Security Content Automation Protocol (SCAP)

一种使用各种开放标准来评估漏洞并衡量这些漏洞潜在影响的方法。

## security patches

为特定目的发布的更新，用于纠正已观察到的弱点，以防止漏洞被利用。

## security policy

说明在每个层级如何实施安全性的文档。企业和组织制定全面的安全政策，定义谁有权访问不同资产以及在访问时可以对这些资产执行哪些操作。

## segregated

在网络中，物理或逻辑上的分离。常用于分隔个人、数据和其他资产。

## server

管理网络资源的集中式计算机或计算机程序。

## server administrator

负责服务器的设计、实施和维护的个人。

## Server Message Block (SMB)

也称为通用互联网文件系统，该网络协议旨在提供对文件和设备的共享访问，以及网络通信。

## server rooms

存放服务器的受保护房间。

## service pack

主要 Windows 更新和/或大量单个 Windows 更新的集合。

## session cookie

存储在临时内存中，关闭网页浏览器时此 cookie 就会被删除。

## Session Replay attack

此攻击涉及攻击者窃取用户的会话 ID，然后获得访问权限，可以做授权用户在给定网站上能够做的一切。

## side channel attack

攻击者在同一台物理服务器上运行的另一台虚拟机中获取私钥信息。

## signature analysis

进出流量与存储特定代码模式（签名）的数据库进行比较，这些模式已被识别为恶意威胁。

## signature-based IDS/IDPS

这些系统通过查找内容中的特定模式，即签名来工作。如果检测到已知的恶意模式，则可以采取适当措施保护主机。

## single authentication

仅需一种验证形式的身份验证。这代表可用的最低安全级别。

## single firewall DMZ

具有单个防火墙关联的网络 DMZ。

## siren

一种可听的发声器，设计为非常响亮。

## smart card

一种卡设备，通常类似于磁条卡。它们通常包含有关其所有者的信息，例如密码、个人识别号码（PIN）、网络密钥、数字证书和其他可在身份验证过程中使用的个人身份信息。

## smart phone applications

专门在移动设备上运行的应用程序，例如平板电脑和手机。

## Smurf amplifiers

计算机网络借其用途放大 Smurf 攻击的效果。

## Smurf attack

一种 DDoS 攻击，通过 ICMP 回复数据包淹没受害者。此攻击在 ping 洪水攻击的基础上增加了反射属性。这种反射属性是通过在攻击中使用更多参与者，即 Smurf 放大器而创建的。

## Snort

一种开源跨平台入侵检测系统，提供实时流量分析、数据包记录和协议分析，以及对蠕虫、端口扫描和漏洞利用尝试的主动检测。

## social engineering

使用心理操纵是一种非技术方法，旨在利用人际互动，希望绕过正常的安全措施。

## Social Engineering Toolkit (SET)

用于渗透测试的 Linux 软件包，可用于对目标执行高级攻击。

## socket

双向通信的一个端点。套接字绑定到端口号。

## soft targets

由于内置安全功能很少或没有，且添加安全功能的选项很少，因此容易受到破坏的设备。如果可以直接或虚拟访问，它们很容易被操纵。

## softphone

一种软件程序，使用户能够通过互联网拨打电话。

## software exploitation

旨在利用软件产品、操作系统和应用程序中的漏洞或弱点的网络攻击。

## software-defined networking (SDN)

一种计算机网络方法，分析任意两个节点之间的连接，并可以根据定义的策略过滤该连接。

## software firewall

安装在主机计算机上的防火墙，类似于任何其他应用程序。

## SolarWinds

该软件是一种商业网络性能监控产品。可用于监控正常运行时间、性能、流量和利用率；提供大量报告、图表和通知选项。

## spanning-tree attack

如果数据包仅在此类拓扑中的第 2 层交换机之间循环，则其生存时间（TTL）字段永远不会递减——而是继续通过冗余链路循环。这会产生广播风暴，用流量淹没网络。

## spanning-tree Protocol (STP)

该协议为多路径网络中的交换机提供无环路冗余链路。它通过配置交换机端口来实现这一点，使其根据所连接的段类型转发或阻止流量。

## spear phishing

而钓鱼攻击是随机发送给广泛的目标， spear-phishing 攻击针对特定组织或该组织内的个人，以试图获得对机密数据的未经授权访问。spear-phishing 攻击更有可能由寻求巨额经济利益、行业机密或军事信息的攻击者实施。

## spoof

任何伪造虚假身份的形式，从而获得对资产的访问权限。

## spoofing attacks

这些攻击基于更改设备的 MAC 或 IP 地址以改变其明显身份。

## spyware

一种监控系统操作并收集用户名、密码、信用卡号码和其他个人身份信息的软件程序。

## SQL injection

恶意用户用来操纵网页上 SQL 输入填充框的技术。特别是，精通 SQL 的黑客会通过字段框输入有效的 SQL 命令，导致 SQL 数据库泄露除输入创建目的之外的信息。

## SSH tunneling

在远程主机和本地设备或计算机之间创建安全连接，通过该连接未加密的流量可以通过加密通道传输。

## star topology

这种逻辑布局中，所有节点都通过分支连接到中央单元。节点通过中央单元相互通信。

## stateful packet-filtering firewalls

这些防火墙收集网络连接信息并维护用于后续连接的动态状态表，从而能够根据数据包过滤规则打开和关闭端口。

## stateless packet-filtering firewalls

作为访问控制列表（ACL）更有效运行，它们不跟踪两台计算机之间连接的状态；然而，它们将数据包与过滤规则进行比较。

## Storage Area Networks (SANs)

一种基于网络的存储系统，对主机机器来说看起来像是本地连接的。

## stream cipher

一种对称密钥密码，一次转换每个明文字符。

## subnet

最终属于更大网络的一部分的隔离网络。

## super cookies

第三方 cookie，比其他类型的 cookie 更难删除。许多 cookie 不使用传统的 cookie 存储方法，而是使用本地浏览器 HTML5 数据库存储甚至 Adobe Flash 数据存储。
