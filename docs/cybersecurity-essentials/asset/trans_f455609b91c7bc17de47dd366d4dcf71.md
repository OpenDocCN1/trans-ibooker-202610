- 5. **以下哪种攻击类型采用欺骗性框架技术来诱使用户点击其内容而非预期内容？**
   - A. 中间人攻击（MITM）
   - B. 分布式拒绝服务攻击（DDoS）
   - C. 点击劫持（Clickjacking）
   - D. Fraggle 攻击

**答案：C.** 点击劫持攻击采用欺骗性框架技术，诱使用户点击其内容而不是预期内容。

- 6. **质询握手认证协议（CHAP）主要用于什么？**
   - A. 网络层加密
   - B. 远程访问
   - C. 局域网服务器配置
   - D. 广域网 ISDN 连接

**答案：B.** CHAP 创建一个随机字符串、一个质询短语或一个*秘密*。然后将其与用户名或主机名等其他信息组合，并将组合后的信息发送给请求系统。请求方随后对该字符串进行哈希运算并返回结果。服务器接着检查哈希结果是否正确，并据此对请求方进行认证或拒绝。

- 7. **在可用于企业网络的各种防火墙类型中，哪种类型会拆解每个数据包、对其进行评估，然后重新组装，从而使此类连接的速度明显慢于其他防火墙类型？**
   - A. 状态检测包过滤防火墙
   - B. 静态包过滤防火墙
   - C. 代理过滤防火墙
   - D. MAC 过滤防火墙

**答案：C.** 代理服务器，即代理过滤防火墙，是配置为过滤掉不需要的数据包的服务器。代理过滤是一个比包过滤复杂得多的过程。在过滤过程中，每个数据包都会被拆解、评估并重新组装，这使得此类连接的速度明显慢于其他防火墙类型。

- 8. **IPSec 协议套件中哪个协议对于防止重放攻击很有价值？**
   - A. AH
   - B. ESP
   - C. SA
   - D. IKE

**答案：A.** 认证头（AH）提供数据完整性和来源认证，以防范重放攻击（攻击者重放录制的传输内容以获取访问权限的攻击）。

- 9. **在可用于企业网络的各种防火墙类型中，哪种类型会收集网络连接信息并维护用于后续连接的动态状态表，从而能够根据需要打开和关闭端口？**
   - A. 状态检测包过滤防火墙
   - B. 静态包过滤防火墙
   - C. 代理过滤防火墙
   - D. MAC 过滤防火墙

**答案：A.** 状态检测包过滤防火墙确实会跟踪实体之间的连接状态。这些防火墙收集网络连接信息并维护用于后续连接的动态状态表。这使端口能够根据需要打开和关闭。一旦客户端完成通信会话，状态检测包过滤防火墙就会关闭所使用的特定端口，直到再次请求该端口。

- 10. **即使密码可以作为哈希值而不是明文发送，仍然有几种黑客工具可用于获取用户密码。这些工具会被用来执行哪些类型的攻击？（选择两项。）**
   - A. 逻辑炸弹
   - B. 字典攻击
   - C. 缓冲区溢出
   - D. 暴力破解

**答案：B、D.** 字典攻击和暴力破解攻击使用工具来猜测用户密码。

## 术语表

### 3DES

也称为 Triple DES，3DES 是一种采用对称密钥的分组密码加密算法。它对每个数据块应用三次 DES 算法。

### 访问控制列表

通过白名单或黑名单控制对网络网段访问的列表。

### 访问控制策略

生成访问控制列表所采用的方法。

### A

### AAA 协议

认证、授权和计账，它使用 PPP 等不同的链路层协议，并通过 PAP 或 CHAP 进行认证。

### 确认（ACK）

TCP/IP 协议三次握手中第二步和第三步（最后一步）的一部分。报文的这一部分确认同步请求。

### 访问代码

数字序列，通常为四位数字，用于标识被授权的客户端或用户。一旦正确认证，访问代码可以布防、撤防或访问安全系统的其他功能。

### Active Directory

微软提供的目录服务，负责域管理，包括认证、授权、证书管理等。

### 访问控制

确保资源仅授予有权使用的用户的安全防范措施。

### 有源 RFID 标签

这些自带电源的标签提供更远的读取范围，但价格要高得多。有源射频识别标签通过电磁场传输识别信息。

### 访问控制门

墙壁或围栏上的开口，作为两个开放空间之间的通道（不同于门，门提供进入封闭空间或在不同封闭空间之间通行的途径）。

### ActiveX

一种 Microsoft 实用工具，使 Web 应用程序能够在浏览器中构建扩展的交互式特性和功能。ActiveX 会自动下载而不涉及用户操作，这可能造成安全漏洞，被破解者利用来在受攻击的网站中嵌入恶意代码。

### 自适应跳频扩频（AFHSS）

蓝牙规范在免许可证的 2.4GHz 频段中实现此技术，通过在预先划分的子频率之间跳频来提供安全性并避开拥挤的频段。

### 地址解析协议（ARP）欺骗攻击

一种攻击，攻击者发送伪造的 ARP 消息，将其 MAC 地址与另一用户的 IP 地址关联起来。一旦建立关联，发往该地址的消息将被转发给攻击者。攻击者随后可以利用从截获消息中获得的信息发起其他类型的攻击，如 DoS 或中间人攻击。

### 地址空间布局随机化（ASLR）

这是一种用于防止或减轻缓冲区溢出攻击影响的技术。

### 管理工具

这些工具包括用于控制计算机内存使用、管理和优化硬盘驱动器使用、配置计算机上运行的 OS 服务、控制启动期间的硬件/操作系统交接以及排除操作系统问题的程序。

### Adobe Reader

Adobe 的 PDF 软件。漏洞利用可能导致任意代码执行、沙箱绕过或常见的由内存损坏引起的拒绝服务。

### 高级加密标准（AES）

一种使用对称密钥的分组级加密算法。由 NIST 于 2001 年发布，已被美国政府采用，取代 DES。

### 高级持续性威胁

这类威胁在持续时间内针对非常具体且高度安全的系统。

### 广告软件

不需要的、未经请求的广告，通常显示在 Web 浏览器中。

### 算法

就计算机安全而言，算法是用于改变消息从而使未经授权的人无法阅读的代码。

### 模拟摄像机

需要单独的同轴电缆连接到监视器或录制设备的摄像机。模拟摄像机容易受到所传输信息质量下降的影响。

### Android

为平板电脑和智能手机设备使用而开发的操作系统。它主要通过触摸屏手势进行操作和控制。它目前是使用最广泛的移动操作系统。

### 报警指示器

报警系统设备，通过声音、光或其他指示来显示系统的运行状态。

### 异常分析

此分析系统对数据流应用统计分析技术，以确定其在任何给定时间点是“正常”还是“异常”。

### 基于异常的 IDS/IDPS

使用异常分析来检测和防止未经授权访问网络的入侵检测系统。

### 匿名代理

通过隐藏原始 IP 地址来提供客户端匿名性的代理服务器。

### 反间谍软件

通过检测然后清除间谍软件和/或一开始就阻止间谍软件来防御间谍软件的程序。

### 防病毒软件

通过检测然后清除计算机病毒和/或一开始就阻止病毒来防御计算机病毒的程序。

### Apple OS X

苹果操作系统，基于 Unix。

### Apple 的 Time Machine

苹果的备份软件应用程序。

### 基于设备的虚拟化

这些是放置在用户网络和存储网络之间的封闭式存储管理系统。

### 应用层加密

一种在应用层应用加密的方法，提供更广泛的安全标准。

### 应用软件包

这些作为操作系统的扩展运行。根据所使用的操作系统类型，应用程序可能直接控制某些系统资源（如打印机和网络接口），而操作系统在后台提供基础支持。在更高级的系统中，操作系统为系统中的所有应用程序提供通用的输入、输出和磁盘管理功能。

### 应用服务器

配置为在组织的业务活动中提供特定角色、为组织内部用户提供服务的服务器。

### 应用服务提供商（ASP）

现代云计算的先驱。通过网络向付费客户提供基于应用服务的企业。

### 应用区域

在 Intranet 环境中由应用程序的使用方式定义的委派区域。该区域通过使用防火墙、路由器和交换机来创建。
