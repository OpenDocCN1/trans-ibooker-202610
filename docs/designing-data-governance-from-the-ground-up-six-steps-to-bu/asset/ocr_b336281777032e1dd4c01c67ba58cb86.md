+   - Data available as a self-service infrastructure: data mesh architecture keeps all domain data on a central platform that manages storage, streaming, pipelines, and more. This prevents data from living in disparate systems and eases the need to build integrations, APIs, and so on. It allows each data steward to manage their domain data from the same source.
+   - Ecosystem governance: governance is a core tenet of successful data mesh. It reinforces the framework and mission statement you wrote in Chapter 1, ensuring that all data is formatted, standardized, and discovered against equal standards. These standards give everyone the assurance that the data they use is controlled for quality.
