# 对《从零开始设计数据治理》的早期评价

这本书是任何致力于建立数据治理计划的团队都可以立即付诸行动的资源。Maffeo 提供的聪明且全面的建议适用于各行各业，无论是企业还是非营利组织。以本书为指南，领导者和利益相关者可以立即执行战略。

Lisa Tagliaferri, PhD
研究员、教育者和软件开发者

许多组织在不了解建立健全数据治理项目所需的基础要素之前，就急于深入技术。Maffeo 将数据治理的最重要方面提炼成一套清晰的基础构建模块，所有组织都可以使用它来提高可见性和控制力。无论您是刚刚开始数据治理之旅，还是正在重组和优化现有项目，请将 Lauren Maffeo 的《Designing Data Governance》放在您的阅读清单之首。

Diana Kelley
联合创始人，SecurityCurve

Lauren Maffeo 写了一本精彩且必读的关于建立卓越数据驱动文化的大师课，将所有组织带到数据治理的最高水平。阅读这本全面而清晰易懂的指南，了解如何收集、保护和管理您组织的数据。从最好的专家之一那里学习。

Kweku Opoku-Agyemang, Ph.D.

一本简单易懂的指南，用于构建数据治理项目的基础模块。

► **Gaurav Patole**
Global Data Governance Senior Manager, BGC

作为我的法律实践的一部分，我花了很多时间研究和整理我最喜欢的关于人工智能、隐私和数据治理发展的文章和书籍。*Designing Data Governance* 是我在这个主题上最喜欢的书籍之一。Lauren Maffeo 轻松地处理了这个具有挑战性的主题，用通俗易懂的语言回答了实施数据治理项目的“如何做和为什么”的问题。我向任何想了解数据治理一般知识的人以及首次着手实施数据治理的人推荐这本书。需要补充的是，鉴于监管对隐私、数据安全和公司数据使用的关注度不断提高，这本书尤其及时。
