# AWS Porting Assistant

Another tool you can use to aid your migration from .NET Framework is the Porting Assistant provided by AWS themselves. This is a Windows application that you download to the machine on which you have your .NET Framework solution. Although the porting assistant runs locally on your code it will need to connect to AWS in order to retrieve NuGet package upgrade information from an S3 bucket, it is for this reason that you need to set it up with a local AWS profile as shown in Figure 2-16. No resources will be created on your AWS profile.
