Depending on the type of .NET Framework project you have (WebForms, WPF etc) the upgrade assistant will give you a different set of steps. I have an ASP.NET MVC Web Application so we are offered a 10 step process for the upgrade as seen in Figure 2-15. Most of the steps are self explanatory, step 2 in my example is “Convert project to SDK style”. This means reformatting the `.csproj` file to the newer .NET format that starts with `<Project Sdk="Microsoft.NET.Sdk">`. As you go through these steps, use a source control diff tool such (eg KDiff, VSCode or the “Git Changes” window in Visual Studio) to see the changes being made to your code and project files.
