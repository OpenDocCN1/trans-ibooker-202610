# The elimination of up-front commitment by Cloud users

For many startups, it is not feasible to spend hundreds of thousands of dollars on buying equipment to try out an idea. The cloud enables an opportunistic way to develop software by eliminating high fixed costs typical before cloud computing.

# The ability to pay for the use of computing resources on a short-term basis as needed
