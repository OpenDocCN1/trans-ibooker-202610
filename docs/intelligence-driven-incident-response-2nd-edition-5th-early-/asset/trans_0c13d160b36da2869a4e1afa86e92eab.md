
# 命令与控制 (C2) 通信

一旦攻击者建立了持久化，特别是如果他们选择了 RAT 路线，他们就需要一种传递命令的方法（无论是推送还是拉取）。命令与控制 (C2) 通信通过多种方法进行，并可利用不同的端口、协议和服务。攻击者在建立 C2 进程方面以极具创造力著称。一个著名的例子是 Turla，该组织以在命令与控制通道上进行创新而闻名。在一次事件中，他们使用了一种植入程序，通过流行歌手布兰妮·斯皮尔斯 Instagram 评论中的编码命令进行通信。过去，许多恶意软件，特别是分布式拒绝服务 (DDoS) 工具，通过加入 IRC 频道或向攻击者控制的服务器发起 HTTP 调用进行通信。[注释组](http://symc.ly/2tHeLKX) 这个绰号源于他们利用看似无害的网页上的 HTML 注释进行命令与控制。一些攻击者使用多种方法，包括 DNS 查询、社交媒体或流行的云应用程序。

攻击者专注于确保其通信通道不被发现，并提供足够的带宽以满足攻击者的需求。在某些情况下，恶意软件可能每天仅使用几行文本进行通信，而其他恶意软件则包含完整的虚拟桌面功能。

## 目标行动

在大多数情况下，所有这些并非最终目标，而只是铺垫。攻击者经历建立访问权限的过程，以赋予自己以一种以前没有的方式影响目标的能力。我们称这种新能力为*目标行动*。

虽然最早的许多目标行动仅限于探索，但自 1990 年代中期以来，最常见的目标行动一直是收集并窃取目标系统上的信息。从某种简单的角度来看，这很合理：计算机归根结底是用于处理信息的。据传臭名昭著的银行劫匪威利·萨顿曾被问及为何抢劫银行。萨顿回答：“因为钱在那里。”在现代社会，金钱即数据（作为账本或区块链中的 0 和 1），下一代军事技术的计划存储在企业服务器的计算机辅助设计和开发文件中，政治情报存储为 PDF 或 Excel 电子表格，数据窃取成为主要的目标行动，这有什么好奇怪的吗？

除了数据窃取，最常见的目标行动，且与安装阶段的网络持久化相辅相成的，是跳板攻击。在许多情况下，攻击者真正追求的目标无法直接攻击。人们不应该从存放其最宝贵计划的 FTP 服务器打开钓鱼邮件（不幸的是他们经常这么做），也不应该从存放所有客户数据的系统浏览可疑网站（他们也这么做），但在遵循这些做法的情况下，攻击者通常会攻击可能促进进一步访问的相关系统，以达到最终目标。在许多情况下，攻击者甚至不知道他们最终针对的是哪个系统，而是攻击任何可用的系统，建立持久化，并进行跳板攻击；本质上是重新开始整个入侵过程（杀伤链中的杀伤链）。一种常见的入侵模式是：初始系统相当无害且无关紧要（例如攻击者针对可能启用了 Microsoft Office 宏的招聘人员或会计师），通过破解安全账户管理器 (SAM) 文件获取管理员凭证，跳板攻击到域控制器，再次窃取 SAM 文件。现在攻击者拥有了全网范围的管理员凭证，可以直接追踪其最终目标。

除了信息窃取和跳板攻击，攻击者对目标（不仅限于计算机）最常见的行动被美国空军归类如下（我们稍后将详细讨论这些内容，涉及防御者可以采取哪些措施来应对攻击者）：

### 销毁

攻击者销毁物理或虚拟项目。这可能意味着销毁数据、覆盖或删除文件，或以其他方式使系统不可用，直到完全重建。这也可能意味着销毁物理对象，尽管这在计算机攻击中很少见，例如震网病毒摧毁伊朗离心机。^([1](#ch03.html#idm46530557019536))

### 拒绝

攻击者拒绝目标使用资源（如基础设施或特定能力），例如拒绝服务攻击不允许访问站点。近年来受到关注的另一个例子是勒索软件，它加密用户数据，并要求付款后攻击者才会（理论上）解密数据以供再次使用。

### 降级

攻击者降低目标基础设施或能力的效用。这通常指目标控制和指挥基础设施的能力，例如禁用网络服务。一个稍微不那么细微的版本，具有简单的杀伤链，是分布式拒绝服务。

### 破坏

通过中断信息流，攻击者可以破坏目标执行正常操作的能力。

### 欺骗

攻击者试图让目标相信虚假信息。在这种情况下，攻击者可能会将虚假信息插入工作流以重定向资产或信息，或导致目标采取有利于攻击者的行动。

这些大多表面上看起来简单直接。然而，攻击者将这些组合在一起的方式至关重要，往往直接反映了攻击者的身份和目标。攻击者通常可以隐藏恶意软件、混淆命令与控制等；但最终，目标行动无法被混淆、编码或保护。要窃取信息，攻击者必须窃取文件。要执行 DoS 攻击，攻击者必须利用受感染的主机发送大量网络流量。简而言之，目标行动阶段无法伪造。

同样重要的是要理解，攻击者可能会结合多种行动和载体，包括物理/非网络行动。这可能包括从招募内部人员泄露战略信息到*动能行动*（例如轰炸地理位置）的任何事情。

正如您在[图 3-3](#ch03.html#fig_3tk)中所见，攻击者的杀伤链保持严格定义，而事件响应周期必须对其做出反应，这始于识别阶段。识别可能发生在杀伤链的识别阶段和目标行动阶段之间的任何位置，并导致截然不同的事件响应。在投递阶段识别到的事件是理想的。防御者可以在电子邮件或 Web 代理处阻止攻击，防止攻击执行。在后期阶段（如命令与控制或目标行动）检测到的攻击可能会很痛苦，涉及许多受感染资源，并需要昂贵且漫长的事件响应调查。

为了说明杀伤链，想象一个代号为“灰刺”的虚构攻击组织发起的一系列攻击。该组织对多个国家进行政治情报收集。最近的报告表明，他们一直在针对美国和英国的竞选活动。他们寻求获取候选人在经济、外交政策和军事问题上的立场信息。以下是他们的策略所包含的内容：

### 目标定向

“灰刺”不自行选择目标，而是从国家决策者那里接收任务（情报术语，指他们被指示针对的数据和组织）。该任务描述了具体的目标国家和候选人以及感兴趣的关键词。
