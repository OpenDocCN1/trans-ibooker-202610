
# 网络威胁数据的易失性

所收集的大多数网络威胁数据都是易失的。该数据的生命周期从几分钟到潜在的几个月甚至几年不等，但总有一段时间是该信息相关的。了解数据收集的时间可以帮助防御者理解如何对其采取行动。如果不知道数据何时被收集，就很难正确分析或利用任何数据。

## 背景

收集方法和日期都能为数据提供一定程度的背景，但可用的背景信息越多，分析起来就越容易。背景可以包括额外细节，例如与信息相关的具体活动以及信息片段之间的关系。

## 解决分析中的偏见

所有分析师都有偏见，识别并抵消这些偏见以使其不影响分析，是高质量情报的关键组成部分。分析师应力求避免的偏见包括*确认偏误*，即寻找支持先前得出结论的信息；以及*锚定偏误*，即导致分析师过度关注单条信息而忽视其他可能更有价值的信息。我们在第7章“分析”中深入探讨偏见。

# 情报层级

我们迄今为止研究的情报模型侧重于信息通过某种分析管道的逻辑流向。但正如事件分析一样，这种方法并非建模信息的唯一途径。我们可以从不同抽象层级来思考情报，范围从高度具体（战术）到后勤/作战层面（作战）再到非常笼统（战略）。在审视这些情报层级时，请记住该模型代表一个连续的光谱，中间存在灰色地带，而非离散的桶。

## 战术情报

**战术情报**是支持安全运营和事件响应的低层级、高度易失性信息。战术情报的客户包括安全运营中心（SOC）分析师和计算机事件响应团队（CIRT）调查员。在军事领域，这一层级的情报支持小分队行动。在网络威胁情报（CTI）中，这通常包括 IOC 和可观测对象，以及高度细粒度的 TTP，精确描述对手如何部署特定能力。战术情报使防御者能够直接应对威胁，方法包括在网络中搜寻对手活动的迹象、根据活跃利用报告确定关键补丁的优先级，或向员工发布针对其组织的活跃网络钓鱼活动信息。

战术情报的一个例子是与新发现漏洞利用相关的 IOC。这些战术层面的 IOC 包括执行扫描搜索漏洞的 IP 地址、托管恶意软件的域名（如果利用成功，恶意软件将被下载到主机），以及在利用和恶意软件安装过程中生成的各种基于主机的工件。这种战术情报将使安全运营团队能够有效地在网络中搜寻恶意活动，同时采取具体措施缓解任何未来的利用。

## 作战情报

在军事领域，**作战情报**比战术情报高一个层级。该信息支持后勤并分析地形和天气对大规模行动的影响——换句话说，它涉及的背景远超当前的战术任务。在 CTI 中，这通常包括关于活动和高阶 TTP 的信息，以及预期的对手响应和这些行动可能如何影响其他行动。它还可能包括特定攻击者归因、能力和意图的信息。作战情报的客户包括高级数字取证和事件响应（DFIR）分析师以及其他 CTI 团队。

这是许多分析师难以处理的情报层级之一，因为它有时感觉太笼统而不像战术情报，又太具体而不像战略情报。作战情报需要在一定程度上紧急采取行动，然而任何采取的行动都可能产生深远影响，因此 OODA 循环中的“观察”和“定向”阶段包含更多组件和复杂性。此外，处理数据的分析师和位于高管层的决策者对做出决策并采取行动的必要性感受不同，后者可能希望花费大量时间权衡最佳行动方案。

承接前文关于漏洞活跃利用战术指标的示例，作战层面的情报将包括利用范围有多广、是定向还是机会主义、还有谁被攻击、正在安装的恶意软件的目的，以及实施攻击的攻击者的任何细节。了解这些细节可以支持后续情报的生成，包括可能观察到的其他行动，并应包含威胁严重性信息以帮助规划响应。

## 战略情报

在军事或政府领域，**战略情报**处理国家和政策层面的信息，通常是多年分析工作的积累，旨在提供态势的全貌。在 CTI 中，我们认为这是支持高管和董事会在风险评估、资源分配和组织战略方面做出重大决策。该信息包括威胁趋势和攻击者动机，以及与组织相关的其他信息。在前面的示例中，战略情报将包括攻击者动机的信息，特别是当活动表明存在新的或先前未识别的威胁时，以及任何表明新战术或攻击者目标可能需要更高层面响应的信息，例如新政策或架构变更。

# 置信度

如前所述，情报通常具有不同的关联置信度。这些置信度反映了分析师对信息正确性和准确性的信任程度。对于某些类型的数据，这种置信度可能基于数值量表（例如 0 到 100）并使用传统统计方法计算，而在其他情况下，置信度评估由分析师基于定性、主观基础直接提供。重要的是要在两个关键领域确定置信度：对信息来源的置信度，以及对分析师结论的置信度。

描述来源可靠性的一种常见方法是 `FM 2-22.3` (`https://fas.org/irp/doddir/army/fm2-22-3.pdf`) 中的海军部代码或北约体系。这包含两个量表。第一个基于以往信息评估来源可靠性，范围从 A（可靠）到 E（不可靠）。第二个量表评估对信息内容本身的置信程度，范围从 1（已确认）到 5（不可能）。这两个分数根据来源和具体内容针对特定信息进行组合，因此来自有效信息历史来源的已知真实信息可能被评为 B1，但来自无效信息历史来源的不可能信息将被评为 E5。
