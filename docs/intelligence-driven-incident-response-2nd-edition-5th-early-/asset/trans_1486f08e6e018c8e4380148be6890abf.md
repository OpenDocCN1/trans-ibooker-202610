

# 域名

极少数网络连接直接指向 IP 地址，因此大多数攻击者使用域名。某些域名被选作特定的诱饵或用于迷惑分析师，旨在模仿或看起来与其他可识别的域名相似（例如使用同形异义攻击，如用小写字母 l 代替大写字母 I）。

# 电子邮件地址

网络钓鱼是攻击者利用电子邮件的首要且最明显的方式。这些电子邮件地址通常构建为一次性或限时使用，并且像域名一样可能模仿相关域名甚至特定人物。电子邮件地址也是建立其他基础设施、嵌入证书，甚至关联加密货币等支付收发方式所必需的。

## 投递

一旦攻击者收集了足够的信息来构建攻击，杀伤链的下一阶段就是投递。常见的投递场景包括但不限于以下内容：

### 定向钓鱼

攻击者通过直接通信（通常是电子邮件）向特定目标发送武器化的漏洞利用代码，形式为附件或链接。该通信通常经过精心设计，使其看起来合法，从而降低目标用户的戒备心理。近年来，攻击者还利用即时通讯平台和短信向用户发送包含恶意链接的通信。

### 服务漏洞利用

2000 年代初常见的一类直接利用面向 Web 的服务的攻击向量再次抬头。在这些情况下，攻击者发现面向 Web 的服务（如 Web 应用程序或虚拟专用网络）中的漏洞，并直接发起攻击。在许多情况下，这些是通用系统（例如中国关联攻击者入侵 Pulse VPN - <https://www.mandiant.com/resources/suspected-apt-actors-leverage-bypass-techniques-pulse-secure-zero-day>）。虽然其中一些攻击高度定向，但像 Shellshock 和 Log4J 这样的漏洞已被广泛利用。

### 战略性网站入侵（水坑攻击）

在一种两阶段攻击中，通常基于之前的服务漏洞利用场景，攻击者首先入侵一个次级资源（通常是预期目标可能会使用的网站），并在其上植入浏览器或媒体漏洞利用代码。其假设是目标（通常针对整个群体而非特定个人）会访问该网站，从而被攻陷。

投递的关键在于其简单性：仅仅是将有效载荷传递给受害者。这种简单性掩盖了该阶段的重要性。投递是攻击者对受害者采取的第一个必然的主动阶段。虽然之前的阶段（在目标选择和侦察的情况下）可以是主动的，但投递是攻击者*必须*主动的第一种情况，这往往会导致受害者（无论是预期目标还是安全团队）能够检测到的痕迹。这意味着投递是受害者保证拥有妥指标和攻击者战术、技术与流程以供分析的第一种情况。在定向钓鱼的情况下，这可能是邮件头和电子邮件地址等邮件工件，而对于 SQL 注入，这可能是发起 Web 服务器/数据库连接的 IP 地址。

## 漏洞利用

理解投递和漏洞利用之间的区别可能具有挑战性。在投递开始之前，攻击者未与目标有过直接交互，也不控制目标系统。即使在定向钓鱼邮件的情况下，安全措施也可能阻止成功投递，因此即使发生了投递，也未发生实际的漏洞利用。漏洞利用是攻击者获得代码执行控制权并开始执行其自身代码的时刻。

在水坑攻击中，这发生在受害者访问受感染页面的那一刻。对于定向钓鱼攻击，这是受害者点击恶意附件或链接的时刻。从这一点开始，攻击者控制了目标系统上至少一个进程。这个立足点是攻击者横向移动进入网络的起点。

漏洞利用本身就是一个庞大的主题，以至于拥有自己的专家（甚至拥有自己的公司、市场和经济体系）。如需深入了解，请参阅：

- [The Ida Pro Book](https://www.goodreads.com/book/show/3004460-the-ida-pro-book?from_search=true&from_srp=true&qid=SrY3kR5hSP&rank=1) by Chris Eagle

## 安装

获得初始执行通常很困难，也不是攻击者愿意重复多次的事情。一旦攻击者获得代码执行权限，他们的第一步通常是通过创建永久立足点来巩固访问权限。洛克希德·马丁杀伤链论文对此描述如下：“在受害者系统上安装远程访问木马或后门，允许攻击者在环境中保持持久性。”虽然这是攻击者在此阶段通常所做的，但我们发现将这些行为视为建立系统或网络持久性很有用（在许多情况下，攻击者两者都会做，但分别考虑它们仍然有帮助）。

### 系统持久性

此时，攻击者在单个系统上获得了代码执行权限，且可能仅限于单个进程。这是一个有用的开端，但无法在重启后持久存在。受损应用程序的关闭甚至可能移除他们的访问权限。

大多数攻击者首先通过部署 Rootkit 或远程访问木马（RAT）风格的植入程序，来巩固他们对少量主机的控制。Rootkit 建立对系统的内核级访问，一旦安装，允许攻击者规避底层操作系统的许多检测方法。RAT 是一种远程控制软件，旨在持久化以度过重启，且不依赖特定漏洞。这使攻击者能够在单个主机上持久化。

### 网络持久性

绝大多数攻击者不满足于建立单系统立足点。相反，他们想要建立更深层的持久性。为此，他们通常会建立更广泛的足迹，使用以下两种技术中的一种（或两者兼用）：

#### 在多个系统上建立系统持久性

这意味着使用窃取的凭证，在其他系统上安装 RAT 或类似的访问方法。攻击者有多种选择，从定制软件到原生工具，如 Windows 中的 `PsExec` 或 \*nix 环境中的 `SSH`。

#### 收集凭证以实现广泛的网络资源访问

这通常意味着 VPN、云服务或其他面向互联网的系统，如 Web 邮箱。这在许多情况下降低了被检测的风险，且不需要恶意软件形式，而是使用原生工具。

这些技术可以单独使用，也可以组合使用。这种技术组合通常是大多数攻击者的标志性技术集。
