

# 情报收集学科

## HUMINT（人力情报）

人力情报源于人类，无论是通过秘密或隐蔽方法，还是通过公开收集（如来自外交官）。人力情报是最古老的情报收集形式。关于网络威胁情报是否可以从 HUMINT 中获取，存在严肃的争论，然而越来越多的证据表明 HUMINT 可以成为故事中至关重要的一部分。一个例子是对涉入入侵事件或拥有入侵第一手知识的个人进行访谈或交谈，例如当 `Kaspersky Labs` 的研究人员设法联系上一名系统管理员，其网络作为 `Moonlight Maze` 行动的一部分被攻陷。这位系统管理员不仅提供了只有经历过入侵的人才能拥有的内部信息和视角，还提供了入侵期间使用的一台服务器的访问权限——那台服务器一直放在他的桌子底下——HUMINT 往往能引出额外的数据收集。另一个常被描述为 HUMINT 的例子是通过受限或仅限会员的在线论坛与个人互动获得的信息。这种情报收集类型也可被视为 SIGINT，因为它源于电子通信。

## SIGINT（信号情报）

信号情报包括通过拦截信号获得的情报，包括通信情报（COMINT）、电子情报（ELINT）和外国仪器信号情报（FISINT）。大多数技术情报收集都属于 SIGINT 范畴，因为毕竟，计算机通过电子信号运作，所以源自计算机或其他网络设备的任何东西都可被视为 SIGINT。

## OSINT（开源情报）

开源情报从公开可用的来源收集，包括新闻、社交媒体和商业数据库，以及各种其他非机密来源。我们之前讨论过，情报分析（包括网络威胁情报）涉及某种程度的保密性。然而，这并不意味着*所有*情报来源都必须是秘密的。关于网络安全威胁的公开报告是一种 OSINT，在情报分析中非常有用。在处理政府支持的行为体时，详细描述该政府进攻性网络部队组织架构的出版物能提供大量知识。OSINT 还能帮助揭示公开可访问的技术细节，如 IP 地址或域名；例如，详细记录谁注册了恶意域名的 `WHOIS` 查询。

## IMINT（影像情报）

影像情报从视觉表现中收集，包括摄影和雷达。IMINT 通常不是网络威胁情报的来源，但总会有视觉表现能提供关键信息的情况，例如在大规模、政府支持的拒绝服务攻击期间监控部队调动的能力，正如之前在俄罗斯和格鲁吉亚冲突中所见。[^1]

## MASINT（测量与特征情报）

测量与特征情报通过技术手段收集，不包括信号和影像。MASINT 通常包括核、光学、射频、声学和地震特征。由于 MASINT 专门排除了信号情报，它也不是典型的网络威胁情报来源。

## GEOINT（地理空间情报）

地理空间情报从地理空间数据中收集，包括卫星和侦察影像、地图、`GPS` 数据以及其他与位置相关的数据源。一些组织认为 IMINT 是 GEOINT 的一部分，而另一些则认为它是一个独立的学科。与 IMINT 类似，GEOINT 不是典型的网络威胁情报来源，但它可以提供关于威胁的背景信息，帮助你理解攻击者如何利用网络领域实现其目标。

## 其他情报学科

此时，许多人会提出多年来出现的各种其他 INT，包括 `CYBINT`、`TECHINT`、`FININT`，以及我们发现的最新一个——`CyberHumint`——但这些新术语大多已被其他情报收集方法涵盖。例如，网络情报主要源自 `ELINT` 和 `SIGINT`。争论现存 INT 的数量并不重要；重要的是理解数据的来源。归根结底，如果将特定收集类型称为其自己的 INT 有助于工作，那就尽管用吧；只需准备好应对该领域常出现的术语冲突即可。

## 网络威胁情报特定收集方法

除了此处列出的传统情报收集学科外，一些收集方法常专门用于网络威胁情报。深入了解这些特定威胁数据的来源非常有用：

### 事件与调查

这些数据源自对数据泄露和事件响应活动的调查。这通常是网络威胁情报中使用的最丰富数据集之一，因为调查人员能够识别威胁的多个方面，包括所使用的工具和技术，且通常能识别入侵背后的意图和动机。

### 蜜罐与蜜网

这些设备被设置为模拟单台机器或整个网络，并收集关于与这些设备交互的信息。蜜罐有多种类型：低交互、高交互、内部蜜罐和公共互联网上的蜜罐。只要你知道蜜罐的类型、它们监控的内容以及交互的性质，蜜罐信息就很有用。从捕获漏洞利用尝试或在系统上安装恶意软件尝试的蜜罐收集的流量，在分析中比扫描或网页抓取流量要有用得多。

### 论坛与网站

各种公司声称拥有深网或暗网收藏。在许多情况下，这些公司指的是访问受限、无法从互联网轻易访问的论坛和聊天室。在这些论坛和网站上，个人经常交换经过分析后很有价值的信息。这类网站数量众多，几乎不可能让任何一家公司完全覆盖 `the dark net`，因此要意识到收集范围通常有限，且会与其他声称拥有类似数据的公司有所不同。

即使这些技术也是过去常用技术的新迭代。随着技术演进，故者常新，情报亦不例外。哲学家乔治·桑塔亚那关于遗忘过去的警示一如既往地真实。

# 模型

## 模型的作用

模型是分析师工具箱中的关键工具。没有模型，许多分析师将无法应对世界上存在的海量数据，或应对要求他们赋予这些数据意义的需求。他们将难以综合刚才讨论的所有各种来源收集的信息，并产出与决策者相关的意义和洞察。

## 模型类型：心智模型与概念模型

关于情报用途模型的最佳工作定义之一来自《定量情报分析》一书——“模型是指对系统、实体、现象或过程的认知、概念、数学、物理或其他逻辑表征。”网络威胁情报中最常用的两种模型是心智模型和概念模型。心智模型是持有分析师现实感知的认知模型。即使分析师接受过相似的正规培训，由于个体感知和处理信息的多样化方式，他们的心智模型可能截然不同。
