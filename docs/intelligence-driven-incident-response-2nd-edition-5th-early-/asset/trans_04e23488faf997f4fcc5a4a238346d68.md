

## 情报周期

情报周期如[图 2-3](#ch02.html#figure_2_3_the_intelligence_cycle)所示，是生成和评估情报的正式流程。该周期始于上一个情报流程结束之处，并在此基础上持续构建。情报周期不必严格遵循每一个细节。事实上，本书后面探讨的流程将在此基础上构建。然而，你必须小心，不可遗漏关键步骤。如果你开始跳过整个步骤，就会面临最终得到更多数据和问题而非情报的风险。

![](assets/image-to-come.png)

要妥善利用情报周期，你需要了解各步骤涉及的内容，我们将在接下来深入探讨。

### 方向

情报周期的第一步是方向——也称为需求。*方向*是确定情报旨在回答的问题的过程。该问题可以来自外部来源，由情报团队自身制定，或由利益相关者和情报团队共同制定。（这有时称为 *RFI 流程*，我们将在第 4 章“查找”中讨论。该过程的理想结果是一个清晰、简洁的问题，其答案为利益相关者所可用。

大量情报工作围绕需求展开。在情报界，任何开展的工作或流传的报告都需要直接关联到某项情报需求，无论是常设（长期）需求还是优先（紧急且时效性强）需求。

### 收集

下一步是收集回答问题所需的数据。这是一项广泛的工作，应侧重于从多个来源收集尽可能多的数据。冗余信息在此处增加价值，因为佐证往往很重要。

这引出了建立有效情报计划的一个关键理念：建立收集能力。很难确切知道哪些数据最终可能被证明有用，因此建立广泛的能力以收集各类信息非常重要。这包括战术信息，如基础设施、恶意软件和漏洞利用，以及作战战略信息，如攻击者目标、社交媒体监控、新闻监控和高层文档开发（识别报告，如供应商发布的关于团体的报告，并从中收集信息）。请务必记录来源并谨慎对待：新闻故事往往转载或引用相同的原始材料，导致难以分辨什么是佐证，什么只是对同一材料的重述。如果无法确定特定数据集的来源，你可能需要避免将其用作收集来源。

收集是一个过程，而非一次性行动。利用第一轮收集的信息（如收集 IP 地址）引出第二轮（如使用反向 DNS 查找与这些 IP 地址相关的域名），进而引出第三轮（使用 WHOIS 收集关于这些域名的信息）。这种开发利用随着自身的构建而呈指数级增长。此时的重点不是理解数据如何关联，而只是尽可能开发更多信息。关联分析留待后续进行。此外，别忘了考虑内部来源，如事件管理系统。组织发现其早已熟知的行为体或攻击的情况很常见。

### 处理

数据并不总是能以其原始格式或收集时的格式直接使用。此外，不同来源的数据可能采用不同格式，有必要将其转换为统一格式，以便共同分析。使数据可用所需的*处理*往往是一项被忽视的任务，但没有它，生成情报几乎是不可能的。在传统情报周期中，处理是收集的一部分。然而，在处理事件响应中涉及的数据类型和组织时，单独考虑处理可能更有用。以下是处理与网络威胁相关数据的一些最常见方式。

#### 标准化

处理包括将收集的数据标准化为统一格式以供分析。收集过程将产生几乎所有可想象的数据结果。情报数据采用多种格式，从 JSON、XML、CSV 到电子邮件中的纯文本。供应商在网站的博客文章或表格中共享信息，也以基于 PDF 的报告甚至 YouTube 视频的形式共享。同时，组织倾向于以不同格式存储数据。一些组织使用专门构建的威胁情报平台，而其他组织则从维基或内部应用程序构建定制解决方案。

#### 索引

大量数据需要可搜索。无论处理网络地址和互斥体等可观测指标，还是论坛帖子和社交媒体等作战数据，分析师都需要能够快速高效地搜索。

#### 翻译

在某些情况下，地区分析师可能提供源文档的人工翻译，但对于处理来自世界各地信息的大多数组织来说，这通常不可行。机器翻译虽不完美，但通常提供足够的价值，使分析师能找到感兴趣的项目。如有必要，随后可升级给专家进行更准确的翻译。

#### 丰富

为一条信息提供额外的元数据很重要。例如，域名地址需要解析为 IP 地址，并获取 WHOIS 注册数据。Google Analytics 跟踪代码应交叉引用以查找使用相同代码的其他网站。此丰富过程应自动完成，以便相关数据立即可供分析师使用。

#### 过滤

并非所有数据提供同等价值，当面对无尽的无关数据流时，分析师可能不堪重负。算法可以过滤掉已知无用的信息（尽管仍可搜索），并将最有用和相关的数据浮现出来。

#### 优先级排序

收集到的数据可能需要排序，以便分析师将资源分配给最重要的项目。分析师的时间宝贵，应正确聚焦以最大化情报产品的效益。

#### 可视化

数据可视化已显著进步。虽然许多分析师因供应商仪表盘通常包含的杂乱内容而畏惧它们，但基于分析师需求（而非市场和高管认为好看的东西）设计可视化，有助于降低认知负荷。

花时间有效处理数据能赋能并改进未来的情报工作。

### 分析

*分析*既是一门艺术也是一门科学，旨在回答方向阶段确定的问题。在情报分析中，收集到的数据被表征并与其他可用数据对照考量，并对其含义和影响做出评估。通常会对未来影响做出预测。进行分析有多种方法，但最常见的是使用分析模型来评估和构建信息、识别关联，并对其影响做出评估。除了我们将在本章后面介绍的预存模型外，分析师开发适合其特定数据集或解读信息方式的自有模型也很常见。
