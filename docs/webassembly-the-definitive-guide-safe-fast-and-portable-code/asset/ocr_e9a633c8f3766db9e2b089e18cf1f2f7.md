# Example 3-3. A WebAssembly module that imports a function.

```
(module
    (func $log (import "imports" "log_func") (param i32)) ①

    (func $how_old (param $year_now i32) (param $year_born i32)
    (result i32) ②
        get_local $year_now
        get_local $year_born
        i32.sub)

    (func $log_how_old (param $year_now i32) (param $year_born i32) ③
        get_local $year_now
        get_local $year_born
        call $how_old
        call $log
    )

    (export "how_old" (func $how_old)) ④
    (export "log_how_old" (func $log_how_old)) ⑤
)
```

① Importing a function from the host that expects a single i32 parameter

② Our same $how_old function as before

③ A new function that takes two parameters and then calls our imported function

④ Exporting our old how_old function as before

⑤ Exporting our new log_how_old function
