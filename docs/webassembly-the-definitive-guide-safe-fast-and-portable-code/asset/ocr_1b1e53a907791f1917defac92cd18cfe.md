There are some things that are unnecessarily difficult in WebAssembly as a consequence of the security and safety goals that are easier on other platforms. Reading from the filesystem, writing to the console, and manipulating strings in memory are all simple activities in a language like C, C++ or Rust. It is expected that an operating system will allow a user with sufficient priviliges to do these things. There are not explicit, contextual boundaries.

Unfortunately, that is also the problem behind most modern cyber threats such as phishing attacks, privilege escalation, supply chain attacks and more. If an attacker is able to convince a privileged user to run untrustworthy code, he can often steal access to other resources not otherwise due him.
