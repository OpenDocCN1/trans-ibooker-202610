# Example 8-5. A simple program to add two numbers with Emscripten macros

```
#include <emscripten.h>

EMSCRIPTEN_KEEPALIVE int add(int x, int y) {
    return x + y;
}
```

> 1  Include the Emscripten header for the macro definition.

> 2  Tell the Emscripten compiler to keep the add() method around.

Now we can recompile with emcc and run it with Node.js:

```
brian@tweezer ~/g/w/s/c/node> emcc add.c
brian@tweezer ~/g/w/s/c/node> ls -alF
```

If you investigate the file a.out.js, you will see all of the set up the Emscripten toolchain has handled for us.

There is a proper JavaScript-based WebAssembly API available via the Node.js runtime such as we have seen in the browser. This allows you to load and instantiate modules and invoke behavior on them as you see fit. Behind the scenes, this is what the Emscripten toolchain is generating for us.
