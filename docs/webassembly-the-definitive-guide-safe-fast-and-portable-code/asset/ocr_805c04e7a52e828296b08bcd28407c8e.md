Artichoke is a Rust-based Ruby runtime environment that is designed to be compatible with Matz’s Ruby Interpreter (MRI)⁶. It is early days so I do not want to spend much time on this project, but it seems to be moving quickly and they are looking for contributors so I wanted to mention it in case you were interested. I would love to see this evolve into a full-throttle way of getting Ruby more fully into Webassembly environments as it also supports running untrusted code in a sandboxed environment.

I have detailed some ways to install artichoke in Appendix A. This includes the artichoke Ruby interpreter and an irb⁷ replacement called airb. For now the easiest way to experiment with this Ruby-to-WebAssembly toolchain is probably through the Playground⁸ which can be seen in Figure 17-4.
