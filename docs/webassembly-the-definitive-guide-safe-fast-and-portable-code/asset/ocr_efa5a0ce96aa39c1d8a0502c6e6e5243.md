In addition to making it easier to export functions from Wasm modules, AssemblyScript also makes it easy to import functionality for the module to call into its JavaScript environment. In Example 14-6 you can see we are expressing an intent to import a function called log() by using the declare keyword.

# Example 14-6. Declaring functions for import to AssemblyScript

```
declare function log(num: i32): void;

export function addAndLog(a: i32, b: i32): void {
  log(a + b);
}
```
