```
println!("Rust is {}", s);
}
```

Now, by recompiling (and suppressing the unused assignment warning) we end up in a happier place.

```
brian@tweezer ~/g/w/s/ch10> rustc -A unused_assignments

brian@tweezer ~/g/w/s/ch10> ./immutable
Rust is safe
```

It may annoy you at first that you have to communicate this clearly, but the Rust compiler is just teaching you how to be an adult where communication is critical to well-being and success.
