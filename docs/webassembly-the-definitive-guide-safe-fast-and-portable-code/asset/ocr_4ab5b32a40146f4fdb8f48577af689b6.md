# Simple Example

By now you should not be surprised that our first example will be to add two numbers together. It is just the simplest thing we can show in WebAssembly usually before things get weird. You will see just such a starter example in Example 14-4.

Example 14-4. The ubiquitous code to add two integers together

```
export function add(a: i32, b: i32): i32 {
  return a + b;
}
```
