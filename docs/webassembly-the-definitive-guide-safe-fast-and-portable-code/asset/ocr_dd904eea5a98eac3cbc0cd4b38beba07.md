# Installing Dotnet Tools

As you have seen in the book, .NET has become a robust WebAssembly environment, particularly now that it is cross-platform.

The good news is that it is a piece of cake to install. The instructions for the major operating systems are located here:

https://dotnet.microsoft.com/download

Once those are installed, you should be able to run the command line examples we featured in the book.

# Installing AssemblyScript

AssemblyScript is emerging as a strong player in the WebAssembly world. It strikes a nice balance between the past and the future. You do not have to learn C or C++ code and can stay in a somewhat familiar language space while still producing higher performance software.

The main website is here:

https://www.assemblyscript.org

Installation instructions are here:

https://www.assemblyscript.org/quick-start.html
