> —Brian Eno

My career started in the user interface world. I first worked on an X/Motif¹ application to control Network Matrix Switches. From there, I went on to a Whole Earth visualization environment capable of displaying terabytes of terrain data and hyperspectral imagery. Not only was this fun from a 3D visualization perspective, but we were inspired by Doug Young at Silicon Graphics to build the entire application around the Command Pattern² a year before the “Gang of Four” “Design Patterns” book emerged.

Working on software that humans sat down and used was a fun and rewarding experience most of the time. You could genuinely make people’s lives easier and less stressful by putting some thought into how they went about their work tasks. Despite these positives, it had its drawbacks as well.
