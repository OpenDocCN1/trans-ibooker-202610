Finally, we have a Code section which contains the actual instructions of our only function.

The red colors indicate section boundaries, but you can also get more details by hovering over the various sections in the browser. The purple bytes of the Export section, for instance, should indicated the name of the exported function how_old if you place the mouse over one of one of them. You can see the actual instructions by hanging out over the green and blue bytes in the final Code section.
