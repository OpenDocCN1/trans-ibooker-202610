So far we have been using a block of code in a file called utils.js that looked like what you see in Example 3-7. Performance is not just about run-time performance, it is also about load-time performance.

# Example 3-7. The simple way we have been instatiating modules

```
function fetchAndInstantiate(url, importObject) {
  return fetch(url).then(response =>
    response.arrayBuffer()
  ).then(bytes =>
    WebAssembly.instantiate(bytes, importObject)
  ).then(results =>
    results.instance
  );
}
```
