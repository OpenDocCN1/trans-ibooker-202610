# Installing TinyGo

As I indicated in the last chapter, TinyGo is emerging as a nice starting point for the integration between Go and WebAssembly in addition to its support for microcontrollers and other embedded systems.

The main website is here:
https://tinygo.org

Instructions for installing on various operating systems or Docker are available here:
https://tinygo.org/getting-started/install/
