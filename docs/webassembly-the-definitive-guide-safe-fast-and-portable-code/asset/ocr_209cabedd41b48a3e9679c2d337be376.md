The main website for Wasmer is:

https://wasmer.io

In addition to being a standalone runtime, it has integration support for:

+   - Rust
+   - C and C++
+   - JavaScript
+   - Go
+   - Python
+   - PHP
+   - Ruby

It also maintains the WebAssembly Package Manager (WAPM), WebAssembly.sh, and the Wasienv toolkit.

A great place for getting started and installing the runtime is their excellent documentation here:

https://docs.wasmer.io/ecosystem/wasmer/getting-started

# Installing Rust Tools

Rust clearly has a big place in the WebAssembly ecosystem, but it has a lot to speak of on its own as a safe, fast programming language that is growing in adoption rapidly.

The main website is:

https://rust-lang.org

You will generally want to use the rustup tool for managing your Rust toolchain. They support nightly, beta and stable versions.
