# The Bigger Picture

The full vision of WebAssembly is way more expansive than most people have realized. There is a decent awareness about the capabilities of the MVP out there, but for most people that is where it ends. The idea of being able to use languages other than JavaScript to deploy code to the browser is kind of cool but not a strict necessity given the advancements in the language and the JavaScript runtime engines.
