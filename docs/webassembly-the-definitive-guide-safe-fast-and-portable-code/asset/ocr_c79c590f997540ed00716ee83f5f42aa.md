As a simple example, we will build a set of functions for calculating details of a circle based on its radius. In Example 14-10 we have three exported functions for calculating the diameter (2r), circumference (2πr), and area (πr²)⁹. Because AssemblyScript defaults to f64 numbers, we cast them to f32 numbers before returning the values from the functions.

# Example 14-10. AssemblyScript that uses the Standard Library

```
export function diameter(radius: f32): f32 {
    let diam = <f32>(2.0 * radius);
    return diam;
}

export function circumference(radius: f32): f32 {
    let circ = <f32>(2.0 * Math.PI * radius);
    return circ;
}

export function area(radius: f32): f32 {
    let area = <f32>(Math.PI * Math.pow(radius, 2));
    return area;
}
```
