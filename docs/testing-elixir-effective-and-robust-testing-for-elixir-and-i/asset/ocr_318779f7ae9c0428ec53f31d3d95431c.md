# Plugs

The Phoenix library has been hugely helpful to the productivity of anyone wanting to write an Elixir-based web application, but it’s useful to know that it owes a lot of its success to another library, Plug.[42] Plug is a basic specification and tooling set that allows users to create composable web applications. In this chapter, we’ll mention “plugs” as a reference to middleware that you might be using in your application. Additionally, the Plug library provides some of the testing tools that we’ll require. Don’t worry, though: because Plug is a dependency of the Phoenix framework, if you’re working in a Phoenix-based application, you already have Plug and its testing tools available to you. We’ll refer to any modules, both those provided by Phoenix and those custom written, that match the interface defined by Plug as plugs.
