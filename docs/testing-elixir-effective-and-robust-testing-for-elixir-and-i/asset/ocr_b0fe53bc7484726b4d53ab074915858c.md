Mox provides two main functions to create stubs and mocks of functions in the behaviour. The first one is called Mox.stub/3. This function takes the mock module, the name of the function to be stubbed, and an anonymous function of the same arity of the function to be stubbed. This anonymous function is what will be executed when the stubbed function is invoked on the mock module. Usually, stub/3 is used inside single tests.
