There’s a tool called Bypass that helps in this situation.

Bypass is a library that lets you define Plug-based servers on the fly with an API similar to the one provided by Mox that we saw in the previous sections. Let’s see how we can use it to improve our tests.[17] First of all, add the library to your dependencies in place of :plug_cowboy:

end
