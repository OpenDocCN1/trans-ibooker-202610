# Microsoft Office's roaming settings

Office's roaming feature enables experiences across Microsoft 365 apps and devices to improve productivity and make Office more personalized to you across any device. Some examples of settings and features are the list of most recently used files, the last reading position in a document, the first-run experience for Office add-in, autocorrect preferences, and themes.
