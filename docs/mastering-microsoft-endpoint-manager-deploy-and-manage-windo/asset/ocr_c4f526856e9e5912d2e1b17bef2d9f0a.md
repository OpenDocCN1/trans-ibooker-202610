+   - Rights to create computer accounts in the right Organization Unit
+   - Azure AD Connect configuration
+   - Subnet range – are there enough IP addresses available for your deployment?
+   - Endpoint connectivity (MEM and AV service URLs)

The other great thing about this feature/service is that it constantly runs in the background. For example, when something changes in your environment, it will try to fix it for you – or send you, as the IT admin, a notification with the resolution of the problem!
