# Profile: **Windows Security experience**

The Windows Security app is used by several Windows security features to provide notifications about the health and security of a machine. Security app notifications include firewalls, antivirus products, and Windows Defender SmartScreen.

The Windows Security experience profile can be used to turn off areas in the Windows Security app, such as family options if you don't want to show family options on your Intune-managed devices:
