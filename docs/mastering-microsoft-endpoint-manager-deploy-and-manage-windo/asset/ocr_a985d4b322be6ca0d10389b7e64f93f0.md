# Enrolling devices – Windows enrollment

In this section, we will learn about several different ways a Windows 10 PC can be enrolled into Intune by users or admins, which you can find under **Devices | Enroll devices | Windows enrollment** inside the admin center portal.

> **Important Note**
> 
> Windows 365 Cloud PCs are automatically enrolled into Microsoft Endpoint Manager's Intune.

# Automatic enrollment

This section covers configuring Windows devices to enroll when they join or register with **Azure Active Directory (AAD)**. We covered this in the previous chapter, *Chapter 5, Requirements for Microsoft Endpoint Manager*, so please go back to that chapter to learn more.
