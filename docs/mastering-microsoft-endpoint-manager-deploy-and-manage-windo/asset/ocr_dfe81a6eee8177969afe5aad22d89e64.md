Microsoft Endpoint Manager app delivery supports the direct enrollment of Microsoft 365 apps from within the app profile configuration menu.

It’s just a drop-down menu that allows you to include or exclude Microsoft 365 apps from installation (without the need for an ODT – XML file):

Figure 8.39 – Add Microsoft 365 Apps

When you have selected the Office apps you want in this deployment, you can continue in the Microsoft 365 Apps wizard.
