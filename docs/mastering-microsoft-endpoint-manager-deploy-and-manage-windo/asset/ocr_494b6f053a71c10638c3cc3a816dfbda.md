You will get the information back to proceed. The GPOs you imported are now all listed with the following information:

+   - **Group policy name:** The name is automatically generated using the information in the GPO.
+   - **Active Directory Target:** The target is automatically generated using the Organizational Unit (OU) target information in the GPO.
+   - **MDM Support:** This shows the percentage of group policy settings in the GPO that has the same setting in Intune.
+   - **Targeted in AD:** Yes means the GPO is linked to an OU in on-premises group policy. No means the GPO isn't linked to an on-premises OU.
+   - **Last imported:** This shows the date of the last import.
