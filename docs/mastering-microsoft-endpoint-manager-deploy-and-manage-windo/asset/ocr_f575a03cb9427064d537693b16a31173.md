# How to create MSIX packages

The process of creating MSIX packages looks pretty similar to what you may have done in the past with App-V. The app developer creates the application and creates the MSIX package (this could be the **Independent Software Vendor (ISV)**), after which you customize the application for deployment via Intune – Microsoft Endpoint Manager and assign it to the correct AAD group or users.
