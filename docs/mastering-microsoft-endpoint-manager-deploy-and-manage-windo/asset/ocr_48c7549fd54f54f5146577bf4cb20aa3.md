# Section 3:
Mastering Microsoft
Endpoint Manager

The main section explains everything you should know, from A-Z, about the configuration and management process for Microsoft Endpoint Manager as well as other services that you can use to modernize your exiting Windows 10 Enterprise deployment. After reading this section, you will have enough knowledge to start deploying.

+   - *Chapter 10, Advanced Policy Management*
+   - *Chapter 11, Office Policy Management*
