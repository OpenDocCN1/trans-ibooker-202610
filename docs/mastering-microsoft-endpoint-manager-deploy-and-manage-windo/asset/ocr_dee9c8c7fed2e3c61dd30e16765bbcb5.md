# On-premises network connections

On-premises network connections are required so that we can create cloud PCs, join them to a specified domain, and manage them with Microsoft Endpoint Manager.

Before you start, create a connection to an on-premises environment for your line-of-sight connection to AD DS. You should have Network Contributor rights on the VNet to perform these steps.
