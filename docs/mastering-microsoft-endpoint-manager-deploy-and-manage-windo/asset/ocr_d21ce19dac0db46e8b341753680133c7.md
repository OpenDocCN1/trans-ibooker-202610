# Provisioning a cloud PC

Before we start, make sure that the account you are using has at least the Intune Service Admin role assigned. After provisioning, you can set the rights back to standard MEM RBAC. Perform the following steps:

+   1. Go to the Admin center portal's Windows 365 blade to provision policies.
+   2. Click on + Create policy:

![](bbox=[0.232, 0.264, 0.73, 0.337])

Figure 4.11 – Creating a provisioning policy

+   3. Provide a name for the policy; for example, East US Office.
+   4. Select the on-premises network connection (location) where you wish to place your cloud PCs:
