An IT administrator can defer the installation of both feature and quality updates from deploying to devices within a bounded range of time from when those updates are first made available on the Windows Update service.

This deferral can be used to allow time to validate deployments as and when they are pushed to devices.

Deferrals work by allowing you to specify the number of days after an update is released before it is offered to a device. In this way, you can create a ring deployment with different deferral days for the following:

+   - Pilot group
+   - Production ring 1
+   - Production ring 2
+   - Broad deployment
