# Purchasing and assigning cloud PC licenses via the Microsoft 365 admin center portal

Make sure that you have either a trial or production license with Microsoft Intune assigned to your tenant before moving on. Perform the following steps:

+   1. Go to https://admin.microsoft.com/ and purchase a Windows 365 license per size.
+   2. Go to Active users.
+   3. Open the required user(s).
+   4. Assign the Windows 365 cloud PC size license.
