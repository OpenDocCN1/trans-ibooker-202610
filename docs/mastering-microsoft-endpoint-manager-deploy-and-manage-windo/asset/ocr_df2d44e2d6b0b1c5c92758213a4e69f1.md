# Where does my printed data go?

Universal Print stores all print queues in Office data storage. This is the same storage that stores customers' Office 365 mailboxes and OneDrive files. A job stays in the print queue for a few days. If the job is not claimed at the printer within 3 days, it gets marked as aborted. Even after printing, a job may stay in Universal Print for a few more days (up to a total of 10 days).
