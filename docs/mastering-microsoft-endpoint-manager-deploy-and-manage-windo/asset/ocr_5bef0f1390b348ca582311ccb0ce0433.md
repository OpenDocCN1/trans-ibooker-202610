# Deploying Microsoft Edge

Microsoft Edge has been fairly easy to distribute to your endpoints ever since update 79 – it completely integrates within Microsoft Endpoint Manager, and this also applies to most of the policies that we'll cover in the next chapter.

In the Intune apps menu, you must add Microsoft Edge for Windows to install the Microsoft Edge browser on managed Windows 10 devices – as App type to start the configuration:
