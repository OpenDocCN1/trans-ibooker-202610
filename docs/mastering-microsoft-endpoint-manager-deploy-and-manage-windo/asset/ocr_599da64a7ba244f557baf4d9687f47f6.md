# Policy management

Using Microsoft Endpoint Manager – Intune to manage your Windows 10/11 Enterprise desktops is all about standardizing and simplifying the management layer of your environment. As explained in the previous chapter, everything is centered around layering your configuration sets (and applications) separately for the guest OS to remove the need to create custom images that include these things from the get-go.

Policy management within Microsoft Endpoint Manager – Intune makes it possible to configure the following options from within the Devices menu:

+   - Compliance policies
+   - Conditional access
+   - Configuration profiles
+   - Settings catalog
+   - Scripts
+   - Group policy analytics (preview)
+   - Enrollment restrictions
+   - Policy sets
