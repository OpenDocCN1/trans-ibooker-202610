# Network URL requirements for PowerShell scripts and Win32 apps

To find your tenant location (or Azure Scale Unit (ASU)), follow these steps:

+   1. Sign in to the MEM admin center.
+   2. Go to **Tenant administration | Tenant details.**

The location can be found under **Tenant location** as something such as **North America 0501** or **Europe 0202**. Look for the matching number in the following table.

The rows are differentiated by geographic region, as can be seen in the first two letters in the names (eu = Europe, na = North America, ap = Asia Pacific). Although your organization’s actual geographic location might be elsewhere, your tenant location will be one of these three regions:
