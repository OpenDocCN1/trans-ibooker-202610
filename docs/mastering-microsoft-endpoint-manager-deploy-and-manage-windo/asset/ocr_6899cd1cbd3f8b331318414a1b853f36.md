+   - **Simplified management and monitoring:** Provide easy access, control, and visibility of who is able to sync their Windows profile settings to ESR and who isn't. In the Azure portal, you can filter access based on Azure AD groups.

# What specific profile data is included in ESR?

Here's a list of profile settings for the Azure AD users that are stored within the ESR data and that will be restored every time the user logs on to a clean Windows 10 Enterprise device to provide a unified experience:

| Profile component | Description |
|---|---|
| Windows themes | Your desktop themes and taskbar settings are saved. |
| Language settings | Keyboard layouts, system language, date and time settings, and more. |
| Cached password | Your passwords are stored in both Windows and your browsers. |
| Ease of access features | High-contrast theme preferences and Narrator and Magnifier settings are saved. |
| Other Windows settings | Mouse properties and settings are saved. |

Once you enable ESR, log on to your Windows 10 Enterprise desktop and open **Accounts** under the **Settings** menu. You'll see all the activated settings synced as part of your Windows profile!
