# Insights and recommendations – score trends

It’s also possible to see the last 30 days of resource consumption and whether there’s a trend. This would make it easy, when you provide a fix, to see whether the improvement affects all your users.

Also, the other way around, when issues occur or you install an update that requires way more resources than before, you can start correlating your results with the time of enrollment of that patch or update. Very insightful.
