# Questions

+   1. What are the main benefits of using MEM?
+      A. MEM ensures that an organization no longer needs credentials to access and share company data.
+      B. MEM prevents remote devices and apps from accessing an organization's resources.
+      C. MEM helps keep an organization's cloud and on-premises devices, apps, and data secure.
+   2. What are the main differences between Windows 365 Cloud PC and AVD?
+      A. Windows 365 Cloud PC is designed for simplicity and AVD for flexibility.
+      B. Windows 365 Cloud PC has a fixed-price cost model and AVD is consumption-based.

# Answers

+   1. (A)
+   2. (A)
