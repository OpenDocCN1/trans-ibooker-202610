# Assigning permissions to use a printer(s)

In this section, you'll learn how to assign the right level of permissions to your end users in order for them to print:

> Tip
> Did you know you can also select the Allow access to everyone in my organization option to allow all users to print?

+   1. Select your Azure AD users or groups. Once you're ready, click on Share Printer:
