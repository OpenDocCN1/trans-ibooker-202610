There are a few settings that you need to configure to silently configure OneDrive KFM for the end user:

+   - **Silently sign in users to the OneDrive sync app with their Windows Credentials:** Select **Enabled:**
+   - **Silently move Windows known folders to OneDrive:** Select **Enabled.**
+   - **Tenant ID:** Use the tenant ID from your Microsoft 365 tenant.
