Make sure that the server where you configure AAD Connect – HAADJ – can connect to all the following URLs:

+   - https://enterpriseregistration.windows.net
+   - https://login.microsoftonline.com
+   - https://device.login.microsoftonline.com
+   - https://autologon.microsoftazuread-sso.com

Follow these steps to align with the prerequisites of the service. For physical PCs, do the following:

+   1. Go to your AAD Connect server, most likely running on-premises in your own private cloud data center environment.
+   2. Open the Microsoft AAD Connect program.
+   3. Open the Configure device options task.
