+   2. When you configure this on top of your existing profile solution, the syncing of data will happen while your users remain working on the existing solution.
+   3. The IT admin can then (after successfully configuring all the modern parts) schedule a cutover moment to remove the roaming profile elements and continue using local profiles instead. This approach also applies to FSLogix.

This could be an option to choose when you currently use a traditional VDI solution and want to leverage Windows 365, but also when you use Endpoint Configuration Manager or any other management solution for physical endpoint management and want to migrate them to physical endpoints managed by Microsoft Endpoint Manager.
