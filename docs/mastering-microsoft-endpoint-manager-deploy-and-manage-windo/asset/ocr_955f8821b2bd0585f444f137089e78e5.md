# Microsoft Endpoint Manager and Intune

What is unified endpoint management and how does this look through the concept of **Microsoft Endpoint Manager**? The following high-level architecture drawing explains how everything within Microsoft Endpoint Manager comes together in one unified endpoint management experience.

There is one console for your physical and cloud PCs via **Windows 365** endpoints and mobile devices. This is the only place where they can be managed in a unified way. Also, the Intune company portal can deploy apps from Configuration Manager, Intune, Windows 365, Azure Virtual Desktop, and Azure Active Directory – one end user experience for all apps!
