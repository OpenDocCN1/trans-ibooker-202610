# **术语表**

**A 面** 场景或机位在剪辑之前的部分。

**跨课程** 教育术语，指设计将多个学科相互关联的课程，而不是以专门且孤立的方式学习。

**自动对白替换**（ADR）在受控录音棚中录制角色对白并同步到画面的做法。与录制拟音时使用的过程类似。

**B 面** 指场景或机位在剪辑之后的部分。

**背景** 场景中并非主要焦点的音效或角色。为场景和环境增添氛围的次要角色或道具。

**吸音板** 用于减弱或消除在拟音棚中表演的拟音效果的结构。通常由泡沫或类似吸音材料制成。可以是固定式或便携式。

**明亮** 指拟音或音效的音色。音质轻盈而尖锐。

**取巧** 指一种拟音技巧，用于掩盖剪辑或表演中不完美的匹配，例如不易察觉地改变脚步声节奏，或掩饰不匹配的道具表演。

**警察**装备 简短术语，指警察佩戴的枪、警棍、皮带和手铐等道具组合。

**提示点** 用于标识要表演的特定拟音效果，通常带有精确的时间码以标明表演开始和结束。

**提示表** 为拟音师和混音师在拟音棚及随后在混录棚使用而计划并明确具体提示点的纸质表格。

**切入** 专业术语，指将音效剪辑进场景中。

**剪辑音效** 专业术语，指经过剪辑的音效，与表演录制的拟音效果相对。

**舞蹈拟音** 专门为舞步制作的拟音脚步声，通常由受过舞蹈训练的拟音师表演。

**无混响室** 设计为几乎不给声音增添活力或反射的拟音棚或录音室；通常有许多柔软墙面和表面来吸音。

**设计师** 实际构思并设计特定想象效果所需特殊声音的人，通常使用合成器和插件。

**泥土坑** 填有特定泥土的拟音坑，用于表演角色在泥土中行走的脚步声。

**混录棚** 具有重录能力的专门设计房间，用于对电影中使用的所有声音元素进行最终混音。

**装片员** 给录音机装填磁片的录音师。这台机器被称为“哑机”，因为它只装载用于播放的磁片而不录音，但它连接到拟音棚或 ADR 棚的录音设备。

**音效套件** 经过试听并分配给声音剪辑师、用于剪辑进特定场景或影片段落的特定音效；通常由声音编辑总监提供。

**精剪** 对拟音或音效进行精确剪辑，通常是剪辑场景或片段的最后一步。

**平直** 专业术语，指不添加混响或空间感的录音技术。

**翻轨，翻一条轨** 一种技术：将一段已剪辑的声音翻转过来，使声音不会与声头接触。用于消除轨道中的声音。在现代计算机剪辑中，采用清除声音的方法。

**拟音舞者** 从事舞蹈拟音的拟音师。

**拟音行话** 拟音师、混音师等使用的俚语，使用专业术语作为描述实践和技巧的简略说法。

**拟音棚** 表演同步音效的录音区域。

**拟音走步** 在拟音棚中替换电影角色脚步声的技术。

**拟音过的** 专业术语，指由拟音师同步画面表演的音效，与剪辑音效相对。

**福利的录音室** 指杰克·福利（Jack Foley）用来表演其同步音效的录音区域所获的称呼。

**全涂磁片** 用于录制拟音的一种磁带，可同时录制四条轨道。

**砂粒附着** 用于粗糙表面时粘在鞋上的泥土或其他物质。

**砂砾系数** 一种审美选择，即使用多少某种物质使行走表面听起来有砂砾感，例如用于肮脏的城市街道。

**砂砾表面** 添加了某种物质、使其听起来肮脏或像户外的行走表面。

**粗剪** 初步剪辑，给出同步和风格的总体概念，随后再进行更精细具体的剪辑。

**枪械动静** 为产生戏剧效果，用一把或多把枪发出的轻微碰撞声来表明它们在场景中的存在。

**喷涌、黏稠物、血腥** 指用于描述恐怖或悬疑场景声音的拟声俚语。

**整段挂用** 按录制原样使用拟音，不进行剪辑。时间有限时在电视制作中很常见。源自过去在磁带上录制、拟音录在全涂磁片上的做法。

**硬音效，硬 FX** 剪辑加入的音效，与表演录制的拟音效果相对。

**高频端** 录音或混音中明亮或单薄的声音；指声音中较高音高的范围。

**高电平** 专业术语，指以高音量录制或混合声音。常用于描述需要在大声场景中播放的拟音效果录音。

**工作站内** 专业术语，指音效在同一计算机系统或“盒子”中录制、剪辑和混合。

**音效库套件** 从音效库中预先安排的声音组合，由主管试听并挑选，供剪辑师用于为电影中的声音事件分层。




# Foley 术语表

## 术语

**准确落点，**落到提示点 指以正确的风格或角色特质准确完成拟音表演。通常用于形容第一次或第二次尝试（“take”）就表现优异。

**杂项清单（Laundry list）** 行业术语，指给拟音师的随意列出的脚步声和道具提示清单，没有时间码、细节或具体说明。

**引导片（Leader）** 未录制声音的胶片，用作画面或声轨中的空白，通常位于片盘开头，或作为未来音效的占位。

**循环配音（Looping）** 当代用法中指 ADR（自动对白替换）的行业术语。源于历史上不同步录制演员台词的做法，录下的内容可以“循环”播放供他人聆听和评判。

**低频（Low end）** 指音色更暗沉、更深沉的声音，例如用于营造神秘或恐惧效果的“低频隆隆声”。

**音乐与效果（M&E）** 音乐与效果。指包含效果、音乐和同期声轨完整混音的声轨，其中对白已被剪掉，用于需要替换语言的外语版影片。通常比保留原语言的国内发行版包含更完整的效果系列。

**磁性磁带（Mag）** 磁性磁带。在数字录音之前用于录制声音、音乐、对白和拟音。

**道具拟音（Manipulations）** 道具拟音的另一种说法。

**结合，效果与拟音结合（Marry, married effects and Foley）** 指一个完整的声音事件同时依赖剪辑效果和表演的拟音效果。

**金属余响（Metal ring off）** 指撞击声录下后仍持续存在的金属共振。

**动作捕捉（Motion capture）** 又称表演捕捉，指为真人电影、动画电影以及游戏的三维动画记录演员或物体运动的做法。

**口部音效（Mouth sounds）** 用嘴表演的拟音，通常补充其他拟音；往往带有喜剧效果。

**多轨（Multiple tracks）** 为一个声音事件的各个层面使用一条以上录音轨。

**光学声轨（Optical sound）** 在磁性磁带之前记录在光学胶片上的声音。声轨位于胶片的一条条带上。

**声像移动（Panning）** 混音拟音效果时使声音从一侧移动到另一侧的做法，例如人物横穿画面时声音从左到右。

**纸感（Paper life）** 行业术语，指在没有明确具体动作的情况下传达纸的存在感。

**课程平台（Platform）** 教育术语，指从第一门课程到最终课程逐步建立技能和知识的计划课程体系；每门课程都依赖前一门课程的知识。

**后期制作（Postproduction）** 电影制作流程，从画面剪辑开始，到最终混音或配音结束。

**预混（Predub）** 在最终混音将所有声音融合之前，将音效、拟音、ADR 和对白分别按组混音的过程。

**预混素材（Predubs）** 按“食物类别”分组的已收集声音素材，分为对白、主要 ADR、群杂 ADR、音效、背景效果、拟音脚步声和拟音道具。

**Pro Tools** 可在 Macintosh 或 PC 上使用的数字录音、编辑和混音系统。行业标准。

**同期声轨（Production track）** 制作期间录制的声轨，通常以场景中的对白为主。制作中录下的声音会被纳入，并作为音效和拟音的蓝本。

**挑选，已挑选（Pull, pulled）** 指从素材库中试听并汇编音效以供声轨使用。

**插入录音（Punch in）** 拟音混音中的技术：混音师在预先录制的提示中选定精确位置开始录音，并从该点进入该提示。

**四分之一英寸**磁带 用于盘式录音的录音磁带。

**读解（Read）** 指观众如何理解某事物。

**自由录制（Recorded wild）** 为特定目的在拟音棚中不同步录制的定制拟音效果；通常录制多个变化版本。

**录音员（Recordist）** 协助混音师的音频专业人员。历史上职责包括准备磁性磁带并确保录音质量。当代录音员最常协助混音师设置录音会话、排除 Pro Tools 故障，并记录拟音提示。

**余响（Ring off）** 道具撞击完成后录下的残留声音。

**擦蹭声（Scuffs）** 不是完整脚步声的脚步提示，但具有闷响撞击的特征质感。

**鞋履元素（Shoe element）** 所用鞋子的质感；所用鞋子的特性。

**单条磁带（Single stripe）** 只有一条可用于录音声轨的磁性胶片。

**雪声设计（Snow design）** 根据所描绘天气的质感，为制造特定雪声而使用的特定物质组合。

**声音师（Soundman）** 历史术语，指为电影、广播和电视制作或录制声音的职业。

**分轨（Stems）** 声轨中使用的特定配音声音素材组，例如对白分轨、音效分轨、音乐分轨。

**流线提示（Streamers）** 在电影银幕或监视器上移动的线条，用于提醒混音师和拟音师即将开始表演的提示。

**最佳**点 声音中界定其特质的最佳部分；源自体育术语。

**润色（Sweeten）** 增强已有的声音；添加原本不存在的声音特质。

**合成器师（Synthesist）** 使用合成键盘和乐器创造特殊声音与音乐效果的音频专业人员。常被误称为声音设计师。

**临时**混录 为影片或片段展示而制作的临时声音混录，并非完整声轨；通常用于观众测试。

**叠加同期声（Topping production）** 在已有同期声的情况下添加拟音或音效；需要精确同步，并与同期声轨协同播放。

**剪辑废料箱（Trim bin）** 剪辑中使用的金属箱，供剪辑师收集不需要的胶片，或悬挂待替换回声轨的胶片片段。

**移交，移交版本（Turn over, turnover）** 将影片最新版本交给流程下一环节的惯例；通常指画面剪辑将最终剪辑版交给声音编辑部门，用于制作音效、拟音、ADR 和音乐。

**走拟音（Walk the Foley）** 俚语行业术语，指为影片表演拟音效果。源于脚步声曾是拟音中需要替换的关键部分这一做法。

**走，走步（Walk, walking）** 表演拟音脚步声。

**拟音师（Walker）** 拟音师。俚语。

**看声导演（Watching directors）** 罗伯特·L·莫特创造的术语，指那些观看声音所用对象、而不是聆听声音本身的导演。
