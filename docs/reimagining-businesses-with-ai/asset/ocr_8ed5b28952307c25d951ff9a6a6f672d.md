# Software Architecture

Software architecture has evolved since the introduction of software to meet the requirements of the day and operate within the technological constraints. In the mainframe world, architecture was more monolithic, which transitioned to a more service-oriented one in the client-server world. As the web and mobile development continued to become the norm and kept getting more complex and distributed at the same time, the architecture evolved to a more microservices-based architecture. Growth of IoT and cloud computing introduced the paradigm of containerization to this whole mix.
