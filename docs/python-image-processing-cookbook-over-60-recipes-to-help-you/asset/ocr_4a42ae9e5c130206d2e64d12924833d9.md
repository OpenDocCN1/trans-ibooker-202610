**Optical Character Recognition (OCR)**/text recognition refers to the task of extracting text from images. In this recipe, we will use Tesseract v4 for text recognition. Tesseract v4, by default, uses an LSTM-based recognition engine. The `pytesseract` module just provides a wrapper over the Tesseract command-line tool (we can specify the command-line arguments with the `config` argument). # # Getting started

First, download the pretrained EAST text detector model from https://codeload.github.com/ZER-0-NE/EAST-Detector-for-text-detection-using-OpenCV/zip and extract the compressed model in the appropriate path inside the `models` folder. Install Tesseract (v4) from http://mop.tamu.edu/Installing-Tesseract-Windows8, for example, and the `pytesseract` package with `pip`. Import the required libraries using the following code snippet:

```
import pytesseract
from imutils.object_detection import non_max_suppression
```
