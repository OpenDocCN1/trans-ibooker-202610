## 使用变分自编码器重建和生成图像

变分自编码器（Variational Autoencoder，VAE）是一种生成模型，它使用贝叶斯推断，并试图对图像的底层概率分布进行建模，以便可以从该分布中采样新图像。就像普通自编码器一样，它由两个组件组成：一个编码器（在标准自编码器中将输入压缩到瓶颈的一组层）和一个解码器（在标准自编码器中从瓶颈的压缩表示重建输入的一组层）。VAE 与普通自编码器的区别在于，编码器不是将输入层映射到称为瓶颈向量的潜在变量，而是将输入映射到一个分布。然后从该分布中绘制随机样本并将其馈送到解码器。

由于无法通过采样节点运行反向传播并推送梯度，因此应用了重参数化技巧，其中通过搁置随机部分，使用反向传播学习图像的均值和标准差向量。VAE 的目标是变分下界；它还确保学习到的分布不会远离标准正态分布。它试图使用变分（贝叶斯）推断来估计真实后验（pθ(z|x)）。以下图示说明了前面的步骤：

![](img/7e2c8bbde0ebcd14e54d2862adfee480_402_0.png)

这里，pθ(x|z)、z 和 qφ(z|x) 分别表示解码器网络、潜在变量和编码器网络。在本示例中，我们将使用 Fashion MNIST 图像数据集来训练，然后使用 VAE 生成新图像，并在 PyTorch 中实现它。

- 3. 定义 VAE 类，该类具有 encode()、decode()、forward() 和 reparameterize() 方法，通过实现 VAE 来完成，如以下代码块所示：

```
z_dim = 32 # latent variable dimension
class VAE(nn.Module):
    def __init__(self):
        super(VAE, self).__init__()
        self.fc1 = nn.Linear(n*n, 512)
        self.fc21 = nn.Linear(512, z_dim) # mu
        self.fc22 = nn.Linear(512, z_dim) # sigma
        self.fc3 = nn.Linear(z_dim, 512)
        self.fc4 = nn.Linear(512, n*n)

    def encode(self, x):
        h1 = F.relu(self.fc1(x))
        return self.fc21(h1), self.fc22(h1)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5*logvar)
        eps = torch.randn_like(std)
        return mu + eps*std

    def decode(self, z):
        h3 = F.relu(self.fc3(z))
        return torch.sigmoid(self.fc4(h3))

    def forward(self, x):
        mu, logvar = self.encode(x.view(-1, n*n))
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar
```

- 5. 为 VAE 实现损失函数，即对所有元素和批次求和的重建损失和 KL 散度损失：

```
def loss_function(recon_x, x, mu, logvar):
    BCE = F.binary_cross_entropy(recon_x, x.view(-1, n*n), \
    reduction='sum')
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return BCE + KLD
```

- 6. 实现 train 函数：

```
def train(epoch):
    model.train()
    batch_idx = 0
    train_loss = 0
    losses = []
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        recon_batch, mu, logvar = model(data)
        loss = loss_function(recon_batch, data, mu, logvar)
        loss.backward()
        train_loss += loss.item()
        optimizer.step()
        if batch_idx % log_interval == 0:
            print('Train Epoch: {} [{}/{} ({:.0f}%)]\tLoss: {:.6f}'.format(
                epoch, batch_idx * len(data), len(train_loader.dataset),
                100. * batch_idx / len(train_loader), loss.item() / len(data)))
        batch_idx += 1
    print('=====> Epoch: {} Average loss: {:.4f}'.format(epoch,
        train_loss / len(train_loader.dataset)))
```
