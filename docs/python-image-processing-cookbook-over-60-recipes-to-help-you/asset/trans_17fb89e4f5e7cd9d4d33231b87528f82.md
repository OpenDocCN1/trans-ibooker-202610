## 前言

随着无线设备和移动技术的进步，对数字图像处理技能的需求与日俱增，以便从日益增长的图像量中提取有用信息。本书全面介绍了工具和算法，并指导您进行图像处理的分析和可视化。

借助 60 多个前沿示例，您将解决图像处理中的常见挑战，并学习如何使用大型混合数据集执行图像检测、图像分割和图像重建等复杂任务。专门章节还将指导您实现各种图像增强和图像恢复技术，例如卡通化、梯度融合和稀有字典学习。随着学习的深入，您将掌握人脸变形和图像分割技术。本书侧重于实用解决方案，将帮助您应用基于深度学习的技术（如迁移学习和微调）来解决现实问题。

阅读完这本 Python 图书后，您将能够熟练应用图像处理技术，充分发挥 Python 生态系统的能力。

## 适合读者人群

本 Python 烹饪书面向图像处理工程师、计算机视觉工程师、软件开发人员、机器学习工程师，或任何希望通过基于示例的方法熟练掌握图像处理技术和方法的人。虽然不需要图像处理知识，但需要具备先前的 Python 编码经验，才能理解本书中涵盖的关键概念。

## 本书内容概览

### 第 1 章，图像操作与变换

是您将学习如何使用不同的 Python 库（NumPy、SciPy、scikit-image、OpenCV 和 Matplotlib）进行图像操作和变换的地方。您将学习如何编写 Python 代码来执行点变换（对数/伽马变换、Gotham 滤镜、颜色空间变换和增加亮度/对比度）以及几何变换（漩涡变换、透视变换和单应性）。

### 第 2 章，图像增强

是您将学习如何使用不同的 Python 库（NumPy、SciPy、scikit-image、OpenCV、PyWavelet 和 MedPy）对图像进行去噪的地方（使用线性/非线性滤波器、快速傅里叶变换 (FFT) 和自编码器）。您将学习如何实现图像增强技术，例如直方图均衡/匹配、素描/卡通化、金字塔融合/梯度融合以及带零交叉的边缘检测。

### 第 3 章，图像恢复

是您将学习如何使用反卷积（逆/维纳/LMS）滤波器（使用 NumPy、scikit-image、OpenCV 和 scikit-learn）实现图像恢复的地方。您将学习如何使用修复、变分方法和稀有字典学习实现图像恢复。您还将学习如何使用 pysteg 实现隐写术/隐写分析技术。

### 第 4 章，二值图像处理

是您将学习如何使用不同的 Python 库（NumPy、SciPy、scikit-image 和 OpenCV）进行二值图像处理的地方（使用数学形态学）。您将学习如何实现形态学算子、滤波器和模式匹配，并了解如何将其应用于分割、指纹增强、对象计数和 blob 分离。

### 第 5 章，图像注册

是您将学习如何使用不同的 Python 库（NumPy、scikit-image、OpenCV 和 PyStasm）进行图像匹配/注册/拼接的地方。您将学习如何使用基于变形/特征（SIFT/SURF/ORB）的方法和 RANSAC 算法实现图像注册技术。您还将学习如何实现全景图像创建、人脸变形，以及如何实现基本图像搜索引擎。

### 第 6 章，图像分割

是您将学习如何使用不同的 Python 库（NumPy、scikit-image、OpenCV、SimpleITK 和 DeepLab）进行图像分割的地方。您将学习如何使用基于图的方法/聚类方法、超像素化和机器学习算法实现图像分割技术。您还将学习如何使用 DeepLab 实现语义分割。

### 第 7 章，图像分类

是您将学习如何使用不同的 Python 库（scikit-learn、OpenCV、TensorFlow、Keras 和 PyTorch）进行图像分类的地方。您将学习如何实现基于深度学习的技术，例如迁移学习/微调。您将学习如何实现全景图像创建和人脸变形。您还将学习如何实现用于手势和交通信号的基于深度学习的分类技术。

### 第 8 章，图像中的物体检测

是您将学习如何使用不同的 Python 库（scikit-learn、OpenCV、TensorFlow、Keras 和 PyTorch）进行图像中物体检测的地方。您将学习如何实现经典机器学习（HOG/SVM）技术以及深度学习模型来检测物体。您还将学习如何实现图像中的条形码检测和文本检测。

### 第 9 章，人脸检测与识别

是您将学习如何使用不同的 Python 库（scikit-learn、OpenCV、dlib、TensorFlow、Keras、PyTorch、DeepFace 和 FaceNet）进行图像中人脸检测的地方。您还将学习如何使用深度学习实现面部关键点识别以及面部/情绪/性别识别。

## 充分利用本书

要理解和运行代码，需要具备 Python 和图像处理的基础知识，还需要能够访问几个在线图像数据集和本书的 GitHub 链接。

需要 Python 3.5+（代码测试使用了 Python 3.7.4），Windows 用户最好安装 Anaconda，以及 Jupyter（用于查看/运行笔记本）。

所有代码均在配备 32 GB RAM 和 Intel i7 系列处理器的 Windows 10 (Pro) 上进行了测试。但是，代码在 Linux 上运行时应几乎不需要或不需要更改。

您需要使用 pip3 安装所有所需的 Python 包。

建议能够访问 GPU，以便运行涉及深度学习训练（即涉及 TensorFlow、Keras 和 PyTorch 等库的训练）的示例，运行速度会快得多。最适合使用 GPU 运行的代码在配备 Nvidia Tesla K80 GPU（带 CUDA 10.1）的 Ubuntu 16.04 机器上进行了测试。

还需要具备基础数学背景才能理解本书中的概念。
