12. For the training phase, compute the training loss and run a backward pass (back propagation) to update the model weights. For the validation phase, just compute the validation loss (with the `loss_function()`, using the actual and the predicted class labels for a traffic signal instance):

        output = model(data.to(device))
        target = target.long().to(device)
