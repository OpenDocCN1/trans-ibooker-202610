# # Segmentation with GMM-EM

Run the following steps to segment an MR T1 brain image using GMM-EM, this time using scikit-learn library functions:

+   1. First, download the atlas image from atlas_slicez90.nii.gz (this is a high-quality image, obtained by registering and averaging inpatient T1 brain images) from https://github.com/curiale/Medical-Image-Analysis-IPython-Tutorials/tree/master/tutorial_3/data. Read the brain slice image with the following code snippet:

```
```python
max_int_val = 512;
image = sitk.ReadImage("images/atlas_slicez90.nii.gz",
sitk.sitkFloat32)
image = sitk.RescaleIntensity(image, 0.0, max_int_val)
image_data = sitk.GetArrayFromImage (image)
```
```

+   2. Compute the parameters for the Gaussian mixture model:

```
```python
g = GaussianMixture(n_components=4, covariance_type='diag',
tol=0.01, max_iter=100, n_init=1, init_params='kmeans')
```
```

+   3. Estimate the GMM model parameters (using MLE) with the expectation maximization (EM) algorithm:

```
```python
g.fit(image_data[0].flatten().reshape(-1, 1))
```
