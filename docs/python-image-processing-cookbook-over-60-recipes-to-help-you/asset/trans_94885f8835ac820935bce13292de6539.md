## 转换颜色空间（RGB → Lab）

CIELAB（缩写为 Lab）颜色空间由三个颜色通道组成，用三个元组（**L、a、b**）表示像素的颜色，其中 **L** 通道代表 **亮度/照明/强度**（明度）。**a** 和 **b** 通道分别代表 **绿-红** 和 **蓝-黄** 颜色分量。该颜色模型完全将 *强度* 与 *颜色* 分离。它与设备无关且具有广泛的 *色域*。在此配方中，您将看到如何将 RGB 转换为 Lab 颜色空间及其逆转换，以及该颜色模型的实用性。
