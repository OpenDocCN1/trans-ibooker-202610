Implement a function match that performs the classification task—that is, it accepts the extracted features of a new image along with the features of the reference images as parameters, then matches the new image with the reference images and returns the index of the reference image that is the nearest in feature space (let's use Euclidean distance, here):

```
def match(feats, ref_feats):
    min_error = np.inf
    min_i = None
    for i in range(ref_feats.shape[0]):
        error = np.sum((feats - ref_feats[i, :])**2)
        if error < min_error:
            min_error = error
            min_i = i
    return min_i
```
