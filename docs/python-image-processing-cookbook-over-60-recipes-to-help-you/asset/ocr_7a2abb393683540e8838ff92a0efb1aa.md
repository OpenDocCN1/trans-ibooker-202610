Only the weights of the convolutional layers were loaded for the pretrained VGG16 model (with `include_top=False`, the weights corresponding to the last two FC layers were not loaded); this model was used as the classifier model. Note that the size of the last layer was 7 x 7 x 512.

A couple of new FC layers were added on top of the pretrained convolutional layers (the weights for these layers are to be trained on the training image partition using forward/backward propagation), followed by a softmax output layer that has three classes.
