# 引言

我从事数据科学领域的工作已超过十年，而我是在 15 多年前接触到 Python 的。当我第一次使用 NumPy、Matplotlib 和 Pandas 等库时，我发现翻阅各种印刷书籍、视频教程和在线文章中的所有可用文献有点乏味，因为其中大多数缺乏适合初学者的全面步骤。于是我决心写一本这样的书，很高兴在 Apress 的帮助下，我能够将这一决心付诸实践。

本书是数千小时工作的成果（除了撰写实际书籍所花费的时间之外），包括阅读技术文档、观看培训视频、使用不同工具编写代码、调试有问题的代码片段、在各种技术论坛上提问和参与讨论，以及参考各种代码仓库以获取提示。我以初学者易于理解的方式撰写了本书。本书包含数百个代码示例和代码输出图像，以便您完全理解每个引入的概念。所有代码示例都进行了详细解释。

本书首先对 Python 进行一般性讨论，并提供一个小指南，解释如何在各种计算平台上安装它，例如 Windows 操作系统和 Linux 计算机（如 Raspberry Pi）。然后我们将讨论科学生态系统。然后我们重点关注 NumPy，它是数值计算的基础库。我们特别关注 NumPy 的多维、类数组数据结构，称为 *Ndarray*。然后我们探索数据可视化库，如 Matplotlib 和 Plotly，以学习如何绘制 Ndarrays。

大多数章节都探讨数据可视化库 Matplotlib。您将在这些章节中学习大量数据可视化技巧和技术。

然后我们深入 Pandas，以便您可以了解其重要的数据结构，称为 *series* 和 *dataframe*。在本书中途，您还将学习如何使用 Python、NumPy、Matplotlib 和 Pandas 从各种数据源读取数据。您还将学习如何使用流行的可视化库（如 Matplotlib 和 Seaborn）可视化 Pandas 数据，以及如何处理时间索引数据。
