+   - Python programming language
+   - Python installation on various platforms
+   - Python modes
+   - Python IDEs
+   - Scientific Python ecosystem
+   - Overview and setup of Jupyter Notebook
+   - Running code in Jupyter Notebook

After reading this chapter, you will be comfortable with the installation and the basic usage of the Python 3 programming language in various modes on various platforms.
