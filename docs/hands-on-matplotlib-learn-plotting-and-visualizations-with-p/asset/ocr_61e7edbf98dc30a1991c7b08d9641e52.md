# Basic Operations on Series

You can perform a few basic operations on a series. For example, you can display the negative numbers as follows:

```
print(s5[s5 < 0])
```

The output is as follows:

```
e    -3.14
dtype: float64
```

You can retrieve the positive numbers as follows:

```
print(s5[s5 > 0])
```

The output is as follows:

```
a    3.0
b    2.0
c    1.0
d    75.0
dtype: float64
```

These were examples of a comparison operation. You can perform arithmetic operations such as multiplication as follows:

```
c = 3
print ( s5 * c )
```

The output is as follows:

```
a      9.00
b      6.00
c      3.00
d    225.00
e     -9.42
dtype: float64
```
