The same visualization can be prepared with Seaborn, which produces a much better bar plot aesthetically.

```
sns.barplot(x=x, y=y1)
plt.xticks(rotation=45)
plt.show()
```

You can even change the color palette as follows:

```
sns.barplot(x=x, y=y1,
    palette="Blues_d")
plt.xticks(rotation=45)
plt.show()
```
