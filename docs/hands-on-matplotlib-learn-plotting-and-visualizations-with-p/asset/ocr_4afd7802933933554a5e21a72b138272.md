# Introducing Jupyter Notebook

Earlier in this chapter, you learned various ways to run Python statements. You ran Python statements in a script and in the interpreter’s interactive mode. The main advantage of using interactive mode is the immediate feedback. The main disadvantage of this mode is that if you make any mistakes in the statements you’re typing in, you must write the entire statement again to re-execute it. Also, it is difficult to save it as a program. The option for saving the statements to run on the interpreter can be found in the File option of the menu. However, all the statements and their outputs will be saved in plain-text format with the .py extension.
