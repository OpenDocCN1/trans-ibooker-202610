# Exploring the Scientific Python Ecosystem

The scientific Python ecosystem is a collection of open source Python libraries for scientific computing. It has the following core components:

+   - *Python*: This is a programming language.
+   - *NumPy*: This is the fundamental library for numerical computation. Almost all the libraries in the scientific Python ecosystem are based on NumPy. It provides a versatile data structure known as an *Ndarray* (for “N-dimensional array”).
