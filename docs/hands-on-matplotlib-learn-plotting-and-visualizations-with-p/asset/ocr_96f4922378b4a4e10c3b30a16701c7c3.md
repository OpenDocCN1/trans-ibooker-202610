The previous graphs were examples of vertical bar graphs. Similarly, you can have horizontal bar graphs as follows:

```
```python
x = np.arange(4)
y = np.random.rand(4)
plt.barh(x, y)
plt.show()
```
```

Figure 6-10 shows the output.

![](bbox=[0.287, 0.294, 0.711, 0.488])

**Figure 6-10.** *Horizontal bar graph*

You can also have combined horizontal bar graphs as follows:

```
```python
y = np.random.rand(3, 4)
plt.barh(x + 0.00, y[0], color = 'b', height=0.25)
plt.barh(x + 0.25, y[1], color = 'g', height=0.25)
plt.barh(x + 0.50, y[2], color = 'r', height=0.25)
plt.show()
```
