# Multiline Plots

It is possible to visualize multiple plots in the same output. Let’s see how to show multiple curves in the same visualization. The following is a simple example:

```
```python
%matplotlib inline
import numpy as np
import matplotlib.pyplot as plt
x = np.arange(7)
plt.plot(x, -x**2)
plt.plot(x, -x**3)
plt.plot(x, -2*x)
plt.plot(x, -2**x)
plt.show()
```
```
