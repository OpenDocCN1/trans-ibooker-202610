You can even pass a NumPy Ndarray as an argument to the constructor function to create a series, as follows:

```
```python
import numpy as np
y = np.array(x)
s4 = pd.Series(y)
```
```

You can see the values as follows:

```
```python
print(s4.values)
```
```

The following is the output:

```
```
[ 3.    2.    1.   75.   -3.14]
```
```

You can retrieve the index as follows:

```
```python
print(s4.index)
```
```

The output is as follows:

```
```
RangeIndex(start=0, stop=5, step=1)
```
```

You can assign a custom index as follows:

```
```python
s5 = pd.Series( x, index = ['a', 'b', 'c', 'd', 'e'])
print(s5)
```
```

The output is as follows:

```
```
a     3.00
b     2.00
c     1.00
d    75.00
e    -3.14
dtype: float64
```
```
