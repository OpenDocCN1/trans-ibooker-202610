plt.errorbar(x, y, xerr = xe, yerr = ye)

# Bar Graphs

A bar graph is a representation of discrete and categorical data items with bars. You can represent the data with vertical or horizontal bars. The height or length of bars is always in proportion to the magnitude of the data. You can use bar charts or bar graphs when you have discrete categorical data. The following is a simple example of a bar graph:

```
x = np.arange(4)
y = np.random.rand(4)
plt.bar(x, y)
plt.show()
```
