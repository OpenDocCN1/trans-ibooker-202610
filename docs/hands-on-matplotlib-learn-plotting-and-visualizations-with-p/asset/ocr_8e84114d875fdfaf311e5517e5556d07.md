plt.streamplot(X, Y, U, V,

You can also use quiver plots for the vector visualizations as follows:

```
X = np.arange(-5, 5, 0.5)
Y = np.arange(-10, 10, 1)
U, V = np.meshgrid(X, Y)
plt.quiver(X, Y, U, V)
plt.show()
```
