## Plotting 3D Lines

Let’s plot a 3D line. Let’s create a figure and axes, as shown here:

```python
fig = plt.figure()
ax = plt.axes(projection='3d')
```

Let’s create 3D data as follows:

```python
z = np.linspace(0, 30, 1000)
x = np.sin(z)
y = np.cos(z)
```

You can create a 3D plot as follows:

```python
ax.plot3D(x, y, z, 'red')
plt.show()
```

Figure 11-2 shows the output.

![](img/124f805c8155c7226d129ebbcc2842f0_155_0.png)

## 3D Scatter Plots

You can create random points and show them with a 3D scatter as follows. Let’s create a figure and axes first, as shown here:

```python
fig = plt.figure()
ax = plt.axes(projection='3d')
```

```python
X = np.linspace(-10, 10, 30)
y = np.linspace(-10, 10, 30)
X, Y = np.meshgrid(X, y)
Z = np.sin(np.sqrt(X ** 2 + Y ** 2))
```

You can create a contour as follows:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
ax.contour(X, Y, Z, 50, cmap='coolwarm')
plt.show()
```

Figure 11-4 shows the output.

![](img/124f805c8155c7226d129ebbcc2842f0_157_0.png)

**Figure 11-4.** 3D contour plot

You can obtain similar output as visualized in Figure 11-4 using the following code:

```python
fig = plt.figure()
ax = plt.axes(projection='3d')
ax.contour3D(X, Y, Z, 40,
    cmap='coolwarm')
plt.show()
```

You can also create a filled contour with the function contourf() as follows:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
ax.contourf(X, Y, Z, 50, cmap='coolwarm')
plt.show()
```

## Bar Graphs

You can show 2D bars in 3D axes. Let’s create a figure and axes, as shown here:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
```

Let's define colors for the bars.

```python
colors = ['r', 'g', 'b', 'c', 'm', 'y','k']
yticks = [0, 1, 2, 3, 4, 5, 6]
```

Now, let's create bar graphs with the defined colors with the following loop:

```python
for c, k in zip(colors, yticks):
    x = np.arange(25)
    y = np.random.rand(25)
    ax.bar(x, y, zs=k, zdir='y',
           color=c, alpha=0.8)
plt.show()
```

Figure 11-8 shows the output.

![](img/124f805c8155c7226d129ebbcc2842f0_162_0.png)

**Figure 11-8.** Visualizing 2D bars in 3D coordinates

You can also create a 3D bar graph with Matplotlib. Let’s create the data first, as shown here:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')

x = np.arange(10) * np.arange(10)
y = np.arange(10) * np.arange(10)
x, y = np.meshgrid(x, y)
x, y = x.ravel(), y.ravel()
top = x + y
bottom = np.zeros_like(top)
width = depth = 5
```

You can then show this as 3D bars as follows:

```python
ax.bar3d(x, y, bottom, width,
         depth, top,
         shade=True,
         color='g')
plt.show()
```

## Quiver and Stem Plots

A quiver plot is used to represent directional entities (for example, vectors). Let's define the data, as shown here:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
x = y = z = np.arange(-0.1, 1, 0.2)
X, Y, Z = np.meshgrid(x, y, z)
u = np.cos(np.pi * X) * np.sin(np.pi * Y) * np.sin(np.pi * Z)
v = -np.sin(np.pi * X) * np.cos(np.pi * Y) * np.sin(np.pi * Z)
w = np.sin(np.pi * X) * np.sin(np.pi * Y) * np.cos(np.pi * Z)
```

Finally, you can visualize the data as follows:

```python
ax.quiver(X, Y, Z, u, v, w,
          length=0.1,
          normalize=True)
plt.show()
```

Figure 11-10 shows the output.

![](img/124f805c8155c7226d129ebbcc2842f0_165_0.png)

**Figure 11-10.** *Quiver plots*

You can also create stem plots where perpendicular lines are drawn in the visualization. Let’s use trigonometric functions to define the data, as shown here:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
theta = np.linspace(0, 2 * np.pi)

x = np.sin(theta)
y = np.cos(theta)
z = np.cos(theta)
```

You can visualize the stem plot as follows:

```python
ax.stem(x, y, z)
plt.show()
```

## 3D Volumes

You can show 3D volumetric data as enclosed surfaces. Let’s create such data as follows:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
u = np.linspace(0, 2 * np.pi, 100)
v = np.linspace(0, np.pi, 100)
x = 10 * np.outer(np.cos(u), np.sin(v))
y = 10 * np.outer(np.sin(u), np.sin(v))
z = 10 * np.outer(np.ones(np.size(u)), np.cos(v))
```

You can show this data as a sphere as follows:

```python
ax.plot_surface(x, y, z)
plt.show()
```

Figure 11-12 shows the output.

![](img/124f805c8155c7226d129ebbcc2842f0_167_0.png)

**Figure 11-12.** Surface plot as a volume

ma = np.random.randint(1, 3, size=(3, 3, 3))

ax.voxels(ma, edgecolor='k')
