Here’s an example of the function call for the function arange() with the start and stop arguments:

```
np.arange(2, 6)
```

It returns the following output (it directly prints and we are not storing it in a variable):

```
arrray([2, 3, 4, 5])
```

We can even add an argument for the interval as follows:

```
np.arange(2, 6, 2)
```

The output is as follows:

```
arrray([2, 4])
```
