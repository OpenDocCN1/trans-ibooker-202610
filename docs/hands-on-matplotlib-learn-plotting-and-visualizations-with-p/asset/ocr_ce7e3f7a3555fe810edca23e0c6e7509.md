Let’s define the function as follows:

```
def f(x, y):
    return (x ** 3 + y ** 2)
```

Let’s visualize it as an image, as follows:

```
n = 10
x = np.linspace(-3, 3, 8 * n)
y = np.linspace(-3, 3, 6 * n)
X, Y = np.meshgrid(x, y)
Z = f( X, Y )
plt.imshow(Z, interpolation='nearest',
           cmap = 'cool', origin='lower')
plt.axis('off')
plt.show()
```
